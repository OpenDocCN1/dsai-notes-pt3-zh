## 协变量偏移问题

在基于批次的训练中，一个主要问题是协变量偏移。观察学习到的节点表示或嵌入，例如其第一维（F1）和第二维（F2）特征，在训练初期，这些特征之间的关系呈现某种分布。随着梯度下降优化的进行，这种特征关系的分布形状会发生显著变化，甚至在连续两次迭代之间产生巨大偏移。

这种不稳定性带来了很大问题，因为节点嵌入是激活函数的输出，而激活函数的输入包含了权重变换和聚合操作。嵌入的不稳定意味着模型训练过程不稳定。

## 批归一化层原理

为了解决上述问题，批归一化层被引入神经网络，旨在稳定训练过程。批归一化对每个激活值 **H** 进行平移和重新缩放，使得整个批次的均值和方差成为训练过程中可学习的值。

以下是批归一化的核心操作步骤：

1.  **计算批次统计量**：对于一个批次 **B** 中的所有节点嵌入，计算其经验均值 **μ_B** 和方差 **σ_B^2**。
    *   **公式**：`μ_B = (1/m) * Σ_{i=1}^{m} H_i`， `σ_B^2 = (1/m) * Σ_{i=1}^{m} (H_i - μ_B)^2`，其中 **m** 是批次大小。
2.  **归一化**：使用计算出的均值和方差对每个节点嵌入 **H_i** 进行归一化。
    *   **公式**：`Ĥ_i = (H_i - μ_B) / √(σ_B^2 + ε)`，其中 **ε** 是一个极小的常数，用于防止除以零。
3.  **缩放与平移**：对归一化后的值进行可学习的缩放和平移变换。
    *   **公式**：`BN(H_i) = γ * Ĥ_i + β`
    *   其中 **γ**（缩放参数）和 **β**（平移参数）是该层可学习的参数，与网络权重一同优化。

## 批归一化的优势

![](img/bebeea53376b8a8762426882d28a35a2_16.png)

![](img/bebeea53376b8a8762426882d28a35a2_17.png)

批归一化为训练带来了多项显著优势：

![](img/bebeea53376b8a8762426882d28a35a2_19.png)

![](img/bebeea53376b8a8762426882d28a35a2_20.png)

![](img/bebeea53376b8a8762426882d28a35a2_21.png)

![](img/bebeea53376b8a8762426882d28a35a2_23.png)

*   **允许使用更高的学习率**：批归一化平滑了损失函数的曲面，使梯度更新方向更稳定，减少了“之字形”震荡。这使得我们可以使用更大的学习率，从而加速收敛。
*   **起到正则化作用**：归一化依赖于整个批次的统计量，这相当于向训练过程注入了噪声。这种依赖于批次组成的“扰动”有助于模型更好地泛化，防止过拟合。
*   **稳定前向传播**：通过每层学习的 **γ** 和 **β** 参数，批归一化控制了节点嵌入在连续网络层之间的方差。这稳定了网络变换函数（如权重矩阵 **W**），使网络能够更有效、更可控地进行学习。

从效果对比图可以看出，使用批归一化后，特征关系在优化过程中变化更平缓、路径更一致，损失函数曲面也更平滑，这与未使用批归一化的不稳定、震荡的训练过程形成鲜明对比。
