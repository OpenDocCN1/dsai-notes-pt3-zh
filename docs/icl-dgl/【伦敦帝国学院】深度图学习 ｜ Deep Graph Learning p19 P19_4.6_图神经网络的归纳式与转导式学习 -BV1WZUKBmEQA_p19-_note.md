# 深度图学习：P19：图神经网络的归纳式与转导式学习 🧠

![](img/3174610bc579d5320ebdb00a864c0267_0.png)

![](img/3174610bc579d5320ebdb00a864c0267_2.png)

在本节课中，我们将要学习图神经网络（GNN）的两种核心训练范式：归纳式学习和转导式学习。我们将探讨它们的定义、工作原理、各自的优缺点，以及如何在实际应用中进行转换和选择。

## 概述

到目前为止，我们在所有之前的课程中只探讨了归纳式学习。归纳式学习是机器学习和深度学习中的常规设置。其核心思想是，训练数据与测试数据完全独立。训练和测试是两个独立的步骤。

现在，我们来看看另一种可能的方式：同时进行训练和测试，这被称为转导式学习。

## 归纳式学习 🧩

![](img/3174610bc579d5320ebdb00a864c0267_4.png)

在归纳式学习中，我们首先在训练集上训练模型，然后在独立的测试集上测试模型。这是一个两步过程。

![](img/3174610bc579d5320ebdb00a864c0267_6.png)

以下是归纳式学习的步骤：
1.  **在训练集上训练模型**：使用带有标签的训练数据来学习一个通用的映射规则。
2.  **在测试集上测试模型**：将学习到的规则应用于未见过的测试数据，以预测其标签。

![](img/3174610bc579d5320ebdb00a864c0267_7.png)

![](img/3174610bc579d5320ebdb00a864c0267_9.png)

![](img/3174610bc579d5320ebdb00a864c0267_11.png)

在节点分类任务中，我们拥有多个独立的训练图。训练完成后，我们得到一个独立的测试图，并可以预测该测试图中每个节点的标签。

## 转导式学习 🔄

![](img/3174610bc579d5320ebdb00a864c0267_13.png)

![](img/3174610bc579d5320ebdb00a864c0267_14.png)

![](img/3174610bc579d5320ebdb00a864c0267_15.png)

![](img/3174610bc579d5320ebdb00a864c0267_16.png)

转导式学习与归纳式学习截然不同。在转导式设置中，我们将所有训练样本和测试样本构建成一个**单一的大图**。

这个图的邻接矩阵包含了所有节点（训练节点 + 测试节点）。这些节点并非简单堆叠，而是相互连接的。我们的目标是在这个大图上进行预测。

训练时，我们只计算**有标签的训练节点**上的损失函数并进行优化。然而，由于消息传递机制，测试节点的嵌入表示也会在训练过程中被更新。因此，训练结束时，我们已经得到了测试节点的预测嵌入和标签。

**转导式学习的核心是训练和测试同时进行**。

![](img/3174610bc579d5320ebdb00a864c0267_18.png)

在转导式节点分类中，存在一个包含所有节点的大图。其中一部分节点（训练节点）带有已知标签，另一部分节点（测试节点）的标签是未知的。我们训练模型以正确预测已知的训练节点标签，然后评估模型在未知的测试节点标签上的预测性能，以此检验模型的泛化能力。

上一节我们介绍了两种学习范式的基本概念，本节中我们来看看它们各自的优缺点。

以下是归纳式学习与转导式学习的详细比较：

![](img/3174610bc579d5320ebdb00a864c0267_27.png)

![](img/3174610bc579d5320ebdb00a864c0267_28.png)

![](img/3174610bc579d5320ebdb00a864c0267_29.png)

![](img/3174610bc579d5320ebdb00a864c0267_31.png)

*   **学习目标**
    *   **归纳式**：学习一个通用的映射规则 `f: Graph/Node -> Y`，可应用于任何新数据。
    *   **转导式**：仅为当前数据集中特定的未知节点生成标签，不产生通用规则。

![](img/3174610bc579d5320ebdb00a864c0267_33.png)

*   **处理分布偏移的能力**
    *   **归纳式**：训练时无法访问测试数据的特征分布。若训练集和测试集存在**协变量偏移**（即特征分布不同），模型可能难以泛化。
    *   **转导式**：训练时能同时看到所有节点（包括测试节点）的特征。这有助于模型更好地适应测试数据的分布，缓解分布偏移问题。

![](img/3174610bc579d5320ebdb00a864c0267_35.png)

![](img/3174610bc579d5320ebdb00a864c0267_36.png)

![](img/3174610bc579d5320ebdb00a864c0267_37.png)

*   **内存与计算成本**
    *   **归纳式**：推理时只需加载训练好的模型参数，对测试数据进行前向传播，内存和计算成本较低。
    *   **转导式**：需要将整个大图（包含所有训练和测试节点）存储在内存中，并在整个图上进行消息传递，因此内存占用高，计算更昂贵。

![](img/3174610bc579d5320ebdb00a864c0267_39.png)

*   **对新数据的适应性**
    *   **归纳式**：得益于参数共享，训练好的模型可以立即应用于任何新加入的节点或图，非常适合实时应用。
    *   **转导式**：一旦有新的测试节点加入，就需要将其与原有节点重新构建成图，并**从头开始重新训练**整个模型，非常耗时且不实用。

## 从归纳式到转导式的转换 🔧

了解了两种范式的特点后，我们来看看如何在技术上实现从归纳式节点分类到转导式节点分类的转换。这实际上非常简单。

![](img/3174610bc579d5320ebdb00a864c0267_41.png)

![](img/3174610bc579d5320ebdb00a864c0267_42.png)

在归纳式学习中，对于一个新测试节点 `v_test`，我们将其特征向量输入已训练好的GNN，通过前向传播得到其最终层嵌入 `h_test^(L)`，然后通过一个分类层（如带Sigmoid激活的全连接层）得到预测标签 `ŷ_test`。

用公式可以表示为：
`ŷ_test = σ( h_test^(L) * W_class + b_class )`
其中 `σ` 是Sigmoid函数，`W_class` 和 `b_class` 是分类层的权重和偏置。

在转导式学习中，我们拥有包含 `N` 个节点（`N_train` 个训练节点 + `N_test` 个测试节点）的大图。通过GNN的消息传递，我们得到所有节点的最终嵌入矩阵 `H^(L) ∈ R^(N×d)`。

此时，我们对所有节点同时进行预测：
`Ÿ = σ( H^(L) * W_class + 1 * b_class^T )`
这里 `Ÿ ∈ R^N` 是一个包含所有节点预测分数的向量。`1` 是一个全1的列向量，用于将偏置 `b_class` 广播到所有节点。

**关键区别在于优化过程**：在计算损失函数时，我们只使用训练节点部分的预测 `Ÿ_train` 与真实标签 `Y_train` 进行比较。测试节点部分的预测 `Ÿ_test` 不参与损失计算，但它们的嵌入会在优化训练节点损失的过程中，通过图连接被间接更新。训练完成后，`Ÿ_test` 即为我们对测试节点标签的预测。

因此，我们可以总结为：
*   **优化（训练）**：基于训练节点 `Ÿ_train` vs `Y_train`。
*   **评估（测试）**：基于测试节点 `Ÿ_test` vs `Y_test`（在拥有真实标签的情况下）。

## 总结

![](img/3174610bc579d5320ebdb00a864c0267_49.png)

本节课中我们一起学习了图神经网络的两种基本学习范式。

![](img/3174610bc579d5320ebdb00a864c0267_51.png)

*   **归纳式学习**采用“先训练，后测试”的分离流程，学习通用规则，泛化能力强，效率高，适合动态和实时场景，但可能受训练与测试数据分布差异的影响。
*   **转导式学习**采用“训练与测试联合进行”的方式，将所有数据构建成单一图表，在优化过程中利用测试数据的结构信息，能更好地处理分布偏移，但计算和内存成本高昂，且无法直接泛化到新数据。

选择哪种范式取决于具体的任务需求、数据特性以及对计算效率和泛化能力的权衡。理解这两种范式是灵活应用图神经网络解决实际问题的重要基础。
