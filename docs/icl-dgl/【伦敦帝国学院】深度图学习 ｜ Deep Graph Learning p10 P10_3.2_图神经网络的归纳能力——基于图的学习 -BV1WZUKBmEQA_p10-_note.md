# 深度图学习：P10：图神经网络的归纳能力——基于图的学习 🧠

![](img/563237866fb7f9d485a773a0e9c5f30f_0.png)

在本节课中，我们将要学习图神经网络（GNN）一个非常强大的特性——归纳能力。我们将探讨GNN如何对训练时未见过的节点甚至整个图进行预测，并理解其背后的核心原理。

![](img/563237866fb7f9d485a773a0e9c5f30f_2.png)

## 节点预测的归纳能力

上一节我们介绍了图神经网络的基本训练流程。本节中我们来看看，当一个全新的、未与训练图连接的节点出现时，我们能否预测它的输出分数。

### 核心问题：孤立节点能否获得嵌入？

首先，让我们回顾节点嵌入的更新规则。一个常见的更新公式如下：

`h_v^(k) = σ( W_self^(k) * h_v^(k-1) + W_neigh^(k) * Σ_{u∈N(v)} h_u^(k-1) + b^(k) )`

![](img/563237866fb7f9d485a773a0e9c5f30f_4.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_6.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_8.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_9.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_11.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_12.png)

这个公式包含两个关键部分：
1.  **自编码部分** (`W_self^(k) * h_v^(k-1)`)：处理节点自身的特征。
2.  **邻域聚合部分** (`W_neigh^(k) * Σ_{u∈N(v)} h_u^(k-1)`)：聚合邻居节点的信息。

![](img/563237866fb7f9d485a773a0e9c5f30f_14.png)

对于一个未连接的测试节点，它没有邻居。因此，邻域聚合项将为零。更新规则简化为：

![](img/563237866fb7f9d485a773a0e9c5f30f_16.png)

`h_test^(k) = σ( W_self^(k) * h_test^(k-1) + b^(k) )`

**结论是：可以。** 即使节点未连接，我们仍然可以通过其自身的特征，经过多层参数变换（`W_self`），得到它在最后一层的嵌入表示。

![](img/563237866fb7f9d485a773a0e9c5f30f_18.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_19.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_20.png)

然而，这样做有明显的缺点：
*   **退化为个体化学习**：模型不再考虑该节点与图中其他节点的相互关系和依赖，回到了传统的、将每个样本视为独立同分布的机器学习范式。
*   **丧失GNN的核心能力**：移除了邻域聚合，GNN就退化成了一个简单的多层感知机（MLP）。正是**邻域聚合**赋予了GNN强大的表征学习能力。

![](img/563237866fb7f9d485a773a0e9c5f30f_22.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_23.png)

这个特性被称为GNN的**归纳能力**。GNN可以轻松泛化到未见过的样本，这是其相对于许多传统模型的巨大优势。

![](img/563237866fb7f9d485a773a0e9c5f30f_25.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_26.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_28.png)

### 扩展到多个新节点

那么，能否泛化到同时到来的多个新节点呢？

答案是肯定的，原理相同。假设我们有一个原始图 `G = (V, E)`，以及其特征矩阵 `X`。当加入多个新测试节点后，我们得到一个新图 `G‘ = (V‘, E‘)`，其邻接矩阵 `A‘` 和特征矩阵 `X‘` 的维度都相应增大了。训练好的GNN模型可以直接在这个新图结构上运行，为所有新节点生成嵌入并进行预测。

![](img/563237866fb7f9d485a773a0e9c5f30f_30.png)

这种对动态变化、不同规模图结构的强大泛化能力，是图神经网络的核心魅力之一。

![](img/563237866fb7f9d485a773a0e9c5f30f_32.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_33.png)

## GNN归纳能力的源泉

![](img/563237866fb7f9d485a773a0e9c5f30f_35.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_36.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_37.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_38.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_39.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_41.png)

为什么GNN具备如此强大的归纳能力？这主要源于两个设计：

1.  **特征聚合**：通过聚合邻居信息，模型能够捕捉样本间的相互依赖和图的拓扑结构，实现了从“个体化”学习到“集体化”学习的转变。
2.  **参数共享**：这是关键所在。在更新规则 `h_v^(k) = σ( W^(k) * AGG( h_u^(k-1) for u in {v}∪N(v) ) )` 中，变换参数 `W^(k)` **并不依赖于特定节点v**。同一层的所有节点共享同一套参数 `W^(k)`。

让我们思考一下，如果**不共享参数**会怎样？即每个节点 `i` 在第 `k` 层都有自己独有的参数 `W_i^(k)`。
*   **问题一：参数量爆炸**。需要学习的参数数量变为 `节点数 × 层数`，对于大图来说不可行。
*   **问题二：难以泛化**。对于拓扑结构不同或节点位置不同的新图，应该使用哪套节点参数？模型必须为图中的每个位置重新学习“连接”的含义，这要求训练数据包含大量具有相同拓扑结构的图，极大限制了模型的适用性。

因此，**跨节点的参数共享**使得GNN学习到的是关于“如何根据邻居信息更新任意节点状态”的通用规则，而非针对特定位置节点的记忆。这正是其强大泛化能力的根基。

![](img/563237866fb7f9d485a773a0e9c5f30f_43.png)

## 从节点级到图级的学习

现在，我们面临一个更复杂的场景：如何处理尺寸（节点数）各不相同的图，并进行整图级别的预测？

![](img/563237866fb7f9d485a773a0e9c5f30f_45.png)

### 多分辨率图的学习挑战

![](img/563237866fb7f9d485a773a0e9c5f30f_46.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_48.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_50.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_51.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_52.png)

假设我们有一个大脑网络数据集，包含N个图。每个图 `G_i` 的节点数 `n_i` 可能不同，对应不同的邻接矩阵 `A_i`（尺寸为 `n_i × n_i`）和特征矩阵 `X_i`。每个图都有一个需要预测的目标向量 `y_i`（例如，年龄、IQ分数等）。

如果我们想使用传统机器学习（如SVM）或深度学习（如MLP）来处理这个数据集，会遇到一个根本性障碍：**维度不匹配**。每个图的特征（无论是邻接矩阵向量化还是节点特征拼接）维度都不同，无法直接堆叠成统一的张量进行训练。

![](img/563237866fb7f9d485a773a0e9c5f30f_54.png)

### GNN的解决方案：集成节点嵌入

![](img/563237866fb7f9d485a773a0e9c5f30f_56.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_57.png)

这个问题恰好可以通过GNN的归纳能力来解决。思路是：**先学习图中每个节点的嵌入，然后将所有节点的嵌入集成（整合）为一个全局的图嵌入**。

![](img/563237866fb7f9d485a773a0e9c5f30f_59.png)

以下是具体步骤：

![](img/563237866fb7f9d485a773a0e9c5f30f_61.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_62.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_63.png)

1.  **节点嵌入学习**：使用我们熟悉的GNN层，处理每个输入图，得到图中所有节点在最后一层的嵌入表示 `{h_v^(K) for v in G}`。
2.  **图嵌入集成**：引入一个**集成函数** `I(·)`，将图中所有节点的嵌入聚合为一个单一的向量，即图嵌入：`h_G = I( {h_v^(K) for v in G} )`。
3.  **图级预测**：将这个图嵌入 `h_G` 输入到一个预测头（例如，一个全连接层），输出整图的预测值 `ŷ`。其优化目标与节点级学习类似，只是对象从节点变为了图。

对于训练和测试，流程是统一的：
*   **训练**：对训练集中的每个图，通过GNN前向传播得到节点嵌入，集成后得到图嵌入，计算预测损失并反向传播更新参数。
*   **测试**：对于一个全新的、尺寸任意的测试图，使用训练好的模型执行相同的“前向传播 -> 集成 -> 预测”流程，即可得到预测结果。

![](img/563237866fb7f9d485a773a0e9c5f30f_65.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_66.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_67.png)

这种范式具有极强的通用性，可应用于药物分子（预测毒性）、蛋白质结构、社交网络等任何可以表示为图的数据上进行整图分类或回归任务。

![](img/563237866fb7f9d485a773a0e9c5f30f_69.png)

![](img/563237866fb7f9d485a773a0e9c5f30f_70.png)

*   我们首先探讨了GNN如何对孤立的新节点进行预测，关键在于其更新规则中的**自编码部分**和**参数共享机制**，这使得模型即便在没有邻居信息时也能工作，但会牺牲其核心的协同学习优势。
*   接着，我们理解了这种能力源于**特征聚合**和**跨节点的参数共享**，后者让GNN学习通用的、位置无关的变换规则，从而能泛化到不同大小和结构的图上。
*   最后，我们解决了如何用GNN处理尺寸各异的图并进行整图预测的挑战。方法是**先获取节点嵌入，再通过一个集成函数得到图嵌入**，进而完成图级任务。这解决了传统ML/DL方法在处理变尺寸图数据时维度不匹配的根本问题。
