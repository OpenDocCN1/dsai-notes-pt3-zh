# 005：2.2 特征嵌入的发展概况 📈

![](img/2f873d97cff36be3ac0f07a9daf9d525_0.png)

在本节课中，我们将要学习特征嵌入概念的发展历程。我们将从传统的个体化机器学习方法开始，逐步过渡到流形学习，最终引出基于图的集体化学习范式。我们将探讨如何从图结构中提取特征，并了解传统方法的局限性，为后续学习图卷积网络（GCN）奠定基础。

---

## 从个体化学习到集体化学习

上一节我们介绍了图的基本概念。本节中，我们来看看机器学习中特征表示方法的演变。

![](img/2f873d97cff36be3ac0f07a9daf9d525_2.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_3.png)

首先，我们从一个简单的线性机器学习问题开始。我们将其形式化如下：

**损失函数**：`L(W) = Σ_i loss(y_i, W * x_i)`
**训练样本**：`{(x_i, y_i)}`
**目标**：学习一个在所有训练样本间共享的映射 `W`。

然而，这里的训练样本之间不允许直接交互。这是一个缺点，意味着在学习映射 `W` 时，没有考虑数据点之间的相似性或关系。例如，某个点可能与另一个点非常相似，在学习映射函数 `W` 时，应该将这种关系考虑进去。

![](img/2f873d97cff36be3ac0f07a9daf9d525_5.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_6.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_7.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_8.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_9.png)

这种方法独立地看待每个数据点，我们称之为**个体化方法**。数据样本独立地存在于一个高维流形上。

![](img/2f873d97cff36be3ac0f07a9daf9d525_0.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_11.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_12.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_13.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_15.png)

即使在流形学习中，例如上图所示，我们希望将高维流形上的数据点投影到二维平面，并发现其内在结构。流形学习也试图计算点之间的相似性，并保持邻域关系，即尝试让原始空间中相似的点在目标空间中也保持相似。

![](img/2f873d97cff36be3ac0f07a9daf9d525_2.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_3.png)

但流形学习仍然没有**连接**这些点。它发现了一个能很好表示数据结构和几何分布的空间，但这个空间仍然是“个体化”的。它独立地看待每个点，没有利用点之间的多重交互来建模或表示这个流形。

![](img/2f873d97cff36be3ac0f07a9daf9d525_5.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_6.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_7.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_8.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_9.png)

现在，我们距离真正的交互只差一步。让我们看看下一步。

## 引入图结构：集体化学习

假设我们输入数据的流形结构或分布看起来像这样。

![](img/2f873d97cff36be3ac0f07a9daf9d525_11.png)
![](img/2f873d97cff36cbe3ac0f07a9daf9d525_12.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_13.png)

为了能够在学习过程中建模并包含这些点之间的交互，我们需要学习或定义这些点的**邻接矩阵**。如果我们有 `n` 个点，就会得到一个 `n x n` 的矩阵。这个矩阵编码了所有点之间的交互。

例如，我们可能得到一个如下图所示的图。

![](img/2f873d97cff36be3ac0f07a9daf9d525_15.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_17.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_18.png)

这里我们构建了一个图，它允许我们建模不同点之间的交互。当我们学习如何将单个点 `x_i` 嵌入到一个新的维度空间时，我们会考虑它与邻居的交互。现在，我们学习这个点的嵌入表示，不仅仅基于单个样本的相似性，而是通过观察它的邻域。

![](img/2f873d97cff36be3ac0f07a9daf9d525_19.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_20.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_21.png)

这非常重要，因为我们正在尝试学习一个**结构化的流形**，一个用图编码的流形。这个流形能让我们更好地表示数据，因为现在我们不再独立地看待这些点。实际上，这些点是相互连接的，其中许多点彼此相似或接近。我们正在构建一个连接所有这些点的大图。如果点非常接近，它们将位于同一个图模块中；如果相距甚远，它们之间将会有长边连接。

这里的核心思想不是独立学习，而是**协同学习**。这有一个非常有趣的方面：如果不考虑与其他点的关系，单独看待一个点是高度简化的；但如果考虑一个点与所有其他点的连接或非连接关系，就等于考虑了该特定训练集或批次中训练点的分布相似性，从而能够学得更好。

这基本上就是使用图来建模和捕获数据点对之间的关系。每个样本都与所有其他点交互。这是第二种学习范式：第一种使用个体化点，第二种则定义了一个图，该图编码、表示或建模了不同数据样本之间的交互权重和强度。

![](img/2f873d97cff36be3ac0f07a9daf9d525_17.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_18.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_19.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_20.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_21.png)

现在我们进入了**集体化学习范式**。在这里，数据点是集体化的，它们通过这个图结构矩阵 `A` 共同学习。当然，我们有了图、特征，并定义了邻接矩阵。有些节点相似，所以它们被连接起来。我们可以观察图的拓扑结构，即这些不同节点之间的连接结构。当我们想要学习某个节点的嵌入或预测其标签时，我们不应该独立地预测，而应该依赖于它相邻的相似节点进行预测。这是基本思想。

![](img/2f873d97cff36be3ac0f07a9daf9d525_23.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_24.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_25.png)

此外，我们可以添加边特征和节点特征。请记住，我们现在有了一个可供学习的图。

![](img/2f873d97cff36be3ac0f07a9daf9d525_23.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_24.png)
![](img/2f873d97cff36be3ac0f07a9daf9d525_25.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_27.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_29.png)

既然我们有了图，就可以在其上进行分类等任务。我们将数据编码、表示为图，然后可以应用图神经网络（例如后续将学到的 GCN）来学习图中每个节点的嵌入表示。现在，嵌入学习不再仅仅是在流形上进行，而是在这个图上进行。图中每个节点的图嵌入将使我们能够整合这些知识，并对图进行分类。

## 如何从图中提取特征？ 🛠️

一个关键问题是：我们如何实际获取节点特征、边特征或图特征？你可能在想，既然我们已经将数据建模为图，就需要从图中定义或提取特征。

![](img/2f873d97cff36be3ac0f07a9daf9d525_27.png)

例如，我有一个样本图，它看起来像这样，并且有连接矩阵 `A`。

![](img/2f873d97cff36be3ac0f07a9daf9d525_31.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_29.png)

如何仅从 `A`（即图的邻接矩阵编码的结构）中提取特征？下一步就是解决如何从图中提取特征。

图论中有许多方法可以从图中提取节点、边和图级别的特征。以下将介绍几种简单的方法。如果你有兴趣了解更多，可以查看视频描述中的资源或图论播放列表。

主要有三种类型的特征：基于节点的特征、基于边的特征和基于图的特征。

### 基于节点的特征

在第一讲中，我们讨论过中心性度量、拓扑角色等概念。这些是可用于量化节点在图中的重要性的度量。

对于图 `G`，如果我们要进行节点分类，就需要为每个节点提取特征。

![](img/2f873d97cff36be3ac0f07a9daf9d525_33.png)

**目标**：为节点 `i` 提取一组特征 `x_i ∈ R^d`（`d` 个特征）。

以下是提取节点特征的方法：
*   **中心性度量**：例如度中心性、介数中心性。这些度量可以量化节点在图中的重要性（例如，是否是枢纽节点、边缘节点或连接图不同部分的关键节点）。
*   **手动计算**：例如，某个节点的度为3，我们就可以将3作为一个特征值。这样，我们可以仅从图的拓扑结构中手动提取这些特征。

每个节点 `i` 将由这个特征向量表示，然后我们可以基于此进行学习。例如，我们可以训练一个 SVM 分类器，使用从图中为每个节点提取的这些特征来预测节点标签。

![](img/2f873d97cff36be3ac0f07a9daf9d525_31.png)

### 基于边的特征

最简单的方法是处理图的邻接矩阵 `A`。假设我们有一个无向图（也可以是加权图）。

以下是提取边特征的一种方法：
*   **向量化上三角部分**：我们可以向量化邻接矩阵的**上三角部分**（不包括对角线，因为那是自连接）。对于一个 `n x n` 的矩阵，上三角部分的大小是 `n*(n-1)/2`。这样我们就得到了一个代表整个图的特征向量 `x`，其中每个元素对应一条边的权重（如果是加权图）或连接状态（如果是二值图）。

![](img/2f873d97cff36be3ac0f07a9daf9d525_33.png)

但更常见的是，我们希望为**单条边**提取多个特征，而不仅仅是一个权重值。

**目标**：用多个特征组成的向量 `x` 来表示单条边 `e_ij`。

以下是构建边特征向量的方法：
*   **边权重**：`w_ij`。
*   **边中心性度量**：例如边的介数中心性。这告诉我们这条边是否位于连接图中所有节点对的大部分路径上，即它对于连通性的重要程度。
*   **路径统计**：例如，计算经过该边的游走（walk）数量或平均游走长度等拓扑驱动度量。

这样，对于每条边，我们都有一个特征向量 `x ∈ R^d`。如果我们有目标值（例如边的某种分数），就可以应用线性回归等模型，通过学习映射 `W` 来预测它。

### 基于图的特征

![](img/2f873d97cff36be3ac0f07a9daf9d525_35.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_36.png)

对于图级别的特征，我们可以从边特征或节点特征中整合信息。

![](img/2f873d97cff36be3ac0f07a9daf9d525_38.png)

以下是提取图特征的方法：
*   **整合边特征**：将所有边的特征向量（例如权重）堆叠或拼接起来，形成一个代表整个图 `G` 的长向量。
*   **整合节点特征**：将所有节点的特征（例如中心性度量）堆叠起来，形成代表图 `G` 的向量。
*   **结合两者**：将节点和边的特征以某种方式组合起来。

当我们对图进行分类或从图级别进行学习时，这些方法可以提供图的整体表示。

## 传统图特征提取方法的局限性 ⚠️

然而，上述所有方法都是传统方法，它们仅使用邻接矩阵 `A` 来提取特征。

![](img/2f873d97cff36be3ac0f07a9daf9d525_43.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_44.png)

![](img/2f873d97cff36be3ac0f07a9daf9d525_45.png)

这些传统方法存在几个主要缺点：

1.  **无法利用丰富的特征信息**：它们不能利用节点特征矩阵 `X` 和边特征矩阵 `E`，而仅仅依赖于表示图结构的邻接矩阵 `A`。
2.  **无法获得嵌入表示**：这些方法是基本的图论分析方法，无法为节点学习低维空间的**嵌入表示**。
3.  **缺乏泛化能力，计算效率低**：对于训练集之外的节点，这些方法无法直接获得其嵌入。如果向图中添加一个新节点，由于图的拓扑结构发生了变化，所有基于拓扑的特征（如中心性）都需要重新计算。这意味着每次图结构变动，都需要更新所有节点的特征，这在动态图或大规模图中是非常低效的。
4.  **不适应新节点**：这些静态特征提取方法难以方便地处理未知节点（未在训练中出现的节点）的特征提取问题。

## 总结与展望

本节课中，我们一起学习了特征嵌入思想的发展脉络：

1.  我们从**个体化学习**开始，模型独立处理每个数据点。
2.  然后过渡到**流形学习**，它考虑了数据点之间的相似性和邻域关系，以发现数据的内在结构，但点之间仍然没有显式交互。
3.  接着引入了**基于图的集体化学习**，通过构建图来显式建模数据点之间的交互关系，使得节点能够协同学习。
4.  我们探讨了如何使用传统图论方法从图中提取**节点、边和图级别**的特征。
5.  最后，我们指出了这些传统特征提取方法的**局限性**：它们无法利用额外的节点/边特征，无法学习可泛化的嵌入，并且在图结构变化时计算效率低下。
