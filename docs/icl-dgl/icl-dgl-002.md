在本节课中，我们将深入探讨邻接矩阵，它是图的核心表示。我们将学习邻接矩阵的不同性质，并学习如何诊断它，例如它何时会变得不那么“强韧”。我们将了解如何提取邻接矩阵的属性，并理解其背后的拓扑结构。

## 邻接矩阵的基本性质

邻接矩阵是图的核心表示。我们将首先探索其基本性质，包括对称性、权重以及图的规模。

### 对称性与方向性

邻接矩阵的第一个简单性质与图的对称性有关。无向图对应一个对称矩阵。

例如，观察以下邻接矩阵 **A**。它包含两个节点对，节点 **I** 连接到节点 **J**，节点 **J** 也连接到节点 **I**。这两个元素是对称的。

当 **A_ij = A_ji** 时，意味着矩阵是对称的，这两个权重相同，表明我们只有一条无向边。因此，我们拥有一个**无向图**。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_4.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_6.png)

另一方面，我们也可以拥有**非对称矩阵**。当 **A_ij ≠ A_ji** 时，意味着我们的图是**有向图**。例如，从 **I** 到 **J** 的权重是 0.1，而从 **J** 到 **I** 的权重是 0.3。

### 权重与二元性

接下来，我们看看矩阵是加权的还是二元的。我们的图可以是加权的，也可以是二元的。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_8.png)

*   **二元矩阵**：矩阵中只包含 0 和 1。如果两个节点相连，则置为 1；不相连，则置为 0。
*   **加权矩阵**：矩阵元素 **A_ij** 可以取任何值（例如 0.1, -5.1 等）。加权矩阵是二元矩阵的泛化。

一个常见的问题是：我们能否拥有一个非对称的二元矩阵？答案是肯定的。例如，从 **I** 到 **J** 的连接为 1，但从 **J** 到 **I** 的连接为 0，这就构成了一个有向的二元图。

## 图的规模与密度

上一节我们介绍了邻接矩阵的对称性和权重。本节中，我们来看看图的规模概念，即密度和稀疏性。

图的规模编码在其矩阵中。这里有两个关键要素：
1.  **节点数量**：记为 **|V|**，即集合 V 的基数。
2.  **边数量**：记为 **|E|**，可以通过计算矩阵 **A** 中非零元素的数量得到。

矩阵 **A** 定义了图的规模。节点越多，图越大；边越多，图越密集。

我们根据矩阵中零元素的比例来定义稀疏性和密度：
*   **稀疏矩阵**：如果超过 90% 的元素是零，我们称矩阵是稀疏的。这意味着图中存在大量零连接。
*   **密集矩阵**：如果矩阵中有大量非零连接，则称矩阵是密集的。

图的稀疏性和密度是其非常重要的属性，因为它们影响着图的连通性和信息扩散。随着节点和边数量的增加，计算会变得极具挑战性。

## 置换不变性

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_10.png)

现在，我们来看图的一个关键属性：**置换不变性**。这意味着当我们改变节点的索引（编号）时，虽然会得到一个不同的邻接矩阵，但图本身的拓扑结构保持不变。

例如，我们有一个包含三个节点的简单图。其原始邻接矩阵如下：

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_12.png)

```
节点: 1, 2, 3
矩阵:
[0, 0, 1]
[0, 0, 1]
[1, 1, 0]
```

现在，我们置换节点的索引，例如将顺序改为 3, 2, 1。新的邻接矩阵会不同：

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_14.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_15.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_16.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_18.png)

```
节点: 3, 2, 1
矩阵:
[0, 1, 1]
[1, 0, 0]
[1, 0, 0]
```

尽管这两个矩阵看起来不同，但它们编码的是**同一个图**的拓扑结构。这就是图的置换不变性：图的结构不依赖于节点的具体编号顺序。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_20.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_21.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_22.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_24.png)

这与空间图像形成对比。在图像中，你不能随意置换两个像素的位置而保持图像内容不变。置换不变性是图数据独有的强大属性。

### 如何实现置换？

置换操作可以通过一个**置换矩阵 P** 来实现。置换矩阵是一个方阵，其中每行和每列有且仅有一个元素为 1，其余元素为 0。

如果我们有一个图表示 **X**（可以是邻接矩阵或节点特征矩阵），通过乘以置换矩阵 **P**，我们可以改变节点的索引顺序：

```
X' = P * X
```

要恢复原始的索引顺序，我们可以乘以 **P** 的转置：

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_26.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_27.png)

```
X = P^T * X'
```

强烈建议你拿起纸笔，尝试对一个小的对称矩阵进行置换操作，以加深理解。

## 矩阵乘法的整合能力

到目前为止，我们已经了解了连通性、对称性、图的规模以及置换不变性。现在，我们将探讨矩阵乘法的强大能力，特别是矩阵与向量的乘法。

当我们用一个 **n x n** 的邻接矩阵 **A** 乘以一个 **n x 1** 的向量 **v** 时，会得到一个 **n x 1** 的输出向量 **y**：

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_29.png)

```
y = A * v
```

这个乘法操作利用了矩阵的**聚合能力**。它允许我们沿着每个节点及其局部邻域**整合信息**。

让我来解释一下：假设我们关注节点 **i**。在乘法中，向量 **v** 会与矩阵 **A** 的第 **i** 行相乘。由于 **A** 的第 **i** 行编码了节点 **i** 与所有其他节点的连接权重，这个操作实际上是在计算节点 **i** 的邻域内所有节点值的加权和。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_31.png)

**公式表示**：对于输出向量 **y** 的第 **i** 个元素 **y_i**，其计算方式为：
```
y_i = Σ_j (A_ij * v_j)
```
其中，**j** 遍历所有节点。如果 **A_ij = 0**，则节点 **j** 对 **y_i** 没有贡献。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_33.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_34.png)

**核心思想**：这个操作就像一个**扩散过程**。向量 **v** 中的信息沿着图的拓扑结构（由 **A** 定义）进行传播和整合。对于每个节点，我们收集其邻居的信息，并根据连接强度进行加权。

这种能力非常强大，它构成了图卷积网络（GCNs）的基础。我们稍后将利用它来学习如何嵌入图、表示图、在图进行扩散、寻找最短路径以及执行监督和非监督机器学习任务。

### 与机器学习的类比

这种矩阵-向量乘法形式化了所有机器学习任务。例如，一个简单的线性回归模型可以表示为：

```
ŷ = X * w
```

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_36.png)

其中：
*   **X** 是输入数据矩阵（n 个样本，每个样本有 d 个特征）。
*   **w** 是我们要学习的权重向量。
*   **ŷ** 是预测值。

我们的目标是学习 **w**，使得预测值 **ŷ** 尽可能接近真实值 **y**。这本质上就是通过可学习的权重 **w** 对输入数据 **X** 进行投影或映射。这个过程同样可以建模为一个图，其中权重作为连接。

因此，矩阵乘法可以看作是**扩散**、**整合**、**投影**或**映射**过程。这些术语描述的是同一种现象。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_38.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_39.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_40.png)

## 图的拓扑编码

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_42.png)

邻接矩阵编码了图的拓扑结构。我们可以定义各种度量来量化节点或边在图中的拓扑重要性。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_44.png)

我们可以定义两个函数：
*   **F_N(A)**：量化节点 **N** 的拓扑角色。
*   **F_E(A)**：量化边 **E** 的拓扑角色。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_46.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_47.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_48.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_49.png)

有许多中心性度量可以使用，例如：
*   **度中心性**（用于二元图）：节点 **i** 的度 **d_i** 是其连接边的数量。
    ```
    d_i = Σ_j A_ij  (对于二元图，A_ij ∈ {0,1})
    ```
*   **强度中心性**（用于加权图）：节点 **i** 的强度是其所有连接权重的和。
    ```
    s_i = Σ_j A_ij  (对于加权图)
    ```

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_51.png)

例如，在一个星形图中，中心节点的度最高，因此它是最重要的节点。

对于边，我们可以使用诸如**介数中心性**之类的度量。它衡量一条边出现在图中所有最短路径上的频率。连接两个密集模块的唯一桥梁边通常具有很高的介数中心性，因为移除它会断开图的连接。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_53.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_55.png)

### 通过分布“窃听”拓扑

通过绘制这些拓扑度量的分布图，我们可以“窃听”图的结构。例如，绘制节点度中心性的分布：
*   如果分布显示少数节点具有非常高的中心性，而大多数节点中心性较低，则表明图存在**枢纽节点**。
*   如果绘制边介数中心性的分布，可能会发现一个异常值（值很高的边），这很可能就是图中最关键的那条边。

这种分布分析告诉我们图潜在的结构信息。

### 拓扑的尺度

拓扑分析可以在不同尺度上进行：
1.  **微观尺度**：关注单个节点和边的中心性度量。
2.  **中观尺度**：关注图的组织模式，例如**核心-外围结构**。
3.  **宏观尺度**：关注图的全局属性，如连通组件。

## 矩阵的幂与路径

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_57.png)

邻接矩阵的幂运算揭示了图中路径的信息，这是一个非常强大的性质。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_59.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_60.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_61.png)

*   **邻接矩阵 A**：其元素 **A_ij** 表示从节点 **i** 到节点 **j** 的**长度为 1 的路径**（即直接边）的数量。
*   **A 的平方 (A²)**：其元素 **(A²)_ij** 表示从节点 **i** 到节点 **j** 的**长度为 2 的路径**的数量。
*   **A 的 L 次方 (A^L)**：其元素 **(A^L)_ij** 表示从节点 **i** 到节点 **j** 的**长度为 L 的路径**的数量。

**示例**：
假设我们有一个向量 **e_k**，它是一个独热向量，只有第 **k** 个元素为 1，其余为 0。
*   **A * e_k**：结果向量中的非零元素表示从节点 **k** 出发，通过**一条边**（一步）可以到达的所有节点。
*   **A² * e_k**：结果向量中的非零元素表示从节点 **k** 出发，通过**两条边**（两步）可以到达的所有节点。

通过计算 **A^L**，我们可以探索一个节点的 **L** 跳邻域。这对于理解局部信息传播和发现节点间的最短路径（通过找到使 **(A^L)_ij > 0** 的最小 **L**）非常有用。

## 矩阵的谱分析

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_63.png)

矩阵的**特征分解**是机器学习和图学习中一个非常强大的概念。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_65.png)

### 特征分解定义

对于一个 **n x n** 的矩阵 **A**，特征分解试图找到标量 **λ**（特征值）和向量 **x**（特征向量），使得：
```
A * x = λ * x
```
这意味着矩阵 **A** 对向量 **x** 的线性变换，仅仅是对 **x** 进行缩放（乘以 **λ**），而不改变其方向。特征向量 **x** 是系统的“自然模式”，特征值 **λ** 量化了这些模式的强度或重要性。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_67.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_68.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_69.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_70.png)

### 在图中的应用

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_72.png)

将特征分解应用于图的邻接矩阵 **A**，我们可以得到图的谱信息。
*   **主特征向量**（对应最大特征值的特征向量）给出了图中每个节点的**特征向量中心性**度量。这个值量化了节点在图中的全局重要性。
*   特征值本身也包含了图拓扑的重要信息。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_74.png)

例如，对于一个大脑连通性图（对称矩阵），对其进行特征分解。最大的特征值对应的特征向量，其各元素的大小就反映了各个大脑区域在网络中的中心性。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_76.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_77.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_79.png)

图的谱分析是一个深入的主题，可以揭示图结构的许多基本原理。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_81.png)

## 图的组织模式与效率

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_82.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_83.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_84.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_85.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_86.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_87.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_88.png)

正如在拓扑部分提到的，我们可以通过拓扑度量的分布来推断图的组织模式。图可以具有不同的形状和模式。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_90.png)

研究人员通过定义如**扩散效率**和**路由效率**等度量，来探索图的空间。这些效率衡量了信息在图中的传播速度。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_91.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_92.png)

*   **星形图**：通常具有最高的路由和扩散效率，因为信息可以通过中心节点快速到达任何地方。
*   **链状图**：效率最低，因为信息需要遍历很长的路径才能从一端到达另一端。
*   **核心-外围结构**：效率介于两者之间，具体取决于核心的密度和大小。

可视化图或其邻接矩阵有助于理解这些组织模式。例如，一个具有密集块（核心）和稀疏外围的矩阵，对应着核心-外围结构。

## 效率与韧性

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_94.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_95.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_96.png)

最后，我们探讨图的**效率**和**韧性**。我们可以通过分析矩阵来测量图对攻击（如随机移除节点或边）的韧性。

*   **渗透阈值**：这是一个临界值，当被移除的边（或节点）比例达到此值时，图会分裂成互不连通的碎片。研究这个阈值有助于理解图的韧性。
*   **效率计算**：通过检查信息从一个节点传播到另一个节点的速度来衡量。这取决于图的拓扑属性。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_98.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_99.png)

效率研究的是图的拓扑属性如何约束信息流动的方式，以及哪些特定的图属性可以用于洞察图单元（节点和边）的信息处理能力。

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_101.png)

![](img/a3dfe94de9baa18f3eebc7df4ba63f66_102.png)

例如，攻击一个机场（节点）会影响整个航班网络。研究这种影响可以帮助我们设计更具韧性的网络。

## 总结

在本节课中，我们一起深入学习了邻接矩阵的多种性质及其在图分析中的强大应用：

1.  **基本性质**：我们了解了邻接矩阵如何表示图的对称性（有向/无向）和权重（二元/加权）。
2.  **规模与密度**：我们学习了如何通过节点和边的数量以及矩阵的稀疏性/密度来理解图的规模。
3.  **置换不变性**：我们认识到图的结构不依赖于节点的编号顺序，这是图数据独有的重要属性。
4.  **整合能力**：我们探讨了矩阵-向量乘法的强大之处，它能够沿着图的拓扑结构聚合和扩散信息，这是图神经网络的基础。
5.  **拓扑编码**：我们了解到邻接矩阵编码了图的拓扑结构，并可以通过各种中心性度量在微观、中观和宏观尺度上进行分析。
6.  **矩阵的幂**：我们发现计算邻接矩阵的幂可以揭示图中任意长度路径的信息，对于探索节点邻域至关重要。
7.  **谱分析**：我们简要介绍了特征分解，它可以通过特征向量中心性等方式揭示图的全局拓扑重要性。
8.  **组织模式与效率**：我们明白了不同的图结构（如星形、核心-外围）具有不同的信息传播效率。
9.  **效率与韧性**：我们认识到可以通过分析矩阵来评估图在面对攻击时的稳健性和信息处理效率。
