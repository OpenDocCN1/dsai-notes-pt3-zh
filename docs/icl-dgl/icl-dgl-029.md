在本节课中，我们将要学习一种新的编码器-解码器网络——图U-Net。这是一种自监督的图自动编码器，能够学习图的紧凑表示，并用于图的重建与生成。我们将详细介绍其核心组件，包括图卷积层、图池化与反池化操作，并探讨如何将其扩展以生成新的图数据。

## 概述

图U-Net是一种基于U型结构的自编码器网络，它通过编码器学习图的潜在嵌入表示，再通过解码器重建原始图。其核心目标是最小化重建图与原始图之间的差异。这种结构不仅适用于图的重建，还可以通过扰动潜在空间来生成新的图样本。

## 图U-Net的结构

上一节我们介绍了图生成任务的基本概念，本节中我们来看看图U-Net的具体架构。

图U-Net由编码器和解码器两部分组成，整体呈U型结构。编码器部分通过堆叠的图卷积层和图池化层，逐步下采样，将输入图压缩为一个紧凑的潜在表示。解码器部分则通过图反池化层和图卷积层，逐步上采样，从潜在表示中重建出图。

![](img/82409922a4da6bb9efb239871dbc2d9d_1.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_2.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_3.png)

该模型是一个自编码器，这意味着它是自监督的。它接收一个输入图 `G`，并输出一个重建图 `G_tilde`。其目标是**最小化原始图 `G` 与重建图 `G_tilde` 之间的距离**，这被称为自重建损失。

![](img/82409922a4da6bb9efb239871dbc2d9d_11.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_12.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_13.png)

**自重建损失公式**：
`L = distance(G, G_tilde)`

![](img/82409922a4da6bb9efb239871dbc2d9d_15.png)

学习这种紧凑表示的重要性在于，编码过程能将图映射到一个潜在的嵌入空间。在典型的U-Net中，这个嵌入表示是数据驱动的，并不强制遵循特定的分布（如正态分布）。

## 核心操作：图池化与反池化

![](img/82409922a4da6bb9efb239871dbc2d9d_28.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_29.png)

理解了整体结构后，我们深入探讨其两个关键操作：图池化和图反池化。在卷积神经网络中，池化是下采样，反池化是上采样。图U-Net为图数据定义了类似的操作。

图池化本质上是图的下采样，目的是减少图中的节点数量。图反池化则是图的上采样，目的是恢复图的规模。

![](img/82409922a4da6bb9efb239871dbc2d9d_31.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_32.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_11.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_12.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_13.png)

图U-Net因其U型结构而得名，并且它引入了跳跃连接，这些连接有助于在解码过程中融合编码器不同层的信息。

![](img/82409922a4da6bb9efb239871dbc2d9d_15.png)

### 图池化操作详解

现在，让我们具体看看图池化是如何实现的。图池化的目标是同时缩减节点特征矩阵 `X` 和邻接矩阵 `A`。

以下是图池化的步骤分解：

![](img/82409922a4da6bb9efb239871dbc2d9d_34.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_17.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_18.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_19.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_20.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_21.png)

假设我们有一个包含4个节点、每个节点有5个特征的特征矩阵 `X`（尺寸 4x5），以及对应的邻接矩阵 `A`（尺寸 4x4）。我们的目标是将节点数从4个减少到2个。

![](img/82409922a4da6bb9efb239871dbc2d9d_23.png)

以下是实现图池化的具体步骤：

1.  **学习投影与评分**：首先，我们学习一个可训练的投影向量 `p`（尺寸为 `d x 1`，`d` 是特征维度）。我们用这个向量对每个节点的特征向量进行投影，得到一个标量分数 `y_i`，用于衡量该节点的重要性。
    `y = X * p / ||p||`
    这样，我们得到了一个包含所有节点重要性分数的向量 `y`（尺寸 `n x 1`）。

2.  **选择重要节点**：接着，我们根据分数 `y` 选择得分最高的 `k` 个节点（例如 `k=2`），并记录它们的索引 `idx`。

![](img/82409922a4da6bb9efb239871dbc2d9d_36.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_37.png)

3.  **构建池化后的特征矩阵**：根据索引 `idx`，我们从原始特征矩阵 `X` 中选取对应的行，得到一个较小的矩阵 `X_l`（尺寸 `k x d`）。然后，我们对选出的 `k` 个节点的分数应用 `sigmoid` 函数进行归一化，得到向量 `y_tilde`（尺寸 `k x 1`）。最后，通过元素级乘法对特征进行加权，得到池化后的新特征矩阵 `X_{l+1}`。
    `X_{l+1} = y_tilde ⊙ X_l` （`⊙` 表示元素级乘法，这里通过广播机制实现）

![](img/82409922a4da6bb9efb239871dbc2d9d_39.png)

4.  **构建池化后的邻接矩阵**：同样根据索引 `idx`，我们从原始邻接矩阵 `A` 中选取对应的行和列，得到池化后的新邻接矩阵 `A_{l+1}`（尺寸 `k x k`）。

![](img/82409922a4da6bb9efb239871dbc2d9d_41.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_42.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_43.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_44.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_45.png)

通过以上步骤，我们得到了一个节点更少但保留了最重要节点及其连接关系的“粗化”图。

![](img/82409922a4da6bb9efb239871dbc2d9d_47.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_25.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_26.png)

### 图反池化操作详解

![](img/82409922a4da6bb9efb239871dbc2d9d_51.png)

了解了池化，反池化就相对简单了。图反池化是图池化的逆过程，目的是恢复图的原始规模。

反池化的步骤如下：

1.  **恢复图结构**：利用存储的索引 `idx`，我们知道哪些节点被保留了。在解码器中，我们首先创建一个与原始图规模相同的空特征矩阵（例如7个节点）。将被池化节点（4个）的特征放入对应位置，而将被移除节点（3个）的特征初始化为零。
2.  **恢复邻接关系**：邻接矩阵 `A` 是固定的，我们可以根据原始图的连接关系，轻松恢复出完整规模的邻接矩阵。
3.  **通过GCN更新特征**：这是关键的一步。仅仅恢复零值特征是不够的。接下来，我们应用一个图卷积层。通过消息传递机制，那些被初始化为零的节点特征，会根据其邻居节点的信息被更新，从而获得有意义的特征表示。

## 从重建到生成

图U-Net不仅用于重建，还可用于生成新图。一个直接的想法是：如果我们已经训练好了一个能完美重建原图的U-Net，那么如何让它创造出新的、合理的图呢？

答案在于操作潜在空间中的嵌入表示 `Z`。

![](img/82409922a4da6bb9efb239871dbc2d9d_62.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_63.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_67.png)

假设我们有一个训练好的编码器函数 `F_encoder`（参数为 `θ*`）和解码器函数 `F_decoder`（参数为 `φ*`）。对于输入图 `G_i`，其重建过程为：
`G_tilde_i = F_decoder( F_encoder(G_i; θ*); φ* )`
损失函数是 `L = distance(G_i, G_tilde_i)`。

![](img/82409922a4da6bb9efb239871dbc2d9d_65.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_69.png)

**生成新图的方法如下**：

1.  对输入图 `G_i` 进行编码，得到其潜在表示 `Z_i`。
2.  对 `Z_i` 添加一个小的随机扰动 `ε`，`ε` 可以从某个先验分布（如高斯分布）中采样。
    `Z_new = Z_i + ε`, 其中 `ε ~ P(ε)`
3.  将扰动后的新潜在表示 `Z_new` 输入到训练好的解码器中。
    `G_new = F_decoder(Z_new; φ*)`
4.  解码器将输出一个新的图 `G_new`。通过采样不同的 `ε`，我们可以生成多个符合原始数据分布的新图样本。

![](img/82409922a4da6bb9efb239871dbc2d9d_67.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_69.png)

## 处理边特征的扩展

![](img/82409922a4da6bb9efb239871dbc2d9d_71.png)

一个自然的问题是：标准的图U-Net处理的是节点特征和拓扑结构。如果图还有边特征，该如何扩展模型以同时生成节点特征、边特征和拓扑结构呢？

![](img/82409922a4da6bb9efb239871dbc2d9d_73.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_74.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_73.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_74.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_76.png)

解决方案在2020年的一篇关于解纠缠变分图自动编码器的论文中被提出，其思路直观而清晰。

![](img/82409922a4da6bb9efb239871dbc2d9d_77.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_79.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_76.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_77.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_79.png)

模型结构如下：

![](img/82409922a4da6bb9efb239871dbc2d9d_81.png)

1.  **三个独立的编码器**：
    *   **节点编码器**：接收节点特征矩阵 `F`、邻接矩阵 `A` 和边特征张量 `E`，学习节点特征的潜在表示 `Z_F`。
    *   **拓扑编码器**：接收邻接矩阵 `A`，学习图拓扑结构的潜在表示 `Z_G`。
    *   **边编码器**：接收边特征张量 `E`，学习边特征的潜在表示 `Z_E`。
2.  **变分推断**：每个潜在表示 `Z` 都不是一个确定值，而是从一个分布中采样得到。例如，`Z_F ~ N(μ_F, σ_F)`，其中均值 `μ_F` 和方差 `σ_F` 是编码器的输出，也是可学习的参数。这迫使模型学习到平滑且有意义的潜在空间。
3.  **三个独立的解码器**：采样得到的 `Z_F`, `Z_G`, `Z_E` 被分别送入对应的解码器，重建出节点特征 `F‘`、邻接矩阵 `A’`（或 `G‘`）和边特征 `E‘`。

![](img/82409922a4da6bb9efb239871dbc2d9d_83.png)

![](img/82409922a4da6bb9efb239871dbc2d9d_81.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_83.png)

**生成新图的方法**：
要生成一个全新的图，我们只需从学到的三个分布中分别采样：
`Z_F_new ~ N(μ_F, σ_F)`
`Z_G_new ~ N(μ_G, σ_G)`
`Z_E_new ~ N(μ_E, σ_E)`
然后将这三个采样值输入各自对应的解码器，即可联合生成具有节点特征、边特征和拓扑结构的新图。

![](img/82409922a4da6bb9efb239871dbc2d9d_86.png)
![](img/82409922a4da6bb9efb239871dbc2d9d_88.png)

## 总结与评估

本节课中我们一起学习了生成式图U-Net。我们首先了解了图U-Net作为自编码器的基本结构和目标——最小化自重建损失。然后，我们深入探讨了其核心操作：**图池化**（通过投影评分选择重要节点进行下采样）和**图反池化**（恢复图结构并通过GCN更新特征）。接着，我们学习了如何通过扰动潜在空间嵌入来**生成新的图样本**。最后，我们探讨了如何将模型扩展以处理**边特征**，通过为节点、拓扑和边分别建立编码器-解码器并进行变分推断，来实现对图所有属性的联合生成。

关于生成图质量的评估，这是一个持续研究的前沿领域，有许多指标和方法可供探索，我们将在本单元结束时简要提及。
