## 🧠 P1：L1- 深度学习基础

在本节课中，我们将要学习深度学习的基础概念。这是构建后续所有知识的基石。

上一节我们介绍了课程的整体框架，本节中我们来看看深度学习的核心思想。深度学习是机器学习的一个子领域，它试图使用包含复杂结构或由多重非线性变换构成的多个处理层对数据进行高层抽象。

一个简单的神经元（感知机）可以用以下公式描述：

**`y = f(w·x + b)`**

其中：
*   `x` 是输入向量。
*   `w` 是权重向量。
*   `b` 是偏置项。
*   `f` 是激活函数（如 Sigmoid, ReLU）。
*   `y` 是输出。

深度学习网络就是由大量这样的神经元相互连接而成。

## 💻 P2：【Notebook】编写神经网络代码

理论需要实践来巩固。在学习了基础概念后，本节我们将动手编写第一个神经网络代码。

我们将使用 Python 和深度学习框架（如 PyTorch 或 TensorFlow）来实现一个简单的全连接网络。以下是一个最小化的代码示例：

```python
import torch
import torch.nn as nn

class SimpleNN(nn.Module):
    def __init__(self, input_size, hidden_size, output_size):
        super(SimpleNN, self).__init__()
        self.layer1 = nn.Linear(input_size, hidden_size)
        self.relu = nn.ReLU()
        self.layer2 = nn.Linear(hidden_size, output_size)

    def forward(self, x):
        out = self.layer1(x)
        out = self.relu(out)
        out = self.layer2(out)
        return out

# 实例化模型
model = SimpleNN(10, 5, 2)
print(model)
```

通过这个练习，你将理解模型定义、前向传播的基本流程。

## 🖼️ P5：L2A- 卷积神经网络

全连接网络在处理图像数据时效率低下。本节我们将学习专门为图像设计的卷积神经网络（CNN）。

CNN 的核心是卷积操作，它通过卷积核（Filter）在输入数据上滑动，提取局部特征。其数学表达为：

**`S(i, j) = (I * K)(i, j) = Σ_m Σ_n I(i+m, j+n) K(m, n)`**

其中 `I` 是输入图像，`K` 是卷积核，`S` 是输出的特征图。

CNN 通常由卷积层、池化层和全连接层交替堆叠而成，能够高效捕获图像的空间层次信息。

## 🔄 P7：L3- 循环神经网络

对于序列数据（如文本、时间序列），我们需要考虑数据点之间的顺序依赖关系。循环神经网络（RNN）就是为此设计的。

RNN 的核心思想是引入“隐藏状态”，该状态会随着时间步传递，保留历史信息。其单元的基本更新公式为：

**`h_t = f(W * x_t + U * h_{t-1} + b)`**

其中：
*   `h_t` 是当前时间步的隐藏状态。
*   `x_t` 是当前时间步的输入。
*   `h_{t-1}` 是上一个时间步的隐藏状态。
*   `W`, `U`, `b` 是可学习的参数。
*   `f` 是激活函数。

然而，标准 RNN 存在梯度消失/爆炸问题，这引出了 LSTM 和 GRU 等更复杂的变体。

## 🚀 P9：L4- 迁移学习和 Transformer

从头训练大型模型成本高昂。迁移学习允许我们利用在大型数据集上预训练好的模型，快速适应到新的特定任务上。

近年来，基于 **Transformer** 的架构（如 BERT, GPT）在 NLP 等领域取得了革命性成功。Transformer 完全基于自注意力机制，摒弃了 RNN 的循环结构，使其能够高效并行处理序列数据。

自注意力机制的核心是计算查询（Q）、键（K）、值（V）之间的关系：

**`Attention(Q, K, V) = softmax(QK^T / √d_k) V`**

其中 `d_k` 是键向量的维度。

## 📊 P11：L5- 机器学习项目

构建一个成功的机器学习项目，远不止编写模型代码。本节我们将了解一个标准 ML 项目的完整生命周期。

一个典型的机器学习项目流程包含以下关键阶段：

1.  **问题定义与规划**：明确业务目标，确定 ML 是否适用。
2.  **数据收集与理解**：获取数据，进行探索性数据分析（EDA）。
3.  **数据准备与预处理**：清洗数据，进行特征工程。
4.  **模型构建与训练**：选择算法，训练模型，进行超参数调优。
5.  **模型评估与验证**：使用预留的测试集评估模型性能。
6.  **部署与监控**：将模型部署到生产环境，并持续监控其表现。

理解这个流程有助于你系统性地管理和推进项目。

## 🛠️ P14：L7- 深度神经网络调试与故障处理

模型训练不顺利是常态。本节我们将学习如何系统地调试神经网络并解决常见问题。

当模型表现不佳时，可以遵循以下检查清单进行诊断：

*   **数据问题**：检查输入数据是否正确，标签是否有误，数据分布是否均衡。
*   **模型问题**：检查模型架构是否合理，参数初始化是否正确。
*   **训练问题**：检查损失函数是否选择得当，学习率是否设置合适，是否出现过拟合/欠拟合。
*   **代码问题**：检查前向/反向传播实现是否有误，梯度计算是否正确。

常用的调试工具包括：可视化损失/准确率曲线、检查梯度直方图、使用更简单的模型或数据进行测试。

## ⚖️ P16：L9- 伦理

能力越大，责任越大。在开发和应用机器学习系统时，我们必须考虑其伦理影响。

机器学习系统可能带来多种伦理风险，主要包括：

*   **偏见与公平性**：训练数据中的社会偏见可能导致模型产生歧视性结果。
*   **可解释性与透明度**：“黑箱”模型在关键领域（如医疗、司法）的应用可能缺乏问责。
*   **隐私与安全**：模型可能记忆并泄露训练数据中的敏感信息。
*   **责任与问责**：当自动化系统做出错误决策时，责任归属问题。

作为开发者，我们有责任在技术设计中融入伦理思考，通过技术手段（如公平性指标、差分隐私）和管理流程来缓解这些风险。

## 🚢 P22：L11A- 部署 ML 模型

让模型在实验室中运行良好只是第一步。本节我们将学习如何将模型部署到真实的生产环境中，为用户提供服务。

模型部署有多种模式，常见的选择包括：

*   **批量预测**：定期对一批数据进行推理，结果写入数据库。
*   **实时 API 服务**：将模型封装为 REST API 或 gRPC 服务，接受实时请求。
*   **边缘部署**：将模型部署到手机、IoT设备等终端上，进行本地推理。
*   **嵌入式部署**：将模型集成到更大的应用程序或系统中。

部署时需考虑延迟、吞吐量、资源消耗、版本管理和回滚策略等工程问题。
