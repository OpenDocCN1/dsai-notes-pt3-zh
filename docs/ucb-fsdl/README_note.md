# UCB 全栈深度学习课程笔记 01：神经网络基础 🧠

在本节课中，我们将要学习神经网络最基础的概念与工作原理。我们将从单个神经元开始，逐步理解其如何通过组合形成强大的网络，并最终学习如何通过反向传播算法来训练网络。

## 1. 神经元：网络的基本单元

上一节我们介绍了课程概述，本节中我们来看看神经网络的基本构建块——神经元。

一个神经元接收多个输入信号，对其进行加权求和，然后通过一个非线性函数（激活函数）产生输出。这个过程模拟了生物神经元的工作方式。

以下是神经元计算过程的数学描述：

**公式**：`output = activation_function( sum( weight_i * input_i ) + bias )`

其中：
*   `input_i` 是输入信号。
*   `weight_i` 是与每个输入相关联的权重，代表该输入的重要性。
*   `bias` 是偏置项，允许神经元在输入全为零时也能有输出。
*   `activation_function` 是激活函数，引入非线性，使网络能够学习复杂模式。

## 2. 激活函数的作用

单个神经元的线性加权和仍然是线性的，无论堆叠多少层，最终效果都等同于一个线性变换。为了赋予神经网络学习非线性关系的能力，我们需要激活函数。

以下是几种常见的激活函数：

*   **Sigmoid**：将输入压缩到 (0, 1) 区间。公式为 `σ(x) = 1 / (1 + e^(-x))`。常用于输出概率，但存在梯度消失问题。
*   **Tanh**：将输入压缩到 (-1, 1) 区间。公式为 `tanh(x) = (e^x - e^(-x)) / (e^x + e^(-x))`。其输出以零为中心，收敛速度通常比Sigmoid快。
*   **ReLU (整流线性单元)**：目前最常用的激活函数。公式为 `ReLU(x) = max(0, x)`。计算简单，能有效缓解梯度消失问题，但可能导致“神经元死亡”。

## 3. 从神经元到网络

单个神经元能力有限。通过将许多神经元连接成层，并将多层堆叠起来，就构成了神经网络。

*   **输入层**：接收原始数据。
*   **隐藏层**：位于输入和输出层之间，可以有一层或多层，负责进行特征提取和转换。
*   **输出层**：产生网络的最终预测结果。

网络中的每个神经元都与前一层的所有神经元相连（全连接），这种结构称为**全连接层**或**稠密层**。

## 4. 训练网络：前向传播与反向传播

网络结构搭建好后，我们需要用数据来训练它，即调整所有权重和偏置，使网络的预测尽可能准确。这个过程主要分为两个步骤：前向传播和反向传播。

**前向传播**：输入数据从网络第一层流向最后一层，逐层计算，最终得到预测值。

**反向传播**：计算预测值与真实值之间的误差（损失），然后将这个误差从输出层向输入层反向传播，并根据误差来更新每一层的权重和偏置。其核心是链式求导法则。

以下是训练循环的基本步骤：

1.  初始化网络权重和偏置。
2.  对一个批次的数据进行前向传播，得到预测值。
3.  使用损失函数（如均方误差、交叉熵）计算预测值与真实值的误差。
4.  通过反向传播算法计算损失相对于每个参数的梯度。
5.  使用优化器（如随机梯度下降SGD）根据梯度更新参数。
6.  重复步骤2-5，直到模型收敛。

## 总结

本节课中我们一起学习了神经网络的基础知识。我们从模拟生物神经元的数学模型出发，理解了激活函数引入非线性的必要性。接着，我们看到了如何将神经元组织成层，并堆叠成深度网络。最后，我们探讨了网络训练的核心机制：通过前向传播计算预测，再通过反向传播和梯度下降来优化网络参数，使其能够从数据中学习。这些概念是理解所有现代深度学习模型的基石。
