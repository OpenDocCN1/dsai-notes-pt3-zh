# 数据素养：P01：欢迎与课程概述 🎓

在本课程中，我们将学习数据的基础知识、其类型、分析框架以及描述性统计和数据可视化的核心概念。通过本课程，你将建立起如何利用数据来更好地理解世界运作方式的基础认知。

大家好。我是詹妮弗·布赫纳，负责约翰斯·霍普金斯大学数据分析与政策科学硕士项目。我很高兴欢迎大家参加这门名为“数据：它是什么以及我们能用它做什么”的课程。这是数据素养专项课程的第一门课。

这门课程将介绍可用于分析的不同数据类型、一个可用于估计因果效应的框架，以及描述性统计和数据可视化的基础知识。到课程结束时，你应该对如何以及为何能使用数据来更好地理解世界的运作方式，拥有良好的基础性理解。

---

上一节我们了解了课程的整体目标，本节中我们将具体看看课程涵盖的核心内容模块。

以下是本课程将涵盖的几个关键学习领域：

*   **数据类型**：识别并理解用于分析的各种数据形式。
*   **分析框架**：学习一个用于估计因果效应的系统性方法。
*   **描述性统计**：掌握总结和描述数据集特征的基本统计方法。
*   **数据可视化**：学会通过图表有效呈现和解读数据。
