# 🧠 UCB CS188 人工智能导论笔记：第1课 - 智能体与理性

在本节课中，我们将要学习人工智能的基础概念，特别是智能体的定义、理性智能体的概念以及如何评估其性能。我们将从最根本的问题“什么是人工智能”开始，逐步构建起对智能体及其所处环境的理解框架。

## 什么是人工智能？

人工智能是致力于构建能够执行通常需要人类智能才能完成的任务的智能体的科学和工程。这个定义引出了两个核心问题：什么是“智能体”？以及什么是“智能”行为？

上一节我们介绍了人工智能的总体目标，本节中我们来看看构成AI研究核心的“智能体”概念。

## 智能体与环境

一个**智能体**是指能够通过**传感器**感知其**环境**，并通过**执行器**对环境施加影响的任何实体。例如，一个机器人使用摄像头和激光雷达（传感器）来观察世界，并通过轮子和机械臂（执行器）来移动和操作物体。

智能体与其环境持续互动，形成一个感知-行动的循环。智能体在任一时刻所拥有的感知数据序列，构成了其**感知历史**。

## 理性智能体

一个**理性智能体**是指对于每一个可能的感知序列，它都选择能使其**性能度量**最大化的行动。这里的关键在于，理性取决于四件事：
1.  性能度量，它定义了成功的标准。
2.  智能体对环境的先验知识。
3.  智能体可以执行的动作。
4.  智能体到此刻为止的感知序列。

理性并不意味着全知或完美。理性智能体是在其已知信息和可行行动范围内，做出最佳选择的智能体。

理解了理性智能体的定义后，我们需要一个框架来具体描述和设计它。接下来，我们将介绍智能体的核心组成部分——智能体函数。

## 智能体函数与智能体程序

智能体的行为在数学上可以由一个**智能体函数**来描述。该函数将任意的感知序列映射到一个行动：

**公式：** `行动 = 智能体函数(感知历史)`

在计算机中，这个函数通过**智能体程序**来实现。智能体程序运行在某种**体系结构**（即计算设备）上，其输入来自传感器，输出则控制执行器。

一个核心观点是：**智能体函数是抽象的描述，而智能体程序是具体的实现。**

## 智能体类型

根据其内部状态和对世界的建模方式，智能体可以分为几种基本类型。以下是几种主要的智能体设计范式：

*   **简单反射型智能体**：仅根据当前的感知直接选择行动，不关注历史。其条件-行动规则可以表示为：`如果（当前感知情况）则（执行某行动）`。
*   **基于模型的反射型智能体**：维护一个描述世界如何演化的内部**模型**。智能体使用模型和感知历史来跟踪当前**状态**（世界可能状况的描述），再根据状态选择行动。
*   **基于目标的智能体**：在模型的基础上，还拥有**目标**信息。它选择那些能让环境状态达到其目标状态的行动。行动选择需要考虑未来：“这个行动会导致我达成目标吗？”
*   **基于效用的智能体**：在目标和模型之外，还有一个**效用函数**，用于衡量状态的好坏程度。它选择能最大化其预期效用的行动。这解决了目标之间可能存在冲突或存在多条路径的问题。

## 环境类型

智能体的设计极大地依赖于其运行的环境特性。评估环境特性是设计过程中的关键一步。以下是用于描述环境的主要维度：

*   **完全可观察 vs. 部分可观察**：智能体的传感器是否能获取每个时间点下环境的完整状态？
*   **单智能体 vs. 多智能体**：环境中除了自身，是否存在其他自主智能体？这引出了竞争或协作问题。
*   **确定性的 vs. 随机的**：下一个环境状态是否完全由当前状态和智能体的行动决定？
*   **片段式的 vs. 延续式的**：智能体的体验是否被划分为独立的片段（如棋类游戏），行动仅影响当前片段？
*   **静态的 vs. 动态的**：在智能体“思考”时，环境是否会发生变化？
*   **离散的 vs. 连续的**：环境的状态、时间、感知和行动是否具有有限的、可枚举的可能性？

## 本节课总结

本节课中我们一起学习了人工智能的基础框架。我们定义了**智能体**是感知并行动于环境的实体，而**理性智能体**则是在给定感知序列和先验知识下，致力于最大化其性能度量的智能体。我们探讨了智能体如何通过**智能体函数/程序**来实现，并介绍了从简单反射到基于效用的多种智能体类型。最后，我们了解了用于分析和分类智能体工作**环境**的多个重要维度（如可观察性、确定性等）。这些概念为后续学习具体的人工智能算法和技术奠定了坚实的理论基础。
