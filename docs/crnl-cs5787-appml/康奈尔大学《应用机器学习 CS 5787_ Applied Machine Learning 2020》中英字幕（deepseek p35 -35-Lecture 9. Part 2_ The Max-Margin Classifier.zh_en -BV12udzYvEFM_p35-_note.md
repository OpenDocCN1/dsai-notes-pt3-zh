# 应用机器学习：第9讲（第二部分）：最大间隔分类器 🎯

在本节课中，我们将继续学习最大间隔分类器。上一节我们介绍了间隔的直观概念和数学定义，本节中我们将探讨如何通过优化算法找到具有最大间隔的超平面。

![](img/0107ef03c3c0a909d7984dfee762002b_1.png)

## 概述

![](img/0107ef03c3c0a909d7984dfee762002b_3.png)

在二分类问题中，我们使用线性模型进行数据划分。模型形式如下：

![](img/0107ef03c3c0a909d7984dfee762002b_5.png)

**公式**：`y = sign(θ^T x + θ₀)`

其中目标变量 `y` 取值为 `-1` 或 `+1`，`θ` 是参数向量，`θ₀` 是偏置项。

上一节我们定义了数据点 `x` 到超平面的间隔公式：

![](img/0107ef03c3c0a909d7984dfee762002b_7.png)

![](img/0107ef03c3c0a909d7984dfee762002b_8.png)

**公式**：`margin(x) = y * (θ^T x + θ₀) / ||θ||`

我们的目标是找到使所有数据点最小间隔最大化的超平面参数。

![](img/0107ef03c3c0a909d7984dfee762002b_10.png)

## 优化问题推导

![](img/0107ef03c3c0a909d7984dfee762002b_12.png)

### 初始优化问题

以下是寻找最大间隔超平面的第一种优化问题表述：

**公式**：
```
maximize γ
subject to y_i(θ^T x_i + θ₀) / ||θ|| ≥ γ, for all i
```

![](img/0107ef03c3c0a909d7984dfee762002b_14.png)

其中 `γ` 是所有数据点间隔的下界（最小值）。我们同时优化 `θ`、`θ₀` 和 `γ`，目标是最大化最小间隔。

![](img/0107ef03c3c0a909d7984dfee762002b_16.png)

![](img/0107ef03c3c0a909d7984dfee762002b_18.png)

### 问题简化

初始优化问题存在两个主要困难：
1. 约束条件高度非线性（包含除法运算）
2. 存在冗余的自由度

![](img/0107ef03c3c0a909d7984dfee762002b_20.png)

为了解决第二个问题，我们注意到如果将所有参数乘以正常数 `c`，间隔值保持不变。这意味着我们可以通过添加约束来消除这种冗余。

![](img/0107ef03c3c0a909d7984dfee762002b_22.png)

![](img/0107ef03c3c0a909d7984dfee762002b_24.png)

我们添加约束 `||θ|| = 1/γ`，这总是可以通过适当的缩放实现。将这个关系代入原问题，得到简化形式：

**公式**：
```
maximize 1/||θ||
subject to y_i(θ^T x_i + θ₀) ≥ 1, for all i
```

![](img/0107ef03c3c0a909d7984dfee762002b_26.png)

![](img/0107ef03c3c0a909d7984dfee762002b_27.png)

![](img/0107ef03c3c0a909d7984dfee762002b_28.png)

![](img/0107ef03c3c0a909d7984dfee762002b_29.png)

### 最终优化形式

最大化 `1/||θ||` 等价于最小化 `||θ||`。为了计算方便，我们使用平方范数并添加系数 `1/2`，得到最终优化问题：

**公式**：
```
minimize (1/2)||θ||²
subject to y_i(θ^T x_i + θ₀) ≥ 1, for all i
```

![](img/0107ef03c3c0a909d7984dfee762002b_31.png)

这是一个二次优化问题，具有线性约束条件，比原始问题更容易求解。

## 支持向量机算法

通过上述推导，我们得到了支持向量机（SVM）分类算法的基本形式：

以下是该算法的关键特征：
* 模型类型：线性决策边界
* 学习类型：监督学习，二分类
* 优化目标：最大化间隔
* 问题形式：二次规划问题

![](img/0107ef03c3c0a909d7984dfee762002b_33.png)

这个公式为我们提供了第一个可实际求解的最大间隔分类器。后续课程中，我们将看到这个算法的其他变体。

## 总结

![](img/0107ef03c3c0a909d7984dfee762002b_35.png)

本节课中我们一起学习了最大间隔分类器的优化问题推导。我们从直观的间隔最大化目标出发，通过一系列数学变换，将复杂的非线性优化问题转化为易于求解的二次规划问题。最终得到的支持向量机算法框架为线性分类问题提供了坚实的理论基础和实用的解决方案。
