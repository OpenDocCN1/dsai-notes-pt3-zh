# 斯坦福 CS124 从信息到语言课程笔记 第1讲：语言模型基础 🧠

在本节课中，我们将要学习语言模型的基本概念。语言模型是自然语言处理的核心，它能够计算一个句子出现的概率，或者预测下一个词是什么。理解语言模型是理解后续更复杂NLP任务的基础。

## 什么是语言模型？

上一节我们介绍了课程目标，本节中我们来看看语言模型的具体定义。

语言模型的核心任务是**为词序列分配一个概率**。简单来说，它评估一个句子或一段文本在现实世界中出现的可能性。例如，“今天天气很好”这个句子应该比“天气今天很好很”拥有更高的概率。

一个包含m个词的序列的概率可以表示为：
**P(w1, w2, ..., wm)**

这个概率可以分解为一系列条件概率的乘积，这基于概率的链式法则：
**P(w1, w2, ..., wm) = P(w1) * P(w2|w1) * P(w3|w1, w2) * ... * P(wm|w1, w2, ..., wm-1)**

## N-gram 语言模型

直接计算一个长序列的条件概率非常困难。因此，我们引入一个关键假设：**一个词出现的概率只依赖于它前面有限的n-1个词**。这就是N-gram模型。

以下是N-gram模型的常见类型：
*   **Unigram (1-gram)**: 假设每个词独立出现。公式为：**P(w1, w2, ..., wm) ≈ Π P(wi)**
*   **Bigram (2-gram)**: 假设一个词的概率只依赖于前一个词。公式为：**P(wi|w1, ..., wi-1) ≈ P(wi|wi-1)**
*   **Trigram (3-gram)**: 假设一个词的概率只依赖于前两个词。

## 如何计算概率？

那么，这些条件概率如何从数据中获取呢？答案是通过在大型文本语料库中统计词序列出现的频率。

以Bigram模型为例，条件概率P(wi|wi-1)可以通过计数来估计：
**P(wi|wi-1) = count(wi-1, wi) / count(wi-1)**

这里，count(wi-1, wi)是词对(wi-1, wi)在语料中出现的次数，count(wi-1)是词wi-1出现的总次数。

## 平滑技术

然而，直接使用计数会面临一个问题：**数据稀疏性**。许多合理的词序列可能在训练语料中从未出现，导致其概率被估计为0。

为了解决零概率问题，我们需要使用平滑技术。其核心思想是从已知事件中分配一些微小的概率质量给未见过的事件。

以下是几种常见的平滑方法：
*   **加一平滑（拉普拉斯平滑）**: 将所有计数加1。公式为：**P(wi|wi-1) = (count(wi-1, wi) + 1) / (count(wi-1) + V)**，其中V是词汇表大小。
*   **回退**: 如果高阶N-gram计数为0，则回退到低阶N-gram（例如，从Bigram回退到Unigram）进行概率估计。
*   **插值**: 将不同阶数的N-gram模型概率加权组合起来，例如：**P_interp(wi|wi-1) = λ * P(wi|wi-1) + (1 - λ) * P(wi)**。

## 语言模型的评估

我们如何知道一个语言模型的好坏呢？通常使用**困惑度**作为评估指标。

困惑度是衡量模型预测不确定性的指标。对于一个测试集，其困惑度定义为：
**PP(W) = P(w1, w2, ..., wm)^{-1/m}**

其中，W是测试词序列。直观上，困惑度越低，说明模型对测试数据的预测越准确、越有信心。一个优秀的语言模型应该具有较低的困惑度。
