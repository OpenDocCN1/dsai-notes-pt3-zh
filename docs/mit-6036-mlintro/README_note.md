# MIT 6.036 机器学习入门笔记 📚

在本节课中，我们将要学习机器学习的基本概念。课程内容涵盖机器学习的定义、核心任务类型以及一个简单的线性预测模型。我们将从宏观理解开始，逐步深入到具体的技术细节。

## 什么是机器学习？🤔

上一节我们介绍了课程概述，本节中我们来看看机器学习的定义。

机器学习是计算机科学的一个领域。它使计算机系统能够从数据中“学习”并改进性能，而无需进行明确的编程。机器学习算法通过分析数据来构建模型。这些模型用于进行预测或决策。

## 机器学习的任务类型 🎯

了解了机器学习的定义后，我们来看看它主要解决哪些类型的问题。

机器学习任务主要分为三类。

以下是三种核心任务类型：

1.  **监督学习**：算法在带有标签的数据集上进行训练。每个训练样本都包含输入特征和对应的正确输出（标签）。目标是学习一个从输入到输出的映射函数，以便对新的、未见过的数据做出准确预测。例如，根据房屋特征（面积、位置）预测其价格。
2.  **无监督学习**：算法在没有标签的数据集上寻找内在结构或模式。目标通常是发现数据中的分组（聚类）或降低数据的维度。例如，根据客户的购买行为将其分成不同的群体。
3.  **强化学习**：算法通过与环境交互来学习。它采取行动，接收奖励或惩罚作为反馈，并调整策略以最大化长期累积奖励。例如，训练一个智能体玩电子游戏。

## 一个简单的预测模型：线性预测器 📈

上一节我们介绍了机器学习的任务类型，本节中我们来看看一个最基础的预测模型。

线性预测器是监督学习中最简单的模型之一。它假设输入特征和输出标签之间存在线性关系。

模型的核心是一个线性函数，其公式如下：

**`y_pred = w · x + b`**

在这个公式中：
*   **`x`** 代表输入特征向量。
*   **`w`** 代表权重向量，表示每个特征的重要性。
*   **`b`** 代表偏置项，是一个常数。
*   **`y_pred`** 代表模型对输出标签的预测值。
*   **`·`** 代表点积运算。

模型的“学习”过程就是寻找最佳的权重 `w` 和偏置 `b` 的过程。我们通过最小化预测值 `y_pred` 和真实标签 `y_true` 之间的差异（即损失）来实现这一点。

一个常用的损失函数是平方误差损失，其公式为：

**`Loss = (y_true - y_pred)²`**

对于整个数据集，我们的目标是找到使所有样本损失之和最小的 `w` 和 `b`。
