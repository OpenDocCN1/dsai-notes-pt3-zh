# 🧠 MIT 6.036 机器学习入门笔记 📚

在本课程中，我们将系统性地学习机器学习的基础概念、核心算法及其应用。课程内容涵盖从最基础的线性模型到复杂的深度神经网络，旨在为初学者构建一个清晰、完整的知识框架。

## 📖 P1：L1- 基础知识

本节课是机器学习之旅的起点。我们将介绍机器学习的基本定义、主要类型以及核心术语，为后续学习奠定基础。

机器学习是让计算机从数据中学习规律，并利用这些规律对新数据进行预测或决策的技术。它主要分为三大类：

以下是机器学习的三种主要类型：

*   **监督学习**：算法从带有标签的训练数据中学习，目标是学习一个从输入到输出的映射函数。
*   **无监督学习**：算法从无标签的数据中发现内在的结构或模式，如聚类或降维。
*   **强化学习**：智能体通过与环境交互，根据获得的奖励或惩罚来学习最优策略。

核心的机器学习流程通常包括数据收集、特征工程、模型选择、训练、评估和部署。

## 🧩 P2：L2- 感知器

上一节我们介绍了机器学习的基本分类，本节中我们来看看一个最简单但非常重要的线性分类模型——感知器。

感知器是神经网络的基本单元，用于解决二分类问题。其核心思想是通过一个线性函数对输入数据进行分类。

感知器的决策规则可以用以下公式表示：

**`y_pred = sign(w · x + b)`**

其中：
*   `x` 是输入特征向量。
*   `w` 是权重向量。
*   `b` 是偏置项。
*   `sign` 是符号函数，输出+1或-1。

感知器学习算法通过迭代更新权重来减少分类错误。

## 🔍 P3：L3- 特征

理解了感知器这样的基础模型后，我们需要认识到，模型的表现很大程度上依赖于输入数据的表示方式，这就是特征工程。

特征是描述数据的属性或变量。原始数据通常需要经过处理和转换，转化为模型能够有效利用的特征。

以下是特征处理中常见的几个步骤：

*   **特征提取**：从原始数据（如文本、图像）中构造出有意义的特征。
*   **特征选择**：从所有特征中挑选出对预测目标最重要的子集，以降低复杂度并防止过拟合。
*   **特征缩放**：将特征值归一化到相同的尺度（如[0,1]区间），以加速模型收敛并提高性能。

良好的特征工程能显著提升模型的性能。

## 📈 P4：L4- 逻辑回归(对数几率回归)

从线性分类的感知器过渡，我们引入一个更强大、更常用的分类算法——逻辑回归。它不仅能进行分类，还能输出属于某个类别的概率。

逻辑回归虽然名字中有“回归”，但它是一种用于二分类的线性模型。其核心是使用Sigmoid函数将线性组合的结果映射到(0,1)区间，解释为概率。

Sigmoid函数公式为：

**`σ(z) = 1 / (1 + e^{-z})`**

其中 `z = w · x + b`。模型预测概率 `P(y=1|x) = σ(z)`。

逻辑回归通过最大化对数似然函数（或最小化交叉熵损失）来训练模型参数 `w` 和 `b`。

## 🎯 P5：L5- 回归建模

学习了分类问题后，我们转向机器学习的另一大类任务——回归。回归的目标是预测一个连续值。

回归分析用于建立因变量（目标）与一个或多个自变量（特征）之间的关系模型。最简单的形式是线性回归。

线性回归模型试图拟合一个线性方程：

**`y_pred = w · x + b`**

模型通过最小化预测值与真实值之间的差距（即损失函数，如均方误差MSE）来学习参数。

以下是回归中常用的损失函数：

*   **均方误差**：`MSE = (1/n) * Σ(y_i - y_pred_i)^2`，对异常值敏感。
*   **平均绝对误差**：`MAE = (1/n) * Σ|y_i - y_pred_i|`，对异常值更稳健。

## ⚙️ P6：L6- 神经网络

当问题复杂、线性模型无法很好拟合时，我们需要更强大的模型。本节介绍神经网络，它通过组合多个简单的非线性单元来逼近复杂的函数。

神经网络是由大量称为“神经元”的互联处理单元组成的计算系统。一个基本的前馈神经网络包括输入层、隐藏层和输出层。

单个神经元的计算可表示为：

**`a = g(w · x + b)`**

其中 `g` 是非线性激活函数，如ReLU或Sigmoid。

神经网络通过反向传播算法和梯度下降来优化所有权重和偏置，以最小化损失函数。

## 🖼️ P8：L8- 卷积神经网络

休息之后，我们开始学习专门为处理网格状数据（如图像）而设计的强大神经网络——卷积神经网络。

CNN通过使用卷积层、池化层等特殊结构，能够高效地提取图像中的空间层次特征。

CNN的核心操作是卷积。一个卷积核在输入图像上滑动，计算局部区域的点积，生成特征图。

以下是一个简单的卷积操作代码示意（概念性）：

```python
# 伪代码：卷积核K在图像I上滑动
for i in range(output_height):
    for j in range(output_width):
        output[i, j] = sum(K * I[i:i+kh, j:j+kw])
```

池化层（如最大池化）则用于降低特征图的空间尺寸，增加模型的平移不变性。

## 🤖 P9：L9- 状态机与马尔可夫决策过程

从处理静态数据的模型转向能够处理序列决策的框架。本节介绍状态机和马尔可夫决策过程，它们是强化学习的理论基础。

MDP为序列决策问题提供了一个形式化的数学模型，包含状态、动作、转移概率和奖励函数等要素。

智能体的目标是找到一种策略 `π`，以最大化从环境中获得的累积奖励（回报）。

## 🎮 P10：L10- 强化学习

基于上一节MDP的理论基础，本节正式介绍强化学习。这是一种让智能体通过试错与环境交互来学习最优策略的机器学习范式。

强化学习的核心要素是智能体、环境、状态、动作和奖励。其学习过程不依赖于带有标签的数据，而是通过奖励信号来指导行为。

著名的Q-Learning算法是一种无模型强化学习算法，它通过学习一个动作价值函数 `Q(s, a)` 来找到最优策略。其更新规则为：

**`Q(s, a) ← Q(s, a) + α * [r + γ * max_a' Q(s', a') - Q(s, a)]`**

其中 `α` 是学习率，`γ` 是折扣因子。

## 🔁 P11：L11- 循环神经网络

现在我们关注另一类序列数据，如时间序列或自然语言。循环神经网络是专门为处理这类可变长度序列数据而设计的神经网络。

RNN的关键特性是它具有“记忆”能力，能够将之前时间步的信息传递到当前时间步的计算中。

RNN单元在时间步 `t` 的计算包含对隐藏状态 `h_t` 的更新：

**`h_t = g(W_hh * h_{t-1} + W_xh * x_t + b_h)`**

然而，标准RNN存在梯度消失或爆炸的问题，难以学习长距离依赖关系。

## 🌳 P12：L12- 决策树与随机森林

从神经网络回到另一种直观且强大的机器学习模型——决策树。它以树形结构模拟决策过程，易于理解和解释。

决策树通过一系列基于特征值的if-then规则对数据进行分类或回归。构建树的核心是选择最佳特征进行分裂，常用指标有信息增益或基尼不纯度。

单个决策树容易过拟合。随机森林通过构建多棵决策树并集成它们的预测结果，显著提高了模型的泛化能力和鲁棒性。

以下是随机森林的构建关键步骤：

*   **自助采样**：从训练集中有放回地随机抽取多个样本子集。
*   **特征随机性**：在每个节点分裂时，仅考虑特征的一个随机子集。
*   **集成**：对于分类任务，采用投票法；对于回归任务，采用平均法。

## 📊 P13：L13- 聚类算法

我们再次回到无监督学习领域，深入探讨其中最经典的任务之一——聚类。其目标是将数据点分组，使得同一组内的点彼此相似，不同组的点彼此相异。

K-Means是最常用的聚类算法之一。它试图将数据划分为K个簇，使得每个点到其所属簇中心的距离平方和最小。

K-Means算法流程如下：

1.  随机初始化K个簇中心。
2.  **分配步骤**：将每个数据点分配到距离最近的簇中心。
3.  **更新步骤**：重新计算每个簇的中心（该簇所有点的均值）。
4.  重复步骤2和3，直到簇中心不再发生显著变化。
