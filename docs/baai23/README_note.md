# 智源大会 2023 笔记：大模型基础概念与训练流程 🧠

在本节课中，我们将学习大语言模型（LLM）的核心基础概念和其训练流程。课程内容将涵盖从模型架构到训练步骤的关键知识，旨在为初学者提供一个清晰、系统的入门指南。

## 1. 什么是大语言模型？🤔

上一节我们介绍了课程目标，本节中我们来看看大语言模型究竟是什么。

大语言模型是一种基于深度学习的自然语言处理模型。它通过在海量文本数据上进行训练，学习语言的统计规律和语义信息。模型的核心目标是预测给定上下文后，下一个词或一段文本出现的概率。

其核心运作可以概括为一个**概率预测公式**：
`P(下一个词 | 上下文)`

## 2. 核心架构：Transformer

理解了模型的目标后，我们需要了解其实现的基础架构。

目前，绝大多数先进的大语言模型都基于 **Transformer** 架构。该架构由编码器（Encoder）和解码器（Decoder）组成，但其核心机制是**自注意力（Self-Attention）**。

自注意力机制允许模型在处理一个词时，权衡并关注输入序列中的所有其他词，从而更好地理解上下文关系。其计算过程可以用以下公式表示：
`Attention(Q, K, V) = softmax(QK^T / √d_k) V`
其中，Q（Query）、K（Key）、V（Value）是由输入向量线性变换得到的矩阵。

## 3. 大模型的训练流程 🏋️

掌握了模型的基础架构，本节我们将深入探讨大模型是如何被训练出来的。

大模型的训练是一个复杂且资源密集的过程，主要分为以下几个阶段。

以下是训练流程的三个关键步骤：

1.  **预训练（Pre-training）**
    *   这是最核心、最耗资源的阶段。模型在超大规模、无标注的通用文本数据（如网页、书籍、文章）上进行训练。
    *   训练目标是完成**自监督学习**任务，例如掩码语言建模（MLM）或下一个词预测。
    *   此阶段让模型学会了通用的语言知识、世界知识和逻辑推理能力。

2.  **有监督微调（Supervised Fine-Tuning, SFT）**
    *   在预训练模型的基础上，使用高质量的指令-回答对数据进行进一步训练。
    *   目标是教会模型理解并遵循人类的指令，以对话或任务完成的形式进行输出。
    *   经过此阶段，模型从一个“语言统计学家”转变为一个“对话助手”。

3.  **人类反馈强化学习（RLHF）**
    *   为了让模型的输出更符合人类偏好（如更有帮助、更真实、更无害），会引入RLHF。
    *   首先，训练一个**奖励模型（Reward Model）** 来学习人类对不同回答的偏好评分。
    *   然后，利用这个奖励模型作为反馈信号，通过强化学习算法（如PPO）进一步优化SFT后的模型，使其生成更受人类青睐的回答。

## 4. 关键概念总结 📝

本节课中，我们一起学习了关于大语言模型的基础知识。

我们首先定义了大语言模型是一种用于预测序列概率的深度学习模型。接着，我们剖析了其赖以成功的**Transformer**架构，特别是**自注意力**机制。最后，我们详细拆解了大模型的训练流程，包括**预训练**、**有监督微调**和**人类反馈强化学习**这三个核心阶段。理解这些概念是深入探索人工智能前沿领域的重要第一步。
