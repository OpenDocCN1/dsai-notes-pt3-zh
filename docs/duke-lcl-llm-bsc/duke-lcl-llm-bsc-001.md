# 1：认识课程讲师-诺亚·吉夫特 👨‍🏫

在本节课中，我们将认识本课程的讲师诺亚·吉夫特，并初步了解课程将涵盖的核心主题，包括大语言模型的技术细节、伦理考量以及实际应用。

我的名字是诺亚·吉夫特，我是本课程的讲师之一。

当前，由于大语言模型和生成式人工智能的出现，技术领域正处在一个激动人心的时代。

本课程将帮助你深入了解未来即将发生的一些重要趋势。

课程内容包括深入探讨负责任的AI组件，了解这些内容至关重要。

目前存在大量关于现有偏见问题的信息，我们需要确保模型对社会产生积极影响。

我在课程中也会从经济学角度进行探讨，并考虑负外部性。

例如，如果你能从某件事中获得全部利润，却将负面影响推给社会，这并不公平。

我们看到一些与大语言模型相关的技术问题正在浮现，课程将讨论其中需要警惕的重要方面。

试想，如果所有的艺术和音乐都被彻底商品化，创意工作者将失去创作动力，那将是怎样的未来？

因此，我认为社会在考虑使用AI时，需要处理好一些重要事项。

我们也将深入探讨本地大语言模型的一些技术细节。

我们会分析为什么本地大语言模型如此重要。

课程还将展示如何使用**Elo评分系统**来评估大语言模型，这是一种基于赛程强度的评估组件。

在这个竞争激烈、近乎完全竞争加速的新时代，越来越多的人需要评估这些本地大语言模型。

与商业大语言模型相比，本地模型在隐私、延迟和成本方面具有优势。

掌握本地大语言模型将是一项重要技能，你将在本课程中学到它。

最后，我们会讨论大语言模型的一些特性，例如使用**检索增强生成（RAG）** 技术。

考虑这些方面很重要，因为它们是提升你工作流程的方法。

本课程汇集了从伦理到技术的一系列前沿主题。

我希望你能享受这门课程。让我们开始吧。
