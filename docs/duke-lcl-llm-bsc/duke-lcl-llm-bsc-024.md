## Colab Pro的特色功能 💻

上一节我们介绍了课程背景，本节中我们来看看Colab Pro这个工具。Colab Pro是一个托管式的Jupyter笔记本环境，它提供了许多你可能不知道的有趣功能。

以下是Colab Pro的几个核心优势：

*   **托管运行时**：系统为你管理运行环境。这意味着你无需担心软件包管理和依赖冲突问题。

*   **高内存模式**：在处理大型数据集时，可以开启此选项，非常有用。

这些功能使得Colab Pro成为一个功能齐全的数据科学集成开发环境。我们可以在其中轻松实验像R这样可能较难配置的语言，而无需关注底层设置和库的安装。

## 实现ELO评分系统 📈

上一节我们成功在Colab中运行了R，本节我们将具体实现ELO评分系统。即使你不熟悉R语言，下面的代码也相对直观易懂。

首先，我们定义一个名为`elo_rating`的函数。这个函数接收三个参数：`fighter1`（选手1的当前评分）、`fighter2`（选手2的当前评分）和`result`（比赛结果，1代表选手1获胜）。

以下是该函数的核心逻辑：

1.  **设置默认值与K因子**：
    *   选手的默认初始评分设为1500。
    *   `K`是一个常数因子，影响评分更新的幅度。公式为：`K <- 32`。

2.  **计算预期胜率**：
    *   我们定义一个辅助函数`expected_score`来计算选手1的预期胜率。公式为：
        `E1 <- 1 / (1 + 10^((rating2 - rating1) / 400))`
    *   选手2的预期胜率为：`E2 <- 1 - E1`。

3.  **根据比赛结果更新评分**：
    *   使用一个条件判断语句来处理输赢。
    *   如果选手1获胜（`result == 1`），则按以下公式更新评分：
        `new_r1 <- r1 + K * (1 - E1)`
        `new_r2 <- r2 + K * (0 - E2)`
    *   如果选手1失败（`result == 0`），则更新公式为：
        `new_r1 <- r1 + K * (0 - E1)`
        `new_r2 <- r2 + K * (1 - E2)`

4.  **返回更新后的评分**：
    *   函数最后返回一个包含两位选手新评分的列表。

这是一个非常直接的代码实现。让我们运行它来初始化这个函数。

## 应用ELO系统进行计算 🥊

函数定义完成后，我们现在可以应用它来进行实际计算。假设有两位选手：“Connor”和“Khabib”。

我们初始化他们的评分，并模拟一场比赛，其中“Khabib”战胜了“Connor”。

以下是计算步骤：
```r
# 初始化选手评分
fighters <- elo_rating(1500, 1500, result = 0) # result=0 表示第一个参数对应的选手（Connor）输掉了比赛

# 打印结果
print(fighters)
```
执行这段代码后，我们可以看到输出结果。因为Connor输了比赛，他的评分从1500下降到了1475；而Khabib因为获胜，评分从1500上升到了1525。
