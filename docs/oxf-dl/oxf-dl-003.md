#  003：最大似然与信息论

在本节课中，我们将学习如何从概率的角度重新审视线性回归模型。我们将介绍高斯分布、最大似然估计的基本原理，并探讨概率、损失函数、熵和信息论之间的深刻联系。通过本节课，你将理解如何用概率语言描述机器学习问题，以及最大似然估计如何成为连接模型与数据的关键桥梁。

## 高斯分布回顾 📊

![](img/f52225fabb1078e487dacfe3c8958ca6_1.png)

上一节我们介绍了如何使用线性模型和最小二乘法拟合数据。本节中，我们来看看如何用概率的语言重新表述这个问题。首先，我们需要回顾一些基础知识，特别是高斯分布。

高斯分布，也称为正态分布，是一种常见的连续概率分布。其概率密度函数是一个“钟形曲线”。

对于一个一维高斯分布，其概率密度函数由两个参数决定：均值 `μ` 和方差 `σ²`。均值决定了分布的中心位置，方差决定了分布的宽度（即数据的离散程度）。这两个参数被称为**充分统计量**，因为它们足以完整描述整个分布的特性。

![](img/f52225fabb1078e487dacfe3c8958ca6_3.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_5.png)

高斯分布的概率密度函数公式如下：

```
P(x) = (1 / √(2πσ²)) * exp(-(x - μ)² / (2σ²))
```

![](img/f52225fabb1078e487dacfe3c8958ca6_7.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_8.png)

其中，`exp` 表示自然指数函数。这个函数满足概率密度函数的性质，即曲线下的总面积（对所有 `x` 的积分）等于1。

![](img/f52225fabb1078e487dacfe3c8958ca6_10.png)

```
∫ P(x) dx = 1
```

我们可以将概率 `P(x) dx` 理解为在 `x` 附近一个极小宽度 `dx` 区间内找到数据点的可能性。如果我们在图上画出数据点，那么数据点密集的区域对应着概率密度函数较高的区域。

## 从分布中采样 🎲

给定一个分布（如高斯分布），我们可以从中**采样**或**模拟**生成数据。这个过程就像是根据一个已知的规则（分布）来“抛骰子”，只不过结果是连续的数值。

![](img/f52225fabb1078e487dacfe3c8958ca6_12.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_14.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_16.png)

在计算机中，一个常用的方法是通过**逆变换采样**。其基本思想是：
1.  首先生成一个在 `[0, 1]` 区间上均匀分布的随机数 `u`。
2.  然后计算目标分布的**累积分布函数**的逆函数 `F⁻¹(u)`。
3.  `F⁻¹(u)` 的值就是一个服从目标分布的样本。

![](img/f52225fabb1078e487dacfe3c8958ca6_18.png)

累积分布函数 `F(x)` 定义为概率密度函数从负无穷到 `x` 的积分：
```
F(x) = ∫_{-∞}^{x} P(t) dt
```
它表示随机变量取值小于等于 `x` 的概率。

因此，如果我们知道分布的参数（`μ` 和 `σ²`），就可以生成看起来像是从这个分布中抽取的数据。反之，如果我们有大量数据，也可以估算出这些参数。

## 期望与协方差 📈

接下来，我们回顾两个重要的概念：期望和协方差。

随机变量 `X` 的**期望**（或称均值）是其概率加权平均值，定义为：
```
E[X] = ∫ x P(x) dx
```
对于高斯分布，其期望值就等于参数 `μ`。在实践中，我们通常用样本的平均值来近似期望值：
```
E[X] ≈ (1/N) * Σ_{i=1}^{N} x_i
```
其中 `x_i` 是从分布中独立抽取的样本。当样本数量 `N` 很大时，这个近似会非常准确，这被称为**大数定律**。

当我们处理多个随机变量时（例如，人的身高 `X` 和体重 `Y`），我们关心它们之间的关系。**协方差**就是衡量两个变量线性相关程度的指标。

![](img/f52225fabb1078e487dacfe3c8958ca6_20.png)

对于两个变量 `X` 和 `Y`，其协方差定义为：
```
Cov(X, Y) = E[(X - E[X])(Y - E[Y])]
```
如果协方差为正，意味着当一个变量高于其均值时，另一个变量也倾向于高于其均值（正相关）。如果协方差为负，则意味着一个高一个低（负相关）。如果协方差为零，则说明两者没有线性关系。

![](img/f52225fabb1078e487dacfe3c8958ca6_22.png)

对于 `d` 维的随机向量 `X`，其协方差是一个 `d×d` 的矩阵（协方差矩阵），对角线上的元素是各个分量的方差，非对角线上的元素是不同分量之间的协方差。

![](img/f52225fabb1078e487dacfe3c8958ca6_24.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_25.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_27.png)

## 多元高斯分布 🌐

![](img/f52225fabb1078e487dacfe3c8958ca6_29.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_31.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_33.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_35.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_37.png)

上述概念自然引向了**多元高斯分布**，即高维空间中的高斯分布。对于一个 `d` 维向量 `x`，其多元高斯分布的概率密度函数为：
```
P(x) = (1 / ((2π)^{d/2} |Σ|^{1/2})) * exp(-1/2 (x - μ)^T Σ^{-1} (x - μ))
```
其中：
*   `μ` 是一个 `d` 维均值向量。
*   `Σ` 是一个 `d×d` 的协方差矩阵（对称正定）。
*   `|Σ|` 表示矩阵 `Σ` 的行列式。
*   `(x - μ)^T` 表示向量 `(x - μ)` 的转置。

![](img/f52225fabb1078e487dacfe3c8958ca6_39.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_41.png)

这个分布同样由均值向量和协方差矩阵这两个充分统计量完全决定。当各维度变量相互独立时，协方差矩阵 `Σ` 是一个对角矩阵。

![](img/f52225fabb1078e487dacfe3c8958ca6_43.png)

## 最大似然估计原理 🎯

现在，我们进入核心部分：**最大似然估计**。这是一种根据观测数据来估计模型参数的强大方法。

假设我们观测到三个独立的数据点：`0.5, 1.0, 1.5`。我们相信它们来自一个方差已知为 `1` 的高斯分布，但均值 `θ` 未知。现在有两个候选的 `θ` 值：`1.0` 和 `2.5`。哪个值更可能是真实均值？

![](img/f52225fabb1078e487dacfe3c8958ca6_45.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_47.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_49.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_51.png)

最大似然估计的思想是：**选择那个使得观测数据出现概率最大的参数值**。

![](img/f52225fabb1078e487dacfe3c8958ca6_53.png)

具体步骤如下：
1.  对于每个候选参数 `θ`，画出对应的高斯分布曲线。
2.  计算每个数据点在该分布下的概率密度值（即曲线的高度）。
3.  由于数据点是独立的，它们同时出现的概率是各自概率的乘积，这个乘积称为**似然**。
4.  比较不同 `θ` 下的似然值，选择似然值最大的那个 `θ`。

在这个例子中，均值 `θ = 1.0` 的分布会使三个数据点处于概率较高的区域，其似然值乘积要大于 `θ = 2.5` 的情况。因此，我们更倾向于认为 `θ = 1.0` 是真实均值。

![](img/f52225fabb1078e487dacfe3c8958ca6_55.png)

## 线性回归的概率视角 🔄

![](img/f52225fabb1078e487dacfe3c8958ca6_56.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_58.png)

让我们将最大似然估计应用到线性回归中。上一节我们从“最小化弹簧能量”（最小二乘）的角度看待线性回归。现在，我们从概率角度重新审视。

![](img/f52225fabb1078e487dacfe3c8958ca6_60.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_62.png)

我们的模型是：`y = xθ + ε`，其中 `ε` 是噪声。我们假设噪声服从均值为 `0`、方差为 `σ²` 的高斯分布。这意味着，对于给定的输入 `x`，输出 `y` 是一个随机变量，服从如下高斯分布：
```
P(y | x, θ) = N(y | xθ, σ²)
```
即 `y` 的均值是模型的预测值 `xθ`，方差是 `σ²`。

![](img/f52225fabb1078e487dacfe3c8958ca6_64.png)

形象化地理解：我们在拟合的直线上，为每一个数据点的 `x` 坐标处，放置一个垂直的高斯分布“钟形曲线”。曲线的中心位于直线上的预测值 `xθ` 处。数据点 `y` 的真实值是这个高斯分布的一个样本。

![](img/f52225fabb1078e487dacfe3c8958ca6_66.png)

对于所有独立同分布的数据点 `(x_i, y_i)`，其联合概率（似然）为：
```
P(数据 | θ) = Π_i P(y_i | x_i, θ) = Π_i N(y_i | x_i θ, σ²)
```
最大似然估计的目标就是找到参数 `θ`，使得这个似然值最大化。

![](img/f52225fabb1078e487dacfe3c8958ca6_68.png)

## 从似然到损失函数 ⚖️

![](img/f52225fabb1078e487dacfe3c8958ca6_70.png)

直接最大化似然的乘积在计算上不方便（容易产生数值下溢）。我们通常对其取自然对数，得到**对数似然**。由于对数函数是单调递增的，最大化似然等价于最大化对数似然。

![](img/f52225fabb1078e487dacfe3c8958ca6_72.png)

对于高斯噪声假设下的线性回归，其负对数似然经过推导后，形式如下：
```
- log P(数据 | θ) = (常数) + (1/(2σ²)) * Σ_i (y_i - x_i θ)²
```
忽略与 `θ` 无关的常数项，我们发现**最大化（高斯）似然，等价于最小化残差平方和**，而这正是我们上一节使用的最小二乘损失函数！

![](img/f52225fabb1078e487dacfe3c8958ca6_74.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_76.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_78.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_80.png)

因此，我们可以通过求导并令导数为零来找到最优 `θ`，得到与最小二乘法完全相同的解：
```
θ_ML = (X^T X)^{-1} X^T y
```
这从概率角度验证了最小二乘法的合理性。

![](img/f52225fabb1078e487dacfe3c8958ca6_82.png)

## 伯努利分布与熵 🪙

![](img/f52225fabb1078e487dacfe3c8958ca6_84.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_86.png)

除了高斯分布，另一个重要的分布是**伯努利分布**，它描述二元随机变量（如抛硬币，正面/反面）。其概率质量函数为：
```
P(x | θ) = θ^x * (1-θ)^{1-x}, 其中 x ∈ {0, 1}
```
参数 `θ` 表示 `x=1` 的概率。其最大似然估计就是观测中 `x=1` 出现的频率。

基于伯努利分布，我们可以引入信息论的核心概念——**熵**。熵是衡量随机变量不确定性的度量。对于伯努利分布，其熵 `H` 定义为：
```
H = - [θ log(θ) + (1-θ) log(1-θ)]
```
当 `θ=0.5`（最不确定）时，熵最大；当 `θ` 接近 `0` 或 `1`（非常确定）时，熵最小。

![](img/f52225fabb1078e487dacfe3c8958ca6_88.png)

## 最大似然与信息论的连接 🔗

![](img/f52225fabb1078e487dacfe3c8958ca6_90.png)

![](img/f52225fabb1078e487dacfe3c8958ca6_92.png)

最后，我们探讨最大似然估计与信息论之间的深刻联系。假设存在一个真实的参数 `θ*` 生成了我们观测到的数据。我们模型的目标是找到一个参数 `θ`，使得模型分布 `P_θ` 尽可能接近真实分布 `P_θ*`。

![](img/f52225fabb1078e487dacfe3c8958ca6_94.png)

衡量两个分布差异的一个常用指标是 **KL 散度**：
```
KL(P_θ* || P_θ) = ∫ P_θ*(x) log( P_θ*(x) / P_θ(x) ) dx
```
KL 散度总是非负的，当且仅当两个分布完全相同时为零。

可以证明，**最大化模型的对数似然，等价于最小化真实分布与模型分布之间的 KL 散度**。进一步，KL 散度可以分解为：
```
KL(P_θ* || P_θ) = -H(P_θ*) + CrossEntropy(P_θ*, P_θ)
```
其中 `H(P_θ*)` 是真实分布的**熵**（固有的不确定性，与模型无关），`CrossEntropy(P_θ*, P_θ)` 是**交叉熵**。

因此，最大似然估计的本质是：**通过调整模型参数，最小化模型预测分布与真实数据分布之间的交叉熵**。这意味着，学习的过程就是让模型产生的“想象”（预测）与我们从世界观察到的“现实”之间的信息差异越来越小的过程。

![](img/f52225fabb1078e487dacfe3c8958ca6_96.png)
