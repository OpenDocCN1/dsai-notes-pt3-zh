## 什么是机器学习？🤔

![](img/390d1aa840fb3763800a990e180cd852_59.png)

在深入路线图之前，我们需要明确机器学习的定义。简单来说，**机器学习是将事物（即数据）转化为数字，并在这些数字中寻找模式的过程**。计算机通过数学运算来完成模式的寻找。

![](img/390d1aa840fb3763800a990e180cd852_61.png)

![](img/390d1aa840fb3763800a990e180cd852_63.png)

![](img/390d1aa840fb3763800a990e180cd852_65.png)

另一个经典定义来自 Arthur Samuel：**机器学习是让计算机无需明确编程就能学习的研究领域**。关键在于“无需明确编程”。

### 传统编程 vs. 机器学习

![](img/390d1aa840fb3763800a990e180cd852_78.png)

上一节我们介绍了机器学习的定义，本节中我们来看看它与传统编程的区别。

![](img/390d1aa840fb3763800a990e180cd852_80.png)

![](img/390d1aa840fb3763800a990e180cd852_81.png)

*   **传统编程 (软件 1.0)**：我们从**输入**和明确的**规则**开始，得到**输出**。例如，按照菜谱（规则）处理食材（输入）来烹饪烤鸡（输出）。
*   **机器学习 (软件 2.0)**：我们从**输入**和理想的**输出**开始，让算法找出从输入到输出的**规则**。例如，给算法看许多份烤鸡的食材（输入）和成品（输出），让它自己总结出菜谱（规则）。

![](img/390d1aa840fb3763800a990e180cd852_83.png)

机器学习需要传统编程作为基础，而传统编程可以独立于机器学习存在。

### 何时使用机器学习？

![](img/390d1aa840fb3763800a990e180cd852_85.png)

那么，为什么以及何时应该使用机器学习呢？以下是三个主要场景：

![](img/390d1aa840fb3763800a990e180cd852_87.png)

1.  **规则列表过长的问题**：例如，为自动驾驶汽车编写所有驾驶规则（避让行人、识别交通灯等）几乎不可能。
2.  **环境持续变化的问题**：为某个郊区编写的驾驶规则，在另一个城市或隧道中可能失效。机器学习模型可以适应新环境。
3.  **从海量数据中发现洞察**：手动分析一家大公司所有的交易记录来发现消费模式是低效的，机器学习可以高效处理。

![](img/390d1aa840fb3763800a990e180cd852_89.png)

![](img/390d1aa840fb3763800a990e180cd852_91.png)

![](img/390d1aa840fb3763800a990e180cd852_93.png)

**首要原则**：如果能用简单的、基于规则的系统解决问题，就不要使用机器学习。

![](img/390d1aa840fb3763800a990e180cd852_95.png)

![](img/390d1aa840fb3763800a990e180cd852_97.png)

一个生动的例子是特斯拉的自动驾驶系统。他们的汽车通过摄像头收集环境数据（图像），机器学习模型（如卷积神经网络）将这些图像转化为数字，识别出道路、车辆、行人等模式，然后指导汽车行动。这是一个持续循环的数据引擎：收集数据 -> 训练模型 -> 部署 -> 发现不足 -> 收集新数据 -> 重新训练。

## 机器学习问题类型 🧩

上一节我们了解了机器学习的应用场景，本节中我们来看看具体的机器学习问题有哪些主要类型。

![](img/390d1aa840fb3763800a990e180cd852_112.png)

![](img/390d1aa840fb3763800a990e180cd852_113.png)

![](img/390d1aa840fb3763800a990e180cd852_115.png)

![](img/390d1aa840fb3763800a990e180cd852_117.png)

![](img/390d1aa840fb3763800a990e180cd852_119.png)

![](img/390d1aa840fb3763800a990e180cd852_121.png)

机器学习问题主要分为以下几类学习方式：

![](img/390d1aa840fb3763800a990e180cd852_123.png)

![](img/390d1aa840fb3763800a990e180cd852_125.png)

![](img/390d1aa840fb3763800a990e180cd852_126.png)

![](img/390d1aa840fb3763800a990e180cd852_128.png)

![](img/390d1aa840fb3763800a990e180cd852_130.png)

![](img/390d1aa840fb3763800a990e180cd852_131.png)

*   **监督学习**：数据带有标签。模型学习数据与标签之间的关系。例如，用带有“猫”或“狗”标签的图片训练一个分类器。
*   **无监督学习**：数据没有标签。模型自行在数据中寻找模式。例如，聚类分析或异常检测。
*   **强化学习**：智能体通过与环境互动，根据奖励或惩罚来学习最佳行为策略。
*   **迁移学习**：将一个模型已学到的知识（通常是在大数据集上预训练的）应用到自己的问题上。这在你数据或计算资源有限时非常有用。

以下是几种常见的问题领域：

*   **分类**：预测样本属于哪个类别。
    *   **二分类**：例如，判断邮件是否为垃圾邮件。
    *   **多分类**：例如，识别图片中是哪种狗。
    *   **多标签分类**：例如，判断一个YouTube视频涉及哪些主题。
*   **回归**：预测一个连续数值。例如，根据房屋特征预测其售价。
*   **序列到序列**：将一个序列转换为另一个序列。例如，机器翻译（英译西）。
*   **聚类**：将数据分组，使得组内相似度高，组间相似度低。例如，对音乐听众进行分群。
*   **降维**：减少数据特征的数量，同时保留重要信息，以克服“维度灾难”。常用技术有主成分分析。

对于不同的问题，我们需要使用不同的评估指标来衡量模型性能，例如分类问题用混淆矩阵、准确率，回归问题用均方误差、R平方等。

## 机器学习项目流程 🔄

![](img/390d1aa840fb3763800a990e180cd852_137.png)

上一节我们介绍了各种问题类型，本节中我们来看看解决一个机器学习项目的典型步骤。这是路线图中最详细的部分。

![](img/390d1aa840fb3763800a990e180cd852_143.png)

一个机器学习项目通常包含以下六个主要步骤，它们往往形成一个循环：

1.  **数据收集**：获取用于训练模型的数据。
2.  **数据准备**：将数据转化为适合模型训练的格式（主要是数值）。
3.  **训练模型**：使用算法在数据上学习模式。
4.  **分析与评估**：检查模型性能，判断其是否可用。
5.  **部署模型**：将训练好的模型投入实际使用。
6.  **重新训练模型**：当模型性能下降或数据分布变化时，用新数据重新训练。

### 数据准备

这是将原始数据转化为模型可消化形式的关键步骤。主要子步骤包括：
*   **探索性数据分析**：深入了解数据，例如特征和目标变量是什么，有无缺失值或异常值。
*   **数据预处理**：
    *   **特征插补**：处理缺失值。
    *   **特征编码**：将分类数据等转化为数值。
    *   **特征缩放/标准化**：将不同尺度的数值特征调整到相近范围。
    *   **特征工程**：利用领域知识创建新的、更有意义的特征。
    *   **特征选择**：选择对预测最有用的特征。
*   **数据划分**：将数据分为**训练集**（用于模型学习）、**验证集**（用于调整模型超参数）和**测试集**（用于最终评估模型性能）。务必保持测试集的独立性。

### 训练模型

![](img/390d1aa840fb3763800a990e180cd852_175.png)

![](img/390d1aa840fb3763800a990e180cd852_177.png)

![](img/390d1aa840fb3763800a990e180cd852_183.png)

这个阶段可以细分为：
*   **选择算法**：根据问题类型（分类、回归等）选择合适的算法。对于初学者，可以从Scikit-learn的算法选择图开始。
*   **过拟合与正则化**：模型可能在训练集上表现太好（过拟合），而在新数据上表现不佳。需要使用正则化技术（如L1/L2正则化、Dropout）来减少过拟合。
*   **超参数调优**：调整模型的设置（如学习率、网络层数），以找到最佳性能组合。可以手动调整，也可以使用自动化工具。

以下是主要工具类别，主要以Python生态为例：

![](img/390d1aa840fb3763800a990e180cd852_250.png)

*   **库与框架**：编写代码的核心。
    *   **基础与数据处理**：Python, NumPy, Pandas。
    *   **传统机器学习**：Scikit-learn。
    *   **深度学习**：TensorFlow, PyTorch, Keras。
*   **实验跟踪**：记录和管理不同的模型训练实验。
    *   TensorBoard, Weights & Biases Dashboard, Neptune.ai。
*   **预训练模型**：用于迁移学习，节省训练时间和资源。
    *   TensorFlow Hub, PyTorch Hub, Hugging Face Transformers, Detectron2。
*   **数据与模型版本控制**：跟踪数据和模型的变化。
    *   Weights & Biases Artifacts, DVC (Data Version Control)。
*   **云计算服务**：提供强大的计算资源（如GPU）。
    *   Google Colab (免费入门), Google Cloud Platform, AWS, Microsoft Azure, Paperspace, FloydHub。
*   **自动化机器学习与超参数调优**：自动化模型选择和调参过程。
    *   TPOT, Google Cloud AutoML, Weights & Biases Sweeps, Keras Tuner。
*   **可解释性工具**：理解模型为何做出特定预测。
    *   What-If Tool, SHAP。
*   **机器学习生命周期 (MLOps)**：管理端到端的ML项目。
    *   MLflow, Kubeflow, Seldon。
*   **用户界面设计**：快速构建演示或应用界面。
    *   Streamlit（强烈推荐用于快速构建原型）。

## 机器学习数学 📐

![](img/390d1aa840fb3763800a990e180cd852_268.png)

![](img/390d1aa840fb3763800a990e180cd852_270.png)

上一节我们介绍了各种工具，本节中我们来看看驱动这些工具和算法的底层引擎——数学。机器学习本质上是应用数学。

你不需要在开始时精通所有数学，但了解核心领域有助于你深入理解模型。主要数学分支包括：

![](img/390d1aa840fb3763800a990e180cd852_280.png)

*   **线性代数**：处理向量、矩阵和张量。机器学习数据通常被表示为这些形式。核心操作包括矩阵乘法。
    *   `公式示例：矩阵乘法 C = A · B，其中 C[i][j] = Σ A[i][k] * B[k][j]`
*   **微积分**：特别是**多元微积分**和**链式法则**。它们用于优化模型，通过**梯度下降**等算法调整参数以最小化损失。
    *   `核心概念：梯度 ∇f(x) 表示函数 f 在点 x 处增长最快的方向。`
*   **概率与统计**：用于处理不确定性、制定损失函数和理解数据分布。
*   **优化**：寻找最佳参数组合，使模型性能（如准确率）最高或损失最小。

![](img/390d1aa840fb3763800a990e180cd852_282.png)

![](img/390d1aa840fb3763800a990e180cd852_284.png)

![](img/390d1aa840fb3763800a990e180cd852_286.png)

**学习建议**：不要被数学吓倒。最佳路径是：**先通过代码实践机器学习，在遇到瓶颈或产生好奇心时，再回头学习相关的数学概念**。例如，当你使用神经网络时，再去研究反向传播和链式法则。优秀的资源如“Mathematics for Machine Learning”一书和3Blue1Brown的视频系列可以帮助你。
