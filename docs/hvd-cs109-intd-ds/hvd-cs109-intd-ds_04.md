# 致谢

> 原文：[`rafalab.dfci.harvard.edu/dsbook/acknowledgments.html`](https://rafalab.dfci.harvard.edu/dsbook/acknowledgments.html)

本书献给所有参与构建和维护 R 以及本书中使用的 R 包的人们。特别感谢 R 基础、tidyverse 和 caret 包的开发者和维护者。

特别感谢我的 tidyverse 大师 David Robinson 和 Amy Gill，他们提出了数十条评论、编辑和建议。还要感谢 Stephanie Hicks，她两次担任我的数据科学课程助教，以及耐心回答我关于 bookdown 的许多问题的 Yihui Xie。感谢 Karl Broman，我从他那里借鉴了数据可视化和生产力工具部分的想法，以及 Héctor Corrada-Bravo，他提供了关于如何最好地教授机器学习的建议。感谢 Peter Aldhous，我从他那里借鉴了数据可视化原则部分的想法，以及撰写了*Happy Git and GitHub for the useR*的 Jenny Bryan，这对我们的 Git 章节产生了影响。感谢 Alyssa Frazee，她帮助创建了成为推荐系统章节的家庭作业问题，以及 Amanda Cox，她提供了纽约州教育委员会考试数据。还要感谢 Jeff Leek、Roger Peng 和 Brian Caffo，他们的课程启发了本书的章节划分方式，以及 Garrett Grolemund 和 Hadley Wickham，他们使他们的 R for Data Science 书籍的 bookdown 代码开源。最后，感谢 Alex Nones，他在本书的不同阶段进行了校对。

这本书是在教授几门应用统计学课程的过程中构思的，始于十五年前。多年来与我一起工作的助教们对本书做出了重要的间接贡献。这门课程的最新版本是由 Heather Sternshein 和 Zofia Gajdos 协调的 HarvardX 系列课程。我们感谢他们的贡献。我们还要感谢所有提出问题和评论的学生，他们的帮助使我们改进了本书。这些课程部分由 NIH 资助的 R25GM114818 项目资助。我们非常感谢美国国立卫生研究院的支持。
