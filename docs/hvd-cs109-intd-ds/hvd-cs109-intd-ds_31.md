# 第二十章 数据整理简介

> 原文：[`rafalab.dfci.harvard.edu/dsbook/introduction-to-data-wrangling.html`](https://rafalab.dfci.harvard.edu/dsbook/introduction-to-data-wrangling.html)

本书使用的数据集已经以 R 对象的形式提供给你，具体来说是数据框。美国谋杀数据、报告身高数据和 Gapminder 数据都是数据框。这些数据集包含在**dslabs**包中，我们使用`data`函数加载了它们。此外，我们还以所谓的`整洁`形式提供了数据。tidyverse 包和函数假设数据是`整洁`的，这个假设是这些包能够如此良好协作的重要原因之一。

然而，在数据科学项目中，数据作为包的一部分轻松可用的情况非常罕见。我们做了大量“幕后”工作，将原始的原始数据整理成你使用的*整洁*表格。更典型的情况是，数据存储在文件、数据库中，或者是从文档中提取出来的，包括网页、推文或 PDF 文件。在这些情况下，第一步是将数据导入 R，当使用**tidyverse**时，整理数据。数据分析过程中的这一初始步骤通常涉及多个步骤，通常是复杂的步骤，以将数据从其原始形式转换为*整洁*形式，这极大地简化了后续的分析。我们将这个过程称为`数据整理`。

在这里，我们涵盖了数据整理过程中的几个常见步骤，包括整理数据、字符串处理、HTML 解析、处理日期和时间以及文本挖掘。在单一分析中，通常不需要所有这些整理步骤，但数据科学家可能会在某个时刻遇到它们。我们用来展示数据整理技术的某些示例是基于我们将原始数据转换为**dslabs**包提供的整洁数据集的工作，这些数据集在书中作为示例使用。
