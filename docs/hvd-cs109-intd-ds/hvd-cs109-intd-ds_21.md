# 使用 R 的统计学简介

> [`rafalab.dfci.harvard.edu/dsbook/introduction-to-statistics-with-r.html`](https://rafalab.dfci.harvard.edu/dsbook/introduction-to-statistics-with-r.html)

数据分析是本书的主要关注点之一。虽然我们介绍的计算工具是相对较新的发展，但数据分析已经存在一个多世纪了。多年来，从事特定项目的数据分析师们提出了许多跨多个应用领域的一般性想法和概念。他们还确定了在数据中容易被明显模式欺骗的常见方式以及一些重要的数学现实，这些现实并不立即明显。这些想法和洞察的积累催生了统计学这一学科，它提供了一个数学框架，极大地促进了这些想法的描述和正式评估。

为了避免重复常见的错误和浪费时间重新发明轮子，数据分析师对统计学有深入理解是非常重要的。然而，由于这个学科的成熟，已经有数十本关于这个主题的优秀书籍出版，因此我们在此不专注于描述数学框架。相反，我们简要介绍概念，然后提供详细的案例研究，展示统计学在数据分析中的应用，以及实现这些想法的 R 代码。我们还使用 R 代码来帮助阐明一些通常使用数学描述的主要统计概念。我们强烈建议用一本基本的统计学教科书来补充这本书的这一部分。本部分涵盖的具体概念包括描述性统计、概率、统计推断、统计模型、回归和线性模型，这些都是统计学课程中的主要主题。我们提供的案例研究涉及金融危机、预测选举结果、理解遗传以及组建棒球队。
