# 简介

> 原文：[`rafalab.dfci.harvard.edu/dsbook/introduction.html`](https://rafalab.dfci.harvard.edu/dsbook/introduction.html)

在工业、学术界和政府中，对熟练的数据科学实践者的需求正在迅速增长。本书介绍了可以帮助你应对现实世界数据分析挑战的概念和技能。它涵盖了概率、统计推断、线性回归和机器学习等概念。它还帮助你发展 R 编程、使用**dplyr**进行数据整理、使用**ggplot2**进行数据可视化、使用**caret**构建算法、使用 UNIX/Linux shell 进行文件组织、使用 Git 和 GitHub 进行版本控制以及使用**knitr**和 R markdown 进行可重复文档准备等技能。本书分为六个部分：**R**、**数据可视化**、**数据整理**、**R 中的统计学**、**机器学习**和**生产力工具**。每个部分都有几个章节，旨在作为一次讲座进行展示，并包括分布在各章节中的数十个练习。

## 案例研究

在整本书中，我们使用具有启发性的案例研究。在每个案例研究中，我们试图真实地模拟数据科学家的经验。对于每个涵盖的概念，我们首先提出具体问题，并通过数据分析来回答这些问题。我们通过学习这些概念来回答问题。本书中包含的案例研究示例包括：

| 案例研究 | 概念 |  |
| --- | --- | --- |
| 按州划分的美国谋杀率 | R 基础 |  |
| 学生身高 | 统计摘要 |  |
| 世界健康和经济趋势 | 数据可视化 |  |
| 疫苗对传染病率的影响 | 数据可视化 |  |
| 2007-2008 年金融危机 | 概率 |  |
| 选举预测 | 统计推断 |  |
| 报告的学生身高 | 数据整理 |  |
| 钱球：组建一支棒球队 | 线性回归 |  |

| 电影推荐系统 | 机器学习 |  |

## 谁会发现这本书有用？

本书旨在作为数据科学入门课程的教科书。不需要 R 的先验知识，尽管一些编程经验可能会有所帮助。用于回答案例研究问题的统计概念仅简要介绍，因此强烈建议阅读概率和统计学教科书以深入了解这些概念。如果你阅读并理解了所有章节并完成了所有练习，你将能够执行基本的数据分析任务，并准备好学习成为专家所需的更高级的概念和技能。

## 本书涵盖了哪些内容？

我们首先回顾 R 和 tidyverse 的**基础**。你将在整本书中学习 R，但在第一部分，我们回顾了继续学习所需的构建块。

信息数据集和软件工具的日益可用导致许多领域对**数据可视化**的依赖性增加。在第二部分，我们展示了如何使用**ggplot2**生成图表并描述重要的数据可视化原则。

在第三部分，我们通过使用 R 语言中的**概率、推断和回归**来回答案例研究问题，展示了统计学在数据分析中的重要性。

第四部分通过几个例子使读者熟悉**数据处理**。我们学习的具体技能包括网络爬虫、使用正则表达式以及合并和重塑数据表。我们使用**tidyverse**工具来完成这些工作。

在第五部分，我们提出了几个挑战，这些挑战引导我们引入**机器学习**。我们学习使用**caret**包来构建预测算法，包括 K 最近邻和随机森林。

在最后一部分，我们简要介绍了我们在数据科学项目中日常使用的**生产力工具**。这些工具包括 RStudio、UNIX/Linux shell、Git 和 GitHub，以及**knitr**和 R Markdown。

## 本书没有涵盖哪些内容？

本书专注于数据科学的数据分析方面。因此，我们不涉及与数据管理或工程相关的方面。尽管 R 编程是本书的重要组成部分，但我们不教授更高级的计算机科学主题，例如数据结构、优化和算法理论。同样，我们也不涵盖诸如网络服务、交互式图形、并行计算和数据流处理等主题。统计概念主要作为解决问题的工具来介绍，本书中不包括深入的理论描述。
