# 校验位的确定示例

校验位通过事先规定的数学方法计算出来。

+   ◉ 如果编码设计方法中 共XXXX X，其中第五位为校验位，令A1 A2 A3 A4表示该编码的1-4位；则不妨取
+   
+   ◉ a5=MOD（a1＋2a2＋3a3＋4a4）,9]

例如：

```text
      a1  a2  a3  a4  a5
      5   1   3   2   6
X)    1   2   3   4
      5＋2＋9＋8=24
则a5＝（24/9）的余数=6
```

当编码51326错写为57326时，计算中便可得到a5=0，因此51326、57320为正确情况，可得出57326不能通过校验。
