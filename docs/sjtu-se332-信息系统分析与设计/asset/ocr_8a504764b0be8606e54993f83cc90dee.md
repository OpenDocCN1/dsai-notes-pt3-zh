# 能力需求计划（CRP）

# 第1步：计算工作中心能力

+   - 为了编制能力需求计划，首先要计算工作中心负荷能力。各工作中心所需的负荷能力可用下式计算：
+   
+     **工作中心负荷能力=件数×单件加工时间+准备时间**
+   
+   - 例如，对于工作中心30，由于最终产品A在工作中心30加工，单件加工时间和生产准备时间分别为0.09h和0.4h。因此对于主生产计划的每一批计划量25、20及30件在该工作中心的负荷能力分别是：25×0.09+0.4=2.65h、20×0.09+0.4=2.20h和30×0.09+0.4=3.10h。
+   - 基于上述方法，可以得到其它加工中心所需的能力负荷情况。
