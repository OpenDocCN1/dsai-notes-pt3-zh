# （1）定量库存控制模型

年总成本=年产品成本+年采购成本+年库存成本

T_C = D×P + C×D/Q + H×Q/2    （条件 R=L_T+A）

+   T_C ----年总成本

+   D ----库存物料的年需求率（件/年）

+   P ----单位产品成本（产品价格）

+   C ----单位订货费用（元/次）

+   Q ----订货批量

+   R ----订货点

+   H ----单位库存保管费用（元/件.年）

+   L_T ----订货周期内物料的消耗量

+   A ----安全库存量

+   L ----订货提前期

+   F ----单件库存保管费与单件库存购买费之比，即 F=H/P
