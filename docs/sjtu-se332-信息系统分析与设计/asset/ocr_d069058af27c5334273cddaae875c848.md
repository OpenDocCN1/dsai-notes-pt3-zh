# A1 BPMN 建模

+   - 业务流程建模标注BPMN(Business Process Modeling Notation)，是用流程图形式来描述业务流程的一种方法。
+   - BPMN从2002年开始制定，2004年5月发布第一个版本，由对象管理组织OMG进行维护管理。目前版本为BPMN 2.0。
+   - BPMN定义了建立业务流程的图形模式：
+   - 业务流程图BPD(Business Process Diagram)。BPD由一系列的图形元素组成，所采用的图形化的标注使用一些简单的形状来区分。为了满足对业务流程描述的全面性，BPMN通过对基本元素增加一些额外信息及标注来进行扩展，扩展后的BPD图能够支持相对复杂的业务流程描述。
