# 例2 物料需求的计算
（当独立需求与相关需求同时存在时）

已知：物料A既是产品X的组件又是产品Y的组件，BOM图如下图。所以，A的需求为相关需求；此外，A作为配件又有独立需求。因此，物料A的总的毛需求应为其独立需求和相关需求之和。其算例见下表。
