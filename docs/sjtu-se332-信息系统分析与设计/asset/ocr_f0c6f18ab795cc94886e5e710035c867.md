# 目标/问题图表

+   - 目标/问题图表是描述对象及其相互关系的UML对象图。
+   - 完整的目标模型是多个对象图的组合，其中每个图表都展示了某个特定的高层目标如何被分解为各个子目标。
+   - 目标以类的对象描述，这些对象拥有构造型元素<goal>。在图中这样的对象用于展示目标，目标之间的相互依赖，目标与它们所解决问题之间的关系。
