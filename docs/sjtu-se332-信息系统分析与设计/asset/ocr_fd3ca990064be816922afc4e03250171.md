# 2.3 任务

一般的逻辑工作单元，而不是过程实例的一次执行；

+   - 工作的逻辑单元，不可分割且必须完整执行；
+   - 任务被分为：
+     - 手动的任务 (manual)；
+     - 自动的任务 (automatic)；
+     - 半自动的任务 (semi-automatic)

注意下面的概念的区别：

+   - 任务 A logical step which may be executed for many cases.
+   - 工作项 = task + case
+     A logical step which may be executed for a specific case.
+   - 活动 = task + case + (resource) + (trigger)
+     The actual execution of a task for a specific case.
+     工作项和活动是任务的实例
