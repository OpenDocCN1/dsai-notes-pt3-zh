# 工艺路线（Routing）

主要说明物料实际加工和装配的工序顺序、每道工序使用的工作中心，各项时间定额（如：准备时间、加工时间和传送时间，传送时间包括排队时间与等待时间），及外协工序的时间和费用。

工艺路线也即是加工的流程。
