# Eriksson-Penker业务扩展

+   - 这些扩展为UML业务扩展奠定了基础框架，业务架构可以在这个框架之上根据业务需要添加相应的构造型或者属性。
+   - 扩展不是业务扩展的最终形式，它们作为开发的基础以满足特定建模情况的需要或者进一步改进UML业务建模。
+   - 这些扩展以标准UML扩展机制定义并与标准UML完全兼容，将UML和过程建模相结合，使得UML业务建模将更加简单。
+   - 这些扩展并非是试图创造一种新的建模语言。
