# ARIS软件工具

ARIS有一套标准的软件工具集支持ARIS建模及仿真实施。自1990年以来，IDS Prof.Scheer公司一直致力于基于ARIS模型的软件实施及相应工具的发展。

+   - IDS Scheer 是德国第二大软件公司，并位居前十名 IT 服务商之列。\n- 2004年初，IDS Scheer中国公司正式成立，注册名称爱迪斯（上海）软件有限公司，致力于业务流程管理和 SAP 系统咨询实施服务，直接为国内广大客户提供支持。\n- 2007年ARIS7.0正式发布并投入使用。

# ARIS 工具的产品包括：

+   - ARIS EasyDesign\n- ARIS Toolset\n- ARIS forR/3\n- ABC (Activity Based Costing)\n- Weblink和标准界面。\n- 这些产品可互相集成
