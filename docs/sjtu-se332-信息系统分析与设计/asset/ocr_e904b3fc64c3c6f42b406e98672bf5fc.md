# 用来定义业务系统的概念有：

+   - **资源** 业务中的对象，如人、原料、信息和产品，这些业务中使用的或者产出的东西。资源放置在各个结构之中并彼此关联，资源在业务中使用的或者产出。资源可以分类为物理、抽象和信息形式。
+   - **过程** 业务资源状态变化过程中所执行的活动。过程描述了业务中的操作如何完成，受规则的支配。
+   - **目标** 业务的目标，或者业务要实现的整体目标。目标可以被分解为子目标并分派给业务的各个部分，如过程和对象。目标表达了资源的期望状态，这些状态通过各个过程的运作实现，可以以一个或者多个规则表达。
+   - **规则** 对业务的某些方面进行定义或者约束，并表现业务知识。规则决定业务如何运作或者各种资源怎样进行组织并相互联系。
