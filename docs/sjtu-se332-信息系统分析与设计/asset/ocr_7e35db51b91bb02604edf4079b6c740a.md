# 装配线图示例说明

装配线图示例以装配线上的系列资源展示了股票订单处理 (Stock Order Handling) 以及交易处理 (Trade Handling) 过程及其交互作用。

本例中有三个装配线包，分别对应投资组合 (Portfolio)、订单 (Order) 和证券持有 (Security Holding)；装配线包市场 (Market) 和行政管理 (Administration) 用于对组织中的市场和行政管理进行划分。

+   - 例如，交易处理过程在行政管理包中创建了合约注解 (Contact Note) 作为它与装配线的最后引用，这里的合约注解 (买卖双方作为交易凭证的文档) 是行政管理对象，也就是说此对象位于行政管理包中。
