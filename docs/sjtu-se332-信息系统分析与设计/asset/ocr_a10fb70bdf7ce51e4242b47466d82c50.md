# BAAN IV Orgware组成

+   - **企业建模工具：** 它使公司可以用图形描述业务模型的组织结构、功能特点以及业务过程的先后顺序。
+   - **企业参考模型：** 这些模型为自动化、电子、项目工程等领域内的企业，提供了建立本企业模型的参考。
+   - **企业效能管理工具：** 这是ORGWARE性能管理工具，包括一套应用BAAN IV ORGWARE所有模块的预定义性能指标。即评价模块。
+   - **企业实施工具：** 在DEM概念框架内，BAAN通过三个预定义模型的连续赋值来实现，每个模型表示结构的不同方面，而它们组合起来就表示了整个企业。
