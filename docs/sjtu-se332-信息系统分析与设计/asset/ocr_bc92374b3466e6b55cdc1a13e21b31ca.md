# ERM: Cluster

+   - A cluster represents a logical view on (several) entity- and relationship types of a data model.
+   - It may describe a complex object.

In the ARIS-Toolset:
Clusters may be described in more detail by entity- and relationship types or by (more detailed) clusters.
