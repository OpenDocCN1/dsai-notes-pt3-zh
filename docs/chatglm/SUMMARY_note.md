## 🎯 核心概念与学习方法

上一节我们列出了完整的课程目录，本节中我们来看看如何高效地学习这些内容。对于初学者，理解以下几个核心概念和公式将大有裨益。

**大模型（Large Language Model, LLM）**：指参数规模巨大（通常数十亿以上）的语言模型，其核心是**自回归生成**。给定一个输入序列（Prompt），模型会预测下一个词的概率分布，并以此生成后续文本。其基本公式可以简化为：
`P(下一个词 | 上文)`

**微调（Fine-tuning）**：为了让预训练好的通用大模型适应特定任务（如法律、金融问答），我们需要用特定领域的数据继续训练模型。本教程介绍了三种主流方法：
*   **P-Tuning**：一种参数高效的微调方法，只训练少量的**连续提示（Prompt）参数**，而冻结模型绝大部分参数。
*   **LoRA**：在原始模型参数旁添加低秩适配器进行微调，训练时只更新适配器参数。其核心操作可表示为：`W' = W + BA`，其中`W`是原始权重，`B`和`A`是可训练的低秩矩阵。
*   **Full Parameter Fine-tuning**：全参数微调，更新模型的所有参数，效果通常最好，但计算成本最高。

**Prompt工程**：通过精心设计输入给模型的指令或示例，来引导模型生成更准确、更符合要求的输出。一个简单的代码示例可能是：
```python
prompt = “””
你是一个专业的翻译官。请将以下英文句子翻译成中文：
英文：{user_input}
中文：
“””
```

**智能体（Agent）**：一个能够理解目标、规划步骤、调用工具（如搜索、计算、写代码）并执行任务的大模型系统。其基本工作流可以概括为：`感知 -> 规划 -> 行动 -> 观察 -> 循环`。

## 🚀 学习路径建议

为了帮助你更好地安排学习顺序，以下是针对不同背景的学习者推荐的学习路径。

**如果你是初学者：**
1.  首先学习第22课 **《GLM 使用指南：入门 GLM API（一）》**，了解如何与模型交互。
2.  接着学习第15课 **《ChatGLM3 一键安装，懒人专属》**，尝试在本地部署模型。
3.  然后学习第5课 **《ChatGLM 的 Prompt 工程实践》**，掌握引导模型的核心技巧。
4.  最后通过第9课 **《「第一课」GPT快速迁移GLM》**，将已有的AI知识进行迁移。

**如果你希望深入开发与应用：**
1.  从第3课 **《ChatGLM + LangChain 实践培训》** 开始，学习构建应用的流行框架。
2.  深入学习第4课 **《ChatGLM-6B 微调》**，掌握定制化模型的能力。
3.  探索第12课 **《Agent丨工作流》** 和第10课 **《2024，智能体 Builder 时代》**，了解前沿的智能体开发。
4.  关注第17课 **《CogVLM2》** 和第7课 **《CogVideoX》**，了解多模态模型的最新进展。

**如果你是特定领域的从业者：**
*   **金融领域**：重点关注第2课和第16课。
*   **法律领域**：重点关注第23课和第24课。
*   **视频生成**：重点关注第7课、第8课和第11课。
