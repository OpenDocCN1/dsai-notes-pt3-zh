# 1：课程简介

![](img/57142b5de4818bd18b9dd95215cf06be_0.png)

在本课程中，我们将探讨生成式人工智能如何作为学习设计伙伴，并了解其在教学与学习专业领域的潜在影响。

欢迎来到“生成式AI作为学习设计伙伴”系列课程。我们很高兴能与您一同探索这个主题。我是克里斯·卡纳博士，密歇根大学马塞尔家族教育学院的副教授。我是丽贝卡·卡纳纳博士，学术创新中心嵌入式与在线学习设计主任，同时也是马塞尔家族教育学院的特聘讲师。

鉴于当前生成式AI在许多领域受到关注，人们自然会思考它在包括教学在内的各种专业背景下的潜在影响。本系列课程将聚焦于学习设计专业人员如何在设计情境中考虑使用生成式AI。

由于生成式AI的广泛应用对大多数学习设计专业人员来说是一个相对较新的概念，我们希望从自身在该领域的经验出发，概述我们如何看待这一机遇。我们也将在此过程中提供多个示例，以激发您的思考。我们希望您能受到启发，在专业实践中运用合理的设计判断，尝试新事物。

本系列课程由三个短期课程构成，重点在于您如何在实践中利用生成式AI。我们的目标是让您将其视为学习设计中一个潜在的合作伙伴。

我们想从一开始就说明，本系列中的每门课程都设计为大约需要三到五个小时完成。每门课程将让您专注于一两个学习目标，并提供机会让您在真实情境中进行实践和应用概念。

如果您是学习设计领域的新手，我们也鼓励您探索本平台上提供的、更长的“学习体验设计”三课程系列。

以下是本系列三个课程的核心内容：

*   **第一门课程**：您将制定一个计划，考虑如何将生成式AI用作设计伙伴。
*   **第二门课程**：您将尝试使用生成式AI来支持学习设计任务。
*   **第三门课程**：我们将从更广阔的视角，探讨学习设计师如何与各利益相关方就这项新兴技术的使用进行思想合作。

无论您是寻求提升技能或扩大工作影响力的早期职业人士，还是对探索新工作方式感兴趣的经验更丰富的学习设计师，我们认为您都能从本课程中发现价值。我们也认为，负责为团队和部门设定方向的学习专业人员和领导者，在寻求理解设计领域如何演变的机会时，会发现此类系列课程非常有用。

现在，您可能想知道，作为本课程的讲师，我们是否使用了生成式AI来设计您即将开始的这段学习体验。这是一个非常“元”的问题，值得我们一同在课程中探索。我们可以告诉您，在本系列课程的设计和开发过程中，我们一直在与同事和设计伙伴尝试各种工具和技术。因此，您将看到我们的一些实验成果，甚至可能在过程中发现一些惊喜。

我们设计了课程结构，以便您在完成每个部分后，能够解锁我们关于在整个过程中如何将生成式AI作为学习设计伙伴的笔记。我们希望您会觉得这种方法具有激励性和吸引力。我们也希望您能通过讨论区和课程活动，自由地与课程中的同伴分享您使用生成式AI的经验。

既然我们已经完成了介绍，是时候开始了。让我们看看如何将生成式AI作为学习设计伙伴来拥抱。
