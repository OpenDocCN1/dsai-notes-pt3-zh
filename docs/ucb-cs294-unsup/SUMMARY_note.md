## 核心概念简介

上一节我们列出了课程大纲，本节中我们来初步了解几个贯穿课程的核心概念。

一个核心目标是学习数据的概率分布 `p(x)`。生成模型的目标是让模型学习到的分布 `p_θ(x)` 尽可能接近真实数据的分布 `p_data(x)`。评估方式通常是比较两个分布之间的差异，例如使用 **Kullback-Leibler (KL) 散度**：

`D_KL(p_data(x) || p_θ(x)) = ∫ p_data(x) log(p_data(x) / p_θ(x)) dx`

另一种重要范式是表示学习，即学习数据的有用表征 `z = f(x)`，这些表征可以用于下游任务。
