# UCB CS294 深度无监督学习笔记 第1课：自编码器与表示学习 🧠

在本节课中，我们将要学习深度无监督学习的一个基础模型——自编码器。我们将探讨其核心思想、数学原理、变体以及如何用它来学习数据的有用表示。

---

## 概述

自编码器是一种神经网络，其设计目标是学习对输入数据的有效编码。它通过将输入压缩到一个低维的潜在空间，然后再从这个表示中重建输入来实现这一目标。这个过程迫使网络捕捉数据中最关键的特征。

---

## 自编码器的基本结构

自编码器通常由两部分组成：编码器和解码器。

上一节我们介绍了自编码器的目标，本节中我们来看看它的具体结构。

**编码器** 将输入数据 `x` 映射到一个潜在表示 `z`。这个过程可以表示为：
`z = f(x; θ_e)`
其中 `f` 是编码器函数，`θ_e` 是其参数。

**解码器** 则尝试从潜在表示 `z` 中重建原始输入 `x̂`。这个过程可以表示为：
`x̂ = g(z; θ_d)`
其中 `g` 是解码器函数，`θ_d` 是其参数。

整个网络的目标是最小化重建误差，即原始输入 `x` 与重建输出 `x̂` 之间的差异。常用的损失函数是均方误差：
`L(x, x̂) = ||x - x̂||²`

---

## 自编码器的类型

理解了基本结构后，我们来看看几种常见的自编码器变体，它们通过引入不同的约束或结构来学习更有意义的表示。

以下是几种主要的自编码器类型：

*   **欠完备自编码器**：这是最基本的形式。它通过使潜在空间 `z` 的维度小于输入 `x` 的维度，来强制网络学习数据的压缩表示。这可以防止网络简单地学习恒等映射。
*   **正则化自编码器**：这类自编码器不限制潜在空间的维度，而是通过在损失函数中添加一个正则化项来约束学习过程。这鼓励模型学习到其他理想的特性，如稀疏性、对微小扰动的鲁棒性等。
*   **去噪自编码器**：其核心思想是向输入数据 `x` 中添加噪声，得到 `x̃`，然后训练网络从 `x̃` 重建出干净的原始数据 `x`。这迫使编码器学习到能够抵抗噪声干扰的、更鲁棒的数据特征。
*   **变分自编码器**：这是一种生成模型。它不再将输入编码为一个固定的向量 `z`，而是编码为潜在空间中的一个概率分布（通常是高斯分布）。然后从该分布中采样得到 `z`，再由解码器重建数据。其损失函数包含重建误差和潜在分布与先验分布（如标准正态分布）之间的KL散度。

## 表示学习

自编码器的核心价值在于其编码器部分能够学习到输入数据的一种“表示”。

上一节我们介绍了各种自编码器，本节中我们聚焦于它们共同的目标——学习良好的数据表示。

一个好的表示应该具有以下特点：

以下是理想数据表示的几个关键属性：

*   **可分离性**：不同类别或模式的数据在表示空间中应该易于区分。
*   **不变性**：对于数据的某些无关紧要的变换（如光照变化、平移），其表示应保持稳定。
*   **解耦性**：表示的不同维度应该对应数据中独立变化的因素。
*   **平滑性**：表示空间应该是连续的，即输入数据的小变化应导致表示的小变化。

自编码器通过最小化重建损失，隐式地鼓励其潜在表示 `z` 包含足够的信息来重构 `x`，从而学习到数据中的重要特征。

## 总结

本节课中我们一起学习了自编码器的基本原理与应用。我们首先了解了自编码器由编码器和解码器组成，通过最小化重建误差来工作。接着，我们探讨了几种重要的变体，包括欠完备、正则化、去噪和变分自编码器。最后，我们讨论了自编码器的终极目标——学习数据的有用表示，并列举了良好表示应具备的特性。自编码器为无监督表示学习提供了一个强大而直观的框架。
