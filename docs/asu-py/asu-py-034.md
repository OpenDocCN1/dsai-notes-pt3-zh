# 34：使用 NumPy 库进行数据分析 🐍📊




在本节课中，我们将学习如何使用 Python 的 NumPy 库来创建和操作数组。我们将从创建整数和浮点数数组开始，然后探索如何指定数据类型、用默认值填充数组、生成数字序列，以及构建和操作多维矩阵。通过本教程，你将掌握 NumPy 数组的基本操作。



---


## 导入 NumPy 库



首先，我们需要导入 NumPy 库，以便在 Python 中使用其功能。



```python
import numpy as np
```





这行代码允许我们访问 NumPy 库中的所有功能。




---




## 创建第一个 NumPy 数组




上一节我们导入了 NumPy 库，本节中我们来看看如何创建第一个数组。


我们将使用 `np.array()` 函数，并传入一个列表来创建数组。



```python
a = np.array([[1, 2, 3], [3, 4, 5]])
print(a)
```




请注意，创建二维数组时，需要将整个列表组用方括号括起来。运行代码后，你将看到一个两行三列的二维数组。



---




## 创建浮点数数组





除了整数，我们还可以创建其他数据类型的数组。接下来，我们创建一个浮点数数组。




```python
b = np.array([[1.1, 2.2, 3.3], [3.3, 4.4, 5.5]])
print(b)
```



运行代码后，你将看到输出的数组元素都是浮点数。为了清晰地区分不同的数组，我们可以在打印语句之间添加空行。




---



## 指定数组数据类型




NumPy 允许我们显式指定数组的数据类型。例如，我们可以创建一个复数数组。




以下是创建复数数组的步骤：





```python
c = np.array([[1, 2, 3], [3, 4, 5]], dtype=complex)
print(c)
```



运行代码后，你会看到数组中的数字被表示为复数形式（例如，1+0j）。




---



## 用默认值填充数组




有时我们需要创建特定形状并用默认值（如全零）填充的数组。NumPy 提供了便捷的函数来实现这一点。



我们可以使用 `np.zeros()` 函数来创建一个全零数组。




```python
d = np.zeros((4, 6))
print(d)
```





这段代码创建了一个 4 行 6 列的全零数组。


---




## 使用范围填充数组



除了用零填充，我们还可以用一系列数字来填充数组。`np.arange()` 函数可以生成一个数字序列。





首先，我们生成一个从 0 到 11 的序列：



```python
e = np.arange(12)
print(e)
```




然后，我们可以使用 `reshape()` 方法将这个一维序列重新塑形为一个二维数组。



```python
e_reshaped = e.reshape(3, 4)
print(e_reshaped)
```




运行后，你将看到一个 3 行 4 列的数组。




---



## 访问数组元素



创建数组后，我们经常需要访问或修改其中的特定元素。NumPy 数组的索引方式与常规列表类似。




要访问数组中的元素，我们需要指定其行索引和列索引。



例如，要访问上面创建的数组 `a` 中的第一个元素（位于第 0 行，第 0 列），可以这样做：





```python
print(a[0, 0])
```




这将输出值 `1`。要访问第二行第三列的元素（值为 5），则使用：




```python
print(a[1, 2])
```
