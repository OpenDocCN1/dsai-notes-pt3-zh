## 什么是字符串？ 🔤

![](img/1ba07cbc40b46c3c41b0c97dba9d38aa_2.png)

字符串是字符的集合。Python 有一个内置的字符串类，称为 `str`。在 Python 中，字符串是不可变的，这意味着它们在创建后不能被更改。字符串操作是通过创建新的字符串并调用 Python 方法来对字符串执行操作来完成的。在本课程稍后部分，你将了解更多关于 Python 方法的知识，并看到它们在操作字符串、整数或其他不同数据类型的变量时有多么有用。

为了表示字符串，我们使用单引号、双引号和三引号来包含它们。

![](img/1ba07cbc40b46c3c41b0c97dba9d38aa_4.png)

## 字符串的表示方法 ✍️

## 字符串的不可变性 🔒

我们提到字符串是不可变的。这意味着你不能直接修改一个已有字符串中的某个字符。任何看似“修改”字符串的操作，实际上都是创建了一个全新的字符串。

例如，尝试通过索引直接修改字符串中的字符会导致错误：
```python
my_string = “hello”
my_string[0] = ‘H’  # 这行代码会引发 TypeError 错误
```
正确的做法是创建一个新的字符串：
```python
my_string = “hello”
new_string = ‘H’ + my_string[1:]  # 创建新字符串 “Hello”
```

## 字符串操作方法 🛠️

由于字符串不可变，Python 提供了许多方法来对字符串进行操作并返回新的字符串结果。这些方法非常强大，能帮助我们完成各种常见任务。

以下是几个常用的字符串方法示例：

*   **`.upper()`**: 将字符串中的所有字符转换为大写。`“hello”.upper()` 的结果是 `“HELLO”`。
*   **`.lower()`**: 将字符串中的所有字符转换为小写。`“HELLO”.lower()` 的结果是 `“hello”`。
*   **`.strip()`**: 移除字符串开头和结尾的空白字符（如空格、换行符）。`“  hello  “.strip()` 的结果是 `“hello”`。
*   **`.replace(old, new)`**: 将字符串中的 `old` 子串替换为 `new` 子串。`“hello world”.replace(“world”, “Python”)` 的结果是 `“hello Python”`。
*   **`.split(separator)`**: 根据指定的分隔符将字符串分割成列表。`“apple,banana,orange”.split(“,”)` 的结果是 `[‘apple’, ‘banana’, ‘orange’]`。
