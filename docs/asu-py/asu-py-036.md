在本节课中，我们将要学习 Python 中强大的数据分析库 Pandas。我们将了解 Pandas 是什么，并学习如何对数据进行切片、合并、更改索引以及修改表头。

---

## 什么是 Pandas？🔍

Pandas 是一个我们可以用来导入、查看和修改数据的工具。它允许我们以所需的格式处理数据。

我们可以用它处理简单的**序列**、**数据框**、**缺失数据**和**分组数据**。

*   **序列** 非常类似于一维的 NumPy 数组。我们可以查看数据参数，其定义可以是一个常量值、一个列表、一个 NumPy 数组或一个字典。
*   **数据框** 可以看作是一个包含不同类型列和行的表格，这使我们能更容易地处理数据。你也可以将其视为一个二维数组。
*   **缺失数据** 是指数据中不存在的部分。很多时候，如果程序遇到缺失数据可能会崩溃。在 Pandas 中，`NA` 值会被放入相应位置，以表示该数据不可用。
*   **数据分组** 在许多领域都有应用，例如经济学、大数据分析、广告和股票预测，这些都是数据性能分析和操作最常见的场景。

---

## 如何对数据进行切片？🔪

首先，我将向你展示如何显示所有数据。在显示所有数据之后，我将展示如何显示前几行数据以及后几行数据。

以下是具体步骤：

1.  导入 Pandas 库，通常使用别名 `pd`：`import pandas as pd`
2.  创建一个字典形式的数据集，例如包含天数、参会人数和评分。
3.  使用 `pd.DataFrame()` 将字典转换为数据框。
4.  打印数据框以查看所有数据。
5.  使用 `df.head(n)` 显示前 `n` 行数据。
6.  使用 `df.tail(n)` 显示后 `n` 行数据。

---

## 如何合并数据？🤝

上一节我们介绍了数据切片，本节中我们来看看如何合并两个不同的数据集。我们可以使用 `merge` 和 `join` 方法。

以下是合并数据的几种方式：

*   **`pd.merge(df1, df2)`**：默认合并两个数据框中所有列名匹配且值相同的行。
*   **`pd.merge(df1, df2, on=‘列名’)`**：根据指定的列进行合并，会显示两个数据框中该列的所有值，并匹配对应的行。
*   **`df1.join(df2)`**：根据索引进行连接，将第二个数据框的列添加到第一个数据框的右侧。如果某些位置没有对应数据，则会用 `NA` 填充。

---

## 如何设置和修改索引？🏷️

如果我想设置一个特定的列作为数据框的索引，可以这样做。

具体操作是使用 `df.set_index(‘列名’, inplace=True)`。`inplace=True` 参数表示直接在原数据框上进行修改。执行后，指定的列将变为索引列。

---

## 如何修改表头（列名）？✏️

最后，我们来看看如何修改数据框的表头，即列名。

修改列名的方法是使用 `df.rename(columns={‘旧列名’: ‘新列名’}, inplace=True)`。这会将指定的旧列名替换为新列名。
