# 知识的依赖性

知识库中的知识的重要性并不相同，有些知识可由其他知识导出。

+   设K=(U, R)为知识库，P, Q ⊆ R

+   (1) 知识Q依赖于知识P，记作P⇒Q，当且仅当IND(P) ⊆ IND(Q)

+   (2) 知识P与知识Q等价，记作P≡Q，当且仅当P⇒Q 且 Q⇒P

+   (3) 知识P与知识Q独立，记作P≠Q，当且仅当P⇒Q与Q⇒P均不成立

+   当知识Q依赖于知识P时，也称知识P可推导出知识Q。

+   P≡Q当且仅当IND(P)=IND(Q)。

+   知识的依赖性也可能是部分的，即知识P可部分地推导出知识Q。

+   知识的部分依赖于知识P可由知识的正域来定义。
