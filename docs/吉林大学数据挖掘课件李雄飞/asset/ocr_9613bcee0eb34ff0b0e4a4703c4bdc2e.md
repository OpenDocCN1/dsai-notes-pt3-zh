# 知识与知识库(例)(续)

◆设属性对应的等价关系R₁，R₂，R₃分别为：
R₁ = {⟨x, y⟩ | x与y年级相同}
R₂ = {⟨x, y⟩ | x与y成绩相同}
R₃ = {⟨x, y⟩ | x与y性别相同} 则
U/R₁ = {{x₁, x₅, x₆}, {x₂, x₃}, {x₄}} 为关于年级的初等知识
U/R₂ = {{x₁, x₄, x₅}, {x₂, x₃}, {x₆}} 为关于成绩的初等知识
U/R₃ = {{x₁, x₅}, {x₂, x₃, x₄, x₆}} 为关于性别的初等知识
其中的等价类为知识库K = (U, {R₁, R₂, R₃}) 的初等概念。

◆若P = {R₁, R₂}，P基本知识为U/IND(P) = {{x₁, x₅}, {x₂, x₃}, {x₄}, {x₆}}，其中的等价类为P基本概念。基本概念是初等概念的交集，如{x₁, x₅} = {x₁, x₅, x₆} ∩ {x₁, x₄, x₅} 是P = {R₁, R₂} 的一年级成绩优秀的学生这一基本概念。概念是对象的集合，如{x₄} ∪ {x₂, x₃} = {x₂, x₃, x₄} 是{R₁} 的概念，表示二年级或三年级（非一年级）。

◆有些概念在知识库中对应空集，如：{x₂, x₃} ∩ {x₁, x₄, x₅} = ∅，即知识库中不存在二年级成绩优秀的学生概念。
