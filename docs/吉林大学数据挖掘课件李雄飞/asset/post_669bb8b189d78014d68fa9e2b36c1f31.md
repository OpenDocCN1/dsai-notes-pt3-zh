# 决策规则

设 S = (U, A, V, f) 是决策表，A = C ∪ D，C 为条件属性集，D 为决策属性集。令 X_i 和 Y_j 分别表示条件类和决策类。

Des(X_i) 表示条件类 X_i 的描述，
定义为：Des(X_i) = {(a, v_a) | f(x, a) = v_a, ∀a ∈ C}

Des(Y_j) 表示决策类 Y_j 的描述，定义为：
Des(Y_j) = {(a, v_a) | f(x, a) = v_a, ∀a ∈ D}

决策规则定义为：
T_ij : Des(X_i) → Des(Y_j)，当 X_i ∩ Y_j ≠ ∅

规则 T_ij 的确定性因子 μ(X_i, Y_j) = |Y_j ∩ X_i| / |X_i|，显然 0 < μ ≤ 1。

- 当 μ(X_i, Y_j) = 1 时，T_ij 是确定的规则；
- 当 0 < μ < 1 时，T_ij 是不确定的规则，此时 μ(X_i, Y_j) 反映 X_i 中的对象可分类到 Y_j 中的比例。

决策表中所有决策规则的集合称为决策算法。

# 决策规则(续)

- 在从决策表中提取决策规则时，如果多个对象的信息（属性值）完全相同，则只保留其中之一，然后求条件属性的相对约简，得到约简的决策表。
- 重复的行表达同一决策规则，可以将其移去，这里的行不表示任何实际对象的描述。
- 最后对每条决策规则进行约简，并利用决策逻辑方法求出极小化的决策算法。
- 例如，由上述约简决策表生成的决策规则为：

```
(b, 0) ∧ (c, 2) → (e, 1)
(b, 2) ∧ (c, 0) → (e, 2)
(b, 2) ∧ (c, 2) → (e, 0)
(b, 1) ∧ (c, 0) → (e, 2)
(b, 1) ∧ (c, 1) → (e, 2)
(b, 1) ∧ (c, 2) → (e, 1)
```

# 著名的复杂性与精确性“不相容原理”

当系统的复杂性不断增长时，对系统特性精确而有效描述的能力将相应降低，直至达到一个阈值，一旦超过该阈值，精确性和有效性将变成互相排斥的两个特性，
即，系统复杂程度越高，人们对它的认识越模糊。
不相容原理深刻地揭示了模糊数学产生与发展的必然性。

# 模糊集与隶属函数

论域U上的一个模糊集合通过一个隶属函数刻画：
μ_A(x):U→[0,1]，x∈U

对任意x∈U，都指定一个数 μ_A(x)∈[0,1]与之对应，称为x对A的隶属度(Degree Of Membership)，μ_A称为A的隶属函数(Membership Function)。

- 若 μ_A(x)=0，则x完全不属于A;
- 若 μ_A(x)=1，则x完全属于A;
- 若0< μ_A(x)<1，则x属于A的隶属度为 μ_A(x)。

当 μ_A 的值域为{0,1}时，A退化为经典集合，即经典集合是模糊集合的特例。

模糊性的根源在于客观事物之间的差异存在中间过渡，存在亦此亦彼的现象。

隶属函数是模糊集理论的基本概念，它以0、1之间的一个数反映一个元素隶属于集合的程度，进而描述模糊现象。

# 常用的隶属函数

- 1. 三角形隶属函数
- $\mu_A(x)=\begin{cases}\dfrac{x-a}{m-a} & x\in[a,m]\dfrac{b-x}{b-m} & x\in[m,b]\0 & x\le a\ \text{或}\ x\ge b\end{cases}$

- 2. S隶属函数
- $\mu_A(x)=\begin{cases}0 & x\le a\2\left(\dfrac{x-a}{b-a}\right)^2 & x\in[a,m]\1-2\left(\dfrac{x-a}{b-a}\right)^2 & x\in[m,b]\1 & x>b\end{cases}$

- 3. 正态隶属函数
- $\mu_A(x)=e^{-k(x-a)^2},\ k>0$

- 4. 梯形隶属函数
- $\mu_A(x)=\begin{cases}\dfrac{x-a}{m-a} & x\in[a,m]\1 & x\in[m,n]\dfrac{b-x}{b-n} & x\in[n,b]\0 & x<a\ \text{或}\ x>b\end{cases}$

# 模糊集的表示方法

当U为有限个元素时，称为有限论域，设U={x₁, x₂, ..., xₙ}，模糊集就表示为 A = Σ μ_A(x_i)/x_i = μ_A(x₁)/x₁ + μ_A(x₂)/x₂ + ⋯ + μ_A(xₙ)/xₙ 这只是一种记法，表示每个元素x_i的隶属度为 μ_A(x_i)，而不是通常意义下的分式求和。

当U是连续论域时，A = ∫ μ_A(x)/x ，这里的积分号不是通常的积分含义，该式表示对每个x都指定了相应的隶属度 μ_A(x)。

- 用隶属函数的解析式来表示一个模糊集；
- 当论域为有限集时，可以用序偶的形式或向量的形式表示模糊集。
