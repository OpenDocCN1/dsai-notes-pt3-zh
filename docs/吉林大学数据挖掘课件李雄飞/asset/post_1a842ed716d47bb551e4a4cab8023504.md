
## 模糊集的基本运算

设 A、B 是同一论域 U 上的两个模糊集合，其隶属函数分别为 μ_A(x) 和 μ_B(x)，A 与 B 的并集、交集分别记为 A∪B 和 A∩B。A 的补集记为 \bar A。它们的隶属函数分别为：

μ_{A∪B}(x) = μ_A(x) ∨ μ_B(x) = max{μ_A(x), μ_B(x)}, ∀x ∈ U

μ_{A∩B}(x) = μ_A(x) ∧ μ_B(x) = min{μ_A(x), μ_B(x)}, ∀x ∈ U

μ_{A^c}(x) = 1 - μ_A(x), ∀x ∈ U

其中，max 和 ∨ 表示最大运算，min 和 ∧ 表示最小运算。

## 模糊运算与性质

设 A, B 是同一论域 U 上的两个模糊集，定义模糊集间的包含关系、相等关系如下：

若 ∀x∈U, 都有 μ_A(x) ≥ μ_B(x), 则称 A 包含 B, 记作 A⊇B;

若 ∀x∈U, 都有 μ_A(x) = μ_B(x), 则称 A 等于 B, 记作 A=B;

显然, A=B 当且仅当 A⊇B 且 B⊇A。

论域 U 上的模糊集 A, B, C, 空集用 ∅ 表示, 模糊集的并、交、补运算具有如下性质：

- 1. 幂等律: A∪A=A, A∩A=A
- 2. 交换律: A∪B=B∪A, A∩B=B∩A
- 3. 结合律: (A∪B)∪C=A∪(B∪C), (A∩B)∩C=A∩(B∩C)
- 4. 分配律: A∪(B∩C)=(A∪B)∩(A∪C), A∩(B∪C)=(A∩B)∪(A∩C)
- 5. 吸收律: (A∩B)∪A=A, (A∪B)∩A=A
- 6. 同一律: A∪∅=U, A∩U=A, A∪∅=A, A∩∅=∅
- 7. 复原律: \overline{\overline{A}} = A
- 8. 对偶律(德·摩根律): \overline{A∪B}=\overline{A}∩\overline{B}    \overline{A∩B}=\overline{A}∪\overline{B}

## 模糊集运算(例)

例4.3 设论域U={x₁, x₂, ..., x₅}, U上的模糊集A, B分别为：

A=0.9/x₁ +0.7/x₂ +1/x₃ +0.2/x₄ +0.3/x₅

B=0.6/x₁ +0.8/x₂ +0.5/x₃ +0.5/x₄ +0/x₅

求A∪B, A∩B, Ā 及 B̄ 。

解 A∪B= 0.9∨0.6/x₁ + 0.7∨0.8/x₂ + 1∨0.5/x₃ + 0.2∨0.5/x₄ + 0.3∨0/x₅

= 0.9/x₁ + 0.8/x₂ + 1/x₃ + 0.5/x₄ + 0.3/x₅

A∩B= 0.9∧0.6/x₁ + 0.7∧0.8/x₂ + 1∧0.5/x₃ + 0.2∧0.5/x₄ + 0.3∧0/x₅

= 0.6/x₁ + 0.7/x₂ + 0.5/x₃ + 0.2/x₄ + 0/x₅

Ā = 1-0.9/x₁ + 1-0.7/x₂ + 1-1/x₃ + 1-0.2/x₄ + 1-0.3/x₅

= 0.1/x₁ + 0.3/x₂ + 0/x₃ + 0.8/x₄ + 0.7/x₅

B̄ = 1-0.6/x₁ + 1-0.8/x₂ + 1-0.5/x₃ + 1-0.5/x₄ + 1/x₅

## 分解定理与扩展原理

在实际应用中，往往需要对模糊现象做出明确判定。因此，需要建立模糊集与经典集合的关系。经典集合中判断一个元素属于某集合的阈值是1，即一个元素相对于集合的特征函数值为1时，该元素属于这个集合，否则不属于这个集合。对于模糊集来说，可以取 λ∈[0,1] 作为阈值。

设 A 为论域 U 上的模糊集， λ∈[0,1]，
令 A_λ = {x | μ_A(x) ≥ λ}，称 A_λ 为 A 的 λ 截集。

令 A_λ^• = {x∈U | μ_A(x) ≥ λ}，称 A_λ^• 为 A 的强 λ 截集。

例 4.4 令 U = {x₁, x₂, x₃, x₄, x₅}，
A = 0.9/x₁ + 0.7/x₂ + 1/x₃ + 0.2/x₄ + 0.3/x₅，求 A₀.₃，A₀.₅，A₀.₇，A₁，A₀。
解 A₀.₃ = {x₁, x₂, x₃, x₅}，A₀.₅ = {x₁, x₂, x₃}，A₀.₇ = {x₁, x₂, x₃}，
A₁ = {x₃}，A₀ = U。

## 分解定理与扩展原理(续)

- ◆ 定理4.1  $(A\cup B)_\lambda = A_\lambda \cup B_\lambda$, $(A\cap B)_\lambda = A_\lambda \cap B_\lambda$
- ◆ 定理4.2 若 $\lambda \le \mu$, 则 $A_\lambda \supseteq A_\mu$。
- ◆ 对 $U$ 上的模糊集合 $A$, 称 $A_1$ 为 $A$ 的核, 记作 $core(A)$, 即:
  $core(A) = \{x \in U \mid \mu_A(x)=1\}$
- ◆ 称 $SuppA = \{x \mid \mu_A(x)>0\}$ 为 $A$ 的支集, 称 $SuppA - A_1$ 为 $A$ 的边界。
- ◆ 核 $core(A)$ 由完全隶属于 $A$ 的成员组成。若 $core(A)$ 不空, 则称 $A$ 为正规模糊集; 否则, 称为非正规模糊集。

## 分解定理

- 设 λ∈[0, 1], A为论域U上的模糊集, λ和A的数乘记为 λA, 定义其隶属函数为: μ_{λA}(x)=λ∧μ_A(x)
- 定理4.3(分解定理) 设 λ∈[0, 1], A为模糊集, A_λ为A的λ截集, 则: A = ⋃_{λ∈[0,1]} λA_λ
- 定理4.4(隶属函数形式的分解定理) 设 λ∈[0, 1], A为模糊集, A_λ为A的λ截集, 是A_λ的特征函数, 则有: μ_A(x)= ∨_{λ∈[0,1]} (λ∧C_{A_λ}(x))

## 扩展原理

扩展原理 X和Y是两个论域，映射f：X→Y

A为X上的模糊集，A在映射f下的像是Y上的一个模糊集 B=f(A)，对∀y∈Y， μ_B(y)= sup μ_A(x)，其中x∈X且y=f(x)。

扩展原理使得模糊集A经f映射成模糊集f(A)时，模糊集A和f(A)的对应元素的隶属函数保持不变。

模糊集合允许将一个映射或关系的定义域从论域U上的点扩展到论域U上的模糊集。扩展原理不仅可以用于映射，还可以用于关系或谓词。

## 模糊集的特征

- 高：隶属函数值的上确界，即 Sup μ_A(x) 称为 A 的高，记作 hgt(A)。显然，模糊集是正规的，等价于其高为1。
- 单峰性：A 是单峰的，若隶属函数为单峰函数。
- 凸性：模糊集 A 称为凸模糊集，当其隶属函数满足对 ∀x₁, x₂∈U, λ∈[0,1], μ_A(λ x₁ - (1 - λ) x₂) ≥ min{ μ_A(x₁), μ_A(x₂) }
- 基：给定有限论域 U 上的模糊集 A，A 的基定义为其隶属函数值的和，记作 Card(A)，即： Card(A) = Σ_{x∈U} μ_A(x) 若 U 是无限的，则定义 Card(A) = ∫_{x∈U} μ_A(x) d x
- 例如，模糊集 A=0.1/x₁+0.3/x₂+0.6/x₃+1.0/x₄+0.4/x₅，则 Card(A)=2.4。

## 模糊集的度量

设映射 d：F(U)→[0,1]，如果满足条件：

- (1) d(A)=0，当且仅当A为经典集合
- (2) μ_A(x)恒为1/2时，d(A)=1
- (3) 当∀x∈U，|μ_A(x)-1/2| ≤ |μ_B(x)-1/2| 时，d(A) ≥ d(B)
  则称 d(A) 为模糊集的模糊度。

U上的模糊度可看作从U到[0,1]的函数。所以，凡是用来度量函数间距离的方法都可以用來度量模糊集间的距离。

若 d(x,y) ≥0，称 d(x,y) 为 x 与 y 间的距离。应满足条件：

- (1) d(x,y)=0，当且仅当 x = y
- (2) d(x,y)=d(y,x)
- (3) d(x,y) ≤ d(x,z)+d(z,y)
