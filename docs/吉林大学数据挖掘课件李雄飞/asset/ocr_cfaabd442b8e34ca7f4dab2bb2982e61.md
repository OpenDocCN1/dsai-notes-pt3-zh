# 引言

# 数据存储量急剧上升

+   - NASA轨道卫星上的EOS每小时向地面发回50GB的图像数据
+   - 美国零售商系统Wal-Mart每天产生2亿交易数据
+   - 人类基因组项目已经搜集数以GB计的基因编码数据

# 存储技术的发展

+   - 大容量、高速度、低价格的存储设备相继问世
+   - 数据仓库技术
+   - VLDB技术

# 面临的问题

+   - 信息量过大，超过了人们掌握、消化的能力
+   - 一些信息真伪难辨，难以正确运用
+   - 信息组织形式的不一致性，增加信息处理难度

# 新的认识

隐藏在数据之后更深层次、更重要的信息能够描述数据的整体特征，可以预测发展趋势，在决策中具有重要价值。
