# 分辨矩阵与分辨函数

令 S = (U, A, V, f) 为一信息系统，|U| = n，|A| = m，S 的分辨矩阵 M 定义为一个 n 阶对称矩阵，其 i 行 j 列处元素定义为：

m_ij = {a ∈ A | f(x_i, a) ≠ f(x_j, a)}    i, j = 1, …, n

即 m_ij 是能够区别对象 x_i 和 x_j 的所有属性的集合。

对于每一个 a ∈ A，指定布尔变量 a̅，将信息系统的分辨函数定义为一个 m 元布尔函数，形式如下：

ρ(a1, a2, …, am) = ∧ {∨ m_ij | 1 ≤ j < i ≤ n, m_ij ≠ ∅}

即 ρ 为 (∨ m_ij) 的合取，而 (∨ m_ij) 为 m_ij 中各属性对应的布尔变量的析取。

分辨函数的析取范式中的每一个合取式对应一个约简。

核是分辨矩阵中所有单个元素组成的集合，即：
CORE(A) = {a ∈ A | m_ij = {a}, 1 ≤ i, j ≤ n}
