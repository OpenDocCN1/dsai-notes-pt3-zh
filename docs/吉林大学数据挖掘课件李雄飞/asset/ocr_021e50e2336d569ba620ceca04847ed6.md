# 知识约简(例)

例3.6 设有知识库K=(U,R)，其中U={x₁, x₂, ..., x₈}，R={R₁, R₂, R₃}，等价关系R₁, R₂, R₃的等价类如下：

U/R₁ = {{x₁, x₄, x₅, x₆}, {x₂, x₃}, {x₇, x₈}}

U/R₂ = {{x₁, x₂, x₅}, {x₄, x₆, x₇}, {x₃, x₈}}

U/R₃ = {{x₁, x₂, x₅}, {x₄, x₆}, {x₃, x₇}, {x₈}}

求约简和核。

解 由题意，

U/IND(R) = {{x₁, x₅}, {x₂}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

U/IND(R−{R₁}) = U/{R₂, R₃} = {{x₁, x₂, x₅}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

U/IND(R−{R₂}) = U/{R₁, R₃} = {{x₁, x₅}, {x₂}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

U/IND(R−{R₃}) = U/{R₁, R₂} = {{x₁, x₅}, {x₂}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

显然，R₁是R中不可省的，R₂与R₃是R中可省的。故核为R₁，即 CORE(R) = {R₁}。
