# 模糊等价关系

设 R = (r_ij)_{n×n} 为论域 U 上的模糊矩阵（模糊关系），

+   (1) 若对任意的 i 都有 r_ii = 1，则称 R 满足自反性。
+   (2) 若对任意的 i 都有 r_ij = r_ji，则称 R 满足对称性。
+   (3) 若有 R² ⊆ R，则称 R 满足传递性。

称满足自反性、对称性和传递性的模糊关系为模糊等价关系；称满足自反性和对称性的模糊关系为模糊相似关系。

定理4.5 R 为模糊等价关系的充要条件是对任意的 λ ∈ [0,1]，λ 截矩阵 R_λ 是经典集合论中的等价关系。

在经典集合论中，等价关系对应论域上的一个划分，即等价关系可用于对论域对象进行分类。由定理4.5可知，模糊等价关系确定之后，当给定一个 λ ∈ [0,1] 时，可得到一个普通的等价关系 R_λ，从而得到一个 λ 水平的分类。

定理4.6 若 0 ≤ α ≤ β ≤ 1，则由 R_β 分出的每个类必是由 R_α 分出的某一类的子类（R_β 的分类法是对 R_α 的分类法的“加细”）。
