# 分解定理与扩展原理(续)

+   ◆ 定理4.1  $(A\cup B)_\lambda = A_\lambda \cup B_\lambda$, $(A\cap B)_\lambda = A_\lambda \cap B_\lambda$

+   ◆ 定理4.2 若 $\lambda \le \mu$, 则 $A_\lambda \supseteq A_\mu$。

+   ◆ 对 $U$ 上的模糊集合 $A$, 称 $A_1$ 为 $A$ 的核, 记作 $core(A)$, 即:
+   $core(A) = \{x \in U \mid \mu_A(x)=1\}$

+   ◆ 称 $SuppA = \{x \mid \mu_A(x)>0\}$ 为 $A$ 的支集, 称 $SuppA - A_1$ 为 $A$ 的边界。

+   ◆ 核 $core(A)$ 由完全隶属于 $A$ 的成员组成。若 $core(A)$ 不空, 则称 $A$ 为正规模糊集; 否则, 称为非正规模糊集。
