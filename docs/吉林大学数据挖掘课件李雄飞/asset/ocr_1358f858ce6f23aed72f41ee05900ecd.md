# 决策表(续)

◆由决策表可知：
U/C = {{x₁}, {x₂}, {x₃}, {x₄}, {x₅}, {x₆}, {x₇}}，
U/D = {{x₁, x₂, x₇}, {x₃, x₅, x₆}, {x₄}}，
POS_C(D) = {x₁, x₂, x₃, x₄, x₅, x₆, x₇}，
k = |POS_C(D)| / |U| = 1，故该决策表是一致决策表。

◆与一般约简类似，可以定义决策表的分辨矩阵及分辨函数。

| | x₁ | x₂ | x₃ | x₄ | x₅ | x₆ | x₇ |
|---|---|---|---|---|---|---|---|
| x₁ |  |  |  |  |  |  |  |
| x₂ |  |  |  |  |  |  |  |
| x₃ | b, c, d | b, c |  |  |  |  |  |
| x₄ | b | b, d | c, d |  |  |  |  |
| x₅ | a, b, c, d | a, b, c |  | a, b, c, d |  |  |  |
| x₆ | a, b, c, d | a, b, c |  | a, b, c, d |  |  |  |
| x₇ |  |  | a, b, c, d | a, b | c, d | c, d |  |
