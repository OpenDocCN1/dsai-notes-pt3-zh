# 近似空间(例)

例3.1 设论域 U={x₁, x₂, x₃, x₄, x₅}, R={R₁, R₂, R₃}, I是恒等关系, R₁, R₂, R₃定义如下:

R₁={<x₁, x₂>, <x₂, x₁>, <x₃, x₄>, <x₄, x₃>}∪I

R₂={<x₁, x₂>, <x₂, x₁>, <x₄, x₅>, <x₅, x₄>}∪I

R₃={<x₁, x₂>, <x₂, x₁>, <x₁, x₃>, <x₃, x₁>, <x₂, x₃>, <x₃, x₂>, <x₄, x₅>, <x₅, x₄>}∪I

若 P={R₁, R₂}⊆R, 则由定义可知:

IND(P)=R₁ ∩ R₂={<x₁, x₂>, <x₂, x₁>}∪I

IND(R)=R₁ ∩ R₂ ∩ R₃={<x₁, x₂>, <x₂, x₁>}∪I

利用商集来描述不可分辨关系。

U / R₁={{x₁, x₂}, {x₃, x₄}, {x₅}}

U / R₂={{x₁, x₂}, {x₃}, {x₄, x₅}}

U / R₃={{x₁, x₂, x₃}, {x₄, x₅}}

U / IND(P)=U / {R₁, R₂}={{x₁, x₂}, {x₃}, {x₄}, {x₅}}

U / IND(R)=U / {R₁, R₂, R₃}={{x₁, x₂}, {x₃}, {x₄}, {x₅}}
