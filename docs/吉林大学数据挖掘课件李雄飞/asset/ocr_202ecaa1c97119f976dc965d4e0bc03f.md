# 模糊集运算(例)

例4.3 设论域U={x₁, x₂, ..., x₅}, U上的模糊集A, B分别为：

A=0.9/x₁ +0.7/x₂ +1/x₃ +0.2/x₄ +0.3/x₅

B=0.6/x₁ +0.8/x₂ +0.5/x₃ +0.5/x₄ +0/x₅

求A∪B, A∩B, Ā 及 B̄ 。

解 A∪B= 0.9∨0.6/x₁ + 0.7∨0.8/x₂ + 1∨0.5/x₃ + 0.2∨0.5/x₄ + 0.3∨0/x₅

= 0.9/x₁ + 0.8/x₂ + 1/x₃ + 0.5/x₄ + 0.3/x₅

A∩B= 0.9∧0.6/x₁ + 0.7∧0.8/x₂ + 1∧0.5/x₃ + 0.2∧0.5/x₄ + 0.3∧0/x₅

= 0.6/x₁ + 0.7/x₂ + 0.5/x₃ + 0.2/x₄ + 0/x₅

Ā = 1-0.9/x₁ + 1-0.7/x₂ + 1-1/x₃ + 1-0.2/x₄ + 1-0.3/x₅

= 0.1/x₁ + 0.3/x₂ + 0/x₃ + 0.8/x₄ + 0.7/x₅

B̄ = 1-0.6/x₁ + 1-0.8/x₂ + 1-0.5/x₃ + 1-0.5/x₄ + 1/x₅
