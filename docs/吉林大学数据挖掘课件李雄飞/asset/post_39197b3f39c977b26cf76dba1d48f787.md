
## 知识的依赖性

知识库中的知识的重要性并不相同，有些知识可由其他知识导出。

- 设K=(U, R)为知识库，P, Q ⊆ R
- (1) 知识Q依赖于知识P，记作P⇒Q，当且仅当IND(P) ⊆ IND(Q)
- (2) 知识P与知识Q等价，记作P≡Q，当且仅当P⇒Q 且 Q⇒P
- (3) 知识P与知识Q独立，记作P≠Q，当且仅当P⇒Q与Q⇒P均不成立
- 当知识Q依赖于知识P时，也称知识P可推导出知识Q。
- P≡Q当且仅当IND(P)=IND(Q)。
- 知识的依赖性也可能是部分的，即知识P可部分地推导出知识Q。
- 知识Q部分依赖于知识P可由知识的正域来定义。

设K=(U, R)为一个知识库，且P, Q⊆R，令
k = γ_P(Q) = |POS_P(Q)| / |U|

称知识Q依赖于知识P，依赖度为k，记作P⇒_k Q。

当k=1时，称知识Q完全依赖于知识P，P⇒_1 Q，也简记为P⇒Q；

当0<k<1时，称知识Q部分依赖于知识P；

当k=0时，称知识Q完全独立于P。

依赖度k反映了根据知识P将对象分类到知识Q的基本概念中的能力。当P⇒_k Q时，论域中共有k|U|个属于Q的P正域的对象，这些对象可以依据知识P分类到知识Q的基本概念中去。

例3.8 U={x₁, x₂, ..., x₈}，U/P={{x₁}, {x₂}, {x₃, x₄}, {x₅, x₆}, {x₇, x₈}}，U/Q={{x₁, x₂}, {x₃, x₄}, {x₅, x₆}, {x₇}, {x₈}}，求γ_P(Q)。

解 POS_P(Q)={x₁}∪{x₂}∪{x₃, x₄}∪{x₅, x₆}={x₁, x₂, x₃, x₄, x₅, x₆}，γ_P(Q)=6/8=0.75。即知识Q相对于知识P的依赖度为0.75。

## 信息系统

信息系统是一种知识表达方式，利用信息系统和决策表来解释粗糙集的相关概念更易于理解。

称四元有序组 S = (U, A, V, f) 为信息系统，其中非空有限集合 U 为论域；A 为属性的非空有限集合；V = ∪_{a∈A} V_a，而 V_a 为属性 a 的值域；f: U×A→V 是一个信息函数，∀x∈U ∀a∈A, f(x, a)∈V_a，对于给定对象 x，f(x, a) 赋予对象 x 在属性 a 下的属性值。信息系统也可简记为 S = (U, A)。

信息系统可用数据表格表示，表格的行对应论域中的对象，列对应描述对象的属性。一个对象的全部信息用一行属性的值来反映。

设 P ⊆ A 且 P ≠ ∅，定义由属性子集 P 导出的二元关系如下：

IND(P) = { (x, y) | (x, y) ∈ U×U 且 ∀a∈P 有 f(x, a) = f(y, a) }

若 (x, y) ∈ IND(P)，则称 x 和 y 是 P 不可分辨的，即依据 P 中属性无法将 x 和 y 区分开。

若定义由属性 a∈A 导出的等价关系为：

ã = {(x, y) | (x, y) ∈ U × U 且 f(x, a) = f(y, a)}

则 P ⊆ A 导出的不可分辨关系亦可定义为：

IND(P) = ⋂_{a∈P} ã

给定信息系统 S=(U, A)，A 的每个属性对应一个等价关系，而属性子集对应不可分辨关系。信息系统与一个知识库相对应，因此一个数据表格可以看成一个知识库。

在不引起混淆的前提下，为简单起见，用属性集符号来代替等价关系（如用 P 代替 IND(P)）。前面讨论的知识依赖性、知识约简等问题，在信息系统中可以转化为属性依赖性、属性的约简等问题。

## 信息系统(例)

例3.9 设有信息系统 S=(U, A)，U={x₁, x₂, x₃, x₄, x₅, x₆}，A={a, b, c, d}，利用数据表格表示如下：

| U | a | b | c | d |
|---|---|---|---|---|
| x₁ | 0 | 0 | 0 | 0 |
| x₂ | 0 | 2 | 1 | 1 |
| x₃ | 0 | 1 | 0 | 0 |
| x₄ | 1 | 2 | 1 | 2 |
| x₅ | 1 | 0 | 0 | 1 |
| x₆ | 1 | 2 | 1 | 2 |

所有A基本集形成的集合为：

U/A = U/{a, b, c, d} = {{x₁}, {x₂}, {x₃}, {x₄, x₆}, {x₅}}

可见，对象x₄和x₆在信息系统中是不可分辨的。

若取属性集B={b, c}，则B基本集为{x₁, x₅}，{x₂, x₄, x₆}，{x₃}，

U/B = U/{b, c} = {{x₁, x₅}, {x₂, x₄, x₆}, {x₃}}

对象x₁和x₅是B不可分辨的，即用属性b及属性c提供的信息，不足以区分x₁和x₅（同样，x₂、x₄、x₆也是B不可分辨的）。

设X={x₂, x₃, x₄}，则有 B̲X = POS_B(X) = {x₃}， B̄X = {x₂, x₃, x₄, x₆}，BN_B(X) = {x₂, x₄, x₆}，NEG_B(X) = U - B̄X = {x₁, x₅}。

计算可得{a, b}和{b, d}是约简，{b}是核。

## 分辨矩阵与分辨函数

令 S = (U, A, V, f) 为一信息系统，|U| = n，|A| = m，S 的分辨矩阵 M 定义为一个 n 阶对称矩阵，其 i 行 j 列处元素定义为：

m_ij = {a ∈ A | f(x_i, a) ≠ f(x_j, a)}    i, j = 1, …, n

即 m_ij 是能够区别对象 x_i 和 x_j 的所有属性的集合。

对于每一个 a ∈ A，指定布尔变量 a̅，将信息系统的分辨函数定义为一个 m 元布尔函数，形式如下：

ρ(a1, a2, …, am) = ∧ {∨ m_ij | 1 ≤ j < i ≤ n, m_ij ≠ ∅}

即 ρ 为 (∨ m_ij) 的合取，而 (∨ m_ij) 为 m_ij 中各属性对应的布尔变量的析取。

分辨函数的析取范式中的每一个合取式对应一个约简。

核是分辨矩阵中所有单个元素组成的集合，即：

CORE(A) = {a ∈ A | m_ij = {a}, 1 ≤ i, j ≤ n}

## 信息系统约简(例)

例3.10 针对例3.9中的信息系统，求约简及核。

解 分辨矩阵如下：

|   | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|
| 1 |   |   |   |   |   |   |
| 2 | b, c, d |   |   |   |   |   |
| 3 | b | b, c, d |   |   |   |   |
| 4 | a, b, c, d | a, d | a, b, c, d |   |   |   |
| 5 | a, d | a, b, c | a, b, d | b, c, d |   |   |
| 6 | a, b, c, d | a, d | a, b, c, d | - | b, c, d |   |

分辨函数为：

ρ(a, b, c, d) = (b∨c∨d) ∧ (b) ∧ (a∨b∨c∨d) ∧ (a∨d) ∧ (a∨b∨c∨d) ∧ (b∨c∨d) ∧ (a∨d) ∧ (a∨b∨c) ∧ (a∨d) ∧ (a∨b∨c∨d) ∧ (a∨b∨d) ∧ (a∨b∨c∨d) ∧ (b∨c∨d) ∧ (b∨c∨d) = b ∧ (a∨d)

因此，该信息系统有两个约简{a, b}和{b, d}，核是{b}。得到两个约简的数据表格。

## 决策表

设S=(U, A, V, f)为信息系统，若A划分为条件属性集C和决策属性集D，即C∪D=A，C∩D=∅，则称信息系统为决策表（Decision Table）。IND(C)的等价类称为条件类，IND(D)的等价类称为决策类。

决策表的分类：

- (1) 称决策表是一致的，当且仅当D依赖于C，即C⇒D；
- (2) 称决策表是不一致的，当且仅当C⇒_k D (0<k<1)；

例3.11 设论域U={x₁, x₂, ..., x₇}，属性集A=C∪D，条件属性集C={a, b, c, d}，决策属性集D={e}，决策表如下。

|   | a | b | c | d | e |
|---|---|---|---|---|---|
| x₁ | 1 | 0 | 2 | 1 | 1 |
| x₂ | 1 | 0 | 2 | 0 | 1 |
| x₃ | 1 | 2 | 0 | 0 | 2 |
| x₄ | 1 | 2 | 2 | 1 | 0 |
| x₅ | 2 | 1 | 0 | 0 | 2 |
| x₆ | 2 | 1 | 1 | 0 | 2 |
| x₇ | 2 | 1 | 2 | 1 | 1 |
