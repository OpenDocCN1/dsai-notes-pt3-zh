# 模糊集的基本运算

设 A、B 是同一论域 U 上的两个模糊集合，其隶属函数分别为 μ_A(x) 和 μ_B(x)，A 与 B 的并集、交集分别记为 A∪B 即 A∩B。A 的补集记为 。它们的隶属函数分别为：

μ_{A∪B}(x) = μ_A(x) ∨ μ_B(x) = max{μ_A(x), μ_B(x)}, ∀x ∈ U

μ_{A∩B}(x) = μ_A(x) ∧ μ_B(x) = min{μ_A(x), μ_B(x)}, ∀x ∈ U

μ_{A^c}(x) = 1 - μ_A(x), ∀x ∈ U

其中，max 和 ∨ 表示最大运算，min 和 ∧ 表示最小运算。
