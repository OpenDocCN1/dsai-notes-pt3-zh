
## 粗糙集的特征描述

- 用表示近似精度的数值表示粗糙集的数字特征
  表示粗糙集边界域的相对大小，但没有说明边界域的结构。
- 用粗糙集的拓扑分类表示粗糙集的拓扑特征
  给出边界域的结构信息，但没有给出边界域大小的信息。
  应用时应综合考虑数字特征和拓扑特征。

由等价关系R定义的集合X的近似精度为：

```
α_R(X) = | \underline{R} X | / | \overline{R} X |
```

其中X非∅，|X|表示集合的基数，显然，0 ≤ α_R(X) ≤ 1。

α_R(X)反映了利用知识R近似表示X的完全程度。

- 当 α_R(X)=1时，X是R精确集，其边界域为空集；
- 当0≤ α_R<1时，X是R粗糙集，边界域非空。

## 粗糙集近似精度(例)

例3.4 论域U，等价关系R及X_i (i=1, 2, 3, 4)的定义同例3.3，求X_i的近似精度。

解 根据例3.3中的结果，有：

α_R(X₁) = | \underline{R} X₁ | / | \overline{R} X₁ | = 4/4 = 1

α_R(X₂) = | \underline{R} X₂ | / | \overline{R} X₂ | = 3/7

α_R(X₃) = | \underline{R} X₃ | / | \overline{R} X₃ | = 0/7 = 0

α_R(X₄) = | \underline{R} X₄ | / | \overline{R} X₄ | = 3/10

## 粗糙集的特征描述(续)

设X是一个R粗糙集，

- (1) 称X是R粗糙可定义的，当且仅当 \underline{R}(X) ≠ ∅ 且 \overline{R}(X) ≠ U
- (2) 称X是R内不可定义的，当且仅当 \underline{R}(X) = ∅ 且 \overline{R}(X) ≠ U
- (3) 称X是R外不可定义的，当且仅当 \underline{R}(X) ≠ ∅ 且 \overline{R}(X) = U
- (4) 称X是R全不可定义的，当且仅当 \underline{R}(X) = ∅ 且 \overline{R}(X) = U

- 若集合X是R粗糙可定义的，则可以确定U中某些元素是否属于X或~X；
- 若X是R内不可定义的，则可以确定U中某些元素是否属于~X，但对U中任一元素都无法确定其是否属于X；
- 若X是R外不可定义的，则可以确定U中某些元素是否属于X，但对U中任一元素都无法确定其是否属于~X；
- 若X是R全不可定义的，则对U中任一元素x，既无法确定x是否属于X，也无法确定x是否属于~X。

## 知识约简

知识库中可能含有冗余的知识。知识约简研究在保持分类能力不变的前提下，删除冗余的知识的方法。它是粗糙集理论的核心内容之一，在数据挖掘领域具有重要的应用意义。

设ℛ是一个等价关系族，R∈ℛ，若有IND(ℛ)=IND(R-{R})，则称R为等价关系族ℛ中可省的，否则称为不可省的。若ℛ中任意一个等价关系R都是不可省的，则称ℛ是独立的，否则称为依赖的。

设Q⊂P，若Q是独立的，且IND(Q)=IND(P)，则称Q是等价关系族P的一个约简(Reduct)。P中所有不可省关系的集合称为等价关系族P的核(Core)，记作CORE(P)。

显然，P可以有多个约简，以RED(P)表示P的所有约简的集合。

定理:等价关系P的核等于P的所有约简的交集，即有：
CORE(P) = ∩RED(P)

## 知识约简(例)

例3.6 设有知识库K=(U,R)，其中U={x₁, x₂, ..., x₈}，R={R₁, R₂, R₃}，等价关系R₁, R₂, R₃的等价类如下：

U/R₁ = {{x₁, x₄, x₅, x₆}, {x₂, x₃}, {x₇, x₈}}

U/R₂ = {{x₁, x₂, x₅}, {x₄, x₆, x₇}, {x₃, x₈}}

U/R₃ = {{x₁, x₂, x₅}, {x₄, x₆}, {x₃, x₇}, {x₈}}

求约简和核。

解 由题意，

U/IND(R) = {{x₁, x₅}, {x₂}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

U/IND(R−{R₁}) = U/{R₂, R₃} = {{x₁, x₂, x₅}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

U/IND(R−{R₂}) = U/{R₁, R₃} = {{x₁, x₅}, {x₂}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

U/IND(R−{R₃}) = U/{R₁, R₂} = {{x₁, x₅}, {x₂}, {x₃}, {x₄, x₆}, {x₇}, {x₈}}

显然，R₁是R中不可省的，R₂与R₃是R中可省的。故核为R₁，即 CORE(R) = {R₁}。

## 知识约简(例)(续)

上述计算表明，
(U, {R₁, R₂}), (U, {R₁, R₃})与原有知识库K表示同样的知识(等价)，但{R₁, R₂}或{R₁, R₃}是否为约简，还要看其是否是独立的。

U/{R₁, R₂}≠U/R₁且U/{R₁, R₂}≠U/R₂，故{R₁, R₂}是独立的，所以{R₁, R₂}是R的一个约简。

同理{R₁, R₃}也是R的一个约简。

R有两个约简，分别为{R₁, R₂}和{R₁, R₃}。

核CORE(R)={R₁, R₂}∩{R₁, R₃}={R₁}。

## 相对约简和相对核

相对约简和相对核反映了一个分类与另一个分类的关系。这两个概念是决策表属性约简的基础。

设P和Q为论域U上的等价关系，Q的P正域记作POS_P(Q)，定义为： POS_P(Q)= ⋃_{X∈U/Q} P X

Q的P正域是U中所有可以根据分类(知识)U/P的信息准确分类到关系Q的等价类中去的对象构成的集合。

设P和Q为论域U上的等价关系族，R∈P，若 POS_IND(P)(IND(Q))=POS_IND(P-{R})(IND(Q)) 则称R为P中Q可省的，否则称R为P中Q不可省的。

若P中的任一关系R都是Q不可省的，则称P是Q独立的(相对于Q独立)。可以用POS_P(Q)代替POS_IND(P)(IND(Q))。

## 相对约简和相对核(续)

设 S⊆P，称 S 为 P 的 Q 约简，当且仅当 S 是 P 的 Q 独立子族，且 POS_S(Q)=POS_P(Q)。P 中所有 Q 不可省的原始关系构成的集合称为 P 的 Q 核，记作 CORE_Q(P)。

P 的所有 Q 约简构成的集合记作 RED_Q(P)，P 的 Q 约简称为相对约简，P 的 Q 核称为相对核。

定理 P 的 Q 核等于 P 的所有 Q 约简的交集

CORE_Q(P)=∩RED_Q(P)

- P 的 Q 核是知识的本质部分。
- 为保证将对象分类到 Q 的概念中去的分类能力不变，Q 核知识是不可消去的。
- 知识 P 的 Q 约简是 P 的子集，该子集是 Q 独立的，且与知识 P 相同的分类能力。

## 相对约简和相对核(例)

例3.7 设K=(U,P)为知识库，U={x1, x2, …, x8}，P={R1, R2, R3}。等价关系R1，R2，R3的等价类集合如下：
U/R1 = {{x1, x2, x3, x4}, {x5, x6}, x7, x8}}
U/R2 = {{x1, x3, x4, x7}, {x2, x6}, {x5, x8}}
U/R3 = {{x1, x5, x8}, {x2, x3, x4}, {x6, x7}}
由等价关系族Q导出的不可分辨关系的等价类集合为
U/Q-U/IND(Q) = {{x1, x3, x4}, {x2, x5, x6}, {x7, x8}}，求P的Q约简及P的Q核。
解 等价关系族P导出的不可分辨关系IND(P)的等价类为：
U/P-U/IND(P) = {{x1}, {x2}, {x3, x4}, {x5, x8}, {x6}, {x7}}
Q的P正域为：
POS_P(Q) = {x1} ∪ {x2} ∪ {x3, x4} ∪ {x6} ∪ {x7} = {x1, x2, x3, x4, x6, x7}
下面求出P中不可省的关系：
U/(P−{R1}) = U/{R2, R3} = {{x1}, {x2}, {x3, x4}, {x5, x8}, {x6}, {x7}}
U/(P−{R2}) = U/{R1, R3} = {{x1}, {x2, x3, x4}, {x5, x8}, {x6, x7}}
U/(P−{R3}) = U/{R1, R2} = {{x1, x3, x4}, {x2}, {x5, x8}, {x6}, {x7}}

## 相对约简和相对核(例)(续)

POS_(P-{R1})(Q) = {x1} ∪ {x2} ∪ {x3, x4} ∪ {x6} ∪ {x7} = {x1, x2, x3, x4, x6, x7} = POS_P(Q)

POS_(P-{R2})(Q) = {x1} ≠ POS_P(Q)

POS_(P-{R3})(Q) = {x1, x3, x4} ∪ {x2} ∪ {x6} ∪ {x7} = {x1, x2, x3, x4, x6, x7} = POS_P(Q)

可见R2是P中Q不可省的，而R1和R3是P中Q可省的，故CORE_Q(P) = (R2)。

{R1, R2}和{R2, R3}若是独立的，则是P的Q约简。

由于POS_{R1,R2}(Q) = {x1, x2, x3, x4, x6, x7}， POS_R1(Q) = ∅， POS_R2(Q) = {x2, x6}， 故{R1, R2}是独立的，因此是P的一个Q约简。

同理{R2, R3}也是一个P的Q约简。

一般约简是在不改变对论域中对象的分类能力的前提下消去冗余知识，而相对约简是在不改变将对象划分到另一个分类中去的分类能力的前提下消去冗余知识。
