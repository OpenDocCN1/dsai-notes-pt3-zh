# k-means改进算法

# 改进工作集中在：

+   - 参数k的选择
+   - 差异程度计算
+   - 聚类均值的计算方法等

# 例如：

+   - 先应用自下而上层次算法来获得聚类数目，并发现初始分类，然后再应用循环再定位(k-mean)来帮助改进分类结果。
+   - k-modes：用新的相异性度量方法处理对象，用基于频率的方法修改簇的modes。
+   - k-prototype：将k-means扩展到处理符号属性。
+   - EM(期望最大化)
+     - 概率权值, 聚类边界不严格
+     - 可扩展性, 识别数据中存在的三种类型区域
