# 信息系统

信息系统是一种知识表达方式，利用信息系统和决策表来解释粗糙集的相关概念更易于理解。

称四元有序组 S = (U, A, V, f) 为信息系统，其中非空有限集合 U 为论域；A 为属性的非空有限集合；V = ∪_{a∈A} V_a，而 V_a 为属性 a 的值域；f: U×A→V 是一个信息函数，∀x∈U ∀a∈A, f(x, a)∈V_a，对于给定对象 x，f(x, a) 赋予对象 x 在属性 a 下的属性值。信息系统也可简记为 S = (U, A)。

信息系统可用数据表格表示，表格的行对应论域中的对象，列对应描述对象的属性。一个对象的全部信息用一行属性的值来反映。

设 P ⊆ A 且 P ≠ ∅，定义由属性子集 P 导出的二元关系如下： IND(P) = { (x, y) | (x, y) ∈ U×U 且 ∀a∈P 有 f(x, a) = f(y, a) }

若 (x, y) ∈ IND(P)，则称 x 和 y 是 P 不可分辨的，即依据 P 中属性无法将 x 和 y 区分开。
