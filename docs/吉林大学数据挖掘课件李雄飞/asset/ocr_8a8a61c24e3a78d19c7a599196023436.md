# 模糊运算与性质

设 A, B 是同一论域 U 上的两个模糊集，定义模糊集间的包含关系、相等关系如下：

若 ∀x∈U, 都有 μ_A(x) ≥ μ_B(x), 则称 A 包含 B, 记作 A⊇B;

若 ∀x∈U, 都有 μ_A(x) = μ_B(x), 则称 A 等于 B, 记作 A=B;

显然, A=B 当且仅当 A⊇B 且 B⊇A。

论域 U 上的模糊集 A, B, C, 空集用 ∅ 表示, 模糊集的并、交、补运算具有如下性质：

+   1. 幂等律: A∪A=A, A∩A=A

+   2. 交换律: A∪B=B∪A, A∩B=B∩A

+   3. 结合律: (A∪B)∪C=A∪(B∪C), (A∩B)∩C=A∩(B∩C)

+   4. 分配律: A∪(B∩C)=(A∪B)∩(A∪C), A∩(B∪C)=(A∩B)∪(A∩C)

+   5. 吸收律: (A∩B)∪A=A, (A∪B)∩A=A

+   6. 同一律: A∪∅=U, A∩U=A, A∪∅=A, A∩∅=∅

+   7. 复原律: \overline{\overline{A}} = A

+   8. 对偶律(德·摩根律): \overline{A∪B}=\overline{A}∩\overline{B}    \overline{A∩B}=\overline{A}∪\overline{B}
