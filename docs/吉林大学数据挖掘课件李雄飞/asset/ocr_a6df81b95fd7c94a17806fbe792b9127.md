# 模糊关系性质

(1) 结合律：(Q ∘ R) ∘ S = Q ∘ (R ∘ S)
(2) 关于并的分配律：(Q ∪ R) ∘ S = (Q ∘ S) ∪ (R ∘ S)，
S ∘ (Q ∪ R) = (S ∘ Q) ∪ (S ∘ R)
但关于交的分配律不成立，即：
(Q ∩ R) ∘ S ≠ (Q ∘ S) ∩ (R ∘ S)，
S ∘ (Q ∩ R) ≠ (S ∘ Q) ∩ (S ∘ R)
(3) 设 O 为零关系，I 为恒等关系，
则有：O ∘ R = R ∘ O = O，    I ∘ R = R ∘ I = R
(4) Q ⊆ R ⇒ Q ∘ S ⊆ R ∘ S， Q ⊆ R ⇒ S ∘ Q ⊆ S ∘ R， Q ⊆ R ⇒ Q^T ⊆ R^T
(5) (Q ∘ R)_λ = Q_λ ∘ R_λ
