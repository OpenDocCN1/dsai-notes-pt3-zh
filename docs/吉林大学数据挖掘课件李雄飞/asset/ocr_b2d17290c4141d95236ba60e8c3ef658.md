# 模糊关系(续)

例4.9 设身高的论域为U {140, 150, 160, 170, 180}，单位为厘米，设体重的论域为V {40, 50, 60, 70, 80}，单位为公斤。下表是人的身高与体重之间的模糊关系。

| | 40 | 50 | 60 | 70 | 80 |
|---|---|---|---|---|---|
| 140 | 1 | 0.8 | 0.2 | 0.1 | 0 |
| 150 | 0.8 | 1 | 0.8 | 0.2 | 0.1 |
| 160 | 0.2 | 0.8 | 1 | 0.8 | 0.2 |
| 170 | 0.1 | 0.2 | 0.8 | 1 | 0.8 |
| 180 | 0 | 0.1 | 0.2 | 0.8 | 1 |

模糊矩阵 R =

```
⎛ 1   0.8  0.2  0.1  0 ⎞
⎜ 0.8 1    0.8  0.2  0.1 ⎟
⎜ 0.2 0.8  1    0.8  0.2 ⎟
⎜ 0.1 0.2  0.8  1    0.8 ⎟
⎝ 0   0.1  0.2  0.8  1   ⎠
```
