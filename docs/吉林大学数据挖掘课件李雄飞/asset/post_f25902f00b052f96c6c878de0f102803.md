
## DBSCAN算法

DBSCAN（Density Based Spatial Clustering of Applications with Noise）算法是一种基于密度的聚类算法，它将足够高密度的区域划分为簇，能够在含有“噪声”的空间数据库中发现任意形状的簇。

- 定义5.1 点p的 ε-邻域记为 Nε(p)，定义如下：
- Nε(p) = {q∈D | dist(p, q) ≤ ε}

- 定义5.2 若 |Nε(q)| ≥ MinPts，则 q为核心对象。

- 定义5.3 如果p, q满足下列条件：
- (1) p∈Nε(q)，
- (2) |Nε(q)| ≥ MinPts，则称点p是从点q关于 ε 和 MinPts 直接密度可达的。

- 定义5.4 如果存在一个点 o, p 和 q 都是从点 o 关于 ε 和 MinPts 密度可达的，则称点 p 从点 q 关于 ε 和 MinPts 密度相连的。
- 定义5.5 令 D 表示数据点的集合，若 D 的非空子集 C 满足下列条件：
  (1) 对任意 p 和 q，若 p∈C 且 q 是从 p 关于 ε 和 MinPts 密度可达的，则有 q∈C。（最大性）
  (2) ∀p, q∈C：p 与 q 是关于 ε 和 MinPts 密度相连的。（连通性）
  则称 C 是基于密度的簇。基于密度的簇是基于密度可达的最大的密度相连的点的集合。

- 定义5.6 如果存在一个点的序列 p₁, p₂, …, pₙ, p₁ = q, pₙ = p, pᵢ₊₁是从 pᵢ直接密度可达的，则称点p是从点q关于 ε 和 MinPts 密度可达的。

- 虽然DBSCAN算法可以对数据对象进行聚类，但需要由用户确定输入参数 ε 和 MinPts。在现实的高维数据集合中，很难准确确定聚类参数。由于这类算法对参数值非常敏感，参数值的微小变化往往会导致差异很大的聚类结果。现实的高维数据集合往往不是均匀分布的，因此，全局密度参数不能很好地刻画内在的聚类结构。
