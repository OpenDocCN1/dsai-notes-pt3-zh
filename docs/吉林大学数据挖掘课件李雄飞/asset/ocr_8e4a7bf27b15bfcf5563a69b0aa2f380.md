# 模糊集的度量(续)

设映射 N : F(U) x F(U) → [0, 1], 如果满足条件：

+   (1) N(A, A) = 1
+   (2) N(A, B) = N(B, A)
+   (3) 当, ∀x ∈ U | μ_A(x) - μ_C(x) | ≥ | μ_A(x) - μ_B(x) | 时, N(A, C) ≤ N(A, B)

则称 N 为 F(U) 上的贴近度。

例4.8 U = {x₁, x₂, …, xₙ} 时, 汉明贴近度为：

```
N_H(A, B) = 1 - (1/n) Σ_{i=1}^{n} | μ_A(x_i) - μ_B(x_i) |
```
