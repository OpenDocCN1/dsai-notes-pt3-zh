# Catalan数列的生成函数

当 n≥3，考虑一个凸 n + 1 边形，它的顶点分别用 A₁, A₂, …, Aₙ₊₁ 表示。取定多边形的一条边 A₁Aₙ₊₁，任取多边形的顶点 Aₖ₊₁(k=1,2,…,n−1)，将 Aₖ₊₁ 分别与 A₁, Aₙ₊₁ 之间连线，得三角形 T，三角形 T 将凸 n + 1 边形分成 T，R₁ 和 R₂ 三部分，其中，R₁ 为 k+1 边形，R₂ 为 n−k+1 边形。因此，R₁ 可以用 h(k) 种方法划分，R₂ 可以用 h(n−k) 种方法划分，所以

```
h(n) = Σ_{k=1}^{n-1} h(k) h(n−k). (5.5.1)
```

这正是 Catalan 数列的形式。
