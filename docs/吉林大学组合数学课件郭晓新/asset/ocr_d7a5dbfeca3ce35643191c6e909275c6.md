# 有禁区的排列问题

从而得到 $r_1 = n$, $r_2 = \binom{n}{2}$, …, $r_n = \binom{n}{n}$, 代入定理 4.5.1 得

$D_n = n! - n(n-1)! + \binom{n}{2}\cdot(n-2)! - \cdots + (-1)^n \binom{n}{n}\cdot 0!$

$= n!\left[1 - \frac{1}{1!} + \frac{1}{2!} - \cdots + (-1)^n \frac{1}{n!}\right]$

Ref: $n! - r_1 (n-1)! + r_2 (n-2)! - \cdots + (-1)^n \cdot n!$
