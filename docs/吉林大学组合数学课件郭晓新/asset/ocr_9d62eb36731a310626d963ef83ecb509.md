# 容斥原理

设 x 具有 n 条性质，n ≥ 1。则 x 对 |S| 的贡献为 1，对 ∑_{i=1}^m |A_i| 的贡献为 n = C(n,1)，对 ∑_{1≤i<j≤m} |A_i ∩ A_j| 的贡献为 C(n,2)，⋯，对 |A_1 ∩ A_2 ∩ ⋯ ∩ A_m| 的贡献为 C(n,m)。所以 x 对等式右边的总贡献是：

C(n,0) - C(n,1) + C(n,2) - ⋯ + (-1)^m C(n,m)  (n < m)

= C(n,0) - C(n,1) + C(n,2) - ⋯ + (-1)^n C(n,n) = (1-1)^n = 0
