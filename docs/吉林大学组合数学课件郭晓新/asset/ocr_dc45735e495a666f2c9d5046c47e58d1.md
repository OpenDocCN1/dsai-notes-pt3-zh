# 常系数线性齐次递推关系的求解

所以，该递推关系的解为

g(t) = 3/4 · 3^t − 3/4 · (−1)^t.

从而求得

f(t) = g(t−1) = 3/4 · 3^{t−1} − 3/4 · (−1)^{t−1},

f(t) + g(t) = 3/4 · 3^{t−1} − 3/4 · (−1)^{t−1} + 3/4 · 3^t − 3/4 · (−1)^t = 3^t.

因此

f(100) = 3/4 · 3^{99} − 3/4 · (−1)^{99} = 3/4 (3^{99} + 1),

g(100) = 3/4 · 3^{100} − 3/4 · (−1)^{100} = 3/4 (3^{100} − 1),

故 f(100) + g(100) = 3^{100}.
