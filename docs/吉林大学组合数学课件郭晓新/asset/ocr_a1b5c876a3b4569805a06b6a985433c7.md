# 常系数线性非齐次递推关系的求解

有些非线性的递推关系通过变换化为常系数线性的递推关系。

# 例 6.3.5 求解递推关系

```
⎧ f(n) = 3 f²(n-1),
⎨
⎩ f(0) = 1.
```

解 对递推关系两边取对数，得

```
lg f(n) = lg 3 + 2 lg f(n-1).
```

令 h(n) = lg f(n)，得

```
⎧ h(n) = 2 h(n-1) + lg 3,
⎨
⎩ h(0) = 0.
```
