# Möbius反演

定理 4.6.1. 对任意正整数 n，有

∑_{d|n} μ(d) = { 1, 当 n=1 时
0, 当 n>1 时 }

其中 ∑_{d|n} μ(d) 表示让 d 取遍 n 的所有正因子而对 μ(d) 求和，其中包括因子 1 和 n。

证明： 当 n=1 时，由定义知 μ(n)=1。

当 n>1 时，设 n 的标准质因数分解为 n = p₁^{a₁} p₂^{a₂} ... p_k^{a_k}，并令：

n* = p₁ p₂ ... p_k

若 d | n*，则 d | n；若 d | n，但 d ∤ n*，则 d 能被某个质数的平方整除，从而 μ(d)=0。
