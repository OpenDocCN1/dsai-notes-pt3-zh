# 生成函数

例 共有 1 克，2 克，3 克，4 克的砝码各一枚，问能称出哪几种重量，有几种可能方案？

```
(1 + x)(1 + x²)(1 + x³)(1 + x⁴)
= 1 + x + x² + 2x³ + 3x⁴ + 2x⁵ + 2x⁶ + 2x⁷ + x⁸ + x⁹ + x¹⁰
```

从右端的生成函数知，可称出 1 ，2 ，⋯，10 克，系数便是方案数。例如右端有

2x⁵项，即称出 5 克的方案有 2 ，即 5 = 3 + 2 = 1 + 4 ；

2x⁶项，即称出 6 克的方案有 2 ，即 6 = 1 + 2 + 3 = 4 + 2 ；

x¹⁰项，即称出 10 克的方案有 1 ，即 10 = 1 + 2 + 3 + 4 。
