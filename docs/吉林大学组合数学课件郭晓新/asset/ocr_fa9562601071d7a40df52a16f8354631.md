# 排列数的指数型生成函数

例 5.4.2 3 个红球，2 个黄球，3 个蓝球，每次从中取出 4 个排成一行，求排列方案数。

解 $m=3, r_1=3, r_2=2, r_3=3, k=4$ 由推论 5.4.2 知

$G_e(x)=\left(1+\frac{x}{1!}+\frac{x^2}{2!}+\frac{x^3}{3!}ight)\left(1+\frac{x}{1!}+\frac{x^2}{2!}ight)\left(1+\frac{x}{1!}+\frac{x^2}{2!}+\frac{x^3}{3!}ight)$

$=1+3x+\frac{9}{2}x^2+\frac{14}{3}x^3+\frac{35}{12}x^4+\frac{17}{12}x^5+\frac{35}{72}x^6+\frac{5}{72}x^7+\frac{1}{72}x^8$

$=1+3\cdot\frac{x}{1!}+9\cdot\frac{x^2}{2!}+28\cdot\frac{x^3}{3!}+70\cdot\frac{x^4}{4!}+170\cdot\frac{x^5}{5!}+350\cdot\frac{x^6}{6!}$

$+350\cdot\frac{x^7}{7!}+560\cdot\frac{x^8}{8!}$

故知，从所给 $n$ 色球取出 4 个的排列方案有 70 种。
