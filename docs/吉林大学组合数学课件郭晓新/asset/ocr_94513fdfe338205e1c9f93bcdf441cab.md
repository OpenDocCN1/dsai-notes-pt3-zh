# 二项式定理及性质

若 n 为奇数，于是

（ i ） 若 k = (n + 1)/2 ， 则 n - k + 1 = n - (n + 1)/2 + 1 = (n + 1)/2 = k ，所以

      C(n, (n + 1)/2) = C(n, (n - 1)/2)；

（ ii ） 若 k > (n + 1)/2 ， 则 n - k + 1 < n - (n + 1)/2 + 1 = (n + 1)/2 < k ，所以

      C(n, k) < C(n, k - 1) 。

（ iii ） 若 k ≤ (n - 1)/2 ， 则 n - k + 1 ≥ n - (n - 1)/2 + 1 = (n + 1)/2 < k ，所以

      C(n, k) > C(n, k - 1) 。

综合以上分析，性质（ 3 ）成立。
