# 递推关系

2) 对递推关系两边取对数，得 2 lg aₙ = lg 2 + lg aₙ₋₁

令 f(n) = lg aₙ，代入原递推关系得 { 2f(n) = lg 2 + f(n-1) ; f(0) = lg a₀ = 2 lg 2. }

相应的特征方程为 2x - 1 = 0

解这个方程，得 x = 1/2.

故齐次解为 f(n) = c (1/2)ⁿ.

此问题属于 g(n) = α βⁿ，其中 β = 1。因为 1 不是特征方程的根，所以该递推关系的非齐次特解设为 b，代入原递推关系，得 2b = lg 2 + b

所以特解为 b = lg 2，根据前面的分析，可知该递推关系的通解为 f(n) = c (1/2)ⁿ + lg 2.
