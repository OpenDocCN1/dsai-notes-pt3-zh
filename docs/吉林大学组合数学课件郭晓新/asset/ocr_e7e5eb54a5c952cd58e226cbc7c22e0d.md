# Möbius函数

根据数论的知识，对于大于 1 的自然数 n，有标准的分解形式，即

n = p₁^{α₁} p₂^{α₂} ⋯ p_k^{α_k}, (4.6.1)

其中 p₁,p₂,…,p_k 为 k 个互不相同的质数。依此为基础，有下面的定义。

# 定义 4.6.1 Möbius 函数 μ(n) 定义为

μ(n) = { 1, 当 n=1 时
0, 若式 (4.6.1) 中存在 α_i > 1
(-1)^k, 若式 (4.6.1) 中 α₁ = α₂ = ⋯ = α_k = 1 }

例如，

μ(2) = (-1)¹ = -1, μ(9) = μ(3²) = 0, μ(10) = μ(2×5) = (-1)² = 1.
