# 常系数线性非齐次递推关系的求解

# 例 6.3.1 求解递推关系

f(n) = 2 f(n-1) + 4^{n-1},
 f(0) = 1.

解 因为 4 不是特征方程的根，所以该递推关系的非齐次特解为 a 4^{n-1}，将其代入递推关系，得

4^{n-1} a = 2·4^{n-2} a + 4^{n-1}

比较等式两边 4^{n-1} 的系数，得

a = \frac{1}{2} a + 1

从而

a = 2.
