# 多项式定理

证明 先将 $(x_1 + x_2 + \cdots + x_t)^n$ 写成 $n$ 个 $x_1 + x_2 + \cdots + x_t$ 因子的乘积： $(x_1 + x_2 + \cdots + x_t)^n = (x_1 + x_2 + \cdots + x_t) \cdots (x_1 + x_2 + \cdots + x_t)$。

现在我们将其展开，直到没有括号为止。因为每个因子中我们都可取 $x_1, x_2, \cdots, x_t$ 中的任一个，所以展开式共有 $t^n$ 项，且每项都可以写成 $x_1^{n_1} x_2^{n_2} \cdots x_t^{n_t}$ 的形式。要得到这一项，我们应该在 $n$ 个因子中的 $n_1$ 个里面取 $x_1$，有 $inom{n}{n_1}$ 种取法；在剩下的 $n - n_1$ 个因子中的 $n_2$ 个里面取 $x_2$，有 $inom{n - n_1}{n_2}$ 种取法；……；最后，在 $n_t = n - (n_1 + n_2 + \cdots + n_{t-1})$ 个因子里面取 $x_t$，有 $inom{n - (n_1 + n_2 + \cdots + n_{t-1})}{n_t}$ 种取法。由乘法原则知，$x_1^{n_1} x_2^{n_2} \cdots x_t^{n_t}$ 前的系数为 $inom{n}{n_1} inom{n - n_1}{n_2} \cdots inom{n - (n_1 + n_2 + \cdots + n_{t-1})}{n_t} = \frac{n!}{n_1! n_2! \cdots n_t!}$。
