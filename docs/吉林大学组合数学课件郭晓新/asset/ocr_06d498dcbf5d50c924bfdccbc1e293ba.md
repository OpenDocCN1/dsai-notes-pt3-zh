# Pólya定理

Q = {q₁, q₂, q₃, q₄} 是针对 S 的置换集（绕大的正方形中心逆时针旋转）：

Q: { q₁ = (1)(2)(3)(4), 旋转0°
q₂ = (1 2 3 4), 旋转90°
q₃ = (1 3)(2 4), 旋转180°
q₄ = (4 3 2 1), 旋转270° }

而且 λ{qᵢ} 1 ≤ i ≤ 4 如下：

λ(q₁) = 4    λ(q₂) = 1    λ(q₃) = 2    λ(q₄) = 1

所求不等价的方案数为

L = 1/4 (2⁴ + 2¹ + 2¹ + 2²) = 1/4 (16 + 2 + 2 + 4) = 6。
