定理 4.6.2 Möbius 反演公式：设 f(n)、g(n)是自然数集上的两个函数，则

f(n)=∑_{d|n} g(d) ⇔ g(n)=∑_{d|n} μ(d) f(n/d) (4.6.3)

证明：先证必要性.若式（4.6.3）左端的等式对自然数 n 成立，那么它对自然数 n/d 也应该成立，即将式 f(n)=∑_{d|n} g(d) 中的 n 换成 n/d，有

f(n/d)=∑_{d₁|n/d} g(d₁)，从而有

=∑_{d₁|n} ∑_{d|n/d₁} μ(d) g(d₁)=∑_{d₁|n} g(d₁) (∑_{d|n/d₁} μ(d))
