# 构造性问题

+   例1.6 构造3阶幻方

解：3阶幻方幻和=15

∵ (a₁ + a₅ + a₉) + (a₄ + a₅ + a₆) + (a₇ + a₅ + a₃) + (a₈ + a₅ + a₂) = 4×15

且 ∵ a₁ + a₂ + a₃ + a₄ + a₅ + a₆ + a₇ + a₈ + a₉ = 3×15

∴ 3a₅ = 15 ⇒ a₅ = 5

∴ a₁ + a₉ = a₂ + a₈ = a₃ + a₇ = a₄ + a₆ = 10

又 ∵ (a₁ + a₂ + a₃) + (a₁ + a₄ + a₇) = 30

∴ 2a₁ + a₂ + a₄ = 30 − (a₃ + a₇) = 20
