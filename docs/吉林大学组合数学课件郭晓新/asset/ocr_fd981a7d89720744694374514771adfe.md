# 用迭代归纳法求解递推关系及其应用

有否找到 $f(n)$ 的一个简单表达式呢？为此，考察该数列的前 5 项，得

$f(0) = 0 = 0^2$
$f(1) = 1^3 = 1 = 1^2$
$f(2) = 1^3 + 2^3 = 9 = 3^3 = (1 + 2)^2$
$f(3) = 1^3 + 2^3 + 3^3 = 36 = 6^3 = (1 + 2 + 3)^2$
$f(4) = 1^3 + 2^3 + 3^3 + 4^3 = 100 = 10^2 = (1 + 2 + 3 + 4)^2$

由此，我们得出 $f(n)$ 的前 5 项满足

$f(n) = (0 + 1 + \cdots + n)^2 = \frac{n^2 (n+1)^2}{4}.$
