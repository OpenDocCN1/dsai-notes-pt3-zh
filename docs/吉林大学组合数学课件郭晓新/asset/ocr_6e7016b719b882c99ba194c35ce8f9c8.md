# 用迭代归纳法求解递推关系及其应用

根据以上的分析可以得到递推关系

\begin{cases} h(n) = (4n-6)h(n-1), & n \ge 2, \\ h(1) = 1. \end{cases}

这不是常系数线性递推关系，用迭代和归纳法求解。

h(n) = (4n-6)h(n-1) 
= (4n-6)[4(n-1)-6]h(n-2) 
= (4n-6)(4n-10)(4n-14)h(n-3) 
= (4n-6)(4n-10)(4n-14)···6·2·h(1) 
= 2^{n-1}[(2n-3)(2n-5)···3·1] 
= 2^{n-1} \frac{(2n-2)!}{(2n-2)(2n-4)···4·2} 
= \frac{(2n-2)!}{(n-1)!} = (n-1)! \binom{2n-2}{n-1}, \quad n \ge 2
