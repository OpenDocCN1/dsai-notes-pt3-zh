# 常系数线性非齐次递推关系的求解

可知该递推关系的通解为

$$g(n)=2^n c-1.$$

代入初值 $g(0)=4$，得 $c=5$。所以

解这个递推关系得

$$g(n)=5\cdot 2^n-1,$$

从而得到

$$h(n)=\sqrt{5\cdot 2^n-1}\quad(\because h(n)>0).$$
