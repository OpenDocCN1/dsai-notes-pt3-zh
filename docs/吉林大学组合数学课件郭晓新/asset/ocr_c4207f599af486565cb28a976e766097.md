# 组合的生成

（一）求 S = { x_{n-1}, ..., x_1, x_0 } 的所有组合。
S 的每个组合是它的一个子集，根据定理 一个子集的确定是对每个元素的两种可能性的选择，即选定为 1，否则为 0。以三个元素的集合 { a_2, a_1, a_0 } 为例，看一下每个子集的确定。

|  | a_2 | a_1 | a_0 |
|---|---|---|---|
| Φ | 0 | 0 | 0 |
| { x_0 } | 0 | 0 | 1 |
| { x_1 } | 0 | 1 | 0 |
| { x_1, x_0 } | 0 | 1 | 1 |
| { x_2 } | 1 | 0 | 0 |
| { x_2, x_0 } | 1 | 0 | 1 |
| { x_2, x_1 } | 1 | 1 | 0 |
| { x_2, x_1, x_0 } | 1 | 1 | 1 |

每个组合对应一个二进制数
