# 组合恒等式

3. $\sum_{i=0}^{n} \binom{n}{i}^2 = \binom{2n}{n}$. （3.4.13）

证明 $\binom{2n}{n}$ 是 $2n$ 元集合 $A$ 的 $n$ 组合数, 把集合 $A$ 分成两个集合 $A_1$ 和 $A_2$, 使 $|A_1| = |A_2| = n$, 则 $A$ 的 $n$ 元子集可以分成如下 $n+1$ 类: 从 $A_1$ 中选取 $i$ ($0 \leqslant i \leqslant n$) 个元素, 从 $A_2$ 中选取 $n-i$ 个元素, 将 $A_1$ 的 $i$ 个元素与 $A_2$ 的 $n-i$ 个元素并到一起构成 $A$ 的第 $i$ 类 $n$ 元子集.
