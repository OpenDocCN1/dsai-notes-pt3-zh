# 排列数的指数型生成函数

M = {∞·a₁, ∞·a₂, …, ∞·aₙ} 中每个 aᵢ (1 ≤ i ≤ n) 至少出现一次的 k 排列 a₁ aᵢ₁ … aᵢₖ

可以看成是把 k 个不同的球 1, 2, …, k 放入 n 个不的盒子 a₁, a₂, …, aₙ, 并且每盒非空的一种放法, 即球 j 放入盒子 aᵢⱼ 中 (1 ≤ j ≤ k), 在第 2 章 2.7 节中可知共有

Aₖ = n! S(k, n) = Σᵢ₌₀ⁿ (-1)ⁱ C(n, i) (n - i)ᵏ.  (k ≥ n)

种放法，由此得出 k 元集合的 n 分划数的显式表达式

S(k, n) = 1/n! Σᵢ₌₀ⁿ (-1)ⁱ C(n, i) (n - i)ᵏ.
