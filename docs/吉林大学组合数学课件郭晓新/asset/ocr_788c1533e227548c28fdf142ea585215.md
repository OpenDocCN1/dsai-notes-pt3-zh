# 多项式定理

例 3.4.3 证明下面的等式成立：

$$inom{n}{r_1 r_2 \cdots r_i} = inom{n-1}{r_1-1\ r_2 \cdots r_k} + inom{n-1}{r_1 r_2-1 \cdots r_k} + \cdots + inom{n-1}{r_1 r_2 \cdots r_k-1}.$$

证明 左边是把 $n$ 个不同的球放到 $k$ 个不同的盒子里且使得第一个盒子有 $r_1$ 个球，第二個盒子有 $r_2$ 個球，…，第 $k$ 個盒子有 $r_k$ 個球的方法數，任取一個球 $a_1$，然後把它放盒子球的方法進行分類：

$a_1$ 放到第一个盒子的放法数是 $inom{n-1}{r_1-1\ r_2\ \cdots\ r_k}$；

$a_1$ 放到第二个盒子的放法数是 $inom{n-1}{r_1\ r_2-1\ \cdots\ r_k}$；

$a_1$ 放到第 $k$ 个盒子的放法数是 $inom{n-1}{r_1\ r_2\ \cdots\ r_k}$。由加法法则等式得证。
