# # 错位排列

```
$$\left\{ \begin{array}{l} D_n = (n-1)(D_{n-1} + D_{n-2}) \quad n \geq 3, n\text{为整数,} \\ D_1 = 0, D_2 = 1 \end{array} \right.$$ (4.3.1)
```

D_1和D_2是初值，由 (4.3.1) 式可以计算出任何一个 D_n 的值。

证明：设 n≥3，考虑排列 12⋯n 的所有的错位排列。根据在排列中的第一位的数字是2，3，⋯，n 而将这些排列划分成 n-1 类。

+   2i_2i_3⋯i_n ← 先考虑这种情况
+   3i_2i_3⋯i_n
+   :
+   ni_2i_3⋯i_n
