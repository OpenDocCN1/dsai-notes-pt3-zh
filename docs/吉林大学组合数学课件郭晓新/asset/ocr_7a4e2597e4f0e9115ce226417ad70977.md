# 二项式定理及性质

当 $n，r$ 均为非负整数，且 $n\ge r$ 时，$\binom{n}{r}$ 有一些最基本的性质：

+   （1）对称关系
+   
+   $$\binom{n}{r}=\binom{n}{n-r}；$$

+   （2）递推关系
+   
+   $$\binom{n}{r}=\binom{n-1}{r}+\binom{n-1}{r-1}\quad(n\ge r\ge1)；$$

+   （3）单峰性
+   
+   当 $n$ 为偶数时，有
+   
+   $$\binom{n}{0}<\binom{n}{1}<\cdots<\binom{n}{\frac n2}>\cdots>\binom{n}{n-1}>\binom{n}{n}；$$
+   
+   当 $n$ 为奇数时，有
+   
+   $$\binom{n}{0}<\binom{n}{1}<\cdots<\binom{n}{\frac{n-1}{2}}=\binom{n}{\frac{n+1}{2}}>\cdots>\binom{n}{n-1}>\binom{n}{n}。$$
