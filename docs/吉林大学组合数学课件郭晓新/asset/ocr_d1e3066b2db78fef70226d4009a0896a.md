# 有禁区的排列问题

例 4.5.3 错位排列问题也可以看作是有禁区的排列问题,其禁区在主对角线上。下面使用定理 4.5.1 来求 $D_n$。

解  禁区的棋盘多项式是

```
R\begin{pmatrix} \square \square \ \ \ \ \square \square \end{pmatrix}= \overbrace{R(\square)\cdot R(\square)\cdots R(\square)}^{n\uparrow}

= (1+x)^n = 1+\binom{n}{1}x+\binom{n}{2}x^2+\cdots+\binom{n}{n}x^n
```
