# 组合数的生成函数

问题（2）：求{∞·a₁,∞·a₂,…,∞·aₙ}的k组合数。

令 M = {∞·a₁,∞·a₂,…,∞·aₙ} 的 k 组合数为 bₖ，序列 {bₖ} 的生成函数是 n 个形式幂级数的乘积：

(1+x+x²+⋯)(1+x+x²+⋯)⋯(1+x+x²+⋯)
=(1+x+x²+⋯)ⁿ = 1/(1−x)ⁿ

G{ C(n−1+k, k) } = 1/(1−x)ⁿ

从而中 xᵏ 的系数就是 M 的 k 组合数 bₖ，因此为 bₖ = C(n−1+k, k)。

用生成函数获得了多重集合 M 的 k 组合数的公式。

定理 3.2.4 多重集合 M = {∞·a₁,∞·a₂,…,∞·aₙ} 的 r 组合数为 C(n+r−1, r) (pp. 21)
