# 组合恒等式

4. \(\displaystyle \sum_{i=0}^{r}\binom{m}{i}\binom{n}{r-i}=\binom{m+n}{r}.\) （3.4.14）

**证明** 此恒等式称为 Vandermonde 恒等式。

方法一 由二项式定理有

\[(1+x)^m=\sum_{k=0}^{m}\binom{m}{k}x^k,\qquad (1+x)^n=\sum_{l=0}^{n}\binom{n}{l}x^l,\]

\[(1+x)^{m+n}=(1+x)^m(1+x)^n=\left[\sum_{k=0}^{m}\binom{m}{k}x^k\right]\left[\sum_{l=0}^{n}\binom{n}{l}x^l\right]\]
