# # 常系数线性非齐次递推关系的求解

对于一般f(n)没有普遍的解法，只对一些简单的情况可以用待定系数法求H*(n)。



```
H(n)+5H(n-1)+6H(n-2)=3n²
```

的特解。

解: 设特解H*(n)=P₁n²+P₂n+P₃，其中P₁,P₂,P₃为待定系数，把H*(n)代入原递推关系得：

```
(P₁n²+ P₂n+P₃)
+5[P₁(n-1)² + P₂(n-1)+P₃]
+6[P₁(n-2)² + P₂(n-2)+P₃]=3n²
```

化简左边得：

```
12 P₁n²+(-34P₁+12P₂)n+(29P₁-17P₂+12 P₃)=3n²
```
