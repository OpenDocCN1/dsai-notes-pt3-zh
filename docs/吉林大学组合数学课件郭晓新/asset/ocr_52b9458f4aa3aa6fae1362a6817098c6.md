# 排列数的指数型生成函数

推论 5.4.1 设 S = {∞·e₁, ∞·e₂, …, ∞·eₘ}，若元素 eᵢ (i = 1,2,…,m) 重复出现的次数构成集合 Γᵢ，则集 S 中元素的这种 k 可重排列数 Pₖ 对应序列 {Pₖ} 的生成函数为

```
G(x) = ∏_{i=1}^{m} Σ_{j∈Γᵢ} x^{j} / j!
```

k 可重排列数 Pₖ 为 G(x) 展开式中 xᵏ / k! 的系数。

G(x) = Σₖ Pₖ xᵏ / k! = Σ_{i=1}^{∞} (x^{αᵢ} / αᵢ!) Σ_{i=1}^{∞} (x^{βᵢ} / βᵢ!) … Σ_{i=1}^{∞} (x^{λᵢ} / λᵢ!)

Γ₁ = {α₁, α₂, …}, Γ₂ = {β₁, β₂, …}, … Γₘ = {λ₁, λ₂, …}
