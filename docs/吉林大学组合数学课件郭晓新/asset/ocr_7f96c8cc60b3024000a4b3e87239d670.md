# 生成函数的性质

性质 4 若 $b_k = \sum_{i=k}^{\infty} a_i$，则 $B(x)=\frac{A(1)-xA(x)}{1-x}$。这里，$\sum_{i=0}^{\infty} a_i$ 是收敛的。

证明 因为 $A(1)=\sum_{k=0}^{\infty} a_k$ 收敛，所以 $b_k = \sum_{i=k}^{\infty} a_i$ 是存在的，于是有

$b_0 = a_0 + a_1 + a_2 + \cdots = A(1),$\n$b_1 x = a_1 x + a_2 x + \cdots = [A(1)-a_0]x,$\n$b_2 x^2 = a_2 x^2 + a_3 x^2 + \cdots = [A(1)-a_0 - a_1]x^2,$\n$\cdots,$\n$b_k x^k = a_k x^k + a_{k+1} x^k + \cdots = [A(1)-a_0 - a_1 - \cdots - a_{k-1}]x^k,$\n$\cdots.$

性质 3 若 $b_k = \sum_{i=0}^{k} a_i$，则 $B(x)=\frac{A(x)}{1-x}$。
