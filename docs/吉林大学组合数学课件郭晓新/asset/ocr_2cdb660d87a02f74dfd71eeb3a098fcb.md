# 有限制条件的排列问题

例 4.4.2 有八个小孩做在旋转木马上，如果让他们交换座位，使得每一个小孩的前边都不是原来在他前边的小孩，问有多少种方法？

解 这是一个有条件限制的环排列问题。

P_j：有 j(j+1) 出现的环排列中（j = 1, 2, …, n−1）。

P_n：有 n1 出现的环排列中。

A_j：具有性质 P_j 的环排列的集合。则

Q_n = |Ā₁ ∩ Ā₂ ∩ … ∩ Ā_n|

X 的环排列 |S| = (n−1)!，

再计算 |A_j|。A_j 中的环排列就是 {1,2,…,j(j+1)…,n} 的一个环排列，因此 |A_j| = (n−2)!。
