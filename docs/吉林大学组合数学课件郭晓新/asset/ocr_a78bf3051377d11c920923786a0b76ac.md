# 生成函数的性质

性质 7 若 $c_k = \alpha a_k + \beta b_k$，则 $C(x) \equiv \sum_{k=0}^{\infty} c_k x^k = \alpha A(x) + \beta B(x)$。
形式幂级数的数乘

性质 8 若 $c_k = a_0 b_k + a_1 b_{k-1} + \cdots + a_k b_0$，则 $C(x) \equiv \sum_{k=0}^{\infty} c_k x^k = A(x) \cdot B(x)$。
形式幂级数的加法
形式幂级数的乘法

性质 9 若 $b_n = \alpha^n a_n$，$\alpha$ 为常数，则 $B(x) = A(\alpha x)$。

性质 7 和性质 8 可以形式幂级数的数乘、加法及乘法运算的定义直接得出。形式幂级数在加法和乘法运算下构成一个环。
