# 递推关系的建立

解 设 “010” 子串在第 n 位出现的长为 n 的 0,1 字符串的个数为 f(n)，则显然 f(3)=1， f(4)=2， f(5)=3。

最后 3 位是 “010” 的 n 位 0,1 字符串有 2^{n-3} 个，其中 “010” 在第 n 位出现的字符串有 f(n) 个。“010” 不在第 n 位出现，当且仅当最后 5 位形如 “01010”，并且 “010” 在第 n−2 位出现，所以这类字符串共有 f(n−2) 个。从而有

```
⎧ f(n) = 2^{n-3} − f(n−2) (n ≥ 5),
⎨
⎩ f(3) = 1, f(4) = 2.
```
