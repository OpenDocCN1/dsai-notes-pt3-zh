# 安排的存在性（存在性问题）

+   - 一个**n**阶幻方中的所有整数的和为 1+2+3+…+n² = \(\frac{n^2(n^2+1)}{2}\)

由于一个**n**阶幻方共有**n**行，每一行都有一个幻和**s**，因此我们得到关系。

\(ns = n^2(n^2+1)/2\)

于是，任意两个**n**阶幻方都有相同的幻和，即

\(s = n(n^2+1)/2\)

不难验证，不可能存在2阶幻方（其幻和应该是5）。但是，对于所有其他的**n**，**n**阶幻方能够构造出来。存在着许多构造幻方的特殊方法。
