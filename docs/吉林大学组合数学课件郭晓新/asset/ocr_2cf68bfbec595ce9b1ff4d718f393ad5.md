# 研究的内容

+   - **安排的存在性（存在性问题）**
+     如果想把离散对象按照它们所应满足的条件来进行安排，当符合要求的安排并非显然存在或显然不存在时，首要的问题就是要证明或否定它的存在。
+   - **安排的枚举、分类和计数（计数问题）**
+     如果所要求的安排存在，则可能有多种不同的安排。此时，就就可以计数不同的方案数，并将它们进行枚举和分类。
+   - **构造性问题**
+     研究怎样构造出所需要的安排方法。
+   - **优化问题**
+     此类问题是在一定条件下找出一个（或几个）最优或近乎最优的安排方案。

如果安排的原则带有技巧性或比较复杂，那么存在性问题就成为主要问题，而在实际应用中更多的是计数问题和优化问题。
