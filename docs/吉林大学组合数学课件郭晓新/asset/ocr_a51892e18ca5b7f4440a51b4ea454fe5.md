首先，对于满足限定条件的每个 k 可重排列，设其中元素 e1 出现 α_i 次，元素 e2 可重复 β_i 次，元素 e_m 可重复 λ_i_m 次(i=1, 2, ...), 则 (α_i, β_i, ..., λ_i_m) 就是方程 α_i + β_i + ⋯ + λ_i_m = k (i=1,2,⋯,n) 的一个解。
