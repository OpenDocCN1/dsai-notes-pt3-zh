# 生成函数在计数问题中的应用

习题5.3 由a, b, c, d, e组成的长为n的字中，要求a与b 的个数之和为偶数, 问这样的字有多少个?

解 分两种情况：

+   (1) a与b的个数都为奇数；

+   (2) a与b的个数都为偶数；

则对第一种情况有

M_a = M_b = {1,3,5,…}, M_c = M_d = M_e = {0,1,2,3,…}

该排列的指数型生成函数为

⎛ x   x³   ⎞² ⎛      x    x²      ⎞³
⎜── + ── + …⎟ ⎜1 + ── + ── + …⎟ = 1/4 (e(x) − e(−x))² e(3x)
⎝1!   3!   ⎠ ⎝      1!   2!      ⎠

= 1/4 (e(5x) + e(x) − 2e(3x))
