归纳从一个组合 c_1 c_2 ⋯ c_r 得到下一个组合的步骤如下：

+   ① 求满足不等式 c_i < n - r + i 的最大的下标 i，即 i = max{ j | c_j < n - r + j }

+   ② c_i ← c_i + 1

+   ③ 从 i + 1 位开始作修改：c_i ← c_{j-1} + 1; j = i + 1, i + 2, ⋯ r。
