# 生成函数的性质

性质 1 若

b_k = { 0      (k < r) 
       a_{k-r}  (k ≥ r) }

则

B(x) = x^r · A(x).

证明 由假设条件，有

B(x) = Σ_{k=0}^{∞} b_k x^k = b_0 + b_1 x^1 + b_2 x^2 + ⋯ + b_{r-1} x^{r-1} + b_r x^r + b_{r+1} x^{r+1} + ⋯

= Σ_{k=r}^{∞} b_k x^k = 0 + 0 + ⋯ 0 + b_r x^r + b_{r+1} x^{r+1} + ⋯

= Σ_{k=r}^{∞} a_{k-r} x^k = a_0 x^r + a_1 x^{r+1} + ⋯

= x^r · A(x).
