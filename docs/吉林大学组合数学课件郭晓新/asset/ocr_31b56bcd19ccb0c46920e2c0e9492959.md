# 二项式定理及性质



> (x + y)^n = y^n + \left(\begin{array}{c} n \ 1 \end{array}\right)xy^{n-1} + \left(\begin{array}{c} n \ 2 \end{array}\right)x^2 y^{n-2} + \cdots

> + \left(\begin{array}{c} n \ n-1 \end{array}\right)x^{n-1} y + x^n

(3.4.3)

> = \sum_{r=0}^n \left(\begin{array}{c} n \ r \end{array}\right) x^r y^{n-r}.
