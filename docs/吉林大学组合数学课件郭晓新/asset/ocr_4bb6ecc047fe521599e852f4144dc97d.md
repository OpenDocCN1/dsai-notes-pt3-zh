# Möbius 反演

所以，问题化简为

∑_{d|n} μ(d)
= ∑_{d|n*} μ(d)

> 对于 n = p₁^{α₁} p₂^{α₂} ⋯ pₖ^{αₖ}，Möbius函数为
> μ(n) = { 1, 当n=1时 
> 0, 若式(4.6.1)中存在αᵢ>1 
> (-1)ᵏ, 若式(4.6.1)中 α₁=α₂=⋯=αₖ=1 }

= μ(1) + ∑_{i=1}^k μ(p_i) + ∑_{1≤i<j≤k} μ(p_i p_j) + ⋯ + μ(p₁ p₂ ⋯ pₖ)

= 1 + Cₖ¹ (-1) + Cₖ² (-1)² + ⋯ + Cₖᵏ (-1)ᵏ

= (1-1)ᵏ = 0
