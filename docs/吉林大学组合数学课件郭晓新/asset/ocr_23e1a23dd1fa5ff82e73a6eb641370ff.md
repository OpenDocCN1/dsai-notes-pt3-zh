# 有限制条件的排列问题

再计算|A_i ∩ A_j|，属于|A_i ∩ A_j|的环排列或者是

{1,2,...,i-1,i(i+1)(i+2),i+3,...,n} ←(n-2)项

的环排列，或者是

{1,2,...,i-1,i(i+1),i+2,...,j-1,j(j+1),j+2,...,n} ←(n-2)项

的环排列，所以有|A_i ∩ A_j|=(n-3)!。

同理可得，对于任意的1≤k≤n有

|A_{i1} ∩ A_{i2} ∩⋯∩ A_{ik}| = (n - k - 1)!  (1 ≤ k ≤ n - 1)

|A_1 ∩ A_2 ∩⋯∩ A_n| = 1

应用容斥原理得

|Ā_1 ∩ Ā_2 ∩⋯∩ Ā_n| = (n-1)! - C(n,1)(n-2)! + ⋯ + (-1)^n C(n,n)·1
