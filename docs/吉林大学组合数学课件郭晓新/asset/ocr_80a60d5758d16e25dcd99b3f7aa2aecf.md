# 常系数线性齐次递推关系的求解

例 6.2.5 求解递推关系

f(n) = -f(n-1) + 3 f(n-2) + 5 f(n-3) + 2 f(n-4)
f(0) = 1, f(1) = 0, f(2) = 1, f(3) = 2.

解 该递推关系的特征方程为

x⁴ + x³ - 3x² - 5x - 2 = 0,

其特征根为

x₁ = x₂ = x₃ = -1, x₄ = 2.

由定理 6.2.2，对应于 x = -1 的解为

f₁(n) = c₁(-1)ⁿ + c₂ n (-1)ⁿ + c₃ n² (-1)ⁿ,

对应于 x = 2 的解为

f₂(n) = c₄ 2ⁿ.
