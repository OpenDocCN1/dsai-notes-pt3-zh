# 相异元素不允许重复的排列数和组合数

从n个相异元素中不重复地取r个元素(r ≤ n)的排列数和组合数在中学已经学过，它们分别为：

P_n^r = P(n,r) = n(n-1)⋯(n-r+1) = n! / (n-r)!

C(n,r) = (n choose r) = P(n,r)/r! = n! / [r!(n-r)!]

显然，

+   （1）当 r > n 时，P(n,r)=0，C(n,r)=0。

+   （2）当 r = 1 时，P(n,1)=n      (n ≥ 1)

+   （3）C(n,0)=C(n,n)=1

+   （4）若 0 ≤ r ≤ n，则 C(n,r)=C(n,n-r)
