# Möbius反演的应用

例 4.6.3 可重圆排列问题 $m$ 个相异元素的不重圆排列数为 $(m-1)!$

这 $m$ 个相异元素的可重圆排列数是多少，问题将复杂的多的，即从 $m$ 个相异元素中可重复地取 $n$ 个构成的圆排列的个数并不能简单地直接推广为 $m^n / n$。

例如，设集合 $A = \{a_1, a_2, \cdots, a_m\}$ 有 $m$ 个相异元素，当 $d \mid n$ 时，取 $d$ 个不同的元素 $a_1, a_2, \cdots, a_d$ 重复 $n/d$ 次构成的 $n$ 个元素的圆排列

⊙ $a_1 a_2 \cdots a_d \, a_1 a_2 \cdots a_d \, \cdots \, a_1 a_2 \cdots a_d$ 
$\frac{n}{d}$ 组

只能形成 $d$ 个不同的线排列(⊙为上述 $n$ 个元素首尾相接形成一个圆排列)。
