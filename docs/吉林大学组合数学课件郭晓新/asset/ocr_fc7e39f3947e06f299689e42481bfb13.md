# 常系数线性非齐次递推关系的求解

# 例 6.3.4 求 Hanoi 塔问题满足的递推关系

```
f(n) = 2 f(n-1) + 1,
 f(0) = 0.
```

解 相应的特征方程为 x=2，故齐次解为 2^n。设非齐次特解为 b，代入原递推关系，得

```
b - 2b = 1
```

所以特解为 b = -1，根据前面的分析，可知该递推关系的通解为

```
f(n) = 2^n c - 1
```

代入初值 f(0) = 0, 得 c = 1. 所以

```
f(n) = 2^n - 1
```
