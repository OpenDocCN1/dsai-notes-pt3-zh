# 常系数线性非齐次递推关系的求解

例 6.3.3 求解递推关系 f(n) - f(n-1) = 7n 的特解。

解 由于 1 是特征方程的一重根，所以该递推关系的特解为

f''(n) = b₁n² + b₂n

代入递推关系得

(b₁n² + b₂n) - [b₁(n-1)² + b₂(n-1)] = 7n

化简上式得

2b₁n + b₂ - b₁ = 7n

建立方程组 { 2b₁ = 7 ; b₂ = b₁ }

解得 b₁ = b₂ = 7/2，因此所求得特解是

f''(n) = 7/2 n(n+1)
