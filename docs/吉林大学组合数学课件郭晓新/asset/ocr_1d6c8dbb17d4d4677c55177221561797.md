# 错位排列

Dₙ = n Dₙ₋₁ + (-1)ⁿ
D₁ = 0
(n≥2, n 为整数), (4.3.4)

做迭代就得到

Dₙ = n[(n-1)Dₙ₋₂ + (-1)ⁿ⁻¹] + (-1)ⁿ
= n(n-1)Dₙ₋₂ + n(-1)ⁿ⁻¹ + (-1)ⁿ
= n(n-1)[(n-2)Dₙ₋₃ + (-1)ⁿ⁻²] + n(-1)ⁿ⁻¹ + (-1)ⁿ
= …
= n!·D₁ / 1! + n!·(-1)² / 2! + n!·(-1)³ / 3! + … + n!·(-1)ⁿ⁻¹ / (n-1)! + n!(-1)ⁿ / (n-1)!
= n![(-1)² 1/2! + (-1)³ 1/3! + … + (-1)ⁿ 1/n!]
= n![1 - 1/1! + 1/2! - 1/3! + … + (-1)ⁿ 1/n!]

这个结果与定理 4.3.1 一致。
