# Catalan数列的生成函数

解 设 $G(x)=h_0+h_1x+h_2x^2+\cdots=\sum_{i=1}^{\infty}h_ix^i$，其中 $h_0=0$

$$G^2(x)=\sum_{i=1}^{\infty}h_ix^i\sum_{i=1}^{\infty}h_ix^i=\sum_{i=1}^{\infty}\sum_{j=1}^{\infty}(h_ih_j)x^{i+j}$$

$$=\sum_{n=2}^{\infty}\sum_{i=1}^{\infty}(h_ih_{n-i})x^n=\sum_{n=2}^{\infty}x^n\sum_{i=1}^{n-1}h_ih_{n-i}$$

$$=\sum_{n=2}^{\infty}h_nx^n=\sum_{n=1}^{\infty}h_nx^n-x=G(x)-x$$

> $$h(n)=\sum_{k=1}^{n-1}h(k)h(n-k).$$
