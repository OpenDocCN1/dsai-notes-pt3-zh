# 非降路径问题

2. \(\binom{m}{0}\binom{n}{r}+\binom{m}{1}\binom{n}{r-1}+\cdots+\binom{m}{r}\binom{n}{0}=\binom{m+n}{r}\tag{3.4.17}\)

在 **3.4.2** 节中已给出简单的证明，下面用非降路径来证明。\n证明  上式右边表示从\((0,0)\)点到\((m+n-r,r)\)点的非降路径数。任何一条这样的非降路径一定经过图 3.4.4 中斜线上的点，我们按所经过点的不同将路径分类。从\((0,0)\)点到\((m-k,k)\)点的非降路径是 \(\binom{m}{k}\) 条，从\((m-k,k)\)点到\((m+n-r,r)\)点的非降路径是 \(\binom{n}{r-k}\) 条，由乘法法则，可知从\((0,0)\)点经过\((m-k,k)\)点的非降路径是 \(\binom{m}{k}\binom{n}{r-k}\) 条，再对 \(k=0,1,\ldots,r\) 求和就得到所有的从\((0,0)\)点到\((m+n-r,r)\)点的非降路径数。所以等式成立。
