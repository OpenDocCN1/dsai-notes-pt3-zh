# 递推关系

解：1）令 $f(n)=n a_n$，代入原递推关系得 $egin{cases} f(n)+f(n-1)=2^n \ f(0)=0\cdot a_0=0\cdot 273=0. \end{cases}$

相应的特征方程为 $x+1=0$

解这个方程，得 $x=-1.$

故齐次解为 $f(n)=c(-1)^n.$

此问题属于 $g(n)=\alphaeta^n$，其中 $eta=2$。因为 $2$ 不是特征方程的根，所以该递推关系的非齐次特解
