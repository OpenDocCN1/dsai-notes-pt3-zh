# 组合数的生成函数

问题（3），求{3·a₁,4·a₂,5·aₙ}的10组合数。

将{3·a,4·b,…,5·c}的k组合数记为bₖ，{bₖ}的生成函数就是

(1+x+x²+x³)(1+x+x²+x³+x⁴)(1+x+x²+x³+x⁴+x⁵)

=(1−x⁴−x⁵−x⁶+x⁹+x¹⁰+x¹¹−x¹⁵)·∑ₙ₌₀^∞ C(n+2, n) xⁿ

所以，x¹⁰的系数b₁₀为

b₁₀ = C(10+2,10) − C(6+2,6) − C(5+2,5) − C(4+2,4) + C(1+2,1) + C(0+2,0) = 6

与第4章中用容斥原理得到的结果相同。

n=10

n=6

n=5

n=4

n=1

n=0
