# 容斥原理

推论 在 S 中至少具有一条性质的元素数是

|A₁ ∪ A₂ ∪ ⋯ ∪ Aₘ|
= Σᵢ₌₁ᵐ |Aᵢ| - Σ₁≤i<j≤m |Aᵢ ∩ Aⱼ| + Σ₁≤i<j<k≤m |Aᵢ ∩ Aⱼ ∩ Aₖ| ⋯
+ (-1)ᵐ⁺¹ |A₁ ∩ A₂ ∩ ⋯ ∩ Aₘ|

证明：根据 De Morgan 定律

|A₁ ∪ A₂ ∪ ⋯ ∪ Aₘ| = |S| - |\overline{A₁ ∪ A₂ ∪ ⋯ ∪ Aₘ}|
= |S| - |\overline{A₁} ∩ \overline{A₂} ∩ ⋯ ∩ \overline{Aₘ}|
= Σᵢ₌₁ᵐ |Aᵢ| - Σ₁≤i<j≤m |Aᵢ ∩ Aⱼ|
+ Σ₁≤i<j<k≤m |Aᵢ ∩ Aⱼ ∩ Aₖ| ⋯ + (-1)ᵐ⁺¹ |A₁ ∩ A₂ ∩ ⋯ ∩ Aₘ|
