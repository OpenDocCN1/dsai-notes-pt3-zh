# Möbius反演的应用

若用 $T_m(n)$ 表示从 m 元集合中构成长度为 $n$ 的所有 $n$ 可重圆排列的个数，那么

$T_m(n) = \sum_{d|n} M(d)$

可以证明

$T_m(n) = \sum_{d|n} \frac{m^d}{d} \sum_{d_1|\frac{n}{d}} \frac{\mu(d_1)}{d_1} = \frac{1}{n} \sum_{d|n} \varphi(d) m^{n/d}$

其中 $\varphi(d)$ 为 Euler 函数。

$M(n) = \frac{1}{n} \sum_{d|n} \mu(d) m^{n/d}$
