# 容斥原理小结

✓广义容斥原理

S 中恰具有 r(0≤r≤m)种性质的事物的个数为：

```
W(r) - \binom{r+1}{r}W(r+1) + \binom{r+2}{r}W(r+2) - ... + (-1)^{m-r}\binom{m}{r}W(m)
```

```
= \sum_{i=0}^{m-r} (-1)^i \binom{r+i}{r} W(r+i)
```

当 r=0 时公式变成

```
\sum_{i=0}^{m} (-1)^i \binom{i}{i} W(i) = \sum_{i=0}^{m} (-1)^i W(i)
```

这就是容斥原理(定理 4.1.1).
