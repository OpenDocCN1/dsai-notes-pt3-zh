# Möbius反演

对于 n = p₁^{α₁} p₂^{α₂} … p_k^{α_k}，Möbius函数为
μ(n) = { 1, 当 n=1 时
0, 若存在 α_i > 1
(-1)^k, 若 α₁ = α₂ = … = α_k = 1 }

若 n > 1, 设 n = p₁^{α₁} p₂^{α₂} … p_k^{α_k}, 并令 n* = p₁ p₂ … p_k, 则

n ∑_{d|n} μ(d)/d = n ∑_{d|n*} μ(d)/d + n ∑_{d|n*} μ(d)/d = n ∑_{d|n*} μ(d)/d + 0 = n ∑_{d|n*} μ(d)/d

= n ( μ(1) + ∑_{i=1}^k μ(p_i)/p_i + ∑_{1≤i<j≤k} μ(p_i p_j)/(p_i p_j) + … + μ(p₁ p₂ … p_k)/(p₁ p₂ … p_k) )

= n ( 1 + ∑_{i=1}^k (-1)/p_i + ∑_{1≤i<j≤k} (-1)^2/(p_i p_j) + … + (-1)^k/(p₁ p₂ … p_k) )

= n ( 1 - ∑_{i=1}^k 1/p_i + ∑_{1≤i<j≤k} 1/(p_i p_j) - … + (-1)^k 1/(p₁ p₂ … p_k) )

= n (1 - 1/p₁)(1 - 1/p₂)…(1 - 1/p_k)

= φ(n)
