# 常系数线性非齐次递推关系的求解

# 例 6.3.6 求解递推关系

$$egin{cases} h^{2}(n)-2h^{2}(n-1)=1, & h(n)>0, \ h(0)=2. \end{cases}$$

解 令 $g(n)=h^{2}(n)$，代入原递推关系得

$$egin{cases} g(n)-2g(n-1)=1 \ g(0)=h^{2}(0)=4. \end{cases}$$

设非齐次特解为 $b$，代入原递推关系，得

$$b-2b=1,$$

所以特解为 $b=-1$，
可知该递推关系的通解为

$$g(n)=2^{n}c-1.$$
