# 常系数线性非齐次递推关系的求解

$$\begin{cases}h(n)=2h(n-1)+\lg 3,\\h(0)=0.\end{cases}$$

设非齐次特解为 $b$，代入原递推关系，得

$$b-2b=\lg 3,$$

所以特解为 $b=-\lg 3$，根据前面的分析，可知该递推关系的特征根为 $x=2$，通解为

$$h(n)=2^n c-\lg 3.$$

代入初值 $h(0)=0$，得 $c=\lg 3$。

所以解得

$$h(n)=(2^n-1)\lg 3,$$

从而

$$f(n)=3^{2^n-1}.$$
