# 容斥原理

思考题：求 1 到 10000 之间的非完全平方，非完全立方更不是完全四次方数的个数。

解 因为一个完全四次方数也一定是一个完全平方数。所以这 9883 个数中，一定不含有完全四次方数。因而解题时不必考虑完全四次方数。

|Ā₂ ∩ Ā₃ ∩ Ā₄|

= |S| - (|A₂| + |A₃| + |A₄|) + (|A₂ ∩ A₃| + |A₂ ∩ A₄| + |A₃ ∩ A₄|) - |A₂ ∩ A₃ ∩ A₄|

= |S| - (|A₂| + |A₃| + |A₄|) + (|A₂ ∩ A₃| + |A₂ ∩ A₄| + |A₃ ∩ A₄|) - |A₂ ∩ A₃ ∩ A₄|

= |S| - (|A₂| + |A₃|) + |A₂ ∩ A₃|
