# 001：增量式路径规划 🚀

![](img/924d1e24aa2a570625843a6379f0277a_1.png)

在本节课中，我们将要学习增量式路径规划。这是一种高效的路径规划方法，特别适用于环境动态变化或机器人感知受限的场景。我们将从问题动机出发，介绍增量式搜索的核心思想，并深入讲解一个具体的算法——D* Lite。通过本教程，你将理解如何利用先前搜索的结果来加速新的搜索过程，从而实现快速且最优的重新规划。

***

## 问题动机 🤖

想象一个机器人生活在一个网格世界中。它从起点出发，目标是到达终点。机器人只能看到周围八个单元格的情况，并且它拥有一张预先定义好的世界地图。然而，在移动过程中，新的障碍物可能出现，旧的障碍物也可能消失。机器人需要根据移动过程中观察到的新信息，不断更新其到达目标的计划。

机器人首先根据初始地图规划一条从起点到终点的路径。当它移动到下一个位置时，可能会发现原计划路径上出现了新的障碍物。此时，它必须重新规划以找到一条新的有效路径。这个过程会不断重复，直到机器人成功抵达目标。

这种行为不仅适用于二维路径规划，也适用于多维机器人臂规划、与人协作的制造环境或活动规划。核心思想是让机器人能够考虑环境表示中的新障碍物或变化，并继续快速、最优地规划路径。

***

## 什么是增量式搜索？ 🔄

上一节我们介绍了动态环境中路径规划的需求，本节中我们来看看实现这一目标的关键技术：增量式搜索。

传统方法如快速探索随机树（RRT）虽然快速，但通常不能保证路径最优。而RRT*等优化版本虽然能找到最优路径，但需要大量的离线计算时间。我们的目标是实现快速计算、保证最优性，并且能让机器人在接收环境信息的同时持续移动。

增量式搜索的核心思想是**重用先前搜索的数据**，以加速新的搜索过程。它通过以下循环实现：
1.  执行计划中的下一个动作。
2.  通过传感器接收环境变化。
3.  利用这些信息更新先前的搜索结果，而不是完全重新规划。
4.  重复此循环，直到达到目标。

与完全重新规划相比，增量式搜索可以显著减少需要重新计算的节点数量，从而大幅提升性能。

## 图搜索基础回顾 📊

![](img/924d1e24aa2a570625843a6379f0277a_11.png)

![](img/924d1e24aa2a570625843a6379f0277a_13.png)

在深入增量式搜索算法之前，我们需要回顾一些基础的图搜索概念。一个图搜索问题通常包含以下要素：
*   **图（Graph）**：由**节点（Vertices/Nodes）** 和连接节点的**边（Edges）** 构成。
*   **边权函数（Edge Weighting Function）**：描述从一个节点移动到另一个节点的代价。
*   **启发式函数（Heuristic Function）**：估计从当前节点到目标节点的剩余代价。
*   **起点（Start Vertex）** 和 **终点（Goal Vertex）**。

![](img/924d1e24aa2a570625843a6379f0277a_15.png)

![](img/924d1e24aa2a570625843a6379f0277a_17.png)

在搜索中，我们使用几个关键值：
*   **G值**：从起点到当前节点的实际累积代价。公式为：`G(current) = G(predecessor) + w(predecessor, current)`，其中 `w` 是边权。
*   **H值**：从当前节点到目标节点的启发式估计代价。
*   **F值**：节点的总估计代价，`F = G + H`。

![](img/924d1e24aa2a570625843a6379f0277a_19.png)

![](img/924d1e24aa2a570625843a6379f0277a_20.png)

![](img/924d1e24aa2a570625843a6379f0277a_22.png)

![](img/924d1e24aa2a570625843a6379f0277a_24.png)

为了对现实世界环境进行推理，我们首先需要将其转换为图。例如，网格世界可以转换为四连通或八连通的图结构。

![](img/924d1e24aa2a570625843a6379f0277a_26.png)

![](img/924d1e24aa2a570625843a6379f0277a_27.png)

另一个重要概念是**松弛（Relaxation）**，这在Dijkstra等最短路径算法中很常见。其思想是：初始时，将起点代价设为0，其他所有节点代价设为无穷大。然后通过不断比较和更新，将节点的代价从无穷大“松弛”到其真实的最短路径值。

增量式搜索方法的核心在于存储先前搜索的最优结果。具体存储方式因算法而异，例如可以存储最短路径列表，或者像D* Lite算法那样存储每个节点的G值（从该节点到目标节点的最短距离）。

![](img/924d1e24aa2a570625843a6379f0277a_49.png)

![](img/924d1e24aa2a570625843a6379f0277a_51.png)

![](img/924d1e24aa2a570625843a6379f0277a_52.png)

当环境发生变化（如图中边权改变）时，算法会检查图中数据的**不一致性（Inconsistencies）**。然后，它利用先前存储的数据，仅对受影响的节点进行必要的“松弛”操作，从而高效地计算出新的最优路径，而不是重新搜索整个图。

![](img/924d1e24aa2a570625843a6379f0277a_54.png)

![](img/924d1e24aa2a570625843a6379f0277a_56.png)

增量式搜索的应用领域很广，不仅限于移动机器人路径规划，还可用于时间规划、命题可满足性判断等。在本课程中，我们将重点介绍应用于移动机器人的D* Lite算法。

## D* Lite 算法详解 🧠

D* Lite 算法结合了增量式搜索和启发式搜索（A*）的优点，能够在环境变化时快速重新规划出最优路径。我们可以从两个视角理解它：
1.  **A* 的修改版**：在第一次运行（环境无变化时），其行为与A*非常相似。
2.  **有引导的Dijkstra算法**：在重新规划时，它像Dijkstra算法一样进行松弛操作，但只关注从当前起点到目标点的必要节点，效率更高。

![](img/924d1e24aa2a570625843a6379f0277a_60.png)

### 关键概念与公式

![](img/924d1e24aa2a570625843a6379f0277a_62.png)

D* Lite 搜索的方向是**从目标点反向搜索到起点**。这样，每个节点的G值表示的是**从该节点到目标点的最短距离**，这个值在机器人移动时是保持不变的，有利于效率。而启发值H则表示从起点到该节点的估计代价。

![](img/924d1e24aa2a570625843a6379f0277a_64.png)

![](img/924d1e24aa2a570625843a6379f0277a_66.png)

算法为每个节点 `s` 维护两个值：
*   **`g(s)`**：当前认为的从节点 `s` 到目标点的最短路径代价。
*   **`rhs(s)`**：一个基于节点 `s` 所有后继节点 `s'` 计算得到的值，可以看作是 `g(s)` 的一个“一步前瞻”的候选值。其计算公式为：
    `rhs(s) = min_{s' ∈ Succ(s)} ( c(s, s') + g(s') )`
    其中 `Succ(s)` 是 `s` 的后继节点集合，`c(s, s')` 是边权。

**局部不一致性（Local Inconsistency）**：
*   如果 `g(s) > rhs(s)`，称节点 `s` 为 **过一致（Overconsistent）**。这意味着当前存储的路径代价高于新发现的可能更优的代价，需要“松弛”降低。
*   如果 `g(s) < rhs(s)`，称节点 `s` 为 **欠一致（Underconsistent）**。这通常发生在边权增加导致原有路径失效时，当前存储的代价过于乐观。

![](img/924d1e24aa2a570625843a6379f0277a_68.png)

![](img/924d1e24aa2a570625843a6379f0277a_70.png)

![](img/924d1e24aa2a570625843a6379f0277a_72.png)

算法使用一个优先队列来处理不一致的节点。队列中每个节点 `s` 的排序键值 `key(s)` 是一个二元组：
`key(s) = [ min(g(s), rhs(s)) + h(s, start) + km; min(g(s), rhs(s)) ]`
其中：
*   `h(s, start)` 是从起点到节点 `s` 的启发值。
*   `km` 是一个键值修正量，用于在机器人移动（起点改变）时调整队列中已有节点的键值，使其与新加入的节点可比。

![](img/924d1e24aa2a570625843a6379f0277a_74.png)

![](img/924d1e24aa2a570625843a6379f0277a_76.png)

### 算法流程

![](img/924d1e24aa2a570625843a6379f0277a_78.png)

![](img/924d1e24aa2a570625843a6379f0277a_80.png)

![](img/924d1e24aa2a570625843a6379f0277a_82.png)

以下是D* Lite的核心流程：

![](img/924d1e24aa2a570625843a6379f0277a_84.png)

![](img/924d1e24aa2a570625843a6379f0277a_86.png)

1.  **初始化**：将所有节点的 `g(s)` 和 `rhs(s)` 设为无穷大（∞），除了目标点 `rhs(goal)=0`。将目标点放入优先队列。
2.  **计算最短路径**：
    *   从优先队列中取出键值最小的节点 `u` 进行处理。
    *   如果 `g(u) > rhs(u)`（过一致）：
        *   令 `g(u) = rhs(u)`。
        *   更新节点 `u` 的所有**前驱节点**的 `rhs` 值，并将变为不一致的前驱节点加入队列。
    *   如果 `g(u) < rhs(u)`（欠一致）：
        *   令 `g(u) = ∞`。
        *   更新节点 `u` 本身及其所有**前驱节点**的 `rhs` 值，并将它们（包括 `u`）中变为不一致的加入队列。
    *   重复此过程，直到**起点变得一致**（`g(start) == rhs(start)`）且其键值不小于队列中任何节点的键值。此时，从起点开始，每一步都选择使 `g(successor) + c(current, successor)` 最小的后继节点，即可回溯出最优路径。
3.  **机器人移动与重新规划**：
    *   机器人沿规划路径移动到下一个节点，该节点成为新的起点。
    *   更新键值修正量 `km += h(old_start, new_start)`。
    *   **感知环境变化**：如果发现边权改变（如出现新障碍），对于每条改变的边 `(u, v)`，更新其**源节点 `u`** 的 `rhs` 值，并将节点 `u` 加入队列（如果因此变得不一致）。
    *   跳回第2步进行重新规划。

![](img/924d1e24aa2a570625843a6379f0277a_88.png)

通过这种方式，D* Lite 只对受环境变化影响的局部区域进行重新计算，极大地提高了在动态环境中反复规划的效率。

## 何时使用增量式路径规划？ ⚖️

D* Lite 等增量式规划算法并非在所有情况下都是最佳选择。理解其适用场景很重要。

![](img/924d1e24aa2a570625843a6379f0277a_100.png)

增量式规划的优势在于，当环境变化发生在**已规划路径的末端**（即靠近当前机器人的位置）时，它只需要修复路径的一小部分，效率极高。这对于传感器视野有限的移动机器人来说是常见情况，因为新障碍通常在机器人靠近时才会被发现。

![](img/924d1e24aa2a570625843a6379f0277a_102.png)

![](img/924d1e24aa2a570625843a6379f0277a_104.png)

![](img/924d1e24aa2a570625843a6379f0277a_106.png)

然而，如果环境变化发生在**已规划路径的起始端**（即远离机器人的地方），增量式算法可能不得不撤销大量先前的计算，几乎相当于重新搜索整个图。在这种情况下，直接使用像A*这样的算法进行完全重新规划可能更简单、更高效。

![](img/924d1e24aa2a570625843a6379f0277a_108.png)

![](img/924d1e24aa2a570625843a6379f0277a_110.png)

![](img/924d1e24aa2a570625843a6379f0277a_112.png)

![](img/924d1e24aa2a570625843a6379f0277a_114.png)

因此，选择规划算法时，需要考虑环境变化的预期模式。对于传感器信息逐步更新、障碍物常在近处出现的移动机器人导航，D* Lite 是非常合适的选择。

![](img/924d1e24aa2a570625843a6379f0277a_116.png)

## 算法扩展与应用 🚀

![](img/924d1e24aa2a570625843a6379f0277a_120.png)

![](img/924d1e24aa2a570625843a6379f0277a_122.png)

![](img/924d1e24aa2a570625843a6379f0277a_124.png)

增量式路径规划的思想可以扩展到其他有趣的问题和应用中：

![](img/924d1e24aa2a570625843a6379f0277a_126.png)

![](img/924d1e24aa2a570625843a6379f0277a_128.png)

*   **全覆盖路径规划（Greedy Mapping）**：目标是让机器人访问图中的所有节点。一种技巧是引入一个虚拟目标节点，并假设所有未访问的节点都有一条低成本边通向它。当机器人访问一个节点后，就“移除”这条边。这样，D* Lite 会不断规划前往最近的未访问节点的路径，从而实现近似全覆盖。
*   **随时规划器（Anytime Planners）**：这种规划器首先快速生成一个可行但不一定最优的解，然后随着时间推移不断优化它。我们可以结合增量式规划来实现：首先使用**膨胀的启发值**（`h(s) * ε, ε > 1`）进行快速搜索，找到一条初始路径。然后，逐步减小膨胀系数，并利用增量式规划高效地修复和优化当前路径。
*   **应用于移动机器人**：将连续的真实世界环境转化为图是应用这些算法的前提。常见方法有：
    *   **单元分解法**：将自由空间划分为不重叠的单元，每个单元的中心作为一个图节点。
    *   **可见性图法**：连接所有彼此“可见”（连线不穿越障碍物）的障碍物顶点，形成图。
    *   **基于采样的图构建法**：在空间中随机或确定性采样点，然后连接邻近的点形成图。

![](img/924d1e24aa2a570625843a6379f0277a_130.png)

对于非完整动力学约束的机器人（如汽车），还需要在连接图节点时考虑可行的运动基元（如直线、左转弧、右转弧）。

![](img/924d1e24aa2a570625843a6379f0277a_132.png)

![](img/924d1e24aa2a570625843a6379f0277a_134.png)
