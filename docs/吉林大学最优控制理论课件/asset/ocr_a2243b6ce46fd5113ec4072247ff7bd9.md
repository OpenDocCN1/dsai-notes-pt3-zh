不是燃料最优控制。还可以验证（4.5-4）（4.5-5）任何控制，皆不是最优控制。

结论：初始 x₀ 位于 R₁、R₃ 内，燃料最优控制无解。

综上所述，问题 4.7 的燃料最优控制为：
 u* = u*(x₁,x₂) = +1   ∀(x₁,x₂) ∈ γ₊
 u* = u*(x₁,x₂) = -1   ∀(x₁,x₂) ∈ γ₋
 u* = u*(x₁,x₂) = 0    ∀(x₁,x₂) ∈ R₂ ∪ R₄

若 (x₁,x₂) ∈ R₂ ∪ R₄，则不存在最优控制。
