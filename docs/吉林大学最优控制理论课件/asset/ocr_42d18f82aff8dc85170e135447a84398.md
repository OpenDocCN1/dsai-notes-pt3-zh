# 第二章 变分法及其在最优控制的应用

# §2.1 变分法的基本概念

# 一 泛函

对于某一类函数集合中的每一个函数 y(x)，均有一个确定的数 J 与之对应，那么就称 J 为

依赖于函数 y(x) 的泛函，记作

J = J[y(x)]，或简称 J

其中 y(x) 称为泛函的宗量(自变量)。

# 二 容许函数类(空间)

满足一定条件的一类函数称为泛函的容许函数类(空间)。

例：所有在区间[a,b]上连续函数的全体是一个函数空间，记 C[a,b]。

所有在区间[a,b]上连续且一阶可微函数的全体是一个函数空间，记 C¹[a,b]

所有在区间[a,b]上连续且二次可微函数的全体是一个函数空间，记 C²[a,b]

# 三 泛函的极值

最简单的一类函数

J[y] = ∫ₐᵇ F(x, y, y') dx

对任一条与 y = y₀(x) 接近的曲线上，有

J[y(x)] − J[y₀(x)] ≥ 0

则称 J[y(x)] 在曲线上 y₀(x) 上达到极小值。

# 1. 接近定义

两个函数具有零阶接近度：

|y(x) − y₀(x)| ≤ ε, (x₁ ≤ x ≤ x₂)

两个函数具有一阶接近度：

|y(x) − y₀(x)| ≤ ε, (x₁ ≤ x ≤ x₂)， |y'(x) − y₀'(x)| ≤ ε, (x₁ ≤ x ≤ x₂)

当 y(x) 为函数空间的一个点时，接近度可用点距来表示：

零阶距离 d₀(y, y₀) = max_{x∈[a,b]} |y(x) − y₀(x)|
