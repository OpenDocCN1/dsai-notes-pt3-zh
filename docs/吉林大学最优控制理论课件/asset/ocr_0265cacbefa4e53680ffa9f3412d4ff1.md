# §4.4 简谐振荡型受控系统的最速控制

特征值为实数的其他二阶系统，其最优控制的分析与综合，与上节相似，以下研究特征值为复数情况。

x₁(t) = ωx₂(t)

问题 4.6 已知受控系统为 x₂(t) = -ωx₁(t) + u(t) (4.4-1)

求一满足如下约束条件的容许控制 u(t)

|u(t)| ≤ 1, ∀t ∈ [0,T]. (4.4-2)

使系统 (4.4-1) 的任意初态 x₀ 转移到原点的时间最小。(4.4-1) 的特征值为 μ₁ = jω, μ₂ = -jω。

1 哈密顿函数 H

H = 1 + λ₁ωx₂ - λ₂ωx₁ + λ₂u u* = -sgn λ₂

2

λ₁ = -∂H/∂x₁ = λ₂ω
λ₂ = -∂H/∂x₁ = -λ₁ω

λ(t) = [cos ωt sin ωt; -sin ωt cos ωt] [π₁; π₂]

⇒ λ₂(t) = -π₁ sin ωt + π₂ cos ωt = D sin(ωt + α₀)

其中 D > 0, α₀ 是和 λ₁(0), λ₂(0) 有关的常数。

3 最优控制

u*(t) = -sgn{ D sin(ωt + α₀) }
