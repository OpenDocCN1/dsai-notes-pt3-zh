+   1>0 的某一确定数；
+   ε>0 是一个充分小的数；
+   σ 任意

U^*(t)+Δ_{σϵ}U(t)={ U^*(t), t₀ ≤ t < σ, σ+εl < t ≤ t_f \bar{U}(t), σ ≤ t ≤ σ+εl }

对 b(t)作变换可得

b(t)={ 0   t₀ ≤ t < σ, σ+εl < t ≤ t_f \ b   σ ≤ t ≤ σ+εl }

于是是(3.2-9)可变为

|ΔX(t)| ≤ ∫_{t₀}^{t} e^{a(t-τ)} b(τ) dτ ≤ ∫_{t₀}^{t} e^{a(t-τ)} b(τ) dτ ≤ e^{a t_f} ∫_{t₀}^{t_f} b(τ) dτ = e^{a t_f} · b l ε (3.2-10)

上式表明|ΔX(t)|与ε 视同阶小量。
