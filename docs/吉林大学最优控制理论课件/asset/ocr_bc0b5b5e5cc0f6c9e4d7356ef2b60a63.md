设 x₀ ∈ R₄ , 则 (4.5-5) 只有 u⁽¹⁾={0,+1},u⁽²⁾={-1,0,+1}两种可能为最优控制。 求出燃料消耗量的下限。 对 (4.5-1) 积分 ⇒ x₂₀ = ∫₀ᵗ u(t)dt 即： |x₂₀| = |∫₀ᵗ u(t)dt| ≤ ∫₀ᵗ |u(t)|dt ≤ J (4.5-7) J的下限为 x₂₀ , u⁽¹⁾={0,+1} , 对应轨线是弧 ABO 。 J⁽¹⁾ = ∫₀ᵗ |u(t)|dt = ∫₀^{t₁} |u(t)|dt + ∫_{t₁}^t |u(t)|dt + ∫_t^{t₂} |u(t)|dt = 0 + ∫_{t₁}^t |u(t)|dt + ∫_t^{t₂} |u(t)|dt = -x₂₀ = |x₂₀| 同理可以得出： J⁽²⁾ > J⁽¹⁾ = |x₂₀| 即： u⁽¹⁾ = {0,+1} , 是满足必要条件且消耗燃料最少的最优控制。
