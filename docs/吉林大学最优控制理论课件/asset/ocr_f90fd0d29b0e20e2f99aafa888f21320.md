特点：1）Bang—Bang控制
2）多次切换，没有上界
3）每次切换时间是 π/ω （首尾除外，小于等于 π/ω），周期 2π/ω
4 最优轨线

```
dx1/dt = ω x2
 dx2/dt = -ω x1 ± 1  ⇒  dx1/dx2 = ω x2 / (-ω x1 ± 1) ⇒ (-ω x1 ∓ 1)² + (ω x2)² = e
```
