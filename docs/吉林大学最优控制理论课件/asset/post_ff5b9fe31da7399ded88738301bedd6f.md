
J*[x(t+h),t+h]=J*[x(t),t]+∂J*/∂t h+ (∂J*/∂x)^T [x(t+h)-x(t)]+o(h) (5.4-6)

将（5.4-3），（5.4-6）代入（5.4-5）整理得

J*[x(t),t]=min_{u(t)∈U(t)} { J*[x(t),t]+{ L[x(t),u(t),t]+∂J*/∂t+(∂J*/∂x)^T f[x(t),u(t),t] } h+o(h) }

另有J*[x(t),t]与u(t)无关，故有

-∂J*/∂t h = min_{u(t)∈U(t)} { L[x(t),u(t),t]h+(∂J*/∂x)^T f[x(t),u(t),t]h+o(h) }

两端除h，且h→0有

-∂J*/∂t = min_{u(t)∈U} { L[x(t),u(t),t]+(∂J*/∂x)^T f[x(t),u(t),t] } (5.4-7)

一般说 u*(t)=u[ x(t), ∂J*/∂x ,t ] (5.4-8)

代入（5.4-7）得

-∂J*/∂t = L[ x(t),u* (x(t),∂J*/∂x ,t),t ] + (∂J*/∂x)^T f[ x(t),u* (x(t),∂J*/∂x ,t),t ] (5.4-9)

（5.4-9）为哈密顿-雅可比方程。另知

J*[x_f,t_f]=s[x_f,t_f] (5.4-10)

（5.4-10）为H-J方程的边界条件。（5.4-9）和（5.4-10）是问题5.3最优控制与最优代价的充分条件。

H函数

H(x,u,λ,t)=L(x,u,t)+λ^T f(x,u,t) (5.4-11)

令其中 λ(t)=∂J*/∂x (5.4-12)

则方程（5.4-7）可改写为

-∂J*/∂t = H*[ x(t),∂J*/∂x ,t ] (5.4-13)

其中

H*[ x(t),∂J*/∂x ,t ] = min_{u(t)∈U} H[ x(t),u(t),∂J*/∂x ,t ] (5.4-14)

求解步骤：

- Step1. 选 H[x(t),u(t),t]=L[x(t),u(t),t]+(∂J*/∂x)^T f[x(t),u(t),t]
  求极小值：对 u 无约束，求 ∂H/∂u；对 u 有约束，求 MinH
  ⇒ u* = u*[x(t), ∂J*/∂x ,t]
- Step2. 解 H-J 方程 (5.4-9)，边界条件 (5.4-10)
  ⇒ J*[x(t),t]
- Step3. 将 J* 代入 u*，u* 是 x 的函数
- Step4. 将 u* 代入状态方程 (5.4-1)，⇒ x*(t)
- Step5. 将 x*(t) 代入 u* 中，得 u* = u*(t)

### 例 1. 已知线性定常系统

ẋ(t)=A x(t)+B u(t), x(0)=x0, A n×n, B n×m, u(t) 不受约束

求一控制 u(x(t))，使

J = 1/2 ∫0^∞ [x^T Q x + γ u^T u] dt = min

其中 Q 为非负定对称常数矩阵，γ 是一正数。

（1）H 函数 →

H(x,u,λ,t)=1/2 x^T Q x + 1/2 γ u^T u + λ^T A x + λ^T B u

H 的最小值：∂H/∂u = γ u + B^T λ = 0 ⇒ u* = -γ^{-1} B^T λ

代入 H 中：

H*(x,λ,t)=1/2 x^T Q x + λ^T A x - 1/2 λ^T B B^T λ γ^{-1}

因受控系统是定常的，Q、γ 是常数阵及常数，积分时间为无穷大，故知 J* 只依赖于初态，与 t 无关 ⇒ ∂J*/∂t =0

（2）H-J 方程为

1/2 x^T Q x + (∂J*/∂x)^T A x - 1/2 (∂J*/∂x)^T B B^T (∂J*/∂x) γ^{-1}=0

令上式解为 J*[x(t)]=1/2 x^T P x ⇒ ∂J*/∂x = P x

代入上式 ⇒

1/2 xᵀ [Q + PᵀA + AᵀP - PᵀBBᵀPγ⁻¹] x = 0

对于非零 x，矩阵 P 应满足如下 Riccati 矩阵代数方程：

PᵀA + AᵀP - PᵀBBᵀPγ⁻¹ + Q = 0

易证 P = Pᵀ，即 P 为对称矩阵，因此，上面方程写成：

PA + AᵀP - PBBᵀPγ⁻¹ + Q = 0

（3）由 Riccati 矩阵代数方程解得 P，则最优控制为

u* (t) = -γ⁻¹ Bᵀ ∂J*/∂x = -γ⁻¹ Bᵀ P x(t) → 状态 x(t) 的线性反馈

## §6.2 有限时间状态调节器 (T ≠ ∞)

问题 6.2 的目标是求使 J 为最小的最优控制 u*(t)，t ∈ [t₀, T]，以及最优性能指标

J*[x(t₀), t₀] = J*[x(t₀), t₀, u*(·), t₀]

为解决此问题，给出如下结果。

- 如果 J*[x(t₀), t₀] 存在，则必为 xᵀ(t₀) P(t₀) x(t₀) 的形式，即 P(t₀) 为对称矩阵。

J*[x(t₀), t₀] 为二次型的充分必要条件是：

- (1) J*[λx(t₀), t₀] = λ² J*[x(t₀), t₀]，其中 λ 为任意实数   (6.2-1)
- (2) J*[x₁(t₀), t₀] + J*[x₂(t₀), t₀] = ½ { J*[x₁(t₀)+x₂(t₀), t₀] + J*[x₁(t₀)-x₂(t₀), t₀] }   (6.2-2)

证明：必要性显然成立。

充分性：

⎧ ẋ(t) = A(t)x(t) + B(t)u(t)  
⎨  
⎩ x(t₀) = x₀          t ∈ [t₀, T]

J*[x₀, u(t), t₀] = ½ xᵀ(T) F x(T) + ½ ∫ₜ₀ᵀ [xᵀ(t) Q(t) x(t) + uᵀ(t) R(t) u(t)] dt

J*[x(t₀), t₀] = J*[x₁(t₀), t₀]

条件(1)

J*[λx(t₀), t₀] ≤ J*[x(t₀), λu*(t₀), t₀] = λ²J*[x(t₀), t₀]

最优控制性质

λ²J*[x(t₀), t₀] ≤ λ²J*[x(t₀), λ⁻¹u*(t), t₀] = J*[λx(t₀), t₀]
