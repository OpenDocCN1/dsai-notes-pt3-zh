
并设二曲线 x = x(t) 与 x = \bar{x}(t) 之间的小块面积

σ = ∫_{t_i - δ}^{t_i + δ} [\bar{x}(t) - x(t)] dt = ∫_{t_i - δ}^{t_i + δ} δx dt

设计的泛函增量

ΔJ = J[\bar{x}(t)] - J[x(t)] = ∫_{t_i - δ}^{t_i + δ} [F(t, \bar{x}, \bar{\dot{x}}) - F(t, x, \dot{x})] dt

由二元函数泰勒中值定理可得：

ΔJ = ∫_{t_i - δ}^{t_i + δ} [\bar{F}_x δx + \bar{F}_{\dot{x}} δ\dot{x}] dt = ∫_{t_i - δ}^{t_i + δ} [\bar{F}_x - d/dt \bar{F}_{\dot{x}}] δx dt = [\bar{F}_x - d/dt \bar{F}_{\dot{x}}]_{t = t_i} · ∫_{t_i - δ}^{t_i + δ} δx dt

= [\bar{F}_x - d/dt \bar{F}_{\dot{x}}]_{t = t_i} · σ

令小块 σ 向 M(\bar{t}, \bar{x}(\bar{t})) 点这样地收缩

+   (1) [t - δ, t + δ] 收缩到 t̄, 即 δ → 0
+   (2) 曲线 x = x(t) 与 x = \bar{x}(t) 的一阶距离 |\bar{x}, x| → 0

[\bar{F}_x - d/dt \bar{F}_{\dot{x}}]_{t = t_i} → [F_x - d/dt F_{\dot{x}}]_{t = t_i}

或 [\bar{F}_x - d/dt \bar{F}_{\dot{x}}]_{t = t_i} = [F_x - d/dt F_{\dot{x}}]_{t = t_i} + ε, 其中 ε 随 σ → 0 趋于零。

ΔJ = {[F_x - d/dt F_{\dot{x}}]_{t = t_i} + ε} · σ = [F_x - d/dt F_{\dot{x}}]_{t = t_i} · σ + ε σ

称 [F_x - d/dt F_{\dot{x}}]_{t = t_i} · σ 为泛函 J 在点 M 上的变分，

称 lim_{σ→0} [J[\bar{x}(t)] - J[x(t)]] / σ = [F_x - d/dt F_{\dot{x}}]_{t = t_i} 为 M 点导数。

多变量情况：

δV Σ_{i=1}^n p_i [F_{x_i} - d/dt F_{\dot{x}_i}]_{t = t_i} 为泛函在 M 点上的变分，其中 P = [p_1, p_2, ..., p_n], δV 是 σ 的广义坐标。

## §2.5 哈米顿原理

本节利用泛函的变分，推导力学中的一个基本变分原理-哈米顿原理。

考虑由 n 个质点组成的力学系：

n 个质点的质量分别为 m₁, m₂, …, mₙ，以 (xᵢ, yᵢ, zᵢ) 表示第 i 个质点的坐标。

以 T 表示这个系统的动能，则

T = 1/2 Σᵢ₌₁ⁿ mᵢ [ẋᵢ²(t) + ẏᵢ²(t) + żᵢ²(t)]

以 G = G(x₁, y₁, z₁, …, xₙ, yₙ, zₙ) 表示系统的势能，则在第 i 个质点上，作用力的分量为

∂G/∂xᵢ , ∂G/∂yᵢ , ∂G/∂zᵢ

再令第 i 个质点上的惯性力的分量为：

-mᵢ ẍᵢ(t), -mᵢ ÿᵢ(t), -mᵢ z̈ᵢ(t)

### 达朗贝尔原则：

如果某所受的作用力叠加惯性力，那么沿任意位移合成的做功等于零。

若设

F̄ᵢ = (∂G/∂xᵢ - mᵢ ẍᵢ(t)) i⃗ + (∂G/∂yᵢ - mᵢ ÿᵢ(t)) j⃗ + (∂G/∂zᵢ - mᵢ z̈ᵢ(t)) k⃗

δr̄ᵢ = δxᵢ i⃗ + δyᵢ j⃗ + δzᵢ k⃗

则有 Σᵢ₌₁ⁿ F̄ᵢ · δr̄ᵢ = 0，即

Σᵢ₌₁ⁿ [ (∂G/∂xᵢ - mᵢ ẍᵢ(t)) δxᵢ + (∂G/∂yᵢ - mᵢ ÿᵢ(t)) δyᵢ + (∂G/∂zᵢ - mᵢ z̈ᵢ(t)) δzᵢ ] = 0

记 δn = √[ Σᵢ₌₁ⁿ [ (δxᵢ)² + (δyᵢ)² + (δzᵢ)² ] ], pᵢ = ∂xᵢ/∂n, qᵢ = ∂yᵢ/∂n, rᵢ = ∂zᵢ/∂n

则有 Σᵢ₌₁ⁿ [ (∂G/∂xᵢ - mᵢ ẍᵢ(t)) pᵢ + (∂G/∂yᵢ - mᵢ ÿᵢ(t)) qᵢ + (∂G/∂zᵢ - mᵢ z̈ᵢ(t)) rᵢ ] = 0

因 G 只依赖于 xᵢ, yᵢ, zᵢ，所以

∂G/∂ẋᵢ = 0, ∂G/∂ẏᵢ = 0, ∂G/∂żᵢ = 0,

由于在曲线 xᵢ = xᵢ(t), yᵢ = yᵢ(t), zᵢ = zᵢ(t) 上任一点，沿着方向 (p₁, q₁, r₁ … pₙ, qₙ, rₙ)

上的泛函 J₁ = ∫ G dt 的微商为：

∑_{i=1}^{n}[(∂G/∂x_i)p_i + (∂G/∂y_i)q_i + (∂G/∂z_i)r_i]

因为 ∂T/∂x_i = ∂T/∂y_i = ∂T/∂z_i = 0，所以泛函 J_2 = ∫T dt 的做简约为：

- ∑_{i=1}^{n} m_i[ẍ_i(t)p_i + ÿ_i(t)q_i + z̈_i(t)r_i]

有 δ∫(G + T)dt = 0，此即哈米顿原理。

在实际应用中，如果力场是保守场，则存在势函数 G，使： δ∫_{t0}^{t1}(T - G)dt = 0

## 第三章 极大值原理

### 古典变分法的问题：

1.控制变量 u 没有约束条件，或只有开集性的约束条件，而在最优控制问题中，都经常带有闭集性的约束条件，如 |u(t)| ≤ 1，此时变分法不适用。
2.要求 F 和 f 都有足够的微分性，特别是要求 ∂F/∂u 存在。 J = ∫_{t0}^{t_f} |u(t)| dt 这样的性能指标就被排除在外了，而实际问题经常存在此情况，为克服上述困难，不少人作了许多努力，较成功的是庞特里亚金的最大值原理。

## § 3-1 自由末端的极大值原理

考虑常态的末值型性能指标、末态自由的控制问题。

定理 3.1 设 U(t) ∈ U 是—容许控制，指定末值型性能指标泛函为 J[U(·)] = S[ x(t_f) ]

X(t) 是常态系统 Ẋ(t) = f(X,U), X(t0) = X0, t ∈ [t0, t_f] 相对于 U(t) 的轨迹。 t_f 为未知的末端时刻。

设 U*(t) 和 t_f* 是使性能指标最小的最优解, X*(t) 为相应的最优轨线, 则存在非零的 n 维向量函数 λ̄(t), 使得:

(1) λ̄(t) 是方程 λ̄̇(t) = - ∂H(X, λ̄, U)/∂X 满足边界条件

(2) λ̄(t_f) = ∂S(x(t_f))/∂X(t_f) 的解。

其中, 哈密顿函数为 H(X, λ̄, U) = λ̄^T f(X,U) 则有 (3) H(X*(t), λ̄(t), U*(t)) = min_{U(t)∈U} H(X*(t), λ̄(t), U(t)), t ∈ [t0, t_f]

(4)  H(X*(t), λ̄(t), U*(t)) = H(X*(t_f*), λ̄(t_f*), U*(t_f*)) = 0    当 t_f 自由时
H(X*(t), λ̄(t), U*(t)) = H(X*(t_f), λ̄(t_f), U*(t_f)) = const    当 t_f 固定时

说明：

+   1. 容许控制条件的放宽 没有要求 ∂H/∂u 存在
+   2. H 取全局最小值，而 t 是变分法中的极值
+   3. 最优控制 U*(t) 使哈密顿函数 H 取最小值——“极小值原理”。

证明过程中，H̄ = −H —— 均称“极大值原理”。以下沿用“极大值原理”的习惯叫法，实际上采用的是“极小值原理”。

4. 定理 3.1 中的条件(1)、(2)称为协态方程（共轭方程）的横截条件。

先根据(3)、(4)作出 U*(t) 及 t_f*，然后求解

```
⎧ Ẋ = ∂H(X, λ̄, U)/∂λ̄ = f(X,U), X(t₀)=X₀
⎨
⎩ λ̇ = − ∂H(X, λ̄, U)/∂X , λ(t_f)= ∂S[X(t_f)]/∂X(t_f)
```

5. 只给出必要条件
实际问题的解是否存在，如存在极大值原理的解又只有一个，则可以说，此解就是最优控制。
