最优代价  J*[x(k)] = J[x(k), u*]      u* 为最优策略

对于给定问题，当 x(k) 固定是，u* 是确定的 → 最优代价 J* 仅是起始状态的函数。J*[x(k), k]

下面求解问题 5.1：J*[x(0), 0]

应用不变嵌入原理 ⇒ J[x(k), k] = Σ_{j=k}^{N} L[x(j), u(j), j]

其中，x(k) 认为是固定的。

x(k+1) = f[x(j), u(j), j], j=k, k+1, ..., j=N-1.

J*[x(k), k] = min_{u(k),u(k+1),...,u(N)} { Σ_{j=k}^{N} L[x(j), u(j), j] }
= min_{u(k),u(k+1),...,u(N)} { L[x(k), u(k), k] + Σ_{j=k+1}^{N} L[x(j), u(j), j] }
= min_{u(k)} min_{u(k+1),...,u(N)} { L[x(k), u(k), k] + Σ_{j=k+1}^{N} L[x(j), u(j), j] }

第一项 仅取决于 u(k)。
第二项 x(k+1) 固定时，却决于 x(k+1), ..., x(N) 与 u(k) 不直接相关。
但 u(k) 通过 (5.2-3) 影响 x(k+1)。
故 ⇒

J*[x(k), k] = min_{u(k)} { L[x(k), u(k), k] + J*[x(k+1), k+1] }
= min_{u(k)} { L[x(k), u(k), k] + J*[f[x(k), u(k), k], k+1] }
→ 递推方程
J*[x(N), N] = min_{u(N)} { L[x(N), u(N), N] }          (对其他形式的 J 同理可推)

例 1：
{ J = ψ[x(0)] + Σ_{k=1}^{N-1} L[x(k), u(k), k] + φ[x(N)]
x(k+1) = f[x(k), u(k), k]      k = 0,1,..., N-1 }

与问题 5.1 有两点不同；(1) 没给初始条件，改用了取决于初态的始端代价 ψ[x(0)]
(2) 以末端代价 x(N) 代替 L[x(N), u(N), N]
最后一级决策 u(N) 不影响末端代价，可设
① J*[x(N), N] = φ[x(N)]
