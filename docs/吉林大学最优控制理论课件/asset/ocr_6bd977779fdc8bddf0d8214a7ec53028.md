r₊ = {(x₁,x₂): x₁ = 1/2 x₂², x₂ ≤ 0}

r₋ = {(x₁,x₂): x₁ = -1/2 x₂², x₂ ≥ 0}

r = r₊ ∪ r₋ = {(x₁,x₂): x₁ = -1/2 x₂|x₂|}

曲线 r 及坐标轴 x₁ 将平面分成以下四个区域

R₁ = {(x₁,x₂): x₁ > -1/2 x₂², x₂ ≥ 0}

R₂ = {(x₁,x₂): x₁ < -1/2 x₂², x₂ > 0}

R₃ = {(x₁,x₂): x₁ < 1/2 x₂², x₂ ≤ 0}

R₄ = {(x₁,x₂): x₁ > 1/2 x₂², x₂ < 0}

初态位于 r₊ 上, u=+1 是唯一的燃料最优控制因此此时 (4.5-5) 中只有 {+1} 能使系统的状态轨迹达到坐标原点, 满足末态条件, 若采用 (4.5-4), 即奇异情况, 有

x₁(t) = x₁(0) + x₂(0)t + ∫₀ᵗ ∫₀^σ [-sgn{λ₂(0)}v(σ)] dσ
x₂(t) = x₂(0) + ∫₀ᵗ [-sgn{λ₂(0)}v(τ)] dτ  (4.5-6)

一般情况 (4.5-6) 不通过原点, 因而不是最优轨迹, 同理, 初态位于 r₋ 上, u=-1 是唯一燃料最优控制。
