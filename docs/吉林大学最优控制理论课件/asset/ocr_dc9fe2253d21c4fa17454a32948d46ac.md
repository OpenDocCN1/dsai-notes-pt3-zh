1）u(t)=+1
{ x₁(t)=x₁₀+x₂₀t+½t²
  x₂(t)=ẋ₂₀+t }
消去 t，相轨迹为：x₁=(x₁₀−½x₂₀)t²+½x₂²

2）u(t)=−1
{ x₁(t)=x₁₀+x₂₀t−½t²
  x₂(t)=ẋ₂₀−t }
消去 t，相轨迹为：x₁=(x₁₀+½x₂₀)t²−½x₂²

终端 X(T):{ x₁(T)=0
          ...
          x₂(T)=0 }

r:{ r₊:x₁=½x₂²,x₂≤0
     ...
     r₋:x₁=−½x₂²,x₂≥0 } （开关线，切换线）

定义 R₊平面：r 域以下平面（包括 r₊线）
R₋平面：r 域以下平面（包括 r₋线）

最优控制规律
(x₁₀,x₂₀)∈r₊,u*(t)=+1
(x₁₀,x₂₀)∈r₋,u*(t)=−1
(x₁₀,x₂₀)∈R₋∉r₋,u*(t)=−1⇒u*(t)=+1
(x₁₀,x₂₀)∈R₊∉r₊,u*(t)=+1⇒u*(t)=−1

工程实现：
r₊:x₁=−½x₂|x₂|
令 F(X₂)=−½x₂|x₂|⇒X₁=F(X₂)
σ(x₁,x₂)=X₁−F(X₂)
