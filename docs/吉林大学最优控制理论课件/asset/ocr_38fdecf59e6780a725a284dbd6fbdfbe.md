# §5.1 多阶段决策问题

例：最优路线问题

![](bbox=[0.15, 0.35, 0.88, 0.58])

始点为 A 点，终点为 E 点，求最优路线，即 A—E 时间最短

+   1. 穷举法

计算所有的路线； 共有 2^(n-1) = 8 线路(n = 4)

需做加法 3 * 2^(n-1) = 24

如有 N 段 则加法次数 = (N - 1) * 2^(n-1)

+   2. 动态规划

从末端 E 点开始逐段向前推算

第四段 D1→E 代价 J=4 D2→E J=3

第三段 C1→E C1D1E,J=5 C1D2E,J=5 C1D2E(J=4) C2→E C2D2E,J=5 C2D1E,J=6 C2D2E(J=5)

第二段 B1→E B1C1D2E,J=10 B1C2D2E,J=11 B2C1D2E(J=8)
