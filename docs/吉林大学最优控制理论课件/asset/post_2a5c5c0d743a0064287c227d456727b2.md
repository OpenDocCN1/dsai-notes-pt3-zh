
J*[x1(t0),t0]+J*[x2(t0),t0] ≤ 1/2{J*[x1(t0)+x2(t0),t0]+J*[x1(t0)-x2(t0),t0]}

同理可证

1/2{J*[x1(t0)+x2(t0),t0]+J*[x1(t0)-x2(t0),t0]} ≤ J*[x1(t0),t0]+J*[x2(t0),t0]

故条件(2)得证。

综上所述：J*[x(t0),t0]具体形式

J*[x(t0),t0]=x^T(t0)P(t0)x(t0) (6.2-4)

以任意时刻 t 为初始时刻，则有 J*[x(t),t]=x^T(t)P(t)x(t)

## 二 P(t)为 Riccati 方程的解

用 H-J 方程证明

状态方程 x(t)=[x(t),u(t),t]

性能指标 J=S[x(t_f),t_f]+∫_{t0}^{t_f} L[x(t),u(t),t]dt

则 H-J 方程为

-∂J*/∂t = H*[x(t),∂J*/∂x,t]
H*[x(t),∂J*/∂x,t]=min_{u∈U} H[x(t),x(t),∂J*/∂x,t]

其中 H[x(t),u(t),λ,t]=L[x(t),u(t),t]+λ^T f(x,u,t) (λ=∂J*/∂x)

⇒ ∂J*[x(t),t]/∂t = -min_{u∈U}{L[x(t),u(t),t]+(∂J*/∂x)^T f[x(t),u(t),t]} (6.2-5)

本章具体问题

L[x(t),u(t),t]=x^T(t)Q(t)x(t)+u^T(t)R(t)u(t)
f[x(t),u(t),t]=A(t)x(t)+B(t)u(t)
∴ J*[x(t),t]=x^T(t)P(t)x(t)

故有 ∂J*[x(t),t]/∂t = x^T(t)Ṗ(t)x(t), ∂J*[x(t),t]/∂x = 2P(t)x(t)

代入式(6.2-5)得

x^T(t) Ṗ(t) x(t) = - min_{u(t)} { x^T(t) Q(t) x(t) + u^T(t) R(t) u(t) + 2 x^T(t) P(t) A(t) x(t) + 2 x^T(t) P(t) B(t) u(t) } = - min_{u(t)} { [u(t) + R^{-1}(t) B^T(t) P(t) x(t)]^T R(t) [u(t) + R^{-1}(t) B^T(t) P(t) x(t)] } + x^T [Q(t) - P(t) B(t) R^{-1}(t) B^T(t) P(t) + P(t) A(t) + A^T(t) P(t)] x(t) } (6.2-6)

R(t) 正定, 为满足 (6.2-6) 式 显然有 u(t) + R^{-1}(t) B^T(t) P(t) x(t) = 0 即 u* = -R^{-1}(t) B^T(t) P(t) x(t) (6.2-7)

将 (6.2-7) 代入 (6.2-6) x^T(t) Ṗ(t) x(t) = -x^T(t) [Q(t) - P(t) B(t) R^{-1}(t) B^T(t) P(t) + P(t) A(t) + A^T(t) P(t)] x(t)

由 x(t) 为任意时刻可得 -Ṗ(t) = P(t) A(t) + A^T(t) P(t) - P(t) B(t) R^{-1}(t) B^T(t) P(t) + Q(t) (6.2-8) 即为 Riccati 方程

边界条件: 由 H-J 方程的边界条件 J*[x(T), T] = S[x(T), T] 在本章 S[x(T), T] = x^T(T) F x(T) ⇒ P(T) = F (6.2-9)

## 三 最优控制指标 J*[x(t), t] 的存在性

方程 (6.2-8) 和 (6.2-9) 式对所有 t ≤ T 确定了 P(t), 且最优指标 J*[x(t), t] = x^T(t) P(t) x(t) 对所有 t ≤ T 存在。

## 四 最优控制 u* = -R^{-1}(t) B^T(t) P(t) x(t) (6.2-10)

是 一线性反馈控制规律。

## 五 调节器问题的解

初始时间 t 和初始状态 x(t) 的调节器问题, 其最优性能指标是 J*[x(t), t] = x^T(t) P(t) x(t), 最优控制为 (6.2-10). 其中 P(t) 为满足 (6.2-8) 和 (6.2-9) 的解, 且对所有 t ≤ T 存在。

## 六 举例

设状态方程为 ẋ = 1/2 -x + u 性能指标为 J* = ∫_{t0}^{T} (2 e^{-t} u^2 + 1/2 e^{-t} x^2) dt

解: Riccati 方程为:

\begin{cases} -\dot{P} = P - \frac{1}{2} e^{t} P^{2} + \frac{1}{2} e^{-t}, \\
 P(T)=0 \end{cases}

\Rightarrow P(t)=(1-e^{-t})(e^{t} + e^{2t} e^{-t})^{-1}

U^{*}(t)=-\frac{1}{2}(1-e^{-t})(1+e^{t})^{-1}x(t)

J^{*}[x(t_{0}),t_{0}]=x(t_{0})(1-e^{-t_{0}})(e^{t_{0}}+e^{2t_{0}}e^{-t_{0}})^{-1}x(t_{0})

# § 6.3 无限时状态调节器 (T → ∞)

## 一 无限时间调节器问题

考虑系统

\dot{x}(t)=A(t)x(t)+B(t)u(t) \quad x(t_{0})=x_{0} \text{给定} \quad (6.3-1)

定义性能指标为

J[x(t_{0}),u(t),t_{0}]=\int_{t_{0}}^{T}[x^{T}(t)Q(t)x(t)+u^{T}(t)R(t)u(t)]dt \quad (6.3-2)

求最优控制 u^{*}(t),t≥t_{0}, 使J最小, 并且求 J^{*}[x(t_{0}),t_{0}].

其中 \{A(t),B(t)\}的元素是连续函数. 且 Q(t) 为非负定对称矩阵

Q(t), R(t) 为正定对称矩阵

考察系统

\begin{bmatrix} \dot{x}_{1} \\ \dot{x}_{2} \end{bmatrix} = \begin{bmatrix} x_{1} \\ x_{2} \end{bmatrix} + \begin{bmatrix} 0 \\ 1 \end{bmatrix} u \quad \begin{bmatrix} x_{1}(t_{0}) \\ x_{2}(t_{0}) \end{bmatrix} = \begin{bmatrix} x_{1} \\ 0 \end{bmatrix}

R=1, Q=\begin{bmatrix} 1 & 0 \\ 0 & 0 \end{bmatrix}

易得 J[x(t_{0}),u(t),t_{0}]=\int_{t_{0}}^{\infty}(u^{2}+e^{2t})dt \quad 无论 u(t) 取何值, J\to\infty

结论: 对有限时间问题，最优 J 是有限的, 但对无限时间问题未必如此. J\to\infty 原因:

- 1. 状态 x_1 是不可控的.
- 2. 系统轨线的不可控部分被反映 (x_1(t)=e^t ) 是不稳定的.
- 3. 系统轨线的... 反映在 J 中.

如上述原因之一不存在, 则不会产生 J 为无穷大的难题.

为保证问题分解, 需作如下假定

假定 6.3.1 系统(6.3-1)对每一时间 t 完全可控的.

## 一 无限时调节器问题的求解

设 P(t,T) 为方程 ...

则 x(t)P(t,T)x(t)=P_{ii}(t,T)
⇒ 得P_{ii}(t,T)存在极限，即所有P(t,T)的对角元素存在极限

另外，对 x(t)=e_i+e_j    (i≠j)
2P_{ij}(t,T)=(e_i+e_j)^T P(t,T)(e_i+e_j)−P_{ii}(t,T)−P_{jj}(t,T)
因上式右边对 T→∞ 都存在极限。
故 P_{ij}(t,T) 也存在极限。

结论：P(t,T) 存在极限，即 \overline{P}(t)=\lim_{T→∞}P(t,T)

## 2. \overline{P}(t) 为 Riccati 方程(6.3-7)的一个解：

记 P(t,T,F) 为满足 P(T)=F 的方程(6.3-7)的解
令 P(t,T) 表示的是 P(T,T)=0 的解，即 P(t,T)=P(t,T,0)
由式(6.3-2)得

J^T[x(t),t]=∫_t^T [x^T(τ)Q(τ)x(τ)+J(τ)R(τ)u(τ)]dτ
=u(•)*u(•)
= x^T(t)P(t,T,0)x(t)
=∫_t^{T1}[x^T(τ)Q(τ)x(τ)+u^T(τ)R(τ)u(τ)]dτ
+∫_{T1}^T[x^T(τ)Q(τ)x(τ)+u^T(τ)R(τ)u(τ)]dτ
=u(•)*u(•)
=∫_t^{T1}[x^T(τ)Q(τ)x(τ)+u^T(τ)R(τ)u(τ)]dτ + x^T(T1)P(T1,T,0)x(T1)
= x^T(t)P(t,T1,P(T1,T,0))x(t)
(6.3-8)
因此有： x^T(t)P(t,T,0)x(t)=x^T(t)P(t,T1,P(T1,T,0))x(t)

由 X(t) 的任意性 ⇒ P(t,T,0)=P(t,T1,P(T1,T,0))   (6.3-9)
对 t≤T1≤T,上式成立，故有 \overline{P}(t)=\lim_{T→∞}P(t,T,0)=\lim_{T→∞}P(t,T1,P(T1,T,0))

上式表明：对于固定的时间 T1，式(6.3-3)的解 P(t,T1,F) 连续地依赖于 F，因此有
\overline{P}(t)=P(t,T1,\lim_{T→∞}P(T1,T,0))
= P(t,T1,\overline{P}(T1))
即证明了，\overline{P}(t) 是对所有 t 定义的方程(6.3-3)的一个解
