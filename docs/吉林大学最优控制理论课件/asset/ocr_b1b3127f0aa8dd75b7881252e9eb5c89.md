条件(1)  J*[λx(t₀), t₀] ≤ J*[x(t₀), λu*(t₀), t₀] = λ²J*[x(t₀), t₀]
最优控制性质
由(6.1-4)
λ²J*[x(t₀), t₀] ≤ λ²J*[x(t₀), λ⁻¹u*(t), t₀] = J*[λx(t₀), t₀]
显然，条件(1)得证。
条件(2) 令
J*[x₁(t₀), t₀] = J[x₁(t₀), u₁*(t), t₀] = ½ x₁ᵀ(T)Fx₁(T) + ½ ∫ₜ₀ᵀ [x₁ᵀ(t)Q(t)x₁(t) + u₁*ᵀ(t)R(t)u₁*(t)] dt
J*[x₂(t₀), t₀] = J[x₂(t₀), u₂*(t), t₀] = ½ x₂ᵀ(T)Fx₂(T) + ½ ∫ₜ₀ᵀ [x₂ᵀ(t)Q(t)x₂(t) + u₂*ᵀ(t)R(t)u₂*(t)] dt
状态方程变量也做相应的变化
J*[x₁(t₀), t₀] + J*[x₂(t₀), t₀] ≤ ¼{J*[2x₁(t₀), t₀] + J*[2x₂(t₀), t₀]} 由条件(1)
(6.2-3)
J*[2x₁(t₀), t₀] ≤ J[2x₁(t₀), u₁*(t) + u₂*(t), t₀]
= ½ {4x₁ᵀ(T)Fx₁(T) + ∫ₜ₀ᵀ [4x₁ᵀ(t)Q(t)x₁(t) + (u₁*ᵀ(t) + u₂*ᵀ(t))R(t)(u₂*(t) + u₂*(t))] dt}
(令 x(t)=2x₁(t))
J*[2x₂(t₀), t₀] ≤ J[2x₂(t₀), u₁*(t) - u₂*(t), t₀]
= ½ {4x₂ᵀ(T)Fx₂(T) + ∫ₜ₀ᵀ [4x₂ᵀ(t)Q(t)x₂(t) + (u₁*ᵀ(t) - u₂*ᵀ(t))R(t)(u₂*(t) - u₂*(t))] dt}
(令 x(t)=2x₁(t))
上两式相加
J*[2x₁(t₀), t₀] + J*[2x₂(t₀), t₀] ≤ 2x₁ᵀ(T)Fx₁(T) + 2x₂ᵀ(T)Fx₂(T)
+ 2∫ₜ₀ᵀ [x₁ᵀ(t)Q(t)x₁(t) + ½ u₁*ᵀ(t)R(t)u₁*(t)] dt
+ 2∫ₜ₀ᵀ [x₂ᵀ(t)Q(t)x₂(t) + ½ u₂*ᵀ(t)R(t)u₂*(t)] dt
= [x₁ᵀ(T) + x₂ᵀ(T)]F[x₁(T) + x₂(T)]
+ ∫ₜ₀ᵀ {[x₁ᵀ(T) + x₂ᵀ(T)]Q(t)[x₁(t) + x₂(t)] + u₁*ᵀ(t)R(t)u₁*(t)} dt
+ [x₁ᵀ(T) - x₂ᵀ(T)]F[x₁(T) - x₂(T)]
+ ∫ₜ₀ᵀ {[x₁ᵀ(T) - x₂ᵀ(T)]Q(t)[x₁(t) - x₂(t)] + u₂*ᵀ(t)R(t)u₂*(t)} dt
= 2J*[x₁(t₀) + x₂(t₀), t₀] + 2J*[x₁(t₀) - x₂(t₀), t₀]
