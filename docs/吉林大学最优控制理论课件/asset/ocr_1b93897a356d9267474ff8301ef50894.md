u* = { -1 当 x1 > -1/2 x2 |x2| ; +1 当 x1 < -1/2 x2 |x2| ; -sgn{x2} 当 x1 = -1/2 x2 |x2| }

最短转移时间 T* = (x1, x2)

T* = (x1, x2) = { x2 + sqrt(4x1 + 2x2^2) 当 x1 > -1/2 x2 |x2| ; -x2 + sqrt(-4x1 + 2x2^2) 当 x1 < -1/2 x2 |x2| ; |x2| 当 x1 = -1/2 x2 |x2| }

由上式可知，最短时间 T* (即 J*) 是初始状态 x1, x2 的连续函数，但不是处处可微的。如 x2 = -2 的直线为初始点集，T* 与 x1 的关系为
