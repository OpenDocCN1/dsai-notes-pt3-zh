# 图 4.18

R₁ = {(x₁,x₂): x₁ ≥ -½ x₂|x₂|, |x₁| > -(ρ+4)/(2ρ) x₂|x₂|}

R₂ = {(x₁,x₂): x₁ < -½ x₂|x₂|, |x₁| ≥ -(ρ+4)/(2ρ) x₂|x₂|}

R₃ = {(x₁,x₂): x₁ ≤ -½ x₂|x₂|, |x₁| < -(ρ+4)/(2ρ) x₂|x₂|}

R₄ = {(x₁,x₂): x₁ > -½ x₂|x₂|, |x₁| ≤ -(ρ+4)/(2ρ) x₂|x₂|}

综上所述，问题 4.9 的时间—燃料最优控制规律

u*(t) = +1    当 (x₁,x₂) ∈ R₃

u*(t) = -1    当 (x₁,x₂) ∈ R₁

u*(t) = 0      当 (x₁,x₂) ∈ R₂ ∪ R₄

讨论：当 ρ → ∞ 时，β₋₀ 与 γ₊ 重合 ⇒ 时间最优控制

当 ρ = 0 时，β₊₀ 与 γ₋ 重合 ⇒ 燃料最优控制
