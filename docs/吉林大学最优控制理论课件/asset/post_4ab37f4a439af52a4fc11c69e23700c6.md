## § 1.2 最优控制的数学模型

### 一 控制系统的数学模型（集中参数系统）

直接法建立：动力学、运动学的基本规律，即解析法。

间接法建立：通过“辨识”的途径确定系统的结构与参数。

其中 x(t)=f(x(t),u(t),t)

其中 x(t)=[x_1(t),x_2(t),⋯,x_n(t)]^T , u(t)=[u_1(t),u_2(t),⋯,u_r(t)]^T , f=[f_1,f_2,⋯,f_n]

x(t)为n维状态向量，u(t)为r维控制向量，f为n维函数向量。

### 二 目标集

通过u(t)使x(t)由x(t_0)到x(t_f)，其中x(t_0)为初始状态，并且通常为已知；x(t_f)为终端状态，即控制所要求达到的目标。一般来说对终端状态的要求可用如下的约束条件表示：

g_1(x(t_f),t_f)=0，g_2(x(t_f),t_f)≤0。

### 三 容许控制

u_i具有不同的物理属性，一般有|u_i|≤α，i=1,2,⋯,r，即在控制域U内。凡在闭区间[t_0,t_f]上有定义，且控制域U内取值的每一个控制函数u(t)均为容许控制。

### 四 性能指标

主要取决于问题所要解决的主要矛盾。

表达式为：

J[u(·)] = S(x(t_f),t_f) + \int_{t_0}^{t_f} L(x,u,t) dt

其中x(t)是动态系统起始于x(t_0)=x_0，对应于u(t)的状态轨线。x(t_f)是此轨线在终端时刻的值。

### 五 最优控制的提法

受控系统的状态方程及给定的初始

x(t)=f(x(t),u(t),t), x(t_0)=x_0

规定的目标集为

M = {x(t_f): x(t) ∈ R^n , g_1(x(t_f),t_f)=0 , g_2(x(t_f),t_f) ≤ 0}

# 第二章 变分法及其在最优控制中的应用

## §2.1 变分法的基本概念

### 一 泛函

对于某一类函数集合中的每一个函数 y(x)，均有一个确定的数 J 与之对应，那么就称 J 为依赖于函数 y(x) 的泛函，记作

J = J[y(x)]，或简称 J

其中 y(x) 称为泛函的宗量（自变量）。

### 二 容许函数类（空间）

满足一定条件的一类函数称为泛函的容许函数类（空间）。

例：所有在区间[a,b]上连续函数的全体是一个函数空间，记 C[a,b]。

所有在区间[a,b]上连续且一阶可微函数的全体是一个函数空间，记 C¹[a,b]。

所有在区间[a,b]上连续且二次可微函数的全体是一个函数空间，记 C²[a,b]。

### 三 泛函的极值

最简单的一类函数

J[y] = ∫ₐᵇ F(x, y, y') dx

对任一条与 y = y₀(x) 接近的曲线上，有

J[y(x)] − J[y₀(x)] ≥ 0

则称 J[y(x)] 在曲线 y₀(x) 上达到极小值。

#### 1. 接近定义

两个函数具有零阶接近度：

|y(x) − y₀(x)| ≤ ε, (x₁ ≤ x ≤ x₂)

两个函数具有一阶接近度：

|y(x) − y₀(x)| ≤ ε, (x₁ ≤ x ≤ x₂)， |y'(x) − y₀'(x)| ≤ ε, (x₁ ≤ x ≤ x₂)

当 y(x) 为函数空间的一个点时，接近度可用点距来表示：

零阶距离 d₀(y, y₀) = max_{x∈[a,b]} |y(x) − y₀(x)|

记为

δJ = L[y(x), δy(x)]

也称为泛函的微分。

### 引理 2.1 泛函 J[y(x)] 的变化

δJ = ∂/∂α J[y(x) + αδy(x)]|_{α=0}

### 定理 2.1 若可微泛函 J[y(x)] 在 y₀(x) 上达到极小（大）值，则在 y = y₀(x) 上有

δJ = 0

例 求泛函

J = ∫ₓ₀ˣ¹ F(x, y(x), ẏ(x)) dx

的变分。

δJ = ∂/∂α J[y(x) + αδy(x)]|_{α=0} = ∫ₓ₀ˣ¹ ∂/∂α F[x, y + αδy, ẏ + αδẏ]|_{α=0} dx

= ∫ₓ₀ˣ¹ [∂F(x,y,ẏ)/∂y δy + ∂F(x,y,ẏ)/∂ẏ δẏ] dx

在上例中应用了宗量变分的导数等于导数变分的性质，即 (δẏ)' = δẏ。

## §2.2 欧拉方程

变分法是研究泛函极值的一种方法，为古典变分法。

拉格朗日问题：求一容许函数 x(t)，使泛函

J = ∫ₜ₀ᵗ¹ F(t, x(t), ẋ(t)) dt

取最小值。

下面利用泛函 J[x(t)] 达到极值的必要条件：δJ = 0，导出欧拉方程。

### 引理：设连续函数 M(t) 对于任一具有下述性质的函数 η(t)

1. 在 [t₀, t₁] 上，η(t) 连续；
2. η(t₀) = η(t₁) = 0，

总有

∫ₜ₀ᵗ¹ M(t) η(t) dt ≡ 0

则对于 t ∈ [t₀, t₁]，有 M(t) = 0。

### 定理：若最简单的泛函

J[x(t)] = ∫_{t0}^{tf} F(t, x(t), ẋ(t)) dt ; x(t0) = x0, x(tf) = xf

在曲线 x = x(t) 处达到极值，则 x = x(t) 必为欧拉方程

F_x - d/dt F_ẋ = 0

的解。

证明 因为泛函 J[x(t)] 在 x = x(t) 处达到极值，所以有

δJ = ∫_{t0}^{tf} (F_x δx + F_ẋ δẋ) dt = 0

其中 δx(t0) = δx(tf) = 0

而 ∫_{t0}^{tf} F_ẋ δẋ dt = F_ẋ δx|_{t0}^{tf} - ∫_{t0}^{tf} δx d/dt (F_ẋ) dt = -∫_{t0}^{tf} δx d/dt (F_ẋ) dt

代入得

δJ = ∫_{t0}^{tf} (F_x - d/dt F_ẋ) δx dt = 0

由引理可得

F_x - d/dt F_ẋ = 0

还可写成

F_x - F_{tẋ} - ẋ F_{xẋ} - ẍ F_{ẋẋ} = 0

欧拉方程是二阶常微分方程。两个积分常数由两个边界条件确定。

例 求泛函

J[x(t)] = ∫_{0}^{π/2} (ẋ² - x²) dt

满足边界条件 x(0)=0, x(π/2)=1 的极值曲线。

解 F = ẋ² - x²，欧拉方程为

F_x - d/dt F_ẋ = -2x - 2ẍ = 0

求得 x = C₁ cos t + C₂ sin t，由边界条件可得 C₁ = 0, C₂ = 1。故得极值曲线为 x = sin t。

含有多个未知函数的变分问题

J[X] = ∫_{t0}^{tf} F(t, X, Ẋ) dt

其中 X(t) = [x₁(t), x₂(t), ..., xₙ(t)]^T

有相似结论

F_X - d/dt F_Ẋ = 0

边界条件为 X(t₀) = X₀, X(t_f) = X_f。

## §2.3 条件极值的变分问题

问题：求泛函 J = \int_{t_0}^{t_f} F(t,x(t),\dot{x}(t))dt 在约束条件

f(t,x,\dot{x}) = 0, f = [f_1,f_2,\cdots,f_m]^T

下，满足边界条件 x(t_0)=x_0, x(t_f)=x_f 的极值。

求解步骤：

1. 作系统 J₀ = \int_{t_0}^{t_f} [F(t,x(t),\dot{x}(t)) + \lambda^T f(t,x(t),\dot{x}(t))]dt

其中向量 λ^T(t) = [λ₁(t),λ₂(t),⋯,λ_m(t)]

2. 解欧拉方程

H_x - \frac{d}{dt}H_{\dot{x}} = 0

其中 H = F(t,x(t),\dot{x}(t)) + \lambda^T f(t,x(t),\dot{x}(t))

将欧拉方程与约束方程联立求解，可得 x(t) 和 λ(t)，积分常数由边界条件确定。

## §2.4 在一点处的变分

积分中值定理：

f(x) 连续，φ(x) 在 [a,b] 上不变号且可积，则有 ξ 满足

\int_a^b f(x)φ(x)dx = f(ξ)\int_a^b φ(x)dx, a ≤ ξ ≤ b

下面建立泛函 J = \int_{t_0}^{t_f} F(t,x,\dot{x})dt 在一点 t̄ 处的变分概念如下：

设 x = x(t) 与 x̄ = x̄(t) 都属于 C¹[t₀,t₁]，且 x̄(t) = x(t) + δx(t)

其中这样选取 δx(t)：

- (1) δx(t) ∈ C¹[t₀,t₁]
- (2) δx(t) 非零值在 t̄ 的邻域 (t̄−δ, t̄+δ) 之内，0 在 t̄ 的邻域 (t̄−δ, t̄+δ) 之外

且 δx(t) 保持定号。
