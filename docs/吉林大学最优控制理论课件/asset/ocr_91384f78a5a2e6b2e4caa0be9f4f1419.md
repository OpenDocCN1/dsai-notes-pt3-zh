则 x(t)P(t,T)x(t)=P_{ii}(t,T)
⇒ 得P_{ii}(t,T)存在极限，即所有P(t,T)的对角元素存在极限

另外，对 x(t)=e_i+e_j    (i≠j)
2P_{ij}(t,T)=(e_i+e_j)^T P(t,T)(e_i+e_j)−P_{ii}(t,T)−P_{jj}(t,T)
因上式右边对 T→∞ 都存在极限。
故 P_{ij}(t,T) 也存在极限。

结论：P(t,T) 存在极限，即 \overline{P}(t)=\lim_{T→∞}P(t,T)

# 2. \overline{P}(t) 为 Riccati 方程(6.3-7)的一个解：

J^T[x(t),t]=∫_t^T [x^T(τ)Q(τ)x(τ)+J(τ)R(τ)u(τ)]dτ

(6.3-8)
