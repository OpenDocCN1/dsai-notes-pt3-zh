# 例 1. 已知方程线性定常系统
 ẋ(t)=A x(t)+B u(t), x(0)=x0, A n×n, B n×m, u(t) 不受约束
 求一控制 u(x(t)), 使
 J = 1/2 ∫0^∞ [x^T Q x + γ u^T u] dt = min Q 为非负定对称常数矩阵, γ 是一正数。

(1) H 函数→ H(x,u,λ,t)=1/2 x^T Q x + 1/2 γ u^2 + λ^T A x + λ^T B u
 H 的最小值 ∂H/∂u = γ u + B^T λ =0
 ⇒ u* = -γ^{-1} B^T λ

代入 H 中, H*(x,λ,t)=1/2 x^T Q x + λ^T A x -1/2 λ^T B B^T λ γ^{-1}
 因受控是定常的, Q, γ 是常数阵及常数, 积分时间为无穷大。
 ⇒ 故知 J* 只依赖于初态, 与 t 无关 ⇒ ∂J*/∂t =0

(2) H-J 方程为 1/2 x^T Q x + (∂J*/∂x)^T A x -1/2 [ (∂J*/∂x)^T B ]^2 γ^{-1}=0

令上式解为 J*[x(t)]=1/2 x^T P x ⇒ ∂J*/∂x = P x
