J[x(t)] = ∫_{t0}^{tf} F(t, x(t), ẋ(t)) dt ; x(t0) = x0, x(tf) = xf

在曲线 x = x(t) 处达到极值，则 x = x(t) 必为欧拉方程

F_x - d/dt F_ẋ = 0

的解。

证明 因为泛函 J[x(t)] 在 x = x(t) 处达到极值，所以有

δJ = ∫_{t0}^{tf} (F_x δx + F_ẋ δẋ) dt = 0

其中 δx(t0) = δx(tf) = 0

而 ∫_{t0}^{tf} F_ẋ δẋ dt = F_ẋ δx|_{t0}^{tf} - ∫_{t0}^{tf} δx d/dt (F_ẋ) dt = -∫_{t0}^{tf} δx d/dt (F_ẋ) dt

代入得 δJ = ∫_{t0}^{tf} (F_x - d/dt F_ẋ) δx dt = 0

由引理可得 F_x - d/dt F_ẋ = 0

还可写成 F_x - F_tẋ - ẋ F_xẋ - ẍ F_xẋ = 0

欧拉方程是二阶常微分方程。两个积分常数由两个边界条件确定。

例 求泛函 J[x(t)] = ∫_{0}^{π/2} (ẋ² - x²) dt

满足边界条件 x(0)=0, x(π/2)=1 的极值曲线。

解 F = ẋ² - x²,

欧拉方程为 F_x - d/dt F_ẋ = -2x - 2ẍ = 0

求得 x = C1 cos t + C2 sin t, 由边界条件可得 C1 = 0, C1 = 1。 故得极值曲线为 x = sin t。

含有多个未知函数的变分问题 J[X] = ∫_{t0}^{tf} F(t, X, Ẋ) dt

其中 X(t) = [x1(t), x2(t), ..., xn(t)]^T

有相似结论 F_X - d/dt F_Ẋ = 0

边界条件为 X(t0) = X0, X(tf) = Xf。
