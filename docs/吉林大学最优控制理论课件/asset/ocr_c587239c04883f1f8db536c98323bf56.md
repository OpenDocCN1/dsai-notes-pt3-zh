Ẋ*(t)=f[X*(t),U*(t)]

Ẋ*(t)+ΔẊ(t)=f[X*(t)+ΔX(t),U*(t)+ΔU(t)]
ΔẊ(t)=f[X*(t)+ΔX(t),U*(t)+ΔU(t)]−f[X*(t),U*(t)]
=f[X*(t),U*(t)+ΔU(t)]+∂f[X(t),U(t)]/∂X^T |_{X=X*}^{U=U*+ΔU}·ΔX(t)+o(|ΔX(t)|)−f[X*(t),U*(t)]
=∂f[X*(t),U*(t)]/∂X^T·ΔX(t)+{f[X*(t),U*(t)+ΔU(t)]−f[X*(t),U*(t)]}
+{∂f[X*(t),U*(t)+ΔU(t)]/∂X^T−∂f[X*(t),U*(t)]/∂X^T}ΔX(t)+o(|ΔX(t)|)

(3.2-2)

令 Φ(t,τ) 为线性方程 ΔẊ(t)=∂f[X*(t),U*(t)]/∂X^T ΔX(t) (3.2-3)
的状态转移矩阵，则有 { dΦ(t,τ)/dt = ∂f[X*(t),U*(t)]/∂X^T Φ(t,τ) ; Φ(τ,τ)=I } (3.2-4)

因为 ΔX(t)→0，故方程(3.2-2)的解为
ΔX(t)=∫_{t0}^{t} Φ(t,τ){f[X*(τ),U*(τ)+ΔU(τ)]−f[X*(τ),U*(τ)]}dτ
+∫_{t0}^{t} Φ(t,τ){∂f[X*(τ),U*(τ)+ΔU(τ)]/∂X^T−∂f[X*(τ),U*(τ)]/∂X^T}ΔX(τ)dτ
+∫_{t0}^{t} Φ(t,τ)·o(|ΔX(τ)|)dτ (3.2-5)
