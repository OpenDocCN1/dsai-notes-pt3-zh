λ_{n_s}(t_f) - λ_{n_s}(t) = -∫_{t}^{t_f} ∂H(X,λ,U,τ)/∂τ dτ

式(3.3-7)可化为 H[X*(t),λ(t),U*(t),t] = H[X*(t_f),λ(t_f),U*(t_f),t_f] + ∫_{t_f}^{t} ∂H(X,λ,U,τ)/∂τ dτ

证明条(ⅴ)。
结论：

+   ①比较定理 3.2 与定理 3.1，非定常性并没有改变最大值原理中规范方程、横截条件及极值条件；
+   ②不同之处在于
+   1. 在最优轨线末端 H 值不同；
+   2. 沿最优轨线 H 值不同。
+   定常情况为常数，非定常系统不是常数。
+   ③条件(5)不是最优控制的最优条件，i ~ iv 才是最必要条件。

# 二 积分型性能指标

定理 3.3 设 U(t)∈U 是一容许控制，指定积分型性能指标泛函为 J[U(·)] = ∫_{t0}^{t_f} L[X(t),U(t)] dt

X(t) 是定常系统 Ẋ = f(X,U)，X(t0)=X0，t∈[t0,t_f]，t_f 未定 对应于 U(t) 的轨线。

则当 U*(t) 和 t_f* 为性能指标 J 取最小值的最优解，X*(t) 是对应的最优轨线。必存在 n 维向量函数 λ(t)，使 U*(t)、t_f*、X*(t) 和 λ(t) 满足如下条件：

(i) X(t)、λ(t) 满足是规范方程 Ẋ = ∂H(X,U,λ)/∂λ f(X,U)，X(t0)=X0  λ̇ = -∂H(X,U,λ)/∂X 其中，H(X,λ,U)=L(X,U)+λ^T f(X,U)

(ii) 在最优轨线末端满足横截条件，即 λ(t_f)=0 亦称自然边界条件。

(iii) H 作为 U(t)∈U 的函数，在 U(t)=U*(t) 时取绝对极小，即 H[X*(t),λ(t),U*(t)] = min_{U(t)∈U} H[X*(t),λ(t),U(t)]

(iv) 在最优轨线的末端 H 应满足 H[X*(t),λ(t),U*(t)] = H[X*(t_f),λ(t_f),U*(t_f)] = 0，t_f 未定；
