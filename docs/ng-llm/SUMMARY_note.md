# 吴恩达大模型系列课程教程 📚

在本教程中，我们将系统性地学习吴恩达教授及其团队发布的一系列关于大语言模型与生成式AI的核心课程。课程内容涵盖从基础概念、提示工程、应用开发到高级微调技术的完整知识体系，旨在帮助初学者构建扎实的理论基础和实践能力。

## 课程一：面向所有人的生成式AI 🤖

在本课程中，我们将要学习生成式AI的基本定义、核心原理、广泛应用场景以及其作为通用技术的深远影响。

### 1. 什么是生成式AI - 了解其定义、应用与影响
生成式AI是一种能够创造新内容的人工智能，例如文本、图像、代码或音乐。它通过学习现有数据的模式来生成新颖且合理的输出。

### 2. 什么是生成式AI - 原理和指南
生成式AI的核心原理基于概率模型，预测序列中下一个最可能出现的元素。其工作流程可以概括为：**输入提示 (Prompt) -> 模型处理 -> 生成输出 (Completion)**。

### 3. 什么是生成式AI - 大语言模型作为思考助手
大语言模型可以作为强大的思考助手，帮助人类进行头脑风暴、梳理逻辑和激发创意。它们通过补全和扩展人类的初始想法来辅助思考。

### 4. 什么是生成式AI - AI是一种通用技术
与电力或互联网类似，生成式AI是一种“通用技术”，具有广泛的应用潜力，能够渗透并改造众多行业和领域，而不仅仅是单一用途的工具。

### 5. 生成式AI应用 - 写作
在写作场景中，生成式AI可以帮助起草邮件、创作故事、润色文本甚至生成诗歌。一个简单的代码示例如下：
```python
# 示例：使用API调用模型进行文本续写
response = model.generate(prompt="请帮我写一封会议邀请函的开头：")
```

### 6. 生成式AI应用 - 阅读
对于阅读，AI可以快速总结长篇文档、提取关键信息、翻译不同语言的内容，或者回答关于文档内容的特定问题。

### 7. 生成式AI应用 - 聊天
聊天应用是生成式AI最直观的体现，能够进行多轮、上下文相关的对话，提供客户服务、陪伴或信息咨询。

### 8. 生成式AI应用 - 大语言模型的能力与局限
大语言模型虽然强大，但也有其局限，例如可能产生“幻觉”（编造事实）、存在知识截止日期、以及无法进行真正的逻辑推理。

### 9. 生成式AI应用 - 高效提示词撰写技巧
撰写高效的提示词是发挥模型能力的关键。技巧包括：指令清晰、提供示例（Few-shot）、指定输出格式、以及进行迭代优化。

### 10. 生成式AI应用 - 图像生成
除了文本，生成式AI在图像领域同样出色，能够根据文字描述生成、编辑或修复图像，其核心公式可以表示为：**图像 = G(文本描述, 随机噪声)**。

**总结**：本节课我们一起学习了生成式AI的基础概念、多样化的应用场景以及其作为通用技术的特性，并初步了解了如何通过提示词与AI有效交互。

## 课程二：ChatGPT提示词工程师 ✍️

上一节我们介绍了生成式AI的应用，本节中我们来看看如何通过专业的提示词工程来精确引导模型行为，实现更复杂、更可靠的任务。

### 第1集 引言
提示词工程是一门通过精心设计输入文本来优化大语言模型输出的技术和艺术。

### 第2集 指南
有效的提示通常包含清晰的指令、必要的上下文、以及期望的输出格式。以下是构建提示的基本原则：
*   **原则一**：编写清晰、具体的指令。
*   **原则二**：给模型充足的“思考”时间（例如通过分步指令）。

### 第3集 迭代
开发好的提示词是一个迭代过程。很少有一次成功的情况，需要根据模型的输出反复调整和优化提示词。

### 第4集 摘要
摘要任务要求模型将长文本浓缩为简短的核心内容。关键技巧是指定摘要的长度、风格和焦点。

### 第5集 推理
推理任务涉及让模型进行逻辑推断、情感分析或原因解释。可以通过“思维链”提示来提升推理能力，即要求模型**分步推理**。

### 第6集 转换
转换任务包括翻译、格式转换、语气调整等。需要明确指定源格式、目标格式及任何特殊要求。

### 第7集 扩展
扩展是指根据简短的提示或开头，让模型生成更长的文本，如邮件、文章或报告。需要提供足够的种子内容和风格指引。

### 第8集 聊天机器人
构建聊天机器人需要管理对话历史（记忆），使模型能理解上下文。其系统设计通常包含：**系统消息（设定角色） + 对话历史 + 用户最新查询**。

### 第9集 总结
提示词工程的核心在于通过结构化、迭代式的沟通，将人类意图准确传达给模型，从而解锁大语言模型在各种任务上的潜力。

**总结**：本节课我们一起学习了提示词工程的核心原则与六大常见任务（摘要、推理、转换、扩展、聊天），掌握了通过迭代优化来控制模型输出的方法论。

## 课程三：基于LangChain的大语言模型应用开发 ⛓️

掌握了提示词基础后，我们将进入应用开发层面。本节课程将学习如何使用LangChain框架来构建功能丰富的大模型应用。

### 1——介绍
LangChain是一个用于开发由大语言模型驱动的应用程序的框架。它通过提供模块化组件，简化了构建复杂应用链的过程。

### 2——模型，提示和输出解析
LangChain抽象了与不同模型（如OpenAI， Anthropic）的交互，统一了提示模板管理，并提供了输出解析器来将模型返回的非结构化文本转换为结构化数据。

### 3——记忆
为了让应用在对话中记住上下文，LangChain提供了多种记忆组件，如对话缓冲区记忆，其核心是维护一个**消息列表**作为历史记录。

### 4——链
链是将多个组件（模型、提示、工具等）按顺序组合起来的工作流。例如，一个简单的链可以是：**检索文档 -> 组织提示 -> 调用模型 -> 解析输出**。

### 5——基于文档的问答
这是LangChain的经典用例。系统从外部文档中检索相关信息，并将其作为上下文提供给模型来回答问题，从而超越模型本身的知识限制。

### 6——评估
评估应用效果至关重要。可以通过人工评估、基于模型的评估（让另一个AI评分）或使用精确率/召回率等指标来衡量检索和生成的质量。

### 7——代理
代理是具备自主决策能力的组件，它可以动态选择和使用工具（如计算器、搜索引擎API）来完成用户请求。其决策逻辑可表示为：**思考（Thought） -> 行动（Action） -> 观察（Observation）** 的循环。

### 8——总结
LangChain通过其模块化设计，极大地加速了大模型应用的开发流程，使开发者能够专注于业务逻辑而非底层集成。

**总结**：本节课我们一起学习了LangChain的核心模块——模型I/O、记忆、链、检索问答、评估和代理，理解了如何利用该框架构建端到端的大语言模型应用。

## 课程四：LangChain：构建与数据对话的聊天机器人 🤖💬

上一节我们学习了LangChain的基础，本节我们将深入一个具体场景：构建一个能够查询和分析私人或企业文档的智能聊天机器人。

### 1——介绍
与数据对话的聊天机器人允许用户用自然语言查询非结构化的文档数据（如PDF、Word），获得精准的答案。

### 2——文档加载
第一步是加载各种格式的文档。LangChain提供了`DocumentLoader`，支持从文本、PDF、CSV、网页等多种源加载内容。

### 3——文档分割
大语言模型有上下文长度限制，因此需要将长文档分割成更小的块（Chunks）。常用的分割方法包括按字符、递归按分隔符或按标记（Token）分割。

### 4——向量和嵌入
为了快速检索，需要将文本块转换为机器可理解的数值形式，即向量（嵌入）。嵌入模型（如`text-embedding-ada-002`）会将语义相似的文本映射到向量空间中相近的点。相似度通常用**余弦相似度**计算。

### 5——检索
当用户提问时，系统将问题也转换为向量，并在向量数据库中搜索与之最相似的文本块。这个过程称为“检索”，它返回最相关的文档片段作为生成答案的上下文。

### 6——问答聊天机器人
将检索到的上下文与用户问题一起构造成提示，发送给大语言模型，从而生成答案。这就是检索增强生成（RAG）的基本流程。

### 7——完整功能的聊天机器人
一个完整的系统还需要集成对话记忆、处理多轮问答、并可能包含来源引用（显示答案出自哪个文档块）等功能。

### 8——完结
通过结合文档加载、分割、向量化、检索和生成，我们成功构建了一个能够理解私有数据并智能回答问题的聊天机器人。

**总结**：本节课我们一起学习了构建基于RAG的文档问答机器人的完整技术栈，从原始文档处理到向量检索，再到最终的答案生成与对话管理。

## 课程五：大模型微调 🔧

当预训练模型或提示工程无法满足特定需求时，我们需要对模型本身进行定制。本节课程将学习大模型微调的核心知识与实践。

### 1-介绍
微调是在预训练大模型的基础上，使用特定领域或任务的数据进行额外训练，使模型适应新需求的过程。

### 2-为什么要微调
微调的主要目的是提升模型在特定任务上的性能、适应特殊的输出格式、注入领域知识，以及用更少的提示词获得更稳定的输出。

### 3-微调在训练过程中的位置
微调位于整个训练流程的下游。完整流程是：**预训练（海量通用数据） -> 指令微调/对齐（指令数据） -> 特定任务微调（高质量小数据）**。

### 4-指令微调
指令微调使用（指令， 输出）配对的数据集来训练模型，使其更好地理解和遵循人类的指令。其损失函数关注于根据指令生成正确输出。

### 5-准备数据
准备高质量、格式一致的微调数据至关重要。数据通常需要被整理成如JSONL格式，每条数据包含“指令”和“期望输出”字段。

### 6-训练过程
微调训练过程会更新模型的部分或全部参数。关键超参数包括学习率、训练轮次和批次大小。代码框架（如Hugging Face Transformers）简化了这一过程。

### 7-评估和迭代
微调后需要使用验证集评估模型效果。根据评估结果，可能需要收集更多数据、调整数据质量或修改超参数，进行迭代优化。

### 8-建议和实用技巧
实用技巧包括：从高质量提示工程开始、优先收集更多数据、使用参数高效微调技术以节省成本，以及进行彻底的评估。

### 9-总结
微调是使大语言模型适应专业化、定制化需求的强大手段，需要精心准备数据、执行训练并持续评估迭代。

**总结**：本节课我们一起学习了微调的意义、流程、数据准备、训练方法以及评估迭代的完整周期，掌握了定制化大模型的关键技术。

## 课程六：构建高级RAG应用 🚀

基础的RAG系统可能面临检索不准、答案不精等问题。本节课程将学习如何构建和评估更先进、更健壮的RAG应用。

### 1. 开篇 - 介绍
高级RAG应用通过优化检索和生成环节的各个组件，旨在提升答案的准确性、相关性和实用性。

### 2. 第一篇 - 先进的RAG管道
一个先进的RAG管道可能包含查询转换、混合检索、重排序和答案合成等步骤，比基础RAG更复杂、更强大。

### 3. 第二篇 - RAG指标三元组
评估RAG系统需要从三个核心维度（指标三元组）考量：**上下文相关性**、**答案忠实度**和**答案相关性**。

### 4. 第三篇 - 句子窗口检索
这是一种检索策略，先检索最相关的单个句子，然后将其前后相邻的句子（窗口）作为上下文提供给模型，以提高上下文的连贯性和精确性。

### 5. 第四篇 - 自动合并检索
另一种策略是构建文档的层次结构（如段落->章节），检索时先找到相关父节点，再自动合并其所有子节点内容作为上下文，确保信息完整性。

### 6. 终篇 - 结论
构建高级RAG应用是一个系统工程，需要根据具体场景选择合适的检索策略、优化组件并持续用三元组指标进行评估，以追求最佳效果。

**总结**：本节课我们一起学习了超越基础RAG的高级技术，包括复杂的处理管道、核心的评估指标以及句子窗口和自动合并等先进的检索策略。
