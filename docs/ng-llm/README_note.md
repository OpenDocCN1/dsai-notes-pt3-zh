# 吴恩达大模型教程笔记 01：大模型基础 🧠

在本节课中，我们将要学习大语言模型（LLM）的核心概念和工作原理。我们将从最基础的“预测下一个词”任务开始，逐步理解模型如何通过海量数据学习，并最终生成连贯的文本。

## 概述

大语言模型的核心是一个基于概率的文本生成器。它的基本任务是：给定一段已有的文本（称为“上下文”或“提示”），预测接下来最有可能出现的词是什么。这个过程不断重复，从而生成长篇文本。

## 核心机制：预测下一个词

上一节我们介绍了大模型的基本任务，本节中我们来看看它是如何完成“预测下一个词”的。

模型通过分析海量的文本数据，学习词语之间的统计规律和关联。例如，在“今天天气很___”这个上下文中，模型根据学习到的模式，会计算出“好”、“晴朗”、“糟糕”等词出现的概率，并选择概率最高的一个作为输出。

从技术角度看，模型计算的是一个条件概率分布：
**P(下一个词 | 上下文)**
即，在给定上下文的前提下，词汇表中每一个词作为下一个词出现的概率。

## 模型是如何训练的

理解了预测任务后，一个自然的问题是：模型如何获得这种预测能力？答案是通过训练。

训练大模型需要两个关键要素：
1.  **海量数据**：模型从互联网、书籍、文章等文本中学习。
2.  **学习目标**：让模型预测的下一个词尽可能准确。

训练过程可以简化为以下步骤：
1.  给模型输入一段文本。
2.  让模型尝试预测这段文本中每一个位置的下一个词。
3.  将模型的预测与真实的文本进行比较，计算误差（损失）。
4.  通过优化算法（如梯度下降）调整模型内部的参数，以减少这个误差。
5.  在数十亿甚至数万亿的词元上重复此过程。

以下是训练过程中的一个简化示例：

```python
# 假设模型看到句子：“猫坐在垫子上”
输入上下文: “猫坐在”
模型预测下一个词: 它可能会为“垫子”、“地板”、“那里”等词分配高概率。
真实的下一个词: “垫子”
# 模型根据预测与真实的差异来更新自身参数。
```

## 关键概念：提示与生成

经过训练后，模型就可以为我们所用了。使用模型主要涉及两个阶段：提示（输入）和生成（输出）。

**提示** 是我们提供给模型的初始文本或指令。模型的生成完全基于对提示的理解和延续。提示的质量和内容直接影响生成结果的相关性和质量。

**生成** 是模型根据提示自动续写文本的过程。生成不是一次性输出一整段话，而是循环进行“预测下一个词”的过程，将新生成的词不断追加到上下文中，作为预测下一个词的新依据。

以下是使用模型时的一个典型流程：
1.  **编写提示**：用户输入“请写一首关于春天的五言诗。”
2.  **模型处理**：模型理解指令，并开始预测符合“五言诗”格式和“春天”主题的词序列。
3.  **文本生成**：模型输出：“春风吹绿柳，细雨润红花。”
4.  **迭代继续**：如果需要更长的文本，可以将已生成的部分作为新的上下文，继续让模型生成。

## 总结

本节课中我们一起学习了大型语言模型的基础知识。我们了解到，大模型本质上是一个强大的“下一个词预测器”，它通过在海量文本数据上进行训练，掌握了语言的内在规律。我们探讨了其核心机制 **P(下一个词 | 上下文)**，并解释了模型通过训练获得知识的过程。最后，我们介绍了如何使用模型，即通过“提示”来引导模型“生成”我们所需的文本。理解这些基础概念是后续探索大模型能力与应用的第一步。
