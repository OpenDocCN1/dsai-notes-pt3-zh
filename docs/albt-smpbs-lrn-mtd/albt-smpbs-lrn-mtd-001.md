# 001：课程介绍

![](img/d1e094db7d930487f1f9e8f92c810aa4_1.png)

## 概述

在本节课中，我们将要学习基于样本的学习方法。这类方法的核心是让智能体仅通过试错交互和经验来学习世界如何运作，而无需依赖一个预设的世界模型。我们将从蒙特卡洛方法开始，逐步深入到时序差分学习等强化学习的基础算法。

## 课程内容结构

上一节我们回顾了强化学习的基础，本节中我们来看看本课程的具体安排。本课程将遵循与第一门课程相似的结构，但聚焦于从经验样本中学习的方法。

以下是本课程将涵盖的三个主要部分：

1.  **预测**：学习价值函数的方法。
2.  **控制**：学习动作价值函数以实现控制的方法。
3.  **规划**：讨论如何使用已学习的模型进行规划。

## 核心方法与概念

我们将首先介绍蒙特卡洛方法。之后，我们将讨论时序差分方法如何同样应用于预测和控制问题。

我们将看到像 **Sarsa** 和 **Q-learning** 这样的TD控制方法，是如何与广义策略迭代和贝尔曼算子联系起来的。在此过程中，我们会重点探讨**探索**问题，这在试错交互学习中至关重要。

您还将接触到**离策略学习**，这是从经验中学习的关键环节。本课程将以 **Dyna** 架构作为结尾，这是一个集规划、学习和行动于一体的综合架构。

我们也会讨论在使用可能不准确的学习模型进行规划时，所产生的一些新问题。

## 学习设置与后续课程

本课程（第二门课）将深入探讨在线学习算法的理论基础，这些基础贯穿于整个强化学习领域。目前，我们暂时继续在**表格型设置**下进行学习，即假设状态和动作空间是有限的，并学习一个价值表格。

在第三门课程中，我们将把在线算法扩展到**函数逼近**的设置中。但即便在当前这个简化的表格设置下，我们仍有大量的问题需要讨论和解决。

## 总结

本节课中我们一起学习了《基于样本的学习方法》这门课程的整体介绍。我们了解到，本课程将专注于让智能体从经验样本中学习，无需环境模型，涵盖从预测、控制到规划的完整路径，并会深入探讨蒙特卡洛、时序差分等核心算法。让我们继续强化学习理论与实践的探索之旅。
