## 图像识别背景与目标检测定义

上一节我们介绍了课程的整体安排，本节中我们来看看目标检测技术所处的背景。

图像识别是计算机视觉的基础任务，旨在让计算机理解图像内容。目标检测是图像识别的一个重要分支，它不仅需要识别图像中存在哪些物体，还需要定位出每个物体的具体位置。

目标检测的技术历史可以追溯到早期的模板匹配方法，随着机器学习的发展，出现了基于特征（如HOG、SIFT）的方法。深度学习的兴起，特别是卷积神经网络（CNN）的应用，极大地推动了目标检测技术的进步，使其在精度和速度上都有了质的飞跃。

## 目标检测的应用场景与算法原理铺垫

目标检测技术已广泛应用于各个领域。以下是其主要应用场景：

*   **自动驾驶**：检测车辆、行人、交通标志等。
*   **安防监控**：进行人脸识别、异常行为检测。
*   **医疗影像分析**：辅助定位病灶区域。
*   **零售与仓储**：实现商品识别、库存盘点，这也是本课程实践项目的重点。
*   **无人机与机器人**：用于环境感知与导航。

为了理解后续的算法，我们需要先了解一些核心概念。目标检测的核心任务是**分类**与**定位**。分类是判断区域内是什么物体，定位则是用边界框（Bounding Box）标出物体的位置。边界框通常用其中心点坐标（x, y）、宽度（w）和高度（h）来描述，公式为：`BBox = [x_center, y_center, width, height]`。

## 目标检测任务描述与早期模型（Overfeat）

一个典型的目标检测任务可以描述为：给定一张输入图像，算法需要输出一系列检测结果，每个结果包含被检测物体的类别标签以及一个包围该物体的矩形框坐标。

在深度学习目标检测算法的发展初期，Overfeat模型是一个重要的里程碑。它创新性地将CNN应用于多尺度滑动窗口检测，共享了特征提取的计算，提高了效率，为后来的区域提议类方法（如R-CNN系列）提供了思路。

# 🔍 课程02：两阶段检测算法精讲（R-CNN, SPP-Net, Fast R-CNN, Faster R-CNN）

在本节课中，我们将深入剖析两阶段目标检测算法的代表：R-CNN系列及其改进模型。两阶段算法的核心思想是“先找候选区域，再对区域进行分类和精修”。

## R-CNN：开创性的两阶段检测框架

R-CNN是第一个成功将深度学习应用于目标检测的算法，其流程清晰，奠定了两阶段检测的基础。

### R-CNN步骤流程介绍

R-CNN的检测流程分为四个核心步骤：
1.  **候选区域生成**：使用选择性搜索（Selective Search）算法从输入图像中提取约2000个可能包含物体的候选区域（Region Proposal）。
2.  **特征提取**：将每个候选区域缩放到固定大小（如227x227），然后分别输入一个预训练好的CNN（如AlexNet）中，提取出固定长度的特征向量。
3.  **分类**：将每个区域提取出的特征向量输入到一系列类别特定的线性SVM分类器中，判断该区域属于哪个类别或背景。
4.  **边界框回归**：使用线性回归模型对候选区域的边界框进行微调，使其更紧密地包围物体。

### 候选区域与特征提取

选择性搜索通过合并相似的超像素区域来生成候选框，力求覆盖所有可能的物体位置。每个候选区域被独立地通过CNN进行前向传播，在最后一个全连接层获得特征。这个过程计算开销很大，因为2000个区域需要2000次CNN前向传播。

### SVM分类器与非极大抑制（NMS）

对于每个类别，R-CNN训练一个独立的二元SVM分类器来区分该类别和背景。所有候选区域经过SVM打分后，会得到大量重叠的检测框。

非极大抑制（NMS）是后处理的关键步骤，用于去除冗余框。其原理是：对于每个类别，按置信度得分排序，保留得分最高的框，然后计算其他所有框与该框的重叠面积（IoU）。如果IoU超过设定阈值（如0.5），则抑制（删除）得分较低的框。这一过程迭代进行，伪代码如下：
```python
def nms(boxes, scores, threshold):
    keep = []
    order = scores.argsort()[::-1]
    while order.size > 0:
        i = order[0]
        keep.append(i)
        iou = calculate_iou(boxes[i], boxes[order[1:]])
        inds = np.where(iou <= threshold)[0]
        order = order[inds + 1]
    return keep
```

### 候选区域修正（边界框回归）

边界框回归旨在对候选框的位置和大小进行精细调整。模型学习一个从候选框特征到真实框（Ground Truth）偏移量的映射。对于候选框P=(P_x, P_y, P_w, P_h)和目标框G=(G_x, G_y, G_w, G_h)，需要学习的变换是四个偏移量：`t_x = (G_x - P_x)/P_w`, `t_y = (G_y - P_y)/P_h`, `t_w = log(G_w/P_w)`, `t_h = log(G_h/P_h)`。

### 训练与测试过程及总结

R-CNN训练分多步进行：先预训练CNN（在ImageNet分类任务上），然后在候选区域上对CNN进行微调（将其视为一个21类——20个物体类+背景——的分类问题），接着训练SVM分类器，最后训练边界框回归器。

R-CNN的优点是精度较传统方法有巨大提升。但其缺点也非常明显：
*   **训练多阶段**：流程繁琐，需要单独训练CNN、SVM和回归器。
*   **训练耗时耗内存**：需要从每个候选区域提取特征并存储到磁盘。
*   **推理速度极慢**：测试一张图片需要数十秒，因为每个区域都要独立经过CNN。

## SPP-Net：共享计算，提升效率

上一节我们分析了R-CNN效率低下的问题，本节中我们来看看SPP-Net是如何通过空间金字塔池化层来解决这一问题的。

SPP-Net的核心改进是**在整个图像上只进行一次CNN特征提取**，然后通过映射关系，将原始图像上的候选区域映射到最后一层卷积特征图上对应的区域。

### 与R-CNN的区别及网络流程

与R-CNN为每个区域单独计算特征不同，SPP-Net先对整图进行卷积，得到整张特征图。对于任意一个候选区域，根据其在原图的位置，通过比例关系直接映射到特征图上的对应区域（称为特征窗口）。

### SPP层的作用

映射得到的特征窗口形状各异，而全连接层需要固定长度的输入。SPP层（空间金字塔池化层）被引入来解决这个问题。它对任意大小的特征窗口进行池化，输出固定长度的特征向量。

SPP层使用多尺度池化：例如，将特征窗口分别划分为4x4, 2x2, 1x1个网格，在每个网格内进行最大池化，然后将所有结果拼接起来，形成一个固定长度（如`(16+4+1)*256`）的特征向量。这样，不同大小的区域经过SPP层后，都能得到统一维度的输出，从而送入后续的全连接层。代码逻辑如下：
```python
# 伪代码示意
def spatial_pyramid_pooling(feature_map, levels=[4,2,1]):
    pooled_features = []
    for level in levels:
        h, w = feature_map.shape[1:3]
        pool_size_h = ceil(h / level)
        pool_size_w = ceil(w / level)
        pooled = max_pooling(feature_map, [pool_size_h, pool_size_w])
        pooled_features.append(pooled.flatten())
    return concatenate(pooled_features)
```

SPP-Net大幅提升了速度（比R-CNN快数十倍），因为特征提取只做一次。但它仍然存在一些不足：训练依然是多阶段的，并且SPP层之前的卷积层在微调时难以更新，因为反向传播通过SPP层较复杂。

## Fast R-CNN：整合流程，端到端训练

Fast R-CNN在SPP-Net的基础上进一步革新，提出了RoI Pooling层，并将分类和回归任务合并，实现了端到端的训练。

### 改进之处与网络流程

Fast R-CNN的输入是整个图像和一组候选区域。网络首先通过若干卷积层和池化层处理整张图像，生成卷积特征图。然后，对于每个候选区域，使用RoI Pooling层从特征图上提取固定大小的特征向量。该特征向量随后被送入一系列全连接层，最终分支成两个输出层：一个输出K+1个类别的softmax概率（K个物体类+背景），另一个输出K+1个类别对应的边界框回归偏移量。

### RoI Pooling结构与SPP对比

RoI Pooling可以看作是SPP层的特例，它只使用一个尺度的划分（例如7x7）。其操作是将任意大小的候选区域特征窗口均匀划分为HxW（如7x7）个网格，然后在每个网格内进行最大池化，从而得到固定大小（HxW）的输出。这简化了计算，并使得梯度可以通过RoI Pooling层进行反向传播。其前向过程需要记录最大值所在位置（argmax），以便在反向传播时能将梯度只传回该位置。

### 多任务损失

Fast R-CNN使用一个多任务损失函数进行联合训练，该损失函数由分类损失和回归损失加权求和构成：
`L(p, u, t^u, v) = L_cls(p, u) + λ[u≥1] L_loc(t^u, v)`
其中：
*   `L_cls(p, u) = -log(p_u)` 是真实类别u的对数损失。
*   `L_loc` 是边界框回归的平滑L1损失，仅对非背景目标（u≥1）计算。`t^u`是网络预测的偏移量，`v`是真实偏移量。
*   `λ`是平衡两个损失的权重参数。

Fast R-CNN将特征提取、分类、回归整合到一个网络内，通过多任务损失进行端到端训练，大大简化了训练流程，并提高了检测精度和速度。但它的候选区域仍然依赖于外部算法（如Selective Search），这成为性能瓶颈。

## Faster R-CNN：引入RPN，实现完全端到端

Faster R-CNN的里程碑式贡献在于提出了区域提议网络（RPN），将候选区域生成这一步骤也融入到神经网络中，实现了真正意义上的端到端目标检测系统。

### 网络结构与步骤

Faster R-CNN的网络结构可以看作是两个模块的集成：**RPN** 和 **Fast R-CNN检测模块**。它们共享基础的卷积特征。
1.  **共享卷积层**：输入图像经过一组基础卷积网络（如VGG-16的conv layers），生成共享特征图。
2.  **RPN**：在共享特征图的每个滑动窗口位置上，生成多个不同尺度和长宽比的锚框（anchors），并预测每个锚框是“物体”的得分以及对应的边界框偏移量。输出一组高质量的候选区域（Proposals）。
3.  **RoI Pooling**：将RPN生成的候选区域映射到共享特征图上，通过RoI Pooling层得到固定大小的特征。
4.  **检测网络**：与Fast R-CNN一样，对每个候选区域进行分类和边界框精修。

### RPN网络的原理

RPN是Faster R-CNN的核心。它在共享特征图上滑动一个小型网络（如3x3卷积），该滑动窗口对应的特征被映射到一个低维向量（如256-d）。这个向量被输入到两个并列的全连接层：
*   **分类层（cls layer）**：输出每个锚框是前景（物体）和背景的2个分数。
*   **回归层（reg layer）**：输出每个锚框对应的4个边界框偏移量（相对于锚框本身）。

**锚框（Anchor）** 是预先定义在图像上的一组基准框，具有不同的尺度和长宽比（如128x128, 256x256, 512x512三种面积，每种面积有1:1, 1:2, 2:1三种比例，共9种锚框）。RPN的任务就是判断这些锚框中哪些可能包含物体，并如何调整它们以更好地匹配物体。

Faster R-CNN通过引入RPN，统一了候选区域生成和物体检测 within a single, end-to-end trainable network，在保持高精度的同时显著提升了速度，成为两阶段检测算法的标杆。

本节课中我们一起深入学习了从R-CNN到Faster R-CNN的两阶段检测算法演进历程。我们看到了算法如何从耗时的多阶段流水线，逐步发展为高效、集成的端到端网络。下一节课，我们将转向另一类思路迥异但速度更快的算法：单阶段检测器。

# ⚡ 课程03：单阶段检测算法精讲（YOLO, SSD）与第一阶段总结

在本节课中，我们将学习单阶段目标检测算法的代表：YOLO和SSD。这类算法摒弃了“候选区域”的步骤，直接在图像上进行密集预测，因此通常速度更快，适合实时应用。

## YOLO：统一的实时检测框架

YOLO（You Only Look Once）的核心思想是将目标检测视为一个单一的回归问题，直接从图像像素映射到边界框坐标和类别概率。

### 算法特点与流程介绍

YOLO的设计非常直接。它将输入图像划分为SxS（如7x7）的网格。每个网格负责预测中心点落在该网格内的物体。每个网格预测B个边界框以及这些框的置信度分数，同时预测C个类别概率。最终，模型将预测编码为一个 `S x S x (B*5 + C)` 的张量。其流程可以概括为：单次前向传播 → 得到所有预测 → 后处理（NMS）。

### 单元格原理过程

假设S=7, B=2, C=20（PASCAL VOC数据集）。那么每个网格需要预测的信息包括：
*   对于每个边界框（共2个）：4个坐标值（x, y, w, h）和1个置信度（confidence）。置信度定义为 `Pr(Object) * IOU(pred, truth)`，即该框包含物体的概率乘以预测框与真实框的IOU。
*   20个条件类别概率：`Pr(Class_i | Object)`，即在该网格包含物体的前提下，属于每个类别的概率。

在测试时，将条件类别概率与每个框的置信度相乘，就得到每个框对于每个类别的“类别特定置信度”，它同时体现了该类别的概率和框的定位准确度：
`Class-specific confidence score = Pr(Class_i | Object) * Pr(Object) * IOU = Pr(Class_i) * IOU`

### 训练过程样本标记

在训练时，需要将真实标注框分配给特定的网格和锚点。对于每个真实框，其中心点落在哪个网格，就由哪个网格负责预测。该网格预测的B个边界框中，选择与真实框IOU最大的那个作为“正样本”，负责预测该物体。其他框则被视为负样本。这种分配策略使得每个物体通常只由一个网格的一个边界框预测器负责，有助于预测器的专业化。

YOLO的优势在于速度极快，能够达到实时检测。但由于每个网格只能预测有限数量的物体，且对物体的尺度变化、小物体检测以及不常见长宽比的物体检测能力较弱。

## SSD：多尺度特征图的单阶段检测器

SSD（Single Shot MultiBox Detector）在YOLO思想的基础上，引入了**多尺度特征图预测**和**默认框（Default Boxes，类似Faster R-CNN的锚框）** 的概念，显著提升了检测精度，尤其是对小物体的检测能力。

### 网络结构与检测结构

SSD基于一个前馈卷积网络（如VGG-16，截断到conv5_3层），在其后添加了一系列逐渐变小的辅助卷积层。**检测不仅发生在最后的特征图上，而是发生在这些不同尺度的多个特征图上**。较大的特征图（分辨率高）用于检测小物体，较小的特征图（分辨率低）用于检测大物体。

在每个用于检测的特征图上，使用一组卷积滤波器进行预测。对于每个特征图位置，预测相对于该位置默认框的偏移量以及各类别的置信度。

### 定位与置信度

与YOLO类似，SSD的每个预测输出包含两部分：
1.  **定位偏移（localization offsets）**：4个值，表示对默认框的中心点（cx, cy）和宽高（w, h）的调整。公式与Faster R-CNN的边界框回归类似。
2.  **类别置信度（confidence）**：对于每个类别（包括背景），输出一个置信度分数。在PASCAL VOC中，是21个分数（20类+背景）。

### 训练与测试流程总结

SSD的训练涉及将真实框匹配到默认框。对于每个真实框，从所有默认框中选择IOU最大的，以及那些IOU超过阈值（如0.5）的默认框作为正样本。这种多对一的匹配策略比YOLO更宽松，使得学习更容易。损失函数也是分类损失（Softmax Loss）和定位损失（Smooth L1 Loss）的加权和。

在测试时，网络在所有特征图的所有位置上进行前向传播，得到大量的预测框。然后通过置信度阈值过滤和NMS后处理，得到最终的检测结果。

SSD在速度和精度之间取得了很好的平衡，是单阶段检测器中的经典之作。TensorFlow提供了官方的SSD模型接口，方便研究者使用和部署。

## 第一阶段算法总结

至此，我们已经完成了对经典目标检测算法的学习。以下是核心算法的对比与总结：

*   **R-CNN系列（两阶段）**：
    *   **思想**：先产生候选区域，再对区域进行分类和精修。
    *
