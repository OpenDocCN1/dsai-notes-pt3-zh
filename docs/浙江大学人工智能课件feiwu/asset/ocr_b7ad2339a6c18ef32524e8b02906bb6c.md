# # Multiple classes

+   - Single K-class discriminant comprising K linear functions:

\(y_k(\mathbf{x})=\mathbf{w}_k^\mathrm{T}\mathbf{x}+w_{k0}\)

+   - assigning a point x to class C<sub>k</sub> if y<sub>k</sub>(x) > y<sub>j</sub>(x) for all j ≠ k.

+   - decision boundary between class C<sub>k</sub> and class C<sub>j</sub> is given by y<sub>k</sub>(x) = y<sub>j</sub>(x)

\((\mathbf{w}_k-\mathbf{w}_j)^\mathrm{T}\mathbf{x}+(w_{k0}-w_{j0})=0\)

+   - R<sub>k</sub> is singly connected and convex.

![](bbox=[0.098, 0.518, 0.371, 0.771])

\(\widehat{\mathbf{x}}=\lambda\mathbf{x}_\mathrm{A}+(1-\lambda)\mathbf{x}_\mathrm{B}\quad\text{where }0\leqslant\lambda\leqslant 1\)
\(y_k(\widehat{\mathbf{x}})=\lambda y_k(\mathbf{x}_\mathrm{A})+(1-\lambda)y_k(\mathbf{x}_\mathrm{B})\)

Because both x<sub>A</sub> and x<sub>B</sub> lie inside R<sub>k</sub>,
it follows that y<sub>k</sub>(x<sub>A</sub>) > y<sub>j</sub>(x<sub>A</sub>)
y<sub>k</sub>(x<sub>B</sub>) > y<sub>j</sub>(x<sub>B</sub>), for all j ≠ k,
and hence y<sub>k</sub>(x̂) > y<sub>j</sub>(x̂),
and so x̂ also lies inside R<sub>k</sub>.

Illustration of the decision regions for a multiclass linear discriminant, with the decision boundaries shown in red. If two points x<sub>A</sub> and x<sub>B</sub> both lie inside the same decision region R<sub>k</sub>, then any point x̂ that lies on the line connecting these two points must also lie in R<sub>k</sub>, and hence the decision region must be singly connected and convex.
