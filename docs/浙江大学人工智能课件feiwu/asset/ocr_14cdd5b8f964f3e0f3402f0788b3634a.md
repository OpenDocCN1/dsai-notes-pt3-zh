# # Sequential learning

+   • Batch gradient descent:

\(\mathbf{w}^{(\tau+1)} = \mathbf{w}^{(\tau)} - \eta\nabla E_D(\mathbf{w})\)

\(E_D(\mathbf{w}) = \frac{1}{2} \sum_{n=1}^N \{t_n - \mathbf{w}^T \phi(\mathbf{x}_n)\}^2 = \frac{1}{2} \|\mathbf{t} - \Phi \mathbf{w}\|^2\)

\(let \, J(w) = E_D(w), \qquad \nabla J(w) = -\Phi^T(t - \Phi w)\)

\(w^{(\tau+1)} = w^{(\tau)} + \eta \Phi^T(t - \Phi w^{(\tau)})\)

\(if \, w^{(\tau+1)} = w^{(\tau)}, \, then \, \eta \Phi^T(t - \Phi w^{(\tau)}) = 0,\)

\(w^{(\tau)} = (\Phi^T \Phi)^{-1} \Phi^T \, t\)
