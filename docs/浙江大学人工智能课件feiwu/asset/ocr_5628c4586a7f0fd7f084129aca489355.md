+   - Given a training set \(\{(x_1,t_1),\dots,(x_N,t_N)\}\), learning problem is to construct a "good" function \(y(x)\) from these.
+     - \(y: \mathbb{R}^{784} \rightarrow \mathbb{R}^{10}\)
