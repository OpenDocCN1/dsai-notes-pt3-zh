# # Well-defined problems and solutions

+   - Problem definition:

+   1. **Initial state**: The initial state that the agent starts in. For example, the initial state for our agent in Romania might be described as _In(Arad)_.

+   2. **Actions**: A description of the possible actions available to the agent. Given a particular state _s_, _ACTIONS(s)_ returns the set of actions that can be executed in _s_. We say that each of these actions is applicable in _s_. For example, from the state _In(Arad)_, the applicable actions are {_Go(Sibiu), Go(Timisoara), Go(Zerind)_}.
