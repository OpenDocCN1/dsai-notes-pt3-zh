# # Basic notation

+   - Random variable and rules of probability
+     - Sum rule (marginal)
+   
+     $$p(X)=\sum_Y p(X,Y)$$
+   
+     - Product rule (joint)
+   
+     $$p(X,Y)=p(Y|X)p(X)$$
+   
+     - Bayes's theorem
+   
+     $$p(Y|X)=\frac{p(X|Y)p(Y)}{p(X)}$$
