Output size:

**(N - F) / stride + 1**

e.g. N = 7, F = 3:

stride 1 => (7 - 3)/1 + 1 = 5  
stride 2 => (7 - 3)/2 + 1 = 3  
stride 3 => (7 - 3)/3 + 1 = 2.33 :\
