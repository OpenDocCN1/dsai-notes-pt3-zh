# # The perceptron algorithm

+   • Construct a generalized linear model:

\(y(\mathbf{x}) = f\left(\mathbf{w}^\mathrm{T}\phi(\mathbf{x})\right)\qquad f(a) = \left\{\begin{array}{ c c }
+1, & a \geqslant 0 \\
-1, & a < 0
\end{array}\right.\)

![](bbox=[0.668, 0.065, 0.973, 0.465])

We therefore consider an alternative error function known as the _perceptron criterion_. To derive this, we note that we are seeking a weight vector **w** such that patterns **x**_<sub>n</sub>_ in class C<sub>1</sub> will have **w**<sup>T</sup>φ(**x**_<sub>n</sub>_) > 0, whereas patterns **x**_<sub>n</sub>_ in class C<sub>2</sub> have **w**<sup>T</sup>φ(**x**_<sub>n</sub>_) < 0. Using the _t_ ∈ {-1,+1} target coding scheme it follows we would like all patterns to satisfy **w**<sup>T</sup>φ(**x**_<sub>n</sub>_)_t<sub>n</sub>_ > 0. The perceptron criterion associates zero error with any pattern that is correctly classified, whereas for a misclassified pattern **x**_<sub>n</sub>_ it tries to minimize the quantity -**w**<sup>T</sup>φ(**x**_<sub>n</sub>_)_t<sub>n</sub>_. The perceptron criterion is therefore given by

+   • Perceptron criterion (need to be minimized):

\(E_\mathrm{P}(\mathbf{w}) = -\sum_{n\in\mathcal{M}}\mathbf{w}^\mathrm{T}\phi_n t_n\)

where M denotes the set of all misclassified patterns. The contribution to the error associated with a particular misclassified pattern is a linear function of **w** in regions of **w** space where the pattern is misclassified and zero in regions where it is correctly classified. The total error function is therefore piecewise linear.
