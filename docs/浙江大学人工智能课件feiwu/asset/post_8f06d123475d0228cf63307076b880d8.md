### Backpropagation: a simple example

f(x, y, z) = (x + y)z

e.g. x = -2, y = 5, z = -4

f(x,y,z)=(x+y)z

e.g. x=-2, y=5, z=-4

q=x+y   ∂q/∂x=1, ∂q/∂y=1

f=qz   ∂f/∂q=z, ∂f/∂z=q
