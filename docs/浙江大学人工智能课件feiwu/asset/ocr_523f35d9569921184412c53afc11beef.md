# # Nearest-neighbor methods

+   - KNN classifier

\(p(x|C_k) = \frac{K_k}{N_k V}\)
\(p(C_k) = \frac{N_k}{N}\)
\(p(x) = \frac{K}{NV}\)
\(\Rightarrow p(C_k|x) = \frac{p(x|C_k)p(C_k)}{p(x)} = \frac{K_k}{K}\)

\(p(C_1|x) = 1\)

\(p(C_2|x) = 1\)
