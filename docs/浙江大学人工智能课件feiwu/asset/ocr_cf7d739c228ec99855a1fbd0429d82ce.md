# # Three classification approaches

+   - Generative approach:
+     - Model the class-conditional densities and the class priors
+     - Compute posterior probabilities through Bayes's theorem

Compare the probability of the input under separate, class-specific, generative models

Model both the class conditional densities p(x|Ck), and the prior class probabilities p(Ck)

Compute posterior using Bayes' theorem

p(Ck|x) = p(x|Ck)p(Ck) / p(x) = p(x|Ck)p(Ck) / Σj p(x|Cj)p(Cj)

+   - Discriminative approach:
+     - Directly training posterior probabilities.
+     - Discriminative Approach: Model p(Ck|x), directly, for example by representing them as parametric models, and optimize for parameters using the training set (e.g. logistic regression).
