# # Expectations and Covariances

# ## the Variance of the Sum of Two Independent Random Variables is the Sum of the Variances

Imagine two such random variables X and Y.

| X   | probability   |
|-----|---------------|
| x₁  | p₁            |
| x₂  | p₂            |
| ... | ...           |
| xₙ  | pₙ            |

| Y   | probability   |
|-----|---------------|
| y₁  | q₁            |
| y₂  | q₂            |
| ... | ...           |
| yₘ  | qₘ            |

Since X and Y are independent random variables, the probability of X
taking on the value xᵢ and Y the value yⱼ is simply the product pᵢqⱼ.

Var(X + Y) = Σᵢⱼpᵢqⱼ(xᵢ + yⱼ - μₓ - μᵧ)²
= Σᵢⱼpᵢqⱼ(xᵢ - μₓ)² + Σᵢⱼpᵢqⱼ(yⱼ - μᵧ)² + 2Σᵢⱼpᵢqⱼ(xᵢ - μₓ)(yⱼ - μᵧ)
= (Σⱼqⱼ) Var(X) + (Σᵢpᵢ) Var(Y) + 2 (Σᵢpᵢ(xᵢ - μₓ)) (Σⱼqⱼ(yⱼ - μᵧ))
= 1 · Var(X) + 1 · Var(Y) + 2 · 0 · 0
= Var(X) + Var(Y).
