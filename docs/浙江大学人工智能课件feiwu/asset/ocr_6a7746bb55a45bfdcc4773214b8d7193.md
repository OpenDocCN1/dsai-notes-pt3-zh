# # Example: Polynomial curve fitting

+   - Error function:
+     - SSE (sum-of-square) error

\( E(\mathbf{w}) = \frac{1}{2} \sum_{n=1}^{N} \{ y(x_n, \mathbf{w}) - t_n \}^2 \)

+   - RMS (root-mean-square) error

\( E_\text{RMS} = \sqrt{2E(\mathbf{w}^*)/N} \)
