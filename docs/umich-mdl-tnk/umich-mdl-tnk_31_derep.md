# 译者的话

现在到处都在谈大数据，热度令人眼花缭乱。可是热闹背后，很多时候我们只是被这股浪潮卷着走。光有数据远远不够，关键是如何让数据开口说话，把信息提炼出来，再把信息沉淀成真正能用的知识。归根结底，每个人都需要一套属于自己的看世界、想问题的框架。斯科特·佩奇这本新作，就为此给出了清晰的方向——多模型思维。

佩奇本身就是个典型的跨界高手，书里涉及的模型横跨多个学科，有的相当精深，但他总能把复杂的东西讲得通透易懂。早在《多样性红利》里，他就论证过群体智慧能让决策变好；这次他把这个观点走到了实操层面，告诉我们如何真正拿到多样性的红利：搭建多个模型，让它们像一个思考共同体一样一起工作。这本书本质上就是一整套可用的方法箱。只要你愿意去尝试做一个会用模型的思考者，这里一定能带给你不少收获。

同时也需要拉紧警戒线。市场上充斥着“只要猛敲数据，数据就会开口”之类的说法，我们得保持清醒。佩奇写作的底层逻辑和学术根基不能丢，他是复杂性科学领域的顶尖人物，已经能把繁杂化为简约。模型的作用，就是帮助普通人也能像大师一样去思考。但这绝不意味着要把真实世界简化。我们不能以为埋一支温度计就能读懂整颗星球的体温。相反，模型思维的出发点恰恰是正视世界的复杂。书中反复强调的多模型范式，说白了就是另一种形式的复杂性表达。

还要特别感谢汪丁丁教授、叶航教授、罗卫东教授的点拨，我对复杂性科学的兴趣正是源于他们。此外，何永勤、虞伟华、余仲望、鲍玮玮、傅晓燕、傅锐飞、陈叶烽、童乙伦、罗俊、邓昊力、陈姝、黄达强、李燕、李欢、丁玫、何志星等朋友，也都给予了我宝贵的帮助，在此一并致谢。

这是我承接的佩奇的第二部作品。佩奇的文字简洁而饱满，纯粹却又充满张力，有一种让人上头的吸引力，翻泽起来格外顺手顺心，这样的体验实属难得。感谢湛庐文化与简学提供的这次机会。

书中难免有疏漏，还请各位专家与读者批评指正。
