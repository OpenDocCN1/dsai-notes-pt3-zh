+   - JavaScript is used extensively in the browser
+   - Single web-page applications are possible
+     - Entire page need not be refreshed
+     - Browser interacts with server by sending and receiving small chunks of data
+     - These update individual components or data items on a page
+     - This is also known as AJAX (misleading but widely used term) (Asynchronous JavaScript and XML)
+   - Two advantages
+     - Speed: fewer data items are exchanged
+       - Faster network transfer, less work for server and browser
+     - Smoother experience for user – less clunky
