# Remote Object Activation

+   - `Client.policy`
+   
+     ```
+     grant
+     {
+         permission com.sun.rmi.rmid.ExecPermission
+             "${java.home}${/}bin${/}java";
+         permission com.sun.rmi.rmid.ExecOptionPermission
+             "-Djava.security.policy=*";
+     };
+     ```

+   - `rmid.policy`
+   
+     ```
+     grant
+     {
+         permission com.sun.rmi.rmid.ExecPermission
+             "${java.home}${/}bin${/}java";
+         permission com.sun.rmi.rmid.ExecOptionPermission
+             "-Djava.security.policy=*";
+     };
+     ```

+   - Copy the `rmid.policy` to `java.home/bin`
