# 3.1.2.4 C均值算法

+   1. 选取聚类块数 $k$
+   2. 从训练集中任意选定 $k$ 个向量 $c_1,c_2,\cdots,c_k$ 作为聚类中心
+   3. 将每个样本向量（$n$ 为输入向量维数），按下列欧氏距离公式，归入中心为 $c_i$ 的类中。
+   4. 重新调整聚类中心。对于 $c_{im}$，其中 $m=1,2,3,\cdots,k$，由下式计算得出：
+      $$c_{im}=\frac{\sum_{x_l\in cluster_i}x_{lm}}{N_i}$$
+      其中 $N_i$ 是第 $i$ 个聚类块中的向量数，$i=1,2,3,\cdots,k$。
+   5. 如果步骤4中的聚类中心不再变化，则终止。否则，转至步骤3。
