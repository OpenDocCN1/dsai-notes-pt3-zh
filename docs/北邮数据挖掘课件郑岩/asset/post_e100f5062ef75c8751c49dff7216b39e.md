## Classifying

- Classifying
  - Algorithms

| 分类方法 | 说明 |
|---|---|
| Rudimentary rules | 1R – one-level decision tree – just using best first-level rules |
| Statistical modelling | Naive Bayes – uses prior probability of class combined with instance probability – assumes attributes are independent |
| Decision trees | ID3 / C4.5 decision tree induction – information gain or gain ratio calculated at each node to decide which branch to go down – maximise the separation of classes |
| Covering rules | Rules found to cover all instances of each class – attribute-value pair to maximise the classification rule – PRISM method |
| Association rules | Looking for item sets with high coverage and specified minimum confidence – works for nominal values – Apriori algorithm |
| Linear models | Numeric prediction – linear regression to minimise difference between actual and predicted values |
| Instance-based learning | Euclidean distance of attribute sets found to calculate the nearest neighbour algorithm – filtering k-nearest matches |
