# 客户信息主题的维度设计书

模型名称：客户基本信息

模块功能：用于客户数量的分析以及客户属性的分析

事实表：客户信息事实表

度量：客户数量

数据粒度：
每个客户每月计算一次收益，事实表中每条记录表示一个客户的属性。
事实表中存放1年以内的数据，超过10年的数据按月进行滚动，最初的数据进行汇总后从事实表中卸出。

相关维度：

+   （1）客户详细资料维
+   （2）客户性别维
+   （3）客户年龄层次维
+   （4）客户在网时间维
+   （5）客户消费层次维
+   （6）客户信用度层次维
+   （7）是否大客户维
+   （8）交费类型维
+   （9）地理维
+   （10）客户流失概率层次维
+   （11）客户挽留价值层次维
+   （12）成为大客户概率层次维
