# 1.7 数据挖掘的应用

数据挖掘技术的产生本身就有其强烈的应用需求背景，它从一开始就是面向应用的。数据挖掘技术在市场分析、业务管理、决策支持等方面有广泛的应用，是实现CRM和BI的重要技术手段之一。具体涉及数据挖掘的商业问题有数据库营销（Database Marketing）、客户群体划分（Customer Segmentation & Classification）、背景分析（Profile Analysis）、交叉销售（Cross-selling）等市场分析行为，以及客户流失分析(Churn Analysis)、客户信用评分(Credit Scoring)、欺诈甄别(Fraud Detection)等。
