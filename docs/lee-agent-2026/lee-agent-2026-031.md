## 为什么选择云服务器学习RAG？

![](img/b0784e1217d82b28f8a098b18a58e263_14.png)

上一节我们介绍了RAG学习对GPU的依赖。本节中我们来看看为什么云服务器是初学者的理想选择。

如果你不通过商用API访问大语言模型，学习RAG确实需要GPU。为了看出明显的RAG效果，经常需要使用70B参数以上的大模型。如果本地没有GPU，使用云服务器是更好的方案。

![](img/b0784e1217d82b28f8a098b18a58e263_16.png)

使用云服务器有以下几个优势：
*   无需前期投入大量资金购置GPU机器。
*   无需纠结于选择何种型号或显存大小的GPU。
*   避免了购买GPU后却发现无法运行目标模型的尴尬。
*   可以按小时付费，低成本体验高端GPU（如A100）。

![](img/b0784e1217d82b28f8a098b18a58e263_18.png)

因此，即使没有本地机器，也推荐尝试使用云服务器学习。注册后平台会赠送代金券，首次充值也有优惠，性价比很高。

## 运行RAG程序：环境准备

一切就绪，现在让我们进入服务器终端，开始运行RAG程序。

![](img/b0784e1217d82b28f8a098b18a58e263_64.png)

点击应用界面上的 **`Jupyter Lab`** 按钮，进入开发环境。然后打开一个终端。

首先，检查预装的Ollama及模型：
```bash
ollama list
```
此命令会列出已安装的模型，可以看到`llama3:70b`模型已经就绪。

![](img/b0784e1217d82b28f8a098b18a58e263_66.png)

我们的RAG程序还需要一个嵌入模型。这里我们使用`nomic-embed-text`模型。在终端中下载它：
```bash
ollama pull nomic-embed-text
```
下载速度很快，大约一分钟即可完成。再次运行`ollama list`确认模型已下载。

![](img/b0784e1217d82b28f8a098b18a58e263_68.png)

## 运行RAG程序：代码执行

![](img/b0784e1217d82b28f8a098b18a58e263_72.png)

环境准备好后，我们将在Jupyter Notebook中编写并执行RAG代码。

![](img/b0784e1217d82b28f8a098b18a58e263_74.png)

在Jupyter Lab中创建一个新的Notebook文件。首先，安装必要的Python开发库，例如`langchain`、`chromadb`等。安装过程大约需要2-3分钟。

![](img/b0784e1217d82b28f8a098b18a58e263_76.png)

安装完成后，在代码单元格中导入所需库：
```python
# 示例：导入必要的库
from langchain.vectorstores import Chroma
from langchain.embeddings import OllamaEmbeddings
from langchain.llms import Ollama
# ... 其他导入
```

![](img/b0784e1217d82b28f8a098b18a58e263_78.png)

接着，创建向量数据库，并使用我们刚才下载的嵌入模型：
```python
embeddings = OllamaEmbeddings(model="nomic-embed-text")
# ... 创建向量存储的代码
```

![](img/b0784e1217d82b28f8a098b18a58e263_80.png)

![](img/b0784e1217d82b28f8a098b18a58e263_82.png)

然后，定义提示词模板，并创建LangChain链。这里的关键是指定使用`llama3:70b`作为大语言模型：
```python
llm = Ollama(model="llama3:70b")
# ... 构建链的代码
```

最后，执行一个查询。有时在Jupyter中运行后可能看不到输出，这是常见问题。解决方法很简单：重启内核（Kernel），然后重新执行所有单元格即可。

![](img/b0784e1217d82b28f8a098b18a58e263_84.png)

程序运行后，你可以通过系统监控看到GPU使用率和显存占用。运行70B模型会占用约39GB显存，而A100处理速度非常快。

## 云服务器学习实用建议

为了更经济、高效地使用云服务器学习，以下是几点核心建议：

![](img/b0784e1217d82b28f8a098b18a58e263_100.png)

![](img/b0784e1217d82b28f8a098b18a58e263_102.png)

*   **不用即停**：学习结束后，第一时间停止服务器。
*   **专注学习**：使用云服务器时请集中精力，避免发呆，因为发呆也在计费。
*   **善用提醒**：为应用设置运行时长提醒和自动关机时间。
*   **小额充值**：如果仍担心费用失控，可以采用“少额多次”的方式充值，即使忘记关机，损失也有限。
