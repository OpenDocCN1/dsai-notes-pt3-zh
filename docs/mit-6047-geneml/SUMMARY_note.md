## P2：L2- 动态规划 ⚙️

上一节我们介绍了课程的整体框架，本节中我们来看看序列比对的基础算法——动态规划。

动态规划是一种通过将复杂问题分解为更简单的子问题来高效求解的算法策略。在序列比对中，它用于计算两条序列之间的最优比对。

以下是动态规划在全局序列比对（Needleman-Wunsch算法）中的核心公式：

设序列 `X` 长度为 `m`，序列 `Y` 长度为 `n`。我们构建一个 `(m+1) x (n+1)` 的得分矩阵 `F`。
初始化：
`F[0, 0] = 0`
`F[i, 0] = F[i-1, 0] + gap_penalty`
`F[0, j] = F[0, j-1] + gap_penalty`

递推公式（对于 i>0, j>0）：
`F[i, j] = max( F[i-1, j-1] + s(Xi, Yj), F[i-1, j] + gap_penalty, F[i, j-1] + gap_penalty )`
其中 `s(Xi, Yj)` 是字符 `Xi` 和 `Yj` 的匹配得分。

## P3：L3- 局部对齐、哈希、BLAST、对齐分数 🔍

在掌握了全局比对后，本节我们聚焦于更常见的生物学场景——局部序列比对，并介绍加速比对的BLAST工具。

局部比对旨在找出两条序列中相似度最高的子区域，使用Smith-Waterman算法。由于直接进行动态规划计算量巨大，BLAST工具采用哈希（Hash）和种子扩展策略来快速寻找可能的高分匹配区域。

BLAST的核心步骤包括：
1.  **创建哈希表**：将查询序列分割成固定长度的“字”（words），并建立字到序列位置的映射。
2.  **命中（Hit）**：在目标数据库中搜索这些字，找到匹配位置。
3.  **延伸（Extension）**：对每个命中点向两端延伸，使用动态规划计算局部比对分数。
4.  **评估（Evaluation）**：根据统计模型（如E-value）评估比对结果的显著性。

## P4：L4- HMM L1 部分 🧮

从序列比对过渡到更复杂的序列模式建模，本节我们开始学习隐马尔可夫模型的第一部分。

隐马尔可夫模型（HMM）是一种用于描述含有隐含未知参数的马尔可夫过程的统计模型。在基因组学中，它常用于基因预测、蛋白质家族建模等。

一个HMM由以下要素定义：
*   **状态集合 Q**：例如，在基因预测中可能是“外显子”、“内含子”。
*   **观测集合 V**：例如，核苷酸 {A, C, G, T}。
*   **状态转移概率矩阵 A**：`A[i][j]` 表示从状态 `i` 转移到状态 `j` 的概率。
*   **观测概率矩阵 B**：`B[i][k]` 表示在状态 `i` 下观察到符号 `k` 的概率。
*   **初始状态概率分布 π**：模型在初始时刻处于各状态的概率。

---

## P5：L5- HMM L2 部分 🧠

上一节我们定义了HMM的组成部分，本节中我们来看看HMM的三个核心问题及其求解算法。

HMM主要解决三类问题：
1.  **评估问题**：给定模型参数 λ=(A, B, π) 和观测序列 O，计算该观测序列出现的概率 P(O|λ)。使用**前向算法**或后向算法高效计算。
2.  **解码问题**：给定模型 λ 和观测序列 O，找出最可能产生该观测序列的隐藏状态序列。使用**维特比算法**求解。
3.  **学习问题**：仅给定观测序列 O，估计模型参数 λ 使得 P(O|λ) 最大。使用**鲍姆-韦尔奇算法**（一种EM算法）进行无监督训练。

维特比算法是一种动态规划算法，其递推公式为：
`V[t, j] = max_i ( V[t-1, i] * A[i, j] ) * B[j, O_t]`
其中 `V[t, j]` 表示在时刻 `t` 到达状态 `j` 的所有路径中，产生前 `t` 个观测的最大概率。

## P6：L6- 表达分析、聚类、分类 📊

离开序列分析，我们进入功能基因组学领域。本节探讨如何利用机器学习分析基因表达数据。

基因表达数据通常来自微阵列或RNA-seq实验，形成一个“基因 x 样本”的矩阵。分析目标包括：
*   **聚类**：发现具有相似表达模式的基因组或样本组，暗示共同功能或状态。常用方法有层次聚类、K-means聚类。
*   **分类**：根据表达谱对样本进行类别预测（如疾病/健康）。常用方法有支持向量机（SVM）、决策树、逻辑回归。

以下是使用Python进行K-means聚类的简单代码示例：
```python
from sklearn.cluster import KMeans
import numpy as np
# 假设 expr_data 是一个 (n_genes, n_samples) 的矩阵
kmeans = KMeans(n_clusters=5, random_state=0).fit(expr_data.T) # 对样本聚类需转置
cluster_labels = kmeans.labels_
```

## P7：L7- RNA折叠、RNA世界、RNA结构 🧬

本节我们关注非编码RNA领域。RNA分子不仅能传递信息，还能通过折叠形成复杂的三维结构执行功能。

RNA二级结构预测是核心问题，其目标是找到使自由能最低的碱基配对方式。这可以通过**动态规划**算法（如Nussinov算法）解决。

Nussinov算法递归地计算序列 `s` 从位置 `i` 到 `j` 的最大配对数 `γ(i, j)`：
`γ(i, j) = max( γ(i+1, j), γ(i, j-1), γ(i+1, j-1) + δ(i, j), max_{i<k<j} [γ(i, k) + γ(k+1, j)] )`
其中 `δ(i, j)` 在位置 `i` 和 `j` 的碱基可配对时为1，否则为0。

## P8：L8- 表观基因组学 L1 部分 🧫

从遗传序列到表观遗传修饰，本节我们开始学习表观基因组学的第一部分。

表观遗传学关注不改变DNA序列但可遗传的基因表达调控变化，主要机制包括：
*   **DNA甲基化**：通常在CpG二核苷酸上添加甲基，常抑制基因表达。
*   **组蛋白修饰**：如甲基化、乙酰化，影响染色质结构和基因可及性。
*   **染色质可及性**：开放染色质区域通常与活跃转录相关。

## P9：L9- 表观基因组学 L2 部分和 3D 基因组 🧩

承接上一节，本节深入探讨表观基因组数据的分析和三维基因组结构的影响。

利用ChIP-seq、ATAC-seq等技术产生的表观基因组数据，可以进行峰检测、差异分析和 motif 发现。此外，基因组在细胞核内并非线性排列，而是折叠成复杂的**三维结构**（如染色质环、拓扑关联结构域TADs），这显著影响基因调控。Hi-C等技术用于研究3D基因组结构。

## P10：L10- 调控基因组学和基序 🎯

本节整合序列与表观遗传信息，聚焦于基因的转录调控。

核心调控元件是**基序**，即转录因子偏好结合的短DNA序列模式。基序通常用位置频率矩阵表示，并通过如MEME、STREME等工具从一组共调控基因的上游序列中从头发现。

一个PFM可以转换为位置权重矩阵用于序列打分：
`PWM[i, b] = log2( (p(i, b) + pseudo) / (bkg[b] + pseudo) )`
其中 `p(i, b)` 是位置 `i` 上碱基 `b` 的频率，`bkg[b]` 是背景频率，`pseudo` 是伪计数。

## P11：L11- 网络 🌐

生物学系统是复杂的网络。本节介绍如何用网络（图）模型来研究基因、蛋白质之间的相互作用。

网络由**节点**（如基因、蛋白质）和**边**（如相互作用、共表达关系）构成。分析网络可以帮助我们：
*   识别关键节点（枢纽基因）。
*   发现功能模块（紧密连接的子网络）。
*   理解信号流或调控路径。

常用指标包括度中心性、介数中心性、聚类系数等。

## P12：L12- 深度学习 🤖

面对高通量、高维度的基因组学数据，深度学习显示出强大能力。本节介绍深度学习在基因组学中的应用。

深度学习模型，特别是卷积神经网络，已成功应用于：
*   **序列特异性预测**：如预测DNA/RNA结合蛋白的结合位点。
*   **基因表达预测**：从DNA序列预测表达水平。
*   **变异效应预测**：评估非编码区遗传变异的调控影响。

一个用于基序识别的简单CNN结构可能如下：
```python
import torch.nn as nn
class MotifCNN(nn.Module):
    def __init__(self, seq_len=200, vocab_size=4):
        super().__init__()
        self.conv1 = nn.Conv1d(vocab_size, 32, kernel_size=15) # 卷积层检测基序
        self.pool = nn.MaxPool1d(2)
        self.fc1 = nn.Linear(32 * ((seq_len-14)//2), 64)
        self.fc2 = nn.Linear(64, 1) # 输出结合概率
    def forward(self, x):
        x = self.pool(torch.relu(self.conv1(x)))
        x = x.view(x.size(0), -1)
        x = torch.relu(self.fc1(x))
        x = torch.sigmoid(self.fc2(x))
        return x
```

## P13：L13- 群体遗传学 👥

我们将视角从个体扩展到群体。本节介绍群体遗传学的基本概念，研究遗传变异在群体中的分布和变化。

核心概念包括：
*   **等位基因频率**：群体中某等位基因的比例。
*   **哈迪-温伯格平衡**：理想群体中基因型频率的预测模型。
*   **遗传漂变、自然选择、基因流**：影响等位基因频率的进化力量。
*   **群体结构**：群体内存在亚群的现象。

## P14：L14- GWAS 和疾病解剖 🔎

群体遗传学的一个重要应用是寻找复杂疾病的遗传基础。本节学习全基因组关联研究。

GWAS通过比较病例组和对照组在全基因组范围内数百万个SNP位点的等位基因频率，来寻找与疾病显著相关的遗传变异。

其核心是统计检验，例如对于每个SNP进行卡方检验或逻辑回归：
`logit(P(disease)) = β0 + β1 * genotype + covariates`
其中 `β1` 的显著性p值用于判断关联性。结果需经过多重检验校正。

---

## P15：L15- eQTLs (表达 Quantitative Trait Loci) 🧬➡️📈

GWAS发现的疾病相关变异大多位于非编码区。本节介绍eQTL分析，它将遗传变异与基因表达水平联系起来，解释变异的功能。

eQTL是指其基因型与某个基因的表达量显著相关的基因组位点。分析通常对每个“基因-变异”对进行线性回归：
`Expression_gene = β0 + β1 * genotype_SNP + covariates`
寻找显著的 `β1`。

## P16：L16- 系统遗传学和遗传力 🧬➕📊

为了理解复杂性状，我们需要同时考虑遗传和调控网络。本节介绍系统遗传学以及遗传力的概念。

**系统遗传学**整合了遗传变异、分子表型（如表达、代谢）和复杂性状，以构建因果网络。**遗传力**衡量性状变异中可由遗传因素解释的比例，分为加性遗传力等。

## P18：L18- 基因组进化 🦖

基因组本身是进化的产物。本节探讨驱动基因组结构和内容演化的机制。

主要进化机制包括：
*   **基因复制**：新基因的主要来源。
*   **水平基因转移**：尤其在原核生物中常见。

## P21：L21- 癌症基因组学 🩺

将所学知识应用于人类健康的重要领域——癌症。本节概述癌症基因组学。

癌症是一种基因组疾病，体细胞突变驱动了癌细胞的生长和扩散。研究包括：
*   识别**驱动突变**与乘客突变。
*   分析拷贝数变异、结构变异。
*   探索肿瘤异质性和进化。
*   基于基因组特征进行分型和个性化治疗。

## P22：L22- 单细胞基因组学 🔬

传统的组学技术测量的是细胞群体的平均值。本节介绍革命性的单细胞基因组学技术。

单细胞RNA测序等技术允许我们在单个细胞分辨率下分析基因表达，从而能够：
*   发现新的细胞类型或状态。
*   描绘细胞分化轨迹（拟时序分析）。
*   解析肿瘤微环境内的细胞异质性。
*   构建高分辨率的细胞图谱。

分析流程通常包括数据预处理、降维、聚类和轨迹推断等步骤。
