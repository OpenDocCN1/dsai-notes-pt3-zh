在本节课中，我们将要学习如何将机器学习技术应用于基因组学数据。我们将从基本概念开始，逐步深入到具体的算法和应用场景。

## 1. 引言与背景 🧬

基因组学产生了海量的生物数据。这些数据包括DNA序列、基因表达水平和蛋白质结构信息。传统生物信息学方法难以充分挖掘这些数据中的复杂模式。机器学习为此提供了强大的工具。它能够从数据中自动学习规律并进行预测。

上一节我们介绍了课程的基本背景，本节中我们来看看机器学习在基因组学中的核心价值。

## 2. 核心概念与数据表示 🔑

在基因组机器学习中，我们需要将生物数据转化为计算机可以处理的格式。DNA序列由四种碱基组成：腺嘌呤（A）、胸腺嘧啶（T）、胞嘧啶（C）和鸟嘌呤（G）。一个序列可以表示为字符串，例如 `ATCGGA`。

基因表达数据通常是一个矩阵。行代表基因，列代表样本（例如不同的病人或实验条件）。矩阵中的每个值代表特定基因在特定样本中的表达水平。我们可以用公式表示为一个矩阵 **X**，其中 `X[i, j]` 表示第 `i` 个基因在第 `j` 个样本中的表达量。

以下是常见的数据预处理步骤：
*   **归一化**：调整数据使其具有相同的尺度。
*   **特征选择**：从所有基因中挑选出与目标最相关的子集。
*   **序列编码**：将DNA序列转化为数值向量，例如使用独热编码。

## 3. 监督学习：分类与回归 🎯

监督学习的目标是根据已有标签的数据训练模型，并对新数据做出预测。在基因组学中，一个典型任务是基于基因表达数据预测癌症亚型（分类），或预测某种药物的反应强度（回归）。

逻辑回归是一种常用的分类算法。它通过sigmoid函数将线性组合映射到0和1之间，表示属于某一类的概率。其核心公式为：

**P(y=1|x) = σ(wᵀx + b) = 1 / (1 + e^(-(wᵀx + b)))**

其中，**w** 是权重向量，**x** 是特征向量，**b** 是偏置项，**σ** 是sigmoid函数。

以下是训练一个监督学习模型的基本流程：
1.  准备带有标签的训练数据集。
2.  选择一个模型（如逻辑回归、支持向量机）。
3.  定义损失函数来衡量预测误差。
4.  使用优化算法（如梯度下降）最小化损失函数，调整模型参数。
5.  在独立的测试集上评估模型性能。

## 4. 无监督学习：发现隐藏结构 🔍

无监督学习用于发现没有标签的数据中的内在结构。在基因组学中，这常用于发现新的疾病亚型或识别功能相似的基因簇。

聚类是最常见的无监督学习任务之一。K-means算法是一个经典方法，其目标是将数据点划分为K个簇，使得每个点与其所属簇中心的距离平方和最小。算法步骤可以用伪代码描述：

```
初始化K个簇中心
while 簇中心不再显著变化：
    将每个数据点分配到最近的簇中心
    根据每个簇中所有点的均值重新计算簇中心
```

主成分分析是另一个重要技术，用于降维和可视化。它通过线性变换将数据投影到方差最大的几个新坐标轴（主成分）上。

## 5. 深度学习在基因组学中的应用 🤖

深度学习，特别是卷积神经网络和循环神经网络，非常适合处理序列和空间数据。它们已被成功应用于预测DNA-蛋白质结合位点、基因表达调控和蛋白质结构预测。

一个用于识别转录因子结合位点的简单CNN架构可能如下所示：
*   **输入层**：接收编码后的DNA序列窗口。
*   **卷积层**：使用多个滤波器扫描序列，检测局部模式（如 motif）。
*   **池化层**：降低特征维度，保留重要信息。
*   **全连接层**：整合特征。
*   **输出层**：输出结合概率。

## 6. 挑战与最佳实践 ⚠️

基因组机器学习面临独特挑战。数据维度通常远大于样本数量，这容易导致过拟合。生物数据噪声大，且存在批次效应。模型的解释性在生物医学应用中至关重要。

为了应对这些挑战，请遵循以下最佳实践：
*   使用正则化（如L1/L2）来防止过拟合。
*   采用严格的交叉验证来评估模型泛化能力。
*   结合生物学先验知识进行特征工程或模型设计。
*   使用SHAP、LIME等工具来解释模型预测。
