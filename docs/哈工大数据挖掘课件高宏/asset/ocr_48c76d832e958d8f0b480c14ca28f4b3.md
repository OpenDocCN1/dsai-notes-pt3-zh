# 聚类中的属性类型

+   - 距离度量
+     - 两个常用的距离度量方法
+     - suppose there are n attributes, two tuples (x_i1, ..., x_in) and (x_j1, ..., x_jn)
+     - Euclidean distance 欧几里得距离
+     - Manhattan distance 曼哈顿距离

```
d(i, j) = sqrt(|x_i1 - x_j1|^2 + |x_i1 - x_j1|^2 + ... + |x_in - x_jn|^2)
```

```
d(i, j) = |x_i1 - x_j1| + |x_i1 - x_j1| + ... + |x_in - x_jn|
```
