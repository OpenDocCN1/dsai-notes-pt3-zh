# 聚类中的属性类型

+   - Ratio-Scaled Variables 比例标度
+     - are continuous attributes of a nonlinear scale
+     - three possible methods:
+       - treat them like interval-scaled variables—*not a good choice!*
+       - perform transformations, then treat them as interval-scaled attributes
+         - e.g. Logarithmic transformation $y'i= log(xi)$
+       - treat them as continuous ordinal attributes
+         - replacing real values by ranks, mapping ranks to [0, 1], and then applying Minkowski distance
