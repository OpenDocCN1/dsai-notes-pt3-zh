# How to construct a decision tree?(cont.)

+   - Other Attribute Selection Measures
+     - Gain ratio
+     - a shortcoming of information gain is its preference to attributes with lots of values. In order to overcome this shortcoming, J. R. Quinlan used gain ratio in C4.5 instead of information gain

```
Gain_ratio(A) = Gain(A) / IV(A)
```

```
IV(A) = - sum_{j=1}^{v} (S'_j / S) log_2 (S'_j / S)
```

where attribute A is selected to partition the instance set into the subsets {S'_1, S'_2, ..., S'_v}
