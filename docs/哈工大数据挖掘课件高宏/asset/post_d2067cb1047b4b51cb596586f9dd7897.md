
## Data mining applications — an example

- Data mining solution:
  - Select customers from a previous campaign data.
  - Attach responded or non-responded identification to the selected customer records
  - Divide the selected customer data into training, testing and evaluation data sets
  - Use neural network or decision tree algorithms to build prediction models from the training data set
  - Test and evaluate the models with the testing and evaluation data sets.

## Data mining applications — an example

- Data mining solution:
  - Apply the models to customers to select a mailing list.
    All customers in the mailing list are predicted as potentially responding customers.
  - Post product invitations to the selected customers.
  - Collect and analyze the campaign results.
  - Adjust the prediction models with the new data.

## Real Data Mining Work

- A real data mining work is more than running a data mining algorithm on the sample data
- It requires
  - Methodology
  - Process

## Data Mining Process

1. Identify business problems.
2. Identify and study data sources, and select data.
3. Extract and preprocess data.
4. Mine data, e.g., discovering association rules or building predictive models.
5. Verify the mining results.
6. Deploy models in the business process.
7. Measure ROI. (Return Of Invest)

## Data Mining Process ---- Identify business problems

- Common Problems Data Mining can Solve
  - Customer profitability
  - Customer acquisition
  - Customer segmentation
  - Direct marketing
  - Cross-selling
  - Customer retention
  - Clickstream analysis
  - Fraud detection
  - Manufacturing process optimization
  - Traffic accident analysis

## Data Mining Process
---- Identify and study data sources, and select data

- **Understand Data**
  - Data warehouses
  - OLTP systems such as billing systems
  - Special databases, such as marketing and sales
  - Excel, Access
  - Flat files
  - External data sources, e.g., demographic data, market survey data

## Data Mining Process
---- Extract and preprocess data

- **Common Data Problems**
  - Data size – too much data, too little relevant.
  - Data sufficiency – current data warehouses don’t contain all necessary customer data.
  - Data integrity – data in different sources don’t always match.
  - Data accessibility – DBAs control the data access.
  - Data understandability – data dictionary, metadata.
  - Data quality – Errors, missing values.
  - Data reliability – out-of-date data, unreliable data.
  - Integration of external data sources

## Data Mining Process
---- Extract and preprocess data

- **Summary Statistics of Data**
  To understand the extracted data to be used for mining, it is useful to calculate the following summary statistics.
  - Data size, no. of records, no. of columns.
  - Numbers of columns in different data types, e.g., numeric and categorical.
  - Mean, Min, Max, Variance of numeric columns (variables).
  - Distinct values of categorical columns.
  - Frequencies of categorical values of each categorical column.
  - No. of records having missing values.
  - Percentages of records which miss values for each column.

## Data Mining Process
---- Extract and preprocess data

- **Data Preprocessing**
  - Variable selection
  - Sampling
  - Data correction
  - Missing values treatment
  - Data transformation, e.g., birth date to age.
  - Derive new variables
  - Data aggregation

## Data Mining Process
---- Mine data

- **Run a data mining algorithm to**
  - Discover knowledge from the input data, e.g., rules, patterns, etc.
  - Build predictive models or forecasting models
  - Segment customers

## Data Mining Process
---- Verify the mining results

- Patterns and models derived from the training data have to be thoroughly verified before deployed in the business process
- **Verification methods**
  - Cross validation
  - Independent validation data sets
  - Original data source
  - Consulting business experts
