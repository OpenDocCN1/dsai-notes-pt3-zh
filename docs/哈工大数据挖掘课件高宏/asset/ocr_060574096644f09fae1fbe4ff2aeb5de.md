# 关于熵

+   - Shannon 的信息论
+   - 一组数据中的平均信息量，成为熵
+   - 熵的定量表示
+     - 设有三种消息按不规则的次序出现，一共 n 个。
+     - 三个消息出现的概率为 p₁,p₂,p₃
+     - n 个消息中含有的消息数为： np₁,np₂,np₃
+     - 一个消息所含的信息量为 -log p₁, -log p₂, -log p₃

| 消息出现的概率 | 1个消息的信息量 | n 中的消息个数 | 它的信息量 |
|---|---|---|---|
| p₁ | -log p₁ | n p₁ | - n p₁ log p₁ |
| p₂ | -log p₂ | n p₂ | - n p₂ log p₂ |
| p₃ | -log p₃ | n p₃ | - n p₃ log p₃ |
