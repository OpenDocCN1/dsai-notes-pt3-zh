# Common Data Problems in Enterprises

+   - **Scattered**
+     - Data are scattered in different legacy systems in different formats
+   - **No standard**
+     - Data are not standardized (e.g. in Customer Information System, the name of a person is Bill Gates; but in the Mailing System, the name of that person is Gates, Bill)
+   - **Inconsistent**
+     - Contradictory data are found in different systems (e.g. in one system, the gender code of a person is Male; but in another system, the title of that person is Miss)
