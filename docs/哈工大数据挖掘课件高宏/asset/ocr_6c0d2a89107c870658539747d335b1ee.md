# Example :

首先计算期望：
例如 E(video,game):

| | game | Not game | Sum (row) |
|---|---|---|---|
| video | 4000 (4500) | 3500 (3000) | 7500 |
| Not video | 2000 (1500) | 500 (1000) | 2500 |
| Sum(col.) | 6000 | 4000 | 10000 |

6000/10000 = E(video,game)/7500
E(video,game)=4500

χ²=(4000-4500)²/4500+(3500-3000)²/3000
+(2000-1500)²/1500+(500-1000)²/1000=555.6

χ2 >1, 且位置(game,video)上的观测值小于期望值
⇒负相关
