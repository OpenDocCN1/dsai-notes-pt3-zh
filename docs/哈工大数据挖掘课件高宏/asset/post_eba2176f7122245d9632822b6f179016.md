## Data mining as an confluence of multiple disciplines

Database techniques and tools (SQL) are used for

- Access to data sources
- Data selection and integration

## Statistical Techniques for Data Mining

Statistical techniques are used for

- Data exploration
- Data pre- and post-processing
- Statistical model building
- Model test and result verification

## Machine Learning Techniques for Data Mining

Machine Learning provides useful data mining algorithms such as

- Decision tree induction
- Neural networks

## Pattern Recognition Techniques for Data Mining

Pattern recognition provides well developed techniques and methodologies for

- Classification
- Clustering
- Feature selection
- Result validation

## Visualization Techniques for Data Mining

- Visualization is a new technology and very important in data mining.
- Human beings are superior in picking up irregularities from visualized information

## Data Mining: A KDD Process

- Data mining—core of knowledge discovery process

## Steps of a KDD Process

- Learning the application domain
  - relevant prior knowledge and goals of application
- Creating a target data set: data selection
- Data cleaning and preprocessing: (may take 60% of effort!)
- Data reduction and transformation
  - Find useful features, dimensionality/variable reduction, invariant representation.
- Choosing functions of data mining
  - summarization, classification, regression, association, clustering.
- Choosing the mining algorithm(s)
- Data mining: search for patterns of interest
- Pattern evaluation and knowledge presentation
  - visualization, transformation, removing redundant patterns, etc.
- Use of discovered knowledge

## Examples: Relational Data

Table: Acme Investors Incorporated

| Customer ID | Account Type | Margin Account | Transaction Type | Transaction Month | Sex | Age | Favorite Destination | Annual Income |
|---|---|---|---|---|---|---|---|---|
| 12345 | Joint | No | Online | 12.5 | F | 20-29 | Paris | 40-50K |
| ... |  |  |  |  |  |  |  |  |

- Semantics
  - This relational table represents a set of objects, i.e., customers.
  - Each row/record represents a particular customer
  - Each column gives values for an attribute or variable for each of the customers
  - Attributes are defined in different data types, numeric/categorical.

- Data mining questions
  1. Can I find a general profile of different investor types? (CLASSIFICATION)
  2. What characteristics distinguish between Online and Broker investors? (DISCRIMINATION)
  3. Can I develop a model that can predict the average trade/month for a new investor? (PREDICTION)
