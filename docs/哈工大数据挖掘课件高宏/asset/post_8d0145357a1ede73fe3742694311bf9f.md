
## 怎样才是一个好的聚类？

- 一个好的聚类方法产生具有如下性质的簇：
  - 类内：数据项之间具有 high 相似性
  - 类间数据项之间具有 low 相似性

![](img/76d573223e44fade1c0950849390a4b3_244_0.png)

- 聚类结果的质量好坏取决于
  - 聚类方法中使用的相似性度量
  - 聚类的实现方法
- 对聚类方法好坏的评价
  - 发现（一些/所有）隐含模式的能力

## 什么是聚类分析？

- **数据样本X：**
  由*d*个属性值组成： X = (x₁, x₂, ..., x_d)，其中x_i表示样本中的各属性，*d*是样本或样本空间的维数（或属性个数）
- **数据样本集：**
  记为{X₁, X₂, ..., Xₙ}，第i个样本记为X_i = {x_i1, ..., x_id}
- **簇C_i: Cluster C_i**
  数据样本集分成*k*个簇，每个簇是相应数据样本的集合，相似样本在同一簇中，相异样本在不同簇中。

- 用下面的特征来描述簇：

簇的质心（centroid）：（样本的平均值）是簇的“中间值”（middle），但并不需要是簇中实际点。

令 $n_i$ 表示簇 $C_i$ 中样本的数量，$m_i$ 表示对应样本的均值：

centroid = $m_i = \frac{1}{n_i} \sum_{X \in C_i} X$

## 相似性度量

X_i{x_i1,...,x_in}和X_j{x_j1,...,x_jn}是两个具有n个属性的两个样本。距离度量标准d(X_i, X_j)表示第i个样本与第j个样本间的距离。

在聚类分析中，最常用的距离度量标准是d维空间中的欧几里德距离：

$d(i,j)=\sqrt{|x_{i1}-x_{j1}|^2+|x_{i2}-x_{j2}|^2+\cdots+|x_{in}-x_{jn}|^2}$

## 类中的属性类型

- 不同类型的属性需要使用不同的相异性度量
  - Interval-scaled variables 区间标度变量
    - 是一个粗略线性标度的连续度量
    - 例如：重量和高度、经度和纬度、以及大气温度
  - Binary variables 二元变量
    - 只有两个值：0、1
  - Nominal, ordinal, and ratio variables
    标称型、序数型和比例标度型变量
  - Variables of mixed types 混合类型

## 聚类中的属性类型

- Interval-valued variables区间标度

区间标度变量的度量单位直接影响聚类分析的结果。

- 例如，将高度的度量单位由“米”改为“英寸”，可能产生非常不同的聚类结果

为避免对度量单位选择的依赖，数据应当标准化。
给定一个变量f的度量值，可以进行如下变换：

- 计算平均的绝对偏差：

s_f = 1/n (|x_1f - m_f| + |x_2f - m_f| + ... + |x_nf - m_f|)

- Where m为均值

- 计算标准化的度量值 (Z-score) m_f = 1/n (x_1f + x_2f + ... + x_nf)

z_if = (x_if - m_f) / s_f

## 聚类中的属性类型

- 距离度量
  - 两个常用的距离度量方法
  - suppose there are n attributes, two tuples (x_i1, ..., x_in) and (x_j1, ..., x_jn)
  - Euclidean distance 欧几里得距离
  - Manhattan distance 曼哈顿距离

```
d(i, j) = sqrt(|x_i1 - x_j1|^2 + |x_i2 - x_j2|^2 + ... + |x_in - x_jn|^2)
```

```
d(i, j) = |x_i1 - x_j1| + |x_i2 - x_j2| + ... + |x_in - x_jn|
```

## 距离度量满足如下要求：

- d(i, j) ≥0    距离是一个非负的数值
- d(i, i) =0    一个对象与自身的距离是 0
- d(i, j) = d(j, i)    距离函数具有对称性
- d(i, j) ≤ d(i, h) + d(h, j)    三角不等式

## 其它的距离度量

- Minkowski distance(明考斯基距离，欧几里得距离与曼哈坦距离的概括)

d(i, j) = (|x_{i1} - x_{j1}|^q + |x_{i2} - x_{j2}|^q + … + |x_{in} - x_{jn}|^q)^{1/q}

- if the attributes have different importance, *weights* can be used:

d(i, j) = (w_1|x_{i1} - x_{j1}|^q + w_2|x_{i2} - x_{j2}|^q + … + w_n|x_{in} - x_{jn}|^q)^{1/q}

## 聚类中的属性类型

- 二元变量（属性）
  - 如果“0”和“1”两个状态是同等价值的，并有相同的权重，则该二元变量是对称的。
    - 例如，性别，两个取值“0”和“1”没有优先权。
    - 基于对称二元变量的相似度称为恒定的相似度。
    - 采用简单匹配系数评价两个对象之间的相异度：
      $d(i, j) = \frac{b + c}{a + b + c + d}$
  - 否则，则该二元变量是不对称的。
    - 通常，出现几率较小的结果编码为1。
    - 两个都取值1的情况(正匹配)被认为比两个都取值0的情况(负匹配)更有意义。
    - Jaccard coefficient: $d(i, j) = \frac{b + c}{a + b + c}$

## Example

| Name | Gender | Fever | Cough | Test-1 | Test-2 | Test-3 | Test-4 |
|------|--------|-------|-------|--------|--------|--------|--------|
| Jack | M      | Y     | N     | P      | N      | N      | N      |
| Mary | F      | Y     | N     | P      | N      | P      | N      |
| Jim  | M      | Y     | P     | N      | N      | N      | N      |

- gender 是一个对称的二元变量
- 其它的都是非对称的二元变量
- 将值 Y 和 P 编码为 1, 值 N 编码为 0, 根据 Jaccard 系数计算得：

d ( jack , mary ) = (0 + 1) / (2 + 0 + 1) = 0.33

d ( jack , jim ) = (1 + 1) / (1 + 1 + 1) = 0.67

d ( jim , mary ) = (1 + 2) / (1 + 1 + 2) = 0.75
