
## Data Mining Process

### Deploy models in the business process

- **Business issue**
  - The model deployment shouldn’t disturb the normal business process but is better incorporated into it
- **Technical Issues**
  - Understand the deployment environment
  - Develop a good deployment strategy that suits best the IT environment
- **Alternatives:**
  - Export the models from the data mining tool and integrate them into the data warehouse environment
  - Couple the data mining tool to the data warehouse
  - Extract data from the data warehouse and import it to the data mining tool to run the models
  - Implement a result tracking process

### Measure ROI

- **Methods to measure ROI**
  - Profit increase
  - Competition competence increase
  - Cost saving
  - Business process efficiency
  - System improvement
  - Business process reengineering

    - Garbage in, garbage out

### Why数据仓库

#### Common Data Problems in Enterprises

- **Scattered**
  - Data are scattered in different legacy systems in different formats
- **No standard**
  - Data are not standardized (e.g. in Customer Information System, the name of a person is Bill Gates; but in the Mailing System, the name of that person is Gates, Bill)
- **Inconsistent**
  - Contradictory data are found in different systems (e.g. in one system, the gender code of a person is Male; but in another system, the title of that person is Miss)
- Not enough historic data
  - Usually in legacy systems, old data (say one or two months before) has always been archived to tapes instead of online
- Long access time
  - As data has to be retrieved, merged, organized and analyzed manually, it takes a lot of time to get the business information
- Inflexible MIS Systems
  - Existing MIS systems cannot fulfill the rapidly changing business needs

#### Solutions to the Data Problems

- Build data warehouses to
  - Integrate data
  - Standardize data definitions
  - Clean data

### Benefits of Data Warehouse

- A central place of information
- A single view of truth as data have been standardized and cleaned
- Historic data can be kept (usually at least one year) to allow trend analysis
- Shorten the time for data analysis as data is centralized and organized in a good way for decision making support

Better Knowledge about Business → More Competitive Power → More Customer → More Business → More $$
