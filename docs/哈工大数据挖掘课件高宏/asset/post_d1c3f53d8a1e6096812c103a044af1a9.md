
## 7.2.2 Hierarchical methods

### CURE

算法步骤：

- 从源数据对象中抽取一个随机样本S；
- 将样本S分割为一组划分；
- 对每个划分局部地进行聚类；
- 通过随机取样剔除孤立点。如果一个簇增长太慢就去掉它；
- 对局部的簇进行聚类。
- 用相应的簇标签来标记每个簇。

### Example

对象的一个随机样本

对象被划分和局部聚类，每个簇的代表点用“+”标记

局部聚类被进一步地聚类，对每个新簇，代表点向簇中

最后的结果簇是非球形的

## 7.2.3 Density-Based Clustering Methods

![](img/76d573223e44fade1c0950849390a4b3_314_0.png)

- 为了发现任意形状的聚类结果，提出了基于密度的聚类方法；
- 将簇看做是数据空间中被低密度区域分割开的高密度对象区域
- 其主要思想是

只要临近区域的密度（样本的数目）超过某个阈值则继续聚类。即对于给定簇中的每个样本，在一个给定范围的区域中必须至少包含某个数目的样本

## 7.2.3 Density-Based Clustering Methods

Major features:

- Discover clusters of arbitrary shape
- Handle noise
- One scan
- Need density parameters as termination condition

Several interesting studies:

- DBSCAN: Ester, et al. (KDD'96)
- OPTICS: Ankerst, et al. (SIGMOD'99).
- DENCLUE: Hinneburg & D. Keim (KDD'98)
- CLIQUE: Agrawal, et al. (SIGMOD'98)

## Density Concepts

Two parameters:

- ε-邻域：给定对象半径ε内的区域称为该对象的ε-邻域。ε是邻域的最大半径。
- MinPts: 某个点的ε-邻域内的最少对象个数；

N_ε(p): 对象p的ε-邻域内的所有对象的集合

{q belongs to D | dist(p,q) <=ε}

Core object (CO)

- P is called a core object if |N_ε(P)|≥ MinPts, given ε and MinPts.

## Density Concepts

- Directly density reachable (DDR)

给定一个对象集合 D，如果 p 是在 q 的 ε -邻域内，而 q 是一个核心对象，则对象 p 从对象 q 出发是直接密度可达的(directly density-reachable)。

## Density Concepts

### Density reachable

如果存在一个对象链 p₁, ..., pₙ, p1=q, pₙ=p, pᵢ∈D, (1≤i≤n), pᵢ₊₁ 是从 pᵢ 关于 ε 和 MinPts 直接密度可达的，则对象 p 是从对象 q 关于 ε 和 MinPts 密度可达的 (density-reachable)。

![](img/76d573223e44fade1c0950849390a4b3_318_0.png)

## Density Concepts

### Density-connected

如果对象集合 D 中存在一个对象 O，使得对象 p 和 q 是从 O 关于 ε 和 MinPts 密度可达的，那么对象 p 和 q 是关于 ε 和 MinPts 密度相连的。

![](img/76d573223e44fade1c0950849390a4b3_319_0.png)

## Density Concepts

- 密度可达是直接密度可达的传递闭包，这种关系是非对称的
- 只有核心对象之间是相互密度可达的。
- 而密度相连性是一个对称的关系。

## DBSCAN

### Density-Based Spatial Clustering of Applications with Noise

基于高密度连接区域的聚类方法

- 一个基于密度的簇是：基于密度可达性的最大的密度相连对象的集合。
- 不包含在任何簇中的对象被认为是“噪声”。
- Discovers clusters of arbitrary shape in spatial databases with noise

## DBSCAN

### 算法步骤

- Arbitrary select a point *p*
- Retrieve all points density-reachable from *p* w.r.t *ε* and *MinPts*.
- If *p* is a core point, a cluster is formed.
- If *p* is a border point, no points are density-reachable from *p* and DBSCAN visits the next point of the database.
- Continue the process until all of the points have been processed.

## Grid-based method

- Using multi-resolution grid data structure
- 将空间量化为有限数目的单元，这些单元形成网格结构，所有的聚类操作都在网格上进行。
- 优点：
  - 处理速度快，处理时间独立于数据对象的数目，仅依赖于量化空间中每一维上的单元数目。
- Several interesting methods
  - STING (a STatistical INformation Grid approach) by Wang, Yang and Muntz (1997)
  - WaveCluster by Sheikholeslami, Chatterjee, and Zhang (VLDB’98)
    - A multi-resolution clustering approach using wavelet method
  - CLIQUE: Agrawal, et al. (SIGMOD’98)

## Model-based method

- a model-based method hypothesizes a model for each of the clusters, and finds the best fit of the data to that model
- representatives:
  - COBWEB
  - CLASSIT
  - AutoClass
  - Competitive learning
  - SOM (Self-Organizing Maps)

## 离群点发现

- 什么是离群点?
  - The set of objects are considerably dissimilar from the remainder of the data
  - Example: Sports: Michael Jordon, Wayne Gretzky, ...
- 问题
  - Find top n outlier points
- 应用:
  - Credit card fraud detection
  - Telecom fraud detection
  - Customer segmentation
  - Medical analysis
