# Data mining applications —an example

+   - Data mining solution:
+     - Select customers from a previous campaign data.
+     - Attach responded or non-responded identification to the selected customer records
+     - Divide the selected customer data into training, testing and evaluation data sets
+     - Use neural network or decision tree algorithms to build prediction models from the training data set
+     - Test and evaluate the models with the testing and evaluation data sets.

# Data mining applications —an example

+   - Data mining solution:
+     - Apply the models to customers to select a mailing list.
+       All customers in the mailing list are predicted as potentially responding customers.
+     - Post product invitations to the selected customers.
+     - Collect and analyze the campaign results.
+     - Adjust the prediction models with the new data.

# Real Data Mining Work

+   - A real data mining work is more than running a data mining algorithm on the sample data
+   - It requires
+     - Methodology
+     - Process

# Data Mining Process

+   1. Identify business problems.
+   2. Identify and study data sources, and select data.
+   3. Extract and preprocess data.
+   4. Mine data, e.g., discovering association rules or building predictive models.
+   5. Verify the mining results.
+   6. Deploy models in the business process.
+   7. Measure ROI.(Return Of Invest)
