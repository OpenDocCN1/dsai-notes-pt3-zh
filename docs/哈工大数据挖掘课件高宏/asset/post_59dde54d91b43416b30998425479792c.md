## No Free Lunch

Generally, there is no algorithm which is consistently better than other algorithms

The No Free Lunch Theorem states that if an algorithm performs well on a certain class of problems then it necessarily pays for that with degraded performance on the set of all remaining problems

- D.H. Wolpert and W.G. Macready. No free lunch theorems for search. IEEE TEC, 1997, 1(1): 67-82
- D.H. Wolpert and W.G. Macready. No free lunch theorems for optimization. Tech. Rep. SFI-TR-95-02-010, Santa Fe Institute, 1995.

Different algorithms usually have different pros and cons, therefore, it is important to know the real strength (weakness) of an algorithm and when should it be used

## Linear regression and multiple regression

- Linear regression
- 数据用直线建模：
  Y=α+βX，其中，
- α和β是回归系数，分别表示直线在Y轴的截距和直线的斜率。
- α和β可以用最小二乘法求解。
- 给定s个样本或形如(x₁,y₁),(x₂,y₂),....,(xₛ,yₛ)的数据点，回归系数α和β可以用下式计算：

β = Σᵢ(xᵢ - x̄)(yᵢ - ȳ) / Σᵢ(xᵢ - x̄)²      α = ȳ - βx̄

其中，x̄是x₁,x₂,...,xₛ的平均值，ȳ是y₁,y₂,...,yₛ的平均值

## Linear regression and multiple regression

- **Multiple regression**
  - 响应变量Y是一个多维特征向量的线性函数。
  - Y=α+βX₁+χX₂+δX₃+……
  - 其中，可以用最小二乘法求解系数α, β, χ, δ等。

## Nonlinear regression

- **Polynomial regression 多项式回归**
  - data are modeled to fit a polynomial function
    $Y = \alpha + \beta_1 X + \beta_2 X^2 + \beta_3 X^3 + ......$
  - it can be converted to linear regression problem, e.g. $X_1 = X$, $X_2 = X^2$, $X_3 = X^3$, ......
  - there are also nonlinear regression models that cannot be converted to a linear model. For such cases, it may be possible to obtain least-square estimates through extensive calculations on more complex formulae

## 什么是聚类分析？

- 簇 Cluster: a collection of data objects
  - 同一个簇内的数据是相似的
  - 不同簇间的数据是相异的
- 聚类分析
  - 将一组数据对象划分为若干个簇
- 聚类是一种无指导的分类: 无预先定义的类
- 典型应用：
  - as a stand-alone tool to gain insight into the distribution of data
  - to serve as a preprocessing step for other data mining tasks
