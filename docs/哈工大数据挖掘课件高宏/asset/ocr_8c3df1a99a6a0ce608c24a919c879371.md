# 1.4 Data Mining Functionalities

# Data Mining Functionalities

+   - Association (correlation and causality)
+     - The first association rule discovery algorithm was designed for basket analysis in retail.
+       - Diaper → Beer [0.5%, 75%]
+     - Such algorithm has been found useful in other applications.
+       - e.g., associations of drugs.

# Data Mining Functionalities

+   - Classification (supervised)
+     - the most common data mining task
+     - E.g., Classify credit applicants as low, medium and high risks.
+     - Classify customers as profitable, non-profitable and costly customers.
+     - To find a model for predicting the class labels of unseen data
+     - Algorithms:
+       - Decision-tree, Bayesian classifiers, Genetic algorithms, Neural network, K-nearest neighbors, Support Vector Machines

# Data Mining Functionalities

+   - Prediction
+     - Building prediction models, to predict some unknown or missing numerical values
+     - Difference from classification
+     - Example
+       - Predict whether a mobile phone customer is likely to churn or not.

# Data Mining Functionalities

+   - Cluster analysis
+     - Clustering is a process of partitioning a set of objects such as customers into groups in which the objects in the same group are similar to each other and the objects in different groups are dissimilar, according to some similarity measure.
+     - Class label is unknown: Group data to form new classes
+     - Maximizing intra-class similarity & minimizing interclass similarity
+     - often called unsupervised learning
