
## Apriori 算法

- 如何利用 $L_k$ 计算 $L_{k+1}$
  - 产生候选 $k+1$-项集 $C_{k+1}$
  - 扫描数据库，确定 $C_{k+1}$ 中每个候选项集的计数，从而得到 $L_{k+1}$。

## Apriori 算法

- 如何产生候选 k+1-项集 C_{k+1}
  - （假设事务或项集中的项已经按字典序排序）

- 连接
  - 通过 L_k 与自己连接，产生候选 k+1-项集 C_{k+1}

- 对于 L_k 中的任意两个项集 i_r、j_s，若 i 和 j_s 的前 k-1 个项是相同的，则产生新项集 i[1] i[2]... i[k] j_s[k]，并加入到 C_{k+1} 中。

- 裁减
  - 根据 Apriori 推理，对 C_{k+1} 进行裁减。

假设有2-项集L₂如下：

{{I1,I2}, {I1,I3}, {I1,I5}, {I2,I3}, {I2,I4}, {I2,I5}}

候选3-项集产生过程如下：

首先做L₂的自连接，得到如下结果：

{ {I1,I2,I3} {I1,I2,I5} {I1,I3,I5} {I2,I3,I4} {I2,I3,I5} {I2,I4,I5} }

然后对自连接的结果进行裁减，去掉不可能的3-项集

最后，得到最终的候选3-项集如下：

{ {I1,I2,I3} {I1,I2,I5} }

对于 l= {I1,I2,I5}

- I1∧I2⇒I5 conf=2/4=50%
- I1∧I5⇒I2 conf=2/2=100%
- I2∧I5⇒I1 conf=2/2=100%
- I1 ⇒ I2∧I5 conf=2/6=33%
- I2⇒ I1∧I5 conf=2/7=29%
- I5 ⇒ I1∧I2 conf=2/2=100%

## Apriori算法流程

Input: DB: database of transactions; min_sup: minimum support threshold

Output: L: frequent itemsets in DB

Method:

- 1. C₁ = Itemsets of size one in I;
- 2. Determine all frequent itemsets of size 1, L₁;
- 3. i = 1;
- 4. Repeat
- 5. i = i + 1;
- 6. Cᵢ = Apriori-Gen(Lᵢ₋₁);
- 7. Count Cᵢ to determine Lᵢ;
- 8. until no more frequent itemsets found;

## Apriori算法流程（cont.）

生成辅助频繁k+1-项集

```
procedure apriori_gen(L_k: frequent k-itemsets; min_sup: minimum support)
  for each itemset l1 ∈ L_k
    for each itemset l2 ∈ L_k
      if (l1[1] = l2[1]) ∧ (l1[2] = l2[2]) ∧ ... ∧ (l1[k-1] = l2[k-1]) ∧ (l1[k] < l2[k]) then {
        c = l1 ⋈ l2; // join step: generate candidates
        if has_infrequent_subset(c, L_k) then
          delete c; //prune step:remove unfruitful candidate
        else add c to C_{k+1};
      }
  return C_{k+1};
```

## Apriori算法流程 (cont.)

对辅助频繁k+1-项集的裁减

```
procedure has_infrequent_subset(c: candidate (k+1)-itemset; L_k: frequent k-itemsets)
for each k-subset s of c
  if s ∉ L_k then
    return TRUE;
return FALSE;
```

## 生成关联规则

```
Input:
    D        //Database of transactions
    I        //Items
    L        //Large itemsets
    s        //Support
    α        //Confidence
Output:
    R        //Association Rules satisfying s and α
ARGen Algorithm:
    R = ∅;
    for each l ∈ L do
        for each x ⊂ l such that x ≠ ∅ and x ≠ l do
            if support(l) / support(x) ≥ α then
                R = R ∪ {x ⇒ (l − x)};
```
