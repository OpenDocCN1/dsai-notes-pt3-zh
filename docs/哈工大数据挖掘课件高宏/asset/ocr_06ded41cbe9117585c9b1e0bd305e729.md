# 聚类中的属性类型

+   - 二元变量（属性）
+     - 二元变量只有两个状态：
+       0或1
+     - 0表示该变量为空，1表示该变量存在。

|  | Object j |  |  |
|---|---|---|---|
|  | 1 | 0 | sum |
| Object i | 1 | a | b | a+b |
|  | 0 | c | d | c+d |
|  | sum | a+c | b+d | p |

+   - 表中 a 是对于对象 i 和 j 值都为 1 的变量（属性）的数目
+   - 每个对象有 p 个变量（属性），p = a + b + c + d
