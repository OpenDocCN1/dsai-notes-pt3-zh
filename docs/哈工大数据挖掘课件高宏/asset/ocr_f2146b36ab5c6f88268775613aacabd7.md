# 5.1 基本概念

+   - 关联规则的类型
+     - 根据规则中所处理的值类型
+       - 布尔关联规则
+         `buys(X, “diapers”) ⇒ buys(X, “beers”) [0.5%, 60%]`
+       - 量化关联规则
+         `age(X, “30-39”) ∧ income(X, “42-48K”) ⇒ buys(X, “computer”) [1%, 75%]`
+     - 根据所涉及的数据维
+       - 单维关联规则
+         `buys(X, “diapers”) ⇒ buys(X, “beers”) [0.5%, 60%]`
+       - 多维关联规则
+         `age(X, “30-39”) ∧ income(X, “42-48K”) ⇒ buys(X, “computer”) [1%, 75%]`
