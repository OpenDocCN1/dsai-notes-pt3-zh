# Nonlinear regression

+   - **Polynomial regression 多项式回归**
+     - data are modeled to fit a polynomial function
+       $Y = \alpha + \beta_1 X + \beta_2 X^2 + \beta_3 X^3 + ......$
+     - it can be converted to linear regression problem, e.g. $X_1 = X$, $X_2 = X^2$, $X_3 = X^3$, ......
+     - there are also nonlinear regression models that cannot be converted to a linear model. For such cases, it may be possible to obtain least-square estimates through extensive calculations on more complex formulae
