# Common Data Problems in Enterprises

+   - Not enough historic data
+     - Usually in legacy systems, old data (say one or two months before) has always been archived to tapes instead of online
+   - Long access time
+     - As data has to be retrieved, merged, organized and analyzed manually, it takes a lot of time to get the business information
+   - Inflexible MIS Systems
+     - Existing MIS systems cannot fulfill the rapidly changing business needs
