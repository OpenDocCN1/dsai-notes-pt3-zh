| 消息出现的概率 | 1个消息的信息量 | n中的消息个数 | 它的信息量 |
|---|---|---|---|
| p₁ | -log p₁ | n p₁ | - n p₁ log p₁ |
| p₂ | -log p₂ | n p₂ | - n p₂ log p₂ |
| p₃ | -log p₃ | n p₃ | - n p₃ log p₃ |

+   - 则全部信息量为：
+     -n p₁ log p₁ - n p₂ log p₂ - n p₃ log p₃
+   - 平均信息量(熵)为：
+     (-n p₁ log p₁ - n p₂ log p₂ - n p₃ log p₃)/n
+     = -p₁ log p₁ - p₂ log p₂ - p₃ log p₃
+   - 熵的一般形式为：
+     $I = -\sum_{i} p_i \log p_i$
