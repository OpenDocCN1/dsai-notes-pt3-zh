## 多维数据集上的代数操作

- • 幂聚集集cube

- 给定一个多维数据集合R(D₁, D₂, ..., Dₙ; M₁, M₂, ..., Mₖ), R上的幂聚集集操作表示为Cube(R, F), 其中F = {f₁, f₂, ..., fₖ}, fⱼ是Mⱼ上聚集函数，如求最大值、最小值、均值、和、计数等。Cube(R, F)的结果Rel定义如下：

For {D₁, D₂, ..., Dₙ}的每个子集合sub Do 
Rel=Rel∪{Agg(R, sub, F)};

EndFor.

- 如果R中有n个维属性，则Cube(R, F)的结果Rel包含R的2ⁿ个聚集操作，每个操作的聚集属性集合是{D₁, D₂, ..., Dₙ}的一个子集合。

> Cube(R,F)操作的结果得到R对应的一个Data Cube
