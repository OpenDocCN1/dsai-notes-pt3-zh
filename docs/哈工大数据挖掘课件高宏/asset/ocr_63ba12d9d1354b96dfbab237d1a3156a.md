# Why data preprocessing?

+   - **Data in the real world is dirty**
+     - 不完整的
+       - 存在空值, 缺少感兴趣的属性或仅包含聚集数据
+       - 例如: occupation=""
+     - 含有噪声的
+       - 含有错误或存在偏离期望的孤立点值
+       - e.g., Salary="-10"
+     - 不一致的
+       - 数据值存在偏差
+         - e.g., Age="42" Birthday="03/07/1997"
+         - e.g., Was rating "1,2,3", now rating "A, B, C"
+         - e.g., discrepancy between duplicate records
