# Apriori算法流程（cont.）

生成辅助频繁k+1-项集

```
procedure apriori_gen(L_k: frequent k-itemsets; min_sup: minimum support)
  for each itemset l1 ∈ L_k
    for each itemset l2 ∈ L_k
      if (l1[1] = l2[1]) ∧ (l1[2] = l2[2]) ∧ ... ∧ (l1[k-1] = l2[k-1]) ∧ (l1[k] < l2[k]) then {
        c = l1 ⋈ l2; // join step: generate candidates
        if has_infrequent_subset(c, L_k) then
          delete c; //prune step:remove unfruitful candidate
        else add c to C_{k+1};
      }
  return C_{k+1};
```
