S: training set

平均信息量（熵）：表示分类在训练集中分布的不确定性
I(S1,S2,...,Sm) = - Σ_{i=1}^{m} |S_i|/|S| log₂ |S_i|/|S|

条件熵：已知属性A的分类分布后，分类在训练集中分布的不确定性。A with values {a₁,a₂,...,a_v}
E(A)= Σ_{j=1}^{v} |S₁j|+...+|S_mj| / |S| I(S1j,...,Smj)
