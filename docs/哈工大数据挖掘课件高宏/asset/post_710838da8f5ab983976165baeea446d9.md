
## 聚类中的属性类型

### Nominal attributes

- 标称变量是二元变量的推广，它可以具有多于两个的状态，比如变量 map_color 可以有 red, yellow, blue, green 四种状态。

- 两种计算相异度的方法：

  - Method 1：简单匹配方法

    - $m$: # of matches, $p$: total # of variables

    $$d(i, j) = (p - m) / p$$

  - Method 2：使用二元变量

    - 为每一个状态创建一个新的二元变量，可以用非对称的二元变量来编码标称变量。

### Ordinal Variables 序数型变量

- 一个序数型变量既可以是离散的、也可以是连续的
- Order is important, e.g., rank
- Can be treated like interval-scaled
  - replace $x_{if}$ by their rank $r_{if} \in \{1, \ldots, M_f\}$
  - map the range of each variable onto [0, 1] by replacing $i$-th object in the $f$-th variable by $z_{if} = \frac{r_{if} - 1}{M_f - 1}$
  - compute the dissimilarity using methods for interval-scaled variables

### Ratio-Scaled Variables 比例标度

- are continuous attributes of a nonlinear scale
- three possible methods:
  - treat them like interval-scaled variables—*not a good choice!*
  - perform transformations, then treat them as interval-scaled attributes
    - e.g. Logarithmic transformation $y_i = \log(x_i)$
  - treat them as continuous ordinal attributes
    - replacing real values by ranks, mapping ranks to [0, 1], and then applying Minkowski distance

### Attributes of mixed types

- transform the dissimilar measures of different kinds of attributes to a same range, e.g. [0, 1], then combine the dissimilar measures
- weights can be used to express the relative importance of the attributes
- example:

$$d(i, j) = \sum_{k} w_k d_{ij}^{A_k}$$

where $w_k$ is the weight of attribute $A_k$, $d_{ij}^{A_k}$ is the dissimilarity of the $i$-th object and the $j$-th object on attribute $A_k$. $d_{ij}^{A_k}$ has already been normalized to [0, 1].

## 簇间的距离度量标准

用于簇 $C_i$ 和簇 $C_j$ 之间的距离度量标准是：

- 最小距离：

$$D_{\min}(C_i, C_j) = \min |X_i - X_j|$$

其中 $X_i \in C_i$ 和 $X_j \in C_j$

- 最大距离：

$$D_{\max}(C_i, C_j) = \max |X_i - X_j|$$

其中 $X_i \in C_i$ 和 $X_j \in C_j$

- 均值距离：

$$D_{mean}(C_i,C_j) = |m_i - m_j|$$

其中 $m_i$ 和 $m_j$ 是 $C_i$ 和 $C_j$ 的质心

- 平均距离：

$$D_{avg}(C_i,C_j) = \frac{1}{n_i n_j} \sum \sum |X_i - X_j|$$

其中 $X_i \in C_i$ 和 $X_j \in C_j$，且 $n_i$ 和 $n_j$ 是类 $C_i$ 和 $C_j$ 中的样本数。

## 聚类的准则函数

- 误差平方和准则（sum-of-squared-error criterion）：

$$J_e = \sum_{i=1}^{k} \sum_{X \in C_i} |X - m_i|^2$$

其中 $X \in C_i$，$m_i$ 是 $C_i$ 的质心。

$J_e$ 即所有样本的平方误差和。

使生成的结果簇尽可能地紧凑和独立。

### 7.2.1 Partitioning methods

- 划分方法的基本思想是，给定一个 *n* 个样本的数据库和参数 *k*，划分方法将数据划分为 *k* 个划分（*k<=n*），每个划分表示一个簇，同时满足：
  - 每个簇至少包含一个样本；
  - 每个样本必须属于且仅属于一个簇。

- each cluster is represented by the mean value of the data in the cluster
- each cluster is represented by one of the objects near the center of the cluster

- k-means, k-medoids, k-modes
- PAM (Partition Around Medoids)
- CLARA (Clustering LARGE Applications)
- CLARANS (Clustering LARGE Applications based upon Randomized Search)

### The K-Means Clustering Method

- 以簇中对象的平均值作为参照点
  - each cluster is represented by the mean value of the data in the cluster
- 最小化所有对象与其参照点之间的相异度之和

- Given *k*, the *k-means* algorithm is implemented in four steps:
  - 选择一个含有随机选择样本的*k*个簇的初始划分，计算这些簇的质心。
  - 根据欧氏距离把剩余的每个样本分配到距离它最近的簇质心的一个划分。
  - 计算被分配到每个簇的样本的均值向量，作为新的簇的质心。
  - 重复2,3直到*k*个簇的质心点不再发生变化或平方误差准则最小。

#### Example

K=2

Arbitrarily choose K object as initial cluster center

Assign each objects to most similar center

Update the cluster means

reassign

reassign

Update the cluster means
