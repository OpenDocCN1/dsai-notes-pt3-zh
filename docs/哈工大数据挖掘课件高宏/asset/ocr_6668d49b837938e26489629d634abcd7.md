# Linear regression and multiple regression

+   - Linear regression
+   - 数据用直线建模：
+     Y=α+βX，其中，

+   - α和β是回归系数，分别表示直线在Y轴的截距和直线的斜率。
+   - α和β可以用最小二乘法求解。
+   - 给定s个样本或形如(x₁,y₁),(x₂,y₂),....,(xₛ,yₛ)的数据点，回归系数α和β可以用下式计算：

β = Σᵢ(xᵢ - x̄)(yᵢ - ȳ) / Σᵢ(xᵢ - x̄)²      α = ȳ - βx̄

其中，x̄是x₁,x₂,...,xₛ的平均值，ȳ是y₁,y₂,...,yₛ的平均值
