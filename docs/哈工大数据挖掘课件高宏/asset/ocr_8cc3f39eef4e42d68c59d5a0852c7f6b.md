# 其它的距离度量

+   Minkowski distance(明考斯基距离，欧几里得距离与曼哈坦距离的概括)

d(i, j) = (|x_{i1} - x_{j1}|^q + |x_{i1} - x_{j1}|^q + … + |x_{in} - x_{jn}|^q)^{1/q}

+   if the attributes have different importance, *weights* can be used:

d(i, j) = (w_1|x_{i1} - x_{j1}|^q + w_2|x_{i1} - x_{j1}|^q + … + w_n|x_{in} - x_{jn}|^q)^{1/q}
