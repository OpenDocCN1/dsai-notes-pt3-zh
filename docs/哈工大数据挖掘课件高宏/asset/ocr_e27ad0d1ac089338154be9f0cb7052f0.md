# 支持度-置信度框架的局限

+   支持度的缺陷
+   
+   很多潜在的有意义的模式由于包含支持度小的项而被删除

+   置信度问题
+   
+   例如：
+   产生关联规则：{茶} -> {咖啡}
+   支持度：15%，置信度75%

| | 咖啡 | 非咖啡 | |
|---|---|---|
| 茶 | 150 | 50 | 200 |
| 非茶 | 650 | 150 | 800 |
|  | 800 | 200 | 1000 |

但是，所有人中，不管他是否喝茶，喝咖啡的人的比例为80%，而喝咖啡的饮者却只占75%。

这意味着，一个人如果喝茶，则他喝咖啡的可能性由80%降到75%。

因此，尽管规则{茶} -> {咖啡}有很高的置信度，但是它却是一个误导！

> Strong association rules may not be interesting
