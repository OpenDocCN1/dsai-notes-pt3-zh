## How to construct a decision tree?(cont.)

- Other Attribute Selection Measures
  - Gain ratio
  - a shortcoming of information gain is its preference to attributes with lots of values. In order to overcome this shortcoming, J. R. Quinlan used gain ratio in C4.5 instead of information gain

```
Gain_ratio(A) = Gain(A) / IV(A)
```

```
IV(A) = - sum_{j=1}^{v} (S'_j / S) log_2 (S'_j / S)
```

where attribute A is selected to partition the instance set into the subsets {S'_1, S'_2, ..., S'_v}

## How to construct a decision tree?(cont.)

### Other Attribute Selection Measures

- Gini index (CART, IBM Intelligent Miner)
- S: training set
- S_i: training instances of class C_i (i= 1, ..., m)
- a_j: values of attribute A (j= 1, ..., v)
- the gini of S is

Gini(S) = 1 - Σ_{i=1}^{m} (S_i / S)^2

- suppose attribute A is selected to partition the instance set into the subsets {S'_1, S'_2, ..., S'_v}, then the gini of A is

Gini(A) = Σ_{j=1}^{v} (S'_j / S) Gini(S'_j)

the attribute provides the smallest gini is chosen to split the node

## Extracting Classification Rules from Trees

- Represent the knowledge in the form of IF-THEN rules
- One rule is created for each path from the root to a leaf
- Each attribute-value pair along a path forms a conjunction
- The leaf node holds the class prediction
- Rules are easier for humans to understand

IF age = "<=30" AND student = "no" THEN buys_computer = "no"
IF age = "<=30" AND student = "yes" THEN buys_computer = "yes"
IF age = "31...40" THEN buys_computer = "yes"
IF age = ">40" AND credit_rating = "excellent" THEN buys_computer = "yes"
IF age = "<=30" AND credit_rating = "fair" THEN buys_computer = "no"

## 6.2.2 Bayesian Classification

## Basic concepts

- Bayesian classifiers have exhibited high accuracy and fast speed when applied to large databases
- What is Bayesian classification
  - based on Bayes theorem

## Basic concepts

- 假设X为一个数据样本，其类标识未知
- H为一个假设： X属于类-C
- 分类问题可以描述为： 确定 P(H/X):
  - 在已知样本X的情况下，H成立的概率

## Basic concepts

- P(H|X) is the posterior probability(后验概率), 或条件X下H的后验概率
  - Example
  - 假设数据样本由水果组成，用它们的颜色和形状描述。
  - 假设X表示红色和圆的，H表示假设X是苹果，则
  - P(H|X)反映当我们看到X是红色并且是圆的时，我们对X是苹果的确信程度。

## Basic concepts

- P(H): prior probability of hypothesis H
  - Example
  - 任意给定的数据样本为苹果的概率，而不管数据样本看上去如何。
- 后验概率P(H|X)比先验概率基于更多的信息(如背景知识)。
- P(H)独立于X

## Basic concepts

- **P(X|H)是条件H下，X的后验概率**
  - X表示红色和圆的，H表示假定X是苹果
  - P(X|H)是“X是红色的且为圆的”的概率。
- **P(X)是X的先验概率**
  - 由水果中取出一个数据样本是“红色的且为圆的”的概率

## Basic concepts

- **Bayes theorem**

P(H|X) = P(X|H)P(H) / P(X)

## Naive Bayesian classifier

- 假定有 $m$ 个类：$C_1, C_2, ……, C_m$
- $n$ 个属性：$A_1, A_2, ……, A_n$
- 每个数据样本用一个 $n$ 维特征向量 $X=(x_1,x_2,…,x_n)$ 表示，其中 $x_k$ 是 $X$ 在属性 $A_k$ 上的取值
- 给定一个未知的数据样本 $X$(即没有类标号)，分类法将预测 $X$ 属于具有最高后验概率(条件 $X$ 下)的类。即，朴素贝叶斯分类将未知的样本分配给类 $C_i$，当且仅当 $P(C_i|X)>P(C_j|X)$ for $1\leq j\leq m,j\ne i$
- $P(C_i|X)$ 最大的类 $C_i$ 称为最大后验假设。

## Naive Bayesian classifier

- 根据贝叶斯定理
  $$P(C_i|X)=\frac{P(X|C_i)P(C_i)}{P(X)}$$
- 由于 P(X) 对所有类是一个常数, 因此只需要 P(X|C_i)P(C_i) 最大即可。
  - P(C_i) 可以用 S_i/S 来估计, 其中 S_i 是类 C_i 中的训练样本数, 而 S 是训练样本的总数
