# Closed Patterns and Max-Patterns

+   - Max-patterns: borders of frequent patterns
+     - A subset of max-pattern is frequent
+     - A superset of max-pattern is infrequent

+   - 如果频繁项集F 的所有超集都是非频繁项集，那么称F为最大频繁项集，所有F的集合称为最大频繁项集集合 (maximum frequent sets).

+   - 显然，任何频繁项集都是最大频繁项集的子集。

+   - 发现所有频繁项集的问题可以转化为发现所有最大频繁项集的问题.

+   - BCDE, ACD are max-patterns
+   - BCD is not a max-pattern
