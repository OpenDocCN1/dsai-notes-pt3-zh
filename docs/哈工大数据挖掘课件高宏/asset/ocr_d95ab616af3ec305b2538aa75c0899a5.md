# Why data is dirty

+   - **Incomplete data comes from**
+     - 输入时认为是不重要的，而分析时是需要的
+     - 人工理解错误、硬件设备故障等
+   - **Noisy data comes from the process of data**
+     - 收集数据的设备故障
+     - 人工输入错误
+     - 数据传输时
+   - **Inconsistent data comes from**
+     - 数据来源于不同的数据源，命名、编码不一致
+     - 违背了函数依赖关系
+   - 重复记录也需要清洗
