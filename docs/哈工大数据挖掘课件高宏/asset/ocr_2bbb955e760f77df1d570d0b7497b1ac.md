# Data Integration

+   - 数据集成

combines data from multiple sources into a coherent store

+   - 模式集成

+   - 集成不同数据源上的元数据
+   - 实体识别问题:
+     - 一个数据库中的cust-id和另一个数据库中的B.cust是否指的是同一个实体。
+     - 例如，family name vs. surname

+   - 语义异构：发现和解决数据值的冲突问题
+     - 对于同一个实体，在不同的数据源中具有不同的值，如度量单位；175cm vs. 1.75m
+     - 原因：基于不同的表示方式、度量单位或编码等
