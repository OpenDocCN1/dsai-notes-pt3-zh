# 聚类中的属性类型

+   Interval-valued variables区间标度

区间标度变量的度量单位直接影响聚类分析的结果。

+   例如，将高度的度量单位由“米”改为“英寸”，可能产生非常不同的聚类结果

为避免对度量单位选择的依赖，数据应当标准化。
给定一个变量f的度量值，可以进行如下变换：

+   计算平均的绝对偏差：

s_f = 1/n (|x_1f - m_f| + |x_2f - m_f| + ... + |x_nf - m_f|)

+   Where m为均值

+   计算标准化的度量值 (Z-score) m_f = 1/n (x_1f + x_2f + ... + x_nf)

z_if = (x_if - m_f) / s_f
