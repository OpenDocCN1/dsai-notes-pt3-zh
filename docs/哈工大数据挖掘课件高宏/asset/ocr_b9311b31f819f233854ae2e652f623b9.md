# Naive Bayesian classifier

+   - A simplified assumption:
+     *class conditional independence*: assume that the effect of an attribute value on a given class is independent of the values of other attributes
+     $P(X|C_i) = \prod_{k=1}^{n} P(x_k|C_i)$

+   - 若 $A_k$ 为分类属性，则 $P(x_k|C_i)=s_{ik}/s_i$，其中 $s_{ik}$ 是在属性 $A_k$ 上具有值 $x_k$ 的类 $C_i$ 的训练样本数，而 $s_i$ 是 $C_i$ 中的训练样本数。

+   - 若 $A_k$ 为连续值属性，则通常假定该属性服从高斯分布：
+     $P(x_k|C_i)=g(x_k,\mu_{C_i},\sigma_{C_i})=\frac{1}{\sqrt{2\pi}\sigma_{C_i}}e^{-\frac{(x_k-\mu_{C_i})^2}{2\sigma_{C_i}^2}}$

+   - 给定类 $C_i$ 的训练样本属性 $A_k$ 的值，$g(x_k,\mu_{c_i},\sigma_{c_i})$ 是属性 $A_k$ 的高斯密度函数，而 $\mu_{c_i},\sigma_{c_i}$ 分别为平均值和标准差。
