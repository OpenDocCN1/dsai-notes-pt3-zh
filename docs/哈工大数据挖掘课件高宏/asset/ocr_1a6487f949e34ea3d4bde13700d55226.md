# 多媒体数据挖掘

+   - 多媒体数据的相似性搜索
+     - 基于数据描述的相似性搜索
+       - 如基于关键字、标题、尺寸、创建时间等
+     - 基于内容的相似性搜索
+       - 如颜色构成、纹理、形状等
+       - 基于图像样例的查询
+         - 找出与给定图像样本相似的图像
+         - 具体做法：把从样本中提取的特征向量与从图像数据库中提取的图像特征向量相比较，得到与样本相近的图像
+       - 基于图像特征描述的查询
+         - 给出图像的特征描述(颜色、纹理或形状)，把其转换为特征向量，与数据库中已有图像的特征向量匹配
