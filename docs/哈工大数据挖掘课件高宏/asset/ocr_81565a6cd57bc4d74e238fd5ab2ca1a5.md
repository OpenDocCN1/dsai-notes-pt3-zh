# 挖掘序列模式

+   - 问题定义
+     - 给定一个交易数据库D，其中
+     - 每一个记录为一个交易，其包含如下内容:
+       - Customer ID
+       - Transaction Time
+       - Set of items purchased

+   * No two transactions have same customer ID and transaction time
+   * Don’t consider quantity of items purchased. Item was either purchased or not purchased
