# 4：3_欢迎来到模块2

![](img/fec4b37ca9be4c87c501efcaced6d209_0.png)

在本节课中，我们将正式开始学习提示词工程，深入探讨如何精心设计和构建有效的提示词。我们已经对大型语言模型和ChatGPT及其底层技术有了基本了解，现在是将重点转向提示词工程的时候了。

在开始之前，有必要提醒你，提示词工程**不是编程**，也不像编程。它更像是使用日常语言与机器协作，告诉它你想要什么，指导它如何执行特定任务，并与它进行迭代式合作。这更像是与一位同事、合作者、导师或辅导员一起工作。实际上，你正在培养的技能更接近于与人协作所需的技能，而非与机器交互的技能，这非常不可思议。

在本模块的学习过程中，我们将通过一系列练习来培养一套非常具体的技能。以下是本模块将涵盖的核心技能：

![](img/fec4b37ca9be4c87c501efcaced6d209_12.png)

![](img/fec4b37ca9be4c87c501efcaced6d209_13.png)

*   **提示词构建**：学习如何实际组合和构建提示词。
*   **减少歧义**：学习如何降低你要求ChatGPT执行的任务中的模糊性。
*   **基于约束的提示**：学习如何围绕你希望ChatGPT为你做的事情以及你希望它返回的结果，设置特定或具体的约束条件。
*   **比较性提示工程**：学习如何让ChatGPT比较不同的事物，同时也尝试不同的方法来从ChatGPT中获得有用的输出。
