# 课程13：分组与汇总数据 📊

在本节课中，我们将学习如何使用 `tidyverse` 中的 `arrange`、`group_by` 和 `summarize` 命令来对数据进行排序、分组和汇总。这些是数据整理过程中非常关键的操作，能帮助我们更好地理解和分析数据。

---

## 数据排序：`arrange` 命令

上一节我们介绍了如何计算新列，本节中我们来看看如何对数据进行排序。`arrange` 是 `tidyverse` 中用于排序的命令，它类似于基础 R 包中的 `sort` 函数，但功能更强大。

使用 `arrange`，你可以根据一列或多列的值来改变数据集中行的顺序。例如，在我们一直使用的 CCES 数据样本中，如果想先按性别、再按七点政党认同对调查受访者进行排序，可以使用以下代码：

```r
CCES %>%
  arrange(gender, PID7)
```

当然，你也可以将排序后的数据保存到一个新的对象中。若要进行降序排序，只需将变量放入 `desc()` 函数中：

```r
CCES %>%
  arrange(desc(PID7))
```

---

## 数据分组：`group_by` 命令

排序完成后，有时我们需要根据某些列的值对数据进行分组。分组本身不会改变数据的顺序，但会改变数据框与其他 `tidyverse` 函数的交互方式。

以下是使用 `group_by` 函数设置分组的方法：

```r
CCES %>%
  group_by(gender)
```

分组后，你可以查看创建的分组对象以确认分组情况。如果想取消分组，可以使用 `ungroup` 函数。

`group_by` 单独使用并不十分有用，但与其他 `tidyverse` 函数结合时，尤其是与 `summarize` 结合，能发挥巨大作用。

---

## 数据汇总：`summarize` 命令

分组数据后，我们通常需要进行汇总分析。`summarize` 用于将数据表中的值缩减为单个汇总值，从而生成各列的汇总统计量，如均值、中位数、标准差等。

`summarize` 会创建一个新的数据框，并为每一列指定不同的汇总统计量。这类似于我们之前见过的数据框创建命令，但这里是为每个指定的汇总方式生成一个汇总值。

在 `summarize` 函数中，首先指定要汇总的数据框，然后为汇总列命名，并使用 R 函数生成该列的汇总统计量。例如：

```r
CCES %>%
  summarize(
    mean_PID7 = mean(PID7, na.rm = TRUE),
    mean_income = mean(family_income, na.rm = TRUE)
  )
```

如果你先使用 `group_by` 对数据进行分组，再使用 `summarize`，那么汇总统计量将按组生成：

```r
CCES %>%
  group_by(gender) %>%
  summarize(
    mean_PID7 = mean(PID7, na.rm = TRUE),
    mean_income = mean(family_income, na.rm = TRUE)
  )
```
