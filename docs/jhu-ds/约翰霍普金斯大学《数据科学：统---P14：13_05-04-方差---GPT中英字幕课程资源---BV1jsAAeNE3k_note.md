## 计算关键统计量

接下来，我们计算几个关键的数字。这里我计算了：
*   `x` 的方差
*   `x` 的方差除以 `n`
*   `x` 的标准差
*   `x` 的标准差除以 `n` 的平方根

所有数字都四舍五入到两位小数。

```r
var_x <- var(x)               # 样本方差
var_x_over_n <- var_x / n     # 样本均值的方差估计
sd_x <- sd(x)                 # 样本标准差
se_x <- sd_x / sqrt(n)        # 标准误
```

## 理解标准误

![](img/da494dcd9c14ca0cc75cb954cf868b55_23.png)

而 **0.01**（方差除以n）和 **0.09**（标准差除以根号n）这两个值，讨论的就不再是儿童身高的变异性了。它们讨论的是 **10个儿童身高平均值的变异性**。

![](img/da494dcd9c14ca0cc75cb954cf868b55_24.png)

![](img/da494dcd9c14ca0cc75cb954cf868b55_20.png)
![](img/da494dcd9c14ca0cc75cb954cf868b55_21.png)

因此，**0.09** 可能是最有意义的一个值，它就是 **标准误**。换句话说，它是 **N个儿童身高平均值的分布的标准差**。同样，在此例中，这是对标准误的一个估计，但它是我们根据现有数据能得到的最佳估计。

## 核心概念总结 📝

现在让我们总结一下所学内容，因为本节课涵盖了许多有些复杂的主题。我认为，理解统计学与不理解统计学的根本区别在于 **是否理解变异性**。如果要说哪一讲最重要，可能就是这一讲。

![](img/da494dcd9c14ca0cc75cb954cf868b55_31.png)

以下是本节课的核心要点总结：

![](img/da494dcd9c14ca0cc75cb954cf868b55_33.png)

![](img/da494dcd9c14ca0cc75cb954cf868b55_26.png)
![](img/da494dcd9c14ca0cc75cb954cf868b55_27.png)

**1. 样本方差与总体方差**
*   **样本方差** 是 **总体方差** 的一个估计量。
*   样本方差的分布以其所要估计的总体方差为中心。这是一个很好的性质，意味着它是 **无偏的**。
*   随着收集的数据增多，样本方差的分布会围绕其估计目标（总体方差）更加集中。这同样是一个好性质，意味着如果我们费力收集更多数据，就能得到更好的估计。

![](img/da494dcd9c14ca0cc75cb954cf868b55_31.png)
![](img/da494dcd9c14ca0cc75cb954cf868b55_33.png)
![](img/da494dcd9c14ca0cc75cb954cf868b55_35.png)

![](img/da494dcd9c14ca0cc75cb954cf868b55_35.png)

**2. 样本均值的分布**
*   从上节课我们知道，样本均值的分布以总体均值 `μ` 为中心。
*   本节课我们还知道，**样本均值的方差** 等于 **总体方差 `σ²` 除以样本量 `n`**。
*   其平方根，即 **`σ / √n`**，就是所谓的 **标准误**。

![](img/da494dcd9c14ca0cc75cb954cf868b55_36.png)

**公式表示如下：**
```
Var(样本均值) = σ² / n
标准误 (SE) = σ / √n
```

![](img/da494dcd9c14ca0cc75cb954cf868b55_36.png)
![](img/da494dcd9c14ca0cc75cb954cf868b55_38.png)

**3. 标准误的意义**
*   这些量（方差除以n和标准误）代表了从该总体中抽取的 **样本平均值的变异程度**。

![](img/da494dcd9c14ca0cc75cb954cf868b55_38.png)

![](img/da494dcd9c14ca0cc75cb954cf868b55_39.png)

![](img/da494dcd9c14ca0cc75cb954cf868b55_39.png)
![](img/da494dcd9c14ca0cc75cb954cf868b55_40.png)

![](img/da494dcd9c14ca0cc75cb954cf868b55_40.png)

**4. 统计推断的基础**
*   事实证明，即使在实际数据中我们只能看到一个样本均值，我们也可以对来自随机样本的 **平均值的分布** 说出很多信息。
*   这为我们提供了大量可用的工具，并构成了我们进行许多统计推断方法的基石。
