# 分布式设计因素表

+   - 要决定业务过程的应用程序操作是集中处理还是分布处理，需要考虑多种因素
+   - 在系统开发工作的组织上，是集中的还是分散的，这与操作和管理上的集中式还是分散式是不同的
+   - 因素表
+     - 各列指出系统开发、系统操作和管理上应考虑的方面
+     - 各行指出选择集中式还是分散式所要考虑的因素
