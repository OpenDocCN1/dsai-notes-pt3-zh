# 逻辑数据库标准例

+   - 港口生产管理信息系统的“船舶动态”（逻辑的）主题数据库标准如下：
+     - 船舶动态基本信息（* 船舶航次编号，船舶动态码，船名，呼号，来自港，...）
+     - 船舶动态-预报船（* 船舶航次编号，预计抵港时间，抵港时间，抵港吃水，...）
+     - 船舶动态-锚地船（* 船舶航次编号，下锚时间，锚位，预靠时间，...）
+     - 船舶动态-靠泊船（* 船舶航次编号，* 泊位号，* 靠泊时间，泊位船状态码，...）
+     - 船舶动态-作业船（* 船舶航次编号，* 泊位号，* 装卸标志，* 开始时间...）
+     - 船舶动态-开航船（* 船舶航次编号，实卸吨，实装吨...）

其中，第一个基本表与其后的基本表错开排列，是因为它有特殊的、综合的性质，它对其后的基本表都有“一对多”的关系。每个基本表后边括号内的属性列表项，都是数据元素，其中前面加* 的是主键关键字
