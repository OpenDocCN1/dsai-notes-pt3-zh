# 职能模型的分析案例

# 山东高速集团物流规划咨询竞争性谈判文件

+   1. 掌握宏观环境和产业环境现状与发展趋势，以及国内外相关行业现状与发展趋势，为战略决策提供翔实、全面的数据与资料。
+   2. 掌握国内外同类企业的业务现状、运作模式、管理模式、战略目标等基本情况。
+   3. 分析国内外企业相关业务的成功发展模式，结合实际，深入分析港口物流、大宗商品贸易、物流地产、全产业链物流等业务，找出适合高速集团物流业务发展的商业模式。
+   4. 明确物流业务未来五年的国内战略布局方案。
+   5. 明确物流业务未来五年发展目标与衡量指标。
+   6. 为高速集团物流业务未来五年战略联盟与并购计划提供指导意见和决策依据。
+   7. 为确定物流业务未来五年的管理框架、运作模式、财务结构等提供决策建议。
+   8. 制定公司物流业务未来五年人力资源保障和激励机制方案。
+   9. 为公司未来五年投资重点及财务模拟提供指导意见和决策依据。
+   10. 制定战略实施时间表与阶段方案，在实施过程中根据实际提出指导意见并制定有效措施。
