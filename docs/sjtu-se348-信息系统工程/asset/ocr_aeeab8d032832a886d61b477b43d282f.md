# 实体图的结构化方法

+   □ 如果一个非根实体具有多个上层实体，应该选择哪一个上层实体呢？
+     ■ 图中实体A是一个第二层实体，它可以被画在B、G或L这三个第一层实体中的任何一个下面
+     ■ 图中H是第三层实体，它可以被画在第二层实体J 或者K下面
+   □ 原则
+     ■ 应该选择联系最强的上层实体，或者是最常使用的联系
+       ✓ 假定A与B的联系比A与G的联系强，那末A就画在 B的下面
+       ✓ 如果J与H的联系比K与H的联系使用得更加频繁，那末H就可在J下面
+     ■ 遇到形成回路的联系时，回路中最弱的联系必须被暂时断开，以便于绘图
+       ✓ 这里假定C 与N是最弱的联系
+     ■ 如果联系的强度是未知的，或者是相同的，只要进行一个任意的选择，以便能够绘制实体图
