# TMS—运输管理

# 调度管理

+   1. 空车调派：当一次调度任务没有搭载货物，但又希望在系统中记录该次调度任务和相关费用时，使用空车调派。
+   2. 空车运力登记：指完成调度任务的空车，被其他机构登记使用。主要用于空车的回程调度等。
+   3. 发运信息输入：生成一张调度单，将货物信息与车辆建立匹配关系，选择随车人员，以及行车路线和相关费用。
+   4. 运办申请：用于中途装货的申请，查询可利用的运力调度，向车辆调度机构做出申请，列出需要搭载的货物及路线的变更。如果车辆调度机构批准，则申请机构可以在调度单上增加自己的货物明细，路经发生变化。
+   5. 发车确认：对于配货完成的单据进行发车确认，代表该货物已经在运输途中。
+   6. 换车作业：对于中途换车的托运单，都需要登记详细的换车信息。
+   7. 车辆到达：选择已经到达的托运单，录入到达的时间，确认到达。
+   8. 回单登记：针对完成卸货的作业单，进行回单登记。

# 装卸管理

+   1. 装货管理：根据作业单信息，按作业单的货物明细安排装运货物。一张作业单可以多次装货。如果在装货过程中有事故发生，可保存现场照片。
+   2. 货物到达目的地或者到达中转机构需要换车或入库时，需要先将货物卸下。如果在装货过程中有事故发生，可保存现场照片。

# 计费管理

+   1. 费用项目：用于维护与业务单据有关的费用（包含支出和收入）。
+   2. 计费合约设定：维护与托运商、承运商、中转分公司的费用合约。可以在做业务单据时引用合约。
+   3. 托运单/作业单/调度单费用输入：显示字段：直接引用“托运单”，“调度单”，“作业单”的数据信息。
+   4. 费用审核：对所有产生的费用需审核后才能进入财务付款流程。
