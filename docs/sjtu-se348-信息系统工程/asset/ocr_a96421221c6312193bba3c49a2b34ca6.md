# 新系统与旧系统并存
数据字典如何处理案例

+   - 某公司决定开发一个新的人力资源系统，来取代运行了多年的旧的现行系统。这个现行系统实际上包括三个子系统：
+     - 人事子系统
+     - 工资子系统
+     - 劳动分布子系统

由于新系统的规模和复杂性，决定分阶段实现。因为大多数修改问题出现在工资子系统，而且该公司预见到上级要求的工资报表要作重大修改，所以工资子系统首先被取代

图2.3 是新工资系统的数据流程图，E1和E2是现行人事系统的两个程序，它们把数据送给新的工资系统。C1和C2是转换程序，它们把旧的人事系统的数据转换成新的工资系统能接受的格式

程序N1到N8代表新的工资系统

转换程序C3和C4将把新工资系统的一些记录转换成旧的劳动分布系统的格式
