# 按照物流系统的性质分类

+   以产品生产、制造为目的的“企业物流”（又称“小物流”）
+   
+   定义：企业在产品生产、制造过程中，为保证生产正常进行伴随着生产物料移动、停顿和时间上的占用所进行的活动。包括：采购、搬运、装卸、等待、储存、配送、包装、销售、信息处理等。
+   
+   目的：准时化、低成本、最佳的物流是“无物流”

企业物流是研究企业内部、与企业的生产活动相关联的物流活动。这种物流活动是一种以产品生产中心的包括物料的采购、储存、搬运、储存、等待、配送、包装、销售等活动。这一系列活动，从企业的生产角度分析，是不产生价值的、又不可省略的活动，企业物流就是试图缩减这些活动，降低生产成本，提高产品的市场竞争能力
