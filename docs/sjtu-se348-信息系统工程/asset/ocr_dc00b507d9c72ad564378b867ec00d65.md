# 利用数据交换标准格式接口实现集成

为克服专用数据接口集成模式的弊端，有些系统开发商提出用通用数据格式作为系统集成的接口
应用系统数据按标准格式输入/输出，就可集成到一起

![](bbox=[0.22, 0.42, 0.82, 0.62])

比较典型的公用数据交换标准：IGES、STEP、GKS、VDI...

![](bbox=[0.18, 0.74, 0.26, 0.84])

作为系统集成的接口，应用最多的标准数据格式是美国国家标准局（NBS）主持开发的数据交换规范IGES (Initial Graphics Exchange Specification)
