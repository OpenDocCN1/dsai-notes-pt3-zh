# 3.原型设计法的的使用

“原型设计”是一个特别重要的概念

+   - 对于非常复杂的工程项目，在成品生产以前，要先建立一个原型。通过原型来检验该产品的设计原理，保证系统运转，采集设计反馈信息，从而在进行大量投资之前对设计能进行调整。
+   - 化学工厂在完成最终产品设计之前，先要在试验室里做
+   - 船体的外壳形状也需要先做实验
+   - 一种新型飞机要在正式建造之前以各种方式进行模拟实验

复杂的数据处理系统要比大多数工程系统更需要原型化设计，这是因为需要从试验操作中了解很多东西，并且很有可能对设计要作许多改动。原型会帮助解决所讨论的系统能不能按照最终用户真正需要方式工作的问题。
