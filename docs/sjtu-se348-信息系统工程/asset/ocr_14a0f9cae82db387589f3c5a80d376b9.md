# 4. 自顶向下规划与自底向上设计的结合

信息工程的开发方法区别于传统的软件工程的方法，要强调整个方法论的特点是：自顶向下的规划与自底向上的设计

+   - 企业计算机化的首要的、基础的工作是战略规划，特别是战略的数据规划
+   - 战略规划从总体上讲是自顶向下的规划，即由企业最高领导层主持的、从企业模型的研究开始到数据分布规划的完成
+   - 应用项目或系统的开发是在战略规划的控制下进行的，这些具体项目的设计基础是总体数据模型（各个主题数据库），这时有的已经规划出来，有的已经设计完成
+   - 每个具体项目或应用系统的开发，应该采取自顶向下与自底向上设计相结合的方法，而且需要自动化工具支持
