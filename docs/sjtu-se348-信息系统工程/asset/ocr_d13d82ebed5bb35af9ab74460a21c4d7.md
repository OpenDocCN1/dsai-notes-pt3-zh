# Physical Distribution与Logistics

|  | Physical Distribution | Logistics |
|---|---|---|
| 概念出现最早时间 | 1915年，阿奇·萧《市场流通中的若干问题》 | 1905年，琼西·贝克解释 物流，二战获得大发 |
| 最先使用的领域 | 流通领域 | 军事领域 |
| 概念的外延关系 | 包含在Logistics中 | 包含Physical Distribution |
| 概念的内涵 | 为计划、执行和控制原材料、在制品库存及制成品从起源地到消费地的有效率的流动而进行的2种或多种活动的集成。 | 对货物、服务及相关信息从起源地到消费地的有效率、有效益的流动和储存进行计划、执行和控制，以满足顾客要求的过程。 |
| 美国物流管理协会使用的名词 | 1963年成立到1985年下半年使用Physical Distribution；之后使用Logistics代替Physical Distribution |  |
