# 分布式数据规划步骤
分布式数据规划加细

+   - 规划矩阵可以表示数据结构而不是主题数据库，矩阵的主要部分可以指出已经存在的数据结构
+   - 一个数据结构既可以是一个文件，也可以是一个数据库，两者都可以是联机的或脱机的。数据结构有的很简单，最简单的可以是一个字段；有的相当复杂，如有12个物理数据库，多个不相交的数据库存在于一个数据库系统之中，形成一个数据结构。
+   - 选择数据结构或数据结构定位，有下列可能的约束：
+     - 所考虑的机器上没有数据库管理系统
+     - 所采用的数据库管理系统对所允许的数据结构有限制
+     - 数据结构已经适应现有的应用项具，而转换代价太高
+     - 外围计算机或小型/微型计算机存储能力有限
+     - 外围计算机缓冲区大小/数目有限
+     - 外围计算机的地点使安全性受限制
+     - 必须规划数据的完整性控制
+     - 机器发生故障期间必须提供恢复手段
+     - 如果数据偶然丢失，必须能重新组织
+     - 必须设计重新启动过程，以便数据更新不被丢失或重复处理
