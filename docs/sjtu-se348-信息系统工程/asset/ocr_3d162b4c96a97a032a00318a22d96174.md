# “信息工程”与“信息资源管理”的关系

+   - “信息工程”方法论的核心是总体数据规划
+   - 在“信息工程”产生和发展的同一时期，“信息资源管理”（Information Resource Management，简称IRM）的概念、理论和方法也得到了发展
+   - **IRM**的有关理论和方法不仅补充、丰富了总体数据规划的理论和方法，而且作为具体的信息组织技术，对于开发利用企业的信息资源有更为实际的作用
+   - 特别是在建立企业信息资源管理的基础标准方面，威廉·德雷尔（William Durell）在80年代中期卓有成效的工作成果，对于进行企业信息化建设来说更具有借鉴意义
+   - 信息资源管理的核心是数据管理，这就是本讲的重点
