# 多重心法（多设施选址）

问题：某产品在四个区域市场销售。现需要设置一些中转仓库，已知仓库到各市场的运输费率为0.08元/件公里，每建一个仓库每年需要承担的固定成本（如折旧等）为100000元，仓库的平均维持成本为500000元，其中N为仓库的个数。假设该产品由国外进口，无论中转仓库建在目标市场中的什么位置，产品从生产厂到仓库的运输费用都大致相等，这部分费用可以忽略不计。请做出仓库建设决策。

| 节点 | 需求数量 | 坐标 |
|---|---|---|
| M1 | 20000 | (3,3) |
| M2 | 50000 | (6,8) |
| M3 | 60000 | (11,9) |
| M4 | 30000 | (9,5) |
