# 打码到条——两打三扫

+   □ 条烟32位编码示例
+   ■ “3071046809733201
+   ■ xyy c360502104957”
+   ■ 前五个数字“30710”代表配送日期2013年7月10日；第6至14位一共9个数字“468097332”是该条卷烟所属件烟件码的最后9位，以此可以通过烟草行业“一号工程”确定件烟的相关信息；第15和16位是代表这条烟在所属件烟中的序号，从01至50不等；第17至20位“xyyc”是该地市烟草公司名称“新余烟草”拼音的缩写；第21至26位“360502”是该地市的行政区域国标代码，可以通过国家统计局官网公布的“全国最新行政区划代码表”对照查询；第27至32位“104957”是零售户代码，即该零售户烟草专卖零售许可证号的后6位。
