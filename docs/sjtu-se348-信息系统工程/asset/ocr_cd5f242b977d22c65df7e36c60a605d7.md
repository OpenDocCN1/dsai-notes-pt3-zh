# 如何对上述相关系数矩阵中的实体进行分组

下一对相关性系数最高的是E7和E4(相关系数=0.76)

+   E7和E4已分别在一个组中（E1、E4，E6、E7），是否应该把这两组合并？
+   要计算E7对于现有的E1、E4实体组的复合加权相关系数，和E7对E1、E4、E6这一合并实体组的复合加权相关系数
+   如果假定这两个相关系数分别为0.55和0.37，这两个数字低于表中下一个相关系数，即E8和E10的相关系数（相关系数=0.74）。因此，需要先来处理这一对实体

+   进行每一个分组决策的顺序要根据相关系数来决定

+   在相关系数序列的末尾，有些实体也许与任何其它实体都很少相关，这些实体可以用文件系统或独立的简单数据库来实施。

+   设计人员应当仔细考察剩余的低相关系数的实体，以确定它们是否属于已有的某个数据库
