# 物流网络优化总模型（目标函数）

Minimize  T + W + P

s.t.

V_f = Σ_{r=1}^{R} D_r  (f = 1,2,...,F)

U_r = (R_r / Σ_{r=1}^{R} R_r x_r) U

R_r = Σ_{d=1}^{D} δ_{rd} × R_{rd} + Σ_{r=1}^{F} δ_{rα} × R_{rα}  (r = 1,2,...R)

c_r = { c1,  U_r ≥ 20
        c2,  U_r < 20   （单位：万箱） }

μ_r = { μ1,  U_r ≥ 20
        μ2,  U_r < 20   （单位：万元/库位） }

S_r = Σ_{r=1}^{R} R_r × β_r  (r = 1,2,...R)

Σ_{f=1}^{F} V_f = Σ_{r=1}^{R} R_r
