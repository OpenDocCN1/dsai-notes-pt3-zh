# （3）组织与协调

+   最好能使高级管理人员根据周密的计划，简短地参加研究。他们参与研究的时间应该在研究开始之前得到最高领导的指示和许可。一个有效的组织方法是，让他们在整个研究过程中，每隔一段时间参加两个小时左右的简短活动。核心小组应该为高级经理人员所参加的每次简短活动进行充分的准备工作。

+   除了核心小组在需要的时候对重要经理人员进行访问之外，还应当指派不脱产的用户分析员参加研究：

+   时间要求：通常每个星期他们要投入一天时间，每个用户分析员在他们所熟悉的公司有关领域中进行工作

+   数量要求：所需用户分析员数目，取决于公司规模，在一家大型航空公司中，曾有40位用户分析员参加了一个分布式系统的数据分析工作，而在小型企业中，三到四位用户分析员就够了

+   素质要求：用户分析员也必须是优秀人员，而不是组织中那些闲散无事、无关重要的人员
