## TMS—运力管理

## 车辆管理

+   1. 车辆档案管理：记录物流企业所拥有的运力资源(尤其是自有运力)管理时产生的文档资料、证件等。
+   2. 证件管理：该功能主要是对证件办理状态的控制，主要有登记、办理完毕、领回等几个状态。证件管理主要分证件登记、证件办理完毕、证件领回等几个步骤。

## 保险、事故、理赔管理

+   1. 保险登记：记录车辆保险及货物保险资料。
+   2. 事故信息：记录交通事故信息资料，可保存现场照片。
+   3. 理赔信息：车辆事故后保险理赔信息。赔付金额、赔付时间回写到事故中。

## 司法诉讼、货运纠纷管理

+   1. 司法诉讼信息：记录由事故、理赔、货运纠纷及其他原因引起的司法诉讼，不涉及诉讼流程，只记录不同阶段的信息。
+   2. 货运纠纷信息：记录由货运引起的纠纷。引起货损的原因有交通事故、装卸、保管等。

## 维修保养管理

+   1. 维修材料管理：运输设备维修常用维修材料的维护。
+   2. 维修/保养项目管理：常用维修项目维护，在维修管理/保养管理时选取已经维护好的项目。
+   3. 维修、保养管理：车辆维修、保养记录。

## 安检管理

+   1. 安检项目：出车前安检、回场安检或定期检查的常用项目。
+   2. 安检类型：常用的安检维护，在此可设定某种安检都需要检查什么项目。设定好的类型在安检登记时使用。
+   3. 安检登记：记录各种安检的信息。出车前安检可以针对车辆或者调度单进行检查。

## TMS —运输管理

+   计划管理
+   1. 维修计划：针对车辆制定的维修计划，包括计划日期，开始年月，结束年月，车号，里程表数，计划维修日期，办理人，所在地区，维修单位，项目代号，项目名称，维修原因，工时费，材料费。
+   2. 费用计划：针对各种费用制定的预算，包括机构编号，计划类型，系统编号，计划日期，开始年月，结束年月，项目代号，项目名称，计划金额。

+   协同运输管理
+   1. 协同运输订单输入和确认：新增或修改协同运输订单，准确无误后进行确认。
+   2. 协同运输调度：对确认完成的协同运输订单进行进一步的调度作业，将一张需要由多个机构共同协作完成的协同订单调度细分成每个机构都可各自执行的一系列托运单。指定其中所有运输的机构在适当的时间、适当的地点执行其对应的托运任务。

+   托运单管理
+   1. 公路/水路/铁路托运单输入和确认：新增或修改托运单，明确每一种运输方式下的运输委托任务。
+   2. 接受托运单：托运单需要被接受机构接收后才能进行后续的业务操作。
+   3. 作业单拆分：由于一些托运单中所指定的商品数量太多，无法一次性由一辆车完全配送，需要拆分成多个更细的作业单以便下一步的调度。

## TMS—运输管理

## 调度管理

+   1. 空车调派：当一次调度任务没有搭载货物，但又希望在系统中记录该次调度任务和相关费用时，使用空车调派。
+   2. 空车运力登记：指完成调度任务的空车，被其他机构登记使用。主要用于空车的回程调度等。
+   3. 发运信息输入：生成一张调度单，将货物信息与车辆建立匹配关系，选择随车人员，以及行车路线和相关费用。
+   4. 运办申请：用于中途装货的申请，查询可利用的运力调度，向车辆调度机构做出申请，列出需要搭载的货物及路线的变更。如果车辆调度机构批准，则申请机构可以在调度单上增加自己的货物明细，路经发生变化。
+   5. 发车确认：对于配货完成的单据进行发车确认，代表该货物已经在运输途中。
+   6. 换车作业：对于中途换车的托运单，都需要登记详细的换车信息。
+   7. 车辆到达：选择已经到达的托运单，录入到达的时间，确认到达。
+   8. 回单登记：针对完成卸货的作业单，进行回单登记。

## 装卸管理

+   1. 装货管理：根据作业单信息，按作业单的货物明细安排装运货物。一张作业单可以多次装货。如果在装货过程中有事故发生，可保存现场照片。
+   2. 货物到达目的地或者到达中转机构需要换车或入库时，需要先将货物卸下。如果在装货过程中有事故发生，可保存现场照片。

## 计费管理

+   1. 费用项目：用于维护与业务单据有关的费用（包含支出和收入）。
+   2. 计费合约设定：维护与托运商、承运商、中转分公司的费用合约。可以在做业务单据时引用合约。
+   3. 托运单/作业单/调度单费用输入：显示字段：直接引用“托运单”，“调度单”，“作业单”的数据信息。
+   4. 费用审核：对所有产生的费用需审核后才能进入财务付款流程。
