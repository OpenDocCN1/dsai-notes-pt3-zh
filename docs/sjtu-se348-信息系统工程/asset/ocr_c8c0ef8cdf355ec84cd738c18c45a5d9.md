# 实体分析应注意的问题
（3）关于重复处理问题

+   - 在大多数公司中数据变得非常混乱，当对其进行全面协调的分析时，结果是令人震惊的。而且数据处理逻辑也非常混乱，会有很多不必要的重复。互不联系的系统分析人员，各自开发出自己的处理程序，而没有意识到他们在互相重复着别人的工作

+   - 例如，在一家小型纺织公司中，发现有9项独立的活动在处理到货业务，实际上每项活动都进行一系列相同的作业，产生一个到货记录。公司中有好几个地方都接收货物，先后为每一个收货地点都设计了有关的表格和单据，并且开发了不同的应用程序来处理这些单据。因此，产生了9套应用程序。这9项活动粗看起来都有一些细微差别，但是，在仔细研究了单据上的数据之后，可以看出，它们实际上是相同的，实际上一个套系统就够了，这9套应用程序会带来维护成本

+   - 实体分析目标之一应该是尽可能消除不必要的重复处理
