# 烟草行业的一号工程——“一打两扫”

![](bbox=[0.12, 0.28, 0.46, 0.78])

图1 一号工程码的构成和具体内容

+   1 中国烟草总公司图标
+   2 "检验合格"字样
+   3 "检验合格"边框
+   4 "中国烟草"中文字样
+   5 "CHINA TOBACCO"英文字符

+   6 生产信息字符：位于条码序号上方，共20位数字。1-10表示生产时间，如0910161041代表09年10月16日10:41时；11-13位表示手码；14-15位表示自动打码机或条码打印机设备号；16位表示班次[A-甲班，B-乙班，C-丙班，D-丁班，R-日班]；17-20位表示流水号
+   7 条码序号
+   8 供人识别的字符：共30位数字。1-6位引用行业类产品代码对应件号代码的后六位，记录件号烟根号信息；7-14位引用《烟草行业组织机构代码》，记录条烟产地；15-20表示生产日期，如091016代表2009年10月16日；21位代表经营方式(0-自产自销；1-内销；2-海外外销；3-来料加工；4-供出口；5-出口)；22-30位表示随机数，保证件箱的唯一性
+   9 表示标准字符(91)
