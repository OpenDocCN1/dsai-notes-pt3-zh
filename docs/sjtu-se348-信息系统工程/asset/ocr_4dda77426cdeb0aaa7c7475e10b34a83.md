# TMS—运力管理

# 车辆管理

+   1. 车辆档案管理：记录物流企业所拥有的运力资源(尤其是自有运力)管理时产生的文档资料、证件等。
+   2. 证件管理：该功能主要是对证件办理状态的控制，主要有登记、办理完毕、领回等几个状态。证件管理主要分证件登记、证件办理完毕、证件领回等几个步骤。

# 保险、事故、理赔管理

+   1. 保险登记：记录车辆保险及货物保险资料。
+   2. 事故信息：记录交通事故信息资料，可保存现场照片。
+   3. 理赔信息：车辆事故后保险理赔信息。赔付金额、赔付时间回写到事故中。

# 司法诉讼、货运纠纷管理

+   1. 司法诉讼信息：记录由事故、理赔、货运纠纷及其他原因引起的司法诉讼，不涉及诉讼流程，只记录不同阶段的信息。
+   2. 货运纠纷信息：记录由货运引起的纠纷。引起货损的原因有交通事故、装卸、保管等。

# 维修保养管理

+   1. 维修材料管理：运输设备维修常用维修材料的维护。
+   2. 维修/保养项目管理：常用维修项目维护，在维修管理/保养管理时选取已经维护好的项目。
+   3. 维修、保养管理：车辆维修、保养记录。

# 安检管理

+   1. 安检项目：出车前安检、回场安检或定期检查的常用项目。
+   2. 安检类型：常用的安检维护，在此可设定某种安检都需要检查什么项目。设定好的类型在安检登记时使用。
+   3. 安检登记：记录各种安检的信息。出车前安检可以针对车辆或者调度单进行检查。
