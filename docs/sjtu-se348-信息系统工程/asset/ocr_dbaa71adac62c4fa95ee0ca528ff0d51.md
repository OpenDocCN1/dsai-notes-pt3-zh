# 用户视图组成规范化模式三：
列名、行名都不稳定 ⇒ 列名、行名代码化

示例： 模式三报表

| 列名1 | 列名2 | 列名3 | 列名4 | ........ | 列名n |
| --- | --- | --- | --- | --- | --- |
| 行名1 |  |  |  |  |  |
| 行名2 |  |  |  |  |  |
| ........ |  |  |  |  |  |

列名码表组成
01 LDM 列代码
02 LMC 列名称

行名码表组成
01 HDM 行代码
02 HMC 行名称

报表组成
01 HDM 行代码
02 LDM 列代码
03 SZ 实例值
