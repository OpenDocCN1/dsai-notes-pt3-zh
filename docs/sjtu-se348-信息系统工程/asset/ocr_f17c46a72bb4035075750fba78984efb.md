# CIMS的发展状况
——美国

把保障国家安全，提高其工业在国际上的竞争力作为科技发展的战略方针，国防部、能源部、陆军器材部、航空航天部等政府部门都极为关注和重视CIM的进展状况，指定自身的CIM发展战略计划

| 时间 | 发展情况 |
|---|---|
| 1975年 | 美国空军制定空军计算机辅助制造计划AFCAM |
| 1976年 | 美国工程师学会制定计算机辅助计划ICAM |
| 1985年 | 正式形成CIM计划，投资1亿美元 |
| 1990年 | 道格拉斯飞机制造公司建成CIMS系统 |
|  | HP、DEC信息网络为基础的开放式结构平台 |
|  | 波音公司，777制造过程采用并行工程思想实施，组织了238个不同的工作组，采用数字化定义、数字化预装配（可装配）技术，实现无图纸生产，达到了无样机一次制造成功 |
