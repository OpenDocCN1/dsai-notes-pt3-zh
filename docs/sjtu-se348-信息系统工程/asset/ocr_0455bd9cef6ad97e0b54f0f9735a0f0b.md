# 电子商务物流系统物流网络设计

当前的物流服务已经很难跟上电子商务发展的步伐，各大电子商务纷纷选择满足物流。

电子商务物流覆盖状况：

+   - **当当网：**
+     郑州、北京、上海、广州、成都和武汉配送中心
+   - **卓越网：**
+     北京、苏州、广州物流中心
+   - **京东商城：**
+     北京、上海、广州、成都、武汉物流中心
+   - **淘宝网：**
+     上海、北京、广州、成都、深圳、东莞、南通配送中心
+   - **凡客诚品：**
+     北京、上海、广州、成都、武汉储运中心
