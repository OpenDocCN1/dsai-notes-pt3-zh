# 职能区域与业务过程例

职能和过程的顺序，是按产品的生命周期顺序排列的：首先是经营计划，然后是资金获取，接着是市场研究等，直到最后产品被送给客户，再完成会计业务。人事部门是与产品生命周期没有直接联系的职能部门，因此被列在最后。
