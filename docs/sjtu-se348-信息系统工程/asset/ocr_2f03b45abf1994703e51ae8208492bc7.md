# 信息系统中所使用的大部分数据名，是少数数据元素的同义词或别名

+   这些同义词或别名的产生原因，是由于缺少数据元素命名标准，或者缺少考虑数据元素的创建和使用的规划，而由那些只管标记自己拥有的 数据，而不顾及别人（其他的程序员和分析员）已建立并命名数据 的人所建立的重复数据

+   例如：

+   “职工姓名”、“员工姓名”、“职工姓名”等，如不加以统一，在用汉语拼音表示其标识时有 ZGXM、YGXM、ZYXM 等，而其英文标识可能是 EMP—NAME、E—NAME、NAME—OF—EMPLOYEE、EMP—NAME、EMPLOYEE—NM, EMP—NM 等

+   如果采用“职工姓名”这个统一标准，其标识为 ZGXM 或 EMP—N M，这就形成少数的“核心”数据元素

+   如果开发人员都这样做，就可大幅度减少信息系统中所使用的数据元素的总数，并可以大大简化其结构
