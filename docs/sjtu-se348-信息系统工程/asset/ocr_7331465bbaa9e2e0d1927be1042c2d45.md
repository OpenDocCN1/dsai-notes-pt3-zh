# 阿里从战略高度为未来电商业务物流布局

+   2012年，中国网络零售市场交易规模达13205亿元，同比增长64.7%。阿里巴巴集团旗下淘宝和天猫平台网络零售交易额突破1万亿元，日包裹量1200万单，单日峰值超过7200万单。对于社会化物流基础设施提出更高要求——规模更大、效率更高、网络更完善、服务更优质。

+   淘宝系“双十一”及节假日出现的爆仓、送货延迟问题暴露出电商的物流瓶颈问题，“快递企业和物流企业都靠不住了，只有自己来了！”

+   阿里巴巴集团发布物流战略，意味着阿里正在从物流能力（地网）和物流分析能力（天网）两方面，为其未来的电商业务所需要的物流支持能力做系统性的规划。
