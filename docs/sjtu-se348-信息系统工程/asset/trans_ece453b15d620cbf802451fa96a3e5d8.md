## 优化前后运作模式对比

| 对比 | 现有运作模式 | 规划后运作模式 |
|---|---|---|
| 物流中心 | 14个，多而分散 | 4个，少而面广 |
| 资源配置 | 以地市为单位，行政区划明显 | 跨行政区域实现集中配置 |
| 分拣形式 | 各地市独立分拣，规模效应没有得到展现 | 集中于4个RDC进行分拣，可充分发挥规模效应，提高分拣效率 |
| 机器设备 | 设备标准化程度低 | 设备统一，标准化程度高 |
| 物流成本 | 较高 | 可明显降低 |
| 物流人员 | 各RDC独立运营，人员冗余 | 集中管理，减少冗余人员 |
| 配送线路 | 按行政区域划分，存在迂回现象 | 可有效降低线路迂回的概率 |
| 运输时间 | 较长 | 可有效缩短 |

## 运输决策（配送路线优化）模型

### 定位—配给问题（Location Allocation Problems，简称LAP）

最传统的模型，配送中心与每个需求点之间是往复运输，没有路线的优化。

### 定位—车辆运输路线安排问题（Location-routing Problems，简称LRP）

综合考虑选址和运输路线优化，同时解决设施最优数量、规模和最优路线。但前提是每个需求点在每次的需求量均确定且是常量。而市场是动态变化的，每个需求点的需求是时变的。

## 节约法的基本思想

| 方案 | 配送路线 | 配送距离 |
| --- | --- | --- |
| a) | P0 → Pi → P0 → Pj → P0 | 2d0i + 2d0j |
| b) | P0 → Pi → Pj → P0 | d0i + dij + d0j |

里程节约量 S_ij = d0i + d0j - dij

基本思想：如果一个配送中心P₀分别向N个客户Pⱼ（j=1，2......n）配送货物，在汽车载重能力允许的前提下，每辆汽车的配送线路上经过的客户个数越多，里程节约量越大，配送线路越合理。

例：配送中心P₀分别向12个客户Pⱼ（j=1，2，...，12）配送货物。
