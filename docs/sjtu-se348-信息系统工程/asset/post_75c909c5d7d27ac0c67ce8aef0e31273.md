
## 小结：不含有复合数据项的数据结构
是一范式（1-NF）的数据结构(P106)

非一范式的数据结构：

| 工号 | 姓名 | 基本工资 | 奖金项目-金额 | 扣款项目-金额 | 实发金额 |
一范式的数据结构：

| * 工号 | 姓名 |
| * 收入代码 | 收入名称 |
| * 扣除代码 | 扣除名称 |
| * 工号 | * 收入代码 | 收入金额 |
| * 工号 | * 扣除代码 | 扣除金额 |

基于规范化的“工资数据结构”，可开发出不需要维护的工资程序。
