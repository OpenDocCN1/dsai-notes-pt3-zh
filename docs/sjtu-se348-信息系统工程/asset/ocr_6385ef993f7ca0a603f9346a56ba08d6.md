# 信息工程的系统开发方法

+   - 企业战略规划涉及到一个全面业务规划的开发，它包括企业的目标和任务
+   - 信息战略规划从企业目标出发为企业开发一个基本的信息体系结构，识别适于自动化的业务区域，并且要准备一份计划表来表明计算机应当怎样与这些区域打交道
+   - 业务区域分析对在上述规划中所识别的业务区域充分详细地分析它们的组成部分，确定出它们之间的所有联系和相互作用，开发详细的企业模型
+   - 业务系统设计确定需要计算机支持的业务过程和活动，同用户一起制定处理它们最好的方法
+   - 技术设计使用用户的要求与可用的技术相适应：它提供全面的输入输出格式，物理数据库结构设计，程序和事务处理设计
+   - 建造是实现程序设计和数据库描述，完成整个系统的安装和测试以及所有的操作和用户处理的准备
+   - 转换涉及并行运行，已完成系统的分割覆盖和分散周期及采用别的转换或过渡方法
+   - 投入运行包括系统的整个运行生命周期，系统的性能监测，运行和维护
