# 子集数据（Subset Data）

+   - 是存储在外围设备上的、较大计算机数据库的一个子集。这样做的基本原因有两个：
+     - 这种数据在外围地点使用频繁
+     - 这种数据在外围地点生成

+   - 子集数据是复制数据的一种形式，所以可以区别，是因为子集数据没有对主档的完整模式或完整的关键字，子集数据只或关键字仅是母本数据的一部分

+   - 例如，低层计算机可以存储一些高层计算机中的数据，同时也存储一些从不向上传送的自己所拥有的数据。低层计算机可以保存客户的地址和概况信息，这是一些容量很大而高层计算机又从不需要的数据；高层计算机则存放客户编码、名称、信贷信息和详细订货单，低层计算机也可以存储这些数据，但是这些数据的任何修改，必须上传给高层计算机
