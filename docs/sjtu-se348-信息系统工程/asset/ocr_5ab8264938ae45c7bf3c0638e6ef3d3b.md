# 物流与供应链整体解决方案——案例分析

SGM和APLL对XX物流提出的目标：

XX保证向总包方提供作为整车运输/仓储服务提供商在中国 的广泛经 验，以便使SGM能在无质损且费用尽可能最经济的情况下将车辆高效快 捷地交给客户。

SGM和APLL对XX物流提出的要求：

# 1、车辆仓储设备的要求（不限于）

+   在最小厚度为10厘米的经适当铺设并压实的地基上铺至少10厘米的沥青或水泥地块；
+   存放SGM的库存设施的任何部分都不能建在或处在已知的漫水区内；
+   能随机任意地取出车辆的场地规划；
+   场地设计安排每公顷不得超过300辆
+   场地的安排应尽量优化车辆流向和尽量减少二次移动车辆；
