# 根据实体相关性进行分组的方法

+   - 如果两个实体具有较高相关系数，它们就应该被放在相同的主题数据库中。如果它们之间相关系数为 **0**，不应该放在一起

+   - 根据实体相关性进行分组时，如果把相关系数等于 **0** 的实体放在同一个组中，那么将只能得到一个组。如果只把相关系数等于 **1** 的实体放在相同的组中，那么有多少实体，就会有多少个组

+   - 可以选择一个相关系数，使得所产生的分组数目在 **20 到 30** 之间，或者是设计人员所选定的其它数字，所得的分组可以被用作主题数据库的规划

+   - 这样分组方法，没有考虑活动的使用量。实践中，考虑活动的使用量后，实体分组会更加准确和合理
