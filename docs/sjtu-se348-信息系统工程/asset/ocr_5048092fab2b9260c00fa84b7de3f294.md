# 问题三

# 程序员和分析员一直在进行数据管理，为什么还要进行数据管理？

+   数据字典的另一作用是作为一个术语汇编，数据字典类似于大词典，其中包含公司所使用的术语词汇

如果说大词典对于准确的语言交流是必不可少的，那么数据字典对于企业内信息资源的了解和相互沟通，同样也是十分重要的。作为各种术语的词汇表，数据字典对于数据处理和用户部门的新来职员，也是非常有价值的培训工具

+   数据字典是支持结构化分析和设计的有效工具

它可用于形成数据存储（Data store），数据流（Data flow）和处理实体类（Process entity class）的文档资料，这样，它就成为向用户描绘系统设计细节的有力工具。数据字典还可以用于生成文件、片断和记录的定义，集中控制程序中的数据定义，确保数据使用的一致性，并且抑制数据冗余。数据字典中的文档资料是“活的”资料，数据字典的自动检索和相互参照功能，可包括多个程序、系统、数据库、报表格式定义，以及其他文档的目录
