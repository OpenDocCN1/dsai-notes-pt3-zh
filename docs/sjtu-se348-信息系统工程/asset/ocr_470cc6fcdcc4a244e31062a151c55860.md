# # 1.数据元素命名标准（5）

基本词是类别词的重要修饰词，它对一大类数据对象进一步分类（反映一小类数据对象），一般具有行业特征，条目比较多。例如，制造业常用的基本词有：

+   - 会计（ACCOUNTING）
+   - 预算（BUDGET）
+   - 顾客（CUSTOMER）
+   - 分配（DISTRIBUTION）
+   - 员工（EMPLOYEE）
+   - 工程（ENGINEERING）
+   - 设备（FACILITY）
+   - 库存（INVENTORY）
+   - 制造（MANUFACTURING）
+   - 市场（MARKET）
+   - 税金（TAX）
+   - 订单（ORDERS）
+   - 付款（PAYMENTS）
+   - 计划（PLANNING）
+   - 采购（PROCUREMENT）
+   - 产品（PRODUCT）
+   - 研究（RESEARCH）
+   - 销售（SALES）
+   - 供应商（SUPPLIER）
