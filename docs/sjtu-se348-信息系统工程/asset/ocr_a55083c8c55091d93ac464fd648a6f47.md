# 新系统与旧系统并存
数据字典如何处理案例

+   （1）通过减少数据管理工作范围和复杂性，会增加你在该项目中取得成功的机会，如果时间允许，你可以稍后考虑增加项目的范围，将现行系统的一些部分包括在内

+   （2）旧系统中使用的大多数数据元素不符合数据管理标准。把这些非标准的、“不像样子的”数据元素输入字典，你就助长和维持了它们在其他数据定义中的使用。把它们排斥在数据字典之外，有助于确保它们的消亡。

+   （3）在许多情况下，用于旧系统的一些数据元素将是用于新系统的标准的数据元素的变形或别名。如果把这些数据元素都在字典中加以定义，就会大量地增加数据元素不同版本的总数。

+   （4）如果你将这些额外的别名和不同版本的定义装入字典，就会增加未来数据字典维护的工作量。当你再重新设计人事子系统和劳动分布子系统时，你还得从字典中删除这些非标准的别名和版本。你怎样能断定它们全被消除了呢？如果其他一些程序或应用项目已开始使用这些别名和版本，如何处理呢？
