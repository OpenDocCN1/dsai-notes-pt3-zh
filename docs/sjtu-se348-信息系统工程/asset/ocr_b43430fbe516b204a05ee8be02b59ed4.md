# 多重心法算例

解 中转仓库最少建一个，最多建四个。分别用重心法求出四种情况下的最低运输成本，与其中最小运输成本对应的解将是最优位置决策。

例如，对修建三个仓库的情况有：

| 方案 | 供货任务分配 | 最小成本 |
| --- | --- | --- |
|  | 仓库1 | 仓库2 | 仓库3 |  |
| 1 | M1, M2 | M3 | M4 | 932953 |
| 2 | M1, M3 | M2 | M4 | 1600001 |
| 3 | M1, M4 | M2 | M3 | 1011931 |
| 4 | M2, M3 | M1 | M4 | 2039615 |
| 5 | M2, M4 | M1 | M3 | 1018235 |
| 6 | M3, M4 | M1 | M2 | 1073314 |
