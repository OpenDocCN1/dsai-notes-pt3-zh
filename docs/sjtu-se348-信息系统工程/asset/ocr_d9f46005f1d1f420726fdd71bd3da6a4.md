# （1）企业模型与教据模型引起的思考

+   - 在许多企业中，考察现行的管理过程的职能分析已经完成。但是，考虑企业的管理过程应该如何，比只注意它们现状如何更有价值。数据库技术为组织中管理过程及信息资源进行重大改革提供了机会

+   - 第一辆汽车曾经被称为“无马马车”，其形状也与没有马的马车相同，很长时间以后，人们认识到，汽车应该具有不同的外形。与此相似，我们所建立的数据库和管理系统重复了现行的或以前的工作组织方式，我们会逐步认识到，数据库和管理系统应该使我们能够采取不同的和更好的工作组织方式

+   - 实体和实体活动分析常常导致人们重新考虑一个公司中的职能和方法，这项工作有时被称为职能分析

+   - 实体活动分析会使人们重新思考管理过程，常常会导致部门的改组和审查委员会的建立。研究小组应该提出的一个问题是：“你认为企业的组织结构应该是怎样的？”必须经常不断地探索使用数据库和计算机终端来改进企业管理过程和组织结构的方法。了解不同的部门或分部使用什么数据，常常使最高领导感到惊讶。这常常揭示出组织中他们还不了解的一些事实，这就使组织机构变动或企业改组的需要变得清晰起来。
