# 数据管理工作的波浪式发展

+   - 突然，该公司在销售上遭受了某些损失而被迫削减费用。在权力变动中，有些高层管理人员被免职而进行了全面的改组。新的管理部门在致力于制定降低费用的紧急措施。有些经理对在公司内搞数据管理的作用和方向是怀疑的。有些数据处理人员和数据管理人员被迫解雇。数据管理部门内士气下降，工作效率降低。时间段D 说明了这种情况。

+   - 在时间段E，企业经营情况好转并有了新的发展。主管部门开始认识到从数据管理可以得到长期效益，他们决定重新雇用数据管理人员，达到以前的水平。工作效率提高了，再次出现发展的势头。

+   - 这幅曲线说明了任何新的和有争议的课题都可能经历可以预见到的失望、挫折和改进过程。数据管理正是这种新课题之一。然而，这幅图也表明了数据管理的成绩，虽然缓慢，但毕竟是稳步增长的。尽管数据管理多次失去成功机会，它仍然会在这场信息资源管理的斗争中赢得胜利。
