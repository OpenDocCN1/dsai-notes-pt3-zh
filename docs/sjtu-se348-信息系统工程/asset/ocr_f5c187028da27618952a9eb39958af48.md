# 分布式数据规划步骤

+   - 0 类程序是最理想的一类程序，3类程序应尽量避免，1类程序是集中式系统中常用的。为了避免模块间的相互作用，地理数据结构矩阵应进行调整，使得0类程序占最大的比例，避免3类程序，2 类程序尽可能减少

+   - 设计者可画出一张表，说明每类程序的数目

+   - 不属0类的程序可以复制所考虑的数据结构，形成0类程序，有利于复制数据的因素如下：
+     - 事务处理量大
+     - 数据量少
+     - 数据更新不频繁
+     - 数据更新简单，因而容易避免完整性和重启问题
+     - 复制的数据结构简单（尽管它可能是一个复杂的数据库中导出的
+     - 数据通信有困难
