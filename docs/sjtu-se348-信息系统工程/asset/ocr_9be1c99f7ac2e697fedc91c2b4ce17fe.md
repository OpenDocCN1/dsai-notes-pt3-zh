# 关键成功因素的确定

关键成功因素应该成为最高层管理人员管理控制企业系统的基础。

对一个行业来说，某些关键成功因素差不多是共同的

+   - 汽车工业
+     - 燃料的节约
+     - 式样
+     - 高效的销售组织
+     - 生产成本的严格控制
+   - 软件公司
+     - 产品革新
+     - 销售和用户资料的质量
+     - 国际市场和服务
+     - 产品的多用性
+   - 微电子公司
+     - 吸引和保存最好设计人员的能力
+     - 政府对研发的支持
+     - 地区销售力量的支持
+     - 新的市场需求的确定
+   - 包装食品公司
+     - 广告效果
+     - 货物分发
+     - 产品革新
+   - 培训公司
+     - 雇用最好的讲课人
+     - 题目的确定
+     - 通信表的大小和质量
+   - 人寿保险公司
+     - 管理人事机构的开发
+     - 广告效果
+     - 文书工作的效率
