
## 运输量—运输距离—运输费率—重心法

解：（1）初始计算

+   1）令Di=1，求出仓库的初始位置

$$X=\frac{\sum_i Q_iR_iX_i}{\sum_i Q_iR_i},\qquad Y=\frac{\sum_i Q_iR_iY_i}{\sum_i Q_iR_i}$$

+   2）将求出的仓库初始位置（X，Y）带入下式求出Di

$$D_i=[(X_i-X)^2+(Y_i-Y)^2]^{1/2}$$

+   3）由下式求出仓库建在初始位置时的总运输成本

$$C=\sum_i Q_iR_iD_i$$

（2）第一次迭代计算

+   1）将求出的Di代入下式, 求出仓库的新位置

$X = \frac{\sum_i Q_i R_i X_i / D_i}{\sum_i Q_i R_i / D_i} \quad Y = \frac{\sum_i Q_i R_i Y_i / D_i}{\sum_i Q_i R_i / D_i}$

+   2）将求出的仓库新位置（X, Y）带入下式求出仓库新位置到各客户的距离Di

$D_i = [(X_i - X)^2 + (Y_i - Y)^2]^{1/2}$

+   3）由下式求出仓库建在新位置时的总运输成本

$C = \sum_i Q_i R_i D_i$

## 单设施选址重心法的常用假设

+   - 需求量往往聚集在一定数量的点上。
+   - 忽略了不同地点选址可能产生的固定资产构建、劳动力成本、库存成本等的差异。
+   - 运输费率的线性假设。
+   - 直线运输假设。一般结点间的直线距离和实际行走路线之间存在差异，要通过修正系数来修正。
+   - 静态选址假设。往往不考虑未来的收益与成本变化。

## 前端定性分析

## 0级影响因素:

+   0.1. 政府或类似权力机构规划
+   0.2. 区域内有卷烟工业公司
+   0.3. 其它重大肯定性因素
+   0.4. 自然地理状况（地形、地貌）非常恶劣
+   0.5. 基础设施建设水平非常低
+   0.6. 存在重大的天灾人祸因素
+   0.7. 其它重大否定性因素

本类因素的特点是只要满足任何一项肯定性因素（因素 0.1-0.3），则可进入定量模块进行计算，但并非直接作为仓库点。若满足任何一项否定性因素（因素 0.4-0.7），则直接淘汰。

## 1级影响因素:

本类因素一共可以归纳为以下三项:

+   0.8 区域销售量情况，是否有效大的销售量
+   0.9 物流网络发展情况，是否具备较好的可扩展性
+   0.10 经济发展力，是否具有区域领导力

本类因素的特点是必须满足其中的所有因素，则可进入定量模块进行计算，而并非直接作为仓库点，其中所有因素排名都靠后的点淘汰。
