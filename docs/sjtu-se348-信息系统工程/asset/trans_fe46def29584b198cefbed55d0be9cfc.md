## 中端定量分析模型

- 基本目标函数
- Min 总运输成本＋仓储成本＋服务水平控制
- 总运输成本：（省内工商之间 + RDC-CD + RDC-TCD-CD + 终端配送）的运输费用
- 仓储成本：仓储、分拣费用＋折旧的预算
- 服务水平：超出服务半径的惩罚成本
- 特别说明：RDC-CD打破行政区划测算

## 物流网络优化总模型（目标函数）

Minimize  T + W + P

s.t.

V_f = Σ_{r=1}^{R} D_r  (f = 1,2,...,F)

U_r = (R_r / Σ_{r=1}^{R} R_r x_r) U

R_r = Σ_{d=1}^{D} δ_{rd} × R_{rd} + Σ_{r=1}^{F} δ_{rα} × R_{rα}  (r = 1,2,...R)

c_r = { c1,  U_r ≥ 20
        c2,  U_r < 20   （单位：万箱） }

μ_r = { μ1,  U_r ≥ 20
        μ2,  U_r < 20   （单位：万元/库位） }

S_r = Σ_{r=1}^{R} R_r × β_r  (r = 1,2,...R)

Σ_{f=1}^{F} V_f = Σ_{r=1}^{R} R_r

## 求解此模型的算法选择说明

- 上述模型是一个混合0-1 整数非线性规划问题，是典型的NP-hard问题，用常规方法求解很困难。
- 将智能化算法与问题的特有知识集成到一起，或在智能化算法中融合其他算法的思想、方法，构成一种混合算法，可以产生出求解性能很好的方法。

## 常见的启发式NP-hard问题求解方法

- 现代优化算法是80年代初兴起的启发式算法，这些算法包括
  - 人工神经网络（neural networks）
  - 遗传算法（genetic algorithms）
  - 粒子群算法（Particle Swarm Optimization）
  - ...

目前，这些算法在理论和实际应用方面得到了较大的发展。无论这些算法是怎样产生的，它们有一个共同的目标就是求NP-hard组合优化问题的全局最优解。

## 神经网络算法原理说明

- 建立误差函数 $E(w,b)=\frac{1}{2}\sum_{k=1}^{s}(t_k - a_{2k})^2$
- 反复修订网络权值得到函数映射 $y = f(x)$

## 遗传算法原理说明

- 自然选择和遗传中发生的复制、交叉和变异等现象。从任一初始群体出发，通过随机选择、交叉和变异操作，产生一群更适应环境的个体。这样一代一代的不断繁殖进化，最后收敛到一群最适应环境的个体。
- 遗传算法过程说明：编码方式，评价函数，初始种群，群体个数，遗传算子（选择，交叉，变异），迭代代数。

## 粒子群算法原理说明

- > 粒子群算法(PSO) 是一种新的进化计算技术，由Kennedy 和 Eberhart 提出，源于对鸟群捕食群体行为的研究。
- > 假设在一个D维的搜索空间，有n个粒子组成一个群落，其中第i个粒子的位置表示一个D维向量，将 X_i = (x_i1, x_i2, ..., x_iD) i = 1,2,...n 带入一个目标函数就可以计算出其评价值。

## 三种启发式算法的比较

| 算法 | 功能和适用性 | 优点 | 缺点 |
|---|---|---|---|
| 神经网络 | 有明显的输入输出值的一般性的问题，利于建立专家库，尤其是<br>有大量历史对比数据的问题，如：安全库存设置 | 自学习，存储 | 收敛速度慢<br>拓扑结构参数难以确定，影响可靠性<br>对大数据集合容易出现训练过度<br>时间、空间复杂度过高 |
| 粒子群算法 | 能够将问题建立编码的随机性问题，如：网络优化<br>实数编码 | 算法速度快，解质量高<br>无过多的参数需要调整 | 早熟收敛<br>粒子位置和速度不易表达<br>提出的时间相对较晚，尚不够完善和成熟 |
| 遗传算法 | 能够将问题建立二进制编码的随机性问题，如：网络优化<br>二进制编码 | 目标函数不要求连续<br>目标函数不要求可微<br>全局优化算法 | 早熟收敛<br>编码困难<br>对不完全信息适应性差 |
