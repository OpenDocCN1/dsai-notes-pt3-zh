# 企业数据管理工作成败的要点

| 活动 | 要做 | 不要做 |
|---|---|---|
| 规划 | 规划短期和长期数据管理目标，如何开展数据字典的使用，支持企业目标的数据管理环境；使高层管理人员与制定和复查这些规划 | 不要仓促地或盲目地开始数据管理工作或使用数据字典；未经充分地规划不要开始任何数据管理项目 |
| 文档 | 制定数据管理图表和数据管理部门每项业务的职责；所有数据管理活动开始之前，要写出成本效益的估计；编写数据管理标准和规则；吸收主管部门和用户参加这些文档的制定和复查工作 | 不要以为别人了解数据管理的目标或方法；不要以为主管部门了解数据管理的任务和局限性 |
| 自动化 | 使数据字典完全自动化，使兼容性及符合命名常规的检查工作自动化，使来自数据字典的软件生成自动化 | 不要使数据字典承担任何过多任务；不要人工检查是否遵守数据管理标准；不要人工做数据定义编码 |
| 简要 | 宣扬、提供数据管理和数据字典的好处；向数据处理人员和最终用户进行数据管理原则的教育培训；单独或与同行进行适当的教育手段以建立起能够同数据管理人员接触的联系方式 | 不要命令用户强制执行数据管理标准，不要发布有关数据管理规则和规程的命令或布告；不要期望立即完全符合新的标准 |
| 适应 | 使标准和数据字典发展与当前环境紧密衔接；使数据管理标准与具有的适用开发规则和方法相结合 | 不要期望业务需求或公司的政策去适合标准的数据管理规则；记住，搞不通数据管理，公司都必须继续维系业务；在你能够支持应用商家之前，不要一定要坚持严格的控制和完全符合标准 |
| 保证 | 得到高层管理部门的赞成和支持；我们自己和其他一些人要努力手成功地实现 | 不能用一小部分时间或无计划的方法来完成；不可低估成功地进行企业数据管理工作所需要的资源或时间的费用 |

资料译自：William Durrell. DATA ADMINISTRATION; A Practical Guide to Successful Management. 1985; 174 - 175
