# “信息工程”的完整方法论（4）-（5）

+   构件④⑤保证了信息中心和个人应用项目的迅速建立

有时，信息中心和个人的计算任务所使用的数据不是规范的，而且在详细的数据模型中没有进行描述，于是要进行的计算任务应建立在②之上，即它们所使用的数据不要进行详细的逻辑数据库设计、规范化和进行各种检查（如一致性、可靠性、完整性检查），这是构件⑤的内容

有时，用户需要使用详细的数据模型中的数据，来完成计算任务。这样用户就不必花费时间设计自己的数据，且有利于各独立开发的系统之间进行数据交换。这时，构件④面向终端用户的计算应建在第③块之上。
