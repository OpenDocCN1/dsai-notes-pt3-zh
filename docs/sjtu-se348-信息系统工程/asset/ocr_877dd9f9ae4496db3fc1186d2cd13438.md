# （3）组织与协调

+   □ 参加规划研究的人员中，应该有一个较小的核心小组全程脱产工作，另外再配备一些用户部门不脱产的人员

+   □ 核心小组决定研究方向，协调输入，绘制图表并且汇总结果。这个小组的组成原则

+   ■ 需要由素质优秀的人员构成，但是不要太大，四位素质很好的人员就比较理想，小组过大反而很少能产生出色的设计

+   ■ 核心小组不应该完全由数据处理人员组成，理想的应该是由两位数据处理经验丰富的专业人员，和两个具有企业中多方面业务经验和广泛的组织经营知识的非数据处理人员组成

+   ■ 数据处理人员负责提供指导方法和帮助了解可以使用的软件工具，非数据处理人员负责帮助挑选公司中各方面的用户代表人员

+   ■ 核心小组负责人一般是一位数据管理员
