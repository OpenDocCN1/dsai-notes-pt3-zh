# 4. 表面粗糙度的符（代）号

基本符号：单独使用没有意义。

加工符号：表示表面粗糙度是用去除材料的方法获得。

毛坯符号：表示表面粗糙度用不去除材料的方法获得。

# 表面特征规定标注位置

a—粗糙度高度参数值，μm；
b—加工方法；
c—取样长度，mm；
d—加工纹理方向符号；
e—加工余量，mm；
f—粗糙度间距参数值，mm。
