# 概念数据库标准例
——某港口生产管理信息系统的概念数据库1

+   - 组织机构
+     - 港口所有机构部门统一编码，记存机构的基本信息
+   - 职工信息
+     - 全港职工的自然情况、简历、社会关系、奖惩、劳动
+       合同、岗位合同等
+   - 设备信息
+     - 设备基本信息，设备组成、变更、运行、故障、设备
+       维修计划-实绩等
+   - 设备技术档案
+     - 设备的折旧率、使用年限、备品配件、技术性能、运
+       行维护标准等
+   - 设备更新改造
+     - 年度更新改造、大修计划、初审、会审、计划完成情
+       况等
