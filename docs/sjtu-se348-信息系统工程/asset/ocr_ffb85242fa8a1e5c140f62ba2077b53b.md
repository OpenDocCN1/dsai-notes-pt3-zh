# # 实体图与数据模型的比较

+   - **实体图与数据模型是不同的**
+     - 数据模型要精确得多，并且表示出第三范式的数据结构，并仔细确定主关键字，其中有一些可能是复杂的联合关键字
+     - 数据模型从对最终用户视图的全面综合，以及对综合结果所进行的稳定性分析中产生
+     - 实体图只是对企业实体的一个汇总，它常常省略比较复杂的联合关键字

+   - **建立全面的详细数据模型的工作，需要的时间比仅仅确定企业实体要长得多**
+     - 建立数据模型的过程所需的时间往往过长，不能使最高领导始终保持兴趣
+     - 但是最高领导的兴趣对于实体分析却是至关重要的，因为它反映了企业真正的信息需求
