# 2. 数据元素标识标准

+   - 数据元素标识即数据元素的编码，是计算机和管理人员共同使用的标识
+   - 数据元素标识用限定长度的大写字母字符串表达，字母字符可按数据元素名称的汉语拼音抽取首音字母，也可按英文词首字母或缩写规则得出
+   - 例如：

| 数据元素名称 | 数据元素标识（汉语） | 数据元素标识（英文） |
|---|---|---|
| 申报开工日期 | SBKG RQ | APL_ST_DT |
| 设备数量 | SBSL | EQP_QTY |
| 概算设备工程量 | GSSBGCL | EST_EQP_QTY |
|  | GJZBDM | KPI_CD |
