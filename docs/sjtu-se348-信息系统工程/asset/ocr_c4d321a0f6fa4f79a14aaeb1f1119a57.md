# 1.开发生命周期的变化

# 系统开发方法的不断发展……

+   为了快速开发系统，在20世纪80年代中期推出了原型化方法

在获取一组基本说明后，快速地构造出一个初始原型，通过运行该原型得到的反馈，增强对系统需求的理解，依此建立和确认一组完整需求规范说明。上述的借助一个原型建立和确认最终采用的规范化需求说明的方法就叫“原型化方法”

+   20世纪90年代，又有面向对象的分析与设计方法

面向对象的分析是自顶向下逐层分析实体类，抽象出实体的属性与活动，建立实体类之间的关系。也可以自底向上建立概念模型，由已定义的基本对象类来构造新的对象类。

面向对象的设计主要指模块分解，分解的原则是信息隐藏和模块封装。
