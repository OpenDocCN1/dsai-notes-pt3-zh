# 物流与供应链整体解决方案——案例分析

6、项目管理能力方面的要求（最低限度的项目管理能力）

在未来几年SGM将经历市场扩张时期。因此，为配合有秩序的履行，需要制定有秩序的计划。

+   使用现代化的项目操作技术；
+   确立重要的业务进度及工作以支持市场拓展；
+   与VLSP沟通重要的业务进度及工作；
+   追踪重要业务进度工作实行，包括在实际操作滞后于计划的弥补计划。

7、其他方面的要求

+   应该在SGM规定的期限内完成SGM要求的工作；
+   为完成工作范围内工作，允许将合同项下部分业务外包给第三方，但必须实现向SGM提供有关分包商的名单和资质，经SGM和VLSP书面允许后方可执行。
