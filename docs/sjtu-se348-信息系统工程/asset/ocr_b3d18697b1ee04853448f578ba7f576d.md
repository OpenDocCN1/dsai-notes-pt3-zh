# 问题一
已经有了数据字典，为什么还需要数据管理？

为了从数据字典获得最大的投资回报，数据管理人员必须向主管部门提供下述问题的答案：

+   （1）建立数据字典要达到的目的是什么？建立数据字典的成本和效益是什么？
+   （2）什么信息应该装到数据字典中去？
+   （3）谁负责数据字典的信息输入工作？
+   （4）这些信息输入字典前谁必须负责检查和批准？
+   （5）输入前确保这些信息质量的步骤是什么？
+   （6）一旦信息输入字典，将如何对它进行维护？
+   （7）谁负责字典中数据一致性的维护？
+   （8）该字典将如何用于新系统的开发或辅助现行系统的维护？
+   （9）该字典将支持哪几种软件语言？
