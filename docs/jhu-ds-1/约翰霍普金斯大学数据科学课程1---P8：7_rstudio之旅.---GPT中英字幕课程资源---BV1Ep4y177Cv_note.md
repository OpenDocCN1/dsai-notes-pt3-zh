## 1. 菜单栏探索 🗂️

菜单栏位于屏幕顶部，通常有两行。第一行是标准的菜单，以“文件”和“编辑”开始。下方是一行图标，提供了常用功能的快捷方式。

我们将首先探索菜单栏中你将用到的主要部分。

![](img/7c6f65b968cd366045729cb0520fb6fa_16.png)

![](img/7c6f65b968cd366045729cb0520fb6fa_17.png)

### 文件菜单
在“文件”菜单中，我们可以打开新的或已保存的文件，也可以打开新的或已保存的项目（关于R项目，我们将在未来的课程中专门讲解）。你还可以保存当前文档或关闭RStudio。

![](img/7c6f65b968cd366045729cb0520fb6fa_18.png)

![](img/7c6f65b968cd366045729cb0520fb6fa_19.png)

![](img/7c6f65b968cd366045729cb0520fb6fa_20.png)

![](img/7c6f65b968cd366045729cb0520fb6fa_21.png)

![](img/7c6f65b968cd366045729cb0520fb6fa_22.png)

将鼠标悬停在“新建文件”上，会出现一个新菜单，列出了可用的各种文件格式。**R脚本**和**R Markdown**文件是最常用的文件类型，但你也可以生成R Notebook、Web应用、网站或幻灯片演示文稿。点击其中任何一个，都会在“源代码”象限打开一个新标签页。我们将在后续课程中花更多时间讲解R Markdown文件及其用途。

![](img/7c6f65b968cd366045729cb0520fb6fa_23.png)

### 会话菜单
“会话”菜单包含一些R特有的功能，你可以在这里重启、中断或终止R会话。当R运行异常、卡住，或者你想停止当前操作并从头开始时，这些功能会很有帮助。

### 工具菜单
“工具”菜单是一个功能宝库，值得你深入探索。目前你需要知道的是，你可以在这里安装新包（参见下一讲）、设置版本控制软件（参见未来关于连接GitHub和RStudio的课程），以及设置RStudio的外观和功能选项。我们现在暂时不修改这些设置，但建议你在对RStudio有更多经验后，自行探索这些菜单，根据个人偏好进行调整。

控制台区域对你来说应该很熟悉。当你打开R时，首先看到的就是控制台。这是你输入和执行命令的地方，也是命令输出显示的地方。

要执行你的第一个命令，可以尝试在大于号 `>` 提示符后输入 `1 + 1`，然后按回车。你应该会看到输出 `[1] 2` 显示在你的命令下方。

现在，将屏幕上的代码复制并粘贴到你的控制台中，然后按回车。这段代码会创建一个4行2列、包含数字1到8的矩阵。

```r
example <- matrix(c(1,2,3,4,5,6,7,8), nrow=4, ncol=2)
```

## 5. 文件、绘图、包与帮助区域 🔍

我们要看的最后一个区域位于RStudio窗口的右下角。这个象限顶部有五个标签页：**文件**、**绘图**、**包**、**帮助**和**查看器**。

*   **文件**：在这里，你可以看到当前工作目录中的所有文件。如果这不是你想保存或检索文件的位置，你也可以在此标签页中使用最右侧的省略号（…）更改当前工作目录：找到所需文件夹，然后在“更多”齿轮图标下，将此新文件夹设置为工作目录。
*   **绘图**：如果你的代码生成了图形，它将显示在这里。你可以使用箭头浏览之前生成的图形。“缩放”功能会在一个新窗口中打开图形，该窗口比象限区域大得多。“导出”是保存图形的方式，你可以将其保存为图像或PDF。“扫帚”图标会清除内存中的所有图形。
*   **包**：我们将在下一节关于R包的课程中更深入地探索这个标签页。在这里，你可以看到所有已安装的包，加载、卸载这些包，以及更新它们。
*   **帮助**：这是你查找R包和各种函数文档的地方。此面板的右上角有一个搜索功能，用于当你对特定函数或包有疑问时进行查询。
