## 循环与列表的核心概念 🔄

上一节我们介绍了本周的学习目标，本节中我们来看看具体要掌握哪些技能。

你将能够：
*   预测包含**循环**和**列表**的代码的输出。
*   在遍历对象时使用 **`range`** 函数。
*   使用 **`for each`** 循环来遍历字符串或列表。
*   使用带 **`range`** 的 **`for`** 循环或 **`while`** 循环。
*   在遍历列表时，比较两个相邻的值。

我将向你展示如何使用**列表推导式**，这是一种能让代码更简洁、并能过滤数据的方法。

同时，你也需要学会在面对具体问题时，如何判断并选择使用哪种类型的循环。
