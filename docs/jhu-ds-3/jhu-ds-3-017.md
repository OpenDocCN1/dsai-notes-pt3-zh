# 017：创建新变量 📊




在本节课中，我们将学习如何在R中创建新的变量。当我们将数据集加载到R后，有时会发现原始数据中并不包含我们需要的某些变量。因此，我们需要对数据进行一些转换，以获得所需的值。通常，我们会将这些新值添加回数据框中，这在预测建模等场景中尤为重要，因为我们需要创建可能用作预测因子的新变量。



## 概述

创建新变量是数据清理和准备过程中的关键步骤。它允许我们根据现有数据生成新的信息，从而更好地进行分析和建模。本节将介绍几种常见的创建新变量的方法，包括创建序列、指示变量、分类变量以及应用数学变换。



---




## 创建序列 🔢


在深入分析数据之前，我们首先需要了解如何创建序列。序列常用于索引对数据执行的各种操作。在R中，我们使用 `seq` 命令来创建序列。



通常，你需要告诉 `seq` 函数序列的最小值和最大值。有两种主要方式来指定生成多少个值：

1.  使用 `by` 参数。例如，`by = 2` 表示从1开始，每个新值增加2。
    ```r
    seq(1, 10, by = 2)
    ```

2.  指定向量的长度。例如，下面的代码会创建一个从1开始到10结束，且恰好包含3个值的向量。
    ```r
    seq(1, 10, length = 3)
    ```







3.  第三种方法是使用 `seq_along`。假设你有一个包含五个值的向量 `x`，并且你想创建一个索引来遍历这五个值，你可以使用 `seq_along(x)`。这将创建一个与 `x` 长度相同、具有连续索引的向量，可用于循环或访问数据子集。
    ```r
    x <- c(5, 10, 15, 20, 25)
    seq_along(x)
    ```

## 创建子集指示变量 🏷️



上一节我们介绍了如何创建序列，本节中我们来看看如何创建指示变量。一种你可能想要创建的变量类型是用于指示另一个变量属于哪个子集的变量。



例如，在我们的餐厅数据中，我们有餐厅所在的社区信息。我可能想找到所有位于我附近的两个社区（Roland Park 和 Homeland）的餐厅。使用 `%in%` 命令可以让我只找到位于这两个社区的餐厅。该命令会返回一个逻辑向量：如果在指定社区中则为 `TRUE`，否则为 `FALSE`。

然后，我将这个名为 `nearMe` 的新变量附加到餐厅数据中。这样，我现在就可以根据这个变量来筛选出我附近的餐厅，这是一种比总是使用较长的 `%in%` 命令更简洁的数据子集筛选方式。

```r
restData$nearMe <- restData$neighborhood %in% c(“Roland Park”, “Homeland”)
```

## 创建二元变量 ✅❌



你可能想做的另一件事是创建二元变量。例如，我们可能想找出邮政编码错误的情况。




这里，我通过赋值给数据框来创建变量 `zipWrong`。我使用了 `ifelse` 命令。对于 `ifelse` 命令，我首先给它一个条件。在这个例子中，条件是邮政编码是否小于0。如果邮政编码小于0，我们认为这个邮政编码一定是错误的。如果条件成立（即邮政编码小于0），函数返回 `TRUE`；如果条件不成立（即邮政编码为正数），则返回 `FALSE`。

最终，我可以创建一个表格来查看邮政编码是否错误（即是否小于0）。在所有邮政编码大于0的情况下，我得到 `FALSE`；在邮政编码小于0的那一个案例中，我得到 `TRUE`。这可能是一个我希望从数据集中过滤掉的值，而这种方法使得过滤这些值变得容易。

```r
restData$zipWrong <- ifelse(restData$zipCode < 0, TRUE, FALSE)
```

---



## 将定量变量转换为分类变量 📈➡️📊







你可能还想将定量变量转换为分类变量。例如，我们可能想将邮政编码分成连续的几组。





这里，我将创建一个名为 `zipGroups` 的变量。我将使用 `cut` 命令，将其应用于定量变量 `zipCode`，并告诉 `cut` 命令按照我提供的一些值（在这个例子中是该邮政编码的分位数）来分割它。

```r
restData$zipGroups <- cut(restData$zipCode, breaks = quantile(restData$zipCode))
```


这将返回一个因子变量 `zipGroups`，它将 `zipCode` 变量分割成从第0分位数到第25百分位数、第25到第50百分位数、第50到第75百分位数以及第75到第100百分位数的区间。例如，大约有375个值落在第25百分位数和第50百分位数之间。





然后，我可以制作一个表格，显示哪些邮政编码属于这些不同的分组。你可以看到，低值落入第一组，中等值落入下一组，依此类推。这样做的效果是将一个定量变量分割成一个分类变量。

---





## 使用 `cut2` 函数简化分组



上一节我们使用 `cut` 函数和分位数来创建分组，但需要手动指定所有断点。有一个更简单的方法：如果你使用 `Hmisc` 包中的 `cut2` 函数，你可以直接指定你想将邮政编码分成四个不同的组，并且按照分位数来分割。




```r
library(Hmisc)
restData$zipGroups <- cut2(restData$zipCode, g = 4)
```


当你这样做时，它会自动为你找出分位数，并按照分位数将其分成四组。如果你不想提前设置断点，这是一种很好的方法。

## 创建因子变量 🔠





你可能想做的另一件事是创建因子变量。例如，`zipCode` 变量在加载到R中时是一个整数变量，但你可能想把它变成一个因子变量。换句话说，邮政编码增加1并不一定意味着变量在数量上发生了有意义的变化，因此你可能想将其转换为因子变量。

你可以使用 `factor` 命令来实现这一点。它接收这个整数变量作为输入，并将其转换为一个我称为 `zcf` 的因子变量。如果我查看 `zcf` 的前10个值，它们看起来和以前一样，就像邮政编码的值。但它会告诉我有多少个不同的邮政编码水平（有32个）。如果我查看这个变量的类别，它是一个因子变量。

```r
zcf <- factor(restData$zipCode)
```

---






## 因子变量的其他属性






关于因子变量，你可能还想知道其他一些属性。这里，我将创建一个虚拟向量，以便我们可以看到因子变量的其他一些属性。我将创建一个包含“yes”和“no”的向量，并随机生成一个大小为10的向量。

```r
y <- sample(c(“yes”, “no”), size = 10, replace = TRUE)
```





然后，我将其转换为一个因子变量。默认情况下，它会按字母顺序将最低值作为因子变量的第一个水平。但假设我希望将“yes”值作为最低水平（即参考水平），那么我可以告诉它按照这个顺序创建水平。

```r
y <- factor(y, levels = c(“yes”, “no”))
```





例如，我可以重新设定该变量的水平，使参考类别等于“yes”值。



另一件你可以做的事情是，如果你想在某些类型的模型中使用它，可以使用 `as.numeric` 命令将因子变量变回数值变量。它会从最低值开始，将其称为1，然后下一个最低值称为2，依此类推。

```r
as.numeric(y)
```

## 使用 `mutate` 函数添加新变量




实际上，你可以使用 `mutate` 函数创建一个变量的新版本，并同时将其添加到数据集中。这是 `plyr` 包（注：原文为`plier`，应为`plyr`或`dplyr`，根据上下文推断）的一部分。

这里，我将创建一个新的数据框。我将对旧数据框应用 `mutate` 函数，并添加一个新变量 `zipGroups`，它等于原始 `restData` 数据框中某个变量的函数。现在，新数据框 `rest2` 将是旧的 `restData` 数据框加上新变量。现在，我可以制作 `zipGroups` 的表格，并看到它出现在这个新的 `rest2` 数据框中。

```r
library(dplyr) # 假设使用的是 dplyr 包
rest2 <- mutate(restData, zipGroups = cut2(zipCode, g = 4))
```

## 对定量数据应用变换 🔄

在探索性分析中，你可能需要对定量数据应用一些不同的变换。以下是最常见的变换列表：

*   **绝对值**：`abs(x)`
*   **平方根**：`sqrt(x)`
*   **向上取整/向下取整**：`ceiling(x)`, `floor(x)` （如果你想将值向上或向下舍入到最接近的整数）
*   **四舍五入**：`round(x, digits = n)` （舍入到指定位数），`signif(x, digits = n)` （舍入到指定有效数字）
*   **三角函数和对数**：所有标准的计算器函数，如 `cos(x)`, `sin(x)`，以及 `log(x)`（常用于处理偏态数据或有很多异常值的数据）
*   **指数函数**：`exp(x)`
