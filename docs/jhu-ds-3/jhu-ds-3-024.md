## 匹配任意字符：点号 `.`

![](img/6fc37b4015bbc555031c6dc2aa99b298_11.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_12.png)

点号 `.` 是一个元字符，它可以匹配**任何**单个字符（除了换行符）。

例如，正则表达式 `9.11` 会寻找“9”，后面跟着**任意一个字符**，再后面是“11”。

![](img/6fc37b4015bbc555031c6dc2aa99b298_14.png)

**公式/代码表示：**
```
模式： 9 . 11
匹配： 9（任意字符）11
```

![](img/6fc37b4015bbc555031c6dc2aa99b298_15.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_16.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_17.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_18.png)

因此，它会匹配以下所有短语，因为在这些例子中，“9”和“11”之间都恰好由一个字符分隔：
- `9-11`
- `9:11`
- `9 11`
- `9a11`

## 使用“或”逻辑：竖线 `|`

竖线 `|` 是表示“或”逻辑的元字符，用于组合两个不同的子表达式（称为“备选项”）。

![](img/6fc37b4015bbc555031c6dc2aa99b298_24.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_25.png)

以下是其基本用法示例：
正则表达式 `flood|fire` 会匹配包含“flood”**或**“fire”的文本行。

![](img/6fc37b4015bbc555031c6dc2aa99b298_26.png)

**公式/代码表示：**
```
模式： flood | fire
匹配： 包含“flood”或“fire”的文本
```

![](img/6fc37b4015bbc555031c6dc2aa99b298_28.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_29.png)

你可以包含任意数量的备选项。例如，`flood|earthquake|hurricane|fire` 会匹配包含其中任何一个词的文本行。

## 组合与约束：圆括号 `()`

![](img/6fc37b4015bbc555031c6dc2aa99b298_34.png)

圆括号 `()` 不仅可以将多个表达式组合成一个整体，还可以用来约束“或”逻辑 `|` 的作用范围。

例如，正则表达式 `^(good|bad)` 表示：行首必须是“good”或“bad”。这里的 `^` 被括号约束，同时作用于两个备选项。

![](img/6fc37b4015bbc555031c6dc2aa99b298_36.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_37.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_38.png)

**公式/代码表示：**
```
模式： ^ ( good | bad )
匹配： 以“good”或“bad”开头的行
```

![](img/6fc37b4015bbc555031c6dc2aa99b298_39.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_40.png)

如果不加括号，如 `^good|bad`，则意味着：要么行首是“good”，要么整行中任意位置有“bad”。

![](img/6fc37b4015bbc555031c6dc2aa99b298_42.png)

## 表示可选：问号 `?`

当问号 `?` 紧跟在某个字符或子表达式（用括号括起）后面时，表示该部分是可选的。

例如，要匹配“George Bush”或“George W. Bush”，可以使用正则表达式 `[Gg]eorge( [Ww]\.)? Bush`。这里的 `( [Ww]\.)?` 表示中间带点的“W”或“w”是可选的。

![](img/6fc37b4015bbc555031c6dc2aa99b298_46.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_47.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_48.png)

**注意**：点号 `.` 本身是元字符。要匹配字面意义上的点号，需要使用反斜杠进行转义，写作 `\.`。

![](img/6fc37b4015bbc555031c6dc2aa99b298_49.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_50.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_51.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_52.png)

**公式/代码表示：**
```
模式： [Gg]eorge ( [Ww] \. )? Bush
匹配： “George Bush” 或 “George W. Bush”
```

## 重复匹配：星号 `*` 和加号 `+`

![](img/6fc37b4015bbc555031c6dc2aa99b298_54.png)

星号 `*` 表示前面的元素可以重复**任意次数**，包括**零次**。
加号 `+` 表示前面的元素必须至少出现**一次**。

![](img/6fc37b4015bbc555031c6dc2aa99b298_55.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_56.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_57.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_58.png)

以下是应用示例：
正则表达式 `\(.*\)` 会匹配一对圆括号 `()` 及其中的**任何内容**（包括空内容），因为 `.*` 可以匹配零个到任意多个字符。

![](img/6fc37b4015bbc555031c6dc2aa99b298_59.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_60.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_61.png)

**公式/代码表示：**
```
模式： \( .* \)
匹配： (这里可以是任何字符，也可以没有字符)
```

![](img/6fc37b4015bbc555031c6dc2aa99b298_63.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_64.png)

而正则表达式 `[0-9]+ (.* [0-9]+)?` 则用于匹配至少一个数字，后面可能跟着一些字符，然后再跟着至少一个数字。

## 精确控制重复次数：花括号 `{}`

![](img/6fc37b4015bbc555031c6dc2aa99b298_66.png)

花括号 `{}` 作为区间限定符，可以精确指定一个表达式匹配的**最小**和**最大**次数。

![](img/6fc37b4015bbc555031c6dc2aa99b298_67.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_68.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_69.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_70.png)

其用法规则如下：
- `{m,n}`：至少匹配 `m` 次，至多匹配 `n` 次。
- `{m}`：恰好匹配 `m` 次。
- `{m,}`：至少匹配 `m` 次，无上限。

![](img/6fc37b4015bbc555031c6dc2aa99b298_72.png)

例如，正则表达式 `[Bb]ush( +[^ ]+){1,5} debate` 用于查找“Bush”和“debate”之间出现1到5个单词（由空格分隔的非空格字符序列）的句子。

![](img/6fc37b4015bbc555031c6dc2aa99b298_73.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_74.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_76.png)

**公式/代码表示：**
```
模式： [Bb]ush ( +[^ ]+ ){1,5} debate
匹配： Bush [空格单词]（重复1到5次） debate
```

## 引用已匹配的文本：圆括号与 `\1`, `\2`...

![](img/6fc37b4015bbc555031c6dc2aa99b298_82.png)

在大多数正则表达式实现中，圆括号 `()` 还有另一个重要功能：**捕获**匹配到的子字符串，并可以通过 `\1`、`\2` 等对其进行**反向引用**。

![](img/6fc37b4015bbc555031c6dc2aa99b298_84.png)

例如，正则表达式 ` +([a-zA-Z]+) +\1 +` 用于查找被空格包围、并且**紧接着重复出现一次**的单词。

![](img/6fc37b4015bbc555031c6dc2aa99b298_85.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_86.png)

**公式/代码表示：**
```
模式：空格 (单词) 空格 \1 空格
匹配：寻找像“ night night ”或“ blah blah ”这样的重复短语。
```

## 贪婪匹配与惰性匹配

默认情况下，`*` 和 `+` 等重复符是“贪婪的”，它们会尽可能匹配**最长**的字符串。

例如，对于字符串 `“sitting at the table”`，正则表达式 `s.*s` 会匹配从第一个`s`到最后一个`s`的整个字符串 `“sitting at the table”`。

![](img/6fc37b4015bbc555031c6dc2aa99b298_92.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_93.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_94.png)

![](img/6fc37b4015bbc555031c6dc2aa99b298_95.png)

如果想让它变得“懒惰”（匹配尽可能短的字符串），可以在重复符后面加上 `?`。例如，`s.*?s` 会匹配最短的可能结果，如 `“sittins”`（假设字符串是 `“sittings”`）。

![](img/6fc37b4015bbc555031c6dc2aa99b298_96.png)

**公式/代码表示：**
```
贪婪模式： s .* s -> 匹配从第一个s到最后一个s的所有内容。
惰性模式： s .*? s -> 匹配从第一个s到紧接着的下一个s的内容。
```

## 总结与回顾 🎯

本节课我们一起深入学习了正则表达式的核心元字符及其应用：

1.  **点号 `.`**：匹配任意单个字符。
2.  **竖线 `|`**：提供“或”逻辑选择。
3.  **圆括号 `()`**：组合表达式、约束范围、捕获分组以供反向引用（如 `\1`）。
4.  **问号 `?`**：表示前面的元素是可选的。
5.  **星号 `*` 和加号 `+`**：控制元素重复次数（任意次/至少一次）。
6.  **花括号 `{}`**：精确控制元素重复的最小和最大次数。
7.  **贪婪与惰性**：理解 `*` 和 `+` 的默认贪婪特性，以及如何使用 `?` 使其变为惰性匹配。

正则表达式是文本处理的强大工具，它由**字面量**（要查找的具体文本）和**元字符**（提供匹配规则的语法）构成。在处理非结构化或格式混乱的文本数据（如日志文件、网页抓取内容）时，正则表达式尤其有用。在R语言中，我们常将正则表达式与 `grep()`、`grepl()`、`sub()`、`gsub()` 等函数结合使用，来进行字符串的搜索、提取和替换操作。

通过掌握这些模式，你将能够更高效地清理、筛选和转换文本数据，为后续的数据分析打下坚实基础。
