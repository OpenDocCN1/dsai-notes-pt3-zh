# 使用LlamaIndex构建RAG全栈Web应用：P1：课程介绍 🚀

在本节课中，我们将要学习由吴恩达与LlamaIndex合作推出的《使用LlamaIndex构建RAG全栈Web应用》课程的核心内容与学习路径。本课程将指导你使用JavaScript构建一个完整的RAG（检索增强生成）全栈Web应用程序。

## 概述

RAG应用目前在多个商业领域的需求非常高，是许多开发者希望基于大语言模型构建的最常见应用之一。在本课程中，你将深入学习构建全栈RAG Web应用背后的技术细节，包括如何在JavaScript中设置后端和前端的完整工作流。

虽然本课程使用JavaScript，但如果你熟悉编程而只是不熟悉JavaScript语言，你仍然能够跟上课程进度。

## 课程内容与结构

以下是本课程将涵盖的核心模块。

### 1. 构建后端Web API

你将首先学习构建一个后端Web API，了解如何调用它，以及如何将LlamaIndex集成到该API中。这是整个应用的数据处理与检索核心。

### 2. 构建交互式React前端组件

接下来，你将构建一个React交互式组件，该组件会调用你的API，并将对查询的响应结果显示出来。这构成了应用的用户界面层。

![](img/5f4a9db02d224ec7a2e1cf9517ee8e5d_1.png)

### 3. 深入RAG技术与智能代理

在第三课中，你将通过构建一个智能代理来进一步深入研究RAG技术。这个代理能够：
*   在多个数据源之间进行选择。
*   使用函数作为工具来采取行动、收集信息。

这是一种非常强大的技术，可用于创建高度灵活、能力强大的软件。

### 4. 生产环境就绪技术

你还会深入学习Web应用的生产就绪技术，包括：
*   如何持久化你的数据。
*   如何加载数据索引，以便能够持续地对数据进行重新索引。

### 5. 从简单查询到持续聊天与流式响应

课程将引导你从简单的一次性查询，过渡到持续的聊天对话。同时，你将学习如何从等待完整答案，切换到获取实时响应或流式传输结果。

## 课程工具与支持

讲师Lori将详细讲解这些概念，并向你展示如何设置LlamaIndex的 `create-llama` 命令行工具。这个工具可以生成全栈Web应用模板，帮助你将所有内容部署到生产环境。
