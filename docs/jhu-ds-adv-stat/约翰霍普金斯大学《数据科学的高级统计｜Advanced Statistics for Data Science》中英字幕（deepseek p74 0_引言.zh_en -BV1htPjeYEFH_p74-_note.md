# 高级统计与数据科学：0：引言

在本节课中，我们将要学习《高级线性模型 1》的课程介绍。本节将概述课程内容、学习前提、课程结构以及学习目标。

大家好，我是布莱恩·卡霍，约翰霍普金斯大学生物统计学系的教授。

欢迎来到《高级线性模型 1》课程。我认为线性模型或许是整个统计学中最重要的课题。它是我们揭示近似于潜在机制模型的基本方法，这些模型有时能在大大小小的数据集中被发现。

为了学习这门课程，我认为具备一些先修知识会很有帮助。

以下是学习本课程前建议掌握的知识点：

*   **线性代数**：需要具备一些线性代数知识，并且最好有一定程度的掌握。
*   **多元微积分**：掌握一些多元微积分知识也会很有用。
*   **基础统计学**：如果你从未上过统计学课程，了解一些关于假设检验、分布、抽样假设等基础统计学知识会很有帮助。我的另一门课程《统计推断》是数据科学专项课程的一部分，还有课程 Boot Camp 1 和 2 也基于 Coursera 平台，它们可以作为学习本课程所需知识的合理先修课程。

这是一门关于线性模型课题的相当高级的课程。在本课程中，我们将几乎完全专注于**最小二乘法**。在后续课程中，我们将继续学习统计推断和更高级的回归建模技术。然而，我们不会花大量时间来阐述线性模型的必要性。因此，如果你确实需要这方面的知识，甚至从未真正见过线性模型，也不知道它们可能的用途是什么，我真心建议你先学习《回归模型》课程，它也是数据科学专项课程的一部分。或者，至少可以观看我在 YouTube 上发布的《回归模型》讲座视频，我的 YouTube 用户名是 BcaO。

上一节我们介绍了课程的先修要求，本节中我们来看看课程的具体结构。

本课程主要采用一系列可汗学院风格的视频进行教学。在这些视频中，我将使用一个手写板进行书写，并讲解其背后的数学原理，尤其是在第一组讲座中重点讲解**最小二乘法**的数学基础。此外，我们还有一些计算机实验，我会展示数学原理如何与计算相关联，以实际执行线性模型的计算。所有测验均为选择题，每个模块有一个测验。

欢迎加入本课程。我期待与大家一起学习，并希望能在后续的线性模型课程中再次见到大家。
