
## 转化为Skolem 范式的例子

- 一公式的前束范式与原公式是等价的，但一般情况下一公式的 Skolem范式与原公式是不等价的。很多人写公式的Skolem范式时与原公式间 “=”相连，这是不对的。
- 例. 将公式 ∀x∀y（A(x)→B(x,y)）→(∃yC(y)→∃zD(z)) 化为Skolem范式。
- 解：前面已经将该公式化成了前束范式 ∃x∃y∀t∃z((A(x)∨∼C(t)∨D(z))∧(∼B(x,y)∨∼C(t)∨D(z)))，且母式为合取范式。
- 用a代替x，用b代替y，用f(t)代替z，得公式的Skolem范式： ∀t((A(a)∨∼C(t)∨D(f(t)))∧(∼B(a,b)∨∼C(t)∨D(f(t))))

## 17 子句集

- 子句
- 若干个文字的一个析取式称为一个子句。特别，没有文字的子句称为空子句，记为 。只有一个文字的子句称为单元子句。

- 子句集
- 设G是一阶逻辑中的公式，将其化为Skolem标准型，设其母式为M，M给出的子句集S称为公式G的子句集。

- 定理2 设S是公式G的子句集. 于是，G是不可满足的，当且仅当S是不可满足的.

## 公式与其Skolem范式不等价的例子

- 一般来说，S和G不等价。但是，G是S的逻辑结果（或S蕴涵G）。

例. G=∃xP(x)， S=P(a)。令G和S的解释I如下：

D={2, 3},

| a | P(2) | P(3) |
|---|---|---|
| 2 | F | T |

则I满足G，但I弄假S。

## 讨论： G与S的恒真性是否等价

- • 若G是恒真的，S是否是恒真的？
- 不一定！
- I: D={2, 3},
- a b P(2) P(3)
- 2 3 F T
- G=∀xP(x)→P(a)    S= ~P(b) ∨ P(a)
- G是恒真的,而T₁(S)=F。

- • 如果S是恒真的，G是否是恒真的？
- 确定（ S ⇒ G ）

## 对于合取形式求其子句集的方法

- • 推论 设 $G=G_1\land\dots\land G_n$，$S_i$ 是 $G_i$ 的 Skolem 标准型，$i=1,\dots,n$。令 $S=S_1\cup\dots\cup S_n$。于是，$G$ 是不可满足的，当且仅当 $S$ 是不可满足的。此后，也称 $S$ 是 $G$ 的子句集。

例 已知某些病人喜欢所有的医生，没有一个病人喜欢任意一个骗子。证明任意一个医生都不是骗子。

A1: ∃x (P(x) ∧ ∀y(D(y)→L(x, y)))

A2: ∀x(P(x) →∀y(Q(y) →∼L(x, y)))

B: ∀x(D(x) →∼Q(x))

我们要证明B是A1和A2的逻辑结果，即公式 A1∧A2∧∼B是不可满足的。

A1=∃x (P(x) ∧ ∀y(~D(y) ∨ L(x, y))) 
=∃x ∀y (P(x) ∧ (~D(y) ∨ L(x, y))) 
----> ∀y (P(a) ∧ (~D(y) ∨ L(a, y))) 
A2=∀x(P(x) → ∀y(~Q(y) ∨ ~L(x, y))) 
=∀x(~P(x) ∨ ∀y(~Q(y) ∨ ~L(x, y))) 
=∀x∀y (~P(x) ∨ ~Q(y) ∨ ~L(x, y)) 
~B=~(∀x(D(x) → ~Q(x))) 
=∃x (D(x) ∧ Q(x)) 
----> D(b) ∧ Q(b) 
因此，公式A1∧A2∧~B的子句集为 
S= {P(a), ~D(y)∨L(a,y), ~P(x)∨~Q(y)∨~L(x, y),D(b),Q(b)} 
下一章从S出发给出推出空子句的归结演绎，从而证出S不可满足。

## 6.3 合一算法

例：

- - C₂: ~P(f(x)) ∨ R(x)

没有互补对；

- - C₃: R(x) ∨ Q(f(x))

替换和合一是为了处理谓词逻辑中子句之间的模式匹配而引进。

## 一、替换与最一般合一替换

- - 定义(替换)一个替换是形如{t1/v1, ..., tn/vn}的一个有限集合，其中vi是变量符号，ti是不同于vi的项。并且在此集合中没有在斜线符号后面有相同变量符号的两个元素，称ti为替换的分子，vi为替换的分母。

例. {a/x, g(y)/y, f(g(b))/z}是替换;
{x/x}, {y/f(x)}, {a/x, g(y)/y, f(g(b))/y}不是替换;

基替换:当t1,...,tn是基项时，称此替换为基替换。

空替换: 没有元素的替换称为空替换，记为ε。

## 替换

定义（改名） 设替换 σ={ t₁/x₁, ..., tₙ/xₙ } 如果 t₁, ..., tₙ是不同的变量符号，则称 σ为一个改名替换，简称改名。

替换作用对象： 表达式（项、项集、原子、原子集、文字、子句、子句集）。

基表达式： 没有变量符号的表达式。

子表达式： 出现在表达式 E 中的表达式称为 E 的子表达式。

## E的例

定义（E的例） 设 θ = { t₁/v₁, ..., tₙ/vₙ } 是一个替换，E 是一个表达式。将 E 中出现的每一个变量符号，vᵢ (1 ≤ i ≤ n)，都用项 tᵢ 替换，这样得到的表达式记为 E^θ。称 E^θ 为 E 的例。

若 E^θ 不含变量，则 E^θ 为 E 的基例。

例. 令 θ = {a/x, f(b)/y, c/z}， E = P(x, y, z)

于是 E 的例（也是 E 的基例）为 E^θ = P(a, f(b), c)

## 练习：

- - E=P(x, g(y), h(x,z)),
- θ={a/x, f(b)/y, g(w)/z}
- E^θ=P(a, g(f(b)), h(a,g(w)))
- - E=P(x, y, z), θ={y/x, z/y}
- E^θ=P(y, z, z). E^θ≠P(z, z, z).

## 替换的乘积

- - 定义（替换的乘积）设 θ = { t₁/x₁, ..., tₙ/xₙ }, λ = { u₁/y₁, ..., uₘ/yₘ } 是两个替换。将下面集合 { t₁^λ/x₁, ..., tₙ^λ/xₙ, u₁/y₁, ..., uₘ/yₘ } 中任意符合下面条件的元素删除：
- 1） uᵢ/yᵢ, 当 yᵢ ∈ {x₁, ..., xₙ} 时；
- 2） tᵢ^λ/xᵢ, 当 tᵢ^λ = xᵢ 时。
- 如此得到一个替换，称为 θ 与 λ 的乘积，记为 θ·λ。

- - 例. 令 θ = {f(y)/x, z/y}
- λ = {a/x, b/y, y/z}
- 于是得集合
- { t₁^λ/x₁, t₂^λ/x₂, u₁/y₁, u₂/y₂, u₃/y₃ }
- = {f(b)/x, y/y, a/x, b/y, y/z}
- θ 与 λ 的乘积为
- θ·λ = {f(b)/x, y/z}

θ={a/x}, λ={b/x}
θ·λ={a/x}
λ·θ={b/x}
可见： θ·λ ≠ λ·θ

- - 例子：
- - E=P(x, y, z)
- - θ={a/x, f(z)/y, w/z}
- - E^θ=P(a, f(z), w)
- - λ={t/z, g(b)/w}
- - (E^θ)^λ=P(a, f(t), g(b))
- - θ·λ={a/x, f(t)/y, g(b)/z,g(b)/w}
- - E^θλ=P(a, f(t), g(b))

## 引理 若E是表达式，θ，λ是两个替换，则E^(θ·λ) = (E^θ)^λ

证明：设v_i是E中任意一个变量符号，而
θ = { t1/x1, ..., tn/xn }， λ = { u1/y1, ..., um/ym }

- - 若v_i既不在{ x1, ..., xn }中，也不在{ y1, ..., ym }中，则v_i在E^(θ·λ)中和在(E^θ)^λ中都不变。

- - 若v_i = x_j (1≤j≤n)，则E中的v_i，在(E^θ)^λ中先变成t_j，然后再变成t_j^λ；E中的v_i在E^(θ·λ)中立即就变成了t_j^λ。故E中v_i在(E^θ)^λ中和在E^(θ·λ)中有相同变化。

- - 若v_i = y_j (1≤j≤m)，且y_j ∉ { x1,...,xn }，则E中v_i在(E^θ)^λ中变为u_j；E中v_i在E^(θ·λ)中也变为u_j(注意:y_j ∉ {x1,..., xn}，所以u_j/y_j ∈ θ·λ)，故E中v_i在(E^θ)^λ中和在E^(θ·λ)中有相同变化。

由于v_i的任意性，故引理得证。
