# 五、广义归结

定义（广义子句）设 A₁, ..., Aₙ 是一些原子, Φ(A₁, ..., Aₙ) 是以逻辑联结词 ~、∨、∧、→、↔ 联结这些原子和一些 0, 1 做成的公式, 称为广义子句, 其中 0 代表 F, 1 代表 T。

如果一个广义子句中没有原子，只有 0 或者 1，则称其为常子句。

其值为 0 的常子句称为零子句，其值为 1 的常子句称为壹子句。

定义（广义子句的因子）设 Φ(A₁, ..., Aₙ) 是一个广义子句，A_{i₁}, ..., A_{i_r} 有一个 mgu σ（1 ≤ i_j ≤ n, j = 1, ..., r），则称 Φ^σ 为 Φ 的因子。
