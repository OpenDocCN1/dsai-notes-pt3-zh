# 例. 设 $G=\forall x(A(x)\to B(x))$，
$H=\forall x A(x)\to \forall x B(x)$ 证明：$G\Rightarrow H$

证明：设 $I$ 是满足 $G$ 的任意一个解释。

若 $T_I(\forall x\,A(x))=F$，则 $T_I(\forall x A(x)\to \forall x B(x))=T$；

若 $T_I(\forall x\,A(x))=T$，则在 $I$ 下对任意 $x\in D$，有
$T_I(A(x))=T$，

又由 $T_I(\forall x(A(x)\to B(x)))=T$ 知，对
任意 $x\in D$，$T_I(A(x)\to B(x))=T$，故
$T_I(B(x))=T$，即，$T_I(\forall x(B(x)))=T$，

因此，$T_I(\forall x A(x)\to \forall x B(x))=T$。
