# 应用归结原理进行定理证明-习题3

练习：
(1)马科斯(Marcus)是男人； (2)马科斯是庞贝人；
(3)所有庞贝人都是罗马人； (4)恺撒(Caesar)是一位统治者；
(5)所有罗马人忠于或仇恨恺撒； (6)每个人都忠于某个人；
(7)男人只想暗杀他们不忠于的统治者； (8)马科斯试图暗杀恺撒。
证明：马科斯仇恨恺撒。

定义谓词：
Man(x): x是男人； Pompeian(x): x是庞贝人；
Roman(x):x是罗马人； Ruler(x):x是统治者；
Loyalto(x,y):x忠于y； Hate(x,y):x仇恨y；
Tryassassinate(x,y):x试图暗杀y。
