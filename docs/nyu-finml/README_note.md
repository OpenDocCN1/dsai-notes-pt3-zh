## 强化学习基础 🧠

上一节我们介绍了课程概述，本节中我们来看看强化学习的基本框架。

强化学习是机器学习的一个分支。它关注智能体如何在一系列行动中学习，以最大化累积奖励。智能体通过与环境互动来学习。环境在智能体执行行动后提供新的状态和奖励。

以下是强化学习中的核心要素：

*   **智能体**：做出决策的学习者。
*   **环境**：智能体与之交互的一切。
*   **状态**：环境在特定时刻的描述，记为 **s**。
*   **行动**：智能体可以执行的操作，记为 **a**。
*   **奖励**：智能体在采取行动后从环境获得的即时反馈，记为 **r**。
*   **策略**：智能体在给定状态下选择行动的规则，记为 **π(a|s)**。

## 马尔可夫决策过程 📊

理解了基本要素后，我们需要一个形式化的模型来描述强化学习问题，这就是马尔可夫决策过程。

马尔可夫决策过程为序列决策问题提供了数学框架。MDP假设未来状态仅取决于当前状态和行动，而与过去历史无关。这个性质称为马尔可夫性。

一个MDP由五元组 **(S, A, P, R, γ)** 定义：
*   **S**：所有可能状态的集合。
*   **A**：所有可能行动的集合。
*   **P**：状态转移概率，**P(s'|s, a)** 表示在状态 **s** 采取行动 **a** 后转移到状态 **s'** 的概率。
*   **R**：奖励函数，**R(s, a)** 或 **R(s, a, s')** 表示在状态 **s** 采取行动 **a**（并转移到 **s'**）后获得的期望奖励。
*   **γ**：折扣因子，范围在 **[0, 1]**，用于权衡即时奖励和未来奖励的重要性。

## 价值函数与贝尔曼方程 ⚖️

定义了问题模型后，我们需要评估策略的好坏。价值函数和贝尔曼方程是完成这一任务的核心工具。

价值函数用于评估状态或状态-行动对的好坏。状态价值函数 **V^π(s)** 表示从状态 **s** 开始，遵循策略 **π** 所能获得的期望累积折扣奖励。行动价值函数 **Q^π(s, a)** 表示在状态 **s** 采取行动 **a**，然后遵循策略 **π** 所能获得的期望累积折扣奖励。

它们满足贝尔曼方程，这是一个递归关系：

**V^π(s) = Σ_{a} π(a|s) Σ_{s'} P(s'|s, a) [ R(s, a, s') + γ * V^π(s') ]**

**Q^π(s, a) = Σ_{s'} P(s'|s, a) [ R(s, a, s') + γ * Σ_{a'} π(a'|s') Q^π(s', a') ]**

## 主要算法：动态规划与时间差分 🚀

有了评估方法，下一步就是寻找最优策略。动态规划和时间差分是两类经典算法。

动态规划方法在已知环境模型（即 **P** 和 **R**）的情况下非常有效。策略迭代通过交替进行策略评估和策略改进来寻找最优策略。价值迭代则直接迭代更新价值函数直至收敛到最优值。

然而，金融环境通常是模型未知的。时间差分方法通过与环境的实际交互来学习。它结合了蒙特卡洛采样和动态规划自举的思想。SARSA是一种在策略TD控制算法，它使用当前策略选择的行动来更新Q值。Q-Learning是一种离策略TD控制算法，它使用所有可能行动中的最大Q值来更新，其更新规则为：

**Q(s, a) ← Q(s, a) + α [ r + γ * max_{a'} Q(s', a') - Q(s, a) ]**

其中 **α** 是学习率。

## 金融应用实例：交易与投资组合管理 💰

最后，我们将理论应用于实践，看看强化学习如何解决具体的金融问题。

在算法交易中，智能体的状态可以是资产价格、技术指标、市场深度等。行动可以是“买入”、“持有”或“卖出”。奖励通常与交易利润或夏普比率相关。

在投资组合管理中，状态包含各资产的历史收益和风险特征。行动是资产权重的重新分配。奖励函数可以设计为投资组合的回报率，同时用风险度量（如方差）作为惩罚项。

一个简化的投资组合再平衡任务可以建模为：在每个时间步 **t**，智能体观察状态 **s_t**（如资产收益率），输出行动 **a_t**（新的资产权重向量），环境根据资产的实际回报产生奖励 **r_t**，并进入下一个状态 **s_{t+1}**。
