## 从确定性策略到随机策略

![](img/1609815f75ad65b2acccd2e7d59a4a5e_13.png)

我们之前将问题表述为一个马尔可夫决策过程，并使用了二次一阶奖励函数。只要有了MDP问题，我们就可以使用动态规划或强化学习来寻找最优策略。这个最优策略是一个从状态空间到行动空间的映射函数，在强化学习中被称为**确定性策略**。

确定性策略可以视为一个由狄拉克δ函数给出的特殊概率分布：
```
π(a_t | x_t) = δ(a_t - a_t*)
```
其中，`a_t*` 是通过求解投资组合优化问题得到的确定性最优行动。

然而，确定性策略在现实中几乎不存在，也与金融实践不太相关。原因如下：
*   策略的参数是从有限数据中估计得出的，这些参数本身具有随机性。
*   模型依赖的预期变量（如预期收益）是估计值，因此模型推荐的配置也具有随机性。
*   现实数据往往不是严格最优的，可能包含次优决策。确定性策略会赋予这些数据零概率，这不符合实际情况。

![](img/1609815f75ad65b2acccd2e7d59a4a5e_15.png)

因此，我们需要考虑更具一般性的**随机策略**。

## 随机策略的定义与优势

![](img/1609815f75ad65b2acccd2e7d59a4a5e_17.png)

随机策略 `π` 是给定状态 `x_t` 下，行动 `a_t` 的一个有效概率分布，通常由参数向量 `θ` 参数化：
```
π_θ(a_t | x_t)
```

![](img/1609815f75ad65b2acccd2e7d59a4a5e_19.png)

![](img/1609815f75ad65b2acccd2e7d59a4a5e_21.png)

使用随机策略而非确定性策略，为我们带来了新的视角和工具：
*   **概率建模**：我们可以为观察到的数据建立概率模型。
*   **生成模型**：该概率模型可用于模拟和生成未来的数据。
*   **不确定性评估**：模型不仅能给出推荐配置，还能提供对该配置的置信度评估。

![](img/1609815f75ad65b2acccd2e7d59a4a5e_23.png)

![](img/1609815f75ad65b2acccd2e7d59a4a5e_25.png)

## 基于随机策略的优化问题

![](img/1609815f75ad65b2acccd2e7d59a4a5e_27.png)

现在，让我们看看如何将投资组合优化问题改写为基于随机策略的形式。新的优化目标是最大化期望折扣未来奖励：
```
J(π) = E_{τ∼p_π} [ Σ_{t=0}^{T-1} γ^t R_t ]
```
其中，路径概率 `p_π` 由策略和状态转移共同决定：
```
p_π(τ) = π(a_0 | x_0) Π_{t=0}^{T-2} p(x_{t+1} | x_t, a_t) π(a_{t+1} | x_{t+1})
```
这里，`p(x_{t+1} | x_t, a_t)` 是环境的状态转移概率。

![](img/1609815f75ad65b2acccd2e7d59a4a5e_29.png)

这一公式化的核心转变是：**我们将函数空间中的优化问题，转换为了概率分布空间中的优化问题**。接下来的关键是如何在这个概率空间中进行优化。

![](img/1609815f75ad65b2acccd2e7d59a4a5e_31.png)

## 引入参考策略

![](img/1609815f75ad65b2acccd2e7d59a4a5e_33.png)

![](img/1609815f75ad65b2acccd2e7d59a4a5e_35.png)

为了在概率空间中进行优化，我们引入**参考策略**的概念。参考策略可以被视为在看到任何数据之前所使用的先验策略，这是贝叶斯方法中的常见思路：从先验开始，然后用数据对其进行更新。

我们将使用一个简单的高斯分布作为参考策略 `π_0`：
```
π_0(a_t | x_t) = N(a_t | â_t, Σ_a)
```
其中，均值 `â_t` 是状态 `x_t` 的线性函数：
```
â_t = a_0 + A_1 x_t
```
系数 `a_0`、`A_1` 和协方差矩阵 `Σ_a` 构成了先验的参数。为了简化，初始时我们可以使用常数系数和一个简单的协方差矩阵（例如，所有资产具有相同方差和相关性的矩阵）。

![](img/1609815f75ad65b2acccd2e7d59a4a5e_37.png)

在后续的学习中，我们将看到如何利用数据和强化学习目标，对这个先验参考策略进行贝叶斯更新，从而得到与数据一致且表现更优的后验策略。

![](img/1609815f75ad65b2acccd2e7d59a4a5e_39.png)

## 总结

![](img/1609815f75ad65b2acccd2e7d59a4a5e_43.png)

![](img/1609815f75ad65b2acccd2e7d59a4a5e_44.png)

本节课中，我们一起学习了：
1.  **确定性策略的局限性**：在随机的金融世界中，纯粹的确定性策略是不现实的。
2.  **随机策略的引入**：将策略定义为概率分布，允许我们对数据和决策进行概率建模，并能评估不确定性。
3.  **优化问题的重构**：投资组合优化问题被重新表述为在策略概率分布空间中的优化问题。
4.  **参考策略的作用**：引入高斯参考策略作为先验，为后续基于数据的贝叶斯更新提供了起点。
