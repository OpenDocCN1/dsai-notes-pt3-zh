# 048：策略梯度定理 🎯

![](img/a9e212a2748fa5d189fba6ee6659c03a_0.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_2.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_3.png)

在本节课中，我们将学习策略梯度定理。这是训练策略网络的核心理论，它告诉我们如何计算目标函数的梯度，从而通过梯度上升来优化策略。

![](img/a9e212a2748fa5d189fba6ee6659c03a_5.png)

## 概述

![](img/a9e212a2748fa5d189fba6ee6659c03a_7.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_8.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_10.png)

我们的核心目标是训练一个策略网络。这个网络观察当前状态，并输出一个动作的概率分布，我们可以从这个分布中采样一个动作。我们希望更新网络参数，以最大化状态价值函数。然而，我们不能独立地最大化每个状态的价值，因此我们选择最大化所有可能状态的期望价值。

上一节我们介绍了策略网络和价值函数的基本概念，本节中我们将深入探讨如何计算这个最大化目标的梯度。

![](img/a9e212a2748fa5d189fba6ee6659c03a_12.png)

## 目标函数的定义

![](img/a9e212a2748fa5d189fba6ee6659c03a_14.png)

我们从初始状态 S0 开始，它服从某个初始分布 P0（例如在整个环境中均匀随机）。将状态输入策略网络，网络给出动作的概率分布 πθ(a|s)，我们据此采样一个动作 A0。在环境中执行该动作后，我们会收到一个奖励 R0 并转移到新状态 S1。

状态 S0 的价值函数 Vπθ(S0) 表示从 S0 开始，遵循策略 πθ 所能获得的期望回报。我们的目标是最大化所有可能初始状态的期望价值：

![](img/a9e212a2748fa5d189fba6ee6659c03a_16.png)

**目标函数 J(θ) = 𝔼S0~P0 [ Vπθ(S0) ]**

为了最大化 J(θ)，我们需要计算其梯度 ∇θ J(θ)。由于期望运算符是线性的，梯度可以移入期望内部：

**∇θ J(θ) = 𝔼S0~P0 [ ∇θ Vπθ(S0) ]**

![](img/a9e212a2748fa5d189fba6ee6659c03a_18.png)

因此，关键在于计算单个状态价值函数 Vπθ(s) 的梯度。

![](img/a9e212a2748fa5d189fba6ee6659c03a_20.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_22.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_24.png)

## 计算价值函数的梯度

![](img/a9e212a2748fa5d189fba6ee6659c03a_26.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_28.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_30.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_32.png)

根据定义，状态价值函数是动作价值函数在其策略分布下的期望：

**Vπθ(s) = ∫ πθ(a|s) Qπθ(s, a) da**

![](img/a9e212a2748fa5d189fba6ee6659c03a_34.png)

现在，我们对这个等式两边关于参数 θ 求梯度。根据乘积法则，梯度运算可以进入积分内部：

![](img/a9e212a2748fa5d189fba6ee6659c03a_36.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_38.png)

**∇θ Vπθ(s) = ∫ [ ∇θ πθ(a|s) Qπθ(s, a) + πθ(a|s) ∇θ Qπθ(s, a) ] da**

![](img/a9e212a2748fa5d189fba6ee6659c03a_40.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_42.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_43.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_45.png)

这个结果包含两项。第一项涉及策略概率的梯度，我们可以通过反向传播轻松计算。第二项涉及动作价值函数 Q 的梯度，这比较棘手，因为我们通常没有 Q 函数的直接解析形式。

![](img/a9e212a2748fa5d189fba6ee6659c03a_47.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_48.png)

## 处理 Q 函数的梯度

![](img/a9e212a2748fa5d189fba6ee6659c03a_50.png)

为了处理 ∇θ Qπθ(s, a)，我们利用贝尔曼方程：

![](img/a9e212a2748fa5d189fba6ee6659c03a_52.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_54.png)

**Qπθ(s, a) = R(s, a) + γ 𝔼S‘~P(·|s,a) [ Vπθ(S‘) ]**

![](img/a9e212a2748fa5d189fba6ee6659c03a_56.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_57.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_58.png)

其中，即时奖励 R(s, a) 和状态转移概率 P 都来自环境，与策略参数 θ 无关。因此，对 Q 函数求梯度时，只有未来的价值函数 Vπθ(S‘) 项会产生梯度：

![](img/a9e212a2748fa5d189fba6ee6659c03a_60.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_62.png)

**∇θ Qπθ(s, a) = γ 𝔼S‘~P(·|s,a) [ ∇θ Vπθ(S‘) ]**

![](img/a9e212a2748fa5d189fba6ee6659c03a_64.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_65.png)

这个结果非常关键：当前状态-动作对的 Q 函数梯度，可以表达为下一状态的价值函数梯度的期望。

![](img/a9e212a2748fa5d189fba6ee6659c03a_67.png)

## 递归展开与策略梯度定理

![](img/a9e212a2748fa5d189fba6ee6659c03a_69.png)

我们将 ∇θ Qπθ(s, a) 的表达式代回最初的 ∇θ Vπθ(s) 公式中。经过一系列代入和展开（具体过程涉及对后续状态的递归），并假设折扣因子 γ 和无限时间步，最终会发现一个模式。

理查德·萨顿在1992年证明，所有这些项最终可以整理成一个简洁而强大的形式，即**策略梯度定理**：

![](img/a9e212a2748fa5d189fba6ee6659c03a_71.png)

**∇θ J(θ) = 𝔼(S, A)~dπθ(·), πθ(·|S) [ Qπθ(S, A) ∇θ log πθ(A|S) ]**

其中：
*   **dπθ(s)** 是一个特殊的分布，称为**折扣状态访问分布**。它本质上是智能体遵循策略 πθ 时，在所有时间步上访问到的状态的加权平均分布（权重与折扣因子 γ 有关）。
*   期望是针对服从该分布的状态 S，以及根据策略 πθ(·|S) 采样的动作 A 而言的。

![](img/a9e212a2748fa5d189fba6ee6659c03a_73.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_74.png)

## 定理的核心意义与重要性

![](img/a9e212a2748fa5d189fba6ee6659c03a_76.png)

策略梯度定理是策略梯度方法的基石。它的强大之处在于：

1.  **梯度形式简单**：目标函数的梯度最终只依赖于策略本身的对数梯度 ∇θ log πθ(A|S) 和动作价值函数 Qπθ(S, A)。
2.  **可通过采样估计**：我们不需要知道复杂的状态访问分布 dπθ(s) 的具体形式。我们只需要按照当前策略 πθ 与环境交互，收集到的一系列状态、动作和回报，这些轨迹中的 (S, A) 对本身就是从所需联合分布中采样的样本。
3.  **指导更新方向**：它从理论上证明了使用“对数似然梯度”作为策略网络更新方向的核心组成部分是正确的。

基于这个定理，我们可以用样本均值来估计梯度：

**梯度估计 ĝ ≈ (1/N) Σ [ Qπθ(s_i, a_i) ∇θ log πθ(a_i|s_i) ]**

这个估计量正是我们上次课讨论的REINFORCE算法的基础。在REINFORCE中，我们用从该状态开始的**蒙特卡洛回报 G_t** 来估计 Qπθ(s_i, a_i)。

![](img/a9e212a2748fa5d189fba6ee6659c03a_78.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_80.png)

## 策略梯度方法的演进

策略梯度定理催生了一系列算法：

![](img/a9e212a2748fa5d189fba6ee6659c03a_82.png)

![](img/a9e212a2748fa5d189fba6ee6659c03a_84.png)

*   **朴素策略梯度**：直接使用上述估计，如REINFORCE算法。但估计的方差可能很高，导致训练不稳定。
*   **带基线的策略梯度**：引入一个基线函数（通常是状态价值函数 V(s)），将更新项改为 (Q(s,a) - V(s)) ∇θ log πθ(a|s)。这能显著降低方差而不改变期望，从而稳定训练。
*   **信赖域策略优化**：通过约束策略更新的步长，防止新策略与旧策略差异过大，解决了朴素方法中因“隐式重要性采样”带来的稳定性问题，使得训练更加鲁棒可靠。

## 总结

![](img/a9e212a2748fa5d189fba6ee6659c03a_86.png)

本节课我们一起学习了策略梯度定理。我们从最大化期望回报的目标出发，通过数学推导，展示了如何将复杂的目标函数梯度，最终简化为一个易于采样估计的期望形式：**𝔼 [ Q(s,a) ∇θ log πθ(a|s) ]**。这个定理不仅为REINFORCE等算法提供了理论依据，也指明了所有策略梯度方法的核心：通过策略的对数梯度方向进行更新，并使用来自环境交互的样本进行估计。理解这个定理是掌握后续更高级策略优化算法（如Actor-Critic、TRPO、PPO）的关键。
