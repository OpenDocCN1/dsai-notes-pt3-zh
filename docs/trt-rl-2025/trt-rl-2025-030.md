## 贪婪改进的问题

上一节我们介绍了基于贪婪策略改进的控制循环。这种方法存在一个主要问题：一旦我们根据当前估计找到了一个看似最优的动作，就会永远执行它（即“利用”），而不再尝试其他可能更好的动作（即“探索”）。

**公式：** 纯贪婪策略
```
π(s) = argmax_a Q(s, a)
```

这意味着，如果初始估计不准确，算法可能会陷入一个次优策略，永远无法发现真正的最优解。

## ε-贪婪策略

![](img/6923642636c41b4d81c3da4866ddbc3c_8.png)

为了解决上述问题，一个更好的想法是采用 **ε-贪婪** 策略。其核心思想很简单：在大部分时间遵循当前最优估计的同时，以一个小概率随机尝试其他动作。

![](img/6923642636c41b4d81c3da4866ddbc3c_10.png)

以下是ε-贪婪策略的具体定义：

![](img/6923642636c41b4d81c3da4866ddbc3c_12.png)

![](img/6923642636c41b4d81c3da4866ddbc3c_14.png)

![](img/6923642636c41b4d81c3da4866ddbc3c_15.png)

![](img/6923642636c41b4d81c3da4866ddbc3c_17.png)

**公式：** ε-贪婪策略
```
以概率 (1 - ε) 选择： argmax_a Q(s, a)
以概率 ε 选择： 所有动作中的任意一个（均匀随机）
```

更精确地说，假设有 M 个可选动作，策略可以写为：
- 对于最优动作 a*：概率为 `1 - ε + ε/M`
- 对于其他任何动作 a：概率为 `ε/M`

这样，即使当前估计指向某个方向，我们仍有ε的概率去探索其他路径，从而有机会发现更优的奖励。

## ε-贪婪改进定理

我们可能会问：使用ε-贪婪策略是否能保证最终收敛到最优策略？答案是肯定的，但前提是我们能无限次地与环境交互。

**定理核心：** 如果我们从一个策略 π 出发，对其进行ε-贪婪改进得到新策略 π‘，那么对于任意状态 s，新策略的价值都不低于旧策略，即 `V^π'(s) >= V^π(s)`。

![](img/6923642636c41b4d81c3da4866ddbc3c_21.png)

![](img/6923642636c41b4d81c3da4866ddbc3c_23.png)

![](img/6923642636c41b4d81c3da4866ddbc3c_24.png)

**证明思路：**
1.  新策略的价值 `V^π'(s)` 可以表示为其动作值函数 `Q^π(s, a)` 按新策略 π‘ 的加权平均。
2.  将 π‘ 的表达式（ε-贪婪）代入。
3.  利用 `Q^π(s, a*)`（最优动作的值）大于等于任何 `Q^π(s, a)` 的加权平均这一事实。
4.  经过代数推导，可以证明 `V^π'(s) >= V^π(s)`。

由于每次ε-贪婪改进都能提升策略，在无限探索的假设下，策略序列将最终收敛到最优策略。

> **重要说明：** 该定理假设我们拥有真实的动作值函数 `Q^π`。在实践中，我们使用的是估计值 `Q^π_hat`，这引入了误差。然而，如果有无限的时间进行学习，估计最终会变得准确，从而理论上仍能保证收敛。

## 控制循环中的ε-贪婪

现在，我们将ε-贪婪整合到蒙特卡洛控制循环中。

![](img/6923642636c41b4d81c3da4866ddbc3c_26.png)

以下是更新后的算法步骤：

1.  **初始化：** 随机策略 π 和动作值函数 Q。
2.  **循环（每个回合）：**
    a. 根据当前策略 π（例如ε-贪婪策略）生成一个回合（轨迹）。
    b. 使用该回合的数据，通过蒙特卡洛方法更新动作值估计 Q。
    c. **策略改进：** 基于更新后的 Q，使用ε-贪婪方法生成新策略 π。
3.  重复步骤2，直到策略收敛。

![](img/6923642636c41b4d81c3da4866ddbc3c_28.png)

与纯贪婪改进的主要区别在于第2步(a)和(c)：我们始终使用ε-贪婪策略来与环境交互并生成新策略，这鼓励了探索。

![](img/6923642636c41b4d81c3da4866ddbc3c_30.png)

## 从ε-贪婪到GLIE算法

虽然固定的ε-贪婪策略在理论上能保证收敛，但在实践中，即使已经学到了最优策略，我们仍会以概率ε执行随机动作，这并非最优表现。

![](img/6923642636c41b4d81c3da4866ddbc3c_34.png)

一个更实用的方法是让ε随着时间衰减。这类算法被称为 **“贪心无限探索”** 算法。

![](img/6923642636c41b4d81c3da4866ddbc3c_35.png)

![](img/6923642636c41b4d81c3da4866ddbc3c_37.png)

![](img/6923642636c41b4d81c3da4866ddbc3c_39.png)

**GLIE算法的两个关键属性：**
1.  **无限探索：** 所有状态-动作对在极限情况下被访问无限多次。
2.  **贪心极限：** 策略在极限情况下收敛到一个纯贪婪策略（即ε -> 0）。

**一个简单的GLIE实现：** 在第 k 次迭代中，设置 `ε_k = 1/k`。
- 开始时（k=1），ε=1，完全随机探索。
- 随着k增大，ε逐渐减小，利用的成分越来越多。
- 当 k -> ∞ 时，ε -> 0，策略趋于纯贪婪，但探索已充分进行。

将这种衰减的ε应用于蒙特卡洛控制循环，我们就得到了一个GLIE版本的蒙特卡洛控制算法，它在实践中能更稳健地收敛到最优策略。

![](img/6923642636c41b4d81c3da4866ddbc3c_41.png)

## 实例：悬崖漫步

考虑“悬崖漫步”网格世界示例：
- **目标：** 从起点安全走到终点。
- **风险：** 掉下“悬崖”会获得巨大负奖励并回到起点。
- **最优路径：** 紧贴悬崖上方的狭窄路径。
- **安全路径：** 上方绕远的路径。

如果使用纯贪婪策略：
- 智能体可能早期偶然走上安全路径并获得不错估计。
- 此后它将永远选择这条安全路径，而**永远无法发现**更短但风险更高的最优路径。

![](img/6923642636c41b4d81c3da4866ddbc3c_43.png)

如果使用ε-贪婪或GLIE策略：
- 智能体有机会尝试靠近悬崖的格子。
- 一旦它成功走通最优路径一次，就会获得非常高的回报估计。
- 后续策略会倾向于选择这条更优的路径。

这直观地展示了探索对于发现全局最优解的必要性。

## 总结

![](img/6923642636c41b4d81c3da4866ddbc3c_45.png)

本节课我们一起学习了如何为强化学习控制循环引入探索机制：

![](img/6923642636c41b4d81c3da4866ddbc3c_47.png)

1.  我们首先指出了纯贪婪策略改进可能陷入局部最优的问题。
2.  接着，我们引入了 **ε-贪婪策略**，它以概率ε进行随机探索，以概率(1-ε)利用当前最优估计。
3.  我们探讨了 **ε-贪婪改进定理**，它从理论上证明了该策略能逐步改进并最终收敛到最优策略。
4.  然后，我们看到了如何将ε-贪婪整合到蒙特卡洛控制循环中。
5.  最后，我们介绍了更先进的 **GLIE算法**，它通过让探索概率ε随时间衰减，既保证了充分探索，又在极限下收敛到纯贪婪的最优策略。

![](img/6923642636c41b4d81c3da4866ddbc3c_49.png)

通过引入这些探索机制，智能体能够更好地了解环境，克服初始估计偏差，并最终找到真正的最优策略。
