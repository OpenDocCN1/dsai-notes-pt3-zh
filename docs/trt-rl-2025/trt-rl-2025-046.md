上一节我们定义了策略网络的目标函数，即期望回报。本节中，我们来看看如何最大化这个目标函数。由于目标函数依赖于神经网络的输出，我们必须使用基于梯度的方法。核心挑战在于如何从只能通过采样交互的环境中，估计出这个梯度。

![](img/fd5d430410c19722700fda9b0a7bc776_9.png)

## 梯度上升与核心挑战

我们的目标是最大化目标函数 **J(θ)**，这等价于最小化 **-J(θ)**。为此，我们采用梯度上升法。参数更新公式为：

![](img/fd5d430410c19722700fda9b0a7bc776_11.png)

`θ ← θ + α ∇θ J(θ)`

![](img/fd5d430410c19722700fda9b0a7bc776_13.png)

其中 **α** 是学习率。

![](img/fd5d430410c19722700fda9b0a7bc776_15.png)

唯一的挑战是，我们需要找到一种方法来实际估计这个梯度 **∇θ J(θ)**。这个梯度依赖于策略网络和只能通过采样来交互的环境。

## 推导策略梯度

我们的目标函数 **J(θ)** 是在轨迹分布 **P(τ; θ)** 下的期望回报 **G(τ)**：

`J(θ) = Eτ~P(τ;θ) [G(τ)]`

为了进行梯度上升，我们需要计算其梯度：

![](img/fd5d430410c19722700fda9b0a7bc776_17.png)

`∇θ J(θ) = ∇θ Eτ~P(τ;θ) [G(τ)]`

![](img/fd5d430410c19722700fda9b0a7bc776_19.png)

由于回报 **G(τ)** 本身不直接依赖于参数 **θ**，梯度会作用在轨迹的概率分布 **P(τ; θ)** 上。直接计算这个梯度很复杂，但我们可以使用一个数学技巧来简化。

![](img/fd5d430410c19722700fda9b0a7bc776_21.png)

## 对数导数技巧

这里我们使用一个关键的数学工具：**对数导数技巧**。对于一个函数 **f(x)**，其导数可以表示为：

![](img/fd5d430410c19722700fda9b0a7bc776_23.png)

`∇x f(x) = f(x) ∇x log f(x)`

这个技巧在多元情况下同样适用，只需将导数替换为梯度。应用这个技巧，我们可以将目标函数的梯度重写为：

![](img/fd5d430410c19722700fda9b0a7bc776_25.png)

`∇θ J(θ) = Eτ~P(τ;θ) [ G(τ) ∇θ log P(τ; θ) ]`

![](img/fd5d430410c19722700fda9b0a7bc776_27.png)

这个形式非常有用，因为它将梯度表示为一个期望。我们可以通过从分布 **P(τ; θ)** 中采样轨迹，然后用蒙特卡洛方法来估计这个期望。

![](img/fd5d430410c19722700fda9b0a7bc776_29.png)

![](img/fd5d430410c19722700fda9b0a7bc776_30.png)

![](img/fd5d430410c19722700fda9b0a7bc776_32.png)

## 分解轨迹概率

现在，我们需要计算 **∇θ log P(τ; θ)**。轨迹的概率可以分解为初始状态分布、一系列策略决策和环境转移概率的乘积：

![](img/fd5d430410c19722700fda9b0a7bc776_34.png)

![](img/fd5d430410c19722700fda9b0a7bc776_36.png)

![](img/fd5d430410c19722700fda9b0a7bc776_37.png)

`P(τ; θ) = P(s0) ∏ πθ(at|st) P(st+1|st, at)`

对其取对数后，乘积变为求和：

`log P(τ; θ) = log P(s0) + ∑ log πθ(at|st) + ∑ log P(st+1|st, at)`

当我们对参数 **θ** 求梯度时，只有策略项 **πθ(at|st)** 的贡献不为零，因为初始状态分布和环境转移概率与 **θ** 无关。因此：

`∇θ log P(τ; θ) = ∑ ∇θ log πθ(at|st)`

这个求和遍历轨迹中的每一个时间步 **(st, at)**。

## 策略梯度估计

将上述结果代入梯度公式，我们得到：

![](img/fd5d430410c19722700fda9b0a7bc776_39.png)

`∇θ J(θ) = Eτ~P(τ;θ) [ G(τ) ∑ ∇θ log πθ(at|st) ]`

![](img/fd5d430410c19722700fda9b0a7bc776_41.png)

![](img/fd5d430410c19722700fda9b0a7bc776_43.png)

![](img/fd5d430410c19722700fda9b0a7bc776_44.png)

![](img/fd5d430410c19722700fda9b0a7bc776_45.png)

这个公式就是**策略梯度定理**的核心。它告诉我们，梯度的估计可以通过以下步骤获得：
1.  用当前策略 **πθ** 采样一条轨迹 **τ**。
2.  计算该轨迹的总回报 **G(τ)**。
3.  对于轨迹中的每一步 **(st, at)**，计算策略网络输出对数概率的梯度 **∇θ log πθ(at|st)**，并将它们求和。
4.  将总回报与梯度之和相乘，作为本次梯度估计。

![](img/fd5d430410c19722700fda9b0a7bc776_47.png)

以下是计算单条轨迹梯度估计的步骤：
1.  **采样轨迹**：从环境中运行策略，收集状态、动作、奖励序列。
2.  **计算回报**：`G = ∑ γ^t * rt` （考虑折扣因子 **γ**）。
3.  **计算策略梯度**：
    ```python
    # 伪代码示意
    policy_gradient = 0
    for t in range(T):
        # 将状态 st 输入策略网络，得到动作概率分布
        action_probs = policy_network(st)
        # 计算所选动作 at 的对数概率
        log_prob = log(action_probs[at])
        # 计算该对数概率关于网络参数的梯度，并累加
        policy_gradient += gradient(log_prob, θ)
    ```
4.  **组合**：最终的梯度估计为 `grad_estimate = G * policy_gradient`。

## 随机梯度上升与REINFORCE算法

![](img/fd5d430410c19722700fda9b0a7bc776_49.png)

理论上，我们可以采样多条轨迹，用蒙特卡洛平均来获得更准确的梯度估计。然而，在实践中，由于采样效率的考虑，我们通常使用**随机梯度上升**，即每次只用一条轨迹的估计来更新参数：

![](img/fd5d430410c19722700fda9b0a7bc776_51.png)

![](img/fd5d430410c19722700fda9b0a7bc776_53.png)

![](img/fd5d430410c19722700fda9b0a7bc776_55.png)

`θ ← θ + α * G(τ) * ∑ ∇θ log πθ(at|st)`

![](img/fd5d430410c19722700fda9b0a7bc776_57.png)

这种每次使用单样本更新的方法，就是经典的 **REINFORCE 算法**（Williams, 1992）。其更新规则与我们推导的形式略有不同，但本质相同，都遵循策略梯度定理。

## 总结

![](img/fd5d430410c19722700fda9b0a7bc776_59.png)

本节课中我们一起学习了策略梯度方法的基础。我们从最大化期望回报的目标出发，利用对数导数技巧推导出了策略梯度定理的关键公式。这个公式允许我们通过采样轨迹来估计梯度，进而使用随机梯度上升法直接优化策略网络参数。我们介绍的最简单的实现形式就是REINFORCE算法，它虽然简单，但奠定了直接策略优化方法的基础。下一节，我们将探讨如何改进这个基础算法，以提高其稳定性和样本效率。
