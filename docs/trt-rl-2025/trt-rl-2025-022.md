## 概述
在本节课中，我们将要学习如何在不了解环境模型（即马尔可夫决策过程MDP）的情况下，评估一个策略的价值。我们将重点介绍蒙特卡洛方法，这是一种通过从环境中采样并平均样本回报来估计价值函数的核心技术。

## 从基于模型到无模型方法

![](img/31f6e8d63148bb0bd661d1ad746338b5_4.png)

![](img/31f6e8d63148bb0bd661d1ad746338b5_6.png)

上一章我们介绍了基于模型的方法，即当我们知道环境的完整MDP模型时，我们可以精确地计算最优策略。然而，在实践中，我们通常无法获得环境的精确模型。

![](img/31f6e8d63148bb0bd661d1ad746338b5_8.png)

本节中我们来看看无模型方法。在无模型设定下，我们假设不知道环境的转移概率和奖励函数。我们的目标仍然是找到最优策略，但必须仅依靠从环境中获得的样本来近似计算价值函数和动作价值函数。

本课程的第一部分将主要讨论两种无模型估计方法：**时序差分学习**和**蒙特卡洛方法**。掌握这些方法后，我们将进一步学习在策略方法（如Sarsa）和离策略方法（如Q学习）。

## 广义策略迭代框架

![](img/31f6e8d63148bb0bd661d1ad746338b5_14.png)

无模型方法依然遵循**广义策略迭代**的总体框架。我们从一个策略开始，评估该策略（即使评估是近似的），然后基于评估结果改进策略，并不断迭代。

![](img/31f6e8d63148bb0bd661d1ad746338b5_16.png)

![](img/31f6e8d63148bb0bd661d1ad746338b5_17.png)

唯一的区别在于策略评估步骤。由于没有MDP模型，我们无法使用贝尔曼方程精确计算期望值。我们需要用从样本中获得的估计值来替代这些期望。

## 蒙特卡洛方法核心思想

![](img/31f6e8d63148bb0bd661d1ad746338b5_19.png)

蒙特卡洛方法的核心思想非常简单：用样本均值来估计期望值。

![](img/31f6e8d63148bb0bd661d1ad746338b5_21.png)

设想一个简单实验：你有一个设备，向其输入随机信号，并测量输出。你不知道输入信号的分布，也不知道设备的精确函数。为了估计设备的平均输出，你可以多次运行实验，记录每次的输出值，然后计算这些输出值的平均值。

用公式表示，假设真实期望值为：
**μ = E[y]**
我们可以通过采集K个独立样本 {y₁, y₂, ..., yₖ} 来估计它：
**μ̂ = (1/K) * Σᵢ yᵢ**

![](img/31f6e8d63148bb0bd661d1ad746338b5_23.png)

根据大数定律，随着样本数量K的增加，估计值μ̂会收敛到真实值μ，其方差会以 **σ²/K** 的速度减小。我们可以将估计值视为真实值加上一个误差项，该误差随样本增多而减小。

![](img/31f6e8d63148bb0bd661d1ad746338b5_25.png)

## 蒙特卡洛策略评估

我们可以将上述思想应用于策略评估。一个策略π在状态s下的价值Vπ(s)定义为**未来回报的期望值**。

![](img/31f6e8d63148bb0bd661d1ad746338b5_27.png)

如果我们不知道MDP，无法直接计算这个期望。蒙特卡洛方法的解决方案是：从状态s开始，遵循策略π运行多个完整的回合（直到终止状态），计算每个回合的实际回报，然后对这些回报取平均值。

![](img/31f6e8d63148bb0bd661d1ad746338b5_29.png)

![](img/31f6e8d63148bb0bd661d1ad746338b5_30.png)

以下是评估单个状态价值的算法步骤：

1.  初始化价值估计 V(s) = 0。
2.  对于 k = 1 到 K 个回合：
    *   从状态s开始，遵循策略π运行，直到回合结束。
    *   计算该回合获得的回报 Gₖ。
    *   更新价值估计：V(s) ← V(s) + Gₖ。
3.  最终估计：V(s) ← V(s) / K。

![](img/31f6e8d63148bb0bd661d1ad746338b5_32.png)

这个算法必须等待所有K个回合完成后才能得到最终估计。

![](img/31f6e8d63148bb0bd661d1ad746338b5_34.png)

## 在线增量式更新

在实际算法中，我们更常使用**在线增量式更新**，这样无需等待所有回合结束，每完成一个回合就能更新估计。

推导如下：设 Vₖ 为前k个回合后的估计值。
**Vₖ = (1/k) * Σᵢ₌₁ᵏ Gᵢ**
可以重写为：
**Vₖ = Vₖ₋₁ + (1/k) * (Gₖ - Vₖ₋₁)**

![](img/31f6e8d63148bb0bd661d1ad746338b5_38.png)

![](img/31f6e8d63148bb0bd661d1ad746338b5_40.png)

这个更新规则非常直观：新的估计等于旧的估计加上一个步长乘以“新观测回报”与“旧估计”的差值。

我们通常将固定的步长 **1/k** 替换为一个常数 **α**（其中 0 < α ≤ 1）。使用常数α意味着我们更重视最近的样本，可以进行非均匀加权平均，并且更新规则变为：
**V(s) ← V(s) + α * (G - V(s))**

![](img/31f6e8d63148bb0bd661d1ad746338b5_42.png)

## 利用整个回合：每次访问蒙特卡洛

更高效的做法是，一个完整的回合轨迹可以为其中访问到的**每一个状态**都提供一个价值样本。

考虑一个回合序列：S₀, A₀, R₁, S₁, A₁, R₂, ..., Sₜ（终止状态）。
*   从S₀开始的回报G₀可用于更新V(S₀)。
*   从S₁开始的回报G₁可用于更新V(S₁)。
*   ... 以此类推。

因此，我们可以从轨迹的**末尾反向计算**回报，并更新沿途每个状态的价值。算法步骤如下：

![](img/31f6e8d63148bb0bd661d1ad746338b5_44.png)

![](img/31f6e8d63148bb0bd661d1ad746338b5_46.png)

1.  初始化所有状态的价值V(s)。
2.  对一个回合序列 S₀, A₀, R₁, S₁, ..., Sₜ：
    *   令回报 G = 0。
    *   从最后一个时间步 t = T-1 反向遍历到 t = 0：
        *   G ← Rₜ₊₁ + γ * G （γ是折扣因子）
        *   更新状态 Sₜ 的价值：V(Sₜ) ← V(Sₜ) + α * (G - V(Sₜ))

这种方法极大地提高了数据利用率，一个回合可以更新多个状态。

## 收敛性与挑战

理论上，如果每个状态都被访问了无限多次，蒙特卡洛估计值将收敛到真实的策略价值Vπ(s)。这是大数定律的直接结果。

然而，关键挑战在于**状态空间巨大**。为了确保每个状态都被“充分”访问，所需的样本数量至少要与状态数量成正比。对于像国际象棋（约10¹²⁰个状态）这样的复杂环境，这是完全不可行的计算量。

因此，虽然蒙特卡洛方法提供了无模型评估的基本原理，但其原始形式无法扩展到大规模问题。这促使我们寻找更高效的方法，如时序差分学习，并最终与函数近似（深度学习）结合，形成深度强化学习。

## 总结
本节课中我们一起学习了无模型策略评估的基础——蒙特卡洛方法。我们了解到：
1.  蒙特卡洛方法通过采样回报并计算平均值来估计期望值。
2.  它可以用于在未知环境模型的情况下评估策略的价值函数。
3.  我们介绍了在线增量式更新规则：**V(s) ← V(s) + α * (G - V(s))**。
4.  通过利用整个回合轨迹更新所有访问过的状态，可以提高样本效率。
5.  尽管蒙特卡洛方法概念简单且能保证收敛，但其需要大量样本以覆盖巨大状态空间的特性，使其在实际复杂问题中直接应用受限，这为后续学习更高效的算法奠定了基础。
