## 动态规划简介

上一节我们介绍了贝尔曼方程，它描述了价值函数之间的递归关系。本节中我们来看看如何利用这种递归关系，通过动态规划算法来实际计算价值函数。

![](img/799e1a9396a7c17f1f9e347e7344553b_9.png)

动态规划是一种解决递归问题的通用算法思想。其核心在于，对于一个形如 `x = f(x)` 的方程，我们可以从一个初始猜测 `x0` 开始，反复应用函数 `f` 来逼近方程的解。具体步骤如下：

1.  从一个初始猜测 `x0` 开始。
2.  计算 `x1 = f(x0)`。
3.  计算 `x2 = f(x1)`。
4.  重复此过程，直到 `x` 的变化非常小，即 `x_{k+1}` 非常接近 `x_k`。

![](img/799e1a9396a7c17f1f9e347e7344553b_11.png)

![](img/799e1a9396a7c17f1f9e347e7344553b_12.png)

这个过程可以表示为迭代公式：`x_{k+1} = f(x_k)`。

![](img/799e1a9396a7c17f1f9e347e7344553b_14.png)

![](img/799e1a9396a7c17f1f9e347e7344553b_15.png)

![](img/799e1a9396a7c17f1f9e347e7344553b_17.png)

> **注意**：并非所有函数 `f` 都能保证这种迭代收敛到方程的解。函数的性质（如是否为压缩映射）决定了算法的收敛性。

## 从方程到价值函数

贝尔曼方程具有与 `x = f(x)` 完全相同的形式，只不过这里的“变量” `x` 是整个价值函数向量 **V**。

对于一个给定的策略 π，其状态价值函数 **V^π** 满足贝尔曼期望方程：
**V^π(s) = E_π [ R_{t+1} + γ * V^π(S_{t+1}) | S_t = s ]**

对于所有状态 `s`，我们可以将其写成一个向量方程：
**V = B^π(V)**
其中 `B^π` 是贝尔曼期望算子，它根据输入的价值向量计算出一个新的价值向量。

![](img/799e1a9396a7c17f1f9e347e7344553b_19.png)

因此，策略评估问题（即计算给定策略 π 的价值函数 **V^π**）就转化为了求解方程 **V = B^π(V)**。我们可以直接应用动态规划的思想：

![](img/799e1a9396a7c17f1f9e347e7344553b_21.png)

1.  初始化价值向量 **V_0**（例如，除终止状态设为0外，其余状态可设为随机值）。
2.  迭代更新：**V_{k+1} = B^π(V_k)**
3.  重复步骤2，直到 **V_{k+1}** 与 **V_k** 的差异小于一个预设的阈值 ε。

![](img/799e1a9396a7c17f1f9e347e7344553b_23.png)

![](img/799e1a9396a7c17f1f9e347e7344553b_25.png)

## 策略评估算法

![](img/799e1a9396a7c17f1f9e347e7344553b_27.png)

以下是策略评估算法的伪代码实现：

![](img/799e1a9396a7c17f1f9e347e7344553b_29.png)

```
输入：待评估的策略 π， 折扣因子 γ， 阈值 ε > 0
初始化：对于所有状态 s， V(s) 可任意初始化，但终止状态必须设为 0。
循环：
    Δ ← 0
    对于每个状态 s：
        v ← V(s) # 保存旧值
        # 根据贝尔曼方程计算新值
        V(s) ← Σ_a π(a|s) Σ_{s‘, r} p(s‘, r | s, a) [ r + γ * V(s‘) ]
        Δ ← max(Δ, |v - V(s)|) # 记录本轮最大变化量
直到 Δ < ε
输出： V ≈ V^π
```

![](img/799e1a9396a7c17f1f9e347e7344553b_31.png)

算法说明：
*   **初始化**：价值函数的初始猜测可以任意，但将终止状态的价值初始化为0是一个好习惯，这符合其定义，并有助于收敛。
*   **循环**：在每次迭代中，我们遍历所有状态，并用贝尔曼方程的右侧（基于旧的价值函数 `V_k`）来更新该状态的价值，得到 `V_{k+1}`。
*   **收敛判断**：我们记录本轮迭代中所有状态价值变化的最大值 `Δ`。当 `Δ` 小于一个很小的数 `ε` 时，我们认为价值函数已经收敛，算法停止。

![](img/799e1a9396a7c17f1f9e347e7344553b_33.png)

## 网格世界示例

让我们在一个简单的网格世界环境中直观理解策略评估的过程。

假设我们有一个 2x2 网格：
*   状态0（左上角）是终止状态，到达后奖励为0，并永远停留。
*   状态1、2、3（其他三个格子）每走一步奖励为 -1。
*   给定策略 π：在状态1向右走，状态2向上走，状态3向左走。
*   折扣因子 γ = 1。

![](img/799e1a9396a7c17f1f9e347e7344553b_35.png)

我们的目标是评估这个策略的价值函数 `V^π`。

![](img/799e1a9396a7c17f1f9e347e7344553b_37.png)

**第一步：初始化**
我们初始化价值函数。根据规则，终止状态 `V(0) = 0`。其他状态可以任意初始化，例如 `V(1)=0, V(2)=0, V(3)=0`。

**第二步：迭代更新**
我们根据贝尔曼方程和给定的策略进行更新：
*   对于状态0（终止状态）：`V(0) = 0 + 1 * V(0) = 0`
*   对于状态1：根据策略，会向右进入状态0。`V(1) = (-1) + 1 * V(0) = -1 + 0 = -1`
*   对于状态2：根据策略，会向上进入状态1。`V(2) = (-1) + 1 * V(1) = -1 + (-1) = -2`
*   对于状态3：根据策略，会向左进入状态2。`V(3) = (-1) + 1 * V(2) = -1 + (-2) = -3`

完成第一次迭代后，价值向量变为 `[0, -1, -2, -3]`。

**第三步：继续迭代**
我们用新的价值向量开始第二次迭代：
*   状态0: `V(0) = 0`
*   状态1: `V(1) = -1 + 0 = -1`
*   状态2: `V(2) = -1 + (-1) = -2`
*   状态3: `V(3) = -1 + (-2) = -3`

![](img/799e1a9396a7c17f1f9e347e7344553b_39.png)

我们发现，从第二次迭代开始，价值函数不再发生变化。这意味着算法已经收敛。

**最终结果**：策略 π 的价值函数为 `V^π = [0, -1, -2, -3]`。这个结果符合直觉：离终止状态越远，在策略 π 指导下到达终止状态所需的步数越多，累积的负奖励（惩罚）越大，价值就越低。

## 总结

![](img/799e1a9396a7c17f1f9e347e7344553b_41.png)

本节课中我们一起学习了如何通过动态规划进行策略评估。核心要点如下：
1.  **动态规划思想**：利用贝尔曼方程的递归结构，通过迭代 `V_{k+1} = B^π(V_k)` 来逼近真实价值函数 `V^π`。
2.  **策略评估算法**：该算法从一个初始价值猜测开始，反复用贝尔曼期望方程的右侧更新所有状态的价值，直到价值函数收敛。
3.  **关键细节**：终止状态的价值应初始化为0；使用一个阈值 ε 来判断收敛；折扣因子 γ < 1 通常能保证收敛性。
4.  **直观理解**：通过网格世界的例子，我们看到了算法如何一步步计算出给定策略下每个状态的价值。

![](img/799e1a9396a7c17f1f9e347e7344553b_43.png)

策略评估是许多强化学习算法的基础组件。下一节我们将探讨如何利用评估好的价值函数来改进策略，即“策略改进”，从而引出更强大的“策略迭代”算法。
