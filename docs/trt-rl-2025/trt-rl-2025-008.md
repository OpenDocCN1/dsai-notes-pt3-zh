在本节课中，我们将学习强化学习中的两个核心概念：**策略**和**价值函数**。我们将了解如何用数学语言描述智能体的行为策略，以及如何评估在特定策略下，从某个状态出发能获得的长期回报期望。

## 策略函数 🎯

![](img/750d116435b33efb3b1ad44b14716df9_7.png)

![](img/750d116435b33efb3b1ad44b14716df9_8.png)

![](img/750d116435b33efb3b1ad44b14716df9_10.png)

上一节我们介绍了强化学习的基本框架。本节中，我们来看看如何为智能体构建一个策略，并定义何为“最佳”策略。

策略本质上是智能体与环境互动时所遵循的行为准则。我们可以用数学方式定义它。

![](img/750d116435b33efb3b1ad44b14716df9_12.png)

环境具有状态。智能体在观察到某个状态后，会采取一个动作。因此，策略可以表示为一个**条件概率分布**。这个分布以当前状态为条件，决定采取每个可能动作的概率。

![](img/750d116435b33efb3b1ad44b14716df9_14.png)

用公式表示如下：
```
π(a | s) = P(A_t = a | S_t = s)
```
其中：
*   `s` 表示当前状态。
*   `a` 表示一个具体的动作，它来自一个有限的动作集合（例如，{左， 右}）。
*   `π(a | s)` 表示在状态 `s` 下采取动作 `a` 的概率。

![](img/750d116435b33efb3b1ad44b14716df9_16.png)

这个定义意味着，当环境处于状态 `s` 时，策略会告诉我们采取“右”动作的概率是多少，采取“左”动作的概率是多少。

![](img/750d116435b33efb3b1ad44b14716df9_18.png)

你可能会问，为什么策略要定义为一个概率分布？难道智能体不是总采取确定性的行动吗？实际上，策略可以是随机的。例如，在一个游戏局面下，你可能认为有几个动作都不错，并以一定的概率随机选择其中之一。当然，确定性策略是随机策略的一个特例。在确定性策略中，对于给定的状态 `s`，某个动作 `a` 的概率为 1，而其他动作的概率为 0。

以下是策略的一个具体例子：

![](img/750d116435b33efb3b1ad44b14716df9_20.png)

假设我们在玩井字棋，对手刚刚在格子0落子。此时的状态 `s` 就是“对手占据格子0”。我的策略 `π(a | s)` 需要描述我接下来在哪个格子落子的概率。显然，格子0的概率为0，其他8个格子则可能具有非零的概率。例如，我可能认为格子1、3、4是好选择，并以均等的概率随机选择其中之一。那么策略可以描述为：
```
π(动作=1 | 状态=0) = 1/3
π(动作=3 | 状态=0) = 1/3
π(动作=4 | 状态=0) = 1/3
π(其他动作 | 状态=0) = 0
```
如果我采取确定性策略，比如“只要对手下0，我就下1”，那么策略就是：
```
π(动作=1 | 状态=0) = 1
π(其他动作 | 状态=0) = 0
```

![](img/750d116435b33efb3b1ad44b14716df9_22.png)

![](img/750d116435b33efb3b1ad44b14716df9_24.png)

需要理解的关键点是：**策略不是一个单一的概率分布，而是一族分布**。对于每一个可能的状态 `s`，策略 `π` 都给出一个不同的动作概率分布。当状态从 `s` 改变为 `s'` 时，策略 `π(a | s')` 给出的分布也会随之改变。这是合理的，因为智能体应该根据不同的局面做出不同的反应。

![](img/750d116435b33efb3b1ad44b14716df9_26.png)

## 价值函数 💰

![](img/750d116435b33efb3b1ad44b14716df9_30.png)

当我们有了一个策略 `π`，理论上就可以描述智能体与环境的未来交互过程。策略告诉我们当前状态下该如何行动，行动会改变环境状态，新的状态又通过策略决定下一个行动，如此循环。

基于此，我们可以评估从某个状态开始，遵循策略 `π` 所能获得的长期回报。这就是**价值函数**。

回忆一下，回报 `G_t` 是从时间 `t` 开始未来所有奖励的折扣和：
```
G_t = R_{t+1} + γ * R_{t+2} + γ^2 * R_{t+3} + ...
```
其中 `γ` 是折扣因子。

![](img/750d116435b33efb3b1ad44b14716df9_32.png)

**状态价值函数** `v_π(s)` 定义为：从状态 `s` 开始，遵循策略 `π` 所能获得的期望回报。
用公式表示如下：
```
v_π(s) = E_π[ G_t | S_t = s ]
```
其中 `E_π[·]` 表示在策略 `π` 下的期望。

这个值依赖于两个因素：
1.  **状态 `s`**：不同的起始状态，未来的期望回报自然不同。
2.  **策略 `π`**：采取不同的策略（行动准则），会导致不同的状态转移序列和奖励序列，从而影响最终的期望回报。

![](img/750d116435b33efb3b1ad44b14716df9_34.png)

接下来，我们看看这个期望值是如何具体计算出来的。

![](img/750d116435b33efb3b1ad44b14716df9_36.png)

## 价值函数的计算 🧮

![](img/750d116435b33efb3b1ad44b14716df9_38.png)

![](img/750d116435b33efb3b1ad44b14716df9_39.png)

![](img/750d116435b33efb3b1ad44b14716df9_40.png)

![](img/750d116435b33efb3b1ad44b14716df9_42.png)

回报 `G_t` 是一个随机变量，因为：
*   根据策略 `π`，动作是随机的。
*   给定状态和动作后，环境产生的奖励 `R` 可能是随机的（例如赌博机问题）。
*   状态转移（即下一个状态是什么）也可能是随机的。

要计算 `v_π(s) = E_π[ G_t | S_t = s ]`，我们需要计算未来所有折扣奖励的期望之和。我们可以从计算即时奖励的期望开始。

![](img/750d116435b33efb3b1ad44b14716df9_44.png)

![](img/750d116435b33efb3b1ad44b14716df9_45.png)

![](img/750d116435b33efb3b1ad44b14716df9_47.png)

**第一步：计算即时奖励的期望**

在状态 `s` 下，策略 `π` 给出了采取每个动作 `a` 的概率 `π(a|s)`。
如果我们在状态 `s` 下采取了动作 `a`，那么从奖励函数 `R` 我们可以得到获得某个奖励 `r` 的概率 `p(r | s, a)`，以及此时的期望奖励 `E[ R | s, a ]`。

由于动作 `a` 本身由策略 `π` 随机决定，因此**在状态 `s` 下，遵循策略 `π` 所能获得的即时期望奖励**，需要对所有可能的动作进行加权平均：
```
E_π[ R_{t+1} | S_t = s ] = Σ_a π(a|s) * E[ R | s, a ]
                         = Σ_a π(a|s) * Σ_r r * p(r | s, a)
```
这个值显然依赖于策略 `π`。如果改变策略，即时期望奖励就会改变。

![](img/750d116435b33efb3b1ad44b14716df9_49.png)

![](img/750d116435b33efb3b1ad44b14716df9_51.png)

**后续步骤：计算未来奖励的期望**

![](img/750d116435b33efb3b1ad44b14716df9_53.png)

计算完 `R_{t+1}` 的期望后，我们需要计算 `R_{t+2}`, `R_{t+3}` 等的期望。这会更复杂，但原理类似，形成了一个树状结构：
1.  从状态 `s` 和策略 `π` 出发，得到动作分布。
2.  每个动作 `a` 与当前状态 `s` 结合，通过状态转移函数 `P` 产生下一个状态 `s'` 的分布。
3.  在新的状态 `s'` 下，再次使用策略 `π` 决定动作。
4.  重复步骤2-3，并结合奖励函数计算每一步的奖励。

理论上，只要我们知道策略 `π`、奖励函数 `R` 和状态转移函数 `P`，就可以通过这种层层递推的方式，计算出从任何状态 `s` 开始，遵循策略 `π` 的期望总回报 `v_π(s)`。这个过程虽然繁琐，但清晰地揭示了价值函数是如何依赖于策略以及整个环境模型的。

## 总结 📝

本节课中我们一起学习了强化学习的核心构件：
*   **策略 `π`**：智能体的行为准则，形式上是一个将状态映射到动作概率分布的函数族。它可以是随机的，也可以是确定性的。
*   **状态价值函数 `v_π(s)`**：衡量在给定策略 `π` 下，从状态 `s` 出发所能获得的长期期望回报。它是评估策略好坏的关键指标。
*   **价值计算原理**：价值函数可以通过对策略、奖励和状态转移模型进行序列化的期望运算来求解，这体现了强化学习中“向前看”和“动态”的特性。

![](img/750d116435b33efb3b1ad44b14716df9_59.png)

理解策略和价值函数是学习后续如何寻找最优策略（即最大化价值函数的策略）的基础。
