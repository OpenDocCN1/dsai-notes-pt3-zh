在本节课中，我们将要学习强化学习中的一个核心概念——贝尔曼方程。我们将从未来回报的递归性质出发，逐步推导出这个方程，并理解它如何帮助我们更高效地计算策略的价值函数。

## 概述

![](img/5fef2fc214c443a43f0b923ac6b8fce7_7.png)

上一节我们介绍了价值函数的基本概念，它衡量了在特定策略下，从某个状态出发能获得的期望总回报。然而，直接计算这个期望值可能非常复杂。本节中，我们来看看如何利用回报的递归性质，推导出一个更易于处理的方程——贝尔曼方程。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_9.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_10.png)

## 未来回报的递归性质

我们首先观察未来回报 `G_t` 所具有的递归结构。假设我们在时间 `t` 处于某个状态，执行一个动作后，会立即获得奖励 `R_{t+1}`，然后状态转移，继续这个过程。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_12.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_13.png)

我们可以将未来回报 `G_t` 展开为：
`G_t = R_{t+1} + γ * R_{t+2} + γ^2 * R_{t+3} + ...`

现在，我们可以对这个和进行因式分解。保留第一项，并将折扣因子 `γ` 从后续项中提取出来：
`G_t = R_{t+1} + γ * (R_{t+2} + γ * R_{t+3} + ...)`

请注意，括号内的表达式 `(R_{t+2} + γ * R_{t+3} + ...)` 正是从时间 `t+1` 开始的未来回报 `G_{t+1}`。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_15.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_17.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_18.png)

因此，我们得到了一个关键的递归关系：
`G_t = R_{t+1} + γ * G_{t+1}`

这意味着当前时刻的未来回报，等于立即获得的奖励加上折扣后的下一时刻的未来回报。

## 推导贝尔曼方程

![](img/5fef2fc214c443a43f0b923ac6b8fce7_20.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_21.png)

上一节我们看到了回报的递归关系，本节中我们利用这个关系来推导价值函数满足的方程。

根据定义，策略 `π` 下状态 `s` 的价值函数 `V^π(s)` 是未来回报 `G_t` 的期望值，给定当前状态 `S_t = s`：
`V^π(s) = E[G_t | S_t = s]`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_23.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_24.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_25.png)

现在，我们将递归关系 `G_t = R_{t+1} + γ * G_{t+1}` 代入上述期望中：
`V^π(s) = E[ R_{t+1} + γ * G_{t+1} | S_t = s ]`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_27.png)

根据期望的线性性质，我们可以将其拆开：
`V^π(s) = E[ R_{t+1} | S_t = s ] + γ * E[ G_{t+1} | S_t = s ]`

第一项 `E[ R_{t+1} | S_t = s ]` 是**立即奖励的期望值**，我们之前计算过，它由策略 `π` 和环境动态共同决定。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_29.png)

第二项 `E[ G_{t+1} | S_t = s ]` 需要仔细分析。它表示**给定当前状态 `s`，下一时刻未来回报的期望值**。这**不是**状态 `s` 的价值函数 `V^π(s)`，因为价值函数定义中的回报是从当前时刻开始的，而这里是从下一时刻 (`t+1`) 开始。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_31.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_32.png)

为了计算 `E[ G_{t+1} | S_t = s ]`，我们引入下一时刻的状态 `S_{t+1}` 作为中间变量，并使用全期望公式：
`E[ G_{t+1} | S_t = s ] = Σ_{s'} P(S_{t+1}=s' | S_t=s) * E[ G_{t+1} | S_t=s, S_{t+1}=s' ]`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_34.png)

由于马尔可夫性质，当给定 `S_{t+1}=s‘` 时，`G_{t+1}` 的期望不再依赖于更早的状态 `S_t=s`。因此：
`E[ G_{t+1} | S_t=s, S_{t+1}=s' ] = E[ G_{t+1} | S_{t+1}=s' ]`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_36.png)

而 `E[ G_{t+1} | S_{t+1}=s' ]` 正是策略 `π` 下状态 `s‘` 的价值函数 `V^π(s‘)`。

所以，第二项可以写为：
`E[ G_{t+1} | S_t = s ] = Σ_{s'} P(S_{t+1}=s' | S_t=s) * V^π(s‘)`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_38.png)

其中，状态转移概率 `P(S_{t+1}=s' | S_t=s)` 由策略 `π` 和环境模型决定：
`P^π(S_{t+1}=s' | S_t=s) = Σ_a π(a|s) * P(s' | s, a)`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_40.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_42.png)

将上述所有部分组合起来，我们就得到了**贝尔曼方程**：
`V^π(s) = E[ R_{t+1} | S_t = s ] + γ * Σ_{s'} P^π(S_{t+1}=s' | S_t=s) * V^π(s‘)`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_44.png)

这个方程表明，一个状态的价值，等于立即奖励的期望，加上所有可能到达的下一状态价值的折扣期望值。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_46.png)

## 贝尔曼方程的意义与应用

![](img/5fef2fc214c443a43f0b923ac6b8fce7_48.png)

上一节我们推导出了贝尔曼方程，本节中我们来看看它的重要意义以及如何利用它。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_50.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_51.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_52.png)

贝尔曼方程的核心在于它建立了一个状态价值与其他状态价值之间的联系。对于一个有 `n` 个状态的问题，如果我们为每个状态 `s` 都写出其贝尔曼方程，就会得到一个包含 `n` 个方程的方程组，未知数正是这 `n` 个状态的价值 `V^π(s_1), V^π(s_2), ..., V^π(s_n)`。

理论上，我们可以通过求解这个线性方程组来得到策略 `π` 下所有状态的价值，而无需进行复杂的轨迹采样和期望计算。这比我们之前通过模拟求平均的方法要高效得多。

以下是利用贝尔曼方程求解价值函数的关键步骤：
1.  为每个状态 `s` 列出其贝尔曼方程。
2.  方程中包含已知量（立即奖励期望、转移概率）和未知量（各状态价值）。
3.  将所有方程联立，形成一个线性方程组。
4.  求解该方程组，得到每个状态的价值 `V^π(s)`。

## 网格世界示例

![](img/5fef2fc214c443a43f0b923ac6b8fce7_54.png)

让我们通过之前使用的简单网格世界示例，具体演示如何使用贝尔曼方程。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_56.png)

假设有一个 2x2 的网格，状态编号为 0（左上，终止状态），1（右上），2（左下），3（右下）。智能体遵循一个确定性策略：在状态1向左走，状态2向上走，状态3向左走。每移动一步获得奖励 -1，到达终止状态后奖励为 0。折扣因子 `γ=1`。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_58.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_60.png)

首先，我们写出各状态的立即奖励期望：
*   `E[R | s=0] = 0` （终止状态）
*   `E[R | s=1] = -1` （向左移动到状态0）
*   `E[R | s=2] = -1` （向上移动到状态0）
*   `E[R | s=3] = -1` （向左移动到状态2）

接下来，我们为每个状态写出贝尔曼方程。由于策略是确定性的，转移概率为 0 或 1。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_62.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_63.png)

*   **状态0（终止状态）**：
    `V(0) = 0 + 1 * [1*V(0) + 0*V(1) + 0*V(2) + 0*V(3)] => V(0) = V(0)`
    这是一个恒等式，未提供新信息，但我们知道终止状态价值 `V(0) = 0`。

*   **状态1**：
    `V(1) = -1 + 1 * [1*V(0) + 0*V(1) + 0*V(2) + 0*V(3)] => V(1) = -1 + V(0)`

*   **状态2**：
    `V(2) = -1 + 1 * [1*V(0) + 0*V(1) + 0*V(2) + 0*V(3)] => V(2) = -1 + V(0)`

*   **状态3**：
    `V(3) = -1 + 1 * [0*V(0) + 0*V(1) + 1*V(2) + 0*V(3)] => V(3) = -1 + V(2)`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_65.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_66.png)

现在我们有一个方程组：
1.  `V(0) = 0` （已知终止状态价值）
2.  `V(1) = -1 + V(0)`
3.  `V(2) = -1 + V(0)`
4.  `V(3) = -1 + V(2)`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_68.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_69.png)

代入 `V(0)=0` 求解：
*   `V(1) = -1 + 0 = -1`
*   `V(2) = -1 + 0 = -1`
*   `V(3) = -1 + (-1) = -2`

![](img/5fef2fc214c443a43f0b923ac6b8fce7_71.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_72.png)

这个结果与我们之前通过直接计算期望得到的结果完全一致，但通过贝尔曼方程求解更加系统和高效。

![](img/5fef2fc214c443a43f0b923ac6b8fce7_74.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_76.png)

## 总结

![](img/5fef2fc214c443a43f0b923ac6b8fce7_78.png)

![](img/5fef2fc214c443a43f0b923ac6b8fce7_80.png)

本节课中我们一起学习了强化学习的核心——贝尔曼方程。
*   我们从未来回报 `G_t = R_{t+1} + γ * G_{t+1}` 的递归性质出发。
*   通过代入价值函数的定义并应用全期望公式，推导出了贝尔曼方程：`V^π(s) = E[R|s] + γ Σ_{s'} P^π(s'|s) V^π(s‘)`。
*   该方程揭示了状态价值之间的内在联系，将一个状态的价值表达为立即奖励与下一状态价值的折扣期望之和。
*   通过为所有状态建立贝尔曼方程，我们可以得到一个线性方程组，从而直接求解出策略 `π` 下的价值函数，这为策略评估提供了强大的理论工具。
