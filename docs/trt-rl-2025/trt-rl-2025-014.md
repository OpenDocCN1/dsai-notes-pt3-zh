在本节课中，我们将学习动作价值函数的概念，并推导其对应的贝尔曼方程。我们还将通过回溯图来直观地理解这些方程，这对于后续学习时间差分方法至关重要。

## 从价值函数到动作价值函数

上一节我们介绍了状态价值函数的贝尔曼方程。本节中，我们来看看如何将这一思想扩展到动作价值函数。

你可能会问为什么需要动作价值函数。原因在于，如果你想找到最优策略，就必须了解动作价值。

![](img/fbc8d0f823e3e486ec462578db44cfff_5.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_6.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_7.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_8.png)

动作价值函数与我们之前讨论的状态价值函数本质上是相同的。唯一的区别在于，它不再对即时动作进行平均。它明确地考虑了在特定状态下采取特定动作后的情况。

![](img/fbc8d0f823e3e486ec462578db44cfff_10.png)

**动作价值函数 Q^π(s, a)** 的定义是：在状态 `s` 下执行动作 `a`，然后遵循策略 `π` 所能获得的期望未来回报。

![](img/fbc8d0f823e3e486ec462578db44cfff_12.png)

\[
Q^{\pi}(s, a) = \mathbb{E}_{\pi}[G_t | S_t = s, A_t = a]
\]

![](img/fbc8d0f823e3e486ec462578db44cfff_14.png)

## 动作价值函数的贝尔曼方程推导

![](img/fbc8d0f823e3e486ec462578db44cfff_16.png)

与状态价值函数类似，我们可以为动作价值函数写出递归方程。我们从定义开始，将未来回报 `G_t` 替换为即时奖励加上折扣后的下一时间步回报。

![](img/fbc8d0f823e3e486ec462578db44cfff_18.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_19.png)

\[
Q^{\pi}(s, a) = \mathbb{E}_{\pi}[R_{t+1} + \gamma G_{t+1} | S_t = s, A_t = a]
\]

![](img/fbc8d0f823e3e486ec462578db44cfff_21.png)

接下来，我们展开这个期望。

首先看第一项：在给定当前状态 `s` 和动作 `a` 的情况下，所获得的即时奖励 `R_{t+1}`。这一项是否依赖于策略 `π`？需要仔细思考。

当处于特定状态并已知要执行的动作时，下一个奖励的分布仅由马尔可夫决策过程（MDP）决定。MDP 定义了在状态 `s` 下执行动作 `a` 后，下一个奖励的分布。因此，在计算即时奖励的期望时，我们不需要策略 `π`。

![](img/fbc8d0f823e3e486ec462578db44cfff_23.png)

\[
\mathbb{E}[R_{t+1} | S_t = s, A_t = a]
\]

![](img/fbc8d0f823e3e486ec462578db44cfff_25.png)

对于第二项，即未来回报 `G_{t+1}`，我们需要考虑下一状态 `S_{t+1}`。因此，我们引入对下一状态的期望。

![](img/fbc8d0f823e3e486ec462578db44cfff_27.png)

\[
\mathbb{E}_{\pi}[\gamma G_{t+1} | S_t = s, A_t = a] = \gamma \sum_{s'} P(s' | s, a) \mathbb{E}_{\pi}[G_{t+1} | S_t = s, A_t = a, S_{t+1} = s']
\]

现在，分析表达式 `E_π[G_{t+1} | S_t = s, A_t = a, S_{t+1} = s']`。这还不是动作价值函数 `Q^π(s', a')`，因为它的条件包含了上一时间步的状态和动作。

实际上，当我们已知下一状态 `s'` 时，上一时间步的状态 `s` 和动作 `a` 就不再提供额外信息了。此时，未来回报的期望就变成了在状态 `s'` 下遵循策略 `π` 所能获得的价值，即状态价值函数 `V^π(s')`。

![](img/fbc8d0f823e3e486ec462578db44cfff_29.png)

\[
\mathbb{E}_{\pi}[G_{t+1} | S_t = s, A_t = a, S_{t+1} = s'] = V^{\pi}(s')
\]

将各部分组合起来，我们得到动作价值函数的贝尔曼方程：

![](img/fbc8d0f823e3e486ec462578db44cfff_31.png)

\[
Q^{\pi}(s, a) = \mathbb{E}[R_{t+1} | S_t = s, A_t = a] + \gamma \sum_{s'} P(s' | s, a) V^{\pi}(s')
\]

这个方程的含义是：在状态 `s` 下执行动作 `a` 的价值，等于该动作带来的即时奖励期望，加上所有可能下一状态 `s'` 的转移概率乘以该下一状态的状态价值 `V^π(s')` 的折扣总和。

![](img/fbc8d0f823e3e486ec462578db44cfff_33.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_34.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_36.png)

## 价值函数与动作价值函数的关系

![](img/fbc8d0f823e3e486ec462578db44cfff_38.png)

理解价值函数 `V^π(s)` 和动作价值函数 `Q^π(s, a)` 之间的关系非常重要。

![](img/fbc8d0f823e3e486ec462578db44cfff_40.png)

**从 `V^π` 计算 `Q^π`**：如果已知所有状态的价值函数 `V^π` 和 MDP 模型（即奖励和转移概率），我们可以直接利用上面的贝尔曼方程计算出任何状态-动作对的 `Q^π(s, a)`。

![](img/fbc8d0f823e3e486ec462578db44cfff_42.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_44.png)

**从 `Q^π` 计算 `V^π`**：反之，如果已知所有状态-动作对的 `Q^π(s, a)`，那么一个状态的价值 `V^π(s)` 就是在该状态下，根据策略 `π` 选择各个动作的概率加权平均的动作价值。

![](img/fbc8d0f823e3e486ec462578db44cfff_46.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_47.png)

\[
V^{\pi}(s) = \sum_{a} \pi(a | s) Q^{\pi}(s, a)
\]

这表明，在已知 MDP 模型的情况下，价值函数和动作价值函数包含相同的信息，可以相互推导。

![](img/fbc8d0f823e3e486ec462578db44cfff_49.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_51.png)

## 纯粹的动作价值贝尔曼方程

![](img/fbc8d0f823e3e486ec462578db44cfff_53.png)

我们也可以推导出一个只包含 `Q^π` 的递归方程。只需将上面方程中的 `V^π(s')` 用其定义（即对动作的加权平均）替换掉。

\[
Q^{\pi}(s, a) = \mathbb{E}[R_{t+1} | S_t = s, A_t = a] + \gamma \sum_{s'} P(s' | s, a) \sum_{a'} \pi(a' | s') Q^{\pi}(s', a')
\]

这是一个关于 `Q^π` 的固定点方程。对于一个有 `n` 个状态和 `m` 个动作的环境，我们有 `n * m` 个未知数（每个状态-动作对的价值），也可以写出 `n * m` 个这样的方程。通过求解这个方程组，我们可以得到策略 `π` 下的动作价值函数。

## 回溯图：贝尔曼方程的直观表示

![](img/fbc8d0f823e3e486ec462578db44cfff_55.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_56.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_57.png)

贝尔曼方程可以用一种称为“回溯图”的树形图来直观表示，这极大地帮助了我们理解方程和后续的时间差分学习。

![](img/fbc8d0f823e3e486ec462578db44cfff_58.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_59.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_61.png)

回溯图的核心思想是：当前时刻的价值，可以通过对未来可能发生的情况进行“回溯”或“备份”来计算。

我们做以下简化以便图示：假设折扣因子 `γ = 1`。图中使用两种节点：
*   **状态节点**：用圆圈表示。
*   **动作节点**：用方块表示。

![](img/fbc8d0f823e3e486ec462578db44cfff_63.png)

连接节点的边上的权重表示转移概率。

![](img/fbc8d0f823e3e486ec462578db44cfff_65.png)

**从 `V^π(s)` 到 `Q^π(s, a)` 的回溯**：
1.  根节点是状态 `s`（我们想计算其价值 `V^π(s)`）。
2.  从 `s` 出发，有 `m` 条边连接到 `m` 个可能的动作节点 `a_1, ..., a_m`。边上的权重是策略概率 `π(a_i | s)`。
3.  每个动作节点 `a_i` 有一个值，即动作价值 `Q^π(s, a_i)`。
4.  将每个动作节点的值乘以其对应的策略概率（边权重），然后求和，就得到了根节点状态 `s` 的价值 `V^π(s)`。这正是公式 `V^π(s) = Σ_a π(a|s) Q^π(s, a)` 的图示。

**从 `Q^π(s, a)` 到下一状态 `V^π(s')` 的回溯**：
1.  根节点是动作节点，代表在状态 `s` 下采取动作 `a`，其值为 `Q^π(s, a)`。
2.  从该动作节点出发，有 `n` 条边连接到 `n` 个可能的下一状态节点 `s'_1, ..., s'_n`。边上的权重是 MDP 的转移概率 `P(s'_j | s, a)`。
3.  每个下一状态节点 `s'_j` 有一个值，即状态价值 `V^π(s'_j)`。
4.  此外，从状态 `s` 执行动作 `a` 转移到每个 `s'_j` 时，还会获得一个即时奖励 `r(s, a, s'_j)`。在图中，这通常表示在边旁或并入计算。
5.  `Q^π(s, a)` 的计算方式是：对于每个可能的下一状态 `s'_j`，计算 `(即时奖励 + V^π(s'_j))`，然后用转移概率 `P(s'_j | s, a)` 加权求和。这正是公式 `Q^π(s, a) = Σ_{s'} P(s'|s,a)[ R(s,a,s') + γV^π(s') ]` 的图示。

![](img/fbc8d0f823e3e486ec462578db44cfff_67.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_68.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_69.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_70.png)

将这两部分回溯图连接起来，就形成了一棵从当前状态 `s` 开始，不断向下展开的树。这棵树在理论上可以无限延伸，代表了整个决策过程的未来轨迹。

![](img/fbc8d0f823e3e486ec462578db44cfff_72.png)

回溯图的威力在于，它清晰地展示了如何通过未来（树的叶子节点）的价值估计，来更新当前（树的根节点）的价值估计。在后续的时间差分学习中，我们会“截断”这棵树，用估计值代替深层的精确计算，从而实现高效的学习。

![](img/fbc8d0f823e3e486ec462578db44cfff_74.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_76.png)

## 总结

![](img/fbc8d0f823e3e486ec462578db44cfff_79.png)

![](img/fbc8d0f823e3e486ec462578db44cfff_81.png)

本节课中我们一起学习了：
1.  **动作价值函数 `Q^π(s, a)`** 的定义：在状态 `s` 下执行动作 `a` 并随后遵循策略 `π` 的期望回报。
2.  **动作价值函数的贝尔曼方程**：它建立了 `Q^π(s, a)` 与即时奖励期望以及下一状态价值 `V^π(s')` 之间的联系。
3.  **价值函数与动作价值函数的互推关系**：在已知 MDP 模型的情况下，`V^π` 和 `Q^π` 可以相互计算。
4.  **纯粹的动作价值贝尔曼方程**：一个完全用 `Q^π` 自身表示的递归方程，可用于直接求解。
5.  **回溯图**：一种强大的可视化工具，用于直观理解贝尔曼方程如何通过“从未来回溯”来计算当前价值，为理解时间差分算法奠定了基础。
