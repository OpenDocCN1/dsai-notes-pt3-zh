## 环境模型与即时奖励

![](img/ab42bfb990b41252af15d3857d06421e_12.png)

![](img/ab42bfb990b41252af15d3857d06421e_13.png)

![](img/ab42bfb990b41252af15d3857d06421e_15.png)

![](img/ab42bfb990b41252af15d3857d06421e_16.png)

![](img/ab42bfb990b41252af15d3857d06421e_17.png)

上一节我们介绍了MDP模型。当我们拥有环境的完整模型，即知道状态转移和奖励的概率分布时，理论上我们可以计算出任何我们想要的期望值。

![](img/ab42bfb990b41252af15d3857d06421e_19.png)

![](img/ab42bfb990b41252af15d3857d06421e_21.png)

例如，假设我们处于一个特定状态 **S**，并执行了一个特定动作 **A**。我们想知道接下来能获得的**即时奖励**的期望值。这很容易计算，因为模型给出了在给定当前状态和动作下，获得每个可能奖励 **R** 的概率 **P(R | S, A)**。因此，即时奖励的期望值 **r(S, A)** 可以通过对所有可能的奖励进行加权平均得到：

**公式：**
`r(S, A) = Σ_R [ R * P(R | S, A) ]`

如果我们没有直接获得 **P(R | S, A)**，但拥有联合分布 **P(S', R | S, A)**，我们可以先对下一个状态 **S'** 进行边缘化，然后再计算奖励的期望值。

![](img/ab42bfb990b41252af15d3857d06421e_23.png)

## 策略下的平均即时奖励

![](img/ab42bfb990b41252af15d3857d06421e_25.png)

上一节我们计算了给定状态和动作的即时奖励。本节中，我们来看看如何计算在遵循某个策略 **π** 时，从特定状态 **S** 出发能获得的平均即时奖励。

![](img/ab42bfb990b41252af15d3857d06421e_27.png)

![](img/ab42bfb990b41252af15d3857d06421e_29.png)

![](img/ab42bfb990b41252af15d3857d06421e_31.png)

我们希望知道，如果按照策略 **π** 行动，在状态 **S** 下平均能获得多少即时奖励。计算方法如下：首先，对于每个可能的动作 **A**，计算在该动作下的即时奖励期望 **r(S, A)**。然后，用策略 **π(A | S)** 给出选择该动作的概率，并对所有动作进行加权平均。

![](img/ab42bfb990b41252af15d3857d06421e_33.png)

![](img/ab42bfb990b41252af15d3857d06421e_34.png)

![](img/ab42bfb990b41252af15d3857d06421e_36.png)

**公式：**
`r_π(S) = Σ_A [ π(A | S) * r(S, A) ] = Σ_A [ π(A | S) * Σ_R [ R * P(R | S, A) ] ]`

![](img/ab42bfb990b41252af15d3857d06421e_37.png)

![](img/ab42bfb990b41252af15d3857d06421e_39.png)

这个值 **r_π(S)** 代表了在状态 **S** 下，遵循策略 **π** 执行一步所能获得的平均奖励。

### 网格世界示例

![](img/ab42bfb990b41252af15d3857d06421e_41.png)

让我们在一个简单的网格世界环境中看看即时奖励是什么样的。

![](img/ab42bfb990b41252af15d3857d06421e_43.png)

假设我们处于状态“1”。可以执行的动作有四个（上、下、左、右）。根据环境规则：
*   执行动作“左”或“下”会移动到相邻格子，获得奖励 -1。
*   执行动作“右”或“上”会撞墙，停留在原地，获得奖励 -0.5。

如果我们采用一个**随机策略**（每个方向概率均为0.25），那么在状态“1”的平均即时奖励计算如下：
`(-1 * 0.25) + (-1 * 0.25) + (-0.5 * 0.25) + (-0.5 * 0.25) = -0.75`

![](img/ab42bfb990b41252af15d3857d06421e_45.png)

如果我们采用一个**确定性最优策略**（例如，在此状态总是选择“左”），那么平均即时奖励就是选择“左”动作的奖励：`-1`。

![](img/ab42bfb990b41252af15d3857d06421e_47.png)

![](img/ab42bfb990b41252af15d3857d06421e_48.png)

![](img/ab42bfb990b41252af15d3857d06421e_50.png)

![](img/ab42bfb990b41252af15d3857d06421e_52.png)

**注意**：这个例子揭示了一个关键点。随机策略在状态“1”的即时奖励（-0.75）高于最优策略的即时奖励（-1）。如果只关注即时奖励，我们可能会错误地认为随机策略更好。但实际上，最优策略虽然第一步奖励更低，但它能更快到达终点，避免长期累积更多的负奖励（比如反复撞墙）。这正是我们定义**价值函数**（考虑未来总回报的期望）而非只看即时奖励的原因。

![](img/ab42bfb990b41252af15d3857d06421e_54.png)

## 计算价值函数的朴素方法

![](img/ab42bfb990b41252af15d3857d06421e_56.png)

现在，我们面临核心任务：计算**价值函数 V_π(s)**，即在状态 **s** 下，遵循策略 **π** 所能获得的**未来总回报（Return）** 的期望值。

![](img/ab42bfb990b41252af15d3857d06421e_58.png)

![](img/ab42bfb990b41252af15d3857d06421e_59.png)

由于我们已知环境模型，理论上可以描述或评估这个价值函数，但计算可能非常复杂。我们首先尝试一种“朴素方法”。

![](img/ab42bfb990b41252af15d3857d06421e_61.png)

根据定义，价值函数是未来各时刻奖励折扣和的期望：

**公式：**
`V_π(s) = E_π [ G_t | S_t = s ] = E_π [ R_{t+1} + γR_{t+2} + γ²R_{t+3} + ... | S_t = s ]`

我们可以利用期望的线性性质将其展开：
`V_π(s) = E_π [ R_{t+1} | S_t = s ] + γE_π [ R_{t+2} | S_t = s ] + γ²E_π [ R_{t+3} | S_t = s ] + ...`

第一项 `E_π [ R_{t+1} | S_t = s ]` 正是我们之前计算的 `r_π(s)`。

![](img/ab42bfb990b41252af15d3857d06421e_63.png)

![](img/ab42bfb990b41252af15d3857d06421e_65.png)

问题在于计算后续项，例如第二项 `E_π [ R_{t+2} | S_t = s ]`。这表示在已知当前状态为 **s** 的条件下，两个时间步后的奖励的期望值。

为了计算它，我们需要考虑从当前状态 **s** 开始，到时间 **t+2** 获得奖励 **R_{t+2}** 的所有可能路径。这涉及到：
1.  在时间 **t**，根据策略 **π** 选择动作 **A_t**。
2.  根据模型 **P(S_{t+1}, R_{t+1} | S_t, A_t)** 转移到下一个状态 **S_{t+1}**，并获得奖励 **R_{t+1}**。
3.  在时间 **t+1**，在状态 **S_{t+1}** 下，根据策略 **π** 选择动作 **A_{t+1}**。
4.  最后，在时间 **t+2**，根据模型 **P(R_{t+2} | S_{t+1}, A_{t+1})** 获得奖励 **R_{t+2}**（注意，由于马尔可夫性，`R_{t+2}` 的条件概率只依赖于 `S_{t+1}` 和 `A_{t+1}`，与更早的状态/动作无关）。

因此，`E_π [ R_{t+2} | S_t = s ]` 需要对所有可能的中间状态 `S_{t+1}`、中间动作 `A_t` 和 `A_{t+1}` 进行求和（积分），并将每条路径的概率（由策略 **π** 和模型 **P** 共同决定）乘以在该路径下 `R_{t+2}` 的期望值。

**计算过程简述：**
`E_π [ R_{t+2} | S_t = s ] = Σ_{a_t} Σ_{s_{t+1}} Σ_{a_{t+1}} [ π(a_t | s) * P(s_{t+1} | s, a_t) * π(a_{t+1} | s_{t+1}) * r(s_{t+1}, a_{t+1}) ]`
其中 `r(s_{t+1}, a_{t+1}) = Σ_{r_{t+2}} [ r_{t+2} * P(r_{t+2} | s_{t+1}, a_{t+1}) ]`。

![](img/ab42bfb990b41252af15d3857d06421e_67.png)

![](img/ab42bfb990b41252af15d3857d06421e_69.png)

可以看到，即使只计算第二步的奖励期望，表达式已经相当复杂，涉及多重求和。如果要计算第三步、第四步，乃至无穷步的奖励期望，然后对它们进行折扣求和，这将变成一个计算上难以处理的“噩梦”。这种直接展开并逐项计算期望的方法就是“朴素方法”。

### 朴素方法在网格世界的简化

![](img/ab42bfb990b41252af15d3857d06421e_71.png)

![](img/ab42bfb990b41252af15d3857d06421e_72.png)

在某些特定环境下，朴素方法可以简化。例如，在我们之前的网格世界和确定性最优策略中：
*   从任何非终止状态出发，执行一步策略动作后，必然到达终止状态（或另一个特定状态）。
*   一旦到达终止状态，后续所有奖励均为0。
因此，对于这些策略，价值函数 `V_π(s)` 实际上就等于第一步的即时奖励 `r_π(s)`，因为后续奖励期望全为0。计算变得非常简单。

![](img/ab42bfb990b41252af15d3857d06421e_74.png)

然而，对于更一般的策略和环境（比如存在循环、随机转移等），这种简化不成立，我们必须处理复杂的多步期望计算。

![](img/ab42bfb990b41252af15d3857d06421e_76.png)

## 总结与展望

![](img/ab42bfb990b41252af15d3857d06421e_78.png)

本节课中，我们一起学习了通过MDP模型计算价值函数的“朴素方法”。

*   我们首先回顾了如何利用模型计算**即时奖励**的期望，以及如何将其扩展到计算特定**策略下的平均即时奖励**。
*   然后，我们尝试直接通过价值函数的定义来计算它，即将其展开为未来各时刻奖励期望的折扣和。
*   通过分析第二步奖励期望的计算过程，我们发现这种方法需要枚举所有可能的多步路径，并进行复杂的多重求和。对于长期或无限时域的问题，这种方法是**计算上不可行**的。

![](img/ab42bfb990b41252af15d3857d06421e_80.png)

这种朴素方法的复杂性和计算瓶颈，恰恰** motivates **了我们对更高效方法的需求。幸运的是，价值函数具有一个优美的**递归特性**（即贝尔曼方程），它允许我们通过求解一个方程组来得到所有状态的价值，而无需进行繁琐的多步路径枚举。这将是下一节课的重点内容。
