## 1. 机器学习简介 🤖

上一节我们介绍了课程的整体框架，本节中我们来看看什么是机器学习。

机器学习是让计算机从数据中学习规律，并利用这些规律对未知数据进行预测或决策的技术。其核心思想是找到一个函数 `f`，使得对于输入 `x`，能得到期望的输出 `y`。

**核心公式**：`y = f(x)`

这个过程通常包含三个关键步骤：定义模型（选择函数集合）、定义损失函数（评估函数好坏）、以及进行优化（找到最好的函数）。

## 2. 深度学习基础 🧠

了解了机器学习的基本范式后，本节我们将聚焦于其中一种强大的方法——深度学习。

深度学习使用包含多个隐藏层的神经网络作为模型。每一层由许多神经元（或称节点）组成，它们对输入数据进行非线性变换。

一个简单的神经元计算可以表示为：

**核心公式**：`a = σ(w·x + b)`

其中，`x` 是输入，`w` 是权重，`b` 是偏置，`σ` 是非线性激活函数（如Sigmoid或ReLU）。

以下是构建一个深度学习模型通常需要考虑的几个方面：

*   **网络结构**：决定层数、每层的神经元数量以及它们之间的连接方式。
*   **激活函数**：为网络引入非线性，使其能够学习复杂模式。常用函数包括ReLU和Sigmoid。
*   **损失函数**：衡量模型预测值与真实值之间的差距，如均方误差或交叉熵。
*   **优化器**：用于更新网络权重以最小化损失函数，例如梯度下降法及其变种。

## 3. 模型训练与优化 ⚙️

定义了模型之后，我们需要通过训练来找到最优的参数。本节中我们来看看模型是如何被训练和优化的。

训练的核心是**反向传播算法**。它首先进行前向传播计算预测值和损失，然后反向计算损失函数对于每个参数的梯度，最后利用梯度下降法更新参数。

参数更新的基本公式为：

**核心公式**：`w_new = w_old - η * ∇L(w_old)`

其中，`η` 是学习率，`∇L` 是损失函数关于权重的梯度。

为了更有效地训练模型，实践中会采用一些高级优化技巧。以下是几种常见的优化方法：

*   **自适应学习率算法**：如Adam、RMSProp，它们能为每个参数调整不同的学习率。
*   **正则化技术**：如L1/L2正则化、Dropout，用于防止模型在训练数据上过拟合。
*   **批标准化**：对每一层的输入进行标准化，可以加速训练并提升模型稳定性。

## 4. 卷积神经网络 👁️

处理图像、视频等网格状数据时，全连接网络效率低下。本节我们将介绍为此而设计的强大工具——卷积神经网络。

CNN通过**卷积层**自动提取图像的局部特征（如边缘、纹理）。卷积操作使用一个小的滤波器（或核）在输入图像上滑动并进行计算。

一个简单的二维卷积计算可以表示为：

**核心代码（概念）**：
```python
# 伪代码示意
output_feature_map[x, y] = sum( input_region * kernel ) + bias
```

CNN的典型架构包含以下几种层：

*   **卷积层**：使用多个滤波器提取特征，生成特征图。
*   **池化层**（如最大池化）：对特征图进行下采样，减少数据量并增强特征不变性。
*   **全连接层**：在网络的末端，将学习到的高级特征映射到最终的输出（如分类标签）。

## 5. 循环神经网络 🔄

对于序列数据（如文本、语音、时间序列），我们需要模型能够记忆历史信息。本节我们介绍循环神经网络。

RNN的核心是拥有“记忆”的循环结构，其隐藏状态 `h_t` 包含了到当前时刻为止的序列信息。

RNN单元在时间步 `t` 的计算可简化为：

**核心公式**：`h_t = f(W * [h_{t-1}, x_t] + b)`

然而，标准RNN存在梯度消失或爆炸问题，难以学习长距离依赖。因此，在实践中更常使用其改进版本。

以下是两种重要的RNN变体：

*   **长短期记忆网络**：通过引入输入门、遗忘门、输出门和细胞状态，有效地捕捉长程依赖。
*   **门控循环单元**：LSTM的一个简化版本，合并了部分门控机制，结构更简洁，计算效率更高。
