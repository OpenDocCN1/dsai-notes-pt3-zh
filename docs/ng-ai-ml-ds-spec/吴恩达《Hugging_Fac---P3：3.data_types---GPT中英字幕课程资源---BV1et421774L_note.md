# 量化基础：3：数据类型与大小 🔢

在本节课中，我们将学习机器学习模型参数存储中常见的数据类型。理解这些数据类型对于掌握量化技术至关重要，因为量化本质上就是通过将数值转换为不同的数据类型来实现的。让我们开始吧。

## 整数数据类型

首先，我们从整数数据类型开始。整数类型主要分为无符号整数和有符号整数。

### 无符号整数

无符号整数数据类型用于表示正整数。对于一个 **n** 位的无符号整数，其可表示的范围是从 **0** 到 **2^n - 1**。

例如，一个 **8** 位无符号整数的最小值是 **0**，最大值是 **255**。

计算机会分配一个 **8** 位的序列来存储这个整数。解码过程如下：
*   如果某一位等于 **0**，则其解码值为 **0**。
*   如果某一位等于 **1**，则其解码值为 **2** 的幂次方。具体来说，从右向左（最低有效位开始），第 **i** 位（从0开始计数）的值为 **2^i**。

**公式表示**：`value = Σ (bit_i * 2^i)`，其中 `i` 从 0 到 n-1。

例如，对于二进制序列 `10001001`：
*   第0位（最右边）是1：`1 * 2^0 = 1`
*   第3位是1：`1 * 2^3 = 8`
*   第7位是1：`1 * 2^7 = 128`
*   其他位为0。
*   最终值：`128 + 8 + 1 = 137`。

![](img/b4a9696f19beb032dd23d25c41c9d9fc_1.png)

### 有符号整数

有符号整数数据类型用于表示负整数或正整数。最常用的表示方法是 **二进制补码**。

对于一个 **n** 位的有符号整数（补码表示），其范围是从 **-2^(n-1)** 到 **2^(n-1) - 1**。

例如，一个 **8** 位有符号整数的最小值是 **-128**，最大值是 **127**。

![](img/b4a9696f19beb032dd23d25c41c9d9fc_3.png)

解码过程与无符号整数类似，但**最高有效位（最左边的位）的权重为负**。

**公式表示**：`value = -bit_(n-1) * 2^(n-1) + Σ (bit_i * 2^i)`，其中 `i` 从 0 到 n-2。

例如，对于相同的二进制序列 `10001001`：
*   最高位（第7位）是1：`-1 * 2^7 = -128`
*   第3位是1：`1 * 2^3 = 8`
*   第0位是1：`1 * 2^0 = 1`
*   最终值：`-128 + 8 + 1 = -119`。

二进制补码的一个优点是，**两个有符号整数的加法可以直接使用标准的二进制加法电路进行**，无需额外的符号处理逻辑。

上一节我们介绍了整数数据类型的原理，本节中我们来看看如何在 PyTorch 中使用它们。

### 在 PyTorch 中使用整数类型

在 PyTorch 中，使用整数数据类型非常简单，只需设置正确的 `torch.dtype`。

以下是常见的整数数据类型及其对应的 PyTorch 表示：

| 数据类型 | PyTorch dtype | 说明 |
| :--- | :--- | :--- |
| 8位有符号整数 | `torch.int8` | |
| 8位无符号整数 | `torch.uint8` | `U` 代表无符号 |
| 16位有符号整数 | `torch.int16` 或 `torch.short` | |
| 32位有符号整数 | `torch.int32` 或 `torch.int` | |
| 64位有符号整数 | `torch.int64` 或 `torch.long` | |

我们可以使用 `torch.iinfo()` 函数来查看整数类型的范围信息。

```python
import torch

# 检查 8 位无符号整数的范围
print(torch.iinfo(torch.uint8))
# 输出：iinfo(min=0, max=255)

# 检查 8 位有符号整数的范围
print(torch.iinfo(torch.int8))
# 输出：iinfo(min=-128, max=127)
```

## 浮点数数据类型

浮点数表示法用于存储实数（带小数点的数）。它由三个部分组成：
1.  **符号位**：1位，表示正负。
2.  **指数位**：决定数字的范围（能表示多大或多小的数）。
3.  **尾数位**：决定数字的精度（能表示多精细）。

常见的浮点数格式有：
*   **FP32 (float32)**：单精度浮点数。
*   **FP16 (float16)**：半精度浮点数。
*   **BF16 (bfloat16)**：Brain Floating Point 格式。
*   **FP8**：8位浮点数（有多种变体）。

以下是几种格式的对比：

| 格式 | 符号位 | 指数位 | 尾数位 | 总位数 | 大致范围 (正数) | 特点 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **FP32** | 1 | 8 | 23 | 32 | 1.4e-45 ~ 3.4e38 | 高精度，标准模型权重格式 |
| **FP16** | 1 | 5 | 10 | 16 | 5.96e-8 ~ 65504 | 精度较好，范围较小 |
| **BF16** | 1 | 8 | 7 | 16 | 1.18e-38 ~ 3.39e38 | 范围接近FP32，精度较低 |

**总结对比**：
*   **FP32** 具有最佳的精度和非常大的范围。
*   **FP16** 的精度优于 BF16，但表示范围较小。
*   **BF16** 的表示范围与 FP32 接近，但精度最差。

**FP16 和 BF16 的主要优势在于它们只占用 FP32 一半的存储空间**，这能显著减少内存占用并可能提升计算速度。

上一节我们比较了不同浮点数的格式，本节中我们来看看它们在 PyTorch 中的具体使用和表现。

### 在 PyTorch 中使用浮点数类型

在 PyTorch 中创建指定浮点类型的张量非常直观。

| 数据类型 | PyTorch dtype |
| :--- | :--- |
| 16位浮点数 (FP16) | `torch.float16` 或 `torch.half` |
| Brain浮点数 (BF16) | `torch.bfloat16` |
| 32位浮点数 (FP32) | `torch.float32` 或 `torch.float` |
| 64位浮点数 (FP64) | `torch.float64` 或 `torch.double` |

![](img/b4a9696f19beb032dd23d25c41c9d9fc_5.png)

让我们通过一个例子观察不同精度下的数值近似情况：

```python
import torch

![](img/b4a9696f19beb032dd23d25c41c9d9fc_7.png)

value = 1 / 3 # Python 默认使用高精度（类似float64）存储
print(f"原始 Python 值: {value}")

![](img/b4a9696f19beb032dd23d25c41c9d9fc_9.png)

# 创建不同精度的张量
fp64_tensor = torch.tensor(value, dtype=torch.float64)
fp32_tensor = torch.tensor(value, dtype=torch.float32)
fp16_tensor = torch.tensor(value, dtype=torch.float16)
bf16_tensor = torch.tensor(value, dtype=torch.bfloat16)

![](img/b4a9696f19beb032dd23d25c41c9d9fc_11.png)

![](img/b4a9696f19beb032dd23d25c41c9d9fc_13.png)

print(f"FP64: {fp64_tensor.item()}")
print(f"FP32: {fp32_tensor.item()}")
print(f"FP16: {fp16_tensor.item()}")
print(f"BF16: {bf16_tensor.item()}")
```

**观察结果**：位数越少，对原始值的近似精度就越低。BF16 的精度确实比 FP16 更差，这与理论分析一致。

我们可以使用 `torch.finfo()` 查看浮点类型的详细信息：

```python
print(torch.finfo(torch.bfloat16))
print(torch.finfo(torch.float32))
```

比较两者，你会发现 BF16 的范围与 FP32 相近，但 `eps`（可表示的最小正数，反映精度）远大于 FP32，证实了其精度较低。

## 向下转换及其影响

**向下转换**是指将数据从一种较高精度（更多位数）的数据类型转换为一种较低精度（更少位数）的数据类型。转换时，数值会被舍入到目标类型中最接近的可表示值。

![](img/b4a9696f19beb032dd23d25c41c9d9fc_17.png)

例如，将 FP32 值 `0.1` 向下转换为 8 位整数，结果会是 `0`，这导致了信息丢失。

### 向下转换对矩阵运算的影响

![](img/b4a9696f19beb032dd23d25c41c9d9fc_19.png)

让我们通过一个实验来观察向下转换对计算的影响。

```python
import torch

![](img/b4a9696f19beb032dd23d25c41c9d9fc_21.png)

# 1. 创建一个 FP32 的随机大张量
fp32_tensor = torch.randn(1000, dtype=torch.float32)
print("FP32 前5个元素:", fp32_tensor[:5])

![](img/b4a9696f19beb032dd23d25c41c9d9fc_23.png)

# 2. 将其向下转换为 BF16
bf16_tensor = fp32_tensor.to(torch.bfloat16)
print("BF16 前5个元素:", bf16_tensor[:5])
print("数据类型:", bf16_tensor.dtype)

# 3. 比较两种精度下的点积结果
dot_fp32 = torch.dot(fp32_tensor, fp32_tensor)
dot_bf16 = torch.dot(bf16_tensor, bf16_tensor)

print(f"\nFP32 点积结果: {dot_fp32.item()}")
print(f"BF16 点积结果: {dot_bf16.item()}")
print(f"绝对误差: {abs(dot_fp32 - dot_bf16).item()}")
```

![](img/b4a9696f19beb032dd23d25c41c9d9fc_25.png)

**结果分析**：BF16 的结果与 FP32 的结果非常接近，但并非完全相等，存在一定的精度损失。

![](img/b4a9696f19beb032dd23d25c41c9d9fc_27.png)

### 向下转换的优缺点

![](img/b4a9696f19beb032dd23d25c41c9d9fc_29.png)

以下是向下转换的优缺点总结：

![](img/b4a9696f19beb032dd23d25c41c9d9fc_31.png)

**优点**：
*   **减少内存占用**：更低精度的数据占用更少的 GPU/内存空间。
*   **提升计算速度**：许多现代硬件（如GPU的Tensor Cores、TPU）对低精度计算（FP16/BF16）进行了优化，计算速度更快。
*   **允许更大模型/批次**：节省下的内存可以用于训练更大的模型或使用更大的批次大小。

![](img/b4a9696f19beb032dd23d25c41c9d9fc_33.png)

**缺点**：
*   **精度损失**：计算结果的准确性会下降，可能导致模型训练不稳定或最终性能略有降低。
*   **数值溢出/下溢风险**：更低精度的表示范围更小，在计算中更容易出现数值过大（溢出）或过小（下溢）的问题。

一个重要的应用是 **混合精度训练**：在训练过程中，使用 FP16/BF16 进行前向传播和反向传播的计算以提升速度，但使用 FP32 来维护和更新模型的主权重副本，以保持训练的数值稳定性。
