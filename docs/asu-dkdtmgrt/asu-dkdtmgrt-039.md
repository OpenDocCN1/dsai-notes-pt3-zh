# 1：价值提取总览 🧭

在本节课中，我们将学习如何从黑暗数据中创造价值的最佳方法。我们将从一个原则性的方法开始，逐步深入到探索数据时所需的具体功能和视角。

上一节我们介绍了课程的整体目标，本节中我们来看看价值提取的具体路径。我们将首先确立一个核心原则，然后探讨在探索数据——无论是已捕获的、未捕获的还是未知边界的数据——时所需的功能与视角。最终，我们将学习如何构建能够预防失败并创造价值的数据产品。

以下是本课程将涵盖的核心步骤：

1.  **采用原则性方法**：确立从黑暗数据中提取价值的基础框架和指导思想。
2.  **探索数据维度**：深入检视已捕获的数据、识别未捕获的数据，并探索数据的未知边界。
3.  **构建数据产品**：基于探索结果，设计和开发能够创造实际价值并规避风险的数据解决方案。

本课程对于实际交付数据价值至关重要。课程最后，我们将通过一个复杂的综合性项目来收尾。该项目包含多个层面，将使您亲身体验如何思考未知领域的问题，并在项目结束时交付一个融合了新认知的、处于领先地位的产品。

本节课中，我们一起学习了从黑暗数据中提取价值的整体框架与步骤，为后续深入每个具体环节奠定了基础。
