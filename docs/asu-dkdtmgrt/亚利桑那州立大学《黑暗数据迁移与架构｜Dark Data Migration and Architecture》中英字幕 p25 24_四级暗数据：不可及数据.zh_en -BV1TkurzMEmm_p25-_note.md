# 黑暗数据迁移与架构：P25：四级暗数据：不可及数据 🔍

在本节课中，我们将要学习暗数据分类中的第四级B类——不可及数据。我们将探讨其定义、成因、分类，并通过一个历史案例来理解其重要性。

## 概述

![](img/956682890e47ac073766495e8af6897c_1.png)

![](img/956682890e47ac073766495e8af6897c_2.png)

![](img/956682890e47ac073766495e8af6897c_3.png)

不可及数据位于公司数据仓库之外，其具体形态和内容通常是未知的。这类数据通常用于推导或生成新的数据集。从宏观上看，不可及数据主要存在于两个层面。

![](img/956682890e47ac073766495e8af6897c_4.png)

![](img/956682890e47ac073766495e8af6897c_6.png)

## 不可及数据的两个层面

![](img/956682890e47ac073766495e8af6897c_7.png)

以下是不可及数据存在的两种主要情况：

![](img/956682890e47ac073766495e8af6897c_9.png)

![](img/956682890e47ac073766495e8af6897c_10.png)

1.  **未被捕获且无法再捕获**：这类数据可能在过去某个时间点未被捕获，现已“消失”在时空之中；也可能是因为公司当前不具备捕获能力或技术而无法获取。
2.  **未来可获取**：对于这类数据，关键问题是如何从过去未获取的数据中提取价值，或者如何为未来获取这些数据做好准备，并找到方法去量化或评估这些数据，从而基于它们做出更好的决策。

## 故意不可及的数据

上一节我们介绍了不可及数据的一般情况，本节中我们来看看一种特殊情况——故意不可及的数据。在某些情况下，公司会**故意**不捕获某些数据。

![](img/956682890e47ac073766495e8af6897c_17.png)

![](img/956682890e47ac073766495e8af6897c_18.png)

![](img/956682890e47ac073766495e8af6897c_19.png)

![](img/956682890e47ac073766495e8af6897c_20.png)

![](img/956682890e47ac073766495e8af6897c_21.png)

以下是故意使数据不可及的常见原因：

![](img/956682890e47ac073766495e8af6897c_22.png)

![](img/956682890e47ac073766495e8af6897c_24.png)

*   **保护身份信息（PII）与安全**
*   **消除偏见**
*   **进行A/B测试等实验**：有时需要保持匿名性和隐蔽性。

## 案例分析：Excite与Google

![](img/956682890e47ac073766495e8af6897c_31.png)

现在，我想通过一个历史案例来说明未获取关键数据可能带来的问题。回顾1998-1999年，谷歌刚刚起步（当时还叫Backrub.com），而Excite.com是当时第二大搜索引擎。

当时互联网信息检索仍比较困难。谷歌开发了一种算法，能比其他搜索引擎更快地帮用户找到所需信息。谷歌创始人拉里·佩奇曾找到Excite，提议以75万美元出售谷歌及其算法，理由是它能更快地满足用户需求。

然而，Excite拒绝了这笔交易。他们的理由是：**谷歌的搜索功能太快了，会使用户过快离开网站**。Excite的商业模式依赖于广告收入，需要用户停留在网站上点击广告。

![](img/956682890e47ac073766495e8af6897c_33.png)

![](img/956682890e47ac073766495e8af6897c_34.png)

![](img/956682890e47ac073766495e8af6897c_35.png)

谷歌团队离开时认为Excite并不清楚自己在做什么。这里的暗数据——关于**客户价值、长期竞争格局和性能表现**的洞察——在当时没有被Excite获取和重视。随着课程深入，你会发现许多不可及数据都围绕行业或市场数据，帮助你理解自身市场定位。

![](img/956682890e47ac073766495e8af6897c_36.png)

![](img/956682890e47ac073766495e8af6897c_37.png)

![](img/956682890e47ac073766495e8af6897c_38.png)

![](img/956682890e47ac073766495e8af6897c_39.png)

通常，这类数据不会被捕获，因而成为“不可及数据”。你可以主动收集这类数据，并思考如何模拟或预测过去未获取的信息。**千万不要重蹈Excite的覆辙**：他们未能理解，即使当下形势良好，如果竞争对手表现更优，客户价值就会流向竞争对手，因为客户追求的是高效获取信息，而非点击广告。

因此，至少在关注如何获取客户价值这一点上，**请遵循谷歌的模式**。这也正是我们研究此类暗数据的核心焦点。
