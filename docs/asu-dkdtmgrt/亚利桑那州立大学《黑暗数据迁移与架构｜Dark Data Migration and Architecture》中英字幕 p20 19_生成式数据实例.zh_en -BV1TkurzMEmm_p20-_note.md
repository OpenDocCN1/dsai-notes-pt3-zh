# 黑暗数据迁移与架构：20：生成式数据实例 🧠

在本节课中，我们将深入探讨一个关于生成式数据的简单实例。我们将学习如何通过衍生和扩展现有数据来创造新的价值，并将黑暗数据转化为数据产品。

## 概述

![](img/dd0cc61947665bbad505664ae24b2720_4.png)

![](img/dd0cc61947665bbad505664ae24b2720_6.png)

生成新数据的目的是扩展我们已有数据以及未来能够创造的数据的能力。当我们谈论扩展能力时，重点在于**价值创造**和**定位**，即创造能够做更多事情的能力。这有助于我们揭示未知、回答问题、增加价值，并推动产品性能随时间改进。这正是我们将黑暗数据转化为数据产品的地方，这些数据产品可以提升我们的定位并促进增长。

![](img/dd0cc61947665bbad505664ae24b2720_7.png)

## 从交易数据到账户视角

![](img/dd0cc61947665bbad505664ae24b2720_9.png)

![](img/dd0cc61947665bbad505664ae24b2720_10.png)

![](img/dd0cc61947665bbad505664ae24b2720_11.png)

上一节我们介绍了生成式数据的目的。本节中，我们来看看如何通过改变数据视角来创造新见解。

首先，我们从一个简单的数据集开始。这是一个标准的交易数据视图，包含以下列：
*   **交易ID**
*   **账户号码**
*   **城市**
*   **州**
*   **产品**
*   **价格**
*   **优惠**
*   **购买时间**

![](img/dd0cc61947665bbad505664ae24b2720_13.png)

![](img/dd0cc61947665bbad505664ae24b2720_14.png)

![](img/dd0cc61947665bbad505664ae24b2720_15.png)

这个视图展示了交易发生时，优惠、购买价格和购买时间等信息。显然，实际数据中会有更多的列和变量，但这是一个典型的通用示例。

现在，我们进入关键部分。以下是我们将数据视角从“交易”转变为“账户”后，衍生出的新数据列。这是数据扩展和产生新想法的关键步骤。

![](img/dd0cc61947665bbad505664ae24b2720_17.png)

![](img/dd0cc61947665bbad505664ae24b2720_18.png)

![](img/dd0cc61947665bbad505664ae24b2720_19.png)

![](img/dd0cc61947665bbad505664ae24b2720_21.png)

我们将账户号码与具体账户关联，并添加以下衍生列：
*   **购买的产品数量**
*   **交易次数**（一次交易可能包含多个产品）
*   **产品与交易比率**（`产品数量 / 交易次数`）
*   **交易量**
*   **平均交易价值**（`总价值 / 交易次数`）
*   **推荐次数**
*   **推荐使用率**
*   **推荐响应时间**
*   **优惠使用次数**
*   **优惠使用率**
*   **优惠响应时间**
*   **关系深度**

通过这种转变，我们不再孤立地看待每一笔交易，而是聚焦于每一个细粒度的账户，分析其整体行为模式。

## 通过衍生数据回答关键问题

基于新的账户视角数据，我们可以提出并回答一系列关键业务问题。以下是我们可以探索的一些方向：

![](img/dd0cc61947665bbad505664ae24b2720_29.png)

![](img/dd0cc61947665bbad505664ae24b2720_30.png)

*   **识别营销放大器**：是否存在典型的用户画像，能够放大我们的营销效果？我们能否通过现有的营销广告找到他们？他们是否对特定类型的广告（如推荐广告）反应更好？
*   **分析推荐行为**：哪些消费者推荐次数更多、使用推荐更频繁？哪些人对推荐的响应更快？推荐发出后，响应反馈的速度如何？
*   **理解优惠关系**：通过优惠吸引来的客户，其后续行为如何？例如，是否存在这样的客户：他们通过一次优惠购买后，持续购买我们的产品（如T恤、牛仔裤），但再也不使用任何优惠？这类客户至关重要，因为他们认可产品价值并愿意支付全价。
*   **优化客户沟通**：我们如何根据客户的操作方式和感知价值来调整沟通策略，从而获得更多互动，而不是仅仅基于我们内部的运营思路？

![](img/dd0cc61947665bbad505664ae24b2720_32.png)

这引出了一个重要原则：我们需要专注于为**客户**创造价值，而不仅仅是为企业自身。就像Google和Excite的例子，Google的成功在于它专注于为用户提供价值。

## 进一步的衍生指标与行动闭环

除了上述列出的衍生数据，我们还可以计算更多指标来深化分析。以下是一些可能的衍生指标：

![](img/dd0cc61947665bbad505664ae24b2720_34.png)

*   **平均交易总额**
*   **月均交易次数**
*   **月均节省金额**（通过优惠节省的总额）
*   **平均每笔交易节省金额**
*   **利润率减少/节省分析**

![](img/dd0cc61947665bbad505664ae24b2720_35.png)

![](img/dd0cc61947665bbad505664ae24b2720_37.png)

分析这些指标可以帮助我们理解：随着时间的推移，我们是否能够减少提供的优惠额度（节省）？不同客户群体对优惠的依赖程度如何？

![](img/dd0cc61947665bbad505664ae24b2720_38.png)

最初，我们可能直接回答关于产品绩效的问题，如销售额、利润、EBITDA等。随后，我们会转向更多基于绩效的指标，并将各种指标整合起来。

![](img/dd0cc61947665bbad505664ae24b2720_40.png)

一个有效的方法是形成一个**综合评分**。这个评分可以是一个单一的数字，它背后综合了众多基准指标。这样做可以减少前期的困惑，因为如果一开始就向决策者展示所有复杂的数据切片视图，可能会让人不知所措。

![](img/dd0cc61947665bbad505664ae24b2720_42.png)

因此，我们需要专注于数据产品本身：它如何诞生、如何呈现给领导和决策者，以及我们如何不仅为决策者提供价值，还能将价值反馈到上游的**交易系统**和**沟通渠道**中。

![](img/dd0cc61947665bbad505664ae24b2720_44.png)

这是一个关键闭环：我们不仅利用数据产品来获取洞察和做出决策，更利用这些信息来**采取行动**——调整与客户的沟通、优化产品、提升产品性能，并识别那些无论我们如何沟通和定位都表现不佳的产品。
