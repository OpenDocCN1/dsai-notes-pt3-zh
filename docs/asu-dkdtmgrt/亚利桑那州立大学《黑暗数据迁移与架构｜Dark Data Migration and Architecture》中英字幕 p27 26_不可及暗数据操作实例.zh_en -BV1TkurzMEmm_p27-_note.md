# 黑暗数据迁移与架构：P27：不可及暗数据操作实例 🎯

在本节课中，我们将尝试深入探讨如何利用不可及数据、生成数据、捕获数据以及我们整个数据生态系统中的所有资源来创建一个数据产品。我们将从高层次进行聚焦，因为我们的核心目标是制定一个专注于商业目标的数据产品，而不是审查、监控结果或根据结果进行调整。本节内容主要关于设定目标，因此是最高层次的概述。

上一节我们介绍了数据产品的概念，本节中我们来看看一个具体的商业案例。

## 营销分析与核心假设 📈

接下来是我们想要关注的营销分析。以下是左上角的一些假设：
*   假设每个人购买一件T恤（尽管我们知道并非每个人都会购买）。
*   假设每个家庭购买两件T恤。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_25.png)

我们必须将这个假设与另一项评估相结合：只有83%的人口甚至没有购买过T恤，这意味着有17%的人购买过T恤。因此，我们的视角是：我们希望每个人购买一件T恤，并且每个家庭有两个人购买T恤。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_27.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_25.png)

在这17%的购买人群中，我们的领导层目标是占据20%的市场份额。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_27.png)

到明年年底实现。其中一个问题是：这个目标是否可实现？可能实现，也可能无法实现。目前我们只占有13%的市场份额，因此需要在一年内提升7个百分点。我们必须明确我们的目标是什么，以及如何实现。可能的T恤总销售额是340万件。根据我们的假设，我们有可能达到340万件的销量。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_29.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_31.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_29.png)

然而，现实中只售出了183万件。因此，可能性远高于实际情况。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_31.png)

所以，部分策略在于：我们是否应该发起活动，让人们对T恤整体更感兴趣，从而增加购买T恤的人数？当我们这样做时，我们必须明白，我们也在为其他商家做广告，并且在进行这类广告时，我们会让其他公司分走一部分利润。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_33.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_34.png)

## 目标设定与计算过程 🧮

现在，让我们深入看看右侧的目标数字。我们将从846万（18岁以上人口数）开始计算。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_33.png)
![](img/b42d2e99f26af55c4c0021c8c5f5a006_34.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_36.png)

然后，450万是家庭数量。我们将其乘以2，因为假设每个家庭购买两件T恤，这样我们得到1736万这个数字。接着，我们转向行业数据。从1736万中，我们只取购买人口的17%，然后再乘以我们的目标市场份额20%。这样计算下来，我们得到略高于50万件，接近60万件的T恤销量目标。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_37.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_38.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_36.png)
![](img/b42d2e99f26af55c4c0021c8c5f5a006_37.png)
![](img/b42d2e99f26af55c4c0021c8c5f5a006_38.png)

然后，我们根据每件T恤的价格，再次基于实际购买人口的17%进行折算，得出112万美元的销售额。我们认为，这112万美元对应的T恤销量，应该是我们基于未来一年的增长预期，在市场中应占据的份额。因为目前我们看已售出的T恤数量，这个目标已经超过了一半。所以，我们考虑的是未来一年的增长。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_40.png)
![](img/b42d2e99f26af55c4c0021c8c5f5a006_41.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_40.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_41.png)

当我们看到112万这个数字时，我们会说：这比目前的18.7万件是一个巨大的飞跃。领导层，你们真的想让我们去争取20%的市场份额吗？这将是我们提出的问题，因为这样可能会让我们自己走向失败。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_43.png)
![](img/b42d2e99f26af55c4c0021c8c5f5a006_44.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_43.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_44.png)

因为归根结底，市场会增长，尤其是当我们开始投放更多广告和进行更多销售时。

## 其他考量指标与数据产品完善 💡

现在考虑其他目标。以下是我采用的一些基准数字：13%的市场份额，10%的T恤总销量，以及销售额的13%中的10%。这些数字让我们知道，我们的产品实际售价略高于市场平均水平。

![](img/b42d2e99f26af55c4c0021c8c5f5a006_46.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_47.png)

![](img/b42d2e99f26af55c4c0021c8c5f5a006_46.png)
![](img/b42d2e99f26af55c4c0021c8c5f5a006_47.png)

我们还瞄准了14%的点击量和8%的交易量，同时关注展示量，以及如前所述的3%更高的平均销售额。需要考虑的一点是：购物车部分填写是否有价值？展示量是否有价值？推荐流量是否有价值？

![](img/b42d2e99f26af55c4c0021c8c5f5a006_49.png)
