# 黑暗数据迁移与架构：1.6：一级暗数据深度剖析：存量数据 📊

在本节课中，我们将聚焦于一级暗数据中的“存量数据”。存量数据是生成性数据的基础，通常存在于组织内部，因此也被称为“内部数据”。我们将详细探讨其来源、常见类型，并特别关注一个常被忽视但有时具有价值的类别——ROT数据。

## 存量数据概述

存量数据位于暗数据分类的第一层级。它通常存在于组织内部，通过事务处理系统捕获，并存储在数据库中。随后，这些数据通常会进入分析空间，为业务决策提供支持。存量数据是迈向生成性数据的重要前驱。

*   **系统数据**：来自CRM（客户关系管理）、CMS（内容管理）、DAM（数字资产管理）等系统的数据。

## 被忽视的领域：系统文件与ROT数据

上一节我们介绍了常见的存量数据类型，本节中我们来看看一个常被忽略的部分：系统文件和ROT数据。

大多数人认为ROT数据价值极低，这通常是正确的。ROT代表冗余、过时、琐碎的数据。这类数据通常包括没有业务或法律价值的文档、时间戳记录等。

1.  **作为元数据与层级结构的辅助**：它有时能帮助构建数据的元信息或层次关系。
2.  **提供故障安全保障**：当主要数据出现问题时，时间戳等ROT数据可能成为排查依据。
3.  **满足合规性要求**：某些冗余或过时的数据因监管原因必须保留。
4.  **创造新衍生的基础**：在探索生成新数据时，ROT数据可能提供意想不到的线索或上下文。

![](img/687288fb05f48b48ca668fba4f306c69_25.png)

尽管ROT数据主要被视为冗余，但它在特定场景下——尤其是在我们后续将要探讨的生成性数据领域——可能扮演辅助角色。进入生成性数据阶段时，我们将主要依赖之前幻灯片中确定的核心数据价值，但也会酌情考虑部分ROT数据。
