# 黑暗数据迁移与架构：1：价值创造总览 🧭

在本节课中，我们将学习如何从黑暗数据中创造价值的最佳方法。我们将从一个原则性的方法开始，然后深入探讨在探索数据时需要具备的详细功能和视角。课程最后，我们将通过一个复杂的综合性项目，展示如何思考未知问题并交付一个前沿的数据产品。

---

上一节我们介绍了课程的整体目标，本节中我们来看看创造价值的具体原则性方法。我们将从探索已被捕获和未被捕获的数据开始，理解数据的未知边界，并最终构建能够预防失败并创造价值的数据产品。

以下是探索数据时需要关注的几个核心功能和视角：

*   **探索已被捕获的数据**：分析系统中已经存在但未被充分利用的信息。
*   **探索未被捕获的数据**：识别哪些有价值的信息尚未被系统记录。
*   **探索数据的未知边界**：发现数据之间隐藏的关联和潜在模式。

在明确了数据探索的范畴后，我们需要思考如何将这些洞察转化为实际价值。关键在于构建有效的数据产品。

构建数据产品的核心目标是：**预防失败** 与 **创造价值**。这要求我们在思考数据时，始终以价值创造为导向。

本课程对于实际交付数据价值至关重要。为了巩固所学，课程将以一个复杂的多层面项目作为结束。

该项目将允许你实践如何系统性地思考未知问题，并在项目结束时交付一个融合了新认知的前沿产品。

---

本节课中，我们一起学习了从黑暗数据中创造价值的整体框架。我们从原则性方法入手，探讨了数据探索的关键方面，并明确了构建预防失败、创造价值的数据产品的目标。最后，我们预览了将通过一个综合项目来实践这些概念。
