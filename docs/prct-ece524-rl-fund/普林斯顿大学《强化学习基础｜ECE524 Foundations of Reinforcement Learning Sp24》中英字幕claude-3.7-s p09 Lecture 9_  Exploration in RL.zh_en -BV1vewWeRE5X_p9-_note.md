## 从多臂老虎机到强化学习

上一节我们介绍了多臂老虎机中的探索，具体讨论了两种算法：ε-贪心算法和上置信界（UCB）算法。

![](img/aff6c92a3411e8da7c16d4fc130bf53a_42.png)

![](img/aff6c92a3411e8da7c16d4fc130bf53a_43.png)

![](img/aff6c92a3411e8da7c16d4fc130bf53a_45.png)

以下是两种算法的遗憾界对比：
*   **ε-贪心算法**：遗憾界为 `O(T^{2/3})`。
*   **UCB算法**：遗憾界为 `O(√T)`。

在强化学习场景中，探索的挑战性要大得多。我们之前讨论过一个反例——组合锁（combinatorial lock）问题。如果使用随机探索或ε-贪心策略，我们至少需要 `Ω(A^H)` 次尝试才能首次识别出最优策略，这导致遗憾界呈指数级增长。这是不可接受的。

![](img/aff6c92a3411e8da7c16d4fc130bf53a_47.png)

本讲的核心思想是将UCB的思想融入到强化学习中。通过结合值迭代（VI）和UCB，我们可以得到类似 `O(√T)` 且关于H为多项式的遗憾界。

## UCB-VI算法详解

![](img/aff6c92a3411e8da7c16d4fc130bf53a_49.png)

![](img/aff6c92a3411e8da7c16d4fc130bf53a_50.png)

UCB-VI算法的核心思想与多臂老虎机中的UCB类似：我们不仅估计值函数，还为其添加一个奖励（bonus），以鼓励探索不确定性较高的状态-动作对。

以下是算法的具体步骤：

![](img/aff6c92a3411e8da7c16d4fc130bf53a_52.png)

1.  **初始化**：
    *   初始化一个空的数据集 `D`。
    *   对所有状态 `s` 和动作 `a`，初始化 `Q_h(s, a) = H`（因为总奖励的上界是H）。
    *   对所有状态 `s`，初始化 `V_{H+1}(s) = 0`。

2.  **主循环（对每个回合k=1, 2, ..., K）**：
    *   **步骤A：计算值的上置信界**。从 `h=H` 到 `h=1` 反向进行：
        *   如果状态-动作对 `(s, a, h)` 在数据集 `D` 中（即被访问过）：
            *   使用数据集中的经验计数 `N_h(s, a)` 和 `N_h(s, a, s')` 来估计经验转移概率 `\hat{P}_h(s'|s, a)`。
            *   执行带截断和奖励的贝尔曼更新：
                `Q_h(s, a) = min( H, r_h(s, a) + \hat{P}_h \cdot V_{h+1} + b(N_h(s, a)) )`
                其中奖励 `b(n)` 通常设计为 `b(n) = c * √(H^2 * ι / n)`，`ι` 是一个对数项（如 `log(SAT/δ)`）。
        *   否则（即未访问过）：
            *   保持 `Q_h(s, a) = H`。
        *   更新值函数：`V_h(s) = max_a Q_h(s, a)`。
    *   **步骤B：执行贪心策略并收集数据**。对每一步 `h=1` 到 `H`：
        *   选择动作 `a_h = argmax_a Q_h(s_h, a)`。
        *   执行动作，观察奖励 `r_h` 和下一状态 `s_{h+1}`。
        *   将轨迹元组 `(s_h, a_h, s_{h+1})` 添加到数据集 `D` 中。

你可以将此算法视为多臂老虎机UCB算法的MDP版本：我们为贝尔曼更新中的Q值添加奖励，然后根据这个加了奖励的Q值执行贪心策略。

## 理论保证与证明思路

在MDP中，我们定义K回合后的遗憾为：`Regret(K) = Σ_{k=1}^K [V_1^*(s_1^k) - V_1^{π_k}(s_1^k)]`。

UCB-VI算法的主要定理指出，以至少 `1-δ` 的概率，其遗憾上界为：
`Regret(K) ≤ O( √(H^3 S A T ι) + H^3 S^2 A ι^2 )`
其中 `T = K * H` 是总步数，`ι` 是对数项。主导项是 `O(√T)`，且关于H是多项式的，这比随机探索的指数级代价要好得多。

证明主要分为两步：

1.  **证明Q值是真实最优Q值的上界**。通过归纳法证明，关键在于我们设计的奖励 `b(n)` 足以覆盖经验转移概率估计的误差（由霍夫丁不等式控制）。这保证了 `Q_h^k(s, a) ≥ Q_h^*(s, a)` 以高概率成立。
2.  **遗憾分析**。利用上界性质，可以证明总遗憾大致上由访问过的状态-动作对所获得的奖励之和所界定，即 `Regret(K) ≲ Σ_{k, h} b(N_h^k(s_h^k, a_h^k))`。具体的求和计算较为繁琐，但最终可导出上述定理中的界。

奖励函数的设计至关重要。一个更紧的奖励（例如基于伯恩斯坦不等式而非霍夫丁不等式）可以进一步将遗憾中的 `H^3` 因子改进为 `H^2`。

## 组合锁问题的再审视

回顾那个难以探索的组合锁MDP，其中只有一条特定的动作序列能到达高奖励状态。随机探索找到它的概率是指数级小的。

然而，UCB-VI算法能更有效地解决它。算法从所有Q值等于H开始。当观察到非最优动作时，其Q值会因缺乏正向奖励而迅速下降（通过奖励项调整），从而被快速淘汰。这种动态规划式的方法能逐步排除错误动作，最终在多项式时间内找到最优路径。

## 更高效的算法：Q-learning with UCB

UCB-VI算法有一个计算上的缺点：每收集一条新轨迹，都需要对整个状态-动作空间进行一次完整的值迭代扫描，计算成本高。

为此，我们引入了基于UCB的Q-learning算法，它进行增量式更新，计算效率更高。以下是算法步骤：

1.  **初始化**：对所有 `(s, a, h)`，设 `Q_h(s, a) = H`，`N_h(s, a) = 0`。
2.  **对每个回合k**：
    *   接收初始状态 `s_1`。
    *   对每一步 `h=1` 到 `H`：
        *   选择动作 `a_h = argmax_a Q_h(s_h, a)`。
        *   执行动作，观察奖励 `r_h` 和下一状态 `s_{h+1}`。
        *   更新计数：`t = N_h(s_h, a_h) + 1`。
        *   **执行Q-learning更新**：
            `Q_h(s_h, a_h) ← (1 - α_t) * Q_h(s_h, a_h) + α_t * [ r_h + V_{h+1}(s_{h+1}) + b(t) ]`
            其中学习率 `α_t` 通常大于 `1/t`（以偏向近期更新，减少方差），奖励 `b(t)` 类似地为 `c * √(H^3 * ι / t)`。
        *   更新值函数：`V_h(s_h) = min(H, max_a Q_h(s_h, a))`。

这个算法是**无模型**的（无需显式估计转移概率 `P`），并且只更新访问到的状态-动作对，每回合计算量远小于UCB-VI。其遗憾界为 `O(√(H^4 S A T ι))`，比UCB-VI多一个 `√H` 因子，这是增量更新方差更大的代价，但在计算和存储上更具优势。

## 总结

本节课我们一起学习了强化学习中探索的核心方法。
*   我们首先认识到RL中探索的挑战性，并指出了简单方法的缺陷。
*   接着，我们详细介绍了**UCB-VI算法**，它通过向值迭代中添加精心设计的奖励项，实现了探索与利用的平衡，并获得了多项式级别的遗憾上界。
*   然后，我们探讨了理论保证背后的证明思路，即先证明值函数上界，再通过奖励之和来界定遗憾。
*   最后，我们介绍了计算上更高效的**UCB Q-learning算法**，它通过增量更新在计算复杂度和样本效率之间取得了不同的权衡。

这些算法为我们提供了在复杂环境中进行有效探索的强大工具。
