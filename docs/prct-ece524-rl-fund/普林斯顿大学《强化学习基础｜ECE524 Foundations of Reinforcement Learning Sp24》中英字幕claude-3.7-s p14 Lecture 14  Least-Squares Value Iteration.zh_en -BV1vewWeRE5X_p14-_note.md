## 课程回顾与线性MDP

上一节我们介绍了函数近似，并聚焦于最简单的线性函数近似。在线性函数近似中，最关键的是确保价值函数是线性的。为此，我们引入了一个充分条件——线性MDP。

线性MDP包含状态集、动作集、转移、奖励和范围等标准元素。其最重要的特性是奖励和转移都具有线性结构：
*   **奖励是线性的**：对于每一步 `h`，状态-动作对 `(s, a)` 的奖励等于某个已知特征映射 `φ_h(s, a)` 与未知参数 `θ_h` 的内积。
    **公式**：`r_h(s, a) = φ_h(s, a)^T θ_h`
*   **转移是线性的**：从 `(s, a)` 转移到下一个状态 `s'` 的概率（或测度）同样可以表示为 `φ_h(s, a)` 与某个未知测度 `μ_h` 的内积。
    **公式**：`P_h(s' | s, a) = φ_h(s, a)^T μ_h(s')`

在上节课的最后，我们讨论了如何为这种线性函数近似进行价值迭代。我们介绍的算法称为**最小二乘价值迭代**。其核心思想是，由于我们使用函数近似，无法精确求解贝尔曼方程，转而寻找一个线性价值函数，使其最小化与贝尔曼目标之间的平方损失。

## 最小二乘价值迭代算法

具体而言，我们使用线性函数来参数化Q值：`Q_h(s, a) ≈ φ(s, a)^T w_h`。参数 `w_h` 通过最小化以下平方损失来求解：

**公式**：
`w_h = argmin_w Σ_{i=1}^n [ φ(s_i, a_i)^T w - (r_i + V_{h+1}(s_i')) ]^2`

其中，我们假设已经收集了 `n` 个形式为 `(s_i, a_i, r_i, s_i')` 的数据元组。

为了找到最小化器，我们令目标函数 `J(w)` 的梯度为零。这导出了标准的最小二乘解：

**公式**：
`w_h = Λ^{-1} * (Σ_{i=1}^n φ_i * (r_i + V_{h+1}(s_i')))`
其中，`Λ = Σ_{i=1}^n φ_i φ_i^T`，`φ_i = φ(s_i, a_i)`。

需要注意的是，为了保证矩阵 `Λ` 可逆，在实践中可以加入一个小的正则化项，即使用 `Λ' = Λ + λI`。这等价于求解正则化的最小二乘问题：`min_w J(w) + λ||w||^2`。

表格型MDP是线性MDP的一个特例。当我们选择特征映射 `φ(s, a)` 为对应于每个 `(s, a)` 对的基向量（即 `e_{s,a}`）时，最小二乘价值迭代就退化为标准的表格型价值迭代。

## 核心集与高效数据收集

接下来，我们探讨该算法的理论保证。我们希望建立类似于表格型设置中模拟器访问的理论对应物，但现在是针对线性函数近似。

在表格型模拟器设置中，策略是查询所有可能的 `(s, a, h)`。然而，在状态空间巨大的函数近似场景中，这不再可行。我们需要一种方法来只查询一组有代表性的状态-动作对。

理想情况下，我们希望查询一组状态-动作对，其对应的特征向量能够张成整个特征空间。我们称这样的集合为**核心集**。

以下是核心集的正式定义。设核心集 `K` 包含 `d` 个状态-动作对 `(s_i, a_i)`，记其对应的特征向量为 `ψ_i = φ(s_i, a_i)`。定义矩阵 `Ψ` 为这些特征向量的并置：`Ψ = [ψ_1, ..., ψ_d]`。

核心集需要满足两个关键属性：
1.  **满秩**：矩阵 `Ψ` 是满秩的（秩为 `d`）。这意味着核心集的特征向量能够张成整个 `d` 维特征空间。
2.  **有界表示系数**：对于任何可行的状态-动作对 `(s, a)`，要求 `||Ψ^{-1} φ(s, a)||_1 ≤ L`。其中 `L` 是一个常数。这个条件意味着，任何特征向量 `φ(s, a)` 都可以用核心集特征向量的线性组合来表示，且组合系数的 `L1` 范数有界。这可以看作是要求核心集的特征向量不仅张成空间，而且彼此之间不能“太接近”，以保证表示的稳定性。

**备注**：
*   **存在性**：对于给定的特征向量集合，这样的核心集总是存在的，并且可以通过算法找到。
*   **直观理解**：第二个条件确保了任何特征向量都能用核心集以“小权重”线性表示。
*   **例子**：如果所有特征向量都在 `d` 维单纯形中（即每个分量非负且和为1），那么选择特征向量为标准基向量 `e_1, ..., e_d` 的集合就构成一个核心集。此时 `Ψ` 是单位矩阵，`L=1`。

## 基于核心集的最小二乘价值迭代算法

结合核心集的思想，完整的算法分为两部分：

**第一部分：数据收集**
对于所有步数 `h` 和核心集 `K` 中的所有状态-动作对 `(s, a)`：
1.  查询模拟器，获得 `n` 个从 `(s, a, h)` 出发的下一状态样本 `s_1', ..., s_n'`（为简化，假设奖励 `r` 已知）。
2.  将数据元组 `(s, a, r, s_i')` 存入数据集 `D_h`。

**第二部分：价值迭代（从最后一步 `H` 反向进行到第一步 `1`）**
对于每一步 `h`：
1.  **求解最小二乘问题**：使用数据集 `D_h`，求解参数 `w_h`，使得线性Q函数 `φ(·,·)^T w_h` 最小化贝尔曼残差。
    **代码/公式描述**：
    `w_h = argmin_w Σ_{(s,a,r,s') in D_h} [ φ(s,a)^T w - (r + V_{h+1}(s')) ]^2`
2.  **更新Q值和V值**：
    *   `Q_h(s, a) = φ(s, a)^T w_h`
    *   `V_h(s) = max_a Q_h(s, a)` （假设动作集有限或可以高效最大化）

这个算法可以看作是表格型模拟器价值迭代在线性函数近似下的推广，核心新增成分是**核心集**和**最小二乘价值更新**。

## 理论保证

本节中我们来看看算法的性能保证。

**定理**：如果对核心集中的每个状态-动作对查询 `n` 次样本，其中 `n` 满足：
`n ≥ C * L^2 * H^4 * (log(HD/δ)) / ε^2`
（`C` 为常数，`δ` 为置信度参数），那么，以至少 `1-δ` 的概率，算法输出的策略 `π_hat`（即 `Q_hat` 的贪婪策略）是 `ε-最优` 的。

**样本复杂度**：总样本数为步骤数 `H` × 核心集大小 `d` × 每对查询次数 `n`，即：
`总样本数 = O( H^5 * d * L^2 * log(HD/δ) / ε^2 )`

**关键点**：这个保证**不再依赖于状态数 `S` 和动作数 `A`**，而是依赖于特征空间的维度 `d` 和核心集的质量参数 `L`。这使我们能够处理超越表格设定的大规模或连续状态空间问题。

## 证明概要

证明的整体思路与表格型模拟器设置相似，但需要针对核心集和线性函数近似进行调整。以下是关键步骤的简化概述：

1.  **连接最小二乘解与贝尔曼方程**：将算法得到的Q值 `Q_h(s,a) = φ(s,a)^T w_h` 代入 `w_h` 的解中，并利用线性MDP的定义（奖励和转移的线性形式），可以将Q值重写为类似贝尔曼更新的形式，但其中的“经验转移”算子 `P_hat` 并非一个标准的概率分布（其系数可能为负）。
2.  **价值差分解**：与之前类似，最优价值 `V_1^*` 和算法价值 `V_1_hat` 之间的差异，可以分解为沿最优轨迹的转移差异之和的期望。
3.  **分析转移差异**：核心步骤是分析 `(P_h - P_hat) V_{h+1_hat}`。通过代入定义和核心集的结构，可以将这一项表达为 `φ(s,a)^T Ψ^{-1} ε`，其中 `ε` 是一个向量，其每个分量是对于核心集中某个特征方向，真实期望值与经验平均值的偏差（即 `ε_j = E[V|ψ_j] - (1/n)Σ_i V(s_{j,i}')`）。
4.  **应用集中不等式**：对于每个核心集方向 `j`，由于我们采样了 `n` 个独立下一状态，根据霍夫丁不等式，偏差 `ε_j` 以高概率有界：`|ε_j| ≤ O(H * sqrt(log(1/δ)/n))`。
5.  **结合核心集性质**：利用核心集的第二个性质 `||Ψ^{-1} φ(s,a)||_1 ≤ L`，以及霍尔德不等式，可以得出单个转移差异项以高概率有界：`|(P_h - P_hat) V_{h+1_hat}| ≤ O(L * H * sqrt(log(dH/δ)/n))`。
6.  **汇总并完成证明**：将 `H` 步的边界求和，并代入 `n` 的条件，可以证明 `|V_1^* - V_1^{π_hat}| ≤ ε`。证明的另一半（涉及 `V_1_hat` 和 `V_1^{π_hat}` 的差异）思路类似。

## 总结与展望

本节课中我们一起学习了线性函数近似下的最小二乘价值迭代算法。我们首先回顾了线性MDP的设定，它通过奖励和转移的线性结构确保了价值函数的线性。接着，我们介绍了算法的两个核心部分：1) 利用**核心集**进行高效、有代表性的数据收集；2) 使用**最小二乘法**来拟合线性价值函数，以最小化贝尔曼残差。

我们给出了算法的理论保证，其样本复杂度依赖于特征维度 `d` 和核心集参数 `L`，而非状态或动作的数量，从而能够突破表格型方法的限制。证明的关键在于利用核心集的线性表示性质和集中不等式来控制估计误差。
