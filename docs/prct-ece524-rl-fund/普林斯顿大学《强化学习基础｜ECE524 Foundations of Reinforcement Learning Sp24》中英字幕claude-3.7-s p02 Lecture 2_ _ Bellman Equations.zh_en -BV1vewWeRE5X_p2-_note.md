# 强化学习基础：第2讲：贝尔曼方程 🧠

在本节课中，我们将要学习马尔可夫决策过程（MDP）中的核心概念——贝尔曼方程。我们将首先回顾上一讲的内容，然后深入探讨如何计算策略的价值，以及如何利用贝尔曼方程找到最优策略。本节课的核心是理解动态规划的思想，并掌握贝尔曼方程及其最优形式。

---

## 回顾与设定

上一讲我们介绍了MDP的基本公式。简单回顾一下，当我们谈论MDP时，我们讨论以下元素：
*   状态集合 `S`
*   动作集合 `A`
*   奖励函数 `R`
*   转移概率矩阵 `P`
*   最终时间步长 `H`（在本课程中，我们主要讨论分幕式设定）

我们还讨论了环境和策略。环境通常指 `P` 和 `R`。今天我们首先讨论环境已知的情况，后续会讨论在未知环境中需要从观测数据中学习 `P` 和 `R` 的场景。

策略是第一个关键部分。我们主要讨论两种策略：
1.  **马尔可夫策略**：策略 `π` 由 `H` 个函数组成，每个函数将当前状态 `s` 映射到动作集 `A` 或其概率分布上（取决于策略是确定性的还是随机的）。其形式为 `π_h(a|s)`。
2.  **一般策略**：策略 `π` 在每个时间步的决策依赖于整个历史 `τ = (s1, a1, ..., s_h)`，而不仅仅是当前状态。

最后，我们讨论了价值函数。对于马尔可夫策略，状态价值函数 `V_h^π(s)` 定义为从步骤 `h`、状态 `s` 开始，遵循策略 `π` 所能获得的期望累积奖励。动作价值函数 `Q_h^π(s, a)` 则额外条件于初始动作 `a`。

需要注意的是，对于一般策略，其价值函数通常依赖于整个历史，而不仅仅是当前状态。然而，在第一步，由于没有历史，其价值 `V_1^π(s1)` 的定义与马尔可夫策略相同。

我们的最终目标是找到一个最优策略 `π*`，以最大化初始状态 `s1` 下的价值 `V_1^π(s1)`。

---

## 命题一：聚焦于马尔可夫策略

上一节我们介绍了两种策略。本节中我们来看看一个重要的结论，它允许我们在MDP中只关注马尔可夫策略，而不失一般性。

**命题一**：对于任何一般策略 `π`，都存在一个马尔可夫策略 `μ`，使得在初始状态 `s1` 下的价值相等，即 `V_1^π(s1) = V_1^μ(s1)`。

这个命题的直接推论是：**至少存在一个最优策略是马尔可夫策略**。因此，在后续关于MDP的讨论中，我们可以只关注马尔可夫策略。

### 证明概要

证明的核心思想是构造一个马尔可夫策略 `μ`，使其与一般策略 `π` 具有相同的“访问度量”，即访问每个状态-动作对的概率相同。

我们通过逆向归纳法来构造 `μ`。对于每个步骤 `h` 和状态 `s`，我们定义马尔可夫策略 `μ_h(a|s)` 为一般策略 `π` 在到达状态 `s` 的所有可能历史路径上，选择动作 `a` 的概率平均值。具体公式如下：

`μ_h(a|s) = ( Σ_{τ: s_h=s} P^π(τ) * π_h(a|τ) ) / P^π(s_h=s)`

其中，`P^π(τ)` 是遵循策略 `π` 产生轨迹 `τ` 的概率，`P^π(s_h=s)` 是第 `h` 步访问状态 `s` 的概率。如果分母为零（即策略 `π` 永远不会访问该状态），则 `μ_h(a|s)` 可以任意定义。

通过归纳法可以证明，按照此构造的马尔可夫策略 `μ` 与原始一般策略 `π` 在每个步骤访问每个状态-动作对的概率完全相同。由于价值函数是奖励关于访问度量的期望，因此两个策略的价值也必然相等。

---

## 符号约定与贝尔曼方程基础

在深入贝尔曼方程之前，我们先约定一些符号。我们考虑表格化设定，即状态和动作集合都是有限的。价值函数 `V_h^π` 可以看作一个维度为 `|S|` 的向量。类似地，`Q_h^π` 可以看作一个维度为 `|S| * |A|` 的向量。

我们引入一个简洁的符号来表示对下一状态价值的期望：
`[P_h V_{h+1}^π](s, a) = Σ_{s‘} P_h(s‘|s, a) * V_{h+1}^π(s‘)`
这个符号表示，从当前状态-动作对 `(s, a)` 出发，转移到下一个状态 `s‘`，并对 `s‘` 的价值取期望。

---

## 策略评估与贝尔曼方程 🔄

上一节我们确立了可以只研究马尔可夫策略。本节中我们来看看如何评估一个给定策略的好坏，即**策略评估**问题。

策略评估的问题是：给定已知的环境 `(P, R)` 和一个固定的策略 `π`，如何计算其初始价值 `V_1^π(s1)`？

一种朴素的方法是直接根据定义，枚举所有可能的轨迹并计算加权奖励和。但轨迹数量是 `(S*A)^H` 级别的，计算是指数级的，不可行。

关键在于利用MDP的马尔可夫结构，通过**动态规划**来高效计算。这引出了**贝尔曼方程**。

贝尔曼方程建立了不同步骤价值函数之间的递归关系：

1.  **状态价值与动作价值的关系**：
    `V_h^π(s) = Σ_a π_h(a|s) * Q_h^π(s, a)`
    这个方程说明，一个状态的价值是其所有可能动作价值的概率加权平均。

2.  **动作价值的递归定义**：
    `Q_h^π(s, a) = R_h(s, a) + [P_h V_{h+1}^π](s, a)`
    这个方程说明，一个状态-动作对的价值等于即时奖励加上下一状态的期望价值。

### 动态规划进行策略评估

利用贝尔曼方程，我们可以通过动态规划高效计算 `V_1^π(s1)`：

1.  **初始化**：设 `V_{H+1}^π(s) = 0`（因为第 `H` 步之后没有奖励）。
2.  **逆向迭代**：对于 `h = H, H-1, ..., 1`：
    *   使用方程2计算所有 `(s, a)` 的 `Q_h^π(s, a)`。
    *   使用方程1计算所有 `s` 的 `V_h^π(s)`。

这个过程的时间复杂度是 `O(H * S * A * S)`，是多项式级别的，远优于指数级的枚举法。

## 最优策略与贝尔曼最优方程 ⭐

仅仅评估一个策略是不够的，我们的目标是找到最优策略。本节我们探讨如何找到最优策略。

一个直观的想法是修改贝尔曼方程：既然最优策略应该选择最好的动作，那么是否可以将方程1中的“平均”`Σ_a π_h(a|s) * Q_h^π(s, a)` 替换为“最大”`max_a Q_h^*(s, a)` 呢？

![](img/27da8557347f45292b1139ea1b1c8753_1.png)

这引出了**贝尔曼最优方程**：

1.  `V_h^*(s) = max_a Q_h^*(s, a)`
2.  `Q_h^*(s, a) = R_h(s, a) + [P_h V_{h+1}^*](s, a)`

其中，`V_h^*` 和 `Q_h^*` 表示最优价值函数。与这些最优价值函数对应的**贪心策略** `π*` 定义为：
`π*_h(a|s) = 1, 如果 a = argmax_a‘ Q_h^*(s, a‘)；否则为 0`
（若有多个动作同时达到最大值，可任意打破平局）。

我们可以证明，这个贪心策略 `π*` 的价值函数恰好满足贝尔曼最优方程，即 `V_h^{π*} = V_h^*` 且 `Q_h^{π*} = Q_h^*`。

更重要的是，我们有：

**命题二**：由贝尔曼最优方程定义的策略 `π*` 是最优策略。并且，`V_h^*(s) = max_{π} V_h^π(s)` 对于所有步骤 `h` 和状态 `s` 同时成立。

这意味着 `π*` 不仅在初始状态是最优的，而且在所有状态、所有时间步都是同时最优的。

### 证明概要（逆向归纳）

证明使用逆向归纳法：
*   **基例**：在最后一步 `H+1`，`V_{H+1}^* = 0`，显然对所有策略都是最优的。
*   **归纳步骤**：假设对于步骤 `h+1`，`V_{h+1}^*` 是所有策略在 `h+1` 步的最优价值。
    1.  首先证明 `Q_h^*` 是最优动作价值。利用归纳假设，可以论证在贝尔曼最优方程中，最大化操作和期望操作可以交换顺序（因为最优策略 `π*` 在所有后续状态 `s‘` 上同时达到最优），从而证明 `Q_h^*` 确实等于所有策略中最大的 `Q_h^π`。
    2.  然后证明 `V_h^*` 是最优状态价值。通过将 `V_h^π` 表示为 `Q_h^π` 的加权平均，并利用上一步 `Q_h^*` 的最优性，可以证明 `V_h^*` 等于所有策略中最大的 `V_h^π`。

由此，归纳完成，命题得证。

## 总结

本节课我们一起学习了强化学习中的核心数学工具——贝尔曼方程。

*   我们首先通过**命题一**明确了在MDP中研究马尔可夫策略而不失一般性。
*   接着，我们定义了**策略评估**问题，并引入了**贝尔曼方程**，它通过递归关系 `V_h^π(s) = Σ_a π_h(a|s) * Q_h^π(s, a)` 和 `Q_h^π(s, a) = R_h(s, a) + E[V_{h+1}^π(s‘)]` 描述了策略的价值。利用该方程进行动态规划，可以高效计算策略价值。
*   最后，为了寻找最优策略，我们引入了**贝尔曼最优方程** `V_h^*(s) = max_a Q_h^*(s, a)` 和 `Q_h^*(s, a) = R_h(s, a) + E[V_{h+1}^*(s‘)]`，并证明了由其导出的贪心策略 `π*` 就是全局最优策略（**命题二**）。

![](img/27da8557347f45292b1139ea1b1c8753_3.png)

这些方程为我们在已知环境下的规划问题（即计算最优策略）奠定了理论基础。在下一讲中，我们将探讨具体的规划算法，并开始讨论更具挑战性的环境未知情况下的学习问题。
