# MIT 6.S087 生成式人工智能笔记 🧠

在本节课中，我们将要学习生成式人工智能的核心概念。我们将从基础的概率模型开始，逐步深入到现代生成模型，如变分自编码器和生成对抗网络。课程内容旨在为初学者构建清晰的知识框架。

## 1. 生成式人工智能基础

上一节我们介绍了课程概述，本节中我们来看看生成式人工智能的基本定义和目标。

生成式人工智能的目标是学习数据集的潜在概率分布，并能够从中采样以生成新的、类似的数据样本。这与判别式模型形成对比，后者主要学习给定输入条件下输出的条件概率分布。

核心任务可以形式化为：给定一个真实数据分布 `p_data(x)`，我们希望学习一个模型分布 `p_model(x; θ)`，使其尽可能接近 `p_data(x)`。

## 2. 核心概率概念

为了理解生成模型，我们需要回顾一些关键的概率论概念。

以下是几个必须掌握的基础概念：

*   **概率分布**：描述随机变量所有可能取值及其对应概率的函数。
*   **似然函数**：在参数估计中，用于衡量在给定参数下观察到当前数据的可能性，记作 `L(θ | x) = p(x | θ)`。
*   **最大似然估计**：一种参数估计方法，目标是找到能使观测数据似然性最大化的参数值 `θ_MLE = argmax_θ p(X | θ)`。
*   **KL散度**：衡量两个概率分布之间差异的非对称性度量，公式为 `D_KL(P || Q) = Σ_x P(x) log(P(x) / Q(x))`。

## 3. 自编码器

理解了概率基础后，我们引入一个重要的概念——自编码器，它是许多生成模型的前身。

自编码器是一种神经网络，用于学习数据的有效编码。它由两部分组成：编码器将输入数据压缩为潜在空间中的低维表示（编码），解码器则试图从这个编码中重建原始输入。

其训练目标是最小化重建误差，例如均方误差：`L_recon = ||x - decode(encode(x))||^2`。

## 4. 变分自编码器

自编码器的潜在空间通常是不规则且难以解释的。为了解决这个问题并使其具备生成能力，我们引入了变分自编码器。

VAE 是一种深度生成模型，它假设数据是由某个潜在变量 `z` 生成的。与普通自编码器不同，VAE 的编码器输出的是潜在空间上的一个概率分布（通常是高斯分布）的参数，然后从这个分布中采样得到 `z`，再由解码器重建数据。

VAE 的损失函数包含两部分：
1.  **重建损失**：确保解码后的数据与原始输入相似。
2.  **KL散度正则项**：迫使编码器产生的潜在分布 `q(z|x)` 接近先验分布 `p(z)`（如标准正态分布）。

总损失函数为：`L_VAE = L_recon + β * D_KL(q(z|x) || p(z))`。

## 5. 生成对抗网络

除了 VAE，另一个革命性的生成模型框架是生成对抗网络。它采用了截然不同的训练思想。

GAN 由两个相互对抗的神经网络组成：生成器 `G` 和判别器 `D`。生成器的目标是生成足以“欺骗”判别器的假数据，而判别器的目标是准确区分真实数据和生成器产生的假数据。

这个过程可以形式化为一个极小极大博弈，其价值函数为：
`min_G max_D V(D, G) = E_{x~p_data}[log D(x)] + E_{z~p_z}[log(1 - D(G(z)))]`。

## 6. 总结

本节课中我们一起学习了生成式人工智能的核心脉络。我们从概率基础出发，了解了自编码器如何学习数据表示，然后深入探讨了两种主流的深度生成模型：变分自编码器通过概率编码和正则化实现生成，而生成对抗网络则通过对抗训练让生成器与判别器共同进化。理解这些基础模型是探索更现代、更复杂生成式AI技术的关键。
