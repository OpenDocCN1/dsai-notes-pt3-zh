## Integral images

- The integral image computes a value at each pixel (x, y) that is the sum of the pixel values above and to the left of (x, y), inclusive.

## Computing the Integral Image

- The integral image computes a value at each pixel (x, y) that is the sum of the pixel values above and to the left of (x, y), inclusive.
- This can quickly be computed in one pass through the image.

## Boosting

- Boosting is a classification scheme that works by combining weak learners into a more accurate ensemble classifier
  - A weak learner need only do better than chance
- Training consists of multiple boosting rounds
  - During each boosting round, we select a weak learner that does well on examples that were hard for the previous weak learners
  - "Hardness" is captured by weights attached to training examples

> Y. Freund and R. Schapire. A short introduction to boosting. Journal of Japanese Society for Artificial Intelligence, 14(5):771-780, September, 1999.

## The AdaBoost Algorithm

```
Given: (x1,y1),...,(xm,ym) where xi ∈ X, yi ∈ {-1,+1}
Initialization: D1(i)=1/m i=1,...,m   [D_t is the probability distribution of x_i at time t]
For t=1,...,T
• Find classifier ht: X→{-1,+1} which minimizes error w.r.t. D_t i.e.
ht = argmin_h where ε_t = Σ D_t(i)[h(x_i) ≠ y_i]   [minimize weighted error]
• Weight classifier: α_t = ½ ln[(1-ε_t)/ε_t]   [larger weight for smaller error]
• Update distribution: D_{t+1}(i)= D_t(i)exp(-α_t y_i h_t(x_i))/Z_t   Z_t is for normalization
Note: misclassified patterns raise their weight for training
```

## Boosting

- Training set contains face and nonface examples
  - Initially, with equal weight
- For each round of boosting:
  - Evaluate each rectangle filter on each example
  - Select best threshold for each filter
  - Select best filter/threshold combination
  - Reweight examples
- Computational complexity of learning: O(M N K)
  - M rounds, N examples, K features
