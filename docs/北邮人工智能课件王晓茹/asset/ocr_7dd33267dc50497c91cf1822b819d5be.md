# 2.6 语义网络法

# 一 概念

语义网络是用图来表示知识，表示事物概念及语义关系。

+   - 节点：表示概念、实体、事物、事件等；
+   - 弧或链路：表示关系。

# 二 表示

+   1. 基本单元：<节点><语义关系><节点>
+   网络：<基本单元>组合
+   2. 表示基本事物和概念：

![](bbox=[0.58, 0.22, 0.92, 0.35])

3. 表示情况、动作、事件；
用一节点表示，拥有一组向外的弧，表示不同的情况。
例：小燕还只燕子从春天到秋天占有 一个窝：

![](bbox=[0.08, 0.48, 0.38, 0.65])

4. 连接逻辑关系
增加设合、取消取、增加设注。
例：与会者有男有女、有年老的、有年轻的。

![](bbox=[0.58, 0.48, 0.9, 0.68])

5.量化（部分网络）：网络分区与全称链
将复杂命题分解若干子问题，每一子问题用一简单的语义网络表示，称为一个子空间。多个子空间构成一个大空间。
例：每个学生都会有一首诗歌。

![](bbox=[0.1, 0.78, 0.42, 0.9])

# 二 求解

+   1. 继承推理；
+   语义联系上若能承含义，能有结构的继承。
+   2. 匹配；
+   构造问题的语义网络片段；
+   与存储的知识网络进行匹配求解。

例：
赵云是一个学生，在东方大学主修计算机专业。入学时间是2000年。
问题：
赵云主修什么专业？

6. 多元网络：一个节点有多向外的弧。
例：北朝鲜清华举行了一场足球比赛。比分是2：1。

7. 常见语义联系：
A member of 个体和集合
Composed of 构成
have 占有、拥有
Before, After, At 时间
Located_on 事物间相对关系
Similar to 比较
A Kind of 分类
Part 聚集、从属
