# Discrete and Continuous Attributes

+   Discrete Attribute
+   - Has only a finite or countably infinite set of values
+   - Examples: zip codes, counts, or the set of words in a collection of documents
+   - Often represented as integer variables.
+   - Note: binary attributes are a special case of discrete attributes

+   Continuous Attribute
+   - Has real numbers as attribute values
+   - Examples: temperature, height, or weight.
+   - Practically, real values can only be measured and represented using a finite number of digits.
+   - Continuous attributes are typically represented as floating-point variables.

# 2. Record Data 记录数据

数据集是记录records（数据对象）的汇集，每个记录包含固定的数据项或属性集。记录数据通常放在平展文件或关系数据库中。数据挖掘一般不在关系数据库上挖掘。

# Asymmetric attribute 非对称的属性

对于非对称的属性(asymmetric attribute)，出现非零属性值才是最重要的。
例如：
大学的选课记录数据集中，数据集的对象是每个学生，每个学生记录了学生是否选了某个课程。
对于每个学生，如果选修了对应属性的课程，则对应属性取值为1，否则为0。
由于学生只选修了可选课程的很小一部分，则这种数据集的大部分值都是0。
因此，关注非零值将更有意义，更有效。
如果在不选修的课程比较，则大部分学生都是相似的。

# 1. Important Characteristics of Structured Data

+   Dimensionality (维度)
+   - 是数据集中对象具有的属性的数目
+   - 低维度数据特征与中、高维度数据有质的不同
+   - Curse of Dimensionality (维度诅咒) 使降维的 (dimensionality reduction) 变得更加必要
+   Sparsity (稀疏性)
+   - 对象具有非常稀疏的数值数据报，一个对象大部分属性的值都为 0，如非零属性只有1%
+   - 稀疏性对于存储和处理是非非常有利的
+   Resolution (分辨率)
+   - 可以在不同的分辨率下得到数据，并且在不同分辨率下数据的性质也不同。
+   - 数据的模式依赖于分辨率，如果模式太小，模式可能看不出来，或者被噪声所掩盖，如果数据太粗糙，可能就不显现出来。

# Data Matrix 数据矩阵

如果数据集中所有的数数据对象具有相同的数值型属性集，则数据集可以看作多维空间中的点(向量)，其中每维代表对象的同一个属性。
数据集对象集合可以用一个m×n的矩阵表示，一行一个对象，一列一个属性。
