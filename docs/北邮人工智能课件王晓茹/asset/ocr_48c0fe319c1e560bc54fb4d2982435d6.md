# The AdaBoost Algorithm

What goal the AdaBoost wants to reach?

Given \(\{x_i,y_i\}_{i=1}^N\), where \(y_i\in\{-1,+1\}\). Initialize distribution \(D_1(i)=1/N\). For \(t=1,\ldots,T\): find classifier \(h_t\), weight classifier \(\alpha_t\), and update distribution. Output final classifier: \(\operatorname{sign}(H(x))=\operatorname{sign}\left(\sum_t\alpha_t h_t(x)\right)\).

# Goal

Minimize \(loss_{exp}[H(x)] = E_{x,y}[e^{-yH(x)}]\)

Final classifier: \(\operatorname{sign}(H(x))=\operatorname{sign}\left(\sum_t\alpha_t h_t(x)\right)\)

# \(\alpha_t=?\)

Define \(H_t(x)=H_{t-1}(x)+\alpha_t h_t(x)\), with \(H_0(x)=0\). Then, \(H(x)=H_T(x)\).

Set \(\frac{\partial}{\partial\alpha_t}E_{x,y}[e^{-yH_t(x)}]=0\), hence \(E_x[e^{-H_{t-1}(x)}(-e^{-\alpha_t}P(y=h_t(x))+e^{\alpha_t}P(y\ne h_t(x)))] = 0\).

# \(\alpha_t=?\)

Define \(H_t(x)=H_{t-1}(x)+\alpha_t h_t(x)\), with \(H_0(x)=0\). Then, \(H(x)=H_T(x)\).

\(\alpha_t=\frac12\ln\frac{P(y=h_t(x))}{P(y\ne h_t(x))}=\frac12\ln\frac{1-\epsilon_t}{\epsilon_t}\), where \(\epsilon_t=P(error)=\sum_iD_t(i)[y_i\ne h_t(x_i)]\).

# \(\alpha_t=?\)

Final classifier: \(H(x)=\sum_t\alpha_t h_t(x)\)

The distribution update is proportional to \(D_{t+1}(i)=D_t(i)e^{-\alpha_t y_i h_t(x_i)}\), with normalization.

# \(D_{t+1}=?\)

Update distribution: \(D_{t+1}(i)=\frac{D_t(i)e^{-\alpha_t y_i h_t(x_i)}}{Z_t}\), where \(Z_t\) is the normalization factor.
