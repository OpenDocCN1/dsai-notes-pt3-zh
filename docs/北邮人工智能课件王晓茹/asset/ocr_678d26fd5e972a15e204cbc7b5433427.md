# （1）定类数据：众数（mode）

+   - 出现次数最多的变量值
+   - 用M0表示
+   - 不受极端值的影响
+   - 可能没有众数或有几个众数
+   - 主要用于定类数据，也可用于定序数据和数值型数据

# 众数的非唯一性

无众数 原始数据：10 5 9 12 6 8

一个众数 原始数据：6 5 9 8 5 5

多于一个众数 原始数据：25 28 28 36 42 42

# 众数的例子

| 例子 某家公司对其客户对各类广告的偏好分布 |
| 广告类别 | 人数(人) | 比例 | 百分比(%) |
| 商品广告 | 112 | 0.56 | 56.0 |
| 服务广告 | 51 | 0.255 | 25.5 |
| 企业广告 | 9 | 0.045 | 4.5 |
| 娱乐广告 | 18 | 0.09 | 9.0 |
| 其他广告 | 10 | 0.05 | 5.0 |
| 合计 | 200 | 1 | 100 |

解：这里的变量为“广告类型”，这是个定类变量，不可按大小排列其所观察值。我们看到，在所调查的200人当中，关注商品广告的人数最多，为112人，占总人数的56%，因此众数为“商品广告”这一类别，即 M0=商品广告

# （2）定序数据：中位数（median）

+   - 排序后处于中间位置上的值
+   - 用Me表示
+   - 不受极端值的影响
+   - 主要用于定序数据，也可用于数值型数据，但不能用于定类数据
+   - 各变量值与中位数的离差绝对值之和最小，即 Σ|xi - Me| 最小

# 中位数

中位数位置 = (N+1)/2
Me = { X[(N+1)/2] 当N为奇数时
1/2 ( X[N/2] + X[(N+1)/2] ) 当N为偶数时 }

# 中位数的例子(定序数据)

| 例子 某城市家庭对电视广告满意程度频数分布 |
| 满意类别 | 户数(户) | 累计频数 |
| 非常满意 | 24 | 24 |
| 不满意 | 108 | 132 |
| 一般 | 93 | 225 |
| 满意 | 45 | 270 |
| 非常满意 | 30 | 300 |
| 合计 | 300 | — |

解：中位数的位置为：300/2=150 从累计频数看，中位数在“一般”这一组别中。因此，Me=一般

# 中位数的例子(数值型数据)

+   - 原始数据：24 22 21 26 20
+   - 排 序：20 21 22 24 26
+   - 位 置：1 2 3 4 5

位置 = (N+1)/2 = (5+1)/2 = 3
中位数 = 22

# 中位数的例子(数值型数据)

+   - 原始数据：10 5 9 12 6 8
+   - 排 序：5 6 8 9 10 12
+   - 位 置：1 2 3 4 5 6

位置 = (N+1)/2 = (6+1)/2 = 3.5
中位数 = (8+9)/2 = 8.5
