# 五、面向对象知识表示与语义网络、框架的比较

（1）皆为结构化的知识表示方法，面向对象知识表示法最结构化：

（2）语义网络中的节点对应于面向对象中的对象，有向弧定义的语义关系可对应于对象间的消息传递，实例联系等可对应对象、类、子类之间的继承关系。

语义网络由于开发和维护较简单，对象的增加、网络的维护和属性的修改变得困难，而面向对象的封装能力一定程度发展。

（3）框架和面向对象的表示很类似，可以使用类的概念按一定的层次结构进行组织。

框架知识表示的模块性不能简捷地定义；框架之间的关系既可能是具有继承关系的子类连接和成员连接，也可能是全体和部分关系的组成连接；规则可以通过一个框架到另一个框架；

面向对象的表示中，两个类之间的连接关系只有子类连接；规则用作一个类的内部方法，不会出现跨越两个对象的规则；通过消息传递进行。
