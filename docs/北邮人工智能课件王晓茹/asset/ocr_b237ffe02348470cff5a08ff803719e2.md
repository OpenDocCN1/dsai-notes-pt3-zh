# 四 特点

# 1. 优长：

联想性，体现联想思维结构；
自然性，表现问题直观，利于理解；
结构性，结构化的知识表示方式。

# 2. 缺点：

非严格性，无统一公认的形式表示体系；
处理复杂性；
对时间相关知识、深层知识或与时间相关动态知识不善于表达。

# 2 框架网络

+   (1) 框架间联系：
+   框架中值域和槽值是另一个框架的名字，例如教师框架、
+   作业框架、工作框架等之间的调用。
+   (2) 纵向联系：
+   用继承来建立纵向联系，下层框架可以继承上层框架的值。
+   例如教授工作框架和数学教师框架之间。

# 2.7 框架表示法

# 一 构成

+   1. 框架提供一种结构和组织，描述一种格式相对固定的语义网络的节点和槽。
+   以框架作为基本单位，语义网络可看作框架集合。
+   2 构成：
+   框架名
+   槽
+   侧面
+   值
+   约束条件

# 二 表示

+   1 挂本描述
+   例：智商齐商品的描述。
+   框架名：<购买商品>
+   槽——商品名称；
+   生产厂家；
+   出售商店；
+   存放；
+   侧面——
+   购买方式；
+   购买时间：年 月 日
+   送货时间；
+   填值：对于定义的框架填入具体的信和值，得到相应框架的实例框架

# 3 槽、侧面的设置和组织

+   (1) 充分表达各方面的属性
+   (2) 充分表达相关事物之间的关系。常见规则：
+   ISA：框架间关系，是一个、一类、一种；
+   AKO：具体类属关系，是一种；
+   Subclass：子类、子集；
+   Instance：AKO的逆关系，指某一下层框架；
+   Part of. 部件与全部的关系。
+   Infer：表示两框架之间的隐含关系，蕴涵、条件与结论；
+   (3) 对框架和面进行合理的组织
+   共同相联、适合于的槽
+   (4) 有利于进行解释和推理
