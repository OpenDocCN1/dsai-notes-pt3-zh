# 1、K-均值算法

k-means算法，也被称为k-平均或k-均值，是一种得到广泛使用的聚类算法。相似度的计算根据一个簇中对象的平均值来进行。

+   1) 首先将所有对象随机分配到k个非空的簇中。
+   2) 计算每个簇的平均值，并用该平均值代替相应的簇。
+   3) 根据每个对象与各个簇中心的距离，分配给最近的簇。
+   4) 然后将第二步，重新计算每个簇的平均值。这个过程不断重复直到满足某个准则或迭代次数停止。

# 算法 k-means算法

输入：k做为数目和包含n个对象的数组。
输出：k个簇，使方差准则函数最小。

+   (1) assign initial value for means: 任意分配给k个对象作为初始的平均值

+   (4) FOR i=1 to k DO x̄_i = (1/|C_i|) Σ_{x∈C_i} x  //更新平均值
+   (5) Compute E = Σ_{i=1}^k Σ_{x∈C_i} ||x - x̄_i||^2  //计算误差函数E
+   (6) UNTIL E不再明显地变化。
