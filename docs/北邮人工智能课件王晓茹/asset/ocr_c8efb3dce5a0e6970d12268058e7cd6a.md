# 2、k-中心点算法（k-medoids）

# PAM算法特点

+   - 比k-means健壮，但对于大数据集效率不高。
+   - 当存在“噪声”和离群数据时，k-中心点方法比k均值方法具有更强的处理噪声的能力，这是因为中心点不像平均那样容易被离群数据影响。
+   - k-中心点方法的执行代价比k-平均高。

以TCAE为例说明计算过程：
a) 当A被替换以后，A不再是一个中心点，因为A离B比离A更近。
b) A被分配到中心点B所在的簇，CAE=d(A,B)-d(A,A)=1。
c) B原来在中心点B所在的地方，当A被替换以后，C不再是中心点，C被分配到中心点A所在的簇，CAE=d(C,A)-d(C,B)=0。
d) D原来在A中心点所在的地方，当A被替换以后，D离最近的中心点是C，根据PAM算法代价函数的第二种情况CAE=d(D,C)-d(D,A)=1-2=-1。
e) E原来在B中心点所在的地方，当A被替换以后，离E最近的中心点仍然是B，根据PAM算法代价函数的第三种情况CAE=0。因此，TCAE=CAE+CB...=0+0-1+0= -2。

# 改进算法

+   - CLARA(Clustering Large Applications),1990
+     用较大数据的抽样来替代整个数据集，然后再在这些抽样的数据集上利用K-medoids算法得到最终的中心点。
+     如果样本是以非随机的方选取，它应当足以代替原来的数据集集合。从中选出的代表对象（中心点）很可能与从整个数据集选出的代表相似。

# 改进算法

CLARANS（“随机化的”CLARA），1994
利用多次不同抽样来改进CLARA。
其聚类过程可以被描述为对一个图的搜索过程，图中每一个节点都是一一个簇在的集合。即使中心点是集合。在替换了一个中心点后得到的聚类被发现为聚类结构较好的局部，如果一个更优的邻居被发现，也就意味着它有更好的平方误差值，clarans移动该邻居节点，处理过程重新开始，如果没有发现更好的邻居，则达到局部最优。

# 七、层次聚类方法

+   - 层次聚类方法对给定的数据集进行层次的分解，直到某种条件满足为止。其主要可分为：
+     ■聚类的层次聚类：一自底向上或自顶向下。
+     ■分离的层次聚类：采用自顶向下的策略，它首先将所有对象置于一个簇中，然后逐渐细分为越来越小的簇，直到达到某种结束条件。
+     ■层次聚类的代表是AGNES算法。层次分裂的代表是DIANA算法。
