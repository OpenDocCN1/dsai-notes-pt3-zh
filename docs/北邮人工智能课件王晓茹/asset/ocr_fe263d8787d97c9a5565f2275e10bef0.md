# 线性回归

代价函数 (Cost Function)：
J(θ₀,θ₁)=1/(2m)∑(hθ(x⁽ⁱ⁾)-y⁽ⁱ⁾)²
其中
J(θ₀,θ₁)表示代价函数的元素
hθ(x⁽ⁱ⁾)表示模型的预测值
y⁽ⁱ⁾表示真实值
m表示训练的数目

代价函数与参数的关系：J(θ₀,θ₁)=1/(2m)∑(hθ(x⁽ⁱ⁾)-y⁽ⁱ⁾)²
注意：如果假设函数只有一个θ₀,θ₁，则cost function J(θ₀,θ₁)的图形是一条碗状，
即只有一个最小值。

# 线性回归

一般情况：x⁽ⁱ⁾∈Rⁿ
h_θ(x)=θ₀+θ₁x₁+...+θₙxₙ
J(θ)=1/(2m)∑(hθ(x⁽ⁱ⁾)-y⁽ⁱ⁾)²
最小二乘法求解
min_θ J(θ)
要点：
> 最小二乘法 θ=(XᵀX)⁻¹Xᵀy
> 是一个直接的数学公式，不过要复杂到矩阵运算的。
> 梯度下降法。

Gradient Descent (梯度下降)
找到cost function的最小值；
梯度下降法：梯度下降法是一种迭代法，假设我们在一个山坡上，往下走，从最陡的方向向下走一步，重复直到最低点。
方法：
(1) 先确定一个学习率α，取一个learning rate；
(2) 每次有一个θ值，θ值；
(3) 每次迭代更新θ值，同时计算cost function，并更新θ；
(4) 当梯度下降到小于某个值时，停止迭代。

# 线性回归的梯度下降算法

梯度下降算法：
repeat until convergence
θ_j := θ_j - α ∂/∂θ_j J(θ)
simultaneously update
temp0 := θ₀ - α ∂/∂θ₀ J(θ)
temp1 := θ₁ - α ∂/∂θ₁ J(θ)
θ₀ := temp0
θ₁ := temp1
特点：
(1) 梯度不为零，算法的收敛速度不快，因此梯度下降法的其它最优化方法小。
(2) 选择合适的α，下降速度更快。

梯度下降算法：
问题：如何确定局部最小值(local minimum)的位置，梯度下降法如何？
如果我们从一个点开始，cost function会下降到一个局部最小值。
如果我们选择一个正的α，cost function会逐渐下降到局部最小值。
要点：
要找到最小值，cost function J(θ₀,θ₁) 的值，随着迭代次数的增加，会逐渐下降到一个最小值。
