引入四维变量（x,y,z）

w：表示猴子所处的位置；
x：猴子是否在台子上（x=1在，x=0不在）；
y：箱子所处的水平位置；
z：猴子是否拿到香蕉（z=1拿到，z=0没有拿到）；

引入操作集：

goto(u)：(w,0,y,z) → (u,0,y,z)
pushbox(v)：(w,0,w,z) → (v,0,v,z)
climbbox：(w,0,w,z) → (w,1,w,z)
grasp：(c,1,c,0) → (c,1,c,1)

# 2.3 与或树表示

+   - 问题归约法
+     1. 方法：已知问题描述，通过一系列变换把问题最终变为一个可归题集合，并可以直接求解，解决初始问题。
+     2. 构成：
+        （1）初始问题描述；
+        （2）分解/转换的规则/操作符；
+        （3）本原问题描述：具有明显解答，已解决的问题等。

# 二 与或图

用类似图的结构来表示把问题归约为后继问题的替换集合。

+   1  与图：将复杂的大问题分解为一组简单的小问题；
+   
+   2  或图：将复杂的大问题变换为等价或等效的问题；

![](bbox=[0.171, 0.595, 0.267, 0.704])

+   3  构成：
+      初始节点：原始问题
+      终叶节点：本原问题，无后裔
+      与节点：子问题对应的节点为与逻辑
+      或节点：子问题对应的节点为或逻辑
+   
+   4  可解节点：
+      （1）终叶节点为可解节点；
+      （2）非终叶节点为或节点，后继节点中至少有一个为可解节点；
+      （3）非终叶节点为与节点，后继节点全部为可解节点。

+   5  不可解节点
+      （1）没有后继的非终叶节点；
+      （2）或节点其后继节点全部为不可解节点；
+      （3）与节点其后继至少有一个为不可解节点；
