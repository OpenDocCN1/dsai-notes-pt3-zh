# 估价函数

估价函数定义如下：
一般形式为：f(n) = g(n) + h(n)
f为估价函数，f(n)按启发式搜索中节点的估价值排序。
g(n)表示从初始节点到n实际代价。
h(n)是启发式估计从节点n到目标节点的估计代价，利用到领域的信息等。

例如用f(n)对OPEN表上节点进行排序，选择其最大最小值节点作为下一个搜索节点。

# 有搜索策略

又称启发式搜索。
自此搜索的几种方法也可以看成有界搜索的特例。

例：八数码棋，定义估价函数：
f(n)=d(n)+w(n)
d(n)为搜索树中节点的深度，
w(n)用以计算节点n对应于目标状态错放的棋子数。

# 3.3 与或树搜索策略

# 一 与或树一般搜索策略

+   1 可解标记过程：由可解的子节点确定其父，祖节点可解。〈依据可解标记定义〉
+   2 不可解标记过程：由不可解的子节点确定其父，祖节点不可解。
+   3 解树：由初始节点和目标节点可解的子节点构成。
+   4 一般搜索过程：

深度优先：深度小优先；
深度优先：深度深优先。

局部优先搜索（深度）：对邻域的当前节点按代价大小排序；
全局优先搜索（宽度）：对OPEN表中所有节点按代价大小排序。

对于的选择，没有合适的价值的衡量标准，则：
① 时间和空间之间的折衷。
② 搜索后一最佳解或最差解。

解的三种情况：
① 求解最佳〈最小代价〉解。
② 当没有解可找到时，满意解。值域与最佳值很难确定。
③ 找到一个解即可。
