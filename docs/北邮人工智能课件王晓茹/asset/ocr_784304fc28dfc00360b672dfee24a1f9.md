# 2、k-中心点算法（k-medoids）

+   - 也称PAM算法（Partitioning Around Medoids）\n  基于有代表性的数据（中心点），而不是均值代表每个簇。\n- 思路\n  1. 为每个簇随机选择一个代表对象（中心点）；\n  2. 剩余的对象根据其与代表对象的距离分配给与其最近的一个簇；\n  3. 反复使用非代表对象来替换代表对象，以提高聚类的质量，直至找到最合适的中心点。

![](bbox=[0.027, 0.257, 0.337, 0.481])

一个数据的替代代价 Cᵢₕ：用 h 代替 i 后，到中心点距离的变化。计算用非代表对象替换代表对象的总代价：Cᵢₕ = ∑ Cᵢₕ。

为了判定一个非代表对象 Oₕ 是否是当前一个代表对象 Oᵢ 的好的替代，对于每一个非中心点对象 Oⱼ，下面的四种情况被考虑：\n✓ 第一种情况：Oⱼ 当前隶属于中心点对象 Oᵢ。如果 Oₕ 被 Oᵢ 代替作为中心点，且 Oⱼ 离另一个最近的中心点 Oₘ，那么 Oⱼ 被重新分配给 Oₘ。\n✓ 第二种情况：Oⱼ 当前属于一个非代表对象 Oₕ。如果 Oₕ 代替作为一个中心点，且 Oⱼ 离 Oₕ 最近，那么 Oⱼ 被重新分配给 Oₕ。\n✓ 第三种情况：Oⱼ 当前隶属于 Oₘ，m≠i。如果 Oₕ 被 Oᵢ 代替作为一个中心点，而 Oⱼ 离 Oₕ 最近，那么 Oⱼ 被重新分配给 Oₕ。\n✓ 第四种情况：Oⱼ 当前隶属于 Oₘ，m≠i。如果 Oₕ 被 Oᵢ 代替作为一个中心点，且 Oⱼ 离 Oᵢ 最近，那么 Oⱼ 被重新分配给 Oₘ。

```

```

# 2、k-中心点算法（k-medoids）

+   - PAM作为最早提出的k-中心点算法之一，它选用簇的中心点作为对象作为代表对象，试图不对对象给出k个划分。\n- 代表对象也被称为是中心点，其他对象则被称为非代表对象。\n- 最初随机选择k个对象作为中心点，该算法反复地用非代表对象来代替代表对象，试图找出更好的中心点，以改进聚类的质量。\n- 在每次迭代中，所有可能的对象都被分析，每个对象中的一个对象是中心点，而另一个是非代表对象。\n- 对可能的各种组合，估算聚类结果的质量。一个对象 Oᵢ 可被产生最小平方误差的对象代替。在一次迭代中产生的最佳对象集合成为下次迭代中的中心点。

![](bbox=[0.556, 0.277, 0.951, 0.477])
