# 1. 数据对象

+   - 数据集由数据对象组成
+   - 一个数据对象代表一个实体
+   - 例子：
+     - 销售数据库 sales database: 客户/顾客、商店/商品、sales
+     - 医学数据库: patients, treatments
+     - 大学数据库: students, professors, courses
+   - 又称为 样本、事例、实例、数据点、对象、元组 tuples。
+   - 数据对象由属性来描述
+   - Database rows -> data objects; columns ->attributes.

# 属性

+   - 属性(Attribute)（or维度、特征、变量）：一个数据字段，表示一个数据对象的某个特征。
+     - E.g., customer_ID, name, address
+   - 类型：
+     - 标称属性，或名词性属性，Nominal attribute
+     - 二元属性，Binary attribute
+     - 数字属性，Numeric attribute
+       - 区间属性，Interval-scaled
+       - 比率标度属性，Ratio-scaled
+     - 序数属性，Ordinal attribute

# 2. 属性类型——名词属性

+   - 标称属性，名词属性，Nominal：
+     - 属性的值是一些符号或事物的名称。每个值代表某种类别、编码或状态，因此标称属性有着看作是分类的（categorical）。
+     - 属性的值不具有有意义的序，因为是无序的，或是枚举的（enumeration）。
+     - 属性的值没有数学运算的意义，即均值、中位数等没有意义。
+   - 举例：类别、状态，or“名目”
+     - Hair color = {auburn, black, blond, brown, grey, red, white}
+     - 婚姻状态 = {单身、结婚、离异、丧偶}
+     - Customer_ID = {0001, 0001, ……}
+     - zip codes

# 2. 属性类型——二元属性

+   - 二元属性，Binary attribute
+     - 有亦属性的名词性属性：
+       - 只有2个状态的名词属性（0 and 1）
+     - 对称二元，Symmetric binary
+       - 同样重要的两种状态
+       - e.g., gender
+     - 非对称，Asymmetric binary
+       - 非同等重要的状态
+       - e.g., 医疗检查（positive vs. negative）
+       - 惯例Convention: assign 1 to most important outcome (e.g., HIV positive)

# 2. 属性类型——序数属性

+   - 序数属性，Ordinal attribute
+     - 属性值之间具有有意义的序或级别（ranking），但相继值之间的差是未知的
+       - e.g., drink_size: 大、中、小
+       - e.g., grade: A+, A-, A, B+, B+
+     - 对于记录不能具有有意义的主观质量评估，使用序数属性，如等级评定调查
+       - e.g., 顾客满意度
+     - 数值属性的离散化：
+       - 将某种属性的数值量划分成有限个有序类别。
+       - 称称，二元和序数属性都是定性的，他们描述数据对象的特征，而不将给出实际的大小或数量，是一种代表类别的词。

# 属性类型——数值属性

+   - 数值属性（Numeric attribute）
+     - 是定量的，是可度量的量，通常数或实数值表示；
+     - 分别区间标度或比率标度
+   - 区间（Interval-scaled）
+     - 用相等的单位度量
+     - 属性值有序，可以为正、零、负。
+     - 没有真正的零点，无法计算倍数
+     - e.g., temperature in ℃ or ℉；calendar dates
+   - 比率标度属性（Ratio-scaled）
+     - 有真正的零点，被测量单位一个数量级（10 K is twice as high as 5 K）。
+     - e.g., 温度在开尔文；长度；计数；货币等
+     - 工作年限，字数，重量，高度，速度，盛度，所量等
