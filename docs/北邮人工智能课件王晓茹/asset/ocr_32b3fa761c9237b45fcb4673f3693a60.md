# 第三章　问题求解

问题求解：在知识表达的基础上，进行机器思维，求解问题，是知识利用的基础。

推理技术：问题求解（从初始状态到目标状态）的方法和途径。
与知识表达技术密切相关。
图搜索方法：基于图的知识表达。从图中相当于初始状态的出发到相当于目标状态的终止节点的路径搜索过程。
广度优先搜索，深度优先搜索……
逻辑论证法：基于谓词逻辑或其他形式逻辑方法的知识表达。
不确定性推理
非单调推理

推理方法：
是否充分：
　推理算法：推理过程完备，能找到解。
　推理步骤：推理过程不完备，不一定能求得问题的解。
是否加入启发性知识：
　启发发理：在推理过程中，运用与问题有关的启发性知识，即解决问题的策略、技巧、窍门，对问题的特性及规律的估计等实践经验和知识，加快推理过程，提高搜索效率。
　非启发推理：在问题求解的推理过程中，不运用启发性知识，只按一般的逻辑法则或控制性知识，进行通用性的推理。

# 3.1 一般搜索原理

# 一般性图搜索策略

+   1. 图搜索：在图中寻求从初始状态到目标状态的路径。
+   2. 盲目搜索：无信息搜索，非启发性搜索。
+   3. 搜索策略：
+      （1）相关数据结构及概念：
+      - OPEN表：用于存放刚生成的节点。
+      - CLOSED表：用于存放已经扩展或已扩展的节点。
+      - 扩展：用定义的算子或算符对节点进行操作，生成子节点。
+      - 指针：用以记录节点被扩展的路径，反向指向父节点。
+      - 搜索图：通过搜索所得的图。
+      - 搜索树：由搜索图中所有节点及反向指针所构成的集合。

# 宽度优先搜索

搜索按层进行，在对下一层节点进行搜索之前，必须搜索完本层所有的所有节点。

![](bbox=[0.13, 0.58, 0.43, 0.73])

# 深度优先搜索

搜索按深度进行，首先扩展最新产生的节点。

![](bbox=[0.63, 0.58, 0.88, 0.73])

有界深度优先搜索：
深度优先搜索不完备，可能陷入无限深度中，引入搜索深度界限。

# 3.2 启发式搜索

# 一、思想

找到一种有效的方法处理当前（非均匀扩展节点），利用问题本身的特性进行扩展，提高搜索效率。
有信息搜索。
有向搜索：选择具有希望的节点作为扩展节点。
通过定义某一衡量标准决定扩展程度。

（1）决定要扩展的下一个节点；
（2）生成哪一个或哪几个后继节点；
（3）决定从搜索树中选择或修剪节点。
