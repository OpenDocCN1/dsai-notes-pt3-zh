# 怎样获得不同的弱分类器？

+   - 使用不同的弱学习算法得到不同基学习器参数估计、非参数估计……
+   - 使用相同的弱学习算法，但用不同的超参数：K-Mean不同的K，神经网络不同的隐含层……
+   - 相同输入对象的不同表示：不同的表示可以显现物体的特征
+   - 使用不同的训练集：装袋（bagging）、提升（boosting）

# 怎样组合弱分类器

+   - 多专家组合
+     一种并行结构，所有的弱分类器结合出各自的预测结果，通过“组合器”把这些预测结果转换为最终结果。eg. 投票（voting）及其变种、混合专家模型
+   - 多级组合
+     一种串行结构，其中下一个分类器只在前一个分类器预测不够优（不够自信）的实例上进行训练或检测。eg. 级联算法（cascading）

# 弱学习小结

+   - bagging在给定样本上随机抽取（有放回）训练子集，每个训练子集上用不稳定的学习算法训练分类器
+   - boosting在前一个弱分类器错分的实例在后续的弱分类器上得到更大权重
+   - 从训练子集的获取方式上看：bagging常“运气”，boosting有“依据”

# AdaBoost的先验知识

1990年，Schapire最先将弱通过一种多项式复杂度的算法，明显优于Boosting算法。这样带来的弱分类器可以逐步聚焦难以被正确分类的数据集。一年后，Freund提出了一种效率更高的Boosting算法。1993年，Drucker和Schapire等人以构造网络的方式为弱学习器建立多个分类器的ORC问题。由于Boosting算法最终能够构造出强分类器，因此AdaBoost算法在实际应用中表现良好。

# 原理

+   - AdaBoost的核心思想
+     “关注”被错分的样本，“聚重”性能好的弱分类器
+   - 怎么实现
+     （1）不同的训练集→调整样本权重
+     （2）“关注”→增加错分样本权重
+     （3）“聚重”→好的分类器权重大
+     （4）样本权重间接影响分类器权重
