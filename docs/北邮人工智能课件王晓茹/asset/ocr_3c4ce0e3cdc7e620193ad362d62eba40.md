# 3.1 最小二乘学习法

+   - 最小二乘学习法是对模型的参数fθ(X)和训练集的输出{y_i}_{i=1}^n 的平方误差
+   - J_LS(θ)=1/2∑_{i=1}^n (f_θ(X_i)-y_i)^2 (3.1)
+   - 为最小化时参数θ进行作用 θ_LS = arg min_θ J_LS(θ)
+   - 因此，最小二乘学习法也称为L2损失最小化学习法。
