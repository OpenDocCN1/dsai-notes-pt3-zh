# ### 4.2 $\ell_2$ 约束的最小二乘学习法

部分空间约束的最小二乘学习法中，只使用了参数空间的一部分，但是由于正则项受到严格的限制或者约束失效的原因，因此应先确定应用中参数是否合理。本节将介绍保留相对而言最少的约束的最小二乘学习法。

$\min_\theta J_{LS}(\theta)$，约束条件 $\|\theta\|_2 \le R$（4.1）

实际上给出的条件是，约束参数的最小二乘学习法要求参数空间的原点在圆心，在其中任意范围内的任意一个解都被认为是合理的。

# ### 拉格朗日对偶问题

> 可变分的约束：原问题和对偶问题之间的关系，以及约束条件的最优化问题。

# ### 4.2 $\ell_2$ 约束的最小二乘学习法

利用拉格朗日对偶问题，通过求解下面的最优化问题，就可以得到最优回归问题（4.1）的解。

$\max_\alpha\min_\theta \left[J_{LS}(\theta)+\frac{\lambda}{2}(\|\theta\|^2-R)\right]$，约束条件 $\lambda\ge0$

对给定的对偶问题的解，若不根据KKT决定，直接指定参数，$\ell_2$约束的最小二乘学习法的解就可以通过以下式子求得：

$\hat\theta=\arg\min_\theta\left[J_{LS}(\theta)+\frac{\lambda}{2}\|\theta\|^2\right]$（4.2）

$J_{LS}(\theta)$表示对训练样本的拟合程度，通过与$\|\theta\|^2$相结合得到最小值，防止过拟合。

# ### 4.2 $\ell_2$ 约束的最小二乘学习法

式（4.2）的目标函数进行关于参数的偏导，并设为0，$\ell_2$约束的最小二乘学习法的解就可以通过以下式子求得：

$\hat\theta=(\Phi^T\Phi+\lambda I)^{-1}\Phi^Ty$

+   1. 在这里，$I$是单位矩阵。从式（4.3）可知，在$\ell_2$约束的最小二乘学习中，通过将矩阵$\Phi^T\Phi$加上相对较小的正则项，通常可以使其稳定地进行矩阵求逆。
+   2. 因此，$\ell_2$约束的最小二乘学习法也成为正则化的最小二乘学习法。
+   3. 式（4.2）中的第二项正则项为正则项，因为正则化参数$\lambda$越大，越是限制了模型参数的取值范围。

# ### 4.2 $\ell_2$ 约束的最小二乘学习法

如果考虑将核进行中的参数条件。

$\Phi=\sum_{i=1}^{m}K_{x_i}\psi(x_i)$

+   ➢ $\ell_2$约束的最小二乘学习法中的解可以表示为：
+   
+   $\hat\theta=\sum_{i=1}^{m}\frac{K_{x_i}}{K_{x_i}^TK_{x_i}+\lambda}\psi(x_i)$
+   
+   ➢ 当$\lambda=0$时，$\ell_2$约束的最小二乘学习法与一般的最小二乘学习法相同。
+   ➢ 通过在分母中加入正则项，可以避免过拟合，成为正则化最小二乘学习法。

$h(x)=\sum_i\beta_iK(x,x_i)$

$K(x,c)=\exp\left(-\frac{\|x-c\|^2}{2\sigma^2}\right)$

# ### 一般约束的最小二乘学习法

虽然$\ell_2$约束的最小二乘学习法中加入了$\ell_2$正则，但是通过限制参数$\theta$的取值范围来防止过拟合，可以将其扩展为一般约束的最小二乘学习法。

$\min_\theta J_{LS}(\theta)$，约束条件 $\theta^TG\theta\le R$（4.1）

在式中，对约束项进行变换，由$\theta^TG\theta$可以表示模型在椭圆形参数空间内的取值范围。

$\hat\theta=(\Phi^T\Phi+\lambda G)^{-1}\Phi^Ty$
