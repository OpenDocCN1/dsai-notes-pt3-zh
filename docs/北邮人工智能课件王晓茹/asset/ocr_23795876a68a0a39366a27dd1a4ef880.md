# 四、相似性计算方法—数值类型

+   - Dissimilarity/Similarity 度量： Similarity is expressed in terms of a distance function, which is typically metric: d(i, j)
+   - 对于不同的数据类型，相似度函数的定义又是非常不同的
+   - 区间标度变量(Interval-scaled variables)
+   - 二元变量(Binary variables)
+   - 标称型、序数和比例标度
+   - 混合型

# 四、相似性计算方法—区间标度度量

+   - 距离通常是用来作为对象之间相似度和不相似度的最主要的方法
+   - 区间标度是一个略微线性标度的连续度量。典型的例子包括重量和高度、经度和纬度坐标（聚类分析）、以及大气温度。

# 四、相似性计算方法—区间标度度量

+   - Some popular ones include: 闵可夫斯基距离 (Minkowski distance): d(i,j) = ( |x_i1 - x_j1|^q + ... + |x_ip - x_jp|^q )^{1/q} where i = (x_i1, x_i2, ..., x_ip) and j = (x_j1, x_j2, ..., x_jp) are two p-dimensional data objects, and q is a positive integer
+   - If q = 1, d is 曼哈顿距离(Manhattan distance) d(i,j) = |x_i1 - x_j1| + |x_i2 - x_j2| + ... + |x_ip - x_jp|

# 四、相似性计算方法—区间标度度量

+   - If q = 2, d is 欧几里得距离 Euclidean distance: d(i,j) = sqrt( (x_i1 - x_j1)^2 + ... + (x_ip - x_jp)^2 )
+   - Properties
+     - d(i,j) >= 0
+     - d(i,i) = 0
+     - d(i,j) = d(j,i)
+     - d(i,j) <= d(i,k) + d(k,j)
+   - Also, one can use weighted distance, or other dissimilarity measures

# 四、相似性计算方法—二元变量

+   - 一个二元变量只有两种状态: 0或1, 0表示改变量为零, 1表示改变量存在。
+   - 例如，给出一个描述人的变量 smoker, 1表示该人抽烟, 0表示该人不抽烟。
+   - 我们可以对给定的数据集构建度量矩阵。如果假设所有的二元变量具有相同的权值，我们得到一个两列两列的可能性

# 四、相似性计算方法—二元变量

+   - A contingency table for binary data

| | Object j | | |
| | 1 | 0 | sum |
| Object i | 1 | a | b | a+b |
| | 0 | c | d | c+d |
| | sum | a+c | b+d | p |

+   - a是对于对象i和j都取值为1的变量的数目。
+   - b是对于对象i取值为1而对于对象j取值为0的变量的数目。
+   - c是对于对象i取值为0而对于对象j取值为1的变量的数目。
+   - d是对于对象i和j都取值为0的变量的数目。
+   - 变量的总数目 p = a+b+c+d

# 四、相似性计算方法—二元变量

+   - 对称的二元变量: 如果它的两种状态是同等价的，并在相同的程度上被观察到，则二元变量是对称的。也就是说两个值0和1没有优先状态。例如，“型”变量就是这样的一个例子，它有两个值“女性”和“男性”。
+   - 简单匹配系数: Simple matching coefficient (invariant, if the binary variable is symmetric):

| | Object j | | |
| | 1 | 0 | sum |
| Object i | 1 | a | b | a+b |
| | 0 | c | d | c+d |
| sum | a+c | b+d | p |

d(i,j) = (b + c) / (a + b + c + d)
