# 协方差矩阵推广

设有我们有m个维数n的数据记录，将其列成矩阵m×n的矩阵X, 设C = 1/m XXᵀ。

则C是一个协方差矩阵，其对角线分别各自变量的方差，而第i行第j列则相同，表示两个变量的协方差。

1/m XXᵀ = ( 1/m Σxᵢ²   1/m Σaᵢbᵢ ; 1/m Σaᵢbᵢ   1/m Σbᵢ² )

+   1) 实际的数据矩阵X通常不是在原点处，所以需要先做中心化处理。
+   2) 协方差矩阵A是对称、实对称矩阵可以对角化为A = E Λ Eᵀ，其中E的列向量是标准正交。
+   3) ...

E = (e₁ e₂ ... eₙ)

Eᵀ C E = Λ - ( λ₁ λ₂ ... ; ... λₙ )

P = Eᵀ

# 协方差矩阵对角化

+   目标：要求找到矩阵P使协方差矩阵对角化，即使新坐标轴相互正交且Σ=0，并且在对角线上将元素最大化上下面下述。
+   设Y = P X, 则Y与X的协方差矩阵为D, 我们推导出Y与D的关系：

D = 1/m YYᵀ = 1/m (PX)(PX)ᵀ = 1/m PXXᵀPᵀ = P C Pᵀ

P能让原始协方差矩阵对角化的P。换句话说，优化目标变成了从一个k维子空间中挑选k个前K行是使投影后的数据满足优化条件。

# PCA算法

+   设有m条数据记录。
+   1) 将原始数据整理成m×n矩阵X
+   2) 对每一行（代表一个n维样本）进行均值化，即减去这一行的均值
+   3) 求协方差矩阵 C = 1/m XXᵀ
+   4) 求出协方差矩阵的特征值和特征向量
+   5) 将特征值按对应特征值大小从上到下排列成序列，取前k行组成矩阵P
+   6) Y = P X 即为降维到k维后的数据

P = ( 1/√2 1/√2 ; -1/√2 1/√2 )
