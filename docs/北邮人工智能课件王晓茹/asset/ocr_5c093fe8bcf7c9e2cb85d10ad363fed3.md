# 置信风险->结构风险

+   - 置信风险与两个量有关：
+     - 一是样本数量，显然给定样本数量越大，我们的学习结果越有可能正确，此时置信风险越小。
+     - 二是分类器的VC维，显然VC维越大，推广能力越强，置信风险会变大。
+   - 泛化误差界的公式：
+     - R(w)≤Remp(w)+Φ(n/h)
+     - 公式中R(w)就是真实风险，Remp(w)就是经验风险；
+     - Φ(n/h)就是置信风险。
+     - 统计学习的目标从经验风险最小化变为寻找经验风险与置信风险的和最小，即结构风险最小。

# SVM的特点：

+   - 基于最小化结构风险的算法：
+     - 小样本：
+       - 并不是说样本的绝对数量少（实际上，对任何算法来说，更多的样本几乎总是能带来更好的效果），而是指与问题的复杂度比起来，SVM算法要求的样本数是相对比较少的。
+     - 非线性：
+       - 是指SVM擅长应付样本数据线性不可分的情况，主要通过核变量（也有人叫变换变量）和核函数技术来实现，这一部分是SVM的精髓。

# SVM与文本分类

+   - 高维模式识别是指样本维数很高，例如文本的向量表示，如果没有经过降维处理，出现几万维的信息很正常，其它算法基本上就没能力付了，SVM却可以，主要原因是为SVM生产的部分类器很简洁，用到的样本信息很少（仅仅用到那些样本中支持向量样本，此为后话），使得它使用样本维数很高，也不会给存储和计算带来大麻烦（相对而言，kNN算法在分类时就要用到所有样本，样本数巨大，每个样本维数再一高，这日子就没法过了……）。

线性分类器（定义文本上可以叫做线性感知机）是简单而有效的小样本学习器中一个很典型的例子，可以看作SVM的原型，并且根据更多SVM的核思想。
