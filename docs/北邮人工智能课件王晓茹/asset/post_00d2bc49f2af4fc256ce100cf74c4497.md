## 2.3.3 DIMENSIONALITY REDUCTION
维度归约

### Dimensionality Reduction

+   Purpose:
+   - Avoid curse of dimensionality
+   - Reduce amount of time and memory required by data mining algorithms
+   - Allow data to be more easily visualized
+   - May help to eliminate irrelevant features or reduce noise

+   Techniques
+   - Principle Component Analysis 主成分分析
+   - Singular Value Decomposition 奇异值分解
+   - Others: supervised and non-linear techniques

## 1. Curse of Dimensionality 维度灾难

当数据维度的增加时，数据在所占据的空间中越来越稀疏：
- 对分布：则可能信息率没有足够的样本对象来验证某种模型。
- 对聚类：点之间距离和最近邻点（对聚类非常重要的）都将失去意义。

Another way to reduce dimensionality of data

## Feature Subset Selection

+   Techniques:
+   - Brute-force approach: 蛮力法
+     * Try all possible feature subsets as input to data mining algorithm
+   - Embedded approaches: 嵌入方法
+     * Feature selection occurs naturally as part of the data mining algorithm
+   - Filter approaches: 过滤方法
+     * Features are selected before data mining algorithm is run
+   - Wrapper approaches: 包装方法
+     * Use the data mining algorithm as a black box to find best subset of attributes

## 基于熵Entropy的离散化

给定一个数值数据属性 A，其基于熵 A 离散化的方法如下：
1. A 的每个可能值可以为一个值所在的同一个区间
2. 选择划分的 T 使得其划分结果的信息熵最大
I(S,T)=|S1|/|S| Ent(S1)+|S2|/|S| Ent(S2)
其中，S1 和 S2 分别对应于中属性值 A < T 和 A ≥ T 的样本
Ent(S1)= -∑ pi log2(pi)
其中，pi 是类 i 在 S1 中的概率。
等价于 S1 中的样本总数为 S1 中样本总数。
3. 连续地进行上述操作 Ent(S) - (I(S,T)) > δ

## Chi-merge离散化

+   - Chi-merge: χ²-based discretization
+   - 有监督: use class information
+   - 初始向上: find the best neighboring intervals (具有相似的类分布, i.e., low χ² values) to merge
+   - 递归合并, until a predefined stopping condition
