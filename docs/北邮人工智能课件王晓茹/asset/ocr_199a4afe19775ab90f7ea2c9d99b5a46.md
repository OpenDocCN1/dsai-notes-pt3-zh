# 2.8 剧本表示法

# 一 概念

可视为框架的一种特殊形式，用一组描述相遇事件的发生序列。
70年代，夏克（R.C.Schank）概念依赖理论，用一组原子概念来描述生活中的故事、事件、情节。

例如对动作的抽象，11种原子动作（PROPEL，GRASP，MOVE，ATRANS，PTRANS，ATTEND，INGEST，EXPEL，SPEAK，MTRANS，MBUILD）

# 2 构成

由以下几个部分构成：
（1）开场条件：前提条件
（2）角色：人物
（3）道具：与事件相关的物体等
（4）场景：事件发生的情景，因果链，顺序
（5）结果：事件发生后的情况

# 二 推理

准备好剧本，根据所给的条件和事件进行推理，预测未发生或未提及的事件。

# 2.9 面向对象的表示法

# 一 以面向对象的观点进行描述。

研究领域和世界由各种对象构成，对象又可被划分成对象类。

# 二 表示

面向对象方法学的观点，对象的形式定义为：
对象：<属性，MS，MP>，其中：
IO为对象标识名。
MS描述对象当前的内部状态和所具有的静态属性；
MP说明对象所具有的内部处理方法或对受理消息的操作过程。

作过程：
M1为对象接收外部信息和驱动内部方法的对外接口。

例：定义新车对象
Class car: motorized vehicle
    Attribute
        Number of the doors;
        Color;
        Power;
        Air Condition;
        Produced by;
        …
    Method
        Move(direction,speed);
        Stop;
        …

例示：建立某一个或几个实例

# 三 继承性

单继承性：每一对象类只有唯一的父类；
多继承性：允许对象类从一个以上的父类中继承信息。

# 四 封装性

用于定义一个对象的实例属性和方法，仅仅属于该对象，对其他对象不可见。
