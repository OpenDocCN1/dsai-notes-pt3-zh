# 九、网格类类

+   - 将对象空间量化为有限数目的单元，形成一个网格结构，所有的聚类都在这个网格结构中进行。

+   - 其优点是处理速度很快，其处理时间取决于数据的数目，只有与量化空间中每一维的单元数目有关。

在网格聚类方法中有关利用存储在小格单元中的统计信息进行聚类的STING算法、用于小波转换方法进行聚类的WaveCluster方法和在高维数据空间基于网格和密度的聚类方法。

STING算法的主要优点是效率高，通过对数据集的一次扫描来计算单元的统计信息，因此产生聚类的时问复杂度是O(n)。在建立层次结构以后，查询的时间复杂度是O(g), g远小于n。STING算法采用网格结构，有利于并行处理和增量更新。

基于网格和密度的聚类CLIQUE算法主要步骤;

+   (1)将数据空间划分为互不相交的长方形单元，记录每个单元中的对象数。

+   (2)用先验属性识别包含簇的子空间。

+   (3)先寻找兴趣的子空间中先找出密集单元，再找出相连接的密集单元，以识别簇。

+   (4)为每个簇生成最小化的描述。

# STING算法

STING(Statistaical Information Grid based method)是一种基于网格的多分辨率聚类技术，它将空间区域划分为矩形单元。针对不同的分辨率，通常在多级形成矩形单元，这些单元形成了一个层次结构。两级的每个单元被划分为多个一层的单元。高层单元的统计参数可以很宽松的从底层单元的统计参数得到。这些参数与数据无关的参数count、属性相关的参数m(平均值)、s(标准差)、mint最小值、max最大(以及该单元中属性值随分布类型)。STING算法采用了一种多分辨率层次结构来提高聚类分析，该聚类算法的顶层采用粗粒度网格的最近邻聚类。如果粒度比较细，处理的代价会显著增加；如果粒度较粗，则聚类质量会受到影响。

+   WaveCluster方法首先通过在数据空间上强加一个多维网格结构来汇总数据，每个网格单元汇总了一组映射到该单元中的点的信息，然后采用一种小波变换对原位数据进行变换，重点信息在进行小波变换时使用，转换在变换空间中集中到类区域。

+   小波变换的聚类是无监督聚类，不用事先假设聚类的形状，可以发现任意形状的聚类，边界弱信号不会被屏蔽，可以剔除孤立点，本身体运算开销不大。
