# The AdaBoost Algorithm

Given: (x₁,y₁),...,(xₘ,yₘ) where xᵢ ∈ X, yᵢ ∈ {−1,+1}. Initialization: D₁(i)=1/m i=1,...,m For t=1,...,T: • Find classifier hₜ: X→{−1,+1} which minimizes error wrt Dₜ i.e., εₜ = arg minₕ Σᵢ Dₜ(i) [yᵢ ≠ h(xᵢ)] • Weight classifier: αₜ = ½ ln[(1−εₜ)/εₜ] • Update distribution: Dₜ₊₁(i)= Dₜ(i) exp(−αₜ yᵢ hₜ(xᵢ))/Zₜ Zₜ is for normalization Output final classifier: sign[ H(x)= Σₜ αₜ hₜ(x) ]
