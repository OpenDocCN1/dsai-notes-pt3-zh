# 逻辑回归（Logistic Regression）

+   - 逻辑回归的模型是一个非线性模型。
+   - sigmoid 函数，又称逻辑回归函数，但是它本质上又是一个线性回归模型。
+   - 因为除去 sigmoid 映射函数关系，其他的步骤、算法都是线性回归的。
+   - 可以说，逻辑回归，都是以线性回归为理论支持的。
+   - 只不过，线性模型，无法做 sigmoid 的非线性形式，sigmoid 可以轻松处理 0/1 分类问题。

# 二分类问题

二分类问题是指预测的值只有两个取值（0或1）。二分类问题可以扩展到多分类问题。例如：垃圾邮件过滤系统，是邮件的特征，预测的值就是邮件的类别，是垃圾邮件还是正常邮件。对于案例我们通常称为正类（positive class）和负类（negative class）。垃圾邮件的例子中，正类就是正常邮件，负类就是垃圾邮件。

应用举例：是否垃圾邮件分类？是否肺癌？是否金融欺诈？

# Logistic 函数

如果我们想把二分类问题中的取值是一个离散的数值（0或1），我们继续使用线性回归来预测的取值。这样数字导致的取值很有可能不在0、1之间。逻辑回归使用一个非线性函数，将函数值压缩到0和1之间，这个函数称为 Logistic 函数。

![](bbox=[0.629, 0.862, 0.85, 0.975])

Logistic 函数的取值处于无穷大时，函数趋近于1；当趋近于负无穷大时，函数趋近于0。
