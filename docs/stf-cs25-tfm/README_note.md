# 斯坦福 CS25 课程笔记：Transformer 模型原理详解 🧠

在本节课中，我们将要学习 Transformer 模型的核心原理。Transformer 是一种完全基于注意力机制的神经网络架构，它彻底改变了自然语言处理领域，并成为当今众多先进模型（如 GPT、BERT）的基石。我们将从最基础的注意力机制开始，逐步剖析其核心组件和工作流程。

---

## 注意力机制：模型的核心 🔍

上一节我们介绍了 Transformer 的重要性，本节中我们来看看其最核心的组件——注意力机制。注意力机制允许模型在处理序列数据时，动态地关注输入序列中不同部分的信息，从而捕捉长距离的依赖关系。

注意力机制的计算过程可以概括为三个步骤：首先，将输入转换为查询（Query）、键（Key）和值（Value）向量；其次，计算查询与所有键的相似度；最后，根据相似度权重对值进行加权求和。

其核心公式如下：

**注意力(Q, K, V) = softmax( (Q * K^T) / sqrt(d_k) ) * V**

其中：
*   **Q** 代表查询矩阵。
*   **K** 代表键矩阵。
*   **V** 代表值矩阵。
*   **d_k** 是键向量的维度，使用其平方根进行缩放是为了防止点积结果过大导致梯度消失。

---

## Transformer 架构总览 🏗️

理解了注意力机制后，我们现在可以观察 Transformer 的整体架构。它采用编码器-解码器结构，但完全摒弃了循环和卷积，仅依赖注意力机制和前馈神经网络。

Transformer 模型主要由堆叠的编码器层和解码器层构成。编码器用于理解输入序列，解码器则用于生成输出序列。每一层都包含自注意力机制和前馈神经网络，并辅以残差连接和层归一化来稳定训练。

以下是其核心组件列表：

*   **编码器**：由 N 个相同的层堆叠而成。每层包含一个多头自注意力子层和一个前馈神经网络子层。
*   **解码器**：同样由 N 个相同的层堆叠而成。每层包含三个子层：掩码多头自注意力层、编码器-解码器注意力层以及前馈神经网络层。
*   **位置编码**：由于模型不含循环和卷积，需要额外注入序列的顺序信息。这是通过将正弦和余弦函数计算出的位置向量与词嵌入相加来实现的。

## 多头注意力机制 🤹

上一节我们介绍了单头注意力，本节中我们来看看更强大的多头注意力。多头注意力允许模型同时从不同的表示子空间（例如，语法、语义）关注信息，从而增强模型的表达能力。

其工作原理是，将查询、键和值矩阵分别线性投影到 h 个不同的子空间，在每个子空间并行执行注意力计算，最后将结果拼接并再次投影。

以下是其计算过程的伪代码描述：

```python
# 假设输入维度为 d_model，头数为 h
def MultiHeadAttention(Q, K, V):
    # 线性投影到 h 个头
    Q_i = Linear(Q) # 形状: [batch_size, seq_len, d_k]
    K_i = Linear(K)
    V_i = Linear(V)

    # 对每个头计算注意力
    head_i = Attention(Q_i, K_i, V_i)

    # 拼接所有头的输出
    concat_heads = Concatenate(head_1, ..., head_h)

    # 最终线性投影
    output = Linear(concat_heads)
    return output
```

## 位置编码与层归一化 📍

Transformer 模型本身不具备感知单词顺序的能力。为了解决这个问题，我们引入了位置编码。位置编码是一个与词嵌入维度相同的向量，它包含了单词在序列中位置的信息，并与词嵌入直接相加。

常用的位置编码使用不同频率的正弦和余弦函数生成：

**PE(pos, 2i) = sin(pos / 10000^(2i/d_model))**
**PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))**

其中，`pos` 是位置，`i` 是维度索引。这种编码方式使得模型能够轻松学习到相对位置信息。

此外，为了训练更深的网络，Transformer 在每个子层（自注意力、前馈网络）周围都采用了残差连接，并紧接着进行层归一化。这可以表示为：

**LayerNorm(x + Sublayer(x))**

其中 `Sublayer(x)` 是子层本身的函数。这种设计有助于缓解梯度消失问题，加速模型收敛。

---

## 前馈神经网络与输出生成 🚀

在注意力层提取了上下文信息之后，每个位置的特征会独立地通过一个前馈神经网络进行进一步处理和转换。这个网络由两个线性变换和一个激活函数组成。

前馈网络的公式如下：

**FFN(x) = max(0, x * W1 + b1) * W2 + b2**

其中，`W1`, `b1`, `W2`, `b2` 是可学习的参数。这个模块为模型增加了非线性变换能力。

对于解码器，其最终输出会通过一个线性层和一个 softmax 函数，来预测目标词汇表中下一个词的概率分布。

**概率 = softmax(线性层(解码器输出))**

模型在训练时通过最大化正确词序列的似然概率（即最小化交叉熵损失）来学习所有参数。

## 总结 📝

本节课中我们一起学习了 Transformer 模型的核心原理。我们从最基础的注意力机制公式出发，逐步剖析了多头注意力、位置编码、层归一化以及前馈网络等关键组件。Transformer 通过完全基于注意力机制的设计，实现了高效的并行计算和对长程依赖的强大建模能力，为现代自然语言处理奠定了坚实的基础。理解这些原理是进一步学习 BERT、GPT 等衍生模型的关键。
