# Combine short and long paths in unfolded flow graph

+   - Longer-delay connections allow to connect the past states to future states through short paths
+   - Gradients will vanish exponentially with respect to the number of time steps
+   - If we have recurrent connections with a time-delay of D, the instead of the vanishing or explosion going as O(λ^T) over T steps (where λ is largest eigenvalue of the Jacobians ∂h_t/∂h_{t-1}), the unfolded recurrent network now has paths through which gradients grow as O(λ^{T/D}) because the number of effective steps is T/D
