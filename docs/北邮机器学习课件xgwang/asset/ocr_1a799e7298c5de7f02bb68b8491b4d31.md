# Find the Optimal Projection Direction $e_1$

+   - $S = \sum_{k=1}^{n}(x_k-\bar{x})(x_k-\bar{x})^t$ is the scatter matrix
+   - $e_1^t S e_1 = \sum_{k=1}^{n} a_k^2 \left(\sum_{k=1}^{n} a_k = 0\right)$ is the variance of the projected data
+   - The vector $e_1$ that minimizes $J_1$ also maximizes $e_1^t S e_1$, subject to the constraint that $\|e_1\| = 1$
