# Stochastic gradient descent

+   - Given $n$ training samples, our target function can be expressed as
+   
+   $$J(w) = \sum_{p=1}^{n} J_p(w)$$

+   - Batch gradient descent
+   
+   $$w \leftarrow w - \eta \sum_{p=1}^{n} \nabla J_p(w)$$

+   - In some cases, evaluating the sum-gradient may be computationally expensive. Stochastic gradient descent samples a subset of summand functions at every step. This is very effective in the case of large-scale machine learning problems. In stochastic gradient descent, the true gradient of $J(w)$ is approximated by a gradient at a single example (or a mini-batch of samples):
+   
+   $$w \leftarrow w - \eta \nabla J_p(w)$$
