# Parameters of HMM

+   - Initial state parameters $P(h_t = \omega_i) = \pi_i, \sum_i \pi_i = 1$
+   - Transition probabilities $P(h_t = \omega_j | h_{t-1} = \omega_i) = a_{ij}, \sum_j a_{ij} = 1$. A = [a_{ij}] is transition matrix
+   - Emission probabilities $p(x_t | h_t)$
+     - If $x_t$ is a single discrete variable, $x_t = x_i \in \{v_1, ..., v_m\}$, $P(x_t = v_k | z_t = \omega_j) = b_{jk}, \sum_k b_{jk} = 1$
