# Difficulty of Learning Long-Term Dependencies

+   - Consider the gradient of a loss $L_T$ at time $T$ with respect to the parameter $	heta$ of the recurrent function $F_	heta$
+     $h_t = F_	heta(h_{t-1}, x_t)$
+     $\frac{\partial L_T}{\partial \theta} = \sum_{t=1}^{T} \frac{\partial L_T}{\partial h_T} \frac{\partial h_T}{\partial h_t} \frac{\partial F_	heta(h_{t-1}, x_t)}{\partial \theta}$
+     $\frac{\partial L_T}{\partial h_T} \frac{\partial h_T}{\partial h_t} \frac{\partial F_	heta(h_{t-1}, x_t)}{\partial \theta}$ encodes long-term dependency when $T - t$ is large
