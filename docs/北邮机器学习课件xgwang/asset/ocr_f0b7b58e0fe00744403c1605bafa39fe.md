# Recurrent neural networks (RNN)

+   - While HMM is a generative model RNN is a discriminative model
+   - Model a dynamic system driven by an external signal x_t
+   - h_t = F_θ(h_{t-1}, x_t)
+   - h_t contains information about the whole past sequence. The equation above implicitly defines a function which maps the whole past sequence (x_1, ..., x_t) to the current state h_t = G_θ(x_1, ..., x_t)
