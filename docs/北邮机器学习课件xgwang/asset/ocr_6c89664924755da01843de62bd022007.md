# Curse of dimensionality

+   - The more training samples in each cell, the more robust the classifier
+   - The number of cells grows exponentially with the dimensionality of the feature space. If each dimension is divided into three intervals, the number of cells is $N = 3^n$
+   - Some cells are empty when the number of cells is very large!
