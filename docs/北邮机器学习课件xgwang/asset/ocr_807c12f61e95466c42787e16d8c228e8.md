bias(θ̂) = E(θ̂) − θ

where expectation is over all the train sets of size n sampled from the underlying distribution

+   - An estimator is called unbiased if E(θ̂) = θ
+   - Example: Gaussian distribution. p(x_i; θ) = N(θ, Σ) and the estimator is θ̂ = 1/n Σ_{i=1}^n x_i^{(train)}

E(θ̂) = E[ 1/n Σ_{i=1}^n x_i^{(train)} ] = 1/n Σ_{i=1}^n E[ x_i^{(train)} ] = 1/n Σ_{i=1}^n θ = θ
