# BP on a flow graph

```
∂loss/∂x_N ← 1
for j = N − 1 down to 1 do
  ∂loss/∂x_j ← Σ_{k ∈ parents(j)} ∂loss/∂x_k · ∂x_k/∂x_j
end for
return {∂loss/∂x_i}_{i=1}^M
```

> (Bengio et al. Deep Learning 2014)

∂u_N/∂w_i = ∂u_N/∂u_j · ∂u_j/∂net_j · ∂net_j/∂w_i = ∂u_N/∂u_j · ∂u_j/∂net_j · f'(net_j) u_i

+   - BP has optimal computational complexity in the sense that there is no algorithm that can compute the gradient faster (in the O(·) sense)
+   - It is an application of the principles of dynamic programming
