# Interpolation with Kernel

f(x) = b + Σ_{i=1}^{n} α_i K(x, x_i)

K is a kernel function, e.g., the Gaussian kernel

K(u, v) = N(u − v, 0, σ²)

+   - b and α_i can be learned by SVM
+   - Treat each x_i is a template and the kernel function as a similarity function that matches a template and a test example
