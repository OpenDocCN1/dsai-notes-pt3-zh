# Parameters of HMM

+   - **Evaluation problem**: determine the probability that a particular data sequence x₁, ..., x_T was generated by that model,
+   
+     P(x₁, ..., x_T)
+   - **Decoding problem**: given a set of observations x₁, ..., x_T, determine the most likely sequence of hidden states h₁, ..., h_T that lead to the observations
+   
+     (h₁*, ..., h_T*) = argmax_{h₁,...,h_T} P(h₁, ..., h_T | x₁, ..., x_T)
+   - **Learning problem**: given a set of training observations of visible variables, without knowing the hidden variables, determine the parameters of HMM.
+   
+     θ* = P(x₁, ..., x_T; θ)
