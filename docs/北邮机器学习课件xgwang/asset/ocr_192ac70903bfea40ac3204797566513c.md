# Three-layer neural network

+   Net activation of an output unit k

net_k = Σ_{i=1}^{n_h} y_i w_{kj} + w_{k0} = Σ_{j=0}^{n_h} y_j w_{kj} = w_k^T y

+   Output unit emits

z_k = f(net_k)

+   The output of the neural network is equivalent to a set of discriminant functions

g_k(x) = z_k = f( Σ_{j=1}^{n_h} w_{kj} f( Σ_{i=1}^{d} w_{ji} x_i + w_{j0} ) + w_{k0} )
