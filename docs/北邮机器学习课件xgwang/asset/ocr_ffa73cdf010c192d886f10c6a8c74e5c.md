# Principal Component Analysis (PCA)

+   - There are n d-dimensional samples x₁, ..., xₙ.
+   - PCA seeks a principal subspace spanned by d′ (d′ < d) orthonormal vectors e₁, ..., e_d′, such that
+     - the projected samples (x̂_k = a₀ + Σ_{i=1}^{d′} a_{ki} e_i) onto this subspace has maximum variance; or equivalently
+     - the mean squared distance between the samples and their projections are minimized.
+   - The projections {a_{ki}} are uncorrelated (i.e. independent if data distribution is assumed as Gaussian distribution)
