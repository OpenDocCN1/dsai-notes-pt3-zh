# Classification

+   - $f(x)$ predicts the category that $x$ belongs to
+     $f : \mathcal{R}^D \to \{1,\dots,K\}$
+   - $f(x)$ is decided by the decision boundary
+   - As an variant, $f$ can also predict the probability distribution over classes given $x$, $f(x) = P(y|x)$. The category is predicted as $y^* = \arg\max_k P(y = k|x)$
