## Parameters of HMM

- Initial state parameters $P(h_t = \omega_i) = \pi_i, \sum_i \pi_i = 1$
- Transition probabilities $P(h_t = \omega_j | h_{t-1} = \omega_i) = a_{ij}, \sum_j a_{ij} = 1$. $A = [a_{ij}]$ is the transition matrix
- Emission probabilities $p(x_t | h_t)$
  - If $x_t$ is a single discrete variable, $x_t = v_i \in \{v_1, \ldots, v_m\}$, $P(x_t = v_k | z_t = \omega_j) = b_{jk}, \sum_k b_{jk} = 1$

![](img/a04b187c89c5018c5ef6132980e27196_135_0.png)

- **Evaluation problem**: determine the probability that a particular data sequence $x_1, \ldots, x_T$ was generated by that model,

  $$P(x_1, \ldots, x_T)$$

- **Decoding problem**: given a set of observations $x_1, \ldots, x_T$, determine the most likely sequence of hidden states $h_1, \ldots, h_T$ that lead to the observations

  $$(h_1^*, \ldots, h_T^*) = \arg\max_{h_1,\ldots,h_T} P(h_1, \ldots, h_T | x_1, \ldots, x_T)$$

- **Learning problem**: given a set of training observations of visible variables, without knowing the hidden variables, determine the parameters of HMM.

  $$\theta^* = \arg\max_{\theta} P(x_1, \ldots, x_T; \theta)$$

## Recurrent neural networks (RNN)

- While HMM is a generative model, RNN is a discriminative model
- Model a dynamic system driven by an external signal $x_t$
- $h_t = F_\theta(h_{t-1}, x_t)$
- $h_t$ contains information about the whole past sequence. The equation above implicitly defines a function which maps the whole past sequence $(x_1, \ldots, x_t)$ to the current state $h_t = G_\theta(x_1, \ldots, x_t)$

![](img/a04b187c89c5018c5ef6132980e27196_137_0.png)

Left: physical implementation of RNN, seen as a circuit. The black square indicates a delay of 1 time step. Right: the same seen as an unfolded flow graph, where each node is now associated with a particular time instance.

- The summary is lossy, since it maps an arbitrary length sequence $(x_1, \ldots, x_t)$ to a fixed length vector $h_t$. Depending on the training criterion, $h_t$ keeps some important aspects of the past sequence.
- Sharing parameters: the same weights are used for different instances of the artificial neurons at different time steps
- Share a similar idea with CNN: replacing a fully connected network with local connections with parameter sharing
- It allows to apply the network to input sequences of different lengths and predict sequences of different lengths

![](img/a04b187c89c5018c5ef6132980e27196_138_0.png)

### A vanilla RNN to predict sequences from input

$$P(y_1, \ldots, y_T | x_1, \ldots, x_T)$$

- Forward propagation equations, assuming that hyperbolic tangent non-linearities are used in the hidden units and softmax is used for output for classification problems

  $$h_t = \tanh(W_{in} x_t + W_{hh} h_{t-1} + b_h)$$

  $$z_t = \mathrm{softmax}(W_{hz} h_t + b_z)$$

  $$p(y_t = c) = z_{t,c}$$

### Backpropagation on RNN

- Review BP on flow graph

![](img/a04b187c89c5018c5ef6132980e27196_142_0.png)

```
∂loss/∂w ← 1
for j = N − 1 down to 1 do
  ∂u_j/∂w ← Σ_{k∈parents(j)} (∂u_k/∂u_j) (∂u_k/∂w) / ∂u_j
end for
return (∂u_N/∂w)^M_{j=1}
```

> (Bengio et al. Deep Learning 2014)

$$\partial u_j/\partial w_i = \partial u_j/\partial a_i \cdot \partial a_i/\partial net_i \cdot \partial net_i/\partial w_i$$

### Gradients on W_hz and b_z

$$\partial L/\partial L_t = 1, \quad \partial L/\partial z_t = \partial L/\partial L_t \, \partial L_t/\partial z_t = \partial L_t/\partial z_t$$

$$\partial L/\partial W_{hz} = \sum_t \partial L_t/\partial z_t \, \partial z_t/\partial W_{hz}$$

$$\partial L/\partial b_z = \sum_t \partial L_t/\partial z_t \, \partial z_t/\partial b_z$$

![](img/a04b187c89c5018c5ef6132980e27196_143_0.png)

### Gradients on W_hh and W_xh

$$\partial L/\partial W_{hh} = \sum_t \partial L/\partial h_t \, \partial h_t/\partial W_{hh}$$

$$\partial L/\partial h_t = \partial L/\partial h_{t+1} \, \partial h_{t+1}/\partial h_t + \partial L/\partial z_t \, \partial z_t/\partial h_t$$
