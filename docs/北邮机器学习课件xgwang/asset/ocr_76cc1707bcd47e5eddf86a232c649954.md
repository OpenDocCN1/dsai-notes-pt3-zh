张量（tf.Tensor）

![](bbox=[0.22, 0.35, 0.48, 0.65])

+   - **dtype**: tf.float32、tf.int8等, 数据类型
+   - **Shape**: (n1, n2, n3), 数据形状
+   - **Name**: tensor1, 数据名称
+   - **Op**: 该tensor的来源操作
+   - **Graph**: 该tensor属于的图
+   - ...

+   ◆ 万物皆张量
+   ◆ 张量包括常数\变量\占位符等
+   ◆ 涉及到数据都是张量
