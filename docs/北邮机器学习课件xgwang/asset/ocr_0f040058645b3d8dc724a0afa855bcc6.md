# A recommended sigmoid function for activation function

激活函数

```
f(x) = 1.79159 \frac{e^{\frac{3}{2}x} - e^{-\frac{3}{2}x}}{e^{\frac{3}{2}x} + e^{-\frac{3}{2}x}}
```

f(±1) = ±1, liner in the range of -1 < x < 1, f'(x) has extrema near x = ±1.
