## 1. 基础绘图系统 🎨

基础绘图系统是R中最古老的绘图系统，它随R的原始版本一同发布。其构建图形的概念模型类似于“画家的调色板”。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_11.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_12.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_13.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_14.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_15.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_16.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_17.png)

该模型将绘图过程视为从一个空白画布开始，然后逐步向其中添加元素。例如，先创建一个带有数据点的坐标轴框，然后添加标签，再画一条回归线，最后加上标题和坐标轴刻度等。图形的每一个小部分都需要通过一行（或多行）代码来逐步拼接完成。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_18.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_19.png)

这种模型非常直观，尤其是在探索数据时，因为你可能无法立刻确定最终图形的样子。你可以先画一些点，再添加颜色和标签，最终将它们组合起来。只要记录下所有用于创建图形的代码，你就能随时复现该图形。

这种模型的典型模式是使用 `plot()` 函数来生成图形，然后使用其他函数（常称为注释函数）来为图形添加文本、线条、标签等元素。因此，整个过程分为**图形生成**和**图形注释**两个阶段。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_21.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_22.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_23.png)

以下是基础绘图系统的一个简单示例，它展示了其典型外观。我们使用了名为 `cars` 的数据集，它显示了汽车速度与完全停止所需距离之间的关系。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_24.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_25.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_26.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_27.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_28.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_29.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_30.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_31.png)

```r
plot(cars$speed, cars$dist, xlab = "Speed", ylab = "Stopping Distance")
```

![](img/c2a4543767541e4e2b7fad21d4c7ff37_32.png)

你可以在此基础上添加许多其他元素：添加标题、在图形内部添加标签、改变点的颜色或形状等。基础绘图系统提供了丰富的选项供你选择，我们将在后续课程中详细讨论。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_34.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_35.png)

**基础绘图系统的优点与缺点：**

![](img/c2a4543767541e4e2b7fad21d4c7ff37_36.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_37.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_38.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_39.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_40.png)

*   **优点**：该系统非常方便且直观。许多人习惯以这种方式构建图形。
*   **缺点**：
    1.  **不可逆性**：一旦在图形上添加了元素，就无法撤销。这是一个递增的、累积的过程。
    2.  **难以交流**：很难将一个新图形的构建思路传达给他人，因为缺乏一种通用的概念性语言。每个图形本质上只是一堆R代码。
    3.  **需要精细控制**：由于你对系统拥有高度控制权，因此也必须细致地控制一切。如果你不喜欢默认值，就需要手动设置所有细节。

## 2. Lattice绘图系统 📈

上一节我们介绍了逐步构建的基础绘图系统。本节中，我们来看看另一种完全不同的思路——Lattice系统。它是R中的第二大绘图系统，通过 `lattice` 包实现。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_42.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_43.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_44.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_45.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_46.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_47.png)

Lattice系统的理念与基础绘图系统截然不同。它不是通过一系列命令逐步拼接图形，而是通过**单次函数调用**来构建整个图形。最常用的函数是 `xyplot()`，此外还有 `bwplot()` 等。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_48.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_49.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_50.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_51.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_52.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_53.png)

这些函数基本上能一次性构建出完整的图形。因此，你必须在函数调用中指定大量信息，以便系统有足够的数据以恰当的方式构建图形。

Lattice系统最适用于创建**条件图**。在这种图中，我们希望观察变量X和Y之间的关系如何随着第三个变量Z的不同水平而变化。也就是说，你根据Z的不同水平进行条件划分，然后在每个子图中观察X和Y的关系。这类图有时也被称为**面板图**，因为你在每个面板中观察相同的内容，只是针对第三个变量的不同水平。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_55.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_56.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_57.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_58.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_59.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_60.png)

你甚至可以组合多个变量，观察多个因素的影响。这个系统非常有用，因为只要你遵循这种条件模型，就可以非常轻松、快速地将许多图形排列在一个页面上。此外，许多在基础绘图系统中需要直接指定的细节（如边距和间距）在Lattice系统中是自动计算的。只要你接受这些默认设置，大多数图形看起来都会相当不错。

![](img/c2a4543767541e4e2b7fad21d4c7ff37_61.png)

以下是Lattice系统的一个基本示例。我们使用了 `lattice` 包中的一些数据，绘制了各州人均收入与平均预期寿命的关系，并按地区进行条件划分。

```r
library(lattice)
xyplot(life.exp ~ income | region, data = state, layout = c(4, 1))
```

![](img/c2a4543767541e4e2b7fad21d4c7ff37_64.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_67.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_68.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_69.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_70.png)

可以看到，这种面板图在Lattice系统中只需一次简单的 `xyplot()` 函数调用即可构建。而在基础绘图系统中，实现类似效果需要多行代码，过程要复杂得多。

**Lattice绘图系统的优点与缺点：**

![](img/c2a4543767541e4e2b7fad21d4c7ff37_72.png)

*   **优点**：非常适合创建多面板条件图，能自动处理布局和间距等美学细节。
*   **缺点**：
    1.  **指定复杂**：有时通过单次函数调用来指定整个图形会显得非常笨拙。
    2.  **难以注释**：图形一旦生成，就很难再添加内容。如果想要添加，基本上需要重新构建整个函数调用。虽然存在为每个面板添加注释的方法（如使用面板函数 `panel.*` 或下标），但这非常棘手且不直观。
    3.  **不可添加**：图形完成后无法再添加元素。

## 3. ggplot2绘图系统 ✨

最后，我们来探讨第三个，也是目前非常流行的绘图系统——ggplot2。它基于图形语法理论，该理论为绘图设定了一套原则，并创建了一种用于描述图形不同方面的“语法”或语言。

ggplot2系统建立在坚实、严谨的理论体系之上，并通过R中的 `ggplot2` 包实现。它在一定程度上融合了基础系统和Lattice系统的思想。

## 总结与重要提示 🎯

![](img/c2a4543767541e4e2b7fad21d4c7ff37_108.png)

![](img/c2a4543767541e4e2b7fad21d4c7ff37_109.png)

本节课中，我们一起学习了R语言中的三大基本绘图系统：
1.  **基础绘图系统**：采用“画家调色板”模型，逐步添加元素。
2.  **Lattice系统**：通过单次函数调用指定整个图形。
3.  **ggplot2系统**：融合了前两者的一些思想。

使用这三个系统时，有一个重要事项需要知道：**它们不能混合使用**。你不能在它们之间互换函数。如果你决定使用基础绘图系统，就必须使用与该系统相关的所有函数；同样，如果使用ggplot2系统，也必须使用其自身的函数集。混合不同系统的函数会导致绘图混乱。

因此，你通常需要根据绘图需求选择一个系统，并在创建图形时坚持使用它。这就是R中的三大主要绘图系统，在后续单独的课程中，我们将详细讲解如何使用每一个系统。
