![](img/000505990caf512797732a40f9b294a4_13.png)

以下是您会频繁使用的一些关键基础绘图函数。

![](img/000505990caf512797732a40f9b294a4_18.png)

![](img/000505990caf512797732a40f9b294a4_20.png)

![](img/000505990caf512797732a40f9b294a4_21.png)

*   **`plot`**：这是最常用的函数，主要用于创建散点图。根据所绘制对象的类型，它也可以生成其他类型的图形。
*   **`lines`**：此函数不创建新图形，而是向现有图形添加线条。当您想连接多个点（例如绘制时间序列图）时，它非常有用。
*   **`points`**：此函数向现有图形添加数据点。例如，您可能想先创建一个图形，然后添加代表不同组或不同数据子集的点。
*   **`text`**：此函数用于在图形内部添加文本标签，以注释图形。
*   **`title`**：此函数通常用于在图形外部添加注释，如X轴和Y轴标签、主标题和副标题等。
*   **`mtext`**：`m`代表边距（margin），此函数用于在图形的边距（包括内边距和外边距）内放置文本。
*   **`axis`**：此函数用于指定坐标轴的刻度。

### 示例3：初始化图形并添加图例

有时，为了避免数据点重叠，我们可以先初始化一个空的图形框架。这里，我们在`plot`函数中设置参数`type = "n"`，这意味着它会设置好图形设备和其他所有元素，但不会绘制任何数据点。

然后，我们分别添加五月份（蓝色）和非五月份（红色）的数据点。最后，使用`legend`函数在图形的右上角添加图例，以区分这两组数据。

![](img/000505990caf512797732a40f9b294a4_46.png)

![](img/000505990caf512797732a40f9b294a4_47.png)

![](img/000505990caf512797732a40f9b294a4_48.png)

```r
plot(wind, ozone, main = "Ozone and Wind in New York City", type = "n")
with(subset(airquality, Month == 5), points(Wind, Ozone, col = "blue"))
with(subset(airquality, Month != 5), points(Wind, Ozone, col = "red"))
legend("topright", pch = 1, col = c("blue", "red"), legend = c("May", "Other Months"))
```

### 示例4：添加回归线

![](img/000505990caf512797732a40f9b294a4_56.png)

为图形添加回归线或平滑曲线是常见需求。这里，我们首先创建散点图，并将默认的绘图符号（`pch`）改为20（一个小的实心圆）。接着，我们使用`lm`函数拟合一个线性模型，最后调用`abline`函数将回归线添加到图形中。参数`lwd = 2`表示绘制一条比默认线更粗的线。

```r
plot(wind, ozone, pch = 20)
model <- lm(ozone ~ wind)
abline(model, lwd = 2)
```

### 示例6：为多图面板添加总标题

![](img/000505990caf512797732a40f9b294a4_75.png)

![](img/000505990caf512797732a40f9b294a4_76.png)

![](img/000505990caf512797732a40f9b294a4_77.png)

当使用多个图形时，除了每个图有自己的标题，您可能还想为整个图形面板添加一个总标题。这需要用到外边距（outer margin）。

在这个例子中，我们设置`par(mfrow = c(1, 3))`来创建一行三列的图形。我们调整了内边距（`mar`）使其比默认值小，同时增大了外边距（`oma`），为顶部标题留出空间。然后，我们调用三次`plot`函数创建三个图形。最后，使用`mtext`函数在整个图形面板的顶部外边距中添加总标题。

```r
par(mfrow = c(1, 3), mar = c(4, 4, 2, 1), oma = c(0, 0, 2, 0))
plot(wind, ozone, main = "Ozone and Wind")
plot(solar.r, ozone, main = "Ozone and Solar Radiation")
plot(temp, ozone, main = "Ozone and Temperature")
mtext("Ozone and Weather in New York City", outer = TRUE)
```
