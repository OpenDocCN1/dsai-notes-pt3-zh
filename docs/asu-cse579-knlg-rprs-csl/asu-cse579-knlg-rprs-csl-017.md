# 017：马尔可夫逻辑网络中的学习 🧠

在本节课中，我们将学习如何在马尔可夫逻辑网络中进行学习，特别是如何利用梯度上升法来学习公式的权重。我们将从最大似然估计的基本概念开始，逐步深入到马尔可夫逻辑网络中的参数学习。

## 概述：什么是学习？

在概率模型中，学习通常指从给定的数据中推断出模型的参数。这与推理相反：推理是在已知模型参数的情况下，计算观察到特定数据的概率；而学习是在已知数据的情况下，找出最能解释这些数据的模型参数。

## 最大似然估计简介

我们使用的方法是**最大似然估计**。似然度是衡量不同参数值对数据解释好坏的标准。我们的目标是找到能使似然度最大化的参数值。

例如，给定一枚硬币，你抛掷了100次，观察到66次正面，34次反面。这枚硬币是公平的还是有偏的？我们想知道，基于这些数据，硬币出现正面的实际概率是多少。

![](img/a88dda8dc03a808270c1ba4578bce03e_1.png)

在推理中，我们已知概率分布（例如，公平硬币 `P(正面)=0.5`），然后计算得到此数据的概率。学习则是相反的方向：我们已知数据，但不知道底层的概率分布参数（例如，有偏硬币的正面概率 `θ`），需要找出这个参数。

假设我们有一组独立同分布的观测数据 `X = {x1, x2, ..., xn}`，其分布由未知参数 `θ` 决定。在已知 `θ` 的情况下，观察到这组数据的概率为：
`P(X; θ) = ∏ P(xi; θ)`

这里的似然函数 `L(θ; X)` 在数学形式上与 `P(X; θ)` 完全相同，但视角不同。我们将数据 `X` 视为固定，而将参数 `θ` 视为变量。我们的目标是找到使 `L(θ; X)` 最大的 `θ` 值。

**一个简单例子**：假设抛掷硬币三次，得到序列：正面(H)、反面(T)、正面(H)。如果硬币是公平的(`p=0.5`)，得到此序列的概率是 `0.5 * 0.5 * 0.5 = 0.125`。但在学习中，我们固定数据 `H, T, H`，寻找最佳的 `p`。似然函数为 `L(p) = p * (1-p) * p = p²(1-p)`。通过求导或观察可知，当 `p = 2/3` 时，似然函数取得最大值。这就是最大似然估计的结果。

## 从似然度到对数线性模型

上一节我们介绍了最大似然估计的基本思想。本节中，我们来看看如何将其应用到更复杂的模型中。

在马尔可夫逻辑网络中，我们学习的是**公式的权重**。之前我们进行推理时，权重是固定的，我们计算某个世界（赋值）为真的概率。现在，我们给定数据（一个世界），要找出最能解释这个数据的权重。

![](img/a88dda8dc03a808270c1ba4578bce03e_3.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_5.png)

马尔可夫逻辑网络使用对数线性模型。一个通用的对数线性模型定义如下：

![](img/a88dda8dc03a808270c1ba4578bce03e_7.png)

`P(X) = (1/Z(W)) * exp( Σ_i wi * fi(X) )`

![](img/a88dda8dc03a808270c1ba4578bce03e_9.png)

其中：
*   `X` 是一个完整赋值（世界）。
*   `wi` 是第 `i` 个特征的权重（即我们要学习的参数）。
*   `fi(X)` 是第 `i` 个特征函数，在马尔可夫逻辑中，通常表示对应公式在 `X` 下为真的**基础实例数量**。
*   `Z(W)` 是配分函数，用于归一化，它依赖于权重 `W`，使得所有 `X` 的概率之和为1。

为了便于数学处理，我们通常使用**对数似然函数** `log P(X)`。

## 梯度上升法

对数似然函数通常是**凹函数**，这意味着任何局部最大值就是全局最大值。因此，我们可以使用**梯度上升法**来找到这个最大值。

梯度上升法的思想很简单：想象你在一个山坡上，目标是爬到山顶（最大值）。你环顾四周，找到最陡的上坡方向（梯度），然后朝那个方向走一小步。重复这个过程，直到你无法再向上走（梯度接近零）。

算法步骤如下：
1.  随机初始化权重 `W`。
2.  重复以下步骤直到收敛：
    `wj := wj + η * (∂ log P(X) / ∂ wj)`
    其中 `η` 是学习率，控制步长大小。

对于之前硬币的例子 `L(p)=p²(1-p)`，我们可以用梯度上升法求解。设置初始 `p=0.4`，学习率 `η=0.5`，梯度 `∂L/∂p = 2p - 3p²`。经过几次迭代，`p` 会收敛到 `2/3`。

当模型复杂（如马尔可夫逻辑网络），无法求出闭合解时，梯度上升这类迭代方法就非常有用。

## 马尔可夫逻辑网络中的生成式学习

现在，让我们将梯度上升法应用于马尔可夫逻辑网络的参数学习。我们假设输入数据是一个**关系数据库**，它可以被看作一个完整的逻辑解释（即一个可能世界 `X`）。

我们关注的是**参数学习**：给定一组一阶逻辑公式（规则），但不知道它们的权重，通过数据来学习这些权重。

![](img/a88dda8dc03a808270c1ba4578bce03e_11.png)

在马尔可夫逻辑中，特征函数 `fi(X)` 就是公式 `i` 在解释 `X` 下为真的基础实例数量，记作 `ni(X)`。因此，对数似然函数为：
`log Pw(X) = Σ_i wi * ni(X) - log Z(W)`

我们的目标是找到权重向量 `W`，最大化 `log Pw(X)`。为此，我们需要计算对数似然函数关于每个权重 `wj` 的梯度。经过推导（推导过程详见课程资料），梯度有一个直观的形式：

`∂ log Pw(X) / ∂ wj = nj(X) - Ew[nj(X)]`

其中：
*   `nj(X)`：在**给定数据（世界）`X`** 下，公式 `j` 为真的基础实例数量。这部分容易计算。
*   `Ew[nj(X)]`：在**当前权重 `W` 下**，公式 `j` 为真的基础实例数量在所有可能世界上的**期望值**。这部分计算成本很高，因为它需要对所有可能世界进行求和。

![](img/a88dda8dc03a808270c1ba4578bce03e_13.png)

**梯度含义**：权重的更新方向，是“数据中为真的实例数”与“模型预测的期望实例数”之差。如果数据中为真的实例多于模型预测，则增加该权重；反之则减少。

## 学习示例与计算

让我们通过一个简单例子来理解计算过程。假设我们有三个原子：`P1`, `P2`, `P3`。以及三条规则（初始权重设为1）：
1.  `P(x)` （权重 `w1`）
2.  `P1 ^ P2` （权重 `w2`）
3.  `P1 ^ ¬P3` （权重 `w3`）

给定的数据（世界）`X` 是：`P1=true, P2=true, P3=false`，即 `110`。

**计算 `n1(X)`**：第一条规则 `P(x)` 有三个基础实例：`P1`, `P2`, `P3`。在数据 `X(110)` 中，`P1` 和 `P2` 为真，`P3` 为假。所以 `n1(X) = 2`。

**计算 `Ew[n1(X)]`**：这需要枚举所有8个可能世界（`000` 到 `111`）。对于每个世界 `X'`，计算：
1.  该世界在当前权重下的概率 `Pw(X')`。
2.  在该世界下 `n1(X')` 的值（即 `P1`, `P2`, `P3` 中为真的个数）。
期望值 `Ew[n1(X)] = Σ_X' Pw(X') * n1(X')`。通过计算可得约为 `2.7941`。

![](img/a88dda8dc03a808270c1ba4578bce03e_15.png)

假设学习率 `η=1`，则 `w1` 的更新为：`w1_new = 1 + 1 * (2 - 2.7941) = 0.2059`。

类似地，我们可以计算 `w2` 和 `w3` 的梯度并更新。计算 `Ew[nj(X)]` 需要对所有可能世界求和，这是计算上的主要瓶颈。在实际系统中，会使用近似方法（如伪似然）来提高效率。

## 判别式学习

![](img/a88dda8dc03a808270c1ba4578bce03e_17.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_19.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_21.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_23.png)

上一节我们讨论了生成式学习，它试图对整个数据世界的概率分布建模。本节我们介绍**判别式学习**，它更专注于在给定部分证据的情况下，预测查询变量的值。

![](img/a88dda8dc03a808270c1ba4578bce03e_24.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_26.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_28.png)

在许多应用中，一些变量（证据）的值总是已知的。例如，在分类问题中，特征属性是已知的，我们只想预测类别标签。我们可以将证据变量标记出来，只学习与查询变量相关的权重。

![](img/a88dda8dc03a808270c1ba4578bce03e_30.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_32.png)

判别式学习最大化的是**条件似然** `P(Y | X)`，其中 `X` 是证据变量，`Y` 是查询变量。其梯度公式与生成式学习类似，但期望值是在给定证据 `X` 的条件下，对所有可能的 `Y` 取值进行求和计算得到的。

![](img/a88dda8dc03a808270c1ba4578bce03e_34.png)

![](img/a88dda8dc03a808270c1ba4578bce03e_36.png)

这种方法参数更少，通常在预测任务上表现更好。

## 实践工具：Alchemy

![](img/a88dda8dc03a808270c1ba4578bce03e_38.png)

理论之后，我们来看看实践。Alchemy 是一个用于马尔可夫逻辑网络的软件包。以下是一个简单的学习示例文件结构：

**模型文件 (`model.mln`)**：
```
// 声明谓词和常量
Person = {Alice, Bob, Charlie}
Smokes(Person)
Cancer(Person)

![](img/a88dda8dc03a808270c1ba4578bce03e_40.png)

// 定义待学习权重的公式
w1 Smokes(x)
w2 Smokes(x) => Cancer(x)
w3 Friends(x, y) => (Smokes(x) <=> Smokes(y))
```

**数据文件 (`train.db`)**：
```
// 这是一个可能世界的数据
Smokes(Alice)
Smokes(Bob)
!Smokes(Charlie) // “!” 表示否定
Cancer(Alice)
!Cancer(Bob)
Friends(Alice, Bob)
Friends(Bob, Charlie)
```

![](img/a88dda8dc03a808270c1ba4578bce03e_42.png)

使用 Alchemy 命令行进行学习：
`learnwts -d -i model.mln -o learned_model.mln -t train.db -ne Smokes,Cancer`

这将运行梯度上升学习算法，并输出一个更新了权重的新模型文件 `learned_model.mln`。
