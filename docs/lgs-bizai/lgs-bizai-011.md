# 11：🤖 人工智能在机器人与自主货运中的应用

在本节课中，我们将探讨人工智能在机器人技术和自主货运领域的应用现状与未来潜力。我们将分析当前技术的局限性，并讨论自动化可能带来的社会与伦理影响。

---

一些最广为人知的、关于人工智能与自动化的未来构想，都与机器人有关。这些构想通常带有科幻色彩，可能是双足机器人，也可能是更奇特的形态。

我们目前尚未达到由人工智能驱动的、完全自主甚至半自主机器人成为普遍可能的阶段。你可以在网上看到许多视频，展示多年调试的成果，试图让机器人完成更复杂的杂技或灵巧动作。然而，创造能够站立、行走和移动的机器人实际上非常困难。

因此，许多自动化制造场景中的设备并不像人。它们看起来更像是为执行特定任务而设计的专用机器。尽管如此，人们仍然梦想拥有执法机器人、军用机器人、拆弹机器人或通用型体力劳动机器人，而不是仅限于工厂内执行单一任务的设备。

这些构想都展现了自动化的潜力。随着人工智能及其能力的引入，自动化不再仅仅是呆板、重复的机械劳动，而是可以变得智能，能够被信赖去完成复杂的任务，而非简单的重复性工作。我们尚未实现这一点，但在讨论人工智能的未来及其潜在监管时，这值得考虑。

同样，在自动驾驶车辆方面，我们也尚未完全实现目标，尽管已取得进展。自动驾驶技术一个极具价值的应用领域是自动驾驶卡车，尤其是那些负责在全国范围内运输大量货物与服务的大型18轮地面运输卡车。

在美国，海量货物通过地面车辆运输。这是一项艰苦且危险的工作。卡车司机工作时间极长，驾驶本身具有危险性，驾驶大型车辆更是如此。这对司机的社会生活造成负担，长时间远离所谓的“家”损害了他们建立人际关系的能力。同时，这对人体健康也有害，长时间坐着驾驶并不健康。

因此，将自动驾驶技术引入运输卡车，可能使司机的生活更安全、更健康，也可能完全取代这些工作岗位。这项技术可以增强现有卡车司机的能力，也可能将他们从整个环节中移除。

然而，目前的自动驾驶技术并不可靠，未来也可能永远无法达到完全可靠。目前尚不清楚人工智能是否足够强大，能够应对道路上可能演变的多种复杂情况，以及能否解读它可能面临的各种极其多样的刺激——不仅仅是其他车辆，还有不熟悉的动物、突发事故等任何导致道路状况偏离人工智能预期的因素。

它可能比容易疲劳或分心的人类司机更安全，也可能因为其反应不可预测或难以捉摸而带来更多危险。

当然，有些方面值得期待。目前人类所从事的艰苦、重复性或心理损耗大的劳动，有可能因人工智能而得到缓解、改变、增强或辅助。同样，这些工作也可能以某种方式被取代，这对曾经从事这些工作的一部分人来说，可能在经济上不可行。

此外，这些任务可能足够复杂，以至于人工智能现在乃至未来都无法足够稳健、安全地处理它们，尤其是在后果极端严重的情况下——例如驾驶载有价值数千美元货物的大型车辆穿过人口稠密区，或在涉及生死的执法或军事冲突中部署人工智能机器人系统。

因此，在期待人工智能及其应用的潜力的同时，我们同样必须意识到其中潜在的问题，并以此引导我们对未来人工智能应如何监管的预期。

---

本节课中，我们一起学习了人工智能在机器人与自主货运领域的应用现状、技术挑战以及潜在的社会经济影响。我们认识到，尽管自动化前景广阔，但其发展必须伴随审慎的考量与合理的监管。
