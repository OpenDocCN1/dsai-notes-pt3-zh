# 10：案例示例 📊

在本节课中，我们将通过一个具体的案例文章，探讨人工智能在工作场所中的实际应用及其对员工产生的深远影响。我们将分析AI监控如何改变工作性质，并思考其背后的伦理问题。

---

有一篇优秀的文章讨论了人工智能已被整合到不同劳动力中的多种方式，其结果令人不寒而栗。

文章给出的一个例子是亚马逊的员工，他们被机器人经理要求以非人的速度工作，这些经理以微秒为单位测量他们的生产率。通常，在机器人助手的协助下，任何潜在的停机时间或短暂的休息机会——无论是精神上还是身体上的——都被削减，以追求不断提高的效率。

文章还谈到了呼叫中心。那里采用了人工监控的“共情传感器”，通过人工智能测量人们的语调和用词选择，以根据AI对人类共情的不完美理解，来判断他们是否表现出足够的共情。

该系统衡量人们在通话中是否足够共情的方法之一，是看他们是否说了足够多的“对不起”。因此，员工们被系统逼迫到极限，尽可能接听更多电话，在每次与来电者的对话中尽可能多地重复“对不起”。而他们必须处理的来电，都是复杂的、困难的、情感上耗费精力的，因为所有简单的来电都已经被自动化处理，或由无需人工干预的纯自动应答电话服务处理了。

文章还有一个关于居家办公的部分。居家办公与侵入性的监控软件相结合，这些软件测量击键次数，跟踪电脑上运行的其他程序。因此，员工不允许在后台听音乐。软件还会在一天中随机拍照，并在每次判定员工生产力不足时扣减工资。

所有这些监控方法和优化人类行为的努力，都对员工产生了极其有害的影响。例如在亚马逊，员工的生理健康受到损害，普遍存在重复性劳损。或者从心理层面看，在任何要求人类像机器人一样为机器人工作的情况下，都是如此。而人类管理层期望任何跟不上或达不到这些标准的员工都能被轻易替换。

这一切现在已经在发生，这让我们思考，未来在工作场所实施AI可能会侵犯哪些人权和人类安全。无论是在远程办公场所、员工笔记本电脑上的AI管理和监控，还是在工厂仓库、呼叫中心或任何其他可以通过人工监控提高效率的地方。

这很奇怪，因为曾几何时，自动化的承诺是乐观的。将AI整合到工作场所，曾经是对员工有好处的承诺——它将取代艰苦的工作、危险的工作，让人们更安全、更健康。但目前看来，它似乎正在起反作用。

而且，是否将这些艰苦、危险的工作完全自动化就一定是好事，也并不完全清楚。在某些方面，自动化实际上增加了就业机会。例如，在亚马逊仓库，他们有一个机器人辅助系统，将货架以比人工行走快很多倍的速度运送给工人。这更快、更便宜、时间上更优化，以至于他们实际上不得不雇佣更多的人，以跟上这些机器人加速仓库劳动的程度。

因此，在某些方面，自动化增加了可用工作岗位的数量，这是一件好事。有工作意味着为更多人提供了养家糊口的方式。但另一方面，可用的工作岗位仍然是有害的、具有破坏性的，并且不可能以健康的方式长期维持。

与此相对的，是旧日的自动化梦想，即完全消除工作岗位。所以，从一个角度看，自动化可能意味着从人类可完成的工作池中移除岗位，可能为公司节省成本，但也剥夺了人们谋生的机会。另一方面，随着系统变得更加优化，人们有更多事情可做，自动化实际上可能确实增加了可用工作岗位的数量。

但如果唯一增加的工作岗位都是有害的，那对任何人都没有真正帮助。理想的情况是，自动化的承诺和AI的能力，能够为所有工人增加健康、安全的工作岗位数量。但目前尚不清楚这是否会在短期内发生。

在想象AI和自动化的未来，以及我们或许如何监管它们时，我们需要考虑的事情之一就是这些影响。

---

本节课中，我们一起学习了人工智能在工作场所监控与管理中的具体应用案例。我们看到，AI在追求效率的同时，可能对员工的身心健康造成损害，并引发了关于工作质量、就业机会和人权保障的深刻伦理问题。理解这些现实案例，是思考如何负责任地发展和应用商业AI的第一步。
