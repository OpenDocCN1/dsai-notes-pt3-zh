# 7：人工智能伦理中的隐私问题 🔒

在本节课中，我们将探讨人工智能伦理中的一个核心议题：隐私。我们将分析隐私在当今数字时代如何被侵蚀，并特别关注人工智能技术如何加剧这一问题。通过具体案例，我们会理解为什么隐私保护在商业和人工智能应用中至关重要。

---

隐私，至少在某种程度上，已成为过去的事物。

我无法过分强调我们每次使用Gmail账户登录网站、每次使用手机访问新服务或应用时，被监视和分析的程度。

绝大多数人被收集的信息的深度和广度是惊人的。我们所设想的隐私可能已不复存在。

我们随身携带手机，它们本质上是麦克风、摄像头和GPS追踪设备。

所有这些信息不仅被我们自己使用，也被手机内程序的拥有者以及手机制造商使用。

面部3D打印用于解锁手机、你的声音档案、视网膜扫描、指纹，这些都是极其私密的个人信息。我们以惊人的频率将它们提供给各个手机和应用，从一处到另一处。

我们去的地方、去的时间，所有这些都被记录在手机的追踪数据中。我们使用什么应用、在应用上做什么、何时使用、在何处使用、按什么顺序下载应用、我们的手机使用模式，所有这些都被非常彻底地追踪。这旨在强调隐私已逐渐从我们的期望中被移除的程度。

给你一个小例子，这是我个人不久前经历的一件事。

我打电话给兽医诊所，因为我的狗生病了。

在我结束通话后，我收到了来自同一家兽医的短信。

但他们给我发短信时，没有使用我提供给他们的名字。

相反，他们用我母亲的名字签名给我发短信。我只能推测，因为我并没有告诉他们我母亲的名字。

这是因为这家兽医诊所挖掘了我的手机号码，发现我母亲也在同一个服务计划中，并用她的名字来称呼我。

这应该能突出、能例证我们在隐私方面是多么的匮乏。一家公司、一个办公室、一位兽医，在我打电话请求服务仅仅五分钟后，就给我发消息。

他们专门给我发消息做广告，并且使用了**我并未提供给他们**的信息。

因此，显然隐私是我们整个社会的一个问题，而这个问题在人工智能领域并没有减轻。

ChatGPT和DALL-E等程序目前在隐私问题上尤其引人注目，因为它们倾向于使用未经授权包含在其底层大型数据模型中的数据。

目前，我相信有一个作家联盟正试图起诉OpenAI，因为ChatGPT使用了他们未授权OpenAI使用的书籍数据，以便通过处理这些文本来学习更多关于英语的知识。

而DALL-E曾一度因在其生成的任何图片中都带有显著的水印照片而闻名，因为它使用了大量带有水印的图片进行训练，而这些水印图片本意并非供另一家公司商业使用。

这恰恰例证了我们本质上都是AI模型的素材。我们创造的每样东西、发布的每样内容、在线的每样东西，都可能、也将会被下载，以帮助提升某些AI模型的性能。

不仅仅是这些生成式AI。大型公司也运行复杂的人工智能算法，来设计对其每个用户都**惊人地详细和准确**的档案。

谷歌和亚马逊等大公司创建模型，以便能更好地向用户投放广告。其中一些广告可能**准确得惊人且时机恰当**。

有一个相当著名的例子，某人发现自己怀孕了，还没有告诉任何人。

但几乎立即开始收到与怀孕、分娩相关的广告。这就是这些精算程序、这些预测算法有多么准确和全面。

尽管考虑到隐私侵犯的普遍性，这或许让人感觉是学术性的、不切实际的抱怨，但这绝非小事，因为没有任何数据库是完美的。

没有任何数据库是绝对安全的。高度敏感信息的数据泄露非常频繁，人工智能也不例外。

这些程序中包含的信息令人不安地容易被获取。最近有一个丑闻，某个特定的生成式AI程序可以被诱导泄露它与其他用户的私人对话。

因此，你输入该AI的任何内容，不仅其创建者可以查阅，其他用户也可能看到。这再次惊人地展示了在当今环境下，我们对隐私的期望是多么低。

我提到这些并不是说情况会自行改善。缺乏隐私对广告商来说是福音，这种好处可能利润丰厚到难以轻易放弃。

但无论我们在隐私期望方面下滑了多远，在将任何AI应用应用于问题时，这无疑仍然是一个值得考虑的问题。

---

**总结**

本节课中，我们一起学习了人工智能伦理中的隐私问题。我们了解到，在数字时代，个人隐私正通过手机、应用和各种在线活动被大规模收集和追踪。人工智能，特别是生成式AI和大公司的预测算法，通过使用未经授权的数据或构建详细用户档案，进一步加剧了隐私风险。关键点在于，隐私侵犯已成为常态，且由于商业利益的驱动，改善前景并不乐观。因此，在商业中应用人工智能时，必须将隐私保护作为一个核心的伦理考量因素。
