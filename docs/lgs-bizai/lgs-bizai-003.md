# 3：探索人工智能应用 🤖

在本节课中，我们将学习人工智能在现实世界中的多种应用实例，并重点探讨生成式人工智能（GenAI）的运作方式、潜在风险以及使用时应考虑的关键伦理问题。

---

## 人工智能的多样化应用

上一节我们了解了人工智能的基本概念，本节中我们来看看人工智能技术在实际场景中的具体应用。以下是几个关键领域的例子：

*   **自动驾驶汽车**：依赖人工智能分析海量数据库，学习识别外观、位置多变的障碍物、交通标志和行人。
*   **垃圾邮件过滤器**：通过评估用户手动标记为垃圾邮件的邮件，学习判断何为垃圾邮件。
*   **自动化招聘经理**：根据对已有职位人员简历的分析，构建理想候选人画像，并据此接受或拒绝求职申请。
*   **诊断程序**：能够解读医疗统计数据和其他传感器读数，并根据描述各种病症常见症状的底层数据提供建议。
*   **媒体推荐系统**：至少能部分地根据用户已建立的偏好推荐内容。例如，TikTok的算法将观看视频数秒视为一种认可，不仅根据你的偏好，还会根据它认为与你相似的其他用户的偏好来推荐视频。

## 生成式人工智能（GenAI）的核心机制

在众多人工智能工具中，像ChatGPT或DALL-E这样的生成式人工智能无疑是当下的焦点。它们的工作原理虽然极其复杂，但本质上与其他AI程序相同。

其核心是一个**预测系统**，而非真正的智能。它通过识别海量数据中的模式，并利用这些模式来生成令人惊讶的连贯回应。

**公式/核心机制**：
`生成式AI输出 = f(海量训练数据中识别的模式 + 用户输入的提示词)`

例如，本演示文稿的第四张幻灯片完全由ChatGPT生成。幻灯片上的文字以及我所讲述的内容，都是ChatGPT根据我给出的关于“人工智能伦理”的提示词所撰写的。

## 使用生成式人工智能的潜在风险与关键问题

生成式AI的灵活性和高质量输出也引发了一些担忧。它可能显得如此能干和有见地，以至于人们难以相信它是机器，这甚至引发了关于其是否属于“强人工智能”的讨论。目前看来这不太可能，但由于如此强大的工具触手可及，人们总是倾向于将工作外包给它们。

如果我在非演示目的下使用ChatGPT，或者未披露幻灯片由ChatGPT撰写，那就构成了抄袭。像任何工具一样，它易于使用，也易于滥用。

以下是使用生成式AI（尤其在学术环境中）时，需要问自己的几个重要问题：

*   **我是否在抄袭？** 如果将AI的产出谎称为自己的劳动成果，就是抄袭。如果事先说明使用方式或获得使用许可，则不一定构成抄袭。在许多非正式场合（如写感谢信），使用谷歌搜索建议和询问ChatGPT差别不大。
*   **我是否在传播未经证实的主张？** 生成式AI已知会对甚至简单的问题产生“幻觉”，给出错误答案。它们无法判断信息的真伪，且其知识库的底层数据可能包含错误信息。因此，**验证AI的答案至关重要**。一个著名的反面案例是，一位律师让ChatGPT列举相关法律案例，后来却发现这些案例根本不存在。
*   **我是否意识到偏见的存在？** 即使在AI的回应无法客观判断对错的情况下，它仍可能包含受其底层数据影响的偏见。假设AI的回应完整涵盖了某个问题是危险的，应进行补充研究以确保考虑到所有相关视角。
*   **我是否在损害自身能力发展？** 有效使用GenAI是一项宝贵技能，但写作、研究和形成独立结论的能力同样重要。过度依赖GenAI可能让我逃避练习其他技能。从学习中完全剔除努力，必然会损害重要技能的获取，包括投身于不熟悉或不理想任务的能力。
*   **我是否泄露了隐私信息？** 拥有GenAI程序的公司通常永久有权访问输入聊天窗口的任何内容。分享高度个人化、可归罪或专有的信息可能是危险甚至非法的。例如，陪审员将敏感案件细节输入ChatGPT并让其帮助决定如何投票，会惹上麻烦。

## 学术界对生成式AI的应对

学术不端行为并非新事物，但ChatGPT等程序的极高可及性将问题提升到了新高度。让学生用AI完成作业变得异常容易。

对此，教育者们采取了不同策略：
*   有些教师翻转课堂结构，课外进行教学，所有作业在课堂内于教师监督下完成。
*   有些教师要求手写作业，以防学生直接复制粘贴AI生成的内容。
*   有些教师对被抓到用AI抄袭的学生实施严厉惩罚。
*   另一些教师则选择将GenAI视为工具，无条件鼓励学生使用。

然而，没有一种解决方案是完美的，坚定的学生总能找到规避方法。
