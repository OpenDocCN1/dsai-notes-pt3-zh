# 2：什么是人工智能？🤖

在本节课中，我们将要学习人工智能的基本定义，了解它与传统计算机程序的区别，并探讨其核心工作原理与当前发展水平。

---

人工智能是一种计算机程序。然而，其推理方式和功能目标，即AI程序背后的目标及其计算输出的方式，使其区别于其他非AI程序。

对于某些常见的计算工具，这种区别显而易见。例如，一个基础的计算器不是人工智能。它只是将少量数学函数硬编码到设备中。计算器的底层代码不依赖于机器学习，也不涉及从海量数据中提取趋势进行整合。这或许是最好的安排，因为计算器不需要AI的任何优势，反而可能深受AI相关风险的影响。

从更哲学的角度看，人工智能的独特之处在于，它在某种程度上近似于人类智能。但问题在于，人类智能中“人类”的部分指什么？这可能意味着AI程序能够自我修正，随着接触更多数据而逐渐学习并改进。也可能意味着AI程序能够独立运作，拥有自己的世界。还可能意味着AI程序能够解决那些长期以来被认为是人类思维专属领域的问题。

探讨人类与人工智能之间相互作用最著名的实例，或许是“模仿游戏”，也被称为**图灵测试**。计算机科学史上最具影响力的人物之一艾伦·图灵，将“计算机能否思考”这个复杂问题简化了：一个AI程序能否让另一个人信服地认为它是人类？换言之，与其问“机器能思考吗？”，不如问机器能否做到我们这些会思考的生物所能做的事。显然，它们能做我们做的某些事，例如检查文档拼写或规划飞机航线。但在模仿游戏中，计算机被要求对来自另一个人的、陌生且不可预测的刺激做出恰当反应。

规则很简单：一名评估者与一个人和一台计算机进行对话，理想情况下使用不会暴露身份的方式（例如聊天界面）。机器被编程以模仿人类行为，而另一个人也试图表现得像人（这理应是一项直接的任务）。如果评估者能分辨出两个对话伙伴中哪一个是机器，那么该程序就未能通过模仿游戏。成功通过测试并不代表程序就是人类甚至真正具有智能，但它确实证明了该程序在“模仿人类”这项任务上的灵活性与敏锐度。当然，除非评估者特别天真、轻信或不善观察，或者另一个人表现得特别像机器人或令人感到诡异。

无论在图灵测试中表现如何，人工智能尚未达到**强人工智能**或**通用人工智能**的水平。强人工智能是科幻小说的内容，它能够无需大量训练就掌握新技能，并能展现出人类水平的感知力。《星际迷航》中的Data就是一个强人工智能的例子。尽管近年来AI程序在许多方面取得了进展，一些人表达了对强人工智能可能崛起的担忧，但幸运的是，根据目前所有可用信息，这种担忧是**没有根据的**。我们极不可能面临来自自主行动的人工智能的任何严重威胁。

我们更应关注的是AI程序如何被制造出来，即使用什么方法和数据来创建它们，以及AI如何被使用。这是因为我们目前所接触的，可以被称为**弱人工智能**。弱人工智能能做惊人的事情，正如我们近年来所见，但它只是在人类的指令下运作，并且只有在人类向其输入大量数据以教会它如何完成任务之后。

人工智能的许多效用都基于一个简单的过程：从大量数据中，程序可以提取出模式，尤其是那些对人类而言不明显或不直观的模式。这个被称为**机器学习**的过程，主要采取两种形式：

以下是机器学习的两种主要类型：

*   **监督学习**：用于分类和预测。程序被给予原始数据以进行分类或预测结果。关键在于，AI同时被给予了正确答案，并被允许去猜测如何得出这些正确结论。例如，输入数据可能包含人口统计数据，而期望的输出数据可能是每个人是否投票。在充分猜测后，AI会被给予新的、未标记的数据，以检验它是否仍能生成正确答案。
*   **无监督学习**：不需要给AI标记好的输出结果。相反，程序在没有人类指导的情况下，自行寻找数据中的关联和模式。这有许多应用，但通常涉及基于不直观的联系对项目进行分组。例如，自动创建一个很可能适合特定用户口味的歌曲播放列表。

那么，为了总结非AI程序与AI程序之间的区别：非AI程序基于预设规则运行，不会因引入新数据而改变或提升其能力。非AI程序也不需要海量数据来形成其假设。而AI则依赖于通过对假设进行反复测试，从而对其结论进行渐进式改进。这需要海量数据才能正确完成，但该过程使得AI能够独立得出那些人类可能无法预先编程的结论。
