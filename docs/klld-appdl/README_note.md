# 科罗拉多应用深度学习笔记 01 🧠

在本节课中，我们将要学习深度学习的基础概念，特别是神经网络如何通过调整内部参数来学习数据中的模式。我们将从最简单的线性模型入手，逐步理解其核心机制。

## 概述：什么是学习？

上一节我们介绍了课程背景，本节中我们来看看机器“学习”的本质。在机器学习中，“学习”是指一个模型根据输入数据自动调整其内部参数的过程。目标是让模型的输出尽可能接近真实值或期望值。

这个过程的核心是定义一个**损失函数**，它量化了模型预测与真实值之间的差距。学习的目标就是找到一组模型参数，使得这个损失函数的值最小化。

## 线性模型与损失函数

一个基础的线性模型可以表示为：

**`y_pred = w * x + b`**

其中，`x`是输入特征，`w`是权重参数，`b`是偏置参数，`y_pred`是模型预测值。

为了衡量预测的好坏，我们引入**均方误差**作为损失函数：

**`Loss = (1/N) * Σ(y_true - y_pred)²`**

这里的`y_true`代表真实值，`N`是样本数量。我们的目标就是找到合适的`w`和`b`，使`Loss`最小。

## 梯度下降算法

那么，如何找到最小化损失函数的参数呢？最常用的方法是**梯度下降**。

梯度下降的核心思想是：函数在某一点的梯度方向指向其值增加最快的方向。因此，沿着梯度的反方向更新参数，就能逐步降低函数值。

参数更新遵循以下公式：

**`w_new = w_old - α * (∂Loss/∂w)`**
**`b_new = b_old - α * (∂Loss/∂b)`**

其中，`α`是一个关键的超参数，称为**学习率**。它控制了每次参数更新的步长。

以下是选择学习率时需要注意的几个要点：
*   学习率太小，会导致收敛速度过慢，需要很多轮迭代。
*   学习率太大，可能导致更新步伐过大，在最小值附近震荡甚至发散。
*   通常需要通过实验来选择一个合适的学习率。

## 从线性回归到神经网络

线性模型是神经网络的基本构建块。我们可以将一个神经元看作一个增强版的线性模型。

神经元的计算包含两步：
1.  **线性变换**：`z = w * x + b`
2.  **非线性激活**：`a = σ(z)`，其中`σ`代表激活函数，如Sigmoid或ReLU。

激活函数的引入至关重要，它使神经网络能够拟合输入与输出之间的复杂非线性关系。多个这样的神经元连接成层，层与层之间串联，就构成了深度神经网络。

## 反向传播：高效计算梯度

对于深度神经网络，我们需要计算损失函数对网络中每一个参数的梯度。手动计算非常繁琐。

**反向传播**算法高效地解决了这个问题。它利用链式法则，从输出层开始，反向逐层计算梯度。

具体过程是，先进行前向传播得到预测值和损失，然后将损失从后向前传播，利用导数链式法则计算每一层参数的梯度。优化器（如梯度下降）再利用这些梯度来更新所有权重`w`和偏置`b`。

## 总结

本节课中我们一起学习了深度学习的基础原理。我们从一个简单的线性模型和均方误差损失函数出发，理解了梯度下降算法如何通过迭代更新参数来最小化损失。我们看到了线性模型如何扩展为具有非线性激活函数的神经元，并了解到多个神经元构成层，层层堆叠形成深度神经网络。最后，我们介绍了反向传播算法，它是高效计算深度网络中所有参数梯度的核心机制，使得训练复杂模型成为可能。
