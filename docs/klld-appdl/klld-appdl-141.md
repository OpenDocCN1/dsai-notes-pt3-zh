## 回顾与过渡：从分数化卷积到GAN训练技巧

![](img/110b168662b60987b0cc260ce3776cb0_1.png)

上一节我们介绍了分数化卷积（Fractionally Strided Convolution），并了解到它并非新技术，而是在反向传播计算梯度时自然发生的操作。现在，我们将利用相同的技术来提升图像分辨率。

具体操作是：你有一组生成的图像，并且知道每个图像对应的潜在向量 **z**。因此，你拥有一个由生成图像和其 **z** 向量组成的数据集。例如，你可以找出所有戴眼镜的男性生成图像，对它们的 **z** 向量取平均，然后将这个平均 **z** 输入生成器，就能得到“戴眼镜男性”的平均脸。同样，对“不戴眼镜男性”的 **z** 向量取平均，可以得到对应的平均脸。你甚至可以在这些平均 **z** 向量上进行运算，例如相减后再加上代表女性的向量，从而生成“戴眼镜女性”的脸部图像。

### 特征匹配（Feature Matching）

我们学习的第一个技巧是特征匹配。与其让判别器直接区分真假，不如让它关注特征。具体做法是：去掉判别器的最后一层（分类头），使用中间某一层或多层的输出作为特征。这被称为特征匹配。

### 模式崩溃（Mode Collapse）

![](img/110b168662b60987b0cc260ce3776cb0_32.png)

![](img/110b168662b60987b0cc260ce3776cb0_33.png)

![](img/110b168662b60987b0cc260ce3776cb0_34.png)

![](img/110b168662b60987b0cc260ce3776cb0_35.png)

GAN存在一个重大问题，即模式崩溃。如果你的真实图像数据是双峰分布，在训练过程中，生成器可能会只收敛到其中一个模式。人们并不完全清楚其原因，可能是损失函数的问题，也可能是网络结构的问题，但这种现象确实存在。后续许多论文都试图解决这个问题。

![](img/110b168662b60987b0cc260ce3776cb0_37.png)

![](img/110b168662b60987b0cc260ce3776cb0_38.png)

以下是应对模式崩溃的一种方法：不是独立处理每个图像，而是让一个批次（mini-batch）内的样本相互“看见”彼此。假设输入特征为 **F1, F2, ..., FN**，它们最初是独立的。但经过一个参数为 **T** 的网络结构后，会得到相互依赖的输出 **O1, O2, ..., ON**。这样，样本之间就能建立联系，了解彼此的相似度。我们跳过了具体的数学推导，除非你有疑问。

### 单侧标签平滑（One-sided Label Smoothing）

还有一个技巧是单侧标签平滑。标签平滑的目的是让判别器“笨”一点。有时判别器过于聪明，在训练初期或中期很容易区分真假图像。我们知道，如果判别器太容易区分，其梯度会变为零。而生成器实际上位于判别器内部，如果判别器的梯度为零，生成器就无法学习。因此，你需要让判别器“笨”一点。

![](img/110b168662b60987b0cc260ce3776cb0_59.png)

![](img/110b168662b60987b0cc260ce3776cb0_60.png)

![](img/110b168662b60987b0cc260ce3776cb0_61.png)

标签平滑的做法是：不再给真实数据标签赋值为1，生成数据标签赋值为0。而是给真实数据标签赋值为0.9，给生成数据标签赋值为另一个数（例如0.1）。但这里有个问题：如果β不为零，并且生成器的分布与真实数据分布不匹配，判别器可能会被推向错误的预测。因此，我们采用“单侧”平滑，即设置β=0，然后可以调整α（例如设为0.9）。

### 虚拟批归一化（Virtual Batch Normalization）

另一个技巧可能与批归一化有关。批归一化本应有助于训练，但也许因为每个小批次的统计量（均值和标准差）都在变化，导致网络无法正常收敛。解决方案是：预留一组参考样本，在训练开始时收集并固定它们。在训练过程中，计算当前样本的均值和标准差时，会结合这组固定参考批次的统计量，以此来进行批归一化。

## 核心贡献：Inception Score 📊

然而，这篇论文最重要的贡献是提出了 **Inception Score**。

生成图像是一项创造性任务。与分类任务可以通过准确率评估不同，生成图像的质量在此前只能定性评估。研究者会展示生成的图像，让人判断其真实性，或者比较不同方法生成的图像哪个更逼真。

![](img/110b168662b60987b0cc260ce3776cb0_85.png)

![](img/110b168662b60987b0cc260ce3776cb0_86.png)

![](img/110b168662b60987b0cc260ce3776cb0_87.png)

![](img/110b168662b60987b0cc260ce3776cb0_88.png)

![](img/110b168662b60987b0cc260ce3776cb0_89.png)

![](img/110b168662b60987b0cc260ce3776cb0_90.png)

这篇论文提出：我们非常擅长判别，何不利用一个在ImageNet上预训练好的分类网络（例如Google的Inception模型）来评估生成图像？这个网络是固定的，不参与训练。

![](img/110b168662b60987b0cc260ce3776cb0_91.png)

![](img/110b168662b60987b0cc260ce3776cb0_92.png)

![](img/110b168662b60987b0cc260ce3776cb0_93.png)

![](img/110b168662b60987b0cc260ce3776cb0_94.png)

![](img/110b168662b60987b0cc260ce3776cb0_95.png)

![](img/110b168662b60987b0cc260ce3776cb0_96.png)

具体流程如下：生成一批假图像，将它们输入这个预训练好的分类网络，网络会为每张图像输出一个类别标签的概率分布。

**我们希望从这些标签中得到什么？**

![](img/110b168662b60987b0cc260ce3776cb0_98.png)

![](img/110b168662b60987b0cc260ce3776cb0_99.png)

![](img/110b168662b60987b0cc260ce3776cb0_100.png)

![](img/110b168662b60987b0cc260ce3776cb0_101.png)

1.  **多样性（高熵）**：如果你生成大量图像，并平均它们对应的类别概率分布，你会得到一个在所有类别上的边缘分布 **p(y)**。你希望这个分布具有高熵，即覆盖尽可能多的类别（如猫、狗、飞机、老虎等），这意味着生成图像的内容是多样的。
2.  **清晰度（低熵）**：对于单张生成的图像，你希望它的类别概率分布 **p(y|x)** 具有低熵。这意味着图像内容明确，例如一张“狗”的图片，模型应该以很高的置信度将其归类为“狗”，而不是模糊不清。

![](img/110b168662b60987b0cc260ce3776cb0_102.png)

![](img/110b168662b60987b0cc260ce3776cb0_103.png)

![](img/110b168662b60987b0cc260ce3776cb0_104.png)

![](img/110b168662b60987b0cc260ce3776cb0_105.png)

![](img/110b168662b60987b0cc260ce3776cb0_106.png)

![](img/110b168662b60987b0cc260ce3776cb0_107.png)

![](img/110b168662b60987b0cc260ce3776cb0_108.png)

![](img/110b168662b60987b0cc260ce3776cb0_109.png)

**Inception Score** 将这两个目标结合在一起。其公式为：
`exp( E_x [ KL( p(y|x) || p(y) ) ] )`

其中：
*   `KL( p(y|x) || p(y) )` 是单张图像类别分布 `p(y|x)` 与整体边缘分布 `p(y)` 之间的KL散度。它衡量了单张图像的“特异性”与整体“多样性”的差异。
*   `E_x[.]` 表示对所有生成图像求期望（平均）。
*   最后取指数是为了让得分值更大，便于比较。

![](img/110b168662b60987b0cc260ce3776cb0_111.png)

得分越高，通常意味着生成图像的质量越好（既清晰又多样）。

![](img/110b168662b60987b0cc260ce3776cb0_112.png)

![](img/110b168662b60987b0cc260ce3776cb0_113.png)

## GAN在半监督学习中的应用 🎓

现在，让我们看一个GAN的另一个应用场景。我们之前学过GAN可以用于特征工程。那么，能否利用GAN来帮助我们利用未标注的数据，让模型变得更聪明呢？这就是半监督学习的任务。

假设你有一小部分标注数据和大量未标注数据。你希望高效地利用所有数据。

**如何利用GAN？**

1.  你原本有K个类别。你的分类器输出K个逻辑值（logits），然后通过softmax得到概率。
2.  现在，你将所有未标注数据归入第K+1个“类别”。这样你就有K+1个类别了。
3.  你的目标函数包含两部分：
    *   **有监督部分**：对于所有有标签的数据（类别1到K），最大化其正确类别的对数似然。
    *   **无监督部分**：对于所有无标签数据以及生成器生成的假数据，我们希望模型能将它们判别为第K+1类（即“未标注/假”数据）。
4.  关键的一步是：我们定义判别器 **D(x)** 为模型认为输入 **x** 是“真实标注数据”（即不属于第K+1类）的概率。可以推导出，如果我们固定第K+1类的逻辑值为0，那么 **D(x)** 可以表示为：
    `D(x) = Z(x) / (Z(x) + 1)`
    其中 `Z(x) = sum( exp(logits_i) ) for i=1 to K`，即前K类逻辑值的指数和。
5.  因此，这个共享参数的模型同时肩负两个目标：
    *   作为一个分类器，正确分类有标签的真实数据（1到K类）。
    *   作为一个判别器，区分真实数据（无论是否有标签）和生成器生成的假数据（都将被推向第K+1类）。
6.  生成器的训练目标仍然是欺骗这个判别器，即让生成的图像不被判为第K+1类。

直观上，你希望你的模型既能区分真假，又能对真实数据进行准确分类。通过这种方式，未标注的真实数据和生成的假数据都参与了模型参数的优化，从而提升了模型在半监督设定下的性能。

## 总结 📝

本节课中，我们一起学习了：
1.  **GAN的训练技巧**：包括特征匹配、应对模式崩溃的方法、历史平均、单侧标签平滑和虚拟批归一化，这些技术旨在稳定GAN的训练过程。
2.  **Inception Score**：这是一个重要的量化指标，用于评估生成图像的质量，通过衡量生成图像的**清晰度**和**多样性**来给出分数。
3.  **GAN在半监督学习中的应用**：我们探讨了如何通过修改模型结构，让GAN同时完成数据分类和真假判别的任务，从而利用大量未标注数据来提升模型性能。

通过这些内容，我们更深入地理解了如何训练、评估以及拓展生成对抗网络的应用范围。
