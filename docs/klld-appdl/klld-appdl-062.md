## 🏗️ U-Net 架构概览

U-Net 最初是为图像分割任务设计的。其名称来源于其 U 形的网络结构。

上一节我们介绍了图像分割的基本概念，本节中我们来看看 U-Net 如何具体实现这一任务。

网络处理流程如下：你从一张输入图像开始，经过一系列精心设计步长的操作。图中蓝色箭头代表 3x3 卷积操作。

以下是 U-Net 的核心处理步骤：

![](img/9970c132ebdce7eb0f9b8352988bd343_3.png)

1.  进行两次 3x3 卷积。
2.  进行一次步长为 2 的最大池化，这会降低图像分辨率。
3.  重复进行多次卷积和步长为 2 的池化操作。
4.  在网络的“底部”（即编码器末端）进行一系列卷积。
5.  开始进行上采样，即反卷积操作。
6.  再进行反卷积和一系列卷积。

![](img/9970c132ebdce7eb0f9b8352988bd343_5.png)

然而，我们在之前的论文中也看到过一个关键思想：需要保留局部信息。U-Net 的独特之处在于，它通过跳跃连接将编码器阶段的局部信息直接复制并拼接到解码器的对应层。

![](img/9970c132ebdce7eb0f9b8352988bd343_7.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_9.png)

这只是一个通道维度的拼接操作。通过在不同分辨率层级进行这种“复制-粘贴”操作，网络能够有效地融合深层语义信息和浅层细节信息。剩余的网络部分是常规的前向传播。

![](img/9970c132ebdce7eb0f9b8352988bd343_11.png)

正因为这种先下采样再上采样、并伴有跳跃连接的对称结构，网络呈现出 U 形，故得名 U-Net。

![](img/9970c132ebdce7eb0f9b8352988bd343_13.png)

## 🔢 核心操作的数学原理

上一节我们介绍了 U-Net 的整体架构，本节中我们来看看支撑其运行的核心数学操作，特别是反卷积的精确公式。

### 3x3 卷积的展开

首先，我们从卷积开始，并将其展开为数学项。我们想知道在像素位置 (x, y) 和通道 l 上，一个 3x3 卷积的输出值。

公式如下：
`output(x, y, l) = Σ_k Σ_{a=-1}^{1} Σ_{b=-1}^{1} w_{a,b,k,l} * input(x+a, y+b, k)`

![](img/9970c132ebdce7eb0f9b8352988bd343_15.png)

其中：
*   `input(x, y, k)` 是输入，取决于位置 (x, y) 和通道 k。
*   求和项 `a` 和 `b` 从 -1 到 1，代表取输入中以 (x, y) 为中心的 3x3 窗口。
*   `w_{a,b,k,l}` 是卷积核的权重标量。
*   对 `k` 的求和是跨输入通道的内积操作。
*   `l` 代表不同的输出滤波器。

![](img/9970c132ebdce7eb0f9b8352988bd343_17.png)

这本质上就是取输入的一个小 3x3 窗口，与权重矩阵相乘后求和。

![](img/9970c132ebdce7eb0f9b8352988bd343_19.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_21.png)

### 步长为 2 的 2x2 最大池化

![](img/9970c132ebdce7eb0f9b8352988bd343_23.png)

步长为 2 意味着你每两个像素跳跃一次，因此公式中会出现因子 2。你取一个 2x2 的窗口并计算其最大值（如果是平均池化则计算均值）。

![](img/9970c132ebdce7eb0f9b8352988bd343_25.png)

这即是降低分辨率的方式。

![](img/9970c132ebdce7eb0f9b8352988bd343_27.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_29.png)

### 反卷积（转置卷积）

现在来看反卷积。我们重用卷积的权重，因此它被称为分数步长卷积或转置卷积。

![](img/9970c132ebdce7eb0f9b8352988bd343_31.png)

我们知道步长将为 2，因为我们想要上采样。我们想知道输出在位置 `(2x + 0 或 1, 2y + 0 或 1)` 的值。

![](img/9970c132ebdce7eb0f9b8352988bd343_33.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_35.png)

关键在于，在输入层可能只有一个像素参与计算。这个单一的像素会通过重用权重，为输出层生成多个像素（例如四个像素）。

公式可以表示为对输入像素的加权展开，其中相同的输入像素值乘以不同的权重，以产生输出的不同位置的值。

通道维度（k 和 l）的处理并不复杂，它只是矩阵向量乘法。但在像素维度上，是多个权重乘以同一个输入像素值。

这就是反卷积的精确公式。一旦你理解了其映射关系，就会发现这些操作并不复杂，尽管可视化可能更困难。我们在之前几节中可视化神经网络特征时，也使用过类似的反卷积操作。

![](img/9970c132ebdce7eb0f9b8352988bd343_37.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_39.png)

在 TensorFlow 或 PyTorch 等框架中，底层实现的就是这种操作。

## ⚖️ 图像分割的损失函数

![](img/9970c132ebdce7eb0f9b8352988bd343_43.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_45.png)

上一节我们解析了网络的核心操作，本节中我们来看看 U-Net 论文中为生物医学图像分割量身定制的损失函数。

![](img/9970c132ebdce7eb0f9b8352988bd343_47.png)

我们暂时忽略权重 w，先将其设为 1。目标是增加每个像素被正确标记的概率。

![](img/9970c132ebdce7eb0f9b8352988bd343_49.png)

设 `p_{l}(x)` 是网络通过 softmax 输出的、像素 x 属于真实标签 l 的概率。我们希望最大化这个概率，等价于最小化其负对数。

![](img/9970c132ebdce7eb0f9b8352988bd343_51.png)

因此，基础损失函数是逐像素的交叉熵损失：
`L = - Σ_{x} log(p_{l(x)}(x))`

其中 `l(x)` 是像素 x 的真实标签。

![](img/9970c132ebdce7eb0f9b8352988bd343_53.png)

但在生物医学图像分割中，存在两个突出问题：
1.  **类别不平衡**：某些类别（如背景）的像素远多于其他类别（如细胞）。
2.  **边界重要性**：细胞之间的边界区域对于形态学分析至关重要，但边界像素数量很少。

![](img/9970c132ebdce7eb0f9b8352988bd343_55.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_57.png)

因此，U-Net 论文引入了加权损失函数：
`L = - Σ_{x} w(x) * log(p_{l(x)}(x))`

![](img/9970c132ebdce7eb0f9b8352988bd343_59.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_61.png)

权重 `w(x)` 由两部分构成：
`w(x) = w_c(x) + w_0 * exp( - (d_1(x)^2 + d_2(x)^2) / (2σ^2) )`

![](img/9970c132ebdce7eb0f9b8352988bd343_63.png)

以下是权重函数各部分的解释：

![](img/9970c132ebdce7eb0f9b8352988bd343_65.png)

*   **`w_c(x)`**：用于处理类别不平衡。它基于每个类别在训练集中的频率计算得出，是一个常数。
*   **`w_0 * exp(...)`**：用于强调边界。其中：
    *   `d_1(x)`：像素 x 到最近细胞边界的距离。
    *   `d_2(x)`：像素 x 到第二近细胞边界的距离。
    *   `σ`：控制权重衰减速度的参数。
    *   `w_0`：一个常数缩放因子。

![](img/9970c132ebdce7eb0f9b8352988bd343_67.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_69.png)

这个指数项的作用是：当像素距离边界很远时（`d_1` 很大），指数项值很小，该像素在损失中的权重就小；当像素位于边界附近时（`d_1` 很小），指数项值较大，该像素获得更高的权重，迫使网络更关注边界的准确性。

![](img/9970c132ebdce7eb0f9b8352988bd343_71.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_73.png)

在训练时，由于我们知道真实标签，因此可以计算出每个像素的 `d_1` 和 `d_2`。

![](img/9970c132ebdce7eb0f9b8352988bd343_75.png)

## 🛠️ 其他重要技巧与结果

![](img/9970c132ebdce7eb0f9b8352988bd343_81.png)

![](img/9970c132ebdce7eb0f9b8352988bd343_83.png)

除了核心架构和损失函数，U-Net 论文还采用了一些关键技巧来提升性能，特别是在数据有限的生物医学领域。

![](img/9970c132ebdce7eb0f9b8352988bd343_85.png)

### 反射填充

在卷积操作中，为了保持输出尺寸，通常需要进行填充。U-Net 论文没有使用零填充，而是采用了**反射填充**。这意味着将图像边缘的像素进行镜像反射，然后复制粘贴到填充区域。这比零填充能提供更真实的上下文信息。

### 分块训练与预测

由于全尺寸图像可能很大，U-Net 通常不是将整张图像输入网络。相反，它将输入图像分割成重叠的小图块（tiles），分别对每个图块进行预测，最后将所有的预测结果拼接起来，形成完整的分割图。在重叠区域，可以对预测值进行平均或其它组合。

### 数据增强

在生物医学等数据稀缺的领域，数据增强至关重要。U-Net 的成功离不开大量的数据增强，包括：
*   平移和旋转。
*   弹性形变（模拟真实的组织形变）。
*   灰度值变化（模拟不同的光照和染色条件）。

这些技术极大地增加了数据的多样性，提高了模型的鲁棒性。

### 实验结果

在论文展示的结果中：
*   第一张图是原始生物医学图像。
*   第二张图是专家提供的真实标签（Ground Truth）。
*   第三张图是 U-Net 模型的预测输出，能够很好地区分背景和前景。
*   第四张图可视化的是损失权重 `w(x)`，可以看到网络确实给边界区域（白色）赋予了更高的权重。

与其他当时最先进的方法相比，U-Net 在多个数据集上都取得了显著更好的成绩。
