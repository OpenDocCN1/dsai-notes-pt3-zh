上一节我们介绍了循环神经网络（RNN）的基本工作原理。我们知道，一个简单的RNN处理一个输入序列 `x1, x2, ..., xt`，并输出一个**等长**的序列 `y1, y2, ..., yt`。其核心计算过程可以概括为：接收当前输入和隐藏状态，乘以权重矩阵，经过激活函数（如sigmoid）得到新的隐藏状态，最后通过一个输出层得到预测结果。

**公式表示**：
`h_t = σ(W_hh * h_{t-1} + W_xh * x_t)`
`y_t = W_hy * h_t`

## 处理不等长序列：编码器-解码器架构 🏗️

然而，对于像机器翻译这样的任务，输入序列（如“ABC”）和输出序列（如“WXYZ”）的长度通常不同。为了解决这个问题，seq2seq模型引入了**编码器-解码器**架构。

![](img/183825d3878379f4c97fda50b3084bfc_35.png)

以下是该架构的核心步骤：
1.  **编码阶段**：编码器（一个RNN）读取整个输入序列，并将其信息压缩成一个**固定长度的上下文向量**。这个向量旨在概括输入序列的全部语义。
2.  **解码阶段**：解码器（另一个RNN）以上下文向量为初始状态，开始逐步生成输出序列。

![](img/183825d3878379f4c97fda50b3084bfc_36.png)

![](img/183825d3878379f4c97fda50b3084bfc_38.png)

这个架构的关键在于，它将变长输入编码成一个固定表示，再由解码器展开成变长输出。

## 关键改进：提升seq2seq性能 🚀

与早期研究相比，本篇论文提出了三项主要改进，显著提升了seq2seq模型的性能。

![](img/183825d3878379f4c97fda50b3084bfc_46.png)

![](img/183825d3878379f4c97fda50b3084bfc_47.png)

![](img/183825d3878379f4c97fda50b3084bfc_52.png)

![](img/183825d3878379f4c97fda50b3084bfc_53.png)

![](img/183825d3878379f4c97fda50b3084bfc_54.png)

![](img/183825d3878379f4c97fda50b3084bfc_55.png)

以下是三项核心改进：
1.  **使用独立的LSTM**：编码器和解码器使用两个不同的长短期记忆网络（LSTM）。LSTM能更好地捕捉长期依赖关系，缓解梯度消失问题。
2.  **使用深层堆叠LSTM**：在编码器和解码器端都使用多层堆叠的LSTM，以增加模型的容量和表达能力。
3.  **反转输入序列顺序**：这是最重要的一项改进。例如，将输入序列“ABC”反转为“CBA”再输入编码器。这样做的直觉是，在解码器开始生成输出时，源语言句子的**开头部分**（在反转后位于编码器输出的末端）与解码器的**初始状态**更接近，有助于建立更好的短期依赖，从而改善梯度流动和信息传递。

模型的训练需要大量平行的源语言和目标语言句子对（如英法对照语料）。训练目标是最大化给定源句下目标句的条件概率。

在推理（翻译）阶段，我们需要找到最可能的目标序列。这是一个复杂的搜索问题。我们使用**束搜索**算法来近似求解。

![](img/183825d3878379f4c97fda50b3084bfc_68.png)

![](img/183825d3878379f4c97fda50b3084bfc_69.png)

![](img/183825d3878379f4c97fda50b3084bfc_70.png)

![](img/183825d3878379f4c97fda50b3084bfc_72.png)

![](img/183825d3878379f4c97fda50b3084bfc_73.png)

以下是束搜索的简要介绍：
束搜索是一种启发式搜索算法。它在解码的每一步，不是只保留概率最高的一个候选词，而是保留概率最高的 `k` 个（`k` 称为束宽）。然后基于这 `k` 个候选继续扩展，并在每一步重新筛选出新的 top `k`。这种方法比贪婪搜索（只选当前最优）更好，能在计算成本和结果质量间取得平衡。

## 实验结果与分析 📊

论文通过一系列实验验证了改进的有效性。实验使用BLEU分数作为评估指标。

以下是关键实验结果：
*   简单的正向LSTM模型即使使用束搜索，分数也低于传统的非神经网络基线系统。
*   **反转输入序列**带来了巨大的性能提升，使神经网络模型首次超越了之前的神经网络最佳结果。
*   通过**集成**多个不同初始化的反向LSTM模型，并配合束搜索，最终超越了强大的传统机器学习基线系统。
*   另一种有效策略是使用神经网络模型对传统基线系统生成的 `N` 个最佳候选翻译进行**重排序**，选择神经网络认为概率最高的一个，这也能显著提升分数。

这些结果表明，虽然神经网络模型潜力巨大，但要超越精心设计的传统系统仍需诸多技巧和努力。

## 总结与问答 💎

本节课中我们一起学习了序列到序列建模。我们从基础的等长序列RNN出发，引出了处理不等长序列的编码器-解码器框架。我们详细探讨了通过使用独立LSTM、深层堆叠和反转输入顺序来提升模型性能的关键技术。最后，我们了解了使用束搜索进行推理以及通过模型集成和重排序来达到最佳效果的方法。

**核心公式/代码框架**：
```python
# 伪代码示意
context_vector = encoder_LSTM(reversed(input_sequence))
initial_state = context_vector
output_sequence = decoder_LSTM(initial_state)
# 使用束搜索生成 output_sequence
```

---

**关于反转输入顺序的直觉**：这主要是为了缓解RNN中的梯度消失问题。在长序列中，开头的单词信息在反向传播时难以传递到末尾。通过反转，源句的开头（在反转后位于编码器末端）与解码器开始生成的位置更近，建立了更短的路径，使得梯度更容易传播，模型更容易建立开头单词与早期输出之间的联系。

**关于模型集成**：集成是指独立训练多个模型（例如改变隐藏层维度、初始化方式等），在预测时综合它们的输出（如平均它们的预测概率）。这类似于“集体决策”，能平滑单个模型的误差，通常能获得更稳定、更准确的结果，是机器学习中提升性能的常用技术。
