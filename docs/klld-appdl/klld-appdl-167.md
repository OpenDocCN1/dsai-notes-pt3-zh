## 概述与背景

我们之前承诺过，在涉及语音处理时会详细研究LSTM。现在，我们将兑现这个承诺，对LSTM进行一次系统性的学习。当时存在许多不同版本的LSTM，我们只看到了其中一种共识版本。人们希望对这些版本进行比较。我们知道LSTM在手写识别与生成、语言建模与翻译、声学建模与语音合成（如前一篇论文所示）等领域都有应用。它还可以应用于任何具有序列性质的数据，例如蛋白质二级结构预测、音频和视频处理。LSTM在这些领域非常有用，或者至少曾经非常有用。

## LSTM 标准结构回顾

![](img/d095b69795fc4a6c6a754e9ff7cf9277_24.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_25.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_26.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_27.png)

首先，让我们回顾一下我们目前使用的LSTM类型。在时间步 **t**，你有一个输入向量 **x_t**，其大小为 **M**。LSTM块有一个隐藏大小 **n**。

以下是涉及的权重矩阵：
*   **W_z, W_i, W_f, W_o**: 这些权重将输入（大小为 **M**）映射到隐藏状态（大小为 **n**）。
*   **R_z, R_i, R_f, R_o**: 这些是循环权重（或转移权重），大小为 **n × n**，在隐藏空间上操作。

此外，还有**对角矩阵**形式的**窥视孔权重**（peephole weights），可以将其视为向量。根据本文的大规模分析，这些权重实际上并不关键，可以移除。偏置项 **b** 也存在。

![](img/d095b69795fc4a6c6a754e9ff7cf9277_29.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_30.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_31.png)

我们有两个函数：
*   激活函数 **g**：用于输入单元状态（通常为 `tanh`）。
*   **σ**：用于门控单元（sigmoid函数）。

![](img/d095b69795fc4a6c6a754e9ff7cf9277_32.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_33.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_34.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_35.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_36.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_37.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_38.png)

在时间步 **t**，我们接收输入 **x_t** 和上一个输出 **h_{t-1}**。计算过程如下：

![](img/d095b69795fc4a6c6a754e9ff7cf9277_39.png)

1.  **输入调制**：`z̄_t = W_z * x_t + R_z * h_{t-1} + b_z`，然后 `z_t = g(z̄_t)`。
2.  **输入门**：`i_t = σ(W_i * x_t + R_i * h_{t-1} + b_i)`。
3.  **遗忘门**：`f_t = σ(W_f * x_t + R_f * h_{t-1} + b_f)`。
4.  **记忆单元更新**：`c_t = z_t ⊙ i_t + c_{t-1} ⊙ f_t`。这里，`c_{t-1}` 是之前的记忆，`f_t` 控制保留多少过去记忆，`i_t` 控制加入多少新信息。
5.  **输出门**：`o_t = σ(W_o * x_t + R_o * h_{t-1} + b_o)`。
6.  **最终输出**：`h_t = g(c_t) ⊙ o_t`。

## LSTM 的八个主要变体

经过分析，论文指出：
*   **窥视孔权重**并不关键。
*   **遗忘门**至关重要，不能移除。
*   记忆单元的**激活函数 g** 也非常重要，移除会导致性能下降。

![](img/d095b69795fc4a6c6a754e9ff7cf9277_49.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_50.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_51.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_52.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_53.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_54.png)

基于标准LSTM，可以通过移除或修改组件来定义八个变体。以下是这些变体的描述：

![](img/d095b69795fc4a6c6a754e9ff7cf9277_55.png)

![](img/d095b69795fc4a6c6a754e9ff7cf9277_56.png)

1.  **无输入门**：将输入门 `i_t` 恒设为 1。
2.  **无遗忘门**：将遗忘门 `f_t` 恒设为 1（即记住过去的一切）。
3.  **无输出门**：将输出门 `o_t` 恒设为 1。
4.  **无输入激活函数**：移除 `g` 函数，不对线性操作进行非线性变换。
5.  **无输出激活函数**：移除输出前的 `g` 函数。
6.  **耦合输入与遗忘门**：令 `f_t = 1 - i_t`。这正是**门控循环单元** 的设置。
7.  **无窥视孔连接**：移除所有窥视孔权重。
8.  **全门循环**：这是一种非常昂贵的变体，其循环连接不仅依赖于 `x_t` 和 `h_{t-1}`，还依赖于所有内部状态（如 `c_{t-1}`, `i_t`, `f_t`, `o_t`）。

论文进行了大量实验来比较这些设置。每个模型在每个数据集上进行了 **200 次试验**，总计试验次数非常多，需要大量GPU时间进行收敛。

使用的三个数据集是：
1.  **TIMIT**：用于语音识别（音素分类）。
2.  **IAM-OnDB**：用于在线手写识别。数据是一个4维向量序列：笔的位置变化 (Δx, Δy)，从笔画开始的时间，以及一个指示笔是否抬起的标志。
3.  **JSB Chorales**：用于复调音乐建模，包含3824首四声部和声合唱曲。

## 实验结果与分析

实验结果以统计图表形式呈现。图表中的**箱线图**展示了所有模型性能的25%和75%分位数。**须线**表示性能范围。**红点**代表均值，**虚线**代表中位数。

**粗体蓝色箱线**表示该变体的性能与基线（标准LSTM，即 `Vanilla`）有显著差异。**灰色直方图**表示该变体的平均参数量。

关键发现如下：
*   **遗忘门**至关重要。移除遗忘门的变体性能显著下降。
*   **输出激活函数 `g`** 也非常关键，移除会导致性能显著变差。
*   **耦合输入与遗忘门**的变体性能与标准LSTM相似，这就是GRU。多项研究表明，LSTM和GRU之间没有显著差异，且参数量相近（GRU可能略少）。
*   **窥视孔权重**可以被移除，对性能影响不大。

这些结论在TIMIT、手写识别和音乐建模数据集上都得到了一致验证。

## 总结

本节课我们一起深入研究了LSTM。通过一篇大规模分析论文，我们了解了LSTM标准结构中的各个组件，并比较了其八个主要变体。

我们明确了哪些组件是LSTM成功的关键：
*   **遗忘门**和**记忆单元激活函数**是核心，不可或缺。
*   **窥视孔连接**并非必需。
*   **GRU**作为LSTM的一个变体（耦合输入与遗忘门），在实践中表现出与标准LSTM相当的性能，这解释了为什么在语言、视频、语音等任务中，通常只看到标准LSTM和GRU这两种架构被广泛使用。

现在，你知道了为什么我们在处理各种序列任务时会坚持使用特定的LSTM或GRU设置，也理解了其背后的实验依据。
