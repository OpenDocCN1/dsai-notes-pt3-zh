## 数据收集与处理

![](img/33757f97d185b28c5313eed5159afb38_3.png)

![](img/33757f97d185b28c5313eed5159afb38_4.png)

首先，需要在汽车前方安装三个摄像头：左、中、右。驾驶员在配备这些摄像头的汽车中驾驶，同时操作方向盘。系统会同步记录驾驶员的转向角度和三个摄像头的画面，并将这些数据存储到硬盘中。

雇佣多名驾驶员进行数据采集，可以获得大量驾驶数据。然而，优秀的驾驶员通常很少犯错，他们大多时间会保持直线行驶、稳定在车道内。这对于神经网络学习而言是一个挑战，因为如果看不到错误案例，网络就难以学会如何纠正错误。

但在现实世界中，我们无法为了收集“错误”数据而冒险让汽车越线或发生事故。解决方案是对采集到的图像数据进行**随机平移和旋转**。我们记录下对图像施加的平移和旋转操作，同时可以计算出抵消这种图像变换所需的正确转向调整（例如，如果图像模拟了汽车向左偏移，那么正确的纠正动作是向右转向）。这样，我们就人工合成了“犯错”及“纠正”的数据对。

---

## 模型训练：模仿学习

![](img/33757f97d185b28c5313eed5159afb38_6.png)

接下来，我们使用这些处理后的数据来训练一个卷积神经网络（CNN）。网络的输入是摄像头图像，输出是一个连续的标量值，代表方向盘的转向角度。

以下是训练过程的核心步骤：

1.  **输入**：经过平移/旋转处理的摄像头图像。
2.  **网络预测**：CNN根据输入图像预测一个转向角度。
3.  **计算损失**：将网络预测的转向角度与我们根据图像变换计算出的“真实”纠正角度进行比较，计算误差。
4.  **反向传播**：利用该误差通过反向传播算法更新CNN的权重。

这个过程本质上是**模仿学习**，即让神经网络学习模仿人类驾驶员在特定路况下应做出的转向操作。我们利用海量数据持续重复这一过程来训练网络。

## 模型架构

所使用的CNN结构相对基础，主要由若干卷积层和全连接层构成。其最终输出是一个连续的标量值，直接对应方向盘的转向指令。模型结构并不复杂，关键在于端到端的学习方式。

```python
# 简化的模型架构示意
输入: 摄像头图像 (例如，66x200x3)
卷积层1 + 激活函数
卷积层2 + 激活函数
...
全连接层1
全连接层2
输出层: 一个神经元，输出连续转向角度 (标量)
```

在将训练好的CNN模型部署到真实汽车上并亲自试驾之前，必须进行充分的性能评估。我们可以利用预留的**测试数据集**来进行模拟测试。

![](img/33757f97d185b28c5313eed5159afb38_19.png)

![](img/33757f97d185b28c5313eed5159afb38_20.png)

测试方法如下：对测试集中的图像同样进行随机平移和旋转，生成模拟各种驾驶状况的合成图像。然后将这些图像输入训练好的CNN，让网络在模拟环境中“驾驶”，并观察其行为：它是否能保持在车道内？是否会犯错误？

![](img/33757f97d185b28c5313eed5159afb38_22.png)

![](img/33757f97d185b28c5313eed5159afb38_23.png)

为了量化评估结果，可以定义一个关键绩效指标（KPI）：**人类干预次数**。具体操作是，让一名测试人员在模拟驾驶环境中监控网络的驾驶行为。每当网络做出错误决策（例如即将偏离车道）时，测试人员就进行手动干预纠正。在一段测试路程中，统计所需的人工干预总次数。干预次数越少，说明CNN的驾驶能力越强。

当模拟测试结果令人满意后，才可将模型部署到真实汽车上进行道路测试。

## 方法的优势与启示

![](img/33757f97d185b28c5313eed5159afb38_25.png)

这套框架是一种在实践中可用的模仿学习方法。汽车的目标是模仿人类专家驾驶员的驾驶行为。只要有足够的存储空间，就可以收集海量的驾驶数据用于训练。

![](img/33757f97d185b28c5313eed5159afb38_26.png)

![](img/33757f97d185b28c5313eed5159afb38_27.png)

![](img/33757f97d185b28c5313eed5159afb38_28.png)

![](img/33757f97d185b28c5313eed5159afb38_29.png)

一个有趣的现象是，通过这种端到端的学习方式，CNN在并未接受任何关于“车道线”的显式标注的情况下，其网络权重或激活值自发地学会了关注车道线区域。从网络第一层和第二层的激活可视化图中可以看出，网络正在自主地进行**车道检测**。这说明，仅通过观察原始数据和模仿人类行为，神经网络就能学习到高级的、有用的特征表示。

![](img/33757f97d185b28c5313eed5159afb38_30.png)

在实际的工业部署中，为了确保安全，通常不会只依赖单一框架或模型。自动驾驶系统会集成多种不同的算法和神经网络模型（例如，有些专门训练用于车道检测，有些则采用本课所述的端到端方法）。系统会综合所有模型的输出做出最终决策。如果不同模型间无法达成共识，则会触发安全机制，如警告驾驶员或执行安全停车。

## 问答环节

**问**：在这个案例中，输出层是单个标量吗？正值代表右转，负值代表左转？还是使用Softmax多分类？

**答**：这是一个**连续动作空间**。输出是一个连续的标量值，直接对应方向盘的转向角度。正值和负值分别代表向右和向左转动的角度。

**问**：还有其他问题吗？就方法论而言，这里的内容并不复杂，但可以想象，将其工程化实现是一个艰巨的挑战。
