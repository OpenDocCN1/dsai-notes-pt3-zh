# 72：L33.3 - 单图像超分辨率 🖼️

在本节课中，我们将要学习单图像超分辨率（SISR）的核心思想，特别是如何通过残差学习来简化网络训练，并提升图像重建的质量。我们将探讨一种有效的方法，即让网络学习低分辨率图像与高分辨率图像之间的差异，而不是直接生成完整的高分辨率图像。



我们已经对卷积神经网络有了非常扎实的理解，这为我们学习单图像超分辨率打下了坚实的基础。在超分辨率任务中，你会经常听到 **SISR** 这个缩写，它代表 **单图像超分辨率**。



本文及后续论文的核心思想是：对低分辨率图像进行双三次插值后，已经能得到高分辨率图像的一个良好近似。因此，与其让网络直接从头生成高分辨率图像，不如让它学习**残差**。



这意味着，你可以将低分辨率图像通过双线性或双三次插值放大，然后将这个放大后的图像直接加到网络的输出上。这样，网络的任务就变得简单多了，它只需要学习**插值后的图像**与**真实高分辨率图像**之间的差异。这是另一种理解残差网络（ResNet）的方式。

这种方法在实践中非常强大。在超分辨率任务中，如果采用残差学习，网络需要学习的大部分特征值最终会接近零，这使得学习过程变得不那么困难。例如，最后一个特征图可能只有少数几个非零项。这是因为经过ReLU激活函数后，大部分值会被置零。

这个想法本身并不复杂，但深度学习正是由这些在实践中有效的简单想法构成的。一旦采用残差学习，你就可以使用较高的学习率，并可以结合梯度裁剪技术。此外，你还可以进行**多尺度训练**。



例如，对于一张高分辨率图像，你可以将其下采样2倍、4倍、8倍，从而得到不同尺度的训练样本。你可以用同一个网络在所有尺度上进行训练。



在本文之前，有一些论文声称更深的神经网络对超分辨率任务没有帮助。但本文提出，如果采用这种残差学习的方式，增加网络深度确实会带来帮助。这就是**多尺度深度残差网络**的核心思想。

你可以将这种方法与SRCNN等早期模型进行比较。本文使用的损失函数是 **L2损失**，而非感知损失。深度学习的贡献可以来自多个方面：模型结构、损失函数、评估指标或数据本身。本文的贡献主要在**模型结构**方面。



通过研究网络深度的影响，可以证实增加深度确实有助于提升不同尺度下的超分辨率性能。



本节课中，我们一起学习了单图像超分辨率中的残差学习思想。我们了解到，让网络学习低分辨率图像插值结果与真实高分辨率图像之间的残差，可以显著简化训练并提升效果。我们还探讨了多尺度训练的优势，即使用单一网络处理多种放大倍数。这种方法证明了更深的网络结构在残差学习的框架下对超分辨率任务是有益的。
