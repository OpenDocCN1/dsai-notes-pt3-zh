## 🔍 Inception 模块的基本思想

![](img/c53323974854ad9abb40546a34fc5897_20.png)

![](img/c53323974854ad9abb40546a34fc5897_22.png)

![](img/c53323974854ad9abb40546a34fc5897_24.png)

上一节我们提到了卷积核尺寸的选择难题。本节中我们来看看 Inception 模块是如何解决这个问题的。

![](img/c53323974854ad9abb40546a34fc5897_26.png)

![](img/c53323974854ad9abb40546a34fc5897_28.png)

其基本思想是：并行使用多种尺寸的卷积核（以及池化层），然后将所有输出在通道维度上进行拼接。

![](img/c53323974854ad9abb40546a34fc5897_30.png)

以下是其操作流程：
1.  对同一输入，并行进行 1x1 卷积、3x3 卷积、5x5 卷积和 3x3 最大池化。
2.  每种操作都会产生一定数量的输出通道（例如，1x1 卷积输出 15 个通道，3x3 卷积输出 25 个通道，5x5 卷积输出 50 个通道）。
3.  将这些不同操作的输出，沿通道维度进行拼接。

![](img/c53323974854ad9abb40546a34fc5897_32.png)

![](img/c53323974854ad9abb40546a34fc5897_34.png)

![](img/c53323974854ad9abb40546a34fc5897_36.png)

![](img/c53323974854ad9abb40546a34fc5897_38.png)

这样，网络可以在同一层中同时捕获不同尺度的特征。下一层网络会将这些特征组合起来。

![](img/c53323974854ad9abb40546a34fc5897_40.png)

**核心操作公式化表示**：
假设输入为 `X`，四种并行操作的输出分别为 `Out_1x1`, `Out_3x3`, `Out_5x5`, `Out_pool`，则 Inception 模块的输出为：
`Output = Concat(Out_1x1, Out_3x3, Out_5x5, Out_pool, dim=channel)`

## ⚠️ 朴素版本的问题与计算挑战

![](img/c53323974854ad9abb40546a34fc5897_52.png)

![](img/c53323974854ad9abb40546a34fc5897_54.png)

上一节我们介绍了 Inception 模块的并行结构思想。本节中我们来看看这种朴素设计会带来什么问题。

![](img/c53323974854ad9abb40546a34fc5897_56.png)

![](img/c53323974854ad9abb40546a34fc5897_58.png)

![](img/c53323974854ad9abb40546a34fc5897_60.png)

直接将所有分支的输出进行拼接，在维度匹配上没有问题。因为所有并行操作（当步长为1时）都不会改变特征图的空间分辨率（高度和宽度），只是改变了通道数。因此，它们可以在通道维度上直接拼接。

![](img/c53323974854ad9abb40546a34fc5897_62.png)

![](img/c53323974854ad9abb40546a34fc5897_64.png)

然而，这样做会带来一个严重问题：**通道数量爆炸式增长**，导致计算量非常庞大。

![](img/c53323974854ad9abb40546a34fc5897_66.png)

![](img/c53323974854ad9abb40546a34fc5897_68.png)

当时的研究目标是在增加网络深度和容量的同时，还必须**关注计算复杂度**。朴素 Inception 模块的并行卷积操作计算成本高昂，不符合这一目标。

![](img/c53323974854ad9abb40546a34fc5897_70.png)

## 💡 解决方案：使用 1x1 卷积进行降维

![](img/c53323974854ad9abb40546a34fc5897_76.png)

![](img/c53323974854ad9abb40546a34fc5897_78.png)

为了解决计算量过大的问题，GoogLeNet 引入了一个关键优化：在昂贵的卷积操作（如 3x3、5x5）之前，先使用 **1x1 卷积**来减少通道数（即降维）。

![](img/c53323974854ad9abb40546a34fc5897_80.png)

![](img/c53323974854ad9abb40546a34fc5897_82.png)

以下是优化后的流程：
1.  在 3x3 卷积、5x5 卷积和池化操作**之前**，先添加一个 1x1 卷积层。
2.  这个 1x1 卷积的作用是显著减少输入数据的通道数，从而降低后续大卷积核操作的参数数量和计算量。
3.  经过降维后，再进行各自的卷积或池化操作。
4.  最后，将所有分支的输出在通道维度上拼接。

![](img/c53323974854ad9abb40546a34fc5897_84.png)

![](img/c53323974854ad9abb40546a34fc5897_86.png)

论文中的实验结果表明，这种先降维再卷积的方式，在效果上与朴素版本相当，但**计算成本却低得多**。

![](img/c53323974854ad9abb40546a34fc5897_88.png)

![](img/c53323974854ad9abb40546a34fc5897_90.png)

**代码概念描述**：
```python
# 假设输入通道数为 in_channels
# 1. 1x1 卷积降维分支
branch1 = Conv1x1(in_channels, reduced_channels)(input)
# 2. 3x3 卷积分支（先降维）
branch2 = Conv1x1(in_channels, reduced_channels)(input)
branch2 = Conv3x3(reduced_channels, out_channels_3x3)(branch2)
# 3. 5x5 卷积分支（先降维）
branch3 = Conv1x1(in_channels, reduced_channels)(input)
branch3 = Conv5x5(reduced_channels, out_channels_5x5)(branch3)
# 4. 池化分支（池化后也接1x1卷积调整通道数）
branch4 = MaxPool3x3(stride=1)(input)
branch4 = Conv1x1(in_channels, out_channels_pool)(branch4)

![](img/c53323974854ad9abb40546a34fc5897_92.png)

![](img/c53323974854ad9abb40546a34fc5897_94.png)

![](img/c53323974854ad9abb40546a34fc5897_96.png)

# 最终输出拼接
output = concatenate([branch1, branch2, branch3, branch4], axis=channel_axis)
```

## 🎯 总结

![](img/c53323974854ad9abb40546a34fc5897_106.png)

![](img/c53323974854ad9abb40546a34fc5897_108.png)

![](img/c53323974854ad9abb40546a34fc5897_110.png)

本节课中我们一起学习了 GoogLeNet 的核心创新——Inception 模块。
1.  **动机**：为了解决卷积核尺寸选择困难，提出“并行使用多种尺度卷积核”的思想。
2.  **结构**：并行使用 1x1、3x3、5x5 卷积和池化层，并将结果在通道维度拼接。
3.  **挑战**：朴素并行结构会导致通道数激增，计算复杂度高昂。
4.  **优化**：引入 **1x1 卷积作为“瓶颈层”**，在昂贵操作前先进行降维，大幅减少计算量，同时保持模型性能。

![](img/c53323974854ad9abb40546a34fc5897_112.png)

![](img/c53323974854ad9abb40546a34fc5897_113.png)

这种设计使得 GoogLeNet 能够在保持较高精度的前提下，构建更深的网络，是深度学习模型结构设计中的一个重要里程碑。
