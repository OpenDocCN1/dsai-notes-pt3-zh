之前的算法在自我对弈中，只保留了最终的游戏结果 `Z`（赢或输），并用这个结果通过策略优化算法来更新神经网络参数。能提高胜率的动作会被加强，导致失败的则被削弱。



AlphaGo Zero 的观察是：你实际上可以保留并利用在整个对弈过程中所做的所有计算，并用这些数据来监督你的策略网络。这意味着，你不仅使用最终结果 `Z`，还会使用中间产生的概率分布 `π1, π2, π3...` 等。

![](img/fdd669f8d3741107b15ba3fc69e1b27d_27.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_28.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_29.png)

以下是其核心运作方式：
*   你有一个神经网络，它以棋盘状态 `s` 作为输入。
*   它输出两个东西：一是对各个动作的概率分布 `p`，二是对该状态价值 `v` 的估计（即处于该状态时获胜的可能性）。
*   最终结果 `Z` 将用来监督价值 `v` 的学习。
*   自我对弈中产生的概率分布 `π` 将用来监督策略 `p` 的学习。

## 🧠 神经网络架构与损失函数

上一节我们了解了核心思想，本节中我们来看看实现这一思想的神经网络具体是如何构建和训练的。

该模型使用一个单一神经网络，但具有多个输出头。神经网络以棋盘图像（状态 `s`）为输入，其参数为 `θ`。它输出一个标量值函数 `v = f_v(s; θ)` 和一个向量值函数 `p = f_p(s; θ)`。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_44.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_45.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_47.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_48.png)

训练这个网络的目标是：
*   使用 `Z` 通过均方误差（MSE）来监督 `v` 的学习。
*   使用 `π` 通过交叉熵损失来监督 `p` 的学习。
*   同时使用 L2 正则化来防止过拟合。



因此，总损失函数 `L` 可以表示为：
`L = (z - v)^2 - π^T log(p) + c ||θ||^2`
其中，`(z - v)^2` 是价值网络的均方误差损失，`- π^T log(p)` 是策略网络的交叉熵损失，`c ||θ||^2` 是 L2 正则化项。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_50.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_51.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_52.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_53.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_54.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_55.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_56.png)

## 🌳 π 的来源：蒙特卡洛树搜索

上一节我们明确了损失函数，但 `π` 的来源尚不清楚。本节中我们来看看 `π` 是如何通过蒙特卡洛树搜索产生的。

![](img/fdd669f8d3741107b15ba3fc69e1b27d_63.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_64.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_70.png)

`π` 来源于蒙特卡洛树搜索过程。MCTS 包含四个经典步骤：选择、扩展、评估和回溯。通过反复执行这个过程，最终会为我们提供用于监督的策略分布 `π`。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_71.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_72.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_73.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_74.png)

在树搜索中：
*   `s` 表示树中的一个节点（即一个棋盘状态）。
*   `(s, a)` 表示一条边（即从一个状态 `s` 采取动作 `a`）。
*   对于每条边，我们需要跟踪几个值：
    *   **先验概率 P(s, a)**：这来自我们的神经网络策略 `p`。
    *   **访问次数 N(s, a)**：在“思考”过程中，这条边被访问过的次数。
    *   **动作价值 Q(s, a)**：对该边价值的估计。



在选择节点时，智能体需要平衡**利用**（选择高价值动作）和**探索**（尝试访问次数少的动作）。这是通过以下公式选择动作实现的：
`a = argmax_a [ Q(s, a) + u(s, a) ]`
其中，`u(s, a) ∝ P(s, a) / (1 + N(s, a))`。
访问次数 `N(s, a)` 越多，`u` 值越小，从而鼓励探索其他访问少的边。

## 🔄 MCTS 与神经网络的协同

![](img/fdd669f8d3741107b15ba3fc69e1b27d_86.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_87.png)

上一节我们介绍了 MCTS 如何产生数据，本节中我们具体看看 MCTS 和神经网络是如何协同工作的。

当 MCTS 进行到**扩展**步骤时，我们到达一个新的叶子节点状态 `s‘`。此时，我们会调用神经网络来评估这个状态。
*   神经网络输出该状态的先验概率分布 `p(s‘)` 和价值估计 `v(s‘)`。
*   先验概率 `p` 被赋给从 `s‘` 出发的新边 `(s‘, a)`。
*   价值 `v(s‘)` 被存放在节点 `s‘` 上。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_89.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_90.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_91.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_92.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_93.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_94.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_95.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_96.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_97.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_98.png)

随后是**回溯**步骤。节点 `s‘` 的价值 `v(s‘)` 会沿着导致该节点的路径反向传播，更新路径上所有边的 `Q` 值。具体来说，对于所有能到达 `s‘` 的边 `(s, a)`，其 `Q` 值会根据 `v(s‘)` 进行更新。其他边的 `Q` 值保持不变。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_99.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_100.png)

经过一定时间的思考（例如1分钟），我们完成了多次 MCTS 模拟。此时，对于根节点状态 `s0`，我们可以根据其各条边的访问次数 `N(s0, a)` 来计算一个经验策略分布 `π`：
`π(a | s0) ∝ N(s0, a)^{1/τ}`
其中 `τ` 是温度参数，用于控制探索程度。当 `τ=1` 时，`π` 正比于访问次数；`τ>1` 会使分布更平滑，鼓励更多探索。这个 `π` 分布就是我们用来监督神经网络策略 `p` 的“标签”。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_102.png)

上一节我们完整地描述了 MCTS 如何与神经网络交互并产生训练数据。本节中我们来看看整个训练循环如何闭合，以及如何评估智能体的水平。

![](img/fdd669f8d3741107b15ba3fc69e1b27d_113.png)

至此，我们已经拥有了训练所需的所有要素：
1.  **自我对弈**：使用最新的神经网络参数进行 MCTS，根据得到的 `π` 分布选择动作，直至终局，得到结果 `z`。
2.  **构造训练数据**：将对弈过程中每个状态 `s_t` 及其对应的 MCTS 策略 `π_t` 和最终结果 `z` 保存为 `(s_t, π_t, z)`。
3.  **训练神经网络**：使用这些数据，通过前面定义的损失函数 `L` 进行梯度下降，更新神经网络参数 `θ`。
4.  **循环**：用更新后的网络进行新一轮自我对弈，生成更高质量的数据，如此反复。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_115.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_116.png)

在评估智能体水平时，论文采用了一种贝叶斯逻辑回归框架来估计 Elo 等级分。玩家 A 击败玩家 B 的概率被建模为：
`P(A defeats B) = σ( (E_A - E_B) / C_elo )`
其中 `σ` 是逻辑函数，`E_A` 和 `E_B` 是玩家的 Elo 分数，`C_elo` 是一个常数（通常为 1/400）。通过大量对局数据，可以估计出各个智能体的相对实力。

**问：访问次数 `N(s, a)` 是针对状态-动作对的。在围棋中，不同的行棋顺序可能导致相同的棋盘状态，这时如何处理？**
答：即使棋盘状态相同，只要它们出现在搜索树的不同节点上，就会被视为不同的节点。在回溯更新 `Q` 值时，每个节点的价值只会更新其祖先路径上的边。如果两个不同路径到达了相同的棋盘状态（即两个不同的节点），它们会各自独立地进行价值评估和回溯。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_141.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_142.png)

![](img/fdd669f8d3741107b15ba3fc69e1b27d_143.png)

**问：与之前论文的主要区别是什么？**
答：关键区别在于对自我对弈中产生数据的利用。之前的算法在自我对弈后只保留了胜负结果 `Z`，而丢弃了 MCTS 产生的中间策略分布 `π`。AlphaGo Zero 的核心思想就是“不要丢弃这些有用信息”，用 `π` 来监督策略网络，用 `Z` 来监督价值网络，使得 MCTS 和神经网络能够相互促进、共同提升。



![](img/fdd669f8d3741107b15ba3fc69e1b27d_146.png)

**问：围棋的状态空间极其庞大，策略网络 `p` 如何能处理所有可能状态？**
答：虽然状态空间巨大，但我们将棋盘状态编码为图像（例如，19x19 的棋盘，用多个通道表示棋子、气等信息），然后使用卷积神经网络进行处理。CNN 在处理高维图像数据方面非常有效，能够自动学习棋盘的特征表示，从而应对庞大的状态空间。

本节课中我们一起学习了 AlphaGo Zero 的核心原理。我们了解到，它通过摒弃人类数据，纯粹依靠自我对弈来学习。其关键在于**双重监督**：利用蒙特卡洛树搜索过程中产生的策略分布 `π` 来监督策略网络的训练，同时利用对弈的最终结果 `Z` 来监督价值网络的训练。MCTS 和神经网络形成了一个高效的闭环：神经网络为 MCTS 提供先验知识以引导搜索，而 MCTS 产生的高质量策略数据又反过来训练和提升神经网络。这种优雅的框架使得 AlphaGo Zero 能够从零开始，超越依赖人类知识的先前版本，成为强化学习领域的一个里程碑。
