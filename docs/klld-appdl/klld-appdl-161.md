# 161：L73.1 - 语音识别 🎤

在本节课中，我们将要学习用于语音识别的深度神经网络架构。我们将回顾循环神经网络的基础，并探讨如何结合声学模型与语言模型来提升识别性能。

上一节我们介绍了语音识别的两个基本主题：梅尔频谱图和梅尔频率倒谱系数。它们是语音或音频的两种不同表示形式。在深度学习和一般机器学习中，人们通常使用MFCCs。

现在，我们假设你有一个循环神经网络。第一个问题是如何训练它。语音识别的问题在于，输入序列通常比目标序列长，并且两者在时间上不对齐。因此，我们需要一个合适的损失函数。我们提到，为了计算损失，你需要考虑所有能产生相同标签的路径，并使用动态规划框架来计算它。

我们已经讨论了损失函数、数据和评估方法。现在来看看我们将使用哪种类型的神经网络。

![](img/c82754b287c0a686a79a3c005d79507c_18.png)

你有一个输入序列，这可以是你的梅尔频谱图。我们知道循环神经网络将序列作为输入，并输出序列。在中间层，它会生成隐藏向量序列，并最终给你一个输出序列。一个简单的RNN结构如下：输入序列进入网络，乘以权重矩阵，保留历史信息到隐藏向量中，更新隐藏状态，然后得到概率或分数。这些分数可以通过softmax函数处理。

![](img/c82754b287c0a686a79a3c005d79507c_25.png)

![](img/c82754b287c0a686a79a3c005d79507c_26.png)

如果激活函数更复杂一些，你会得到LSTM。LSTM包含输入门、遗忘门和输出门。需要注意的是，这些门都是矩阵，但作用于细胞状态`C`的系数是对角矩阵，你可以将它们视为向量。

![](img/c82754b287c0a686a79a3c005d79507c_28.png)

![](img/c82754b287c0a686a79a3c005d79507c_29.png)

![](img/c82754b287c0a686a79a3c005d79507c_30.png)

对于双向RNN，因为处理的是语音，你也可以以双向方式处理。你有一个前向动态过程和一个后向动态过程，然后将两者拼接起来，再乘以一个权重矩阵。展开来看，你是将各自的隐藏状态乘以对应的矩阵。

实际上，RNN不仅在时间上是“深”的，在空间上也可以“深”。唯一的区别在于，你是从一层到下一层，此时索引`n`代表你的网络层数。

## 建模与损失函数 ⚙️

![](img/c82754b287c0a686a79a3c005d79507c_45.png)

这就是你建立模型的地方，你在建模那个概率。唯一的区别（与文本处理相比）在于，现在你的输入是梅尔频谱图（本文中）或原始音频。你的任务可以是基于字符、音素、子词或单词的。本文是关于音素的，所以你将预测音素。

我们知道我们感兴趣的不是中间序列`y`，而是最终标签序列`z`。我们希望计算给定输入`X`时`z`的对数概率，这是你的目标函数。我们知道`x`和`y`长度相同，但`z`的长度通常更小，这就是为什么你需要使用连接时序分类损失函数。我们上一节已经介绍过这个损失函数。

音素`k`在`t`时刻的概率通过softmax计算。我们知道需要输出空白符号来覆盖输出不足的情况，因为`z`的长度`U`会小于`T`。但我们上一节观察到，CTC损失做了一个独立性假设。这意味着，知道先前输出的音素这一事实，并不会帮助你预测下一个音素。

![](img/c82754b287c0a686a79a3c005d79507c_55.png)

![](img/c82754b287c0a686a79a3c005d79507c_56.png)

![](img/c82754b287c0a686a79a3c005d79507c_57.png)

![](img/c82754b287c0a686a79a3c005d79507c_58.png)

![](img/c82754b287c0a686a79a3c005d79507c_59.png)

因此，你可以添加另一个神经网络，其任务是给定先前的音素来预测下一个音素，以补偿CTC在输出上所做的独立性假设。这个预测下一个音素的网络可以被视为一个语言模型。这就是语言模型将帮助你的语音识别的地方。你的目标是联合训练声学模型和语言模型。

## 结合声学与语言模型 🔗

![](img/c82754b287c0a686a79a3c005d79507c_67.png)

![](img/c82754b287c0a686a79a3c005d79507c_68.png)

![](img/c82754b287c0a686a79a3c005d79507c_69.png)

![](img/c82754b287c0a686a79a3c005d79507c_70.png)

![](img/c82754b287c0a686a79a3c005d79507c_71.png)

那么如何实现呢？你的输入由时间`t`索引，即 `x1, x2, ..., xT`。你的输出`z`由索引`u`表示。现在你的模型将预测给定输入时间步`t`和输出时间步`u`的标签。这是为了能够以某种方式融入你的语言模型。

![](img/c82754b287c0a686a79a3c005d79507c_72.png)

你需要改变的是，softmax不会变，但输入的分数会改变。它们将同时依赖于时间`t`和输出位置`u`。最后一层仍然是一系列隐藏单元的线性组合，这些隐藏单元是`t`和`u`的函数。

![](img/c82754b287c0a686a79a3c005d79507c_74.png)

现在需要解释`h(t,u)`是什么。`h(t,u)`的一部分来自你的声学模型，即声学模型的隐藏状态。`p`则来自你的语言模型的隐藏状态。你有一个循环神经网络来预测下一个音素，它会给出并保留那些隐藏状态`p`。最终，`l`是来自你的双向循环神经网络的结果，它产生于那些隐藏序列。`h_n`和`h_{n-1}`是你的CTC网络的隐藏序列，`p`是你的预测网络的隐藏状态。

![](img/c82754b287c0a686a79a3c005d79507c_75.png)

![](img/c82754b287c0a686a79a3c005d79507c_76.png)

![](img/c82754b287c0a686a79a3c005d79507c_77.png)

![](img/c82754b287c0a686a79a3c005d79507c_78.png)

![](img/c82754b287c0a686a79a3c005d79507c_79.png)

![](img/c82754b287c0a686a79a3c005d79507c_80.png)

![](img/c82754b287c0a686a79a3c005d79507c_81.png)

![](img/c82754b287c0a686a79a3c005d79507c_82.png)

![](img/c82754b287c0a686a79a3c005d79507c_83.png)

![](img/c82754b287c0a686a79a3c005d79507c_84.png)

然后你将训练它。这会给你一个损失函数，给出你的似然，然后你可以写下你的损失。使用CTC进行训练，然后进行解码。之前我们以不同的方式解码，但在这里你将使用束搜索。束搜索我将在另一篇论文中解释，所以不用担心。它类似于你在语言模型中做的，但更复杂一些。

![](img/c82754b287c0a686a79a3c005d79507c_85.png)

在结果数字方面，你将报告音素错误率。如果使用循环神经网络，那就是你的音素错误率。循环神经网络就是上面描述的这种。如果你使用不同配置的LSTM，比如一层深、两层深，你会得到改进。这些都是单向的，但你可以开始让它们变成双向和更深、更宽，从而提升性能。然后，这种换能器损失或换能器RNN，语言模型将有很大帮助。预训练换能器是指预测网络已经预训练好的换能器。
