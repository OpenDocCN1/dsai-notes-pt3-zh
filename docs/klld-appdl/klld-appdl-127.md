## 传统微调 vs. GPT-3 的上下文学习

传统的自然语言处理模型遵循“预训练-微调”范式。以下是其工作流程：

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_13.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_14.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_15.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_16.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_17.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_18.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_19.png)

1.  **预训练**：在一个大型通用语料库上训练一个基础语言模型（例如 BERT 类模型）。
2.  **微调**：针对特定的下游任务（如翻译），使用该任务的标注数据对预训练模型进行参数更新。

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_20.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_21.png)

这个过程可以看作是一种“软条件化”。数据输入后，模型通过梯度下降算法更新其内部参数。

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_23.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_24.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_25.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_26.png)

**公式表示**：`θ_new = θ_old - η * ∇L(θ_old; batch_data)`

其中 `θ` 是模型参数，`η` 是学习率，`L` 是损失函数。

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_28.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_29.png)

## GPT-3 的核心：上下文学习

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_39.png)

GPT-3 的理念是“上下文学习”。模型在预训练后，参数被永久固定，不再更新。当需要解决一个新任务时，我们通过输入文本来“硬条件化”模型。

以下是其工作原理：

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_41.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_42.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_43.png)

![](img/1be330b1fcfcb6b59dcb50714f3dddd8_44.png)

1.  **任务描述**：用自然语言描述你想要模型做什么（例如，“将英文翻译成法文”）。
2.  **示例（可选）**：提供一个或几个输入-输出对的例子。
3.  **提示**：给出你想要模型处理的实际输入。
4.  **预测**：模型基于以上所有上下文信息，直接预测后续的单词或答案。

**代码示意**：
```
输入: “将英文翻译成法文：cheese => fromage。sea => mer。hello =>”
输出: “bonjour”
```

这个过程没有梯度更新，模型仅仅根据给定的上下文进行概率预测。GPT-2 已经展示了这种能力，但性能尚未达到顶尖水平。

## 规模定律：更大即更好 📈

GPT-3 论文的核心假设是：如果极大地扩展模型规模（参数数量、数据量、计算量），这种上下文学习的性能将显著提升。

实验证明：
*   拥有 13 亿参数的 GPT-2 虽然能完成任务，但效果并非最佳。
*   当参数规模扩大到 1750 亿（GPT-3），并在“少样本”设置下提供更多示例时，模型在许多任务上的准确率开始接近甚至超越当时的先进水平。

这种扩展表明，模型性能随着规模增长而提升，这被称为“规模定律”。

## GPT-3 的能力与数据

GPT-3 的预训练数据极其庞大，包括 Common Crawl、WebText、书籍语料库和英文维基百科，几乎涵盖了整个互联网。

其应用非常广泛，一个著名的例子是文本生成。给定一个开头段落，GPT-3 可以续写出连贯甚至富有创造性的故事，其文本的真实感有时让人类难以分辨。

## 为何需要如此庞大的模型？🧠

你可能会问，许多任务可以用更小的模型解决，为何需要千亿参数的模型？答案是：我们正迈向通用人工智能。

GPT-3 的目标不是解决单一任务（如情感分析或翻译），而是成为一个能够解决多种不同任务的通用系统。你只需通过自然语言描述和几个例子，它就能尝试解决，而无需改变模型本身。这更接近人类解决问题的模式：根据上下文理解任务并执行。

## GPT-3 的局限性与多模态学习的开端

尽管强大，GPT-3 也存在明显缺陷。例如，它生成的故事有时会出现不一致或事实错误。一个重要的原因是：GPT-3 只学习过文本，它“知道”飞机和椅子的概念，但从未“见过”它们的图像。

它的知识没有与现实世界“接地气”。这可能导致其输出缺乏常识或产生荒谬内容。此外，由于训练数据来自未经过滤的互联网，模型可能继承其中的偏见（如性别、种族偏见）。

因此，纯文本学习是不够的。要构建更智能、更可靠的系统，模型需要同时理解语言、图像、语音等多种信息。这就是我们接下来要开始学习的**多模态学习**。

## 总结

本节课中我们一起学习了 GPT-3 的核心机制。我们对比了传统的梯度更新微调与 GPT-3 的上下文学习，理解了后者如何通过“硬条件化”和固定参数来解决多样化的任务。我们看到了模型规模对性能的关键影响，以及 GPT-3 作为通用智能体所展现的潜力和面临的挑战，特别是其缺乏与现实世界 grounding 的局限性，这自然地将我们引向了多模态学习这一重要方向。
