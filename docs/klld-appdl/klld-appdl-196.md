归一化定义是 **L_norm = I - D^{-1/2} W D^{-1/2}**，即你从左和右乘以 D^{-1/2}。现在你开始明白为什么在之前的论文中我们使用 **D^{-1/2} W D^{-1/2}** 了。

事实证明，L 将是一个实值矩阵，它是对称且半正定的。对于这样的矩阵，你知道它有一组完整的正交特征向量。所以我们可以看看你的特征向量，它们将给出一个基，并且最终是正交的。这里有个笔误，应该是 L 从 0 到 n-1。你有 n 个这样的向量，以及 n 个对应的特征值。很酷的是，你实际上可以对它们进行排序，这些特征值是非负的。

你可以根据它们的重要性对它们进行排序。你将 U 称为傅里叶基，这就是“光谱”这些名字的由来。你可以把这些向量放入一个矩阵，把你的特征值对角线放入另一个矩阵，然后你可以对角化你的 L（你的拉普拉斯算子，归一化的）。那么信号的傅里叶变换在这里是什么？你取你的 x（一张图像），如果你乘以 U^T，这将把你从实数域带到傅里叶域。所以 x_hat 现在在你的傅里叶域中，你可以通过使用 U 返回。U^T 将带你从实数到傅里叶，U 将带你从傅里叶到实数。

你如何定义卷积？为什么要费这么大劲？因为我们知道实数域中的卷积对应于傅里叶域中的简单乘法。在实数域中定义图上的卷积非常困难，但也许如果你进入傅里叶域，事情会变得容易得多。让我们看看为什么。这将给你卷积：你首先进入傅里叶域，你有两个信号 X 和 Y，你在图上有一个卷积。这是一个定义。

你取 Y，进入傅里叶域，你取 X，进入傅里叶域，然后将它们相乘，所以这是一个简单的逐点乘法。现在你在傅里叶域，你需要用 U 返回，这将给你一个卷积。现在你开始明白为什么人们称之为图卷积，以及什么是光谱滤波。因为你想在图上应用非线性操作，非线性操作的一些好例子是多项式。假设 G_theta 是一个多项式，你以某种方式参数化它，我将告诉你如何做。如果它是一个多项式，你可以将它应用于你的 L（你的归一化拉普拉斯矩阵），因为你将其对角化，并且因为这些是正交向量，你可以取 G 并仅将其应用于对角线项。这很酷，因为现在你可以参数化这个 G_theta 函数。

例如，一个例子可能是：你选择一个向量，这是你的参数向量，你把它放在一个矩阵中，实际上你是把这个向量放在一个矩阵的对角线上，然后这将给你一些参数化的卷积。现在你在这里拥有的只是一个参数向量的对角线。这种方法有一个问题：它在空间上是非局部化的。因为你在这里得到的，在傅里叶域将是局部的，但当你回到实数域时，这最终将是非局部的。基本上，任何像素都会关注图像上的所有其他像素，这不好，不是我们想要的。我们希望事物是局部的，我们希望有一个小窗口。

还有另一个更大的问题：你的参数数量和数据点一样多。基本上，n 是你的数据大小。所以我们希望更高效，我们希望参数效率更高。一个想法是使用多项式，一个不错的选择是切比雪夫多项式。切比雪夫多项式的工作方式是，你从 1 和 x 开始，然后以迭代的方式创建你的高阶多项式。二阶就是 2x^2 - 1，然后你继续以迭代的方式进行。这些将给你你的多项式。

现在，与其那样定义你的卷积并以那种方式参数化你的卷积，你可以根据这些切比雪夫多项式的系数来参数化它。现在你可以有少得多的参数。你可以在多项式中有 K 项，所以你可以直到 K 阶多项式，现在你有 K 个参数。

我们解决了这个问题。学习复杂度现在是 K。这个 gamma_tilda 是什么？它是你原始的特征值，是这个矩阵除以最大特征值。这就是你定义它的方式，这只是一个归一化常数，我们不用太担心。我们解决了这个问题，并且作为副产品，我们实际上解决了第一个问题。这最终将在空间上是局部化的。论文中实际上有一个定理证明了这一点。这些光谱滤波器被证明严格局部化在半径为 K 的球内。这与你处理图像时非常相似。我们可以把 K 看作是你的窗口大小，你的滤波器大小。就图而言，它将是 K 跳邻居：第一邻居、第二邻居、第三邻居，如果 K 是 3。然后你就有少得多的参数。K 是你选择的一个超参数，它非常类似于图像上的滤波器大小或卷积。

然后，为什么是切比雪夫多项式？因为当你评估时，它会非常高效。这可以是任何多项式，但为什么是切比雪夫？因为它们评估起来更快。X 是你的图像，然后你想通过一个卷积传递它。你取你的切比雪夫多项式，乘以 X，然后这些就是图上卷积的参数。L_tilda 与 gamma_tilda 非常相似，所以它有相同的定义，你只是用 L 替换了你的特征值。

现在你可以定义这个为 x_k，这里的横线并不意味着你在取平均值，它只是你的变量名。它将给你 x_k。你使用下面切比雪夫多项式的定义，并用 x_k 替换所有内容。无论你在哪里有 T_k，你都将用 x_k_bar 替换它。现在你开始迭代。你从你的图像开始，这将给你你的 x0_bar。你应用你的 L_tilder。这只是你的 x 上的矩阵向量乘法，这将给你你的 x1。这与你处理切比雪夫多项式时非常相似。然后剩下的就只是这个的迭代。事实证明，计算复杂度与你处理图像和图像卷积时非常相似。边的数量将参与进来，乘以 K，因为你正在进行一个迭代过程。这是你需要做的操作数量。
