# 课程 P174：L77.2 - 人体水平控制 🎮

在本节课中，我们将学习深度Q学习算法的一个关键改进版本。我们将看到，通过一个微小的修改，相同的算法可以在相同的数据集上产生更稳定、更接近人类水平的表现。这个修改的核心在于引入一个“目标网络”，它能使学习过程更加稳定。

![](img/a97c26f75bc15aaf39cde75b746218c7_1.png)

上一节我们介绍了基础的深度Q学习算法。本节中，我们来看看如何通过一个微小的修改来提升其性能。

在这种情况下，让我们继续下一个主题。这个算法与你刚才看到的算法完全相同，使用相同的数据集，只做了一个微小的修改。我们将看到，我们的目标函数和之前一样，来源于贝尔曼方程。

所做的修改基本上是这样的：这是我们的 `y`，这是我们的神经网络，以状态 `s` 和动作 `a` 作为输入。然后我们从动态构建的数据存储库中进行采样。唯一的修改是，这个参数 `θ` 你将选择它来自若干步之前，而不仅仅是上一轮。例如，可能来自100轮之前，当你进行优化时。这样做的原因是为了使输出更加确定，并且可能更接近独立同分布样本。

这与之前的算法完全相同。唯一要改变的是，你将有一个 `Q̂`，它基本上与 `Q` 非常相似，它将为你提供目标值，但它是在之前的一组其他参数上评估的。

你如何得到 `θ⁻` 呢？你将通过以下方式得到它：每 `C` 步，你将修改并存储你的参数，你将存储 `θ̄`。所以，这完全是之前的算法，即带有经验回放的深度Q学习。你正在收集经验。这个算法的每一行都是我们刚刚讨论过的，除了你使用 `Q̂` 而不是 `Q` 的地方。`Q̂` 基本上就是 `Q`，是同一个网络，只是在之前的一组其他参数上评估的。

现在，让我们更清晰地看一下Q网络的架构。

动作可以是Q网络的输入，也可以是输出。因为动作 `a` 是离散的。如果它是输入，你的 `Q` 将是一维的。如果它是输出，你的 `Q` 将是 `K` 维的，`K` 是你的动作空间的大小。

你获取一张图像，进行一系列卷积操作。这只是示意图，这里没有确切的卷积形式。你不知道内核大小是多少，我们只知道它是一系列卷积和一系列全连接层，最后带有激活函数。你输出一个向量，例如向上、向下、向右、向左等，或者同时按下某个按钮。这就是你的动作空间。

如果你想了解你的状态和动作的价值，你需要做的是：输入一张图像，然后读取相应的输出。可能你什么都不做，可能你向上移动，这些就是你的标量值。所以这两种方式是等价的，但神经网络擅长处理高维数据，因此以这种方式实现更好。

![](img/a97c26f75bc15aaf39cde75b746218c7_32.png)

这是一个非常好的问题，但不在本文的背景下。你问了一个非常重要的问题。强化学习的一个问题是设计好的奖励，这非常重要。因为对于一些游戏，比如围棋或国际象棋，你在走棋时直到最后才会看到奖励，所以你的奖励非常稀疏。但对于这里讨论的游戏，你是在动态收集奖励。这里的数字5256就是你的奖励。

你是在动态收集奖励，这实际上是一个更简单的问题。对于更稀疏的奖励系统，最终可能需要设计奖励，比如保护棋子、控制中心等战略奖励，而不是最终结果的奖励。

![](img/a97c26f75bc15aaf39cde75b746218c7_43.png)

是的，对于那些策略，你不会获得任何奖励。那只是你的策略，是你下棋的方式。你希望你的模型、你的智能体能够发现这些策略。所以有时你必须处理稀疏奖励，无论如何，这只是一个更难的问题。有时在你的奖励中，你也可以鼓励动作的多样性。所以你可以鼓励悲观、乐观等等。所以你的问题非常重要，但就本文而言，问题并没有那么难。如果你考虑一下，对于每个状态和动作，你都会得到一个奖励。同样，对于雅达利游戏来说，这并不难。

## 总结

![](img/a97c26f75bc15aaf39cde75b746218c7_55.png)

![](img/a97c26f75bc15aaf39cde75b746218c7_57.png)

本节课中，我们一起学习了深度Q学习算法的一个关键改进——引入目标网络。我们了解到，通过使用一个来自若干步之前的参数集（`θ⁻`）来计算目标值 `Q̂`，可以使学习过程更加稳定，输出更接近独立同分布样本。我们还探讨了Q网络将离散动作作为输出的架构优势，并看到了该算法在雅达利游戏上达到或超越人类水平的卓越表现。最后，我们讨论了奖励函数设计的重要性，指出在动态奖励环境中，该算法能有效解决问题。
