# 36：L19.2 - Xception 架构详解 🧠

![](img/415cf461e0f0094dc29dc2aeb8057216_1.png)

在本节课中，我们将学习 Xception 网络架构。Xception 是 Inception 架构的一种极端简化形式，其核心思想是深度可分离卷积。我们将从 Inception 模块的简化开始，逐步推导出深度可分离卷积，并了解 Xception 的整体网络结构及其性能表现。

## 🔄 从 Inception 到简化模块

![](img/415cf461e0f0094dc29dc2aeb8057216_5.png)

上一节我们介绍了 Inception 模块。Xception 论文提出对 Inception 架构进行简化。

![](img/415cf461e0f0094dc29dc2aeb8057216_7.png)

原版 Inception 模块同时使用 1x1 卷积、平均池化、3x3 卷积、5x5 卷积和 7x7 卷积。Xception 的简化思路是仅使用 **1x1 卷积** 和 **3x3 卷积**。

## 🔗 使用分组卷积重新表述

![](img/415cf461e0f0094dc29dc2aeb8057216_15.png)

本节中我们来看看如何用分组卷积来重新表述这个简化模块。我们在 ResNeXt 中已经学习过分组卷积。

![](img/415cf461e0f0094dc29dc2aeb8057216_17.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_19.png)

具体做法是：先进行一个 **1x1 卷积**，然后选取一部分通道（例如 10 个通道），仅在这部分通道上执行 **3x3 卷积**，最后将结果拼接起来。

![](img/415cf461e0f0094dc29dc2aeb8057216_21.png)

这个过程本质上就是分组卷积。

以下是该过程的示意图：

![](img/415cf461e0f0094dc29dc2aeb8057216_23.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_11.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_25.png)

## ⚡ 推向极致：深度卷积

![](img/415cf461e0f0094dc29dc2aeb8057216_27.png)

如果将分组卷积的思想推向极致，即每组只包含**单个通道**，那么 3x3 卷积就变成了**逐通道卷积**。

![](img/415cf461e0f0094dc29dc2aeb8057216_29.png)

以下是深度卷积的示意图：

![](img/415cf461e0f0094dc29dc2aeb8057216_31.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_19.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_33.png)

这就是一个新的视角：从 Inception 出发，简化它，应用分组卷积（如 ResNeXt），再将其推向极致，就得到了**深度可分离卷积**。

![](img/415cf461e0f0094dc29dc2aeb8057216_35.png)

实际上，仅进行逐通道卷积是**深度卷积**。当在其后增加一个 **1x1 卷积**（即**逐点卷积**）时，才构成完整的**深度可分离卷积**。

![](img/415cf461e0f0094dc29dc2aeb8057216_37.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_39.png)

其核心公式可表示为：
`输出 = 逐点卷积(深度卷积(输入))`

## 🏗️ Xception 网络宏观结构

![](img/415cf461e0f0094dc29dc2aeb8057216_45.png)

上一节我们介绍了核心模块，本节中我们来看看 Xception 的整体网络结构。

![](img/415cf461e0f0094dc29dc2aeb8057216_47.png)

Xception 网络结构主要分为三部分：入口流、中间流和出口流。

![](img/415cf461e0f0094dc29dc2aeb8057216_49.png)

以下是 Xception 的宏观结构图：

![](img/415cf461e0f0094dc29dc2aeb8057216_51.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_53.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_29.png)

![](img/415cf461e0f0094dc29dc2aeb8057216_55.png)

**入口流** 负责通过步长为 2 的卷积逐步改变特征图的尺寸和通道数。通道数变化依次为：32 -> 64 -> 128 -> ... -> 256 -> 728。

![](img/415cf461e0f0094dc29dc2aeb8057216_57.png)

**中间流** 结构非常简单，由多个相同的模块重复堆叠 8 次构成。每个模块包含深度可分离卷积和快捷连接，此阶段特征图尺寸和通道数保持不变。

![](img/415cf461e0f0094dc29dc2aeb8057216_59.png)

**出口流** 接收中间流的输出，最终通过全连接层输出逻辑回归的概率。

![](img/415cf461e0f0094dc29dc2aeb8057216_61.png)

## 📊 性能对比

Xception 与 Inception V3、ResNet 和 VGG 等网络在参数量相近的情况下进行了性能比较。

以下是性能对比的示意图：

![](img/415cf461e0f0094dc29dc2aeb8057216_55.png)

在 Top-1 和 Top-5 准确率上，Xception 的表现均优于 Inception V3。图中显示的是训练过程中的验证准确率，Xception 的曲线始终位于 Inception V3 之上。

---

## 💡 关于激活函数的一个发现

在之前的 MobileNet 论文中，我们了解到在深度卷积和逐点卷积之间通常会有一个激活函数。

但实验表明，**移除这两个卷积之间的非线性激活函数**（即不使用 ReLU 或其他激活函数）反而能取得最佳效果。

因此，在 Xception 中，深度卷积和其后的逐点卷积之间**没有使用非线性激活**。

---

## ✅ 总结

本节课中我们一起学习了 Xception 架构。我们从简化 Inception 模块出发，通过分组卷积的视角，推导出了深度可分离卷积这一核心概念。Xception 网络结构清晰，分为入口流、中间流和出口流三部分。实验证明，在相似参数量下，Xception 的性能优于 Inception V3，并且其设计中去除了深度卷积与逐点卷积之间的非线性激活，这是一个重要的优化点。
