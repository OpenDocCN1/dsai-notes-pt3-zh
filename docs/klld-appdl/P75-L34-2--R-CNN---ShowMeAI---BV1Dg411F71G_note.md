# 🧠 课程 P75：L34.2 - R-CNN 详解

![](img/758b12bcaa664c3a0ec80f98ec88573e_1.png)

在本节课中，我们将要学习目标检测领域的一个里程碑式算法——R-CNN。我们将详细拆解其多阶段流程，理解其如何利用卷积神经网络进行目标检测，并探讨其训练与推理过程中的关键步骤。

---

## 🚀 概述：从图像分类到目标检测

上一节我们介绍了目标检测的基本概念。本节中我们来看看首个成功应用卷积神经网络（CNN）解决目标检测问题的经典算法——R-CNN。

R-CNN并非一个端到端的单一算法，而是一个多阶段的系统。我们的深度卷积神经网络只是整个目标检测系统中的一小部分。

以下是R-CNN算法的主要阶段：

1.  **区域提议**：使用外部算法生成可能包含目标的候选区域。
2.  **特征提取**：将每个候选区域变形后，送入CNN提取特征。
3.  **目标分类**：使用分类器（如SVM）判断区域中是否存在特定类别的目标。
4.  **边界框回归**：微调候选框的位置，使其更精确地贴合目标。

![](img/758b12bcaa664c3a0ec80f98ec88573e_3.png)

接下来，我们将逐一深入每个阶段。

首先，R-CNN需要一个外部算法来生成**区域提议**。这与深度学习无关，是一个相对廉价的计算过程。

该算法会为每张图像生成大量（例如2000个）可能包含目标的边界框，这些框被称为“候选区域”。在R-CNN的原始实现中，使用的是**选择性搜索**算法。

## 🖼️ 阶段二：特征提取

得到候选区域后，我们需要从中提取特征。由于当时的CNN（如AlexNet）要求输入图像尺寸固定（例如224x224像素），因此需要将每个候选区域内的图像进行**变形**处理。

变形后，图像被送入一个预训练的CNN（如AlexNet）中。CNN在这里充当**特征提取器**的角色。

![](img/758b12bcaa664c3a0ec80f98ec88573e_21.png)

对于训练数据集中的每张图像，我们会生成成千上万个特征向量。每个候选区域经过CNN前向传播后，会输出一个固定维度的特征向量，例如AlexNet会输出一个4096维的特征向量。

## 🧠 阶段三：目标分类

提取出特征后，下一步是进行分类。R-CNN为每个目标类别训练一个独立的**二分类支持向量机**。

例如，对于PASCAL VOC数据集（包含20个目标类别），就需要训练21个SVM分类器（20个物体类别 + 1个背景类别）。每个SVM的任务是判断给定的特征向量是否属于其对应的类别（例如，“是飞机”或“不是飞机”）。

![](img/758b12bcaa664c3a0ec80f98ec88573e_38.png)

![](img/758b12bcaa664c3a0ec80f98ec88573e_39.png)

![](img/758b12bcaa664c3a0ec80f98ec88573e_40.png)

假设我们已经训练好了SVM分类器。在推理时，区域提议步骤会为每张图像生成约2000个候选区域。我们无法将所有区域都报告给用户，因此需要进行筛选。

![](img/758b12bcaa664c3a0ec80f98ec88573e_42.png)

![](img/758b12bcaa664c3a0ec80f98ec88573e_43.png)

![](img/758b12bcaa664c3a0ec80f98ec88573e_44.png)

![](img/758b12bcaa664c3a0ec80f98ec88573e_45.png)

![](img/758b12bcaa664c3a0ec80f98ec88573e_46.png)

这里使用**贪婪非极大值抑制**算法进行筛选。该算法依赖于SVM为每个区域给出的置信度分数。

![](img/758b12bcaa664c3a0ec80f98ec88573e_47.png)

![](img/758b12bcaa664c3a0ec80f98ec88573e_48.png)

以下是NMS的简化过程：
1.  选择一个类别（例如“船”）。
2.  对该类别下所有候选区域按其SVM分数进行排序。
3.  从最高分的区域开始，计算该区域与其他所有区域的**交并比**。
4.  如果某个区域与当前高分区域的IoU超过一个阈值（例如0.5），则将其抑制（移除）。
5.  重复步骤3-4，直到处理完所有区域。

通过结合IoU和分类置信度分数，可以有效地抑制大量重叠的冗余提议框，最终只保留少数最有可能的检测结果。

现在，我们来看看如何训练R-CNN中的各个组件。这里主要涉及**迁移学习**。

**1. 微调CNN特征提取器**
我们的AlexNet是在ImageNet上预训练的，但目标检测数据集（如PASCAL VOC）不同，因此需要对CNN进行**领域特定的微调**。

微调数据来自区域提议框。我们需要自动地为这些区域生成标签：
*   **正样本**：与真实标注框的IoU ≥ 0.5的区域。
*   **负样本**：与所有真实标注框的IoU都较低的背景区域。

在微调时，我们在CNN末尾接上一个**21路分类层**（对应20类物体+背景），并使用交叉熵损失函数进行训练。这样做的目的并非直接使用这个分类器，而是为了让CNN提取的特征更适应我们的目标检测数据集。

**2. 训练SVM分类器**
SVM的训练数据也需要通过IoU来构建：
*   **正样本**：与某个类别的真实标注框高度重叠的区域提议。
*   **负样本**：与所有真实标注框IoU都很低的区域（明确为背景）。
*   **忽略样本**：IoU处于中间地带的区域（不参与训练）。

## ✨ 阶段五：边界框回归

为了得到更精确的检测框，R-CNN在最后增加了一个**边界框回归**步骤。

假设我们有一个区域提议框 `P` 和其对应的真实标注框 `G`。回归器的目标是学习一组变换参数，将 `P` 调整到更接近 `G` 的位置。

变换参数是相对于提议框 `P` 的中心点坐标 `(P_x, P_y)` 以及宽高 `(P_w, P_h)` 进行归一化定义的：
*   `t_x = (G_x - P_x) / P_w`
*   `t_y = (G_y - P_y) / P_h`
*   `t_w = log(G_w / P_w)`
*   `t_h = log(G_h / P_h)`

我们将候选区域的特征（例如4096维）输入一个回归网络，该网络会输出这四个值 `(t_x, t_y, t_w, t_h)`。通过最小化预测变换参数与真实变换参数之间的误差，可以学习如何微调边界框。

## 🔍 可视化：网络在看什么？

R-CNN论文中提出了一个巧妙的想法来可视化CNN“思考”的内容。

我们可以聚焦于网络中间某个特征图上的一个特定**单元**，将其视为一个“物体检测器”。通过以下步骤进行可视化：
1.  用区域提议算法生成大量候选框。
2.  计算每个候选框经过网络后，该特定单元的激活值。
3.  对不同图像，选取激活值最高的前16个候选框进行展示。

例如，下图展示了三个不同单元所关注的内容。结果表明，某个单元可能专门识别人脸，另一个单元关注文字，第三个单元则对镜面反射敏感。这是一种理解CNN所学特征的直观方式。

## 📊 性能与总结

R-CNN使用**平均精度均值**作为核心评估指标。在PASCAL VOC数据集上，它相比传统方法取得了显著的性能提升。

本节课中，我们一起学习了R-CNN目标检测算法。我们了解到，R-CNN是一个多阶段管道，它巧妙地将传统的区域提议方法与深度卷积神经网络的特征提取能力相结合，并通过SVM进行分类，最后利用边界框回归提升定位精度。尽管其流程复杂且速度较慢，但它为后续更高效的目标检测算法（如Fast R-CNN, Faster R-CNN）奠定了重要的基础。
