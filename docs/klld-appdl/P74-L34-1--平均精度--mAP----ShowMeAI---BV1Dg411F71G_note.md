## 什么是目标检测？🔍

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_5.png)

目标检测是计算机视觉中的一项任务，其目标是在图像中定位并识别出感兴趣的物体。一个典型的目标检测算法会为图像中的每个物体输出一个**边界框**以及该框内物体的**类别**和**置信度**。

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_7.png)

例如，在一张图像中，算法需要能够用一个边界框框出船只，并给出“有61.74%的置信度认为框内是船只”这样的判断。

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_9.png)

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_11.png)

## 如何衡量性能？📏

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_13.png)

假设我们已经有了一个检测器，如何衡量它的性能好坏呢？我们需要一个客观的评估标准。

首先，我们聚焦于单一类别（例如“船只”）进行讨论。在测试数据中，每个物体都有一个已知的、标注好的边界框，我们称之为**真实框**。而算法预测出的边界框，我们称之为**预测框**。

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_15.png)

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_17.png)

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_19.png)

为了评估，我们需要定义几个基本概念：
*   **真正例**：正确检测到一个真实框。
*   **假正例**：检测到一个不存在的物体，或检测框位置严重错误。
*   **假反例**：存在一个真实框，但算法未能检测到。
*   **真反例**：对于目标检测任务，理论上存在无限多个不应该被检测到的位置和框，因此**真反例无法被明确定义**。我们的评估指标将只基于前三个概念。

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_21.png)

那么，如何定义“正确检测”呢？这里我们使用**交并比**来衡量预测框与真实框的重合程度。

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_23.png)

**交并比**的计算公式为：
`IoU = 交集面积 / 并集面积`

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_25.png)

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_27.png)

我们会设定一个阈值（例如0.5）。如果预测框与某个真实框的IoU大于该阈值，则认为这次检测是“正确的”（真正例）；否则，就是“错误的”（假正例）。

## 精确率与召回率 📈

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_29.png)

基于真正例、假正例和假反例，我们可以定义两个更直观的指标：

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_31.png)

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_33.png)

*   **精确率**：在所有被算法检测为“正例”（即预测框）的结果中，真正例所占的比例。它衡量的是检测的**准确性**。
    `精确率 = 真正例数量 / (真正例数量 + 假正例数量)`

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_35.png)

![](img/0455a8cc7771a0f0f9d00e8c4d9d662a_37.png)

*   **召回率**：在所有真实的“正例”（即真实框）中，被算法成功检测出来的比例。它衡量的是检测的**全面性**。
    `召回率 = 真正例数量 / 真实框总数量`

## 计算平均精度 🧮

在实际评估中，我们通常有一系列按置信度从高到低排序的预测结果。我们需要计算在不同召回率水平下的精确率，从而绘制出**精确率-召回率曲线**。

以下是计算步骤：

1.  **收集与排序**：在整个测试集的所有图像上，收集算法对某个类别（如“船只”）的所有预测框，并按照其置信度从高到低进行排序。
2.  **逐点计算**：从置信度最高的预测框开始，依次判断每个预测框是真正例还是假正例，并累计计算当前的精确率和召回率。
3.  **绘制曲线**：以召回率为横轴，精确率为纵轴，绘制出PR曲线。
4.  **平滑曲线**：原始的PR曲线可能呈锯齿状。为了得到更稳健的评估指标，我们进行插值平滑：对于每个召回率点，取其右侧（即召回率更高处）所有精确率的最大值，作为该点的“插值精确率”。这使得曲线变为单调递减。
5.  **计算面积**：计算平滑后的PR曲线下的面积，这个面积值就是该类别的**平均精度**。
6.  **计算均值**：对数据集中所有类别重复上述过程，计算每个类别的AP，然后取平均值，即得到**平均精度均值**，也就是我们常说的**mAP**。

mAP综合考虑了算法在不同置信度阈值下的精确率和召回率表现，是目标检测领域最常用、最重要的评估指标之一。

## 总结 📝

本节课我们一起学习了目标检测的核心评估指标——平均精度。我们首先了解了目标检测的任务定义，然后学习了如何通过交并比来判断检测的正确性，并引出了精确率和召回率这两个基础指标。最后，我们详细讲解了如何通过绘制并平滑精确率-召回率曲线来计算单个类别的平均精度，并通过对所有类别取平均得到最终的mAP值。虽然mAP并非一个完美的指标，但它目前是衡量和比较不同目标检测算法性能最有效、最通用的工具。
