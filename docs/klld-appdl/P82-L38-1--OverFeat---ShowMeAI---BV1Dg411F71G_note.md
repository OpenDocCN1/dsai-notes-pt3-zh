# 课程P82：L38.1 - OverFeat 🧠

在本节课中，我们将要学习一篇名为 **OverFeat** 的经典论文。这篇论文发表于2013年，是早期尝试将目标检测任务中的区域提议网络（Region Proposal Network）和检测网络（Detector Network）合并为一个统一框架的重要工作。我们将详细解析其网络结构、多尺度处理策略以及如何在一个前向传播中同时完成分类、定位和检测。

## 从两阶段检测器到单阶段检测器

![](img/33cb0172ad551ba9365e613a9ee578f3_9.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_11.png)

上一节我们介绍了基于区域提议的两阶段目标检测器。这类方法首先使用一个区域提议网络生成候选框，然后使用一个卷积神经网络对这些候选框进行分类和边界框回归。

![](img/33cb0172ad551ba9365e613a9ee578f3_13.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_15.png)

现在的问题是：**能否将这两个阶段合并，在一个前向传播中同时完成区域提议和检测？** 这样做是否会提高效率？如果效率提高了，又会损失多少精度？因为当时最先进的目标检测器都是两阶段的。

![](img/33cb0172ad551ba9365e613a9ee578f3_17.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_19.png)

为了解决这个问题，单阶段检测器（One-stage Detectors）应运而生。**OverFeat** 就是这类方法的早期代表之一。

## OverFeat 网络架构 🔧

![](img/33cb0172ad551ba9365e613a9ee578f3_25.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_27.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_29.png)

OverFeat 的网络结构与 **AlexNet** 非常相似。让我们逐层分析：

![](img/33cb0172ad551ba9365e613a9ee578f3_31.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_33.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_35.png)

*   **第一层**：卷积层（滤波器尺寸 7x7，步长 2） + 最大池化层（池化尺寸 3x3，步长 2）。步长操作会进行下采样，降低特征图的分辨率。
*   **后续层**：包含多个卷积层和池化层，继续进行下采样。
*   **全连接层之前**：网络的总下采样比率（Total Sub-sampling Ratio）为 **36**（即 2 × 3 × 2 × 3）。

![](img/33cb0172ad551ba9365e613a9ee578f3_37.png)

我们知道，在 AlexNet 中，为了在推理时获得更好的分类精度，会对输入图像进行 **10-crop** 操作（取四个角和中心，再水平翻转），将这10个区域分别输入网络，然后对10个预测结果进行投票（通常是概率平均）。

![](img/33cb0172ad551ba9365e613a9ee578f3_39.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_41.png)

以下是 OverFeat 提升分类精度的核心方法：

![](img/33cb0172ad551ba9365e613a9ee578f3_63.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_65.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_67.png)

OverFeat 对输入图像使用**六种不同的尺度**。对于每个尺度的图像，网络会生成多个预测（例如，对于某个尺度，通过特定的滑动窗口策略可以得到9个预测）。最终，将所有尺度得到的大量预测结果进行平均，从而得到更鲁棒的最终分类结果。

![](img/33cb0172ad551ba9365e613a9ee578f3_73.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_75.png)

那么，如何高效地生成这些多尺度、多位置的预测呢？关键在于理解网络中的**偏移（Delta Shift）** 操作。

### 理解偏移操作与下采样比率

![](img/33cb0172ad551ba9365e613a9ee578f3_85.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_87.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_89.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_91.png)

在第五层卷积之前，假设对于尺度2的图像，我们得到了一个分辨率为 **20x23** 的特征图。我们希望进行池化，但直接池化会导致下采样比率过大（36倍）。

![](img/33cb0172ad551ba9365e613a9ee578f3_93.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_95.png)

目标是**将总下采样比率从36降低到12**。这可以通过在池化操作前引入偏移来实现。

![](img/33cb0172ad551ba9365e613a9ee578f3_97.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_99.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_101.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_103.png)

**具体操作如下（以X维度为例，Y维度同理）：**

![](img/33cb0172ad551ba9365e613a9ee578f3_105.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_107.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_109.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_111.png)

1.  原始特征图在X维度上有20个值。
2.  我们使用一个池化窗口（例如尺寸为3），但并非从固定位置开始。
3.  我们进行**三次**池化操作，每次池化窗口的起始位置向右偏移**1个像素**：
    *   **偏移量 Δ=0**：对位置 [0, 1, 2], [3, 4, 5]... 进行池化。
    *   **偏移量 Δ=1**：对位置 [1, 2, 3], [4, 5, 6]... 进行池化。
    *   **偏移量 Δ=2**：对位置 [2, 3, 4], [5, 6, 7]... 进行池化。
4.  每次池化后，在X维度上会得到 **6** 个值（因为 20 / 3 ≈ 6.67，取整操作后为6）。
5.  因此，经过三次偏移池化后，我们得到了 **3组 x 6个** 特征值。

![](img/33cb0172ad551ba9365e613a9ee578f3_113.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_115.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_117.png)

**关键公式与数字：**
*   池化前分辨率（X维度）：`20`
*   池化后分辨率（X维度）：`6`
*   偏移次数：`3`
*   总下采样比率从 `36` 降低为 `36 / 3 = 12`

![](img/33cb0172ad551ba9365e613a9ee578f3_119.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_121.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_123.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_125.png)

### 连接全连接层

![](img/33cb0172ad551ba9365e613a9ee578f3_129.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_131.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_133.png)

全连接层要求输入是固定尺寸的（例如 5x5）。因此，我们需要从上述池化后的特征中提取出 5x5 的块。

![](img/33cb0172ad551ba9365e613a9ee578f3_135.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_137.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_139.png)

![](img/33cb0172ad551ba9365e613a9ee578f3_141.png)

*   在X维度上，我们从6个值中，每次滑动取出连续的5个值，可以得到 **2** 个这样的块（位置[0-4]和[1-5]）。
*   在Y维度上，通过类似操作可以得到 **3** 个块。
*   因此，对于每个偏移量（Δ），我们可以得到 `2 x 3 = 6` 个符合全连接层输入要求的区域。
*   由于我们有3个偏移量，所以总共会得到 `6 x 3 = 18` 个预测向量。再乘以分类数量，就得到了最终大量的分类预测。

![](img/33cb0172ad551ba9365e613a9ee578f3_143.png)

**这种方法的效率非常高**，因为卷积运算本身就非常适合滑动窗口，大部分计算在特征提取阶段是共享的，增加偏移和尺度带来的额外计算成本相对较小。

![](img/33cb0172ad551ba9365e613a9ee578f3_145.png)

## 定位与检测任务 🎯

![](img/33cb0172ad551ba9365e613a9ee578f3_151.png)

到目前为止，我们已经有了一个强大的特征提取器（称为 **OverFeat**）。现在，我们在此基础上增加**定位（Localization）** 和**检测（Detection）** 功能。

### 边界框回归头

我们采用**多任务学习（Multi-task Learning）** 框架：

1.  **固定特征提取器**：保持从输入到高层特征的所有网络参数不变。
2.  **添加回归头**：在共享的特征提取器之后，并联一个用于边界框回归的新网络“头”（Head）。这个头通常由几层全连接层构成。
3.  **回归目标**：回归头的输出是 **4个值**，对应预测边界框的左上角坐标 `(x1, y1)` 和右下角坐标 `(x2, y2)`。重要的是，这是**按类别（per-class）** 的回归，即每个类别都有自己独立的4个回归器。
4.  **损失函数**：使用 **L2 损失** 来训练这个回归头。

至此，网络可以同时输出分类得分和每个类别的边界框坐标，生成了大量的候选框。

### 边界框合并策略

网络会生成海量的边界框，我们需要将它们合并成最终少量的检测结果。OverFeat 没有使用常见的非极大值抑制（NMS），而是提出了一种**贪心合并策略（Greedy Merge Strategy）**。

**算法步骤如下：**

1.  **收集候选框**：对于每个图像尺度，分类头选出概率最高的前K个类别，回归头则给出这些类别对应的边界框。将所有尺度的这些边界框收集到一个集合 `B` 中。
2.  **计算匹配度**：定义两个框之间的匹配度得分。得分基于两个框的中心点距离和它们的交集面积。得分越低，表示两个框越不匹配（可能是不同物体）。
3.  **迭代合并**：
    *   在集合 `B` 中找到匹配度得分**最低**的两个框。
    *   如果它们的最低得分仍然高于一个阈值 `t`，说明所有框都已足够独立，算法停止。
    *   否则，将这两个框合并（例如，直接平均它们的坐标），将合并后的新框加入 `B`，并移除原来的两个框。
4.  **输出结果**：当算法停止时，集合 `B` 中剩余的边界框就是最终的检测结果。

这种贪心合并是 NMS 的一种替代方案，在这篇论文中被采用。

## 总结 📝

本节课我们一起学习了 **OverFeat** 这篇开创性的单阶段目标检测论文：

*   **核心动机**：将两阶段检测合并为单阶段，提升效率。
*   **网络基础**：基于 AlexNet 结构，作为一个强大的特征提取器。
*   **关键技术1：多尺度密集预测**：通过输入图像多尺度化和卷积层内的偏移操作，显著降低有效下采样比率（从36到12），从而在单次前向传播中高效生成大量分类预测，并通过平均提升精度。
*   **关键技术2：多任务学习**：在共享的特征提取器上，并行添加分类头和回归头，实现分类与边界框回归的同步进行。
*   **后处理**：使用一种贪心合并策略来处理大量重叠的预测框，生成最终的检测结果。

OverFeat 统一了分类、定位和检测任务，为后续更高效的单阶段检测器（如YOLO, SSD）奠定了重要的思想基础。
