## 概述

## 从批标准化说起

![](img/b7be239670097f040a872620a54866a8_12.png)

上一节我们介绍了标准化的重要性，本节中我们来看看最经典的批标准化。首先，我们需要理解一个简单神经网络层的基本计算。

![](img/b7be239670097f040a872620a54866a8_14.png)

假设我们有一个全连接层。我们用 **a^l** 表示第 `l` 层的“求和输入”向量。该向量由上一层的输出 **h^{l-1}** 与权重矩阵 **W^l** 相乘，再加上偏置向量 **b^l** 得到。公式如下：

**a^l = W^l h^{l-1} + b^l**

![](img/b7be239670097f040a872620a54866a8_16.png)

![](img/b7be239670097f040a872620a54866a8_17.png)

![](img/b7be239670097f040a872620a54866a8_18.png)

![](img/b7be239670097f040a872620a54866a8_19.png)

然后，**a^l** 会通过一个非线性激活函数（如ReLU）得到该层的输出 **h^l**，并作为下一层的输入。

没有标准化时，深度神经网络可能难以收敛，原因在于“内部协变量偏移”。即，当网络参数在训练中更新时，每一层输入的分布（均值和方差）会发生变化，这可能导致激活函数饱和，梯度消失或爆炸。

批标准化通过规范化每一层的输入来解决这个问题。其操作基于当前训练批次的数据。

![](img/b7be239670097f040a872620a54866a8_21.png)

![](img/b7be239670097f040a872620a54866a8_22.png)

![](img/b7be239670097f040a872620a54866a8_23.png)

以下是批标准化的计算步骤：
1.  对于一个包含 `m` 个样本的迷你批次，计算该层求和输入 **a** 的均值和方差。
    *   均值：**μ_B = (1/m) Σ_{i=1}^{m} a_i**
    *   方差：**σ_B² = (1/m) Σ_{i=1}^{m} (a_i - μ_B)²**
2.  使用计算出的均值和方差对 **a** 进行标准化：**â = (a - μ_B) / √(σ_B² + ε)**，其中 `ε` 是一个很小的常数，用于数值稳定性。
3.  引入可学习的缩放参数 **γ** 和平移参数 **β**，得到最终输出：**y = γ â + β**。

引入 **γ** 和 **β** 是关键，因为单纯的标准化（均值为0，方差为1）会限制网络的表达能力。这两个参数让网络可以学习恢复最优的分布。

![](img/b7be239670097f040a872620a54866a8_26.png)

## 批标准化的局限性

![](img/b7be239670097f040a872620a54866a8_29.png)

![](img/b7be239670097f040a872620a54866a8_30.png)

![](img/b7be239670097f040a872620a54866a8_31.png)

上一节我们介绍了批标准化的计算过程，本节中我们来看看它的主要问题。批标准化的效果严重依赖于批次大小。

*   当批次较大时，计算出的均值和方差能较好地估计整个数据集的分布。
*   但当批次较小时（例如，处理高分辨率图像、长视频或大型语言模型时，由于内存限制，批次大小可能被迫设为1），这些统计量会变得非常不准确且噪声很大。

![](img/b7be239670097f040a872620a54866a8_34.png)

![](img/b7be239670097f040a872620a54866a8_38.png)

此外，批标准化在处理**序列数据**（如文本、语音）时面临根本性挑战，这正是层标准化被提出的主要动机。

## 层标准化的原理 🧩

为了解决批标准化的上述问题，层标准化应运而生。其核心思想是：**不再依赖批次维度计算统计量，而是针对单个样本，在其特征维度上进行标准化**。

![](img/b7be239670097f040a872620a54866a8_43.png)

![](img/b7be239670097f040a872620a54866a8_44.png)

![](img/b7be239670097f040a872620a54866a8_45.png)

![](img/b7be239670097f040a872620a54866a8_46.png)

![](img/b7be239670097f040a872620a54866a8_47.png)

![](img/b7be239670097f040a872620a54866a8_48.png)

对于一个输入向量 **a**（代表某个样本在某一层的求和输入），层标准化的计算如下：

![](img/b7be239670097f040a872620a54866a8_49.png)

![](img/b7be239670097f040a872620a54866a8_50.png)

1.  计算该样本在该层所有隐藏单元上的均值和标准差。
    *   均值：**μ_l = (1/H) Σ_{i=1}^{H} a_i**
    *   标准差：**σ_l = √( (1/H) Σ_{i=1}^{H} (a_i - μ_l)² + ε )**
    *   其中 `H` 是该层的隐藏单元数量（即特征维度）。
2.  使用该样本自身的均值和标准差进行标准化：**â = (a - μ_l) / σ_l**
3.  同样引入可学习的参数进行缩放和平移：**y = γ â + β**

关键区别在于，**μ_l** 和 **σ_l** 的计算是在特征维度 `i` 上进行的，而不是在批次维度上。因此，每个样本都有自己独立的标准化统计量。

![](img/b7be239670097f040a872620a54866a8_53.png)

## 为何层标准化适用于RNN和Transformer？ 🔄

![](img/b7be239670097f040a872620a54866a8_58.png)

![](img/b7be239670097f040a872620a54866a8_59.png)

上一节我们介绍了层标准化的计算方式，本节中我们来看看它为何特别适合序列模型。

循环神经网络用于处理可变长度的序列数据（如不同长度的句子）。在RNN中，网络在时间步上展开，形成深度结构。

![](img/b7be239670097f040a872620a54866a8_61.png)

![](img/b7be239670097f040a872620a54866a8_62.png)

![](img/b7be239670097f040a872620a54866a8_63.png)

![](img/b7be239670097f040a872620a54866a8_64.png)

![](img/b7be239670097f040a872620a54866a8_65.png)

![](img/b7be239670097f040a872620a54866a8_66.png)

*   如果使用批标准化，我们需要在批次中所有样本的同一时间步上计算统计量。
*   问题在于：序列长度不同。较短的序列在后面的时间步没有有效数据（通常是填充的零）。用这些无效数据计算的均值和方差会严重失真，并且随着网络在时间上加深（处理更靠后的时间步），可用的有效样本越来越少，统计量越来越不准确。

![](img/b7be239670097f040a872620a54866a8_67.png)

![](img/b7be239670097f040a872620a54866a8_68.png)

![](img/b7be239670097f040a872620a54866a8_69.png)

![](img/b7be239670097f040a872620a54866a8_70.png)

![](img/b7be239670097f040a872620a54866a8_71.png)

层标准化完美地避开了这个问题。因为它**独立处理每个样本、每个时间步**的激活值，统计量仅基于当前时间步的隐藏状态向量计算，与批次内其他样本的长度无关，也与序列的历史长度无关。这使得RNN的训练更加稳定。

![](img/b7be239670097f040a872620a54866a8_73.png)

![](img/b7be239670097f040a872620a54866a8_74.png)

![](img/b7be239670097f040a872620a54866a8_75.png)

![](img/b7be239670097f040a872620a54866a8_76.png)

在Transformer模型中，层标准化也被广泛采用（例如，用在每个子层之后），因为它同样不依赖于批次统计，能很好地处理可变长度的序列，并且允许使用很小的批次进行训练。

## 不同标准化方法的性质对比 ⚖️

![](img/b7be239670097f040a872620a54866a8_78.png)

![](img/b7be239670097f040a872620a54866a8_79.png)

除了批标准化和层标准化，还有一种称为权重标准化的技术（通过规范化权重向量来稳定训练）。了解它们对不同变换的不变性有助于我们根据任务选择合适的方法。

![](img/b7be239670097f040a872620a54866a8_88.png)

以下是三种标准化方法对几种变换的不变性总结：

![](img/b7be239670097f040a872620a54866a8_89.png)

| 变换类型 | 批标准化 | 权重标准化 | 层标准化 |
| :--- | :--- | :--- | :--- |
| **权重矩阵重缩放** (整体乘以标量) | **是** | **是** | **是** |
| **权重向量重偏移** (对每行加偏置) | 否 | 否 | **是** |
| **输入数据重缩放** (乘以标量) | **是** | 否 | **是** |
| **输入数据重偏移** (加上标量) | **是** | 否 | 否 |
| **单个训练样本重缩放** | 否 | 否 | **是** |

这些不变性解释了为何标准化能提升训练稳定性。例如，对输入数据重缩放和重偏移的不变性，意味着网络对输入数据的尺度和平移变化不敏感，更专注于学习相对模式。

原论文将层标准化应用于多项任务，包括多模态学习（图像-文本匹配）、阅读理解、语言建模等。

实验结果表明：
*   在**图像分类**（如MNIST）任务上，层标准化的效果不如批标准化，这与预期一致，因为图像数据通常批次较大且长度固定。
*   在**序列任务**（如基于LSTM的阅读理解、手写序列生成）上，层标准化显著优于批标准化，能更快地降低验证误差，取得更好的最终性能。
*   在**图像-文本检索**任务中，加入层标准化可以大幅加快模型训练速度。
