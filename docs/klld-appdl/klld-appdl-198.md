# 🧠 课程 P198：L85.4 - 图注意网络

在本节课中，我们将学习图注意网络（Graph Attention Networks, GATs）。这是一种处理图结构数据的强大神经网络架构。我们将了解其核心思想、工作原理以及如何将其应用于各种图数据。

上一节我们介绍了注意力机制在文本处理中的应用。本节中，我们来看看如何将这一思想扩展到图数据上。

![](img/b443e1809832f3613afde1d21e9c0409_9.png)

![](img/b443e1809832f3613afde1d21e9c0409_10.png)

图数据有多种形式，例如：
*   3D网格
*   社交网络
*   电信网络
*   生物网络
*   大脑连接组

对于图数据，我们可以构建图注意力层。假设你的节点有向量表示，每个节点有 **F** 维特征，总共有 **n** 个节点。你的目标是将其转换到下一层，得到另一个维度（例如 **F‘**）的新特征。这可以通过权重矩阵和自注意力机制来实现。这些概念之前在文本处理中已经见过，这里只是将其快速回顾并应用到图数据上。

首先，你需要计算一个节点与另一个节点之间的“分数”，这个分数将给出你的注意力系数。这个分数是一个从负无穷到正无穷的数值。

你可以进行掩码注意力，这样你就不会关注邻居以外的节点。例如，你可能只想关注节点自身及其直接邻居，或者关注自身和两步之外的节点，而屏蔽其他节点，不对它们分配注意力。

![](img/b443e1809832f3613afde1d21e9c0409_14.png)

![](img/b443e1809832f3613afde1d21e9c0409_15.png)

![](img/b443e1809832f3613afde1d21e9c0409_16.png)

![](img/b443e1809832f3613afde1d21e9c0409_17.png)

接着，你需要将这些分数转化为实际数值，并使它们相加和为1。因为你的注意力“预算”总和为1，这代表了节点 **i** 对节点 **j** 的关注程度。

![](img/b443e1809832f3613afde1d21e9c0409_18.png)

![](img/b443e1809832f3613afde1d21e9c0409_19.png)

![](img/b443e1809832f3613afde1d21e9c0409_20.png)

![](img/b443e1809832f3613afde1d21e9c0409_21.png)

![](img/b443e1809832f3613afde1d21e9c0409_22.png)

以下是计算分数的核心步骤：
1.  取节点 **i** 和节点 **j** 的特征表示 **x_i** 和 **x_j**。
2.  将它们拼接（concatenate）起来。
3.  将这个拼接后的向量乘以一个矩阵（或向量），得到一个单一数值，这就是你的分数。

![](img/b443e1809832f3613afde1d21e9c0409_23.png)

![](img/b443e1809832f3613afde1d21e9c0409_24.png)

![](img/b443e1809832f3613afde1d21e9c0409_25.png)

一旦得到分数，你将其通过 **softmax** 函数，使其总和为1，然后将这份注意力“预算”分配到你的邻居节点中。

最后，你将结果通过一个非线性激活函数。

## 👁️ 多头注意力与可视化

![](img/b443e1809832f3613afde1d21e9c0409_28.png)

![](img/b443e1809832f3613afde1d21e9c0409_29.png)

从视觉上看，这个过程是这样的：你取节点 **i** 和节点 **j** 的特征 **h_i** 和 **h_j**，乘以同一个权重矩阵，计算出需要分配多少注意力。然后通过 **softmax** 函数得到最终的注意力权重。

![](img/b443e1809832f3613afde1d21e9c0409_31.png)

![](img/b443e1809832f3613afde1d21e9c0409_32.png)

![](img/b443e1809832f3613afde1d21e9c0409_33.png)

![](img/b443e1809832f3613afde1d21e9c0409_34.png)

![](img/b443e1809832f3613afde1d21e9c0409_35.png)

就像在文本处理中一样，你也可以使用多头注意力。这非常简单，你只需将多个这样的表示拼接在一起，这会增加你的特征维度。

![](img/b443e1809832f3613afde1d21e9c0409_36.png)

![](img/b443e1809832f3613afde1d21e9c0409_37.png)

![](img/b443e1809832f3613afde1d21e9c0409_38.png)

对于最后一层，你通常不希望特征维度继续增加，而是希望保持相同。因此，在最后一层，你不进行拼接，而是进行平均操作，或许最终是为了得到概率输出。

以下是多头注意力的可视化过程：
*   节点 **H1** 通过多个“头”关注自身和其他节点（如 **H2, H3, H4, H5, H6**）。
*   每个“头”计算不同的注意力模式。
*   最终，这些信息汇聚到下一层，生成新的节点表示 **H1‘**。

图注意力网络既可用于直推式学习，也可用于归纳式学习。你可以用它来获取图的表示并进行可视化。

## ❓ 问答环节：归纳学习与特征处理

**问：** 与之前的模型相比，是什么让图注意力网络特别适合动态图？如果图在变化，节点和标签也会变，算法如何调整以获得正确的嵌入？

**答：** 这是一个非常好的问题，涉及归纳式与直推式学习的区别。你会在某个时间点基于给定的图学习参数（即那些权重矩阵 **W**）。一旦学会了，这些参数就固定了。

现在，假设有一个新用户加入你的图。你不需要重新训练整个模型。你只需要将这个新节点加入，查看它的邻居。这个新节点会影响其邻居的表示。一旦某个节点的表示发生变化，你就查看它的邻居，并更新那些邻居的表示。这只是一个单次传递的过程，你遍历数据并更新每个受影响节点的表示。因此，你不需要重新训练，这就是关键所在。

**问：** 我对特征部分有点困惑。一个节点可以有多个特征（比如人的身高、朋友数量等）。嵌入向量是对应这些特征吗？它具体如何与特征一起工作？

**答：** 如果你一开始就有特征，你可以在此基础上构建。如果你从独热编码向量开始，意味着你对节点没有任何先验假设，它们只是不同的ID。但有时你可能拥有特征，例如用户的年龄类别、性别、使用的浏览器等信息。你可以将这些信息放入一个向量中，作为你后续卷积操作的初始点。

因此，你不必从独热编码向量开始，可以从更多信息开始。你也可以从节点的度（连接数）作为特征开始。这比我们之前仅使用度矩阵的方法更灵活，意味着你可以从零开始，也可以从一些已有的特征信息开始。

如果你没有任何信息，第一层本质上就会成为你的嵌入层。因为当你将一个独热向量乘以一个矩阵时，你实际上是在选取该矩阵的一行或一列，这就可以作为你的节点表示。所以，这是之前随机块类型节点表示方法的一个更深层版本，得益于非线性和多层结构。

## 📝 总结

本节课中，我们一起学习了图注意网络。我们了解了如何将注意力机制应用于图结构数据，包括计算节点间的注意力分数、使用掩码和softmax分配注意力，以及引入多头注意力以捕获更丰富的信息。我们还讨论了GATs在动态图场景下的优势（归纳式学习），以及如何利用节点的初始特征。图注意力网络为处理复杂的、非欧几里得空间的数据提供了一种强大而灵活的方法。
