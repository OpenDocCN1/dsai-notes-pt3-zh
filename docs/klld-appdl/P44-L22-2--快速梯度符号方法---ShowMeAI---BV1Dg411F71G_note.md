# 课程 P44：L22.2 - 快速梯度符号方法 ⚡

在本节课中，我们将要学习一种名为“快速梯度符号方法”的技术，用于高效生成对抗样本。我们将探讨对抗样本存在的原因，并理解如何通过一种廉价的方法来增强神经网络的鲁棒性。

---

上一节我们讨论了通过添加对抗样本来增强模型鲁棒性的想法，但指出了其计算成本高昂的问题。本节中我们来看看是否存在一种更廉价的方法来生成对抗样本。

首先，我们需要理解对抗样本为何会存在。以下是一些可能的解释：

![](img/4acd3f587914119178a089089d2c33b1_3.png)

![](img/4acd3f587914119178a089089d2c33b1_9.png)

*   **分类边界**：任何分类器都存在决策边界，靠近边界的样本容易被微小扰动改变分类结果。
*   **高维空间**：图像数据处于高维空间，即使扰动很小，在高维空间中也可能导致输出发生巨大变化。
*   **模型非线性**：神经网络的非线性特性可能使得输入空间的微小变化被放大。
*   **权重条件数**：权重矩阵的条件数不佳可能导致模型对输入扰动过于敏感。

以下是生成对抗样本的步骤：

![](img/4acd3f587914119178a089089d2c33b1_177.png)

![](img/4acd3f587914119178a089089d2c33b1_179.png)

![](img/4acd3f587914119178a089089d2c33b1_181.png)

![](img/4acd3f587914119178a089089d2c33b1_183.png)

![](img/4acd3f587914119178a089089d2c33b1_185.png)

![](img/4acd3f587914119178a089089d2c33b1_187.png)

1.  设模型参数为 **θ**，输入为 **x**，真实标签为 **y**，损失函数为 **J(θ, x, y)**。
2.  计算损失函数相对于输入 **x** 的梯度：**∇ₓ J(θ, x, y)**。
3.  通过取该梯度的符号并乘以一个小常数 **ε** 来构造扰动：**η = ε · sign(∇ₓ J(θ, x, y))**。
4.  生成对抗样本：**x̃ = x + η**。

![](img/4acd3f587914119178a089089d2c33b1_189.png)

![](img/4acd3f587914119178a089089d2c33b1_191.png)

![](img/4acd3f587914119178a089089d2c33b1_193.png)

![](img/4acd3f587914119178a089089d2c33b1_195.png)

![](img/4acd3f587914119178a089089d2c33b1_197.png)

![](img/4acd3f587914119178a089089d2c33b1_199.png)

这种方法非常高效，因为在反向传播过程中，我们几乎可以“免费”获得输入梯度 **∇ₓ J**。与之前需要解决优化问题的方法相比，FGSM 的成本极低。

*   **数据增强**：在训练过程中，动态生成对抗样本并将其添加到训练集中。
*   **修改损失函数**：设计一个新的损失函数，同时考虑原始样本和对抗样本的损失。

在逻辑回归的特定设定下（标签 **y ∈ {-1, +1}**），使用 FGSM 进行对抗训练所引入的正则化项，经过推导，近似等价于对权重 **w** 的 **L1 正则化**（即 **λ‖w‖₁**）。

![](img/4acd3f587914119178a089089d2c33b1_323.png)

![](img/4acd3f587914119178a089089d2c33b1_325.png)

这表明，**对抗训练可以看作是传统 L1 正则化在复杂非线性神经网络上的一种泛化**。它惩罚的是那些会使损失函数对输入变化敏感的参数方向，而不仅仅是参数的大小。

本节课中我们一起学习了快速梯度符号方法。我们首先探讨了对抗样本存在的可能原因，并发现即使线性模型也难以幸免。接着，我们利用线性模型的洞察，推导出了 FGSM 这种高效生成对抗样本的算法。最后，我们了解了如何利用 FGSM 进行对抗训练来提升模型鲁棒性，并揭示了其与经典 L1 正则化之间的深刻联系。掌握这种方法，使我们能够以更低的成本研究和防御对抗性攻击。
