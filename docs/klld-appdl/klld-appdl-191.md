# 🧠 课程 P191：L83.3 - Soft Actor-Critic 算法

在本节课中，我们将学习强化学习领域的一个重要算法——Soft Actor-Critic (SAC)。SAC 旨在结合策略优化和价值优化两种框架的优点，以解决高样本复杂度和超参数敏感性的问题。我们将从最大熵强化学习的基本概念出发，逐步推导出 SAC 算法的核心公式和实现步骤。

## 🎯 最大熵目标函数

在传统的强化学习中，目标是最大化期望累积奖励。在最大熵框架下，目标被修改为同时最大化期望累积奖励和策略的熵。

![](img/5e8255c4c44a9aa2541fe1fea094aef9_27.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_28.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_29.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_30.png)

**目标函数公式：**
`J(π) = Σ E_{(s_t, a_t) ~ ρ_π} [r(s_t, a_t) + α H(π(·|s_t))]`

![](img/5e8255c4c44a9aa2541fe1fea094aef9_31.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_32.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_33.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_34.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_35.png)

其中 `H(π(·|s_t))` 是策略在状态 `s_t` 下的熵，`α` 是温度参数，用于控制熵项的重要性。

这与仅在策略梯度中添加熵正则项以鼓励探索的做法有本质区别。在这里，熵被直接纳入了优化目标本身，这将导致我们得到一个新的“软”价值函数。

## 💡 软贝尔曼方程与引理

![](img/5e8255c4c44a9aa2541fe1fea094aef9_38.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_39.png)

基于新的目标函数，我们可以推导出对应的软贝尔曼备份算子 `T^π` 和软状态价值函数 `V`。

![](img/5e8255c4c44a9aa2541fe1fea094aef9_44.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_45.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_46.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_47.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_48.png)

**软贝尔曼备份算子定义：**
`(T^π Q)(s_t, a_t) = r(s_t, a_t) + γ E_{s_{t+1} ~ P}[V(s_{t+1})]`

**软状态价值函数定义：**
`V(s_t) = E_{a_t ~ π}[Q(s_t, a_t) - α log π(a_t|s_t)]`

“软”这个词来源于价值函数中包含了策略熵的项 `-α log π(a_t|s_t)`。

为了构建算法，我们需要两个核心引理：

![](img/5e8255c4c44a9aa2541fe1fea094aef9_50.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_51.png)

1.  **软策略评估引理**：重复应用软贝尔曼备份算子 `T^π`，软 Q 值会收敛到该策略 π 的真实软 Q 值。
2.  **软策略改进引理**：通过最小化新旧策略之间的 KL 散度，可以改进策略。具体来说，新策略 `π_new` 可以通过以下方式得到：
    `π_new = arg min_{π'} D_KL(π'(·|s_t) || exp(Q^{π_old}(s_t, ·)/α) / Z(s_t))`
    其中 `Z(s_t)` 是归一化配分函数。可以证明，这样得到的新策略的软价值函数不低于旧策略。

## 🧩 软策略迭代定理

结合上述两个引理，我们可以得到**软策略迭代定理**：交替进行软策略评估和软策略改进，最终可以收敛到一个最优策略 `π*`，该策略在允许的策略类 `Π` 中是最优的。关于策略类 `Π` 的具体约束，需要参考原论文。

这个定理为我们将要讨论的 Soft Actor-Critic 算法提供了理论保证。

## 🤖 Soft Actor-Critic (SAC) 算法

![](img/5e8255c4c44a9aa2541fe1fea094aef9_65.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_66.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_67.png)

在深度强化学习的实践中，我们使用神经网络来近似各种函数。SAC 算法主要维护三个神经网络：

![](img/5e8255c4c44a9aa2541fe1fea094aef9_71.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_72.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_73.png)

![](img/5e8255c4c44a9aa2541fe1fea094aef9_74.png)

1.  **软状态价值网络 `V_ψ(s)`**：参数为 ψ，输入状态，输出标量价值。
2.  **软 Q 价值网络 `Q_θ(s, a)`**：参数为 θ，输入状态和动作，输出标量 Q 值。
3.  **策略网络 `π_φ(a|s)`**：参数为 φ，输入状态，输出动作的概率分布（例如高斯分布的均值和方差）。

接下来，我们基于之前的定理和定义，为这些网络构建损失函数。

以下是各个网络的优化目标：

**1. 软状态价值网络 `V_ψ` 的损失函数：**
其目标是最小化当前估计值与基于 Q 值和策略的期望值之间的误差。
`J_V(ψ) = E_{s_t ~ D} [ (V_ψ(s_t) - E_{a_t ~ π_φ}[Q_θ(s_t, a_t) - α log π_φ(a_t|s_t)])^2 ]`

![](img/5e8255c4c44a9aa2541fe1fea094aef9_76.png)

**2. 软 Q 价值网络 `Q_θ` 的损失函数：**
类似于 DQN，我们使用均方误差，但目标值来自软贝尔曼方程。
`J_Q(θ) = E_{(s_t, a_t) ~ D} [ (Q_θ(s_t, a_t) - (r(s_t, a_t) + γ E_{s_{t+1} ~ P}[V_ψ̄(s_{t+1})]))^2 ]`
其中 `ψ̄` 是目标价值网络的参数，通常使用 `ψ` 的指数移动平均值来更新，以稳定训练。

**3. 策略网络 `π_φ` 的损失函数：**
其目标来源于软策略改进引理中的 KL 散度最小化。经过推导，一个可计算的损失函数是：
`J_π(φ) = E_{s_t ~ D, ε_t ~ N} [ α log π_φ(f_φ(ε_t; s_t)|s_t) - Q_θ(s_t, f_φ(ε_t; s_t)) ]`
这里使用了**重参数化技巧**：我们从标准正态分布采样噪声 `ε_t`，然后通过策略网络 `f_φ`（输出动作分布的参数）将其转换为动作 `a_t = f_φ(ε_t; s_t)`。这使得整个损失函数对于策略参数 `φ` 是可微的。

值得注意的是，Q 网络在这里通过梯度 `∇_a Q` 来指导策略网络的更新，这与 Deep Deterministic Policy Gradient (DDPG) 的思想类似。实际上，SAC 可以被视为 DDPG 的一种泛化。

---

## 📋 SAC 算法流程

以下是 SAC 算法的核心步骤：

1.  初始化价值网络 `V_ψ`、Q 网络 `Q_θ`、策略网络 `π_φ` 以及目标网络参数 `ψ̄`。
2.  初始化经验回放缓冲区 `D`。
3.  **对于每一个训练周期：**
    *   根据当前策略 `π_φ` 与环境交互，收集状态转移样本 `(s_t, a_t, r_t, s_{t+1})` 并存入 `D`。
    *   从 `D` 中采样一批数据。
    *   按照上述损失函数 `J_V(ψ)`、`J_Q(θ)`、`J_π(φ)` 的顺序，分别更新价值网络、Q 网络和策略网络的参数。
    *   使用指数移动平均更新目标价值网络参数：`ψ̄ ← τ ψ + (1-τ) ψ̄`。

## 🏆 性能对比

在诸如 Humanoid 等复杂控制任务上，SAC 算法展现出了卓越的性能。与 Deep Deterministic Policy Gradient (DDPG) 和 Proximal Policy Optimization (PPO) 相比，SAC 通常能更快地收敛，并获得更高的平均回报。这得益于其最大熵框架带来的更高效的探索能力。

---

## ❓ 常见问题与讨论

**问：SAC 需要维护三个网络，参数量很大，计算成本是否很高？**
答：确实，SAC 需要参数化价值函数、Q 函数和策略。然而，在 PPO 或 DDPG 等方法中，我们通常也需要参数化策略和 Q 函数（或价值函数）。SAC 主要额外增加了一个状态价值网络 `V`，这部分开销通常是可接受的。其带来的优势——通过随机策略实现更好的探索——往往超过了参数增加的成本。

**问：温度参数 `α` 如何设定？**
答：`α` 是一个重要的超参数，它平衡了奖励最大化和熵最大化。虽然需要调整，但原论文中的研究表明，SAC 对 `α` 的选择相对不那么敏感。此外，也有一些工作致力于自动调整 `α`。

**问：除了 `α`，还有哪些关键超参数？**
答：与其他深度强化学习算法一样，学习率、折扣因子 `γ`、目标网络更新系数 `τ`、批次大小等都是关键超参数。这些属于优化框架本身的通用参数。
