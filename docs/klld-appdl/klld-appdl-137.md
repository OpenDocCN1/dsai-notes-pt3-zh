# 课程 P137：L64.3 - 条件生成对抗网络 (cGAN) 🎨

在本节课中，我们将要学习条件生成对抗网络。这是一种强大的生成模型，它允许我们根据给定的额外信息（如文本、标签或图像）来生成特定内容。我们将了解其核心思想、目标函数以及它在图像生成和图像标注等任务中的应用。

## 概述

上一节我们介绍了生成对抗网络的基本原理。本节中我们来看看它的一个重要变体——条件生成对抗网络。条件GAN的核心思想非常简单：在生成器和判别器的输入中，除了原始数据或噪声外，还加入一个额外的条件信息 **y**。这使得模型能够根据特定条件生成内容，例如根据文本描述生成图像，或根据低分辨率图像生成高分辨率图像。

## 核心思想与应用场景

条件GAN具有广泛的应用。其基本思想是，你拥有一些额外信息，并希望基于此信息生成内容。

以下是条件GAN的一些典型应用场景：
*   **文本生成图像**：根据一段文本描述生成对应的图像。
*   **图像超分辨率**：根据一张低分辨率图像生成对应的高分辨率图像。
*   **条件样本生成**：在MNIST数据集上，生成指定数字（如全零、全一、全二等）的图像。
*   **图像到图像的翻译**：例如将草图转换为真实照片，或将白天场景转换为夜晚场景。

这些应用都属于“一对多映射”问题。这意味着对于一个输入，可能存在多个有效的输出。例如，在翻译任务中，一个法语句子可以有多种同样优秀的英文翻译。

## 目标函数与模型架构

我们之前看到的生成对抗网络的目标函数，在条件版本中修改起来非常简单。你只需要将条件信息 **y** 加入到输入中。

条件GAN的目标函数可以表示为：
`min_G max_D V(D, G) = E_(x~p_data(x))[log D(x|y)] + E_(z~p_z(z))[log(1 - D(G(z|y)))]`

## 以数字生成为例

为了让这个概念更清晰，让我们看一个生成手写数字的例子。假设你想持续生成看起来像数字“0”的样本，或者生成像“1”、“2”、“3”等数字的样本。

![](img/00a00399f41432cc7d81460747236ad2_32.png)

![](img/00a00399f41432cc7d81460747236ad2_33.png)

这里的条件信息 **y** 是一个独热编码的标签向量。如果你对数字“0”感兴趣，那么向量中代表“0”的位置（例如第一个位置）的值就是1，其余位置为0。如果你对数字“7”感兴趣，那么第八个位置的值就是1。

![](img/00a00399f41432cc7d81460747236ad2_34.png)

![](img/00a00399f41432cc7d81460747236ad2_35.png)

![](img/00a00399f41432cc7d81460747236ad2_36.png)

![](img/00a00399f41432cc7d81460747236ad2_37.png)

![](img/00a00399f41432cc7d81460747236ad2_38.png)

![](img/00a00399f41432cc7d81460747236ad2_39.png)

![](img/00a00399f41432cc7d81460747236ad2_40.png)

![](img/00a00399f41432cc7d81460747236ad2_41.png)

这个标签就是你的额外条件信息。现在，你的生成器不仅接收一些随机噪声 **z** 作为输入，还会接收你的标签 **y**。你可以告诉它：“我想生成数字0”或“我想生成数字4”。将这些输入一起送入神经网络，最终你会得到一个“伪造”的图像。

接着，你取出这张伪造的图像，连同真实的图像以及对应的标签，一起送入判别器。实际操作中，你需要将这些信息（图像和标签）连接起来，乘以一系列权重，最终由判别器给出该图像是真实还是伪造的概率。

训练过程与原始GAN相同，只是所有输入都带上了条件。

另一个重要的应用是图像自动标注。当有人给我们一张图像时，我们希望为其打上一些标签。

例如，给定一张街景图像，我们想生成“出租车”、“乘客”、“线路”、“交通”、“车站”等标签。给定一张食物图像，我们想生成“鸡肉”、“烹饪”、“饼干”、“家庭制作”等标签。这同样是一个“一对多映射”问题，因为一张图像可以有多个合理的标签。

那么，我们如何用条件GAN来构建这个问题呢？此时，我们条件依赖的信息 **y** 是图像本身。红色的“图像”部分就是你条件依赖的对象。

![](img/00a00399f41432cc7d81460747236ad2_55.png)

![](img/00a00399f41432cc7d81460747236ad2_56.png)

![](img/00a00399f41432cc7d81460747236ad2_57.png)

![](img/00a00399f41432cc7d81460747236ad2_58.png)

![](img/00a00399f41432cc7d81460747236ad2_59.png)

![](img/00a00399f41432cc7d81460747236ad2_60.png)

![](img/00a00399f41432cc7d81460747236ad2_61.png)

生成器接收随机噪声 **z** 和条件图像 **y**，经过神经网络后，输出一个对应的“伪造”标签。然后，你取出这个伪造标签和一个真实的标签（来自你的数据集），并将它们与条件图像 **y** 一起输入判别器。判别器需要判断这个“标签-图像”对是来自真实数据还是生成器。

![](img/00a00399f41432cc7d81460747236ad2_62.png)

![](img/00a00399f41432cc7d81460747236ad2_63.png)

![](img/00a00399f41432cc7d81460747236ad2_64.png)

![](img/00a00399f41432cc7d81460747236ad2_66.png)

训练完成后，你就可以为新的图像生成标签了。

## 训练细节与问答

![](img/00a00399f41432cc7d81460747236ad2_70.png)

![](img/00a00399f41432cc7d81460747236ad2_71.png)

![](img/00a00399f41432cc7d81460747236ad2_72.png)

![](img/00a00399f41432cc7d81460747236ad2_73.png)

![](img/00a00399f41432cc7d81460747236ad2_74.png)

在训练过程中，一个实际问题是：如何获取“真实标签”？“真实标签”就是你数据集中已有的标注。例如，对于某张图像，你知道它的真实标签是“蒙大拿”、“电车”、“维诺”等。这些标签通常会被编码为词向量。而“伪造标签”则来自你的生成器，初始时可能非常糟糕，但会随着训练逐渐变好。

![](img/00a00399f41432cc7d81460747236ad2_75.png)

![](img/00a00399f41432cc7d81460747236ad2_77.png)

判别器的任务就是区分“真实图像-真实标签”对和“真实图像-伪造标签”对。随着生成器变强，判别器的任务会变得越来越困难。

![](img/00a00399f41432cc7d81460747236ad2_78.png)

![](img/00a00399f41432cc7d81460747236ad2_79.png)

![](img/00a00399f41432cc7d81460747236ad2_80.png)

![](img/00a00399f41432cc7d81460747236ad2_82.png)

关于训练轮次，在理论中，我们假设给定生成器 **G** 可以找到最优判别器 **D**，反之亦然。但在实践中，你需要调整一些超参数，例如训练判别器多少轮，再训练生成器多少轮。这些是需要在实践中积累经验的技术细节。

此外，条件GAN中“条件”和“生成目标”的角色是可以互换的。在数字生成例子中，标签是条件，图像是生成目标。在图像标注例子中，图像是条件，标签是生成目标。同样，条件也可以是文本，根据文本描述来生成图像。所有这些应用都归属于条件GAN的框架之下。
