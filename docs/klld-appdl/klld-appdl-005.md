# 5：L3.1 - 随机失活Dropout 🎲








在本节课中，我们将要学习深度学习中的一项重要技术——随机失活（Dropout）。我们将了解它的两个主要目标：防止模型过拟合以及如何巧妙地组合多个模型。我们会从概念和数学公式两个层面来理解它，并学习其实现方式。







上一节我们介绍了深度学习的开山之作，讨论了卷积和损失函数。本节中，我们来看看该论文中提及但未深入展开的一项技术：Dropout。










## 什么是Dropout？🤔










Dropout在深度学习中有两个主要目标。









第一个目标是**防止模型过拟合**。过拟合发生在模型过于强大，以至于“记住”了训练数据时。这样的模型在训练数据上表现完美，但在未见过的测试数据上表现很差。我们关心的是模型在生产环境（即处理新数据）中的表现。










卷积神经网络由于**权值共享**的概念（例如，同一个3x3或11x11的滤波器在图像上滑动），相对不那么容易过拟合。然而，通常放置在神经网络末端用于提取特征的**全连接层**则容易发生过拟合。Dropout就是为了应对这个问题。









第二个目标是**以巧妙的方式组合多个模型**。通常，为了提升模型的泛化能力，人们会使用模型集成（Ensembling）技术，即让多个模型对同一任务进行预测，然后通过投票或平均得出最终结果。Dropout就是一种实现“智能集成”的方法。











## Dropout如何工作？⚙️











以下是一个标准神经网络与使用了Dropout的网络对比。






















左侧是一个标准神经网络，有输入和神经元。每个神经元的输出是输入与权重的点积，再经过一个非线性激活函数的结果。











Dropout所做的是，在训练过程中，**随机地“丢弃”一部分神经元**。这意味着在每次前向传播时，网络中的每个神经元都有一定的概率被暂时移除（其输出被置为0）。











其核心思想是：**迫使每个神经元能够独立工作**，而不是过度依赖于网络中其他特定神经元的存在。这种现象被称为“协同适应”（co-adaptation），而Dropout的目的正是防止协同适应。












从集成学习的角度看，每一次前向传播，由于随机丢弃的神经元不同，数据“看到”的其实是一个略有不同的网络架构。因此，训练过程相当于在同时训练**指数级数量**的、共享权重的“子网络”。在测试时，我们需要将这些子网络的预测结果结合起来。










## 训练与测试阶段 🔄












在**训练阶段**，对于每一层 \(l\)，我们独立地采样一个掩码向量 \(r^{(l)}\)。其中每个元素都服从伯努利分布（例如，以概率 \(p\) 取1，以概率 \(1-p\) 取0）。然后，我们将该层的激活值乘以这个掩码向量：










\[
\tilde{y}^{(l)} = r^{(l)} * y^{(l)}
\]











其中 \(y^{(l)} = f(z^{(l)})\) 是第 \(l\) 层经过激活函数后的输出，\(z^{(l)} = W^{(l)} y^{(l-1)} + b^{(l)}\)。












被“丢弃”（掩码为0）的神经元，其在前向传播中的贡献为0，在反向传播中对应的权重也不会得到更新。











在**测试阶段**，我们不希望输出是随机的。为了近似地集成所有训练过的子网络，我们采用一种称为**权重缩放**的技巧：保留所有神经元，但是将每一层的权重乘以该层神经元在训练时被保留的概率 \(p\)。










\[
W_{test}^{(l)} = p * W_{train}^{(l)}
\]













这样，测试时神经元的期望输出与训练时大量随机子网络输出的平均值是近似的。











## 如何选择概率 \(p\) ？🎯











概率 \(p\) 是一个超参数，通常通过交叉验证来选择。

![](img/2e147076f781266bf2b61eab4417f21d_434.png)

以下是经验性的选择参考：
*   对于输入层，一个好的 \(p\) 值通常是 `0.8` 或更高（即保留80%以上的输入）。
*   对于中间隐藏层，常用的值是 `0.5`（即随机保留一半的神经元）。

Dropout对 \(p\) 的具体取值并不非常敏感，`0.5` 是一个常用且有效的默认值。

## Dropout的效果与总结 📊

Dropout被广泛应用于各种类型的神经网络（如CNN、RNN）和不同领域（如图像、语音、文本、基因数据）。论文中的实验表明，使用Dropout能有效降低测试误差，并常常使模型收敛更快。

本节课中我们一起学习了：
1.  Dropout的两个核心目标：**防止过拟合**和**近似模型集成**。
2.  Dropout的工作原理：在训练时随机丢弃神经元，迫使神经元独立工作；在测试时通过权重缩放来近似集成效果。
3.  Dropout的数学实现和超参数 \(p\) 的选择。
4.  Dropout是一种通用、有效的正则化技术，几乎可以用于所有类型的神经网络层。

记住，Dropout不仅是一个正则化工具，更是一种巧妙地训练指数数量模型并对其进行集成的智能方法。
