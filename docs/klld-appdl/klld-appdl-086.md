# 86：L40.1 - Focal Loss 🎯

在本节课中，我们将要学习一种用于密集目标检测的新损失函数——Focal Loss。我们将回顾单阶段检测器的发展历程，理解类别不平衡问题的由来，并详细解析Focal Loss如何通过调整损失函数来解决这一问题，从而提升检测器的性能。

## 单阶段检测器回顾 📜

上一节我们介绍了单阶段检测器的发展脉络。我们首先从单阶段检测器开始，最早覆盖的论文是OverFeat，它几乎与用于分类的AlexNet同时期出现。这表明从那时起，人们就开始思考目标检测问题。

随后，我们看到了YOLO（You Only Look Once）。其核心思想是将图像划分为S×S的网格，每个网格负责预测一个边界框、一个置信度以及一个类别概率图。最终，通过将这两者相乘并经过非极大值抑制，得到最终的检测框。

然而，训练YOLO存在一些问题需要解决。其中之一是恰当地权衡这些损失函数，它们都是回归损失，没有分类损失。此外，还需要小心处理边界框的高度和宽度，因为它们是相对于整个图像的尺寸。这就是YOLO。

接着，SSD（Single Shot MultiBox Detector）出现了。它提出可以查看多个特征图，从而提供更多的候选框。它还可以改变损失函数，实际上加入了Softmax形式的分类损失。同样，需要恰当地权衡这两个损失函数。与YOLO相比，这些是主要的变化，并且SSD在速度和精度（平均精度均值）上都取得了非常好的结果，优于Faster R-CNN和YOLO。

然后，YOLO 9000出现了，这是YOLO的第二个版本。它开始与SSD竞争，并提出：如果我们将Faster R-CNN和SSD中的思想（顺便提一下，SSD中还有另一个思想，即类似于Faster R-CNN的锚框）纳入进来，可以提高平均精度均值。但他们进一步指出，实际上，如果根据训练数据中的某种聚类算法来选择锚框，这是没有问题的，因为你从训练数据中知道边界框的分布，所以这不算是作弊。这样做可以获得更好的性能，然后可以摆脱锚框，使用这些先验框。此外，还有一些其他修改，如使用批量归一化、使用传递层（将两个特征图结合起来，这基本上是将较早层的特征图重塑，然后与下一层的特征图拼接，用于检测）。

到目前为止，这些改进构成了YOLO版本2。另一个修改是，现在网络只负责对从聚类中产生的边界框进行小的调整。与边界框的坐标相比，这些是微小的修改。这就是YOLO版本2。

而YOLO 9000之所以得名，是因为它实际上可以预测9000个类别。其中一部分用于分类，数据来自ImageNet，其标签具有精细的细节；另一部分来自COCO，包含大的类别，如猫、狗、汽车、飞机等。在ImageNet中，有波斯猫、虎斑猫、双翼飞机、喷气式飞机等。因此，一个想法是结合这两个数据集。另一个想法是使用分层分类：基本上，从一个物体开始，然后进入动物分支，动物作为猫的父类别，然后继续构建，直到到达叶子节点。例如，你将得到它是诺福克梗的概率（条件是它是梗犬），这将给出该节点在树中的完整概率。剩下的就是训练部分：你在这个数据上联合训练分类和检测算法。

## 引入Focal Loss ⚖️

现在，我将介绍一篇新论文中的损失函数：“Focal Loss for Dense Object Detection”。我们将看看为什么需要一个新的损失函数，以及为什么它是必要的。

![](img/96181912cdb98e5d08d9369d267826d4_33.png)

![](img/96181912cdb98e5d08d9369d267826d4_35.png)

![](img/96181912cdb98e5d08d9369d267826d4_37.png)

![](img/96181912cdb98e5d08d9369d267826d4_39.png)

在分类任务中，训练数据会存在巨大的不平衡。许多边界框非常容易分类：它们要么对应于图像中容易分类的大物体，要么大多数是背景。因此，在训练时会出现类别不平衡问题。

![](img/96181912cdb98e5d08d9369d267826d4_41.png)

![](img/96181912cdb98e5d08d9369d267826d4_43.png)

![](img/96181912cdb98e5d08d9369d267826d4_45.png)

这篇论文指出，单阶段检测器落后于两阶段检测器的主要问题正是由于这种类别不平衡。如果我们能解决这个问题，就能从分类器中获得良好的准确率。

![](img/96181912cdb98e5d08d9369d267826d4_47.png)

![](img/96181912cdb98e5d08d9369d267826d4_49.png)

![](img/96181912cdb98e5d08d9369d267826d4_51.png)

![](img/96181912cdb98e5d08d9369d267826d4_53.png)

处理类别不平衡的一个想法是引入一个α系数。目前，我们假设有两个类别：+1和-1。你可以在损失函数中使用α和1-α。例如，α可以是数据集中正样本的比例，而1-α是负样本的比例。这就是定义α和1-α的方式。

![](img/96181912cdb98e5d08d9369d267826d4_55.png)

![](img/96181912cdb98e5d08d9369d267826d4_57.png)

![](img/96181912cdb98e5d08d9369d267826d4_59.png)

但显然，这还不够。你可以使用交叉熵损失，然后在这里放一个α来处理类别不平衡。对于选择α，你有两个选项：一个是我刚才说的，查看训练数据，统计训练数据中简单样本和困难样本出现的次数，然后根据该规则设置α；另一个选项是使用验证数据来正确设置α，基本上是在训练数据上多次训练算法，观察不同α值在验证数据上的性能，并选择最好的一个。

![](img/96181912cdb98e5d08d9369d267826d4_61.png)

![](img/96181912cdb98e5d08d9369d267826d4_63.png)

![](img/96181912cdb98e5d08d9369d267826d4_65.png)

但显然这还不够。实际上，有一种更简单的方法来处理这个问题，那就是将你的对数概率乘以(1-p)的γ次方。它的作用是：让我们看看不同的γ值。如果γ为0，你将得到交叉熵损失，即这条蓝色曲线。你将在这里看到的所有这些示例都对应于简单样本，它们是具有高概率的样本，这意味着你可以非常容易地对它们进行分类。这些是简单样本，你希望降低它们的权重。如果你调整γ值并使其越来越大，那么你的曲线会越来越低，从红色和黄色到紫色，再到绿色。这样，你就对简单样本施加了非常小的权重。所以，这是另一个工具，可以帮助你通过修改损失函数来处理简单样本。

## 网络结构与训练 🧠

![](img/96181912cdb98e5d08d9369d267826d4_83.png)

![](img/96181912cdb98e5d08d9369d267826d4_85.png)

在网络上，他们实际上使用的是我们之前介绍过的特征金字塔网络。它最初是一个两阶段检测器，但可以修改为单阶段检测器。基本思想是使用图像金字塔（即多尺度图像），利用特征，并通过编码器-解码器结构使这些特征更强。然后，这些特征图将用于预测。每个特征图将为每个锚框预测一个类别和一个边界框。因此，你将有A个锚框，然后有K个类别，这是用于分类的子网络。对于边界框回归子网络，你将有A个锚框，每个锚框将有4个坐标或对这些锚框的调整。这就是你的网络和损失函数。

![](img/96181912cdb98e5d08d9369d267826d4_91.png)

![](img/96181912cdb98e5d08d9369d267826d4_93.png)

![](img/96181912cdb98e5d08d9369d267826d4_95.png)

![](img/96181912cdb98e5d08d9369d267826d4_97.png)

然后，在一轮训练中，你可以使用多任务损失函数同时训练分类器和边界框回归器。最后，问题是：我应该使用什么α和γ？这正是你将在验证数据上做的事情：观察平均精度（这些是COCO风格的平均精度，AP50表示交并比为50%，AP75表示交并比为75%），你不断调整α（这些是你的α值），然后选择最好的一个。最好的可能是0.9，或者我认为31.1是最大的，但这里有一些差异。对于AP50，这是最大的，所以可能我们会选择0.75。你选择了你的α，这是你的最优α，然后你不断变化你的γ。是的，这些是不同的α值，然后你不断变化你的γ。结果表明，这种组合能给你最好的结果，所以这就是你要选择的。你将γ设置为2，α设置为0.25。

## 总结 ✨

本节课中，我们一起学习了Focal Loss。我们首先回顾了单阶段检测器的发展，理解了类别不平衡是阻碍其性能的关键问题。接着，我们深入探讨了Focal Loss的设计原理，它通过引入可调节的α参数和聚焦参数γ，有效降低了简单样本在损失函数中的权重，从而让模型更专注于学习困难样本。我们还了解了应用Focal Loss的RetinaNet网络结构及其训练过程。最后，通过性能对比，我们看到Focal Loss显著提升了单阶段检测器的精度，使其能够与顶级的两阶段检测器竞争。掌握Focal Loss，是理解现代高效目标检测器的重要一步。
