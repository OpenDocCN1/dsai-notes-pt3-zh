## 🖥️ 第一部分：环境与图像基础

上一节我们介绍了课程的整体框架，本节中我们来看看如何搭建开发环境并理解计算机如何处理图像。

### 计算机眼中的图像

对计算机而言，一张图像就是一个由数字组成的矩阵。对于彩色图像，通常使用**BGR**三通道矩阵来表示；对于灰度图像，则是一个单通道的矩阵。每个矩阵元素（像素）的值代表了该点的颜色强度。

### Python与OpenCV配置安装

开始学习前，需要配置好编程环境。以下是核心步骤：

1.  安装Python（建议3.7及以上版本）。
2.  使用pip包管理器安装OpenCV库。
    ```bash
    pip install opencv-python
    ```
3.  可以选择安装Jupyter Notebook或配置PyCharm等IDE作为开发环境。

### 图像与视频的读取处理

安装好环境后，就可以使用OpenCV读取和处理图像与视频了。

以下是对图像进行基本操作的代码示例：
```python
import cv2
# 读取图像
img = cv2.imread('image.jpg')
# 显示图像
cv2.imshow('Image', img)
cv2.waitKey(0)
cv2.destroyAllWindows()
```
对于视频，本质上是逐帧读取图像进行处理：
```python
cap = cv2.VideoCapture('video.mp4')
while True:
    ret, frame = cap.read()
    if not ret:
        break
    # 处理每一帧 frame
    cv2.imshow('Video', frame)
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break
cap.release()
```

### ROI区域

有时我们只对图像中的特定区域感兴趣，这个区域被称为**ROI**。可以通过切片操作轻松获取和修改ROI。
```python
roi = img[y1:y2, x1:x2] # 获取ROI
```

## 🧹 第二部分：图像预处理技术

掌握了图像基础操作后，我们需要学习如何对图像进行预处理，以改善图像质量或提取有用信息。本节将介绍几种常见的预处理技术。

### 图像平滑处理（滤波）

图像平滑主要用于去除噪声。均值滤波是最简单的方法，它用邻域的平均值代替中心像素值。

其公式可以表示为：
`dst(x, y) = (1 / (kernel_width * kernel_height)) * sum(src(x+i, y+j))`
其中，`(i, j)` 在卷积核范围内。

### 高斯滤波与中值滤波

除了均值滤波，还有更常用的滤波方法：
*   **高斯滤波**：根据高斯函数赋予邻域内像素不同的权重，距离中心越近权重越大，平滑效果更自然。
    ```python
    blur = cv2.GaussianBlur(img, (5,5), 0)
    ```
*   **中值滤波**：取邻域内所有像素值的中值来代替中心像素值，对**椒盐噪声**特别有效。
    ```python
    median = cv2.medianBlur(img, 5)
    ```

### 形态学操作：腐蚀与膨胀

形态学操作用于处理图像中的形状特征。
*   **腐蚀操作**：使物体边界向内收缩，可以消除小斑点或分离粘连物体。
    ```python
    kernel = np.ones((5,5), np.uint8)
    erosion = cv2.erode(img, kernel, iterations=1)
    ```
*   **膨胀操作**：与腐蚀相反，使边界向外扩张，可以填补空洞或连接相邻物体。

### 边界填充

在进行卷积等操作时，图像边缘的像素可能没有完整的邻域。边界填充提供了处理边缘的策略，常见方法有常数填充、边缘复制、镜像反射等。
```python
# 使用常数（如0）进行填充
constant = cv2.copyMakeBorder(img, top, bottom, left, right, cv2.BORDER_CONSTANT, value=0)
```

### 图像阈值

阈值化将灰度图像转换为二值图像，用于图像分割。OpenCV提供了多种阈值方法。
```python
ret, thresh_binary = cv2.threshold(gray_img, 127, 255, cv2.THRESH_BINARY)
```

## 🔍 第三部分：图像梯度与边缘检测

图像预处理后，我们常需要检测图像中的边缘，这是许多高级视觉任务的基础。边缘通常对应图像中灰度变化剧烈的区域，可以通过计算**图像梯度**来寻找。

### Sobel算子

Sobel算子是一种用于计算图像梯度近似值的离散差分算子。它分别计算水平和垂直方向的梯度。
*   水平方向Sobel核：
    ```
    [-1, 0, 1]
    [-2, 0, 2]
    [-1, 0, 1]
    ```
*   垂直方向Sobel核：
    ```
    [-1, -2, -1]
    [ 0,  0,  0]
    [ 1,  2,  1]
    ```
计算得到的梯度幅值和方向近似为：
`G = sqrt(Gx^2 + Gy^2)`
`θ = arctan(Gy / Gx)`

### Scharr与Laplacian算子

*   **Scharr算子**：是Sobel算子的优化，对边缘的响应更敏感。
*   **Laplacian算子**：是二阶导数算子，直接计算梯度的散度，对噪声更敏感，常用于判断一个像素是在边缘的亮侧还是暗侧。

### Canny边缘检测流程

Canny边缘检测是一个多阶段的优化算法，效果较好。其流程如下：

1.  **高斯滤波**：平滑图像，去除噪声。
2.  **计算梯度**：使用Sobel等算子计算梯度的幅值和方向。
3.  **非极大值抑制**：沿着梯度方向，保留梯度幅值最大的像素，抑制其他像素，使边缘变细。
4.  **双阈值检测与连接**：
    *   使用高阈值和低阈值将像素分为强边缘、弱边缘和非边缘。
    *   强边缘像素保留为最终边缘。
    *   与强边缘相连的弱边缘像素也被保留为边缘。

```python
edges = cv2.Canny(image, threshold1, threshold2)
```

## 🏗️ 第四部分：特征提取与图像分析

边缘检测帮助我们找到图像的轮廓，而更复杂的任务需要提取更高级的特征。本节我们将学习轮廓、关键点等特征的提取方法。

### 图像金字塔

图像金字塔是同一图像在不同分辨率下的集合。常用于图像缩放、图像融合（如全景图）和多尺度特征提取。
*   **高斯金字塔**：通过重复进行高斯平滑和下采样得到。
*   **拉普拉斯金字塔**：用于重建图像，保存的是高斯金字塔每一层与其上一层上采样结果的差值。

### 轮廓检测

轮廓可以看作是连接所有连续边缘点的曲线。以下是使用OpenCV查找轮廓的基本步骤：
```python
contours, hierarchy = cv2.findContours(binary_image, cv2.RETR_TREE, cv2.CHAIN_APPROX_SIMPLE)
cv2.drawContours(img, contours, -1, (0,255,0), 2)
```
我们可以进一步计算轮廓的特征，如面积、周长、外接矩形等，并对轮廓进行多边形近似。

### 模板匹配

模板匹配是一种在较大图像中搜索和定位模板图像区域的方法。通过滑动模板并计算相似度（如相关系数）来实现。
```python
result = cv2.matchTemplate(img, template, cv2.TM_CCOEFF_NORMED)
min_val, max_val, min_loc, max_loc = cv2.minMaxLoc(result)
```

### 直方图与均衡化

图像直方图表示图像中像素强度值的分布。**直方图均衡化**是一种增强图像对比度的方法，它使得图像的像素强度分布更均匀。
```python
equ = cv2.equalizeHist(gray_img)
```

### 傅里叶变换

傅里叶变换将图像从空间域转换到频率域。在频率域中，图像的低频分量对应平滑区域（如背景），高频分量对应边缘和噪声。这允许我们进行**频域滤波**。
*   **低通滤波**：保留低频，去除高频，使图像模糊。
*   **高通滤波**：保留高频，去除低频，增强边缘。

```python
dft = cv2.dft(np.float32(gray_img), flags=cv2.DFT_COMPLEX_OUTPUT)
dft_shift = np.fft.fftshift(dft)
# 创建掩膜进行滤波...
```

### 角点检测与SIFT特征

*   **角点检测**：角点是图像中在各个方向灰度变化都很大的点。Harris角点检测是经典方法，通过计算一个矩阵M的特征值来判断。
*   **SIFT特征**：尺度不变特征变换是一种强大的局部特征描述子，对旋转、尺度缩放、亮度变化保持不变性。其步骤包括：
    1.  构建尺度空间和高斯差分金字塔。
    2.  检测极值点作为关键点。
    3.  为关键点分配方向。
    4.  生成关键点描述符（特征向量）。

```python
sift = cv2.SIFT_create()
kp, des = sift.detectAndCompute(img, None)
```

## 🎯 第五部分：目标检测与YOLO算法详解

前面我们学习了丰富的图像处理技术，现在可以将它们应用于一个核心任务：目标检测。本节将深入讲解目标检测的评估指标和YOLO系列算法。

### 目标检测基础

目标检测的任务是找出图像中所有感兴趣的目标，并确定它们的位置和类别。

#### 检测阶段与评估指标

目标检测算法可分为**单阶段**（如YOLO、SSD）和**两阶段**（如R-CNN系列）。单阶段算法速度快，两阶段算法精度通常更高。

评估检测效果的核心指标包括：
*   **交并比**：预测框与真实框的交集面积与并集面积的比值，用于判断预测是否正确。
    `IoU = Area of Overlap / Area of Union`
*   **精确率与召回率**：
    *   精确率 = 正确预测的正样本 / 所有被预测为正的样本
    *   召回率 = 正确预测的正样本 / 所有真实的正样本
*   **平均精度均值**：在不同召回率下精确率的平均值，是衡量检测性能的综合指标。

### YOLO算法原理

YOLO的核心思想是将目标检测视为一个**回归问题**，直接在单个神经网络中从图像像素预测边界框和类别概率。

#### YOLOv1 整体思路

1.  将输入图像划分为 S x S 的网格。
2.  每个网格负责预测B个边界框及其置信度，以及C个类别的条件概率。
3.  网络输出一个 `S x S x (B*5 + C)` 的张量。
4.  置信度反映了框包含目标的概率和预测框的准确度：`Confidence = Pr(Object) * IoU(pred, truth)`

#### YOLOv3 主要改进

YOLOv3在之前版本上做了大量优化：
*   **多尺度预测**：在三个不同尺度的特征图上进行预测，更好地检测不同大小的物体。
*   **特征融合**：使用类似FPN的结构，将深层语义特征与浅层细节特征融合。
*   **骨干网络**：采用Darknet-53，引入了残差连接，网络更深更强。
*   **分类预测**：使用独立的逻辑回归代替Softmax，支持多标签分类。

## 🛠️ 第六部分：实战项目

理论学习之后，我们将通过三个实战项目来巩固和综合运用OpenCV与YOLO的知识。

### 项目一：信用卡数字识别

本项目利用模板匹配技术识别信用卡上的数字。
1.  **流程概述**：准备0-9的数字模板，对信用卡图像进行预处理（灰度化、阈值化、轮廓检测），提取每位数字的区域，与模板进行匹配。
2.  **关键步骤**：
    *   图像预处理得到数字的轮廓。
    *   将每个数字轮廓与模板库进行匹配（计算相关系数）。
    *   取匹配度最高的模板类别作为识别结果。

### 项目二：文档扫描与OCR识别

本项目实现将拍摄的文档图像矫正并识别其中的文字。
1.  **流程概述**：检测文档轮廓，进行透视变换得到正视图，最后使用Tesseract OCR引擎识别文字。
2.  **关键步骤**：
    *   使用边缘检测和轮廓查找获取文档的四个角点。
    *   计算透视变换矩阵，将倾斜的文档“拉正”。
    *   配置并使用Tesseract OCR对矫正后的图像进行文字识别。

### 项目三：训练自己的YOLOv3模型

本项目学习如何使用自定义数据训练一个YOLOv3目标检测模型。
1.  **数据准备**：使用LabelMe等工具标注图像，生成边界框和类别标签。将标注文件（如JSON）转换为YOLO格式（每个图像对应一个.txt文件，内容为`<class> <x_center> <y_center> <width> <height>`，数值为相对坐标）。
2.  **环境与配置**：配置Darknet训练环境，根据数据类别修改模型配置文件（.cfg）和数据配置文件（.data）。
3.  **模型训练**：
    *   加载预训练权重。
    *   设置迭代次数、批次大小等参数。
    *   在训练过程中，模型会计算**位置损失**、**置信度损失**和**分类损失**，并反向传播更新权重。
4.  **模型测试**：使用训练好的权重对新的图像或视频进行预测，可视化检测结果。
