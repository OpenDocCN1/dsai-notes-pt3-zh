在本节课中，我们将要学习计算机视觉的基础概念，并了解OpenCV库的基本功能与安装方法。计算机视觉是人工智能的重要分支，旨在让计算机能够“看懂”图像和视频。OpenCV是一个功能强大的开源计算机视觉库，为图像处理提供了丰富的工具。

## 什么是计算机视觉？

计算机视觉的目标是模拟人类视觉系统，使机器能够从数字图像或视频中获取信息、理解内容并做出决策。其应用范围非常广泛。

以下是计算机视觉的一些主要应用领域：
*   **图像分类**：识别图像中的主要物体是什么。
*   **目标检测**：不仅识别物体，还要找出它们在图像中的具体位置（用边界框标出）。
*   **图像分割**：将图像分割成多个区域或对象，进行像素级的识别。

上一节我们介绍了计算机视觉的宏观概念，本节中我们来看看实现这些功能的核心工具——OpenCV。

## OpenCV简介与安装

OpenCV（Open Source Computer Vision Library）是一个基于BSD许可发行的跨平台计算机视觉库。它包含了数百种图像处理和计算机视觉算法，支持C++、Python、Java等多种编程语言。

在Python中使用OpenCV前，需要先进行安装。最常用的方法是使用pip包管理器。

以下是安装OpenCV for Python的命令：
```bash
pip install opencv-python
```
对于需要更多贡献模块（如ArUco标记、背景减除等）的用户，可以安装扩展版：
```bash
pip install opencv-contrib-python
```

安装完成后，我们可以在Python脚本中导入OpenCV库，通常使用`cv2`作为别名。
```python
import cv2
```
