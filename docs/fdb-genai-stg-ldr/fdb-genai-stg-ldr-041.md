# 041：尾部生成模式 🎯

在本节课中，我们将要学习一种称为“尾部生成模式”的提示工程技术。这种技术能有效解决在与大型语言模型进行长对话时，模型可能忘记对话规则或任务目标的问题。

## 概述

当我们与大型语言模型进行长时间对话时，有时会遇到一个挑战：模型可能会忘记我们设定的“游戏规则”或正在尝试完成的任务。因此，我们需要一种方法来提醒模型我们正在做什么。尾部生成模式的核心思想是，让模型在其输出的**末尾**自动生成一段“尾巴”，这段文字会重新引入并强调对话的规则与目标，从而帮助模型维持更长的、符合预期的对话上下文。

上一节我们介绍了替代方案模式与请求输入模式，本节中我们将看看如何将尾部生成模式与它们结合使用。

## 尾部生成模式的工作原理

尾部生成模式通过在模型每次输出的结尾，附加一段固定的或生成的提示性文字来实现。这段“尾巴”的核心作用是**重新引入对话的规则和上下文**。

以下是其工作流程的关键点：
*   **位置固定**：尾部始终出现在模型输出的最后。
*   **内容明确**：尾部内容应清晰地提醒模型当前的任务、规则或下一步该做什么。
*   **结合使用**：它可以与其他模式（如请求输入模式）无缝结合。例如，尾部可以是一个请求用户提供下一个任务的问句。

## 一个结合实例

为了更直观地理解，让我们看一个将尾部生成模式与替代方案模式、请求输入模式结合使用的例子。

假设我们的任务是：让模型（如ChatGPT）持续为我们生成完成特定任务的提示词（Prompt），并且每次都要提供多个替代方案。

初始提示可能如下（这运用了替代方案模式）：
```
请帮我为以下任务生成一组提示词。对于每个任务，请提供多个不同的提示词方案。
任务：编写一个提示词，让ChatGPT能自动从一系列邮件中检测出问题，并以要点形式总结每个人对该问题的看法。
```

如果仅使用上述提示进行多轮对话，模型很可能会在几轮后忘记它需要“生成多个替代方案”这条核心规则。

这时，我们可以运用尾部生成模式来强化规则。我们在给模型的指令末尾添加一句话，要求它在输出结束时生成特定的“尾巴”：

**“当你完成输出后，请在最后询问我下一个需要为其创建替代提示词的任务。”**

请注意，这个“尾巴”同时运用了**请求输入模式**（要求模型主动询问下一个输入）和**规则重申**（暗示了输入的目的和模型应做的处理）。

## 效果演示

当我们输入结合了尾部生成指令的完整提示后，模型会：
1.  为首个任务生成一组替代提示词。
2.  在输出的**最后**，自动生成我们指定的“尾巴”，例如：“请告诉我下一个您希望我为其编写提示词并创建替代方案的任务。”

然后，我们提供下一个任务，例如：“编写一个提示词，用于评估不同的问题总结提示词。”
模型会：
1.  为这个新任务生成替代提示词。
2.  再次在输出末尾生成相同的“尾巴”：“请告诉我下一个您希望我为其编写提示词并创建替代方案的任务。”

通过这种方式，**每次交互结束时，规则都会被自动重新引入对话**。这极大地降低了模型在长对话中忘记初始指令的概率，确保了对话目标的一致性。

## 应用场景与灵活性

尾部生成模式在需要**长时间编程式交互**的场景中尤为有用。当我们预先设定一系列规则，并计划进行多轮交互时，此模式能有效维持上下文。

“尾巴”的内容非常灵活，不限于请求输入。它可以是：
*   对核心规则的简短重述。
*   对当前对话阶段的总结。
*   请求额外信息。
*   任何你认为需要在每次交互后重新强调的内容。

本质上，它是一个附加在输出末尾的“小提示”或“小标记”，用于在进入下一个任务前，提醒大型语言模型：“记住我们一直在讨论什么，这是给你的一个小提示。”

## 总结

本节课中我们一起学习了**尾部生成模式**。我们了解到，通过在大型语言模型的输出末尾固定生成一段提示性文字，可以有效地在长对话中**重新引入并巩固任务规则与上下文**。这种模式特别适合与请求输入、替代方案等其他提示模式结合使用，能显著提升复杂、多轮对话的稳定性和目标一致性。记住，一个精心设计的“尾巴”，是让AI助手在长程任务中保持专注的简单而强大的工具。
