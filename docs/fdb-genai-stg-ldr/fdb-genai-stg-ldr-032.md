# 生成式AI战略领导者：03：模板模式 🧩

在本节课中，我们将学习如何通过“模板模式”来精确控制大型语言模型的输出格式。这种模式能确保模型按照我们指定的结构和样式生成内容，就像为助手提供一个填空模板一样。

## 概述

获取大型语言模型完全符合我们期望格式的输出有时具有挑战性。模板模式旨在解决这一问题。通过向模型提供一个包含占位符的模板，我们可以引导模型将生成的信息填充到指定位置，从而获得结构化的输出。

## 模板模式的工作原理

上一节我们提到了控制输出格式的挑战，本节中我们来看看模板模式的具体实现方式。其核心思想是：我们向模型描述一个输出模板，模型将遵循此模板生成内容，并用其生成的信息替换模板中的占位符。

以下是使用模板模式的基本指令结构：

```markdown
我将为您提供一个输出模板。
全大写的单词是我的占位符。
请用您的输出填充这些占位符。
并请保持我模板的整体格式。
我的模板是：[此处插入模板]
```

在这个指令中，我们首先提示模型需要遵循一个模板。我们约定全大写的单词是待填充的占位符。最后，我们要求模型保持模板的原始格式。

## 一个简单示例：生成问答

让我们通过一个具体例子来理解。假设我们希望模型根据提供的文本生成一系列问答，并且每个问答对都遵循固定的格式。

首先，我们向模型提供模板。以下模板使用了Markdown语法来定义格式，其中`QUESTION`和`ANSWER`是全大写的占位符。

```markdown
***问题***
QUESTION
***答案***
ANSWER
```

在这个模板中，`***`在Markdown中会产生加粗斜体的效果，从而将“问题”和“答案”设置为标题。`QUESTION`和`ANSWER`则是模型需要填充具体内容的位置。

接着，我们告诉模型：“我将在下一个提示中提供需要格式化的数据。请使用我的模板创建20个问题。”然后，我们粘贴一段关于“帕劳印第安人”的维基百科文本。

模型接收指令和文本后，会提取信息，生成20个相关的问答对，并严格按照模板格式输出。例如：

```markdown
***问题***
帕劳印第安人是什么人？
***答案***
帕劳印第安人是史前时期居住在现在美国西南部地区的一群古印第安人。
```

这样，我们就得到了一份格式统一、内容相关的问答列表。

## 模板占位符的进阶用法

模板模式的强大之处在于，占位符不仅可以指示填充位置，还能包含复杂的指令和约束。

例如，我们可以创建一个用于从文本中提取人物传记信息的模板：

```markdown
## 姓名
NAME
## 执行摘要
EXECUTIVE_SUMMARY
## 完整描述
FULL_DESCRIPTION
```

在提供模板时，我们可以为占位符附加详细说明：

*   **`EXECUTIVE_SUMMARY`**：请提供一句总结。
*   **`FULL_DESCRIPTION`**：请提供一段总结。

以下是使用此模板的步骤：
1.  首先，将上述模板及占位符说明提供给模型。
2.  然后，粘贴一大段关于范德堡大学历史的文本。
3.  模型会从文本中自动识别出提到的人物，为每个人物生成一个条目，并严格按照指令填充：`EXECUTIVE_SUMMARY`部分是一句话，`FULL_DESCRIPTION`部分是一个段落。

通过这种方式，占位符从简单的“填空处”变成了包含语义理解和规则遵循的“智能指令点”。我们可以要求模型进行信息提取、总结、按特定规则过滤等复杂操作。

## 模板模式的优势总结

本节课中我们一起学习了模板模式。总结其核心优势如下：

*   **格式控制**：确保输出严格遵循预设的布局和样式。
*   **结构化输出**：轻松获得列表、表格、问答对等结构化数据。
*   **语义化占位符**：占位符可包含复杂指令（如“一句总结”、“按时间顺序列出”），指导模型进行智能填充。
*   **提升效率**：自动化完成从信息提取、加工到格式化的全过程，节省大量人工时间。

模板模式是确保从大型语言模型获得所需格式和内容的有效且强大的方法。通过精心设计模板和占位符指令，你可以将模型转变为高效的结构化内容生成器。
