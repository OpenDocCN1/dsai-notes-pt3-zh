# 025：少样本提示的行动规划示例 🚗

在本节课中，我们将学习大型语言模型如何通过少样本提示技术，执行超越简单分类的复杂任务，例如根据特定情境进行行动规划。我们将通过一个驾驶场景的实例来具体说明。

上一节我们介绍了少样本提示在情感分析中的应用。本节中，我们来看看如何将这项技术应用于一个截然不同的领域——行动规划。

大型语言模型确实具备一定的规划能力。它们能够通过分析少量示例，学习在特定情境下应采取何种后续行动。提供这个例子，并非因为模型仅限于行动规划或情感分析这类任务。目的是希望你能拓展思维，认识到少样本提示作为一种技术，可以适应并应用于各种不同的场景。

我们已经了解了如何使用少样本提示进行情感分析。现在，我们将用它来做一件非常不同的事情。让我们来看一个描述不同驾驶情境的例子。

以下是提供给模型的少样本示例，用于教会它根据“情境”推断“行动”的模式：

*   **情境**：我正以每小时60英里的速度行驶，看到前面车辆的刹车灯亮了。
    **行动**：刹车。
*   **情境**：我刚从匝道进入高速公路，正以每小时30英里的速度行驶。
    **行动**：加速。
*   **情境**：一只鹿突然窜到我的车前，我当时的车速是每小时15英里，且道路旁有宽阔的路肩。
    **行动**：刹车并转向路肩。

通过这些例子，我们正在教导大型语言模型，当给定一个情境时，它需要决定汽车应该做什么。

接着，我们给出一个新的情境来提示模型：“我正在倒车出停车位，看到后面车辆的倒车灯亮了。” 我们在提示末尾留下“行动：”，这表明我们希望大型语言模型来决定行动是什么。

我们看到模型给出的回应是：“**停车，等待后方车辆倒出后再继续**。” 它做出了一个关于行动应该是什么的合理判断。

当然，我们并非要用少样本提示去构建真正的自动驾驶汽车，这还远未达到。但我想表明，我们不必将思维局限在“分类”这样狭窄僵化的框框里。我们实际上可以让模型执行各种复杂的任务。情感分析是复杂任务，而这里的行动规划则是另一种不同性质的复杂任务。因此，我希望我们能非常有创造力地思考如何使用少样本提示。

此外，我们通过这种方式对模型的输出施加了一些约束，它正在学习输出应该是什么样子。

接下来，我要展示大型语言模型一个有趣的能力，即如何使用一个大型语言模型来教导另一个模型。这是一个非常有意思的特性。

我输入指令：“请提供更多示例”，然后以“情境”开头进行提示。模型将开始根据它从我们提供的模式中学到的东西，生成额外的情境和行动描述。

它生成的示例如下：
*   **情境**：你在暴雨中驾驶，注意到前方的道路被淹了。
    **行动**：减速并谨慎驶过积水区域，注意其他车辆，避免突然移动或改变方向。（我个人并不同意这个行动，驶过积水区域可能并非明智之举，这也再次提醒我们需要对大型语言模型的输出负责并进行核查。）
*   **情境**：你在一条双车道公路上行驶，对向一辆车开着远光灯向你驶来。
    **行动**：将你的前灯调至近光，以避免使对向司机眩目。

有趣之处在于，它为我们提供了一些丰富的情境和可能恰当的行动（尽管我对积水示例有保留意见）。我们正在生成不同的情境示例及应对措施，它们看起来与我们之前提供的示例非常相似。

我们可以将这些生成的示例进行整理，由人工进行编辑（例如，我们可能不想要那个关于积水的例子，或者明确制定规则说明不应驶过积水），然后将其作为额外的少样本示例，反馈给同一个或另一个大型语言模型。事实上，已经有人这样做了，例如，他们获取了ChatGPT的输出，并将其输入到另一个模型（如Meta的Llama）中，利用ChatGPT的输出来改进Llama的输出。因此，大型语言模型通过少样本示例，可以为其他模型生成少样本示例，这是另一个有趣的能力。

最后需要回顾的是，这与我们之前看到的任务和风格非常不同。我们有一个“情境”，然后预测一个“行动”。因此，我们可以在任何能够描述模式的地方应用这种方法：提供一组展示输入和期望结果的示例。我们还可以展示包含中间步骤的示例，这将在另一个视频中探讨。

本节课中，我们一起学习了如何利用少样本提示技术，引导大型语言模型进行行动规划这类复杂推理。我们看到了模型如何从示例中学习模式并生成新示例，以及如何利用一个模型的输出来教导另一个模型。这展示了少样本提示技术的强大适应性和扩展潜力。
