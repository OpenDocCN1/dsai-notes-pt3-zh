# 生成式AI战略领导者：P23：翻转互动模式 🎯

在本节课中，我们将学习一种名为“翻转互动”的提示模式。这种模式的核心是让大型语言模型主动向我们提问，以引导我们解决问题或达成目标。当我们不清楚实现目标所需的具体步骤时，这种模式尤为有用。

上一节我们介绍了如何向模型提问以获取答案。本节中，我们来看看如何“翻转”这种互动关系。

## 模式核心概念

翻转互动模式的核心思想是**角色互换**。通常，我们向模型提问，模型提供答案。而在此模式中，我们要求模型向我们提问，我们则提供答案。

其基本结构可以用以下**代码**来描述：
```
用户指令：请就[某个主题]向我提问，直到你收集到足够的信息来[达成某个目标]。当你拥有足够信息时，请[执行某个操作]。现在，请提出第一个问题。
```

## 模式应用场景

以下是翻转互动模式的一些典型应用场景：

*   **游戏与测验**：让模型出题来测试我们的知识。
*   **目标导向的信息收集**：例如，制定健身计划、旅行 itinerary 或诊断问题。
*   **自动化流程**：在客户服务中，自动询问客户以诊断问题并收集必要信息。
*   **知识探索**：当我们对某个领域了解不深，需要被引导时。

## 实战示例：制定健身计划

让我们通过一个具体例子来理解如何应用此模式。假设我们想获得一个针对特定目标的健身计划。

**初始提示如下：**
> 请就我的健身目标向我提问，直到你收集到足够的信息，能为我推荐一个力量训练方案。当你拥有足够信息时，请向我展示该方案。现在，请提出第一个问题。

这个提示包含了几个关键部分：
1.  **指令**：`请...向我提问`
2.  **主题与目标**：`就我的健身目标...直到...能为我推荐一个力量训练方案`
3.  **最终行动**：`...请向我展示该方案`
4.  **启动指令**：`现在，请提出第一个问题`。这有助于确保互动以“一问一答”的形式开始。

模型收到提示后，会开始提问。例如，它可能会问：“你的具体健身目标是什么？是增肌、增强力量、提高耐力，还是达成某个特定目标？”

我们可以回答：“我希望增强爆发力，同时预防因山地车跳跃运动可能引起的髌腱炎。”

随后，模型会根据我们的回答，提出更深入的问题，例如询问训练频率、可用设备、过往伤病史等。这个过程会持续进行，直到模型判定已收集到足够信息。

最终，模型会综合所有回答，生成一个定制化的力量训练方案，其中包含具体的练习动作、组数、次数和注意事项。

## 模式的优势与原理

翻转互动模式的优势在于，它跳过了我们可能需要反复提供背景信息或收到通用回复的步骤。我们直接授权模型通过提问来获取它所需的一切。

这种模式之所以有效，是因为大型语言模型在其训练数据中见过无数类似的“提问-收集信息-提供方案”的对话模式。当我们设定一个明确目标（如“制定力量训练方案”）时，模型能够调用这些模式，提出相关且有效的问题，以收集制定个性化方案所需的关键信息。

无论是在需要诊断问题、设计方案，还是仅仅想进行知识测验的场景中，当我们希望由模型主导提问过程时，翻转互动模式都是一个极其强大的工具。

本节课中，我们一起学习了翻转互动提示模式。我们了解了其核心概念、应用场景，并通过一个制定健身计划的完整示例，掌握了如何构建有效的提示来启动这种互动。记住，当你需要模型引导对话以达成某个明确目标时，可以考虑使用这种模式。
