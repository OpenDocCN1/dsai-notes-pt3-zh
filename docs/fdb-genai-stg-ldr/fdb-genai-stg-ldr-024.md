# 024：少样本示例 🧠

在本节课中，我们将学习一种名为“少样本示例”或“少样本提示”的强大提示技巧。这种方法的核心思想是，通过向大语言模型展示具体的输入和期望输出的例子，来教会它遵循特定的模式或格式，而不仅仅是描述任务。

## 少样本提示的核心思想

上一节我们介绍了如何通过指令来引导模型。本节中我们来看看一种更直观的“教学”方法。

少样本提示的理念是，我们将为大语言模型提供一系列我们希望它处理的输入示例，以及对应的期望输出。这类似于人类学习：通过观察几个具体的例子来理解并遵循一个模式。我们在提示中实际上是在教大语言模型一个新技巧。

我们通过一系列示例向它展示我们希望它做什么，以及我们希望输出如何格式化。我们不是描述希望它遵循的过程，而是给出我们希望它做的事情的例子，然后期望它能延续我们提供的模式。

## 一个简单的示例：情感分析

让我们来看一个具体的例子。以下是一个简单的少样本提示示例。

这个方法的思路是，我们以“输入”开始。你会注意到，在少样本提示中一个常见的做法是为行添加前缀。你的提示和模式可以有各种前缀，不一定只是“输入”和“输出”，它可以包含几个不同的步骤，我们稍后会看到。

在这里，我们有一个输入：“这部电影有点长”。我们要做的是所谓的“情感分析”。情感分析基本上是尝试分析关于某事物的评论，并试图弄清楚用户的情感倾向：他们是积极的（认为这是好事）、消极的（认为这是坏事）还是中立的。

我们将做一个非常简单的例子，分析一些对不同事物的模拟评论，然后判断它们是积极、消极还是中立。

我们没有直接说“去分析这些用户评论并告诉我它们是积极、中立还是消极”，而是提供了一系列示例。

以下是具体的示例序列：

*   **输入**：电影A不错，但有点长。
    **情感**：中立
    （它有一些优点和缺点，不错，但太长了。）

*   **输入**：我不是很喜欢这本书。它缺少重要细节，最后也没讲明白。
    **情感**：消极

*   **输入**：我喜欢这本书，它对我学习如何改善肠道健康真的很有帮助。
    **情感**：积极

然后，我们给出我们真正希望模型执行任务的内容，并期望它能遵循我们建立的模式。

*   **输入**：我不确定该怎么评价这家新餐厅。服务很慢，但菜品相当不错。

接着，我们通过写上“情感：”来提示它遵循模式，基本上是在告诉它：“告诉我们你对这件事的看法。”

现在，我的前缀（如“输入”、“情感”）有点引导性，它们提供了要做什么的信息。但模型也可以仅从这些模式中学习，即使我们只写“输入”和“输出”也可以。我这里给了你更丰富一点的信息。

## 模型的响应与模式学习

我的目标是让大语言模型去分析我给出的输入，并决定“情感”后面应该接什么。它捕捉到了我们的模式，并输出“中立”。它看到这条评论说“服务很慢，但菜品相当不错”，识别出其中的积极和消极因素，并遵循了我之前给出的模式。我并没有告诉它“中立”是什么意思，但在之前的例子中，积极和消极的平衡最终被标记为“中立”。

关于少样本示例，有几点需要注意：
1.  我们没有告诉它具体要做什么。
2.  我们没有精确告诉它输出应该是什么样子。
我们看到的是，它根据我们之前给出的标签（消极、积极、中立）自动约束了自己，并基于此提供了输出。它并不总是能约束自己，但在许多情况下，这有助于我们从模型那里获得更受约束或有边界的输出。

## 延续模式与预测机制

如果我们给它一个新的输入，比如：
**输入**：我真的很讨厌这种咖啡。它烘烤过度了，尝起来有焦味。

注意，这次我没有在后面写上“情感”这个前缀。让我们看看会发生什么。然后你会注意到，它自动提供了前缀和期望的输出。

思考这一点非常重要：回想我们讨论大语言模型及其工作原理时，它们学习的是预测下一个词。它们在学习模式。

因此，当它看到“输入”和一个陈述句时，它预测下一个词应该是“情感”，因为在我们之前提供的例子中，它看到的就是这样。当我们以“情感”结束时，它知道需要在“情感”后面接着输出内容。

所以，如果我们回到之前的例子并编辑它，只是在这里加一行写上“情感：”，那么它就应该在“情感：”之后接着延续模式。当你在思考少样本示例时，了解这一点很有帮助。

## 总结

本节课中我们一起学习了少样本提示技术。这是一个遵循模式的简单示例，但你可以看到这是一种强大的教学方式，特别是当你拥有描述你想要执行的任务的数据时。这里说的“描述”是指展示了输入和输出，而不一定描述了任务是如何执行的。我们可以看到做了什么，这类情况非常适合使用少样本提示。
