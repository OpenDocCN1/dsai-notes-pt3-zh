# 生成式AI战略领导者：P39：菜单操作模式 🍽️

在本节课中，我们将学习一种名为“菜单操作模式”的提示工程技巧。这种模式允许我们在与大型语言模型的对话中，预先定义一系列可重复使用的指令（即“菜单项”），从而高效地执行特定任务，无需在每次需要时重新编写冗长的提示。

## 概述

当我们使用计算机软件时，程序通常有一个包含一系列可执行操作的菜单，这非常有用。例如，文字处理软件中的“文件”菜单允许你执行“新建文件”或“保存文件”的操作。另一个菜单可能允许你“查找和替换”文本。这种拥有菜单和不同可执行操作的概念是一个非常有用的概念。

有时，在进行提示工程时，尤其是在进行长对话时，在提示中开发等效的“菜单”会很有帮助。其基本思路是定义一组可以在对话中运行的操作，而无需重复这些冗长的提示。或者，我们希望将一些对用户有帮助的操作固化下来，并在对话一开始就将其“烘焙”到提示中。

## 菜单操作模式详解

菜单操作模式是一种允许我们在提示中获得相同类型行为的模式。我们将开发一个包含一系列可运行操作的菜单。这些操作本质上就是一组指令，我们会在对话的特定时刻给予大型语言模型，以执行某项任务。

以下是其工作原理。我们描述将要输入什么内容来触发某个操作。

例如，我可以说：“每当我输入 `write <bullet point> <paragraphs>` 时...”。让我稍后详细解释这一点，所以如果现在看起来不太明白，请不要担心。`<bullet point>` 和 `<paragraphs>` 是占位符。基本上，我是在说：我将输入 `write`，然后是一个代表要点的占位符，再然后是一个代表段落数量的占位符。

“...你将为选定的要点撰写内容。” 所以，基本上我是在说：我会给你一个要点，你需要去为它撰写内容。然后我会告诉你需要写多少段文字。接着你就会去撰写文本。

这样，我就创建了一个操作，其功能是“展开我的大纲内容”。在我之前讨论“大纲扩展模式”时，我提到了能够快速扩展大纲。现在我要说的是，在某个时刻，我将能够告诉你：“不，去把它变成文本，而不仅仅是扩展大纲。” 这样我就创建了一个新操作。

同时，我也会保留原来的操作，即仅仅扩展大纲。所以我说：“每当我输入 `<bullet point>` 时，你将扩展该要点。” 这意味着，如果我仅仅输入像 `3.5.2` 这样的要点编号，它会知道这意味着“在提纲中扩展这个要点”。如果我输入的是 `write` 这个关键词，后面跟着一个要点编号和段落数，它就知道这意味着“需要为这个要点撰写文本”。

这样，我就定义了一个菜单。我现在有两个操作：我可以扩展我的大纲，或者我可以为大纲的某个部分撰写文本。因此，我为我的大纲扩展器开发了更复杂的功能。我把它变成了一个真正的、可以交互的“程序”。

## 操作示例

现在让我展示一个运行第一个操作的例子。我输入：`write 3.5.3 2`。

这表示：为标号为 `3.5.3` 的要点撰写内容。也就是说，针对大纲中 `3.5.3` 这个部分，你需要撰写文本，并且要写两段。

我们看到，它从大纲中提取了要点 `3.5.3`，其内容是“尝试不同的语气和风格变化”。然后，它为该要点写了两段文字。这样，我就创建并定义了一个操作。我在我的提示中定义了一个操作菜单，现在我可以运行那个操作并生成文本。

然后，我们看到它再次提示我们：“接下来你想做什么？” 这实际上不是它写的文本的一部分。它写了两段文字，然后问我接下来想做什么。

接着，我回到之前的操作。我说：`expand 3.5.2`。这就是我之前做的操作，现在它知道这是不同的操作，于是它去扩展了 `3.5.2` 并给出了其扩展后的大纲。

然后我继续输入：`text 3.5.2 1`。这里发生了一件有趣的事：我实际上打了一个错字，但它很聪明地推断出我应该做什么。这是一个很有趣的现象：它试图帮助你，试图把事情做对。它根据模式知道，我可能的意思是 `write 3.5.2`，而我输入的是 `text`。所以这是一个相当智能的菜单操作系统。😊

然后，它实际上提取了那个要点 `3.5.2.3`（抱歉我说错了，是 `3.5.2.3`），并为其撰写了一段文字。

这样，我基本上创建了一个复杂的“程序”：如果我愿意，我可以扩展我的大纲；或者，我可以让它为大纲的某个部分撰写文本。而且我不必重复自己，我可以使用这种简单的小格式。我已经解释了这种格式是什么，现在我可以随时重新运行这些操作。

## 模式的优势与应用场景

这种模式对我有用的一个方面是：如果你反复使用提示执行相同的任务，使用菜单操作模式来定义一组操作会很有帮助。这就像为你经常使用的提示创建一个“菜单”。然后，每当你想利用这些内容和这组操作快速迭代时，你只需引入那个菜单操作提示，然后就可以在得到的输出上反复使用那些操作来操纵它或做某些事情。你基本上在对话中为自己构建了一个专属的“程序”。

同时，有时一个组织可能有许多人做同样的工作，他们可以彼此分享这些操作，以帮助自动化不同的任务。因此，这对于帮助人们更有效地工作以及彼此分享有用的提示可能非常有用。

另一个好处是，你不必太担心是否准确地记住了措辞。一旦你写好了一个操作，并让它在菜单中正常工作，你就可以反复重用它，而不用担心在操作时措辞不够准确。

这引出了菜单操作模式最后一个非常有用的方面：在一个组织内部，你可以分享一套每个人都应该使用的通用菜单操作。你可以将那些提示的最佳措辞、那些操作应该做什么，甚至可能将最佳实践固化到其中，然后在整个组织内分享。这允许知识的共享、不同提示的重用，以及这些提示的轻松应用。

你还可以想象将这些操作“烘焙”到类似客户服务门户的根提示中。在那里，你可能希望给人们一些可以运行的操作来查找他们的账户信息。他们可以用自然语言来做这件事，但你也可以描述“这里有一些你可以运行的操作”，并允许他们从中获得更好的服务体验。

本节课中，我们一起学习了菜单操作模式。😊 菜单操作模式是一个非常强大的模式，它允许我们轻松地重用其他提示和操作，与他人分享它们，并开发它们的知识库，从而使我们成为更高效的提示工程师。
