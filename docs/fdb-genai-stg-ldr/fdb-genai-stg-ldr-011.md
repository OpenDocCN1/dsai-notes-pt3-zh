# 011：什么是提示词 🧠

在本节课中，我们将深入探讨“提示词”这一核心概念。提示词是与大型语言模型交互的基础，理解其多维度的含义对于有效进行提示工程至关重要。

---

## 什么是提示词？

我们经常谈论提示工程，以及如何与大型语言模型互动。现在让我们深入探讨“提示词”这个词，因为它不仅仅是向大型语言模型提出的一个问题。为了理解这个概念，我们将通过几个示例与ChatGPT进行互动，来探索提示词的维度和深度。

首先，我向ChatGPT提问：“提示词这个词是什么意思？”

它给出了一些非常有用的信息，可以帮助我们理解提示词：

1.  **作为动词**：指“促使或鼓励某人做某事，激励他们采取行动”。例如：“老师关于即将到来的考试的提醒，促使学生们开始学习。” 提示词的一部分作用，就是**向大型语言模型发出行动号召**，让它开始为我们生成输出，即开始生成构成我们输出基础的词语。这些词语可以呈现为多种格式，如软件代码、诗歌、结构化数据等。关键在于，提示词是我们让大型语言模型开始为我们**提供输出**的方式。

2.  **作为形容词**：指“及时、准时完成”。这对于思考大型语言模型很重要，因为我们正在“即时”地提示它们。但这也是一个有益的讨论点，因为提示词不一定必须是即时发生的。**提示词可以与时间相关联**。当我们向ChatGPT这类大型语言模型提供提示时，提示词可以影响我接下来给它的陈述，也可以影响未来的某个陈述。这是因为这些大型语言模型具备对话能力。提示词本身可以是对话，我们稍后会讨论。目前可以这样理解：提示词不一定必须是即时的，它可以是，但并非必须。

3.  **作为名词（含义一）**：指“帮助某人记住他们应该做什么或说什么的线索或提醒”。这很重要，因为我们可以使用提示词来**提醒大型语言模型记住某些信息或它需要做的事情**。我们可能要求它现在做某事，也可能要求它在未来做某事，这时它需要记住一些事情，所以我们需要给它一个关于它试图做什么的提醒。我们可能需要回溯并提供对话历史或其他有助于它记住目标的信息。

4.  **作为名词（含义二）**：指“出现在计算机或电子设备上，要求用户输入的消息或屏幕”。这很有帮助，因为我们可以提示大型语言模型为我们生成内容。但如果我们结构设置得当，大型语言模型实际上也可以**向用户索取信息**。因此，提示词既可以作为行动号召（激励大型语言模型行动），也可以作为一种输入（向我们索取输入）。大型语言模型的上一个输出可能是向人类提出的一个问题，然后我们向其提供信息作为回应。

因此，提示词具有许多不同的维度。实际上，查看ChatGPT给出的定义，就能体会到提示词能力的这种细微差别。

## 提示词的时间维度示例

为了帮助理解这个概念的复杂性和多维性，我将展示一个关于提示词时间维度的例子。

我输入：“从现在开始，每当我提问时，请建议一个更好的问题版本，并询问我是否想使用它。”

在这里，我通过说“从现在开始”，**将时间附加到了我的提示词上**，所以它不仅仅是即时的。ChatGPT回应说：“当然可以。不过，我会先尽力回答您的原始问题……”它试图重新表述这个原始问题（但这并非我本意）。然后我接着问：“天空是什么颜色的？”

请注意，我们之前的提示词在这里生效了。我最初的提示词是“从现在开始，每当我提问时……”，它立即根据那个提示词给出了回应。但现在我问了一个后续问题，而之前的提示词将影响这个问题。

此刻，我问了一个即时问题“天空是什么颜色的？”，它回应道：“您的问题一个更好的版本可能是：‘白天天空呈现蓝色的科学解释是什么？’ 您希望我使用这个版本吗？” 然后我说“是的”。

现在，我们看到了之前讨论过的提示词的多个维度：
*   我们创建了一个**非即时**的提示词（“从现在开始”），它将影响未来，持续影响大型语言模型的输出。
*   我们有一个**即时**提示词（“天空是什么颜色的？”），它激励大型语言模型立即行动。
*   我们看到了大型语言模型**提示并获取我们输入**的概念（询问我们是否使用更好的版本）。
*   然后我们看到了所有这一切的输出结果。

还需要注意的一点是，我们也谈到了提示词具有**记忆**的概念。我说“从现在开始，每当我提问时”，这是大型语言模型必须在未来的交互中记住的事情。我们稍后会探讨它是如何做到这一点的。当我说“天空是什么颜色的？”时，它记住了我之前说的“每当我提问时，建议一个更好的问题版本”，于是它在这里用更好的问题版本来回应。

如果我再次这样做，会发现它仍然记得我最初的指令。例如，我问：“世界上有多少个国家？” 它会说：“您的问题一个更好的版本可能是：‘目前世界上估计有多少个国家？国家是如何定义的？’ 您希望我使用这个版本吗？” 我说“是的”，然后它给出了详细的回答。

## 提示词作为信息提供者

提示词具有记忆关联性，这也向我们展示了大型语言模型的一些**局限性**。例如，ChatGPT的知识截止于2021年9月。

因此，我们可能需要为大型语言模型**提醒它在训练完成后发生的事情**。我们可以使用提示词向ChatGPT这类大型语言模型提供其训练后发生的信息。我们也可以用它来提供大型语言模型在训练时无法访问的信息，比如我们自己的私人信息或其他内容。

当然，需要注意的是，在使用ChatGPT或许多其他工具时，你实际上是在将信息发送到它们的服务器。在这样做之前，你需要确保你愿意发送这些信息。但如果你在本地机器上使用大型语言模型，或者你愿意发送信息，你就可以提供它无法访问的信息以供其推理。

因此，提示词也可以作为**向这些语言模型提供新信息和更新信息**的一种方式。

例如，如果我们问：“范德堡大学2020年的录取率是多少？” 它应该能访问到这些信息并给出答案（例如9.6%）。但如果我们问：“范德堡大学2022年的录取率是多少？” 它会说抱歉，因为它没有2021年9月之后的信息。

这时，如果我们通过提示词提供这些信息——例如，我复制粘贴了范德堡大学几天前刚刚发布和公布的招生数据——那么它就可以基于我提供的信息进行推理并回答：“根据您提供的信息，范德堡大学2026届常规申请者的录取率似乎是4.7%。”

正如这个例子所示，提示词也可以作为向大型语言模型提供新信息和更新信息的一种方式。

## 总结

本节课中，我们一起学习了“提示词”这一核心概念。我们了解到，提示词远不止是一个简单的问题，它是一个多维度的工具：
*   它可以作为**动词**，激励模型行动并生成输出。
*   它可以具有**时间属性**，既可以是即时的，也可以影响未来的交互。
*   它可以作为**名词**，是提醒模型的线索，或是模型向用户索取输入的请求。
*   它还是**向模型提供其训练数据之外的新信息**的重要途径。

理解提示词的这些不同维度，是进行有效提示工程和与大型语言模型成功交互的基础。在接下来的课程中，我们将继续探索如何构建更复杂、更强大的提示。
