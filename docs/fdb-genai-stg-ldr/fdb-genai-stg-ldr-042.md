# 生成式AI战略领导者：P42：语义过滤模式 🧹

在本节课中，我们将要学习大语言模型（LLM）在处理和理解文本模式方面的核心优势，并重点介绍一种名为“语义过滤”的强大应用模式。我们将通过具体示例，了解如何利用LLM根据语义规则来过滤或移除文本中的特定信息。

大语言模型非常擅长处理文本和理解语言模式。很多时候，文本处理工作非常困难，因为过去我们需要人工仔细审阅和分析才能做好。现在，我们可以使用大语言模型来完成这些任务。处理和操控文本是大语言模型的真正优势之一。

接下来要介绍的模式叫做“语义过滤”。这本质上是一种过滤器，它可以接收文本，并根据我们指定的含义或特定性质，移除其中的信息，或仅保留符合条件的信息。这种模式在各种不同场景下都非常有用。

本节中，我们将通过从文本中过滤并移除某些我们想要清除的内容来展示这一模式。这些内容可能是某种机密信息、非公开内容、冗余信息，或是任何你需要移除的东西。这是一种操控文本的实用模式。

以下是语义过滤模式的一个简单示例。

```text
过滤以下信息，移除所有日期，并尽可能少地重写文本，以修复因移除日期而导致的语句不通顺问题。
```

我粘贴了一段来自维基百科的关于范德堡大学的信息，其中包含许多日期。我创建了一个复杂的过滤器，它将接收信息，移除所有日期，并轻微重写文本，以防移除日期后导致句子生硬或明显缺失信息。

通过使用“过滤此信息”这样的指令，我们清晰地表明了希望保留但移除某些内容的意图。我们不是在创造新内容，而是在对现有信息进行过滤或移除。

因此，语义过滤模式的基本方法是：我们指示模型过滤某些内容，并给出基于语义的规则，即我们希望移除的信息的含义或目的。

然后，模型会遍历并重写所有文本。可以看到，它做得相当不错，移除了所有明确的日期。不过，我注意到可能需要重新思考如何表达“日期”的指令，因为它将“成立于19世纪”也视为日期。这取决于我对“日期”的定义。模型可能采取了字面解释，即具体的年月日。例如，原文是“成立于1873年”，它移除了日期“1873”，并通过重写将其替换为“成立于19世纪”。这实际上是在移除信息，但由于我要求重写，它进行了一些转换。这展示了模型理解文本、理解何为日期、移除日期，并在本例中通过转换进行重写的能力。

上一节我们看了一个基础示例，本节中我们来看看一个更有趣的例子，它能更好地体现语义理解和含义分析的应用。

```text
过滤以下信息，移除任何可能帮助他人推断出该患者患有糖尿病的信息。
首先，解释你将移除哪些信息，以及这些信息如何可能帮助他人推断患者患有糖尿病，然后提供过滤后的信息。
```

下面是一份虚构的医疗记录，描述了患者简·杜的情况，包含一系列症状、现病史、既往病史、用药史、过敏史等多种信息。我将让ChatGPT对这份信息进行语义过滤。

现在，让我们看看它将移除哪些内容。它指出：
*   **主诉**：“口渴加剧和疲劳”应被移除，因为口渴加剧（烦渴）是糖尿病的常见症状。
*   **现病史**：提及“口渴加剧”和“未检查血糖水平”的部分应被移除，因为它们与糖尿病症状和管理相关。
*   **既往病史**：包含“2型糖尿病”的部分应被移除，因为它直接表明患者患有糖尿病。
*   **用药**：“二甲双胍1000毫克，每日两次”应被移除，因为二甲双胍是常用于管理糖尿病的药物。

这个过程基于语义规则：我希望过滤掉任何可能泄露该患者患有糖尿病的信息。模型必须在一定程度上理解文本的含义，或者至少基于其训练数据，识别出这些是与糖尿病相关的常见讨论内容。

然后，它遍历并重写了医疗记录。注意，它将主诉重写为“患者因过去两周疲劳至诊所就诊”，现病史、既往病史和用药部分也相应地被重写。这样，我们就得到了经过过滤的版本。

我们可以利用大语言模型，通过语义过滤模式来开发强大的语义过滤器。

那么，它是完美的吗？不是。正如我们所看到的，它可能存在一些问题。正如我们之前讨论过的，模型的输出并非总是完全可重复的。但它可以作为一个起点，辅助人工进行二次核查，或帮助防止信息意外泄露。它只是系统中的一个额外检查环节。

这是一种成本相对较低的检查方式，用于尝试移除额外信息。它应该是唯一的检查吗？不。如果我们要出于隐私或其他原因过滤信息，特别是那些我们不希望泄露的信息，我们应该始终设置其他检查措施，因为这不会是一个完美的过滤器，它会有一定的随机性，并不总是完全符合我们的预期。

但是，作为另一个流程的一部分，作为一个辅助组件，这是一种非常强大的技术，我们可以将其与其他检查、其他类型的移除方法并行或结合使用。

**总结**
本节课中，我们一起学习了语义过滤模式。我们了解到，大语言模型可以通过理解文本的语义，根据我们设定的规则（如移除日期、过滤敏感医疗信息）来有效地过滤和转换文本内容。虽然这种模式并非完美无缺，需要结合其他检查手段，但它作为一种高效、低成本的辅助工具，在信息处理、隐私保护等领域具有重要的应用价值。
