# 生成式AI战略领导者：P37：组合模式 🧩

在本节课中，我们将要学习如何将不同的提示模式组合起来，以构建更复杂、更强大的提示。这是构建高级提示工程解决方案的核心概念。

你可能已经注意到，我开始将不同的模式组合在一起使用。当你希望构建真正复杂的提示时，最重要的概念之一就是：你需要思考如何将多个模式相互结合，以解决你正在处理的问题。因此，不要只考虑“用哪个模式能解决这个问题”，而应该思考“哪些模式能解决问题的某些方面，以及如何将这些模式组合起来”。

## 组合模式的初步示例

上一节我们介绍了“请求输入”和“提供替代方案”等模式，本节中我们来看看它们如何结合。

我们已经在“请求输入”和“提供替代方案”的例子中看到了一个初步的组合示例。“请求输入”是一个可以与许多其他模式结合使用的模式。在这个案例中，我们将其与“提供替代方案”结合使用。于是我们得到了“替代方案”和“请求输入”，它们被组合在一起，构建了一个解决整体问题的提示。

在本课程剩余部分，我们将看到，构建真正复杂提示的方法就是思考如何以有趣的方式组合多个模式。

## 回顾已学的模式

现在，回想一下我在课程中介绍的一些模式及其示例。既然你了解了更多模式，你可能会发现，我在不同的示例中其实一直在组合模式。

例如，在“游戏玩法”的示例中，我可能使用了“请求输入”模式。同时，在“游戏玩法”中，我可能还使用了“角色扮演”模式。由此可见，将不同元素组合起来有助于我们解决整体问题。

因此，当你尝试处理某个需要设计和开发的新复杂提示时，你应该思考：这个问题的基本组成部分是什么？我是否了解现有的模式，可以用来解决所有部分？如果无法解决所有部分，我能否使用模式并将其应用到尽可能多的不同部分，从而使你必须从头开始发明新方法的那部分未知问题尽可能小？

我们的目标是，尽可能多地使用已有模式作为解决各部分的路线图，这样需要从零开始创造的部分就最小化了。这就是我们现在要做的事情。

## 组合模式的本质

这听起来可能比实际情况更复杂，但归根结底，我们所做的仍然是在构建语言。我们仍然在使用自然语言写作，仍然在写句子，仍然在进行沟通。我们只是有意识地思考语言中的模式，并思考为了解决问题，应该使用哪些语句以及如何组织这些语句。

从某种意义上说，组合模式实际上是在进行一种更强大的“编程”。我们开始将已知的不同“程序”或“指令”组合起来，以更复杂、更精密的方式构建提示，使其拥有更强大的功能和更丰富的内涵。

请记住，不要觉得这是你做不到的事情。每个人都能做到。归根结底，你只是在用语言描述你希望完成的事情。你仍然在用语言描述你想要实现的目标。而所有这些模式所做的，就是帮助我们思考，如果我们要使用某个模式，指令中应该包含什么内容。

## 如何组合模式

以下是组合模式的基本方法：

*   **模式提供指令集**：每个模式都为我们提供了一组需要包含的指令或语句，以及某种组织形式。
*   **简单的组合方式**：很多时候，组合模式就像把每个模式的语句都拿出来，确保它们都出现在提示中一样简单。有时就是这么简单。
*   **注意语句位置**：有时会更微妙，我们可能需要确保某些语句出现在特定的位置。例如，对于“请求输入”模式，我们可能总是希望它出现在提示的末尾，否则其效果会大打折扣。

因此，虽然组合模式有时可能需要你思考语句的放置位置而略显棘手，但大多数时候，它就像把语句放在一起一样简单。

随着我们继续学习本课程的其余部分，我鼓励你注意我何时使用多个模式组合来解决问题，并思考当你尝试用提示工程处理新任务时，如何结合使用多个模式来解决问题。

本节课中我们一起学习了提示工程的组合模式。我们了解到，构建复杂提示的关键在于有意识地将多个基础模式结合起来，像搭积木一样解决整体问题。这要求我们分析问题的组成部分，并运用已知的模式作为构建模块。组合的核心通常是将不同模式的指令语句汇集在一起，有时需要注意特定语句的位置以优化效果。掌握这一思维，你将能设计出更强大、更精准的提示。
