# 生成式AI战略领导者：P40：事实核查清单模式 📋

在本节课中，我们将学习如何应对大型语言模型可能生成不准确信息的问题。我们将重点介绍“事实核查清单模式”，这是一种通过提示词引导模型自我剖析输出内容，从而帮助我们系统化进行事实核查的有效方法。

---

我们反复在新闻中听到，这些大型语言模型会犯各种错误，可能会对你撒谎。它们首先从不承认错误，并且能够一直告诉你它们是正确的，同时产生奇怪的输出。

当然，这从根本上误解了这种工具的用途。它们本质上不一定是用来回答问题的工具。有时它们可以回答问题并且非常准确，但有时它们产生的内容看起来像答案，但实际上并不准确。

因此，只要我们理解它们真正是用来生成文本的，并且有时它们生成的文本可以正确回答我们的问题，有时则会出错，我们就能有效地使用这些工具。现在，我们可以做的一件事是使用提示词来帮助我们识别：工具在其输出中植入了哪些事实，以及其中哪些事实真正重要，然后我们可以跟进并核查它们。

当我们处理这些工具的输出时，有时会发生一种情况：因为输出看起来如此逼真、如此人性化、如此令人信服，我们便假设它是真实的。当它产生大量文本时，我们可能很难发现文本中蕴含的所有不同假设和事实，而这些正是我们需要跟进和核查的。对于从这些模型中获得的任何信息，你都需要承担责任，确保你已经彻底核查并真正相信它。

那么，我们该如何支持这项确保输出正确且符合事实的工作呢？我们可以使用“事实核查清单模式”来帮助我们弄清楚输出中实际包含了哪些需要跟进核查的事实。我将给你一个例子。我使用了我们的大纲扩展工具。如果你还记得，我们使用了包括“菜单操作模式”在内的几种不同模式，我们使用了“大纲扩展模式”。

我们有几个不同的功能。其中一件事是我们可以去扩展大纲。我们还增加了为大纲中任何要点生成文本的能力，并且我们可以为多个项目生成文本。我们有一个完整的菜单系统来实现这一点。现在，我们希望实现的一件事是：当我们为大纲的某部分生成文本时，我希望知道在那个时间点我需要跟进和核查什么，以确保我不会呈现不准确的信息。

如果我们看这个例子，实现这一点的方法就是使用“事实核查清单模式”。我们这样设置提示：**“每当你输出文本时，生成一组包含在输出中的事实。这组事实应插入在输出的末尾（你可以放在任何位置，我这里只是放在末尾）。这组事实应该是基础性事实，如果其中任何一个是错误的，都可能损害输出的真实性。”** 这样，我为大型语言模型建立了一套新的指令，要求它在每次生成文本时，都给出文本所依赖的对应事实集合，这样我就可以跟进并核查它们。

它表示理解了。现在，我将使用我们编写的大纲扩展程序，并告诉它为第3.5.2.2节写一段文字。这一节是关于“选择合适风格的考虑因素”。它为我生成了一整段文字。

然后，它在这里生成了一组基础事实。这些是包含在段落内的事实。例如，事实包括：“写作风格可以从技术性到创造性再到指导性”，以及“指导性内容可能采用清晰、逐步的风格”等。

我选择让它撰写的这个段落包含许多不同的事实。它们可能是正确的，也可能不是。但我不必过于担心需要自己去提取和审视文本，因为我现在有了一个需要跟进的事项清单。至少，我需要查看这个列表并跟进这些项目，或者只是根据我自己的知识进行目视检查。

这算是最低标准。现在我有了一个最低门槛：至少这些事情我需要去跟进。这就像是在向我标记：这里有一些你需要去核查的东西。

我还可以做的另一件事是，将这个列表与上面的段落进行比较。任何使用这些工具的人都可以比较：下面是事实列表，上面是实际文本。事实列表完整吗？上面的文本中是否有陈述没有出现在下面的列表中？如果有，那些可能也是我想跟进核查的事情。

因此，通过检查和比较这两个列表，我们可以看出它是否真正、完整地提取了所有重要的事实。这个过程本身就会提示我们，并让我们思考：这到底在说什么？其中的基础事实是什么？仅仅是进行将事实与生成的文本进行比较这个动作，就能帮助我们进入思考其输出正确性的模式。

接下来我可以做的是，我有一个最低门槛：至少我需要去核查生成的事实列表，并跟进确保它们是正确的。如果其中任何一个是错误的，那么上面的文本很可能就有错误。然后，如果我通过比较发现上面的文本中有某些内容也没有出现在事实列表中，我可以将其添加到我的列表中并进行核查。所以，这是一个可以帮助我们的工具。

它帮助我们进入对输出进行事实核查的模式。输出可能是正确的，但在我们真正完全跟进之前，我们仍然无法确定。这为我们提供了一些工具来帮助我们：第一，知道至少有哪些事情需要跟进；第二，为我们提供了一个工具，可以将其与生成的内容进行比较，看看我需要跟进的最低事项清单是否足够，或者文本中是否还有其他我应该思考或跟进的事情。

它并不能保证我们会得出正确的答案。即使我们跟进了这些事实，我们可能仍然认为它是准确的，而实际上并非如此，因为可能还存在一些隐藏的假设。但这远比我们只是阅读一堆没有任何支持或刺激来思考事实核查过程的文本要好得多。

因此，“事实核查清单模式”有助于我们进入检查输出、检查其真实性的模式，并为我们提供一种格式，使我们更容易提取和比较信息，以及利用其他外部资源来核对事实集合的真实性。

**本节课总结**

在本节课中，我们一起学习了“事实核查清单模式”。我们认识到大型语言模型的输出可能包含不准确信息，因此主动核查至关重要。该模式通过特定的提示词指令，要求模型在生成文本的同时，列出其输出所依赖的核心事实清单。这为我们提供了系统化核查的起点：我们可以将此清单作为最低核查标准，并将其与原始输出文本进行比较，以发现可能遗漏的需要核查的陈述。虽然这不能保证100%的准确性，但它极大地优化了我们的工作流程，将我们从被动阅读者转变为主动的、有方法的事实核查者，从而更负责任、更有效地使用生成式AI工具。
