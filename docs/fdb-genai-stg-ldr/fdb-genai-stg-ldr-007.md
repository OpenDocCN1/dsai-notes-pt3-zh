# 生成式AI战略领导者：P7：课程概述 🚀

在本课程中，我们将学习提示工程的核心概念与实践方法。提示工程是一门关于如何设计有效指令，以引导大型语言模型（如ChatGPT）生成高质量输出的学科。通过学习，你将掌握与这些强大AI工具高效互动的能力。

## 课程介绍

我是朱尔斯·怀特，范德堡大学计算机科学副教授兼工程学院战略学习项目副院长。我将引导你探索这个引人入胜且至关重要的主题：我们应如何与ChatGPT这类大型语言模型进行交互。

本课程旨在重塑你对这些工具的认知。它们不仅是新闻中常被讨论的考试作弊或论文代写工具，从我的视角看，它们更是一种能**释放人类创造力**的新媒介。这些工具能帮助你实现以往难以完成的事情，快速地将想法转化为具体形式，让你比以前**更快、更好**地完成任务。

我的背景始于视觉艺术，曾学习东亚研究，最终成为计算机科学家。但我始终对创造力充满热情，探索如何使用不同媒介（无论是绘画、陶瓷还是代码）来做有趣的事情。我将大型语言模型视为一种新的基础媒介。我可以用它编程，也可以用它创作艺术、改进写作、进行思维实验。像ChatGPT这样的大型语言模型拥有众多有趣用途，但目前的讨论并未充分展现这一点。

因此，本课程的核心是教你如何利用这些模型的各项能力。而为了发挥这些能力、进行真正的创造性工作，你必须理解如何编写**提示词**。这就是本课程的内容：如何与ChatGPT或其他大型语言模型交互。提示词即你输入给模型以获取某种输出的文本。

从根本上说，这些是非常令人兴奋的工具。我认为它们扩展了我们作为人类表达自我、探索新想法和进行创作的能力，让我们能比以往任何时候都更快地实现想法。

让我们开始吧。

## 课程先修要求

基于以上介绍，我的第一个问题是：我需要确保自己不必是程序员也能从本课程中受益吗？我需要懂编程才能学习这门课吗？

**不需要。** 你不需要任何编程经验即可学习本课程。本课程的重点是创建有效的提示词，并使用大型语言模型来实现你期望的输出。虽然理解编程可能有所帮助，但对于掌握本课程将涵盖的概念和技术而言，并非必需。

那么，学习本课程前了解哪些其他事情会对我有帮助呢？

虽然编程经验不是必需的，但如果你对基本计算机概念（如**文件管理、打开和保存文件、使用命令行界面**）有一些了解会很有帮助。这里的命令行界面，可以类比为ChatGPT这样的交互界面。此外，拥有良好的写作技能和创造性思维能力，对于为大型语言模型生成有效的提示词非常重要。最后，**乐于探索新的、不断发展的技术和方法**，将是你能从本课程中获得最大收获的关键。

因此，正如ChatGPT恰当地指出的那样，你真正需要了解的东西并不多。你需要一些基本的计算机概念理解，需要能够打开ChatGPT并与之交互。显然，如果你无法使用这类工具，学习将会很困难。但既然你在这里，很可能已具备所需的计算机技能。

我想谈谈第二点。我们通常认为这些模型源于计算机科学，但实际上，拥有写作经验、能够清晰有效地思考写作，对使用它们非常有帮助。我的父亲曾是创意写作教授，这让我深受启发。当我使用这些工具时，从他那里学到的关于如何设计提示词的知识对我帮助很大。

最后，我想强调最后一点：**创造性和探索的开放性**对于使用这些工具而言确实非常重要。输入提示词的人类用户的创造力——决定提示词包含什么内容、如何组织、提出什么问题以及给出什么指令——对于有效使用这些工具至关重要。

我们听过很多关于这些工具的讨论，比如它们是抄袭工具，或是用于做某些坏事的工具。但事实是，如果你想真正有效地使用它们，你必须具备技能。你必须是一个创造性的思考者，一个创造性的问题解决者。你越有创造力，输出结果就越好。你还需要有开放的心态去探索。必须记住，这些工具仍处于早期阶段，我们尚未制定出最佳实践，也未探索出在所有不同领域（从医疗保健到客户服务，再到创意写作等）如何使用这些工具、如何编写提示词的最佳方法。因此，乐于去探索和尝试不同事物非常重要。

事实上，当你使用这些工具进行“编程”或工作时（不要因为我说“编程”而感到害怕，因为你会看到，任何人都可以通过编写普通的人类语言来使用这些工具进行编程），你经常需要尝试不同的事情。你需要尝试某种方法，并乐于尝试其不同的变体，观察会发生什么，进行一些小实验。在现实生活中，我们通常需要付出大量努力来撰写某些内容、开发软件或完成其他任务，以至于我们没有足够的机会去进行应有的探索，没有足够的时间去思考设计和大局，去思考我们要解决的问题。因此，在使用这些工具时保持探索的开放性是一件好事。

## 核心学习概念

那么，本课程中我们将学习哪些有助于解决问题的关键概念呢？

在本课程中，我们将学习以下几个核心概念：
*   **理解提示词是什么**，以及如何使用它们来编程大型语言模型以生成高质量输出。
*   **学习如何创建有效的提示词**，包括利用训练数据中的模式、使输入具体化，以及使用诸如角色扮演模式、问题精炼和认知验证器等模式。
*   **理解如何优化提示词**，并使用诸如重写、组合、拆分和扩展等技术来实现期望的输出。
*   **学习如何将大型语言模型用于各种任务**，如知识探索、原型设计、内容生产、评估等。
*   **理解如何使用少量示例**来教导大型语言模型执行新任务，以及如何正确格式化这些示例以获得期望的输出。

通过学习和应用这些概念，我们可以有效地利用大型语言模型来解决问题，并在广泛的应用中生成高质量的输出。

## 总结与展望

我希望，随着我们深入学习本课程，你能受到启发，将学到的想法付诸实践，进入ChatGPT或任何你可用的工具中进行尝试，探索你热衷的领域，并找到释放自身创造力的方法。你会发现，你可以为自己腾出更多时间进行高层面的思考和解决问题，而不是陷入如何将想法具体化的细节之中。

因此，贯穿本课程的一个主题将是：尝试通过这个工具将你的想法转化为形式，将其用作加速你的想法变为现实的工具。

我期待与你一起探索提示工程这个引人入胜的概念和主题。
