# 生成式AI战略领导者：07：配方模式 🧩

在本节课中，我们将要学习“配方模式”。这是一种利用大语言模型来帮助我们填补知识或流程中空白的方法。当我们面对一个问题，并且已经知道解决方案中的部分步骤或要素，但不清楚完整细节时，就可以使用这个模式。模型将根据我们提供的“部分配方”，自动补全缺失的步骤。

## 模式概述

上一节我们介绍了如何创建元语言。本节中我们来看看如何将已知与未知结合，让模型帮助我们完成规划。

有时，我们在使用大语言模型解决问题时，已经知道解决方案中的部分内容。我们有一个目标，并且了解达成这个目标需要涉及的一些步骤或要素，但我们不知道完整的解决方案。我们需要大语言模型帮助我们填补空白，将缺失的步骤组合起来，最终完成这个“配方”。模型会根据我们已有的“食材”或已知信息，填充所有空缺，给出一套详细的步骤。

因此，配方模式就是用于实现这一目的的模式。我们给大语言模型一个我们试图达成的目标，并给出我们已知的、在创建整体解决方案（即“配方”或目标）过程中必须涉及的部分步骤集合。我们将提供所需内容的一部分，并要求模型补全其余部分。这实际上是一种让大语言模型帮助我们在某个流程或一系列必要步骤的知识中填补空白的方法。

配方模式非常有用。我还要向大家展示，我们用来描述空白、谈论已知是流程或步骤一部分但不知其确切细节的直观简写方式，实际上是大语言模型（如ChatGPT）能够理解的。

## 模式应用示例

让我们看一个例子。我们将为我们的旅行规划应用添加一个功能。我们会告诉模型我的起点和终点，模型需要为我提供一个完整的停留点列表，包括起点和终点之间的地点。

请注意，我们在这里所做的本质上是提供了一个不完整的“配方”。我们说：“这是我的起点，这是我的终点，但我需要知道中间该有什么。”模型回顾并采用了我们之前的一个例子（实际上是它自己创建了一个例子），即从纳什维尔到亚特兰大的旅行。它注意到途中会经过查塔努加，这确实是开车从纳什维尔到亚特兰大的必经之路。它建议了一些可以做的事情，比如去查塔努加的田纳西水族馆或瞭望山。

有趣的地方在于，如果你还记得旅行规划应用，我曾教它使用我自创的语言来描述旅行（即使用了元语言创建模式）。现在，我将结合元语言创建模式和配方模式来做一些有趣的事情。

## 结合元语言与配方模式

以下是具体操作。我将输入：`Nashville, 0`（表示从纳什维尔出发，停留0天）。然后，我将只输入点（即省略号），基本上是 `... -> ... -> Fairhope, Alabama2`。这表示我从纳什维尔前往阿拉巴马州的费尔霍普。

我向模型传达的信号是：我希望你补全它，告诉我在中间应该在哪里停留。我通过 `...` 表示我在这里有空白，需要停留两次，但我不知道具体地点。请你填充这个配方，让我能从纳什维尔到费尔霍普，并在中间有两次停留。

模型理解了这一点。显然，`...` 是我们表达未知事物的自然方式，模型理解这一点并填充了配方。它说：我们将从田纳西州纳什维尔开始，根据您的要求，停留0天。（我个人强烈建议在纳什维尔多待些时间，我住在这里，所以我所有的行程都从不在这里停留开始，因为我总在这里。当然，不是总是，但大部分时间是。）

然后，它为我们填充了两次停留：阿拉巴马州的伯明翰和蒙哥马利。如果你走最直接的路线，这两个城市都在纳什维尔和费尔霍普之间。终点是阿拉巴马州费尔霍普。

你会发现，它基本上理解了我们设定的约束。我们使用了自定义语言：`Nashville, 0 ->` 定义了起点，然后说 `...`，表示这是一个我不知道的空白点，是我的模板或配方中的空缺，所以你需要在这个配方中填充我们应该在这里停留的地点，然后是 `-> ...`，我说这是另一个空白点，我不知道配方中这里应该放什么，请填充它，最后是 `-> Fairhope, Alabama`。

我们在这里使用配方模式，让ChatGPT或另一个大语言模型来完成我们的请求。

## 探索模糊指示

如果我们再次尝试，输入：`LA, 1 -> ........ -> New York, 3`，让我们看看它会如何解释，因为即使对我来说，这么多点意味着什么也不明确。

它现在开始为我们规划行程：好的，起点是洛杉矶（1天），然后你会到达拉斯维加斯、大峡谷、圣达菲……我好奇它中间会有多少个停留点。

请注意，当我在这里使用了四个占位符（`........`）时，我得到的中间停留点超过了四个。因为我表达得非常不确定。我没有使用 `... -> ... ->` 这样明确的结构，而是用了一大串点，这更加模糊不清，而这正是我想做的有趣实验。我不确定它是否能理解，但我基本上是在表达：我要从洛杉矶去纽约，中间会有很多停留，我不知道应该是哪些，请为我规划行程。这是我在洛杉矶停留的时间，这是我在纽约停留的时间。

每个人都可以争论我在每个地方停留的时间是否合理，这些都是很棒的地方。模型解释了我配方中的缺失部分。它可能也知道我需要相当多的停留点，并且这将是一次从洛杉矶到纽约的悠闲自驾游。于是，它填充了一整串我可能沿途停留的不同地点，以便在从洛杉矶到纽约的长途公路旅行度假中拥有有趣的体验。

## 模式核心与总结

本节课中我们一起学习了配方模式的工作原理。你向大语言模型提供你试图达成的目标、你知道必须融入解决方案的片段或必须存在的步骤及其大致位置，然后要求它填充其余部分。你可以使用省略号或其他类型的标记来指示你不知道内容、希望模型填充的位置，模型将使用配方模式为你补全整个配方。

**核心操作可以总结为以下公式：**
```
已知部分（目标 + 部分步骤/要素） + 明确标记的空白（如“...”） -> 模型补全 -> 完整配方
```

**在代码提示中，这种交互类似于：**
```python
# 用户提供不完整的“配方”
user_input = “从A地到B地，中间在...和...停留，请补全行程。”
# 模型理解“...”为需要填充的空白，并输出完整计划
model_completion = complete_recipe(user_input)
```

总之，配方模式是一个强大的工具，它能将人类的模糊意图与模型的结构化生成能力结合起来，高效地填补规划和知识中的缺口。
