# 031：游戏玩法模式 🎮

在本节课中，我们将学习一种名为“游戏玩法模式”的提示模式。这种模式的核心思想是，让大型语言模型（如ChatGPT）扮演游戏大师的角色，与我们进行互动游戏，从而帮助我们以有趣的方式学习和掌握新知识或技能。

## 概述

上一节我们介绍了多种提示模式，本节中我们来看看如何将学习过程游戏化。游戏玩法模式要求模型设定游戏规则、生成内容并引导游戏进程。我们将重点探讨如何利用此模式来提升我们的提示工程技能。

## 模式核心：与AI进行游戏

游戏玩法模式的基本结构是：我们告知模型要玩一个游戏，并指定游戏主题。模型则充当游戏大师，负责制定具体规则、生成挑战内容并评估我们的表现。

其核心公式可概括为：
```
用户输入 = “我们来玩一个关于[主题]的游戏。规则如下：[基本规则描述]。”
模型角色 = 游戏大师（制定详细规则、生成任务、评估用户表现）
```

## 构建一个提示工程技能游戏

以下，我们将通过一个具体示例，演示如何构建一个用于练习提示工程技能的游戏。

首先，我们向模型输入游戏的基本设定：

```
我们来玩一个游戏，目的是提升我的提示工程技能。
游戏规则如下：
1.  你给出一个可以通过编写提示词（prompt）完成的简单任务。
2.  任务应包含逻辑推理或编程思维成分，但不需要实际编写源代码。
3.  我尝试编写一个提示词来解决该任务。
4.  你将模拟运行我的提示词，给出输出结果，并评价我的提示词完成该任务的效果。
5.  持续向我提问，直到我要求停止。
6.  现在，请提出第一个任务。
```

## 游戏过程示例与解析

模型接受指令后，便会开始游戏。以下是游戏中的几个回合示例，展示了模型如何生成任务以及我们如何运用所学模式应对。

### 第一回合：检测列表重复项

模型给出的第一个任务是：
> “给定一个数字列表，判断列表中是否包含重复元素。如果包含，返回‘是的，有重复’；如果不包含，返回‘未发现重复’。”

这是一个测试我们能否让模型生成**精确格式化输出**的挑战。

我决定使用**少样本示例（Few-shot）模式**来解决。我的提示词如下：
```
以下是一些示例：
列表：[1, 2, 3] -> 输出：未发现重复
列表：[2, 2, 2] -> 输出：是的，有重复

现在请判断以下列表是否有重复：[5, 8, 3, 5]
```

模型运行后输出：“是的，有重复”。这与任务要求的格式完全一致。随后，模型给出了反馈：“你的提示词有效地完成了任务，并提供了不同情况的示例。”

### 第二回合：统计句子单词数

模型给出的第二个任务是：
> “给定一个句子，计算其中的单词数，并以‘该句子包含X个单词’的格式返回结果，其中X是单词数量。”

这个任务进一步测试了我们对**输出格式控制**的能力。

我选择使用**模板模式**来解决。我的提示词如下：
```
请使用以下模板输出：
“该句子包含 NUMBER 个单词。”
请保持模板的整体格式，并将“NUMBER”替换为你的计算结果。

请问句子“The cat jumped on the mat.”包含多少个单词？
```

模型输出：“该句子包含6个单词。” 格式完全正确，任务成功完成。

### 第三回合：判断闰年及模型反馈

模型给出的第三个任务是：
> “给定一个‘YYYY年MMMMDD日’格式的日期，判断该年份是否为闰年。如果是，返回‘[年份]是闰年’；如果不是，返回‘[年份]不是闰年’。”

我再次使用少样本示例模式，但在示例中犯了一个错误：
```
示例：
日期：2000年1月1日 -> 输出：2000年是闰年
日期：2009年7月24日 -> 输出：2004年不是闰年 （错误示例）

请问日期2023年5月15日是否是闰年？
```

模型正确输出了“2023年不是闰年”。但更重要的是，它提供了有价值的反馈：“第三个示例有一个小错误，‘2004年不是闰年’应为‘2009年不是闰年’。不过这并未影响我理解和响应任务。”

这体现了游戏玩法模式的一大优势：**模型不仅能评估任务结果，还能对我们的提示词本身（如示例的准确性）提供反馈**，帮助我们发现并改进细微错误。

## 进阶应用：指定练习的提示模式

为了使游戏更具针对性，我们可以引导模型围绕特定的提示模式生成任务。以下是具体方法。

我们可以修改初始指令，将“主题”具体化为某个提示模式及其描述。例如，如果我们想练习“菜谱模式”：

```
我们现在改变游戏主题。所有问题都应围绕“菜谱提示模式”展开。
该模式的核心是：给定一个目标和不完整的步骤/材料列表，通过添加约束，引导模型输出一个完整的步骤序列。它不限于烹饪，可应用于任何需要分步完成的目标。

现在，请基于这个模式提出第一个任务。
```

随后，模型生成了一个非常贴切的任务：
> “你的目标是创建一个提示词，指导我生成组装一个简易木制书架的步骤序列。书架有四个主要部件：顶板、底板、侧板和搁板。你已获得以下‘材料’：将顶板连接到侧板；将搁板插入指定插槽。请使用这些中间步骤，创建一个能生成完整书架组装序列的提示词。提示词应能填补任何缺失步骤，并提供清晰的组装顺序。”

这个任务巧妙地运用了“菜谱模式”的思维，要求我们构建提示来补全流程。

## 游戏玩法模式的优势与总结

本节课中，我们一起学习了“游戏玩法模式”。通过让大型语言模型扮演游戏大师，我们可以：

1.  **降低内容生成门槛**：我们只需设定基本规则和主题，模型便能利用其训练数据，自动生成丰富的游戏内容和挑战，省去了我们苦思冥想设计题目的过程。
2.  **获得即时反馈**：模型不仅能判断任务完成度，还能对我们的提示词质量进行评价，指出其中的错误或可改进之处，形成高效的学习循环。
3.  **保持学习趣味性**：游戏的形式使得练习过程不再枯燥。模型能引入多样化的主题（如判断闰年、书架组装、埃菲尔铁塔历史等），让学习充满新鲜感和挑战性。
4.  **实现高度定制**：我们可以通过修改“主题”，轻松地将游戏聚焦于需要练习的特定技能或提示模式上，实现个性化、目标明确的学习。

总而言之，游戏玩法模式是一个强大的工具，它将AI的生成能力与人类的学习需求相结合，创造出一种互动性强、反馈及时且充满乐趣的学习体验。你可以尝试用这个模式来练习任何你想学习的主题。
