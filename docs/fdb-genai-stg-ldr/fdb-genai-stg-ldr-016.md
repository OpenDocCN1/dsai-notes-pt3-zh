# 016：向大型语言模型引入新信息 🧠

在本节课中，我们将学习如何向大型语言模型提供其训练数据之外的新信息。这是利用大语言模型处理私有或最新数据的关键技术。

---

大型语言模型在训练时存在一个知识截止点，它无法知晓该日期之后的事件，也无法访问其训练集之外的数据。例如，企业通常拥有大量私有数据源，如内部文档和数据库，希望模型能基于这些信息进行推理。如果模型未使用这些信息进行训练，我们该如何实现这一点？

为了说明具体方法，让我们回顾之前讨论随机性时使用的一个例子。

上一节我们介绍了模型知识的局限性，本节中我们来看看如何通过提示词为其补充信息。

我将再次提出之前的问题：**我家外面有多少只鸟？** 模型在训练时并未包含关于我家外面鸟类的信息，它不知道我的房子在哪里，因此缺乏推理所需的数据。所以，它回答：“作为一个AI语言模型，我没有感知物理世界的能力，因此无法知道你家外面发生了什么。”

我们如何解决这个问题？答案是：**我们为它提供推理所需的信息。**

具体怎么做？我们只需将这些信息放入提示词中。任何时候，当我们想向大型语言模型引入其在训练时无法访问的新信息时，我们只需将其写入提示词。

以下是我将在此处进行的操作。我会在提示词开头提供信息，然后提出问题。

```text
历史观测数据：我家外面随机一天的平均鸟类数量。
一月：120只鸟。
二月：150只鸟。
三月：210只鸟。
四月：408只鸟。
现在是三月，根据我提供的数据，估算一下我家外面有多少只鸟。
```

现在，我完成了一件事：我赋予了它之前无法访问的信息。它之前无法查看我家外面的情况，也不知道我的房子位置。它曾建议我自行获取数据，因为它本身缺乏所需的基础数据。这本质上就是它在告诉我：“嘿，我看不到你家外面，我没有那些数据，我帮不了你。”

因此，我们只需在提示词的开头提供数据即可。

现在，你可以想象，这种方法适用于任何情况。如果你有希望进行推理的私有文档，首先，请确保你同意将这些数据发送给你所使用的模型服务商，或者你本地运行着大语言模型。如果你同意发送文档，你可以提取这些文档的文本，将其置于提示词的开头，并说明：“这是你需要知道的信息。现在，这是我的问题。”

所以，你可以利用提示词来引入信息。这一点我特别想强调，因为未来围绕大型语言模型的许多开发，都将涉及引入新的信息源——例如关于你的旅行、你在某公司的账户信息，或其他你需要处理的文档——并将其放入提示词中，以便模型进行推理。

很可能，未来许多大语言模型应用都会“看到”你的信息。而它们获取信息的方式，就是将信息汇总到某种提示词中，然后提出问题、进行格式化或执行其他操作。

当我提供了历史观测数据后，它现在可以回答了。它说：“根据您提供的历史观测数据，您家外面三月观测到的平均鸟类数量是210只。” 之前它说无法回答，现在它虽然仍会补充一些语言来限定其答案的范围，但它是基于我们提供的数据进行推理的。

我们可以进一步深入。同时，我想指出一个重要事项：**我们总是希望为其提供足够的信息以进行有效推理。** 它无法看到我们周围的环境，无法理解上下文，因此我们提供足够信息以做出合理决策至关重要。

例如，如果我有一些非常重要的隐藏假设，这些假设也需要在提示词中告知模型，而不仅仅是数据本身。它需要知道“游戏规则”、特殊事项等任何对推理重要的信息。这可能不仅是数据，还包括我的组织运作方式、我的生活规则等各种它需要了解的规则。

我将给出一个例子。我将修改这个提示词。

```text
我的房子被一个玻璃穹顶覆盖。没有动物可以进出。所有动物在玻璃穹顶内永生。
历史观测数据：我家外面随机一天的平均鸟类数量。
一月：120只鸟。
二月：150只鸟。
三月：210只鸟。
四月：408只鸟。
现在是三月，根据这些数据，估算我家外面有多少只鸟。
```

这是一个假设，如果语言模型不知道这一点，它将无法准确预测。但有了这个假设，整个推理游戏就完全改变了，因为它明确了某些隐藏的基本规则。

然后，我给出了相同的数据（但请注意，我实际上改变了前提，暗示鸟的数量恒定），并提问。它回答道：“根据您提供的新信息，您家外面的鸟类总数似乎随时间保持恒定。您提到所有动物在玻璃穹顶内永生。鉴于这些条件，鸟类总数将在全年保持不变。” 它在多处给出的答案是120只。

关于这一点，有一个重要事项：我提供给它的信息，与其训练数据所反映的世界常识并不一致。动物不会永生，我们的房子没有玻璃穹顶，鸟的数量也不太可能精确恒定、没有进出。我设定的这些奇怪规则在现实中并不常见。

因此，如果我们仅仅依赖它基于常识进行推理，而不提供这些特殊规则，它可能无法得出正确答案。所以，如果我们有这些与通常做法不同的特殊情况，我们必须将其作为新信息引入提示词。

以上所有在提示词顶部的信息，就是我向大型语言模型输入新信息的方式。我们不需要重新训练模型，也不需要幕后进行复杂操作，我们只是将其放入提示词，然后提出我们的问题，或给出我们期望的输出指令。

现在，如果你思考未来的搜索引擎可能会如何工作：它们可能会进行搜索，将相关文档整合起来，放入给大语言模型的提示词中，然后附上你的原始问题，最后基于这些文档给出答案。许多新的应用程序都将基于以下模式：搜索数据库以寻找可能相关的文档或信息片段，将其整合到提示词中，然后提出问题或请求输出。

因此，一个关键环节将是**提取信息并将其放入提示词**。我们所做的，就是通过直接将其写入提示词的方式，向大型语言模型引入新的信息。每当你需要对大语言模型未经训练的新信息进行推理时，这都是你将始终需要做的事情。

---

本节课中我们一起学习了如何通过提示词为大型语言模型引入其训练数据之外的新信息。核心方法是**将所需信息直接置于提示词的开头**，然后提出具体问题或指令。这是处理私有数据、最新信息或特殊规则的基础，也是未来许多AI应用构建的核心模式。
