# 生成式AI战略领导者：P35：替代方法模式 🧠

在本节课中，我们将学习一种名为“替代方法模式”的提示工程技巧。这种模式的核心是利用大型语言模型，针对同一个问题或任务，快速生成多种不同的解决方案或思路，类似于进行头脑风暴。

## 概述

上一节我们探讨了如何通过特定模式引导模型输出。本节中，我们来看看如何利用“替代方法模式”来激发创意，探索解决问题的多种可能性。其核心思想是：在特定范围内，要求模型始终为特定问题或任务提供不同的解决思路。

## 模式的核心思想

使用大型语言模型进行头脑风暴，为解决问题提供不同思路，是一个非常有趣且实用的方式。模型在训练过程中学习了海量资料，可能见过许多问题及其多种解决方案。因此，它可以基于这些知识，为我们提供多样化的潜在方法，甚至能综合过往信息，为未见过的具体问题合成出有趣的解决思路。

## 基础模式示例

以下是该模式的一个基础应用示例。我们首先给模型设定一个指令：

**指令：**
```
从现在开始，如果存在完成同一件事的不同方法，请列出最佳的替代方案。比较和对比这些方案，并询问我选择使用哪一个。
```

这个指令比较通用。在实际应用中，根据具体任务提供更丰富的上下文，效果通常会更好。指令的后半部分要求模型比较不同方案的优劣，这有助于我们根据自身情况做出更合适的选择。

## 应用实例：生成提示词

接下来，我们通过一个具体任务来演示。假设我们的任务是：让ChatGPT为自己编写一个提示词（Prompt），用于判断给定日期是否为闰年。

**任务描述：**
```
请编写一个提示词，使用少量示例（Few-Shot）来判断格式为“年-月-日”的日期是否为闰年。输出应为“{年份}是闰年”或“{年份}不是闰年”。
```

模型根据“替代方法模式”生成了两种不同的方案：

以下是模型生成的两种不同风格的提示词方案：

**方案一：直接提问格式**
```
提示词：判断以下日期是否为闰年。
示例：
输入：2020-02-29
输出：2020是闰年。
输入：2021-02-28
输出：2021不是闰年。
...（更多示例）
请判断：{用户输入日期}
```

**方案二：对话格式**
```
提示词：我们来玩一个游戏。我会给你一些日期，你告诉我它是不是闰年。
示例：
用户：2020-02-29 是闰年吗？
助手：是的，2020是闰年。
用户：2021-02-28 呢？
助手：不，2021不是闰年。
...（更多示例）
用户：{用户输入日期}
```

随后，模型对两种方案进行了比较：
*   **方案一**更为正式和结构化，易于理解和解析，适合需要清晰、简洁答案的应用场景。
*   **方案二**更具对话性和自然感，能提升用户交互的参与度，适合注重用户体验的交互式应用。

需要注意的是，模型在生成时犯了一个小错误：它没有完全遵循我们要求的输出格式（把年份放在了前面）。这提醒我们，必须仔细检查模型生成的提示词，确保其符合我们的具体要求，必要时可以进行修正和优化。

## 模式变体与进阶应用

我们可以对基础模式进行微调，以适应更复杂的任务。例如，在要求模型生成替代方案之前，先让它明确列出任务本身。

**调整后的指令：**
```
每当我要求你为我编写完成某项任务的提示词时，请：1. 列出任务内容；2. 列出完成该任务的替代方法；3. 为每种方法编写一个提示词。
```

让我们应用这个变体模式来处理一个更实际的问题：自动总结邮件链中的问题。

**新任务：**
```
请编写一个提示词，让ChatGPT能自动识别一封邮件链中的所有问题，并将每个人对每个问题的意见总结为要点，列在相应问题下方。
```

模型生成了三种截然不同的方法：

以下是模型针对邮件总结任务提出的三种替代方法：

1.  **直接分析提取法**：编写提示词，指示模型首先识别邮件链中的所有问题，然后提取与每个问题相关的回复，最后将意见总结为要点。
2.  **角色扮演模拟法**：编写提示词，要求模型模拟一场对话，在其中扮演“总结者”的角色，让用户提供邮件链，然后生成带要点的总结。（这里模型在其为自己编写的提示词中，自发运用了“角色模式”）。
3.  **案例研究报告法**：编写提示词，将邮件链视为一个“案例研究”，要求模型提供一份包含问题及对应意见要点的总结报告。

第三种“案例研究”法是许多人可能不会首先想到的创新角度，这正体现了利用模型进行头脑风暴的价值——它能突破我们固有的思维框架，提供新颖的视角。

## 方案的评估与迭代

生成了多种方案后，下一步自然是对它们进行评估。我们可以再次利用大型语言模型来评估这些提示词本身的效果。通常，建议在一个新的对话中进行评估，以避免模型陷入“自我肯定”的偏差。

**评估任务：**
```
请编写一个提示词，用于评估多个不同的、旨在总结邮件对话中问题及各利益相关方观点的提示词。
```

模型为此评估任务又提供了三种替代方法：

以下是模型为“评估提示词”这个新任务生成的三种方法：

1.  **直接评估法**：编写提示词，向模型呈现多个待评估的提示词，让其评估每个提示词在总结问题和观点方面的有效性。
2.  **评估者角色法**：编写提示词，指示模型模拟对话，扮演“评估者”角色，由用户提供不同的提示词供其评估。（再次使用了角色模式）。
3.  **反馈改进法**：编写提示词，要求模型为每个提示词提供反馈，并给出改进建议。

这样，我们就拥有了三种不同的方法来评估之前生成的方案，形成了一个完整的“生成-评估”循环。

## 总结

本节课中，我们一起学习了“替代方法模式”。我们了解到，该模式的核心是引导大型语言模型为单一问题提供多种解决方案，从而实现高效的头脑风暴。我们通过“生成闰年判断提示词”和“编写邮件总结提示词”两个实例，演示了基础模式及其变体的应用。最后，我们还探讨了如何利用模型本身来评估这些生成的方案，形成迭代优化的工作流。掌握这一模式，能帮助我们在面对复杂任务时，快速拓展思路，发现潜在的最佳路径。
