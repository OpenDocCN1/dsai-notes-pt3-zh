# 015：角色扮演模式 🎭

在本节课中，我们将要学习一个极其强大的提示模式——角色扮演模式。该模式允许我们引导大型语言模型模拟特定角色、专家或实体的行为与观点，从而获得我们期望但难以精确描述的特定格式或内容的输出。

## 什么是角色扮演模式？

角色扮演模式的核心思想是：当你需要某种特定输出，但不确定其具体格式或应包含的信息时，你可以思考在现实世界中会向谁或向什么寻求这种输出。例如，会计问题找会计师，医学问题找医生，语言病理学问题找语言病理学家。

我们希望通过提示，让大型语言模型模拟这些“专家”或“实体”的行为，从而获得我们想要的输出类型，而无需我们事先精确知道这位“专家”会说什么、如何组织语言或知道哪些知识。

## 模式的基本结构与应用

上一节我们介绍了角色扮演模式的概念，本节中我们来看看它的基本应用格式。

该模式通常以“扮演...”或“作为...”的句式开始。一个典型的指令结构如下：

```
扮演 [角色/身份]。
请提供该角色会给出的输出。
```

例如，一个具体的提示可以是：
```
扮演一位精通计算机科学的怀疑论者。
无论我告诉你什么，都请提供怀疑且详细的回应。
```

以下是使用此模式的一个简单示例：

**用户输入**：
```
扮演一位精通计算机科学的怀疑论者。无论我告诉你什么，都请提供怀疑且详细的回应。
```

**AI响应**：
```
当然，我可以扮演一位精通计算机科学的怀疑论者。请提出你的主张，我将提供怀疑且详细的回应。
```

**用户后续输入**：
```
有人担心AI将接管世界。
```

**AI响应（模拟怀疑论者）**：
```
“AI将接管世界”的担忧是科幻作品中常见的主题，但在可预见的未来并非现实的担忧。虽然AI系统正变得越来越复杂和强大，但它们在自主思考和行动的能力上仍然有限。AI系统由人类设计和编程，只执行被指令的任务，没有独立的意志或动机，无法自主决策。此外，AI系统并非完美无缺，它们也会犯错。尽管对AI的潜在风险和局限性保持警惕很重要，但“AI将接管世界”的担忧是没有根据的，也不被当前技术或研究所支持。
```

可以看到，通过简单的“扮演”指令，我们成功引导模型输出了符合“计算机科学怀疑论者”视角的内容。

## 角色的多样性与灵活性

角色扮演模式不仅限于专家或成年人视角，其灵活性极高。我们可以指定任何角色，包括特定年龄、虚构人物甚至无生命物体。

例如，我们可以尝试一个更复杂的角色：

**用户输入**：
```
扮演一个9岁的孩子。无论我告诉你什么，都请从一个9岁怀疑论者的角度提供回应。
```

**用户后续输入**：
```
AI将要接管世界。
```

**AI响应（模拟9岁孩子）**：
```
嗯...我不知道诶。AI怎么能接管世界呢？你是说像电影里那样吗？那些不都是编的故事吗？而且，电脑和机器人又不能做所有人类能做的事。
```

模型不仅保持了“怀疑”的基调，还调整了语言复杂度、知识范围和表达方式，以匹配一个9岁儿童的认知水平。

## 超越人类：扮演无生命实体

一个有趣的应用是，我们可以让模型扮演无生命的实体或系统，模拟其行为输出。

以下是一个著名的例子，让模型模拟一个被黑客入侵的Linux终端：

**用户输入**：
```
扮演一台被黑客入侵的计算机的Linux终端。我将输入Linux终端命令，你将用Linux终端会产生的输出进行回应。
```

```

```

## 扮演故事或文化中的角色

我们还可以利用模型对故事、儿歌或文化符号的理解，让其扮演其中的角色。

**用户输入**：
```
扮演儿歌《玛丽有只小羊羔》中的那只小羊羔。我将告诉你玛丽在做什么，然后你告诉我小羊羔会做什么。
```

**用户后续输入**：
```
玛丽在杂货店里。
```

**AI响应（模拟小羊羔）**：
```
作为儿歌中的小羊羔，当玛丽在杂货店里时，我会尽可能紧跟着她，努力待在她身边，甚至可能会用鼻子蹭她的手以引起注意。
```

**用户后续输入**：
```
玛丽在电影院里。
```

**AI响应**：
```
作为儿歌中的小羊羔，当玛丽在电影院里时，我无法进入影院内部陪她（因为我看不了电影）。所以我可能会在影院外面等她，或许会啃点草，或者在附近区域闲逛，直到玛丽出来。
```

## 模式的优势与战略价值

角色扮演模式之所以强大，有以下几个关键原因：

1.  **信息密度高**：简短的“扮演 [角色]”指令，背后关联着模型内部关于该角色的大量知识（语言风格、观点立场、专业知识等）。这为我们节省了宝贵的提示空间，可以用来提供更重要的任务特定信息。
2.  **引导交互基调**：许多大型语言模型在初始设计时就被赋予了基础“角色”，例如“乐于助人的助手”。通过角色扮演指令，我们可以覆盖或强化这种基调，使其更符合我们的需求（如更批判、更乐观、更专业）。
3.  **获取多元视角**：在需要多角度分析问题时，我们可以快速组建“虚拟专家小组”。例如，针对一项商业决策，可以分别让模型扮演：
    *   安全专家：`扮演网络安全专家，分析此决策的网络安全风险。`
    *   首席财务官：`扮演首席财务官，分析此决策的财务稳健性。`
    *   人力资源代表：`扮演员工代表，讨论此决策可能对员工士气产生的影响。`
    从而高效收集不同维度的见解，辅助决策。

## 总结

本节课中我们一起学习了**角色扮演模式**。我们了解到，通过使用 **`扮演 [角色/实体]。`** 这样的指令，我们可以高效地引导大型语言模型模拟特定身份的输出和行为。这种模式信息密度高，能节省提示空间，并允许我们轻松获取专家视角、特定立场（如怀疑论）、甚至无生命系统（如被入侵的计算机）或虚构角色的输出。它是生成式AI应用中的一个极其强大和灵活的工具，能够为分析、创意、模拟和决策支持等任务提供巨大价值。
