# 生成式AI战略领导者：P52：翻转交互模式 🚀

![](img/4dc0e47f6cea742d61ce65358166e85e_1.png)

在本节课中，我们将要学习生成式AI系统的一个核心基础：**翻转交互模式**。这是一种强大的提示工程模式，它改变了我们与AI的互动方式，让AI从被动应答者转变为主动的引导者和执行者。

## 什么是翻转交互模式？🤔

![](img/4dc0e47f6cea742d61ce65358166e85e_3.png)

上一节我们介绍了生成式AI系统的基础。本节中我们来看看如何启动并让生成式AI以新的方式工作。这背后有一个关键的提示工程模式，我称之为“翻转交互”。

在传统交互中，通常是我们告诉系统做什么，或者向它提问。而在翻转交互模式中，情况正好相反：**系统会主动告诉我们该做什么，或者向我们提问**。更进一步，它甚至会去询问现有的计算机系统，在数据库中运行查询以收集所需信息，或者命令其他系统执行必要的操作，以完成我们设定的目标。

![](img/4dc0e47f6cea742d61ce65358166e85e_5.png)

让我们快速了解一下翻转交互模式，并探讨它是如何运作的。

## 模式的基本结构 🏗️

![](img/4dc0e47f6cea742d61ce65358166e85e_7.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_8.png)

该模式的基本结构是：我们告诉AI，它将通过**一次问一个问题**的方式来收集足够的信息，以完成某个目标。

![](img/4dc0e47f6cea742d61ce65358166e85e_9.png)

以下是该模式的核心提示模板：

```
你将要一次问我一个问题，以收集足够的信息，为我推荐今晚在田纳西州纳什维尔用餐的餐厅。
```

![](img/4dc0e47f6cea742d61ce65358166e85e_11.png)

你可以将这个基本模式理解为“一次问我一个问题”。对于生成式系统来说，“一次一个”通常是最佳实践，尽管并非必须如此。同样，也可以是“一次告诉我一个步骤”。

这个模式的目标是创造一个情境：**AI去创建需要完成的事项、需要执行的任务或需要采取的行动**。然后，系统将代表“智能体”去执行这些行动，并告知执行结果。

![](img/4dc0e47f6cea742d61ce65358166e85e_13.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_14.png)

因此，这个粗略的提示模式——“一次问我一个问题”或“一次告诉我一个步骤”——创造了一个环境，即告诉AI：“你掌握主导权，去做吧。”

![](img/4dc0e47f6cea742d61ce65358166e85e_15.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_16.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_18.png)

在提示的末尾，我通常会加上：“**提出第一个问题。**” 这是一个在许多系统中都非常有效的技巧，确保我们从**仅一个问题**开始。或者说“告诉我第一步”，以确保我们从**仅一个步骤**开始。我们希望创建一个强大的模式和行为，让AI知道它要做什么，并且会一步一步地执行。

## 实战演示：餐厅推荐 🍽️

让我们来看一个具体的提示示例：

![](img/4dc0e47f6cea742d61ce65358166e85e_20.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_21.png)

```
一次问我一个问题，以收集足够的信息，为我推荐今晚在田纳西州纳什维尔用餐的餐厅。提出第一个问题。
```

![](img/4dc0e47f6cea742d61ce65358166e85e_23.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_24.png)

AI的回应是：“**您今晚想吃什么类型的菜系？**”

![](img/4dc0e47f6cea742d61ce65358166e85e_26.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_27.png)

我回答：“**墨西哥菜。**”

现在，我给出了一个答案，AI必须进行**适应**。这种适应的一部分就是**选择下一个要问我的问题**。这一点非常强大。根据已获得的信息来选择下一个问题，这一简单的行为至关重要。因为在执行任务时也会发生同样的事情：它请求运行一个任务，观察发生了什么，然后根据结果调整下一个任务。

以下是完整的交互流程，展示了AI如何根据我的回答动态调整后续问题：

![](img/4dc0e47f6cea742d61ce65358166e85e_29.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_30.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_31.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_32.png)

1.  **AI提问**：您今晚想吃什么类型的菜系？
    *   **我的回答**：墨西哥菜。
2.  **AI提问**：您有任何饮食限制或偏好吗？
    *   **我的回答**：没有。
    *   *（注意：如果我说“有”，它可能会接着询问具体细节；但我说“没有”，它就适应并转向下一个问题。）*
3.  **AI提问**：您更喜欢休闲餐饮体验还是更高档的餐厅？
    *   **我的回答**：适合孩子的。
4.  **AI提问**：您想要有户外座位的餐厅还是室内座位，或者无所谓？
    *   **我的回答**：无所谓。正在下雨，我可能不会在户外用餐。
5.  **AI提问**：您对特定区域有偏好吗？
    *   **我的回答**：范德堡大学附近。
6.  **AI提问**：您愿意出行多远？
    *   **我的回答**：短途车程，5到10分钟。
7.  **AI提问**：您对接受预订的餐厅有偏好吗？还是可以接受直接进店？
    *   **我的回答**：直接进店可以，但我不想等位太久。

![](img/4dc0e47f6cea742d61ce65358166e85e_34.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_35.png)

请注意，整个交互过程非常**流畅**。每次我回答完一个问题，AI都在**适应**。这就是“智能体”部分开始发挥作用的地方，是智能体的魔力所在。它不仅在适应我提供的信息内容，也在适应我提供信息的**各种格式和方式**。这是大语言模型的一个重要特点：它们能够处理多种不同格式的输入，能够理解表达相同信息和想法的多种不同方式，而无需我们去构建复杂的系统来处理我这些“随心所欲”的回应方式。

在我给出关于“直接进店”的回答后，AI说：“好的，根据您的偏好，我推荐 **Rose Pepper Cantina**。”

![](img/4dc0e47f6cea742d61ce65358166e85e_37.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_38.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_39.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_40.png)

然后我去谷歌地图查了一下，发现从我家开车过去大约需要13分钟（考虑到交通），这比我想要的5-10分钟要远一点。于是，我回去对AI说：“嘿，谷歌地图显示要13分钟车程，我有点懒得开那么远。😊”

![](img/4dc0e47f6cea742d61ce65358166e85e_42.png)

AI回应道：“好的，既然这样，去 **Sco** 吧。” Sco恰好就在范德堡大学街对面。

## 模式的核心价值与扩展 💡

现在，我可以运用这种强大而有价值的能力来帮助我解决问题。比如，我该去哪里？它能帮助我做决定，引导我作为一个人进行思考。

![](img/4dc0e47f6cea742d61ce65358166e85e_44.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_45.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_46.png)

AI从我这里收集信息，与它从数据库收集信息**没有本质区别**，只是收集信息的接口发生了变化。向人类提问要容易得多，因为人类可以适应AI所说的任何话。不同之处在于，当AI需要从真实的计算机系统（如数据库）收集信息时，它必须**使用该数据库的语言**，必须**使用该计算机系统的语言**。因此，它需要进行**翻译**。

![](img/4dc0e47f6cea742d61ce65358166e85e_48.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_49.png)

大语言模型极其擅长的一项能力正是**翻译**。它们是语言的专家。因此，另一个巨大的优势是：**我们用人类的语言表达需求，AI将其分解为执行计划，并开始交互式地执行该计划**。

![](img/4dc0e47f6cea742d61ce65358166e85e_51.png)

当交互对象是人类时，它会用人类语言提问；但当它需要与数据库对话时，它可以开始使用那种数据库语言。这有点像《星球大战》里的协议机器人，它能说各种不同的语言，与所有不同的系统通信，并充当与那些系统的接口。**这正是生成式AI和智能体AI正在做的事情**。

![](img/4dc0e47f6cea742d61ce65358166e85e_53.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_54.png)

但与传统AI（我们一步步地指挥一切）不同，在智能体AI中，我们赋予它执行多个不同步骤并适应的能力：**它选择步骤，我们（或系统）执行，它获取该步骤执行结果的信息，然后进行适应，如此循环往复**。

## 总结 📝

本节课中，我们一起学习了生成式AI的**翻转交互模式**。我们了解到：

![](img/4dc0e47f6cea742d61ce65358166e85e_56.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_57.png)

![](img/4dc0e47f6cea742d61ce65358166e85e_58.png)

*   该模式的核心是让AI从**被动应答**转向**主动引导和执行**。
*   其基本结构是通过 **“一次一个问题”** 或 **“一次一个步骤”** 的提示，让AI掌握主导权。
*   该模式的价值在于AI能够**动态适应**用户的回答和外部反馈，并利用其强大的**语言理解和翻译能力**与各种系统交互。
*   这构成了智能体AI的基础，使其能够自主规划并执行多步骤任务，最终实现更复杂的目标。
