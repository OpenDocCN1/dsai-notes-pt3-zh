## 1. 语言模型基础 🤖

上一节我们介绍了课程概述，本节中我们来看看语言模型的基础。

语言模型的核心任务是计算一个句子出现的概率。给定一个由词语序列组成的句子 `S = w1, w2, ..., wn`，其概率 `P(S)` 可以通过链式法则计算：

**P(S) = P(w1) * P(w2|w1) * P(w3|w1, w2) * ... * P(wn|w1, w2, ..., wn-1)**

以下是两种主要的语言模型类型：

*   **N-gram 模型**：该模型基于一个简化假设，即一个词的概率只依赖于它前面的 `N-1` 个词。例如，在二元语法模型中，`P(wn|w1, w2, ..., wn-1) ≈ P(wn|wn-1)`。
*   **神经网络语言模型**：使用神经网络（如循环神经网络RNN）来建模词语之间的长期依赖关系，能够比N-gram模型更有效地捕捉上下文信息。

## 2. 词向量表示 🔤

理解了如何计算句子概率后，我们需要一种方式让计算机“理解”词语。这就是词向量表示的目的。

词向量将词语映射到一个高维的连续向量空间中，语义相似的词其向量在空间中的位置也相近。Word2Vec 是其中最著名的模型之一，它通过一个浅层神经网络来学习词向量。

以下是两种主要的 Word2Vec 训练方法：

*   **Skip-gram**：该方法通过中心词来预测其周围的上下文词。其目标是最大化给定中心词时上下文词出现的概率。
*   **CBOW**：与Skip-gram相反，该方法通过上下文词来预测中心词。其目标是最大化给定上下文词时中心词出现的概率。

一个简单的词向量查找在代码中可能如下所示：

```python
# 假设我们有一个预训练的词向量字典 `word_vectors`
word = "人工智能"
vector = word_vectors[word]
print(f"'{word}' 的词向量维度是：{vector.shape}")
```

## 3. 注意力机制简介 ✨

传统的序列模型（如RNN）在处理长序列时，容易遗忘远距离的信息。注意力机制通过让模型在每一步都能“关注”输入序列中的所有部分，有效地解决了这个问题。

注意力机制的核心是计算一个“注意力权重”分布，它决定了在生成当前输出时，应该对输入序列的每个部分赋予多少重要性。

注意力权重的计算通常涉及三个要素：查询、键和值。其核心计算步骤如下：

1.  计算查询与所有键的相似度得分。
2.  使用Softmax函数将得分归一化为权重（和为1的概率分布）。
3.  将权重与对应的值向量加权求和，得到注意力输出。

这个过程可以用以下公式概括：

**Attention(Q, K, V) = softmax( (Q * K^T) / sqrt(d_k) ) * V**

其中，`Q` 是查询矩阵，`K` 是键矩阵，`V` 是值矩阵，`d_k` 是键向量的维度，除以 `sqrt(d_k)` 是为了稳定梯度。
