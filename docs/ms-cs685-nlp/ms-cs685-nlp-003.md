## 语言模型与 N-gram 模型回顾

![](img/d8e572731c1625e18efe04a4c53e19eb_13.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_14.png)

上一节我们介绍了语言模型的基本概念，本节中我们来看看其具体实现。

![](img/d8e572731c1625e18efe04a4c53e19eb_16.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_17.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_18.png)

语言模型本质上是试图衡量给定词序列的联合概率。这个序列可以是一个句子、短语或大段文本。上次我们学习了如何通过链式法则，将联合概率分解为多个条件概率的乘积。因此，任何能够计算“给定若干前缀词，预测下一个词”的条件概率的模型，也都能通过链式法则计算整个序列的联合概率。

![](img/d8e572731c1625e18efe04a4c53e19eb_20.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_22.png)

我们上次学习了 N-gram 模型，这是一种估计这些条件概率的简单方法。其核心思想是：在训练文本数据集中，对于任何出现的前缀，统计该前缀出现的次数，以及特定词在该前缀后出现的次数。这是一种基于计数和归一化的方式来估计条件概率，是最大似然估计的一个例子。

![](img/d8e572731c1625e18efe04a4c53e19eb_24.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_25.png)

## N-gram 模型的局限性

![](img/d8e572731c1625e18efe04a4c53e19eb_27.png)

在介绍神经语言模型之前，我们先回顾一下 N-gram 模型的一些问题，这些问题促使我们寻求更复杂的模型。

![](img/d8e572731c1625e18efe04a4c53e19eb_29.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_31.png)

以下是 N-gram 模型面临的主要挑战：
1.  **稀疏性问题**：如果某个特定词 `W_j` 在“students open their `W_j`”这个上下文中的计数为零，那么整个条件概率将为零，导致包含该短语的整个文本的概率为零。我们讨论过通过“平滑”技术来解决，即从已观察到的计数中“借用”一小部分概率质量分配给未观察到的计数。
2.  **前缀未出现**：如果整个前缀（如“students open their”）在训练数据中未出现，分母将为零。传统 N-gram 模型使用“回退”方法解决，即回退到更短的前缀（如“students open”或“students”）进行估计。但这两种方法都略显生硬。
3.  **存储问题**：N-gram 表的大小随着 N 的增加呈指数级增长（`V^N` 行），这限制了高阶 N-gram 模型的构建，且稀疏性问题在高阶模型中更为严重。
4.  **独立性假设**：在 N-gram 模型中，所有词和前缀都被独立处理。例如，“students open their”和语义相近的“pupils open their”被视为完全不同的前缀，模型无法在它们之间共享信息。

## 从独热编码到词嵌入

![](img/d8e572731c1625e18efe04a4c53e19eb_39.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_41.png)

上一节我们指出了独热编码的局限性，本节中我们来看看更优的表示方法。

N-gram 模型及许多词袋模型使用**独热编码**表示单词。在这种表示中，每个词是一个仅在某一个维度为 1、其余维度为 0 的向量。例如，在词汇表 `[I, hate, love, the, movie, film]` 中，“movie”可能表示为 `[0,0,0,0,1,0]`。短语可以通过向量相加来表示。

![](img/d8e572731c1625e18efe04a4c53e19eb_43.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_44.png)

独热编码的最大问题是所有词向量彼此正交，点积为零。这意味着同义词“movie”和“film”在向量空间中的距离，与它们和“hate”的距离一样远，无法体现语义相似性。

![](img/d8e572731c1625e18efe04a4c53e19eb_46.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_48.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_49.png)

因此，我们需要一种表示空间，使得语义相似的文本单元也具有相似的表示。我们将从高维稀疏的独热向量转向低维稠密的实值向量，即**词嵌入**。

在神经语言模型中，我们将前缀编码成这些低维实值向量，然后训练一个分类器，根据学习到的前缀表示来预测下一个词。这样，我们就从基于计数的模型转向了基于预测的模型。

![](img/d8e572731c1625e18efe04a4c53e19eb_51.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_52.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_54.png)

## 核心组件：Softmax 层与预测

![](img/d8e572731c1625e18efe04a4c53e19eb_72.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_73.png)

现在，假设我们有了前缀“students open their”的低维向量表示，我们来看看如何将其转化为对下一个词的预测。这是一个在后续课程中会反复出现的重要概念。

![](img/d8e572731c1625e18efe04a4c53e19eb_75.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_76.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_78.png)

我们将使用一个 **Softmax 层** 来完成这个任务。它接收一个向量作为输入，并输出在整个词汇表（或更广义的输出空间）上的概率分布。

具体步骤如下：
1.  我们有一个低维前缀表示向量 `x`（例如三维向量 `[-2.3, 0.9, 5.4]`）。
2.  我们有一个权重矩阵 `W`，用于将 `x` 投影到词汇表大小的维度。矩阵 `W` 的每一行对应词汇表中的一个词，可以理解为该词对于前缀各个特征的权重。
3.  计算矩阵向量积 `s = Wx`，得到一个 `V` 维向量（`V` 为词汇表大小）。
4.  对向量 `s` 应用 **Softmax 函数**，将其转换为一个有效的概率分布（所有元素为正且和为1）。

![](img/d8e572731c1625e18efe04a4c53e19eb_80.png)

**Softmax 函数公式**：
`softmax(x_i) = exp(x_i) / Σ_j exp(x_j)`

通过这个过程，我们就得到了给定前缀后，下一个词是词汇表中每个词的条件概率。

![](img/d8e572731c1625e18efe04a4c53e19eb_82.png)

## 核心组件：组合函数与模型架构

![](img/d8e572731c1625e18efe04a4c53e19eb_84.png)

上一节我们介绍了如何从前缀表示得到预测，本节我们来看看如何从原始词序列得到这个单一的前缀表示。

![](img/d8e572731c1625e18efe04a4c53e19eb_86.png)

我们需要一个**组合函数**（即神经网络），将输入的一系列词嵌入（如“students”、“open”、“their”各自的嵌入）组合成一个单一的向量。有多种方式可以实现：

以下是几种常见的组合方式：
1.  **逐元素相加/平均**：最简单，但完全忽略了词序信息。
2.  **拼接**：将所有词嵌入拼接成一个长向量。这保留了词序，但向量维度会随窗口大小线性增长，且参数不共享。
3.  **前馈神经网络（固定窗口语言模型）**：将拼接后的向量输入一个或多个带有非线性激活函数（如 ReLU）的隐藏层，最后接 Softmax 层。这是 Bengio 等人在 2003 年提出的经典模型。
4.  **循环神经网络（RNN）**：按顺序处理每个词，通过一个循环单元逐步更新隐藏状态，最终隐藏状态作为整个序列的表示。参数在时间步之间共享，可以处理任意长度的序列。
5.  **Transformer**：目前最主流的架构，使用自注意力机制并行处理所有词，更好地捕捉长距离依赖。我们将在后续课程重点学习。

**ReLU 激活函数公式**：
`ReLU(x) = max(0, x)`

## 模型对比与总结

本节课中，我们一起学习了前馈神经语言模型和循环神经语言模型的前向传播过程。

与 N-gram 模型相比，神经语言模型的主要优势在于：
*   **解决了稀疏性问题**：不再依赖显式的计数表。
*   **模型大小可控**：不再随模型阶数指数增长。
*   **能够共享信息**：语义相似的词或短语通过相似的嵌入表示，使模型可以泛化。

![](img/d8e572731c1625e18efe04a4c53e19eb_88.png)

**固定窗口前馈模型 vs 循环神经网络模型**：
*   **RNN 的优势**：可以处理任意长度的输入；模型大小与输入长度无关；参数在时间步间共享。
*   **RNN 的劣势**：顺序处理导致训练速度慢（尤其是长序列）；在实践中难以有效利用很长的上下文信息（梯度消失/爆炸问题）。这些挑战促使了 Transformer 架构的发展。

![](img/d8e572731c1625e18efe04a4c53e19eb_90.png)

![](img/d8e572731c1625e18efe04a4c53e19eb_92.png)
