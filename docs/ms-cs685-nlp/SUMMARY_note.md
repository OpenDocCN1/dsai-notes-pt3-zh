## 🎯 核心概念与工具

在本课程中，你将接触到自然语言处理领域的多个核心概念与工具。以下是其中一些关键点：

*   **语言模型**：其核心是计算一个词序列的概率，公式可表示为 `P(w1, w2, ..., wn)`。
*   **注意力机制**：这是Transformer的关键，允许模型在处理序列时聚焦于不同部分。其核心计算可简化为 `Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) V`。
*   **BERT**：一个基于Transformer编码器的预训练模型，通过掩码语言建模（MLM）和下一句预测（NSP）任务进行训练。
*   **PyTorch**：课程中主要使用的深度学习框架，用于实现各种模型。
