# ## 二、基于概率分配函数的不确定性推理

# ### 1 特殊的概率分配函数

Bel(A) = \(\sum_{q_i \in A} M(\{q_i\})\)

Bel(U) = \(\sum_{B \subseteq U} M(B) = \sum_{i=1}^n M(\{q_i\}) + M(U) = 1\)

Pl(B) = 1 - Bel(~B) = 1 - \(\sum_{q_i \in \sim B} M(\{q_i\}) = 1 - [\sum_{i=1}^n M(\{q_i\}) - \sum_{q_i \in B} M(\{q_i\})]\)

= 1 - [1 - M(U) - Bel(B)]

= M(U) + Bel(B)
