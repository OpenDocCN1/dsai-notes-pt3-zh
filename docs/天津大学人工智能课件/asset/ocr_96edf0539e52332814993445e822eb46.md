# ## 2 激发函数 (activation function)或作用函数 \( f \)

作用是把可能的无限域变换到给定的范围内输出，以模拟生物神经元非线性转移特性，因此，它决定节点输出信号的范围。

+   - 阈值型  
+     \( f(x) = \begin{cases} 1, & x > 0 \ 0, & x \leq 0 \end{cases} \)

+   - 分段线性型  
+     \( f(x) = \begin{cases} 0 & x \leq 0 \ Cx & 0 \leq x \leq x_c \ 1 & x \leq x_c \end{cases} \)

+   - Sigmoid函数  
+     \( f(x) = \frac{1}{1 + e^{-x}} \)

+   - 双曲正切型  
+     \( f(x) = \frac{e^x - e^{-x}}{e^x + e^{-x}} \)
