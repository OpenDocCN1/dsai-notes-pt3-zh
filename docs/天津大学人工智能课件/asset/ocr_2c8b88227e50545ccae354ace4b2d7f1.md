# ## 二、信任传递

# ### 证据间相互无关。

多个证据E₁、 E₂、 ....， Eₙ和多个结论H₁、 H₂、 ....， Hₘ，并且每个证据都以一定程度支持结论，则有：

[ P(H_i \mid E_1, E_2, \cdots, E_n) = \frac{P(E_1, E_2, \cdots, E_n \mid H_i)P(H_i)}{P(E_1, E_2, \cdots, E_n)} ]

[ = \frac{P(E_1 \mid H_i)P(E_2 \mid H_i) \cdots P(E_n \mid H_i)P(H_i)}{P(E_1, E_2, \cdots, E_n \mid H_1)P(H_1) + \cdots + P(E_1, E_2, \cdots, E_n \mid H_m)P(H_m)} ]

[ = \frac{P(E_1 \mid H_i)P(E_2 \mid H_i) \cdots P(E_n \mid H_i)P(H_i)}{\sum_{k=1}^m P(E_1 \mid H_k)P(E_2 \mid H_k) \cdots P(E_n \mid H_k)P(H_k)} ]
