# # 第一节 状态空间法问题求解

# ## 一、问题的状态空间(state space)表示

+   1. 状态空间可用三元组(_S_, _O_, _G_)来描述

+   * _S_: 状态集合。状态是某种事实的符号或数据。  
+     _S_<sub>0</sub>是问题的初始状态。  
+     _S<sub>k</sub>_={_S_<sub>_k_0</sub>, _S_<sub>_k_1</sub>, ...}

+   * _G_: 表示目标状态集。  
+     它可以是具体的状态，也可以是对某些状态性质的描述

+   * _O_是操作算子集(operator)，一个状态转化为另一个状态。  
+     状态空间的一个解是一个有限的操作算子序列，它使初始状态转化为目标状态：  
+     \( S_0 \xrightarrow{O_1} S_1 \xrightarrow{O_2} S_2 \xrightarrow{O_k} \cdots \xrightarrow{} G \)  
+     _O_<sub>1</sub>, ..., _O<sub>k</sub>_即为状态空间的一个解，解不一定是唯一的。
