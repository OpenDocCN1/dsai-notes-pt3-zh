# 轮盘法

+   (1) 计算每个染色体\(x_i\)的适应度\(f(x_i)\);

+   (2) 找出群体的适应度之和; \(SUM = \sum_{i=1}^{pop-size} f(x_i)\)

+   (3) 计算某染色体\(x_i\)的选择概率\(p_i\); \(p_i = f(x_i)/SUM\)

+   (4) 生成区间\([0, 1]\)内的随机数 \(r\);

+   (5) 选择 \(r < p_i\) 的第一个染色体放入缓冲区;

+   (6) 重复执行(4)(5)直到缓冲区中有足够多的染色体。
