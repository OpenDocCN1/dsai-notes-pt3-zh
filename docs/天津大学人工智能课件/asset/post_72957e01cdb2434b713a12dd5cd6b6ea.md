
## 二、不确定性的推理计算

### 1 单条知识支持结论时，结论可信度的计算方法

结论H的可信度因子CF(H)不仅取决于证据E的可信度CF(E)，而且还取决于知识的可信度CF(H, E)。

计算公式为：

$$CF(H)=CF(H,E)\times\max\{0,\ CF(E)\}$$

### 2. 多条知识支持同一结论时，结论不确定性的合成计算

设有如下知识：

IF E₁ THEN H (CF(H, E₁))
IF E₂ THEN H (CF(H, E₂))

则结论H的综合可信度CF₁₂(H)：

1. 分别计算每一条知识的CF₁(H)和CF₂(H)：

CF₁(H)=CF(H, E₁) × max{0, CF(E₁)}
CF₂(H)=CF(H, E₂) × max{0, CF(E₂)}

2. E₁与E₂对结论H的综合影响所形成的可信度CF₁₂(H)：

$$
CF_{12}(H)=
\begin{cases}
CF_1(H)+CF_2(H)-CF_1(H)\times CF_2(H) & \text{若 } CF_1(H)\ge 0 \text{ 且 } CF_2(H)\ge 0 \\
CF_1(H)+CF_2(H)+CF_1(H)\times CF_2(H) & \text{若 } CF_1(H)<0 \text{ 且 } CF_2(H)<0 \\
\dfrac{CF_1(H)+CF_2(H)}{1-\min(|CF_1(H)|,|CF_2(H)|)} & \text{其他}
\end{cases}
$$

### 3. 在已知结论原始可信度的情况下，结论可信度的更新计算

- 当 \(0<\mathrm{CF}(E)\le 1\) 时：

$$
\mathrm{CF}(H\mid E)=
\begin{cases}
\mathrm{CF}(H)+\mathrm{CF}(H,E)\times\mathrm{CF}(E)-\mathrm{CF}(H)\times\mathrm{CF}(H,E)\times\mathrm{CF}(E) & \text{若 } \mathrm{CF}(H)\ge 0 \text{ 且 } \mathrm{CF}(H,E)\ge 0 \\
\mathrm{CF}(H)+\mathrm{CF}(H,E)\times\mathrm{CF}(E)+\mathrm{CF}(H)\times\mathrm{CF}(H,E)\times\mathrm{CF}(E) & \text{若 } \mathrm{CF}(H)<0 \text{ 且 } \mathrm{CF}(H,E)<0 \\
\dfrac{\mathrm{CF}(H)+\mathrm{CF}(H,E)\times\mathrm{CF}(E)}{1-\min(|\mathrm{CF}(H)|,|\mathrm{CF}(H,E)\times\mathrm{CF}(E)|)} & \text{其他}
\end{cases}
$$

- 当 \(\mathrm{CF}(E)\le 0\) 时，规则 IF E THEN H 不可使用，对结论 H 的可信度无影响。

### 例1 合成法求结论的可信度

设知识如下：

- IF E₁ THEN H，CF(H,E₁)=0.9
- IF E₂ THEN H，CF(H,E₂)=0.7
- IF E₃ THEN H，CF(H,E₃)=-0.8
- IF E₄∧E₅ THEN E₁，CF(E₁, E₄∧E₅)=0.7
- IF E₆∧(E₇∨E₈) THEN E₂，CF(E₂, E₆∧(E₇∨E₈))=1.0

已知：CF(E₃)=0.3，CF(E₄)=0.9，CF(E₅)=0.6，CF(E₆)=0.7，CF(E₇)=0.3，CF(E₈)=0.8。

求：CF(H)

![](img/e134d51e2ca4313e722468ebe37ad4b6_193_0.png)

CF(E₃)=0.3，CF(E₄)=0.9，CF(E₅)=0.6，CF(E₆)=0.7，CF(E₇)=0.3，CF(E₈)=0.8。

CF(E₁)=0.7×max{0, CF(E₄∧E₅)}
=0.7×max{0, min{CF(E₄), CF(E₅)}}
=0.42

CF₁(H)=0.9×max{0, CF(E₁)}
=0.38

CF(E₂)=1×max{0, CF(E₆∧(E₇∨E₈))}
=max{0, min{CF(E₆), max{CF(E₇), CF(E₈)}}}
=0.7

CF₂(H)=0.7×max{0, CF(E₂)}
=0.49

CF₃(H)=-0.8×CF(E₃)=-0.24

![](img/e134d51e2ca4313e722468ebe37ad4b6_194_0.png)

CF₁(H)=0.38　CF₂(H)=0.49　CF₃(H)=-0.24

**➤ 合成计算**

- CF₁(H)>0 且 CF₂(H)>0
- CF₁₂(H)=CF₁(H)+CF₂(H)-CF₁(H)×CF₂(H)
  =0.38+0.49-0.38×0.49
  =0.6838

又：CF₁₂(H)>0，CF₃(H)<0

$$
CF_{123}(H)=\frac{CF_{12}(H)+CF_3(H)}{1-\min(|CF_{12}(H)|,|CF_3(H)|)}=0.58
$$

### 例2 更新法求结论的可信度

已知：规则可信度为

- R1: A→X，CF(X,A)=0.8
- R2: B→X，CF(X,B)=0.6
- R3: C→X，CF(X,C)=0.4
- R4: X∧D→Y，CF(Y, X∧D)=0.3

CF(A)=CF(B)=CF(C)=CF(D)=0.5。

X、Y的初始可信度CF₀(X)=0.1，CF₀(Y)=0.2。

求：(1) 结论X的可信度CF(X)；(0.698)　(2) 结论Y的可信度CF(Y)；(0.32)

解：

(1) CF(X|A)=CF₀(X)+CF(A)×CF(X,A)-CF₀(X)×CF(A)×CF(X,A)
=0.1+0.5×0.8-0.1×0.5×0.8=0.46

CF(X|A,B)=CF(X|A)+CF(B)×CF(X,B)-CF(X|A)×CF(B)×CF(X,B)
=0.46+0.5×0.6-0.46×0.5×0.6=0.622

CF(X|A,B,C)=0.698

(2) CF(Y|X∧D)=CF₀(Y)+CF(X∧D)×CF(Y, X∧D)-CF₀(Y)×CF(X∧D)×CF(Y, X∧D)
=0.32

### 例3　更新法求结论的可信度

已知：规则可信度为

- R1：A₁→B₁，CF(B₁,A₁)=0.8
- R2：A₂→B₁，CF(B₁,A₂)=0.5
- R3：B₁∧A₃→B₂，CF(B₂,B₁∧A₃)=0.8

初始证据A₁、A₂、A₃的CF值均设为1，而初始未知证据B₁、结论B₂的CF值均为0。求：(1) CF(B₁)；(2) CF(B₂)。

![](img/e134d51e2ca4313e722468ebe37ad4b6_197_0.png)

解：由已知可得：CF(A₁)=CF(A₂)=CF(A₃)=1，CF(B₁)=CF(B₂)=0

(1) CF(B₁|A₁)=CF(B₁)+CF(A₁)×CF(B₁,A₁)-CF(B₁)×CF(A₁)×CF(B₁,A₁)
=0+1×0.8-0×1×0.8=0.8

CF(B₁|A₁,A₂)=CF(B₁|A₁)+CF(A₂)×CF(B₁,A₂)-CF(B₁|A₁)×CF(A₂)×CF(B₁,A₂)
=0.8+1×0.5-0.8×1×0.5=0.9

CF(B₁)=CF(B₁|A₁,A₂)=0.9

(2) CF(B₂|B₁∧A₃)=CF(B₂)+CF(B₁∧A₃)×CF(B₂,B₁∧A₃)-CF(B₂)×CF(B₁∧A₃)×CF(B₂,B₁∧A₃)
=0+0.9×0.8-0×0.9×0.8=0.72

CF(B₂)=CF(B₂|B₁∧A₃)=0.72

**另解：**

- $CF_1(B_1)=CF(B_1,A_1)\times\max\{0,CF(A_1)\}=0.8\times1=0.8$
- $CF_2(B_1)=CF(B_1,A_2)\times\max\{0,CF(A_2)\}=0.5\times1=0.5$
- $CF_{12}(B_1)=CF_1(B_1)+CF_2(B_1)-CF_1(B_1)\times CF_2(B_1)=0.8+0.5-0.8\times0.5=0.9$
- $CF(B_2)=CF(B_2,B_1\land A_3)\times\max\{0,CF(B_1\land A_3)\}=CF(B_2,B_1\land A_3)\times\max\{0,\min\{CF(B_1),CF(A_3)\}\}=0.8\times0.9=0.72$
