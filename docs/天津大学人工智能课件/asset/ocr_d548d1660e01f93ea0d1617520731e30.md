# # 四、产生式规则的选取

# ## 1.匹配

匹配方式：索引匹配、变量匹配、近似匹配、过滤匹配等。

# ## 2.冲突解决

例如，设在美式足球比赛中有两条规则：

规则R1：If 第四次开始进攻（Fourth down）且进攻方前三次进攻前进的距离少于10码（short yardage）then 可以在第四次进攻踢悬空球（punt）

规则R2：If 第四次开始进攻（Fourth down）且进攻方前三次进攻前进的距离少于10码（short yardage）且进攻位置在对方球门线30码之内（within 30 yards）then 可以射门（field goal）

# ## 3.操作

执行规则的操作部分。
