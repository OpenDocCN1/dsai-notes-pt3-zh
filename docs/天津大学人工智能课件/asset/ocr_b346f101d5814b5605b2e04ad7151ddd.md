# # WFF的基本等价式及推理规则（续）：

# ## 8 量词转换律

∼(∀x)P(x) ≡ (∃x)[∼P(x)]　　∼(∃x)Q(x) ≡ (∀x)[∼Q(x)]

# ## 9 易名规则

(∀x)P(x) ≡ (∀y)P(y)　　(∃x)P(x) ≡ (∃y)P(y)

在一个量化的表达式中的约束变量是一类虚元，它可以用任何一个不在表达式中出现过的其它变量符号来代替。

# ## 10 量词分配律

(∃x)[P(x) ∨ Q(x)] ≡ (∃x)P(x) ∨ (∃x)Q(x)

(∀x)[P(x) ∧ Q(x)] ≡ (∀x)P(x) ∧ (∀x)Q(x)

(∀x)[P → Q(x)] ≡ P → (∀x)Q(x)

(∃x)[P → Q(x)] ≡ P → (∃x)Q(x)

# ## 11 量词辖域变换等价式

(∀x)P(x) ∨ Q ≡ (∀x)[ P(x) ∨ Q ]

(∀x)P(x) ∧ Q ≡ (∀x)[ P(x) ∧ Q ]

(∃x)P(x) ∨ Q ≡ (∃x)[ P(x) ∨ Q ]

(∃x)P(x) ∧ Q ≡ (∃x)[ P(x) ∧ Q ]　　　　Q中不含变量
