# 3. 在已知结论原始可信度的情况下，结论可信度的更新计算

+   - 当 \(0 < \text{CF}(E) \le 1\) 时
+   
+   [\text{CF}(H \mid E) = \begin{cases} \text{CF}(H) + \text{CF}(H,E) \times \text{CF}(E) - \text{CF}(H) \times \text{CF}(H,E) \times \text{CF}(E) \\ \quad ; \text{若 } \text{CF}(H) \ge 0 \text{ 且 } \text{CF}(H,E) \ge 0 \\ \text{CF}(H) + \text{CF}(H,E) \times \text{CF}(E) + \text{CF}(H) \times \text{CF}(H,E) \times \text{CF}(E) \\ \quad ; \text{若 } \text{CF}(H) < 0 \text{ 且 } \text{CF}(H,E) < 0 \\ \frac{\text{CF}(H) + \text{CF}(H,E) \times \text{CF}(E)}{1 - \min(|\text{CF}(H)|, |\text{CF}(H,E) \times \text{CF}(E)|)} \\ \quad ; \text{其他} \end{cases}]

+   - 当 \(\text{CF}(E) \le 0\) 时，规则 IF E THEN H 不可使用，对结论 H 的可信度无影响。
