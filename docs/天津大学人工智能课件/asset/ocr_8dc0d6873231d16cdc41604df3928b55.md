# 例3　更新法求结论的可信度

已知：规则可信度为
R1：A₁→B₁　CF(B₁,A₁)=0.8；
R2：A₂→B₁　CF(B₁,A₂)=0.5；
R3：B₁∧A₃→B₂　CF(B₂,B₁∧A₃)=0.8

初始证据A₁、A₂、A₃的CF值均设为1，而初始未知证据B₁，结论B₂的CF值均为0。求：(1) CF(B₁)；(2) CF(B₂)。

![](bbox=[0.755, 0.125, 0.965, 0.506])

解：由已知可得：CF(A₁)=CF(A₂)=CF(A₃)=1　CF(B₁)=CF(B₂)=0

(1) CF(B₁|A₁)=CF(B₁)+CF(A₁)×CF(B₁,A₁)−CF(B₁)×CF(A₁)×CF(B₁,A₁)
=0+1×0.8−0×1×0.8=0.8

CF(B₁|A₁,A₂)=CF(B₁|A₁)+CF(A₂)×CF(B₁,A₂)−CF(B₁|A₁)×CF(A₂)×CF(B₁,A₂)
=0.8+1×0.5−0.8×1×0.5=0.9

> CF(B₁)=CF(B₁|A₁,A₂)=0.9

(2) CF(B₂|B₁∧A₃)=CF(B₂)+CF(B₁∧A₃)×CF(B₂,B₁∧A₃)−CF(B₂)×CF(B₁∧A₃)×CF(B₂,B₁∧A₃)
=0+0.9×0.8−0×0.9×0.8=0.72

> CF(B₂)=CF(B₂|B₁∧A₃)=0.72
