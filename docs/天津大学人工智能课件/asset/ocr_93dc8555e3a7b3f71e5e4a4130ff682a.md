# 例 设 \( U = \{ \text{red}, \text{blue}, \text{green} \} \)，

# \( 2^U \) 空间的8个子集：

\( A_0 = \Phi; \quad A_1 = \{ \text{red} \}; \quad A_2 = \{ \text{blue} \}; \quad A_3 = \{ \text{green} \}; \)
\( A_4 = \{ \text{red}, \text{blue} \}; \quad A_5 = \{ \text{red}, \text{green} \}; \quad A_6 = \{ \text{blue}, \text{green} \}; \)
\( A_7 = \{ \text{red}, \text{blue}, \text{green} \} \)

# 设定义一个概率分配函数，使各子集的概率分配：

\( M(A_4) = 0.2, \quad M(A_5) = 0.1, \quad M(A_6) = 0.2, \quad M(A_7) = 0.1 \)

+   \( M(\{ \text{red} \}) + M(\{ \text{blue} \}) + M(\{ \text{green} \}) = 0.4 \)

+   \( \text{Bel}(A_5) = M(\{ \text{red} \}) + M(\{ \text{green} \}) + M(\{ \text{red}, \text{green} \}) = 0.4 \)

+   \( \text{Pl}(A_5) = 1 - \text{Bel}(\sim A_5) = 1 - \text{Bel}(\{ \text{blue} \}) \)
+   \( = 1 - M(A_6) = 0.9 \)
