# # 一、DS理论的数学基础

信任函数、似然函数及类概率函数来描述知识的精确信任度、不可驳斥信任度及估计信任度

设\(U\)为样本空间，即\(U=\{q_1,q_2,\dots,q_n\}\)，则\(U\)的幂集合\(2^U\)中的元素个数为\(2^n\)，每个幂集合元素对应一个命题。

例 设\(U=\{red, green, blue\}\)，求\(U\)的幂集\(2^U\)。
解：\(U\)的幂集可包括如下子集：
\(A0=\phi\)，\(A1=\{red\}\)，\(A2=\{绿\}\)，\(A3=\{blue\}\)
\(A4=\{red, green\}\)，\(A5=\{red, blue\}\)，\(A6=\{green, blue\}\)，
\(A7=\{red, green, blue\}\)
其中，\(\phi\)表示空集，空集也可表示为\(\{\}\)。
上述子集的个数正好是\(2^3=8\)。
