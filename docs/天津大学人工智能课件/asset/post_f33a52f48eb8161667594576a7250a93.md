

## 四、确定性理论的优缺点

### 优点

- 计算简单，不要求统计基础。
- 可表达对每个阶段的信任与不信任。
- 可表达多种信任源的总效果。

### 缺点

- 在使用该方法的过程中，增加和删除知识库的知识，会引起现存知识的可信度因子的改变。
- 已知事实的集合——总数据库
- 组合规则的使用顺序不同，可能得到不同的结果。
- 当证据不存在时，证据对结论的影响就无法确定，即该方法无法处理由不知道引发的不确定问题。

## 第三节 主观Bayes方法

主观Bayes方法又称主观概率法，是R.O.Duda等人1976年提出的一种不确定性推理模型，它是对概率论中基本Bayes公式的改进，是一种基于概率逻辑的方法。

## 一、基本Bayes公式

设事件B₁、B₂、...、Bₙ是彼此独立、互不相容的事件，B₁∪B₂∪...∪Bₙ＝W(全集)，且P(Bᵢ)>0。对于任一事件A能且只能与B₁、B₂、...、Bₙ中的一个同时发生，而且P(A)>0。

[P(B_i \mid A) = \frac{P(A \mid B_i)P(B_i)}{\sum_{j=1}^n P(A \mid B_j)P(B_j)}]

P(Bᵢ)是事件Bᵢ的先验概率；P(A|Bᵢ)是事件Bᵢ发生条件下事件A的条件概率，P(Bᵢ|A)是事件A发生条件下事件Bᵢ的条件概率。

例 设 H₁、H₂、H₃ 分别为三个结论，E 是支持这些结论的证据，且已知：P(H₁)=0.4，P(H₂)=0.5，P(H₃)=0.2；P(E|H₁)=0.3，P(E|H₂)=0.4，P(E|H₃)=0.5。

求：P(H₁|E)，P(H₂|E)，P(H₃|E)。

解：

$$P(H_1|E)=\frac{P(E|H_1)P(H_1)}{P(E|H_1)P(H_1)+P(E|H_2)P(H_2)+P(E|H_3)P(H_3)}$$

$$=\frac{0.12}{0.12+0.2+0.1}=0.286$$

P(H₂|E)=0.476

P(H₃|E)=0.238

## 二、信任传递

### 证据间相互无关。

多个证据E₁、E₂、...、Eₙ和多个结论H₁、H₂、...、Hₘ，并且每个证据都以一定程度支持结论，则有：

[ P(H_i \mid E_1, E_2, \cdots, E_n) = \frac{P(E_1, E_2, \cdots, E_n \mid H_i)P(H_i)}{P(E_1, E_2, \cdots, E_n)} ]

[ = \frac{P(E_1 \mid H_i)P(E_2 \mid H_i) \cdots P(E_n \mid H_i)P(H_i)}{P(E_1, E_2, \cdots, E_n \mid H_1)P(H_1) + \cdots + P(E_1, E_2, \cdots, E_n \mid H_m)P(H_m)} ]

[ = \frac{P(E_1 \mid H_i)P(E_2 \mid H_i) \cdots P(E_n \mid H_i)P(H_i)}{\sum_{k=1}^m P(E_1 \mid H_k)P(E_2 \mid H_k) \cdots P(E_n \mid H_k)P(H_k)} ]

例 H₁: Rob感冒 H₂: Rob过敏 H₃: Rob光过敏 E₁: Rob打喷嚏 E₂: Rob咳嗽

已知先验概率和条件概率

|    | i=1(感冒) | i = 2(过敏) | i = 3(光过敏) |
|---|---|---|---|
| P(Hᵢ) | 0.6 | 0.3 | 0.1 |
| P(E₁|Hᵢ) | 0.3 | 0.8 | 0.3 |
| P(E₂|Hᵢ) | 0.6 | 0.9 | 0.0 |

P(H₁ | E₁) = \frac{P(H₁)P(E₁ | H₁)}{P(E₁)} ≈ 0.4 P(H₂ | E₁) = \frac{P(H₂)P(E₁ | H₂)}{P(E₁)} ≈ 0.53

P(H₃ | E₁) = \frac{P(H₃)P(E₁ | H₃)}{P(E₁)} ≈ 0.06

P(H₁ | E₁,E₂) = \frac{P(H₁)P(E₁ | H₁)P(E₂ | H₁)}{\sum_{k=1}^3 P(E₁ | P(E₁ | Hₖ)P(E₂ | Hₖ)P(Hₖ)} ≈ 0.33

P(H₂ | E₁,E₂) ≈ 0.67 P(H₃ | E₁,E₂) ≈ 0.0

## 四、主观Bayes方法的特点

主观Bayes方法对概率论中的Bayes公式进行了修正，并将其用于不确定推理，取得了很好的效果。它的缺点是，需要给出每个命题（包括初始证据、中间及最终结论）的先验概率，通过大量的统计和领域专家给出。

## 第四节 DS证据理论

D-S证据理论是60年代由Dempster提出，70年代由他的学生Shafer对他的理论进行扩充，形成了处理不确定信息的数学理论。该理论引进了信任函数(Bel)，这些函数可以满足比概率函数的公理还要弱的公理，因而可以用来处理由“不知道”所引起的不确定性。

> 既不相信事实A，也不相信事实~A

## 一、DS理论的数学基础

信任函数、似然函数及类概率函数来描述知识的精确信任度、不可驳斥信任度及估计信任度

设U为样本空间，即U={q₁,q₂,...,qₙ}，则U的幂集合2^U中的元素个数为2^n，每个幂集合元素对应一个命题。

例 设U={red, green, blue}，求U的幂集2^U。
解：U的幂集可包括如下子集：
A0=φ，A1={red}，A2={绿}，A3={blue}
A4={red, green}，A5={red, blue}，A6={green, blue}，
A7={red, green, blue}
其中，φ表示空集，空集也可表示为{}。
上述子集的个数正好是2^3=8。

## 一、DS理论的数学基础

### 1. 概率分配函数

函数M将[0，1]区间的一个值赋予2^U中每一个元素A。

M满足

\( M(\Phi) = 0 \quad \sum_{A \subseteq U} M(A) = 1 \)

A是U的一个子集，称命题；

M为2^U上的概率分配函数；

M(A)为命题A的基本概率数。

## 2. 信任函数Bel （ Belief Function ） 下限函数

Bel(A)=\(\sum_{B\subseteq A}M(B)\) Bel(U)=\(\sum_{B\subseteq U}M(B)=1\)

Bel(A)表示对命题A为真的总信任程度，是A的所有子集的基本概率数的和。

## 3. 似然函数 （ Plausiblebelief Function ） 下限函数

Pl(A)=1−Bel(∼A)=\(\sum_{A\cap B\neq\phi}M(B)\)

Bel(A)表示对命题A为真的信任程度，Bel(∼A)表示对A为假的信任程度。Pl(A)表示对A为非假的信任程度。

例 设 \( U = \{ \text{red}, \text{blue}, \text{green} \} \)，

# \( 2^U \) 空间的8个子集：

\( A_0 = \Phi; \quad A_1 = \{ \text{red} \}; \quad A_2 = \{ \text{blue} \}; \quad A_3 = \{ \text{green} \}; \)
\( A_4 = \{ \text{red}, \text{blue} \}; \quad A_5 = \{ \text{red}, \text{green} \}; \quad A_6 = \{ \text{blue}, \text{green} \}; \)
\( A_7 = \{ \text{red}, \text{blue}, \text{green} \} \)

# 设定义一个概率分配函数，使各子集的概率分配：

\( M(A_4) = 0.2, \quad M(A_5) = 0.1, \quad M(A_6) = 0.2, \quad M(A_7) = 0.1 \)

- \( M(\{ \text{red} \}) + M(\{ \text{blue} \}) + M(\{ \text{green} \}) = 0.4 \)
- \( \text{Bel}(A_5) = M(\{ \text{red} \}) + M(\{ \text{green} \}) + M(\{ \text{red}, \text{green} \}) = 0.4 \)
- \( \text{Pl}(A_5) = 1 - \text{Bel}(\sim A_5) = 1 - \text{Bel}(\{ \text{blue} \}) \)
- \( = 1 - M(A_6) = 0.9 \)
