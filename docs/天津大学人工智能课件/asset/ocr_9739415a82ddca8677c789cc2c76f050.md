# # WFF化为子句的基本步骤

+   1. 重复运用蕴含等价式，消去蕴含→  
+      \( P(x) \rightarrow Q(x) \Leftrightarrow \sim P(x) \lor Q(x) \)

+   2. 减少～的辖域，使～最多只作用一个谓词上  
+      \(\sim(P(x) \land Q(x)) \Leftrightarrow \sim P(x) \lor \sim Q(x)\)  
+      \(\sim(\forall x)P(x) \Leftrightarrow (\exists x)[\sim P(x)]\)

+   3. 变量改名  \( (\exists x)P(x) \Leftrightarrow (\exists y)P(y) \)

+   4. 移所有量词到前部，形成前束范式  
+      \( (\forall x)P(x) \lor (\exists w)Q(w) \) 改为 \( (\forall x)(\exists w)[P(x) \lor Q(w)] \)
