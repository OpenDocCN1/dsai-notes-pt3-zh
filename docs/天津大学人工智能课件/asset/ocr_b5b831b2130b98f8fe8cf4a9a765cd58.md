# 3. 与/或图搜索 AO*算法

(1) 设G仅由初始状态节点组成，称此节点为Init，计算h(Init)。

(2) 在Init 标为solved(成功)之前，或h(Init) 大于Futility(失败)之前，重复执行下述过程：

① 沿始于Init 的已带标记的弧，选出当前此路径上但未扩展的节点之一扩展(求后继节点)，新选的节点为node。

② 生成node的后继节点。若无后继节点，则h(node)=Futility，说明node不可解；若有后继节点，则称successor，对不是node祖先的每一后继节点，应做下述事项：

+   a) 把successor加到图G中。

+   b) 如果successor为目标节点，那么将其标记为solved，且h(successor)=0

+   c) 若successor不是目标节点，则计算h(successor)。
