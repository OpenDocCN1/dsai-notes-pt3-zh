# 使用频繁项集产生强关联规则

+   对一个频繁项集L<sub>k</sub>， 首先生产后项只有一项的所有规则，再产生后项有二项的规则，如此不断反复产生具有更多后项的规则。

+   conf ( A → B ) = P(B | A) = \(\frac{\text{sup port\_count (} A \cup B \text{)}}{\text{sup port\_count (} A \text{)}}\)

+   sup port\_count ( \( A \cup B \) )是包含项集 \( A \cup B \)的事务数；sup port\_count ( \( A \) )是包含项集 \( A \)的事务数；

由L = {I1,I2,I5}可以产生那些关联规则？ 设min_conf = 70%

I1^I2→I5 conf=2/4=50%

√I1^I5→I2 conf=2/2=100%

√I2^I5→I1 conf=2/2=100%

I1 → I2^I5 conf=2/6=33%

I2 → I1^I5 conf=2/7=29%

√I5 → I1^I2 conf=2/2=100%
