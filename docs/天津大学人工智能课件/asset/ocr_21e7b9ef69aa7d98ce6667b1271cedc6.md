# ## 2 合一

通过对项进行置换，使两个公式一致的过程。通过合一，可把若干个公式合为一个公式。合一的一般定义为：

设有公式集\(F=F_1, F_2, \dots, F_n\)，置换 \(\Phi\)，使得  
\(F_1 \|\Phi = F_2 \|\Phi = \dots = F_n \|\Phi\)

则称 \(F_1, F_2, \dots, F_n\) 是**可合一的**，且称 \(\Phi\) 为 \(F\) 的一个**合一**。

例 公式集 \(F=\{P[A, f(y)], P[x, f(B)]\}\) 的合一  
\(\Phi = \{A/x, B/y\}\)，  
使公式集成为单一形式 \(P[A, f(B)]\)
