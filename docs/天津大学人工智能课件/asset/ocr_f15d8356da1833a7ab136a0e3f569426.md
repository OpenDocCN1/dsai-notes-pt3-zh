# # 一、基本Bayes公式

设事件B\(_1\), B\(_2\), ..., B\(_n\)是彼此独立、互不相容的事件，B\(_1\cup\)B\(_2\cup\) ... \(\cup\) B\(_n\)= W(全集)，且P(B\(_i\))>0。对于任一事件A能且只能与B\(_1\), B\(_2\), ..., B\(_n\)中的一个同时发生，而且P(A)>0.

[P(B_i \mid A) = \frac{P(A \mid B_i)P(B_i)}{\sum_{j=1}^n P(A \mid B_j)P(B_j)}]

P(B\(_i\))是事件B\(_i\)的先验概率；P(A|B\(_i\))是事件B\(_i\)发生条件下事件A的条件概率，P(B\(_i\)|A)是事件A发生条件下事件B\(_i\)的条件概率。
