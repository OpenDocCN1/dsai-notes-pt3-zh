# WFF的基本等价式及推理规则现一并归纳于下：

+   1. **双重否定律**（否定之否定）　~（~P）≡P
+   2. **蕴含等价式**　P(x) → Q(x) ≡ ~P(x) ∨ Q(x)
+   3. **摩根定律**
+      - ~（P(x) ∨ Q(x)）≡ ~P(x) ∧ ~Q(x)
+      - ~（P(x) ∧ Q(x)）≡ ~P(x) ∨ ~Q(x)
+   4. **逆否律**　P(x) → Q(x) ≡ ~Q(x) → ~P(x)
+   5. **分配律**
+      - P(x) ∧（Q(x) ∨ R(x)）≡（P(x) ∧ Q(x)）∨（P(x) ∧ R(x)）
+      - P(x) ∨（Q(x) ∧ R(x)）≡（P(x) ∨ Q(x)）∧（P(x) ∨ R(x)）
+   6. **交换律**
+      - P(x) ∧ Q(x) ≡ Q(x) ∧ P(x)
+      - P(x) ∨ Q(x) ≡ Q(x) ∨ P(x)
+   7. **结合律**
+      - （P(x) ∧ Q(x)）∧ R(x) ≡ P(x) ∧（Q(x) ∧ R(x)）
+      - （P(x) ∨ R(x)）∨ R(x) ≡ P(x) ∨（Q(x) ∨ R(x)）
