➢ 令$L_k$为一组频繁项集，$C_k$为一组候选$k$-项集。发现所有频繁项集的算法Apriori可描述如下：

输入：数据库$D$；最小支持度$min\_sup$。

输出：$D$中的频繁项集$L$

```
1) $L_1\leftarrow\{频繁1-项集\}$;
2) for (k=2; $L_{k-1}\ne\Phi$; k++){
3)   $C_k$=apriori-gen($L_{k-1}$, $min\_sup$);
4)   for $t$=each transaction of $D$ {    // scan $D$ for count
5)     $C_t$=subset($C_k$, $t$)    // get the subset of t that are candidates
6)     for $c$ = each candidate of $C_t$
7)       $c$.count++}
8)   $L_k$={$c\in C_k\mid c$.count$\ge min\_sup$}
9) }
10) return $L=\bigcup_k L_k$
```
