+   - 支持度(support) 规则A→B在事务集D中成立，具有支持度s， 其中s是D中事务包含A ∪ B的百分比。
+   - 可信度(confidence) ，规则A→B在D中具有可信度c，即D中包含A的同时也包含B的百分比。

+   - support (A→B ) = P (A ∪ B )=包含_A_和_B_的数 / 事务总数
+   - confidence (A→B ) = P (B | A)
+   - 包含_k_个项的项集称为_k_-项集
+   - 项集的出现频率为包含项集的数，也称(支持)计数
+   - 频繁项集 _L<sub>k</sub>_ 项集满足最小支持度，也可利用项集的出现频率.
