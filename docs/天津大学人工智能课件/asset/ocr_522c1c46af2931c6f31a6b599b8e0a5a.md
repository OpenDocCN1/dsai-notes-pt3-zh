# ## 二、基于概率分配函数的不确定性推理

# ### 2 信任度函数

[ f(\text{A}) = \text{Bel}(\text{A}) + \frac{|\text{A}|}{|\text{U}|}[\text{Pl}(\text{A}) - \text{Bel}(\text{A})] ]

# ### 性质

+   1) [ \sum_{i=1}^{n} f(\{q_i\}) = 1 ]

+   2) 当 \(\text{A} \subseteq \text{U}\)，有 \(\text{Bel}(\text{A}) \leq f(\text{A}) \leq \text{Pl}(\text{A})\)

+   3) 当 \(\text{A} \subseteq \text{U}\)，有 \(f(\text{A}) = 1 - f(\sim \text{A})\)
