# ## 2 默认推理

利用默认规则的推理称为默认推理。人们在日常生活中的许多场合都应用着默认推理。默认规则也是人们信息传递的一种约定。

\(\left\{\text{鸟}(Rob); \frac{\text{鸟}(x):m\text{会飞}(x)}{\text{会飞}(x)}\right\} \rightarrow \text{会飞}(Rob)\)

\(\left\{\text{鸟}(Rob),\text{鸵鸟}(Rob); \frac{\text{鸟}(x):m\text{会飞}(x)}{\text{会飞}(x)},\text{鸵鸟}(x) \rightarrow \sim \text{会飞}(x)\right\}\)

\(\downarrow\)

\(\sim \text{会飞}(Rob)\)
