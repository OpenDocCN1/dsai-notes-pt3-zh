# 例　已知一个3个输入和1个输出的神经元，相应的输入值和权值以及阈值如图所示，求不同激活函数下的输出值。

解：

$$x=\sum_{i=1}^{3}w_i x_i-\theta$$

$$=0.3\times0.5+0.2\times0.5+0.5\times0.2-0.2$$

$$=0.15$$

+   - 分段线性函数
+   
+   $$f(x)=\begin{cases}0 & x<0\\x & 0\leq x\leq1\\1 & x>1\end{cases}$$
+   
+   $$y=x=0.15$$

+   - Sigmoid函数
+   
+   $$f(x)=\frac{1}{1+e^{-x}}\qquad y=f(0.15)=\frac{1}{1+e^{-0.15}}=0.54$$
