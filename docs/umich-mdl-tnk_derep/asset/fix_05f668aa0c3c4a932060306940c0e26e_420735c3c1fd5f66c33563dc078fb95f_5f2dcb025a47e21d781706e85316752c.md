# 把“猜不透”装进刻度：熵的用法地图

香农说，信息让疑问落地。我们常用“难猜”“消息多”“真意外”形容世界，这些感觉能不能换算成同一把尺？熵就是这把尺。它量的是结果揭晓前有多难料，并把难料程度、消息量、意外感绑在一起：熵值低，结局近乎按剧本走，知道了也补不了多少新知；熵值高，结局悬着，揭晓时既带情报也带冲击。

## 一、熵看的是可能性如何铺开，不是数值散得多开

熵和“数值散得多开”那个指标容易混淆，其实不是一回事。前者看机会如何分布，后者看极端数值有多远。举个例子：结果只能取1到8的整数。让熵冲顶的铺法，是八个数字各占一份机会；让波动量最大的铺法，则把一半机会压给1，一半压给8。一个追求“每张牌都可能”，一个追求“极端更大”。

## 四、用熵分成四档：静止、循环、乱序、繁复

用熵给一串按时间排出的记录分档，可以放进四类框架：静止、循环、乱序、繁复。桌上铅笔是静止；行星绕日是循环；掷铜板的记录是乱序；华尔街股价也近似乱序；大脑神经细胞放电则繁复——既非乱放，也非固定套路。

静止没有未知，熵为0；循环熵低，且不随日子改变；纯乱序熵最高；繁复夹在有序与无序之间，熵居中。两端容易判，中间两档常要结合判断。

给记录分档，可算各种长度小段的熵。假设某人每天只选A款或B款帽子，一年365条记录。先算长度1的熵：若两类帽子机会各半，熵为1，可排除静止；但他会换帽子，所以另三档仍可能。再算长度2到6的片段熵。若全冲顶，可排除简单循环。若片段变长时熵慢慢升至上限8，再长也不超过8——8相当于256条路径各占一份，这不像简单轮回，更像有结构的繁复过程。但也不能铁口直断：也许此人想装随机，却没成功。

## 五、熵峰与假设

做设定时，常要安放未知，于是得对可能性图谱作假设。原则是少拍脑袋。若对生成机制有了解，可先看机制、再看结构、最后看功能，推出统计形态。

例：拍卖总成交额是各标的之和，可借经典加法极限结论走高斯型；单栋房价值受卧室、浴室、占地等影响，也可走高斯型。但名画、旧抄本的价值，高斯型未必合理。它们的定价机制几乎摸不着，此时可选“让熵冲顶”的图谱。

熵峰形状受限制左右。只晓得下限与上限，等机会平铺型最不偏。很多社科研究爱用平铺型，真实世界里不多见；不过，不预设偏向的规矩能替它说话：既然只晓得区间，就别预先偏袒某段。

只知平均位置，且数值必须为正，熵峰会拖长尾：要把机会摊到更多档位，少量高档位得与大量低档位配平，于是得到指数衰减型。给网页访问量或品类占有率找默认形态时，它很自然。

已知平均位置和波动量，且允许负值，熵峰就是高斯钟形。制造边缘值能增加未知，但会推高波动量，于是要在中心附近补上更多档位，钟形由此出现。

**速查：**

- 平铺型——只给区间[a,b]时，熵到顶；
- 指数衰减型——只给平均位置μ时，熵到顶；
- 高斯型——给平均位置μ与波动量σ²时，熵到顶。

它们也能当探索工具。看到指数衰减或高斯形状，不必强迫追问背后是否真在增熵，但追问常带来新视角。前面用经典加法极限结论解释过生物的身长、重量与尺寸的钟形；这里再给机制解释：若变异倾向于把熵推高以试探最佳生存位置，且典型体量与总波动固定，体量图谱就会呈高斯型。要点不在哪种解释更优，而是“限制下让熵冲顶”必然导向钟形。因此钟形或许正是熵峰产物。

## 六、熵能做什么，也提醒我们什么

熵可量未知、消息、意外，又区别于数值离散幅度；还能分类比较。后文谈无规则漂移和历史锁定时，还会用它识别乱序、测量锁定程度。实际用途很广：看监管动作让市场更迷还是更清楚；检验投票、球赛、彩票结果是否真乱。

这里熵是实证尺：描述世界怎样，不规定世界该怎样。系统熵值高低本身不分好坏，要多少看场景。设计税制时，可能想要稳定行为、不要乱序；做城市设计时，又盼着繁复，静止或轮回都太寡淡。城市要有生气，就得给不期而遇与交流留余地。这时熵多一点更好，但不能过头；纯乱序会让计划失灵，也会把认知压垮。最舒服的状态，是让世界保持有节制的繁复，让人活在有故事的年头。

有位建筑学者提出：主心骨明确、界线有厚度、空间彼此咬合，这类几何安排能孕育出活的房屋、街区与聚落。他偏爱空间里的繁复。央行做计划的人未必爱繁复，在市场里或许更想要看得准的稳定结局。好在借工具，繁复与稳定都能摊开来讨论。
