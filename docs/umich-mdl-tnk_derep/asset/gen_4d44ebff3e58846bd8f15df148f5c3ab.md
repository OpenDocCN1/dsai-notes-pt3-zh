# 房价公式里的通勤账本：一分钟值多少钱，价格战又为何分“拥挤”和“稀疏”

一套房价拟合式，乍看只是几个数字相加，背后却藏着一笔很生活的账：  
**房屋价格 ≈ 100×面积 + 20000×卧室数 − 2000×通勤分钟数。**

它给出的估计是：面积每多1平方英尺，房价约多100美元；每多一间卧室，价格约高2万美元；而通勤每多1分钟，房子价值约少2000美元。假设买下房子后住20年，这20年里上班总天数大约4000到5000天。按较低值4000天算，如果每天通勤能省1分钟，20年就能省出4000分钟，也就是60多个小时。于是，2000美元这个估计值大约折合每小时30美元。换句话说，人们为了住得离上班地点更近而多付的钱，就好像是在花30美元买“一小时不堵车”。¹⁵

## 两种偏好，拼成一个混合模型

空间竞争模型和享受竞争模型，差别在于它们怎么表达人们对属性的偏好。空间竞争模型里，每个人对每种属性都有一个理想水平，某个选项越靠近他的理想点，他就越觉得有价值；享受竞争模型里，则是某个属性越多或越少，人们就越喜欢。

现实中的消费品和服务、理想的生活伴侣、公共政策、宗教，乃至求职者，往往同时带着空间属性和享受属性。比如薯条，每个人喜欢的脆度可能不同，但所有人都希望每份食品价格更低——脆度是空间属性，价格是享受属性。再比如雇主招人，不同企业偏爱的人格类型可能不一样，有的更看重外向，有的更欣赏内向，但几乎所有企业都喜欢诚实正直的人——个性类型是空间属性，诚实正直是享受属性。

把两类属性放进同一个框架，就得到混合模型。它能用来分析市场进入、产品差异化竞争，以及价格竞争到底有多激烈。前面巧克力棒的例子就可以这样用：打算进入巧克力棒市场的企业，先把三种现有产品放进属性空间，再通过消费者问卷了解理想点分布，进而估计新产品能覆盖的沃罗诺伊邻域。如果这个邻域里的消费者太少，就别指望产品会热销。

这套方法不只适用于巧克力棒。一个靴子设计师可以把市面上所有绝缘靴的设计图铺开来看，或许会发现几十种设计里竟没有一款用闪亮漆皮；一个开发待办事项列表手机应用的人，也可以列出现有同类应用的功能，估计市场总需求，并预测可能的销售额。

## 降价像移动分割线：稀疏市场和拥挤市场大不相同

降价可以看成分割线在移动。图20-3展示过两种巧克力棒的情形：分割线对应那些在A与B之间无差异的消费者理想点。如果B巧克力棒降价，而消费者又更愿意少花钱得到同样多的糖果，那么分割线就会向A移动，B的市场份额随之扩大。B降价会扩大份额，这不用模型也能猜到；但影响到底有多大，就需要模型来估计。关键是把拥挤市场和稀疏市场分开：前者是在低维属性空间里挤进大量产品，后者是市场中只有很少的竞争对手。拥挤市场中，每种产品只占一个小小的沃罗诺伊邻域；稀疏市场中，邻域则大得多。

图20-9显示的是B巧克力降价10%的影响，假设价格从每根2美元降到1.8美元。左图是稀疏市场：B与A之间的分割线移动后，B的份额从50%提高到54%，相对增幅约8%。价格降了10%，销量却只增8%，合起来销售收入反而减少3%。所以在这种市场里，降价不是好主意。右图是拥挤市场，市场中有7种不同的巧克力棒：B的份额从15%升到20%，绝对增幅是5个百分点，但折合相对增幅约33%，最终销售收入增加了20%。

由此，模型的预测是：拥挤市场里的价格竞争，比稀疏市场里的价格竞争影响更大；大宗商品^((7))市场上的价格竞争则可以称为“极端的竞争”，影响最大。模型还预测，高端时尚商品很少出现价格战，因为产品的高维性会创造出一个稀疏市场，设计师能够维持较大的价格加成。

属性数量与价格竞争激烈程度之间的这层关系，说明增加新属性是个好策略：市场会变得更稀疏，价格竞争会降温，利润也可能更高。但这件事说起来容易做起来难。消费者必须真的给新属性较高估值，否则策略落空。事实上，每一个成功的新属性出现，比如无绳立体声扬声器，背后都藏着多次失败尝试的历史，比如比克公司那些命运多舛的一次性产品。

## 模型有用，但不是答案本身

空间竞争模型、享受竞争模型以及两者的混合模型，提供了一个很好的框架：我们可以用它来表征不同产品、政治候选人，甚至求职者；可以测量意识形态“位置”、隐含价格属性，并评估潜在的市场进入者。它们带来的洞见包括：市场竞争如何产生差异化激励，政治竞争如何产生建立联盟的激励，以及为什么属性较少的产品价格竞争会更激烈。

不过，这些模型也做了相当强、从经验上看相当可疑的假设。比如前面的模型假设人们偏好不变，也不会屈服于社会压力。若真是如此，企业和政客为什么还要花大量金钱和资源去改变消费者和选民的偏好？面对这种批评，可以再次引用博克斯的格言：所有模型都是错的。

更精细的回应，是区分基本偏好与工具偏好。前者是人们的欲望，即想得到什么；后者是人们对能够产生根本性结果的属性的偏好。一个学生的基本偏好，可能是在受欢迎、身体健康和学术成就之间保持平衡。为了这些根本目标，他可能早起、喝果汁、尽快写完作业，以保证晚上有时间参加社交活动。此时，他对水果奶昔的选择就是工具性的，因为奶昔有助于实现健康这一基本偏好。可如果某天他看到科学论文说水果奶昔糖分很高、不利于健康，他可能改喝饮用水。工具偏好变了，基本偏好却没变。由此可见，模型本身不是目的，它只是帮我们构建思维的一个框架。

## 价值从哪里来：享受、协调与预测

在市场经济中，一件商品对一个人的价值，可以通过他愿意支付的价格来衡量。有人可能认为一个五香熏牛肉三明治值7美元，戈雅^((8))的一幅画值300万美元，佛罗里达州奥卡拉市的一块土地值75000美元。但许多经济模型忽略了这些估值从何而来。美国经济学家乔治·施蒂格勒引用过陀思妥耶夫斯基《卡拉马佐夫兄弟》中米蒂亚的那句话：“De gustibus non est disputandum。”意思是，口味各异，难言好坏。我们这里讨论的模型，确实较少讨论口味本身，更多讨论口味如何转化为人们赋予商品的货币价值。

**享受模型**从商品的内在属性解释价值。估值的差异，取决于人们对商品属性的不同潜在偏好。这些属性可以是商品的物理组成部分。比如一个五香熏牛肉三明治，包含黑麦面包、五香熏牛肉、瑞士奶酪、芥末、泡菜和洋葱，它的价值可以写成这些组成部分价值的加权线性组合。更精细的享受模型还能加入交互项：如果和烤黑麦面包一起售卖，五香熏牛肉可能更有价值。

**协调模型**把价格解释为社会建构的。戈雅画作的价值，取决于其他人是否相信它真有那么高的价值。最初，人们对戈雅画作的价值有自己的看法；随后，他们与社会网络中的其他人互动并更新看法。两个人可以把价值设为两人估价的平均值，一个人可以改变自己的估价去匹配另一个人给出的价值，每个人也可以根据其他人的估价调整自己的估价。无论采用三种假设中的哪一种，估价都可能实现局部收敛。这样，相互有联系的人会形成相似的估值。商品最终被赋予的价值，取决于初始分布、社会网络以及配对发生的顺序。

**预测模型**则把价格解释为对未来价值的预测。按这种模型，奥卡拉市的土地、比特币或股票的价值，都取决于人们将来愿意为它们付多少钱。这些估值取决于预测模型，而预测模型又取决于属性和类别。我们可能把奥卡拉市归类为气候温暖、税率很低、非沿海的城市。人们估值的变化，源于不同的预测模型。投资者会使用多种预测模型：它们可能依赖属性，也可能像比特币估价那样，对协调做出假设。

说到底，这些模型不是要给市场写一份“标准答案”，而是提供多种观察角度：看通勤如何被定价，看产品如何靠属性差异避开价格战，也看价值如何在个人偏好、社会互动和未来预期之间被塑造出来。
