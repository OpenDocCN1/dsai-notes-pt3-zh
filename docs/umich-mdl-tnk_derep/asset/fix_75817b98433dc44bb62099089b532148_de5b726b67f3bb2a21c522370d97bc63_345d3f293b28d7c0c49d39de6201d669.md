# 喝醉的人能摸回家，喝醉的鸟未必：别把噪声当规律

数学家角谷静夫打过一个比方：人喝多了，往往还能摸回自家门口；换成一只喝醉的鸟，它可能再也找不到窝。这个画面，恰好对应一维与三维随机行走的差别。概率论和统计学里有两位“老演员”——伯努利瓮与随机行走。它们看着能长出复杂花纹，骨子里却是随机过程。若不拿数据检验，人很难分辨随机性。选举结果、股票涨跌、球赛比分里，我们总想从噪声中抠出秩序，结果常常落空。塔勒布有句俏皮话：许多人其实是被随机性戏弄的傻瓜。

先看伯努利瓮。想象一只坛子，里面混着灰球与白球。每轮闭眼摸一个，记下颜色，再放回。前后轮互不影响。摸很多次后，某色出现的频率会向坛中占比靠拢——这是大数定律。别误会：7白3灰的坛子摸1000回，并不保证正好700白；它说的是比例会逐渐贴近七成。把灰球占比记作[PRE0]；抽N轮时，灰球个数的均值与波动可用公式算，波动量由[PRE1]给出，完整式子见[PRE2]。

连续同色会形成“串”。若白球出现概率为P，那么连着N次都白，概率就是P的N次方。这个算法很实用：某段惊人连胜到底只是巧得离谱，还是几乎不可能、该怀疑作弊？篮球例子：顶级三分手打十年，想连中9记三分都近乎天方夜谭。投资也可照此检验。伯克希尔·哈撒韦在1965—2014这50年里，有42年跑赢大盘；1964年投1美元，到2016年超过1万美元；同期标普500的1美元约变23美元。若每年胜率只有五成，50年该赢约25次，波动幅度为3.5年[PRE3]。实际胜出年数比均值高约四个波动单位，概率只有约0.0001%，纯靠运气说不通；加上公司定期披露持仓，欺诈也难成立。反观麦道夫，从不公开投资明细；若客户坚持要透明度，他那种连续几十年正回报的“神话”根本演不下去。

随机行走是在抽球罐上再加一条：把历史结果累计起来。起点记0；摸白加1，摸灰减1；当前值就是白球累计减灰球累计。写成式子：V_{t+1}=V_t+R(-1,1)，V0=0，R取±1。任意时长内，期望值都是0，波动幅度为[PRE4]，t是轮数。下面这张图（[PRE5]）画了300轮简单随机行走：乍看像先跌后涨、越过零轴时还崩了一下，其实全是偶然，并非隐藏模式。这个模型可描述气体液体中的微粒、动物在空间里的移动，也能描述孩子从出生到童年的身高变化。

简单随机行走有两个脾气：会反复回到原点，也会越走越远、没有上限。时间够长，它能高过正一万，也能低过负百万，还会无数次穿过零线。回到起点所需步数的分布服从幂次法则：多数时候几步就回；全部过程中约一半只走两步便归零；也有少数要等很久。比如某次行走越过百万步才到达某阈值，那它返回零点的路程也要再花百万步以上。幂次法则还能解释一些意外现象。把企业销售额或雇员数看成随机行走：生意好添人，生意差裁人，裁到零就关门。于是“回到零”的等待时间分布，对应企业寿命分布，第一近似就是幂次法则。生物分类单元的存续也可套用：某属内物种数随机增减，则该类群规模应呈幂次分布，实测数据支持这个判断。冰川也能类比：冰体沿地面推进又退回，每次回落形成湖泊，湖水直径与返回时间相关，湖泊大小分布也应呈幂次法则，观测与模型大体吻合。

模型可改造。若每轮增量来自高斯分布，就得到高斯型随机行走；它未必精确归零，但会无限次穿过零点。若让两种结果概率不等，就得到有偏随机行走，可用来算赌博胜率。轮盘赌押红色，赢面为9/19（约47.4%），输面10/19。押100轮，平均亏5美元，波动10美元；有95%把握，亏损不超过25美元、盈利不超过15美元。押一万轮，平均亏526美元，波动100美元；95%区间是亏325至725美元。此时还能盈利，相当于超过均值五个波动单位，概率低于0.0001%。所以轮盘赌想赢，应该押一大注，而不是拆成许多小注。篮球赛可看成两条有偏随机行走：每队每个攻防回合都有得分机会，概率由进攻与防守能力决定。NBA数据表明，实际比分与模型贴合不错。只有一方大幅领先后，得分才偏离随机：领先继续扩大的可能性反而低于被追近，可解释为领先方松劲、落后方要保住颜面。模型还提示策略：强队应提速，增加回合数；占优方更愿多“摇轮盘”，因为随机偏移对它有利。

维度很关键。一维简单随机行走之外，还有二维版本：从(0,0)出发，每轮向东、南、西、北随机迈一步，像纸上弯弯曲曲的线。二维同样会反复回到起点，也没有边界，类似在客厅里乱找一只掉落的耳环。正因为会反复覆盖旧路，蚂蚁才可把随机觅食当成策略；若二维不回归，蚂蚁就得靠复杂内地图或更强信息素才能回巢。到了三维，情况突变：随机行走不再保证回归。屋里乱飞的苍蝇、空气中弹跳的分子，回到出发点的次数有限。角谷静夫那句醉鸟比喻，说的就是这个。这里直觉会骗人：人们以为维度增加只是少回几次，数学却给出“一刀切”的转折——一维二维必定无限次回家，三维则可能长期在外流浪。只靠直觉推不出来，必须算。

低维回归性还能估图的体量。做法：随便选一个顶点，沿边随机走，记录隔多久回到出发顶点；平均回归时间与图的规模有关。比如估社交图大小，可请某人报出一位联系人，再请这位联系人报下一位，如此接力，看多久绕回同一人。图[PRE6]给了两例：左侧三个顶点围成三角环，从A出发可能A→B→C→A，三步就回；右侧六个顶点、两个三角环，从D出发可能要走七步（F→G→H→F→E→F→D）。重复多次，左图平均回归显然更短。小图未必需要这招，但全球网页图、巨型电邮图谱这类庞然大物就很管用。

股票价格呢？大量证据显示，标的走势接近带正向偏移的高斯型随机行走，正向偏移对应市场平均收益；不少个股也接近随机。图[PRE7]展示脸书（Facebook）2012年5月18日上市后一年的每日价格：挂牌价42美元，2012年6月1日跌到28.89美元，十二个月后收于24.63美元；图中还叠了一条变差相近的随机行走。对脸书这段价格轨迹做统计检验：249个买卖日中127天收跌，占51%；相邻两日涨跌方向相同的比例是54%；按模型，最长同向串约为8天，而这一年实际出现过10个买卖日连涨。总体看，不能拒绝“脸书价格与高斯型随机行走一致”的假设。

所有股票的日价格也可做类似分析，但先要剔除平均上涨趋势。研究显示，20世纪50—80年代，日价格略有正相关；去趋势后，一天上涨后再涨的概率略高于50%。80年代以后，投资者更精，这个概率降到50%，与随机行走吻合。为什么价格会随机？因为聪明钱会识别并抹平模式。90年代分析师发现价格常在年初走强，英文常叫“January effect”；有人想年末买入、次年年初卖出套利。可这策略好得不真实：大家都年末买，价格被推高，效应反而消失。经济学家用“地上捡钱”打比方：只要看见，就会有人捡走；价格模式一旦存在也会被交易掉。一个由聪明人构成的市场，几乎不会留下可预测的规律，所以除去普遍上行趋势后，价格只能像随机行走。

萨缪尔森构造过能生成随机行走的模型。他不要求投资者预知未来各期股票价值，只要求知道其分布。他提醒：“人们不能过于迷信现有的定理，它不能说明实际的竞争性市场运作良好。”后来有人把这种思想扩展成市场有效性理论：任何时点，价格已吸收全部相关信息，未来变化必然随机。该理论有个自相矛盾处：要定出准确价格，分析师得花时间收集数据、建模；若价格真随机，这些努力得不到回报。可若无人研究价格，价格又会失真，路边又会到处是无人捡的钱。格罗斯曼—斯蒂格利茨悖论说的正是这个循环：大家相信市场有效，就停止分析，市场反而低效；大家认为市场低效，就拼命分析，市场反而更有效。

现实里，价格变动确实与随机行走相当接近，尽管复杂统计能挖出一些短期规律。也就是说，路边未必遍地无人捡的钱，但草坪上偶尔也能找到幸运草，前提是你够努力。批评者还指出，一些投资者长期跑赢市场的时间长到不像是巧合。此外，价格随机波动也可能来自复杂交易规则的合力；日常波动幅度超过信息流入量，现实世界看似无事，股市也会大起大落，这提示泡沫。对某人是坏消息，对另一人可能只是“尽管有问题，但……”。波动大，微小信息也能掀起巨浪；即便市场剧烈起落，仍可能服从长尾随机行走——日波动来自长尾分布。说价格永远精准当然不可信，但长期看，价格不会离真实价值太远。72法则可作证：经济年增速3%，五十年约翻四倍。1967年美国国内生产总值按2009年美元约4.2万亿，2017年近17万亿，正好约四倍；同期标普500实际价值也涨约四倍。若股市每年实际涨12%，五十年价格会膨胀256倍，这显然不可能。
