# 别急着找规律：从伯努利瓮到随机游走，世界可能只是“随机漫步的傻瓜”

角谷静夫有句妙语：醉汉总能摸回家，醉酒的小鸟却可能永远找不到巢。这句话背后，藏着一维和三维随机游走的差别。概率论与统计学里有两个经典模型——伯努利瓮模型和随机游走模型。它们表面上会生成复杂结构，骨子里却是随机过程。若不去收集数据，随机性往往很难识别。我们总爱从选举结果、股价涨跌、体育比分里总结模式，但很多时候只是一厢情愿。风险分析师塔勒布调侃得好：我们都是“随机漫步的傻瓜”。

伯努利瓮模型用来描述抛硬币、掷骰子这类离散随机结果。它几个世纪前出现，最初是为了算清赌注胜率，如今已是概率论的核心工具之一。模型很简单：瓮里装灰球和白球，每次随机抽一个，结果就是球的颜色；抽完放回，所以每次抽取与前后无关。大数定律告诉我们：长期看，抽出某种颜色的比例会收敛到它在瓮中的比例。注意，这不是说7白3灰的瓮抽1000次就恰好700白，而是白球比例会向70%靠拢。设灰球比例为[PRE0]，抽N次时灰球期望数量与标准差可按模型计算，标准差为[PRE1]，具体表达式见[PRE2]。

伯努利瓮还会产生可预测长度的“条纹”。若白球概率为P，连续抽到N个白球的概率就是P^N。用这个概率，我们能判断某段连续结果只是巧合得惊人，还是几乎不可能、基本可断定“有诈”。比如篮球运动员连续9次命中三分，是热手效应吗？数学表明，一位很优秀的三分手在10年职业生涯里，连续9次三分命中也几乎完全不可能。类似计算还能帮我们判断投资者是运气、能力还是欺诈。巴菲特执掌的伯克希尔哈撒韦在1965—2014年的50年里有42年跑赢市场；1964年的1美元到2016年超过1万美元，而投标普500的1美元约值23美元。如果每年击败市场的机会只有50%，50年应跑赢约25次，标准差为3.5年[PRE3]。实际跑赢年数约高出均值四个标准差，概率仅百万分之一，因此可排除纯运气；公司定期公布投资，也可排除欺诈。相反，麦道夫从不透露投资，若客户要求透明度，他不可能连续几十年“成功”、连续几十年正回报。

简单随机游走建立在伯努利瓮上，并把过去结果的和保留下来。初始值设为零：抽到白球加1，抽到灰球减1；任一时刻状态等于白球总数减灰球总数。用式子说，V_{t+1}=V_t+R(-1,1)，其中V0=0，R取±1。任何时间段内，随机游走期望值都是零，标准差为[PRE4]，t为周期数。图[PRE5]给出一个300周期的简单随机游走：看起来先长期下降、再上升，上升越过零线时还有一次适度崩溃，但这只是偶然，不是模式。这个模型能刻画液体和气体中粒子的运动、动物在物理空间中的活动，以及人从出生到童年的身高增长等。

简单随机游走既周期性又无界：它会无限次回到零点，也会超过任何正的或负的阈值。等得足够久，它可能高于正1万、低于负100万，还会无数次穿过零线。返回零点所需步数的分布满足幂律：多数时候几步就回，所有游走中有一半是两步返回；但有些游走要很久。比如超过100万步阈值的游走，需要超过200万步才能到达那里并返回零。幂律还有意想不到的用武之地。把企业销售或员工规模建模为随机游走：销售强劲招一名员工，销售不佳裁一名员工，没有员工时企业“寿终正寝”。这样返回次数分布就等于企业生命周期分布，且第一近似为幂律。类似逻辑可预测生物分类单元（界门纲目科属种）的寿命：若某分类单元成员数量随机上下，其大小就应满足幂律，数据支持。冰川类比也适用：冰川沿地面移动，每次落到陆地表面以下再返回顶部，就形成一个直径等于返回时间的湖泊，湖泊大小分布应满足幂律，相关数据与模型基本对应。

正态随机游走是另一种修正：每一周期值的变化服从正态分布。它不会完全回到零点，但会无限次穿过零点。还可以让一种结果比另一种更可能，得到有偏随机游走，用来预测博彩胜率。以轮盘赌为例，增加1的概率为9/19（约47.4%），减少1的概率为10/19。下注100次，预期损失5美元，标准差10美元；95%置信水平下损失不超过25美元、收益不超过15美元。下注1万次，预期损失526美元，标准差100美元；95%置信水平下损失在325—725美元之间。此时还能赢，是超过均值5个标准差的事件，概率不到百万分之一。所以想在轮盘赌中赢，正确做法是下一大注，而不是下很多小注。篮球比赛也可看作两个有偏随机游走：每队每回合都可能得分，概率可由进攻和防守能力估计；NBA数据分析显示实际结果与模型匹配得相当好。只有一支球队大幅领先时，得分才偏离随机性——领先优势继续扩大的可能性低于缩小的可能性，这可以解释为领先方失去继续得分动力、落后方至少要挽回颜面。模型还给出策略：更强球队应加快节奏，创造更多进攻回合；优势方应更频繁地“轮盘赌”，因为随机漂移对它有利。

简单随机游走只在一维。二维随机游走从(0,0)出发，每周期随机往东、南、西、北走；它像纸上一条弯曲线，也满足递归性和无界性，有点像在起居室随机找一只丢失的耳环。正因为递归，随机觅食才成为蚂蚁的一种策略；若二维不递归，蚂蚁就需要更复杂内部地图或更强信息踪迹才能回巢。三维情况则不同：随机游走不再递归。房间里乱飞的苍蝇、空气中弹跳的分子，只会有限次返回起点。这就是角谷静夫说醉酒小鸟可能永远回不了家的原因。随机游走的无递归性很好地说明模型如何改变思考：直觉以为维度增加只是减少返回次数，逻辑却显示会出现突变——一维二维无限次回起点，三维则“永恒在外游荡”。这个结果必须靠数学，不能只靠直觉。

低维随机游走的递归性还能估计网络规模：随机选一个节点，沿边随机游走，记录它回到初始节点的频率；平均返回时间与网络规模相关。比如估计社交网络大小，可让某人指定一个朋友，再让那个朋友说一个朋友，一直继续，看多久回到同一个人。图[PRE6]中，左边网络3个节点组成三角形，从A出发可能A-B-C-A，3步回起点；右边网络6个节点、两个三角形，从D出发可能要走7步（F-G-H-F-E-F-D）。重复多次，左网络平均返回时间显然更短。小型网络未必需要这方法，但万维网或大型电子邮件网络等大型网络会非常有用。

股票价格呢？事实表明，股价接近带正漂移的正态随机游走，正漂移带来市场收益；许多个股价格也接近随机。图[PRE7]展示Facebook在2012年5月18日IPO后一年的每日股价：发行价42美元，2012年6月1日跌到28.89美元，一年后进一步降至24.63美元；图中还画了一个校准为类似变差的随机游走。对Facebook股价序列做统计检验：249个交易日里127天下跌，占51%；连续两天同向变动占54%；持续同向最长波动应为8天，但这一年曾连续10天上涨。总体看，不能否认Facebook股价与正态随机游走一致的假设。

同样的分析适用于所有股票日交易价格，但要先去除平均上涨趋势。研究显示，20世纪50到80年代每日股价略有正相关；去趋势后，一天上涨后再上涨的概率略超50%。80年代后投资者更精明，这个概率降到50%，与随机游走完全一致。为什么股价可能遵循随机游走？因为聪明投资者会识别并消除模式。20世纪90年代，分析师发现股价往往年初上涨，称为“一月效应”；投资者可在12月低价买、来年1月卖获利。可这策略好得不像真的：若大家都在12月买，价格会被抬高，一月效应反而被抵消。它消失并不奇怪。经济学家把人行道上的百元钞票作类比：有人看到就会捡，钞票随即消失；股价模式也一样，存在就会被利用而消失。充满聪明投资者的市场几乎不会留下可预测价格模式，价格也就只能像随机游走（当然要先去掉一般上行趋势）。

萨缪尔森构建过一个能生成随机游走的模型。他的模型不要求投资者知道未来所有期间的股票价值，只要求知道股票价值的分布。萨缪尔森说：“人们不能过于迷信现有的定理，它不能说明实际的竞争性市场运作良好。”一些经济学家把随机游走思想扩展为有效市场假说：任何时刻股价都反映所有相关信息，未来价格必遵循随机游走。这个假说依赖一个自相矛盾的逻辑：要确定准确价格，财务分析师必须花时间精力收集数据、构建模型；若价格真是随机游走，这些活动就得不到预期回报。可如果没人花时间精力估价格，价格就会不准确，人行道上又会铺满百元钞票。格罗斯曼和斯蒂格利茨悖论正强调这一点：投资者相信有效市场，就会停止分析，市场反而低效；投资者认为市场低效，就会用模型分析，市场效率反而提高。

事实上，股价变动与随机游走相当接近，尽管复杂统计技术能揭示某些短期模式。也就是说，人行道未必铺满百元钞票，但草地上确实能找到一些四叶草，只要足够努力。批评有效市场假说的人还指出，不少投资者持续战胜市场的时间明显不能用偶然解释。此外，股价随机波动也可能来自其他原因，比如复杂交易规则的总体影响；日常波动性超过流入市场的信息量，现实世界似乎没发生什么大事时股市也会大幅飙升或跳水，这提示泡沫存在。对某人很不利的事件，对另一人也许只是“尽管有这些问题，但是……”。波动性确实高，很少的信息也可能产生很大影响；即便市场大幅飙升或跳水，它仍可能遵循长尾随机游走——日常波动源于长尾分布。股价始终准确的说法令人难以置信，但长远看，价格确实不会与真实价值相差太远。72法则可证明：经济每年增长3%，半个世纪总量增长4倍。1967年美国GDP相当于今天的4.2万亿美元（按2009年美元计算），2017年增至近17万亿美元，正好约4倍；同期标普500实际价值也增加约4倍。若股市每年实际上涨12%，价格会增256倍，这应该不可能。
