# 为什么我们总在“烧钱”证明自己？

一个人很难把真实的自己完全藏住。穿什么、开什么车、喝什么酒、给谁捐款、在朋友圈晒出什么学历，往往都在替我们“说话”。这背后就是信号模型：人用有代价的举动，把别人看不见的属性——财富、体力、智力、慷慨、立场——亮出来。关键不在于嘴上怎么说，而在于这个信号敢不敢让自己“肉疼”。

早在19世纪，凡勃仑就用“炫耀性消费”点破过这层窗户纸：人们买高价商品，不只是为了享受，也是在展示社会位置。迈巴赫敞篷车、年份香槟、昂贵相机，都是今天的注脚。为什么这类行为长久不衰？因为我们看不清一个人的“隐藏属性”，只好借衣服、车子、酒和捐款来推断。向慈善机构大笔捐款，等于告诉外界“我慷慨”；在社交平台宣布拿到理论生物学博士，等于释放智力与职业信号。几乎每个行动都带点信号味。政客投票宣战还是制裁，也在暴露意识形态；有长期打算的人，甚至可能为了未来竞选前途而投出“有利信号票”，未必选最优政策。

但信号要管用，必须有成本，或者能被验证。求职者都说自己会西班牙语，这句话本身不值钱。雇主若搞一个“西班牙语徽章”，要求用西语做一小时演示，真会的人准备成本低，不会的人成本高得吓人，徽章就把两类人分开了。这就是信号模型的基本逻辑。

## 离散信号：发，还是不发

离散模型里，人只能二选一：发信号，或者不发。假设人群中有“强者”和“弱者”，发信号成本分别是 c 和 C，且 c<C；所有发信号者平分收益 B。结果有三种：

- **混同 [PRE0]**：两类人都发信号；
- **分离 [PRE1] 且 [PRE2]**：只有强者发信号；
- **部分混同 [PRE3]**：强者全发，弱者只有一部分发。

奖学金例子很直观。100名毕业生中，50人学得轻松，学习成本约2000美元；50人学得吃力，成本约5000美元。若总奖金100万美元，人人毕业各拿1万美元，两类人都有动力学，这是混同。若奖金缩到20万美元，全毕业每人只拿2000美元，弱者不划算；强者若独占则每人4000美元，仍有动力，于是分离。若奖金为40万美元，全毕业时弱者每人4000美元仍低于5000美元；可若弱者退出，强者每人可拿8000美元，这又对部分弱者有吸引力。最终可能出现30名弱者和50名强者一起毕业，共80人各拿5000美元，刚好等于弱者学习成本，这就是部分混同。它更复杂，因为需要弱者之间形成某种协调或预期。

## 连续信号：代价可以调大小

连续模型让信号大小可变。强者每单位信号成本更低。为了分离，强者得选一个对弱者来说贵到不划算、但自己算总账仍值得的信号。推导结果是：至少一部分强者能分离，未必全部。有趣的是，强者群体越大，信号带来的好处被摊薄，信号量级反而可能变小；完全分离更容易在强者人数少，或强弱成本差距很大时出现。简单说，任何大小为 [PRE4] 的信号都可能把强者分出来；若 CW≥cN，所有强者都会分离，否则会出现部分混同，一部分弱者也跟着发信号。

## 文凭、医生与“功能性信号”

信号模型给大学文凭提供另一种解释：毕业生工资更高，常被理解为学到了技能；数学和科学专业工资更高，也常被归功于知识的经济价值。但工作中真用微积分的人并不多，面试也很少考余弦函数导数或玻意耳定律。于是另一种可能是：学位在证明“我具备获取知识的能力”。医生考物理、有机化学、微积分，看病时当然不会在病历上解方程；这些内容或许与执业关系不大，却能证明学习能力。更好的信号是“既证明能力，又真有用”：解剖学考试既考记忆，也要求记住人体结构，所以它是功能性信号。反过来说，若只考申请人背各国首都和货币，能证明记忆力，却对当好医生没意义。

## 孔雀、夸富宴与超级碗广告

生态界早就在用昂贵信号。雄孔雀的尾羽几乎没功能价值，甚至可能添麻烦，但强壮的爪子很难在远处被雌孔雀看见，夸张尾羽反而在演化中胜出。雄性果蝇的彩色尾部、蚱蜢和鸟类的鸣叫也类似：鸣叫耗能，只有吃饱的个体才耗得起。人类学则总结出三类昂贵信号：无条件慷慨、浪费性维生方式、精美传统手工艺品。太平洋西北部印第安人的“夸富宴”上，酋长送出甚至毁掉大量财富，向其他酋长叫板；做不到就丢声望。远行狩猎比采集种子浆果收益更低，却可能换来尊重和勇气信号；对澳大利亚北部梅里亚姆人的研究还发现，海龟猎手到50岁时存活后代平均是其他同龄男性的两倍多。传统工艺品多具礼仪意义，制作耗时耗资源，意义不只在实用功能。

商业广告也能这样看。超级碗广告位极贵，买它等于说：企业相信产品会让消费者喜欢，赚得回本。两家咖啡机企业，一家知道产品过硬，另一家预计退货率20%；好产品企业敢投200万美元广告，差产品企业不敢跟，因为后者预计卖不动。花大钱证明质量，有时就叫“烧钱”。孔雀用尾羽吸引配偶，企业用广告吸引消费者。

当然，发信号要付成本，成本会抵消一部分“被识别”的好处；时间和精力还是机会成本。要降低社会浪费，就该让信号更有效：让年轻人用团体运动证明体魄与勇气，而不是骑摩托飞驰跳车；让医生背解剖图谱，而不是考《魔戒》精灵语。浪费性信号不会消失，但我们可以用模型和机制设计，尽量保证发出的信号真的携带信息。

下次看到昂贵手表、铺天广告或漂亮文凭，不妨多问一句：它在替谁发信号？成本够不够高，能不能把真假分开？好的制度，不该只让信号越来越贵，而该让信号越来越可信、越来越有用。
