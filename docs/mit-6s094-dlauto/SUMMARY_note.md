## 🧠 P1：L1- 深度学习与自动驾驶简介

在本节课中，我们将要学习深度学习与自动驾驶的基本概念及其结合点。课程将概述自动驾驶系统的整体架构，并介绍深度学习在其中扮演的关键角色。

自动驾驶汽车是一个复杂的系统，它需要感知周围环境、理解交通状况、规划行驶路径并控制车辆执行。深度学习，作为人工智能的一个强大分支，为这些任务提供了有效的解决方案。

---

## 🤖 P2：L2- 深度学习

上一节我们介绍了自动驾驶的整体框架，本节中我们来看看其核心驱动力——深度学习。深度学习是机器学习的一个子领域，它使用被称为神经网络的模型来学习数据中的复杂模式。

一个简单的神经网络层可以表示为：
`output = activation_function(dot(input, weights) + bias)`

以下是深度学习的一些核心概念：

*   **神经网络**：由相互连接的节点（神经元）组成的计算模型，模仿人脑的工作方式。
*   **前向传播**：数据从输入层通过网络层层传递到输出层的过程。
*   **反向传播**：根据预测输出与真实值之间的误差，从后往前调整网络参数（权重和偏置）的算法。
*   **损失函数**：衡量模型预测结果与真实值之间差距的函数，例如均方误差（MSE）。
*   **优化器**：用于最小化损失函数、更新模型参数的算法，如随机梯度下降（SGD）。

## 🎮 P3：L3- 深度强化学习

在掌握了深度学习的基础后，我们进入一个更动态的领域——深度强化学习。它结合了深度学习的感知能力和强化学习的决策能力，非常适合需要与环境持续交互的自动驾驶场景。

强化学习的核心是智能体通过试错来学习策略，以最大化从环境中获得的累积奖励。深度强化学习用深度神经网络来近似价值函数或策略函数。

其核心公式可以概括为马尔可夫决策过程（MDP）：
`S` 是状态集合，`A` 是动作集合，`P` 是状态转移概率，`R` 是奖励函数，目标是学习一个策略 `π(a|s)` 来最大化期望回报。

## 👁️ P4：L4- 计算机视觉

自动驾驶汽车的眼睛就是计算机视觉系统。本节我们将学习计算机视觉如何让汽车“看见”和理解世界。这是环境感知模块的基础。

计算机视觉任务包括图像分类、目标检测、语义分割等。在自动驾驶中，这些技术用于识别车辆、行人、交通标志和车道线。

一个典型的目标检测任务可以用以下伪代码描述其流程：
```
输入：原始图像
过程：1. 使用卷积神经网络提取特征
      2. 在特征图上生成候选区域或直接预测边界框和类别
输出：带有类别标签的物体边界框
```

## 🧍 P5：L5- 深度学习与类人环境感知

上一节我们了解了计算机视觉的基础任务，本节我们将深入探讨如何让汽车的感知系统更像人类。类人环境感知旨在让机器不仅检测到物体，还能理解场景的上下文和物体间的相互关系。

这涉及到更高级的任务，如实例分割（区分同一类别的不同个体）、场景理解、以及基于视觉的深度和运动估计。这些技术共同构建了一个对周围环境具有丰富、立体理解的感知系统。

## 🛣️ P6：L6- 面向运动规划的深度强化学习

感知环境之后，汽车需要决定如何安全、高效地行驶。这就是运动规划的任务。本节我们将探讨如何应用深度强化学习来解决复杂的运动规划问题。

运动规划需要在动态、不确定的环境中，从起点到终点找出一条最优或可行的轨迹。深度强化学习通过让智能体（车辆）在模拟环境中不断尝试，学习如何应对各种交通状况，如超车、并线、通过交叉路口等。

其学习目标是找到一个策略，使得在状态 `s_t` 下选择的动作 `a_t` 能最大化未来的累积奖励 `G_t = Σ γ^k * R_{t+k+1}`，其中 `γ` 是折扣因子。

---

## 🔄 P7：L7- 用于全驾驶任务端到端学习的卷积神经网络

传统的自动驾驶系统将感知、决策、控制等模块分开处理。本节我们介绍一种不同的思路：端到端学习。这种方法使用一个单一的深度神经网络（通常是卷积神经网络CNN），直接将原始传感器输入（如图像）映射为控制指令（如方向盘角度、油门刹车）。

这种方法的核心思想是让网络自己学习中间的特征表示和决策逻辑。一个经典的端到端自动驾驶模型可以简化为：
`控制指令 = CNN(原始图像序列)`

---

## ⏳ P8：L8- 循环神经网络与时序驾驶操纵

驾驶是一个连续的时序过程，当前的决策依赖于过去的状态。上一节介绍的端到端CNN处理静态图像可能忽略了这种时间依赖性。本节我们引入循环神经网络来处理驾驶中的时序信息。

RNN及其变体（如LSTM长短期记忆网络、GRU门控循环单元）具有内部记忆，能够处理序列数据。在自动驾驶中，它们可以用于理解车辆的运动趋势、预测其他交通参与者的行为，并做出更平滑、更前瞻性的操纵决策。

一个简单的RNN单元更新公式为：
`h_t = tanh(W_{hh} * h_{t-1} + W_{xh} * x_t + b_h)`
其中 `h_t` 是当前时刻的隐藏状态，`x_t` 是当前输入。

## 👥 P9：L9- 以人为中心的半自主驾驶深度学习

自动驾驶的发展是渐进式的，在完全自动驾驶实现之前，人机共驾将是长期存在的模式。本节我们学习以人为中心的半自主驾驶系统，它强调深度学习如何更好地理解驾驶员意图、状态，并实现安全、平滑的控制权交接。

这类系统需要解决的关键问题包括：驾驶员状态监控（如是否疲劳、分心）、驾驶行为建模、以及何时、以何种方式接管车辆控制。深度学习在驾驶员行为预测和个性化驾驶风格适配方面发挥着重要作用。

## 📊 P10：L10- 机器学习简介

在深入学习了各种深度学习的应用之后，我们最后回到更基础的层面，系统性地概述机器学习。理解机器学习的基本原理有助于更好地掌握其各个子领域，包括深度学习。

机器学习是让计算机从数据中学习规律，并利用这些规律对未知数据进行预测或决策的科学。其主要范式可以分为：

以下是机器学习的三种主要类型：

*   **监督学习**：模型从带有标签的训练数据中学习输入到输出的映射关系。例如，分类和回归任务。
*   **无监督学习**：模型从无标签的数据中发现内在结构或模式。例如，聚类和降维。
*   **强化学习**：智能体通过与环境交互获得的奖励信号来学习最优行为策略。
