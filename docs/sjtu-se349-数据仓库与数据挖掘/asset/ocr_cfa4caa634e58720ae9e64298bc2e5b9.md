# 数值数据的相关系数

在概率论与统计学中，协方差和方差是两个类似的度量，评估两个属性如何一起变化

```
Cov(A, B) = E((A - Ā)(B - B̄)) = \frac{\sum_{i=1}^{n}(a_i - \bar{A})(b_i - \bar{B})}{n}
```

Correlation coefficient: r_{A,B} = \frac{Cov(A, B)}{\sigma_A \sigma_B}

n是元组的数量，Ā和B̄是属性A和B的期望，σ_A和σ_B是A和B的标准差

+   正协方差: If Cov_{A,B} > 0, 如果A大于期望，则B也很有可能大于期望

+   负协方差: If Cov_{A,B} < 0, 如果A大于期望，则B很有可能小于期望

+   独立: Cov_{A,B} = 0 但逆命题不成立:
+   — 某些随机变量可能具有协方差0，但不独立。仅在某种附加的假设下 (e.g., 数据遵守多元正态分布，协方差0蕴含独立性
