

## Attributes 属性

- 属性(Attribute):
  - 数据挖掘
  - 数据库
  - 数据仓库
  - 机器学习
  - 统计学
  - 也被称为维(Dimensions)、特征(Features)、变量(Variables)
- 通常是一个 数据字段，表示数据对象的一个特征
  - E.g., 顾客_ID, 姓名, 地址
- 描述对象的一组属性称为属性向量（或特征向量）

- 属性类型：由属性可能具有的值的集合决定
  - 标称属性(Nominal)
  - 二元属性(Binary)
  - 序数属性(Ordinal)
  - 数值属性(Numeric)：量化的
    - 区间标度(Interval-scaled)
    - 比率标度(Ratio-scaled)
  - 定性的
  - 定量的

## Attributes 属性 1 —— 标称属性(Nominal)

- 标称属性(Nominal)：定性的
  - “分类的”，代表某种类别、编码或状态
  - 不必具有有意义的序
  - “枚举的”
    - 头发颜色 = {黑色、棕色、淡黄色、红色、赤褐色、灰色...}
    - 婚姻状况 = {单身、已婚、离异、丧偶}

- 可以用 数 表示这些符号或名称
  - 对于Hair_color，指定代码0表示黑色，1表示棕色...
  - Customer_ID，它可能值可以都是数值。

- 但它不是定量的，并不打算定量地使用这些数，数学运算没有意义
  - 与从一个年龄值（年龄是数值属性）减去另一个不同，从一个顾客号减去另一个顾客号毫无意义
  - 均值、中位数等都没有意义

## Attributes 属性 2 —— 二元属性(Binary)

- 二元属性(Binary): 定性的
  - 它是一种标称属性，只有两个类别或状态（0或1）
  - 又称为布尔属性，如果两种状态对应于True和False
- 分类
  - 对称二元属性（两种状态具有同等价值且拥有 相同权重）
    - 性别 = {男、女}
  - 非对称二元属性（两种状态具有不同权重）
    - 医疗化验结果 = {阴性(常见)、阳性}
    - 通常对重要的结果用1编码

## Attributes 属性 3 —— 序号属性(Ordinal)

- 序号属性(Ordinal): 定性的
  - 可能的值之间具有有意义的序或秩评定（先后次序）
    - 可乐杯大小 = {大、中、小}
    - 成绩 = {A+、A、A-、B+、B、B-、......}
  - 对于记录不能客观度量的主观质量评估，序号属性是有用的。因此，序号属性通常用于等级评定调查
  - 序号属性也可以通过把数值量的值域划分成有限个有序类别，把数值属性离散化而得到
  - 相继值之间的差是未知的
- 可以用 众数（集合中最频繁出现的値）和 中位数（有序数据值的中间値）来表示中心趋势，但不能定义均值

## Attributes 属性 4 —— 数值属性(Numeric)

- 数值属性(Numeric): 定量的
  - 用整数或数值表示
- 分类
  - 区间标度属性(Interval)
    - E.g., 温度、日期等
    - 用 相等的单位尺度度量
      - 摄氏温度是水在标准大气压下沸点温度与冰点温度之差的1/100
    - 值有序，允许比较和定量评估值之间的 差
      - 温度: 假设有许多天的室外温度值，其中每天是一个对象。把这些值排序，则得到这些对象关于温度的秩评定。可以量化不同值之间的差，例如，温度20度比5度高出15度。
      - 日历日期: 2002年与2010年相差8年。
    - 由于没有真正的“零”，不允许 比率
      - 可以计算温度差，但是不能说一个温度值是另一个的倍数
    - 可以计算 中位数、众数、均值

## Attributes 属性 4 —— 数值属性(Numeric) Cont.

- 比率标度属性(Ratio)
  - 具有固有的零点的数值属性
  - 可以计算比率
    - E.g., 开氏温度(绝对零点)、货币量
  - 可以计算中位数、众数、均值

## Attributes 属性 5 —— 离散 v.s. 连续

- **离散属性(Discrete Attributes)**
  - 具有有限或无限个可数个值
  - E.g., 可乐杯大小、顾客_ID、邮政编码
  - 有时，可以用 **整数值** 表示
  - 注意！二元属性是离散属性的一个特殊情况

- **连续属性(Continuous Attributes)**
  - 通常用实数表示
    - E.g., 温度、高度、重量……
  - 连续属性一般用 **浮点** 表示

## Basic Statistical Descriptions of Data
数据的 基本统计描述 之 中心趋势度量

- 我们有某个属性X（例如： salary 工资），共分析N个对象
  - 令 X1, X2, X3, X4, ..., Xn 为 “属性X的N个 观测值”
  - 又称 观测 或 (X的)数据集

- 如果标出Salary的这些观测值(以千美元为单位按递增次序)
  - 30, 31, 47, 50, 52, 52, 56, 60, 63, 70, 70, 110

- 那么大部分值将落在哪处？
  - —这反应数据的中心趋势
  - —包括： 均值(Mean)、中位数(Median)、众数(Mode)

## Basic Statistical Descriptions of Data

数据的基本统计描述 之 中心趋势度量 Cont.

- 中心趋势的思想
  - 包括：均值(Mean)、中位数(Median)、众数(Mode)

- (算数)均值（Mean）：
  - \(\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i\)

- 加权平均
  - \(\bar{x} = \frac{\sum_{i=1}^{n} w_i x_i}{\sum_{i=1}^{n} w_i}\)

- 截尾均值(trimmed mean)
  - 为了抵消少数极端值的影响，丢弃高低极端值后的均值

## Basic Statistical Descriptions of Data

数据的基本统计描述 之 中位数

- 中心趋势的思想

包括：均值(Mean)、中位数(Median)、众数(Mode)

### 中位数（Median）：

- — 对于倾斜（非对称）数据，数据中心的更好度量

- — 有序数据值的 中间值

- — 假设给定某属性X的N个有序观测值

如果N是奇数，

中位数即改有序集的中间值

如果N是偶数，

中位数不唯一
