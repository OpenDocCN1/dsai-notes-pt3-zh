## 数据规约3: 数据压缩

- 字符串压缩 String compression
  - There are extensive theories and well-tuned algorithms
  - Typically lossless, but only limited manipulation is possible without expansion
- 视频/音频压缩 Audio/video compression
  - Typically lossy compression, with progressive refinement
  - Sometimes small fragments of signal can be reconstructed without reconstructing the whole
- Time sequence is not audio
  - Typically short and vary slowly with time
- 维规约和数量规约也可以视为某种形式的数据压缩

## 数据变换 Data Transformation

- 通过变换将整个数据集的给定属性的值映射到新的值，每个老的值都能够通过新的值识别

方法
- 光滑 Smoothing: 去除数据中的噪声（数据清理的方法）
  - 分箱、回归、聚类
- 属性构造 Attribute/feature construction（数据规约方法）
  - 由给定的属性构造新的属性并添加到属性集中
- 聚集 Aggregation: 对数据进行汇总，构造数据立方体（数据规约方法）
- 规范化 Normalization: 把属性数据按比例缩放，使之落入特定大小区间
  - min-max normalization
  - z-score normalization
  - normalization by decimal scaling
- 离散化 Discretization: 组织更高层概念

数据预处理的主要任务之间存在许多重叠，上述策略中前三个在前面已经介绍

## 规范化 Normalization

- 最小-最大规范化 Min-max normalization: to [new_min_A, new_max_A]

v' = (v - min_A)/(max_A - min_A) (new_max_A - new_min_A) + new_min_A

Ex. Let income range $12,000 to $98,000 normalized to [0.0, 1.0]. Then $73,000 is mapped to (73,600-12,000)/(98,000-12,000) (1.0-0)+0 = 0.716

- Z分数规范化 Z-score normalization ( μ : mean, σ : standard deviation):

v' = (v - μ_A)/σ_A

Ex. Let μ = 54,000, σ = 16,000. Then (73,600-54,000)/16,000 = 1.225

- 小数定标规范化 Normalization by decimal scaling

v' = v / 10^j   Where j is the smallest integer such that Max(| v '|) < 1

## 离散化 Discretization

- 属性有三种
  - 标称 Nominal—values from an unordered set, e.g., color, profession
  - 顺序 Ordinal—values from an ordered set, e.g., military or academic rank
  - 数值 Numeric—real numbers, e.g., integer or real numbers
- 离散化 Discretization: 将连续的属性分割为有间隔的
  - 用间隔标签可以代替实际的数据值
  - 通过离散化减少数据大小
  - 监督的离散化 Supervised vs. 非监督的离散化 unsupervised
  - 自顶向下离散化 Split (top-down) vs. 自底向上离散化 merge (bottom-up)
  - 在一个属性值上可以递归地进行离散化
  - 为进一步的分析做准备（如分类）

## 数据离散方法

- 典型方法: 所有方法可以递归使用

- 分箱 Binning
  - Top-down split, unsupervised
- 直方图 Histogram analysis
  - Top-down split, unsupervised
- 聚类分析 Clustering analysis (unsupervised, top-down split or bottom-up merge)
- 决策树分析 Decision-tree analysis (supervised, top-down split)
- 相关分析 Correlation (e.g., χ²) analysis (unsupervised, bottom-up merge)
