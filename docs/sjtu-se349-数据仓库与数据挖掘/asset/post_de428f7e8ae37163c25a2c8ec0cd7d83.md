
## Extensions to Hierarchical Clustering

更多关于层次聚类方法

- 凝聚的层次聚类方法的主要缺点
  - 伸缩性不够好：时间复杂度最小为 O(n²)，n 是全体对象的数目
  - 先前已做的处理不能被撤销

为了提高层次方法聚类质量——多阶段聚类……

- 层次聚类和基于距离聚类的集成
  - BIRCH (1996)：使用 CF 树，增量地调整子聚类的质量
  - CHAMELEON (1999)：采用动态模型的聚类方法

### BIRCH (1996)

- Birch：使用聚类特征树的多阶段聚类 (SIGMOD'96)
  - Balanced Iterative Reducing and Clustering using Hierarchies
- 增量的构造 CF（Clustering Feature，聚类特征）树
  - CF 树是一个用于多阶段聚类的层次数据结构

### Clustering Feature Vector in BIRCH

聚类特征向量本质上是给定簇的统计汇总。

**Clustering Feature (CF):** CF = (N, LS, SS)

- N：Number of data points
- LS：linear sum of N points: ∑ᵢ₌₁ᴺ Xᵢ
- SS：square sum of N points: ∑ᵢ₌₁ᴺ Xᵢ²

簇的形心 x₀ = (∑ᵢ₌₁ⁿ xᵢ)/n = LS/n

簇的半径 R = √[∑ᵢ₌₁ⁿ (xᵢ - x₀)² / n] = √[(n SS - LS²)/n²]

簇的直径 D = √[∑ᵢ₌₁ⁿ ∑ⱼ₌₁ⁿ (xᵢ - xⱼ)² / (n(n-1))] = √[(2n SS - 2 LS²)/(n(n-1))]

![](img/6d25e92eb0bd56a22c311279c19b06b4_1226_0.png)

CF = (5, (16,30),(54,190))

聚类特征是可加的：

CF₁ + CF₂ = ⟨n₁ + n₂, LS₁ + LS₂, SS₁ + SS₂⟩

使用聚类特征概括簇可以避免存储个体对象或点的详细信息。只需要固定大小的空间来存放聚类特征。这是 BIRCH 在空间使用上有效性的关键。

### CF-Tree in BIRCH

- CF 树是一棵高度平衡的树，存储着层次聚类的聚类特征。
  - 树中的非叶结点都有后代或“子女”。
  - 非叶结点存储了其子女的 CF 的总和。
- CF 树有两个参数：
  - 分支因子 B：每个非叶结点的子女的最大数目。
  - 阈值 T：存储在树叶节点的子簇的最大直径。

分支因子：

- 叶节点平衡因子：条目最大个数 L=6

### BIRCH 算法

① 簇直径

$$D = \sqrt{\frac{1}{n(n-1)}\sum_{i=1}^{n}\sum_{j=1}^{n}(x_i-x_j)^2}$$

- 对于输入的每个点而言：
  - 找到最为接近的叶子节点；
  - 将该点加入到叶子节点中并且更新 CF；
  - 如果节点直径 > 最大直径，那么分裂叶子节点，祖先有可能也因此分裂。
- 算法复杂度 O(n)。
- 对数据点的插入顺序敏感。
- CF 树的每个节点由于大小限制只能包含有限的条目，一个 CF 树节点并不总是对应于用户认为的一个自然簇。
- 使用半径或直径来控制簇边界，簇趋向于球形。

### CF 树的构造过程

1. 从根节点开始递归往下，计算当前条目与要插入数据点之间的距离，寻找距离最小的那条路径，直到找到与该数据点最接近的叶节点中的条目。
2. 比较计算出的距离是否小于阈值 T。如果小于，则当前条目吸收该数据点；如果距离大于等于阈值 T，则转步骤 3。
3. 判断当前条目所在叶节点的条目个数是否小于 L。如果是，则直接将数据点插入为该数据点的新条目，否则需要分裂该叶节点。分裂的原则是寻找该叶节点中距离最远的两个条目，并以这两个条目作为分裂后新的两个叶节点的起始条目。其他剩下的条目根据距离最小原则分配到这两个新的叶节点中，删除原叶节点并更新整个 CF 树。

当数据点无法插入时，这个时候需要提升阈值 T 并重建树来吸收更多的叶节点条目，直到把所有数据点全部插入完毕。

### BIRCH 算法

**流程**

- 阶段1：扫描数据库，建立一个初始存在于内存中的 CF 树，它可以被看作数据的多层压缩，试图保留数据内在的聚类结构。
- 阶段2：使用一个任意的聚类算法对 CF 树的叶结点进行聚类，把稀疏的簇当做离群点删除，并把稠密的簇合并为更大的簇。

在阶段一，随着对象被插入，树被动态地构造。这样，该方法支持增量聚类。一个对象被插入到最近的叶条目（子簇）。如果在插入后，存储在叶结点中的子簇的直径大于阈值，则该叶结点和可能的其他结点被分裂。新对象插入后，关于该对象的信息向树根结点传递。

通过修改阈值，CF 树大小可以改变。如果存储树需要的内存大于主存大小，可以定义较大的阈值，并重建树。

重建过程是从旧树叶结点构建一棵新树。这样，重建树的过程不需要重读所有的对象或点。因此，为了建树，只需读一次数据。采用一些启发式方法，通过额外的数据扫描来处理离群点和改进树的质量。CF 树建好后，可以在阶段二使用任意聚类算法，例如典型的划分方法。

### BIRCH 算法

- 线性伸缩性：
  - 单遍扫描找出一个好的聚类，一或多遍的额外扫描可以进一步改进聚类的质量。
  - 算法的时间复杂度是 O(n)，n 是被聚类的对象数。
- 缺点：
  - 树的每个结点由于大小限制只能包含有限的条目，一个树结点并不总是对应于用户认为的一个自然簇。
  - 如果簇不是球形的，则 BIRCH 不能很好地工作，因为它使用半径或直径的概念来控制簇的边界。
  - 只能处理数值数据，对数据记录的顺序很敏感。

## CHAMELEON（变色龙）

由 G. Karypis, E. H. Han 和 V. Kumar ’99 提出的使用动态建模的层次聚类。

### 在动态模型的基础上度量相似性

两个簇被合并当且仅当簇间的互联性和近似度与簇内部对象间的互联性和近似度高度相关。

- 簇中对象的连接情况
- 簇的邻近性

### 基于图的一个两步算法

1. 使用一个图划分算法：把对象聚类到相对较小的子聚类。
2. 使用一个凝聚的聚类层次算法：通过反复合并这些子聚类来找到真正的聚类簇。

### K-最邻近图

图的每个顶点代表一个数据对象，如果一个对象是另一个对象的 k 个最相似的对象之一，那么这两个顶点（对象）之间就存在一条边。

![](img/6d25e92eb0bd56a22c311279c19b06b4_1235_0.png)

### CHAMELEON 的相似度计算

- **Relative Inter-connectivity (RI)** 相对互联度

$$RI(C_i,C_j)=\frac{|EC_{\{C_i,C_j\}}|}{\frac{|EC_{C_i}|+|EC_{C_j}|}{2}}$$

- **Relative closeness (RC)** 相对接近度

$$RC(C_i,C_j)=\frac{\overline{S}_{EC_{\{C_i,C_j\}}}}{\frac{|C_i|}{|C_i|+|C_j|}\overline{S}_{EC_{C_i}}+\frac{|C_j|}{|C_i|+|C_j|}\overline{S}_{EC_{C_j}}}$$

注：

- $EC_{\{C_i,C_j\}}$ 是包含 $C_i$ 和 $C_j$ 的簇的边割。
- $\overline{S}_{EC_{C_i}}$ 和 $\overline{S}_{EC_{C_j}}$ 是最小二分簇的边的平均权重。
- $\overline{S}_{EC_{\{C_i,C_j\}}}$ 是链接 $C_i$ 顶点和 $C_j$ 顶点的边的平均权重。

> 边割最小：簇 C 被划分成子簇 Ci 和 Cj，使得把 C 二分成 Ci 和 Cj 而被切断的边的权重之和最小。

### Overall Framework of CHAMELEON（CHAMELEON 的总体框架）

Data Set → 构造稀疏图 → 划分图 → 合并划分 → 最终的簇

- K-NN Graph：P and q are connected if q is among the top k closest neighbors of p
- Relative interconnectivity：connectivity of c₁ and c₂ over internal connectivity
- Relative closeness：closeness of c₁ and c₂ over internal closeness

与一些著名的算法（如 BIRCH 和基于密度的聚类）相比，在发现高质量的任意形状的簇方面具有更强的能力。然而，在最坏的情况下，高维数据的处理代价可能需要 O(n²) 的时间，其中 n 是对象个数。
