# OPTICS: A Cluster-Ordering Method (1999)

# 通过点排序识别聚类结构， Ordering Points to Identify the Clustering Structure

+   并不显式地产生数据集聚类，而是输出簇排序（cluster ordering）。这个排序是所有分析对象的线性表，并且代表了数据的基于密度的聚类结构。较稠密族中的对象在簇排序中相互靠近。

+   这个排序等价于从广泛的参数设置中得到的基于密度的聚类。这样，不要用户提供特定密度阈值。簇排序可以用来提取基本的聚类信息（例如，族中心或任意形状的簇），导出内在的聚类结构，也可以提供聚类的可视化。可以用图形或使用可视化技术表示
