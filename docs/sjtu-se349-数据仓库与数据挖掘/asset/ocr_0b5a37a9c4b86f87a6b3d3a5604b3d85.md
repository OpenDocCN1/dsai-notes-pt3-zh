# 二元属性的相异性

+   二元属性只有两种状态：0或1
+   0表示该属性不出现，1表示该属性出现
+   注意：不能像对待数值一样来处理二元属性！

+   那么，如何计算两个二元属性之间的相异性？
+   — 针对 对称二元属性
+   E.g., 对于对象 I 和对象 J，
+   q 是对象 I 和 J 都取1的属性数
+   r 是对象 I 取1，对象 J 取0的属性数
+   s 是对象 I 取0，对象 J 取1的属性数
+   t 是对象 I 和 J 都取0的属性数

表 2.3 二元属性的列联表
对象 j
1 0 sum
对象 i 1 q r q+r
0 s t s+t
sum q+s r+t p

此时，相异性 $d(i, j) = \frac{r + s}{q + r + s + t}$
