## 数据规约3: 数据压缩

- 字符串压缩 String compression
  - 有广泛的理论和成熟的算法
  - 通常是无损的，但如果不扩展，只能进行有限的操作
- 视频/音频压缩 Audio/video compression
  - 通常是有损压缩，并逐步细化
  - 有时可以在不重建整个信号的情况下重建信号的小片段
- 时间序列不是音频
  - 通常很短，且随时间变化缓慢
- 维规约和数量规约也可以视为某种形式的数据压缩

## 数据变换 Data Transformation

- 通过变换将整个数据集的给定属性的值映射到新的值，每个老的值都能够通过新的值识别

方法
- 光滑 Smoothing: 去除数据中的噪声（数据清理的方法）
  - 分箱、回归、聚类
- 属性构造 Attribute/feature construction（数据规约方法）
  - 由给定的属性构造新的属性并添加到属性集中
- 聚集 Aggregation: 对数据进行汇总，构造数据立方体（数据规约方法）
- 规范化 Normalization: 把属性数据按比例缩放，使之落入特定大小区间
  - 最小-最大规范化
  - Z分数规范化
  - 小数定标规范化
- 离散化 Discretization: 组织更高层概念

数据预处理的主要任务之间存在许多重叠，上述策略中前三个在前面已经介绍

## 规范化 Normalization

- 最小-最大规范化 Min-max normalization: 到 [new_min_A, new_max_A]

v' = (v - min_A)/(max_A - min_A) (new_max_A - new_min_A) + new_min_A

例如，设收入范围为 $12,000 到 $98,000，归一化到 [0.0, 1.0]。则 $73,000 映射为 (73,600-12,000)/(98,000-12,000) (1.0-0)+0 = 0.716

- Z分数规范化 Z-score normalization ( μ : 均值，σ : 标准差):

v' = (v - μ_A)/σ_A

例如，设 μ = 54,000，σ = 16,000。则 (73,600-54,000)/16,000 = 1.225

- 小数定标规范化 Normalization by decimal scaling

v' = v / 10^j   其中 j 是使 Max(| v '|) < 1 的最小整数

## 离散化 Discretization

- 属性有三种
  - 标称 Nominal—取值来自无序集合，例如颜色、职业
  - 顺序 Ordinal—取值来自有序集合，例如军衔或学术等级
  - 数值 Numeric—实数，例如整数或实数
- 离散化 Discretization: 将连续的属性分割为有间隔的
  - 用间隔标签可以代替实际的数据值
  - 通过离散化减少数据大小
  - 监督的离散化 Supervised vs. 非监督的离散化 unsupervised
  - 自顶向下离散化 Split (top-down) vs. 自底向上离散化 merge (bottom-up)
  - 在一个属性值上可以递归地进行离散化
  - 为进一步的分析做准备（如分类）

## 数据离散方法

- 典型方法: 所有方法可以递归使用

- 分箱 Binning
  - 自顶向下拆分，非监督
- 直方图 Histogram analysis
  - 自顶向下拆分，非监督
- 聚类分析 Clustering analysis (非监督，自顶向下拆分或自底向上合并)
- 决策树分析 Decision-tree analysis (监督，自顶向下拆分)
- 相关分析 Correlation (例如，χ²) analysis (非监督，自底向上合并)
