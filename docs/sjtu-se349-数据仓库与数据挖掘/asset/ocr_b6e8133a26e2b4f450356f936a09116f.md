# Basic Statistical Descriptions of Data

数据的基本统计描述 之 中位数

+   中心趋势的思想

包括：均值(Mean)、中位数(Median)、众数(Mode)

# 中位数（Median）：

+   — 对于倾斜（非对称）数据，数据中心的更好度量

+   — 有序数据值的 中间值

+   — 假设给定某属性X的N个有序观测值

如果N是奇数，

中位数即改有序集的中间值

如果N是偶数，

中位数不唯一
