## 挖掘情境离群点 I：转化为传统的离群点检测

如果情境可以被清晰识别，则将其转化为传统的离群点检测。

- 1. 使用情境属性识别对象的情境。
- 2. 使用传统的离群点检测方法，计算对象在该情境中的离群点得分。

例：在顾客群体情境中检测离群顾客。

- 情境属性：年龄组、邮政编码
- 行为属性：每年交易次数、年度交易总额

步骤：（1）定位顾客 c 的情境；（2）将 c 与同组中的其他顾客进行比较；（3）使用传统的离群点检测方法。

如果情境中包含的顾客很少，则对情境进行一般化（例如，可以假设居住在相同区域、年龄相仿的顾客具有相似的正常行为）。

- 例：在情境属性上学习一个混合模型 U，在行为属性上学习另一个数据混合模型 V。
- 学习一个映射 p(Vi|Uj)：即数据对象 o 在情境属性上属于簇 Uj，并且在行为属性上由簇 Vi 生成的概率。
- 离群点得分：

```
S(o) = Σ_{Uj} p(o ∈ Uj) Σ_{Vi} p(o ∈ Vi) p(Vi|Uj)
```

## 挖掘情境离群点 II

### 对情境相关的正常行为建模

- 在某些应用中，无法将数据清晰地划分到各个情境中。
  - 例如，如果一位顾客突然购买了一件与她最近浏览过的商品无关的商品，那么很难确定她之前浏览过多少商品应被视为情境。
- 对与情境相关的“正常”行为进行建模。
  - 使用训练数据集训练一个模型，该模型根据情境属性值预测期望的行为属性值。
  - 如果对象的行为属性值显著偏离模型预测的值，则该对象是情境离群点。
- 这些方法使用连接情境和行为的预测模型，从而避免了对特定情境的显式识别。
- 方法：可以使用多种分类和预测技术来构建这类模型，如回归、马尔可夫模型和有穷状态自动机。

## 挖掘集体离群点 I：在“结构化对象”集合上（图数据上的集体离群点检测）

- 如果一组对象作为一个整体显著偏离整个数据集，即为集体离群点。
- 需要检查数据集的结构，即多个数据对象之间的关系。
- 这些结构中的每一种都是其相应数据类型所固有的。
  - 对于时间数据（如时间序列和序列），我们探索由时间形成的结构，这些结构出现在时间序列片段或子序列中。
  - 对于空间数据，探索局部区域。
  - 对于图和网络数据，我们探索子图。
  - 与情境离群点检测的区别：这些结构通常没有显式定义，必须作为离群点检测过程的一部分来发现。
  - 集体离群点检测方法分为两类：
    - （1）将问题归约为传统的离群点检测
      - 识别结构单元，将每个结构单元（如子序列、时间序列片段、局部区域或子图）视为一个数据对象，并提取特征。
      - 然后，利用提取的特征，对如此构造的“结构化对象”集合进行离群点检测。

## 挖掘集体离群点 II：直接对结构单元的期望行为建模

- 例 1：检测在线顾客社交网络中的集体离群点
  - 将网络中的每个可能子图视为一个结构单元。
  - 集体离群点：社交网络中的一个离群子图。
    - 出现频率非常低的小子图
    - 出现频率高得异常的大子图
- （2）直接对结构单元的期望行为建模。
- 预先定义结构单元是困难的。
- 例 2：检测时间序列中的集体离群点
  - 从序列中学习一个马尔可夫模型。
  - 如果某个子序列显著偏离该模型，则可将该子序列判定为集体离群点。
- 集体离群点检测是微妙的，因为探索数据中的结构具有挑战性。
  - 这种探索通常使用启发式方法，因此可能依赖具体应用。
  - 由于挖掘过程复杂，计算成本通常很高。
