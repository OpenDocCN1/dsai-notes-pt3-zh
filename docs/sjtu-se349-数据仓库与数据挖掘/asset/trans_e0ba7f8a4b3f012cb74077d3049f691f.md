## 1. Association and Correlation Analysis 关联与相关性分析
数据挖掘模式之一：挖掘频繁模式、关联和相关性

### Association, correlation vs. causality 关联、相关性与因果关系

### — 关联规则

- 尿片 → 啤酒 [0.5%, 75%] (support 支持度, confidence 置信度)
- 支持度0.5%表示所分析的所有事务数据的0.5%显示尿片和啤酒一起购买
- 置信度75%表示如果一位顾客购买了尿片，则购买啤酒的可能性是75%
- 如果一个关联规则不能同时满足最小支持度阈值和最小置信度阈值，则被认为是无趣的而被丢弃

### — 单维关联规则
属性或谓词

包含单个谓词的关联规则（Single-dimension association rule）

- Buys(X,"computer") →buys(X,"software")[support=1%,confidence=50%]
- 去掉谓词，简化为： computer → software [1%,50%]

### — 多维关联规则

- Age(X,"20..29")^income(X,"40k..49k") →buys(X,"laptop")[2%,60%]
- 涉及多个属性或谓词（age,income,buys）

## 关联规则的运用

| 单项统计 | 支持度 |
|---|---|
| {啤酒} | 2 |
| {烤鸭} | 3 |
| {面饼} | 3 |
| {面酱} | 4 |

- 单项统计，60%顾客买了烤鸭、60%顾客买了面酱
- 双项统计，60%的顾客买了烤鸭和面酱
- 三项统计，40%的顾客同时买了烤鸭、面饼和面酱

| 双项统计 | 支持度 |
|---|---|
| {啤酒，面饼} | 2 |
| {烤鸭，面饼} | 2 |
| {烤鸭，面酱} | 3 |
| {面饼，面酱} | 2 |

- R1: 烤鸭→面饼、面酱。支持度40%，置信度为66.6%
- R2: 面饼→烤鸭、面酱。支持度40%，置信度为66.6%
- R3: 面酱→面饼、烤鸭。支持度40%，置信度为50%
- KDD结果不一定是因果关系。运用之妙成乎人。
- 例如：
- 用R1，将烤鸭降价以促销面饼、面酱，很可能会破产
- 用R2 将面饼降价，以促销烤鸭，可能会发财；
- 用R3，引不起顾客的热情。
