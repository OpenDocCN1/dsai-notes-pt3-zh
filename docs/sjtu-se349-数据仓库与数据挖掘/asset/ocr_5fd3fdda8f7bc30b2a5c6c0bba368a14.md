# 云计算“炙手可热”

+   - 国内几十个省市（直辖市/地级市）纷纷制定云计算发展规划，抢占云计算技术和产业制高点
+   - 2014年4月11日发布《广东省云计算发展规划（2014-2020年）》
+     - 2015年云服务产业规模达到1000亿元，云终端制造产业规模达到3000亿元，云计算应用达到国内领先水平
+     - 2017年，云服务产业规模达到1600亿元，云终端制造产业规模达到4000亿元，应用水平力争接近世界先进行列
+     - 2020年，云计算产业核心竞争力显著提升，云服务产业规模3000亿元，云终端制造产业规模达6000亿元，应用水平力争迈进世界先进行列
