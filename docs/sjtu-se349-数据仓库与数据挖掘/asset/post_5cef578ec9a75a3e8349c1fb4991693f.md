
# Basic Statistical Descriptions of Data

## 数据的基本统计描述 之 众数

- 中心趋势的思想
  - 包括：均值(Mean)、中位数(Median)、众数(Mode)

- 众数（Mode）：
  - 集合中出现最频繁的值
  - 可以对定性和定量属性确定众数
  - 可能最高频率对应多个不同值，具有多个众数（单峰、多峰）

对于适度倾斜(非对称)的单峰数值数据，众数近似值计算：

$mean - mode = 3 \times (mean - median)$

- 中列数
  - 数据集的最大和最小值的平均值

# Basic Statistical Descriptions of Data

数据的基本统计描述 之 数据散布

极差、五数概括（基于四分位数）、中间四分位数极差

—极差（range）

- 数据集的最大值和最小值之差

—分位数（quantile）是取自数据分布的每隔一定间隔上的点，把数据划分成基本上大小相等的连贯集合

- 2-分位数是一个数据点，它把数据分布划分成高低两半，分位数对应于中位数。

- 4-分位数是3 个数据点，它们把数据分布划分成4 个相等的部分，使得每部分表示数据分布的四分之一。

- 100-分位数把数据分布划分成100个大小相等的连贯集

—中间四分位数极差(IQR): IQR = Q3 − Q1

- 四分位数: Q1 (25th percentile), Q3 (75th percentile)

—孤立点: 挑出落在至少高于第三个四分位数或低于第一个四分位数 1.5×IQR处的值

# Basic Statistical Descriptions of Data

## 数据的基本统计描述 之 图形显示

## 图形显示包括：

- **一元分布**
  - **分位数图：**
    每个观测值 xᵢ 与一个百分数 fᵢ 配对，这处大约 fᵢ*100% 的数据小于值 xᵢ
  - **分位数-分位数图 (q-q 图)：**
    观测取自两个部门的观测集分布
    判断从一个分布到另一个分布是否有漂移
  - **直方图(频率直方图)：**
    对于标称属性X，对于X的每个已知值，画一个柱或竖直条
    高度表示该X值出现的频率

- **二元分布**
  - **散点图：**
    观察双变量数据（点簇和离群点）及其相关联系的可能性
