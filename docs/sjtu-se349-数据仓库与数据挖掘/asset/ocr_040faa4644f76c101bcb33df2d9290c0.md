# SimRank: Similarity Based on Random Walk and Structural Context 基于随机游走和结构情境的相似性

+   SimRank: structural-context similarity, i.e., based on the similarity of its neighbors

+   In a directed graph G = (V,E),
+   —— 个体入邻域 individual in-neighborhood of v: I(v) = {u | (u, v) ∈ E}
+   —— 个体出邻域 individual out-neighborhood of v: O(v) = {w | (v, w) ∈ E}

+   Similarity in SimRank:
+   —— Initialization: s0(u, v) = { 0 if u ≠ v; 1 if u = v }   s(u, v) = C / |I(u)||I(v)| Σ_{x∈I(u)} Σ_{y∈I(v)} s(x, y)
+   —— Then we can compute s_{i+1} from s_i based on the definition

+   Similarity based on random walk: in a strongly connected component
+   —— Expected distance: d(u, v) = Σ_{t: u~v} P[t] l(t)   P[t] = { Π_{k=1}^{k-1} 1/|O(w_k)| if l(t) > 0; 0 if l(t) = 0. }
+   —— Expected meeting distance:
+   —— Expected meeting probability:
+   P[t] is the probability of the tour
+   m(u, v) = Σ_{t:(u,v)~(x,x)} P[t] l(t)
+   p(u, v) = Σ_{t:(u,v)~(x,x)} P[t] C^{l(t)}
