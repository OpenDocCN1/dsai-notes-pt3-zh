# Non-Parametric Methods: Detection Using Histogram
使用直方图检测离群点

+   - The model of normal data is learned from the input data without any *a priori* structure.
+   - Often makes fewer assumptions about the data, and thus can be applicable in more scenarios
+   - Outlier detection using histogram:

![](bbox=[0.637, 0.175, 0.914, 0.438])

+   - Figure shows the histogram of **purchase amounts in transactions** 每笔事务的购买量
+   - A transaction in the amount of $7,500 is an outlier, since only 0.2% transactions have an amount higher than $5,000

+   - **Problem:** Hard to choose an **appropriate bin size** 合适的箱尺寸 for histogram
+     - Too small bin size → normal objects in empty/rare bins, false positive 将正常点误识别为离群点，导致高假正率和低精度
+     - Too big bin size → outliers in some frequent bins, false negative 将离群点当成正常点，导致高假负率和低召回率

+   - **Solution:** Adopt **kernel density estimation** 核密度估计 to estimate the probability density distribution of the data. If the estimated density function is high, the object is likely normal. Otherwise, it is likely an outlier.
