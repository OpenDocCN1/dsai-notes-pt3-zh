
# 基于距离的离群点检测：一种基于网格的方法
基于网格的方法

- 为什么效率仍然是一个问题？当完整的对象集合无法放入主内存时，需要代价高昂的 I/O 交换
- 主要代价：（1）每个对象都要与整个数据集进行测试，为什么只与其近邻比较呢？（2）逐个检查对象，为什么不逐组检查呢？
- 基于网格的方法（CELL）：数据空间被划分为多维网格。每个单元是一个超立方体，对角线长度为 r/2

其中r是一个距离阈值参数，如果有l维，则单元的每个边长为 r / (2√l)

- 使用第 1 层和第 2 层单元属性进行剪枝：
- 对于单元 C 中的任意可能点 x 和第 1 层单元中的任意可能点 y，dist(x,y) ≤ r
- 对于单元 C 中的任意可能点 x 和任意点 y，若 dist(x,y) ≥ r，则 y 位于第 2 层单元中
- 因此，我们只需要检查无法被剪枝的对象，即使对于这样的对象 o，也只需要计算 o 与第 2 层单元中对象之间的距离（因为超出第 2 层，距 o 的距离大于 r）

# 基于密度的离群点检测
基于密度的离群点检测

- 局部离群点：与局部邻域而非全局数据分布相比较的离群点
- 在图中，o₁ 和 o₂ 是相对于 C₁ 的局部离群点，o₃ 是全局离群点，但 o₄ 不是离群点。
- 然而，基于邻近性的聚类无法发现 o₁ 和 o₂ 是离群点（o1 和 o2 到稠密簇 C1 的距离小于 C2 簇中对象到其最近邻的平均距离，因此，o1 和 o2 都不是基于距离的离群点）
- 直觉（基于密度的离群点检测）：离群点对象周围的密度与其邻居周围的密度显著不同
- 方法：使用对象相对于其邻居的相对密度作为该对象离群程度的指标
- 对象 o 的 k-距离，distₖ(o)：o 与其第 k 个最近邻之间的距离
- o 的 k-距离邻域，Nₖ(o) = {o' | o' in D, dist(o, o') ≤ distₖ(o)}
  - Nₖ(o) 可能大于 k，因为多个对象到 o 的距离可能相等

# 局部离群点因子：LOF

- 从 o' 到 o 的可达距离：
  reachdist_k(o ← o') = max{dist_k(o), dist(o, o')}
  — k 是用户指定的参数，用于控制光滑效果
- o 的局部可达密度：
  lrd_k(o) = ||N_k(o)|| / Σ_{o'∈N_k(o)} reachdist_k(o' ← o)
- 对象 o 的 LOF（局部离群点因子）是 o 的局部可达性与其 k 近邻的局部可达性之比的平均值
  LOF_k(o) = Σ_{o'∈N_k(o)} lrd_k(o') / lrd_k(o) / ||N_k(o)|| = Σ_{o'∈N_k(o)} lrd_k(o') · Σ_{o'∈N_k(o)} reachdist_k(o' ← o)
- o 的局部可达密度越低，且 o 的 k 近邻的局部可达密度越高，则 LOF 越高
- 这能够捕捉到局部密度相对于其 k 近邻的局部密度较低的局部离群点

# 基于聚类的离群点检测（1 和 2）：
不属于任何簇，或远离最近的簇

- 三种基于聚类的离群点检测：如果（1）对象不属于任何簇，（2）对象与其最近簇之间的距离很大，或（3）对象属于一个小型或稀疏的簇，则该对象是离群点
- 情况 I：不属于任何簇
- 识别不属于群体的动物：使用基于密度的聚类方法，如 DBSCAN
- 情况 2：远离其最近的簇
- 使用 k-means 将数据点划分为簇
- 对于每个对象 o，根据其与最近中心的距离分配一个离群点得分
- 如果 dist(o, cₒ)/avg_dist(cₒ) 很大，则很可能是一个离群点
- 例：入侵检测：考虑数据点与训练数据集中簇之间的相似性
- 使用训练集来发现“正常”数据的模式，例如每个分段中的频繁项集，并将相似连接聚类成组
- 将新的数据点与挖掘出的簇进行比较——离群点可能是攻击
