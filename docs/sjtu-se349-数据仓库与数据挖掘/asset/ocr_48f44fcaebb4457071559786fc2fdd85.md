ψ(t) = e^{-t²/2} e^{i ω₀ t}

ψ̂(ω) = √2π e^{-(ω-ω₀)²/2}

Morlet小波不存在尺度函数; 快速衰减但非紧支撑.

Morlet小波是Gabor 小波的特例。

g(t) = 1/(σ²π)^{1/4} e^{-t²/(2σ²)}

ψ(t) = g(t) e^{i η t}

σ = 1, η = 5
