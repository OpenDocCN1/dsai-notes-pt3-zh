## 子空间聚类方法（II）：
基于相关性的聚类方法

- 子空间搜索方法：基于距离或密度的相似性
- 基于相关性的方法：基于高级相关性模型
- 例如，基于 PCA 的方法：
  - 应用 PCA（主成分分析）导出一组新的、不相关的维度；
  - 然后在新空间或其子空间中挖掘聚类
- 其他空间变换：
  - 霍夫变换
  - 分形维数

## 主成分分析法起源

主成分概念首先由 Karl Pearson 在 1901 年引进，当时只对非随机变量来讨论的。1933 年 Hotelling 将这个概念推广到随机变量。

一项十分著名的工作是美国的统计学家斯通（Stone）在 1947 年关于国民经济的研究。他曾利用美国 1929—1938 年各年的数据，得到了 17 个反映国民收入与支出的变量要素，例如雇主补贴、消费资料和生产资料、纯公共支出、净增库存、股息、利息外贸平衡等等。在进行主成分分析后，竟以 97.4% 的精度，用三新变量就取代了原 17 个变量。根据经济学知识，斯通给这三个新变量分别命名为总收入 F1、总收入变化率 F2 和经济发展或衰退的趋势 F3。

这种由讨论多个指标降为少数几个综合指标的过程在数学上就叫做降维。主成分分析通常的做法是，寻求原指标的线性组合 $F_i$。

```
$F_1 = a_{11}X_1 + a_{21}X_2 + \cdots + a_{p1}X_p$
$F_2 = a_{12}X_1 + a_{22}X_2 + \cdots + a_{p2}X_p$
$\cdots$
$F_p = a_{1p}X_1 + a_{2p}X_2 + \cdots + a_{pp}X_p$
```

满足如下的条件：

- 每个主成分的系数平方和为 1。即
  $a_{1i}^2 + a_{2i}^2 + \cdots + a_{pi}^2 = 1$

- 主成分之间相互独立，即无重叠的信息。即
  $Cov(F_i, F_j)=0,\ i \neq j,\ i,\ j=1,\ 2,\ \cdots,\ p$
  $Cov(A,B)=E((A-\bar{A})(B-\bar{B}))=\frac{\sum_{i=1}^{n}(a_i-\bar{A})(b_i-\bar{B})}{n}$

- 主成分的方差依次递减，重要性依次递减，即
  $Var(F_1) \geq Var(F_2) \geq \cdots \geq Var(F_p)$

## 子空间聚类方法（III）：
双聚类方法

- 双聚类：同时对对象和属性进行聚类（以对称的方式处理对象和属性）

- 四项要求：
  — 只有少量对象参与一个聚类
  — 一个聚类只涉及少量属性
  — 一个对象可以参与多个聚类，也可以完全不参与任何聚类
  — 一个属性可以涉及多个聚类，也可以完全不涉及任何聚类

- 例 1：基因表达或微阵列数据：一个基因样本/条件矩阵。
  - 矩阵中的每个元素都是一个实数，记录某个基因在特定条件下的表达水平

- 例 2：对客户和产品进行聚类
  - 另一个双聚类问题

## 双簇的类型

- 设 A = {a₁, ..., aₙ} 为基因集合，B = {b₁, ..., bₙ} 为条件集合
- E=[eᵢⱼ] 是基因表达数据矩阵，i=1,2,...,n，j=1,2,...,m，I、J 是 A、B 的子集
- 一个双簇：基因和条件遵循某些一致模式的子矩阵
- 4 种双簇类型（理想情况）

- 具有常数值的双簇：
  - 对于任意 i ∈ I 和 j ∈ J，eᵢⱼ = c

- 行上具有常数值的双簇：
  - eᵢⱼ = c + αᵢ
  - 列上也可以具有常数值

- 具有相干值的双簇（也称基于模式的簇）
  - eᵢⱼ = c + αᵢ + βⱼ，行与列以同步的方式改变
  - 具有相干值的双簇（基于模式的簇）

- 行上具有相干演变的双簇
  - eᵢⱼ (eᵢ₁ⱼ₁ - eᵢ₁ⱼ₂)(eᵢ₂ⱼ₁ - eᵢ₂ⱼ₂) ≥ 0
  - 即，只关注基因或条件之间的上调或下调变化，而不限制具体数值
  - 具有相干演变的双簇

## 双聚类方法

- 现实世界的数据包含噪声：尝试寻找近似双簇
- 方法：基于优化的方法与枚举方法
- 基于优化的方法
  - 每次尝试寻找一个作为双簇时具有最佳显著性的子矩阵；具有最高显著性得分的子矩阵被识别为双簇
  - 由于计算成本较高，采用贪心搜索来寻找局部最优双簇
  - 例如，δ-Cluster 算法（Cheng 和 Church，ISMB’2000）
- 枚举方法
  - 使用容忍阈值指定被挖掘的双簇对噪声的容忍度
  - 然后尝试将所有满足要求的子矩阵枚举为双簇
  - 例如，δ-pCluster 算法（H. Wang 等，SIGMOD’2002；MaPle：Pei 等，ICDM’2003）
