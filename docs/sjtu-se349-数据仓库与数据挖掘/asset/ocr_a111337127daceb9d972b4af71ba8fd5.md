+   Fuzzy clustering
+   — 给定对象集O₁,...,Oₙ, k fuzzy clusters C₁, ...,Cₖ, can be represented as a partition matrix 划分矩阵
+     • M = [wᵢⱼ] (1 ≪ i ≪ n,1 ≪ j ≪ k)  wᵢⱼ = |Rᵢ ∩ Cⱼ| / |Rᵢ ∩ (C₁ ∪ C₂)| = |Rᵢ ∩ Cⱼ| / |Rᵢ ∩ {数码相机,镜头,计算机}| 
+     • Wᵢⱼ是Oᵢ在模糊簇Cⱼ的隶属度

+   — P1: for each object oᵢ and cluster Cⱼ, 0 ≤ wᵢⱼ ≤ 1 (强制模糊簇是模糊集 fuzzy set)
+   — P2: for each object oᵢ, Σⱼ=1ᵏ wᵢⱼ = 1, 确保每个对象同等的参与聚类
+   — P3: for each cluster Cⱼ, 0 < Σᵢ=1ⁿ wᵢⱼ < n 确保每个簇都至少有一个对象

Let c₁, ..., cₖ as the center of the k clusters

For an object oᵢ, sum of the squared error (SSE,误差的平方和), p is a parameter p是一个参数, 控制隶属度的影响, p越大隶属度的影响越大:

For a cluster Cⱼ, SSE: SSE(Cⱼ) = Σᵢ=1ⁿ wᵢⱼᵖ dist(oᵢ, cⱼ)²    SSE(oᵢ) = Σⱼ=1ᵏ wᵢⱼᵖ dist(oᵢ, cⱼ)²

+   Measure how well a clustering fits the data:
+   — 模糊聚类对数据集的拟合程度
+   SSE(C) = Σᵢ=1ⁿ Σⱼ=1ᵏ wᵢⱼᵖ dist(oᵢ, cⱼ)²
