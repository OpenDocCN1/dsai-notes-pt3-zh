# 模糊集合及其运算

# （1）模糊矩阵间的关系及运算

定义：设 $A = (a_{ij})_{m\times n}, B = (b_{ij})_{m\times n}$ 都是模糊矩阵，定义

相等：$A = B \Leftrightarrow a_{ij} = b_{ij}$

包含：$A \le B \Leftrightarrow a_{ij} \le b_{ij}$

并：$A \cup B = (a_{ij} \vee b_{ij})_{m\times n}$

交：$A \cap B = (a_{ij} \wedge b_{ij})_{m\times n}$

余：$A^{c} = (1 - a_{ij})_{m\times n}$
