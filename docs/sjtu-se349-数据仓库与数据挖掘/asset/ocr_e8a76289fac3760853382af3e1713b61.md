# 7. Meyer小波

它的小波函数与尺度函数都是在频域中进行定义的。具体定义如下：

ψ̂(ω) = (2π)^{-1/2} e^{iω/2} { sin(π/2 ν(3/(2π)|ω| -1))  2π/3 ≤ |ω| ≤ 4π/3
cos(π/2 ν(3/(4π)|ω| -1))  4π/3 ≤ |ω| ≤ 8π/3
0  |ω| ∉ [2π/3, 8π/3] }

ν(t) = t^4 (35 -84t +70t^2 -20t^3)  t ∈ [0,1]

φ̂(ω) = { (2π)^{1/2}  |ω| ≤ 2π/3
(2π)^{-1/2} cos(π/2 ν(3/(2π)|ω| -1))  2π/3 ≤ |ω| ≤ 4π/3
0  |ω| > 4π/3 }
