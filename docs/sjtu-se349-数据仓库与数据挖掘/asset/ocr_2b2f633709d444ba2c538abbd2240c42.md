# What is Cluster Analysis?
什么是聚类分析？

+   - **Cluster 聚类 又称，自动分类/数据分割**
+     - 把数据对象(或观测)划分成子集的过程
+     - 簇内对象彼此相似，簇外彼此相异

+   - **Unsupervised Learning 非监督学习——用于聚类**
+     - 没有提供类标号信息
+     - 通过 观察学习，而不是通过 示例学习
