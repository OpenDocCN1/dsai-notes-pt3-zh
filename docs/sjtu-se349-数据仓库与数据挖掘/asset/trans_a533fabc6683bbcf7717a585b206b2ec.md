

## 支持向量机的基本原理

![](img/6d25e92eb0bd56a22c311279c19b06b4_940_0.png)

设两类问题训练样本集为 $(x_1, y_1)$, $(x_2, y_2), ..., (x_n, y_n)$, 其中 $x_i \in R^n$, $y_i = \{1, -1\}$, $i = 1, ..., n$ 线性可分是指存在着超平面（Hyper-plane）直线 $f(x) = w x + b$, 使得训练样本中的一类输入和另一类输入分别位于该超平面的两侧。

这种线性分类函数在一维空间里就是一个点，在二维空间里就是一条直线，三维空间里就是一个平面，可以如此想象下去，如果不关注空间的维数，这种线性函数还有一个统一的名称——超平面（Hyper Plane）！

## 如何求最优超平面

- 现在，原问题转化为下面这样一个优化问题

- 求解 w 和 b，使得对于所有的样本 {(x_i, y_i)}，能有 m = 2 / ||w|| 最大，其中满足：

- 当 y_i = 1 时， w^T x_i + b ≥ 1

- 当 y_i = -1 时， w^T x_i + b ≤ -1

- 可统一表示为： y_i (w^T x_i + b) ≥ 1

- 如何求解上述带约束的问题？

## 如何求最优超平面

求解最优超平面问题可以表示成约束优化问题

- Minimize  Φ(w) = 1/2 ||w||² = 1/2 (w·w)

- Subject to  y_i ((w·x_i)+b) ≥ 1, i = 1, ..., l

这是一个严格凸规划问题，可以转换成拉格朗日 (Lagrange) 问题进行求解。为此，可以定义如下的Lagrange函数：

L(w,b,α) = 1/2 ||w||² - Σ_{i=1}^l α_i (y_i·((x_i·w)+b) - 1)

其中 α_i ≥ 0 为 Lagrange 乘子。

## 如何求最优超平面

由Karush-Kuhn-Tucker (KKT)条件，上式所示函数在其鞍点位置（分别对w和b求偏导，并令其为0）满足：

∂L/∂w = 0  ⇒  w = Σᵢ₌₁ᴺ αᵢ yᵢ xᵢ

∂L/∂b = 0  ⇒  Σᵢ₌₁ᴺ αᵢ yᵢ = 0

这实际上是寻找极值条件下L函数满足的等式约束

## 如何求最优超平面

$L(w,b,\alpha)=\frac{1}{2}\|w\|^2 - \sum_{i=1}^{l} \alpha_i (y_i \cdot ((x_i \cdot w)+b)-1)$

- 将得到的约束条件

$w = \sum_{i=1}^{N} \alpha_i y_i x_i$

$\sum_{i=1}^{N} \alpha_i y_i = 0$

得到：

$W(\alpha)=\sum_{i=1}^{N} \alpha_i - \frac{1}{2} \sum_{i}^{N} \sum_{j}^{N} \alpha_i \alpha_j y_i y_j \langle x_i, x_j \rangle$

- 该式称为L函数的对偶式，由对偶理论可知，最小化L式等于最大化以式的约束的拉格朗日乘子为变量的上式

- 现在问题转化

这是一个标准二次规划问题，是在一个不等式约束条件下进行二次函数寻优，该问题存在唯一解。

$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i,j=1}^{n} \alpha_i \alpha_j y_i y_j x_i^T x_j$

s.t., $\alpha_i \ge 0, i=1,\cdots,n$

$\sum_{i=1}^{n} \alpha_i y_i = 0$

二次规划解出 $\alpha_i$ 的值,代入

$w = \sum_{i=1}^{N} \alpha_i y_i x_i$

求出 $w$

## 如何求最优超平面

根据最优解 $\alpha^* = (a_1^*,\cdots,a_l^*)^T$

计算 $w^* = \sum_{i=1}^l y_i \alpha_i^* x_i$，选择 $a^*$ 的一个正分量 $\alpha_j^*$，并据此计算

$b^* = y_j - \sum_{i=1}^l y_i \alpha_i^* (x_i \cdot x_j)$

构造划分超平面 $(w^* \cdot x) + b^* = 0$，决策函数 $f(x) = \operatorname{sgn}((w^* \cdot x) + b^*)$

事实上，$\alpha^*$ 的每一个分量 $\alpha_i^*$ 都与一个训练点相对应。而分划超平面仅仅依赖于 $\alpha_i^*$ 不为零的训练点 $(x_i, y_i)$，而与对应于 $\alpha_i^*$ 为零的那些训练点无关。

其中 $\alpha_i^*$ 不为零的这些训练点的输入 $x_i$ 为支持向量(SV)
