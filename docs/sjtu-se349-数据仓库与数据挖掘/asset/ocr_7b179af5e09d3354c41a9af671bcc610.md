# 模式增长方法：
不使用生成候选集挖掘频繁项集

+   - Apriori方法的瓶颈
+     - 广度优先(i.e., level-wise) 搜索
+     - 使用候选集生成
+       - 可能会产生大量候选集
+   - FPGrowth方法(J. Han, J. Pei, and Y. Yin, SIGMOD’ 00)
+     - Frequent-Pattern Growth, 频繁模式增长
+     - 深度优先搜索
+     - 避免显式地产生候选
+   - 主要理念: 从短的模式中使用局部频繁项，得到长的模式
+     - “abc” is a frequent pattern
+     - Get all transactions having “abc”, i.e., project DB on abc: DB|abc
+     - “d” is a local frequent item in DB|abc → abcd is a frequent pattern
