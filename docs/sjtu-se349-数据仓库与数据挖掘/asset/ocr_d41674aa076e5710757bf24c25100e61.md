# Structural Connectivity [1]

+   - **ε-Neighborhood:**
+     \[N_{\varepsilon}(v)=\{w\in\Gamma(v)\mid\sigma(v,w)\geq\varepsilon\}\]
+   - **Core:**
+   - **Direct structure reachable:**
+     \[CORE_{\varepsilon,\mu}(v)\Longleftrightarrow |N_{\varepsilon}(v)|\geq\mu\]
+   - **Structure reachable:** transitive closure of direct structure reachability
+   - **Structure connected:**
+     \[DirRECH_{\varepsilon,\mu}(v,w)\Longleftrightarrow CORE_{\varepsilon,\mu}(v)\land w\in N_{\varepsilon}(v)\]
+     \[CONNECT_{\varepsilon,\mu}(v,w)\Longleftrightarrow \exists u\in V:RECH_{\varepsilon,\mu}(u,v)\land RECH_{\varepsilon,\mu}(u,w)\]
