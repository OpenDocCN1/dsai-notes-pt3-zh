# Weka

+   — Weka (Waikato Environment for Knowledge Analysis, http://www.cs.waikato.ac.nz/ml/weka/)

+   — 可能是名气最大的开源机器学习和数据挖掘软件。高级用户可以通过 Java编程和命令行来调用其分析组件。同时，Weka也为普通用户提供了图形化界面，称为Weka KnowledgeFlow Environment和Weka Explorer。

+   — 和R相比，Weka在统计分析方面较弱，但在机器学习方面强得多。

+   — Weka论坛
+   (http://weka.sourceforge.net/wiki/index.php/Related_Projects)
+   可以找到很多扩展包，比如文本挖掘、可视化、网格计算等等。

+   — 很多其它开源数据挖掘软件也支持调用Weka的分析功能。
