# 模糊聚类分析

# 2、建立模糊相似矩阵（标定）

建立 $x_i$ 与 $x_j$ 相似程度 $r_{ij}=R(x_i,x_j)$ 的方法主要有：

# （1）相似系数法

①夹角余弦法 $r_{ij}=\frac{\sum_{k=1}^{m}x_{ik}\cdot x_{jk}}{\sqrt{\sum_{k=1}^{m}x_{ik}^2}\cdot\sqrt{\sum_{k=1}^{m}x_{jk}^2}}$

②相关系数法 $r_{ij}=\frac{\sum_{k=1}^{m}|x_{ik}-\bar{x}_i||x_{jk}-\bar{x}_j|}{\sqrt{\sum_{k=1}^{m}(x_{ik}-\bar{x}_i)^2}\cdot\sqrt{\sum_{k=1}^{m}(x_{jk}-\bar{x}_j)^2}}$
