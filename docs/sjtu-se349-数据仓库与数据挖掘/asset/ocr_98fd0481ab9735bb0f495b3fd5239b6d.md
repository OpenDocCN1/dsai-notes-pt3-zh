# Parametric Methods I: Detection Univariate Outliers Based on Normal Distribution

+   Univariate data 一元数据: A data set involving only one attribute or variable

+   方法原理 Often assume that data are generated from a normal distribution, learn the parameters from the input data, and identify the points with low probability as outliers

+   Ex: Avg. temp.: {24.0, 28.9, 28.9, 29.0, 29.1, 29.1, 29.2, 29.2, 29.3, 29.4}
+   — 通过假设上述温度数据符合正态分布来检测离群点
+   — Use the maximum likelihood method 最大似然方法, 即最大化对数似然函数 to estimate μ and σ
+   ln ℒ(μ, σ²) = Σᵢ₌₁ⁿ ln f(xᵢ|(μ, σ²)) = -n/2 ln(2π) - n/2 ln σ² - 1/(2σ²) Σᵢ₌₁ⁿ (xᵢ - μ)²

+   Taking derivatives 求导 with respect to μ and σ², we derive the following maximum likelihood estimates 最大似然估计
+   \hat{μ} = ar{x} = 1/n Σᵢ₌₁ⁿ xᵢ      \hat{σ}² = 1/n Σᵢ₌₁ⁿ (xᵢ - ar{x})²

+   For the above data with n = 10, we have \hat{μ} = 28.61 \hat{σ} = √2.29 = 1.51

+   最大偏离值 24.0 偏离均值 4.61, 在正态分布中 (24 - 28.61)/1.51 = -3.04 < -3, 24 is an outlier since μ ± 3σ region contains 99.7% data
+   24 被该正态分布产生的概率小于 15%, 被识别为离群点
