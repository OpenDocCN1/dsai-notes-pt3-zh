# Applications of Cluster Analysis

聚类的常见应用

+   - 空间数据分析
+     - 通过聚类特征空间创建GIS中的主题映射
+     - 探测空间簇,用空间数据挖掘解释它们

+   - 图像模式识别
+     - 对手写数字数据集聚类，确定子类，每个子类代表手写可能出现“2”的变体，使用基于子类的多个模型可以提高整体识别的准确率

+   - 经济学(特别指市场研究)
+     - 把客户分组，有利于开发加强客户关系管理的商务策略

+   - Web关键词搜索
+     - Web页面数量巨大，关键词搜索会返回大量命中对象〈与搜索相关网页〉，用聚类将搜索结果分组，以简明的方式提交结果
