# Basic Statistical Descriptions of Data

数据的基本统计描述 之 中心趋势度量 Cont.

+   中心趋势的思想
+   包括：均值(Mean)、中位数(Median)、众数(Mode)

+   (算数)均值（Mean）：
+   \(\bar{x} = \frac{1}{n} \sum_{i=1}^{n} x_i\)

+   加权平均
+   \(\bar{x} = \frac{\sum_{i=1}^{n} w_i x_i}{\sum_{i=1}^{n} w_i}\)

+   截尾均值(trimmed mean)
+   为了抵消少数极端值的影响，丢弃高低极端值后的均值
