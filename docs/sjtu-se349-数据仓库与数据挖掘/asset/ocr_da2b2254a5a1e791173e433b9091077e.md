# 准确率，错误率，灵敏性和特效性

| A\\P | C | ¬C |  |
|---|---|---|---|
| C | TP | FN | P |
| ¬C | FP | TN | N |
|  | P′ | N′ | All |

+   - 分类器准确率：正确分类元组所占的百分比
+   
+     **Accuracy = (TP + TN)/All**
+   - **Error rate: 1 − accuracy, or**
+   
+     **Error rate = (FP + FN)/All**

+   - 类不平衡问题：
+     - 感兴趣的主类是稀少的，e.g. 欺诈
+     - 负类显著地占多数，正类占少数
+     - 灵敏性：正确识别正元组的百分比
+       - **Sensitivity = TP/P**
+     - 特效性：正确识别负元组的百分比
+       - **Specificity = TN/N**
