# DBSCAN聚类过程

+   （1）随机选择一个点P1，其邻域中包含{P1,P2,P3,P13},P1是核心点，其邻域中的点构成簇1的一部分，依次检查P2、P3和P13的Eps邻域，进行扩展，将点P4并入，P4是边界点

+   （2）检查P5，其Eps邻域中包含{P5,P6,P7,P8}，P5是核心点，其邻域中的点构成簇2，依次检查P6、P7和P8的Eps邻域，每个点都是核心点，但不能扩展簇

+   （3）检查P9，其Eps邻域中包含{P9}，P9是噪声点

+   （4）检查P10，其Eps邻域中包含{P10,P11}，P10是噪声点或边界点，检查P11，其Eps邻域中包含{P10,P11,P12}，P11是核心点，其邻域中的点构成簇3；进一步检查，P10、P12为边界点
