# Using IF-THEN Rules for Classification
使用 IF-THEN 规则分类（Cont）

+   - 如果规则被 *X* 满足，则称该规则被 触发。
+   - 如果规则 R1 是 唯一 满足的规则，则该规则被 激活，返回 *X* 的类预测。

如果有 多个规则 被触发，则需要解决冲突

+   - 如果她们指向了不同的类怎么办？
+     - 规模序：把最高优先权赋予具有最多属性测试（最苛刻）的规则
+     - 基于类的规则序：优先级按照普遍性降序排序，最普遍（或最频繁）类的所有规则首先出现，次普遍类的规则随后，如此等作为选择。也可以根据每个类的误分类代价排序。每个类中规则是无序的，不存在类冲突。
+     - 基于规则的规则序：根据准确度、覆盖率等等把规则组织成一个优先权列表（决策表）

如果不存在 *X* 满足规则的情况？

根据训练集指定一个默认类（默认类的选择视算法而定），可以建立一个省缺或默认规则，根据训练集指定一个默认类。这个类可以是多数类，或者不被任何规则覆盖的元组多数类。当且仅当没有其他规则覆盖*X* 时，最后才使用默认规则。默认规则的条件为空。这样，当没有其他规则时该规则被激活。
