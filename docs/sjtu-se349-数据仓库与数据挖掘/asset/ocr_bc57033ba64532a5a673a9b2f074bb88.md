# 数值属性的相异性

计算数值属性刻画的对象之间相异性的距离度量：

+   - 欧几里得距离
+   - 曼哈顿距离
+   - 闵可夫斯基距离

![](bbox=[0.75, 0.22, 0.92, 0.42])

（加权）欧几里得距离（直线或“乌鸦飞行”距离）

```
d(i,j) = √[(x_i1 - x_j1)² + (x_i2 - x_j2)² + (x_i3 - x_j3)² + … + (x_ip - x_jp)²]
```

```
d(i,j) = √[w1|x_i1 - x_j1|² + w2|x_i2 - x_j2|² + … + wp|x_ip - x_jp|²]
```

其中 i = (x_i1, x_i2, x_i3, …, x_ip)，j = (x_j1, x_j2, x_j3, …, x_jp) 是被 p 个数值属性描述的两个对象

曼哈顿距离（城市两点之间的街区距离）

+   - 如，向南 2 个街区，横过 3 个街区，共计 5 个街区

```
d(i,j) = |x_i1 - x_j1| + |x_i2 - x_j2| + … + |x_ip - x_jp|
```
