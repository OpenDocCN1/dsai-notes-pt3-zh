# Why Data Mining? 为什么进行数据挖掘？

+   - 我们逐渐被数据所淹没
+     - B—KB—MB—GB—TB—PB……
+   - 同时，我们更渴求知识！

+   - “Necessity is the mother of Invention”
+     - 将数据坯墓转化为知识“金块”
+     - 数据挖掘把大型数据集转换成知识
+     - 例：搜索引擎Google每天接受数亿次查询，每个查询都被看做一个事务，用户通过事务描述他们的信息需求。随着时间的推移，搜索引擎可以从这些大量的搜索查询中学到新颖的、有用的知识。Google的“Flu Trends（流感趋势）”使用特殊的搜索项作为流感活动的指示器，它发现了搜索流感相关信息的人数与实际具有流感症状的人数之间的紧密联系，使用聚集的搜索数据，Google可以比传统的系统早两周对流感活动作出评估。
