# 1. Association and Correlation Analysis

数据挖掘模式之一：挖掘频繁模式、关联和相关性

# Association, correlation vs. causality

关联度、Correlation vs 因果关系

# — 关联规则

+   尿片 → 啤酒 [0.5%, 75%] (support 支持度, confidence 置信度)

+   支持度0.5%表示所分析的所有事务数据的0.5%显示尿片和啤酒一起购买

+   置信度75%表示如果一位顾客购买了尿片，则购买啤酒的可能性是75%

+   如果一个关联规则不能同时满足最小支持度阈值和最小置信度阈值，则被认为是无趣的而被丢弃

# — 单维关联规则

属性或谓词

包含单个谓词的关联规则（Single-dimension association rule）

+   Buys(X,"computer") →buys(X,"software")[support=1%,confidence=50%]

+   去掉谓词，简化为： computer → software [1%,50%]

# — 多维关联规则

+   Age(X,"20..29")^income(X,"40k..49k") →buys(X,"laptop")[2%,60%]

+   涉及多个属性或谓词（age,income,buys）
