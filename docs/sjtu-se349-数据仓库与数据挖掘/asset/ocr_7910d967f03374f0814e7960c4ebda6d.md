# 智慧水资源管理

# 哈德森河上游到入海口的实时监控网

分布式传感器网络
由移动和固定无线传感器（每个传感器都有自己的计算芯片）组成的一个分布式传感器网络，负责收集传送流域的物理，化学和生物的变化实时数据

传感器数据的收集和处理
借助IBM的新的“流计算”技术，对分布式传感器网络收集到的实时的连续的物理、化学和生物数据流进行检查分类并按优先级处理

融合采集的数据信息的“创造”可视化的虚拟河流
科学家，教育工作者和政府决策者，通过由电脑综合数据形成的“虚拟”河，以进一步了解生态系统，观察沉积物和化学污染物，深入了解人类类对水质和鱼类的迁移的影响。修订区域发展政策和模式
