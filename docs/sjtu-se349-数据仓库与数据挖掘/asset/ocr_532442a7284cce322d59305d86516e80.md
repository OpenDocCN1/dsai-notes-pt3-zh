# 二元属性的相异性(Cont.)

+   针对 非对称二元属性（E.g., 病理化验的阳性(1)和阴性(0)结果）

+   负匹配（t）被认为是不重要的
+   可以被忽略

表 2.3 二元属性的列联表

|  | 对象 j |  |  |
|---|---|---|---|
|  | 1 | 0 | sum |
| 对象 i |  |  |  |
| 1 | q | r | q + r |
| 0 | s | t | s + t |
| sum | q + s | r + t | p |

+   此时，相异性  $d(i, j) = \frac{r + s}{q + r + s}$

+   相对应的  $sim_{Jaccard}(i, j) = \frac{q}{q + r + s}$
+   也被称为Jaccard系数
