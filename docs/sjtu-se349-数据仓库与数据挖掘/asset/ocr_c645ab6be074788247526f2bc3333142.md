# Outlier Detection II: Unsupervised Methods

+   - **Assume** the normal objects are somewhat ``clustered`` into multiple groups, each having some distinct features
+   - An outlier is expected to be far away from any groups of normal objects
+   - Weakness: **Cannot detect collective outlier effectively**
+     - Normal objects may not share any strong patterns, but the collective outliers may share high similarity in a small area
+   - Ex. In some intrusion or virus detection, normal activities are diverse发散
+     - Unsupervised methods may have a high **false positive rate**假正例率（把正常对象误标记为离群点） but still miss many real outliers.
+     - Supervised methods can be more effective, e.g., identify attacking some key resources（入侵或病毒都攻击目标系统的关键资源）
+   - Many clustering methods can be adapted for unsupervised methods
+     - 这些方法的核心思想是先Find clusters,然后 then outliers: not belonging to any cluster
+     - Problem 1: Hard to distinguish noise from outliers
+     - Problem 2: Costly since first clustering: but far less outliers than normal objects在可以触及实际内容（即离群点）之前必须先处理大量非目标数据实体（即正常对象）可能不那么吸引人
+   - Newer methods: **tackle outliers directly**
