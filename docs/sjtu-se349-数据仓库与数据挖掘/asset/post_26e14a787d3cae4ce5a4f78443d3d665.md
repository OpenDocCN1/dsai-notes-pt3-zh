
## 简单离散化：分箱

- 等宽（Equal-width (distance) partitioning）
  - Divides the range into *N* intervals of equal size: uniform grid
  - If *A* and *B* are the lowest and highest values of the attribute, the width of intervals will be: *W = (B − A)/N*.
  - 最直观，但易受离群点影响
- 等频（Equal-depth (frequency) partitioning）
  - Divides the range into *N* intervals, each containing approximately the same number of samples
  - 良好的数据比例
  - 管理分类属性可能会非常棘手

## 分箱方法在数据光滑中的作用

- Sorted data for price (in dollars): 4, 8, 9, 15, 21, 21, 24, 25, 26, 28, 29, 34
- Partition into equal-frequency (equi-depth) bins:
  - Bin 1: 4, 8, 9, 15
  - Bin 2: 21, 21, 24, 25
  - Bin 3: 26, 28, 29, 34
- Smoothing by bin means:
  - Bin 1: 9, 9, 9, 9
  - Bin 2: 23, 23, 23, 23
  - Bin 3: 29, 29, 29, 29
- Smoothing by bin boundaries:
  - Bin 1: 4, 4, 4, 15
  - Bin 2: 21, 21, 25, 25
  - Bin 3: 26, 26, 26, 34

## 分类离散化与相关性分析

- 分类（Classification）（例如，决策树分析）
  - Supervised: Given class labels, e.g., cancerous vs. benign
  - Using entropy（熵）to determine split point (discretization point)
  - Top-down, recursive split
  - Details to be covered in Chapter "Classification"
- 相关性分析（Correlation analysis）（例如，Chi-merge：χ²-based discretization）
  - Supervised: use class information
  - Bottom-up merge: find the best neighboring intervals (those having similar distributions of classes, i.e., low χ² values) to merge
  - Merge is performed recursively, until a predefined stopping condition

## 概念分层产生（Concept Hierarchy Generation）

- 概念层次组织概念（即 **attribute values**），通常与数据仓库中的每个维度相关联
- 概念层次结构便于在数据仓库中多粒度查看数据
- 概念层次的形成：递归地用更高层次的概念（如青年、成年或老年）取代低层次的概念（如年龄数值），从而减少数据
- 概念分层可以由该领域的专家和/或数据仓库设计人员显式地指定
- 概念分层可以为数值数据和标称数据自动形成；对于数值数据，可以使用离散化方法

## 标称数据的概念分层产生

- 由用户或专家在模式级显式地说明属性的部分序：
  - *street* < *city* < *state* < *country*
- 通过显式数据分组说明分层架构的一部分：
  - {Urbana, Champaign, Chicago} < Illinois
- 说明属性集但不说明它们的偏序：
  - E.g., only *street* < *city*, not others
- 根据每个属性的不同值的个数产生概念分层：
  - E.g., for a set of attributes: {*street*, *city*, *state*, *country*}

## 自动生成概念分层

- 有时候，概念分层可以通过分析数据集中每个属性不同值的个数自动生成
- 不同值个数最多的属性被放在概念分层的最底层
- Exceptions, e.g., weekday, month, quarter, year

## 傅里叶变换（Fourier transform）

— 1807: Joseph Fourier

- 傅里叶理论指出，一个信号可表示成一系列正弦和余弦函数之和，叫做傅里叶展开式

![](img/6d25e92eb0bd56a22c311279c19b06b4_441_0.png)

![](img/6d25e92eb0bd56a22c311279c19b06b4_441_1.png)

```
F(ω) = ∫_{-∞}^{+∞} f(t) e^{-jωt} dt
```

where `e^{-jωt} = cos ωt − j sin ωt`

```
f(t) = 1/(2π) ∫_{-∞}^{+∞} F(ω) e^{jωt} dω
```

- 只有频率分辨率而没有时间分辨率
- 可确定信号中包含哪些频率的信号，但不能确定具有这些频率的信号出现在什么时候
