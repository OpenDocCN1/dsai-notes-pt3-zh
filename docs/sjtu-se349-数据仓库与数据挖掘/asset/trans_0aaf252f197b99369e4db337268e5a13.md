

## 惰性学习法的特点

### 缺点
- 计算开销可能相当大。它们需要有效的存储技术，并且非常适合在并行硬件上实现。
- 它们不提供多少解释或对数据结构的洞察。

### 优点：
- 天生地支持增量学习
- 也能对具有超多边形形状的复杂决策空间建模，这些可能不太容易被其他学习算法描述（如被决策树建模的超矩形形状）

## K-最近邻分类（k-nearest-neighbor classifier）
- K-最近邻方法是20世纪50年代早期首次引进的。当给定大量数据集时，该方法是计算密集的，直到20世纪60年代计算能力大大增强之后才流行起来。
- k-最近邻分类法是基于类比学习，即通过将给定的检验元组与和它相似的训练元组进行比较来学习
- 训练元组用n个属性描述，每个元组代表n维空间的一个点。这样，所有的训练元组都存放在n维模式空间中
- 当给定一个未知元组时，k-最近邻分类法搜索模式空间，找出最接近未知元组的k个训练元组，这k个训练元组是未知元组的k个“最近邻”
- 对于最近邻分类，未知元组被指派到它的k个最近邻中的多数类
- 当k = 1 时，未知元组被指派到模式空间中最接近它的训练元组所在的类
- 最近邻分类也可以用于数值预测

即返回给定未知元组的实数值预测
在这种情况下，分类器返回未知元组的 k个最近邻的实数值标号的平均值

## 数值属性的相异性

计算数值属性刻画的对象之间相异性的距离度量：
- 欧几里得距离
- 曼哈顿距离
- 闵可夫斯基距离

![](img/6d25e92eb0bd56a22c311279c19b06b4_1017_0.png)

（加权）欧几里得距离（直线或“乌鸦飞行”距离）

```
d(i,j) = √[(x_i1 - x_j1)² + (x_i2 - x_j2)² + (x_i3 - x_j3)² + ... + (x_ip - x_jp)²]
d(i,j) = √[w1|x_i1 - x_j1|² + w2|x_i2 - x_j2|² + ... + wp|x_ip - x_jp|²]
```

其中 i = (x_i1, x_i2, x_i3, ..., x_ip)，j = (x_j1, x_j2, x_j3, ..., x_jp) 是被 p 个数值属性描述的两个对象

曼哈顿距离（城市两点之间的街区距离）
- 如，向南 2 个街区，横过 3 个街区，共计 5 个街区

```
d(i,j) = |x_i1 - x_j1| + |x_i2 - x_j2| + ... + |x_ip - x_jp|
```

## 更加学术化的描述：k—近邻法

k一近邻法是在近邻法的基础上加以改进而来的，这个法则就是在 的 k 个近邻中，按出现最多的样本类别来作为 的类别。前面我们详细讨论了近邻法的错误率的表达式及其上下界。同样，对于k一近邻法则，我们也讨论一下错误率的问题，这里以 和 二类问题为例。为避免出现 而不能判决的情况，我们取 为奇数。对待识别模式 x 误分类有以下两种情况: k1 + k2

1  k1 < k2  k1 ≤ (k-1)/2  x ∈ ω1  Σ_{j=0}^{(k-1)/2} C_k^j P(ω1|x)^j P(ω2|x)^{k-j}
2  k2 < k1  k2 ≤ (k-1)/2  x ∈ ω2  Σ_{j=0}^{(k-1)/2} C_k^j P(ω2|x)^j P(ω1|x)^{k-j}

前面我们已经说过，当 $N \to \infty$ ，$x$ 的 $k$ 个已知类别的最近邻样本 $x_1, x_2, \cdots, x_k$ 以概率 1 收敛于 $x$ ，所以这 $k$ 个样本可以不标出下标，纭记为 $x$ 。对于给定的 $x$ 的条件错误率为

$P_{N \to \infty}^k(e|x)=P(\omega_1|x)\sum_{j=0}^{(k-1)/2} C_k^j P(\omega_1|x)^j P(\omega_2|x)^{k-j}$

$+P(\omega_2|x)\sum_{j=0}^{(k-1)/2} C_k^j P(\omega_2|x)^j P(\omega_1|x)^{k-j}$

$=P(\omega_1|x)\sum_{j=0}^{(k-1)/2} C_k^j P(\omega_1|x)^j \left[1-P(\omega_1|x)\right]^{k-j}$

$+\left[1-P(\omega_1|x)\right]\sum_{j=(k+1)/2}^{k} C_k^j P(\omega_1|x)^j \left[1-P(\omega_1|x)\right]^{k-j}$

$P_{N\to\infty}^k(e|\boldsymbol{x}) = P(\omega_1|\boldsymbol{x})\sum_{j=0}^{(k-1)/2} C_k^j P(\omega_1|\boldsymbol{x})^j\left[1-P(\omega_1|\boldsymbol{x})\right]^{k-j}$

$+\left[1-P(\omega_1|\boldsymbol{x})\right]\sum_{j=(k+1)/2}^{k} C_k^j P(\omega_1|\boldsymbol{x})^j\left[1-P(\omega_1|\boldsymbol{x})\right]^{k-j}$

$=P(\omega_1|\boldsymbol{x})+\left[1-2P(\omega_1|\boldsymbol{x})\right]\sum_{j=(k+1)/2}^{k} C_k^j P(\omega_1|\boldsymbol{x})^j\left[1-P(\omega_1|\boldsymbol{x})\right]^{k-j}$

$P^*(e|\boldsymbol{x}) = \min\left[P(\omega_1|\boldsymbol{x}), P(\omega_2|\boldsymbol{x})\right] = \min\left[P(\omega_1|\boldsymbol{x}), 1-P(\omega_1|\boldsymbol{x})\right]$

$P_{N\to\infty}^k(e|\boldsymbol{x}) = P^*(e|\boldsymbol{x}) + \left[1-2P^*(e|\boldsymbol{x})\right]\sum_{j=(k+1)/2}^{k} C_k^j {P^*}^j(e|\boldsymbol{x})\left[1-P^*(e|\boldsymbol{x})\right]^{k-j}$

渐近平均错误率 $P = E\left[ P_{N\to\infty}^k(e|x)\right]$ 
这里定义Bayes条件错误率$P^*(e|x)$的函数$C_k\left[ P^*(e|x)\right]$ 为大于$P_{N\to\infty}^k(e|x)$的最小凹函数，即对所有的$x$ 
$P_{N\to\infty}^k(e|x) \le C_k\left[ P^*(e|x)\right]$ 
$P = E\left[ P_{N\to\infty}^k(e|x)\right] \le E\left\{ C_k\left[ P^*(e|x)\right]\right\} \le C_k\left\{ E\left[ P^*(e|x)\right]\right\} = C_k(P^*)$ 
$k\quad P_{N\to\infty}^k\quad C_k(P^*)\quad$ 
$P^* \le P \le C_k(P^*) \le C_{k-1}(P^*) \le \cdots \le C_1(P^*) = 2P^*(1-P^*)$ 
$P^* \le P \le P^*\left(2 - \frac{c}{c-1}P^*\right)$

## 近邻法则讨论

P* ≤ P ≤ C_k(P*) ≤ C_{k-1}(P*) ≤ ⋯ ≤ C_1(P*) = 2P*(1−P*)

P* ≤ P ≤ P*\left(2 - \frac{c}{c-1}P*\right)
