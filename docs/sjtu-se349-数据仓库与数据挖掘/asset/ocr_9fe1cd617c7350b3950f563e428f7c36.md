# Basic Statistical Descriptions of Data
数据的<|message|> 基本统计描述 之 中心趋势度量

+   - 我们有某个属性X（例如： salary 工资），共分析N个对象
+     令 X1, X2, X3, X4, ..., Xn 为 “属性X的N个 观测值”
+     又称 观测 或 (X的)数据集

+   - 如果标出Salary的这些观测值(以千美元为单位按递增次序)
+     30, 31, 47, 50, 52, 52, 56, 60, 63, 70, 70, 110

+   - 那么大部分值将落在哪处？
+     —这反应数据的中心趋势
+     —包括： 均值(Mean)、中位数(Median)、众数(Mode)
