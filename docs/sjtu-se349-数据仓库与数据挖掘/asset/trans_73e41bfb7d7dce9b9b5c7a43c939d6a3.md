# 统计数据挖掘（1）

- 有许多成熟的数据分析统计技术，尤其是针对数值数据
  - 广泛应用于科学实验数据以及经济学和社会科学数据

# 回归

- 根据一个或多个预测（自变量）变量来预测响应（因变量）变量的值，其中变量为数值型
- 回归的形式：线性、多元、加权、多项式、非参数和稳健回归

![](img/6d25e92eb0bd56a22c311279c19b06b4_1470_0.png)

# 科学和统计数据挖掘（2）

- 广义线性模型
  - 允许将分类响应变量（或其某种变换）与一组预测变量相关联
  - 类似于使用线性回归对数值响应变量进行建模
  - 包括逻辑回归和泊松回归

- 混合效应模型
  - 用于分析分组数据，即可根据一个或多个分组变量进行分类的数据
  - 通常描述按一个或多个因子分组的数据中响应变量与某些协变量之间的关系

![](img/6d25e92eb0bd56a22c311279c19b06b4_1471_0.png)

# 科学和统计数据挖掘（3）

- 回归树
  - 用于分类和预测的二叉树
  - 与决策树类似：测试在内部节点处进行
  - 在回归树中，计算目标属性的均值并用作预测值
- 方差分析
  - 分析由数值响应变量和一个或多个分类变量（因子）描述的两个或多个总体的实验数据

# 统计数据挖掘（4）

- 因子分析
  - 确定哪些变量组合在一起以生成给定因子
  - 例如，对于许多精神病学数据，可以间接测量反映目标因子的其他量（如测试分数）
- 判别分析
  - 预测分类响应变量，常用于社会科学
  - 试图确定若干判别函数（自变量的线性组合），以区分由响应变量定义的各组
