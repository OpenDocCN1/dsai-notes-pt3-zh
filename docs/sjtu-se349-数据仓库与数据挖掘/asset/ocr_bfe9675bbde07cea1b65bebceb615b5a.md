# 贝叶斯信念网络

+   - **朴素贝叶斯分类法假定类条件独立**
+     - 给定元组的类标号，假定属性的值可以条件地相互独立
+     - 这一假定简化了计算。当假定成立，与其他所有分类器相比，朴素贝叶斯分类器是最准确的
+   - 然而，在实践中**变量之间可能存在依赖关系**
+   - **贝叶斯信念网络**说明联合条件概率分布
+     - 允许在变量的子集间定义类条件独立性
+     - 提供一种因果关系的图形模型，可以在其上进行学习
+     - 训练后的贝叶斯信念网络可以用于分类
+   - 贝叶斯信念网络也被称做**信念网络、贝叶斯网络和概率网络**。本课程称为信念网络。
