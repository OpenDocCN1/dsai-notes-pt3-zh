## 引子

- 假设你是一家公司的财务经理，掌握了公司所有数据，包括众多变量，例如固定资产、流动资金、每笔借款的数额和期限、各种税费、工资支出、原料消耗、产值、利润、折旧、职工人数、职工分工和教育程度等。
- 如果要向上级或有关方面介绍公司状况，你能把这些指标和数字原封不动地全部摆出来吗？

- 当然不能。那该汇报什么？
- 人们发现，在这么多变量中，有很多是相关的，因此希望找出少数几个“代表”来描述它们。
- 需要将包含大量变量的数据进行高度概括，用少数几个指标简单明了地把情况说清楚。

## 什么是主成分分析法？

- 主成分分析法（Principal Components Analysis）和因子分析法（Factor Analysis）都是通过降低变量维数，使数据更便于描述、理解和分析的方法。
- 主成分分析也称主分量分析，是一种通过降维简化数据结构的方法：将多个变量化为少数几个综合变量（综合指标），这些综合变量能反映原变量的大部分信息，且所含信息互不重叠，彼此独立、不相关。
- 这些综合变量称为因子或主成分，它们是不可观测的，不是具体的变量，而是几个指标的综合。

## 从本例可能提出的问题

- • 能否将这个数据表中的6个变量用一两个综合变量来表示？
- • 这两个综合变量包含了多少原有信息？

事实上，以上问题在平时研究中也很常见。这类问题可以推广到对企业、学校、区域进行分析、评价、排序和分类等。

例如，对n个样本进行综合评价时，可选的描述样本特征的指标很多，而这些指标往往存在一定的相关性（既不完全独立，也不完全相关），这给研究带来很大不便。指标选得太多，会增加分析问题的难度和复杂性；选得太少，又可能漏掉对样本影响较大的指标，影响结果的可靠性。

因此，需要在相关分析的基础上，采用主成分分析法找到几个新的、相互独立的综合指标，达到减少指标数量、同时区分样本间差异的目的。

## 主成分分析法起源

- 主成分概念最早由卡尔·皮尔逊（Karl Pearson）于1901年引入，当时仅讨论非随机变量；1933年，霍特林（Hotelling）将这一概念推广到随机变量。
- 一项十分著名的工作是美国统计学家斯通（Stone）在1947年关于国民经济的研究。他利用美国1929—1938年的年度数据，得到了17个反映国民收入与支出的变量要素，例如雇主补贴、消费资料和生产资料、纯公共支出、净增库存、股息、利息、外贸平衡等。进行主成分分析后，竟以97.4%的精度，用三个新变量取代了原来的17个变量。根据经济学知识，斯通将这三个新变量分别命名为总收入F1、总收入变化率F2，以及经济发展或衰退的趋势F3。

### （一）主成分分析的几何解释

- • 例中数据点是六维的，即每个观测值是6维空间中的一个点，希望用低维空间来表示这个6维空间。
- • 先假定只有二维，即只有两个变量：语文成绩（x₁）和数学成绩（x₂），分别由横坐标和纵坐标代表；
- • 每个学生都是二维坐标系中的一个点。

### 原始数据标准化

因为实际应用中各指标的量纲往往不同，所以在计算之前必须先消除量纲的影响，即对原始数据进行标准化。为了实现样本数据的标准化，需要求出样本数据的均值和方差。对数据矩阵Y作标准化处理，也就是对每个指标分量作标准化变换，变换公式为：

```
$X_{ij} = \frac{Y_{ij} - \overline{Y}_j}{S_j} \begin{pmatrix} i = 1,2,\cdots n \\ j = 1,2,\cdots p \end{pmatrix}$
```

样本均值

```
$\overline{Y}_i = \frac{1}{n} \sum_{k=1}^{n} Y_{ki}$
```

样本标准差

```
$S_i = \sqrt{\frac{1}{n-1} \sum_{k=1}^{n} (Y_{ki} - \overline{Y}_i)^2}$
```

- 原始变量 $Y_{ij}$ 经标准化后变为新变量 $X_{ij}$，其均值为0，方差为1。
- 对二维空间而言，n个标准化后的样本在二维空间中的分布大体呈椭圆形，该椭圆有长轴和短轴。在短轴方向上数据变化很少；极端情况下，短轴退化成一点，长轴方向就能完全解释这些点的变化，由二维到一维的降维也就自然完成了。

### 平移、旋转坐标轴

![](img/6d25e92eb0bd56a22c311279c19b06b4_511_0.png)

假定语文成绩（$X_1$）和数学成绩（$X_2$）分别为标准化后的分数，右图为其散点图，椭圆倾斜为**45度**。

![](img/6d25e92eb0bd56a22c311279c19b06b4_512_0.png)

如果将坐标轴 X₁ 和 X₂ 旋转45°，那么点在新坐标系中的坐标（Y₁,Y₂）与原坐标（X₁,X₂）有如下关系：

Y₁和Y₂均是X₁和X₂的线性组合：

Y₁ = √2/2 X₁ + √2/2 X₂ = e₁' X
Y₂ = √2/2 X₁ - √2/2 X₂ = e₂' X

在新坐标系中可以发现：虽然散点图的形状没有改变，但新的随机变量 Y₁ 和 Y₂ 已不再相关。大部分点沿 Y₁ 轴散开，Y₁ 方向的变异较大（即 Y₁ 的方差较大）；相对而言，Y₂ 方向的变异较小（即 Y₂ 的方差较小）。

![](img/6d25e92eb0bd56a22c311279c19b06b4_514_0.png)

在上面的例子中，Y₁ 和 Y₂ 就是原变量 X₁ 和 X₂ 的第一主成分和第二主成分。实际上，第一主成分 Y₁ 已基本反映了 X₁ 和 X₂ 的主要信息，因为图中各点在新坐标系中的 Y₁ 坐标基本代表了这些点的分布情况，因此可以选 Y₁ 作为新的综合变量。当然，如果再选 Y₂ 也作为综合变量，那么 Y₁ 和 Y₂ 就反映了 X₁ 和 X₂ 的全部信息。

### 主成分分析的数学模型

假设实际讨论的问题中有p个指标，将这p个指标看作p个随机变量，记为 X₁, X₂, …, Xₚ。主成分分析就是把这p个指标的问题，转化为讨论m个新的指标 F₁, F₂, …, Fₘ（m<p），按照保留主要信息量的原则，使这些新指标充分反映原指标的信息，并且相互独立。

X = [ X₁₁ X₁₂ … X₁ₚ ; X₂₁ X₂₂ … X₂ₚ ; ⋮ ⋮ ⋮ ⋮ ; Xₙ₁ Xₙ₂ … Xₙₚ ] = ( X₁ X₂ … Xₚ ) 其中 Xᵢ = ( X₁ᵢ ; X₂ᵢ ; ⋮ ; Xₙᵢ )

这种将多个指标化为少数几个综合指标的过程，在数学上称为降维。主成分分析通常的做法是寻求原指标的线性组合 Fᵢ：

F₁ = a₁₁X₁ + a₂₁X₂ + ⋯ + aₚ₁Xₚ
F₂ = a₁₂X₁ + a₂₂X₂ + ⋯ + aₚ₂Xₚ
⋯⋯
Fₚ = a₁ₚX₁ + a₂ₚX₂ + ⋯ + aₚₚXₚ

并满足如下条件：

- > 每个主成分的系数平方和为1，即

a₁ᵢ² + a₂ᵢ² + ⋯ + aₚᵢ² = 1

- > 主成分之间相互独立，即没有重叠信息，即

Cov(Fᵢ, Fⱼ) = 0, i ≠ j, i, j = 1, 2, ⋯, p
Cov(A, B) = E((A - Ā)(B - B̄)) = Σᵢ₌₁ⁿ (aᵢ - Ā)(bᵢ - B̄) / n

- > 主成分的方差依次递减，重要性依次递减，即

Var(F₁) ≥ Var(F₂) ≥ ⋯ ≥ Var(Fₚ)
