# C4.5分类算法概念描述

信息熵（entropy）：用于度量一个属性的信息量

+   假设S为训练集，S的目标属性C具有m个可能的类标号值，C={C1,C2,...,Cm}，假设训练集S中Ci在所有样本中出现的概率为pi(i=1,2,3,...,m)，则该训练集S所包含的信息熵定义为

```
Entropy(S) = Entropy(p1,p2,...,pm) = - Σ_{i=1}^{m} p_i log2(p_i)
```

按属性A划分S后的样本子集的熵定义：

+   假设属性A为离散型数据，具有K个不同的取值，将S划分为k个样本子集{S1, S2, ..., Sk}，则按属性A划分S后的样本子集的信息熵如下，其中|Si|（i=1,2,...,k）为样本子集Si中包含的样本数，|S|为样本集S中包含的样本数

```
Entropy_A(S) = Σ_{i=1}^{k} |Si|/|S| Entropy(Si)
```

+   假设属性A为连续型数据，则按属性A的取值递增排序，将每对相邻值的中点看做可能的分裂点，对每个可能的分裂点，计算信息熵。SL和SR对应于分裂点划分的左右两部分子集，选择信息熵最小点作为分裂点

```
Entropy_A(S) = |SL|/|S| Entropy(SL) + |SR|/|S| Entropy(SR)
```
