# Approach II: Finding Outliers in Subspaces
发现子空间中的离群点

+   - Extending conventional outlier detection: Hard for outlier interpretation
+   - **Find outliers in much lower dimensional subspaces: easy to interpret _why_ and _to what extent_ the object is an outlier**
+     - E.g., find outlier customers in certain subspace: *average transaction amount >> avg. and purchase frequency << avg.*
+   - Ex. A grid-based subspace outlier detection method
+     - Project data onto various subspaces to find an area whose density is much lower than average
+     - Discretize the data into a grid with φ 个 equi-depth 等深 regions (why?)
+     - Search for regions that are significantly sparse 显著稀疏
+       - Consider a k-d cube k维立方体: k ranges on k dimensions, with n objects
+       - If objects are independently distributed, the expected number of objects falling into a k-dimensional region is (1 / φ)^k n = f^k n, the standard deviation is √(f^k(1 − f^k)n)
+       - The sparsity coefficient 稀疏系数 of cube C: S(C) = (n(C) − f^k n) / √(f^k(1 − f^k)n)
+       - If S(C) < 0, C contains less objects than expected
+       - The more negative, the sparser C is and the more likely the objects in C are outliers in the subspace
