# 模糊集合及其运算

例3.  $A = \frac{0.3}{x_1} + \frac{0.9}{x_2} + \frac{1}{x_3} + \frac{0.8}{x_4} + \frac{0.5}{x_5}$

$B = \frac{0.2}{x_1} + \frac{0.1}{x_2} + \frac{0.8}{x_3} + \frac{0.3}{x_4} + \frac{0.6}{x_5}$

则： $A \cup B = \frac{0.3}{x_1} + \frac{0.9}{x_2} + \frac{1}{x_3} + \frac{0.8}{x_4} + \frac{0.6}{x_5}$

$A \cap B = \frac{0.2}{x_1} + \frac{0.1}{x_2} + \frac{0.8}{x_3} + \frac{0.3}{x_4} + \frac{0.5}{x_5}$
