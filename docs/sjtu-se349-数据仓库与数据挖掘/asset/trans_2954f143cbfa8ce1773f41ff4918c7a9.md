## 双聚类（一）：δ-双簇

### 使用δ-簇算法最优化

- 对于子矩阵 I x J
  $e_{iJ} = \frac{1}{|J|} \sum_{j \in J} e_{ij}$
  $e_{Ij} = \frac{1}{|I|} \sum_{i \in I} e_{ij}$
  - 第 i 行的均值：
  - 第 j 列的均值：
  - 子矩阵中所有元素的均值是
  $e_{IJ} = \frac{1}{|I||J|} \sum_{i \in I, j \in J} e_{ij} = \frac{1}{|I|} \sum_{i \in I} e_{iJ} = \frac{1}{|J|} \sum_{j \in J} e_{Ij}$
  - 子矩阵作为双簇的质量可以用均方残差（mean squared residue value）来衡量
  $H(I \times J) = \frac{1}{|I||J|} \sum_{i \in I, j \in J} (e_{ij} - e_{iJ} - e_{Ij} + e_{IJ})^2$

- 当 H(I x J) ≤ δ（其中 δ ≥ 0 为阈值）时，子矩阵 I x J 是一个 δ-双簇。当 δ = 0 时，I x J 是一个具有相干值的完美双簇。通过设置 δ > 0，用户可以指定每个元素相对于完美双簇的平均噪声容差
  - 每个元素上的残差 residue(e_ij) = e_ij - e_iJ - e_Ij + e_IJ

## 双聚类（一）：δ-簇算法

- 极大δ-双簇（Maximal δ-bi-cluster）是一个 δ-双簇 I x J，且不存在另一个包含 I x J 的 δ-双簇 I′ x J′
- 计算代价高昂：使用启发式贪心搜索来获得局部最优簇
- 两阶段计算：删除阶段和增加阶段
- 删除阶段：从整个矩阵开始，每当矩阵的均方残差超过 δ 时，迭代地删除行和列
  - 在每次迭代中，对每一行/列计算均方残差：
    $d(i) = \frac{1}{|J|} \sum_{j \in J} (e_{ij} - e_{iJ} - e_{Ij} + e_{IJ})^2$    $d(j) = \frac{1}{|I|} \sum_{i \in I} (e_{ij} - e_{iJ} - e_{Ij} + e_{IJ})^2$
  - 删除具有最大均方残差的行或列，得到的子矩阵 [I,J] 是一个 δ-双簇
- 增加阶段：
  - 在保持 δ-双簇条件的前提下，迭代地扩展删除阶段得到的 δ-双簇 I x J
  - 通过计算均方残差，考虑当前双簇 I x J 中未涉及的所有行/列
  - 将均方残差最小的行/列加入当前的 δ-双簇
- 该方法只找到一个 δ-双簇，因此需要多次运行，每次用随机数替换输出双簇中的元素

## 双聚类（二）：δ-pCluster

### 对于基于模式的簇

- 枚举所有双簇（δ-pCluster）[H. Wang 等, Clustering by pattern similarity in large data sets. SIGMOD'02]
- 当且仅当 e_{i1j1} − e_{i2j1} = e_{i1j2} − e_{i2j2} 时，子矩阵 I x J 才是具有（完美）相干值的双簇。对于 I x J 的任意 2 x 2 子矩阵，定义 p-score
  p-score( [[e_{i1j1}, e_{i1j2}], [e_{i2j1}, e_{i2j2}]] ) = |(e_{i1j1} − e_{i2j1}) − (e_{i1j2} − e_{i2j2})|
- 如果 I x J 的每个 2 x 2 子矩阵的 p-score 至多为 δ（其中 δ ≥ 0 是阈值，用于指定用户对完美双簇的噪声容差），则子矩阵 I x J 是一个 δ-pCluster（基于模式的簇）
- p-score 控制双簇中每个元素上的噪声，而均方残差度量平均噪声
- 单调性：如果 I x J 是一个 δ-pCluster，那么 I x J 的每一个 x × y（x,y ≥ 2）子矩阵也是 δ-pCluster
- 如果无法再向簇中添加行或列且仍保持 δ-pCluster，则该 δ-pCluster 是极大的：我们只需计算所有极大 δ-pCluster
