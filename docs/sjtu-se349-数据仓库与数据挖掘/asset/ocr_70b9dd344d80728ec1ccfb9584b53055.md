# 大数据正在加速落地

# 中国政府出台大数据刺激计划只是时间早晚问题

2014年两会期间，与大数据相关的提案呈现出井喷之势：李彦宏在政协记者会上表示，政府应该把更多和人民生活有关的数据资料，公开的放到网络上；雷军则直接建议将大数据纳入国家战略，推动大数据切实地用起来；科大讯飞刘庆峰建议国家建设声纹数据库进行大数据反恐；张近东、马化腾、杨元庆的提案也与数据应用有着紧密联系。
