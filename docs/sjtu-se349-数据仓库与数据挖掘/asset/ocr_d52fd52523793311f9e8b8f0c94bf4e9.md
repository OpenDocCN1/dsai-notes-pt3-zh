# 基于概率模型的聚类——一个说明聚类的一般框架

![](bbox=[0.22, 0.18, 0.78, 0.38])

+   Ex. 2 categories for digital cameras sold

+   consumer line 业余型 C₁ vs. professional line 专业型 C₂

+   C₁, C₂ 关于价格属性的 density functions f₁, f₂

+   把每个类别看做一个 probabilistic clustering 概率簇

概率簇 C 的密度函数 f 和数据空间的点 o，f(o) 是 C 的一个实例在 o 上出现的相对似然。

聚类分析目标是找出 k 个概率簇 C1, ..., Ck，对于 n 个数据对象的数据集 D，可以看成这些簇的可能实例的一个有限样本。每个簇 Cj 都与一个实例从该簇抽样的概率 ωj 相关。按下述步骤总共执行 n 次，产生 D 的 n 个对象 o₁, ..., oₙ

+   按照概率 ω1, ..., ωk，选择一个簇 Cj

+   按照 Cj 的概率密度函数 fj，选择一个 Cj 的实例

∑_{j=1}^{k} ω_j = 1
