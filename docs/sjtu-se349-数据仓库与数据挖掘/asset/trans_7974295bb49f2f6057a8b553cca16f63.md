

## Parametric Methods III: Using Mixture of Parametric Distributions 使用混合参数分布

- 假设数据由正态分布生成有时过于简化。
- 示例（右图）：两个簇之间的对象无法被捕捉为离群点，因为它们接近估计的均值。估计的均值落在两个簇之间，而这些对象既不属于任何一个簇。

![](img/6d25e92eb0bd56a22c311279c19b06b4_1425_0.png)

为克服此问题，假设正态数据由两个正态分布生成。对于数据集中任意对象 \(o\)，\(o\) 由两个分布的混合生成的概率为

\[
\Pr(o\mid\Theta_1,\Theta_2)=f_{\Theta_1}(o)+f_{\Theta_2}(o)
\]

其中 \(f_{\Theta_1}\) 和 \(f_{\Theta_2}\) 是 \(\Theta_1\) 和 \(\Theta_2\) 的概率密度函数。

- 然后使用 EM 算法从数据中学习参数 \(\mu_1,\sigma_1,\mu_2,\sigma_2\)。
- 如果对象 \(o\) 不属于任何簇，则它是离群点。

## Non-Parametric Methods: Detection Using Histogram 使用直方图检测离群点

- 正常数据的模型是从输入数据中学习得来，没有任何 *a priori* 结构。
- 通常对数据做较少的假设，因此可在更多场景中适用。
- 使用直方图进行离群点检测：

![](img/6d25e92eb0bd56a22c311279c19b06b4_1426_0.png)

- 图显示了 **purchase amounts in transactions** 每笔事务的购买量 的直方图。
- 金额为 $7,500 的交易是离群点，因为只有 0.2% 的交易金额高于 $5,000。
- **Problem:** Hard to choose an **appropriate bin size** 合适的箱尺寸 for the histogram.
  - 箱尺寸太小 → 正常对象落在空/稀有箱中，false positive 将正常点误识别为离群点，导致高假正率和低精度.
  - 箱尺寸太大 → 一些频繁箱中包含离群点，false negative 将离群点当成正常点，导致高假负率和低召回率.
- **Solution:** Adopt **kernel density estimation** 核密度估计 to estimate the probability density distribution of the data. If the estimated density function is high, the object is likely normal. Otherwise, it is likely an outlier.

## Proximity-Based Approaches: Distance-Based vs. Density-Based Outlier Detection 基于距离的 vs. 基于密度的离群点检测

- 直觉：远离其他对象的对象是离群点。
- 基于邻近性方法的假设：离群点的邻近性与数据集中大多数其他对象显著不同。
- 两类基于邻近性的离群点检测方法：
  - Distance-based outlier detection: 对象 \(o\) 是离群点，如果其邻域中没有足够多的其他点。
  - Density-based outlier detection: 对象 \(o\) 是离群点，如果其密度相对远低于其邻居的密度。

## Distance-Based Outlier Detection

- 对于每个对象，检查 *r*-邻域中其他对象的数量，其中 *r* 是用户指定的距离阈值。
- 如果 \(D\) 中大部分对象（以 \(\pi\) 作为分数阈值 分数阈值）远离 \(o\)，即不在 \(o\) 的 *r*-邻域中，则对象 \(o\) 是离群点：

\[
\frac{|\{o'\mid \operatorname{dist}(o,o')\le r\}|}{|D|}\le \pi
\]

- 如果满足上述条件，则对象 \(o\) 是 DB(\(r,\pi\)) 离群点。
- 等价地，可以检查 \(o\) 与其 *k*-th nearest neighbor \(o_k\) 之间的距离，第 \(k\) 个最近邻，其中 \(k=\lceil \pi|D|\rceil\)。
- 如果 \(\operatorname{dist}(o,o_k)>r\)，则 \(o\) 是离群点，即 \(o\) 的 \(r\) 邻域中，除 \(o\) 之外至多有 \(k\) 个对象。

- **Efficient computation:** Nested loop algorithm 嵌套循环算法
  - 对于任意对象 \(o_i\)，计算其与其他对象的距离，并统计 *r*-邻域中的其他对象数量。
  - 如果有 \(\pi\cdot n\) 个其他对象在距离 *r* 以内，则终止内部循环。
  - 否则，\(o_i\) 是 DB(\(r,\pi\)) 离群点。
- **Efficiency:** 实际 CPU 时间不是 \(O(n^2)\)，而是随数据集大小线性增长，因为对于大多数非离群点对象，内部循环会提前终止。
