# 如何处理缺失值？

+   忽略元组 Ignore the tuple: 当缺少类标号时通常这样做（假设挖掘任务涉及分类）—当每个属性缺失值的百分比变化很大时，它的性能很差

+   人工填写缺失值: 费事 + 不可行？

+   使用一定的内容填充
+   —全局常量: e.g., “unknown”, a new class?!
+   —使用属性的中心度量（如均值或中位数）
+   —使用与给定元组属同一类的所有样本的属性均值或总位数: 更科学
+     - 如果将顾客按风险等级分类，则用具有相同信用风险的顾客的平均收入替换缺失值
+   —使用最可能的值: 使用回归、贝叶斯形式化的方法或者决策树等基于推理的工具
