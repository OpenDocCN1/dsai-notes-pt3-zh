# 数据预处理的主要任务

+   • **数据清理Data cleaning**
+     — 填写缺失的值，光滑噪声数据noisy data，识别或删除离群点，解决不一致性
+   • **数据集成Data integration**
+     — 多个数据库、数据立方体或文件的集成
+   • **数据规约Data reduction**
+     — 维规约Dimensionality reduction
+     — 数值规约Numerosity reduction
+   • **数据离散化和概念分层**
+     — 数据离散化
+     — 概念分层Concept hierarchy generation
+     — 数据规范化Normalization
