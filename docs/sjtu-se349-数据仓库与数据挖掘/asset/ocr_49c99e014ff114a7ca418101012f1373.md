# CBR应用案例
中心渔场预报专家系统

系统中，对空间条件属性，采用三个相似性度量方法（函数）：

+   - 基于渔场位置的相似
+     ```
+     sim1 = −Σ(wᵢ * distance(pos(goal) − pos(source))) / Σwᵢ
+     ```

+   - 基于温度场的相似
+     ```
+     sim2 = −Σ(wᵢ * difference(temp(goal) − temp(source))) / Σwᵢ
+     ```

+   - 基于温度梯度的相似
+     ```
+     sim3 = −Σ(wᵢ * difference(delta(goal) − delta(source))) / Σwᵢ
+     ```

其中，wᵢ是权重。如果该温度测试点与样本的中心渔场距离dᵢ越近，权越大。
