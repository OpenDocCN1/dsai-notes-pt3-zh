# 数据规约2: 数量规约Numerosity Reduction

+   - 通过选择替代的，更小的数据形式表示来减少数据量
+   - 参数化方法 Parametric methods (e.g., 回归)
+     - 使用模型估计数据，使得一般只需要存放模型参数，而不是实际数据（离群点可能也要存放）
+     - Ex.: 对数-线性模型 Log-linear models
+   - 非参数方法 Non-parametric methods
+     - 不用模型估计
+     - 包括: 直方图 histograms, 聚类 clustering, 抽样 sampling, ...
