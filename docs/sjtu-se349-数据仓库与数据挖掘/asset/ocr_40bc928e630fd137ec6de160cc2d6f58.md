# 后向传播和可解释性

+   - 神经网络是一个黑盒
+     - 神经网络的主要缺点是知识的表示
+       - 用加权链连接单元网络表示的知识难以理解
+   - 如何提取隐藏在训练后的神经网络中的知识及象征性地表示这些知识
+     - 解决方法
+       - (1) 网络提取规则
+         - 1) 网络剪枝，神经元和连接的数目会大大地减少
+         - 2) 通过进行链、单元或活跃值的聚类在网络中提取规则，以得到表达明确的分类规则
+       - (2) 灵敏度分析
+         - 用户评估一个给定输入变量对网络输出影响，改变该变量的输入而其它变量固定，监测网络输出的改变
