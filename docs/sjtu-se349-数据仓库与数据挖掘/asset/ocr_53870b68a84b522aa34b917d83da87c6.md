# ID3构建决策树的算法过程

数据集weather具有属性{outlook,temperature,humidity,wind}

+   - 属性outlook={sunny,overcast,rain}
+   - 属性temperature={hot,mid,cool}
+   - 属性humidity={high,normal}
+   - 属性wind={weak,strong}

第一步：寻找信息增益最大的属性

Entropy_outlook(S) = Σ_{i=1}^{k} |S_i|/|S| Entropy(S_i) = |S_1|/|S| Entropy(S_1) + |S_2|/|S| Entropy(S_2) + |S_3|/|S| Entropy(S_3)
= 5/14(-2/5 log₂ 2/5 - 3/5 log₂ 3/5) + 4/14(-4/4 log₂ 4/4 - 0/4 log₂ 0/4) + 5/14(-3/5 log₂ 3/5 - 2/5 log₂ 2/5)
= 0.694
Gain(S,outlook) = Entropy(S) - Entropy_outlook(S) = 0.94 - 0.694 = 0.246

Entropy_temperature(S) = Σ_{i=1}^{k} |S_i|/|S| Entropy(S_i) = |S_1|/|S| Entropy(S_1) + |S_2|/|S| Entropy(S_2) + |S_3|/|S| Entropy(S_3)
= 4/14(-2/4 log₂ 2/4 - 2 log₂ 2/4) + 6/14(-4/6 log₂ 4/6 - 2/6 log₂ 2/6) + 4/14(-3/4 log₂ 3/4 - 1/4 log₂ 1/4)
= 0.911
Gain(S,temperature) = Entropy(S) - Entropy_temperature(S) = 0.94 - 0.911 = 0.029

Entropy_humidity(S) = Σ_{i=1}^{k} |S_i|/|S| Entropy(S_i) = |S_1|/|S| Entropy(S_1) + |S_2|/|S| Entropy(S_2)
= 7/14(-3/7 log₂ 3/7 - 4/7 log₂ 4/7) + 7/14(-6/7 log₂ 6/7 - 1/7 log₂ 1/7)
= 0.788
Gain(S,humidity) = Entropy(S) - Entropy_humidity(S) = 0.94 - 0.788 = 0.152
Gain(S,wind) = 0.049
