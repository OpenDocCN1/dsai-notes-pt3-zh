# Attributes 属性

+   - 属性(Attribute):
+     数据挖掘
+     数据库
+     数据仓库
+     机器学习
+     统计学
+     也被称为维(Dimensions)、特征(Features)、变量(Variables)
+   - 通常是一个 数据字段，表示数据对象的一个特征
+     — E.g., 顾客_ID, 姓名, 地址
+   - 描述对象的一组属性称为属性向量（或特征向量）

+   - 属性类型：由属性可能具有的值的集合决定
+     — 标称属性(Nominal)
+     — 二元属性(Binary)
+     — 序数属性(Ordinal)
+     — 数值属性(Numeric)：量化的
+       - 区间标度(Interval-scaled)
+       - 比率标度(Ratio-scaled)
+     定性的
+     定量的
