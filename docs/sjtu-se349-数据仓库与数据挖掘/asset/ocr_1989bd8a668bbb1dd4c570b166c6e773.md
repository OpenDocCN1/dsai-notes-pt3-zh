# Data Warehouse: A Multi-Tiered Architecture
三层数据仓库架构

+   - 底层：数据仓库的数据库服务器
+     —关注的问题：如何通过这一层从操作数据库或其它外部数据源提取数据来构建数据仓库
+     - 通过称为信关Gateway的应用程序提取数据
+       - 开放数据库连接ODBC
+       - Java数据库连接 JDBC
+       - 数据库开放连接和嵌入 OLE-DB

+   - 中间层：OLAP服务器
+     —关注的问题：OLAP服务器如何实施（关系型OLAP，多维OLAP等）

+   - 前端客户工具层
+     —关注的问题：查询工具、报表工具、分析工具、挖掘工具等
