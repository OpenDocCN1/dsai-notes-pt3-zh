

## 基于聚类的离群点检测（3）：检测小簇中的离群点

+ FindCBLOF：检测小簇中的离群点

+ 找到簇，并按大小降序排序

+ 为每个数据点分配一个基于簇的局部离群因子 CBLOF：

+ 如果对象 p 属于一个大簇，则 CBLOF = 簇大小 X p 与簇之间的相似度

+ 如果 p 属于一个小的簇，则 CBLOF = 簇大小 X p 与最近的大簇之间的相似度

Ex. 在图中，o 是离群点，因为其最近的大簇是 C₁，但 o 与 C₁ 之间的相似度很小。对于 C₃ 中的任意点，其最近的大簇是 C₂，但其与 C₂ 的相似度很低，加上 |C₃| = 3 很小

## 基于聚类的方法：优势与劣势

+ 优势
+ — 无需任何标记数据即可检测离群点
+ — 可用于多种类型的数据
+ — 簇可以被视为数据的摘要
+ — 一旦获得簇，只需将任意对象与簇进行比较即可确定其是否为离群点（快速）

+ 劣势
+ — 有效性高度依赖于所使用的聚类方法——它们可能未针对离群点检测进行优化
+ — 计算成本高：需要先找到簇
+ — 一种降低成本的方法：固定宽度聚类
  • 如果簇的中心与点的距离在预定义阈值范围内，则将该点分配给该簇
  • 如果点无法分配给任何现有簇，则创建一个新簇，并且在某些条件下距离阈值可以从训练数据中学习

## 基于分类的方法 I：单类模型

+ - 思想：训练一个分类模型来区分“正常”数据和离群点
+ - 一种基本的方法：考虑一个包含标记为“正常”的样本和标记为“离群点”的样本的训练集
  - 但是，训练集通常严重有偏： “正常”样本的数量很可能远超“离群点”样本的数量
  - 无法检测未见过的异常

单类模型：构建一个分类器仅描述正常类。

+ - 使用诸如 SVM 之类的分类方法学习正常类的决策边界
+ - 任何不属于正常类（不在决策边界内）的样本都被判定为离群点
+ - 优点：可以检测新的离群点，这些离群点可能不会出现在训练集中离群点对象附近
+ - 扩展：正常对象可能属于多个类

## 基于分类的方法 II：半监督学习

### 半监督学习：结合基于分类和基于聚类的方法

### 方法

+ 使用基于聚类的方法，找到一个大簇 C 和一个小簇 C₁

+ 由于 C 中的某些对象带有“正常”标签，将 C 中的所有对象视为正常

+ 使用该簇的单类模型来识别离群点检测中的正常对象

+ 由于簇 C₁ 中的某些对象带有“离群点”标签，将 C₁ 中的所有对象声明为离群点

+ 任何不落入 C 模型的物体（例如 a）也被视为离群点

## 对基于分类的离群点检测方法的评论

+ 优势：离群点检测速度快

+ 瓶颈：质量在很大程度上取决于训练集的可用性和质量，但通常很难获得具有代表性和高质量的训练数据
