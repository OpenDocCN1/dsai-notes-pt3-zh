# Adaboost算法伪代码

```
算法：Adaboost——构建并行算法——创建分类器的组合。每个输出一个加权投票集。

输入：
- D：类标记的训练元组集。
- K：轮数（构造产生一个分类器）。
- 一个分类学习方案。

输出：一个复合模型。

方法：
(1) 将D中的每个元组的权重初始化为1/d；
(2) for t = 1 to k do                              // 对于每一轮
(3)　根据元组的权重从D中有放回抽样，得到Dₜ；
(4)　使用训练集Dₜ导出模型Mₜ；
(5)　计算Mₜ的错误率error(Mₜ)（8.34式）
(6)　if error(Mₜ) > 0.5 then
(7)　　转步骤(3)重试；
(8)　endif
(9)　for D中的每个被正确分类的元组do
(10)　元组的权重乘以error(Mₜ)/(1-error(Mₜ))　// 更新权重
(11)　规范化每个元组的权重；
(12)　endfor

使用组合分类器对元组分类：

(1)　将每个实例的权重初始化为0；
(2)　for t = 1 to k do                         // 对于每个分类器
(3)　　wₜ=log((1-error(Mₜ))/error(Mₜ))           // 分类器的权重
(4)　　C=Mₜ(x);                                  // 从Mₜ得到对类的实例
(5)　　将wₜ加到类C的权重；
(6)　endfor
(7)　返回具有最大权重的类；
```

# 随机森林
集成分类器 —— 3) 随机森林

- 想象组合分类器中的每个分类器都是一颗决策树
- 因此分类器的集合就是一个“森林”
- 分类时，每棵树都投票并返回得票最多的类
- 随机森林可以使用 装袋 与 随机属性选择 结合来构建
- 与 Adaboost 相比：
  - 对错误和离群点鲁棒性更好

# 什么是聚类分析？
什么是聚类分析？

- **Cluster 聚类 又称，自动分类/数据分割**
  - 把数据对象(或观测)划分成子集的过程
  - 簇内对象彼此相似，簇外彼此相异

- **Unsupervised Learning 非监督学习——用于聚类**
  - 没有提供类标号信息
  - 通过 观察学习，而不是通过 示例学习

# 聚类的常见应用
聚类的常见应用

- 空间数据分析
  - 通过聚类特征空间创建GIS中的主题映射
  - 探测空间簇,用空间数据挖掘解释它们

- 图像模式识别

# 质量：什么是好的聚类？
## 什么是一个好的聚类？

- **好的聚类方法**
  - 最大化类内的相似性
  - 最小化类间的相似性

- 聚类结果的质量依靠所使用度量的相似性和它的执行

- 聚类方法的质量也可以用它发现一些或所有隐含模式的能力来度量

# 要求和挑战
对聚类分析的要求

- 可伸缩性
  - 可以针对不同大小的数据进行聚类
- 处理不同属性类型的能力
  - 数值属性、二元属性、标称属性、序数属性、混合的属性等
- 基于约束的聚类
  - 现实世界的应用需要在各种约束条件下进行聚类
- 可解释性和可用性
- 其他
  - 发现任何形状的簇
  - 处理噪声数据的能力
  - 增量聚类和对输入次序不敏感
  - 聚类高维数据的能力

# 主要聚类方法
# 主要聚类方法的分类——（1）划分方法
# 问题表述
给定一个 n 个对象或元组的数据集，通过一个划分方法构建数据的 k 个划分，每个划分表示一个簇，并且 k <= n

- 每个组至少包含一个对象
- 每个对象属于且仅属于一个组

# 划分准则
同一个聚类中的对象尽可能的接近或相关，不同聚类中的对象尽可能的远离或不同

基本划分方法采取互斥的簇划分，每个对象必须恰好属于一个组。这一要求，例如在模糊划分技术中，可以放宽

大部分划分方法是基于距离的。给定要构建的分区数 k，划分方法首先创建一个初始划分。然后，采用一种迭代的重定位技术，通过把对象从一个组移动到另一个组来改进划分。为了达到全局最优，基于划分的聚类可能需要穷举所有可能的划分，计算量极大。
