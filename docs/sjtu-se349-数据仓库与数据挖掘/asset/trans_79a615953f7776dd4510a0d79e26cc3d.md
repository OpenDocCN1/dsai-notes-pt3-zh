## 监督学习 v.s. 非监督学习

- **监督学习（用于分类）**
  - 模型的学习在被告知每个训练样本属于哪个类的“指导”下进行
  - 新数据使用训练数据集中得到的规则进行分类

- **非监督学习（用于聚类）**
  - 每个训练样本的类编号是未知的，要学习的类集合或数量也可能事先未知
  - 通过一系列的度量、观察来建立数据中的类编号或进行聚类

## 分类的两种形式

## 分类

—需要一个模型或分类器，来预测类标号（分类的、无序的）

—例如：

- AllElectronic 的销售经理需要数据分析，以便猜测具有某些特征的顾客是否会购买新计算机
- 医学研究人员希望分析乳腺癌数据，以便预测病人应当接受三种治疗方案中的哪一种

## 数值预测

—构造模型（预测器）预测一个连续值函数或有序值

—例如：

- AllElectronic 的销售经理想要预测给定的客户在一次购物期间将花费多少钱

## 分类的一般方法

## 二阶段过程

—学习阶段

- 基于分析训练集来构建一个分类器模型

— 训练集 = 数据库元组（即训练元组 X）+ 相关联的类标号（标称属性），元组 X=(x1,x2,...,xn) 是 n 维属性向量，分别描述在属性 A1,A2,...,An 上的 n 个度量

— 学习一个映射或函数 y=f(X)，预测给定元组 X 的类标号 y，一般通过分类规则、决策树或数学公式的形式提供

—分类阶段

- 评估该模型的准确率是否可以接受，如果可以，使用该模型对新的数据进行分类

— 准确率：比较校验元组的类标号与学习模型对该元组的类预测，分类器正确分类的校验元组所占的百分比

— 校验元组独立于训练元组，否则会出现“过分适应数据”（过分拟合，overfit）的情况
