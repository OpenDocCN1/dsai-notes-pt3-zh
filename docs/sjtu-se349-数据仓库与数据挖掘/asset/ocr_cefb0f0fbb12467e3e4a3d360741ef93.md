# 多层前馈神经网络——定义网络拓扑

+   - 在开始训练之前，用户必须确定网络拓扑
+     - 输入层的单元数
+     - 隐藏层数（如果多于一层）
+     - 每一隐藏层的单元数
+     - 输出层的单元数

+   - 对训练样本中每个属性的值进行规格化，将有助于加快学习过程
+     - 通常，对输入值规格化，使得它们落入0.0和1.0之间

+   - 对于最好的隐藏层单元数，没有明确的规则
+     - 网络设计是一个实验过程，并可能影响训练结果网络的准确性
+     - 权的初值也可能影响结果的准确性
