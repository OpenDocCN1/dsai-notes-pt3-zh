## 小波变换 Wavelet transform（续）

### 哈尔基函数

- 为了表示矢量空间中的矢量，每一个矢量空间都需要定义一个基(basis)，哈尔基定义为
  
  $$\phi(x)=\begin{cases}1 & 0\le x<1\\0 & \text{其他}\end{cases}$$

- 为生成矢量空间而定义的基函数也叫做尺度函数(scaling function)。哈尔基尺度函数定义为
  
  $$\phi_i^j(x)=\phi(2^j x - i),\quad i=0,1,\cdots,(2^j-1)$$

- 其中，j为尺度因子，使函数图形缩小或放大
  i为平移参数，使函数沿x轴方向平移

### 哈尔函数（Haar小波）

- 哈尔小波(函数)
  —最古老和最简单的小波，定义为

```
ψ(x) = { 1    当 0 ≤ x < 1/2
        -1    当 1/2 ≤ x < 1
         0    其他 }
```

- —生成向量空间W⁰的哈尔小波

```
ψ₀⁰(x) = { 1    0 ≤ x < 1/2
          -1    1/2 ≤ x < 1
           0    其他 }
```
