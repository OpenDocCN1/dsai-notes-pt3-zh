# （1）产品质量的有效控制

+   - 采用LASSO(Least Absolute Selection and Shrinkage Operator)模型建立产品质量回归预测模型
+   - 用遗传算法由质量指标反推生产工艺参数

给定抗拉强度和延伸率的目标值，给出一系列的生产参数，根据回归的抗拉强度和延伸率模型，计算出这些生产参数对应的回归的抗拉强度和延伸率。留下误差小的几组生产参数，去掉误差大的生产参数。

然后通过生产参数向量的交叉和变异形成一些新的生产参数，构成一定规模的新种群，然后再重复上面的过程，直到种群内有一组生产参数所对应的抗拉强度和延伸率与期望的目标值足够接近或进化出了一定的代数为止。

+   - 抗拉强度相对误差平均值：0.0171
+   - 延伸率相对误差平均值：0.0463
+   - 抗拉强度测试命中率：97.8%
+   - 延伸率测试命中率：89.6%
