# Data Objects 数据对象

+   - 数据集由数据对象组成
+   - 一个 数据对象 代表一个实体
+     - 销售数据库：顾客、商品、销售……
+     - 医疗数据库：患者、治疗方法……
+     - 大学的数据库：学生、教授、课程……

+   - 有些人把它称之为……
+     - 样本(Samples)、实例(instances)、数据点(data points)、对象(objects)……

+   - 数据对象通常用 属性 描述
+   - 数据对象通常放在数据库中——
+     - 数据库的行 -> 数据对象
+     - 数据库的列 -> 属性
