# 数据质量：为什么要对数据预处理？

+   衡量数据质量：多种因素 A multidimensional view
+   —准确性 Accuracy：数据是否正确、准确
+   —完整性 Completeness：未被记录，或者缺少属性
+   —一致性 Consistency：有的数据被修改了，有的没有
+   —时效性 Timeliness：数据是否及时更新？
+   —可信性 Believability：数据有多可信？
+   —可解释性 Interpretability：数据是否容易理解？

+   数据质量依赖于数据的应用，对于给定的数据库，两个不同的用户可能有完全不同的评估
+   —例如，对顾客地址列表，有些地址已经过时或不正确，只有80%的地址是正确的
+     • 对于销售经理，会认为数据是不正确的
+     • 对于市场分析人员考虑目标市场营销而言，这是一个大型顾客数据库，对该数据库准确性还算满意
