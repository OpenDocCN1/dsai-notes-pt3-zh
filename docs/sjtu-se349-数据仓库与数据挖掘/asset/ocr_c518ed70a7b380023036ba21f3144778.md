# 模糊集合及其运算

+   5. **分配律**  
+      \(A\cap(B\cup C)=(A\cap B)\cup(A\cap C)\)  
+      \(A\cup(B\cap C)=(A\cup B)\cap(A\cup C)\)

+   6. **0-1律**  
+      \(A\cup\varnothing=A,\ A\cap\varnothing=\varnothing,\ A\cup U=U,\ A\cap U=A\)

+   7. **还原律**  
+      \((A^c)^c=A\)

+   8. **对偶律**  
+      \((A\cup B)^c=A^c\cap B^c,\ (A\cap B)^c=B^c\cup A^c\)
