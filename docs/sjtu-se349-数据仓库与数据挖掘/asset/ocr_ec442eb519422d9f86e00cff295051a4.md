# Attributes 属性 3 —— 序号属性(Ordinal)

+   - 序号属性(Ordinal): 定性的
+     - 可能的值之间具有有意义的序或秩评定（先后次序）
+       - 可乐杯大小 = {大、中、小}
+       - 成绩 = {A+、A、A-、B+、B、B-、......}
+     - 对于记录不能客观度量的主观质量评估，序号属性是有用的。因此，序号属性通常用于等级评定调查
+     - 序号属性也可以通过把数值量的值域划分成有限个有序类别，把数值属性离散化而得到
+     - 相继值之间的差是未知的
+   - 可以用 众数（集合中最频繁出现的値）和 中位数（有序数据值的中间値）来表示中心趋势，但不能定义均值
