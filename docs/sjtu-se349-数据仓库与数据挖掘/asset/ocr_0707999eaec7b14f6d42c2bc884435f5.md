# 关于分类的其它问题

+   - **多类分类**
+     - CART、SVM等算法仅仅支持二元分类，如何扩充这些算法，允许多类划分
+   - **半监督分类**
+     - 同时使用有类标号的数据和无类标号的数据构建分类器
+   - **主动学习**
+     - 迭代的监督学习
+     - 适合数据丰富但类标号稀缺或获取昂贵的情况
+     - 学习算法是主动的，可以有目的地向用户询问类标号，使需要的用于学习概念的元组数远小于典型的监督学习
+   - **迁移学习**
+     - 为训练一个分类模型需要进行大量的工作。如训练客户对照相机的评论，需要对大量的数据加标签，如果对每一类产品都如此训练一个评分分类模型，需要付出大量的努力。能否改编一个已有的分类模型（如为照相机建立的模型），帮助学习一个用于TV的分类模型？
+     - 从一个或多个源任务提取知识，并将这些任务用于目标任务
