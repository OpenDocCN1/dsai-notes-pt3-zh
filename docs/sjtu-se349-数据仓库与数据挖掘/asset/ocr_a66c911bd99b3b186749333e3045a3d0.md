# Attributes 属性 1 —— 标称属性(Nominal)

+   - 标称属性(Nominal)：定性的
+     - “分类的”，代表某种类别、编码或状态
+     - 不必具有有意义的序
+     - “枚举的”
+       - 头发颜色 = {黑色、棕色、淡黄色、红色、赤褐色、灰色...}
+       - 婚姻状况 = {单身、已婚、离异、丧偶}

+   - 可以用 数 表示这些符号或名称
+     - 对于Hair_color，指定代码0表示黑色，1表示棕色...
+     - Customer_ID，它可能值可以都是数值。

+   - 但它不是定量的，并不打算定量地使用这些数，数学运算没有意义
+     - 与从一个年龄值（年龄是数值属性）减去另一个不同，从一个顾客号减去另一个顾客号毫无意义
+     - 均值、中位数等都没有意义
