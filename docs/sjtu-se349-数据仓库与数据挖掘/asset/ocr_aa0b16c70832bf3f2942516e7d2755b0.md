# 区域医疗信息网络

![](bbox=[0.07, 0.22, 0.65, 0.78])

从医疗到健康，把健康检查放在社区，并通过区域医疗中心进行干预

区域医疗信息网络解决方案将不同医疗机构的信息和服务进行整合，实现医疗卫生的信息共享和协同工作流程。其中包括：

+   - 电子健康档案系统 (EHR - Electronic Health Record)
+     - 基于开放标准的信息共享交换
+     - 基于内容的查询与分析
+     - 灵活强大的数据分析与展现

+   - 区域病人索引系统 ( EMPI - Enterprise Master Patient Index )
+     - 维护准确最新的病人信息数据
+     - 基于随机概率匹配技术
+     - 支持大数据量人口信息匹配去重

+   - 区域医疗信息服务总线平台

+   - 区域医疗资源信息目录

+   - 医疗机构前置系统平台

+   - 区域医疗应用系统平台

+   - 区域医疗门户平台

建立多层次的、互连互通的、支持医学科研与疾病预防的区域医疗信息网络（RHIN - Regional Healthcare Information Network）
