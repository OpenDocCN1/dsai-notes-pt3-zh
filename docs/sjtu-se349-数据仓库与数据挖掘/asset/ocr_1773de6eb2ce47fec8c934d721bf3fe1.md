# 第四届全国大学生数学竞赛决赛试题评分细则

（非数学类，2013年3月）

一、（本题共12分）计算下列各题：

1. 求极限 \(\lim\limits_{x \to 0} \dfrac{1}{x^3} \left( \dfrac{1}{x} \int_0^x e^{t^2} dt - 1 - \dfrac{x^2}{3} \right)\).

2. 计算 \(\iiint_\Omega \sqrt{x^2+y^2+z^2} \, dV\)，其中 \(\Omega: x^2+y^2+z^2 \le z\).

二、（本题共12分）设 \(f(x)\) 在闭区间 \([0,1]\) 上连续，且 \(\displaystyle \int_0^1 f(x) \, dx = 0\)。证明：存在 \(\xi \in (0,1)\)，使得 \(\displaystyle f(\xi) + \int_0^\xi f(t) \, dt = 0\).

三、（本题共12分）设 \(f(x)\) 在 \([0,+\infty)\) 上连续，在 \((0,+\infty)\) 内可导，且 \(f(0)=0\)。若 \(f'(x) > f(x)\) 对所有 \(x>0\) 成立，证明：对任意 \(x>0\)，有 \(f(x) > 0\).

四、（本题共12分）设 \(A\) 为 \(n\) 阶实对称矩阵，且 \(A^2 = A\)。证明：存在正交矩阵 \(Q\)，使得 \(Q^T A Q = \operatorname{diag}(I_r, 0)\).

五、（本题共12分）设 \(f(x)\) 在 \([0,1]\) 上具有连续的二阶导数。证明：\(\displaystyle \left| \int_0^1 f(x) \, dx - \frac{f(0)+f(1)}{2} \right| \le \frac{1}{8} \max_{0 \le x \le 1} |f''(x)|\).

六、（本题共12分）设 \(a_1, a_2, \ldots, a_n\) 为正实数，证明：\(\displaystyle \frac{a_1}{a_2+a_3} + \frac{a_2}{a_3+a_4} + \cdots + \frac{a_n}{a_1+a_2} \ge \frac{n}{2}\).
