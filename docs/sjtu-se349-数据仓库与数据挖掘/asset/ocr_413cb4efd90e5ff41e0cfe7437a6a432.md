# 数据变换Data Transformation

+   通过变换将整个数据集的给定属性的值映射到新的值，每个老的值都能够通过新的值识别

+   方法
+   — 光滑Smoothing: 去除数据中的噪声（数据清理的方法）
+     • 分箱、回归、聚类
+   — 属性构造Attribute/feature construction（数据规约方法）
+     • 由给定的属性构造新的属性并添加到属性集中
+   — 聚集Aggregation: 对数据进行汇总，构造数据立方体（数据规约方法）
+   — 规范化Normalization: 把属性数据按比例缩放，使之落入特定大小区间
+     • min-max normalization
+     • z-score normalization
+     • normalization by decimal scaling
+   — 离散化Discretization: 组织更高层概念

+   数据预处理的主要任务之间存在许多重叠，上述策略中前三个在前面已经介绍
