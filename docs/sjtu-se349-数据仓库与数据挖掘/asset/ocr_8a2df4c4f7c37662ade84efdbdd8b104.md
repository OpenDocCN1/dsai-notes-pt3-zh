# 视角1： Knowledge Discovery 知识发现（KDD）过程

观点1：把数据挖掘看成KDD的一个部分；观点2：把数据挖掘看成KDD的同义词

+   - **Cleaning 数据清理**（可能占全部工作的60%！）
+     — 消除噪声和不一致数据
+   - **Integration 数据集成**
+     — 多种数据源可以组合在一起
+   - **Selection 数据选择**
+     — 从数据库中提取与分析任务相关的数据
+   - **Transaction 数据变换**
+     — 汇总或聚集操作，把数据变换和统一为适合挖掘的形式
+   - **Mining 数据挖掘**
+     — 智能方法提取模式
+   - **Evaluation 模式评估**
+     — 兴趣度度量
+   - **Presentation 知识表示**
+     — 向用户通过可视化技术和知识表现技术来展现挖掘的知识
