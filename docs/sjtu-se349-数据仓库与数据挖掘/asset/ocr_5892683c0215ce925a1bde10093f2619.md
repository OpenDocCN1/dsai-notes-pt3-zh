# 多维数据模型 Cont.

例 AllElectronics可能创建一个数据立方体sales,以销售为中心的主体进行组织，使得数据能够在多维上进行建模和浏览

+   —维表： item (item_name, brand, type,......), time(day, week, month, quarter, year,......),......
+   —事实： dollars_sold（销售额）,units_sold（销售量）
+   —事实表： 包含了度量和每个相关维表的码 (item_key,time_key,......)
