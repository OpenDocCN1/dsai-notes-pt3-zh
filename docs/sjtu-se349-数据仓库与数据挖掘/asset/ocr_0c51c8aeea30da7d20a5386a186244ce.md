# 如何理解教材P68主成分分析步骤？

+   - 给定一个$n$维的$N$个数据向量，找到$k \le n$个正交向量（主成分）去表示原有的数据
+     - 对输入数据规范化，使得每个属性都落入相同的空间
+     - 计算$k$个标准正交向量，作为规范化输入数据的基（主成分）
+     - 每个输入的向量都是这$k$个向量的线性组合
+     - 对主成分按“重要性”或强度降序排列。
+     - 既然主成分根据已降序排列，因此可以通过去掉较弱的成分（即方差较小的那些）来契约数据

+   - 只适用于数值数据
