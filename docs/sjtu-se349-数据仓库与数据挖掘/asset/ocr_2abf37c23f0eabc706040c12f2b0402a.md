# 朴素贝叶斯分类的概念

设D是训练元组和他们相关联的类标号的集合，每个元组用一个n维属性向量X= (x1, x2, ..., xn)，假设有m个类C1, C2, ..., Cm

分类法将预测X属于具有 最高后验概率 的类，即 P(Ci|X)的最大值 P(Ci|X)> P(Cj|X)(i!=j , 1<=j<=m )

根据贝叶斯定理，由于P(X)对于所有类为常数，所以只要P(X|Ci)P(Ci) 最大即可

P(Ci|X)= P(X|Ci)P(Ci)/P(X) = P(X|Ci)×P(Ci)/P(X)

类的先验概率可以用P(Ci)=|Ci,D|/|D|估计，|Ci,D|是D中Ci类的训练元组数

如果P(Ci)未知，那么假设这些类等概率，就只要 P(X|Ci) 最大即可
