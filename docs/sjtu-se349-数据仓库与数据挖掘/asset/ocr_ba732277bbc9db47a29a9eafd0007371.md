# （3）直接聚类法

+   ① 取 $\lambda_1=1$（最大值），作相似类 $[x_i]_R=\{x_j\mid r_{ij}=\lambda_1\}$

当不同相似类出现公共元素时，将公共元素所在类合并。

+   ② 取 $\lambda_2=$ 次大值，找出 $r_{ij}=\lambda_2$ 的元素对 $(x_i,x_j)$，

将对应于 $\lambda_2$ 的等价分类中 $x_i$ 所在类与 $x_j$ 所在类合并，所有情况合并后得到相应于 $\lambda_2$ 的等价分类。

+   ③ 依次类推，直到合并到 $U$ 成为一类为止。
