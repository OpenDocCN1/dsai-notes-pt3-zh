

## BP网络的学习算法——学习步骤

- 偏倚由下式更新：
  - Δθⱼ = (l) Errⱼ
  - θⱼ = θⱼ + Δθⱼ
  - 其中，Δθⱼ是偏倚θⱼ的改变。
- 终止条件：
  - (1) 前一周期所有的Δwⱼᵢ都小于某个指定的阈值
  - (2) 前一周期未正确分类的样本百分比小于某个阈值
  - (3) 超过预先指定的周期数

## 后向传播和可解释性

- 神经网络是一个黑盒。
  - 神经网络的主要缺点是知识的表示。
  - 用加权链连接单元网络表示的知识难以理解。
- 如何提取隐藏在训练后的神经网络中的知识并象征性地表示这些知识？
  - 解决方法：
    - (1) 网络提取规则
      - 1) 网络剪枝，神经元和连接的数目会大大地减少
      - 2) 通过进行链、单元或活跃值的聚类，在网络中提取规则，以得到表达明确的分类规则
    - (2) 灵敏度分析
      - 用于评估一个给定输入变量对网络输出的影响：改变该变量的输入而其他变量固定，监测网络输出的改变。

识别每个隐藏结点Hᵢ的公共活跃值集合：

H₁: (-1, 0, 1)  
H₂: (0, 1)  
H₃: (-1, 0.24, 1)

导出与输出结点O₁的公共活跃值相关的规则：

IF (H₂ = 0 AND H₃ = -1) OR  
(H₁ = -1 AND H₂ = 1 AND H₃ = -1) OR  
(H₁ = -1 AND H₂ = 0 AND H₃ = 0.24)  
THEN O₁ = 1, O₂ = 0  
ELSE O₁ = 0, O₂ = 1

导出与输入节点Iᵢ到输出结点Oⱼ相关的规则：

IF (I₂ = 0 AND I₇ = 0) THEN H₂ = 0  
IF (I₄ = 1 AND I₆ = 1) THEN H₃ = -1  
IF (I₅ = 0) THEN H₃ = -1

得到关于输入和输出类的规则：

IF (I₂ = 0 AND I₇ = 0 AND I₄ = 1 AND I₆ = 1)  
THEN class = 1 ↔ O₁ = 1, O₂ = 0  
IF (I₂ = 0 AND I₇ = 0 AND I₅ = 0) THEN class = 1

### 例：下表为某药品的销售情况，现构建一个如下的三层BP神经网络对药品的销售进行预测

- 输入层有3个结点，隐含层5个结点，隐含层的激活函数为`tansig`；
- 输出层结点数为1个，输出层的激活函数为`logsig`；
