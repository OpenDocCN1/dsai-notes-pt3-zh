# 2006世界杯同样是德国和阿根廷的赛场
不是章鱼保罗救了德国，而是一个神秘的小纸条

+   - 分析小组的人员收集了阿根廷队13000个点球的录像，所有这些采集回来的点球数据被输入数据库中，并根据阿根廷射门练习的数据找出了一些可以描述射门动作的行为特征，最终从这些特征中提炼出很少的更具体特征。
+     - 阿里拉，短助跑，右下角；
+     - 里克尔梅，斜向助跑，右下角；
+     - 马克西，长距离助跑，左上角；
+     - 坎比亚索，长距离助跑，右侧；
+     - 索林，短助跑，右下角；
+     - 特维斯，短助跑，中路；
+     - ……。

+   - 这些特征描述了阿根廷队谁罚点球、怎样罚点球的规律。正是这张小纸条让德国队走得更远！小纸条总结的这些规律是大数据分析和挖掘的结果！
