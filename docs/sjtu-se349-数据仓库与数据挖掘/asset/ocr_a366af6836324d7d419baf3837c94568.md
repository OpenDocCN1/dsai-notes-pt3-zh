# 数据挖掘的技术工具
1.通用型工具

+   - 通用型工具占有最大和最成熟的那部分市场
+   - 通用的数据挖掘工具不区分具体数据的含义，采用通用的挖掘算法，处理常见的数据类型。主要产品包括
+     - IBM 公司Almaden 研究中心的QUEST 系统
+     - SGI 公司的MineSet 系统
+     - 加拿大Simon Fraser 大学的DBMiner 系统
+     - SAS Enterprise Miner
+     - SPSS Clementine
+     - IBM Intelligent Miner
+     - Oracle Darwin
+     - Unica PRW
+     - ……
