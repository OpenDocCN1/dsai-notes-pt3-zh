# 回顾：朴素贝叶斯分类

+   - 计算 P(X|Ci) 开销可能非常大
+   - 为降低计算P(X|Ci) 开销，做简单假设 —— 属性有条件的相互独立（属性之间不存在依赖关系），则：
+     $P(X|C_i)=\prod_{k=1}^{n}P(x_k|C_i)=P(x_1|C_i)\times P(x_2|C_i)\times...\times P(x_n|C_i)$
+   - 其中 x_k 表示元组 X 在属性 A_k 的值
+   - 如果 A_k 是分类属性， P(x_k|Ci) 是 D 中属性 A_k 的值为 X_k 的 Ci 类的元组数除以 Ci 类的元组数 |Ci, D|
