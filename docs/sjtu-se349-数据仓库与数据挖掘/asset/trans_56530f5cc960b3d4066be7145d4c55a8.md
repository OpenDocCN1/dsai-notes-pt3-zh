基于概率模型的聚类——一个说明聚类的一般框架

- 之所以在数据集上进行聚类分析，是因为假定数据集中的对象属于不同的固有类别。
- 可以使用聚类趋势分析（霍普金斯统计量）考查数据集是否包含能够形成有意义簇的对象。这里，隐藏在数据中的固有类别是潜在的，因为我们不可能直接观测到它们，而必须使用观测数据来推断。
- 聚类分析的目标是发现隐藏的类别。作为聚类分析主题的数据集可以看作隐藏类别的可能实例的一个样本，但是没有类标号。由聚类分析导出的簇使用数据集推断，并且旨在逼近隐藏的类别。
- 模糊簇提供了一种灵活性，允许一个对象属于多个簇。有没有一个说明聚类的一般框架，其中对象可以用概率的方法参与多个簇？
- 基于概率模型的聚类可以回答这一问题。
- 从统计学上讲，可以假定隐藏的类别是数据空间上的一个分布，可以使用概率密度函数（或分布函数）精确地表示。
- 称这种隐藏的类别为概率簇 C。它的密度函数为 f；对于数据空间的点 o，f(o) 是 C 的一个实例在 o 上出现的相对似然。
- 隐藏类别（即概率簇）是数据空间上的一个分布，可以使用概率密度函数或分布函数进行数学表示。

## 基于概率模型的聚类
### 基于概率模型的聚类——一个说明聚类的一般框架

- 例：数字相机销售中的两类。
- 业余型 C₁ 与专业型 C₂。
- C₁、C₂ 关于价格属性的密度函数 f₁、f₂。
- 将每个类别看作一个概率簇。

概率簇 C 的密度函数为 f；对于数据空间的点 o，f(o) 是 C 的一个实例在 o 上出现的相对似然。

聚类分析的目标是找出 k 个概率簇 C₁, ..., Cₖ。对于包含 n 个数据对象的数据集 D，可以将其看作这些簇的可能实例构成的有限样本。每个簇 Cⱼ 都与从该簇抽样一个实例的概率 ωⱼ 相关。按下述步骤总共执行 n 次，产生 D 的 n 个对象 o₁, ..., oₙ：

- 按照概率 ω₁, ..., ωₖ，选择一个簇 Cⱼ。
- 按照 Cⱼ 的概率密度函数 fⱼ，选择一个 Cⱼ 的实例。

∑ⱼ₌₁ᵏ ωⱼ = 1

## 基于模型的聚类

- 由 k 个概率簇 C₁, ..., Cₖ 构成的集合 C，分别具有概率密度函数 f₁, ..., fₖ 及其概率 ω₁, ..., ωₖ。
- 由簇 Cⱼ 生成对象 o 的概率为：  
  P(o|Cⱼ) = ωⱼ fⱼ(o)
- 由簇集合 C 生成对象 o 的概率为：  
  P(o|C) = Σⱼ₌₁ᵏ ωⱼ fⱼ(o)

由于假定对象是独立生成的，对于数据集 D = {o₁, ..., oₙ}，有：

P(D|C) = ∏ᵢ₌₁ⁿ P(oᵢ|C) = ∏ᵢ₌₁ⁿ Σⱼ₌₁ᵏ ωⱼ fⱼ(oᵢ)

- 任务：找出由 k 个概率簇组成的集合 C，使 P(D|C) 最大。
- 数据集 D 上的基于概率模型的聚类分析任务是找出 k 个概率簇的集合 C，使得 P(D|C) 最大。
- 然而，最大化 P(D|C) 通常难以实现，因为一个簇的概率密度函数可能具有任意复杂的形式。
- 为使计算可行（作为一种折中），假定概率密度函数属于某些参数化分布。

## 单变量高斯混合模型
单变量高斯混合模型

O = {o₁, ..., oₙ}（n 个观测对象），Θ = {θ₁, ..., θₖ}（k 个分布的参数），Pⱼ(oᵢ|θⱼ) 表示使用参数 θⱼ 时，oᵢ 由第 j 个分布生成的概率，则有：

P(oᵢ|Θ) = Σⱼ₌₁ᵏ ωⱼ Pⱼ(oᵢ|θⱼ)  
P(O|Θ) = ∏ᵢ₌₁ⁿ Σⱼ₌₁ᵏ ωⱼ Pⱼ(oᵢ|θⱼ)

- 单变量高斯混合模型。
- 假设每个簇的概率密度函数都服从一维高斯分布。设有 k 个簇。
- 每个簇的概率密度函数以 μⱼ 为中心，标准差为 σⱼ，θⱼ = (μⱼ, σⱼ)，则有：

Pⱼ(oᵢ|θⱼ) = 1/(√(2π)σⱼ) e^(-(oᵢ-μⱼ)²/(2σⱼ²))  
P(oᵢ|Θ) = Σⱼ₌₁ᵏ ωⱼ · 1/(√(2π)σⱼ) e^(-(oᵢ-μⱼ)²/(2σⱼ²))

P(O|Θ) = ∏ᵢ₌₁ⁿ Σⱼ₌₁ᵏ ωⱼ · 1/(√(2π)σⱼ) e^(-(oᵢ-μⱼ)²/(2σⱼ²))

使用单变量高斯混合模型的基于概率模型的聚类任务是进行推断，使似然最大化。

## 期望最大化算法
期望最大化算法

如何计算模糊聚类和基于概率模型的聚类？这里介绍一种原理性方法。从回顾 k-均值聚类问题和 k-均值算法开始。

k-均值算法在每次迭代中有两个步骤：

- **期望步（E-step）**：给定当前簇中心，将每个对象分配到距离它最近的簇。即，预期一个对象属于最近的簇。
- **最大化步（M-step）**：给定簇分配，对于每个簇，算法调整中心，使分配到该簇的对象与新中心之间的距离之和最小，即最大化对象与该簇的相似度。

## 期望最大化算法
期望最大化算法

- 将这一两步过程推广，以处理模糊聚类和基于概率模型的聚类。
- （EM）算法：一种用于求解统计模型中参数最大似然估计或最大后验估计的框架。
- EM 是一种算法框架。在模糊聚类或基于概率模型的聚类中，EM 算法从初始参数集出发，并不断迭代，直到聚类不再改善，即聚类收敛或变化足够小（小于预先设定的阈值）。
- 每次迭代也由两步组成：
  - E-step：根据当前模糊聚类或概率簇的参数，将对象分配到簇。
  - M-step：找到新的聚类或参数，使平方误差和（SSE）或期望似然最大化。
