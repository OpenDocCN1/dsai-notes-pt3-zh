# 用于度量的两种数据结构
数据矩阵与相异性矩阵

# 数据矩阵

+   - 用于存放数据对象
+   - 或称对象——属性结构
+   - 关系表形式或 nxp 矩阵存放 n 个数据对象
+   - 二模（行代表对象和列代表属性）

![](bbox=[0.617, 0.189, 0.904, 0.458])

# 相异性矩阵

+   - 用于存放数据对象对的相异性值
+     - d(i,j)=0，一个对象自身差别为0
+   - 或称对象——对象结构
+   - 存放 n 个对象两两间的邻近度
+   - 通常用 nxn 的矩阵表示
+   - 单模（只包括一类实体或事物）
+   - 许多聚类和最近邻算法都在相异性矩阵上运行
