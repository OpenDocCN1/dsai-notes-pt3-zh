
## 霍普金斯统计量

霍普金斯统计量（Hopkins Statistic）是一种空间统计量，检验空间分布的变量的空间随机性。给定数据集 D，它可以看做随机变量 o 的一个样本，想要确定 o 在多大程度上不同于数据空间中的均匀分布。按以下步骤计算霍普金斯统计量：

- (1) 均匀地从 D 的空间中抽取 n 个点 p₁, …, pₙ。也就是说，D 的空间中的每个点都以相同的概率包含在这个样本中。对于每个点 pᵢ (1 ≤ i ≤ n)，我们找出 pᵢ 在 D 中的最近邻，并令 xᵢ 为 pᵢ 与它在 D 中的最近邻之间的距离，即 xᵢ = min_{v ∈ D} {dist(pᵢ, v)} (10.25)

- (2) 均匀地从 D 中抽取 n 个点 q₁, …, qₙ。对于每个点 qᵢ (1 ≤ i ≤ n)，我们找出 qᵢ 在 D − {qᵢ} 中的最近邻，并令 yᵢ 为 qᵢ 与它在 D − {qᵢ} 中的最近邻之间的距离，即 yᵢ = min_{v ∈ D, v ≠ qᵢ} {dist(qᵢ, v)} (10.26)

- (3) 计算霍普金斯统计量 H：H = (Σ_{i=1}^{n} yᵢ) / (Σ_{i=1}^{n} xᵢ + Σ_{i=1}^{n} yᵢ) (10.27)

霍普金斯统计量告诉我们数据集 D 有多大可能服从数据空间的均匀分布：如果 D 是均匀分布的，则 Σ yᵢ 和 Σ xᵢ 将会很接近，因而 H 大约为 0.5。然而，如果 D 是高度偏斜的，则 Σ yᵢ 将显著地小于 Σ xᵢ，因而 H 将接近于 0。

## Determine the Number of Clusters（确定数据集中的簇数）

### 经验方法

k ≈ √(n/2)，其中 n 是数据集中的点数；例如 n = 200，k = 10。

### 肘方法

使用簇内方差关于簇数的曲线的拐点。

### 交叉验证

把给定的数据集 D 划分为 m 个部分，然后使用 m-1 个部分建立一个聚类模型；使用检验集中所有点与它们的最近形心之间的距离的平方和来度量聚类模型拟合检验集的程度。

## Measuring Clustering Quality（测定聚类质量）

- 根据是否有基准可用，常见方法分为两类：
  - 外在方法（有可用的基准）
  - 内在方法（没有可用基准，通过考虑簇的分离情况评估聚类好坏）
- 外在方法：把基准与聚类进行比较，来评估聚类。
- 内在方法：通过考察簇的分离情况和簇的紧凑情况来评估聚类。
  - 许多内在方法都利用数据集中对象之间的相似度度量。

## Measuring Clustering Quality: External Methods（测定聚类质量）

- 外在方法：给定基准，对聚类赋予一个评分 Q(C, T)。
- 一般而言，一种聚类质量度量 Q 是有效的：
  - 簇的同质性
  - 簇的完全性
  - 碎布袋
  - 小簇保持性
- 例如，B³ 精度和召回率：
  - 一个对象的精度指，同一簇中有多少个其他对象与该对象同属一个类别。
  - 一个对象的召回率反映有多少同一类别的对象被分配在相同的簇中。
- 内在方法：轮廓系数。

## Fuzzy Set and Fuzzy Cluster

- Clustering methods discussed so far（目前讨论的聚类方法）
  - Every data object is assigned to exactly one cluster（每个数据对象被恰好指派给一个簇）
  - 例如：将客户分配给销售经理
- Some applications may need fuzzy or soft（模糊或灵活的）cluster assignment（某些应用可能需要模糊或灵活的簇指派）
  - Ex. An e-game could belong to both entertainment and software
  - 例：客户关于摄像机和计算机的评论各有一个簇。如果一个评论是关于计算机和摄像机兼容的，应该放在哪个簇？

这时需要一种聚类方法，它允许一个评论属于多个簇。为了反映一个评论属于某个簇的强度，你想在评论到簇的指派上附加一个代表这种部分隶属关系的权重。

- Methods: fuzzy clusters and probabilistic model-based clusters（模糊聚类和基于概率模型的聚类）
- Fuzzy cluster：模糊集 S 是 X 的子集。A fuzzy set S 可以表示为：
  - F_S: X → [0, 1]（value between 0 and 1）
  - 给定对象集 X = {X₁, X₂, ..., Xₙ}，允许 X 中的每个对象都具有一个属于 S 的 [0,1] 隶属度。

Example: Popularity（流行程度） of cameras is defined as a fuzzy mapping:

| Camera | Sales (units) |
| --- | --- |
| A | 50 |
| B | 1320 |
| C | 860 |
| D | 270 |

```
Pop(o) = { 1, if 1,000 or more units of o are sold
           i/1000, if i units of o are sold (i < 1000) }
```

Then, A(0.05), B(1), C(0.86), D(0.27)。

Fuzzy clustering（模糊聚类）：

- 给定对象集 O₁, ..., Oₙ，k fuzzy clusters C₁, ..., Cₖ can be represented as a partition matrix（划分矩阵）：
  - M = [wᵢⱼ]（1 ≤ i ≤ n，1 ≤ j ≤ k），其中 wᵢⱼ = |Rᵢ ∩ Cⱼ| / |Rᵢ ∩ (C₁ ∪ C₂)| = |Rᵢ ∩ Cⱼ| / |Rᵢ ∩ {数码相机, 镜头, 计算机}|
  - wᵢⱼ 是 Oᵢ 在模糊簇 Cⱼ 的隶属度。
- P1: for each object oᵢ and cluster Cⱼ, 0 ≤ wᵢⱼ ≤ 1（强制模糊簇是模糊集 fuzzy set）。
- P2: for each object oᵢ, Σ_{j=1}^{k} wᵢⱼ = 1，确保每个对象同等地参与聚类。
- P3: for each cluster Cⱼ, 0 < Σ_{i=1}^{n} wᵢⱼ < n，确保每个簇都至少有一个对象。

设 c₁, ..., cₖ 为 k 个簇的中心。p 是一个参数，控制隶属度的影响；p 越大，隶属度的影响越大。

对于对象 oᵢ，误差平方和（SSE, sum of the squared error）为：

SSE(oᵢ) = Σ_{j=1}^{k} wᵢⱼᵖ dist(oᵢ, cⱼ)²

对于簇 Cⱼ：

SSE(Cⱼ) = Σ_{i=1}^{n} wᵢⱼᵖ dist(oᵢ, cⱼ)²

Measure how well a clustering fits the data（衡量聚类对数据的拟合程度，即模糊聚类对数据集的拟合程度）：

SSE(C) = Σ_{i=1}^{n} Σ_{j=1}^{k} wᵢⱼᵖ dist(oᵢ, cⱼ)²
