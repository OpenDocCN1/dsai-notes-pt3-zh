# # Partitioning Algorithms - Basic Concept
## 划分方法－基本概念

# 划分方法

把具有 n 个对象的数据库 D 构造成具有 k 个簇的集合的划分

$E = \sum_{i=1}^{k}\sum_{p\in C_i}(d(p,c_i))^2$

（其中 $c_i$ 是簇群 $C_i$ 的**形心**）

> 对象 p 与该簇的代表 cᵢ 的误差，用它们的欧氏距离表示

簇 $C_i$ 的质量——**簇内变差**

这个目标函数试图使生成的结果簇尽可能紧凑和独立

# 给定 k，找出有 k 个簇的一个划分使得所选择的划分准则最优

全局最优：穷举所有可能的划分（**NP-困难**）

+   - 簇个数 k、空间维度 d、对象个数 n：时间复杂度 $O(n^{d+1}\log n)$

启发式方法：**k-平均算法** 和 **k-中心点算法**

+   - **k-均值算法**（MacQueen’67）：把簇的形心定义为簇内点的均值
+   - **k-中心点算法**或 PAM（Partition around medoids）：每一个簇用接近聚类中心的一个对象（代表对象）表示
