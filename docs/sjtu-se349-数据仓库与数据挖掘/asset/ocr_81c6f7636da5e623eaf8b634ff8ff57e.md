# 数据离散方法

+   典型方法: 所有方法可以递归使用

+   ——分箱Binning
+     - Top-down split, unsupervised

+   ——直方图Histogram analysis
+     - Top-down split, unsupervised

+   ——聚类分析Clustering analysis (unsupervised, top-down split or bottom-up merge)

+   ——决策树分析Decision-tree analysis (supervised, top-down split)

+   ——相关分析Correlation (e.g., χ²) analysis (unsupervised, bottom-up merge)
