# 傅里叶变换 Fourier transform

—1807: Joseph Fourier

+   - 傅立叶理论指出，一个信号可表示成一系列正弦和余弦函数之和，叫做傅立叶展开式

![](bbox=[0.18, 0.35, 0.88, 0.52])

![](bbox=[0.25, 0.52, 0.95, 0.78])

```
F(ω) = ∫_{-∞}^{+∞} f(t) e^{-jωt} dt
```

where  e^{-jωt} = cos ωt − j sin ωt

```
f(t) = 1/(2π) ∫_{-∞}^{+∞} F(ω) e^{jωt}
```

+   - 只有频率分辨率而没有时间分辨率
+   - 可确定信号中包含哪些频率的信号，但不能确定具有这些频率的信号出现在什么时候
