# 模糊聚类分析

# （2）距离法

一般地，取 $r_{ij}=1-c(d(x_i,x_j))^{\alpha}$，其中 $c,\alpha$ 为适当选取的参数，它使得 $0\le r_{ij}\le1$。采用的距离有：

+   ① **Hamming距离**    $d(x_i,x_j)=\sum_{k=1}^{m}|x_{ik}-x_{jk}|$

+   ② **Euclid距离**    $d(x_i,x_j)=\sqrt{\sum_{k=1}^{m}(x_{ik}-x_{jk})^2}$

+   ③ **Chebyshev距离**    $d(x_i,x_j)=\max_{1\le k\le n}|x_{ik}-x_{jk}|$
