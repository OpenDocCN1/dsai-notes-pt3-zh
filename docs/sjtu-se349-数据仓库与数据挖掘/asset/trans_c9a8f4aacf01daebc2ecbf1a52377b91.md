

## 数据清理作为一个过程

### 第1步：偏差检测 数据不一致检测

- 偏差检测商业工具
  - 数据清洗工具 Data scrubbing：使用简单的领域知识（如邮政地址知识和拼写检查）检查并纠正数据中的错误
  - 数据审计工具 Data auditing：通过分析数据发现规则和联系，并检测违反这些条件的数据来发现偏差，如使用聚类识别离群点

### 第2步：数据迁移和集成 数据迁移和集成

- 一旦发现偏差，通常需要定义并使用（一系列）变换来纠正
- 商业工具可以支持数据变换步骤
  - **数据迁移工具**：允许说明简单的变换
    - 如将串“Gender”用“Sex”替换
  - **提取、变换、装入工具 ETL (Extraction/Transformation/Loading) tools**：允许用户通过 GUI 说明变换
  - 通常，这些工具只支持有限的变换，因此可能需要为数据清理过程编写定制程序

### 以上两步骤的集成

- **迭代**
  - 有些变换可能导致更多偏差
  - 有些嵌套的偏差可能在其他偏差解决之后才能检测到。例如，年份字段上的打字错误“20010”可能在所有日期值都变换成统一格式之后才会浮现
  - 变换常常以批处理方式进行，用户等待而无反馈信息。仅当变换完成之后，用户才能回过头来检查是否错误地产生了新的异常
- **交互性**
  - 用户可以通过编辑和调试每个变换，一次一步，逐渐构造一个变换序列。变换可以通过图形或提供的例子说明，结果立即显示在屏幕上的记录中。用户可以撤销变换，使得导致额外错误的变换被“清除”。工具在最近一次变换的数据视图上自动地进行偏差检测。随着偏差的发现，用户逐渐地开发和精制变换，从而使数据清理更有效

## 数据集成 Data Integration

### 冗余和相关分析

- 当多个数据库集成时，容易发生冗余
- **对象标识**：不同数据库中属性或维名不一致
- **衍生数据 Derivable data**：一个属性可能由另一个或一组属性导出，例如，年收入
- 冗余属性可以用相关分析（**correlation analysis**）检测
- 给定两个属性，这种分析可以根据可用的数据，度量一个属性在多大程度上蕴涵另一个
  - 对于**标称属性**，使用 χ²（卡方）检验
  - 对于**数值属性**，使用相关系数和协方差，评估一个属性的值如何随另一个变化

### 标称数据的相关检验

对于标称数据，两个属性 A 和 B 之间的相关联系可以通过 χ²（卡方）检验发现。假设 A 有 c 个不同值 a₁, a₂, …, a_c，B 有 r 个不同值 b₁, b₂, …, b_r。用 A 和 B 描述的数据元组可以用一个相依表显示，其中 A 的 c 个值构成列，B 的 r 个值构成行。令 (A_i, B_j) 表示属性 A 取值 a_i、属性 B 取值 b_j 的联合事件，即 (A = a_i, B = b_j)。每个可能的 (A_i, B_j) 联合事件都在表中有自己的单元。χ² 值（又称 Pearson χ² 统计量）可以用下式计算：

$$\chi^2 = \sum_{i=1}^{c} \sum_{j=1}^{r} \frac{(o_{ij} - e_{ij})^2}{e_{ij}}$$

其中 $o_{ij}$ 是联合事件 $(A_i, B_j)$ 的观测频度（即实际计数），而 $e_{ij}$ 是 $(A_i, B_j)$ 的期望频度：

$$e_{ij} = \frac{count(A = a_i) \times count(B = b_j)}{n}$$

χ² 统计检验假设 A 和 B 是独立的。检验基于显著性水平，具有自由度 $(r - 1) \times (c - 1)$。

### 卡方计算：实例

|  | Play chess | Not play chess | Sum (row) |
|---|---|---|---|
| Like science fiction | 250(90) | 200(360) | 450 |
| Not like science fiction | 50(210) | 1000(840) | 1050 |
| Sum (col.) | 300 | 1200 | 1500 |

$$e_{11} = \frac{count(Play chess) \times count(Like science fiction)}{n} = \frac{300 \times 450}{1500} = 90$$

- χ²（卡方）计算（括号中的数字是根据两类的数据分布预期的）

$$\chi^2 = \frac{(250-90)^2}{90} + \frac{(50-210)^2}{210} + \frac{(200-360)^2}{360} + \frac{(1000-840)^2}{840} = 507.93$$

对于自由度 1，在 0.001 的显著性水平下，拒绝假设的值是 10.828（取自 χ² 分布上百分点表，参见统计学教科书）。由于计算的值大于该值，因此我们可以拒绝 Play chess 与 Like science fiction 是独立的假设，并断言对于给定的人群，这两个属性是（强）相关的。

### 数值数据的相关系数

- 相关系数（又称皮尔森积矩系数 Pearson's product moment coefficient）

$$r_{A,B} = \frac{\sum_{i=1}^{n} (a_i - \bar{A})(b_i - \bar{B})}{(n-1)\sigma_A \sigma_B} = \frac{\sum_{i=1}^{n} (a_i b_i) - n \bar{A} \bar{B}}{(n-1)\sigma_A \sigma_B}$$

其中 $n$ 是元组的个数，$\bar{A}$ 和 $\bar{B}$ 分别是 $A$ 和 $B$ 的均值，$\sigma_A$ 和 $\sigma_B$ 分别是 $A$ 和 $B$ 的标准差，$\sum (a_i b_i)$ 是 $AB$ 叉积和。

- 如果 $r_{A,B} > 0$，$A$ 和 $B$ 正相关（$A$ 随着 $B$ 值的增加而增加），该值越大，相关性越强。
- 如果 $r_{A,B} = 0$，$A$ 和 $B$ 独立。
- 如果 $r_{A,B} < 0$，$A$ 和 $B$ 负相关。

### 数值数据的相关系数（续）

在概率论与统计学中，协方差和方差是两个类似的度量，评估两个属性如何一起变化。

$$Cov(A, B) = E((A - \bar{A})(B - \bar{B})) = \frac{\sum_{i=1}^{n}(a_i - \bar{A})(b_i - \bar{B})}{n}$$

$$r_{A,B} = \frac{Cov(A, B)}{\sigma_A \sigma_B}$$

其中 $n$ 是元组的数量，$\bar{A}$ 和 $\bar{B}$ 是属性 $A$ 和 $B$ 的期望，$\sigma_A$ 和 $\sigma_B$ 是 $A$ 和 $B$ 的标准差。

- 正协方差：若 $Cov(A,B) > 0$，则当 $A$ 大于期望时，$B$ 也很有可能大于期望。
- 负协方差：若 $Cov(A,B) < 0$，则当 $A$ 大于期望时，$B$ 很有可能小于期望。
- 独立：若 $A$ 与 $B$ 独立，则 $Cov(A,B) = 0$；但逆命题不成立。
  - 某些随机变量可能具有协方差 0，但不独立。仅在某种附加的假设下（例如数据服从多元正态分布），协方差 0 蕴含独立性。

它可被简化为：

$$Cov(A, B) = E(A \cdot B) - \bar{A}\bar{B}$$

- 假设两只股票 A 和 B 在一周内的数值如下：(2, 5), (3, 8), (5, 10), (4, 11), (6, 14)。
- 问题：如果股票受同一行业趋势影响，它们的价格会一起上涨还是下跌？

$$E(A) = (2 + 3 + 5 + 4 + 6) / 5 = 20/5 = 4$$

$$E(B) = (5 + 8 + 10 + 11 + 14) / 5 = 48/5 = 9.6$$

$$Cov(A,B) = (2×5+3×8+5×10+4×11+6×14)/5 − 4 × 9.6 = 4$$

因此，A 和 B 一起上涨，因为 $Cov(A, B) > 0$。
