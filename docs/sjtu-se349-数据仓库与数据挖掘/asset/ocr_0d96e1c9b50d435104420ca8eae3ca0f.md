# 关联规则的运用

| 单项统计 | 支持度 |
|---|---|
| {啤酒} | 2 |
| {烤鸭} | 3 |
| {面饼} | 3 |
| {面酱} | 4 |

+   - 单项统计，60%顾客买了烤鸭、60%顾客买了面酱
+   - 双项统计，60%的顾客买了烤鸭和面酱
+   - 三项统计，40%的顾客同时买了烤鸭、面饼和面酱

| 双项统计 | 支持度 |
|---|---|
| {啤酒，面饼} | 2 |
| {烤鸭，面饼} | 2 |
| {烤鸭，面酱} | 3 |
| {面饼，面酱} | 2 |

+   - R1: 烤鸭→面饼、面酱。支持度40%，置信度为66.6%
+   - R2: 面饼→烤鸭、面酱。支持度40%，置信度为66.6%
+   - R3: 面酱→面饼、烤鸭。支持度40%，置信度为50%
+   - KDD结果不一定是因果关系。运用之妙成乎人。
+   - 例如：
+   - 用R1，将烤鸭降价以促销面饼、面酱，很可能会破产
+   - 用R2 将面饼降价，以促销烤鸭，可能会发财；
+   - 用R3，引不起顾客的热情。
