# 2006世界杯同样是德国和阿根廷的赛场
不是章鱼保罗救了德国，而是一个神秘的小纸条

+   阿根廷和德国在1/4决赛中120分钟难分高下，在点球大战之前，老门将卡恩将一张纸条递到莱曼手中。莱曼每次扑点球之前都要看一眼纸条。结果是，莱曼所有点球都判断对了方向，除了两个点球质量太高无力回天外，其他全部扑出，阿根廷只能黯然出局。

+   纸条上面记录着阿根廷队的克鲁兹、阿亚拉、罗德里格斯以及坎比亚索习惯的脚法。德国队守门员教练科普克如此精确地预测出阿根廷球员射出的点球方向，并不是他有什么过人的占卜天才。那张草草写在格鲁内瓦尔德皇宫酒店便笺上的扑点球秘籍，来自于德国科隆体育学院数据分析小组夜以继日的努力。
