# 模糊集合及其运算

# （3）模糊矩阵的转置

定义：设 $A = (a_{ij})_{m\times n}$，称 $A^{T} = (a_{ij}^{T})_{m\times n}$ 为 $A$ 的

转置矩阵，其中 $a_{ij}^{T} = a_{ji}$。

# 性质：

+   1  $(A^{T})^{T} = A.$

+   2  $(A \cup B)^{T} = A^{T} \cup B^{T}; (A \cap B)^{T} = A^{T} \cap B^{T};$

+   3  $(A \circ B)^{T} = B^{T} \circ A^{T}; \quad (A^{n})^{T} = (A^{T})^{n}.$

+   4  $(A^{c})^{T} = (A^{T})^{c}.$

+   5  $A \le B \Leftrightarrow A^{T} \le B^{T}.$
