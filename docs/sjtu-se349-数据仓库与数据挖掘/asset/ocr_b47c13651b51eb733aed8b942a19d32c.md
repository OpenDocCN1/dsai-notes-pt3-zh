# FP增长算法的频繁项集产生
——发现以E结尾的频繁项集步骤

+   （1）收集包含E结点的所有路径，这些初始路径称为前缀路径
+   （2）由E的前缀路径，把与结点E相关联的支持度计数相加得到E的支持度计数是3，{E}是频繁项集（假定最小支持度为2）
