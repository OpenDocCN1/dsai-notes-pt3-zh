# 数值属性的相异性(Cont.)

+   闵可夫斯基距离：欧几里得距离和曼哈顿距离的推广

$d(i,j)=\sqrt[h]{|x_{i1}-x_{j1}|^h+|x_{i2}-x_{j2}|^h+\cdots+|x_{ip}-x_{jp}|^h}$

+   这种距离又称L-p范数

—h=1时为曼哈顿距离，h=2时为欧几里得距离

+   当趋向于正无穷时，我们得到上确界距离（切比雪夫距离）

$d(i,j)=\lim_{h\to\infty}\left(\sum_{r=1}^{p}|x_{ir}-x_{jr}|^h\right)^{1/h}=\max_{r}|x_{ir}-x_{jr}|$

—各座标数值差的最大值

+   也就是找出属性，它产生两个对象的最大值差
