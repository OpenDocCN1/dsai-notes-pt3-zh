# 遗传算法应用于分类

+   - 创建一个由随机产生的规则组成的初始群体,每个规则可以用一个二进制串表示。
+   - 一个简单的例子
+     - 假设给定的训练集样本用两个布尔属性A1和A2描述，并且有两个类C1和C2
+     - 规则“IF A1 AND NOT A2 THEN C2”可以用二进制串“100”编码，其中最左边的两个二进制分别代表属性A1和A2，而最右边的二进制代表类。
+     - 类似地，规则“IF NOT A1 AND NOT A2 THEN C1”可用“001”编码。
+     - 如果一个属性具有k个值，则可以用k个二进制对该属性的值编码，类可以用类似的方式编码。
