# 特征空间与核函数

+   Mercer核
+   - 多项式核 $k(\mathbf{x}, \mathbf{y}) = (\mathbf{x} \cdot \mathbf{y} + 1)^d$
+   - 高斯径向基函数核
+     $k(\mathbf{x}, \mathbf{y}) = \exp\left(-\frac{\|\mathbf{x} - \mathbf{y}\|^2}{2\sigma^2}\right)$
+   - Sigmoid核
+     $k(\mathbf{x}, \mathbf{y}) = \tanh\big(\kappa(\mathbf{x} \cdot \mathbf{y}) + \Theta\big)$
+   （只在部分参数值情况下才满足核函数的定义）
