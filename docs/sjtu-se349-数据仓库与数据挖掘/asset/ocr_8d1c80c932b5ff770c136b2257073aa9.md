# Fuzzy Set and Fuzzy Cluster

+   Clustering methods discussed so far
+   — Every data object is assigned to exactly one cluster
+   — 例如: 将客户分配给销售经理

+   Some applications may need for fuzzy or soft（模糊或灵活的）cluster assignment
+   — Ex. An e-game could belong to both entertainment and software
+   — 例: 客户关于摄像机和计算机的评论各有一个簇, 如果一个评论是计算机和摄像机兼容, 应该放在哪个簇?

这时需要一种聚类方法, 它允许一个评论属于多个簇, 为了反映一个评论属于某个簇的强度, 你想在评论到簇的指派上附加一个代表这种部分隶属关系的权重

+   Methods: fuzzy clusters and probabilistic model-based clusters

+   Fuzzy cluster: 模糊集S是X的子集, A fuzzy set S可以表示为:
+   — F_S: X → [0, 1] (value between 0 and 1)
+   — 给定对象集X={X1,X2,...,Xn}, 允许X中的每个对象都具有一个属于S的[0, 1]

隶属度Example: Popularity（流行程度） of cameras is defined as a fuzzy mapping

| Camera | Sales (units) |
| --- | --- |
| A | 50 |
| B | 1320 |
| C | 860 |
| D | 270 |

```
Pop(o) = { 1 if 1,000 or more units of o are sold
 i/1000 if i (i < 1000) units of o are sold }
```

Then, A(0.05), B(1), C(0.86), D(0.27)
