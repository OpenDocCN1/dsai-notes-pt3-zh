# Distance-Based Outlier Detection

+   - For each object, examine the # of other objects in the *r*-neighborhood（距离阈值 *r* 定义的合理邻域）of o, where *r* is a user-specified distance threshold
+   - An object o is an outlier if most (taking π as a fraction threshold分数阈值) of the objects in D are far away from o, i.e., not in the *r*-neighborhood of o
+   
+     \[
+     \frac{|\{o'\mid dist(o,o')\le r\}|}{|D|}\le \pi
+     \]
+   
+   - An object o is a DB(*r*, π) outlier if
+   - Equivalently, one can check the distance between o and its *k*-th nearest neighbor \(o_k\), 第k个最近邻，其中 \(k=\lceil \pi|D|\rceil\)
+   - o is an outlier if \(dist(o,o_k)>r\)，在o的r邻域中，除o之外至少有k个对象

+   - **Efficient computation:** Nested loop algorithm 嵌套循环算法
+     - For any object \(o_i\), calculate its distance from other objects, and count the # of other objects in the *r*-neighborhood.
+     - If π·n other objects are within *r* distance, terminate the inner loop
+     - Otherwise, \(o_i\) is a DB(*r*, π) outlier
+   - **Efficiency:** Actually CPU time is not O(n²) but linear to the data set size since for most non-outlier objects, the inner loop terminates early
