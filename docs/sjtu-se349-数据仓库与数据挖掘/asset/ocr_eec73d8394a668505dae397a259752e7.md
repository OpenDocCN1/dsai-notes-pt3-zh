# Density-Reachable and Density-Connected

基于密度的聚类: 背景(II)

+   密度可达的：
+   一个对象p从对象q关于Eps,和MinPts是密度可达的，如果存在一个对象链p1, ..., pn, p1 = q, pn= p pi+1 是从pi关于Eps,和MinPts直接密度可达的

+   密度相连的：
+   如果存在一个对象o，使得对象p和q是从o关于Eps和MinPts 密度可达的，那么对象关于p和q是关于Eps和MinPts 密度相连的
