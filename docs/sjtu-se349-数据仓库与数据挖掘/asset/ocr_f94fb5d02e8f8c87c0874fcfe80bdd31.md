# Information Gain 属性选择度量 之 信息增益

+   - 信息增益计算方式
+   - 信息增益

用属性A划分样本数据集S，划分前样本数据集的不纯程度（熵）和划分后样本数据集的不纯程度（熵）的差值

```
Gain(S, A) = Entropy(S) − Entropy_A(S)
```

按属性A划分S后的样本子集的熵定义：假设属性A具有K个不同的取值，将S划分为k个样本子集{S₁, S₂, ..., Sₖ}，则按属性A划分S后的样本子集的信息熵如下，其中|Sᵢ|（i=1,2,...,k）为样本子集Sᵢ中包含的样本数，|S|为样本集S中包含的样本数

```
Entropy_A(S) = Σ_{i=1}^{k} |S_i|/|S| Entropy(S_i)
```

信息增益越大，说明使用属性A划分后的样本子集越纯，越有利于分类
