# 哈尔函数（Haar小波）

—生成向量空间W¹的哈尔小波

```
ψ₀¹(x) = { 1    0 ≤ x < 1/4
          -1   1/4 ≤ x < 1/2
           0    其他 }
```

```
ψ₁¹(x) = { 1    1/2 ≤ x < 3/4
          -1   3/4 ≤ x < 1/2
           0    其他 }
```
