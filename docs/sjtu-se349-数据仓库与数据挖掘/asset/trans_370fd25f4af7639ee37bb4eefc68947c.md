

## 源程序

```matlab
%以每三个月的销售量经规格化处理后作为输入
%归一化方法： P=(X-min(X(:)))/(max(X(:))-min(X(:)))

P=[0.5152    0.8173    1.0000;
   0.8173    1.0000    0.7308;
   1.0000    0.7308    0.1390;
   0.7308    0.1390    0.1087;
   0.1390    0.1087    0.3520;
   0.1087    0.3520    0.0000]';

%以第四个月的销售量归一化处理后作为目标向量
T=[0.7308    0.1390    0.1087    0.3520    0.0000    0.3761];

%创建一个BP神经网络，每一个输入向量的取值范围为[0,1]，隐含层有5个神经元，输出层有一个神经元，隐含层的激活函数为tansig，输出层的激活函数为logsig
net=newff([0 1;0 1;0 1],[5,1],{'tansig','logsig'},'traingd');
net.trainParam.epochs=15000;    %设置迭代运行次数
net.trainParam.goal=0.01;    %预设误差精度
net.trainParam.lr=0.1;                    %设置学习速率为0.1
net=train(net,P,T);
Y= sim(net,P);
plot(1:6,T,'m*',1:6,Y,'ro');
title('预测销售量效果图，其中*为真实值，o为预测值')
```

## 小结

- 1、算法是由两部分组成
  - 信息的正向传递
  - 误差的反向传播
- 2、网络的输入输出关系是各层连接的权因子决定，权因子是通过学习信号调节的，这样学习越多，网络越聪明
- 3、隐含层越多，网络输出精度越高，且个别权因子的损坏不会对网络输出产生大的影响
- 4、反向传播网络的结构不完全受所要解决问题的限制
  - 网络的输入神经元数目及输出层神经元的数目是由问题的要求所决定
  - 隐含层数以及每层的神经元数是由设计者来决定的

## 支持向量机SVM简介

![](img/6d25e92eb0bd56a22c311279c19b06b4_917_0.png)

- 支持向量机(Support Vector Machine)是贝尔实验室研究者Vapnik等于1995年首先提出的，它在解决小样本、非线性及高维模式识别中表现出许多特有优势，并能够推广应用到其他机器学习问题中。
- SVM方法是建立在统计学习理论的VC维理论和结构风险最小原理基础上的，根据有限的样本信息在模型的复杂性（即对特定训练样本的学习精度）和学习能力（即无错误地识别任意样本的能力）之间寻求最佳折衷，以期获得最好的推广能力。
- SVM发展史虽短，但其理论研究和算法实现方面却都取得突破性进展，这一切与SVM有较完备的统计学习理论基础的发展背景是密不可分的。

## SVM的历史

- 1963年，Vapnik在解决模式识别问题时提出了支持向量方法，这种方法从训练集中选择一组特征子集，使得对特征子集的划分等价于对整个数据集的划分，这组特征子集就被称为支持向量(SV)。
- 1971年，Kimeldorf提出使用线性不等约束重构SV的核空间，解决了一部分线性不可分问题。
- 1990年，Guyon, Boser和Vapnik等开始对SVM进行研究。
- 1995年，Vapnik正式提出统计学习理论。

## 统计学习理论

- 统计方法 —— 从观测自然现象或者专门安排的实验所得到的数据去推断该事物可能的规律性。
- 统计学习理论 —— 在研究小样本统计估计和预测的过程中发展起来的一种新兴理论。

【注意】：这里所说的“小样本”是相对于无穷样本而言的，故只要样本数不是无穷，都可称为小样本，更严格地说，应该称为“有限样本”。
