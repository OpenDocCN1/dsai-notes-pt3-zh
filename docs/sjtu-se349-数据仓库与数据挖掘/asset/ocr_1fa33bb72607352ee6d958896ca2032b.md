# 由频繁项集产生关联规则

频繁项集 X={I1,I2,I5} 的非空子集

+   - {I1,I2}
+   - {I1,I5}
+   - {I2,I5}
+   - {I1}
+   - {I2}
+   - {I5}

{I1,I2} ⇒ I5, confidence = 2/4 = 50%
{I1,I5} ⇒ I2, confidence = 2/2 = 100%
{I2,I5} ⇒ I1, confidence = 2/2 = 100%
I1 ⇒ {I2,I5}, confidence = 2/6 = 33%
I2 ⇒ {I1,I5}, confidence = 2/7 = 29%
I5 ⇒ {I1,I2}, confidence = 2/2 = 100%
