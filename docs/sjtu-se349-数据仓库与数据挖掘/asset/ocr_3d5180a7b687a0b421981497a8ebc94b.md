# Density-Based Clustering: Basic Concepts
基于密度的聚类: 背景知识

+   两个参数:
+   — Eps: 邻域的最大半径
+   — MinPts: 一个对象的Eps-邻域至少包含的对象数

N_Eps(q): {p ∈ D | dist(p,q) <= Eps}

+   直接密度可达: 一个对象p是从对象q关于Eps, MinPts直接密度可达的，如果
+   — 1) p 属于 N_Eps(q)
+   — 2) 核心对象的条件:
+   |N_Eps(q)| >= MinPts
