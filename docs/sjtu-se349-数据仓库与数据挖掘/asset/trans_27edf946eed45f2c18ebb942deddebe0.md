## 高维数据中离群点检测的挑战

- **离群点的解释** 离群点的解释
  - 在高维中检测离群点而不说明其为何为离群点在高维数据集中涉及许多特征（或维度）时并不很有用
  - 例如，哪些子空间体现了离群点，或对对象的“离群程度”进行评估

- **数据的稀疏性** 数据的稀疏性
  - 高维空间中的数据通常是稀疏的
  - 随着维度的增加，对象之间的距离变得严重受噪声主导

- **数据子空间** 数据子空间
  - 自适应于表示离群点的子空间
  - 捕捉数据的局部行为

- **关于维度的可伸缩性** 关于维度的可伸缩性
  - 子空间的数量呈指数增长

## 方法 I：扩展传统离群点检测
扩充的传统离群点检测

- 方法 1：在全空间中检测离群点，例如 HiLOut 算法
  - 寻找基于距离的离群点，但使用距离的秩而非绝对距离进行离群点检测
  - 对于每个对象 o，找到其 k-最近邻：nn₁(o) ... nnₖ(o)
  - 对象 o 的权重：w(o) = Σᵢ₌₁ᵏ dist(o, nnᵢ(o))
  - 所有对象按权重递减序排序 按权重递减序排序
  - 按权重排名前 l 的对象作为离群点输出（l：用户指定参数）
  - 采用空间填充曲线 空间填充曲线 进行近似：关于数据规模和维度在时间和空间上均可伸缩

- 方法 2：降维
  - 仅在低维情况下有效，正常实例仍可与离群点区分
  - PCA：启发式地，方差较低的主成分更受青睐，因为在这些维度上，正常对象可能彼此接近，而离群点通常偏离多数

## 方法 II：在子空间中寻找离群点
发现子空间中的离群点

- 扩展传统离群点检测：难以解释离群点
- **在更低维的子空间中寻找离群点：易于解释对象为何以及在何种程度上是离群点**
  - 例如，在特定子空间中寻找离群客户：*平均交易金额 >> 平均值 且 购买频率 << 平均值*
- 例：基于网格的子空间离群点检测方法
  - 将数据投影到各种子空间以寻找密度远低于平均值的区域
  - 将数据离散化为具有 φ 个等深 等深 区域的网格（为什么？）
  - 寻找显著稀疏 显著稀疏 的区域
    - 考虑一个 k-d 立方体 k维立方体：k 在 k 个维度上取值，共 n 个对象
    - 如果对象独立分布，则落入 k 维区域中的对象期望数量为 (1 / φ)^k n = f^k n，标准差为 √(f^k(1 − f^k)n)
    - 立方体 C 的稀疏系数 稀疏系数：S(C) = (n(C) − f^k n) / √(f^k(1 − f^k)n)
    - 如果 S(C) < 0，则 C 包含的对象少于预期
    - 越负，C 越稀疏，C 中对象的离群可能性越大

## 方法 III：建模高维离群点
高维离群点建模

- 直接为高维离群点开发新模型
- 避免邻近性度量并采用在高维数据中不会退化 不会在高维数据中退化 的新启发式方法

![](img/6d25e92eb0bd56a22c311279c19b06b4_1449_0.png)

- 例：基于角的离群点 基于角的离群点：Kriegel, Schubert, and Zimek [KSZ08]

- 对于每个点 o，检查每对点 x、y 的角度 Δxoy。
  - 中心点（例如 a），形成的角度差异很大
  - 离群点（例如 c），角度变量明显更小
  - 使用点的角度方差 角度的方差 来确定离群点

- 结合角度和距离来建模离群点
  - 使用距离加权的角度方差作为离群点分数
  - 基于角度的离群点因子 基于角度的离群点因子
  - ABOF(o) = VAR_{x,y∈D, x≠o, y≠o} <overleftarrow{ox}, overleftarrow{oy}> / [dist(o,x)^2 dist(o,y)^2]
  - 已开发高效近似计算方法
  - 它可以推广以处理任意类型的数据
