# Information Gain 属性选择度量 之 信息增益

+   - 信息增益
+     - 在树的每个节点上使用信息增益度量选择测试属性
+     - 根据当前节点对应的训练样本，计算各属性的信息增益，然后选择具有最高信息增益的属性作为分裂属性来做样本划分

+   - 信息增益计算方式

信息熵（entropy, εntraρi, 熵, 平均信息量, 负熵）：用于度量一个属性的信息量

✓ 假设S为训练集，S的目标属性C具有m个可能的类标号值，C={C₁,C₂,...,Cₘ}，假设训练集S中Cᵢ在所有样本中出现的概率为pᵢ(i=1,2,3,...,m)，则该训练集S所包含的信息熵定义为

```
Entropy(S) = Entropy(p₁, p₂, ..., pₘ) = - Σᵢ₌₁ᵐ pᵢ log₂(pᵢ)
```

✓ 熵越小，表示样本对目标属性的分布越纯。熵越大，表示样本对目标属性的分布越乱

+   - 熵为0则意味着所有样本的目标属性取值相同
+   - 当S中不同类别的记录数相同时，取得最大值log2ᵐ,m为类别的个数，对于两个类别来说，最大值为1
