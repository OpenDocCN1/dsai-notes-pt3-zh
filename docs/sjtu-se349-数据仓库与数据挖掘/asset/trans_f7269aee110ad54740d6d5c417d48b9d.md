

## 一个社交网络模型

- Cliques（小集团/小圈子）、hubs and outliers
  - 小集团或小圈子中的个体无论群体大小如何，都认识许多相同的人。
  - 中心节点个体认识来自不同群体的许多人，但不属于任何单一群体。例如，政治家连接多个群体。
  - 边缘个体居住在社会的边缘。例如，隐士认识的人很少且不属于任何群体。

## 结构相似性

期望的特征往往被我们称之为结构相似性的度量所捕捉：

\[
\sigma(v, w) = \frac{|\Gamma(v) \cap \Gamma(w)|}{\sqrt{|\Gamma(v)||\Gamma(w)|}}
\]

- 小集团成员的结构相似性较大，而中心节点和边缘个体的结构相似性较小。

## 结构连通性 [1]

- **ε-邻域：**

  \[
  N_{\varepsilon}(v)=\{w\in\Gamma(v)\mid\sigma(v,w)\geq\varepsilon\}
  \]

- **核心：**

  \[
  CORE_{\varepsilon,\mu}(v)\Longleftrightarrow |N_{\varepsilon}(v)|\geq\mu
  \]

- **直接结构可达：**

  \[
  DirREACH_{\varepsilon,\mu}(v,w)\Longleftrightarrow CORE_{\varepsilon,\mu}(v)\land w\in N_{\varepsilon}(v)
  \]

- **结构可达：** 直接结构可达性的传递闭包。

- **结构连通：**

  \[
  CONNECT_{\varepsilon,\mu}(v,w)\Longleftrightarrow \exists u\in V:REACH_{\varepsilon,\mu}(u,v)\land REACH_{\varepsilon,\mu}(u,w)
  \]

[1] M. Ester, H. P. Kriegel, J. Sander, & X. Xu (KDD'96), “A Density-Based Algorithm for Discovering Clusters in Large Spatial Databases.”

## 结构连通簇

- 结构连通簇 C
  - 连通性：
  - 最大性：∀v, w ∈ C: CONNECT_{ε, μ}(v, w)

- 中心节点：∀v, w ∈ V: v ∈ C ∧ REACH_{ε, μ}(v, w) ⇒ w ∈ C
  - 不属于任何簇。
  - 连接多个簇。

- 边缘个体：
  - 不属于任何簇。
  - 连接的簇较少。

## 约束分类

- 聚类分析涉及三个基本方面：作为簇实例的对象、作为对象群的簇和对象之间的相似性。因此，根据约束作用于何处对约束分类，有三种类型：
  - 实例上的约束
  - 簇上的约束
  - 相似性度量上的约束

- Constraints on instances: specifies how a pair or a set of instances should be grouped in the cluster analysis.
  - Must-link vs. cannot-link constraints
    - must-link(x, y): x and y should be grouped into one cluster
  - Constraints can be defined using variables, e.g.,
    - cannot-link(x, y) if dist(x, y) > d

- Constraints on clusters: specifies a requirement on the clusters.
  - E.g., specify the min. # of objects in a cluster, the max. diameter of a cluster, the shape of a cluster (e.g., a convex（凸面的）), # of clusters (e.g., k)

- Constraints on similarity measurements: specifies a requirement that the similarity calculation must respect.
  - E.g., driving on roads, obstacles (e.g., rivers, lakes)

- Issues: hard vs. soft constraints; conflicting or redundant constraints.
