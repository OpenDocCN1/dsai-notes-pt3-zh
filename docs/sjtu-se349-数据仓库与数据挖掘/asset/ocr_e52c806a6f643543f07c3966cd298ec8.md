# C4.5分类算法
算例

最后对outlook的rain分支建立子树

+   — 找出样本数据集weather中outlook取值rain的样本子集Srain
+   — 依次计算剩下两个属性对该样本子集Srain划分后的信息增益率
+   — 建立rain分支子树

![](bbox=[0.08, 0.48, 0.38, 0.72])

① Entropy(S_rain) = Entropy(3/5, 2/5) = -3/5 log₂ 3/5 - 2/5 log₂ 2/5 = 0.971

② 属性 temperature 划分子集 S_rain 的信息增益、分裂信息及信息增益率为
Entropy_temperature(S_rain) = Σ_{i=1}^k |S_i|/|S| Entropy(S_i) = |S₁|/|S| Entropy(S₁) + |S₂|/|S| Entropy(S₂)
= 3/5(-2/3 log₂ 2/3 - 1/3 log₂ 1/3) + 2/5(-1/2 log₂ 1/2 - 1/2 log₂ 1/2)
= 0.9509
Gain(S_rain, temperature) = Entropy(S_rain) - Entropy_temperature(S_rain) = 0.971 - 0.9509 = 0.02
SplitE(S_rain, temperature) = -3/5 log₂ 3/5 - 2/5 log₂ 2/5 = 0.971
GainRatio(S_rain, temperature) = Gain(S_rain, temperature) / SplitE(S_rain, temperature) = 0.02 / 0.971 = 0.0205

③ 属性 wind 划分子集 S_rain 的信息增益、分裂信息及信息增益率为
Entropy_wind(S_rain) = Σ_{i=1}^k |S_i|/|S| Entropy(S_i) = |S₁|/|S| Entropy(S₁) + |S₂|/|S| Entropy(S₂)
= 3/5 × 0 + 2/5 × 0
= 0
Gain(S_rain, wind) = Entropy(S_rain) - Entropy_wind(S_rain) = 0.971 - 0 = 0.971
SplitE(S_rain, wind) = -3/5 log₂ 3/5 - 2/5 log₂ 2/5 = 0.971
GainRatio(S_rain, wind) = Gain(S_rain, wind) / SplitE(S_rain, wind) = 0.971 / 0.971 = 1
