# 数据挖掘的技术工具
1.通用型工具（6） IBM Intelligent Miner

+   - **IBM的Intelligent Miner在数据挖掘工具的领导地位是极具竞争力的，因为它提供了以下的好处：**
+     - 包含了最广泛的数据挖掘技术及算法，可容纳相当大的资料量的能力且有强大的计算能力；事实上，这套产品在IBM SP的大量并行硬件系统上执行效率最好，这套产品也可以在IBM或非IBM平台上执行
+     - 丰富的APIs可用来发展自定的数据挖掘应用软件；所有数据挖掘引擎和资料操作函式可以透过C++函式库来存取
+     - 支持classification、prediction、association rules generation、clustering、sequential pattern detection和time series analysis算法
+     - 藉由利用精密的数据可视化技术及强大的Java-based使用者接口来增加它的可用性（目标大多锁定在有经验的使用者）
+     - 支持DB2关系型数据库管理系统，并整合大量精密的资料操作函式

整体而言，Intelligent Miner(for Data)是市场上最大容量及功能强大的工具，在顾客评定报告中的整体效能是最好的，有些算法的效能甚至比其它应用不同的应用软件还要好。
