# Pixel-Oriented Visualization Techniques
基于像素的可视化技术 Cont.

+   - 对所有顾客按收入的递增序排序
+   - 在4个可视化窗口中按以上排序安排顾客数据
+   - 像素颜色越淡，值越小
+   - 得到四张图

+   - Credit Limit随Income增加而增加
+   - 收入处于中部区间的顾客更可能从AllElectronics购物；
+   - Income与age之间没有明显的相关性
