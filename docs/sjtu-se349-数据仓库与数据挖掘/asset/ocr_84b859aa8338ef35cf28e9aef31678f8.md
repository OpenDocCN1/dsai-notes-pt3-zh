# Boosting

# 集成分类器 —— 2) 提升

+   算法基本思想

提升是一个迭代的过程，用于自适应地改变训练样本的分布，使得使得基分类器聚焦在那些很难分的样本上。不像装袋，提升给每个训练样本赋予一个权值，而且可以在每轮提升过程结束自动地调整权值。

+   训练样本权值的应用

+   ①抽样分布，从原始数据集中提取出自主样本集

+   ②基分类器可以使用权值学习有利于高权值样本的模型

+   算法步骤

+   赋予每个训练元组以权重，迭代地学习 k 个分类器 M_i

+   更新每个训练元组的权重，再次生成新的分类器

+   最终根据权重衡量各个子分类器的投票结果，得到最终的类
