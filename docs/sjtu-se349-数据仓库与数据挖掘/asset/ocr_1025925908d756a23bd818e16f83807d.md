常用的基本小波

# 6. Marr小波(也叫墨西哥草帽小波)

```
ψ(t)= 2 / (√3 √π) (1 - t²) e^(-t²/2)    ψ̂(ω)= 2√2 √[4]{π} / √3 ω² e^(-ω²/2)
```

![](bbox=[0.25, 0.42, 0.48, 0.68])

![](bbox=[0.52, 0.42, 0.76, 0.68])

这是高斯函数的二阶导数，在信号与图像的边缘提取中具有重要的应用。

主要应用于屋脊型边界和Dirac边缘的提取。

特性：指数级衰减，非紧支撑；具有非常好的时间频率局部化；
关于0轴对称。
