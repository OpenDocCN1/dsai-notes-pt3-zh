# 如何学习规则：规则生成

+   - 从空规则开始，然后逐渐向它添加属性测试
+     — 添加的属性测试作为规则前件条件的逻辑合取

+   - 一个例子：训练集D由贷款申请数据组成：
+     — 属性：年龄，收入，文化程度，住处，信誉等级和贷款期限
+     — 分类属性： loan_decision（是否接受贷款申请）

+   - 刚开始的规则为： IF THEN load_decision=accept

+   - 考虑每个可能的属性测试
+     — 对属性-值对(attr, val)考虑attr=val,attr<=val,attr>val

+   - 缺点：计算昂贵
