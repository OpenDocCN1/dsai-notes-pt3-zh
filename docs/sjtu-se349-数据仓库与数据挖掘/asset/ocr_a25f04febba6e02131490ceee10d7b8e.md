# 哈尔函数（Haar小波）

—生成向量空间 W² 的哈尔小波

ψ₀²(x) = { 1   0 ≤ x < 1/8
          -1  1/8 ≤ x < 2/8
           0   其他 }

ψ₁²(x) = { 1   2/8 ≤ x < 3/8
          -1  3/8 ≤ x < 4/8
           0   其他 }

ψ₂²(x) = { 1   4/8 ≤ x < 5/8
          -1  5/8 ≤ x < 6/8
           0   其他 }

ψ₃²(x) = { 1   6/8 ≤ x < 7/8
          -1  7/8 ≤ x < 1
           0   其他 }
