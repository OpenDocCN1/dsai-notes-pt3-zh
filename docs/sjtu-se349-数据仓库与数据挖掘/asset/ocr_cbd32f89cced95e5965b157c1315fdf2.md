# SaaS（软件即服务）

+   - SaaS是指用户获取软件服务的一种新形式
+     - 不需要用户将软件产品安装在自己的电脑或服务器上，而是按某种服务水平协议（SLA）直接通过网络向专门的提供商获取自己所需要的、带有相应软件功能的服务
+     - 本质上而言，SaaS就是软件服务提供商为满足用户某种特定需求而提供其消费的软件的计算能力

+   - SaaS有各种典型的应用
+     - 工具型服务：在线邮件服务、网络会议、网络传真、在线杀毒等
+     - 管理型服务：在线CRM、在线HR、在线进销存、在线项目管理等

+   - SaaS是未来软件业的发展趋势，微软、Salesforce、用友、金蝶等国内外软件巨头都推出了SaaS应用
