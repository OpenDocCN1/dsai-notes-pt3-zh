# 冗余和相关分析

# 数值数据的相关系数

+   相关系数（又称皮尔森积矩系数Pearson's product moment coefficient）
+   
+   $r_{A,B} = \frac{\sum_{i=1}^{n} (a_i - \bar{A})(b_i - \bar{B})}{(n-1)\sigma_A \sigma_B} = \frac{\sum_{i=1}^{n} (a_i b_i) - n \bar{A} \bar{B}}{(n-1)\sigma_A \sigma_B}$
+   
+   其中n是元组的个数, $\bar{A}$ 和 $\bar{B}$ 分别是是A和B的均值, $\sigma_A$ 和 $\sigma_B$ 分别是A和B的标准差, $\sum (a_i b_i)$ 是AB叉积和

+   If $r_{A,B} > 0$, A and B 正相关（A随着B值的增加而增加），该值越大，相关性越强

+   If $r_{A,B} = 0$, A and B 独立

+   If $r_{AB} < 0$, A and B 负相关
