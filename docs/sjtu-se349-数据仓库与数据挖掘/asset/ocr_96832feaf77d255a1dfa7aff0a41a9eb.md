# 结构风险最小原则

最小化经验风险与置信范围之和被称作结构风险最小化原则SRM。

实现SRM原则可以有两种思路：

+   1. 对函数集S的每个子集Si求最小经验风险，然后选择使最小经验风险和置信范围之和最小的子集；

+   2. 设计函数集的某种结构使每个子集中都能取得最小的经验风险，如使训练误差为0，然后只需选择适当的子集使置信范围最小，则这个子集中使经验风险最小的函数就是最优函数。
