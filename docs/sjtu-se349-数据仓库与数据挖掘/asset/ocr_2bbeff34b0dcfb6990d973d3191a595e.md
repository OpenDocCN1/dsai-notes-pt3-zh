# 朴素贝叶斯分类的算法基本描述

+   - 函数名： NaïveBayes
+   - 输入： 类标号未知的样本X={x1,x2,...,xn}
+   - 输出： 未知样本X所属的类标号
+   - (1) for j=1 to m
+   - (2) 计算X属于每个类别Cj的概率
+     $$P(X|C_j)=\prod_{k=1}^{n}P(x_k|C_j)=P(x_1|C_j)P(x_2|C_j)\times...xP(x_n|C_j)$$
+   - (3) 计算训练集中每个类别的概率P(Cj)
+   - (4) 计算概率值 μ = P(X|Cj) * P(Cj)
+   - End for
+   - 选择计算概率值 μ 最大的Ci（1<=i<=m）做为类别的输出
+     $$P(Ci|X)=\frac{P(X|Ci)P(Ci)}{P(X)}=P(X|Ci)\times P(Ci)/P(X)$$
