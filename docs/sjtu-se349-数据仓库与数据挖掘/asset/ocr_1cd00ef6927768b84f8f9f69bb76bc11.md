# 如何求最优超平面

$L(w,b,\alpha)=\frac{1}{2}\|w\|^2 - \sum_{i=1}^{l} \alpha_i (y_i \cdot ((x_i \cdot w)+b)-1)$

+   将得到的约束条件

$w = \sum_{i=1}^{N} \alpha_i y_i x_i$

$\sum_{i=1}^{N} \alpha_i y_i = 0$

得到：

$W(\alpha)=\sum_{i=1}^{N} \alpha_i - \frac{1}{2} \sum_{i}^{N} \sum_{j}^{N} \alpha_i \alpha_j y_i y_j \langle x_i, x_j \rangle$

+   该式称为L函数的对偶式，由对偶理论可知，最小化L式等于最大化以式的约束的拉格朗日乘子为变量的上式

+   现在问题转化

这是一个标准二次规划问题，是在一个不等式约束条件下进行二次函数寻优，该问题存在唯一解。

$\max_{\alpha} \sum_{i=1}^{n} \alpha_i - \frac{1}{2} \sum_{i,j=1}^{n} \alpha_i \alpha_j y_i y_j x_i^T x_j$

s.t., $\alpha_i \ge 0, i=1,\cdots,n$

$\sum_{i=1}^{n} \alpha_i y_i = 0$

二次规划解出 $\alpha_i$ 的值,代入

$w = \sum_{i=1}^{N} \alpha_i y_i x_i$
