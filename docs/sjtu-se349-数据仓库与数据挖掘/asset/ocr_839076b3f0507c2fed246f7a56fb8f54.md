# CLIQUE: The Major Steps
CLIQUE: 主要步骤

+   • 划分数据空间，找出每个划分单元中的点的数目
+     — 把每维划分成不重叠的区间

+   • 使用Apriori 法则识别包含簇的子空间
+     — 任何一个k 维的单元区域是密集的，那么它在k-1 维空间上的投影也是密集，就从Ck 中去掉了那些有k-1 维的映射，使其没有包含在Ck-1 中的单元

+   • 识别簇:
+     — 在所有的兴趣子空间中确定密度单元
+     — 在所有的兴趣子空间中确定相连的密度单元

+   • 为每个簇生成最小化的描述
+     — 对每个簇，确定覆盖相连的密度单元的最大区域
+     — 然后为每个簇确定最小覆盖
