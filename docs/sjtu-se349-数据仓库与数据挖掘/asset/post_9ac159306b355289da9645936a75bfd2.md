
## Parametric Methods III: Using Mixture of Parametric Distributions 使用混合参数分布

- Assuming data generated by a normal distribution could sometimes be overly simplified.
- Example (right figure): The objects between the two clusters cannot be captured as outliers since they are close to the estimated mean. The estimated mean falls between the two clusters, while the objects are inside neither cluster.

![](img/6d25e92eb0bd56a22c311279c19b06b4_1425_0.png)

To overcome this problem, assume the normal data is generated by two normal distributions. For any object \(o\) in the data set, the probability that \(o\) is generated by the mixture of the two distributions is given by

\[
\Pr(o\mid\Theta_1,\Theta_2)=f_{\Theta_1}(o)+f_{\Theta_2}(o)
\]

where \(f_{\Theta_1}\) and \(f_{\Theta_2}\) are the probability density functions of \(\Theta_1\) and \(\Theta_2\).

- Then use the EM algorithm to learn the parameters \(\mu_1,\sigma_1,\mu_2,\sigma_2\) from the data.
- An object \(o\) is an outlier if it does not belong to any cluster.

## Non-Parametric Methods: Detection Using Histogram 使用直方图检测离群点

- The model of normal data is learned from the input data without any *a priori* structure.
- Often makes fewer assumptions about the data, and thus can be applicable in more scenarios.
- Outlier detection using a histogram:

![](img/6d25e92eb0bd56a22c311279c19b06b4_1426_0.png)

- Figure shows the histogram of **purchase amounts in transactions** 每笔事务的购买量.
- A transaction in the amount of $7,500 is an outlier, since only 0.2% of transactions have an amount higher than $5,000.
- **Problem:** Hard to choose an **appropriate bin size** 合适的箱尺寸 for the histogram.
  - Too small a bin size → normal objects in empty/rare bins, false positive 将正常点误识别为离群点，导致高假正率和低精度.
  - Too big a bin size → outliers in some frequent bins, false negative 将离群点当成正常点，导致高假负率和低召回率.
- **Solution:** Adopt **kernel density estimation** 核密度估计 to estimate the probability density distribution of the data. If the estimated density function is high, the object is likely normal. Otherwise, it is likely an outlier.

## Proximity-Based Approaches: Distance-Based vs. Density-Based Outlier Detection 基于距离的 vs. 基于密度的离群点检测

- Intuition: Objects that are far away from the others are outliers.
- Assumption of the proximity-based approach: The proximity of an outlier deviates significantly from that of most of the others in the data set.
- Two types of proximity-based outlier detection methods:
  - Distance-based outlier detection: An object \(o\) is an outlier if its neighborhood does not have enough other points.
  - Density-based outlier detection: An object \(o\) is an outlier if its density is relatively much lower than that of its neighbors.

## Distance-Based Outlier Detection

- For each object, examine the number of other objects in the *r*-neighborhood of \(o\), where *r* is a user-specified distance threshold.
- An object \(o\) is an outlier if most (taking \(\pi\) as a fraction threshold 分数阈值) of the objects in \(D\) are far away from \(o\), i.e., not in the *r*-neighborhood of \(o\):

\[
\frac{|\{o'\mid \operatorname{dist}(o,o')\le r\}|}{|D|}\le \pi
\]

- An object \(o\) is a DB(\(r,\pi\)) outlier if the above condition holds.
- Equivalently, one can check the distance between \(o\) and its *k*-th nearest neighbor \(o_k\), 第 \(k\) 个最近邻，其中 \(k=\lceil \pi|D|\rceil\).
- \(o\) is an outlier if \(\operatorname{dist}(o,o_k)>r\), 即 \(o\) 的 \(r\) 邻域中，除 \(o\) 之外至多有 \(k\) 个对象。

- **Efficient computation:** Nested loop algorithm 嵌套循环算法
  - For any object \(o_i\), calculate its distance from other objects, and count the number of other objects in the *r*-neighborhood.
  - If \(\pi\cdot n\) other objects are within distance *r*, terminate the inner loop.
  - Otherwise, \(o_i\) is a DB(\(r,\pi\)) outlier.
- **Efficiency:** Actual CPU time is not \(O(n^2)\), but linear in the data set size, since for most non-outlier objects, the inner loop terminates early.
