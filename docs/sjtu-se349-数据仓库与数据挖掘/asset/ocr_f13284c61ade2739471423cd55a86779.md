# 模糊聚类分析

# 一、基本概念及定理

定义：设 $R = (r_{ij})_{n\times n}$ 是 $n$ 阶模糊方阵，$I$ 是 $n$ 阶单位方阵，若 $R$ 满足

+   （1）自反性：$I \le R (\Leftrightarrow r_{ii}=1)$；
+   （2）对称性：$R^T = R (\Leftrightarrow r_{ij}=r_{ji})$；
+   （3）传递性：$R^2 \le R (\Leftrightarrow \max\{(r_{ik} \land r_{kj})\mid 1 \le k \le n\} \le r_{ij})$；

则称 $R$ 为模糊等价矩阵。
