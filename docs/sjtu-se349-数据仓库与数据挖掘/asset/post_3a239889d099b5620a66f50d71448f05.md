
## 层次聚类方法的缺陷

- 算法的层次聚类方法也有一些缺点……
- 为层次聚类选择一种好的距离度量通常是困难的
- 为了使用算法的方法，数据对象不能有缺失的属性值
- 聚类层次结构的优化目标可能不清晰
  - 大部分算法的层次聚类方法都是启发式的，在每一步局部地搜索好的合并/划分

- Generative Model 概率层次聚类
- 旨在通过使用概率模型度量簇之间的距离，克服以上缺点

## Generative Model 概率层次聚类

- 假定用于聚类分析的一维点集 X = {x₁, ..., xₙ}
- 满足高斯分布
  
  $\mathcal{N}(\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

- 于是，点 xᵢ ∈ X 被该模型生成的概率为
  
  $P(x_i|\mu, \sigma^2) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x_i-\mu)^2}{2\sigma^2}}$

- X 被该模型生成的似然为
  
  $L(\mathcal{N}(\mu, \sigma^2) : X) = P(X|\mu, \sigma^2) = \prod_{i=1}^{n} \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x_i-\mu)^2}{2\sigma^2}}$

- 学习该生成模型的任务是找出参数 μ 和 σ²
- 使得
  
  $\mathcal{N}(\mu_0, \sigma_0^2) = \arg\max\{L(\mathcal{N}(\mu, \sigma^2) : X)\}$
  the maximum likelihood

## Generative Model 概率层次聚类

那如何度量它的质量呢？
对于划分成 m 个簇 $C_1, ..., C_m$ 的对象集，质量可以用下式度量
$$Q(\{C_1, ..., C_m\}) = \prod_{i=1}^{m} P(C_i)$$
其中，P() 是最大似然

如果我们把两个簇 $C_{j1}$ 和 $C_{j2}$ 合并成一个簇 $C_{j1} \cup C_{j2}$，则整个聚类质量变化
$$Q((\{C_1, ..., C_m\} - \{C_{j1}, C_{j2}\}) \cup \{C_{j1} \cup C_{j2}\}) - Q(\{C_1, ..., C_m\})$$
$$= \frac{\prod_{i=1}^{m} P(C_i) \cdot P(C_{j1} \cup C_{j2})}{P(C_{j1}) P(C_{j2})} - \prod_{i=1}^{m} P(C_i)$$
$$= \prod_{i=1}^{m} P(C_i) \left( \frac{P(C_{j1} \cup C_{j2})}{P(C_{j1}) P(C_{j2})} - 1 \right)$$

给定簇 $C_i$ 和 $C_j$，他们之间的距离为
$$dist(C_i, C_j) = -\log \frac{P(C_1 \cup C_2)}{P(C_1) P(C_2)}$$ 如果 $dist(C_i, C_j) < 0$, 则合并 $C_i$ 和 $C_j$

## Generative Model 概率层次聚类

每次迭代中，我们试图找到Ci和Cj以最大化 log p(Ci ∪ Cj) / P(Ci)P(Cj)

只要 log p(Ci ∪ Cj) / P(Ci)P(Cj) > 0 即聚类质量有提高，则迭代继续

Algorithm: A probabilistic hierarchical clustering algorithm.

Input:

- D = {o1, ..., on}: a data set containing n objects;

Output: A hierarchy of clusters.

Method:

- (1) create a cluster for each object C_i = {o_i}, 1 ≤ i ≤ n;
- (2) for i = 1 to n
- (3) find pair of clusters C_i and C_j such that C_i, C_j = arg max_{i<j} log P(C_i ∪ C_j) / P(C_i)P(C_j);
- (4) if log P(C_i ∪ C_j) / P(C_i)P(C_j) > 0 then merge C_i and C_j;
- (5) else stop;

## Density-Based Clustering Methods
基于密度的聚类方法

划分和层次方法很难发现球状簇以外的簇......

- 基于密度的簇
  - 密度相连的点的集合
  - 数据空间中被稀疏区域分开的稠密区域
- 主要特点：
  - 发现任意形状的簇
  - 能处理噪声
  - 只需一次扫描
  - 需要密度参数作为终结条件
- 几个有趣的研究：
  - DBSCAN: Ester, et al. (KDD’96)
  - OPTICS: Ankerst, et al (SIGMOD’99)
  - DENCLUE: Hinneburg & D. Keim (KDD’98)

## Density-Based Clustering: Basic Concepts
基于密度的聚类: 背景知识

- 两个参数:
- — Eps: 邻域的最大半径
- — MinPts: 一个对象的Eps-邻域至少包含的对象数

N_Eps(q): {p ∈ D | dist(p,q) <= Eps}

- 直接密度可达: 一个对象p是从对象q关于Eps, MinPts直接密度可达的，如果
- — 1) p 属于 N_Eps(q)
- — 2) 核心对象的条件:
  |N_Eps(q)| >= MinPts

MinPts = 5
Eps = 1 cm

## Density-Reachable and Density-Connected

基于密度的聚类: 背景(II)

- 密度可达的：
- 一个对象p从对象q关于Eps,和MinPts是密度可达的，如果存在一个对象链p1, ..., pn, p1 = q, pn= p pi+1 是从pi关于Eps,和MinPts直接密度可达的

- 密度相连的：
- 如果存在一个对象o，使得对象p和q是从o关于Eps和MinPts 密度可达的，那么对象关于p和q是关于Eps和MinPts 密度相连的

## DBSCAN

- 基于高密度连接区域的密度聚类方法
- Density-Based Clustering Based on Connected Regions with High Density
- 依赖簇的基于密度的思想：它定义簇为密度相连的点的最大集合
- 在带有“噪声”的空间数据库中发现任意形状的聚类

![](img/6d25e92eb0bd56a22c311279c19b06b4_1248_0.png)

## # DBSCAN: The Algorithm
### DBSCAN: 算法

- 任意选择一个点p
- 找出从对象p 关于Eps 和MinPts.密度可达的所有点
- 如果是一个核心对象，则一个聚类就形成了
- 如果p 是一个边界点，没有从p密度可达的对象，DBSCAN则访问数据库中的其他点
- 继续这个过程，知道所有的点被处理
