# Spatial, image and multimedia

+   - 空间数据
+     — 有些对象除具其他类型属性外，还具有空间属性，如位置或区域。
+     - 例：不同的地理位置收集的气象数据（降水量、气温、气压）

+   - 空间数据的一个重要特点是空间自相关性（spatial autocorrelation），即物理上靠近的对象趋向于在其他方面也相似。
+     — 地球上相互靠近的两个点通常具有相近的气温和降水量。
