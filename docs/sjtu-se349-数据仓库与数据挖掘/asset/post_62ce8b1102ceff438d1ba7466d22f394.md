
## 二元属性的相异性

- 二元属性只有两种状态：0或1
- 0表示该属性不出现，1表示该属性出现
- 注意：不能像对待数值一样来处理二元属性！

- 那么，如何计算两个二元属性之间的相异性？
- — 针对 对称二元属性
- E.g., 对于对象 I 和对象 J，
- q 是对象 I 和 J 都取1的属性数
- r 是对象 I 取1，对象 J 取0的属性数
- s 是对象 I 取0，对象 J 取1的属性数
- t 是对象 I 和 J 都取0的属性数

表 2.3 二元属性的列联表
对象 j
1 0 sum
对象 i 1 q r q+r
0 s t s+t
sum q+s r+t p

此时，相异性 $d(i, j) = \frac{r + s}{q + r + s + t}$

## 二元属性的相异性(Cont.)

- 针对 非对称二元属性（E.g., 病理化验的阳性(1)和阴性(0)结果）

- 负匹配（t）被认为是不重要的
- 可以被忽略

表 2.3 二元属性的列联表

|  | 对象 j |  |  |
|---|---|---|---|
|  | 1 | 0 | sum |
| 对象 i |  |  |  |
| 1 | q | r | q + r |
| 0 | s | t | s + t |
| sum | q + s | r + t | p |

- 此时，相异性  $d(i, j) = \frac{r + s}{q + r + s}$

- 相对应的  $sim_{Jaccard}(i, j) = \frac{q}{q + r + s}$
- 也被称为Jaccard系数

## 数值属性的相异性

计算数值属性刻画的对象之间相异性的距离度量：

- - 欧几里得距离
- - 曼哈顿距离
- - 闵可夫斯基距离

![](img/6d25e92eb0bd56a22c311279c19b06b4_336_0.png)

（加权）欧几里得距离（直线或“乌鸦飞行”距离）

```
d(i,j) = √[(x_i1 - x_j1)² + (x_i2 - x_j2)² + (x_i3 - x_j3)² + … + (x_ip - x_jp)²]
```

```
d(i,j) = √[w1|x_i1 - x_j1|² + w2|x_i2 - x_j2|² + … + wp|x_ip - x_jp|²]
```

其中 i = (x_i1, x_i2, x_i3, …, x_ip)，j = (x_j1, x_j2, x_j3, …, x_jp) 是被 p 个数值属性描述的两个对象

曼哈顿距离（城市两点之间的街区距离）

- - 如，向南 2 个街区，横过 3 个街区，共计 5 个街区

```
d(i,j) = |x_i1 - x_j1| + |x_i2 - x_j2| + … + |x_ip - x_jp|
```

## 数值属性的相异性(Cont.)

- 闵可夫斯基距离：欧几里得距离和曼哈顿距离的推广

$d(i,j)=\sqrt[h]{|x_{i1}-x_{j1}|^h+|x_{i2}-x_{j2}|^h+\cdots+|x_{ip}-x_{jp}|^h}$

- 这种距离又称L-p范数

—h=1时为曼哈顿距离，h=2时为欧几里得距离

- 当趋向于正无穷时，我们得到上确界距离（切比雪夫距离）

$d(i,j)=\lim_{h\to\infty}\left(\sum_{r=1}^{p}|x_{ir}-x_{jr}|^h\right)^{1/h}=\max_{r}|x_{ir}-x_{jr}|$

—各座标数值差的最大值

- 也就是找出属性，它产生两个对象的最大值差

## 序数属性的邻近性度量

- - 序数属性的值之间具有有意义的序或排列，但相继值之间的量值未知
-     - e.g. 可乐杯大小
-   - 数值属性的值域可以映射到具有 $M_f$ 个状态的序数属性 $f$
-     - e.g. 摄氏温度可以组织成以下状态
-     - -30~-10，-10~10，10~30 代表 cold, moderate, warm
-   - 顺序很重要 e.g. rank

## 序数属性的邻近性度量(Cont.)

- - 如何处理序数属性？ 和数值属性的处理十分类似
-   - 假设f是用于描述n个对象的一组序数属性之一
-     - 属性f有 M_f 个有序的状态，表示排位1,..., M_f
-     - 用对应的排位 r_{if} ∈ {1,..., M_f} 取代 X_{if}
-     - 将第i个对象的第f个属性的值映射到[0.0,1.0]上
+       $$z_{if} = \frac{r_{if} - 1}{M_f - 1}$$
+     - 相异性可以用之前的任一距离度量计算
+   - 同样,可以得到相似性值
+     $$sim(i,j) = 1 - d(i,j)$$

## 混合类型属性的相异性

- - 之前讨论的是如何计算相同类型的属性描述的对象间的相异性
-   - 一个数据库可能包含所有的属性类型
-     —标称的，对称二元的，非对称二元的，数值 的，序数的
-   - 如何计算混合属性类型的对象间的相异性？
-   - 第一种方法：每种类型的属性分为一组，对每种类型分别进行数据挖掘分析
-     —大部分情况不能产生兼容的结果
-   - 第二种方法:一起处理，只做一次分析
-     —将不同的属性组合在一个相异性矩阵中，所有有意义属性转换到共同的区间[0.0, 1.0]上
