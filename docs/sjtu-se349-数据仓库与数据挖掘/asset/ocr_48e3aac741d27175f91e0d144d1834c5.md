# 哈尔函数（Haar小波）

+   哈尔小波(函数)
+   —最古老和最简单的小波，定义为

```
ψ(x) = { 1    当 0 ≤ x < 1/2
        -1    当 1/2 ≤ x < 1
         0    其他 }
```

+   —生成向量空间W⁰的哈尔小波

```
ψ₀⁰(x) = { 1    0 ≤ x < 1/2
          -1    1/2 ≤ x < 1
           0    其他 }
```
