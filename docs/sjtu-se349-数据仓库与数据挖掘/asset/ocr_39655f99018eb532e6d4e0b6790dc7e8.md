# Requirements and Challenges

对聚类分析的要求

+   - 可伸缩性
+     - 可以针对不同大小的数据进行聚类
+   - 处理不同属性类型的能力
+     - 数值属性、二元属性、标称属性、序数属性、混合的属性等
+   - 基于约束的聚类
+     - 现实世界的应用需要在各种约束条件下进行聚类
+   - 可解释性和可用性
+   - 其他
+     - 发现任何形状的簇
+     - 处理噪声数据的能力
+     - 增量聚类和对输入次序不敏感
+     - 聚类高维数据的能力
