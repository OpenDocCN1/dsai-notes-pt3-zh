# Frequent patterns 频繁模式（频繁项集）

+   - 在数据集中频繁出现的模式
+     - 你在超市里最经常 一起 买的东西是什么？
+   - 存在多种类型的频繁模式
+     - 频繁项集
+       - 啤酒与尿布
+     - 频繁子序列（又称序列模式）
+       - 顾客倾向于先购买笔记本，再购买数码相机，然后购买内存卡
+     - 频繁子结构
+       - 图、树、格等，可以与项集或子序列结合
