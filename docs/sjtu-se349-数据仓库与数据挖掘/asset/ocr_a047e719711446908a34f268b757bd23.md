# Attributes 属性 4 —— 数值属性(Numeric)

+   - 数值属性(Numeric): 定量的
+     用整数或数值表示
+   - 分类
+     — 区间标度属性(Interval)
+     - E.g., 温度、日期等
+     - 用 相等的单位尺度度量
+       - 摄氏温度是水在标准大气压下沸点温度与冰点温度之差的1/100
+     - 值有序，允许比较和定量评估值之间的 差
+       - 温度: 假设有许多天的室外温度值，其中每天是一个对象。把这些值排序，则得到这些对象关于温度的秩评定。可以量化不同值之间的差，例如，温度20度比5度高出15度。
+       - 日历日期: 2002年与2010年相差8年。
+     - 由于没有真正的“零”，不允许 比率
+       - 可以计算温度差，但是不能说一个温度值是另一个的倍数
+     - 可以计算 中位数、众数、均值
