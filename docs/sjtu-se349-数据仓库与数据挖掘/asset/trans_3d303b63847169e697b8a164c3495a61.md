
## 离群点检测（3）：基于聚类的方法
# 基于聚类的方法

假设 Normal data belong to large and dense clusters, whereas outliers belong to small or sparse clusters, or do not belong to any clusters
假设正常数据属于大而密集的簇，而离群点属于小或稀疏的簇，或不属于任何簇

- Example (right figure): two clusters
  - All points not in R form a large cluster
  - The two points in R form a tiny cluster, thus are outliers
- 示例（右图）：两个簇
  - R 中所有点形成一个大簇
  - R 中的两个点形成一个微小簇，因此是离群点

- Since there are many clustering methods, there are many clustering-based outlier detection methods as well
- 由于聚类方法很多，因此基于聚类的离群点检测方法也很多

- Clustering is expensive: straightforward adaption of a clustering method for outlier detection can be costly and does not scale up well for large data sets
- 聚类成本高：直接将聚类方法用于离群点检测会很昂贵，且在大规模数据集上扩展性不佳

## Statistical Approaches
统计学方法

- Statistical approaches assume that the objects in a data set are generated by a stochastic process随机过程 (a generative model生成模型)
- 统计学方法假设数据集中对象由随机过程生成

- Idea: learn a generative model fitting the given data set, and then identify the objects in low probability regions低概率区域 of the model as outliers
- 思路：学习拟合给定数据集的生成模型，然后将模型中低概率区域的对象识别为离群点

- 学习生成模型的方法 Methods are divided into two categories: parametric vs. non-parametric
- 学习生成模型的方法分为两类：参数 vs. 非参数

### Parametric method

- Assumes that the normal data is generated by a parametric distribution with parameter θ
- 假设正常数据由具有参数 θ 的参数分布生成

- The probability density function概率密度函数 of the parametric distribution f(x, θ) gives the probability that object x is generated by the distribution
- 参数分布的概率密度函数 f(x, θ) 给出对象 x 由该分布生成的概率

- The smaller this value, the more likely x is an outlier
- 该值越小，x 越可能是一个离群点

### Non-parametric method

- Not assume an a-priori statistical model and determine the model from the input data不假定先验统计模型，而是试图从输入数据确定模型
- 不假定先验统计模型，而是试图从输入数据确定模型

- Not completely parameter free but consider the number and nature of the parameters are flexible and not fixed in advance大多数非参数方法并不假定模型是完全无参的（完全无参假定将使得从数据学习模型是不可能的），相反，非参数方法通常假定参数的个数和性质都是灵活的，不预先确定
- 大多数非参数方法并不假定模型是完全无参的，相反，非参数方法通常假定参数的个数和性质都是灵活的，不预先确定

- Examples: histogram直方图 and kernel density estimation核密度估计
- 示例：直方图和核密度估计

## Parametric Methods I: Detection Univariate Outliers Based on Normal Distribution

- Univariate data 一元数据: A data set involving only one attribute or variable
- 一元数据：一元数据：仅涉及一个属性或变量的数据集

- 方法原理 Often assume that data are generated from a normal distribution, learn the parameters from the input data, and identify the points with low probability as outliers
- 方法原理：通常假设数据由正态分布生成，从输入数据学习参数，并将低概率点识别为离群点

## Parametric Methods II: Detection of Multivariate Outliers
多元离群点检测

- Multivariate data: A data set involving two or more attributes or variables
- 多元数据：涉及两个或多个属性或变量的数据集

- Transform the multivariate outlier detection task into a univariate outlier detection problem
- 将多元离群点检测任务转化为一元离群点检测问题

- Method 1. Compute Mahalaobis distance 使用马哈拉诺比斯距离识别离群点
  - Let õ be the mean vector 均值向量 for a multivariate data set. Mahalaobis distance for an object o to õ is MDist(o, õ) = (o − õ)ᵀ S⁻¹(o − õ) where S is the covariance matrix 协方差矩阵
  - 设 õ 为多元数据集的均值向量。对象 o 到 õ 的马哈拉诺比斯距离为 MDist(o, õ) = (o − õ)ᵀ S⁻¹(o − õ)，其中 S 为协方差矩阵
  - Use the Grubb's test on this measure to detect outliers
  - 使用 Grubb 检验在此度量上检测离群点

- Method 2. Use χ²–statistic 使用 χ²统计量的多元离群点检测
  - where Eᵢ is the mean of the i-dimension among all objects, and n is the dimensionality 维度
  χ² = Σᵢ=1ⁿ (oᵢ − Eᵢ)² / Eᵢ
  - 其中 Eᵢ 为所有对象中第 i 维的均值，n 为维度
  - If χ²–statistic is large, then object oᵢ is an outlier
  - 如果 χ² 统计量很大，则对象 oᵢ 是离群点
