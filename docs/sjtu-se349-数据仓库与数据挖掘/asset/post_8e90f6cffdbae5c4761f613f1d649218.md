
## 广义线性支持向量机

对于近似线性可分问题不要求所有训练点都满足约束条件 $y_i((w \cdot x_i)+b) \ge 1$，为此对第 $i$ 个训练点 $(x_i, y_i)$ 引入松弛变量(Slack Variable) $\xi_i \ge 0$，把约束条件放松到 $y_i((w \cdot x_i)+b)+\xi_i \ge 1$。（即“软化”约束条件）

$\xi = (\xi_1, \cdots \xi_l)^T$ 体现了训练集被错分的情况，可采用 $\sum_{i=1}^l \xi_i$ 作为一种度量来描述错划程度。

两个目标：1. 间隔 $\frac{2}{||w||}$ 尽可能大 2. 错划程度 $\sum_{i=1}^l \xi_i$ 尽可能小

显然，当 $\xi_i$ 足够大时，样本点 $(x_i, y_i)$ 总可以满足以上约束条件。然而事实上应避免 $\xi_i$ 太大，所以需在目标函数对 $\xi$ 进行惩罚 因此，引入一个惩罚参数 $C>0$，新的目标函数变为：

min_{w,b,ξ}  1/2 ||w||² + C Σ_{i=1}^l ξ_i
s.t.     y_i((w·x_i)+b) ≥ 1 - ξ_i, i = 1,⋯l
         ξ_i ≥ 0, i = 1,⋯l

Σ_{i=1}^l ξ_i 体现了经验风险，而 ||w|| 则体现了表达能力。所以惩罚参数 C 实质是对经验风险和表达能力匹配一个裁决。当 C→∞ 时，近似线性可分 SVC 的原始问题退化为线性可分 SVC 的原始问题。

## 广义线性支持向量机分类算法

- 1. 设已知训练集 $T = \{(x_1, y_1), \cdots, (x_l, y_l)\} \in (X \times Y)^l$，其中 $x_i \in X = R^n, y_i \in Y = \{1, -1\}, i = 1, \cdots, l$
- 2. 选择适当的惩罚参数 $C > 0$，构造并求解最优化问题
  $\min_{\alpha} \frac{1}{2} \sum_{i=1}^{l} \sum_{j=1}^{l} y_i y_j \alpha_i \alpha_j (x_i \cdot x_j) - \sum_{j=1}^{l} \alpha_j$
  $s.t. \quad \sum_{i=1}^{l} y_i \alpha_i = 0$
  $0 \le \alpha_i \le C, i = 1, \cdots l \quad \text{求得 } a^* = (a_1^*, \cdots a_l^*)^T$
- 3. 计算 $w^* = \sum_{i=1}^{l} y_i \alpha_i^* x_i$，选择 $\alpha^*$ 的一个分量 $0 < \alpha_j^* < C$，并据此计算出 $b^* = y_j - \sum_{i=1}^{l} y_i \alpha_i^* (x_i \cdot x_j)$
- 4. 构造划分超平面 $(w^* \cdot x) + b^* = 0$, 决策函数 $f(x) = \operatorname{sgn}((w^* \cdot x) + b^*)$

## 支持向量机原理——线性不可分

- 对于无法直接构造分类超平面的样本集，需要采取某种方法使其能够被某个“平面”划分
- 基本思想是通过选择非线性映射 $\Phi(x)$ 将 $x$ 映射到高维特征空间 $Z$，在 $Z$ 中构造最优分类超平面

原来在二维空间中一个线性不可分的问题，映射到三维空间后，变成了线性可分的！因此这也形成了最初想解决线性不可分问题的思路——向高维空间转化，使其变得线性可分。

- 变换后的线性操作相当于原空间的非线性操作
- 变换后可以完全按照线性支持向量机的方法构造分类超平面
- 非线性分类的问题也就转化为如何构造这种将样本向高维空间的映射关系

- 核函数就是需要的那种映射关系的体现
- 定义：核是一个函数K，对所有x,z∈X，满足
  $$K(x,z)=\langle\phi(x)\cdot\phi(z)\rangle$$
- 这里φ是从X到（内积）特征空间的映射
- 一个好的核函数可以很简洁并且高效地将样本映射为线性可分

max  W(α) = Σ_{i}^{n} α_i - 1/2 Σ_{i}^{n} Σ_{j}^{n} y_i y_j α_i α_j (φ(x_i)·φ(x_j))

s.t.  Σ_{i=1}^{n} y_i α_i = 0
∀i: 0 ≤ α_i ≤ C, i = 1,2,...,n

- 问题：维数灾难
- 解决方法：核函数

max  $W(α)=\sum_{i}^{n}α_i - \frac{1}{2}\sum_{i}^{n}\sum_{j}^{n} y_i y_j α_i α_j k(x_i, x_j)$

s.t.  $\sum_{i=1}^{n} y_i α_i = 0$

$\forall i: 0 \le α_i \le C,\ i=1,2,...,n$

$k(x, y)=φ(x)·φ(y)$

## 特征空间与核函数

- 乘积特征
  - 模式： x ∈ R^N
  - 大部分信息包含在 d-阶乘积中：
    x_{j1} · ... · x_{jd}， j1,...,jd ∈ {1,...,N}
  - 提取所有乘积特征，把输入模式映射到所有 d-阶乘积的特征空间 F 中，在这个空间中构造算法。

- **二维**
  
  $\Phi:\mathbb{R}^2 \to F=\mathbb{R}^3$
  
  $(x_1,x_2) \mapsto (x_1^2,x_2^2,x_1x_2)$

- **N维**
  
  $N_F=\frac{(N+d-1)!}{d!(N-1)!}$
  
  16x16的图像，d=5，则 $N_F：10^{10}$

### 核函数导出的多项式特征空间

—如何在输入空间中计算特征空间中的点积？

```
k(x, y) = (Φ(x) · Φ(y))
```

二维

```
C₂ : (x₁, x₂) ↦ (x₁², x₂², x₁x₂, x₂x₁)
```

```
(C₂(x) · C₂(y)) = x₁²y₁² + x₂²y₂² + 2x₁x₂y₁y₂ = (x · y)²
```

命题1.1：
—映射 C_d 把 x ∈ R^N 映射到向量 C_d(x)，C_d(x) 的项是 x 的项的所有有序 d 阶乘积。则有：
$k(\mathbf{x},\mathbf{y}) = (C_d(\mathbf{x}) \cdot C_d(\mathbf{y})) = (\mathbf{x} \cdot \mathbf{y})^d$

直到 d 阶的所有乘积项：
$k(\mathbf{x},\mathbf{y}) = (\mathbf{x} \cdot \mathbf{y} + 1)^d$

- 核函数的定义

核是一个函数 $k$，对所有 $x, y \in X$

$$k(x, y) = \phi(x) \cdot \phi(y)$$

成立。其中 $\phi: X \to R^n$ 是从输入空间 $X$ 到特征空间 $F$(Hilbert空间)的映射。

Mercer定理：要保证 $L_2(C)$ 下的对称函数 $K: C \times C \to R$ 能以正的系数展开成

$$K(u, v) = \sum_{k=1}^{\infty} a_k \psi_k(u) \psi_k(v)$$ 

（即 $K(u,v)$ 描述了在某个特征空间中的一个内积），其中紧集 $C \subset R^N$，充分必要条件是，对使得 $\int g^2(u) du < \infty$ 的所有 $g \neq 0$，条件

$$\iint K(u, v) g(u) g(v) du dv > 0$$ 成立。
