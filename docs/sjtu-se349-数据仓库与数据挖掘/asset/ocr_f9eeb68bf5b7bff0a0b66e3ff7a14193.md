# CART算法构造决策树：一个例子

③对年收入属性

年收入为数值型属性，首先需要对数据按升序排列，然后从小到大一次以相邻值的中间值作为分隔将样本分为两组，取差异性损失最大的分隔作为该属性的分组

以第一个相邻值得中间值65为例，将其作为分隔点，S_L表示年收入小于65的样本，S_R表示年收入大于65的样本

Δgini(年收入,r)=gini(r)−|S_R|/(|S_L|+|S_R|) gini(r_R)−|S_L|/(|S_L|+|S_R|) gini(r_L)
=0.42−1/10(1−(1/1)^2−(0/1)^2)−9/10×(1−(6/9)^2−(3/9)^2)=0.02
