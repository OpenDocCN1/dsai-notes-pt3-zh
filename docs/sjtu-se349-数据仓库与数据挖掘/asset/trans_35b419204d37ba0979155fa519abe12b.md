

## 为什么不用半监督聚类？

- 需要大量信息（来自多个关系）来判断两个元组是否相似
- 用户可能无法提供一个好的训练集
- 对于用户来说，指定一个属性作为提示要容易得多，例如学生的*研究领域*

## CrossClus：概述

- 通过它们将对象分组到簇中的方式来衡量*特征之间的相似性*
- 使用启发式方法搜索相关特征
  - *从用户指定的特征开始并逐步扩展搜索范围*
- 使用*元组 ID 传播*来创建特征值
  - 在扩展搜索范围时，可以通过传播 ID 轻松创建特征
- 探索三种聚类算法：*k-means、k-medoids* 和层次聚类

## 多关系特征

- 多关系特征由以下定义：
  - 一个连接路径，例如 *Student → Register → OpenCourse → Course*
  - 一个属性，例如 *Course.area*
  - （对于数值特征）一个聚合运算符，例如 sum 或 average
- 分类特征 f = [*Student → Register → OpenCourse → Course*，*Course.area*，null]

## 表示特征

- 元组 $t_1$ 和 $t_2$ 关于分类特征 $f$ 的相似性
- — 向量 $f(t_1)$ 和 $f(t_2)$ 之间的余弦相似性

```
sim_f(t_1,t_2)= \frac{\sum_{k=1}^{L} f(t_1).p_k \cdot f(t_2).p_k}{\sqrt{\sum_{k=1}^{L} f(t_1).p_k^2} \cdot \sqrt{\sum_{k=1}^{L} f(t_2).p_k^2}}
```

![](img/6d25e92eb0bd56a22c311279c19b06b4_1376_0.png)

- 特征 $f$ 的最重要信息是 $f$ 如何将元组分组到簇中

- $f$ 由 $f$ 表示的每对元组之间的相似性表示

- 水平轴为元组索引，垂直轴为相似性

- 这可以被视为 $N \times N$ 维的向量

两个特征之间的相似性 – 两个向量的余弦相似性

```
sim(f, g) = (V^f · V^g) / (|V^f| |V^g|)
```
