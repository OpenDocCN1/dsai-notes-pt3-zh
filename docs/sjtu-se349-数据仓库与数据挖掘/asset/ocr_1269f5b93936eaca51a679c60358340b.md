# 规范化Normalization

+   最小-最大规范化 Min-max normalization: to [new_min_A, new_max_A]
+   
+   v' = (v - min_A)/(max_A - min_A) (new_max_A - new_min_A) + new_min_A
+   
+   Ex. Let income range $12,000 to $98,000 normalized to [0.0, 1.0]. Then $73,000 is mapped to (73,600-12,000)/(98,000-12,000) (1.0-0)+0 = 0.716

+   Z分数规范化Z-score normalization ( μ : mean, σ : standard deviation):
+   
+   v' = (v - μ_A)/σ_A
+   
+   Ex. Let μ = 54,000, σ = 16,000. Then (73,600-54,000)/16,000 = 1.225

+   小数定标规范化Normalization by decimal scaling
+   
+   v' = v / 10^j   Where j is the smallest integer such that Max(| v '|) < 1
