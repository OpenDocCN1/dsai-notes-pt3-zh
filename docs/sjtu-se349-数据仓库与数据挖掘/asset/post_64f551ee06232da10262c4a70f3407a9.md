
# Major Clustering Approaches
主要聚类方法的分类——（3）基于密度的方法

- 大部分划分方法基于对象之间的距离进行聚类，只能发现球状族，而在发现任意形状的簇时遇到了困难

- 基本思想
  - 只要“邻域”中的密度（对象或数据点的数目）超过某个阈值，就继续增长给定的簇。也就是说，对给定簇中的每个数据点，在给定半径邻域中必须至少包含最少数目的点
  - 这样的方法可以用来过滤噪声或离群点，发现任意形状的族

| 方法 | 一般特点 |
|---|---|
| 划分方法 | - 发现聚形互斥的簇<br>- 基于距离<br>- 可以用均值或中心点等代表簇中心<br>- 对中小规模数据集有效 |

# Partitioning Algorithms - Basic Concept
## 划分方法－基本概念

# 划分方法

把具有 n 个对象的数据库 D 构造成具有 k 个簇的集合的划分

$E = \sum_{i=1}^{k}\sum_{p\in C_i}(d(p,c_i))^2$

（其中 $c_i$ 是簇群 $C_i$ 的**形心**）

> 对象 p 与该簇的代表 cᵢ 的误差，用它们的欧氏距离表示

簇 $C_i$ 的质量——**簇内变差**

这个目标函数试图使生成的结果簇尽可能紧凑和独立

# 给定 k，找出有 k 个簇的一个划分使得所选择的划分准则最优

全局最优：穷举所有可能的划分（**NP-困难**）

- 簇个数 k、空间维度 d、对象个数 n：时间复杂度 $O(n^{d+1}\log n)$

启发式方法：**k-平均算法** 和 **k-中心点算法**

- **k-均值算法**（MacQueen’67）：把簇的形心定义为簇内点的均值
- **k-中心点算法**或 PAM（Partition around medoids）：每一个簇用接近聚类中心的一个对象（代表对象）表示

# The K-Means Clustering Method
K—均值算法

- 使用簇的均值代表该簇
- 簇Ci的均值可以用以下计算公式：
  $$\bar{x}_i = \frac{1}{|C_i|} \sum_{x \in C_i} x$$
- 对象 $p \in C_i$ 与该簇的代表 $c_i$ 之差用 $dist(p, c_i)$ 度量
- 其中 $dist(x, y)$ 是两个点 x 和 y 之间的欧氏距离
- 簇Ci的质量可以用簇内变差度量
  $$E = \sum_{i=1}^{k} \sum_{p \in C_i} dist(p, c_i)^2$$
- 其中 E 是数据集中所有对象的误差的平方和，p 是空间中的点，表示给定的数据对象，$c_i$ 是簇 Ci 的代表

# The K-Means Clustering Method
K-均值算法

算法：k-均值。用于划分的k-均值算法，其中每个簇的中心都用簇中所有对象的均值来表示。
输入：
• k: 簇的数目；
• D: 包含n个对象的数据集。
输出：k个簇的集合
方法：
(1) 从D中任意选择k个对象作为初始簇中心；
(2) repeat
(3) 根据簇中对象的均值，将每个对象分配到最相似的簇；
(4) 更新簇均值，即重新计算每个簇中对象的均值；
(5) until不再发生变化；

# The K-Means Clustering Method
## K-均值算法 — 优劣

# ## Strength　优点

— 复杂度：**O(tkn)**

其中 n 是对象的数目，k 是簇的数目，t 是迭代的次数。通常 k、t << n

# ## Weakness　缺点

- 需要事先给出 k，簇的数目
- 对初始值选取敏感，常以**局部最优**结束
- 不能处理噪声数据和孤立点，**对离群点敏感！**
- 不适合发现非凸面形状的簇，或具有不同大小或密度的簇
  - 所采用的簇的表示及簇间相似性度量不能反映这些自然簇的特征
- 只有在簇的平均值被定义的情况下才能使用，当涉及有分类属性的数据时该怎么办？

- “不能处理噪声数据和孤立点，对离群点敏感！”

- 例

一维空间7个点{1,2,3,8,9,10,25}

- 直觉应该分为{1,2,3}、{8,9,10}，25是离群点

使用k=2，进行k—均值

- {1,2,3}、{8,9,10,25}

簇内变差计算(1-2)² +(2-2)² +(3-2)² + +(8-13)² + (9-13)² + (10-13)² +(25-13)² =196

- {1,2,3,8}、{9,10,25}

簇内变差计算(1-3.5)² +(2-3.5)² +(3-3.5)² +(8-3.5)² +(9-14.67)² +(10-14.67)² +(25-14.67)² =189.67

- 由于离群点25的影响，使8被聚集到与8、10不同的簇

- 簇中心偏离所有的簇成员

# 一些变种k-平均方法在以下策略上有所不同

- 通过簇的自动合并和分裂得到较为合理的簇数目 K
- K 个初始平均值的选择
- 相异度的计算
- 计算聚类平均值的策略

- 标称属性数字运算没有意义
- 婚姻状况 = {单身、已婚、离异、丧偶}

当簇的均值有定义时才能使用k—均值。在某些应用中，例如当涉及具有标称属性的数据时，均值可能无定义

—k-众数(k-modes)方法(Huang’98)

- • 用 众数 来代替聚类的平均值（集合中出现最频繁的值）
- • 使用新的相异性度量来处理分类对象
- • 采用基于频率的方法来修改聚类的众数
- • 分类数据和数值数据的综合：集成k-均值和k-众数方法

# K-中心点：一种基于代表对象的技术

- K-均值算法对离群点敏感！
  ——一个有着很大值的对象能够大幅度地扭曲数据的分布

- K-中心点：不采用簇中对象的均值作为参照点，而是挑选实际对象来代表簇，每个簇使用一个对象

- 使用绝对误差标准
  $E = \sum_{i=1}^{k} \sum_{p \in C_i} dist(p, o_i)$

E是数据集中所有对象p与Ci的代表对象oi的绝对误差之和

# K-中心点：一种基于代表对象的技术

- K-中心点聚类方法，在时间O(k(k-n)²)内可找到准确中位数，K-中心点是NP-hard问题
  — 对小数据集很有效，但对大数据集计算代价相当高

- PAM (Partitioning Around Medoids，围绕中心点的划分，1987)是K-中心点的一种流行的实现
  — 初始代表对象任意选取，接着重复地用一个非代表对象代替代表对象，如果它改善了结果聚类的整体距离则替换
