# 国家智慧城市名单出炉

+   - 2013年1月29日，住建部组织召开国家智慧城市试点创建工作会议，公布了首批国家智慧城市试点名单
+     - 住建部与第一批90个试点城市（区、县、镇）代表及其上级人民政府签订了共同推进智慧城市创建协议。试点城市将经过3—5年的创建期，住建部将组织评估，对评估通过的试点城市(区、镇)进行评定，评定等级由低到高分为一星、二星和三星
+       - 地级市37个：上海市浦东新区、无锡市…
+       - 区(县)50个：宁波市镇海区、山东寿光市 …
+       - 镇3个：佛山市乐从镇…
+     - 预计“十二五”期间用于建设“智慧城市”各方投资总规模有望达5000亿。伴随各级政府投入力度持续加大，智慧城市建设纵深发展速度加快

+   - 2013年8月5日住建部公布了第二批国家智慧城市试点名单
+     - 北京经济技术开发区等103个城市(区、县、镇)被列入到名单当中,其中包含83个市、区，20个县、镇，以及9个扩大范围的第一批试点城市。
+     - 第二批试点城市扩围至103个地区，有望带动万亿投资
