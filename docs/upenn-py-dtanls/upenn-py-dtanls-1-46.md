# 46：数据更新与创建 📊

在本节课中，我们将学习如何在Pandas DataFrame中创建和插入新的数据列。这是数据预处理和特征工程中的基础操作。

## 概述

上一节我们介绍了DataFrame的基本结构。本节中我们来看看如何向DataFrame中添加新的数据列。

## 创建新列

![](img/a74f8f3672067ffe7076d460589f579d_1.png)

在DataFrame中创建新列非常简单，只需为新列指定一个唯一的名称并为其赋值即可。

![](img/a74f8f3672067ffe7076d460589f579d_2.png)

例如，以下代码演示了创建新列的基本方法：

![](img/a74f8f3672067ffe7076d460589f579d_3.png)

```python
df['new_column'] = some_value
```

以下是创建新列的具体示例：

1.  **创建单值列**：`df['new_column'] = 1`
    *   此操作会创建一个名为“new_column”的新列，该列所有行的值均为1。

![](img/a74f8f3672067ffe7076d460589f579d_5.png)

2.  **创建多值列**：`df['new_column'] = [1, 2, 3]`
    *   此操作会创建一个名为“new_column”的新列，该列包含三行，值分别为1、2和3。

## 插入新列

除了直接赋值创建，你还可以使用`insert`方法将新列插入到DataFrame的指定位置。

`insert`方法允许你指定新列要插入的索引位置。

其基本语法为：
```python
df.insert(loc, column, value)
```
*   **`loc`**： 插入位置的整数索引（0-based）。
*   **`column`**： 新列的名称。
*   **`value`**： 要插入的数据。

## 总结

本节课中我们一起学习了在Pandas DataFrame中创建和插入新列的两种核心方法：通过直接赋值创建，以及使用`insert`方法在特定位置插入。掌握这些操作是进行数据整理和构建分析模型的重要步骤。
