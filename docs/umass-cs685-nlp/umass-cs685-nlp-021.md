# 21：L17 - 视觉与语言模型 🖼️📝

在本节课中，我们将要学习多模态自然语言处理，特别是视觉与语言之间的交互。我们将介绍如何使用神经网络表示图像，然后将这些模型与我们之前见过的标准模型连接起来，以解决图像描述和视觉问答等任务。

## 概述

多模态任务结合了视觉和语言信息。我们将从图像表示的基础知识开始，然后探讨如何将这些表示与语言模型结合，以完成图像描述生成和视觉问答等应用。

## 图像表示基础

![](img/5f0a2b72e7444a3e5284c886dc8c842b_1.png)

在深入应用之前，我们首先需要讨论如何获取图像的表示。与由单词或字符组成的句子不同，图像由像素构成。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_3.png)

### 图像作为像素矩阵

![](img/5f0a2b72e7444a3e5284c886dc8c842b_5.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_6.png)

最简单的图像类型是灰度图像，它可以表示为一个像素值矩阵，范围从0到255。整个图像完全由这些像素定义。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_8.png)

对于彩色图像（如RGB图像），情况类似，但我们需要三个矩阵（分别对应红色、绿色和蓝色通道）。它们共同形成一个三维张量，其中第一个维度（通道）对应颜色。

### 卷积操作

![](img/5f0a2b72e7444a3e5284c886dc8c842b_10.png)

过去十年中，计算机视觉中最基本且最常用的操作是卷积。虽然最近的研究尝试用基于自注意力的网络（如Transformer）替代卷积网络，但卷积仍然是理解视觉模型的基础。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_12.png)

卷积的核心非常简单。我们从一个称为**核**（或**滤波器**）的小矩阵开始。我们将这个滤波器滑动到图像的每个部分。在每个位置，我们计算滤波器与对应图像区域像素值的元素乘积之和，并将结果放入输出矩阵的相应位置。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_14.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_16.png)

以下是卷积操作的直观演示：
*   假设我们有一个用于锐化的核，它对中心像素赋予高权重，并对边缘像素赋予负权重。
*   当我们将这个核滑动到图像上时，输出图像中对应区域的像素值会发生变化，例如边缘变得更暗。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_17.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_19.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_20.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_21.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_23.png)

通过定义不同类型的核，我们可以通过卷积操作获得不同的输出效果，例如模糊、轮廓检测等。许多基本的图像处理操作（如Photoshop中的滤镜）都可以通过简单的核来定义。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_25.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_27.png)

卷积操作通常是并行计算的，每个输出像素的计算不依赖于其他位置的计算。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_29.png)

### 卷积神经网络

![](img/5f0a2b72e7444a3e5284c886dc8c842b_31.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_32.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_34.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_36.png)

卷积神经网络的洞察在于，我们不使用固定的核，而是让网络**学习**对特定任务最有用的变换权重。此外，我们可以堆叠多个卷积层，以获得越来越复杂的变换，最终帮助执行下游任务。

在一个卷积层中，我们通常不只使用一个滤波器，而是使用许多不同的滤波器应用于同一输入。每个滤波器会产生一个输出特征图。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_38.png)

卷积神经网络的**学习参数**就在这些核（滤波器）中。我们通常还有**池化层**（如最大池化），它们没有参数，但目的是降低特征图的维度，迫使模型学习将重要信息编码到更紧凑的表示中。

卷积神经网络比NLP中的Transformer等模型更具可解释性。较低层的滤波器通常对应边缘检测或低级形状检测等功能，而较高层则建模更抽象的概念，如图像中的物体或动作。

## 从图像分类到视觉表示

![](img/5f0a2b72e7444a3e5284c886dc8c842b_40.png)

深度学习革命始于AlexNet等论文，它们首次展示了深度卷积神经网络在图像分类任务上可以达到很高的准确率。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_42.png)

ImageNet是一个经典的图像分类数据集，包含大约1000个类别。模型的目标是将输入图像分类到其中一个类别中。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_44.png)

AlexNet架构相对直接：它包含多个卷积层和池化层，最后通过几个全连接层和一个针对1000个类别的Softmax分类层。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_46.png)

无论网络架构如何，在最终Softmax层之前，我们通常会得到一个固定维度的向量（例如AlexNet中是4096维）。这个向量编码了图像的许多属性。

因此，通过一个在ImageNet上预训练的CNN，我们获得了一个函数：它接收图像作为输入，并输出一个向量。这为我们提供了一种简单的方法，可以将图像表示插入到现有的语言任务架构中。

这种在计算机视觉中预训练大型CNN然后在下游任务上微调的方法，比NLP领域的类似方法（如ELMo）出现得更早，是**迁移学习**的成功范例。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_48.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_49.png)

## 视觉问答

![](img/5f0a2b72e7444a3e5284c886dc8c842b_52.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_53.png)

视觉问答任务的输入是一张图像和一个自然语言问题，输出通常是一个简短的答案（如“是/否”或单个词语）。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_55.png)

### 简单方法及其局限

一个直接的方法是分别计算图像和问题的向量表示：
*   图像向量 `I`：通过预训练的ImageNet CNN获得。
*   问题向量 `Q`：通过BERT等模型获得。

然后，我们可以将这两个向量拼接起来，并通过一个Softmax层来预测答案。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_57.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_59.png)

然而，这种方法存在严重缺陷：它没有让问题影响图像表示，也没有让图像影响问题表示。我们是在分别计算表示后才进行信息融合。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_61.png)

### 视觉注意力

更好的方法是使用**视觉注意力**，其机制与我们在文本中看到的注意力完全相同，只是现在处理的是卷积层的特征图输出，而不是NLP中的不同时间步位置。

基本思想如下：
1.  从问题中获得一个向量表示（例如使用BERT）。
2.  将图像的特征图划分为多个区域（例如一个网格），并为每个区域获取一个向量表示。
3.  使用问题向量作为**查询**，区域向量作为**键**，计算注意力分布。理想情况下，注意力会集中在与问题相关的区域（例如，如果问“有多少条长凳？”，注意力应集中在包含长凳的区域）。
4.  使用注意力概率作为权重，对区域级向量进行加权平均，从而得到一个融合了问题信息的图像向量。
5.  最后，基于这个上下文化的图像向量（或将其与问题向量结合）来预测答案。

我们讨论的是**软注意力**，它通过标准的点积和Softmax计算，所有区域都会获得一定的概率。还有**硬注意力**，它强制只有一个区域获得100%的注意力，但这通常需要强化学习来训练，并不如软注意力实用。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_63.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_65.png)

### 需要推理的复杂VQA

![](img/5f0a2b72e7444a3e5284c886dc8c842b_67.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_68.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_69.png)

除了简单的“是/否”问题，还有一些合成数据集旨在测试模型的多步推理能力。例如，一个问题可能是：“红色形状是否在圆形上方？” 这需要模型先检测圆形，再查看圆形上方的物体，最后判断其颜色。

对于这类任务，一种有趣的方法是**神经模块网络**。其核心思想是将问题解析成一个由多个“模块”组成的程序，每个模块是一个小型神经网络，负责执行特定的子功能（如“检测红色”、“检测上方”）。然后，按照程序结构组合这些模块，并在图像上执行，最终得到答案。这种方法结合了词汇的语义落地和可解释的程序结构。

然而，将这些方法推广到真实世界的复杂VQA任务（如需要同时推理两张图像的NLVR数据集）仍然具有挑战性，目前性能远未达到完美。

## 图像描述生成

![](img/5f0a2b72e7444a3e5284c886dc8c842b_71.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_72.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_74.png)

图像描述生成任务非常直观：模型接收一张图像作为输入，并生成一段描述该图像的文本。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_76.png)

### 基本架构

我们已经掌握了生成文本的所有组件。任何条件语言模型架构都可以用于此。与机器翻译的序列到序列模型相比，唯一需要改变的是编码器。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_78.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_80.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_82.png)

概念上，我们可以将机器翻译模型中的编码器替换为在图像上运行的卷积网络的输出。具体步骤如下：
1.  图像通过预训练的CNN，得到一个向量表示。
2.  将该向量作为**初始隐藏状态**输入到一个循环神经网络解码器（或Transformer解码器）中。
3.  解码器基于图像表示和已生成的词，自回归地生成描述词序列。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_84.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_86.png)

在生成过程中，通常使用**束搜索**来获得近似最可能的描述。虽然采样可以产生更多样化的输出，但可能以牺牲对图像的忠实度为代价。

### 带注意力的图像描述生成

与VQA类似，我们也可以在图像描述生成中加入**注意力机制**。我们不再使用整个图像的单一向量，而是提取图像特征图的不同区域表示。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_88.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_89.png)

在解码的每个时间步，RNN可以关注图像的不同区域。这使我们能够可视化在生成特定词语时模型正在关注图像的哪一部分。例如，在生成“鸟”时，注意力可能集中在鸟身上；在生成“水面”时，注意力可能转移到背景水域。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_91.png)

虽然存在一些注意力图清晰可辨的成功案例，但研究表明，这种注意力并不总是完全可解释的，有时会过度关注图像中心等显著区域。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_93.png)

![](img/5f0a2b72e7444a3e5284c886dc8c842b_94.png)

## 前沿与总结

### 视觉-语言预训练模型

![](img/5f0a2b72e7444a3e5284c886dc8c842b_96.png)

受BERT在NLP领域成功的启发，出现了许多视觉-语言版本的预训练模型，如ViLBERT。这些模型的预训练策略通常包括：
1.  **掩码语言建模**：随机掩码文本中的词，让模型根据图像和上下文文本来预测。
2.  **掩码区域预测**：随机掩码图像区域，让模型预测被掩码区域的类别或描述。
3.  **图像-文本匹配**：判断给定的图像和文本描述是否匹配。

通过在大规模图文对数据上进行此类预训练，模型可以学习到视觉与语言之间的对齐关系，从而显著提升在下游VQA等任务上的性能。

![](img/5f0a2b72e7444a3e5284c886dc8c842b_98.png)

### 更复杂的任务：视觉环境中的导航

一个更具挑战性的研究方向是让智能体在视觉环境中根据自然语言指令进行导航。例如，在一个虚拟3D环境中，智能体需要理解“向左转，朝黄色心形方向前进”这样的指令，并执行一系列低级动作（移动、转向）来完成目标。

这类任务将智能体置于动态的、需要交互的环境中，要求模型具备更强的**基础**能力和**序列决策**能力，通常涉及强化学习。这代表了多模态研究向更复杂、更接近现实世界应用方向的发展。
