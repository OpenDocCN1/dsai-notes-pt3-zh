## 从确定性到不确定性

![](img/7e1e838399e117688bd2181daa321807_12.png)

![](img/7e1e838399e117688bd2181daa321807_14.png)

![](img/7e1e838399e117688bd2181daa321807_16.png)

上一节我们讨论了确定性的计算模型。本节中，我们来看看一个截然不同的世界——一个充满不确定性的世界。现实世界往往是难以精确预测的，而计算思维需要直面这种不确定性。

与典型的、专注于确定性功能的计算机科学入门课程不同，本课程将探讨如何处理不可预测性。一个类比是牛顿力学与量子力学的区别：牛顿力学认为每个结果都有确定的原因，而量子力学（哥本哈根诠释）则认为世界在最基本的层面上是因果非决定论的，我们只能谈论事件发生的概率，而不能断言其必然发生。

![](img/7e1e838399e117688bd2181daa321807_18.png)

然而，无论世界在本质上是否不可预测，我们永远无法获得关于世界的完整知识这一事实，意味着我们不妨将其视为本质上不可预测的。这被称为**预测性非决定论**，它将是我们后续几乎所有讨论的基础。

当我们思考计算中的非决定性时，会用到**随机过程**这个词。它指的是任何其下一个状态依赖于先前状态和某些随机因素的持续过程。

![](img/7e1e838399e117688bd2181daa321807_28.png)

在代码中实现随机过程，我们通常使用Python的`random`库。核心概念是使用`random.choice()`函数从一个序列中**均匀地**随机选择一个元素。

![](img/7e1e838399e117688bd2181daa321807_30.png)

![](img/7e1e838399e117688bd2181daa321807_32.png)

![](img/7e1e838399e117688bd2181daa321807_34.png)

```python
import random

def rollDie():
    """返回一个1到6之间的随机整数"""
    return random.choice([1,2,3,4,5,6])
```

![](img/7e1e838399e117688bd2181daa321807_36.png)

![](img/7e1e838399e117688bd2181daa321807_38.png)

`random.choice()`函数接受一个序列（例如列表）作为参数，并**均匀地**随机选择其中一个成员。这意味着每次调用时，选择列表中任何数字的概率都是相等的。

## 概率的基本概念

![](img/7e1e838399e117688bd2181daa321807_44.png)

为了理解随机模拟的结果，我们需要一些基本的概率知识。概率，特别是离散概率，本质上关乎计数。

![](img/7e1e838399e117688bd2181daa321807_46.png)

计算一个事件概率的基本方法是：
1.  计算所有可能事件的总数。
2.  计算满足我们感兴趣属性的事件数量。
3.  用后者除以前者。

基于这个框架，有三个基本的概率事实我们会经常用到：

![](img/7e1e838399e117688bd2181daa321807_48.png)

![](img/7e1e838399e117688bd2181daa321807_50.png)

以下是三个核心的概率规则：
*   **概率范围**：概率值总是在0到1之间（包含0和1）。0表示事件永远不会发生，1表示事件总是发生。
*   **互补事件**：如果一个事件发生的概率是`P`，那么它不发生的概率就是`1 - P`。这个规则非常实用，因为有时计算一个事件不发生的概率反而更容易。
*   **独立事件的乘法法则**：如果事件A和事件B是**独立的**（即一个事件的结果不影响另一个事件的结果），那么两个事件同时发生的概率等于它们各自概率的乘积，即 `P(A and B) = P(A) * P(B)`。

![](img/7e1e838399e117688bd2181daa321807_52.png)

![](img/7e1e838399e117688bd2181daa321807_54.png)

**必须注意**：乘法法则**仅当事件相互独立时才成立**。错误地假设独立性会导致完全错误的结果。例如，两支球队在各自比赛中获胜可能是独立的，但如果它们彼此对战，则结果就不再独立。

![](img/7e1e838399e117688bd2181daa321807_56.png)

## 通过模拟估计概率

![](img/7e1e838399e117688bd2181daa321807_58.png)

现在，让我们看看如何通过编写模拟程序来估计事件的概率，而不是依赖复杂的数学公式。

![](img/7e1e838399e117688bd2181daa321807_60.png)

![](img/7e1e838399e117688bd2181daa321807_62.png)

![](img/7e1e838399e117688bd2181daa321807_64.png)

几乎所有的模拟都会遵循类似的结构：
1.  初始化一个计数器（例如`numMatches = 0`）。
2.  进行大量（`numTrials`次）实验。
3.  在每次实验中，模拟随机过程（例如，投掷骰子多次）。
4.  检查实验结果是否满足目标条件，如果满足，则增加计数器。
5.  最后，用满足条件的实验次数除以总实验次数，得到估计的概率。

```python
def runSim(goal, numTrials):
    total = 0
    for i in range(numTrials):
        result = ''
        for j in range(len(goal)):
            result += str(rollDie())
        if result == goal:
            total += 1
    estProbability = round(total/numTrials, 8)
    print('Estimated Probability:', estProbability)
```

![](img/7e1e838399e117688bd2181daa321807_66.png)

![](img/7e1e838399e117688bd2181daa321807_68.png)

![](img/7e1e838399e117688bd2181daa321807_70.png)

运行这个模拟会引出两个关键点：
1.  **伪随机性**：计算机无法生成真正的随机数，它生成的是**伪随机数序列**。通过设置`random.seed()`，我们可以让这个序列在每次运行时都相同，这在调试时非常有用。
2.  **样本概率 vs. 实际概率**：模拟得到的是**样本概率**，它是基于有限次试验的估计。对于罕见事件，需要进行非常大量的试验才能获得接近实际概率的可靠估计。如果试验次数不足，估计值可能为0或严重偏离真实值。

模拟的真正威力在于解决那些数学上棘手的问题。经典的“生日问题”就是一个很好的例子：在一个有`n`个人的房间里，至少有两个人生日相同的概率是多少？

对于“至少两人同生日”的情况，存在一个数学解析解（通过计算“所有人生日都不同”这个互补事件的概率来得）。但是，如果我们想问“至少三人生日相同”的概率呢？数学计算会变得非常复杂。

![](img/7e1e838399e117688bd2181daa321807_80.png)

![](img/7e1e838399e117688bd2181daa321807_82.png)

然而，修改模拟代码来回答这个问题却异常简单：我们只需要改变检查条件，从“是否有任意日期计数>=2”改为“是否有任意日期计数>=3”。

![](img/7e1e838399e117688bd2181daa321807_84.png)

![](img/7e1e838399e117688bd2181daa321807_86.png)

```python
# 检查是否有至少`numSame`个人生日相同
maxCount = max(birthdays)
if maxCount >= numSame: # 将numSame从2改为3
    return True
else:
    return False
```

这个例子清晰地展示了模拟的灵活性。我们可以轻松地改变模型参数（如要求共享生日的人数）或假设（如生日的分布不是均匀的），而无需推导复杂的新公式。

## 什么是模拟模型？

通过上面的例子，我们可以总结出**模拟模型**的定义：它是一个描述计算的程序，用于提供关于系统可能行为的信息。

![](img/7e1e838399e117688bd2181daa321807_96.png)

模拟模型有几个关键特征：
*   **描述性而非规定性**：它描述在给定条件下可能发生什么，但并不告诉你如何达到某个特定结果（这与我们之前学的**优化模型**不同，优化模型是规定性的，旨在找到最佳路径或方案）。
*   **现实世界的近似**：所有模型都是对现实的简化，模拟模型也不例外。正如统计学家乔治·博克斯所说：“所有的模型都是错的，但有些是有用的。”
*   **用途广泛**：我们使用模拟来为数学上难以处理的系统建模、获取中间结果、以及进行“假设分析”游戏，通过逐步细化模型来探索不同场景。

本节课中我们一起学习了随机性思维的核心概念。我们了解了概率的基本规则，掌握了在Python中实现随机过程的方法，并深刻体会到模拟模型在解决复杂、不确定性问题时的强大力量和灵活性。我们从简单的掷骰子模拟出发，一直扩展到分析非均匀分布下的生日问题，看到了如何通过计算来探索和理解我们周围的不确定世界。
