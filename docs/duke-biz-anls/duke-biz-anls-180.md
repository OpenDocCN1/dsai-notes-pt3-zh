**核心技能掌握**

上一节我们回顾了学习历程，本节中我们来看看你掌握的核心技能。

你已熟悉商业术语，并掌握了三个核心工具：
*   **Excel**：用于数据清洗、计算与分析。
*   **Tableau**：用于数据可视化与仪表板创建。
*   **SQL**：用于数据库查询，核心操作如 `SELECT * FROM table WHERE condition`。
