# 📐 课程 1.2：向量标记与符号

上一节我们介绍了课程的整体框架，本节中我们来看看线性代数中最基本的概念之一：向量。我们将学习如何表示和标记向量。

## 概述

向量是同时具有大小和方向的量，在数学和工程中用于表示一组有序的数字。本节将介绍向量的标准表示方法。

## 向量的表示

一个包含 *n* 个元素的列向量通常表示为：

**x = [x₁, x₂, ..., xₙ]ᵀ**

其中，*xᵢ* 是向量的第 *i* 个分量，上标 *ᵀ* 表示转置（将行向量转为列向量）。在代码中，我们常用数组或列表来表示向量。

```python
# 示例：在Python中表示一个向量
import numpy as np
x = np.array([1, 2, 3, 4])  # 这是一个行向量
x_column = x.reshape(-1, 1) # 将其转为列向量
```

## 向量的维度

向量的维度指的是其包含的元素个数。一个 *n* 维向量存在于 *n* 维空间中。

# 🔢 课程 1.3：向量示例

理解了向量的符号表示后，本节我们通过具体的例子来看看向量在不同领域中的应用。

## 概述

向量不仅仅是抽象的数学对象，它们可以代表现实世界中的各种数据。本节将展示几个向量示例。

## 常见向量示例

以下是向量在不同场景下的具体例子：

1.  **空间位置**：在物理学和计算机图形学中，一个三维向量 **v = [x, y, z]** 可以表示空间中的一个点或一个方向。
2.  **数据样本**：在机器学习中，一个关于房屋的特征向量可能是 **house = [面积, 卧室数, 房龄, 价格]**。
3.  **时间序列**：在信号处理中，一个向量可以表示一段时间内采集到的离散信号值，例如音频采样点。

## 向量的可视化

对于二维或三维向量，我们可以在坐标系中将其绘制为从原点指向坐标点 `(x, y)` 或 `(x, y, z)` 的箭头。这有助于直观理解向量的方向和大小。

# ➕ 课程 1.4：标量乘法与加法

我们已经见过向量的样子，现在来学习如何操作它们。本节介绍两种最基本的向量运算：标量乘法和向量加法。

## 概述

标量乘法和加法是线性代数的基础，它们定义了向量空间的结构。

## 标量乘法

将一个向量 **v** 乘以一个标量（实数）*α*，意味着将向量的每个分量都乘以 *α*。

**公式**：*α***v** = [*αv*₁, *αv*₂, ..., *αv*ₙ]ᵀ

几何上，这相当于将向量 **v** 拉伸（*α* > 1）、压缩（0 < *α* < 1）或反转方向（*α* < 0）。

## 向量加法

两个相同维度的向量 **u** 和 **v** 可以相加，结果是一个新向量，其每个分量是 **u** 和 **v** 对应分量之和。

**公式**：**u** + **v** = [*u*₁ + *v*₁, *u*₂ + *v*₂, ..., *u*ₙ + *v*ₙ]ᵀ

几何上，向量加法遵循平行四边形法则或三角形法则。

# ⚖️ 课程 1.5：向量与内积

掌握了向量的基本运算后，本节我们引入一个极为重要的概念：内积（或点积）。它用于衡量两个向量之间的“相似性”。

## 概述

内积是一个将两个向量映射到一个标量的运算，其结果与向量的长度和它们之间的夹角有关。

## 内积的定义

对于两个 *n* 维向量 **u** 和 **v**，其内积定义为对应分量乘积之和。

**公式**：**u** · **v** = *u*₁*v*₁ + *u*₂*v*₂ + ... + *u*ₙ*v*ₙ = Σ (*uᵢ* * *vᵢ*)

在代码中，可以轻松计算内积：

```python
import numpy as np
u = np.array([1, 2, 3])
v = np.array([4, 5, 6])
dot_product = np.dot(u, v)  # 计算内积：1*4 + 2*5 + 3*6 = 32
```

## 内积的几何意义

内积与向量的欧几里得长度（范数）和夹角 *θ* 密切相关：**u** · **v** = ||**u**|| ||**v**|| cos(*θ*)。因此，内积为零意味着两个向量正交（垂直）。

# 🧮 课程 1.6：复杂度计算

在学习和应用线性代数算法时，理解其计算成本至关重要。本节简要介绍如何估算向量运算的计算复杂度。

## 概述

计算复杂度通常用大 O 符号表示，它描述了算法执行时间或所需空间如何随输入规模（如向量维度 *n*）增长。

## 基本向量运算的复杂度

以下是之前学过的运算的复杂度分析：

1.  **标量乘法**：需要将 *n* 个分量各乘以一次标量，因此复杂度为 **O(n)**。
2.  **向量加法**：需要将 *n* 对分量各相加一次，因此复杂度也为 **O(n)**。
3.  **内积计算**：需要执行 *n* 次乘法和 *n-1* 次加法，总体复杂度仍是 **O(n)**。

理解这些基础复杂度有助于我们后续分析更复杂的矩阵运算的效率。
