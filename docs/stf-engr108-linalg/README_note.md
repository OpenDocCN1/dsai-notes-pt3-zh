# 斯坦福 ENGR108 矩阵论与应用线性代数笔记 📘

## 概述
在本节课中，我们将要学习矩阵论与应用线性代数的核心概念。这些概念是理解现代工程、数据科学和机器学习中许多算法的基础。我们将从向量和矩阵的基本定义开始，逐步深入到线性变换、特征值等关键主题。

---

## 1. 向量与矩阵基础 🔢

上一节我们介绍了课程概述，本节中我们来看看向量与矩阵的基本定义和运算。

一个**向量**是数字的有序列表，可以表示为列或行。例如，一个三维列向量可以写作：
`v = [v1, v2, v3]^T`

一个**矩阵**是一个由数字排列成的矩形阵列，具有行和列。一个 `m x n` 矩阵 `A` 有 `m` 行和 `n` 列，其元素记为 `a_ij`。

以下是向量与矩阵的基本运算：

*   **向量加法**：对应元素相加。
*   **标量乘法**：向量或矩阵的每个元素乘以一个标量。
*   **矩阵乘法**：若 `A` 是 `m x n` 矩阵，`B` 是 `n x p` 矩阵，则乘积 `C = AB` 是一个 `m x p` 矩阵，其中元素 `c_ij = sum_{k=1}^{n} a_ik * b_kj`。

---

## 2. 线性方程组与高斯消元法 ⚙️

理解了矩阵的基本结构后，我们来看看如何利用它们解决实际问题。线性方程组可以简洁地表示为矩阵方程 `Ax = b`。

**高斯消元法**是通过行变换将增广矩阵 `[A | b]` 化为行阶梯形，从而求解方程组的方法。

以下是高斯消元法的关键步骤：

*   选取主元。
*   利用主元消去下方所有行中的对应元素。
*   重复上述过程，直至矩阵变为行阶梯形。
*   通过回代求解未知数。

---

## 3. 向量空间与子空间 🧭

上一节我们介绍了求解线性方程组的具体算法，本节中我们从更抽象的几何视角来理解解的结构。**向量空间**是由向量构成的集合，满足对加法和标量乘法封闭等八条公理。

**子空间**是向量空间的一个子集，并且本身也构成一个向量空间。

两个核心概念是：
*   **列空间**：矩阵 `A` 的所有列向量的线性组合构成的子空间，记为 `C(A)`。它对应方程 `Ax=b` 中所有可能的 `b`。
*   **零空间**：所有满足方程 `Ax=0` 的解向量 `x` 构成的子空间，记为 `N(A)`。

---

## 4. 线性变换与矩阵表示 🔄

向量空间之间的映射有一种特别重要的类型。**线性变换** `T` 是满足 `T(u+v) = T(u) + T(v)` 和 `T(cv) = cT(v)` 的映射。

每个线性变换（在选定基后）都可以用一个矩阵来表示。变换 `T` 对输入向量 `x` 的作用，等同于用对应的矩阵 `A` 乘以 `x`，即 `T(x) = Ax`。

---

## 5. 特征值与特征向量 🔑

上一节我们看到了矩阵如何表示变换，本节中我们关注变换中那些方向不变的向量。对于一个方阵 `A`，如果存在标量 `λ` 和非零向量 `v`，使得 `Av = λv` 成立，则称 `λ` 为**特征值**，`v` 为对应的**特征向量**。

特征值和特征向量由特征方程求得：
`det(A - λI) = 0`
其中 `I` 是单位矩阵，`det` 表示行列式。

---

## 6. 奇异值分解（SVD）🎯

对于任意 `m x n` 的实数矩阵 `A`，都存在一个**奇异值分解**。SVD 将矩阵分解为三个特殊矩阵的乘积：
`A = UΣV^T`
其中 `U` 和 `V` 是正交矩阵，`Σ` 是对角线上元素（奇异值）为非负实数的对角矩阵。

SVD 在数据压缩、降维和推荐系统等领域有广泛应用。

本节课中我们一起学习了矩阵论与应用线性代数的基础知识。我们从向量和矩阵的定义出发，探索了求解线性方程组的高斯消元法，并深入理解了向量空间、子空间、线性变换等抽象概念。最后，我们介绍了揭示矩阵内部结构的两大工具：特征值分解与奇异值分解。掌握这些概念是进一步学习高级工程与科学课程的基石。
