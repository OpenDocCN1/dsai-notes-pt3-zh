#  046：日常沟通的核心概念与目的

在本节课中，我们将学习数据分析过程中至关重要的日常沟通。我们将探讨其基本目的、不同层次以及确保沟通有效的核心要素。

数据分析是一个高度依赖语言交流的过程。良好的沟通是优秀数据分析的基础，它需要频繁的来回讨论以推动项目前进。在这种背景下，正式和非正式的沟通都极为重要。你需要协调团队成员之间或与自身的沟通，以确保分析过程持续向前推进。因此，本节将重点讨论常规沟通的类型及其在数据分析项目推进过程中的目的。

常规沟通是执行任何优秀数据分析的重要工具。重要的是要认识到，沟通既是数据分析的工具，也是其产物。最终，当你完成一个数据分析项目时，你需要将你的发现和结果传达给受众，这就是作为“产品”的沟通。但在整个分析过程中，你同样需要沟通和对话，以便评估和挑战发现，从而确保你能获得最佳结果。任何优秀的数据分析师都会在整个数据分析过程中多次进行这种常规的非正式沟通，同时他们也会时刻思考如何将最终结果有效地传达给更广泛的受众。

## 日常沟通的基本目的

日常沟通的基本目的是**收集信息**。你通过传达你的结果并接收受众的反馈来收集信息。这些信息将有助于指导你数据分析的后续步骤。

沟通所采取的形式取决于目标或需要收集的信息类型。以下是几种不同层次的沟通目的：

*   **获取具体事实**：你可能需要回答一个非常聚焦的技术性问题，通常只是为了澄清数据或模型的细节。你的最终目标只是收集一个单一的事实。
*   **获取对意外结果的反馈**：在分析数据集时，你可能会遇到令人困惑或意想不到的结果，此时你需要就此获得一些反馈。
*   **获取对整体过程的初步印象**：你可能没有任何具体问题，但希望收集关于整体过程的信息，并获得对你所做工作的初步印象和反馈，以便进一步优化你的数据分析。

因此，对特定沟通的目的进行分类，并为该沟通提供合适的环境和受众，这一点非常重要。

## 沟通目的示例

以下是针对上述不同沟通目的的快速示例：

*   **澄清变量编码**：在较窄的层面上，你可能需要澄清一个变量的编码，因为元数据可能不清晰。例如，如果一个变量被标记为0或1，你可能不知道0代表什么，1又代表什么。这时，你可以与特定人员沟通，沟通会非常简短直接，答案本质上就是一个单一事实。
*   **讨论探索性数据分析中的意外发现**：在下一个层面，你可能正在进行探索性数据分析。当你查看数据时，发现了一些完全出乎意料的情况。作为EDA过程的一部分，你总是会对数据应有的样子设定预期。当你查看数据、制作图表或表格时，如果发现与预期不符且无法解释，你可能需要就此与个人或小组沟通以获得反馈或答案。这可能采取非正式会议的形式，向少数人展示一些初步的表格或图形，你可能需要通过可视化来展示数据。
*   **在重要节点获取广泛反馈**：在最高层面，你可能已经达到了一个重要的里程碑，或者最终开发出了一个主要模型，并希望就你目前的工作获得一些反馈。这背后的理念是，你总是希望检查自己是否遗漏了什么，并不断挑战自己的结果。这可能需要一个稍大的受众群体，例如团队会议或小组会议，你在会上展示结果并获取关于当前工作的反馈。

## 有效日常沟通的核心要素

无论进行何种类型的日常沟通，都有几个需要考虑的核心概念。

*   **受众**：在你能控制沟通对象的范围内，你需要确保面对的是正确的人或人群，以便最高效地获得问题的答案。了解你的受众并确保房间里是合适的人以获得正确的反馈，这很重要。
*   **内容**：做好准备很重要，这样你才能聚焦并简洁地表达你想说的内容。同时，提供足够的信息也很重要，以便受众能够理解你的出发点和目标。特别是当你的受众来自不同学科背景时，你需要在最开始就确保每个人都在同一认知层面上。
*   **风格**：就风格而言，通常应避免使用大量行话。因为一旦受众超过几个人，不同的人很可能拥有不同的专业知识和技能。你不应使用只有一小部分人才能理解的非常技术性的术语。应尝试使用能让更广泛人群理解的语言，并设计你的图表和表格，使得背景各异的人只需稍加解释就能理解其中的内容。
*   **态度**：最后是你的沟通态度。保持开放和协作的态度非常重要，这样受众才能充分投入，为你提供反馈并帮助你的分析。重点不应是想着为自己所做的分析辩护，而是努力获取他们的意见，以便你能做出最好的工作。

## 总结

![](img/5b0780d65da6b12e12432e6f0fc0b9e1_1.png)

本节课中，我们一起学习了数据分析中日常沟通的基本框架。我们了解到，日常沟通的核心目的是**收集信息**，以推动分析进程。沟通可以根据目的分为不同层次：从获取**具体事实**，到讨论**意外发现**，再到获取对**整体过程**的初步反馈。为了确保沟通有效，我们需要关注四个核心要素：选择合适的**受众**，准备聚焦且充分的**内容**，采用易于理解的**风格**，并保持开放协作的**态度**。这种看似不经意的常规沟通，实际上是保证团队成员、管理者与成员之间信息流畅，持续获取反馈并提升数据分析质量的关键环节。
