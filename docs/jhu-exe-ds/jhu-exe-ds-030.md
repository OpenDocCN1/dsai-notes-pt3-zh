#  030：数据分析迭代 🔄

![](img/666d22d07dceb91b01388b2e091a3fda_1.png)

在本节课中，我们将要学习数据分析的核心循环过程。数据分析虽然复杂，但其基本框架可以简化为三个关键步骤。我们将通过一个日常生活中的例子，来清晰地理解这个迭代过程是如何运作的。

![](img/666d22d07dceb91b01388b2e091a3fda_3.png)

## 设定预期 📝

![](img/666d22d07dceb91b01388b2e091a3fda_4.png)

数据分析的第一步是设定预期。这要求你在采取任何行动之前，有意识地思考你将要做什么以及可能产生什么后果。

无论是收集数据、拟合模型、提出问题还是绘制图表，你的每一个行动都会产生某种结果。设定预期的目的是，在行动之前就思考这些结果，从而为自己建立一个衡量标准，以便判断现实是否符合你的预期。

## 收集与比较信息 📊

上一节我们介绍了设定预期的重要性，本节中我们来看看如何验证这些预期。一旦设定了预期，下一步就是收集数据或信息，以便将你的预期与现实进行比较。

收集信息是关键，因为它能告诉你你的预期是否正确、是过高还是过低，这取决于你正在处理的具体问题。

以下是收集信息后可能出现的两种情况：
*   **预期匹配数据**：例如，你预期餐费是30美元，账单也确实是30美元。
*   **预期与数据不匹配**：例如，你预期餐费是30美元，但账单却是40美元。

## 对数据做出反应并修正预期 🔄

在收集信息并与预期进行比较之后，数据分析循环的最后一步是思考我们从中学到了什么，以及下次应该如何调整。

你需要思考：我们从数据、预期以及它们的比较中学到了什么？下次我们会采取什么不同的做法？我们的预期是否匹配？为什么匹配或不匹配？

![](img/666d22d07dceb91b01388b2e091a3fda_6.png)

![](img/666d22d07dceb91b01388b2e091a3fda_7.png)

完成第三步并修正了预期之后，你可能会带着这些修正后的预期，回到第一步，收集更多数据，并再次尝试匹配它们。这个迭代过程在分析任何数据集时，通常都会重复多次。

## 一个具体示例：外出就餐 🍽️

为了更具体地说明这三个组成部分如何应用，我们来看一个外出就餐的常见场景。

![](img/666d22d07dceb91b01388b2e091a3fda_9.png)

假设你和朋友要去一家只收现金的餐厅吃饭。你需要问自己的问题是：应该带多少钱？在就餐并拿到账单之前，你需要设定对餐费的预期。

![](img/666d22d07dceb91b01388b2e091a3fda_10.png)

![](img/666d22d07dceb91b01388b2e091a3fda_11.png)

你可以利用各种先验信息来设定预期：
*   你常去这家餐厅，清楚知道价格。
*   你知道这座城市一顿饭的平均价格。
*   你知道本市最贵餐厅的价格，以此作为可能花费的上限。
*   询问去过那里的朋友。
*   上网搜索餐厅，查看菜单价格。

一旦设定了预期，你就能决定带多少钱。收集数据的过程就是去餐厅就餐并拿到账单。此时，你观察到了餐费的真实情况。

当预期与数据不匹配时（例如预期30美元，实际40美元），你需要问自己为什么不匹配。有两种可能性：
1.  你的预期是错误的（你认为餐厅更便宜）。
2.  数据本身有问题（例如账单计算错误，或收取了你未消费的项目）。

![](img/666d22d07dceb91b01388b2e091a3fda_13.png)

![](img/666d22d07dceb91b01388b2e091a3fda_14.png)

这个例子中，很容易判断预期是否与数据匹配。如果你的预期是30美元，而实际是40美元，你立刻就知道预期不对。

但另一种情况是，如果你的预期非常宽泛（例如餐费在0到1000美元之间），那么当实际账单是40美元时，它确实符合你的预期。然而，由于最初的预期过于宽泛和模糊，你从收集数据中学到的东西非常有限。

这引出了一个重要观点：**设定一个清晰、具体的预期或假设至关重要**。一个清晰的预期（如“30美元”）能让你轻易判断是否匹配。而一个模糊的预期（如“0到1000美元”）则无法帮助你深入了解所研究的过程（本例中的餐费）。

## 总结与行为改变 💡

最终，我们通过设定预期和收集数据，旨在引导行为的改变或对所研究机制的理解。我们学到了什么？下次你会怎么做不同的事？

在预期30美元但实际40美元的情况下，下次你可能会多带10美元。如果你的预期是0到1000美元，而实际花费40美元，你很可能不会基于此数据改变任何行为。

![](img/666d22d07dceb91b01388b2e091a3fda_16.png)

**如果在收集数据并与预期比较后，你的想法或行为没有任何改变，这通常表明：**
*   你的实验证据不够有力。
*   你的数据分析未能产生足够的证据。
*   你的研究或数据分析过程可能存在其他问题。

![](img/666d22d07dceb91b01388b2e091a3fda_17.png)

因此，设定正确的预期，并尽可能使其清晰具体，是整个数据分析循环中至关重要的一环。

![](img/666d22d07dceb91b01388b2e091a3fda_19.png)

本节课中我们一起学习了数据分析的迭代循环，它包含三个核心步骤：**设定预期**、**收集与比较信息**、**对数据做出反应并修正预期**。通过一个外出就餐的例子，我们理解了设定清晰预期的重要性，以及这个循环如何帮助我们不断从数据中学习并优化决策。
