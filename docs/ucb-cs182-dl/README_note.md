# UCB CS182 深度学习笔记：第1课 - 神经网络基础 🧠

在本节课中，我们将要学习神经网络的基本概念。我们将从最简单的线性模型开始，逐步引入非线性激活函数，最终构建出一个能够拟合复杂数据的基本神经网络模型。理解这些基础是掌握深度学习的关键。

## 线性模型与感知机

上一节我们介绍了课程概述，本节中我们来看看神经网络最基础的组成部分——线性模型。

一个线性模型试图通过一个线性函数来拟合输入数据与输出标签之间的关系。其核心是一个加权求和的过程。

以下是线性模型的核心公式：

**`y_pred = w * x + b`**

在这个公式中：
*   `x` 代表输入特征。
*   `w` 代表权重，决定了每个输入特征的重要性。
*   `b` 代表偏置，允许模型进行平移调整。
*   `y_pred` 代表模型的预测输出。

然而，纯粹的线性模型能力有限，它无法学习数据中复杂的非线性模式。

## 引入非线性：激活函数

为了赋予模型学习非线性关系的能力，我们需要在线性变换之后引入非线性激活函数。

激活函数对神经元的输出进行非线性变换。没有它，无论堆叠多少层，整个网络仍然等价于一个线性模型。

以下是几种常见的激活函数：

1.  **Sigmoid函数**：将输入压缩到(0, 1)区间。公式为 **`σ(z) = 1 / (1 + e^(-z))`**。常用于输出概率，但存在梯度消失问题。
2.  **Tanh函数**：将输入压缩到(-1, 1)区间。公式为 **`tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z))`**。其输出均值为0，收敛速度常比Sigmoid快。
3.  **ReLU函数**：整流线性单元。公式为 **`ReLU(z) = max(0, z)`**。这是目前最常用的激活函数，因为它能有效缓解梯度消失问题并加速计算。

通过引入激活函数，单个神经元（感知机）就具备了基本的非线性判别能力。

## 从神经元到网络

单个神经元的能力依然有限。我们可以将许多神经元连接起来，形成网络。

一个基本的前馈神经网络由输入层、隐藏层和输出层组成。数据从输入层流入，经过隐藏层的多次非线性变换，最终从输出层得到结果。

以下是构建一个简单两层网络（一个隐藏层）的步骤：

1.  **前向传播**：数据从输入层开始，逐层进行加权求和并施加激活函数，直到输出层。
    *   隐藏层计算：**`h = activation(W1 * x + b1)`**
    *   输出层计算：**`y_pred = W2 * h + b2`**
2.  **计算损失**：使用损失函数（如均方误差MSE或交叉熵）比较预测值`y_pred`和真实标签`y_true`的差异。例如，MSE公式为 **`Loss = (1/n) * Σ(y_true - y_pred)^2`**。
3.  **反向传播**：利用链式法则，将损失从输出层向输入层反向传播，计算损失函数关于每个参数（`W1, b1, W2, b2`）的梯度。
4.  **参数更新**：使用优化算法（如梯度下降）根据梯度更新网络参数。更新规则为：**`w = w - learning_rate * ∂Loss/∂w`**。

通过反复迭代“前向传播 -> 计算损失 -> 反向传播 -> 参数更新”这个过程，网络逐渐调整其内部参数，使得预测结果越来越接近真实数据。

## 总结

本节课中我们一起学习了神经网络的基础知识。

我们从最简单的线性模型出发，指出了其局限性。为了建模复杂模式，我们引入了非线性激活函数（如ReLU），使单个神经元具备了非线性能力。最后，我们将多个神经元分层组织，构成了一个基本的前馈神经网络，并概述了其通过前向传播、损失计算、反向传播和梯度下降进行学习的关键流程。

理解这些概念是进入深度学习世界的坚实第一步。下一课，我们将深入探讨更具体的网络结构和训练技巧。
