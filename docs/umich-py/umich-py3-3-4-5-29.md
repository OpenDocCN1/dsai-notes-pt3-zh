---

## `zip`函数的基本概念

上一节我们介绍了常见的累积操作，本节中我们来看看`zip`函数。`zip`函数接收两个或多个序列作为参数，并将这些序列中相同位置的元素“拉链”式地配对在一起，形成一个由元组构成的迭代器。

![](img/16e92afbda91e4a141687c1f2b77e8fb_0.png)

其核心行为可以用以下公式描述：
**`zip(sequence1, sequence2, ...) -> iterator of tuples`**

例如，它将第一个序列的第一个元素与第二个序列的第一个元素配对，然后是各自的第二个元素，依此类推。

![](img/16e92afbda91e4a141687c1f2b77e8fb_1.png)

---

## `zip`函数的工作原理

为了更好地理解，让我们看看`zip`函数是如何工作的。它不会一次性生成所有配对的列表，而是返回一个迭代器，这在处理大型数据集时非常高效。

以下是`zip`函数的一个基本代码示例：

```python
names = ['Alice', 'Bob', 'Charlie']
scores = [85, 92, 78]

paired_data = zip(names, scores)
print(list(paired_data))
```

运行上述代码，输出将是：
`[('Alice', 85), ('Bob', 92), ('Charlie', 78)]`

可以看到，`zip`函数将`names`列表和`scores`列表中相同索引的元素组合成了元组。

---

## `zip`函数的常见用途

`zip`函数在多种场景下都非常有用。以下是几个典型的应用场景：

1.  **并行迭代多个列表**：当你需要同时遍历两个或多个列表时，使用`zip`可以避免使用索引，使代码更清晰。
2.  **创建字典**：结合`dict()`构造函数，可以快速地将两个列表（一个作为键，一个作为值）组合成字典。
3.  **数据转置**：在处理矩阵或表格数据时，`zip`可以用于行与列之间的转换。

以下是使用`zip`创建字典的示例：

```python
keys = ['name', 'age', 'city']
values = ['Alice', 30, 'New York']

my_dict = dict(zip(keys, values))
print(my_dict)
```

输出为：`{'name': 'Alice', 'age': 30, 'city': 'New York'}`

---

## 注意事项与高级用法

使用`zip`函数时，有几点需要注意：

*   当输入的序列长度不同时，`zip`会以最短的序列为准停止配对，超出部分将被忽略。
*   如果需要以最长的序列为准，可以使用`itertools.zip_longest`函数。
*   `zip`返回的是一个迭代器，这意味着它只能被消费一次。如果需要重复使用结果，应将其转换为列表或元组。
