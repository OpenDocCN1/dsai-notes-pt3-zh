## 后续学习建议 📚

上一节我们总结了学习成果，本节中我们来看看具体的后续行动建议。以下是关于下一步应该做什么的一些具体建议。

### 1. 学习更多入门课程

首先，正如我在课程开始时所说，我的目标之一是希望你学习更多课程。你应该去学习真正的入门课程。

不要认为学完这门课后就必须去上高级课程，这实际上可能是最糟糕的选择。除非你飞速完成了本课程，否则，如果你在学习中遇到了困难，下一门课应该是另一门入门课程。

我在课程开始时提到的一些课程，例如密歇根大学提供的其他Python入门课程，都是不错的选择。目前，你已经能够编写大约25行的Python代码。

你需要达到能够熟练编写1000行代码的水平。这通常是你开始能在专业环境中运用编程技能的起点。下一门“Python初级”课程（本课程是“Python零基础”）将教你如何编写大约100到1000行代码的程序。

这些课程会向你展示我在本课程中忽略的一些Python特性，因为我只专注于教你基础知识，带你到达起点。这是你学习编程的开始，而不是终点。

### 2. 参与社群与线下活动

我也非常推崇与人交流。世界各地都有Python线下聚会。有一个名为“Free Code Camp”的组织举办面对面活动，新的小型编程训练营也在不断涌现。

提升编程技能不仅仅是通过自学获得一系列技能，更重要的是融入社群。这能帮助你找到工作。你可能会想，我掌握了所有技能，待在家里就会有人上门提供工作，但事实并非如此。

程序员的工作部分关乎技能，但也同样关乎与人协作。这就是为什么去参加活动、结识程序员并了解他们如此重要。

如果你找不到编程训练营或聚会，可以去参加Python大会。是的，你是个初学者，但你会爱上它的。Python大会在世界各地举办，Python是一个庞大的社区运动。

还有一个名为“Django Girls”的活动，专门教导初学者如何使用Python构建网页，这非常棒。

### 3. 在工作中应用编程技能

另一个进入编程领域的方式，也是我与许多学生交流后发现的，是结合你现有的工作。假设你有一份工作，例如图书管理员，你可能认为自己不擅长技术。

但突然有一天，你拿到一个文件，里面是图书借阅和归还的数据，而且数据有些混乱。你想通过分析这个文件找出哪些书被借阅得最频繁。这时你可能会想，这听起来很像你写过的某个程序：读取文件、解析数据、创建字典并进行统计。

你可以尝试编写一个类似的程序来处理工作中的这个数据文件。于是，你将原本需要4小时手动阅读文件的任务，转变为花4小时编写程序，然后花10秒钟运行程序。

下周当你再次遇到同样的问题和文件时，你只需要10秒钟就能解决。猜猜发生了什么？你现在成了图书馆的程序员，因为你编写了120行Python代码，可以读取文件，为某人节省了4小时的工作时间。类似的情况会不断发生。

我听说过很多学生就这样逐渐将编程发展为工作中的一项爱好。他们在工作中帮助他人。你可能是一名销售人员，想从电子表格中找出前三名的销售员，但无法直接从表格中看出。于是你用Python读取电子表格，进行计算；或者你想看看过去三个季度谁的表现最好，但表格只显示了一个季度的数据。

作为销售人员，你写了一些Python代码，得到了想要的答案，你成了英雄，或者成了一名更出色的销售员。

这些都是将非技术性工作与技术结合的方式，学生们一直在这样做，这真的非常棒。

### 4. 寻求新的Python相关工作

下一步是去找一份新工作，一份Python相关的工作。如果你以前是出租车司机，然后去申请了一份编程工作，这难道不是很酷吗？我见过很多精彩的自拍，人们说：“一年前的今天，我对编程一无所知。我完成了所有这些学习，现在这是我第一份编程工作，我太兴奋了。”无论我是否参与其中，当人们能够转换职业时，我都为他们感到高兴。

因为编程工作通常薪酬不错，工作环境安全，你可以放松并使用大脑工作，而不是依靠体力，比如成为送货员等（并非说那些工作不好，只是我个人喜欢编程工作）。

但这里存在一个问题：仅凭初级的编程技能，很难直接找到第一份工作。让我解释一下这背后的反直觉原因。

如果一家公司想发布一个招聘初级程序员的职位，要求只懂一点点Python，并表示会教你其他一切，这样的职位其实很多。但如果他们发布这样的职位，可能会收到上千份申请，因为有很多人想要这份工作并且具备这些技能（因为这些技能要求并不高）。

那么，猜猜他们会怎么做？他们不会发布这样的职位。他们会发布一个要求更资深的职位，或者采取其他方式。

你可能正坐在某个线下聚会中，听了几个月。你会听到有人说：“天啊，我们招不到人。市场上根本找不到懂最基础Python的人。我招不到人，我本来可以招五个人的。”这时你坐在那里，可以说：“嗨，我是查克，我懂一点Python。”

他们可能会说：“真的吗？你需要工作吗？周二过来一起吃个午饭吧。”然后到了周五，你可能就得到了一份工作。

在你的城市里，可能有一千个人想要那份工作，但公司因为害怕收到上千份申请而不敢发布招聘信息。而你，因为参加了线下聚会，恰好听到了这个需求。这就是许多初级编程工作的获取方式：你认识了某人，他们就不需要面试上千人。

他们能看到你参加聚会，听到你谈论一点Python，知道你大致在做什么。你已经通过了非正式的面试。

因此，对我来说，获得第一份工作格外困难，这就是为什么我如此执着于建议你去结识他人、参加活动。

去让你感到舒适的地方，比如线下聚会、PyCon大会、FreeCodeCamp、Django Girls活动。

### 5. 持续学习与技能拓展

无论你是否找到了工作，如果你还没有，请继续学习。持续学习，学习更多关于Python的知识，学习一些数据挖掘、自然语言处理、数据库的知识。

学习如何使用Django或其他框架构建网页。学习一门新的编程语言，不要只学Python。你会发现，你现在有了一个开始学习的起点。

随着你的成长，你在当前工作中的价值会越来越高，你也越来越有资格胜任其他工作，因为世界不仅仅需要Python，也不仅仅是字典和计数。

如果你去学习PHP，也许在你的城市里Python工作不多，但PHP工作很多，那么你就为自己找到了一条出路。或者你学习一些网页设计、无障碍访问知识，学习如何为残障人士构建符合法律规定的网站。

你学得越多，你就越优秀，这些知识碎片会开始连接在一起。然后，你会逐渐向更资深的人员、架构师或设计师的方向发展。

所以，不要停止学习。将这门课程作为你的起点，我期待听到你未来的发展。
