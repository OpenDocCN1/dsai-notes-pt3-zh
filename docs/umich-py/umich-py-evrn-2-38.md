# 每个人的 Python 第二部分 38：毕业典礼 🎓

## 概述

在本节课中，我们将一起回顾并完成《Python数据结构》课程的毕业典礼。本节并非技术内容，而是课程结束时的庆祝与寄语，旨在总结学习历程，并鼓励大家继续在编程与学习的道路上探索。

## 毕业致辞

大家好，欢迎来到我的大规模在线公开课程的毕业典礼。我是查尔斯·塞弗伦斯博士，也是你们的讲师。稍后我将为大家颁发证书。

衷心感谢大家坚持学习，直至获得证书。按照毕业典礼的传统，我们邀请了一位毕业演讲嘉宾——我的好友兼同事，来自印第安纳大学的库尔特·博赫。在开始颁发证书前，我们先请演讲嘉宾简短发言。

库尔特，这将是一场“PC”演讲。这是什么意思？一方面，我猜是指“政治正确”。我戴上了我的红色印第安纳眼镜，穿上了蓝色的“加油蓝色”衬衫。

这次演讲部分内容关乎我所说的“个人电脑”之外的“PC”一词，而是指“可能的课程”，即人生中可能选择的路径。这不一定指你们接下来要跟随查尔斯博士学习的课程，而是想引导大家思考人生中四个以“P”或“C”开头的关键词，它们代表着可能的道路。

这门大规模在线公开课程关乎你们的**热情**与兴趣，关乎你们决定要做的事。你们可能进入了一个新领域，它可能在舒适区内，也可能超出了舒适区，但你们都在寻找人生中的“天赋所在”。正如肯·罗宾逊爵士所说，我们都在寻找个人的天赋。

因此，第一点是**热情**。你必须对所探索的课程和兴趣充满热情。但仅凭热情不足以期待人生成功，你还需要**目标**。你需要一个目的，一个努力的方向。正如斯坦福大学的这位教授所谈论的“最高目标”，也许这门课并非你的最高目标，但它无疑是一个目标。我们都在朝着目标前进。所以我们希望拥有目标，拥有热情。

然而，完成一门大规模在线公开课程的唯一途径是**坚持**或毅力。你需要努力推进，在课程中坚持不懈，发掘内在的额外能量。我要祝贺你们都找到了这份坚持。你们拥有了热情，找到了目标，哪怕是课程相关的目标，并且展现了坚持与毅力。这是当今心理学中的首要词汇。

第四点，当然，既然参加了这门课，你们沿途也需要一点**趣味性**。我当初制作我的大规模在线公开课程时，也加入了一些趣味元素。在人生的可能道路中，请记住这些以“P”开头的词。

至于以“C”开头的词，你们选择参与其中，这本身就是**选择**。自主性是你决定参加并完成这门课的个人决策。

另一个“C”开头的词是**承诺**。你不仅做出了选择，更承诺要完成这门课程。当你做出承诺时，所有的同伴都在关注着你，与你交流、分享。

下一个词是**连接**。一门连通主义的大规模在线公开课程，以及任何在线课程，都关乎联系与关系。希望你们不仅仅是完成了这门课，更建立了新的桥梁、新的关系、人生中新的可能路径。这些连接可能在未来的任何地方帮助到你，不仅限于课程内容，也许能帮你找到新工作或发现新的兴趣。

那么，这一切是为了什么？你们中有些人想要证书，你们会想要这个。有些人可能想要百万美元。也许通过学习这门课或所有课程，你不会赚到一百万，但你可能像史蒂夫·乔布斯一样变得具有**创新性**——这是我目前在车里听的书《发现你的天赋》所探讨的。

你们完成了一门课程，可能会获得证书，这是另一个“C”开头的词。因此，这就是四个“P”开头的词：热情、坚持、目标和趣味性；以及四个“C”开头的词：选择、承诺、连接，当然还有**完成**——获得证书并继续人生旅程。

如果你们在进入其他课程时能牢记这八条原则，我想你们可能会在未来取得一些成功。我希望你们如此。我希望你们跟随内心，继续学习查尔斯博士或其他人的课程。

祝贺你们所有人，不仅注册了课程，更完成了尽可能多（也许是全部）的模块，从而不仅能获得这里的证书，更能获得作为开放学习者和非正式（如今已是正式）学习者的“人生证书”。

非常感谢。

太棒了，太棒了。
