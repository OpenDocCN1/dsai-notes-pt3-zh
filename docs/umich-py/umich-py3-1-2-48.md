## 变量命名约定 📝

上一节我们介绍了本节课的目标，本节中我们来看看变量命名的约定。这些约定并非强制规则，但遵循它们能让你的代码更易读、更易维护。

以下是关于 `for` 循环中变量命名的一些常用约定：

*   **序列变量**：使用**复数名词**命名，例如 `friends`、`numbers`、`items`。
*   **迭代器变量**：使用**单数名词**命名，例如 `friend`、`number`、`item`。

例如，一个遵循此约定的循环结构如下：
```python
friends = ['Alice', 'Bob', 'Charlie']
for friend in friends:
    print(f"Hello, {friend}!")
```
这种命名方式能清晰地表明 `friends` 是一个集合，而 `friend` 是正在处理的集合中的单个元素。

## 使用 Print 语句进行调试 🔍

理解了命名约定后，我们来看看如何调试循环。在循环内部放置 `print` 语句是一种简单有效的调试方法，它能让你观察程序在每次迭代时的状态。

以下是在循环中使用 `print` 语句的示例：

*   打印迭代器变量的值，以确认循环正在遍历预期的元素。
*   打印循环内计算的结果，以验证逻辑是否正确。
*   在循环开始和结束时打印标记信息，以确认循环的执行范围。

例如：
```python
numbers = [1, 2, 3, 4, 5]
sum = 0
for number in numbers:
    sum = sum + number
    print(f"After adding {number}, the sum is {sum}.")
print(f"Final sum: {sum}")
```

## 核心概念巩固：可迭代对象与迭代器变量 🔄

在实践了调试技巧之后，让我们回顾并巩固两个核心概念：**可迭代对象** 和 **迭代器变量**。清晰地区分它们有助于你更好地理解 `for` 循环的工作原理。

*   **可迭代对象**：这是一个可以逐一返回其元素的对象，例如列表、字符串、元组或字典。在 `for item in collection:` 中，`collection` 就是可迭代对象。
*   **迭代器变量**：这是在每次循环中，代表可迭代对象中**当前元素**的变量。在 `for item in collection:` 中，`item` 就是迭代器变量。

公式可以表示为：
**`for`** `[迭代器变量]` **`in`** `[可迭代对象]:`
    `# 循环体`

一致地使用这些术语，能帮助你掌握它们概念上的区别。
