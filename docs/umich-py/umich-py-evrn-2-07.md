# 2：《Python数据结构》｜P7：07_01_03_趣味-教科书作者在PyCon的会面 🎬

在本节课中，我们将跟随课程讲师Charles Severance的视角，了解他与著名教科书作者Allen Downey在PyCon大会上的首次线下会面。我们将探讨开源教科书的历史、许可选择以及其深远影响。

---

摄像机正常，一切就绪。它在工作吗？它在工作。这是我的自拍杆摄像机，我的云台自拍杆摄像机。它效果很好。这样我就能录下我与Allen Downey的会面了，这将会很棒。就在我见到Allen的那一刻。这确实非常酷。

各位，那是Allen Downey。他在1999年开启了“Think Java”、“Think Python”这场革命。我现在要去第一次见他了。然后你可以问他那个我早就该问的问题。

那么，Jeff，在我们见到伟大的Allen Downey之前，你在想什么？很兴奋吗？我非常兴奋，但你已经见过Allen了，这是我第一次见。但这总是令人兴奋的。没错。

Allen Downey，我是Charles Severance，我们是合著者。我们从未见过面。我们通过电话交流。这是著名的Jeff，每个人都让他出名了。所以我问Jeff的第一个问题，他甚至不知道答案，那就是：为什么你在1999年选择了GFDL许可？那时有Creative Commons、OCW等一切。实际上，我最初版本用的是GNU自由文档许可证，因为我当时甚至不知道别的。然后麻省理工学院有人联系我说，你应该用这个许可证，所以我就换了。后来Creative Commons出现，许可证选择更多了。实际上，选择非商业条款是一种妥协。这些是细节。我认为非商业条款是一件美好的事。实际上，Creative Commons正在考虑取消它，我对此感到难过，因为我认为这是一个很好的中间地带。电子版可以免费分发，没人会对此感到不安；印刷版则可以赚钱。所以这很酷，我认为这是一个很好的用途。

你有没有尝试过统计《Think Python》衍生书籍的数量？你认为有100、200还是300本？如果追溯回去，有很多英文书籍是基于它修改的，还有翻译版本，我把这些算作独立的作品。但是像Rune Stone、Brad Miller的东西，或者互动版本呢？他的书有互动版本吗？不，不，我只是有Python格式的电子版和印刷版，但那已经是很多年前的事了。我很多年前做过那个，然后和剑桥大学出版社有过争执，还记得那些电话吗？记得。但是，你当初为什么选择免费分享它？在1999年，免费分享书籍并不那么酷，也不常见。我们能暂停一下吗？我想先完成寄书的事情。好的，我们待会再聊这个。
