在本节课中，我们将要学习**条件执行**。条件执行允许我们编写仅在特定条件满足时才运行的代码，这极大地增强了程序的灵活性和智能性。

## 概述

![](img/650c32d5a4eb9f561bc1f8e9943d91b4_0.png)

到目前为止，当我们点击运行按钮执行代码时，所有代码行都会按顺序执行。例如，如果我们编写了20行代码，那么点击运行时所有20行都会运行。循环结构虽然让情况稍显复杂，但本质上仍是顺序执行。

![](img/650c32d5a4eb9f561bc1f8e9943d91b4_1.png)

本节中，我们将学习如何编写仅在特定条件为真时才执行的代码。例如，假设我们需要编写代码，要求用户输入一个正数。我们可以设计一行代码，在用户输入非正数时运行，以提醒他们应输入正数。

上一节我们介绍了**布尔值**，它用于表达某事的真伪。例如，我们可以有一个布尔变量，当用户输入正数时其值为 `True`，否则为 `False`。

本节我们将学习如何利用布尔值来指定代码何时运行。例如，当用户未输入正数时打印提示信息。我们还将学习如何将这种条件执行与之前课程中学到的**累加器模式**结合，使两者功能更加强大。

## 条件执行的基本概念

条件执行的核心是 `if` 语句。`if` 语句允许我们检查一个条件：如果该条件为真（`True`），则执行其下方缩进代码块中的语句；如果为假（`False`），则跳过该代码块。

其基本语法结构如下：

```python
if condition:
    # 当条件为 True 时执行的代码块
```

这里的 `condition` 是一个能求值为布尔值（`True` 或 `False`）的表达式。代码块通过**缩进**（通常是4个空格）来定义。

## 条件执行的应用步骤

以下是使用条件执行的一个典型流程。

首先，我们需要获取用户的输入，这通常使用 `input()` 函数。

```python
user_input = input("请输入一个正数：")
```

接下来，我们需要将输入转换为数值类型（例如整数），以便进行数学比较。

```python
number = int(user_input)
```

然后，我们使用 `if` 语句来检查条件。例如，检查数字是否不大于0（即非正数）。

```python
if number <= 0:
    print("您输入的不是正数，请重新输入。")
```

在这个例子中，`number <= 0` 是条件。如果 `number` 小于或等于0，条件为 `True`，则会执行 `print` 语句。

## 结合累加器模式

我们可以将条件执行融入更复杂的模式中，例如**累加器模式**。累加器模式常用于在循环中求和或收集数据。

假设我们想持续要求用户输入数字，只累加正数，并忽略非正数。

以下是实现此功能的关键步骤。

首先，初始化一个累加器变量。

```python
total = 0
```

然后，使用循环（例如 `while` 循环）来重复请求输入。

在循环内部，获取用户输入并转换为数字。

使用 `if` 语句判断数字是否为正数。

```python
if number > 0:
    total = total + number  # 累加正数
    print(f"当前正数总和为：{total}")
else:
    print("输入无效，已忽略。")
```

如果数字为正（`number > 0` 为 `True`），则将其加到 `total` 上并更新显示。否则，打印忽略提示。

这种结合方式使得程序能够智能地处理不同情况，只对符合条件的数据执行特定操作。
