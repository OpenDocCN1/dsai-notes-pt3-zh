## 循环迭代的核心

上一节我们介绍了 `for` 循环的基本用法，本节中我们来对其进行总结。`for` 循环允许我们为序列中的每个项目执行一段代码。

其核心结构可以用以下代码描述：

```python
for item in sequence:
    # 对每个 item 执行的操作
```
