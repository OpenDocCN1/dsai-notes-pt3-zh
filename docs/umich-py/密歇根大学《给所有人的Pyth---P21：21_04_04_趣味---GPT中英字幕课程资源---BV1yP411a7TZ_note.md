## 从巴黎的楼层说起

大家好，我是Chuck。我现在在巴黎，我身后是巴黎圣母院。今天下午我在酒店办理入住时，前台告诉我：“您在14号房间，在一楼，电梯就在拐角处。” 我的第一个想法是：去一楼为什么需要电梯？

问题在于，这里的楼层编号是从0开始的。这和Python中字符串与列表的索引方式完全一样。

## 理解从零开始的索引

上一节我们提到了巴黎楼层编号带来的困惑，本节中我们来看看Python是如何处理类似问题的。在Python中，序列（如列表和字符串）中元素的位置编号被称为“索引”，而这个索引是从0开始计数的，而不是从1开始。

这就像在巴黎，“一楼”对应的是地面层，其索引是0；而我们认为的“二楼”在这里被称为“一楼”，其索引是1。

以下是Python索引与常规计数方式的对比：

*   **常规计数**：第一个位置 = 1，第二个位置 = 2，第三个位置 = 3。
*   **Python索引**：第一个位置 = 0，第二个位置 = 1，第三个位置 = 2。

## 在代码中实践

让我们用代码来具体说明这个概念。假设我们有一个代表酒店楼层的列表。

```python
# 创建一个酒店楼层列表
hotel_floors = [‘大堂’, ‘一楼’, ‘二楼’, ‘三楼’]

# 访问列表中的元素
print(hotel_floors[0]) # 输出：大堂
print(hotel_floors[1]) # 输出：一楼
```
在上面的代码中，`hotel_floors[0]` 访问的是列表的第一个元素“大堂”，`hotel_floors[1]` 访问的是第二个元素“一楼”。字符串的索引方式与此完全相同。

```python
# 字符串索引示例
room_number = “14”
print(room_number[0]) # 输出：1
print(room_number[1]) # 输出：4
```
对于字符串 `“14”`，索引0的位置是字符 `‘1’`，索引1的位置是字符 `‘4’`。

## 为什么索引从0开始？

你可能会问，为什么Python要设计成这样？这主要是出于数学计算和内存地址计算的效率考虑。在计算机底层，通过“基地址 + 偏移量”来访问数据非常高效，而偏移量为0正好对应第一个元素。虽然对初学者来说需要适应，但一旦习惯，它会变得非常直观和强大。
