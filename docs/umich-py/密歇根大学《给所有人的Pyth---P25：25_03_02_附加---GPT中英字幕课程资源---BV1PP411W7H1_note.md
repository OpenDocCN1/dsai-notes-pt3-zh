# 课程4：《使用数据库进行Python编程》｜ 第25讲：附加访谈 - Niklaus Wirth 🧠

## 概述
在本节附加访谈中，我们将跟随计算机科学先驱Niklaus Wirth的讲述，了解Pascal等编程语言的诞生背景、设计哲学及其对早期计算机教育的深远影响。这段历史有助于我们理解现代编程语言和计算机系统设计思想的根源。

---

## 访谈内容整理

当我回到瑞士后，我收到了苏黎世联邦理工学院（ETH）的邀请，希望引入计算机科学作为一门新学科。

作为一名本质上从事软件工作的人，我考察了当时可用的工具，结果相当令人失望。

当时有Algol语言可用。它的严谨性和良好结构说服了我。

但它有一个糟糕的实现。我觉得使用那个Algol编译器只会降低它被接受的可能性。

另一方面，只有Fortran可用，我认为它不适合教学。更不用说汇编语言了。

因此我决定继续我在斯坦福大学的工作。并且实现……不，不是另一个Algol编译器，而是后来众所周知的Pascal。

我曾是IFIP工作组的成员。最终有两个提案，一个来自阿姆斯特丹的Arthur Wangharten，另一个来自我。

我可以说我落选了。然后我决定无论如何都要实现它，因为我需要它，我需要它用于教学。

这就是大约一年半后，在1969年诞生Pascal，并在1971年我第一次将其用于入门编程课程的原因。

它某种程度上……它有了自己的生命，在商业世界中有了自己的生命。是的，是的。

尽管我必须承认这花了一些时间。我们在许多不同的计算机上实现了Pascal。

我们也帮助了其他想要它的大学，将其移植到他们的计算机上。代码是Pascal-P，即可移植系统。

但真正的突破实际上是在微计算机出现之后。

特别是Apple I，还有Tandy和其他一些机器。它们推出了UCSD Pascal和由Borland公司开发的Turbo Pascal实现。

它们不仅销售编译器，还销售一个集成了文本编辑器和调试器的系统，价格大约50美元。

这在当时产生了巨大差异，那时大型机的编译器仍需花费数千美元。当然，它们随后传播到了人们没有带着……不良先入之见接触计算机的领域。

你知道，他们是从零开始学习编程的。这就是计算机如何进入家庭和学校的。

在微处理器革命的早期，还有什么其他语言适合呢？

是的，嗯，这当然是关键点，是的，当时只有一个竞争对手，那就是BASIC。

但从教学的角度来看，我认为Pascal是正确的选择。即使你将其视为早期微处理器上的系统开发语言，考虑到它拥有真正的接口以及某种层面上建立基于类型的契约的能力，BASIC根本算不上一个竞争对手。

我认为，如果你开始考虑为初学者课程做得好一些，它当然是，特别是在美国，人们不习惯结构化语言，你知道，即使是Fortran也相当扁平。

但Pascal普及得相当好，在小学也是如此。Pascal一直是苹果公司从Apple II到Macintosh的API定义，对吗？没错。

你和UCSD或苹果公司有互动吗？还是说那时它已经是一种公共产品了？是的，我几乎没有互动。

真的，几乎没有。是的，大西洋太宽了，或者说当时太宽了，不利于密切互动。

我们总是免费分发我们的软件，只收取磁带的成本。所以当然，没有人有义务……反馈给我。

当然，在计算机的早期，开源并不是我们认为特别或不同的事情，它只是一种行为方式。是的，是的。

我认为大学总是那样行事，开源，我的意思是，大学有兴趣传播他们的思想，而不是保护它们。

谈谈那些你小心地没有命名为Pascal的后续语言。是的，我没有，从商业角度来看，这是令人遗憾的。

因为如果我把Modula称为Pascal 2，Oberon称为Pascal 3，它们可能会取得更大的成功。

Modula在Pascal之后九年出现。它是一种为系统开发设计的语言，也受到了我在施乐帕洛阿尔托研究中心（Xerox PARC）度过学术休假期间接触的Mesa语言的影响，而Mesa本身基于Pascal。

Modula的主要新特性是模块。以及随之而来的接口规范。在实现上，是模块的独立编译能力。

独立编译能力。加上严格的接口类型检查，这当然是Fortran所缺少的。

因此，将不同的Modula模块链接在一起，就像在单个模块内编程一样安全。这是一个绝对关键的特性。

那么谈谈从Modula到Oberon的转变。那是在我第二次在施乐帕洛阿尔托研究中心学术休假之后开始的，时间是1987-1989年。

我和我的同事，你的好朋友，实际上已经确信，未来，特别是在编程教学方面，在于更简单的语言。

而Modula 2在我们看来已经因为特性和功能而变得臃肿。所以我们想清理Modula 2。这就产生了Oberon。

我们基本上只增加了一个特性，尽管是一个重要的特性，那就是类型扩展。有了类型扩展，再加上Modula中已有的过程变量，你可以实现完整的面向对象方案。

所以，从一开始，Oberon的创新就是：简洁性，加上面向对象。

Oberon也催生了一个操作系统，对吗？是的，记得我在1976-77年第一次在施乐帕洛阿尔托研究中心学术休假时，他们给了我一台Alto计算机，就放在我自己的桌子下面，这当然彻底改变了计算机的使用方式。我家里仍然有一个通过细线连接到大型机的终端，与数百人共享。

所以，拥有一台自己的、带大映射屏幕的计算机，能够进行更灵活的文本编辑、图形处理等等，这对我来说真的是一种启示。

我决定我不想再用这些古老的恐龙编程了，我也必须拥有这样一台机器，但它们不出售，买不到。

我唯一能做的就是决定自己造一台，这就是我如何涉足硬件领域的原因。幸运的是，我受过电气工程师的训练，所以这稍微容易一些。

但与此同时，大约15年的时间里，电子学经历了巨大的变化。我还在尝试真空管，而现在它们不仅是晶体管，还有集成电路芯片。

但这真的非常吸引人，而且只用很少的钱，我想我得到了大约5万法郎作为启动资金，我们建立了一个小车间并制造了原型机。

当然，它们随后被调整以适应Modula语言。Modula语言及其编译器、操作系统与这台被称为Lilith的计算机紧密相连。

整个事情在10年后以Oberon语言、Oberon操作系统和Ceres计算机的组合方式重演了一遍。

我觉得我们应该将我们在软件中使用的简洁性和结构良好的原则也应用到硬件上。现在由于FPGA的存在，这成为可能。

所以我得到了一个带有FPGA的Xilinx开发工具。我实现了一个处理器，我称之为RISC。但它比ARM或MIPS或SPARC简单得多。

再次真正专注于对学生来说必要且可呈现的核心部分。处理器的Verilog代码大约只有三页。

然后……我刚刚完成了针对那个RISC架构的Oberon编译器，包括编译器、链接器和加载器。

所以现在我们开始修订这本书，完全重写关于编译器和链接器/加载器的章节。

但其余部分令人惊讶地保持了原样，只有相对较少的变化。这表明其中的思想相当现代。

你有任何FPGA已经编程好了吗？是的，这个就是。拔掉它。这只是一个价值约100美元的Xilinx开发板，这就是你的微处理器。

我的意思是，这是FPGA，我已经将RISC处理器下载到了里面。所以当你完成下载后，它就变成了微处理器，没错，正是如此。

内存从哪里来？它有内存，这两个芯片是1兆字节。所以按现在的标准，这仍然是一台小型计算机，但我们可以轻松地放入整个操作系统。

我们理解什么是FPGA，然后你实际上是以一种开放的方式从门电路开始构建。这是用于教学的理念。

在新版书中，也会有一章关于这个内容。必须要有。我能够完成。

## 总结
本节课中，我们一起学习了Niklaus Wirth的访谈，回顾了从Pascal到Modula再到Oberon的编程语言发展历程，以及其简洁、结构化的设计哲学如何贯穿始终。我们还了解到Wirth如何将同样的原则应用于硬件设计，使用FPGA构建了名为RISC的简易教学用处理器。这段历史清晰地展示了优秀设计思想的生命力及其对计算机科学教育的持久影响。
