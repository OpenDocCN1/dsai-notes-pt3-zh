## 概述

![](img/f20857aed7dfc76bc19e80f7494be9c6_0.png)

有时，在创建对象后，你会希望改变它。

![](img/f20857aed7dfc76bc19e80f7494be9c6_1.png)

例如，你创建了一个列表，并希望持续向列表末尾添加新项目。或者，你创建了一个海龟（turtle）图形对象，并希望改变它的画笔颜色。

在Python中，改变一个已存在对象的值主要有两种方式。第一种是创建一个对象的修改副本，第二种则是直接修改原始对象本身。我们将直接修改原始对象的行为称为**突变（Mutation）**。这个概念非常有用，但有时也会带来困惑。

因此，今天的课程将详细讲解现有对象的突变是如何工作的，并帮助你识别由此可能引发的潜在混淆。

## 理解可变与不可变

上一节我们概述了本节课的目标，本节中我们来看看可变与不可变的核心区别。

在Python中，对象根据创建后其内部状态能否被改变，分为两大类：
*   **可变对象（Mutable Objects）**：创建后，其内容可以被修改。例如列表（`list`）、字典（`dict`）、集合（`set`）。
*   **不可变对象（Immutable Objects）**：创建后，其内容**无法**被修改。例如整数（`int`）、浮点数（`float`）、字符串（`str`）、元组（`tuple`）。

判断一个对象类型的可变性，是理解程序行为的第一步。

---

## 突变 vs. 创建副本

理解了基本分类后，我们来看看改变对象的两种具体方式。

以下是两种改变对象方式的对比：

1.  **突变（Mutation）**：直接修改原始对象。操作后，对象的**身份（id）**保持不变，但内容变了。
    ```python
    my_list = [1, 2, 3]
    my_list.append(4)  # 突变操作：直接修改my_list
    print(my_list)  # 输出：[1, 2, 3, 4]
    ```

2.  **创建修改副本**：基于原始对象创建一个全新的对象，新对象包含修改。原始对象保持不变。
    ```python
    my_string = "hello"
    new_string = my_string.upper()  # 非突变操作：创建并返回一个新字符串
    print(my_string)    # 输出："hello" (原对象未变)
    print(new_string)   # 输出："HELLO" (新对象)
    ```

通常，可变对象的方法（如 `list.append()`, `list.sort()`）倾向于执行突变，而不可变对象的方法（如 `str.upper()`, `str.replace()`）则返回新对象。

## 别名与副作用

现在，我们来看一个由可变性引发的常见陷阱：别名（Aliasing）。

当两个或多个变量引用内存中的**同一个对象**时，它们互为该对象的别名。对于不可变对象，这通常没有问题。但对于可变对象，通过一个别名修改对象，会直接影响所有其他别名。

```python
# 创建列表a
a = [1, 2, 3]
# 让b成为a的别名（指向同一个列表对象）
b = a

# 通过别名b突变列表
b.append(4)

print(a)  # 输出：[1, 2, 3, 4]
print(b)  # 输出：[1, 2, 3, 4]
# a 和 b 的内容同时被改变，因为它们指向同一个对象
```

理解别名关系，是预测程序行为、避免意外副作用的关键。
