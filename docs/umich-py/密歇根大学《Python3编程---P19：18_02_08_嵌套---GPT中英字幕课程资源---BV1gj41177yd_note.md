## 理解数据结构

上一节我们介绍了嵌套迭代的基本操作，本节中我们来看看处理复杂数据的第一步：理解其结构。

处理嵌套数据最大的挑战之一就是理解你拥有的数据结构。理想情况下，数据应具有一致的结构。例如，如果有一个字典列表，那么当所有字典都拥有相同的键时，处理起来会容易得多。

## 编写提取代码

一旦理解了数据结构，你就可以构思如何编写代码。最终，你可能不需要太多代码，但如果你试图一次性写出所有代码，过程会非常令人沮丧，并且调试将耗费大量时间。

因此，请遵循“理解、提取、重复”的过程，并在每个阶段测试你的部分代码，这样你就能更快地解决编码问题。

## 一个实用的启发式方法

以下是一个你可能想记住的宝贵启发式方法：

如果目标数据嵌套了三层（例如，一个列表嵌套在另一个列表中，再嵌套在另一个列表中），那么你将需要同样数量的三次提取操作。这些操作将是方括号索引和 `for` 循环的某种组合。

**公式：**
`嵌套层数 = 所需提取操作次数`

**代码示例：**
```python
# 假设 data 是一个三层嵌套列表：list[list[list]]
for outer_item in data:          # 第一层提取：循环
    for middle_item in outer_item: # 第二层提取：循环
        for inner_item in middle_item: # 第三层提取：循环
            print(inner_item)          # 操作目标数据
```
