在本节课中，我们将通过一个关于墨西哥卷饼的趣味例子，来学习Python中数据结构的基本应用。我们将看到如何用简单的代码来组织和表示现实世界中的信息。

上一节我们介绍了数据结构的基本概念，本节中我们来看看一个具体的、有趣的例子：如何用Python描述两种不同的墨西哥卷饼。

以下是两种常见卷饼的简单描述：
*   一种卷饼**有奶酪**。
*   另一种卷饼**没有奶酪**。

在代码中，我们可以用不同的变量或数据结构来清晰地区分它们。例如，我们可以用一个字典（`dict`）来表示每种卷饼的属性。

```python
# 定义两种卷饼
burrito_with_cheese = {
    "name": "Ga",
    "has_cheese": True,
    "color": "green"
}

burrito_without_cheese = {
    "name": "Ta",
    "has_cheese": False,
    "color": "brown"
}
```

通过上面的代码，我们创建了两个字典对象。每个字典都包含了卷饼的名称（`name`）、是否含奶酪（`has_cheese`）和颜色（`color`）等信息。这种结构让我们能够轻松地访问和管理每种卷饼的属性。

例如，我们可以通过键名来获取信息：
```python
print(burrito_with_cheese["name"])  # 输出: Ga
print(burrito_without_cheese["has_cheese"])  # 输出: False
```

这个例子展示了如何将现实物品（卷饼）的特征转化为程序中的数据。选择“有奶酪”或“没有奶酪”，就像在程序中为`has_cheese`属性选择`True`或`False`一样明确。

---

本节课中我们一起学习了如何利用Python的字典数据结构来为现实世界的对象（如墨西哥卷饼）建模。我们看到了通过定义清晰的属性（如名称、是否含奶酪），可以让数据变得有条理且易于处理。掌握这种将事物特征转化为数据的能力，是运用Python解决实际问题的重要一步。
