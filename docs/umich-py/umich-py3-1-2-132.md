## 局部变量的生命周期 🔄

![](img/a36672091332e1dc33532aac169c7179_0.png)

上一节我们介绍了函数的基本概念，本节中我们来看看函数内部变量的具体行为。

每次函数执行时，都会获得一组全新的局部变量。这些变量在函数执行结束时消失。

![](img/a36672091332e1dc33532aac169c7179_1.png)

这意味着函数内部定义的变量在函数外部是不可访问的。例如：

```python
def my_function():
    local_var = 10
    print(local_var)  # 输出: 10

my_function()
print(local_var)  # 这会引发 NameError 错误，因为 local_var 在函数外不存在
```

## 函数的嵌套调用 🔗

函数不仅可以独立运行，还可以调用其他函数。这是构建复杂程序的基础。

以下是函数调用其他函数的一个例子：

```python
def greet(name):
    return f"Hello, {name}!"

def welcome(user):
    message = greet(user)  # 调用 greet 函数
    print(message)

welcome("Alice")  # 输出: Hello, Alice!
```

## 函数的副作用 ⚠️

现在，我们来探讨一个更高级的概念：副作用。当函数修改了其自身作用域之外的某些数据时，就产生了副作用。

函数可以对可变对象（如列表和字典）产生副作用，即修改它们的内容。

以下是识别函数副作用的关键点：

*   **修改传入的可变参数**：如果函数内部修改了作为参数传入的列表或字典，这就是一个副作用。
*   **修改全局变量**：在函数内部修改全局作用域中定义的变量，也是一个副作用。

以下是一个具有副作用的函数示例：

```python
def add_item(shopping_list, item):
    shopping_list.append(item)  # 这会修改传入的列表，产生副作用

my_list = ["apple", "banana"]
add_item(my_list, "orange")
print(my_list)  # 输出: ['apple', 'banana', 'orange']，原始列表被修改了
```

## 如何避免全局变量 🛡️

为了编写更清晰、更少错误的代码，我们应尽量避免在函数内部使用和修改全局变量。

最佳实践是通过创建形式参数，将所有函数需要的数据明确地传递进去。

以下是具体做法：

*   将所有函数需要的外部值定义为函数的参数。
*   在函数体内只使用这些参数和局部变量。
*   如果函数需要“返回”多个结果，考虑使用返回值（如返回一个元组）而不是修改外部变量。

```python
# 好的做法：通过参数传递数据
def calculate_total(price, quantity):
    total = price * quantity  # 使用参数，不依赖外部变量
    return total

# 应避免的做法：依赖全局变量
global_price = 10
def calculate_total_bad(quantity):
    total = global_price * quantity  # 依赖全局变量，使函数难以理解和复用
    return total
```
