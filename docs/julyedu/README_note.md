# 七月在线公开课笔记：Python基础入门（第1课）🎯

在本节课中，我们将要学习Python编程语言的基础入门知识，包括其核心概念、基本语法以及如何运行第一个程序。

## 什么是Python？🐍

Python是一种高级、解释型的编程语言。它以简洁清晰的语法和强大的功能而闻名。Python的设计哲学强调代码的可读性。

上一节我们介绍了Python的总体概念，本节中我们来看看它的主要特点。

以下是Python的几个关键特性：

*   **易于学习**：语法接近英语，结构简单。
*   **解释型语言**：代码无需编译即可运行。
*   **跨平台**：可在Windows、macOS、Linux等系统上运行。
*   **丰富的库**：拥有庞大的标准库和第三方库。

## 安装Python与环境搭建⚙️

要开始编写Python代码，首先需要在计算机上安装Python解释器。

你可以从Python官方网站下载适合你操作系统的安装包。安装过程通常很简单，只需遵循安装向导的指示即可。

安装完成后，可以通过命令行工具验证是否成功。打开终端或命令提示符，输入以下命令：

```bash
python --version
```

如果安装成功，命令行将显示已安装的Python版本号。

## 第一个Python程序：Hello World👋

学习任何编程语言的传统都是从编写一个输出“Hello, World!”的程序开始。

我们将使用Python的`print()`函数来实现这个功能。`print()`函数用于向屏幕输出信息。

以下是具体步骤：

1.  打开文本编辑器，创建一个新文件。
2.  在文件中输入代码：`print("Hello, World!")`
3.  将文件保存为`hello.py`。注意，Python文件通常以`.py`作为扩展名。

要运行这个程序，你需要打开命令行，导航到文件所在的目录，然后输入：

```bash
python hello.py
```

执行后，你将在屏幕上看到输出的文字：`Hello, World!`。

## 理解变量与数据类型🧩

变量是编程中用于存储数据的基本单元。你可以把变量想象成一个贴有标签的盒子，里面可以存放各种信息。

在Python中，使用等号`=`为变量赋值。例如：

```python
name = "七月"
age = 25
```

这里，`name`是一个变量，它存储了字符串`"七月"`；`age`也是一个变量，它存储了整数`25`。

Python有多种内置的数据类型，用于表示不同种类的数据。以下是几种常见的数据类型：

*   **整数**：表示没有小数部分的数字，如 `10`, `-5`, `0`。
*   **浮点数**：表示有小数部分的数字，如 `3.14`, `2.0`, `-0.5`。
*   **字符串**：表示文本信息，由单引号或双引号包围，如 `"Hello"`, `'Python'`。
*   **布尔值**：表示逻辑真或假，只有两个值：`True` 和 `False`。

## 基本运算符🔢

运算符用于对变量和值执行操作。Python支持多种运算符。

**算术运算符**用于进行基本的数学运算：

*   `+` 加法
*   `-` 减法
*   `*` 乘法
*   `/` 除法
*   `%` 取模（返回除法的余数）
*   `**` 幂运算
*   `//` 取整除（返回商的整数部分）

例如：
```python
result = 10 + 3 * 2  # result 的值为 16
```

**比较运算符**用于比较两个值，返回布尔值（`True`或`False`）：

*   `==` 等于
*   `!=` 不等于
*   `>` 大于
*   `<` 小于
*   `>=` 大于等于
*   `<=` 小于等于

例如：
```python
is_equal = (5 == 5)  # is_equal 的值为 True
```
