## 探索苹果的 Create ML 🍎

上一节我们介绍了研究笔记本的结构，本节中我们来看看苹果公司提供的低代码机器学习工具。

苹果的 Create ML 允许用户以极低的代码量创建机器学习模型。其核心工作流程与我们熟知的机器学习步骤一致：**数据输入 -> 模型训练 -> 模型评估**。

以图像分类任务为例，其操作非常简单：

![](img/870d5d5b9f0129ecad6036d31267de4a_12.png)

1.  **数据准备**：你只需要为每个类别（如“大象”、“长颈鹿”）准备约10张或更多的图片。
2.  **数据组织**：将图片按类别放入不同的文件夹中。
3.  **模型创建**：在 Create ML 的图形界面中，创建一个“图像分类”新项目，并将整个文件夹拖入界面。
4.  **数据增强**：为了应对数据不足的问题，你可以选择启用数据增强功能，如添加噪声、模糊、裁剪等，以自动生成更多训练样本。
5.  **训练与评估**：添加测试数据后开始训练。训练完成后，系统会提供评估结果。

**核心概念**：整个流程无需编写任何代码。你只需组织好数据目录，然后通过图形界面进行操作。

这种工具非常适合商业场景。例如，你可以训练一个分类器来识别竞争对手的产品图片。当你巡店时，用手机拍摄货架照片，模型就能自动识别出是否有竞品出现，从而快速启动市场调研。

了解了苹果的工具后，我们转向云服务巨头。谷歌云平台提供了强大的 AutoML 服务，尤其适合处理图像和表格数据。

GCP 的 AutoML 主要有两个对商业智能人员很重要的方向：AutoML Vision（图像）和 AutoML Tables（表格）。

### AutoML Vision：图像识别

![](img/870d5d5b9f0129ecad6036d31267de4a_22.png)

![](img/870d5d5b9f0129ecad6036d31267de4a_24.png)

其使用流程高度可视化：

1.  **创建数据集**：在 GCP 控制台创建新数据集，选择预测类型（单标签、多标签或物体检测）。
2.  **上传数据**：你可以直接上传图片，或提供一个指向云存储中图片的 CSV 文件。无需编码，只需将文件放入云存储。
3.  **浏览与准备**：数据集会以可视化形式展示，你可以浏览、筛选数据，为生成报告做准备。
4.  **训练模型**：点击“训练模型”按钮，系统开始训练。
5.  **分析结果**：训练完成后，你会获得易于理解的评估指标，如准确率和混淆矩阵。混淆矩阵用蓝色表示正确分类，其他颜色表示误分类，你可以直观地查看真阳性、假阴性和假阳性样本。
6.  **部署模型**：你可以以低代码方式将模型导出，甚至部署到移动设备上。

![](img/870d5d5b9f0129ecad6036d31267de4a_26.png)

### AutoML Tables：表格数据分析

![](img/870d5d5b9f0129ecad6036d31267de4a_28.png)

![](img/870d5d5b9f0129ecad6036d31267de4a_30.png)

![](img/870d5d5b9f0129ecad6036d31267de4a_32.png)

对于商业场景中最常见的表格数据，AutoML Tables 提供了强大的自动化分析能力。

1.  **上传数据**：从 BigQuery、云存储 CSV 文件或本地上传表格数据。
2.  **自动分析**：系统会自动推断数据类型（数值型、分类型、文本型），并展示描述性统计信息（如唯一值数量）。
3.  **特征工程**：它会自动计算特征与预测目标之间的相关性，这有助于你理解哪些因素更重要。
4.  **设置预测目标**：你只需指定想要预测的列（例如，预测用户收入是否大于5万美元）。
5.  **获取结果**：系统会给出模型评估指标（如准确率、AUC值），并展示特征重要性图表和混淆矩阵。

**核心概念**：`特征重要性` 图表可以直观地告诉你哪些数据列对预测结果影响最大。你可以轻松地将这些图表下载并插入到研究报告中。

## 探索亚马逊云科技（AWS）的 AI 服务 🌐

最后，我们来看看亚马逊云科技提供的丰富AI服务。AWS 允许你通过其服务快速进行自然语言处理和计算机视觉分析。

### Amazon Comprehend：自然语言处理

AWS Comprehend 可用于文本分析，甚至有针对医疗领域的 Comprehend Medical。

![](img/870d5d5b9f0129ecad6036d31267de4a_45.png)

![](img/870d5d5b9f0129ecad6036d31267de4a_47.png)

1.  **医疗记录分析**：如果你在医疗公司，可以直接将病人的医疗记录文本粘贴到 Comprehend Medical 中，系统会自动提取关键实体、药物、症状等信息，并生成可视化报告，供医生或管理层分析。
2.  **竞品舆情分析**：这是一个典型的商业应用。例如，研究竞争对手耐克（Nike）。
    *   **数据收集**：从维基百科或新闻网站复制关于耐克的文本。
    *   **情感分析**：将文本粘贴到 Comprehend 中，选择“分析”。你可以查看提取的实体、关键短语，最重要的是**情感分析**结果。通过快速分析多篇文章，你可以得出初步结论：“关于耐克的大部分报道情感倾向为中性”。

### 其他 AWS 服务：机器学习与 QuickSight

1.  **Amazon Machine Learning**：用于表格数据预测。流程同样简单：上传数据到 S3，创建数据源，指定预测目标（如“客户是否会存款”），然后系统自动训练模型并给出评估指标和性能权衡分析。
2.  **Amazon QuickSight**：一款商业智能工具。你可以直接上传数据集（如之前从 AutoML 导出的特征重要性数据），QuickSight 会自动生成可视化图表和仪表板。你可以调整颜色、图表类型，并一键分享或发布仪表板，或将图表导出为 PDF 嵌入报告。

**核心概念**：这些低代码工具可以组合使用。例如，用 AutoML 分析数据并导出结果，再用 QuickSight 将这些结果制作成更美观的图表和仪表板，全程几乎无需编码。
