# 斯坦福 CS231 机器视觉进阶课程笔记：第1课 - 图像分类与K最近邻算法 🖼️

在本节课中，我们将要学习计算机视觉中的一个基础且核心的问题：**图像分类**。我们将了解图像分类任务的定义、面临的挑战，并介绍一种简单而直观的算法——**K最近邻**，作为我们进入这个领域的起点。

## 什么是图像分类？

图像分类是计算机视觉中的一项核心任务。其目标是：给定一张输入图像，从一组固定的类别中，为其分配一个标签。

这个任务对人类来说轻而易举，但对计算机而言却极具挑战。因为计算机“看到”的图像只是一个巨大的数字矩阵（例如，一个800x600x3的像素值数组）。图像会因**视角变化、光照条件、物体形变、遮挡以及背景干扰**等因素而发生巨大变化。一个优秀的图像分类模型必须对这些变化具有**鲁棒性**。

## 图像分类的挑战

上一节我们介绍了图像分类的基本目标，本节中我们来看看实现这一目标所面临的具体困难。图像分类的难点主要源于“语义鸿沟”和图像本身的多变性。

以下是图像分类任务中常见的几类挑战：

*   **视角变化**：同一个物体可以从无数个角度进行拍摄。
*   **尺度变化**：物体在图像中显示的大小常常不同。
*   **形变**：许多物体的形状并非固定不变。
*   **遮挡**：目标物体可能只露出一部分。
*   **光照条件**：像素的亮度对物体外观影响极大。
*   **背景干扰**：物体可能融入背景，难以区分。
*   **类内差异**：同一类别的物体（如椅子）可能有多种不同的外形。

一个有效的分类算法必须克服所有这些变化，同时保持对**类间差异**的敏感性。

## 数据驱动方法

既然直接编写规则来识别物体如此困难，我们该如何构建图像分类模型呢？我们采用一种**数据驱动**的方法。

我们不尝试在代码中直接定义每只猫的样子，而是：
1.  收集一个包含图像和对应标签的大型数据集。
2.  使用机器学习算法训练一个分类器。
3.  用新的图像来评估分类器的性能。

这种方法的核心思想是：**从数据中学习**。我们将整个流程抽象为两个关键函数：
*   **训练函数**：接收训练数据和标签作为输入，输出一个模型。
    `model = train(images, labels)`
*   **预测函数**：接收模型和新图像作为输入，输出预测的标签。
    `label = predict(model, test_image)`

## K最近邻分类器

了解了数据驱动方法后，我们来看第一个具体的分类算法：**K最近邻**。它虽然不常用于图像分类，但其思想简单直观，非常适合入门。

K最近邻算法没有任何显式的“训练”过程，它只是简单地**记住**所有训练数据。在预测时，它将新的测试图像与记忆中每一张训练图像进行比较，找出最“相似”的K张图，然后让这K个“邻居”进行投票，得票最多的类别即为预测结果。

以下是决定算法行为的两个关键选择：

1.  **距离度量**：如何计算两张图片之间的“相似度”或“距离”？常见的选择有：
    *   **L1距离（曼哈顿距离）**：`d1(I1, I2) = sum(|I1 - I2|)`
    *   **L2距离（欧氏距离）**：`d2(I1, I2) = sqrt(sum((I1 - I2)^2))`

2.  **K值选择**：K是一个超参数。不同的K值会影响分类结果。
    *   **K值较小**（如K=1）：模型对噪声点敏感，决策边界复杂，容易过拟合。
    *   **K值较大**：决策边界平滑，但可能导致分类模糊，忽略局部细节。

## KNN的优缺点与总结

我们已经介绍了K最近邻算法的工作原理。现在，我们来总结一下它的特点，并理解为什么它不适用于实际的图像分类任务。

**优点**：
*   思想简单，易于理解和实现。

**缺点**：
*   **测试时计算代价高昂**：需要与所有训练数据比较，数据量大时非常慢。
*   **距离函数在像素空间难以反映语义相似性**。例如，对图像进行微小平移后，像素级距离可能很大，但语义未变。
*   维度灾难：在高维像素空间中，数据点分布稀疏，难以找到有意义的最近邻。

**总结**：
本节课中我们一起学习了图像分类的基本概念、挑战以及第一个分类算法——K最近邻。我们了解到图像分类是一个困难但基础的任务，并引入了数据驱动的解决方案。KNN算法虽然直观，但其在像素空间比较的局限性以及低效的测试性能，使其不适合直接用于图像分类。这为我们接下来学习更强大、更高效的**线性分类器**和**神经网络**奠定了基础。
