## P2：L2- 图像分类 🏷️

上一节我们介绍了计算机视觉的广阔领域，本节中我们来看看最基础的任务——图像分类。图像分类的目标是给一张输入图像分配一个标签（或类别）。

以下是图像分类的主要挑战：
*   **视角变化**：同一个物体可以从不同角度观察。
*   **光照变化**：光线对物体外观影响巨大。
*   **形变**：许多物体的形状并非固定。
*   **遮挡**：目标物体可能被部分遮挡。
*   **背景干扰**：物体可能融入背景中。
*   **类内差异**：同一类物体（如椅子）外观差异很大。

一种简单的分类方法是**最近邻分类器**，它通过比较测试图像与训练集中所有图像的差异来进行分类，常用 **L1 距离（曼哈顿距离）** 或 **L2 距离（欧氏距离）** 来衡量差异。

**L1 距离公式**：`d1(I1, I2) = sum(|I1[p] - I2[p]|)`
**L2 距离公式**：`d2(I1, I2) = sqrt(sum((I1[p] - I2[p])^2))`

然而，最近邻方法在测试时效率低下，且对像素级变化敏感。这引出了对更强大方法的需求。

## P3：L3- 线性分类器 ➕

上一节我们看到了使用像素直接比较进行图像分类的局限性。本节我们将介绍一种参数化的方法——线性分类器。线性分类器是神经网络和卷积神经网络的基础。

线性分类器的核心思想是将图像像素值作为一个高维向量，通过学习一个权重矩阵 **W** 和偏置向量 **b**，将图像映射到不同类别的得分。

对于一个输入图像 **x**（例如，拉展成 `[3072x1]` 的向量，代表32x32x3的RGB图像）和类别标签 **y**，线性分类器的打分函数为：

**公式**：`f(x, W, b) = W * x + b`

这里，**W** 是权重矩阵（例如 `[10x3072]`），**b** 是偏置向量（例如 `[10x1]`）。输出是一个包含10个类别得分的向量。得分最高的类别即为预测结果。

## P4：L4- 训练与优化 ⚙️

定义了线性分类器的打分函数后，我们需要一个标准来衡量预测的好坏，并找到最优的参数 **W** 和 **b**。这就是损失函数和优化的作用。

**损失函数**（或称代价函数）量化了预测得分与真实标签之间的不一致程度。一个常用的损失函数是**多类支持向量机损失（SVM Loss）**，它希望正确类别的得分比错误类别的得分高出至少一个边界值 Δ。

**SVM Loss 公式（对于单个样本）**：`Li = sum(max(0, sj - syi + Δ))`，其中 `j ≠ yi`

为了控制模型的复杂度，防止过拟合，我们通常在损失函数中加入**正则化项**，如 L2 正则化：`R(W) = sum(W^2)`。因此，总损失为：`L = (1/N) * sum(Li) + λ * R(W)`，其中 λ 是正则化强度。

我们的目标是找到使总损失 **L** 最小化的 **W**。这个过程称为**优化**。最常用的方法是**梯度下降**：我们计算损失函数关于参数的梯度（导数），然后向负梯度方向更新参数。

**参数更新公式**：`W = W - learning_rate * dW`

## P5：L5- 神经网络介绍 🧠

线性分类器能力有限，无法处理复杂、非线性的数据分布。本节我们引入神经网络，它通过堆叠多个线性变换和非线性激活函数，可以拟合极其复杂的函数。

神经网络的基本单位是**神经元**。一个神经元接收多个输入，进行加权求和，加上偏置，然后通过一个**非线性激活函数**输出。

一个简单的两层神经网络前向传播过程如下：
1.  第一层：`scores1 = W1 * x + b1`
2.  激活函数：`hidden = max(0, scores1)` （这里使用 ReLU 激活函数）
3.  第二层（输出层）：`scores = W2 * hidden + b2`

**ReLU 激活函数公式**：`f(x) = max(0, x)`

通过增加层数和神经元数量，神经网络可以构建越来越复杂的特征表示。

## P6：L6- 反向传播 🔄

对于复杂的神经网络，如何高效地计算损失函数关于所有参数的梯度？**反向传播**算法利用链式法则，从输出层向输入层反向传播误差，逐层计算梯度。

假设我们有一个简单的计算图：`f(x, y, z) = (x + y) * z`。令 `q = x + y`，则 `f = q * z`。
前向传播后，我们从输出 `f` 开始反向传播梯度（假设上游传来 `df/df = 1`）：
*   对于乘法门 `f = q * z`：`df/dq = z`, `df/dz = q`
*   对于加法门 `q = x + y`：`dq/dx = 1`, `dq/dy = 1` （梯度均分）
根据链式法则：`df/dx = (df/dq) * (dq/dx) = z * 1`

在神经网络中，每个操作（矩阵乘法、加法、ReLU等）都是一个“门”，反向传播算法系统地应用链式法则，计算出损失对每一层权重 **W** 和偏置 **b** 的梯度 `dW` 和 `db`，用于后续的参数更新。

## P7：L7- 卷积神经网络 🌀

全连接神经网络在处理图像时参数量巨大，且忽略了图像的空间局部结构。**卷积神经网络** 是专门为处理图像等网格状数据而设计的神经网络。

CNN 的核心是**卷积层**。它使用一组可学习的滤波器（或卷积核）在输入图像上滑动（卷积操作），每个滤波器提取一种特定的局部特征（如边缘、纹理）。

**卷积操作示例（单通道）**：
对于一个 `3x3` 的滤波器 **K** 和 `4x4` 的输入图像区域 **I**，输出特征图的一个元素计算为：`O[i,j] = sum_{m,n} (I[i+m, j+n] * K[m, n]) + b`

卷积层具有**参数共享**和**局部连接**的特性，大大减少了参数量，并保留了空间信息。CNN 通常由卷积层、池化层（用于下采样，如最大池化）和全连接层交替堆叠而成。

## P8：L8- CNN典型结构 🏗️

了解了CNN的基本构件后，本节我们来看看历史上一些经典和高效的CNN网络结构，它们的设计思想深刻影响了深度学习的发展。

以下是几个里程碑式的CNN架构：
*   **LeNet-5**：早期的成功CNN，用于手写数字识别。
*   **AlexNet**：在2012年ImageNet竞赛中取得突破性成功，深度和宽度显著增加，使用了ReLU和Dropout。
*   **VGGNet**：结构非常规整，反复使用 `3x3` 卷积堆叠，证明深度是提升性能的关键。
*   **GoogLeNet**：引入了 **Inception 模块**，在同一个层中并行使用不同尺寸的卷积核，更高效地提取多尺度特征。
*   **ResNet**：提出了**残差连接**，解决了极深网络中的梯度消失和退化问题，允许训练成百上千层的网络。

**残差块公式**：`输出 = F(x) + x`，其中 `F(x)` 是卷积层要学习的目标，`x` 是恒等映射（快捷连接）。

## P9：L9- 深度学习硬件与软件 💻

训练大型神经网络需要强大的计算资源。本节简要介绍支撑深度学习的硬件和软件生态系统。

**硬件**：**GPU** 因其强大的并行计算能力，成为训练神经网络的首选。TPU是谷歌专为机器学习定制的芯片，效率更高。

**软件框架**：它们提供了构建和训练神经网络的高级抽象，自动处理反向传播等底层计算。主流框架包括：
*   **TensorFlow**：由Google开发，工业界广泛应用。
*   **PyTorch**：由Facebook开发，以动态计算图和易用性深受研究人员喜爱。
*   **JAX**：Google开发，结合了NumPy接口和自动微分，适合高性能数值计算。

使用这些框架，我们可以用简洁的代码定义复杂的网络结构。

## P10：L11- 训练神经网络(上) 🚀

有了网络结构和框架，我们如何有效地训练一个神经网络？本节和下一节将深入探讨训练过程中的关键技术和挑战。

训练神经网络不仅仅是运行梯度下降。我们需要精心设计训练流程的各个环节。

以下是训练初期需要考虑的几个重要方面：
1.  **数据预处理**：常见步骤包括去均值、归一化、PCA和白化等，使数据更易于优化。
2.  **权重初始化**：不能全初始化为0，这会导致对称性破坏问题。常用方法有Xavier初始化、He初始化等，根据激活函数调整。
3.  **批量归一化**：对每一层的输入进行归一化（减去均值，除以标准差），可以稳定训练、允许使用更高的学习率，并有一定正则化效果。
4.  **监控训练过程**：在训练过程中，我们需要跟踪损失和准确率，并可视化第一层卷积核的权重，以确保学习到有意义的特征。

## P11：L11- 训练神经网络(下) 📈

上一节我们讨论了训练的准备和初始化工作，本节我们聚焦于优化算法本身以及如何应对过拟合。

**优化算法**：基础的**随机梯度下降** 存在收敛慢、易陷入局部最优点等问题。改进的算法包括：
*   **动量**：模拟物理中的动量，积累之前的梯度方向，加速收敛并减少震荡。`v = ρ * v + dW`， `W = W - learning_rate * v`
*   **Adam**：结合了动量和自适应学习率的优点，是目前最常用的优化器之一。

**正则化**：为了防止模型在训练集上表现过好（过拟合）而在测试集上表现不佳，我们需要正则化。
*   **L2正则化**：在损失函数中增加权重惩罚项。
*   **Dropout**：在训练时随机“丢弃”（置零）一部分神经元的输出，强制网络学习更鲁棒的特征。
*   **数据增强**：对训练图像进行随机翻转、裁剪、颜色抖动等，人工扩大数据集。

## P12：L12- 循环神经网络 🔁

到目前为止，我们处理的都是固定大小的输入（如图像）到固定大小的输出。但许多任务涉及序列数据，如自然语言、语音、视频帧。**循环神经网络** 是处理序列数据的标准神经网络。

RNN 的核心思想是引入“隐藏状态”，该状态可以传递序列的历史信息。

**RNN 基本单元公式**：
`ht = tanh(Whh * h{t-1} + Wxh * xt + bh)`
`yt = Why * ht + by`

其中，`h_t` 是当前时刻的隐藏状态，`x_t` 是当前输入，`y_t` 是当前输出。RNN 在所有时间步共享参数 `(Whh, Wxh, Why)`。

然而，标准RNN存在**梯度消失/爆炸**问题，难以学习长距离依赖。**长短期记忆网络** 和**门控循环单元** 通过引入门控机制，有效地解决了这个问题，成为更常用的RNN变体。

## P13：L13- 注意力机制 🎯

即使有了LSTM，处理非常长的序列或对齐问题（如机器翻译）仍然困难。**注意力机制** 允许模型在生成输出时，动态地“关注”输入序列的不同部分。

注意力机制的核心是计算一个“注意力分布”，它表示在生成当前输出时，输入序列每个位置的重要性权重。

**注意力分数计算（一种常见方式）**：
`e_i = a(s_{t-1}, h_i)`，其中 `s_{t-1}` 是解码器上一时刻的状态，`h_i` 是编码器第 `i` 个位置的隐藏状态。`a` 是一个对齐模型（如一个小神经网络）。
`α_i = softmax(e_i)`，将分数归一化为权重。
**上下文向量**：`c_t = sum(α_i * h_i)`，即输入隐藏状态的加权和。

注意力机制极大地提升了序列到序列任务的性能，并催生了**Transformer** 架构，该架构完全基于自注意力机制，摒弃了RNN结构，成为当前自然语言处理领域的主流模型。

## P14：L14- 可视化与模型理解 👀

深度学习模型常被视为“黑箱”。本节探讨如何可视化和理解CNN内部究竟学到了什么，这有助于调试模型、建立信任并发现新知识。

以下是几种主要的可视化方法：
1.  **可视化第一层卷积核**：通常可以看到边缘、颜色块等基础特征检测器。
2.  **最大化激活**：找到能使某个神经元或某个通道激活值最大的输入图像（通过梯度上升生成）。这可以显示高层神经元对复杂模式（如狗脸、车轮）的响应。
3.  **遮挡实验**：用灰色方块遮挡输入图像的不同区域，观察对输出类别概率的影响，从而定位图像中对分类最重要的区域。
4.  **类激活图**：通过分析最后一个卷积层的特征图，生成一张热力图，高亮显示对预测类别贡献最大的图像区域。
5.  **梯度上升生成图像**：通过优化输入像素（而非权重），生成能最大程度代表某个类别或某个神经元的“理想化”图像，有时能产生艺术化或幻觉般的图案。

## P15：L16- 目标检测 🎯

图像分类回答了“图像是什么”的问题，而**目标检测** 需要回答“哪里有什么”，即定位出图像中所有感兴趣物体的位置（用边界框表示）并识别其类别。

目标检测比分类更复杂。主流方法可分为两类：
*   **两阶段检测器**：首先生成一系列可能包含物体的候选区域，然后对每个区域进行分类和边界框微调。代表是 **R-CNN** 系列（Fast R-CNN, Faster R-CNN）。
*   **单阶段检测器**：将检测视为一个回归问题，直接在图像网格上进行预测，速度更快。代表是 **YOLO** 和 **SSD**。

以YOLO为例，它将图像划分为 `S x S` 的网格。每个网格单元负责预测以该单元为中心的物体。每个预测包含边界框坐标 `(x, y, w, h)`、置信度以及属于各个类别的概率。

---

## P16：L16- 目标检测与图像分割 ✂️

上一节介绍了目标检测，本节我们延伸到更精细的像素级任务——**图像分割**。图像分割分为语义分割和实例分割。

*   **语义分割**：为图像中的每个像素分配一个类别标签，不区分同一类别的不同个体。
*   **实例分割**：在语义分割的基础上，进一步区分开同一类别的不同个体实例。

**全卷积网络** 是解决语义分割的经典方法。它将传统CNN最后的全连接层替换为卷积层，使得网络可以接受任意尺寸的输入，并输出相同空间分辨率的像素级类别预测图。为了恢复因池化而丢失的细节，FCN使用了**跳层连接** 和**转置卷积** 进行上采样。

**Mask R-CNN** 是一个强大的实例分割框架，它在Faster R-CNN的基础上，增加了一个并行的分支，用于预测每个候选区域内的二进制掩码，从而精确勾勒出物体的轮廓。

## P17：L17- 3D计算机视觉 📦

现实世界是三维的。3D计算机视觉旨在从2D图像或视频中理解和重建3D结构。

核心任务包括：
*   **深度估计**：从单张或多张图像中估计每个像素点到相机的距离。
*   **立体视觉**：模仿人眼，利用两个摄像头从不同视角拍摄的图像，通过匹配对应点来计算深度。
*   **运动恢复结构**：从一段视频序列中同时估计相机的运动和场景的3D结构。
*   **3D形状表示**：如何用数据表示3D物体？常见方式有体素网格、点云、网格和多视图图像。
*   **3D物体检测与语义场景补全**：在3D点云数据（如激光雷达扫描结果）中检测物体，或从单张深度图推测被遮挡部分的完整3D形状。

深度学习通过卷积网络处理体素数据，或通过PointNet等架构直接处理点云，在这些任务上取得了显著进展。
