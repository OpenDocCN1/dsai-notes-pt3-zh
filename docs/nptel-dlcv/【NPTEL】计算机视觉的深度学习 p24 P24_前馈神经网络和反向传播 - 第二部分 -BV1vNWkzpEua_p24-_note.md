在本节课中，我们将深入探讨训练神经网络的核心算法——反向传播。我们将学习如何通过链式法则计算梯度，并结合梯度下降法来更新网络参数，从而最小化损失函数。

## 损失函数与梯度下降

上一节我们介绍了前馈神经网络的基本结构。本节中，我们来看看如何训练这个网络。训练的目标是找到一组参数（权重和偏置），使得网络在训练数据上的预测误差最小。这个误差通过损失函数来衡量。

我们采用均方误差作为损失函数。对于一个单独的样本 `(x, y)`，其损失函数定义为：

**公式：** `L(θ; x, y) = 1/2 * (h_θ(x) - y)^2`

其中，`h_θ(x)` 是神经网络的输出，`y` 是期望输出。引入 `1/2` 是为了后续求导的数学简便性，它不影响使损失最小化的参数 `θ` 的取值。

对于包含 `M` 个样本的整个训练集，总体成本函数是每个样本损失的平均值：

**公式：** `J(θ) = 1/M * Σ_{i=1}^{M} L(θ; x_i, y_i)`

我们的目标是通过梯度下降法最小化 `J(θ)`。梯度下降需要计算损失函数对每个参数的偏导数（梯度），而反向传播正是高效计算这些梯度的方法。

## 反向传播算法详解

反向传播结合了链式法则和梯度下降。其核心思想是：先进行前向传播计算网络输出和损失，然后从输出层开始，反向计算损失对每一层参数的梯度。

首先，我们定义一些符号以便清晰地描述算法：
*   设网络共有 `N_L` 层。
*   用 `a_i^l` 表示第 `l` 层第 `i` 个神经元的激活值（即该神经元的输出）。
*   用 `w_{ij}^l` 表示连接第 `l` 层第 `i` 个神经元和第 `l+1` 层第 `j` 个神经元的权重。
*   用 `z^l` 表示第 `l` 层在应用激活函数前的加权输入，即 `z^l = W^l * a^{l-1} + b^l`。

### 前向传播与反向传播流程

神经网络的计算可分为两个阶段：前向传播和反向传播。

在前向传播阶段，输入数据从网络左侧流向右侧，逐层计算激活值，最终得到输出。对于一个三层网络，其向量化形式可表示为：
**代码/公式：**
`z^2 = W^1 * x + b^1`
`a^2 = f(z^2)`
`z^3 = W^2 * a^2 + b^2`
`a^3 = f(z^3) = h_θ(x)`
其中 `f` 是激活函数（如Sigmoid、ReLU）。

在反向传播阶段，我们从最右侧的输出层开始，向左计算损失对每一层参数的梯度。为此，我们为每个神经元引入一个“误差项” `δ_i^l`，它衡量了该神经元对最终输出误差的“责任”大小。

以下是计算这些误差项和最终梯度的关键步骤：

1.  **输出层误差：** 对于输出层（第 `N_L` 层）的第 `i` 个神经元，其误差项为：
    **公式：** `δ_i^{N_L} = (a_i^{N_L} - y_i) * f'(z_i^{N_L})`
    这实际上是损失函数对 `z_i^{N_L` 的偏导数。对于均方误差损失，`∂L/∂a_i^{N_L} = (a_i^{N_L} - y_i)`，再乘以激活函数的导数 `f'(z_i^{N_L})` 就得到了上述结果。

2.  **隐藏层误差：** 对于第 `l` 层（隐藏层）的第 `i` 个神经元，其误差项依赖于下一层 `(l+1)` 所有神经元的误差：
    **公式：** `δ_i^l = ( Σ_{j} w_{ij}^l * δ_j^{l+1} ) * f'(z_i^l)`
    可以理解为，当前神经元的误差，是它通过权重连接到的下一层神经元误差的加权和，再乘以本神经元激活函数的导数。其向量化形式为：`δ^l = ( (W^l)^T * δ^{l+1} ) ⊙ f'(z^l)`，其中 `⊙` 表示逐元素相乘。

3.  **计算梯度：** 一旦得到了每一层的误差项 `δ^l`，计算损失对权重和偏置的梯度就变得非常简单：
    *   损失对权重的梯度：`∂L/∂w_{ij}^l = a_i^{l-1} * δ_j^l`
    *   损失对偏置的梯度：`∂L/∂b_j^l = δ_j^l`
    直观理解是：权重 `w_{ij}^l` 的梯度，等于它前一层对应神经元的激活值 `a_i^{l-1}`，乘以它所在神经元（第 `l` 层第 `j` 个）的误差 `δ_j^l`。偏置的梯度则直接等于其所在神经元的误差。

### 反向传播的直观理解

为什么误差项和梯度公式长这样？我们可以通过链式法则来理解。

假设我们要计算损失 `L` 对某个权重 `w` 的梯度。根据链式法则，`∂L/∂w = (∂L/∂a) * (∂a/∂z) * (∂z/∂w)`。
*   `∂L/∂a` 是损失对最终输出的导数（如 `(a-y)`）。
*   `∂a/∂z` 是激活函数的导数 `f'(z)`。
*   `∂z/∂w` 是加权输入对权重的导数，这正好是前一层神经元的激活值 `a_{prev}`。

因此，`∂L/∂w = (a-y) * f'(z) * a_{prev} = δ * a_{prev}`。这里的 `δ` 就是输出层神经元的误差项。对于隐藏层的权重，链式法则会更长，但最终形式依然是 `δ^l * a^{l-1}`，只是 `δ^l` 需要通过后续层的误差反向传递计算得到。

## 完整的训练算法

基于以上推导，我们可以总结出使用反向传播和梯度下降训练神经网络的完整步骤。

以下是训练算法的伪代码描述：

1.  **初始化：** 随机初始化所有权重 `W` 和偏置 `b`。设置学习率 `η`。
2.  **循环直到收敛（对每个训练周期epoch）：**
    a. 初始化梯度累积变量 `ΔW = 0`, `Δb = 0`。
    b. **对训练集中的每个样本 `(x, y)`：**
        i. **前向传播：** 输入 `x`，计算各层 `z^l` 和 `a^l`，直至得到输出 `h_θ(x)`。
        ii. **计算输出层误差：** `δ^{N_L} = (h_θ(x) - y) ⊙ f'(z^{N_L})`。
        iii. **反向传播误差：** 对于 `l = N_L-1, ..., 2`，计算 `δ^l = ( (W^l)^T * δ^{l+1} ) ⊙ f'(z^l)`。
        iv. **计算样本梯度：** 对于每一层 `l`，计算该样本贡献的梯度：
            *   `∂L/∂W^l += a^{l-1} * (δ^l)^T`
            *   `∂L/∂b^l += δ^l`
            （此处 `+=` 表示将当前样本计算的梯度累加到 `ΔW` 和 `Δb` 上）。
    c. **参数更新：** 在所有样本上累积梯度后，计算平均梯度并更新参数：
        *   `W^l := W^l - η * (1/M) * ΔW^l`
        *   `b^l := b^l - η * (1/M) * Δb^l`

在实际应用中，我们通常不会在所有训练数据上计算完梯度才更新一次（批梯度下降），而是采用小批量梯度下降，即每次只用一小部分数据计算梯度并更新参数，这能提高效率并有助于逃离局部极小点。

本节课中，我们一起学习了神经网络训练的核心——反向传播算法。我们首先明确了通过最小化损失函数来训练网络的目标。然后，我们详细推导了如何利用链式法则，将输出层的误差反向传播到网络的每一层，从而高效地计算出损失函数对所有参数的梯度。最后，我们整合出了结合前向传播、反向传播和梯度下降的完整训练流程。
