## 序列学习问题

到目前为止，无论是前馈神经网络还是卷积神经网络，输入的大小始终是固定的。给定一个CNN，你总是输入一个固定尺寸的图像（例如32x32）进行分类。每个输入也独立于之前或未来的输入。两个连续图像的计算、输出和决策完全相互独立。

这是什么意思？这也与机器学习数据集中常见的**IID**属性相关。IID代表独立同分布。如果我们有一个图像数据集，我们假设数据集中的每个图像都是独立同分布的。这意味着无论你以何种顺序提供这些图像，你的模型最终都可能学习到相同的预测函数。因此，无论输入是这张图像还是那张图像，显然类别标签会改变，但模型参数或架构中的其他内容不会改变。

然而，还有另一类问题被称为**序列学习问题**，它们需要比我们目前所见更多的东西。

以文本自动补全为例，这是你可能每天都会遇到的情况。如果你输入“Google Autocomplete A”，你会得到一组推荐；如果你输入“Google autocomplete B”，你会得到另一组推荐；对于“C”也是如此。在这类问题中，连续的输入不再独立。为了在特定状态下进行预测，你需要查看之前时间步的输入。这是我们在讨论前馈网络或CNN时不需要的。

在这类问题中，输入的长度和需要进行的预测数量也可能不固定。例如，如果你输入“Google autocomplete C”，最后一个词可能是“code”或“country”，它们的长度不同。你希望你的模型不受此类约束的影响。

这类问题的另一个重要启示是：无论你的输入是什么，无论“C”之前有两个词、三个词还是一个词，模型都必须执行相同的任务。在所有上下文中，给定一个先前的短语，它必须预测下一组字符。无论你在哪个时间步尝试进行预测，该任务都不会改变。如果用户输入了一个词，你仍然需要预测下一组字符；如果用户输入了两个词，你的上下文（时间上下文）长度增加了，但任务需要实现的目标保持不变。

这类问题被称为**序列学习问题**。为处理此类序列学习问题而设计的神经网络架构被称为**循环神经网络**，我们很快就会看到它们为何如此命名。

## RNN的架构变体

以下是RNN的几种主要架构变体。

### 一对多架构

如果你将一个标准的前馈神经网络可视化为具有输入、一组隐藏层和输出的结构，那么循环神经网络的变体可以可视化为：你可以有一个**一对多**的变体。其中，你的输入在一个时间步，但你的输出实际上是跨多个时间步的输出序列。

**示例**：图像描述生成。输入是单张图像，输出是一个单词序列，一个单词必须跟随前一个单词以构成完整的句子。这被称为“一对多”，即一个输入，多个输出。

### 多对一架构

类似地，你可以有一个**多对一**架构。其中，你在多个时间步有输入，但只在某个特定时间步进行一次预测。

**示例**：动作预测。输入是一系列视频帧，模型在看完完整的输入序列后给出一个特定的类别。例如，在看完一段足球比赛的完整视频片段后，模型应预测该片段是否为进球事件。

### 多对多架构

还有一种**多对多**设置，其中给定一组跨时间步的多个输入，输出也必须具有跨时间步的多个输出。

**示例**：视频描述生成。输入是一个视频（即随时间变化的一系列帧），输出也是随时间变化的一系列单词。

### 同步多对多架构

你可能还有一个略有不同的**多对多**设置，其中你有一组随时间变化的输入和一组随时间变化的输出，但输出和输入在每个输入处是同步的。

**示例**：逐帧视频分类。你有一个视频作为模型的输入（记住，视频具有时间成分）。但同时，你希望在每一帧级别进行预测。在这种特定上下文中，这将是一个多对多设置。

## 如何为序列建模

那么，我们如何为涉及序列的任务建模呢？我们看到了高级架构，但实际上如何用这些架构学习模型？如何考虑时间序列数据中常见的输入之间的依赖性？如何考虑可变数量的输入？如何确保，例如在图像描述生成中，给定一张图像，描述可能有七个词；给定另一张图像，描述可能有十个词？你如何允许多个输出、可变数量的输出，或者类似地，为另一个应用允许可变数量的输入？

第三个考虑因素是，如何确保在每个时间步执行的函数是相同的？为什么我们需要这个？无论一帧在视频中的哪个位置，你都希望使用相同的逻辑来执行预测。这类似于我们在卷积中所说的：无论猫在图像的左上角还是右下角，我们都想说图像中存在一只猫。我们通过卷积的思想克服了那个问题。但现在，我们如何在时间序列和序列学习问题上做到这一点，这就是我们接下来要讨论的内容。

## RNN的高级抽象

循环神经网络的高级抽象如下图所示。你有一个输入 **x**，一个输出 **y**。在两者之间，有一个被称为循环神经网络的东西。顾名思义，这里存在一个循环，现在由这个单元循环表示。

RNN的关键思想是它们有一个**内部状态**，该状态在序列被处理时更新。人们可以将这个内部状态视为某种记忆，它保留了同一时间序列过去数据的一些信息，这个想法我们本周稍后也会讨论。

如果展开这个循环，你会得到一个这样的网络：你有一组随时间变化的输入 **x1** 到 **xt**。这就是你拥有的输入序列，这就是为什么我们将其视为序列学习问题。对于每个输入，你可以将该输入提供给一个RNN块。这个RNN块可以是单个隐藏层，也可以是多个隐藏层，可以具有跳跃连接，可以在此RNN块内具有任何其他架构，但我们将把它视为一个单一的抽象。该RNN的输出是模型在该时间步的输出。

这将是整个展开的RNN。当你使用RNN时，你必须事先决定要展开多少。这是什么意思？对于特定问题，你必须决定这个 **T** 必须是多少。你是想查看过去的20帧来做决定，还是想查看过去的100帧，或者200帧？这是在你开始学习RNN之前必须决定的事情。

这里的 **T** 将对应于你在进行预测时希望查看的序列长度。一旦 **T** 被决定，你就可以这样展开RNN，其中RNN块内的相同操作用于每个时间步的输入。正如我们之前所说，根据你使用RNN的应用，你可以在每个时间步都有输出，或者只在最后一个时间步有输出，或者也可以在最后一个时间步之后有一个跟随输入的输出序列。所有这些可能性都是我们在屏幕上看到的这个抽象的不同变体。

## 循环操作详解

现在让我们深入更多细节。我们说过它是一个循环神经网络，并且我们也希望这个RNN块对每个时间步的输入重复相同的操作。那么，我们实际想要使用的循环操作是什么？

对我们来说，每个时间步的循环公式是：给定特定时间步的输入 **Xt**，以及 **ht-1**（RNN在前一个时间步的状态），然后你将应用某个函数。这个函数是RNN内部带有一些权重 **U** 和 **W** 的参数。你会得到该时间步的输出 **h**，它被传递给RNN的下一个状态，以处理下一个时间步的输入。

这是一个可视化：在时间步 **T1**，给定输入 **x1** 和初始状态 **h0**，RNN使用权重矩阵 **U** 和 **W** 处理这两个输入，并输出 **y1**（如果该时间步需要输出）以及状态 **h1**，该状态被传递给RNN的下一个时间步。在下一个时间步，RNN接收 **x2** 和 **h1** 作为输入，使用与前一个时间步相同的权重 **U** 和 **W**（记住我们说过，我们希望RNN将每一帧视为类似类型的输入并执行类似的操作，尽管它们在时间上位置不同）。因此，第二个时间步的RNN输出 **y2**（根据问题需要）和其隐藏状态 **h2**，该状态被传递给第三个时间步的RNN，依此类推，直到最后一个时间步。

所以，重复一下循环公式：**ht = F_UW(Xt, Ht-1)**，其中 **U** 和 **W** 是那些权重矩阵。这里的关键观察是，相同的函数和相同的参数集在每个时间步都被使用。这不会改变，而这正是循环神经网络中“循环”所在之处。

现在，你可以考虑根据任务使用激活函数。我们刚才写的循环关系现在可以是：**H = tanh(U * Xt + W * Ht-1)**，其中 **tanh** 是循环神经网络中常用的激活函数。**U** 是乘以 **Xt** 的权重矩阵，**W** 是乘以输入 **Ht-1** 的权重矩阵。**Yt** 可以是 **softmax(V * Ht)**。所以，如果你有一个从RNN输出的 **Ht**，那么你有一组权重 **V** 乘以 **V*Ht**，然后如果你处理的是分类问题，你可以在 **V*Ht** 上应用 **softmax** 来给出RNN的最终输出。

这里的权重，从 **x** 到RNN的是 **U**，查看 **Ht-1** 并给出 **Ht** 的是 **W**。所以你可以看到有三组权重矩阵（当然，**W** 可以根据RNN块内有多少层而变化），否则你这里有作用于输入、隐藏状态和隐藏状态到输出的三组权重。这有时也被称为**Elman RNN**，以Jeffrey Hinton（应为Jeffrey Elman，此处原文有误）命名，他是这些思想的发起者。

## 计算图简介

为了继续前进并理解RNN实际上是如何训练的，我们将退一步，看看所谓的**计算图**的概念。

计算图是实现神经网络（包括推理和反向传播）的一种非常常见的方法，如今在PyTorch或TensorFlow等框架中也是如此。因此，我们将首先回顾一般的计算图，然后讨论如何为RNN定义计算图。

计算图是一个有向图，其节点对应于操作或变量。输入节点和从节点输出的值是**张量**。张量是多维数组，通常是大于二维或二维的。向量的一般化是矩阵，矩阵的一般化通常被称为张量。张量通常包含标量、向量、矩阵等，是表示这些量的更通用术语。

正如我刚才提到的，计算图可以实例化以执行神经网络的前向传播以及反向传播。

让我们在讨论神经网络之前举一个简单的例子，谈谈如何使用计算图来创建表达式并计算它们。如果你有表达式 **E = (a + b) * (b + 1)**，这是一个算术表达式。这里有三个操作：两个加法和一个乘法。

你可以将整个表达式或操作写为一系列中间操作。那些中间操作是什么？你可以首先说 **C = a + b**，**D = b + 1**，然后 **E = C * D**，这是你的最终输出。所以，你说这里的第一个项是 **C**，第二项是 **D**，然后你最终将两者相乘以得到 **E**。这看起来很简单，我们为什么要讨论这个？

现在可以将其写为计算图。你有作为输入给出的值 **A** 和 **B**。你计算由 **a + b** 给出的 **C**。然后你计算 **D**，它只依赖于 **B**，即 **b + 1**。然后你组合 **C** 和 **D** 得到最终输出 **E**，即 **C * D**。

如何评估这些表达式？假设给你特定的 **A** 和 **B** 值，你如何使用计算图评估这个表达式？你会将输入变量设置为给定的特定值，例如 **a=2**，**b=1**，然后你会从这些变量实例值开始，沿着图向上计算节点，直到根节点，得到最终答案。

所以它可能看起来像这样：设置 **a=2**，**b=1**。首先计算 **c = a + b**，得到 **c=3**。类似地，**d=2**。然后组合它们，得到 **E** 的最终答案，即 **E=6**。这很好很简单。

但是你如何使用这样的计算图进行反向传播？或者换句话说，如何使用计算图计算梯度/导数？这里的关键是，要理解梯度，你需要理解计算图的边，因为边表示一个特定变量如何影响另一个变量。

例如，如果你有相同的计算图，你在这个叶节点有 **a**，并且在那个叶节点的父节点有 **c = a + b**。现在，可以写出 **∂c/∂a**。因为 **c = a + b**，所以 **∂c/∂a = 1**。类似地，在连接 **B** 和 **C** 的这条边上，**∂c/∂b** 也是 **1**，因为 **c = a + b**，依此类推，对于图中的每一组边都是如此。

那么，我们如何做到这一点？我们正在将标准求和规则和乘积规则适当地应用于梯度，以计算每条边上的每个梯度。为了得到你的最终梯度，你可以对所有从一个节点到另一个节点的可能路径求和，将路径上每条边的导数相乘。

例如，如果我们想要 **∂E/∂a**，我们查看所有将我们从 **a** 带到 **E** 的可能路径。在这个特定情况下，那将只是这条路径。你将那条路径上的所有梯度相乘，所以在这种情况下是 **1 * 2**，这给了你梯度 **∂E/∂a**。类似地，如果你必须计算 **∂E/∂b**，你必须考虑所有将你从 **B** 带到 **E** 的路径。你将每条路径上的梯度相乘，并将这两条路径的贡献相加，你将得到最终梯度。

所以再次，在这个例子中，**∂E/∂b** 将是 **1 * 2 + 1 * 3**。这就是你如何使用计算图来获取特定表达式中的梯度。

## 在PyTorch中的应用

为了给你一个更具体的例子，在你可能使用的框架（即PyTorch）中，PyTorch在前向传播期间动态跟踪变化，允许创建这样的计算图，称为动态图。当你说 `loss.backward()` 时（当你在PyTorch中训练神经网络时，如果你计算损失然后调用 `.backward()`），或者如果你只是评估一个表达式，你可以在这个我们看到的特定例子中说 `c.backward()`。当你执行 `c.backward()` 时，PyTorch框架会触发梯度的计算，然后你可以打印出表达式中每个边或每个梯度的梯度。

## 神经网络的计算图

那么神经网络的计算图呢？前馈神经网络？假设你在神经网络中有几层，给定输入 **X**，假设你的隐藏层 **H** 是 **tanh(W * X + b)**，**W * X + b** 是你的输入 **x** 的线性组合，让我们假设你在每个节点上有一个非线性激活函数 **tanh**，这给你一个向量 **H**。然后你在 **H** 上应用另一组权重 **V** 来给出你的最终输出 **y**，其中 **b** 和 **a** 是你的偏置。

如果这是你对前馈神经网络的数学表示，那么你对应的计算图将如下所示：你的第一个输入是 **W** 和 **x**，基于此，你在这里得到某个输出。然后你将其与 **+ b** 组合，然后你可以得到某个输出。最后，你取那个并应用 **tanh** 得到你的 **tanh(U)**。所以这里的第一步可以表示为一个计算图，它是一个将 **W**、**X** 和 **b** 作为输入并输出 **H** 的序列。类似地，对于下一个操作，你现在可以将 **h** 视为输入，**v** 视为另一个输入，**a** 视为另一个输入，此时的计算图将是这组操作。显然，此计算图中某个节点的输入是作为前一个计算图的输出而来的边。

## RNN的计算图视角

现在，回到RNN，由于RNN稍微复杂一些，让我们尝试从计算图的角度来看待RNN。给定输入 **x1** 和 **H0**，输入被提供给 **F_UW**（这是我们之前讨论过的），**F_UW** 输出 **h1**。然后 **h1** 和 **x2** 再次进入 **F_UW**，这是我们在每个时间步评估的相同函数。然后第二个时间步的 **F_UW** 给你 **H2**。这再次循环地在下个时间步给出，依此类推，直到你得到该序列最后一个时间步的最终隐藏状态。

所以从计算图的角度来看，这里的输入 **U**、**W**（权重矩阵）在每个时间步都是相同的，这就是这些箭头所显示的，它们进入每个时间步的 **F_UW**。

如果你有一个多对多RNN，你只会稍微改变这一点，因为现在你将在每个时间步都有输出，而我们在前面看到的RNN中没有。你现在可以有一个从多对多RNN出来的输出 **L1**，这最终是作为输出给用户的。你也可以考虑组合所有这些 **L1, L2, L3, ..., Lt** 来给出你的最终 **L** 作为输出。

为什么这很重要？如果你看，比如说，视频描述生成，这将是这种多对多架构的一个实例。你可以将 **L1, L2, L3, ..., Lt** 等视为保存描述每个单词的变量，而 **L** 是作为RNN输出给出的最终描述。

如果你考虑多对一架构，计算图将如下所示，初始部分大致保持不变，但输出 **y** 现在只在最后一个时间步。这完整吗？在计算图方面并不完全，你还需要连接，其中 **y** 可以是一个输出，它也接收 **h1, h2, h3** 等作为输入来计算最终输出值。

在一对多设置的情况下，你可以有这种计算图，其中输入仅在第一个时间步是 **x**，但你现在在每个时间步都有输出 **y1, y2, y3, ..., yt**。

这里的一个问题是，在中间时间步你会给出什么作为输入？为什么我们需要讨论这个？记住，**F_UW** 在每个时间步是相同的函数。我们已经知道在第一个时间步 **F_UW** 需要两个输入 **x** 和 **H0**，这意味着在每个时间步它确实需要两个输入。我们该怎么办？一个选择是，我们可以在每个时间步输入零，这可能是我们可以提供的一个选项。另一个有时也遵循的选项是，前一个时间步的输出也可以通过调整维度作为下一个时间步的输入。你可以使用前一个时间步的输出作为下一个时间步的输入。

为什么这相关？为了生成描述中的下一个单词，你可以提供描述中的前一个单词来帮助模型生成适当的下一个单词。

---

## 一个具体示例

为了给出一个更具体的例子，让我们考虑一个RNN模型。让我们假设输入和输出来自我们的词汇表 **{H, E, L, O}**。你的输入字符，假设是 **‘H’**，表示为 **1000**。这样的表示也称为**独热向量**。独热向量是一个向量，在给定输入的位置（从词汇表中的位置）为1，其他地方为0。由于 **H** 是这里的第一个字符，如果你的输入字符是 **H**，对应的独热向量将是 **1000**。

给定那个作为输入，让我们假设你有一个隐藏层，一个输出层，并假设输出层有 **d** 组输出，在进行 **softmax** 后，你最终得到一组概率，其中第二个概率最高，这意味着你将预测下一个字符为 **E**。

现在，这个字符作为输入被提供给下一个时间步（记住我们刚刚说过 **y1** 作为输入被提供给下一个时间步，作为 **x2**）。所以 **E**，由于其在词汇表中第二个索引的位置，将由独热向量 **0100** 表示，然后这通过相同的网络传递，你现在得到一个 **softmax** 输出为 **0.25, 0.2, 0.5, 0.05**，最高的是第三个，即 **L**，这是RNN在该时间步的输出。

那个 **L** 然后再次作为输入被提供给下一个时间步，**L** 表示为 **0010**（由于 **L** 在词汇表中的位置）。你再次执行这个过程，它再次给出 **L** 作为输出。那个 **L** 被提供给下一个时间步，然后输出是 **O**。在某个时刻，整个RNN模型可以给出一个结束标记作为输出，以知道这组输出在哪里结束。所以结束标记将是词汇表中的一个默认字符，当RNN模型决定结束该特定单词的生成时，就会预测它。
