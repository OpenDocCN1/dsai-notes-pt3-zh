在本节课中，我们将学习循环神经网络中的反向传播。我们将首先回顾RNN的前向传播过程，然后详细推导如何计算误差相对于网络权重（U、V、W）的梯度。最后，我们将讨论RNN训练中一个关键挑战——梯度消失与爆炸问题，并简要介绍其应对思路。

## 回顾RNN架构与问题

上一节我们介绍了RNN的基本结构。本节中，我们来看看RNN架构的两个扩展以及一个核心问题。

首先，RNN可以拥有多个隐藏层。实际上，你可以在每个RNN模块中设置任意数量的隐藏层。此外，你还可以将多个RNN模块堆叠起来，这种架构被称为**堆叠RNN**。

以下是堆叠RNN的示意图：
```
输入 -> RNN块1 -> RNN块2 -> 输出
```
在这种架构中，每一层（级别）的权重在所有时间步之间是共享的。例如，第一层RNN块在所有时间步共享同一组权重，第二层RNN块也是如此。

其次，我们讨论了RNN状态更新的一个潜在问题。RNN的隐藏状态记录了之前所有时间步的信息。如果在某个时间步，当前输入对状态的改变过大，那么之前时间步的影响就会被削弱，这对于序列学习任务可能是不利的。

## RNN的前向传播与损失

现在，我们正式进入RNN的反向传播。首先，让我们回顾一下RNN的前向传播过程。

假设我们有一个用于分类任务的RNN，其前向传播公式如下：

**隐藏状态更新公式**：
`h_t = σ(U * x_t + W * h_{t-1})`
其中，`σ` 是激活函数（如tanh或sigmoid）。

**输出计算公式**：
`ŷ_t = softmax(V * h_t)`

对于分类问题，我们通常使用交叉熵损失函数。总误差 `E` 是每个时间步误差 `E_t` 的总和。

## 计算梯度：以权重V为例

我们的目标是计算总误差 `E` 相对于三组权重 `U`、`V`、`W` 的梯度，以便使用随机梯度下降法更新权重。总梯度是各时间步梯度的和：
`∂E/∂W = Σ_t ∂E_t/∂W`

让我们从一个相对简单的情况开始：计算误差 `E_3`（在时间步t=3）相对于输出层权重 `V` 的梯度。

我们定义 `z_3 = V * h_3`。根据链式法则，梯度计算如下：
`∂E_3/∂V = (∂E_3/∂ŷ_3) * (∂ŷ_3/∂z_3) * (∂z_3/∂V)`

*   `∂E_3/∂ŷ_3`：对于交叉熵损失，这部分通常简化为 `(ŷ_3 - y_3)`，其中 `y_3` 是真实标签。
*   `∂ŷ_3/∂z_3`：这是softmax函数对其输入的导数。
*   `∂z_3/∂V`：根据 `z_3` 的定义，这部分等于 `h_3`。

因此，`∂E_3/∂V` 可以顺利计算。总梯度 `∂E/∂V` 就是所有时间步 `∂E_t/∂V` 的和。

## 计算梯度：权重W与时间依赖的挑战

接下来，我们计算误差 `E_3` 相对于循环权重 `W` 的梯度。这比计算 `V` 的梯度要复杂。

一个初步的想法是：
`∂E_3/∂W = (∂E_3/∂ŷ_3) * (∂ŷ_3/∂h_3) * (∂h_3/∂W)`

然而，这并不完整。因为 `h_3` 不仅直接依赖于 `W`，还通过 `h_2` 间接依赖于 `W`，而 `h_2` 又通过 `h_1` 依赖于 `W`，依此类推。这意味着 `W` 通过多条路径影响了 `E_3`。

为了正确计算梯度，我们必须考虑从时间步0到3的所有路径。应用链式法则，完整的表达式为：
`∂E_3/∂W = Σ_{k=0}^{3} [ (∂E_3/∂ŷ_3) * (∂ŷ_3/∂h_3) * (∂h_3/∂h_k) * (∂h_k/∂W) ]`

其中，`∂h_3/∂h_k` 项本身可以进一步展开为一系列雅可比矩阵的乘积，例如：
`∂h_3/∂h_1 = (∂h_3/∂h_2) * (∂h_2/∂h_1)`

因此，`∂E_3/∂W` 的核心部分包含了一个跨越多个时间步的连乘积：
`Π_{j=k+1}^{3} (∂h_j/∂h_{j-1})`

## 梯度消失与爆炸问题

上述连乘积项正是RNN训练中著名问题的根源：**梯度消失**和**梯度爆炸**。

**梯度消失问题**：
如果每个 `∂h_j/∂h_{j-1}` 的值（通常是激活函数的导数）小于1（例如使用sigmoid或tanh函数时），那么当时间步很长时，这个连乘积会指数级地趋近于零。这意味着，较早时间步的梯度信号在反向传播到更早的层时会变得极其微弱，导致网络无法学习到长距离的依赖关系。

**梯度爆炸问题**：
相反，如果这些导数值大于1，连乘积会指数级增长，导致梯度变得异常巨大。在数值计算中，这通常表现为“NaN”（非数字）错误。

在实践中，梯度爆炸问题相对容易处理，常用的方法是**梯度裁剪**。即设定一个梯度阈值，当梯度的范数超过这个阈值时，就将其缩放回该阈值范围内。

然而，梯度消失问题更为棘手，因为它意味着模型从根本上难以学习长期依赖。关于权重 `U` 的梯度计算与 `W` 类似，也会面临同样的问题，我们将其留作练习。

## 总结与下节预告

本节课我们一起学习了RNN中的反向传播。
1.  我们回顾了RNN的前向传播公式和损失函数。
2.  我们推导了误差相对于输出权重 `V` 的梯度计算，这个过程相对直接。
3.  我们重点分析了误差相对于循环权重 `W` 的梯度计算，揭示了其中包含跨越时间步的连乘积。
4.  正是这个连乘积导致了**梯度消失**（当因子小于1时）和**梯度爆炸**（当因子大于1时）问题。梯度爆炸可以通过梯度裁剪缓解，但梯度消失问题需要更根本的架构改进。

在下一讲中，我们将探讨如何通过改进RNN的架构（例如引入门控机制，如LSTM和GRU）来有效地解决梯度消失问题，从而使RNN能够学习长序列中的长期依赖关系。
