# 053：RNN中的反向传播

![](img/a5372566ee06210bf2e1db61add7cc04_0.png)

在本节课中，我们将学习循环神经网络中的反向传播过程。我们将从回顾RNN的前向传播开始，然后详细推导计算权重梯度的方法，并探讨在此过程中可能遇到的梯度消失与梯度爆炸问题。

## 回顾RNN结构与前向传播

上一节我们介绍了RNN的基本结构。本节中，我们来看看如何计算其梯度。

一个展开的RNN可以可视化为一系列按时间步连接的模块。其前向传播公式如下：

**隐藏状态更新公式**：
`h_t = tanh(U * x_t + W * h_{t-1})`

**输出计算公式**：
`ŷ_t = softmax(V * h_t)`

其中，`U`、`W`、`V` 分别是输入层到隐藏层、隐藏层到隐藏层、隐藏层到输出层的权重矩阵。对于分类问题，我们通常使用交叉熵损失函数。

## 计算梯度：以输出权重V为例

首先，我们计算误差 `E` 对权重 `V` 的梯度。这相对简单，因为 `V` 直接连接到输出。

假设在时间步 `t=3`，我们有中间变量 `z_3 = V * h_3`。根据链式法则，梯度计算如下：

`∂E_3/∂V = (∂E_3/∂ŷ_3) * (∂ŷ_3/∂z_3) * (∂z_3/∂V)`

其中：
*   `∂E_3/∂ŷ_3` 取决于损失函数（如交叉熵损失，可简化为 `ŷ_3 - y_3`）。
*   `∂ŷ_3/∂z_3` 是softmax函数对其输入的导数。
*   `∂z_3/∂V = h_3`。

要得到总误差 `E` 对 `V` 的梯度，我们需要对所有时间步的梯度求和：

`∂E/∂V = Σ_t (∂E_t/∂V)`

## 计算梯度：以循环权重W为例

接下来，我们计算误差对循环权重 `W` 的梯度。这更为复杂，因为 `W` 的影响通过时间传播。

以计算 `∂E_3/∂W` 为例。`W` 不仅直接影响 `h_3`，还通过影响 `h_2`、`h_1` 等间接影响 `h_3`。因此，必须考虑所有路径。

根据链式法则，`∂E_3/∂W` 需要展开为对所有先前时间步 `k` 的求和：

`∂E_3/∂W = Σ_{k=0}^{3} (∂E_3/∂ŷ_3) * (∂ŷ_3/∂h_3) * (∂h_3/∂h_k) * (∂h_k/∂W)`

其中，`∂h_3/∂h_k` 项本身可以进一步展开为一系列雅可比矩阵的乘积，例如：

`∂h_3/∂h_1 = (∂h_3/∂h_2) * (∂h_2/∂h_1)`

因此，`∂E_3/∂W` 最终涉及一连串 `∂h_j/∂h_{j-1}` 的乘积。总误差 `E` 对 `W` 的梯度，则是所有时间步 `t` 的 `∂E_t/∂W` 之和。

## 梯度消失与梯度爆炸问题

上述计算揭示了一个关键问题：在计算 `∂E_t/∂W` 时，我们需要连乘多个 `∂h_j/∂h_{j-1}` 项。

以下是可能出现的两种情况：

1.  **梯度消失**：如果每个 `∂h_j/∂h_{j-1}` 的值都小于1（例如使用sigmoid或tanh激活函数时，其导数的绝对值通常小于1），那么多个小于1的数连乘会迅速趋近于零。这意味着，较早时间步的输入对后面时间步输出的影响梯度会变得极小甚至消失，网络难以学习长期依赖关系。
2.  **梯度爆炸**：反之，如果这些梯度值都大于1，连乘会导致梯度值指数级增长，变得异常巨大，这被称为梯度爆炸。

## 应对策略

对于梯度爆炸问题，实践中有一个简单有效的解决方法：

*   **梯度裁剪**：设定一个梯度阈值（例如10），在更新权重前，如果梯度的范数超过这个阈值，就将其按比例缩放到阈值范围内。这能有效防止参数更新步长过大。

然而，梯度消失问题无法通过简单的裁剪解决，因为它导致梯度变为零，而非过大。这需要更根本的架构改进。
