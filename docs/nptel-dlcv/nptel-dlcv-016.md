# 016：霍夫变换 🧠

![](img/67c599c8d41120a3558078bf9feba9f4_0.png)

在本节课中，我们将要学习一种用于在图像中匹配形状或模板的强大方法——霍夫变换。我们将从简单的直线检测开始，逐步扩展到圆形乃至任意形状的检测，并理解其背后的原理与算法。

## 概述

霍夫变换是一种用于检测图像中特定形状（如直线、圆等）的投票技术。其核心思想是将图像空间中的点映射到参数空间，通过在参数空间中寻找投票的峰值来确定形状的参数。这种方法对噪声和部分遮挡具有较好的鲁棒性。

## 从直线检测开始

上一节我们介绍了最小二乘法和RANSAC等直线拟合方法。本节中，我们来看看当图像中存在多条直线，或者我们需要检测更复杂的形状（如多边形或圆形）时，霍夫变换如何发挥作用。

### 直线的参数化

我们从直线的笛卡尔坐标方程开始，其标准形式为：

**公式：** `y = Mx + C`

其中，`M` 是斜率，`C` 是y轴截距。我们可以重排这个方程，得到：

**公式：** `C = -xM + y`

这个形式将我们带入了 `(M, C)` 参数空间。在这个空间中，每一个 `(M, C)` 点都对应着原始 `(x, y)` 空间中的一条直线。反之，原始空间中的每一个点，也对应着参数空间中的一条直线。这种对应关系是霍夫变换的基础。

然而，笛卡尔坐标表示法在处理垂直线时存在问题，因为此时斜率 `M` 为无穷大。因此，更常用的方法是采用极坐标参数化：

**公式：** `ρ = x cosθ + y sinθ`

这里，`ρ` 是原点到直线的垂直距离，`θ` 是该垂线与x轴的夹角。`ρ` 和 `θ` 都是有界的，这使得计算更加方便。

### 投票机制

霍夫变换的核心是投票机制。以下是其工作原理的步骤说明：

1.  **初始化累加器**：在参数空间（`ρ`, `θ`）中创建一个二维数组（累加器），并将其所有值初始化为0。这个数组的维度由 `ρ` 和 `θ` 的量化级别决定（例如，`θ` 从0到180度，每1度一个区间）。
2.  **遍历边缘点**：对于图像中检测到的每一个边缘点 `(x, y)`：
3.  **为所有可能的 `θ` 投票**：对于每一个量化后的 `θ` 值，使用公式 `ρ = x cosθ + y sinθ` 计算对应的 `ρ` 值。
4.  **累加投票**：在累加器中，找到 `(ρ, θ)` 对应的单元格，并将其计数值加1。这表示该边缘点投票支持这条参数为 `(ρ, θ)` 的直线。
5.  **寻找峰值**：在所有边缘点完成投票后，在累加器中寻找局部最大值。这些峰值点 `(ρ, θ)` 就对应着图像中最可能存在的直线。

通过这种方式，即使图像中有多条直线，我们也能通过参数空间中的多个峰值将它们一一检测出来。

## 扩展到圆形检测

理解了直线检测后，我们可以将霍夫变换的思想推广到检测圆形。一个圆的方程可以表示为：

**公式：** `(x - a)² + (y - b)² = r²`

其中，`(a, b)` 是圆心，`r` 是半径。现在，我们需要检测三个参数：`a`, `b`, `r`。

### 三维累加器

因此，我们需要一个三维的累加器数组。算法流程与直线检测类似：

1.  初始化一个三维累加器 `A(a, b, r)`。
2.  对于每个边缘点 `(x, y)`，遍历所有可能的半径 `r` 和圆心 `(a, b)` 的组合。
3.  如果 `(x, y)` 满足圆的方程 `(x - a)² + (y - b)² = r²`，则在累加器 `A(a, b, r)` 对应的位置投票。
4.  最后，在三维累加器中寻找峰值，其坐标 `(a, b, r)` 即对应检测到的圆。

在实际应用中，为了降低计算复杂度，通常会先利用梯度信息来减少需要遍历的参数空间。

## 广义霍夫变换：检测任意形状

对于没有解析表达式的不规则形状（例如一个特定的商标或物体轮廓），我们可以使用广义霍夫变换。

### 构建R表

首先，我们需要一个已知形状的模板。以下是构建参考表（R表）的步骤：

1.  在模板形状内部选择一个参考点（例如质心）`(x_c, y_c)`。
2.  对于模板形状轮廓上的每一个边缘点 `(x_i, y_i)`，计算：
    *   该点到参考点的向量 `r_i`。
    *   该点处的边缘方向（梯度方向）`φ_i`。
3.  创建一个R表，其索引是边缘方向 `φ`（量化后）。对于每个 `φ`，表中存储所有具有该边缘方向的边缘点，其对应的向量 `r`（即从该点到参考点的位移）。

### 在新图像中检测形状

有了R表后，我们可以在新图像中检测该形状：

1.  对新图像进行边缘检测，得到边缘点及其梯度方向 `φ`。
2.  初始化一个二维累加器 `A(x_c, y_c)`，用于投票可能的参考点位置。
3.  对于新图像中的每一个边缘点 `(x, y)` 及其方向 `φ`：
    *   查找R表中方向为 `φ` 的所有位移向量 `r`。
    *   对于每一个 `r`，计算一个可能的参考点位置：`候选中心 = (x, y) - r`。
    *   在累加器 `A` 中，为该候选中心位置投票。
4.  在累加器 `A` 中寻找峰值。峰值的位置 `(x_c, y_c)` 就是新图像中该形状最可能出现的参考点（如质心）位置。

通过这种方式，即使形状发生了平移，我们也能找到它。如果考虑旋转和缩放，参数空间会变得更加复杂（需要增加角度和尺度维度），但基本原理不变。

## 霍夫变换的优缺点

### 优点
*   **对遮挡鲁棒**：只要可见部分能提供足够多的正确投票，即使物体部分被遮挡也能检测。
*   **对噪声鲁棒**：噪声点通常随机投票，难以形成显著的峰值，而真正的形状会产生集中的高投票区域。
*   **能检测多个实例**：参数空间中的多个峰值对应图像中的多个相同形状。

### 缺点
*   **计算量大**：参数空间的维度随形状参数增加而指数增长，量化精度与计算成本需要权衡。
*   **参数选择敏感**：累加器量化间隔（分辨率）的选择会影响检测的精度和性能。
*   **对非解析形状准备复杂**：广义霍夫变换需要预先构建R表。

## 总结

本节课中我们一起学习了霍夫变换，这是一种通过投票机制在参数空间中检测形状的强大工具。我们从基础的直线和圆形检测入手，理解了其核心的“图像空间点 ↔ 参数空间曲线”对偶思想。进而，我们探讨了广义霍夫变换，它通过构建R表，使得检测任意已知形状成为可能。尽管存在计算成本较高的挑战，但霍夫变换因其对噪声和部分遮挡的鲁棒性，在计算机视觉的许多基础任务中，如车道线检测、圆形物体计数等，仍然被广泛使用。
