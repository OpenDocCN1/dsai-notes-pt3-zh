在本节课中，我们将深入学习反向传播算法的具体细节。我们将从定义损失函数和符号开始，逐步推导出反向传播的数学公式，并最终得到一个完整的神经网络训练算法。我们将确保每一步都清晰易懂，并使用公式和代码来阐明核心概念。

## 概述

上一节我们介绍了前馈神经网络的基本结构。本节中，我们将探讨如何训练这个网络，核心方法是结合梯度下降和链式法则的反向传播算法。我们将学习如何计算网络中每个参数的梯度，并使用这些梯度来更新参数，从而最小化损失函数。

## 损失函数定义

首先，我们需要定义一个衡量网络预测好坏的函数，即损失函数。假设我们有一个包含 `M` 个训练样本的数据集 `{(x_i, y_i)}`，网络的所有权重和偏置参数集合为 `θ`。

对于一个单独的样本 `(x, y)`，我们使用均方误差作为损失函数。网络对输入 `x` 的输出记为 `h_θ(x)`，则单个样本的损失 `L(θ; x, y)` 为：

`L(θ; x, y) = 1/2 * (h_θ(x) - y)^2`

这里引入系数 `1/2` 纯粹是为了后续求导时的数学简便性，它不会改变使损失最小化的参数 `θ`。

对于整个训练集，总成本函数 `J(θ)` 是所有样本损失的平均值：

`J(θ) = 1/M * Σ_{i=1}^{M} L(θ; x_i, y_i)`

我们的目标就是找到一组参数 `θ`，使得 `J(θ)` 最小。

## 符号约定与正向传播

为了清晰地描述反向传播，我们需要建立一套符号系统。

*   假设网络共有 `N_l` 层。
*   用 `a_i^{(l)}` 表示第 `l` 层第 `i` 个神经元的**激活值**（即该神经元的输出）。
*   用 `w_{ij}^{(l)}` 表示连接第 `l` 层第 `j` 个神经元到第 `l+1` 层第 `i` 个神经元的**权重**。
*   用 `b_i^{(l)}` 表示第 `l+1` 层第 `i` 个神经元的**偏置**。
*   用 `z_i^{(l)}` 表示第 `l` 层第 `i` 个神经元的**加权输入**，即 `z_i^{(l)} = (Σ_j w_{ij}^{(l-1)} * a_j^{(l-1)}) + b_i^{(l-1)}`。
*   激活函数记为 `f(·)`，因此 `a_i^{(l)} = f(z_i^{(l)})`。

基于以上符号，一个三层网络的正向传播过程可以用向量化形式简洁地表示：

`z^{(2)} = W^{(1)} * x + b^{(1)}`
`a^{(2)} = f(z^{(2)})`
`z^{(3)} = W^{(2)} * a^{(2)} + b^{(2)}`
`a^{(3)} = f(z^{(3)}) = h_θ(x)`

这个过程从输入层开始，逐层计算，直到得到输出层的激活值，称为**正向传播**。

## 反向传播算法原理

在正向传播得到输出 `h_θ(x)` 后，我们可以计算损失。反向传播的目标是计算损失函数 `J(θ)` 关于网络中每一个权重 `w` 和偏置 `b` 的梯度（偏导数），即 `∂J/∂w` 和 `∂J/∂b`。有了梯度，我们就可以使用梯度下降法更新参数：

`w_{new} = w_{old} - η * (∂J/∂w)`
`b_{new} = b_{old} - η * (∂J/∂b)`

其中 `η` 是学习率。

反向传播的核心思想是**链式法则**。损失是网络输出的函数，而输出又是每一层权重和输入的函数。因此，计算损失对底层参数的梯度需要将梯度从输出层向输入层反向传递。

## 误差项 δ 的定义与计算

为了便于计算，我们为网络中的每个神经元引入一个中间量——**误差项** `δ_i^{(l)}`。它定义为损失函数关于该神经元加权输入 `z_i^{(l)}` 的偏导数：

`δ_i^{(l)} = ∂J / ∂z_i^{(l)}`

这个误差项衡量了该神经元对最终损失应负的“责任”。

**1. 输出层 (第 `N_l` 层) 的误差**

对于输出层的第 `i` 个神经元，其误差可以直接计算。以均方误差损失为例：

`δ_i^{(N_l)} = ∂J / ∂z_i^{(N_l)} = (∂J / ∂a_i^{(N_l)}) * (∂a_i^{(N_l)} / ∂z_i^{(N_l)})`

其中：
*   `∂J / ∂a_i^{(N_l)} = (a_i^{(N_l)} - y_i)` （对于带 `1/2` 系数的均方误差）
*   `∂a_i^{(N_l)} / ∂z_i^{(N_l)} = f'(z_i^{(N_l)})`，即激活函数在 `z_i^{(N_l)}` 处的导数。

因此：
`δ_i^{(N_l)} = (a_i^{(N_l)} - y_i) * f'(z_i^{(N_l)})`

**2. 隐藏层 (第 `l` 层) 的误差**

对于隐藏层的神经元，其误差 `δ_i^{(l)}` 不能直接计算，但可以通过其后一层 (`l+1` 层) 的误差反向传播得到：

`δ_i^{(l)} = ( Σ_{j} w_{ji}^{(l)} * δ_j^{(l+1)} ) * f'(z_i^{(l)})`

这个公式的含义是：第 `l` 层第 `i` 个神经元的误差，等于所有以它为输入的下一层神经元误差的加权和（权重是连接它们的参数 `w_{ji}`），再乘上该神经元自身激活函数的导数。

## 计算权重和偏置的梯度

一旦我们有了每一层神经元的误差项 `δ`，计算梯度就变得非常简单。

损失函数关于权重 `w_{ij}^{(l)}` 的梯度为：
`∂J / ∂w_{ij}^{(l)} = a_j^{(l)} * δ_i^{(l+1)}`

损失函数关于偏置 `b_i^{(l)}` 的梯度为：
`∂J / ∂b_i^{(l)} = δ_i^{(l+1)}`

直观理解：权重 `w_{ij}^{(l)}` 连接了第 `l` 层的激活输出 `a_j^{(l)}` 和第 `l+1` 层的误差 `δ_i^{(l+1)}`，因此梯度是这两者的乘积。偏置的输入可以看作恒为1的激活值，所以其梯度就是误差本身。

## 完整的反向传播算法

现在，我们可以将上述步骤整合成一个完整的算法，用于在单个训练批次上计算所有参数的梯度。

以下是算法的步骤：

1.  **初始化梯度累加器**：将所有权重梯度 `∇W^{(l)}` 和偏置梯度 `∇b^{(l)}` 初始化为零。
2.  **对每个训练样本 `(x, y)`**：
    a. **正向传播**：输入 `x`，计算并保存每一层的 `z^{(l)}` 和 `a^{(l)}`，直到得到输出 `h_θ(x)`。
    b. **计算输出层误差**：`δ^{(N_l)} = (a^{(N_l)} - y) ⊙ f'(z^{(N_l)})`，其中 `⊙` 表示逐元素相乘。
    c. **反向传播误差**：对于 `l = N_l-1, N_l-2, ..., 2`，计算：
       `δ^{(l)} = ( (W^{(l)})^T * δ^{(l+1)} ) ⊙ f'(z^{(l)})`
    d. **计算并累加梯度**：对于每一层 `l`，计算该样本贡献的梯度并累加：
       `∇W^{(l)} += δ^{(l+1)} * (a^{(l)})^T`
       `∇b^{(l)} += δ^{(l+1)}`
3.  **计算平均梯度**：所有样本处理完毕后，计算整个批次的平均梯度：
    `∇W^{(l)} = (1/M) * ∇W^{(l)}`
    `∇b^{(l)} = (1/M) * ∇b^{(l)}`

现在，我们得到了损失函数 `J(θ)` 关于所有参数 `W` 和 `b` 的梯度 `∇W` 和 `∇b`。

## 参数更新与训练循环

获得梯度后，我们使用梯度下降法更新参数：

`W^{(l)} = W^{(l)} - η * ∇W^{(l)}`
`b^{(l)} = b^{(l)} - η * ∇b^{(l)}`

将“正向传播 -> 反向传播计算梯度 -> 参数更新”这三个步骤循环进行，直到损失函数收敛到最小值或达到预定的训练轮数，就完成了一个神经网络的训练过程。

## 总结

本节课中，我们一起深入学习了反向传播算法。我们从定义损失函数开始，引入了误差项 `δ` 的概念，并推导了其从输出层到隐藏层的反向传播公式。利用误差项，我们能够高效地计算出损失函数关于所有权重和偏置的梯度。最后，我们将这些步骤整合成一个完整的训练算法，该算法通过反复迭代正向传播、反向传播和参数更新，使神经网络能够从数据中学习。

反向传播是深度学习得以成功的基石，它使得训练复杂的多层神经网络成为可能。理解其原理对于后续学习更高级的模型和技巧至关重要。
