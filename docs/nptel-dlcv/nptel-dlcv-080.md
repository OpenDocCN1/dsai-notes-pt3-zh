## 神经网络简史

神经网络的历史或许比计算本身的历史更为悠久。它始于20世纪40年代初，当时研究人员McCulloch和Pitts致力于开发人脑的计算模型，并利用该模型模拟逻辑门等简单功能。

随后在20世纪40年代，心理学家Donald Hebb提出了至今仍在使用的Hebb学习法则。Hebb学习法则指出，在人脑中，两个同步激活的神经元之间的连接会增强，而两个不同步激活的神经元之间的连接则会减弱。

到了20世纪50年代，Frank Rosenblatt提出了第一个神经网络模型，称为感知机。感知机是最简单的神经网络，它接收一组输入，通过一组权重进行处理，然后输出一个经过阈值处理的最终决策。

在20世纪60年代初，Widrow和Hoff改进了学习规则，提出了Widrow-Hoff学习规则或Delta学习规则，这为当今使用的算法奠定了基础。然而，Rosenblatt声称感知机可以处理任何二元分类问题，但Minsky和Papert在20世纪60年代后期通过异或门的例子反驳了这一观点，这导致了神经网络在70年代的衰落。

20世纪80年代，随着1980年Neocognitron（被认为是卷积神经网络的雏形）的发展，以及1986年Rumelhart、Hinton和Williams提出的革命性反向传播算法，人们对神经网络的兴趣再次复兴。在80年代和90年代中期，卷积神经网络等变体被开发出来，并应用于手写数字识别等问题。

在90年代中期至21世纪初，支持向量机等传统机器学习算法占据了主导地位。直到21世纪中期，Geoffrey Hinton和Ruslan Salakhutdinov提出了分层特征学习算法，为深度学习的革命播下了种子。2012年，Alex Krizhevsky开发的AlexNet在ImageNet挑战赛中取得显著优势，标志着深度学习黄金时代的到来。

## McCulloch-Pitts神经元模型

McCulloch是一位神经科学家，Pitts是一位逻辑学家，他们在1943年提出了一个简单的神经元计算模型。该模型的工作原理如下：

设有一个函数 **G**，用于聚合一组输入（当时均为二进制输入）。另有一个函数 **F**，根据聚合结果做出决策。输入在当时被认为是兴奋性的（1）或抑制性的（0或-1）。函数 **G** 表示为对各个输入的求和，最终输出 **y** 由 **F(G(x))** 给出，其中向量 **x** 表示输入空间的不同维度。

输出规则为：如果 **G(x) > θ**，则输出为1；如果 **G(x) < θ**，则输出为0。这可以用以下公式表示：
```
y = 1 if Σ(x_i) > θ
y = 0 if Σ(x_i) < θ
```

以下是使用McCulloch-Pitts神经元模拟不同逻辑功能的几个例子：

*   **AND函数**：设置阈值 θ = 3。仅当所有三个输入 x1, x2, x3 均为1时，求和才大于3，神经元输出1。
*   **OR函数**：设置阈值 θ = 1。只要 x1, x2, x3 中任意一个为1，求和就大于等于1，神经元输出1。
*   **NOR函数**：使用抑制性输入（标记为带圈的输入）。只要有一个抑制性输入激活（为1），输出就为0。
*   **NOT函数**：使用单个抑制性输入，并设置阈值 θ > 0，即可模拟非门。

可以看到，使用McCulloch-Pitts神经元可以模拟大多数逻辑函数。事实上，可以证明，虽然不是单个神经元，但由McCulloch-Pitts神经元组成的前馈网络可以计算任何从n维布尔输入到布尔输出的函数。

## 感知机模型

Frank Rosenblatt在1958年提出了感知机模型，这是对McCulloch-Pitts神经元的推广。现在，输入不再局限于布尔值，可以是任何实数值。此外，每个输入都通过一组权重 **W1** 到 **Wn** 进行加权。

数学上，感知机可以表示为：函数 **G** 接收一个n维输入向量 **x**，其输出是权重向量 **W** 与输入向量 **x** 的内积，即 **G(x) = W·x**。最终输出 **y = F(G(x))**，规则为：如果 **G(x) > θ** 则输出1，否则输出0。

另一种更常见的写法是将阈值 θ 吸收到权重中。我们引入一个额外的常数值输入 **x0 = 1**，并对应一个权重 **w0**。这样，求和从 i=0 到 n，其中 **w0** 实际上代表了 **-θ**。此时，决策规则简化为：如果 **Σ(w_i * x_i) >= 0** 则输出1，否则输出0。这对应于一条将输入空间分为两半的决策线（或超平面），其方程为 **W·x = 0**。

## 感知机学习算法

感知机学习算法用于确定合适的权重 **W**。假设我们有一个数据集，包含正类样本集 **P**（标签为1）和负类样本集 **N**（标签为0）。

以下是算法的步骤：

1.  随机初始化权重向量 **W**。
2.  循环执行以下步骤，直到收敛（即所有样本都被正确分类）：
    *   从 **P** 或 **N** 中随机选取一个数据点 **x**。
    *   如果 **x** 属于 **P**（正类），但当前感知机输出 **W·x < 0**（错误分类），则更新权重：**W = W + x**。
    *   如果 **x** 属于 **N**（负类），但当前感知机输出 **W·x >= 0**（错误分类），则更新权重：**W = W - x**。
    *   如果样本被正确分类，则权重保持不变。

## 算法原理直观理解

为什么这样更新权重是有效的？关键在于权重向量 **W** 与决策超平面 **W·x = 0** 垂直。对于一个属于正类 **P** 的点，我们希望 **W·x >= 0**，这意味着向量 **x** 与 **W** 之间的夹角应小于90度。

如果当前 **W·x < 0**（错误分类），说明夹角大于90度。通过执行 **W_new = W + x**，可以证明新的夹角 **α_new** 将小于旧的夹角 **α**。这是因为：
```
cos(α_new) ∝ (W + x)·x = W·x + x·x
```
由于 **x·x**（向量模长的平方）总是正数，因此 **cos(α_new) > cos(α)**，这意味着 **α_new < α**。因此，更新后的权重使该正类样本更可能被正确分类。

对于负类样本的情况可以进行类似分析，更新规则 **W = W - x** 会使误分类的负类样本与 **W** 的夹角变大（超过90度），从而促使其被正确分类。

该算法在每次迭代中都会改善权重，并且在线性可分的数据集上可以证明是收敛的。
