在本节课中，我们将学习卷积神经网络中的反向传播。我们将探讨如何计算卷积层和池化层的梯度，这是训练CNN的关键步骤。

## 卷积层反向传播

上一节我们介绍了卷积神经网络的基本概念。本节中，我们来看看如何对卷积层执行反向传播。我们将从一个简化的场景开始推导。

### 问题设定与符号定义

我们假设输入是单通道灰度图像，即输入通道数 `C=1`。同时，我们只考虑一个卷积滤波器，其尺寸为 `K1 x K2`。输入图像尺寸为 `n1 x n2`，输出特征图 `y` 的尺寸为 `m1 x m2`。

根据卷积定义，输出 `y` 中位置 `(i, j)` 的元素可以表示为：
```
y[i, j] = Σ_{a=0}^{K1-1} Σ_{b=0}^{K2-1} x[i-a, j-b] * w[a, b]
```
注意，这里为了简化表达式，我们假设滤波器从输入像素的角落开始对齐，但这不影响推导的本质。

给定损失函数 `L`，我们需要计算两个关键梯度：
1.  **∂L/∂w**：损失相对于滤波器每个权重的梯度。
2.  **∂L/∂x**：损失相对于输入图像每个像素的梯度，以便将误差继续反向传播到更早的层。

### 计算损失相对于滤波器权重的梯度 (∂L/∂w)

首先，我们考虑滤波器中的一个特定权重 `w[a', b']`。我们需要计算损失 `L` 相对于这个权重的梯度 `∂L/∂w[a', b']`。

在卷积操作中，一个特定的滤波器权重会影响输出特征图 `y` 中的**每一个**像素。因为每次卷积运算中，该权重都会与输入图像中不同位置的像素相乘，并累加到对应的输出像素上。

因此，根据链式法则，`∂L/∂w[a', b']` 需要对所有输出像素的贡献求和：
```
∂L/∂w[a', b'] = Σ_i Σ_j (∂L/∂y[i, j]) * (∂y[i, j]/∂w[a', b'])
```
其中，`∂L/∂y[i, j]` 是通过反向传播从后续层已知的梯度。

现在，我们需要计算 `∂y[i, j]/∂w[a', b']`。根据卷积定义 `y[i, j] = Σ_a Σ_b x[i-a, j-b] * w[a, b]`，当我们对特定的 `w[a', b']` 求偏导时，求和式中只有包含 `w[a', b']` 的那一项（即 `a=a'`, `b=b'` 时）的导数不为零。因此：
```
∂y[i, j]/∂w[a', b'] = x[i-a', j-b']
```

将这个结果代回总梯度公式：
```
∂L/∂w[a', b'] = Σ_i Σ_j (∂L/∂y[i, j]) * x[i-a', j-b']
```

观察这个公式，它实际上是输入 `x` 与来自上一层的梯度 `∂L/∂y` 进行**卷积**运算的结果。这意味着在反向传播时，计算滤波器权重的梯度可以通过一次卷积操作高效完成。

### 计算损失相对于输入像素的梯度 (∂L/∂x)

接下来，我们考虑输入图像中的一个特定像素 `x[i', j']`。我们需要计算损失 `L` 相对于这个像素的梯度 `∂L/∂x[i', j']`。

一个输入像素 `x[i', j']` 会影响输出特征图 `y` 中的一个局部区域 `P`。这个区域由滤波器的尺寸决定：当滤波器滑过输入时，像素 `x[i', j']` 会与滤波器的不同部分相乘，并贡献给输出中从 `(i', j')` 到 `(i'+K1-1, j'+K2-1)` 的矩形区域内的所有像素。

因此，根据链式法则，`∂L/∂x[i', j']` 需要对受其影响的所有输出像素的贡献求和：
```
∂L/∂x[i', j'] = Σ_{(i, j) ∈ P} (∂L/∂y[i, j]) * (∂y[i, j]/∂x[i', j'])
```
其中，区域 `P` 包含所有受 `x[i', j']` 影响的输出像素位置。

现在计算 `∂y[i, j]/∂x[i', j']`。考虑一个受影响的输出像素 `y[i'+a, j'+b]`，根据卷积定义：
```
y[i'+a, j'+b] = Σ_{a'=0}^{K1-1} Σ_{b'=0}^{K2-1} x[i'+a - a', j'+b - b'] * w[a', b']
```
当对 `x[i', j']` 求偏导时，只有当 `i'+a - a' = i'` 且 `j'+b - b' = j'`，即 `a' = a` 且 `b' = b` 时，对应的项 `w[a, b] * x[i', j']` 的导数才不为零。因此：
```
∂y[i'+a, j'+b] / ∂x[i', j'] = w[a, b]
```

将这个结果代回总梯度公式：
```
∂L/∂x[i', j'] = Σ_{a=0}^{K1-1} Σ_{b=0}^{K2-1} (∂L/∂y[i'+a, j'+b]) * w[a, b]
```

观察这个公式，它实际上是来自上一层的梯度 `∂L/∂y` 与滤波器 `w` 进行**互相关**运算的结果。这等价于将滤波器旋转180度后与 `∂L/∂y` 进行卷积。因此，计算输入像素的梯度也可以通过一次（互相关）卷积操作高效完成。

## 池化层反向传播

上一节我们推导了卷积层的反向传播。本节中，我们来看看如何对池化层执行反向传播。池化层没有可训练参数，因此我们只需要计算损失相对于其输入的梯度 `∂L/∂x`，以便误差能够继续反向传播。

以下是两种常见池化操作的反向传播方法：

### 最大池化 (Max Pooling)

在最大池化的前向传播中，我们从每个池化窗口（例如2x2）中选择最大值。

在反向传播时，我们采用“赢家通吃”的策略：
*   记录前向传播中每个池化窗口内最大值的位置（即“获胜神经元”）。
*   来自上一层的梯度 `∂L/∂y` 中，对应于该池化窗口输出位置的梯度，将**全部**传递给前一层中那个产生最大值的输入像素位置。
*   池化窗口内其他非最大值位置的输入像素，其接收到的梯度为0。

**示例**：假设一个2x2窗口的前向传播输出是6（来自左上角像素），那么反向传播时，输出位置6的梯度将全部传递给输入层的左上角像素。

### 平均池化 (Average Pooling)

在平均池化的前向传播中，我们计算每个池化窗口内所有值的平均值。

在反向传播时，我们采用“平均分配”的策略：
*   来自上一层的梯度 `∂L/∂y` 中，对应于该池化窗口输出位置的梯度，将被**均匀地**分配给前一层中该窗口内的所有输入像素。

**示例**：对于一个2x2的窗口，输出位置的梯度将被除以4，然后平均分配给窗口内的四个输入像素。

## 总结

本节课中我们一起学习了卷积神经网络中反向传播的核心机制：

1.  **对于卷积层**：我们推导了损失相对于滤波器权重 `(∂L/∂w)` 和输入 `(∂L/∂x)` 的梯度公式。关键发现是，这些梯度计算都可以通过卷积（或互相关）运算高效完成，这充分利用了卷积操作的数学性质和硬件优化。
2.  **对于池化层**：我们学习了最大池化和平均池化的反向传播规则。最大池化将梯度路由回前向传播中的“获胜者”，而平均池化则将梯度平均分配给池化窗口内的所有输入。
