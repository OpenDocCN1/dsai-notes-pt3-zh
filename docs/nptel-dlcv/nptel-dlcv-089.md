在本节课中，我们将要学习改进神经网络训练的三个核心组件：权重初始化、Xavier/Glorot初始化方法的推导，以及批归一化技术。这些技术对于稳定训练、加速收敛和提升模型性能至关重要。

## 权重初始化的重要性

上一节我们讨论了优化器和学习率，本节中我们来看看另一个关键因素：权重初始化。

神经网络开始学习前，必须首先用特定值初始化权重，然后执行梯度下降。这非常重要，因为神经网络的误差曲面可能非常复杂，起始点决定了最终会收敛到哪个局部最小值。为了达到更好的局部最小值，可能需要从一个更好的初始位置开始。

一个简单的问题是：能否将所有权重初始化为零？答案是否定的。任何恒定的权重初始化方案效果都很差。

以下是一个例子来解释原因。考虑一个具有两个隐藏单元的神经网络，使用ReLU激活函数，偏置设为零，所有权重初始化为常数α。前向传播时，两个隐藏单元的输出将是 `R(α*x1 + α*x2)`。由于权重相同，两个隐藏单元将具有相同的输出，对损失函数产生相同的影响，进而获得相同的梯度。如果梯度相同，权重更新也将相同，导致权重在训练过程中始终保持一致。这不是我们期望的。

因此，我们需要一种比简单使用相同值初始化权重更有效的方法。

## 如何初始化权重

权重通常被随机初始化，例如从高斯分布中采样，以确保权重具有多样性。但需要注意，过大或过小的权重都可能导致Sigmoid或Tanh等激活函数饱和。

在2006年，权重初始化是推动深度神经网络受到关注的主要因素之一。Salakhutdinov和Hinton引入了一种称为“贪婪逐层无监督预训练”的方法。该方法建议在开始训练深度神经网络之前，先使用无监督技术（如受限玻尔兹曼机或自编码器）逐层训练网络以初始化权重。这种方法在几年内被认为是使深度神经网络在实践中工作的关键。

然而，如今人们理解到，有更简单的权重初始化方法可以达到同样好的效果，因此不再需要这种复杂的方法。

## 现代初始化方法的思路

为了理解新初始化方法的思路，我们考虑一个神经网络。假设所有输入都已归一化为均值为0、方差为1。同时假设权重均值为0，并具有某个未知的方差，我们的目标是找到这个方差。

考虑一个神经元 `a1`，其输出为 `a1 = Σ_{i=1}^{n} W_i1 * x_i`，其中 `n` 是输入数量（也称为“扇入”）。假设 `W` 和 `x` 不相关，且我们希望所有神经元具有相同的方差，那么 `a1` 的方差可以推导为 `Var(a1) = n * Var(W) * Var(x)`。

我们希望每一层激活值的方差都保持为1，以确保网络中的信号不会爆炸或消失。因此，我们要求 `n * Var(W) * 1 = 1`，即 `Var(W) = 1 / n`。

这意味着，为了良好的初始化，可以从均值为0、方差为 `1/n` 的高斯分布中采样权重，或者从均匀分布中采样并进行相应缩放。

基于这个思路，发展出了几种权重初始化方法。

以下是目前最流行的两种方法：

*   **Xavier/Glorot初始化**：从范围 `[-√6/√(fan_in + fan_out), +√6/√(fan_in + fan_out)]` 的均匀分布中采样权重。
*   **He初始化**：从范围 `[-√6/√(fan_in), +√6/√(fan_in)]` 的均匀分布中采样权重（针对ReLU激活函数优化）。

## Xavier初始化的推导

我们之前推导出，在前向传播中，希望 `Var(W) = 1 / fan_in`。然而，在反向传播（误差反向传播）过程中，梯度流也会受到影响。为了保持梯度流的稳定，同样希望 `Var(W) = 1 / fan_out`（`fan_out` 是神经元输出到下一层的权重数量）。

因此，一个折中的方案是取两者的平均值：`Var(W) = 2 / (fan_in + fan_out)`。

现在，从范围 `[-a, +a]` 的均匀分布中采样，其方差为 `a² / 3`。

令 `fan_in * (a² / 3) = 1`，可解得 `a = √3 / √fan_in`。这是仅考虑前向传播的情况。

同时考虑前向和反向传播，我们使用平均方差 `2 / (fan_in + fan_out)`。令 `(fan_in + fan_out)/2 * (a² / 3) = 1`，可解得 `a = √6 / √(fan_in + fan_out)`。这就是Xavier初始化的均匀分布范围。

He初始化建立在此基础之上，但针对ReLU激活函数的特性进行了调整，其推导是留给读者的练习。

## 批归一化

现在，让我们进入本讲的最后一个重要组件：批归一化。这是2015年提出的一项重要发展。

**协变量偏移**是机器学习中的一个问题，指的是训练和测试场景之间输入分布的变化。在神经网络内部，这表现为**内部协变量偏移**，即数据分布在网络各层之间发生变化。即使第一层输入是归一化的，由于权重的作用，后续各层的输入分布也会不断变化，网络必须学习处理这些不同的分布。

我们知道，当网络输入经过白化或归一化（即线性变换为均值为0、方差为1）时，网络训练效果更好。那么，能否对每一层的输入都进行类似的归一化呢？

**批归一化** 提供了解决方案。由于我们使用小批量数据训练神经网络，可以计算每一层输出在一个小批量上的均值和方差，然后用它们来归一化该层的激活值。

具体来说，对于给定层在某个小批量的输出值，计算其均值 `μ_B` 和方差 `σ_B²`。然后进行归一化：`x̂_i = (x_i - μ_B) / √(σ_B² + ε)`，其中 `ε` 是一个很小的数，用于数值稳定性。

但是，强制使每一层都具有零均值和单位方差可能会限制网络的表达能力。因此，批归一化引入了两个可学习的参数 `γ` 和 `β`。归一化后的最终输出为：`y_i = γ * x̂_i + β`。这样，网络可以通过学习 `γ` 和 `β` 来恢复数据的原始分布，或找到最有利于训练的新分布。

批归一化层通常插入在仿射变换层和激活函数之间。

批归一化的好处包括：
*   **允许使用更高的学习率**：因为它控制了激活值的尺度，减少了梯度爆炸或消失的风险。
*   **降低对初始化的强依赖**：无论初始权重如何，`γ` 和 `β` 可以在训练中调整分布。
*   **起到轻微的正则化作用**：因为每个批次的均值和方差是基于该批次数据估计的，为激活值添加了噪声。

一个重要的细节是：在测试时，我们可能没有小批量数据（例如，单样本预测）。此时，我们使用在训练过程中计算得到的 `μ_B` 和 `σ_B²` 的移动平均值来进行归一化。
