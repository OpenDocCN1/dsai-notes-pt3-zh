## 卷积层的反向传播

本讲大部分内容改编自佐治亚理工学院Bartra博士的优秀讲座。

为简化说明，我们假设一个灰度图像，即输入通道数 `C = 1`。这不会影响推导本身，只是让解释更简单。同时，我们假设卷积滤波器的数量为1，这意味着输出图的深度也为1。但每个卷积都会遵循相同的步骤来计算其梯度。

首先，考虑一个单一的卷积滤波器。假设该滤波器尺寸为 `K1 x K2`。它被应用于一个尺寸为 `N1 x N2` 的图像，得到一个尺寸为 `M1 x M2` 的输出 `y`。

从视觉上看，这是你的空间：输入 `X`，滤波器 `W`，输出 `y`。

根据卷积的定义，我们知道输出 `y` 中的一个元素 `y[i][j]` 可以写为：
`y[i][j] = Σ (a=0 to K1-1) Σ (b=0 to K2-1) x[i-a][j-b] * w[a][b]`

注意，这里我们没有将滤波器中心对准输入像素，而是对准一个角。这无关紧要，只是为了简化表达式，使后续推导更容易理解。

现在我们有一个用于训练CNN的损失函数 `L`。对于我们的卷积层，需要计算两个量：
1. `∂L/∂w`：损失相对于每个滤波器中每个权重的梯度。
2. `∂L/∂x`：损失相对于输入图像每个像素的梯度，因为这是进一步反向传播到更早层所必需的。

我们将尝试使用链式法则推导这些量的梯度。

### 计算权重梯度 (∂L/∂w)

让我们从 `∂L/∂w` 开始，即损失相对于滤波器权重的梯度。

为此，考虑卷积滤波器中的一个特定权重。假设你的滤波器 `W` 是 `K1 x K2` 维的，其中一个值为 `w[a‘][b’]`。我们现在想计算损失相对于该特定权重的梯度，然后可以推广到滤波器中的所有权重。

要计算这个，让我们问一个问题：如果你在卷积层中使用了一个滤波器 `W`，那么该特定权重值会影响输出层 `Y` 中的多少个像素以及哪些像素？因为请记住，反向传播的方式是：一个特定像素在下一层中影响的所有值，我们必须将所有那些梯度累积回该特定像素的梯度。这是我们在前馈神经网络中看到的。

所以在这种情况下，问题是：如果我们取权重 `w[a‘][b’]`，它会影响下一层特征图中的哪些像素？答案是 `Y` 中的每一个像素。因为 `y` 中的每个像素都是滤波器与 `x` 中某个位置卷积的结果。虽然 `y` 中的某个像素只依赖于 `x` 中的少数像素，但它确实依赖于 `w` 中的每个值。所以输出中的每个像素都对应于滤波器与输入重叠的一个位置，输出中的每个像素都是输入图像一部分的加权和，但滤波器中的权重会影响输出中的每个像素。

现在，我们继续推导。我们写出：
`∂L/∂w[a‘][b’] = Σ (i, j 遍历 y 的所有维度) [ ∂L/∂y[i][j] * ∂y[i][j]/∂w[a‘][b’] ]`

记住 `y` 的维度是 `M1 x M2`，所以我们必须对所有梯度求和。`∂L/∂y[i][j]` 是损失到下一层特征图中某个特定像素的梯度，我们假设它已通过反向传播直到该步骤而得知。

我们现在的挑战是计算 `∂y/∂w`。具体来说，是 `∂y[i][j]/∂w[a‘][b’]`。这就是我们现在必须计算的量，以计算损失相对于 `w[a‘][b’]` 的总梯度。

现在考虑那个特定的量：`∂y[i][j]/∂w[a‘][b’]`。

再次根据卷积的定义，我们有 `y[i][j]` 的表达式。使用这个，我们可以说 `∂y[i][j]/∂w[a‘][b’]` 可以写成对 `y[i][j]` 表达式求导。在所有求和中，只有一项依赖于 `w[a‘][b’]`。请记住，在一次卷积操作中，一个特定的滤波器值只与输入中的一个像素相乘。这个项就是 `w[a‘][b’] * x[i-a‘][j-b’]`。这个双重求和中的其他项，当对 `w[a‘][b’]` 求导时，将变为0，因为它们不依赖于 `w[a‘][b’]`。

因此，这个导数简单地变为 `x[i-a‘][j-b’]`。

让我们看看如何使用这个。把它代回原式，我们现在有：
`∂L/∂w[a‘][b’] = Σ (i, j) [ ∂L/∂y[i][j] * x[i-a‘][j-b’] ]`

仔细观察，这现在就是 `x` 和 `∂L/∂y` 的卷积。这很美妙。`∂L/∂y` 也具有 `y` 的维度，那组梯度看起来也像一幅图像，因为你有损失相对于 `y` 中每个像素的梯度。所以，这将形成一个矩阵，而 `x` 本身也是一个矩阵。`x` 和 `∂L/∂y` 的卷积就是 `∂L/∂w[a‘][b’]`。因此，你可以在反向传播步骤中将其计算为卷积。

### 计算输入梯度 (∂L/∂x)

现在让我们继续下一个量：`∂L/∂x`，即损失相对于该卷积层输入的梯度。

让我们再次考虑一个单一的输入像素 `x[i‘][j’]`。再次问一个问题：`y` 中的哪些像素会受到 `x` 中这个特定像素的影响？从视觉上看，我们可以说，给定一个 `x`，假设有一个由红色方块表示的像素 `x[i‘][j’]`。当它与 `W` 卷积时，它会影响从 `[i‘, j’]` 到 `[i‘+K1-1, j’+K2-1]` 的整个像素范围。为什么是这样？为什么不是以 `[i‘, j’]` 为中心？因为这是我们为了简单起见在此上下文中定义卷积的方式。如果我们定义卷积从 `-K1/2` 到 `+K1/2`，它就会是居中的。但由于我们定义卷积的方式，索引从0到 `K1-1` 和 `b` 到 `K2-1`，你现在会有由这个虚线方块表示的像素，这些是受 `[i‘, j’]` 影响的像素。

我们称这个区域为 `P`。我们现在知道，损失相对于这些像素的梯度将影响损失相对于这个像素的梯度。`y` 中的所有其他像素不受这个像素的影响，因此那些 `L` 相对于 `y` 的梯度对我们来说无关紧要。

现在，我们说：
`∂L/∂x[i‘][j’] = Σ (p 在区域 P 中) [ ∂L/∂y[p] * ∂y[p]/∂x[i‘][j’] ]`

从前一页的图中，我们现在可以将区域 `P` 定义为：`a` 从0到 `K1-1`，`b` 从0到 `K2-1`。对于特定像素 `y[i‘+a][j’+b]`，以及 `y[i‘+a][j’+b]` 相对于 `x[i‘][j’]` 的导数。

左边的量是已知的，因为我们假设所有 `∂L/∂y` 直到那时都是已知的。我们只关心如何计算跨单个卷积层的反向传播；如果有更多卷积层，将迭代应用相同的过程。但这里的第二个量目前我们不知道：`∂y[i‘+a][j’+b]/∂x[i‘][j’]`。

让我们尝试在下一页计算这个。

再次根据卷积的定义，我们有 `y[i‘][j’]` 的表达式。那么 `y[i‘+a][j’+b]` 的定义将是：将 `i‘` 替换为 `i‘+a`，将 `j’` 替换为 `j’+b`。所以 `i‘+a - a` 变成 `i‘`，`j’+b - b` 变成 `j’`，而 `w[a][b]` 保持不变。

现在，`y[i‘+a][j’+b]` 相对于 `x[i‘][j’]` 的导数将是那个单一项 `w[a][b]`。对于不同的 `a` 和 `b` 选择，它将是求和中的那个项。正如我们之前对另一个导数 `∂L/∂w` 所说的，求和中的其他项不会影响相对于一个特定 `[a,b]` 的导数。

所以，这就是我们得到的 `∂y` 在特定像素位置相对于 `∂x` 在 `[i‘, j’]` 的量。

现在把它代回去。我们有：
`∂L/∂x[i‘][j’] = Σ (a,b 在区域 P 中) [ ∂L/∂y[i‘+a][j’+b] * w[a][b] ]`

再次，这变得有趣起来，这看起来像是互相关的定义。它是 `∂L/∂y` 与滤波器 `W` 的互相关。或者，我们可以说它是翻转后的滤波器与 `∂L/∂y` 的卷积。我们知道互相关和卷积的区别在于滤波器的翻转（180度翻转，即两个方向上的翻转）。这就是我们现在在这里得到的：`∂L/∂y` 与一个双重翻转的滤波器进行双重卷积。

这再次有趣，因为即使是现在，跨卷积层计算 `∂L/∂x` 的链式法则也可以计算为卷积。

为什么这很重要？回想第一周关于图像频率的讨论，我们说过卷积可以通过非常高效的方法（如快速傅里叶变换）来评估。你可以使用所有这些方法在反向传播步骤中高效地计算这些梯度。

## 池化层的反向传播

现在我们剩下一个问题，这结束了如何跨卷积层进行反向传播的讨论。我们只有两个量 `W` 和 `x`。我们现在仍然需要知道如何跨池化层进行反向传播。

如前所述，池化层是无参数的。它没有任何权重。没有需要更新的梯度。我们必须计算的唯一梯度是相对于前一层中 `x` 的梯度，以允许梯度传播到更早的层。

我们如何做到这一点？如果我们有最大池化，让我们看右边这个视觉示例。

你可以在这里看到，这些红色、绿色、黄色和蓝色区域在前向传播中被最大池化。
1. `[1, 5, 6]`，最大值是6。
2. `[4, 7, 8]`，最大值是8。
3. `[3, 2, 1, 2]`，最大值是3。
4. `[1, 0, 3, 4]`，最大值是4。
所以，在前向传播中，对于每个 `2x2` 区域，取最大元素放在这里，然后通过后面的层继续传播。

反向传播步骤在同一层中，你跟踪每个 `2x2` 窗口中的获胜位置。例如，我们知道6来自第一个 `2x2` 窗口的这个位置。所以，无论我们在6处有什么梯度，当我们反向传播时，它都会去到前一层中的那个位置。请记住，反向传播是朝另一个方向进行的，但这是前一层。你在右边看到的是前一层。在6处的全部梯度（记住我们假设当反向传播到这一步时，每个像素的梯度都是已知的）全部去到那个位置，这个梯度全部去到那个位置，这个梯度全部去到那个位置，因为那是获胜神经元的位置，类似地，这个到这个。

如果我们不使用最大池化，而是使用平均池化呢？如果你使用平均池化，你会取进入一个特定位置（比如6的位置）的任何梯度，并将该梯度平均分配给这四个位置（在 `2x2` 池化的情况下）。如果你做了 `3x3` 池化，你会将其除以九份，分给九个像素。

在这种情况下，我们有 `2x2` 池化，所以无论你在6处有什么梯度，都会被分成4份，该梯度将给予导致6的 `2x2` 邻域中的每个像素。

这就是跨池化层进行反向传播的方式。

## 总结

![](img/b7ef8b2ba2c35dca43e272ae861b51a2_2.png)

本节课中，我们一起学习了卷积神经网络中的反向传播。我们推导了卷积层权重 `(∂L/∂w)` 和输入 `(∂L/∂x)` 的梯度计算公式，发现它们都可以通过卷积运算高效实现。对于池化层，我们了解了最大池化和平均池化在反向传播时的不同处理方式：最大池化将梯度路由回前向传播中“获胜”的神经元位置，而平均池化则将梯度均匀分配回池化窗口内的所有输入位置。这些原理是训练深层CNN的基础。
