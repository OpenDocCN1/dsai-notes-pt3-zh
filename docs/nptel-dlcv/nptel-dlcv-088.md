## 概述

在本节课中，我们将学习如何改进神经网络的训练过程。上一讲我们讨论了正则化及其对提升模型泛化性能的重要性。本节我们将聚焦于另一个关键组件：激活函数。我们将详细探讨不同激活函数的特性、优缺点，以及它们如何影响神经网络的训练效率和最终性能。

## 回顾：输入噪声与L2正则化

在深入新内容之前，我们先完成上一讲留下的练习：证明当损失函数为均方误差时，向输入添加零均值高斯噪声等价于L2权重衰减。

其核心直觉在于，当噪声通过一层网络时，其方差会被权重平方放大。对于一个简单的单层网络，放大后的噪声会直接加到输出上，并贡献到损失函数的平方误差项中，其效果类似于在损失函数中添加了一个L2惩罚项。

让我们进行数学推导。假设我们有一个输入 `x`，并为其添加了噪声 `ε`，其中 `ε` 服从均值为0、方差为 `σ²` 的高斯分布。那么带有噪声的输出 `y_noisy` 为：

`y_noisy = Σ_i (w_i * x_i) + Σ_i (w_i * ε_i)`

原始的干净输出为 `y = Σ_i (w_i * x_i)`。因此，新的均方误差期望值为：

`E[(y_noisy - t)²] = E[(y - t + Σ_i w_i ε_i)²]`

展开并利用期望的线性性质，同时注意到 `ε_i` 均值为0，交叉项期望为0，我们得到：

`E[(y_noisy - t)²] = (y - t)² + Σ_i (w_i² * σ²)`

由此可见，新的损失函数等于原始损失加上一项 `Σ_i (w_i² * σ²)`，这正是L2权重衰减项的形式，其系数由噪声方差 `σ²` 决定。

## 激活函数详解

现在，让我们进入本节课的核心主题：激活函数。在第一周的介绍中，我们简要提到了激活函数。现在我们将花更多时间深入理解每一种激活函数及其利弊。

激活函数是应用于神经网络中每个神经元输出的非线性函数。传统上，人们在整个网络或至少同一层中使用相同的激活函数。这样做主要是为了简化计算复杂度，便于利用高效的矩阵向量运算，而非为每个神经元单独计算。

### 激活函数的理想特性

那么，激活函数应具备哪些特性呢？以下是一些关键点：

*   **连续且可微**：这是反向传播计算梯度的基础。
*   **非递减（单调）**：理想情况下，我们希望输入增加时，输出不会高低波动，以保证梯度方向的稳定性。
*   **计算高效**：复杂的计算会拖慢整个网络的训练速度。

常见的激活函数包括Sigmoid、双曲正切（Tanh）、线性整流单元（ReLU）等。我们该如何选择？它们对训练有何具体影响？接下来我们将逐一分析。

以下是几种常见激活函数的快速回顾：

*   **Sigmoid**：早期用于解决感知机阈值问题的激活函数，是逻辑函数，形状呈S型。
*   **双曲正切（Tanh）**：也是一种逻辑函数，形状与Sigmoid相似，但值域为[-1, 1]。
*   **线性整流单元（ReLU）**：2012年随AlexNet提出，形式为 `max(0, x)`。
*   **渗漏线性整流单元（Leaky ReLU）**：ReLU的变体，当输入为负时，输出为一个小的斜率（如0.01）乘以输入，而非0。
*   **指数线性单元（ELU）**：为解决ReLU在0点的不连续性而提出，在负输入区域是平滑的指数函数。
*   **Maxout**：一种不太传统的激活函数，它对一组神经元的输出取最大值，可以看作是ReLU的泛化。

接下来，让我们更详细地探讨其中几种激活函数，理解它们如何影响神经网络训练。

### Sigmoid 激活函数

Sigmoid函数定义为 `σ(x) = 1 / (1 + e^{-x})`，它将所有输入压缩到(0,1)区间。其梯度为 `σ'(x) = σ(x) * (1 - σ(x))`。

尽管Sigmoid在80-90年代非常流行，但现在已不常用。原因如下：

1.  **梯度饱和**：当输入值很大或很小时，Sigmoid函数的曲线变得非常平缓。这意味着输入的巨大变化只会导致输出的微小变化，梯度接近于0。这会导致权重更新缓慢，甚至停止学习，即“梯度消失”问题。
2.  **非零中心化**：Sigmoid的输出值恒为正。这可能导致后续层神经元的输入全部为正，进而使得权重的梯度全部为正或全部为负（取决于共同的上一级梯度）。这种“锯齿状”的梯度更新路径会降低学习效率。
3.  **计算成本较高**：涉及指数运算。

考虑一个简单网络片段：输入`h1`, `h2`，权重`w1`, `w2`，预激活`a = w1*h1 + w2*h2`，经过Sigmoid激活后输出`y`。根据链式法则，`∂L/∂w1 = (∂L/∂y) * (∂y/∂σ) * (∂σ/∂a) * h1`。如果`h1`和`h2`来自前一层Sigmoid的输出，则它们恒为正。同时，`∂σ/∂a`也恒为正。因此，`w1`和`w2`的梯度符号完全由`(∂L/∂y) * (∂y/∂σ)`决定，这可能导致该层所有权重同时向相同方向更新，从而减慢学习速度。

### 双曲正切（Tanh）激活函数

Tanh函数定义为 `tanh(x) = (e^{x} - e^{-x}) / (e^{x} + e^{-x})`，它将输入压缩到[-1, 1]区间。其梯度为 `tanh'(x) = 1 - tanh²(x)`。

与Sigmoid相比，Tanh有一个主要优势：
*   **零中心化**：输出范围在-1到1之间，均值为0。这有助于缓解Sigmoid中因输出全正而导致的梯度更新问题，通常能使收敛更快。

然而，Tanh也有缺点：
*   **梯度饱和**：与Sigmoid类似，当输入绝对值很大时，Tanh函数也会饱和，梯度趋近于0，导致“梯度消失”。
*   **计算成本较高**：同样涉及指数运算。

### 线性整流单元（ReLU）激活函数

ReLU函数定义为 `ReLU(x) = max(0, x)`。其梯度为：当 `x > 0` 时，梯度为1；当 `x <= 0` 时，梯度通常被定义为0。

ReLU是当今最常用的激活函数，原因如下：
*   **缓解梯度饱和**：在正区间，ReLU是线性的，梯度恒为1，不存在饱和问题。这使得在正输入区域，梯度可以有效地反向传播。
*   **加速收敛**：在AlexNet中，使用ReLU比使用Sigmoid或Tanh使SGD的收敛速度加快了约6倍。
*   **计算极其高效**：只需一个阈值判断和取值操作。

但是，ReLU有一个著名的缺陷：**“神经元死亡”问题**。
如果某个神经元的输入加权和（预激活`a`）在训练过程中始终为负，那么经过ReLU后其输出恒为0。在反向传播时，该神经元的梯度（`∂ReLU/∂a`）也为0。这意味着流向该神经元权重的梯度被完全切断，这些权重将永远不会得到更新。该神经元在后续训练中持续输出0，如同“死亡”，不再对网络有任何贡献。

如何缓解“神经元死亡”问题？
1.  **使用带正偏置的初始化**：为正偏置设置一个较小的正值，有助于将初始预激活推向正区域。
2.  **使用ReLU的变体**：如Leaky ReLU或ELU。

### ReLU的变体：Leaky ReLU 与 ELU

*   **Leaky ReLU**：定义为 `LeakyReLU(x) = max(αx, x)`，其中α是一个小的正常数（如0.01）。在负输入区域，它允许一个很小的、非零的梯度通过（斜率为α），从而确保权重仍然能得到微小的更新，避免了完全的“神经元死亡”。
*   **指数线性单元（ELU）**：定义为：当 `x >= 0` 时，`ELU(x) = x`；当 `x < 0` 时，`ELU(x) = α(e^x - 1)`。ELU具有平滑的曲线，在负区域渐近于`-α`，同时保持了ReLU在正区域的线性特性。其平滑性可能使优化过程更稳定。

### 如何选择激活函数？

在实践中，可以遵循以下指南：
*   **默认首选ReLU**：它简单、高效且通常效果很好。需要监控网络中“死亡神经元”的比例。
*   **如果ReLU效果不佳**：可以尝试 **Leaky ReLU**、**ELU** 或 **Maxout**。
*   **Tanh** 可以尝试，但性能通常不如ReLU，取决于具体任务。
*   **Sigmoid** 在现代网络中已很少用于隐藏层，除非需要特定的“门控”效果或输出概率（如二分类输出层）。**Tanh** 也在某些需要输出有界值的场景中使用。

一个重要的经验是：**尽可能让激活函数工作在其线性区域**。例如，对于Sigmoid，你希望输入值大部分落在中间近似线性的区间。有时可以通过调整函数参数（如缩放）来扩大线性区域，以适应你数据的分布，这有助于改善训练性能。关于这些技巧，可以参考一篇名为《Efficient BackProp》的经典文献。

## 总结

本节课中，我们一起学习了改进神经网络训练的一个重要方面：激活函数。我们首先通过数学推导，理解了向输入添加高斯噪声在均方误差下等价于L2权重正则化。然后，我们深入探讨了多种激活函数（Sigmoid, Tanh, ReLU及其变体）的特性、优缺点及其对训练动态的影响，特别是梯度饱和和神经元死亡问题。最后，我们给出了在实际应用中如何选择激活函数的实用建议。理解这些内容将帮助你在构建神经网络时做出更明智的设计选择。
