# 斯坦福 CS224W 图机器学习笔记 01：图的基本表示 🧱

在本节课中，我们将要学习图的基本概念和表示方法。图是描述实体及其之间关系的强大数学结构，是图机器学习的基础。理解如何表示图是后续所有学习的第一步。

## 什么是图？

图由两个基本部分组成：节点和边。节点代表我们研究系统中的实体，边则代表这些实体之间的成对关系。例如，在社交网络中，节点可以是用户，边可以表示用户之间的“好友”关系。

## 图的数学定义

一个图 **G** 可以形式化地定义为：
**G = (V, E)**
其中：
*   **V** 是节点的集合。
*   **E** 是边的集合，每条边连接 **V** 中的两个节点。

如果边是无方向的（例如好友关系），我们称该图为**无向图**。如果边是有方向的（例如关注关系），我们称该图为**有向图**。

## 图的表示方法

上一节我们介绍了图的抽象定义，本节中我们来看看如何在计算机中具体地表示一个图。主要有两种核心的表示方法。

### 1. 邻接矩阵

邻接矩阵是一个方阵，用于描述图中节点之间的连接关系。对于一个有 **n** 个节点的图，其邻接矩阵 **A** 是一个 **n × n** 的矩阵。

矩阵元素 **A[i][j]** 的定义如下：
*   如果节点 **i** 和节点 **j** 之间存在边，则 **A[i][j] = 1**。
*   如果节点 **i** 和节点 **j** 之间不存在边，则 **A[i][j] = 0**。

对于无向图，邻接矩阵是对称的，即 **A[i][j] = A[j][i]**。

以下是邻接矩阵的一个简单代码示例（Python风格）：
```python
# 假设一个包含3个节点的无向图，边为 (0-1), (1-2)
n = 3
A = [[0, 1, 0],
     [1, 0, 1],
     [0, 1, 0]]
```

### 2. 邻接表

邻接矩阵在表示稀疏图（边数远小于可能的最大边数）时效率较低。邻接表提供了另一种更节省空间的表示方式。

邻接表为图中的每个节点维护一个列表，记录与该节点直接相连的所有邻居节点。

以下是邻接表的一个简单示例：
```
节点0: [1]
节点1: [0, 2]
节点2: [1]
```

## 节点与边的属性

在实际应用中，图和其组成部分通常具有丰富的属性信息。

*   **节点** 可以具有属性，例如用户的年龄、性别。
*   **边** 也可以具有属性，例如关系的强度、交互的频率。

这些属性通常用特征向量来表示。例如，所有节点的特征可以组合成一个节点特征矩阵 **X**。

## 图的类型

根据不同的特性，图可以分为多种类型。以下是几种常见的图类型：

*   **同质图**：图中只有一种类型的节点和一种类型的边。
*   **异质图**：图中包含多种类型的节点和/或多种类型的边。
*   **二部图**：节点可以被划分为两个不相交的集合，所有边都连接着来自不同集合的节点。
