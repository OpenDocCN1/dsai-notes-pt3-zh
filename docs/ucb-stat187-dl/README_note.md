## 1. 神经网络基础 🧠

上一节我们介绍了课程概述，本节中我们来看看神经网络的基本构成单元——神经元。

一个神经元接收多个输入信号，为每个输入分配一个权重，计算加权和后加上一个偏置项，最后通过一个非线性激活函数产生输出。这个过程可以用以下公式描述：

**公式：**
`z = w1*x1 + w2*x2 + ... + wn*xn + b`
`a = σ(z)`

其中，`x` 是输入，`w` 是权重，`b` 是偏置，`σ` 是激活函数（如Sigmoid函数），`a` 是神经元的输出。

---

## 2. 前向传播 ⏩

理解了单个神经元后，本节我们将探讨信息如何在网络中从输入层流向输出层，这个过程称为前向传播。

前向传播是指输入数据通过神经网络层层传递，最终得到预测结果的过程。对于多层网络，每一层的输出都是下一层的输入。

以下是计算一个三层网络输出的步骤：

1.  计算第一层（隐藏层1）的激活值：`a1 = σ(W1 * x + b1)`
2.  计算第二层（隐藏层2）的激活值：`a2 = σ(W2 * a1 + b2)`
3.  计算输出层的值：`y_hat = σ(W3 * a2 + b3)`

这里，`W` 和 `b` 分别代表各层的权重矩阵和偏置向量。

---

## 3. 损失函数与梯度下降 📉

上一节我们介绍了如何得到预测值，本节中我们来看看如何衡量预测值与真实值之间的差距，并据此调整模型参数。

损失函数用于量化模型预测的误差。对于二分类问题，常用二元交叉熵损失：

**公式：**
`L(y, y_hat) = - [y * log(y_hat) + (1-y) * log(1-y_hat)]`

我们的目标是找到一组参数（权重和偏置），使损失函数的值最小。梯度下降是实现这一目标的核心算法。它通过计算损失函数关于每个参数的梯度（导数），并沿梯度反方向更新参数。

参数更新规则如下：

**公式：**
`w = w - α * ∂L/∂w`
`b = b - α * ∂L/∂b`

其中，`α` 是学习率，控制每次更新的步长。

---

## 4. 反向传播算法 🔄

知道了要用梯度下降来优化，本节我们将学习如何高效地计算神经网络中所有参数的梯度，这就是反向传播算法。

反向传播是一种利用链式法则，从输出层开始反向计算损失函数对每一层参数的梯度的方法。其核心思想是将误差从输出层逐层向前传播，以分摊给每个参数。

以下是反向传播的关键步骤：

1.  进行前向传播，计算并保存每一层的激活值 `a` 和加权输入 `z`。
2.  计算输出层的误差 `δ`：`δ_output = ∂L/∂y_hat * σ‘(z_output)`。
3.  将误差反向传播至隐藏层：`δ_hidden = (W_next.T * δ_next) * σ‘(z_hidden)`。
4.  利用各层的误差 `δ` 计算梯度：`∂L/∂W = δ * a_prev.T`， `∂L/∂b = δ`。
