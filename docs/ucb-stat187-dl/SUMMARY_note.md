### 8. 基础概率论 🎲
概率论为理解模型的不确定性和进行统计推断提供基础。
*   **随机变量**：取值具有随机性的变量。
*   **概率分布**：描述随机变量取不同值的可能性，如离散分布 `P(X=x)` 和连续分布的概率密度函数 `p(x)`。
*   **期望与方差**：`E[X] = Σ x * P(X=x)`， `Var(X) = E[(X - E[X])^2]`。

朴素贝叶斯是一种基于贝叶斯定理的简单分类算法，它假设特征之间相互独立。

*   **分类决策**：对于输入X，选择使后验概率 `P(Y=k|X)` 最大的类别k。

### 16. 线性回归 📉
线性回归用于建模输入特征与连续值输出之间的线性关系。
*   **模型**：`y_hat = w1*x1 + w2*x2 + ... + b`。
*   **损失函数（均方误差）**：`L = (1/n) * Σ (y_i - y_hat_i)^2`。

### 17. 作业与项目物流 📝
说明课程作业和项目的具体要求、提交方式和评分标准。

### 18. 最大似然估计与最大后验估计 🎯
两种参数估计方法。
*   **最大似然估计（MLE）**：寻找使观测数据出现概率最大的参数。`θ_MLE = argmaxθ P(Data|θ)`。
*   **最大后验估计（MAP）**：在MLE基础上引入参数的先验分布。`θ_MAP = argmaxθ P(θ|Data) = argmaxθ P(Data|θ)P(θ)`。

### 19. 损失函数 ⚖️
损失函数衡量模型预测与真实值之间的差异，是模型优化的目标。
*   **平方损失**：用于回归。
*   **交叉熵损失**：用于分类，`L = -Σ y_i * log(p_i)`，其中 `y_i` 是真实标签，`p_i` 是预测概率。

### 20. 逻辑回归 🔮
逻辑回归用于二分类问题，通过Sigmoid函数将线性输出映射为概率。
*   **模型**：`p = σ(w^T x + b)`，其中 `σ(z) = 1 / (1 + exp(-z))`。
*   **决策**：若 `p >= 0.5` 预测为正类，否则为负类。

### 21. Jupyter中的逻辑回归 💾
实现并训练一个逻辑回归模型。

### 22. 信息论 📡
信息论为理解交叉熵损失和模型压缩提供了理论基础。
*   **熵**：衡量随机变量的不确定性。`H(X) = -Σ P(x) log P(x)`。
*   **交叉熵**：衡量两个概率分布之间的差异。`H(P, Q) = -Σ P(x) log Q(x)`。

### 23. 信息论回顾 🔍

### 24. Python中的Softmax分类 🍦
Softmax回归将逻辑回归推广到多分类问题。
*   **Softmax函数**：`softmax(z)_i = exp(z_i) / Σ_j exp(z_j)`，将输出转换为概率分布。
*   **代码示例**：在Gluon中，使用 `gluon.loss.SoftmaxCrossEntropyLoss()`。
