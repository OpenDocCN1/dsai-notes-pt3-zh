## 概述

在本节课中，我们将要学习深度学习的基本概念，特别是神经网络如何通过前向传播和反向传播进行学习和预测。我们将从最简单的线性模型开始，逐步引入非线性激活函数，并解释损失函数与梯度下降的核心原理。



## 1. 线性模型与激活函数 🧠

上一节我们介绍了课程概述，本节中我们来看看神经网络的基础构件：线性模型与激活函数。

一个最简单的神经网络单元是线性变换。它接收输入 `x`，乘以权重 `w`，加上偏置 `b`，得到输出 `z`。这个过程可以用公式表示：

**`z = w * x + b`**

然而，单纯的线性变换能力有限，无法学习复杂模式。因此，我们需要引入非线性激活函数。激活函数作用于线性变换的输出 `z` 上，为模型引入非线性。

以下是几种常见的激活函数：

*   **Sigmoid**: 将输入压缩到 (0, 1) 区间。公式为 **`σ(z) = 1 / (1 + e^{-z})`**。
*   **Tanh**: 将输入压缩到 (-1, 1) 区间。
*   **ReLU (整流线性单元)**: 目前最常用的激活函数，公式为 **`ReLU(z) = max(0, z)`**。



## 2. 损失函数与梯度下降 📉

上一节我们了解了如何通过激活函数引入非线性，但模型如何知道自己的预测是对是错呢？这就需要损失函数来衡量预测值与真实值之间的差距。

损失函数 `L` 量化了模型预测的错误程度。对于回归任务，常用均方误差 (MSE)；对于分类任务，常用交叉熵损失。

模型的目标是找到一组参数（权重和偏置），使损失函数的值最小化。梯度下降是实现这一目标的核心算法。其核心思想是：计算损失函数相对于每个参数的梯度（即导数），然后沿着梯度相反的方向更新参数，因为这是使损失下降最快的方向。

参数更新遵循以下公式：

**`w = w - α * (∂L/∂w)`**
**`b = b - α * (∂L/∂b)`**

其中，`α` 是学习率，控制每次更新的步长。



## 3. 反向传播算法 🔄

上一节我们介绍了梯度下降的概念，但有一个关键问题没有解决：在复杂的多层神经网络中，如何高效地计算损失函数对于所有参数的梯度？这就是反向传播算法要解决的问题。

反向传播是一种利用链式法则，从输出层向输入层反向计算梯度的高效方法。其过程可以概括为两个阶段：

以下是反向传播的两个主要步骤：

1.  **前向传播**：输入数据从网络第一层流向最后一层，计算每一层的输出以及最终的损失值。
2.  **反向传播**：损失值从最后一层反向流回第一层，利用链式法则计算损失函数相对于每一层参数的梯度。

通过反向传播计算出所有梯度后，我们就可以使用上一节介绍的梯度下降法来更新网络中的每一个权重和偏置。



## 4. 构建一个完整的神经网络 🏗️

前面几节我们分别学习了模型构件、优化目标和训练方法。现在，我们将把这些部分组合起来，看看如何构建并训练一个完整的神经网络。

一个典型的多层神经网络由以下部分组成：

以下是构建神经网络的关键组件：

*   **输入层**：接收原始数据。
*   **隐藏层**：包含一个或多个进行线性变换和非线性激活的层。
*   **输出层**：产生最终的预测结果。
*   **损失函数**：衡量预测误差。
*   **优化器**（如梯度下降）：根据梯度更新参数。

训练过程就是重复进行“前向传播计算损失 -> 反向传播计算梯度 -> 优化器更新参数”的循环，直到模型性能满足要求。



## 总结

本节课中我们一起学习了深度学习的基础知识。我们从最简单的线性模型出发，引入了激活函数来增加模型的表达能力。为了训练模型，我们定义了损失函数来衡量误差，并详细讲解了通过梯度下降和反向传播算法来优化模型参数的过程。最后，我们了解了如何将这些部分组合成一个完整的、可训练的多层神经网络。这些概念是理解所有现代深度学习模型的基石。
