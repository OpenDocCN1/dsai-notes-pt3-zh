# 斯坦福 CS221 人工智能导论笔记：第1课 - 什么是人工智能？🤖

在本节课中，我们将要学习人工智能的基本定义、核心目标以及其背后的主要思想。我们将探讨如何让机器像人一样思考、行动，并理解实现这一目标的不同路径。

## 概述

人工智能是计算机科学的一个分支。它致力于创造能够执行通常需要人类智能的任务的机器。这些任务包括学习、推理、问题解决、感知和理解语言。

## 人工智能的目标

上一节我们介绍了人工智能的基本定义，本节中我们来看看它的核心目标。人工智能的研究主要围绕两个互补的目标展开。

以下是人工智能的两个主要目标：

1.  **建造像人一样思考或行动的系统**：这个目标关注于模仿人类的认知过程和行为。例如，创建一个能通过图灵测试的聊天机器人。
2.  **建造能理性思考或行动的系统**：这个目标不强调模仿人类，而是追求在给定信息和目标下，做出最优或最合理的决策。例如，一个在国际象棋中计算出最佳落子的程序。

## 实现路径：结构与行为

理解了目标之后，我们自然会问：如何实现这些目标？实现路径可以从两个维度来观察：我们关心的是系统的内部结构，还是其外部行为。

以下是评估人工智能系统的两个关键维度：

*   **结构**：系统内部的工作原理是否与人类相似？例如，人工神经网络在某种程度上受到了生物神经元的启发。
*   **行为**：系统的外在表现是否与人类相似或达到理性标准？例如，一个翻译软件输出的译文准确流畅，我们并不关心里面是规则系统还是统计模型。

将目标与路径结合，就形成了人工智能研究的四个主要象限：像人一样思考（强调结构）、像人一样行动（强调行为）、理性思考（强调结构）、理性行动（强调行为）。现代人工智能更侧重于**理性行动**这一象限。

## 智能体与环境

无论选择哪条路径，我们都可以用一个统一的框架来思考人工智能系统：智能体与环境互动的模型。

一个智能体可以被定义为一个通过**传感器**感知环境、并通过**执行器**对环境施加影响的实体。其核心是**决策函数**，它根据感知序列来决定采取什么行动。

用简单的伪代码可以描述这个循环：
```
while True:
    percept = 从传感器获取感知()
    action = 决策函数(percept, 记忆)
    通过执行器执行(action)
    更新记忆
```

环境则提供了智能体行动的结果和新的感知。设计人工智能，很大程度上就是为特定环境设计一个优秀的决策函数。

## 课程地图

基于智能体模型，本课程将系统地介绍构建智能决策函数所需的核心组件。

以下是构建智能决策函数的主要模块：

1.  **模型**：智能体对世界如何运作的认知。可以表示为对状态、行动和结果之间关系的描述，例如转移概率 **P(s‘ | s, a)**。
2.  **奖励**：智能体追求的目标量化。通常是一个函数 **R(s)** 或 **R(s, a, s‘)**，用于评估状态或转换的好坏。
3.  **规划**：在已知模型和奖励的前提下，计算出一系列行动以达到目标（如最大化累积奖励）。
4.  **学习**：当模型和奖励未知时，智能体通过与环境互动（经历 `(s, a, r, s‘)` 这样的序列）来自主发现它们。
5.  **推理**：在部分可观察的环境中，智能体需要根据不完整的感知信息来推断世界的真实状态，即维护一个**信念状态**。

## 总结

本节课中我们一起学习了人工智能的广阔图景。我们明确了其目标是建造能像人或理性实体一样思考与行动的系统，并引入了智能体与环境互动的核心范式。最后，我们勾勒出了本课程的知识地图：**模型**、**奖励**、**规划**、**学习**和**推理**这五大支柱，它们共同构成了设计人工智能系统的基础。在接下来的课程中，我们将对这些组件进行深入探讨。
