在本节课程中，我们将学习随机变量期望与方差的三个重要关系。这些关系在后续课程中会非常有用。

上一节我们介绍了独立性与联合密度函数。本节中，我们来看看期望与方差的一些重要性质。

以下是三个核心关系，我们将逐一介绍。

1.  **期望的线性性**：对于任意两个随机变量 **X** 和 **Y**，无论它们是否相关，都有：
    **E[X + Y] = E[X] + E[Y]**
    这个性质可以推广到任意多个随机变量。

2.  **独立随机变量乘积的期望**：如果随机变量 **X** 和 **Y** 相互独立，那么对于任意函数 **f** 和 **g**，有：
    **E[f(X) * g(Y)] = E[f(X)] * E[g(Y)]**
    特别地，当 **f** 和 **g** 是恒等函数时，即 **E[X * Y] = E[X] * E[Y]**。

![](img/3fea5443582cdd1202b95ca303a409ee_5.png)

![](img/3fea5443582cdd1202b95ca303a409ee_6.png)

![](img/3fea5443582cdd1202b95ca303a409ee_8.png)

3.  **独立随机变量和的方差**：如果随机变量 **X₁, X₂, ..., Xₙ** 相互独立，那么：
    **Var(X₁ + X₂ + ... + Xₙ) = Var(X₁) + Var(X₂) + ... + Var(Xₙ)**
    注意，这个性质要求随机变量相互独立。

![](img/3fea5443582cdd1202b95ca303a409ee_10.png)

接下来，我们将详细证明第三个关系，即独立随机变量和的方差公式。

证明过程如下。设 **X₁, X₂, ..., Xₙ** 相互独立。记 **μᵢ = E[Xᵢ]**。

![](img/3fea5443582cdd1202b95ca303a409ee_12.png)

![](img/3fea5443582cdd1202b95ca303a409ee_14.png)

![](img/3fea5443582cdd1202b95ca303a409ee_16.png)

![](img/3fea5443582cdd1202b95ca303a409ee_17.png)

首先，根据期望的线性性，和的期望等于期望的和：
**E[∑ᵢ Xᵢ] = ∑ᵢ μᵢ**

根据方差的定义，我们有：
**Var(∑ᵢ Xᵢ) = E[(∑ᵢ Xᵢ - ∑ᵢ μᵢ)²] = E[(∑ᵢ (Xᵢ - μᵢ))²]**

展开平方项：
**E[(∑ᵢ (Xᵢ - μᵢ))²] = E[∑ᵢ (Xᵢ - μᵢ)² + 2 * ∑ᵢ∑ⱼ (i≠j) (Xᵢ - μᵢ)(Xⱼ - μⱼ)]**

![](img/3fea5443582cdd1202b95ca303a409ee_19.png)

![](img/3fea5443582cdd1202b95ca303a409ee_21.png)

![](img/3fea5443582cdd1202b95ca303a409ee_23.png)

再次利用期望的线性性，上式等于：
**∑ᵢ E[(Xᵢ - μᵢ)²] + 2 * ∑ᵢ∑ⱼ (i≠j) E[(Xᵢ - μᵢ)(Xⱼ - μⱼ)]**

其中，第一项 **E[(Xᵢ - μᵢ)²]** 正是 **Xᵢ** 的方差 **Var(Xᵢ)**。

![](img/3fea5443582cdd1202b95ca303a409ee_25.png)

![](img/3fea5443582cdd1202b95ca303a409ee_27.png)

对于第二项中的交叉项 **E[(Xᵢ - μᵢ)(Xⱼ - μⱼ)]**，由于 **Xᵢ** 和 **Xⱼ** 独立，根据独立随机变量乘积的期望性质，有：
**E[(Xᵢ - μᵢ)(Xⱼ - μⱼ)] = E[Xᵢ - μᵢ] * E[Xⱼ - μⱼ]**

而 **E[Xᵢ - μᵢ] = E[Xᵢ] - μᵢ = 0**。因此，所有的交叉项期望值均为零。

![](img/3fea5443582cdd1202b95ca303a409ee_29.png)

![](img/3fea5443582cdd1202b95ca303a409ee_30.png)

![](img/3fea5443582cdd1202b95ca303a409ee_32.png)

于是，我们得到：
**Var(∑ᵢ Xᵢ) = ∑ᵢ Var(Xᵢ)**

![](img/3fea5443582cdd1202b95ca303a409ee_33.png)

![](img/3fea5443582cdd1202b95ca303a409ee_34.png)

证明完毕。

本节课中我们一起学习了随机变量期望与方差的三个核心性质：期望的线性性、独立变量乘积的期望性质以及独立变量和的方差可加性。这些是概率论和后续机器学习课程中非常重要的基础工具。
