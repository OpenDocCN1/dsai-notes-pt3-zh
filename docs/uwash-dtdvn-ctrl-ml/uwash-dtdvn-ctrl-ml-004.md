在本节课中，我们将学习线性状态空间模型在坐标变换下的变化规律。这是理解后续“平衡模型降阶”技术的关键基础。我们将看到，通过一个特殊的坐标变换矩阵 **T**，可以改变系统的动态方程及其可控性与可观性格拉姆矩阵的表示形式。

## 坐标变换对系统动态的影响

上一节我们介绍了模型降阶的高层目标。本节中，我们来看看如何通过坐标变换来改变系统的表示。

假设我们有一个线性时不变系统，其状态空间方程为：
```
ẋ = A x + B u
y = C x
```
我们引入一个新的状态变量 **z**，通过一个可逆的方阵 **T** 进行坐标变换：
```
x = T z
```
其中，**T** 是一个 n×n 的可逆矩阵。我们的目标是将原系统方程用新的状态 **z** 来表示。

以下是推导新系统方程的步骤：
1.  将 `x = T z` 代入原状态方程：`T ż = A T z + B u`
2.  方程两边同时左乘 **T⁻¹**，得到关于 **ż** 的方程：`ż = T⁻¹ A T z + T⁻¹ B u`
3.  输出方程变为：`y = C T z`

因此，在新坐标 **z** 下，系统的状态空间矩阵变为：
```
Â = T⁻¹ A T
B̂ = T⁻¹ B
Ĉ = C T
```
新的系统方程为：
```
ż = Â z + B̂ u
y = Ĉ z
```
如果变换矩阵 **T** 的列向量是标准正交的（即 **TᵀT = I**），那么其逆矩阵就等于其转置（**T⁻¹ = Tᵀ**），计算会更为简便。

## 坐标变换对格拉姆矩阵的影响

理解了动态方程的变换后，我们更需要知道坐标变换如何影响衡量系统特性的可控性与可观性格拉姆矩阵。这对于我们后续设计特殊的 **T** 矩阵至关重要。

可控性格拉姆矩阵 **W_c** 衡量了输入 **u** 影响状态 **x** 的能力。可观性格拉姆矩阵 **W_o** 衡量了从输出 **y** 观测状态 **x** 的能力。

经过推导（过程涉及积分和矩阵指数运算），我们可以得到在新坐标 **z** 下，这两个格拉姆矩阵的变换关系。以下是核心结论：

在新坐标系下，可控性与可观性格拉姆矩阵分别为：
```
Ŵ_c = T⁻¹ W_c T^(-*) 
Ŵ_o = T* W_o T
```
其中，符号 `*` 表示复共轭转置。对于实数系统，这就是普通的转置 `ᵀ`。`T^(-*)` 表示 `(T⁻¹)ᵀ`。

这个结论非常有力。它告诉我们，通过选择合适的坐标变换矩阵 **T**，我们可以重塑系统的可控性和可观性“椭球”。我们的目标就是找到一个特殊的 **T**，使得变换后的两个格拉姆矩阵不仅相等，而且是对角矩阵：
```
Ŵ_c = Ŵ_o = Σ = diag(σ₁, σ₂, ..., σ_n)
```
其中，对角线元素 **σ_i**（称为 Hankel 奇异值）按从大到小排列。**σ₁** 对应系统中最容易被控制也最容易被观测的状态方向，而 **σ_n** 对应最难以控制和观测的方向。

这就为我们提供了一种清晰的模型降阶方法：保留对应前 **k** 个最大奇异值的状态（即最联合可控与可观的方向），截断其余部分。我们将从 **T** 中选取前 **k** 列构成降阶变换矩阵 **Ψ**，从而实现从高维状态 **x** 到低维状态 **x̃** 的映射。

本节课中我们一起学习了坐标变换如何改变线性系统的动态方程及其可控/可观性格拉姆矩阵。我们得到了变换后的矩阵（**Â, B̂, Ĉ**）和格拉姆矩阵（**Ŵ_c, Ŵ_o**）的表达式。关键在于，存在一个特殊的平衡变换 **T**，能使 **Ŵ_c** 和 **Ŵ_o** 同时化为相等的对角阵 **Σ**，这为下一步的平衡截断模型降阶奠定了理论基础。下一节，我们将具体探讨如何找到这个神奇的 **T** 矩阵。
