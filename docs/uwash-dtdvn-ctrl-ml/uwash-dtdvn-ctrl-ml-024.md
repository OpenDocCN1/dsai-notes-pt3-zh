在本节课中，我们将学习如何利用库普曼算子框架进行带控制的系统辨识。我们将探讨如何将非线性动力学系统嵌入线性框架，并介绍两种主要的控制方法。

上一节我们讨论了基于全状态测量的系统辨识，本节中我们来看看如何将库普曼算子框架应用于控制问题。

库普曼算子框架的核心思想是：如果我能获得一组足够丰富的输出测量值 `Y`（它可能比全状态 `x` 更庞大，例如包含 `x`、`x²`、`sin(x)` 等非线性测量），那么我就可以将非线性动力学嵌入到一个线性框架中。这非常有用，因为一旦系统呈现线性形式，我们就可以使用简单的线性最优控制方法，如LQR或卡尔曼滤波。带控制的库普曼方法的承诺正在于此：只要找到正确的测量函数 `Y(x)`，就能将强非线性动力学转化为线性形式，从而轻松应用各种控制策略，如线性控制或模型预测控制。

我将介绍带控制的库普曼方法的几种不同思路。首先，我喜欢从特征函数的角度来思考。

## 特征函数方法

这里的思路是，我们首先考虑无输入（`U=0`）的非受迫系统，并找到其特征函数 `φ(x)`。这些是系统的特殊测量值，可以认为是“非常好”的测量坐标，使得 `d/dt φ(x)` 是纯线性的，即满足 `d/dt φ = λ φ(x)`。在后续课程中，我们会讨论如何通过数据驱动的方法发现这些好的测量坐标 `φ(x)`，但现在我们假设已经拥有了一些这样的坐标。

一个很好的例子是保守系统，其哈密顿量（总守恒能量）`H(x)` 就是一个特征函数，对应的特征值 `λ=0`，因为 `dH/dt = 0`。

现在，假设我们有一个动力学系统：
`ẋ = f(x) + Bu`
这里，我将系统分解为一个非线性非受迫动力学部分 `f(x)` 和一个附加的线性控制项 `Bu`。这种形式比处理完全非线性的控制项更易于理解库普曼控制的工作原理。

接下来，我们对特征函数 `φ(x)` 的时间导数应用链式法则：
`d/dt φ = ∇φ · ẋ = ∇φ · (f(x) + Bu)`
如果我们只考虑非受迫动力学（`u=0`），那么 `d/dt φ = ∇φ · f(x) = λ φ`。因此，我们可以将上式中的 `∇φ · f(x)` 替换为 `λ φ`，得到：
`d/dt φ = λ φ + (∇φ · B) u`
这本质上就是我们的控制系统。在特征函数坐标 `φ` 下，状态动力学 `φ̇ = λ φ` 是纯线性的，而控制项 `(∇φ · B) u` 则被称为**状态依赖的驱动**，因为 `∇φ · B` 是状态 `x` 的函数。这意味着新的 `B` 向量随状态空间变化。

所以，我们在特征函数坐标中仍然拥有线性动力学，但驱动对特征函数的影响取决于当前状态 `x`。

这是由 Erika Kaiser、Nathan Kutz 和我本人完成的工作。她证明，如果你能识别出这些库普曼特征函数 `φ`，就可以直接在这些特征函数坐标中使用上述方程和所谓的**状态依赖的Riccati方程**进行控制。状态依赖的Riccati方程是标准LQR控制的一个微小修改，适用于这种状态依赖的驱动 `B(x)`。

对于许多系统，如果能通过数据驱动的回归找到这些好的坐标 `φ`，就可以直接在这些坐标中进行控制。这非常有用，例如在哈密顿系统或任何具有守恒量的系统中，你可以设计最优控制律来引导那个守恒量。

我们通常从状态空间的角度思考问题，例如，对于小车上的摆杆，我们想通过使 `θ` 和 `θ̇` 为零来稳定它。但你可能也会考虑系统具有总能量，也许你想做的是将能量提升到垂直位置然后稳定它。因此，像总能量或守恒角动量这样的特征函数坐标，有时可能是比原始状态空间更好的坐标系来编写控制律。你可以使用标准LQR Riccati方程方法的基本修改版本来获得最优非线性控制器。这是Erika展示的一个非常强大的方法，也是我们利用库普曼进行系统辨识，并修改它以考虑驱动和控制项 `+Bu` 的新方法之一。

## 扩展动态模式分解方法

社区中的其他人采取了不同的路径。许多人不是直接在特征函数中进行控制，而是采用所谓的替代路线。

以下是具体做法：
我可以取一个庞大的测量向量 `Y`（它比我的状态 `x` 更大，可能包含状态的非线性测量），并假设系统满足：
`Y_{k+1} = K Y_k + B u_k`
本质上，你可以在这个增广的测量向量上运行带控制的动态模式分解算法，这被称为**扩展DMD**。如果没有控制，就是扩展DMD；当加入控制时，就称为**带控制的扩展DMD**。

这是由 Matt Williams、Clancy Rowley 等人完成的工作，旨在直接从数据中获取系统模型 `K` 和 `B`。然后，你可以将这个模型用于线性控制或模型预测控制。例如，Milan Korda 和 Igor Mezić 最近发表了一篇论文，正是在这些庞大的测量向量 `Y` 上使用带控制的扩展DMD，然后直接将这些模型用于模型预测控制，效果也非常好。

## 两种方法的比较与联系

以上是你可以理解带控制的库普曼方法的两个主要类别：
1.  第一种是在所有增广测量值上建立一个大的 `K` 模型，然后使用带控制的动态模式分解从数据中识别它，并用于模型预测控制。
2.  第二种是尝试直接发现库普曼算子的这些特征函数。需要指出的是，这里的 `φ` 是库普曼算子的特征函数，即 `K φ = λ φ`。因此，这些是库普曼算子的直接特征函数。

然后，与其控制 `Y` 中的所有方向，我可以专注于只想控制的那些感兴趣的特征函数方向（如总角动量、总能量），并使用状态依赖的Riccati方程来实现控制。

本节课中，我们一起学习了如何利用库普曼算子框架处理带控制的系统辨识。我们探讨了通过寻找特征函数将非线性系统在特定坐标下线性化的方法，以及通过扩展测量向量并应用DMDc来直接建立线性模型的方法。这两种方法都为我们提供了强大的工具，能够对复杂的非线性系统应用成熟且高效的线性控制理论。
