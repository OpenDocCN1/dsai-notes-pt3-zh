在本节课中，我们将学习如何设计一个坐标变换矩阵 **T**，以实现格拉姆矩阵的平衡。我们将从回顾之前的内容开始，逐步推导出平衡变换的公式，并解释其背后的数学原理。最后，我们将了解如何利用这个变换进行模型降阶。

## 回顾与目标

上一节我们介绍了在坐标变换下，系统的可控性格拉姆矩阵 **Wc** 和可观测性格拉姆矩阵 **Wo** 如何变化。本节中，我们将寻找一个特殊的变换矩阵 **T**，使得在新坐标系下，这两个格拉姆矩阵不仅相等，而且是对角矩阵。

具体来说，我们的目标是找到一个变换 **T**，使得：
**Wc_hat = Wo_hat = Σ**
其中，**Σ** 是一个对角矩阵，其对角线元素 **σ₁, σ₂, ...** 从大到小排列。这意味着第一个状态方向是“最可控且最可观测”的，第二个次之，依此类推。

## 推导平衡变换

为了找到这个变换 **T**，我们从新坐标系下的格拉姆矩阵定义出发，并进行一些数学推导。

首先，我们写出变换后的格拉姆矩阵：
**Wc_hat = T⁻¹ Wc T⁻***  
**Wo_hat = T* Wo T**

我们希望它们相等且等于 **Σ**，即：
**Wc_hat = Wo_hat = Σ**

一个关键的步骤是考虑这两个矩阵的乘积：
**Wc_hat * Wo_hat**

将上面的定义代入：
**Wc_hat * Wo_hat = (T⁻¹ Wc T⁻*) * (T* Wo T)**

注意到 **T⁻* * T*** 是单位矩阵，因此中间项抵消，得到：
**Wc_hat * Wo_hat = T⁻¹ Wc Wo T**

现在，代入我们的目标 **Wc_hat = Wo_hat = Σ**：
**Σ * Σ = T⁻¹ Wc Wo T**  
即：
**Σ² = T⁻¹ (Wc Wo) T**

这是一个非常重要的形式。我们在等式两边左乘 **T**，得到：
**Wc Wo T = T Σ²**

这个等式看起来非常熟悉。它正是**特征分解**的公式：
**A V = V Λ**
在这里，矩阵 **A = Wc Wo**，其特征向量矩阵是 **T**，特征值矩阵是 **Λ = Σ²**。

因此，**平衡变换矩阵 T 就是原坐标下乘积矩阵 Wc Wo 的特征向量矩阵**，而平衡后的格拉姆矩阵 **Σ** 的对角线元素，就是这些特征值的平方根（因为 **Σ²** 的对角线是特征值）。

在MATLAB中，这可以通过一行代码实现：
`[T, Sigma_squared] = eig(Wc * Wo);`

## 处理缩放问题

然而，这里存在一个细微之处。特征向量可以任意缩放（例如乘以2），它仍然是特征向量。这意味着我们直接得到的 **T** 可能不是最终想要的平衡变换。

具体来说，如果我们用未缩放的 **T_u** 进行变换，可能会得到：
**Wc_hat = Σ_c** 和 **Wo_hat = Σ_o**
这里 **Σ_c** 和 **Σ_o** 都是对角矩阵，但它们的值可能不成比例（例如一个是另一个的4倍），尽管它们的乘积仍然是 **Σ²**。

为了确保变换后两个格拉姆矩阵完全相等（**Σ_c = Σ_o = Σ**），我们需要对特征向量进行适当的缩放。

以下是缩放的方法：
1.  首先，使用未缩放的特征向量 **T_u** 计算变换后的格拉姆矩阵，得到 **Σ_c** 和 **Σ_o**。
2.  构造一个缩放矩阵 **Σ_s**，其对角线元素为：
    **σ_s_i = (σ_c_i)^(1/4) * (σ_o_i)^(-1/4)**
3.  最终的平衡变换矩阵为：
    **T = T_u * Σ_s**

经过这个缩放步骤后，在新坐标系下，我们就能得到：
**Wc_hat = Wo_hat = Σ**
其中 **Σ** 的对角线元素是 **σ_i = sqrt(σ_c_i * σ_o_i)**。

## 总结与应用

本节课中我们一起学习了**平衡变换**的核心内容。

*   **核心结论**：存在一个坐标变换 **T**，能将系统的可控性与可观测性格拉姆矩阵变得相等且对角化。这个 **T** 可以通过计算 **Wc * Wo** 的特征分解得到。
*   **关键步骤**：在获得特征向量后，需要进行额外的缩放处理，以确保两个格拉姆矩阵完全相等，而不仅仅是它们的乘积相等。
*   **重要意义**：平衡变换后的状态空间，其坐标轴按照“联合可控可观测”的程度从高到低排列。第一个状态方向能量传递效率最高，最后一个最低。

这为我们下一步的**模型降阶**奠定了坚实基础。在接下来的课程中，我们将：
1.  在MATLAB中实现这个平衡变换，并通过示例验证其效果。
2.  利用这个变换，通过截断（只保留前 **r** 个最重要的状态方向）来获得一个低维的、但能捕获主要输入输出动态的降阶模型。

这就是Moore在1981年提出的平衡截断法的精髓。我们即将进入实践环节。
