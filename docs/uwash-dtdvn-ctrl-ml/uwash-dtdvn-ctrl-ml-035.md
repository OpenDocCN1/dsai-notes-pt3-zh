### 连接控制回路

![](img/826eff8663e22102965578208d02af6a_134.png)

![](img/826eff8663e22102965578208d02af6a_135.png)

![](img/826eff8663e22102965578208d02af6a_136.png)

![](img/826eff8663e22102965578208d02af6a_138.png)

我们按照极值搜索控制的结构图进行连接。在Simulink中，这就像点击箭头并拖拽到目标位置一样简单。

![](img/826eff8663e22102965578208d02af6a_140.png)

![](img/826eff8663e22102965578208d02af6a_141.png)

![](img/826eff8663e22102965578208d02af6a_143.png)

![](img/826eff8663e22102965578208d02af6a_145.png)

![](img/826eff8663e22102965578208d02af6a_147.png)

![](img/826eff8663e22102965578208d02af6a_149.png)

1.  首先，将目标函数 `F(u)` 的输出连接到高通滤波器，同时也连接到一个示波器以测量输出 `J`。
2.  将高通滤波器的输出连接到乘法模块的一个输入端。
3.  将正弦波模块的输出连接到同一个乘法模块的另一个输入端。这样，高通滤波后的输出就与正弦波相乘了。
4.  乘法模块的输出（即解调后的信号）经过一个增益模块（代表积分器增益 `K`）后，送入积分器模块。积分器的输出是我们的最优估计值 `û`。
5.  将 `û` 与来自正弦波模块的扰动信号相加。
6.  加法器的输出即为最终的控制输入 `u`，它被送入目标函数 `F(u)`，形成闭环。
7.  将 `u` 连接到另一个示波器进行观测。

![](img/826eff8663e22102965578208d02af6a_153.png)

我们使用一个简单的静态目标函数进行演示，其公式为：
`J = 25 - (5 - u)^2`
这个函数在 `u = 5` 时取得最大值 `J = 25`，其形状是一个抛物线。在用户定义函数模块中，我们可以直接输入这个表达式。

我们需要设置一些初始参数：
*   **初始条件**：将积分器模块的初始条件设为 `û = 0`，这是一个足够次优的起点，便于观察收敛过程。
*   **正弦扰动**：假设扰动幅度为 `0.2`，频率为 `10 Hz`（即 `10*2π` 弧度/秒）。在实际系统中，这些参数通常由硬件决定（如DC-AC转换器产生的纹波），可能无法随意更改。
*   **可调参数**：我们主要可以调整的是**积分器增益 `K`** 和**高通滤波器的截止频率 `ω_h`**。

首先运行仿真。如果发现性能不佳，例如收敛速度太慢，第一个调整策略就是增加积分器增益 `K`。例如，将 `K` 从 `1` 增加到 `5`，可以观察到目标函数 `J` 以更快的速度上升并接近最优值。

![](img/826eff8663e22102965578208d02af6a_245.png)

![](img/826eff8663e22102965578208d02af6a_247.png)

![](img/826eff8663e22102965578208d02af6a_248.png)

![](img/826eff8663e22102965578208d02af6a_249.png)

![](img/826eff8663e22102965578208d02af6a_251.png)

然而，`K` 并非越大越好。如果将 `K` 增加到 `20`，虽然仿真中收敛极快，但控制信号 `u` 的波形可能变得粗糙、不一致，这暗示系统可能处于稳定性的边缘。在实际物理系统中，噪声或微小延时可能导致其失稳。因此，我们需要在仿真中寻找一个稳健的增益值，例如 `K = 10`。

### 调整高通滤波器

![](img/826eff8663e22102965578208d02af6a_259.png)

![](img/826eff8663e22102965578208d02af6a_260.png)

![](img/826eff8663e22102965578208d02af6a_262.png)

![](img/826eff8663e22102965578208d02af6a_263.png)

![](img/826eff8663e22102965578208d02af6a_265.png)

接下来调整高通滤波器。其传递函数应为 `s / (s + ω_h)`。截止频率 `ω_h` 的设计需要权衡：
*   它应**低于**扰动频率（本例为 `10 Hz`），以确保纹波信号能有效通过。如果 `ω_h` 太高，会衰减输出纹波，等效于降低了增益。
*   它又不能**过低**，否则系统响应中的快速上升沿也会通过滤波器，可能引起稳定性问题。

![](img/826eff8663e22102965578208d02af6a_267.png)

![](img/826eff8663e22102965578208d02af6a_268.png)

![](img/826eff8663e22102965578208d02af6a_270.png)

因此，`ω_h` 需要设置在扰动频率和其他可能引起不稳定的频率之间。例如，将 `ω_h` 从 `1` 增加到 `5`（弧度/秒），可以获得更平滑、更稳定的收敛曲线，稳态误差带也很小。

![](img/826eff8663e22102965578208d02af6a_286.png)

![](img/826eff8663e22102965578208d02af6a_288.png)

1.  **易于实现**：在Simulink中构建极值搜索控制器非常简单快捷。这种拖放式、模块化的方式大大减轻了仿真负担，让你能快速构建和测试复杂的控制律。
2.  **适用于模拟电路**：所示架构非常适合于模拟控制设计。你可以用正弦波发生器、积分器和高通滤波器等模拟元器件实际搭建这个电路，并将其作为“黑盒”附件连接到你的物理系统上进行连续时间控制。
3.  **调试思路**：对于给定的系统和扰动，主要的可调参数是积分器增益 `K` 和高通滤波器截止频率 `ω_h`。通常的调试步骤是：先粗略设置 `ω_h`（例如为扰动频率的1/10），然后重点调整 `K` 以获得接近期望的动态性能；最后再微调 `ω_h` 来优化稳定性和稳态误差。如果你还能调整扰动本身的幅度和频率，那么就有更多的优化空间。
