## 遗传编程的基本概念

遗传编程是一种进化算法，它通过模拟自然选择的过程，自动生成和优化计算机程序或函数结构。在控制领域，我们用它来寻找传感器测量值 `y` 与执行信号 `u` 之间的有效函数关系 `u = F(y)`。

控制律被定义为一个嵌套的函数树。树的叶子节点是传感器测量值 `y` 和常数 `C`，内部节点则是各种数学运算（如加、减、乘、除等）。通过组合这些元素，可以生成一个候选控制律。

例如，一个函数树可以解释为以下控制律：
```
u = y1 + C3 * (C1 + y2)
```
这个控制律可以在实验中进行测试，评估其性能。

有趣的是，这种策略不仅用于设计控制律，也被用于系统辨识，即发现物理系统的动力学方程 `ẋ = F(x)`。

## 遗传编程的操作流程

![](img/dea65dc61096896d9aa1821fc698ba10_9.png)

以下是遗传编程优化控制律的核心步骤。

![](img/dea65dc61096896d9aa1821fc698ba10_11.png)

首先，随机生成一个包含多个（例如100个）不同函数树的初始种群。每个树代表一个候选控制律。

接着，在实验或仿真中测试每一个控制律，并计算其性能指标（即成本函数 `J` 的值）。性能好的个体（控制律）将获得更高的“适应度”。

![](img/dea65dc61096896d9aa1821fc698ba10_13.png)

然后，利用遗传操作从当前种群中产生新一代的个体。主要的遗传操作有三种：

1.  **交叉**：选择两个性能优秀的个体，交换它们函数树中的某个分支。这旨在结合两个优秀个体的有利特性。
2.  **变异**：随机选择一个个体，将其函数树中的某个分支替换为一个随机生成的新子树。这有助于探索新的、可能更好的控制律结构。
3.  **复制**：直接将性能优秀的个体复制到下一代，以确保好的基因不会丢失。

这些操作的概率需要预先设定，例如交叉概率70%、变异概率20%、复制概率10%。通过多代迭代，种群中的控制律会不断进化，性能逐渐提升。

## 遗传编程控制的应用框架

![](img/dea65dc61096896d9aa1821fc698ba10_15.png)

![](img/dea65dc61096896d9aa1821fc698ba10_16.png)

整个遗传编程控制的应用框架可以概括为一个闭环优化过程。

![](img/dea65dc61096896d9aa1821fc698ba10_18.png)

![](img/dea65dc61096896d9aa1821fc698ba10_19.png)

![](img/dea65dc61096896d9aa1821fc698ba10_20.png)

我们有一个待控制的复杂动力系统（可能是实验设备或仿真模型），它被视为一个“黑箱”。我们不知道其精确模型，但可以施加控制 `u` 并测量输出 `y` 和性能指标 `J`。

优化过程如下：
1.  生成一组控制律（函数树）。
2.  在系统上依次测试每个控制律，记录其性能 `J`。
3.  根据性能评估结果，运用交叉、变异和复制操作生成新一代控制律。
4.  重复步骤2和3，迭代优化，直到获得令人满意的控制性能。

## 重要讨论与扩展

需要指出的是，目前描述的控制律是瞬时反馈，即 `u(t)` 仅依赖于同一时刻的测量值 `y(t)`。在实际控制中，如果测量不完全，可能需要基于历史数据的状态估计（如卡尔曼滤波器）。

为了解决这个问题，可以将函数树中的运算进行扩展，加入传递函数或时间滤波操作（如积分）。这样，控制律就能利用传感器信号的时间历史信息，近似实现状态估计的功能。

![](img/dea65dc61096896d9aa1821fc698ba10_22.png)

尽管如此，在许多流体控制实验中，仅使用瞬时传感器反馈也取得了惊人的成功。这显示了该方法的潜力。
