# 16：特征系统实现算法（ERA）流程 🧠

![](img/41b8f83faec116e151036c917d473805_0.png)

在本节课中，我们将学习特征系统实现算法（ERA）。这是一种纯粹基于数据来获取拟合数据的线性动力系统的方法。它适用于实验系统，其核心假设是：你的数据可以用线性动力学描述，并且你拥有系统的脉冲响应数据。

## 概述

假设我们有一个线性系统，但我们不知道其状态空间模型中的矩阵 **A**、**B**、**C**、**D**。我们所能做的是给系统一个快速的脉冲输入（例如用锤子敲击），然后测量输出 **y** 随时间的变化。我们收集这些时间序列数据：**y(0)**, **y(1)**, **y(2)**... 我们的目标是从这些数据中，反推出一个尽可能简洁（状态数 **x** 尽可能少）但仍能捕捉输入输出动态的最佳拟合模型 **Ã**, **B̃**, **C̃**, **D**。

上一节我们介绍了平衡截断等方法，但那些方法需要已知模型。本节中我们来看看如何纯粹从数据出发。

## 算法步骤详解

以下是执行特征系统实现算法的具体步骤。

### 第一步：收集数据与构建汉克尔矩阵

首先，我们收集系统的脉冲响应数据。对于单输入单输出系统，我们得到一系列输出测量值 **y₀, y₁, y₂, ..., yₖ**。对于多输入多输出系统，每个 **yₖ** 都是一个矩阵。

*   **获取 D 矩阵**：第一个测量值 **y₀** 直接对应于系统的 **D** 矩阵。
    *   `D = y₀`
*   **构建汉克尔矩阵 H**：我们用剩余的数据 **y₁** 到 **yₖ** 构建一个汉克尔矩阵 **H**。这个矩阵的每一行都是时间序列向后平移一个时间步的结果。
    *   ```
        H = [ y₁,  y₂,  y₃, ... ;
              y₂,  y₃,  y₄, ... ;
              y₃,  y₄,  y₅, ... ;
              ...  ...  ...  ... ]
        ```
*   **构建移位汉克尔矩阵 H‘**：我们同时构建一个矩阵 **H‘**，它由 **H** 中每个元素向前推进一个时间步得到（即用 **y₂** 起始）。
    *   ```
        H' = [ y₂,  y₃,  y₄, ... ;
               y₃,  y₄,  y₅, ... ;
               y₄,  y₅,  y₆, ... ;
               ...  ...  ...  ... ]
        ```

**关键联系**：如果存在一个真实的线性系统 (**A, B, C**)，那么可以证明，我们构建的数据矩阵 **H** 在数学上等于之前平衡POD方法中的可观性格拉姆矩阵 **O** 与可控性格拉姆矩阵 **C** 的乘积，即 **H = O * C**。而 **H‘** 则等于 **O * A * C**。这建立了ERA与平衡模型之间的深刻联系。

### 第二步：对汉克尔矩阵进行奇异值分解（SVD）

接下来，我们对构建的汉克尔矩阵 **H** 进行奇异值分解。这与我们在平衡POD中做的完全一样。

*   `[U, Σ, V^T] = svd(H)`
*   我们根据奇异值 **Σ** 的衰减情况，选择一个截断秩 **r**。**r** 应尽可能小，但能捕获大部分的系统动态能量。
*   我们保留主导的左奇异向量 **Ũ**（**U** 的前 **r** 列）、主导的奇异值 **Σ̃**（**Σ** 的左上角 **r×r** 块）和主导的右奇异向量 **Ṽ^T**（**V^T** 的前 **r** 行）。
*   于是，**H ≈ Ũ * Σ̃ * Ṽ^T**。

### 第三步：构建降阶状态空间模型

利用SVD的结果和数据矩阵 **H‘**，我们可以直接计算出降阶模型矩阵 **Ã**, **B̃**, **C̃**。以下是计算公式：

*   **Ã 矩阵**：用于描述隐藏状态 **x̃** 的动态。
    *   `Ã = Σ̃^{-1/2} * Ũ^T * H' * Ṽ * Σ̃^{-1/2}`
*   **B̃ 矩阵**：描述输入 **u** 如何影响状态。这里 **I_p** 是 **p×p** 的单位矩阵（**p** 是输入数量），**0** 是零矩阵，用于从秩为 **r** 的矩阵中选取前 **p** 列。
    *   `B̃ = Σ̃^{1/2} * Ṽ^T * [I_p; 0]`
*   **C̃ 矩阵**：描述状态如何影响输出。这里 **I_q** 是 **q×q** 的单位矩阵（**q** 是输出数量），用于选取前 **q** 行。
    *   `C̃ = [I_q, 0] * Ũ * Σ̃^{1/2}`

### 第四步：得到完整的辨识模型

现在，我们拥有了完整的、数据驱动的线性状态空间模型：

*   状态方程：`x̃_{k+1} = Ã * x̃_{k} + B̃ * u_{k}`
*   输出方程：`y_{k} = C̃ * x̃_{k} + D * u_{k}`

其中，**D** 矩阵来自第一步，**Ã**, **B̃**, **C̃** 来自第三步。这个模型中的状态 **x̃** 是“特征时间延迟坐标”，它可能没有直接的物理意义，但它抽象并封装了为了复现输入输出动态所必需的主导隐藏模式。

## 总结

本节课中，我们一起学习了特征系统实现算法（ERA）的完整流程。我们从**收集脉冲响应数据**出发，通过**构建汉克尔矩阵 H 和 H‘**，并对 **H** 进行**奇异值分解**来选择模型阶次，最后利用公式**直接计算出降阶状态空间模型 (Ã, B̃, C̃, D)**。这个方法纯粹是数据驱动的，无需已知系统模型，并且与平衡模型降阶方法有着紧密的理论联系。它是线性系统辨识中一个非常强大且实用的工具。
