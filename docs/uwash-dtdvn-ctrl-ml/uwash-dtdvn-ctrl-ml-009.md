# 09：平衡截断示例教程 🧮

![](img/fe65987e5b5462bf49ec89d2026a9f98_0.png)

在本节课中，我们将学习如何通过Matlab代码实现平衡变换，将原始状态空间系统转换到新的坐标，使得系统的可控性和可观性格拉姆矩阵相等且对角化，并按重要性排序。我们将通过一个简单的二维系统示例，直观地展示这一过程。

## 概述

上一节我们介绍了平衡变换的理论基础，本节中我们来看看如何在Matlab中实际实现它。我们将构建一个简单的状态空间系统，计算其可控性和可观性格拉姆矩阵，然后应用平衡变换，最终可视化变换前后的格拉姆矩阵椭圆。

## 构建系统与计算格拉姆矩阵

首先，我们创建一个二维系统，该系统具有一个输入和一个输出，没有直接馈通项（D矩阵）。在Matlab中，我们可以使用`ss`命令轻松构建状态空间系统，并使用`gram`命令计算其可控性和可观性格拉姆矩阵。

```matlab
% 定义系统矩阵
A = [ ... ]; % 替换为你的A矩阵
B = [ ... ]; % 替换为你的B矩阵
C = [ ... ]; % 替换为你的C矩阵
D = 0;

% 构建状态空间系统
sys = ss(A, B, C, D);

% 计算可控性和可观性格拉姆矩阵
Wc = gram(sys, 'c'); % 可控性格拉姆矩阵
Wo = gram(sys, 'o'); % 可观性格拉姆矩阵
```

运行上述代码后，我们可以验证`Wc`和`Wo`并不相等，也不是对角矩阵。这反映了原始坐标下，系统在不同方向上的可控性和可观性强度不同。

## 可视化原始格拉姆矩阵

为了直观理解，我们将可控性和可观性格拉姆矩阵可视化为椭圆。以下是绘制这些椭圆的步骤：

1.  定义一个二维单位圆。
2.  分别通过可控性和可观性格拉姆矩阵的平方根映射这个圆。
3.  绘制得到的椭圆，通常用红色代表可控性椭圆，蓝色代表可观性椭圆。

```matlab
% 定义单位圆上的点
theta = linspace(0, 2*pi, 100);
circle = [cos(theta); sin(theta)];

![](img/fe65987e5b5462bf49ec89d2026a9f98_2.png)

% 映射到可控性椭圆
sqrtWc = sqrtm(Wc);
controllability_ellipse = sqrtWc * circle;

% 映射到可观性椭圆
sqrtWo = sqrtm(Wo);
observability_ellipse = sqrtWo * circle;

% 绘制
figure;
hold on;
plot(controllability_ellipse(1,:), controllability_ellipse(2,:), 'r', 'LineWidth', 2);
plot(observability_ellipse(1,:), observability_ellipse(2,:), 'b', 'LineWidth', 2);
axis equal;
legend('可控性椭圆', '可观性椭圆');
title('原始坐标下的格拉姆矩阵椭圆');
```

## 应用平衡变换

Matlab提供了一个非常便捷的命令`balreal`来计算系统的平衡实现。这个命令封装了高效的数值线性代数算法。

```matlab
% 计算平衡实现
[sys_bal, T, Ti, Sigma] = balreal(sys);

% sys_bal: 平衡后的系统
% T: 从原始坐标X到平衡坐标Z的变换矩阵
% Ti: 从平衡坐标Z回到原始坐标X的逆变换矩阵 (Ti = inv(T))
% Sigma: 平衡格拉姆矩阵的对角元素（汉克尔奇异值）
```

运行后，我们可以检查平衡后系统的格拉姆矩阵：

```matlab
Wc_bal = gram(sys_bal, 'c');
Wo_bal = gram(sys_bal, 'o');
disp('平衡后可控性格拉姆矩阵:');
disp(Wc_bal);
disp('平衡后可观性格拉姆矩阵:');
disp(Wo_bal);
```

你将看到`Wc_bal`和`Wo_bal`是相等的对角矩阵，且对角线元素（即`Sigma`中的值）从大到小排列。第一个值远大于第二个值，表明第一个平衡坐标`Z1`是系统中最重要（最联合可控可观）的方向。

## 可视化平衡后的格拉姆矩阵

为了在原始坐标中看到平衡后的效果，我们需要将平衡坐标下的椭圆变换回原始坐标。

1.  在平衡坐标`Z`中，格拉姆矩阵是对角矩阵`Sigma`，其对应的椭圆是一个轴与坐标轴对齐的椭圆。
2.  我们通过逆变换`Ti`将这个椭圆映射回原始`X`坐标进行显示。

```matlab
% 在平衡坐标Z中，格拉姆矩阵是对角阵Sigma，其平方根也是对角阵
sqrtSigma = sqrt(Sigma); % 假设Sigma是向量
balanced_ellipse_in_Z = diag(sqrtSigma) * circle;

% 通过逆变换Ti映射回原始X坐标
balanced_ellipse_in_X = Ti * balanced_ellipse_in_Z;

% 添加到之前的图中
plot(balanced_ellipse_in_X(1,:), balanced_ellipse_in_X(2,:), 'm', 'LineWidth', 2);
legend('可控性椭圆', '可观性椭圆', '平衡后椭圆');
```

紫色的平衡椭圆代表了可控性与可观性之间的折衷，其主轴方向指示了系统中最联合重要（即可控且可观）的状态方向。

## 平衡变换的核心步骤（手动实现）

虽然`balreal`命令很方便，但理解其背后的步骤很有意义。以下是手动计算平衡变换`T`的关键公式：

1.  计算原始系统的可控性和可观性格拉姆矩阵`Wc`和`Wo`。
2.  求解广义特征值问题或进行Cholesky分解与奇异值分解（SVD）：
    *   一种常见方法是计算`Wc * Wo`的特征分解：
        `Wc * Wo * T_unsorted = T_unsorted * Σ²`
        其中`Σ²`是对角矩阵，其元素为汉克尔奇异值的平方，`T_unsorted`是未经排序和缩放的特征向量矩阵。
3.  对特征值进行降序排序，并对特征向量进行相应排序和缩放，得到最终的平衡变换矩阵`T`，使得：
    `T⁻¹ * Wc * T⁻ᵀ = Tᵀ * Wo * T = Σ`
    其中`Σ`是对角矩阵，对角线元素为汉克尔奇异值。

```matlab
% 手动计算平衡变换的简化示意
[V, D] = eig(Wc * Wo); % 特征分解
[sigma_squared, idx] = sort(diag(D), 'descend'); % 排序
T_manual = V(:, idx); % 排序特征向量
```

## 总结

![](img/fe65987e5b5462bf49ec89d2026a9f98_4.png)

本节课中我们一起学习了如何在Matlab中实现平衡截断。我们首先构建了一个示例系统并计算了其格拉姆矩阵，然后利用`balreal`这一行命令轻松找到了平衡坐标变换。在平衡坐标下，系统的可控性和可观性格拉姆矩阵变得相等、对角且按重要性（汉克尔奇异值）排序。这为我们提供了一种原则性的方法，可以从高维系统中截取出最重要的状态，用于模型降阶和简化控制器设计。对于大规模系统，这一方法同样适用，能够自动识别出最联合可控和可观的状态方向层级。
