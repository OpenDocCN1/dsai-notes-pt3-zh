# 🧠 UCB CS285 深度强化学习笔记 - 课程1：强化学习简介与序列决策

在本节课中，我们将要学习强化学习的基本概念，理解智能体如何通过与环境的交互来学习最优策略，并掌握序列决策问题的数学描述框架。

## 概述：什么是强化学习？

强化学习是机器学习的一个分支，它关注智能体如何在复杂、不确定的环境中通过试错来学习，以达成某个长期目标。其核心是**序列决策问题**：智能体在每一步观察环境状态，选择一个动作，然后从环境中获得奖励并转移到下一个状态。目标是学习一个策略，使得长期累积的奖励最大化。

上一节我们概述了强化学习的目标，本节中我们来看看其核心的数学框架——马尔可夫决策过程。

## 马尔可夫决策过程

马尔可夫决策过程为序列决策问题提供了一个形式化的数学模型。它由五个关键元素构成：状态、动作、转移概率、奖励函数和折扣因子。

以下是MDP的五元组定义：

*   **状态 (State, `s`)**: 对环境的描述。在时间步 `t` 的状态记为 `s_t`。
*   **动作 (Action, `a`)**: 智能体可以做出的选择。在状态 `s_t` 下采取的动作记为 `a_t`。
*   **转移概率 (Transition Probability, `T`)**: 给定当前状态和动作，环境转移到下一个状态的概率分布。公式为 `P(s_{t+1} | s_t, a_t)`。
*   **奖励函数 (Reward Function, `R`)**: 智能体在采取某个动作后从环境获得的即时标量反馈。公式为 `r_t = R(s_t, a_t, s_{t+1})` 或简化为 `R(s_t, a_t)`。
*   **折扣因子 (Discount Factor, `γ`)**: 一个介于0和1之间的数，用于权衡即时奖励和未来奖励的重要性。`γ` 越接近0，智能体越短视；越接近1，智能体越有远见。

智能体的目标是找到一个策略 `π`，该策略指定在给定状态下应采取何种动作（`a_t ~ π(· | s_t)`），以最大化从初始状态开始的**期望累积折扣奖励**，即**回报 (Return)**。

回报 `G_t` 的公式定义为：
`G_t = r_t + γ * r_{t+1} + γ^2 * r_{t+2} + ... = Σ_{k=0}^{∞} γ^k * r_{t+k}`

理解了MDP的定义后，我们接下来看看如何评估一个策略的好坏，这引出了价值函数的概念。

## 价值函数与贝尔曼方程

为了评估和比较不同的策略，我们定义了价值函数。价值函数衡量在特定策略下，从某个状态（或状态-动作对）出发，所能获得的期望回报。

以下是两类核心的价值函数：

*   **状态价值函数 (State-Value Function, `V^π(s)`)**: 表示从状态 `s` 开始，遵循策略 `π` 所能获得的期望回报。公式为 `V^π(s) = E_π[ G_t | s_t = s ]`。
*   **动作价值函数 (Action-Value Function, `Q^π(s, a)`)**: 表示在状态 `s` 下采取动作 `a`，然后遵循策略 `π` 所能获得的期望回报。公式为 `Q^π(s, a) = E_π[ G_t | s_t = s, a_t = a ]`。

这两个价值函数通过**贝尔曼方程**相互关联。贝尔曼方程描述了当前价值与后续状态价值之间的递归关系。

状态价值函数的贝尔曼方程公式为：
`V^π(s) = E_{a~π, s‘~P}[ R(s, a) + γ * V^π(s') ]`

动作价值函数的贝尔曼方程公式为：
`Q^π(s, a) = E_{s’~P}[ R(s, a, s') + γ * E_{a‘~π}[ Q^π(s‘, a’) ] ]`

贝尔曼方程是强化学习算法的理论基础。基于价值函数，我们可以定义最优策略的目标。

## 最优策略与最优价值函数

强化学习的终极目标是找到**最优策略 `π*`**，即能获得最大可能期望回报的策略。所有最优策略共享相同的**最优价值函数**。

以下是相关定义：

*   **最优状态价值函数**: `V*(s) = max_π V^π(s)`
*   **最优动作价值函数**: `Q*(s, a) = max_π Q^π(s, a)`
*   **最优策略**: 对于任意状态 `s`，`π*(s) = argmax_a Q*(s, a)`。即总是选择能使最优动作价值函数最大化的动作。

最优价值函数满足**贝尔曼最优方程**，它是贝尔曼方程在取最优动作情况下的特例。

贝尔曼最优方程公式为：
`V*(s) = max_a E_{s‘~P}[ R(s, a, s') + γ * V*(s') ]`
`Q*(s, a) = E_{s’~P}[ R(s, a, s') + γ * max_{a‘} Q*(s‘, a’) ]`

本节课中我们一起学习了强化学习的基础——马尔可夫决策过程。我们定义了状态、动作、奖励等核心概念，引入了价值函数与贝尔曼方程来评估策略，并最终描述了寻找最优策略的数学目标。理解这些基本框架是学习后续深度强化学习算法的重要前提。
