# 课程 1：深度强化学习导论 🚀

在本节课中，我们将要学习深度强化学习的基本概念、核心思想以及其与机器学习和人工智能其他分支的关系。我们将从宏观视角理解强化学习要解决什么问题，以及它为何如此重要。

## 概述

强化学习是机器学习的一个分支，它关注智能体如何在一系列行动中学习，以最大化从环境中获得的累积奖励。与监督学习和无监督学习不同，强化学习通过与环境交互进行学习，其目标是学习一个最优策略。

## 什么是强化学习？

强化学习研究的是**智能体**在**环境**中通过**试错**进行学习的问题。智能体执行**动作**，环境返回新的**状态**和**奖励**。智能体的目标是学习一个**策略**，使其获得的**总奖励**最大化。

以下是强化学习问题中的几个核心组成部分：

*   **智能体**：做出决策的学习者或决策者。
*   **环境**：智能体与之交互的一切外部事物。
*   **状态**：环境在特定时刻的描述。
*   **动作**：智能体可以执行的操作。
*   **奖励**：环境对智能体动作的即时反馈信号。
*   **策略**：智能体在给定状态下选择动作的规则，可以表示为函数 **π(a|s)**。
*   **价值函数**：评估在某个状态下，遵循某个策略所能获得的长期回报的期望值。

## 强化学习与其他机器学习范式的关系

上一节我们定义了强化学习，本节中我们来看看它与其他机器学习范式的区别与联系。

机器学习主要分为三大范式：监督学习、无监督学习和强化学习。

以下是它们之间的主要区别：

*   **监督学习**：从带有标签的数据中学习输入到输出的映射。例如，给定图片和对应的“猫”或“狗”的标签，学习一个分类模型。
*   **无监督学习**：从无标签的数据中发现隐藏的结构或模式。例如，聚类、降维。
*   **强化学习**：通过与环境的交互序列进行学习，目标是最大化累积奖励。它没有直接的“正确”答案（标签），只有奖励信号来评估动作的好坏。

强化学习可以被视为一种**序列决策**问题，它结合了**规划**（对未来进行思考）和**学习**（从经验中改进）。

## 强化学习的应用领域

强化学习的核心思想——通过交互学习最优行为——使其在众多需要序列决策的领域具有巨大潜力。

以下是强化学习的一些成功应用领域：

*   **游戏**：例如，AlphaGo、AlphaStar、OpenAI Five 在复杂游戏中达到超越人类的水平。
*   **机器人控制**：让机器人学习行走、抓取物体等复杂技能。
*   **自动驾驶**：学习在复杂交通环境中安全、高效地驾驶。
*   **资源管理**：优化数据中心能耗、网络资源分配等。
*   **推荐系统**：学习动态调整推荐策略以最大化用户长期参与度。
*   **金融交易**：学习投资组合管理和交易策略。

## 深度强化学习简介

传统的强化学习方法在处理高维状态空间（如图像、文本）时面临挑战。深度学习的出现为这一挑战提供了解决方案。

**深度强化学习** 结合了深度学习的感知能力和强化学习的决策能力。具体来说，我们使用深度神经网络来表示强化学习中的关键组件：

*   **策略网络**：用神经网络 **π_θ(a|s)** 表示策略，参数为 θ。
*   **价值网络**：用神经网络 **V_φ(s)** 或 **Q_φ(s, a)** 来近似状态价值函数或动作价值函数，参数为 φ。
*   **模型网络**：用神经网络来学习环境动态的预测模型 **p_ψ(s‘|s, a)**，参数为 ψ。

这种结合使得智能体能够直接从高维原始输入（如像素）中学习有效的策略，从而在Atari游戏、机器人控制等领域取得了突破性进展。
