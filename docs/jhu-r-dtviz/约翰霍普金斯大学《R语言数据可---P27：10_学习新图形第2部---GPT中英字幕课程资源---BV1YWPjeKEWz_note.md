## 概述：创建篮球球员数据热力图

假设我们有三位篮球球员，并记录了他们在整个赛季中的得分、助攻和篮板数据。如果你不熟悉篮球，不必担心，这些只是描述球员在比赛中表现的数据，数值越高代表表现越好。

首先，我们创建这些模拟数据。

```r
# 创建球员数据
player_names <- c("LeBron", "Steph", "Giannis")
points <- c(28, 26, 30)
assists <- c(8, 6, 5)
rebounds <- c(7, 5, 12)
```

现在，我们将这些数据组合成一个Tibble。你会注意到，这次的数据与之前的热力图示例有所不同。

```r
# 组合成Tibble
player_stats <- tibble(
  player = player_names,
  points = points,
  assists = assists,
  rebounds = rebounds
)
```

## 数据标准化的重要性

在之前的热力图中，所有变量的范围都在0到5之间。而在这里，不同变量的取值范围不同。这一点非常重要，因为热力图只使用一种颜色渐变。因此，你必须对所有变量进行标准化或缩放，使它们处于相同的尺度上，以便轻松进行比较。

如果不这样做，不同单位之间的颜色将无法解释，这可能会带来严重问题。

最简单的标准化方法是将每个值除以数据集中的最大值，这样最高值就会变为1。

```r
# 标准化数据
player_stats_scaled <- player_stats %>%
  mutate(
    points_scaled = points / max(points),
    assists_scaled = assists / max(assists),
    rebounds_scaled = rebounds / max(rebounds)
  )
```

然后，我们使用`select`命令创建一个只包含标准化得分的新Tibble。

```r
# 选择标准化后的列
player_stats_scaled_only <- player_stats_scaled %>%
  select(player, ends_with("scaled"))
```

这里我们快速处理了许多数据整理步骤。如果你需要回顾并逐步理解这些操作，可以暂停视频，并在代码文件中进行尝试，以确保你理解所有步骤。

## 数据从宽格式转换为长格式

现在我们已经有了标准化数据，但它是宽格式而非长格式。在现实世界中处理数据时，这是一个非常常见的问题。

为了匹配我们在图形库中看到的示例，我们需要将宽格式数据转换为长格式。

在R中，有很多方法可以实现这一点，但在tidyverse中，一个非常方便的命令是`pivot_longer`。

以下是使用`pivot_longer`的示例。

```r
# 将数据从宽格式转换为长格式
player_stats_long <- player_stats_scaled_only %>%
  pivot_longer(
    cols = -player,  # 选择除'player'外的所有列进行转换
    names_to = "stat",  # 新列名，存放原列名（如points_scaled）
    values_to = "value"  # 新列名，存放对应的值
  )
```

我再次演示这个过程，是为了向你展示如何将你拥有的数据转换为符合在线模板的格式。这样，你就能接触到大量新的可视化图形。

将数据从宽格式转换为长格式可能有些棘手。首先，我们确定要转换的数据。然后，我们确定要拉伸到第二列数据的变量。在这里，我们称这些变量为“stats”，并将值设置为“values”。

现在我们可以看到，球员的名字被重复列出，每个名字都与一个统计指标及其对应的值配对。

目前的关键是认识到，数据看起来与我们从图形库示例中使用的数据格式完全相同。这意味着我们正在正确地按照示例进行操作。

## 创建热力图

既然我们的数据格式与示例相同，我们就可以运行`ggplot`命令，并适当调整以匹配我们数据的格式和变量名称。

我们将X轴映射到球员名字，Y轴映射到变量名称，填充颜色映射到每个统计指标的标准化值。

```r
# 创建热力图
ggplot(player_stats_long, aes(x = player, y = stat, fill = value)) +
  geom_tile() +
  scale_fill_gradient(low = "white", high = "red") +
  labs(title = "篮球球员表现热力图",
       x = "球员",
       y = "统计指标",
       fill = "标准化值")
```

现在，我们得到了一个热力图，其中颜色较浅的格子表示该变量的得分较高。

## 进一步美化图形

同样，你可以对这个简单的`ggplot`图形进行进一步修改，比如添加标题、标签以及我们之前学过的所有其他元素。你只需要在`ggplot`代码串中添加额外的命令即可。

```r
# 美化后的热力图
ggplot(player_stats_long, aes(x = player, y = stat, fill = value)) +
  geom_tile(color = "black") +  # 添加格子边框
  scale_fill_gradient(low = "white", high = "darkred") +
  theme_minimal() +
  labs(title = "赛季球员表现对比",
       subtitle = "数据已标准化处理",
       x = "球员姓名",
       y = "技术统计",
       fill = "相对表现值") +
  theme(axis.text.x = element_text(angle = 0, hjust = 0.5))
```

## 学习新可视化的流程

当你尝试学习新的可视化方法时，应该遵循以下流程：

1.  寻找模板：在互联网上找到一个你喜欢的图形模板。
2.  逐步学习：仔细阅读并理解与该模板相关的示例或教程的每一步。
3.  理解原理：弄清楚示例是如何工作的。
4.  匹配数据：将你的数据整理成与找到的模板相匹配的格式。

通过这种基本方法，你可以轻松掌握大量新的可视化图形，这一切都得益于你花时间学习了`ggplot`的基础知识。
