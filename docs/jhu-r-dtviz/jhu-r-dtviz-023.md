## 数据准备与变量处理

上一节我们介绍了基础条形图的绘制，本节中我们来看看如何处理分类数据以创建更复杂的条形图。

我们使用的数据来自“合作国会选举调查”（CCES）。数据中包含一个关于政党认同的问题，原始数据是一个七点量表：
- 1至3分表示受访者为“强烈民主党”到“倾向民主党”。
- 4分表示“真正独立人士”。
- 5至7分表示“倾向共和党”到“强烈共和党”。

为了简化分析，我们需要将这个七分类变量重新编码为三个类别：`民主党`、`独立人士`和`共和党`。

以下是数据读取和变量重编码的代码：

```r
# 读取数据
cces_data <- read.csv("cces_sample.csv")

# 重编码政党变量
cces_data <- cces_data %>%
  mutate(party_collapsed = case_when(
    pid7 <= 3 ~ "民主党",
    pid7 == 4 ~ "独立人士",
    pid7 >= 5 ~ "共和党"
  ))
```

处理完成后，我们就得到了一个包含`region`（地区）和`party_collapsed`（政党）两个关键分类变量的数据集。

---

## 绘制堆叠条形图

接下来，我们开始绘制第一个可视化图形：堆叠条形图。这种图形能在一个条形内展示不同类别的构成。

在`ggplot2`中，我们使用`geom_bar()`函数绘制条形图。我们将地区（`region`）映射到X轴，并将条形填充色（`fill`）映射到我们新创建的政党变量（`party_collapsed`）。`geom_bar()`会自动计算每个组合的计数。

```r
ggplot(cces_data, aes(x = region, fill = party_collapsed)) +
  geom_bar()
```

运行以上代码，你将得到一个堆叠条形图。每个地区对应一个条形，每个条形由代表民主党、独立人士和共和党受访者数量的三色块堆叠而成。这种形式可以清晰看到每个地区的总受访者数量以及其内部的政党构成。

---

## 转换为分组条形图

虽然堆叠条形图很实用，但有时我们可能希望直接比较不同地区间同一政党的数量。这时，分组条形图是更好的选择。

从堆叠条形图转换到分组条形图非常简单，只需在`geom_bar()`函数中添加一个参数。以下是具体做法：

```r
ggplot(cces_data, aes(x = region, fill = party_collapsed)) +
  geom_bar(position = "dodge")
```

关键变化在于设置了 `position = “dodge”`。这个参数将原本堆叠在一起的色块“并排”排列。现在，每个地区下会有三个并排的条形，分别对应三个政党。这样，跨地区比较同一政党的支持者数量就变得一目了然。

---

## 图形美化与定制

和之前学习的所有`ggplot2`图形一样，我们可以轻松地美化这个条形图。

以下是你可以定制的一些元素，其方法与之前课程所学的完全一致：
- **标题与标签**：使用`labs()`函数添加主标题、副标题，以及修改X轴、Y轴和图例的标签。
- **颜色**：使用`scale_fill_manual()`函数为不同的政党手动指定更美观的颜色。
- **主题**：使用`theme_*()`系列函数或`theme()`函数来调整字体、网格线、背景等整体外观。

你可以根据自己的审美和读者的需求，自由组合这些元素来优化图表。

## 堆叠与分组：如何选择？

我们已经看到了呈现相同数据的两种不同条形图格式。那么，在实际应用中应该如何选择呢？

选择取决于你希望强调的信息：
- **堆叠条形图** 更适合展示**整体构成**和**部分与整体的关系**。例如，如果你想强调每个地区的总人数以及各政党在其中所占的比例，堆叠条形图是理想的选择。
- **分组条形图** 则更适合进行**跨组别的精确比较**。例如，如果你想直接对比“东北地区的共和党人数”与“西部地区的共和党人数”，分组条形图能让这种比较变得非常直观。

最终选择哪一种，取决于你的分析目的以及你认为哪种形式能为读者提供最清晰、最有用的洞察。
