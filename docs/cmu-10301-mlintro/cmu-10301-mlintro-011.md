## 概述

## 神经网络简介

神经网络是深度学习的核心，它们在所有当前的生成式AI革命中扮演着重要角色。

### 神经网络与深度学习

* 神经网络是深度学习的核心。
* 神经网络是当前生成式AI革命的关键。

### 神经网络与决策边界

* 神经网络可以建立新的决策边界和决策规则。
* 神经网络可以学习复杂的非线性关系。

## 神经网络结构

神经网络由多个层组成，包括输入层、隐藏层和输出层。

### 输入层

* 输入层接收原始数据。
* 输入层将数据传递到隐藏层。

### 隐藏层

* 隐藏层包含多个神经元。
* 隐藏层对数据进行处理和转换。

### 输出层

* 输出层生成最终预测。
* 输出层将预测结果传递给用户。

## 神经网络计算

神经网络通过以下步骤进行计算：

1. **前向传播**：将输入数据传递到网络，并计算每个神经元的输出。
2. **激活函数**：对每个神经元的输出应用激活函数，例如Sigmoid或ReLU。
3. **损失函数**：计算预测值与真实值之间的差异。
4. **反向传播**：根据损失函数计算梯度，并更新网络参数。

## 神经网络示例

以下是一个简单的神经网络示例，用于二分类任务：

```
输入层 -> 隐藏层 -> 输出层
```

### 输入层

* 输入层包含两个特征：x1和x2。

### 隐藏层

* 隐藏层包含一个神经元，其权重为w1和w2。
* 隐藏层使用Sigmoid激活函数。

### 输出层

* 输出层包含一个神经元，其权重为b1和b2。
* 输出层使用Sigmoid激活函数。
