# 机器学习导论：1：课程概述与基础概念 🎯

在本课程中，我们将学习机器学习的基本概念和几种核心算法。机器学习是使计算机能够从数据中学习并做出决策或预测的技术。通过学习本教程，你将建立起对机器学习领域的初步理解。

## 机器学习导论：1.1：机器学习定义

![](img/f6d084c8572a681d7f86ddfeb79f16b2_1.png)

机器学习是一门研究如何让计算机系统通过经验（通常以数据形式提供）自动改进其性能的科学。其核心在于，系统能够从数据中学习规律，并利用这些规律对新的、未见过的数据做出预测或决策。

## 机器学习导论：1.2：常见算法

![](img/f6d084c8572a681d7f86ddfeb79f16b2_3.png)

机器学习领域包含多种算法，适用于不同类型的问题。以下是几种最常见的算法：

*   **线性回归**：用于预测连续数值。
*   **逻辑回归**：用于预测离散类别，例如二分类问题。
*   **决策树**：一种树状模型，可用于分类和回归任务。
*   **支持向量机**：一种强大的分类和回归算法，尤其擅长处理高维数据。
*   **神经网络**：一种模仿人脑结构的模型，擅长处理复杂的模式识别任务。

# 机器学习导论：2：线性回归 📈

线性回归是一种用于预测连续数值的监督学习算法。它试图找到输入特征与输出目标之间的线性关系。

## 机器学习导论：2.1：线性回归公式

线性回归模型的基本形式可以用一个简单的线性方程来表示。

**公式**：`y_hat = θ₀ + θ₁ * x`

在这个公式中：
*   `y_hat` 是模型的预测值。
*   `x` 是输入特征。
*   `θ₀` 是截距参数。
*   `θ₁` 是斜率参数。

## 机器学习导论：2.2：线性回归损失函数

为了找到最佳的参数 `θ₀` 和 `θ₁`，我们需要一个标准来衡量模型预测的好坏，这个标准就是损失函数。对于线性回归，最常用的损失函数是均方误差。

**公式**：`MSE = (1/n) * Σ(y - y_hat)²`

其中：
*   `MSE` 是均方误差。
*   `y` 是真实值。
*   `y_hat` 是预测值。
*   `n` 是样本数量。
*   `Σ` 表示对所有样本求和。

模型的目标就是找到一组参数，使得这个 `MSE` 值最小。

---

了解了用于预测连续值的线性回归后，我们来看看如何处理分类问题。逻辑回归是解决此类问题的经典算法。

# 机器学习导论：3：逻辑回归 🔀

逻辑回归是一种用于预测离散类别（特别是二分类）的监督学习算法。它通过一个S形函数将线性回归的输出映射到概率值。

## 机器学习导论：3.1：逻辑回归公式

逻辑回归的核心是sigmoid函数，它将任何实数映射到(0,1)区间，可以解释为概率。

**公式**：`P(y=1|x) = σ(z) = 1 / (1 + e^(-z))`，其中 `z = θ₀ + θ₁ * x`

这里：
*   `P(y=1|x)` 表示在给定特征 `x` 的条件下，样本属于类别1的概率。
*   `σ` 是sigmoid函数。
*   `θ₀` 和 `θ₁` 是模型参数。

## 机器学习导论：3.2：逻辑回归损失函数

逻辑回归使用对数损失（或交叉熵损失）作为其损失函数，它衡量预测概率分布与真实分布之间的差异。

**公式**：`Log Loss = - [y * log(p) + (1 - y) * log(1 - p)]`

其中：
*   `y` 是真实标签（0或1）。
*   `p` 是模型预测样本属于类别1的概率 `P(y=1|x)`。

对于整个数据集，损失是每个样本损失的平均值。模型训练的目标是最小化这个损失。

---

无论是线性回归还是逻辑回归，都属于“参数化”模型。接下来，我们将学习一种直观的“非参数化”模型——决策树。

# 机器学习导论：4：决策树 🌳

决策树是一种模拟人类决策过程的算法，可用于分类和回归任务。它通过一系列基于特征的问题对数据进行划分，最终到达一个代表预测结果的叶子节点。

## 机器学习导论：4.1：决策树结构

一棵决策树由两种基本类型的节点构成：

*   **决策节点**：代表一个特征测试。根据某个特征的值，数据将被分流到不同的分支。
*   **叶子节点**：代表最终的决策或预测结果。在分类树中，它包含一个类别标签；在回归树中，它包含一个具体的数值。

## 机器学习导论：4.2：决策树算法

构建决策树的关键在于如何选择每个决策节点上用于划分的最佳特征。以下是两种经典算法：

*   **ID3 算法**：使用**信息增益**作为特征选择标准。信息增益衡量的是根据某个特征划分后，数据不确定性的减少程度。
*   **C4.5 算法**：ID3的改进版，使用**信息增益率**作为标准。它通过引入特征的固有信息来修正信息增益对取值较多特征的偏好。

---

决策树易于理解，但在复杂问题上可能表现不佳。支持向量机则是一种更加强大、泛化能力好的分类器。

# 机器学习导论：5：支持向量机 ⚔️

![](img/f6d084c8572a681d7f86ddfeb79f16b2_6.png)

支持向量机是一种强大的监督学习算法，主要用于分类，也可用于回归。其核心思想是寻找一个能够将不同类别数据点分开的“最优”决策边界，并且使得边界到两侧最近数据点的距离（间隔）最大化。

## 机器学习导论：5.1：支持向量机公式

![](img/f6d084c8572a681d7f86ddfeb79f16b2_8.png)

对于一个线性可分的二分类问题，SVM的决策函数可以表示为：

**公式**：`f(x) = sign(w · x + b)`

![](img/f6d084c8572a681d7f86ddfeb79f16b2_10.png)

其中：
*   `w` 是法向量，决定了决策边界的方向。
*   `b` 是偏置项，决定了决策边界的位移。
*   `sign` 是符号函数，输出+1或-1代表不同的类别。
*   `·` 表示点积运算。

那些距离决策边界最近的数据点被称为“支持向量”，它们决定了边界的位置。

![](img/f6d084c8572a681d7f86ddfeb79f16b2_12.png)

## 机器学习导论：5.2：支持向量机优化目标

SVM的训练目标被形式化为一个凸优化问题：最大化分类间隔，这等价于最小化权重向量 `w` 的范数。

![](img/f6d084c8572a681d7f86ddfeb79f16b2_13.png)

**公式**：`min (1/2) * ||w||²`， 同时满足约束 `y_i (w · x_i + b) ≥ 1` 对所有样本 `i` 成立。

这里 `y_i` 是样本 `i` 的真实标签（+1或-1）。这个公式描述的是线性可分情况下的“硬间隔”SVM。

![](img/f6d084c8572a681d7f86ddfeb79f16b2_14.png)

---

支持向量机构建了复杂的决策边界。为了处理更复杂的模式，我们可以使用由多个简单单元组成的神经网络。

# 机器学习导论：6：神经网络 🧠

神经网络是一种受人脑结构启发的强大模型，属于深度学习的基础。它由大量相互连接的简单处理单元（神经元）组成，能够学习数据中高度复杂的非线性模式。

## 机器学习导论：6.1：神经网络结构

一个典型的神经网络包含以下层次：

*   **输入层**：接收原始数据特征。
*   **隐藏层**：位于输入和输出层之间，可以有一层或多层。每一层包含多个神经元，每个神经元对上一层的输出进行加权求和并施加一个非线性激活函数（如Sigmoid、ReLU）。
*   **输出层**：产生最终的预测结果。对于不同任务（如回归、分类），输出层的激活函数会不同。

## 机器学习导论：6.2：神经网络训练算法

![](img/f6d084c8572a681d7f86ddfeb79f16b2_16.png)

训练神经网络，即调整所有神经元之间的连接权重，最核心的算法是反向传播。

*   **反向传播算法**：该算法通过链式法则，将最终预测误差从输出层向输入层反向传播，并据此计算每个权重对总误差的贡献（梯度），然后使用梯度下降法来更新权重，从而逐步减小预测误差。

在本节课中，我们一起学习了机器学习的基础知识。我们从机器学习的定义出发，依次介绍了五种核心算法：用于预测连续值的**线性回归**，用于分类的**逻辑回归**，结构直观的**决策树**，追求最大间隔的**支持向量机**，以及能够拟合复杂函数的**神经网络**。对于每种算法，我们都了解了其基本思想和核心的数学表达（公式或结构）。这些概念和算法构成了机器学习领域的基石，为你进一步探索更高级的主题打下了坚实的基础。
