# CMU 10-301 机器学习导论笔记：1：机器学习基础概念

在本节课中，我们将要学习机器学习的基础概念，包括其定义、核心任务类型以及一个简单的学习流程。这些知识是理解后续更复杂模型和算法的基石。

## 什么是机器学习？

机器学习是计算机科学的一个领域。它使计算机能够在没有明确编程的情况下进行学习。机器学习算法从数据中构建模型。该模型用于进行预测或决策。

上一节我们介绍了机器学习的定义，本节中我们来看看它主要解决哪些类型的问题。

## 机器学习的任务类型

机器学习任务主要分为三大类，以下是它们的简要介绍：

*   **监督学习**：算法从**带有标签**的训练数据中学习。目标是学习一个从输入到输出的映射函数。例如，根据房屋特征（输入）预测其价格（输出）。
*   **无监督学习**：算法从**没有标签**的数据中寻找内在结构或模式。例如，将客户分成不同的群体（聚类），或发现数据中的主要变化方向（降维）。
*   **强化学习**：算法通过与环境交互来学习。它执行动作并获得奖励或惩罚作为反馈，目标是学习一个策略以最大化累积奖励。例如，训练一个机器人学习走路。

了解了任务类型后，一个典型的机器学习流程是怎样的呢？

## 一个简单的学习流程

一个基础的机器学习流程通常包含以下几个步骤。以下是该流程的关键环节：

1.  **数据收集与准备**：获取原始数据，并进行清洗、处理缺失值、特征工程等操作，使其适合模型学习。
2.  **选择模型**：根据任务类型（如分类、回归）选择合适的算法模型，例如线性回归、决策树等。
3.  **训练模型**：使用训练数据来拟合模型。这个过程就是调整模型内部参数，使其能够更好地拟合数据。对于线性回归，就是找到最佳拟合线 `y = w*x + b` 中的参数 `w`（权重）和 `b`（偏置）。
4.  **模型评估**：使用未见过的测试数据来评估模型的性能。常用指标包括准确率、精确率、召回率、均方误差等。
5.  **预测**：使用训练好的模型对新的、未知的数据进行预测。

本节课中我们一起学习了机器学习的基本定义、三大核心任务类型（监督学习、无监督学习、强化学习）以及一个标准的学习流程。理解这些基础概念是进入更广阔机器学习世界的第一步。
