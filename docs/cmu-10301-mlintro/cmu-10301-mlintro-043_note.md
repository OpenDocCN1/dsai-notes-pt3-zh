## 机器学习导论：1：矩阵微积分 🧮

![](img/2d1474c72c360abfdb0b1f9a54b9f318_3.png)

在本节中，我们将学习矩阵微积分，这是机器学习中用于高效计算梯度和导数的重要数学工具。

### 1.1 符号约定

![](img/2d1474c72c360abfdb0b1f9a54b9f318_5.png)

矩阵微积分中常用的符号约定有两种：分子布局和分母布局。本课程使用的是分母布局。

**公式**：在分母布局表示中，导数的形状遵循“分母的形状先于分子的形状”的原则。

### 1.2 链式法则示例

上一节我们介绍了布局约定，本节中我们来看看链式法则在矩阵微积分中的应用。以标量函数为例，假设有两个函数 G 和 F，其中 G(y) = G(F(x))。我们可以计算 Dz/Dx，其中 z = G(y)。

**公式**：Dz/Dx = (Dz/Dy) * (Dy/Dx)

### 1.3 布局与乘法顺序

在标量乘法中，我们可以交换乘法顺序，但在矩阵微积分中，乘法的顺序至关重要，需要根据布局约定来确定正确的顺序。

**公式**：在分母布局下，对于 z = G(y) 和 y = F(x)，有 Dz/Dx = (Dy/Dx)^T * (Dz/Dy)。

## 机器学习导论：2：矩阵求导 📐

上一节我们学习了矩阵微积分的基本法则，本节中我们将具体学习如何对涉及矩阵的表达式进行求导。

### 2.1 矩阵求导示例

假设有一个矩阵 A，其中元素为 a_ij，我们需要计算标量函数对向量 x 的导数。

**公式**：对于 f = sum(A_ij * x_i * x_j)，其梯度 ∂f/∂x 可以通过矩阵运算求得。

### 2.2 矩阵乘法与求导

在矩阵求导中，确保乘积的形状与所需梯度的形状相匹配是关键。以下是处理矩阵乘法求导的一般步骤：

1.  明确输入和输出的维度。
2.  应用链式法则，并注意转置操作以匹配维度。
3.  验证最终结果的维度是否正确。

### 2.3 矩阵求逆的导数

对于涉及矩阵求逆的表达式，其导数有特定的公式。这在推导如线性回归闭式解等场景中非常有用。

**公式**：∂(A^{-1})/∂t = -A^{-1} * (∂A/∂t) * A^{-1}

## 机器学习导论：3：矩阵微积分与线性回归 📉

![](img/2d1474c72c360abfdb0b1f9a54b9f318_8.png)

我们已经掌握了矩阵求导的工具，现在可以将其应用于一个经典机器学习模型——线性回归，并推导其闭式解。

### 3.1 线性回归损失函数

线性回归的目标是最小化预测值与真实值之间的差距。其损失函数定义为均方误差。

**公式**：L(θ) = (1/2) * ||y - Xθ||^2
其中，`y`是目标向量，`X`是特征矩阵，`θ`是待求的参数向量。

### 3.2 损失函数的梯度

为了找到最小化损失函数的参数 θ，我们需要计算损失函数关于参数 θ 的梯度，并令其为零。

**公式**：∂L/∂θ = -X^T * (y - Xθ) = X^T (Xθ - y)

### 3.3 线性回归的闭式解

令梯度为零，我们可以直接解出参数 θ 的最优值，这就是线性回归的闭式解。

**公式**：θ* = (X^T * X)^{-1} * X^T * y

## 机器学习导论：4：前向传播 ➡️

从线性回归过渡到更复杂的模型，如神经网络，我们需要理解前向传播的过程。本节将介绍如何通过神经网络计算预测值。

### 4.1 前向传播的定义

前向传播是指输入数据从神经网络的输入层开始，经过每一层的加权求和与激活函数变换，最终得到输出层预测值的过程。

### 4.2 前向传播的步骤

以下是一个简单两层神经网络前向传播的具体步骤：

1.  **线性变换**：将输入数据 `X` 与第一层权重 `W1` 相乘并加上偏置 `b1`，得到 `Z1 = XW1 + b1`。
2.  **激活函数**：对 `Z1` 应用非线性激活函数（如Sigmoid、ReLU），得到激活值 `A1 = σ(Z1)`。
3.  **输出层**：将 `A1` 与输出层权重 `W2` 相乘并加上偏置 `b2`，得到最终输出 `ŷ = A1W2 + b2`。

### 4.3 前向传播示例

考虑一个具体网络：输入层有两个特征 (x1, x2)，隐藏层有两个节点 (z1, z2)，输出层是一个标量 ŷ。前向传播就是依次计算 z1, z2, 最后得到 ŷ 的数值过程。

## 机器学习导论：5：计算图 🕸️

为了更直观地理解前向传播以及后续的反向传播，我们引入计算图的概念。计算图是描述计算过程的强大工具。

### 5.1 计算图的定义

计算图是一种用图形表示数学表达式的方法。图中的节点代表变量（输入、参数、中间结果）或运算（加、乘、激活函数），边代表数据流向。

### 5.2 计算图的表示方法

在计算图中，每个基本运算都作为一个节点。例如，表达式 `e = (a+b) * c` 可以表示为两个节点：一个加法节点（输入a,b，输出d）和一个乘法节点（输入d,c，输出e）。

### 5.3 计算图的应用

计算图主要有三个应用：
*   **可视化计算过程**：清晰展示数据如何一步步转化为输出。
*   **自动微分**：为反向传播算法提供基础框架。
*   **优化计算**：方便识别和复用中间计算结果。

## 机器学习导论：6：反向传播 ⬅️

上一节我们通过计算图描述了信息的前向流动（预测过程）。本节我们将学习反向传播，它是让神经网络能够“学习”的关键——即计算梯度并更新权重的过程。

### 6.1 反向传播的定义

反向传播是一种基于链式法则，高效计算损失函数关于神经网络中每一个参数梯度的方法。其核心思想是从输出层开始，反向遍历计算图，将误差梯度层层传递回早期的层。

### 6.2 反向传播的步骤

反向传播遵循一个清晰的模式，以下是其主要步骤：

1.  **前向传播**：进行一次完整的预测，计算损失 `L`。
2.  **初始化输出层梯度**：计算损失 `L` 对网络输出 `ŷ` 的梯度。
3.  **反向迭代**：从输出层开始，对每一层应用链式法则：
    *   计算损失对该层**权重和偏置**的梯度。
    *   计算损失对该层**输入**的梯度，该梯度将作为前一层的“误差信号”。
4.  **参数更新**：利用计算得到的梯度，使用优化算法（如梯度下降）更新所有权重和偏置。

### 6.3 反向传播示例

以一个简单的 `sigmoid(wx + b)` 神经元为例，反向传播会计算 ∂L/∂w, ∂L/∂b 和 ∂L/∂x。∂L/∂w 和 ∂L/∂b 用于更新本层参数，而 ∂L/∂x 则继续向更早的层传播。

## 总结

本节课中我们一起学习了机器学习中几个相互关联的核心基础。我们从**矩阵微积分**开始，掌握了计算梯度的数学工具。接着，我们应用该工具推导了**线性回归的闭式解**。然后，为了理解更复杂的神经网络，我们引入了**前向传播**的概念来描述预测过程，并用**计算图**来可视化这一过程。最后，我们深入探讨了**反向传播**算法，它是训练神经网络的核心，通过计算图高效地将误差梯度从输出层反向传播回网络，以更新所有参数。这些概念构成了深度学习模型训练的理论支柱。
