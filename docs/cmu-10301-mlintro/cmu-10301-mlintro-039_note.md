# 机器学习导论：第39讲：树数据结构与二叉搜索树

在本节课中，我们将要学习一种在计算机科学和机器学习中都非常重要的数据结构——树。我们将了解树的基本组成部分、不同类型的树、以及如何遍历和操作树，特别是二叉搜索树。

## 🌳 树数据结构

树是一种层次化的数据结构，通常用于以易于导航和搜索的方式表示组织化的数据。它本质上是一个由节点和边组成的层次集合。

![](img/a8695c14c3d216c8cfe10135e0fe40db_0.png)

上一节我们介绍了树的基本概念，本节中我们来看看树的具体组成部分。

### 树的组成

以下是树的主要组成部分：

- **节点**：树中的每个圆圈代表一个节点。
- **边**：每个指向节点的箭头方向称为边。
- **根节点**：没有父节点的节点称为根节点，通常位于顶部。
- **叶节点**：没有子节点的节点称为叶节点，位于末端。
- **中间节点**：除了根节点和叶节点之外的所有节点通常称为中间节点。
- **兄弟节点**：同一级别的节点称为兄弟节点。

了解了树的构成后，我们来看看树有哪些常见的类型。

### 树的类型

以下是两种常见的树类型：

- **二叉树**：每个节点最多有两个子节点。
- **二叉搜索树**：二叉树的一种特殊类型，其中每个节点的值都严格大于其左子节点的值，并小于或等于其右子节点的值。

## 🔍 树的遍历

为了访问或搜索树中的所有节点，我们需要特定的遍历方法。主要有两种策略：广度优先和深度优先。

### 广度优先搜索（BFS）

广度优先搜索从根节点开始，逐层遍历树。在当前层遍历完成后，再遍历下一层。

### 深度优先搜索（DFS）

深度优先搜索从根节点开始，沿着一条路径尽可能深入地遍历。当到达一个节点时，再回溯并探索其他路径。

## 🌲 二叉搜索树

二叉搜索树因其高效的搜索和插入操作而被广泛应用。接下来，我们看看如何在二叉搜索树中插入节点以及如何从头构建一棵树。

### 插入节点

以下是向二叉搜索树插入新节点的规则：

- 如果要插入的值小于当前节点的值，则将其插入到左子树。
- 如果要插入的值大于当前节点的值，则将其插入到右子树。
