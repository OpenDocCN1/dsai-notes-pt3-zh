# 例题：已知训练样本 $(0,0)^T\in\omega_1$，$(1,1)^T\in\omega_2$，$(-1,1)^T\in\omega_3$，试求解向量 $w_1$、$w_2$ 和 $w_3$。

k=3，$x_k=x_3\in\omega_3$，

因为 $d_3(x_3)=-2\,d_1(x_3)=0$，$d_3(x_3)=d_2(x_3)=0$，错分，

所以 $w_1(4)=w_1(3)-x_3=(0,-2,-1)^T$

$w_2(4)=w_2(3)-x_3=(2,0,-1)^T$

$w_3(4)=w_3(3)+x_3=(-2,0,-1)^T$

k=4，$x_k=x_1\in\omega_1$，

因为 $d_1(x_1)=d_2(x_1)=-1$，$d_1(x_1)=d_3(x_1)=-1$，错分，

所以 $w_1(5)=w_1(4)+x_1=(0,-2,0)^T$

$w_2(5)=w_2(4)-x_1=(2,0,-2)^T$

$w_3(5)=w_3(4)-x_1=(-2,0,-2)^T$
