# 证明：系数矢量 \(ar{w}_0 = (w_1, w_2, \dots, w_n)'\)，是该平面的法矢量, 即 \(ar{w}_0 \perp\) 平面 \(\pi\) 。

设点 \(ar{x}_1\)、\(ar{x}_2\) 在判别界面中，故它们满足方程，于是有

```
\(ar{w}_0' \bar{x}_1 + w_{n+1} = 0\)
\(ar{w}_0' \bar{x}_2 + w_{n+1} = 0\)
```

上面二式相减，可得： \(ar{w}_0' (ar{x}_1 - ar{x}_2) = 0\)

这就表明： \(ar{w}_0 \perp (ar{x}_1 - ar{x}_2)\)

而差矢量 \((ar{x}_1 - ar{x}_2)\) 在判别界面中，由于 \(ar{x}_1\)、\(ar{x}_2\) 是 \(\pi\) 中的任意两点，故 \(ar{w}_0 \perp\) 平面 \(\pi\) 。
