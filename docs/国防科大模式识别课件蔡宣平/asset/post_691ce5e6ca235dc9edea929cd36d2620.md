本章主要介绍了贝叶斯统计决策理论为基础的贝叶斯分类方法，其中包括了最小误判概率、最小损失准则等，依据这些准则设计的分类器，从理论上讲是最优的性能，即分类的错误率或风险在所有可能的分类器中为最小，因此经常被用来作为衡量其他分类器设计方法优劣的标准。

由于正态分布在物理上的合理性和数学上的计算简便性，我们详细介绍了贝叶斯分类方法在正态分布下的几种特殊情形，导出了其对应的判决函数、决策面方程及相应的几何描述。

## 下面我们简单回顾一下本章所学的几种贝叶斯决策准则：

## 1、最小误判概率准则

两类时：如果 $l_{12}(\vec{x}) = \frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \ge \frac{P(\omega_2)}{P(\omega_1)}$ 则判 $\vec{x} \in \begin{cases} \omega_1 \\ \omega_2 \end{cases}$

多类时：如果 $P(\omega_i|\vec{x}) = \max_j [P(\omega_j|\vec{x})]$ 判 $\vec{x} \in \omega_i$

## 2、最小损失准则

两类时：如果 $\frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \ge \frac{P(\omega_2)(\lambda_{21}-\lambda_{22})}{P(\omega_1)(\lambda_{12}-\lambda_{11})}$ 则判 $\vec{x} \in \begin{cases} \omega_1 \\ \omega_2 \end{cases}$

多类时：计算 $R(\alpha_j|\vec{x}) = \sum_{i=1}^{c} \lambda_{ij} P(\omega_i|\vec{x}) \quad j = 1,2,\cdots c$

若 $R(\alpha_l|\vec{x}) = \min_{j} R(\alpha_j|\vec{x})$ 则判 $\vec{x} \in \omega_l$

## 3、含拒绝判决的最小损失准则

两类时：

p(\vec{x}|\omega_1) / p(\vec{x}|\omega_2) ≥ P(\omega_2)(1 - t) / [P(\omega_1) t]   \vec{x} ∈ \omega_1

p(\vec{x}|\omega_1) / p(\vec{x}|\omega_2) ≤ P(\omega_2) t / [P(\omega_1)(1 - t)]   \vec{x} ∈ \omega_2

P(\omega_2) t / [P(\omega_1)(1 - t)] < p(\vec{x}|\omega_1) / p(\vec{x}|\omega_2) < P(\omega_2)(1 - t) / [P(\omega_1) t]   拒绝

其中：

t = (λ_r - λ_c) / (λ_e - λ_c)

λ_r —— 拒绝损失

λ_e —— 误判损失

λ_c —— 正确判决损失

## 3、含拒绝判决的最小损失准则

多类时：计算 $R(α_j|\vec{x}) = \sum_{i=1}^{c} λ_{ij} P(ω_i|\vec{x}) \quad j = 1,2,\cdots c, c+1$

若 $R(α_l|\vec{x}) = \min_{j} R(α_j|\vec{x})$ 则判 $\vec{x} \in ω_l$

其中 $α_{c+1}$ 为拒绝判决。

## 4、最小最大损失准则

如果 p(\vec{x}|\omega_1)/p(\vec{x}|\omega_2) ≥ (λ_{21}−λ_{22})(1−P^*(\omega_1))/(λ_{12}−λ_{11})P^*(\omega_1) 则判 \vec{x} ∈ { ω₁ ω₂ }

P^*(ω₁) 是如何获得的？

让P(ω₁)从0逐渐变化到1，按最小损失准则算出最小平均损失，即取各类条件平均损失的最小者。

由此可得出R—P(ω₁)曲线，最大的R对应的P(ω₁)就是 P^*(ω₁)

## 5、N-P准则

如果 \(\frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \ge \lambda\) ， 则判 \(\vec{x} \in \begin{cases} \omega_1 \\ \omega_2 \end{cases}\)

λ是如何获得的？

由 \(\varepsilon_{21}=\int_{\mu(\lambda)}^{+\infty} p(l|\omega_2) dl = \varepsilon_0\) 固定\(\varepsilon_0\)反求\(\lambda\)

因此按最小损失准则判决时，第一、第二样本属于第二类即坦克，第三、第四属于第一类即灌木丛。
