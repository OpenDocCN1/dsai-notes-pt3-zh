# 2·3 类的定义与类间距离

# 例2.3.1 证明： $S_T = S_W + S_B$

$S_T = \frac{1}{N} \sum_{i=1}^{N} (\vec{x}_i - \vec{m})(\vec{x}_i - \vec{m})' = \frac{1}{N} \sum_{j=1}^{c} \sum_{i=1}^{n_j} (\vec{x}_i^{(j)} - \vec{m})(\vec{x}_i^{(j)} - \vec{m})'$

$S_T = \sum_{j=1}^{c} \frac{n_j}{N} \frac{1}{n_j} \sum_{i=1}^{n_j} (\vec{x}_i^{(j)} - \vec{m})(\vec{x}_i^{(j)} - \vec{m})'$

$= \sum_{j=1}^{c} \frac{n_j}{N} \left[ \frac{1}{n_j} \sum_{i=1}^{n_j} (\vec{x}_i^{(j)} - \vec{m}_j)(\vec{x}_i^{(j)} - \vec{m}_j)' + (\vec{m}_j - \vec{m})(\vec{m}_j - \vec{m})' \right]$

$= S_W + S_B$
