
将实属 ω₁类的模式 \vec{x} 判属 ω₂类的误判概率为

ε₁₂ = ∫_{Ω₂} p(\vec{x}|ω₁) d\vec{x}

将实属 ω₂类的模式判属 ω₁类的误判概率为

ε₂₁ = ∫_{Ω₁} p(\vec{x}|ω₂) d\vec{x}

N-P准则是在使某一类误判概率等于常数的约束下使另一类误判概率最小。

令 $\varepsilon_{21}=\varepsilon_0=$ **常数**，求使 $\varepsilon_{12}$ 最小。运用**拉格朗日乘数法**求条件极值，为此作辅助函数：

$$y=\varepsilon_{12}+\lambda(\varepsilon_{21}-\varepsilon_0)$$

$$=\int_{\Omega_2}p(\vec{x}|\omega_1)d\vec{x}+\lambda\left[\int_{\Omega_1}p(\vec{x}|\omega_2)d\vec{x}-\varepsilon_0\right]$$

$$=(1-\lambda\varepsilon_0)-\int_{\Omega_1}\left(p(\vec{x}|\omega_1)-\lambda p(\vec{x}|\omega_2)\right)d\vec{x}$$

## 拉格朗日乘数法：

在条件极值问题中，满足条件 g(x, y) = 0 去寻求函数 f(x, y) 的极值。对三变量函数 F(x, y, λ) = f(x, y) + λ g(x, y)

分别求F对三变量的偏导,并联立方程式
F_λ = g(x, y) = 0
F_x = f_x (x, y) + λ g_x (x, y) = 0
F_y = f_y (x, y) + λ g_y (x, y) = 0

求得的解 (x, y) 就成为极值的候补。
这样求极值的方法就叫做拉格朗日乘数法、 λ 叫做拉格朗日乘数。

$$y=(1-\lambda\varepsilon_0)-\int_{\Omega_1}\bigl(p(\vec{x}|\omega_1)-\lambda p(\vec{x}|\omega_2)\bigr)d\vec{x}$$

求 $\Omega_1$ 使 $y$ 取极小值。

一般地讲，$\Omega_1$ 无法直接用解析的办法求得。

但注意到 $\lambda$ 在式子中是确定的，$p(\vec{x}|\omega_1)$、$p(\vec{x}|\omega_2)$

在 $\Omega$ 空间中也是确定的，如果选择满足条件

$p(\vec{x}|\omega_1)-\lambda p(\vec{x}|\omega_2)>0$ 的 $\vec{x}$ 的全体作为 $\Omega_1^*$ 就能保证

这时所求得的 $y$ 值 $y^*$ 比 $\Omega_1$ 的其它取法时的 $y$ 值要小。

因为这种取法下，$\Omega_1^*$ 是使被积函数取正数的最大的域。

## 这是因为，对于任何其它取法，ω₁的新的判决类域

Ω₁' = (Ω₁* − Ω₁₁) ∪ Ω₁₂      Ω₁* 如前定义      Ω₁₁ ⊆ Ω₁*      Ω₁₂ ⊆ Ω₂*

于是 在 Ω₁₁ 上有    p(x⃗|ω₁) − λ p(x⃗|ω₂) > 0

在 Ω₁₂ 上有    p(x⃗|ω₁) − λ p(x⃗|ω₂) < 0

## 这时的 y 值为

y = (1 − λ ε₀) − ∫_{Ω₁*−Ω₁₁} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗ − ∫_{Ω₁₂} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗

= y* + ∫_{Ω₁₁} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗ − ∫_{Ω₁₂} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗

上式中第二项的积分为正值，第三项的积分为负值。

显然 y > y*

因此选择满足条件 $p(\vec{x}|\omega_1)-\lambda p(\vec{x}|\omega_2)>0$ 的全体 $\vec{x}$ 作为 $\Omega_1^*$

同理，由

$y = (\lambda - \lambda \varepsilon_0) + \int_{\Omega_2} \big( p(\vec{x}|\omega_1) - \lambda p(\vec{x}|\omega_2) \big) d\vec{x}$

选择满足条件 $p(\vec{x}|\omega_1)-\lambda p(\vec{x}|\omega_2)<0$ 的全体 $\vec{x}$ 作为 $\Omega_2^*$

综上，即：
$
\begin{cases}
\text{在 }\Omega_1\text{中} & p(\vec{x}|\omega_1)-\lambda p(\vec{x}|\omega_2)>0 \\
\text{在 }\Omega_2\text{中} & p(\vec{x}|\omega_1)-\lambda p(\vec{x}|\omega_2)<0
\end{cases}$

## 于是其中一类错误概率作为控制量而使另一类

## 错误概率最小的 N-P 判决规则为：

如果 \( \frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \ge \lambda \) ， 则判 \( \vec{x} \in \begin{cases} \omega_1 \\ \omega_2 \end{cases} \)

上式中, λ 是判决阈值。

可以看出， N-P判决规则的形式和最小误判概率准则及最小损失准则的形式相同，只是依然比阈值不同。

这里 λ 是由下列关系式确定：
ε₂₁ = ∫_{Ω₁} p(\vec{x}|ω₂) d\vec{x} = ε₀

即适当地选取 λ 以保证使 ε₂₁ = ε₀，因此

λ 的值决定着类域 Ω₁、Ω₂。

为求 λ，令 l(\vec{x}) = p(\vec{x}|ω₁) / p(\vec{x}|ω₂)

因当 l > λ 时就判 \vec{x} ∈ ω₁，所以当 ε₀ 给定后，
拉格朗日乘子 λ 可由式 ε₂₁ = ∫_{μ(λ)}^{+∞} p(l|ω₂) dl = ε₀ 确定。
这里 p(l|ω₂) 为似然比 l 的条件概密。

λ的值决定着类域 Ω₁、Ω₂，这里的 λ 是由 ε₀ 所确定的，即适当地选取 λ 使 ε₂₁=ε₀。为求 λ，令 p(l|ω₂) 为似然比 l(x) 在 x∈ω₂ 的条件下的概率密度，因为当 l>λ 时就判 x∈ω₁，所以当 ε₀ 给定后，拉格朗日乘子 λ 可由式

$$\varepsilon_{21} = \int_{\lambda}^{+\infty} p(l|\omega_2) dl = \varepsilon_0$$

确定。

实际上难于由 ε21 = ∫ p(l|ω2) dl = ε0 求得 λ 的解析显式，通常采用近似的办法。

上式的积分是λ的单调减函数，给出一系列λ值，由上式可以相应的算得一系列 ε21 值，总存在一个λ使 ε21 最接近ε0，那 个λ值便是我们所求的λ的近似值。当作得足够精细时，λ的近似值的精度就很高。

在具体运用N-P准则时，首先根据给定的控制量ε0 计算门槛λ，然后运用判决规则进行判决分类。

## 例：设两类问题中，二维模式均为正态分布，其均值向量和协方差阵分别为： μ̄₁ = (-1,0)′ μ̄₂ = (1,0)′ Σ₁ = Σ₂ = I，取定 ε₂₁ = 0.04 试求N-P判决阈值。

## 解：由公式和给定的条件可算得两类的概密分别为：

p(x̄|ω₁) = 1/(2π) exp[ -((x₁ + 1)² + x₂²)/2 ]

p(x̄|ω₂) = 1/(2π) exp[ -((x₁ - 1)² + x₂²)/2 ]

由上面二式可以算得：

p(x̄|ω₁) / p(x̄|ω₂) = exp[-2 x₁] = λ

p(x⃗|ω₁)/p(x⃗|ω₂) = exp[-2x₁] = λ

其为判决界面，上式两边取对数，于是可得判决规则：

x₁ ≷ -1/2 ln λ ⇒ x⃗ ∈ { ω₁
ω₂ }

由于界面只是 x₁ 的函数，需求 p(x⃗|ω₂) 的边缘密度 p(x₁|ω₂)

p(x₁|ω₂) = ∫_{-∞}^{∞} p(x⃗|ω₂) dx₂ = ∫_{-∞}^{∞} 1/(2π) exp[-(x₁-1)² + x₂²)/2] dx₂
= 1/√(2π) exp[-(x₁-1)²/2]

p(x₁|ω₂) = 1/√(2π) exp[-(x₁ - 1)² / 2]

## 由上面的判决规则，有：

ε₂₁ = ∫_{-∞}^{-(1/2)lnλ} 1/√(2π) exp[ -(x₁ - 1)² / 2 ] dx₁

= ∫_{-∞}^{-(1/2)lnλ -1} 1/√(2π) exp[ -y² / 2 ] dy

= 1/2 - ∫_{0}^{(1/2)lnλ +1} 1/√(2π) exp[ -y² / 2 ] dy

= 1/2 - ∫_{0}^{(√2/4)lnλ + √2/2} 1/√π exp[-z²] dz

y = x₁ - 1
dy = dx₁
