# 7.3.1 基于离差矩阵数据的变换法

所以

\[(I+S_W^{-1}S_B)U=U\widetilde{\Lambda}\]
\[S_W^{-1}S_BU=U(\widetilde{\Lambda}-I)\]

设 \(S_W^{-1}S_B\) 的特征值矩阵 \(\Lambda=diag(\lambda_1,\lambda_2,\cdots,\lambda_n)\)，则

\[I+\Lambda=\widetilde{\Lambda}\]

于是

\[J_4=\frac{|S_T|}{|S_W|}=|S_W^{-1}||S_T|=|S_W^{-1}S_T|=|U^{-1}S_W^{-1}S_TU|=\prod_{i=1}^{n}\widetilde{\lambda}_i=\prod_{i=1}^{n}(1+\lambda_i)\]
