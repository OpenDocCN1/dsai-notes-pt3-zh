# 求解最佳权矢量的方法——(2) 梯度法

由前述知，J(\vec{w}) 的梯度为 ∇J(\vec{w}) = 2X'(X\vec{w} - \vec{b})

梯度下降算法迭代公式为：

+   ① \vec{w}(0)任取；
+   ② \vec{w}(k+1) = \vec{w}(k) - \rho_k X'(X\vec{w}(k) - \vec{b})

可以证明，当\rho_k = \rho_1 / k，\rho_1为任意正的常数，则该算法使权矢量序列\{\vec{w}(k)\} 收敛于 \vec{w}^*；满足 ∇J(\vec{w}^*) = 0    \vec{w}^*也称为MSE解。
