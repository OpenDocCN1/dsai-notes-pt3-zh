# 现金识别例子(欧氏平均距离)

数据样本介绍：10个文本文件

文件名：rmb00.txt ......rmb09.txt

每个文件有4个币种的数据，分别是：

100圆、50圆、20圆、10圆

每个币种有新旧两种版本，4个方向，故有8个数据块：

如100圆的8个数据块：

data100a, data100b, data100c, data100d——老版

data100e, data100f, data100g, data100h——新版

每个数据块有8个传感器数据：

传感器1，传感器2，......，传感器8

每个传感器有60个采样数据：

数据1，数据2，......，数据60
