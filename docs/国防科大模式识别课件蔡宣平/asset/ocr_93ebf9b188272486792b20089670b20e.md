# ω_i类的判决函数可以表示为：

d_i(\vec{x}) = p(\vec{x}/ω_i)P(ω_i) 或对数形式

d_i(\vec{x}) = ln P(ω_i) - \frac{n}{2} ln(2π) - \frac{1}{2} ln|Σ_i| - \frac{1}{2} (\vec{x} - \vec{μ_i})' Σ_i^{-1} (\vec{x} - \vec{μ_i})  i = 1,2,…,c

上式中去掉与类别无关的项并不影响分类判决结果：

d_i(\vec{x}) = ln P(ω_i) - \frac{1}{2} ln|Σ_i| - \frac{1}{2} (\vec{x} - \vec{μ_i})' Σ_i^{-1} (\vec{x} - \vec{μ_i})  i = 1,2,…,c

正态分布模式的贝叶斯判决函数。

由上式可知是一超二次曲面。

多类的具体判决是： d_i(x) > d_j(x), ∀j ≠ i → x ∈ ω_i
