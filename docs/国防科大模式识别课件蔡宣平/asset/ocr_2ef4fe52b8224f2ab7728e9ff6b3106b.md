# 2·3 类的定义与类间距离

# 2.3.3 聚类的准则函数

# 一、类间距离准则

设有待分类的模式集 $\{\vec{x}_1,\vec{x}_2,\ldots,\vec{x}_N\}$ 在某种相似性测度基础上被划分为 $c$ 类，$\{\vec{x}_i^{(j)};\ j=1,2,\ldots,c;\ i=1,2,\ldots,n_j\}$。类内距离准则函数 $J_W$ 定义为：（$\vec{m}_j$ 表示 $\omega_j$ 类的模式均值矢量。）

$$J_W=\sum_{j=1}^{c}\sum_{i=1}^{n_j}\left\|\vec{x}_i^{(j)}-\vec{m}_j\right\|^2 \tag{2-3-20}$$
