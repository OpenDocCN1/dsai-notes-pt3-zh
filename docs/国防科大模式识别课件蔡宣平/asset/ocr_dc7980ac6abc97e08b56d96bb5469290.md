# 5.4 概密的窗函数估计法

# Parzen窗法

如果一个样本 $\vec{x}_j$ 落入以 $\vec{x}$ 为中心以 $h_N$ 为棱长的超立方体 $R_N$ 内时则计数为 1，否则计数为 0，我们可以利用窗函数 $\varphi(\vec{x})$ 实现这个约定，即

$\varphi(\vec{x}) = \varphi\left[ \frac{\vec{x} - \vec{x}_j}{h_N} \right]$

落入该立方体 $R_N$ 的样本数

$k_N = \sum_{j=1}^{N} \varphi\left[ \frac{\vec{x} - \vec{x}_j}{h_N} \right]$
