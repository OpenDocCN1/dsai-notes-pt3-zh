
## 5.4 概密的窗函数估计法

### 概率密度的基本估计式

$P_k = C_N^k P^k (1-P)^{N-k}$

当固定 $k$ 时，对 $P$ 的最大似然估计 $\hat{P}=k/N$，由概率论知，$k$ 的数学期望 $E[k]=NP$ 。

综上所述并根据贝努利定理可以认为 $P$ 的估计值

$\hat{P}=k/N$

设区域 $R$ 的体积为 $V$，我们取 $R$ 足够小，使

$P = \int_{R} p(\vec{x}) d\vec{x} \approx p(\vec{x}) V$

设 $\hat{p}(\vec{x})$ 是 $p(\vec{x})$ 的估计，由上面二式有

$k/N = \hat{P} = \int_{R} \hat{p}(\vec{x}) d\vec{x} = \hat{p}(\vec{x}) V$

于是可得 $\hat{p}(\vec{x}) = \dfrac{k/N}{V}$

为了提高 x 处的概密 p(x) 的估计精度，我们根据极限理论，可以采用如下步骤以尽量满足理论要求：

- (1) 构造一包含 x 的区域序列 R₁, R₂, ⋯, 各区域 R_N (N = 1,2,⋯) 的体积 V_N 满足 limₙ→∞ V_N = 0
- (2) 相对区域 R_N (N = 1,2,⋯) 作估计实验，对 R_N 取 N 个样本进行估计，设有 k_N 个样本落入 R_N 中，样本数目应满足 limₙ→∞ k_N = ∞    limₙ→∞ k_N / N = 0

则估计 $\hat p_N(\vec x)=\frac{k_N/N}{V_N}$ 处处收敛于 $p(\vec x)$。

只要区域平稳地缩小，$p(\vec x)$在$\vec x$处连续，则：

$\lim_{N\to\infty}V_N=0$可使空间平均密度$P/V$收敛于真实的密度$p(\vec x)$

$\lim_{N\to\infty}k_N=\infty$仅对$p(\vec x)\neq0$的点才有意义，亦即当$p(\vec x)\neq0$时，使$\hat p(\vec x)\neq0$，可使频率在概率意义上收敛于概率$P$

$\lim_{N\to\infty}\frac{k_N}{N}=0$是$\hat p_N(\vec x)=\frac{k_N/N}{V_N}$收敛的必要条件，它描述了
$N$的增长速度要大于$k_N$的增长速度，使$k_N/N$为无穷小，而$k_N/N$和$V_N$为同阶的无穷小，使$\frac{k_N/N}{V_N}$为非无穷大的有界数，避免了$\hat p(\vec x)\to\infty$。

满足上述三个条件的区域序列和样本选取一般有两种方法，从而形成了两种总体概密估计。

- (1) Parzen窗法
- (2) k_N 近邻估计法

使区域序列的体积 $V_N$ 按 $N$ 的某个函数随 $N$ 的增大不断地缩小。
例如： $V_N = \frac{V_1}{\sqrt{N}}$ ， 在这时应对 $k_N$ 和 $k_N / N$ 都要加以限制以使 $\hat{p}_N(\vec{x})$ 收敛于 $p(\vec{x})$。

### Parzen窗法

在 n 维特征空间中，我们取区域 R_N 是一 n 维超立方体，

h_N 为其棱长，则其体积 V_N = h_N^n 。

为能用函数描述区域 R_N 和对落入 R_N 的样本计数，定义窗函数

```
φ(u⃗) = { 1 , 当 |u_i| ≤ 1/2 , i = 1,2,…,n
          0 , 其它 }
```

u⃗ = (u₁, u₂, …, uₙ)'

这样, φ(u⃗) 以函数值 1 界定了一个以原点为中心、棱长为 1 的 n 维超立方体。

如果一个样本 $\vec{x}_j$ 落入以 $\vec{x}$ 为中心以 $h_N$ 为棱长的超立方体 $R_N$ 内时则计数为 1，否则计数为 0，我们可以利用窗函数 $\varphi(\vec{x})$ 实现这个约定，即

$\varphi(\vec{x}) = \varphi\left[ \frac{\vec{x} - \vec{x}_j}{h_N} \right]$

落入该立方体 $R_N$ 的样本数

$k_N = \sum_{j=1}^{N} \varphi\left[ \frac{\vec{x} - \vec{x}_j}{h_N} \right]$

### 得到\vec{x}点处概密估计

```
\hat{p}_N(\vec{x}) = \frac{1}{N} \sum_{j=1}^{N} \frac{1}{V_N} \varphi\left[ \frac{\vec{x} - \vec{x}_j}{h_N} \right]
```

![](img/d893b90ad57f036ece52d376593dc2c5_550_0.png)

上式实际是一个迭加函数，窗函数作迭加基函数，每个样本点处作为迭加节点，使用 $k_N$ 个以样本 $\vec{x}_j$ 为中心的窗函数迭加对 $\vec{x}$ 处的概密进行估计。显然，样本密集的区域上必然概密估计（迭加函数）值较大。这种方法称为 Parzen 窗估计法。

上面所讲的是从构造上导出了估计式，所取的窗函数即迭加基函数为n维方窗(柱)函数。事实上只要窗函数满足下面的两个条件：

φ(→u) ≥ 0    ∫ φ(→u) d→u = 1

由式

p̂_N(→x) = 1/N Σ_{j=1}^N 1/V_N φ[ (→x - →x_j)/h_N ]

构造的估计式就是概密函数。

### Parzen窗

按照上面的条件，除了选择方窗外，还可以选择其它的满足上述两个条件的函数作窗函数。下面列出几个一维窗函数的例子，n维的窗函数可用乘积的方法由一维函数构造。

- (1) 方窗函数
  φ(u) = \left\{ \begin{array}{ll} 1 , |u| \leq 1/2 \\ 0 , 其它 \end{array} \right.

下面进一步讨论窗宽 $h_N$ 对估计的影响：

定义： $\delta_N(\vec{x}) = \frac{1}{V_N} \varphi\left(\frac{\vec{x}}{h_N}\right)$

于是估计式表示成: $\hat{p}_N(\vec{x}) = \frac{1}{N} \sum_{j=1}^{N} \delta_N(\vec{x} - \vec{x}_j)$

注意到: $V_N = h_N^n$ 可看出 $h_N$ 影响 $\delta_N(\vec{x})$ 的幅度和宽度。

δ_N(\vec{x}) = \frac{1}{V_N} \varphi\left(\frac{\vec{x}}{h_N}\right) \quad \hat{p}_N(\vec{x}) = \frac{1}{N} \sum_{j=1}^{N} \delta_N(\vec{x} - \vec{x}_j)

若 h_N 较大，则 δ_N(\vec{x} - \vec{x}_j) 幅度将较小，而宽度增大

\hat{p}_N(\vec{x}) 是 N 个低幅缓变宽的函数迭加，

\hat{p}_N(\vec{x}) 较平滑，不能跟上 p(\vec{x}) 的变化，分辨率较低。
