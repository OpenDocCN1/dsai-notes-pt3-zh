# (2) \hat{p}_N(\vec{x}) 均方收敛于 p(\vec{x})

∵ \vec{x}_j (j=1,2,...,N) 独立抽取，且分布相同以及 lim_{N→∞} N V_N = ∞

∴ Var[\hat{p}_N(\vec{x})] = Var[ \frac{1}{N V_N} \sum_{j=1}^{N} \varphi(\frac{\vec{x} - \vec{x}_j}{h_N}) ] = \frac{1}{N V_N^2} Var[ \varphi(\frac{\vec{x} - \vec{x}_j}{h_N}) ]

再由式（1）求得的结果可得

Var[\hat{p}_N(\vec{x})] = \frac{1}{N V_N^2} \int \{ \varphi(\frac{\vec{x} - \vec{y}}{h_N}) - V_N E[\hat{p}_N(\vec{x})] \}^2 p(\vec{y}) d\vec{y}

= \frac{1}{N V_N} \int \frac{1}{V_N} \varphi^2(\frac{\vec{x} - \vec{y}}{h_N}) p(\vec{y}) d\vec{y} - \frac{1}{N} E[\hat{p}_N(\vec{x})]^2

由于 \int \frac{1}{V_N} \varphi^2(\frac{\vec{x} - \vec{y}}{h_N}) p(\vec{y}) dy \le Sup(\varphi(\vec{x})) E[\hat{p}_N(\vec{x})]

∴ lim_{N→∞} Var[\hat{p}_N(\vec{x})] = 0
