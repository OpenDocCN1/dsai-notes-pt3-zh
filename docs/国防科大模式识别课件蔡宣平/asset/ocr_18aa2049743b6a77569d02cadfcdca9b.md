# 总的类内离差阵定义为

```
S_W = \sum_{j=1}^c \frac{n_j}{N} S_W^{(j)}
```

# 类间离差阵定义为

```
S_B = \sum_{j=1}^c \frac{n_j}{N} (\bar{m}_j - \bar{m})(\bar{m}_j - \bar{m})'
```

式中，\bar{m} 为所有待得分类模式的均值矢量：

```
\bar{m} = \frac{1}{N} \sum_{i=1}^N \bar{x}_i
```

总的离差阵 S_T ，定义为 S_T = \frac{1}{N} \sum_{i=1}^N (\bar{x}_i - \bar{m})(\bar{x}_i - \bar{m})'

```
S_T = \frac{1}{N} \sum_{i=1}^N (\bar{x}_i - \bar{m})(\bar{x}_i - \bar{m})'
```

于是有下面关系 S_T = S_W + S_B

```
S_T = S_W + S_B
```
