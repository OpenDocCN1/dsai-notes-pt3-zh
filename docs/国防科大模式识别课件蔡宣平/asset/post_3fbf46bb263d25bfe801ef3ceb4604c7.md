# (3) 动态聚类法——改进的C均值法

- 1. 对给定的待分类模式集 \{\bar{x}_1,\bar{x}_2,\dots,\bar{x}_N\} 进行初始划分产生c类；
- 2. 计算各聚类 \omega_j 所含模式数 n_j 、均值矢量 \bar{\mu}_j 和协方差阵 \Sigma_j ；
- 3. 将各模式 \bar{x}_i 按最小距离原则分到某一聚类中。这里采用最小误判概率准则下正态分布情况的判决规则，计算模式 \bar{x} 到 \omega_j 的距离。
  
  d(\bar{x},\omega_j)=\ln|\Sigma_j| + (\bar{x}-\bar{\mu}_j)'\Sigma_j^{-1}(\bar{x}-\bar{\mu}_j)-2\ln\frac{n_j}{N}
  
  如果 d(\bar{x},\omega_k)=\min_j d(\bar{x},\omega_j) 则 \bar{x} \in \omega_k 
  
- 4. 如果没有模式改变其类别，则停止算法；否则转至2。

# 关于C-均值法收敛性的分析

C-均值法中隐含地运用了准则函数：

$$J^{(k)} = \sum_{j=1}^{c} \sum_{\vec{x}_i \in \omega_j^{(k)}} \left\| \vec{x}_i - \vec{z}_j^{(k)} \right\|^2$$

随着迭代次数k的增加，$J^{(k)}$ 趋于变小。

C-均值法算法简单且收敛（已于1974年和1967年分别给出了严格证明）。

# (1) C的调整

作一条C—J曲线，其曲率变化的最大点对应的类数是比较接近最优的类数。

在类别数未知的情况下，可使类数C由较小值逐步增加，对于每个选定的C分别使用该算法。显然准则函数J是随C的增加而单调减少。

在增加过程中，总会出现使本来较密集的类再拆开的情况，此时J虽减小，但减小速度将变缓。如果作一条C—J曲线，其曲率变化的最大点对应的类数是比较接近最优的类数。然而在许多情况下，曲线并无明显的这样的点。
