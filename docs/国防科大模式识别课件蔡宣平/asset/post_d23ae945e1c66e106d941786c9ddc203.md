
显然，这两类不是线性可分的，因而不能用一个分界点将两类分开。但是，对于一条穿过 $a$、$b$ 两点的二次曲线，

$$d(x) = (x - a)(x - b) = x^2 - (a + b)x + ab$$

当 $x \in \omega_1$ 即 $x < a$ 或 $x > b$ 时，$d(x) > 0$

当 $x \in \omega_2$ 即 $a < x < b$ 时，$d(x) < 0$

![](img/d893b90ad57f036ece52d376593dc2c5_351_0.png)

如果作非线性变换：

$$y_1 = x^2,\quad y_2 = x$$

则原来的一维特征空间映射为二维特征空间，二次判别函数 $d(x)$ 变换后在二维特征空间中映射成一次判别函数：

$$d(\vec{y}) = y_1 - (a+b) y_2 + ab$$

原来的一维非线性可分的模式在所映射的二维特征空间中是线性可分的，即：

$$\begin{cases} \vec{y} \in \omega_1 & d(\vec{y}) > 0 \\ \vec{y} \in \omega_2 & d(\vec{y}) < 0 \end{cases}$$

![](img/d893b90ad57f036ece52d376593dc2c5_352_0.png)

下图所示两类模式是线性不可分的。

![](img/d893b90ad57f036ece52d376593dc2c5_354_0.png)

经过非线性变换，两类模式是线性可分的。

![](img/d893b90ad57f036ece52d376593dc2c5_355_0.png)

可以将 $X^n$ 中非线性判别函数 $d(\vec{x})$ 的一般形式和 $\gamma^d$ 中相应的线性判别函数 $\widetilde{d}(\vec{y})$ 的关系表示如下：

$$d(\vec{x}) = w_1 f_1(\vec{x}) + w_2 f_2(\vec{x}) + \cdots + w_d f_d(\vec{x}) + w_{d+1}$$

$$= w_1 y_1 + w_2 y_2 + \cdots + w_d y_d + w_{d+1} \equiv \vec{w}' \vec{y} = \widetilde{d}(\vec{y})$$

式中

$$\vec{w} = (w_1, w_2, \cdots, w_{d+1})'$$

$$\vec{y} = (y_1, y_2, \cdots, y_d, 1)' = (f_1(\vec{x}), f_2(\vec{x}), \cdots, f_d(\vec{x}), 1)'$$

$$y_i = f_i(\vec{x}) \quad (i = 1,2,\cdots,d)$$

是 $\vec{x}$ 的单值实函数。

下面讨论两种典型的 $f_i(\vec{x})$ 的形式。

### $d(\vec{x})$ 为二次多项式

此时 $d(\vec{x})$ 的一般形式为：

$$d(\vec{x}) = \sum_{i=1}^{n} w_{ii} x_i^2 + \sum_{i=1}^{n-1} \sum_{j=i+1}^{n} w_{ij} x_i x_j + \sum_{i=1}^{n} w_i x_i + w_{n+1}$$

取 $y_i = f_i(\vec{x})$ 为二次或一次式，可使 $d(\vec{y})$ 成为线性函数。

上式右边前两项是 $x$ 各分量的二次项求和式，显然它们的项数分别为 $n$ 和 $n(n-1)/2$。

第三项是 $x$ 的各分量一次项求和式，项数为 $n$。

所以 $d(x)$ 的项数为：

$$n + \frac{n(n-1)}{2} + n + 1 = \frac{(n+1)(n+2)}{2}$$

由于有一个常数项，变换后的特征空间维数为：

$$\frac{(n+1)(n+2)}{2} - 1 = \frac{n(n+3)}{2}$$

### 2. $d(\vec{x})$ 为 $r$ 次多项式

此时 $d(\vec{x})$ 的一般形式为：

$$d(\vec{x}) = d^r(\vec{x}) + d^{r-1}(\vec{x}) + \cdots + d^1(\vec{x}) + d^0(\vec{x}) \triangleq d^{(r)}(\vec{x})$$

其中：

$$d^0(\vec{x}) = w_{n+1} = d^{(0)}(\vec{x})$$

$$d^1(\vec{x}) = \sum_{i=1}^n w_i x_i$$

$$d^2(\vec{x}) = \sum_{i_1=1}^n \sum_{i_2=i_1}^n w_{i_1 i_2} x_{i_1} x_{i_2}$$

$$d^r(\vec{x}) = \sum_{i_1=1}^n \cdots \sum_{i_r=i_{r-1}}^n w_{i_1 \dots i_r} x_{i_1} \cdots x_{i_r}$$

各项的项数分别为：

- $d^0(\vec{x})$: $1$
- $d^1(\vec{x})$: $C_n^1$
- $d^2(\vec{x})$: $C_{n+1}^2$
- ...
- $d^r(\vec{x})$: $C_{n+r-1}^r$

显然 $d^{(r)}(\vec{x})$ 可表示为：

$$d^{(0)}(\vec{x}) = w_{n+1}$$

$$d^{(r)}(\vec{x}) = d^{r}(\vec{x}) + d^{(r-1)}(\vec{x})$$

$d^{(r)}(\vec{x})$ 的项数为：

$$\sum_{k=1}^{r} C_{n+k-1}^{k} + 1 = \frac{(n+r)!}{n! r!}$$

令 $f_i(\vec{x}) = x_1^{s_1} x_2^{s_2} \cdots x_n^{s_n}$，其中 $s_1 + s_2 + \cdots + s_n \le r$。

$\vec{y}$ 的维数 $d = \frac{(n+r)!}{n!r!} - 1$。

非线性判别函数 $d(\vec{x})$ 变换成线性判别函数 $d(\vec{y})$ 后，特征空间的维数由原来的 $n$ 维增长到 $d$ 维（$d>n$），增大了二分能力。

## 3.10 二次判别函数

二次判别函数是一种常用的非线性判别函数，函数构造比较简单，适用面比线性判别函数要广。

在 $n$ 维特征空间中，二次判别函数的一般表示式为：

$$d(\vec{x}) = \vec{x}'W\vec{x} + \vec{w}'\vec{x} + w_{n+1}$$

$$= \sum_{k=1}^{n} w_{kk} x_k^2 + 2 \sum_{j=1}^{n-1} \sum_{k=j+1}^{n} w_{jk} x_j x_k + \sum_{j=1}^{n} w_j x_j + w_{n+1}$$

二次判别函数图例

![](img/d893b90ad57f036ece52d376593dc2c5_363_0.png)

一般的判别规则是：

计算训练模式 $\vec{x}_j \in \omega_1$（$j = 1,2,\cdots,N_1$）

$$\widehat{m}_1 = \frac{1}{N_1} \sum_{j=1}^{N_1} \vec{x}_j \quad \widehat{C}_1 = \frac{1}{N_1 -1} \sum_{j=1}^{N_1} (\vec{x}_j - \widehat{m}_1)(\vec{x}_j - \widehat{m}_1)'$$

构造判别函数：

$$d(\vec{x}) = K^2 - (\vec{x} - \widehat{m}_1)' \widehat{C}_1^{-1} (\vec{x} - \widehat{m}_1)$$

对未知模式：

- $d(x) > 0$ 当 $x \in \omega_1$
- $d(x) < 0$ 当 $x \in \omega_2$

## 3.12 位势函数分类法

特点：

- （1）可直接确定判决函数
- （2）适用于非线性和线性可分的情况

位势函数的概念：

位势为0的等位线——判决界面（判别函数）

对于两类问题 $\omega_1$，$\omega_2$，认为

- 如果 $x \in \omega_1$，则 $x$ 带正电荷
- 如果 $x \in \omega_2$，则 $x$ 带负电荷

为了将上述分类思想数学化，我们需定义点 $\vec{x}_j$ 处的位势函数 $K(\vec{x}, \vec{x}_j)$，它应满足：

- (1) $K(\vec{x}, \vec{x}_j) = K(\vec{x}_j, \vec{x})$
- (2) $K(\vec{x}, \vec{x}_j)$ 是连续光滑函数；
- (3) $K(\vec{x}, \vec{x}_j)$ 是 $\vec{x}$ 与 $\vec{x}_j$ 间距离的单值单调下降函数。当且仅当 $\vec{x} = \vec{x}_j$ 时，$K(\vec{x}, \vec{x}_j)$ 达其最大值。当 $\vec{x}$ 与 $\vec{x}_j$ 之间的距离趋于无穷大时，$K(\vec{x}, \vec{x}_j)$ 趋于零。
