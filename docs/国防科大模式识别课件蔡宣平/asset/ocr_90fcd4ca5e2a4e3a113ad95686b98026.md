# 3.3 判别函数值的鉴别意义、权空间及解空间

# 3.3.2 权空间、解矢与解空间

# （1）权空间

增广特征矢量与增广权矢量是对称的，判别函数可以写成 $d(\vec{x})=\vec{w}\vec{x}=\vec{x}\vec{w}=x_1w_1+x_2w_2+\cdots+x_nw_n+w_{n+1}$

这里 $x_1,x_2,\cdots,x_n,1$ 则应视为相应的 $w_i$ 的“权”

$\vec{x}$ 指向平面 $\vec{x}'\vec{w}=0$ 的正侧，即该半空间中的任一点 $\vec{w}$ 都使 $\vec{x}'\vec{w}>0$

而 $\vec{x}$ 背向的半空间中任一点 $\vec{w}$ 都有 $\vec{x}'\vec{w}<0$
