# 7.5.2 基于总的类内、类间离差矩阵、进行特征提取选择

+   依据 $S_W$、$S_B$ 作DKLT以降低特征维数的最优压缩方法

设 $\Lambda$ 和 $U$ 是对称正定阵 $S_W$ 的特征值对角阵和特征向量矩阵，作如下的白化变换

$\Lambda^{-\frac{1}{2}} U^{T} S_W U \Lambda^{-\frac{1}{2}} = I$

易知，存在正交阵 $\tilde{V}$ 可使

$\tilde{V}^{T} \Lambda^{-\frac{1}{2}} U^{T} S_B U \Lambda^{-\frac{1}{2}} \tilde{V} = \tilde{\Lambda}$

式中 $\tilde{\Lambda}$ 是白化变换后的总的类间离差矩阵的特征值对角阵。 $\tilde{S}_B = \Lambda^{-\frac{1}{2}} U^{T} S_B U \Lambda^{-\frac{1}{2}}$
