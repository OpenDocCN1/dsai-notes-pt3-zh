# 1、第一种情况（续）

例3.2.1：已知三类 ω₁, ω₂, ω₃ 的判别函数分别为：

$$egin{cases} d_1(\vec{x}) = -x_1 + x_2 \\ d_2(\vec{x}) = x_1 + x_2 - 5 \\ d_3(\vec{x}) = -x_2 + 1 \end{cases}$$

求：当 \vec{x} = (x_1, x_2)' = (6,5)' 时属于哪一类？

解：三个判别边界分别为：

$$egin{cases} d_1(\vec{x}) = -x_1 + x_2 = 0 \\ d_2(\vec{x}) = x_1 + x_2 - 5 = 0 \\ d_3(\vec{x}) = -x_2 + 1 = 0 \end{cases}$$
