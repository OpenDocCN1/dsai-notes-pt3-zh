# 5.2 参数估计

# 最大似然估计(MLE)
(Maximum Likelihood Estimate)

# 似然函数：

设一个总体 $\vec{x}$ 的概密为 $p(\vec{x}, \vec{\theta})$，其中 $\vec{\theta}$ 是一个未知参数集，当 $N$ 个随机样本取定值 $\vec{x}_1, \vec{x}_2, \cdots, \vec{x}_N$ 时，联合概密 $p(\vec{x}_1, \vec{x}_2, \cdots, \vec{x}_N, \vec{\theta})$ 称为相对于 $\vec{x}_1, \vec{x}_2, \cdots, \vec{x}_N$ 的 $\vec{\theta}$ 的似然函数。
