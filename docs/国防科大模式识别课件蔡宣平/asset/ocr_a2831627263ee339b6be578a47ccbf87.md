# 2. ωᵢ/ωⱼ 两分法（第二种情况）

此类方法同样存在不确定区。

对 c 类中的任意两类 ωᵢ 和 ωⱼ 都分别建立一个判别函数，这个判别函数将属于 ωᵢ 的模式与属于 ωⱼ 的模式区分开。此函数对其他模式分类不提供信息，因此总共需要 c(c−1)/2 个这样的判别函数。

通过训练得到区分两类 ωᵢ 和 ωⱼ 的判别函数为：
$d_{ij}(\vec{x}) = \vec{w}_{ij}' \vec{x} \quad (i,j=1,2,\dots,c; i \neq j)$

它具有性质：
$d_{ij}(\vec{x}) = \vec{w}_{ij}' \vec{x} \begin{cases} >0, \text{若 } \vec{x} \in \omega_i \\ <0, \text{若 } \vec{x} \in \omega_j \end{cases}$
$d_{ij}(\vec{x}) = -d_{ji}(\vec{x})$

判别规则是：
如果： $d_{ij}(x) > 0, \forall j \neq i$ 则判 $x \in \omega_i$
