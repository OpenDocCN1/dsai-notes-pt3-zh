# 均值向量和协方差阵的矩法估计

初始值：协方差矩阵的递推估计式：

C(1) = x⃗₁x⃗₁' - m⃗(1)m⃗(1)' = x⃗₁x⃗₁' - x⃗₁x⃗₁' = Φ

C(N+1) = 1/N Σ_{j=1}^{N+1} (x⃗_j - m⃗(N+1))(x⃗_j - m⃗(N+1))'

= 1/N Σ_{j=1}^{N+1} x⃗_j x⃗_j' - (N+1)/N m⃗(N+1)m⃗(N+1)'

= 1/N Σ_{j=1}^{N} x⃗_j x⃗_j' + 1/N x⃗_{N+1}x⃗_{N+1}' - (N+1)/N [ 1/(N+1)^2 (N m⃗(N) + x⃗_{N+1})(N m⃗(N) + x⃗_{N+1})' ]

= 1/N Σ_{j=1}^{N} x⃗_j x⃗_j' - N/(N+1) m⃗(N)m⃗(N)' - 2/(N+1) m⃗(N)x⃗_{N+1}' + 1/(N+1) x⃗_{N+1}x⃗_{N+1}'

= (N-1)/N [ 1/(N-1) Σ_{j=1}^{N} x⃗_j x⃗_j' - N/(N-1) m⃗(N)m⃗(N)' ] + 1/(N+1) (x⃗_{N+1} - m⃗(N))(x⃗_{N+1} - m⃗(N))'

= (N-1)/N C(N) + 1/(N+1) (x⃗_{N+1} - m⃗(N))(x⃗_{N+1} - m⃗(N))'
