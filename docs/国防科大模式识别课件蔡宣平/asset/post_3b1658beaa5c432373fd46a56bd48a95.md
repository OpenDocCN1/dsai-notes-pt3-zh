
⑥ 设已标准化的待分类模式集为 {\vec{x}_1, \vec{x}_2, \cdots, \vec{x}_N} 希望将它们分为C类。

设：\vec{x}_i = (x_{1i}, x_{2i}, \cdots, x_{ni})'

计算：

sum(i) = \sum_{k=1}^{n} x_{ki} \quad MA = \max_{i}[sum(i)] \quad MI = \min_{i}[sum(i)]

\alpha_i = \frac{(c-1)[sum(i)-MI]}{MA-MI}+1 \qquad (i=1,2,\cdots,N)

显然0≤α_i≤C，若α_i最接近整数j，则把x_i分划至中ω_j。对所有样本都实行上述处理，就可实现初始分类，从而产生初始聚类中心。

## 2·4 聚类的算法

### 2.4.3 动态聚类法——C-均值法的改进

#### (3) 用类核代替类心

前面的算法存在一个不足，即只用一个聚类中心点作为一类的代表，但一个点往往不能充分地反映该类的模式分布结构，从而损失了很多有用的信息。当类的分布不是球状或近似球状时，这种算法很难有较好的效果。

此时，可用类核代替类心，类核可以是一个函数、一个点集或其他适当的模型。比如前面我们讲过的马式距离。

#### (3) 动态聚类法——ISODATA算法

(Iterative Self-Organizing Data Analysis Techniques Algorithm 迭代自组织数据分析)

特点：启发性推理、分析监督、控制聚类结构及人机交互。

## 条件及约定：

设待分类的模式特征向量为 {x₁, x₂, …, x_N} ，算法运行前需设定7个初始参数。

## 算法思想：

在每轮迭代过程中，样本重新调整类别之后计算类内及类间有关参数，并和设定的门限比较，确定是两类合并为一类还是一类分裂为两类，不断地“自组织”，以达到在各参数满足设计要求条件下，使各模式到其类心的距离平方和最小。

## ISODATA算法原理步骤

### （1）预置

① 设定聚类分析控制参数：

- 1. $C$ = 预期的类数，
- 2. $N_c$ = 初始聚类中心个数（可以不等于$c$），
- 3. $\theta_n$ = 每一类中允许的最少模式数目，
- 4. $\theta_s$ = 类内各分量分布的距离标准差上界，**（分裂用）**
- 5. $\theta_D$ = 两类中心间的最小距离下界，**（合并用）**
- 6. $L$ = 在每次迭代中可以合并的类的最多对数，
- 7. $I$ = 允许的最多迭代次数。

② 将待分类的模式特征向量 {x⃗₁, x⃗₂, …, x⃗_N} 读入。

③ 选定初始聚类中心，可从待分类的模式特征向量集 {x⃗_i} 中任选 N_c 个模式特征向量作为初始聚类中心 z⃗_j (j = 1,2,…,N_c)。

(2) 按最小距离原则将模式集{\vec{x}_i}中每个模式分到某一类中，即如果 d_{il}=min_j ||\vec{x}_i - \vec{z}_j|| (i=1,2,⋯,N) 则判 \vec{x}_i ∈ ω_l 式中 d_{il} 表示 \vec{x}_i 和类 ω_l 的中心 \vec{z}_l 之间的距离。

(3) 依据 θ_n 判断合并。如果类 ω_j 中样本数 n_j < θ_n，则取消该类的中心 \vec{z}_j，N_c = N_c -1，转至(2)。

(4) 计算分类后的参数: 各类中心、类内平均距离及总体平均距离。

(4) 计算分类后的参数：各类中心、类内平均距离及总体平均距离。

① 计算各类的中心
\( \vec{z}_j = \frac{1}{n_j} \sum_{\vec{x}_i \in \omega_j} \vec{x}_i \)
\( (j = 1,2,\cdots,N_c) \)

② 计算各类中模式到类心的平均距离
\( \bar{d}_j = \frac{1}{n_j} \sum_{\vec{x}_i \in \omega_j} \| \vec{x}_i - \vec{z}_j \| \quad (j = 1,2,\cdots,N_c) \)

③ 计算各个模式到其类内中心的总体平均距离
\( \bar{d} = \frac{1}{N} \sum_{j=1}^{N_c} n_j \bar{d}_j \)

(6) 计算各类内距离的标准差矢量

σ⃗_j = (σ_{1j}, σ_{2j}, ⋯, σ_{nj})′   (j = 1,2,⋯,N_c)

σ_{kj} = [ 1/n_j Σ_{x̄_i ∈ ω_j} (x_{ki} - z_{kj})^2 ]^{1/2}   (k = 1,2,⋯,n  j = 1,2,⋯,N_c)

式中，k 为分量编号，j 为类的编号，n 为矢量维数，x_{ki} 是 x̄_i 的第 k 个分量，z_{kj} 是 z̄_j 的第 k 个分量。

(7) 对每一聚类，求出类内距离标准差矢量σ̃j中的的最大分量 σjmax = maxk |σkj|

(8) 在{σjmax}中，对任一σjmax，若有σjmax > θs，同时又满足下面两个条件之一：

- ① d̄j > d̄ 和 nj > 2(θn+1)
- ② Nc ≤ c/2

则将该类ωj分裂为两个聚类，且令Nc = Nc+1。

(9) 计算各对聚类中心间的距离
$D_{ij}=||\vec{z}_i-\vec{z}_j||\quad (i=1,2,\cdots,N_c-1;\ j=i+1,\cdots,N_c)$

(10) 依据 $\theta_D$ 判断合并。将 $D_{ij}$ 与 $\theta_D$ 比较，并将小于 $\theta_D$ 的那些 $D_{ij}$ 按递增次序排列，取前 L 个，$D_{i_1j_1}<D_{i_2j_2}<\cdots<D_{i_Lj_L}$
从最小的 $D_{ij}$ 开始，将相应的两类合并。若原来的两个类心为 $\vec{z}_i$ 和 $\vec{z}_j$，则合并后的聚类中心为
$\vec{z}_l = \frac{1}{n_i+n_j}[n_i\vec{z}_i + n_j\vec{z}_j]$
$N_c = N_c - (已并掉的类数)$。

注意：在一次迭代中，某一类最多只能被合并一次。

(1) 如果迭代次数 $I_p$ 已达 $I$ 次或过程收敛，则结束。
否则， $I_p = I_p + 1$ ，若需要调整参数，则转至(1)；
若不改变参数，则转至(2)。

## ISODATA算法总结

我们将ISODATA算法的合并和分裂的条件归纳如下：

合并的条件：

(类内样本数 < θ_n) ∨ (类的数目 ≥ 2c) ∧ (两类间中心距离<θ_D)

分裂的条件：

(类的数目 ≤ c/2) ∧ (类的某分量标准差 >θ_s) ∧ [ (d_j > d̄) ∧ (n_j > 2(θ_n +1)) ∨ (N_c ≤ c/2) ]

如果类的数目N_c 有 c/2 < N_c < 2c ，当 I_p 是奇数时分裂，当 I_p 是偶数时合并。由上述合并与分裂的判断条件可以看出算法初设的7个参数存在一定的相互制约。
