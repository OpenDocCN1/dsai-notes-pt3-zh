# 最小误判概率准则下的判决规则：

**如果，** $P(\omega_1)p(\vec{x}|\omega_1) \leq P(\omega_2)p(\vec{x}|\omega_2)$

**则判** $\vec{x} \in \{\omega_1,\ \omega_2\}$

**或等价地，** **如果，** $l_{12}(\vec{x}) = \frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \leq \frac{P(\omega_2)}{P(\omega_1)}$

**则判** $\vec{x} \in \{\omega_1,\ \omega_2\}$
