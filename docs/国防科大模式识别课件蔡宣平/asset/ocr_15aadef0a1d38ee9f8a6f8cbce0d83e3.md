# 算法步骤：

(1) 赋初值, 分别给c个权矢量wᵢ (i=1, 2, ..., c)赋任意的初值, 选择正常数ρ, 置步数k=1。

(2) 输入已知类别的增广训练模式xₖ, 计算c个判别函数

```
dᵢ(xₖ) = wᵢ' xₖ      (i=1, 2, ..., c)
```

(3) 修正权矢量, 修正规则是：

```
if (xₖ∈ωᵢ) and (dᵢ(xₖ)>dⱼ(xₖ)) (∀j≠i) then
    wᵢ(k+1) = wᵢ(k)      (i=1, 2, ..., c) (正确分类)
```

```
if (xₖ∈ωᵢ) and (dᵢ(xₖ)≤dₗ(xₖ)) (l≠i) then
    wᵢ(k+1) = wᵢ(k) + ρ xₖ
    wₗ(k+1) = wₗ(k) - ρ xₖ
    wⱼ(k+1) = wⱼ(k)   (∀ j≠i, l)
```
