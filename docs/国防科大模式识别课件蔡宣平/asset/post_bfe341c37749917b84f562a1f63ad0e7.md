
## 7.3.1 基于离差矩阵判据的变换法

U' S_T U = ⎛
  ̃λ₁   0
  ̃λ₂  ⋱
  0    ̃λ_n
⎞ = ̃Λ      U' S_W U = I

上面右式两边同时取逆，有 U⁻¹ S_w⁻¹ (U')⁻¹ = I

再与左式相乘，并左乘 U，有：
S_W⁻¹ S_T U = U ̃Λ

这里 U 及 ̃Λ 分别是特征向量组成的矩阵(特征向量矩阵)及特征值对角阵。

所以

\[(I+S_W^{-1}S_B)U=U\widetilde{\Lambda}\]
\[S_W^{-1}S_BU=U(\widetilde{\Lambda}-I)\]

设 \(S_W^{-1}S_B\) 的特征值矩阵 \(\Lambda=diag(\lambda_1,\lambda_2,\cdots,\lambda_n)\)，则

\[I+\Lambda=\widetilde{\Lambda}\]

于是

\[J_4=\frac{|S_T|}{|S_W|}=|S_W^{-1}||S_T|=|S_W^{-1}S_T|=|U^{-1}S_W^{-1}S_TU|=\prod_{i=1}^{n}\widetilde{\lambda}_i=\prod_{i=1}^{n}(1+\lambda_i)\]

例7.1 给定两类模式，其先验概率 $P(\omega_1)=P(\omega_2)$，均值矢量分别为 $\vec{m}_1=(1,3,-1)'$ 和 $\vec{m}_2=(-1,-1,1)'$，离差阵分别为

$$C_1=\begin{pmatrix}4&1&0\\1&4&0\\0&0&1\end{pmatrix},\qquad C_2=\begin{pmatrix}2&1&0\\1&2&0\\0&0&1\end{pmatrix}$$

求基于判据 $J_4$ 的最优特征提取。

# 解：

$$\vec{m}=\frac{\vec{m}_1+\vec{m}_2}{2}=(0,1,0)^T$$

$$S_w=\frac{1}{2}(C_1+C_2)=\begin{pmatrix}3&1&0\\1&3&0\\0&0&1\end{pmatrix}$$

$$S_w^{-1}=\frac{1}{8}\begin{pmatrix}3&-1&0\\-1&3&0\\0&0&8\end{pmatrix}$$

$$S_B=\frac{1}{2}\sum_{i=1}^{2}(\vec{m}_i-\vec{m})(\vec{m}_i-\vec{m})^T=\frac{1}{4}(\vec{m}_1-\vec{m}_2)(\vec{m}_1-\vec{m}_2)^T$$

由于S_W^{-1}S_B的秩为c-1=1，因此S_W^{-1}S_B只有一个非零特征值，于是特征提取矩阵W是一个3x1矩阵，此即S_W^{-1}S_B的非零特征值对应的特征向量\vec{v}。

为求该特征值应解方程： S_W^{-1} S_B \vec{v} = \lambda \vec{v}

即 \frac{1}{4} S_W^{-1} (\vec{m}_1 - \vec{m}_2)(\vec{m}_1 - \vec{m}_2)^T \vec{v} = \lambda \vec{v}

由于\frac{1}{4}(\vec{m}_1 - \vec{m}_2)^T \vec{v}是标量，于是有：

\vec{v} = S_W^{-1}(\vec{m}_1 - \vec{m}_2) = \frac{1}{8}(2,10,-16)^T

这就是所要求的最佳特征提取矩阵。

## 第七章 特征提取与选择

### 7.5 离散K-L变换及其在特征提取与选择中的应用

### 7.5.1 离散K-L变换 (DKLT)

设 n 维随机矢量 x̄ = (x₁,x₂,…,xₙ)ᵀ，其均值矢量 x̄ = E[x̄]，相关阵 Rₓ = E[x̄x̄ᵀ]，协方差阵 Cₓ = E[(x̄−x̄)(x̄−x̄)ᵀ]，x̄经正交变换后产生矢量 ȳ = (y₁,y₂,…,yₙ)ᵀ，

设有标准正交变换矩阵 $T$，（即 $T'T=I$）

$\vec{y}=T'\vec{x}=(\vec{t}_1\ \vec{t}_2\ \cdots\ \vec{t}_n)'\vec{x}=(y_1,y_2\cdots y_n)'$

$y_i=\vec{t}_i'\vec{x}\qquad(i=1,2\cdots,n)$

$\vec{x}=(T')^{-1}\vec{y}=T\vec{y}=\sum_{i=1}^{n}y_i\vec{t}_i$

（称为 $\vec{x}$ 的 K-L 展开式）

取前 $m$ 项为 $\vec{x}$ 的估计值  $\hat{\vec{x}}=\sum_{i=1}^{m}y_i\vec{t}_i\qquad 1\le m<n$

其均方误差为  $\varepsilon^2(m)=E\left[(\vec{x}-\hat{\vec{x}})'(\vec{x}-\hat{\vec{x}})\right]$

$=\sum_{i=m+1}^{n}E[y_i^2]=\sum_{i=m+1}^{n}E[y_i y_i']$

由 $R_x \vec{t}_i = \lambda_i \vec{t}_i \quad i = m+1,...,n$ 表明：

$\lambda_i$ 是 $R_x$ 的特征值，而 $\vec{t}_i$ 是相应的特征向量。

利用上式有：

$\varepsilon^2(m) = \sum_{i=m+1}^{n} \vec{t}_i' R_x \vec{t}_i = \sum_{i=m+1}^{n} \vec{t}_i' \lambda_i \vec{t}_i = \sum_{i=m+1}^{n} \lambda_i$

在上述的估计式中，如果不是简单地舍弃后 (n-m) 项，而是用预选的常数 $b_i$ 代替 $y_i$, $i=m+1,...,n$, 此时的估计式为：

$\hat{\vec{x}} = \sum_{i=1}^{m} y_i \vec{t}_i + \sum_{i=m+1}^{n} b_i \vec{t}_i$

x̂ = Σ_{i=1}^{m} y_i t⃗_i + Σ_{i=m+1}^{n} b_i t⃗_i 的均方误差为：

ε²(m) = E[(x⃗ - x̂)'(x⃗ - x̂)] = Σ_{i=m+1}^{n} E[(y_i - b_i)²]

# （1）最佳的b_i可通过 ∂ε²/∂b_i = 0 求得

∂/∂b_i {E[(y_i - b_i)²]} = 0        b_i = E[y_i] = t⃗_i' E[x⃗] = t⃗_i' x̄

ε²(m) = Σ_{i=m+1}^{n} E[(y_i - b_i)²] = Σ_{i=m+1}^{n} E[(t⃗_i' x⃗ - t⃗_i' x̄)²]

= Σ_{i=m+1}^{n} t⃗_i' E[(x⃗ - x̄)(x⃗ - x̄)'] t⃗_i = Σ_{i=m+1}^{n} t⃗_i' C_x̄ t⃗_i

# （2）求最佳的 \vec{t}_i 由 ε²(m) = Σ_{i=m+1}^{n} \vec{t}_i' C_\bar{x} \vec{t}_i

在 T'T = I 的约束条件下，为使均方误差 ε²(m) → min

作准则函数： J = Σ_{i=m+1}^{n} [ \vec{t}_i' C_\bar{x} \vec{t}_i - λ_i ( \vec{t}_i' \vec{t}_i - 1) ]

由 ∂J / ∂\vec{t}_i = \vec{0} 得 C_\bar{x} \vec{t}_i = λ_i \vec{t}_i, i = m+1,⋯,n

上式表明，\vec{t}_i 是协方差阵 C_\bar{x} 的特征值 λ_i 对应的特征向量。

将上式代入 ε²(m) 式中，可得 ε²(m) = Σ_{i=m+1}^{n} λ_i

上述的讨论可归纳为：

当我们用简单的“截断”方式产生估计式时，使均方误差最小的正交变换矩阵是随机向量x的相关阵Rₓ的特征向量矩阵；

当估计式除了选用m个分量yᵢ(i=1,2,...,m)之外，还用余下的各yᵢ的均值bᵢ代替相应的分量时，使均方误差最小的正交变换矩阵是x的协方差阵。

因为 Rₓ̄ - Cₓ̄ = x̄x̄ᵀ为非负定阵，故有 λᵢ(Rₓ̄) ≥ λᵢ(Cₓ̄) i = 1,2,⋯,n

这表明对于相同的m，第一种估计式比第二种估计式的均方差大。

## DKLT的性质

# (1) 变换后各特征分量正交或不相关

ȳ 的自相关阵和协方差阵为

R_ȳ = E[ȳ ȳᵀ] = E[(T' x)(T' x)'] = T' R_x T = ⎛ λ₁   λ₂   … ⎞
                                   ⎝       λₙ ⎠

C_y = E[(ȳ - ȳ̄)(ȳ - ȳ̄)'] = T' C_x T = ⎛ λ₁   λ₂   … ⎞
                                    ⎝       λₙ ⎠

- ① 变换后的矢量的各分量是正交的，或不相关的（因为 C=R-E(x)E(x')，当 E(x)=0 时，不相关即是正交）；
- ② λ_i=E(y_i²)，或 λ_i=E{[y_i -E(y_i)]²} （方差）
