# 下面讨论两种典型的 $f_i(\vec{x})$ 的形式

```
$d(\vec{x}) = \sum_{i=1}^{n} w_{ii} x_i^2 + \sum_{i=1}^{n-1} \sum_{j=i+1}^{n} w_{ij} x_i x_j + \sum_{i=1}^{n} w_i x_i + w_{n+1}$
```

上式右边前两项是x各分量的二次项求和式，显然它们的项数分别为n和 n(n-1)/2。

第三项是x的各分量一次项求和式，项数为n。

所以d(x)的项数为：

```
n + n(n-1)/2 + n + 1 = (n+1)(n+2)/2
```

由于有一个常数项，变换后的特征空间维数为：

```
(n+1)(n+2)/2 - 1 = n(n+3)/2
```
