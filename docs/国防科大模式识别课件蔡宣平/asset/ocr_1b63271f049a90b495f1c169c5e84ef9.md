P(L_ij < α | ω_i) = ∫_{-∞}^{α} 1/(√(2π) r_ij) exp[ - (L_ij - ½ r_ij²)² / (2 r_ij²) ] dL_ij = Φ( (α - r_ij² / 2) / r_ij )
