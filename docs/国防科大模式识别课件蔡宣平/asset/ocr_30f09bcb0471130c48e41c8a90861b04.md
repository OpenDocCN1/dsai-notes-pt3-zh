# 例题:已知训练样本(0,0)ᵀ∈ω₁, (1,1)ᵀ∈ω₂, (-1,1)ᵀ∈ω₃, 试求解向量w₁、 w₂和w₃。

k=1, x_k=x₁∈ω₁, 因为d₁(x₁)=d₂(x₁)=0, d₁(x₁)=d₃(x₁)=0, 错分, 所以: w₁(2)=w₁(1)+ x₁=(0, 0, 1)ᵀ 
 w₂(2)=w₂(1)- x₁=(0, 0, -1)ᵀ 
 w₃(2)=w₃(1)- x₁=(0, 0, -1)ᵀ

k=2, x_k=x₂∈ω₂,
因为d₂(x₂)=-1<d₁(x₂)=1, d₂(x₂)=d₃(x₂)=-1, 错分,
所以  w₁(3)=w₁(2)- x₂=(-1, -1, 0)ᵀ 
 w₂(3)=w₂(2)+ x₂=( 1, 1, 0)ᵀ 
 w₃(3)=w₃(2)- x₂=(-1, -1, -2)ᵀ
