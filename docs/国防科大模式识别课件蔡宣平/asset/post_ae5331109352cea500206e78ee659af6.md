
## 两种错误(误判概率)

ε₁₂ = ∫_{Ω₂} p(\vec{x}|ω₁) d\vec{x}      ε₂₁ = ∫_{Ω₁} p(\vec{x}|ω₂) d\vec{x}

## 设 ω₁ 和 ω₂ 类出现的概率分别为 P(ω₁) 和 P(ω₂)，则总的误判概率是

P(e) = P(ω₁)ε₁₂ + P(ω₂)ε₂₁
= P(ω₁)∫_{Ω₂} p(\vec{x}|ω₁) d\vec{x} + P(ω₂)∫_{Ω₁} p(\vec{x}|ω₂) d\vec{x}

## 误判概率 P(e) 最小等价于使正确分类概率 P(c) 最大，即：

P(c) = ∫_{Ω₁} P(ω₁) p(\vec{x}|ω₁) d\vec{x} + ∫_{Ω₂} P(ω₂) p(\vec{x}|ω₂) d\vec{x} ⇒ max

## 最小误判概率准则下的判决规则：

**如果，** $P(\omega_1)p(\vec{x}|\omega_1) \leq P(\omega_2)p(\vec{x}|\omega_2)$

**则判** $\vec{x} \in \{\omega_1,\ \omega_2\}$

**或等价地，** **如果，** $l_{12}(\vec{x}) = \frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \leq \frac{P(\omega_2)}{P(\omega_1)}$

**则判** $\vec{x} \in \{\omega_1,\ \omega_2\}$

称 l_{12}(\vec{x}) 为似然比(Likelihood Ratio),
称 θ_{12} 为似然比阈值记为 P (\omega_2 )/P (\omega_1 )

由贝叶斯定理 p(\vec{x})P(\omega_i|\vec{x}) = P(\omega_i)p(\vec{x}|\vec{x})

另一个等价形式是：

如果 P(\omega_2|\vec{x}) \gtrless P(\omega_1|\vec{x})

则判 \vec{x} \in \left\{ \begin{array}{l} \omega_1 \\ \omega_2 \end{array} \right.

对于多类问题，最小误判概率准则有如下几种等价的判决规则：

- (1) 若 $P(\omega_i|\vec{x}) > P(\omega_j|\vec{x})$, $\forall j \neq i$ ，则判 $\vec{x} \in \omega_i$
- (2) 若 $P(\omega_i|\vec{x}) = \max_j [P(\omega_j|\vec{x})]$，则判 $\vec{x} \in \omega_i$ （后验概率形式）
- (3) 若 $p(\vec{x}|\omega_i)P(\omega_i) > p(\vec{x}|\omega_j)P(\omega_j)$, $\forall j \neq i$ ，则判 $\vec{x} \in \omega_i$
- (4) 若 $p(\vec{x}|\omega_i)P(\omega_i) = \max_j [p(\vec{x}|\omega_j)P(\omega_j)]$，则判 $\vec{x} \in \omega_i$ （条件概率形式）
- (5) 若 $l_{ij}(\vec{x}) \triangleq \dfrac{p(\vec{x}|\omega_i)}{p(\vec{x}|\omega_j)} > \dfrac{P(\omega_j)}{P(\omega_i)} \triangleq \theta_{ij}$，$\forall j \neq i$ ，则判 $\vec{x} \in \omega_i$ （似然比形式）
- (6) 如果 $\ln p(\vec{x}|\omega_i) + \ln P(\omega_i) > \ln p(\vec{x}|\omega_j) + \ln P(\omega_j)$ ，$\forall j \neq i$ ，则判 $\vec{x} \in \omega_i$ （条件概率的对数形式）

例：对一批人进行癌症普查，患癌症者定为属ω₁类，正常者定为属ω₂类。统计资料表明人们患癌的概率 P(ω₁)=0.005，从而 P(ω₂)=0.995。设有一 种诊断此病的试验，其结果有阳性反应和阴性反应之分，依其作诊断。化验结果是一维离散模式特征。统计资料表明：癌症者有阳性反映的概率为0.95即 P(x=阳|ω₁)=0.95，从而可知 P(x=阴|ω₁)=0.05，正常人阳性反映的概率为0.01即P(x=阳|ω₂)=0.01，可知 P(x=阴|ω₂)=0.99。

问有阳性反映的人患癌症的概率有多大？

## 解：

P(ω₁|x=阳) = P(x=阳|ω₁)P(ω₁) / P(x=阳)

= P(x=阳|ω₁)P(ω₁) / [P(x=阳|ω₁)P(ω₁) + P(x=阳|ω₂)P(ω₂)]

= 0.95 × 0.005 / [0.95 × 0.005 + 0.01 × 0.995]

= 0.323

说明有阳性反应的人其患癌的概率有32.3%

## 写成似然比形式：

l₁₂(x) = P(x = 阳 | ω₁) / P(x = 阳 | ω₂) = 0.95 / 0.01 = 95

θ₁₂ = P(ω₂) / P(ω₁) = 0.995 / 0.005 = 197

∵ l₁₂(x) < θ₁₂    ∴ x ∈ ω₂

## 4.1.2 正态模式最小误判概率判决准则的具体形式

在 $c$ 类问题中，属于 $\omega_i$ 类的 $n$ 维模式 $\vec{x}$ 的多变量正态分布密度函数为：

$p(\vec{x}|\omega_i)=\frac{1}{(2\pi)^{n/2}|\Sigma_i|^{1/2}}\exp\left[-\frac{1}{2}(\vec{x}-\vec{\mu}_i)'\Sigma_i^{-1}(\vec{x}-\vec{\mu}_i)\right]$

式中，$\vec{\mu}_i=E_i[\vec{x}]$ 为均值矢量，

$\Sigma_i=E_i[(\vec{x}-\vec{\mu}_i)(\vec{x}-\vec{\mu}_i)']$ 为协方差矩阵

## ω_i类的判决函数可以表示为：

d_i(\vec{x}) = p(\vec{x}/ω_i)P(ω_i) 或对数形式

d_i(\vec{x}) = ln P(ω_i) - \frac{n}{2} ln(2π) - \frac{1}{2} ln|Σ_i| - \frac{1}{2} (\vec{x} - \vec{μ_i})' Σ_i^{-1} (\vec{x} - \vec{μ_i})  i = 1,2,…,c

上式中去掉与类别无关的项并不影响分类判决结果：

d_i(\vec{x}) = ln P(ω_i) - \frac{1}{2} ln|Σ_i| - \frac{1}{2} (\vec{x} - \vec{μ_i})' Σ_i^{-1} (\vec{x} - \vec{μ_i})  i = 1,2,…,c

正态分布模式的贝叶斯判决函数。

由上式可知是一超二次曲面。

多类的具体判决是： d_i(x) > d_j(x), ∀j ≠ i → x ∈ ω_i

d_i(\vec{x}) = ln P(ω_i) - \frac{1}{2} ln |Σ_i| - \frac{1}{2} (\vec{x} - \vec{μ_i})' Σ_i^{-1} (\vec{x} - \vec{μ_i}) \quad i = 1,2,⋯,c

## (1) 当 Σ_i = Σ 时

d_i(\vec{x}) = ln P(ω_i) - \frac{1}{2} (\vec{x} - \vec{μ_i})' Σ^{-1} (\vec{x} - \vec{μ_i})

= ln P(ω_i) - \frac{1}{2} \vec{x}' Σ^{-1} \vec{x} + \vec{μ_i}' Σ^{-1} \vec{x} - \frac{1}{2} \vec{μ_i}' Σ^{-1} \vec{μ_i}

## 当 ω_i 和 ω_j 相邻时

d_i(\vec{x}) - d_j(\vec{x}) = ln P(ω_i) - ln P(ω_j) + (\vec{μ_i} - \vec{μ_j})' Σ^{-1} \vec{x}

- \frac{1}{2} \vec{μ_i}' Σ^{-1} \vec{μ_i} + \frac{1}{2} \vec{μ_j}' Σ^{-1} \vec{μ_j} \triangleq \vec{w}_{ij}' (\vec{x} - \vec{x_0}) = 0

## 当ωᵢ和ωⱼ相邻时

dᵢ(x⃗) - dⱼ(x⃗) = ln P(ωᵢ) - ln P(ωⱼ) + (μ⃗ᵢ - μ⃗ⱼ)' Σ⁻¹ x⃗

    - 1/2 μ⃗ᵢ' Σ⁻¹ μ⃗ᵢ + 1/2 μ⃗ⱼ' Σ⁻¹ μ⃗ⱼ  Δ w⃗'ᵢⱼ (x⃗ - x⃗₀) = 0

## 式中：

w⃗ᵢⱼ = Σ⁻¹ (μ⃗ᵢ - μ⃗ⱼ)
x⃗₀ = 1/2 (μ⃗ᵢ + μ⃗ⱼ) - [ln[P(ωᵢ)/P(ωⱼ)]] / [(μ⃗ᵢ - μ⃗ⱼ)' Σ⁻¹ (μ⃗ᵢ - μ⃗ⱼ)] (μ⃗ᵢ - μ⃗ⱼ)

显然，该判别界面为一超平面。此决策超平面过点 x⃗₀，w⃗ᵢⱼ 是该超平面的法矢量。
