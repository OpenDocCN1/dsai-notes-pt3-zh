
## 5.4 概密的窗函数估计法
### Parzen窗法

$\delta_N(\vec{x}) = \frac{1}{V_N} \varphi\left(\frac{\vec{x}}{h_N}\right) \quad \hat{p}_N(\vec{x}) = \frac{1}{N} \sum_{j=1}^{N} \delta_N(\vec{x} - \vec{x}_j)$

当 $h_N$ 很小时，$\delta_N(\vec{x} - \vec{x}_j)$ 幅度很大，宽度很小，近似于以 $\vec{x}_j$ 为中心的 $\delta$—函数，此时 $\hat{p}_N(\vec{x})$ 是 $N$ 个以 $\vec{x}_j$ 为中心的尖脉冲在 $x$ 点处迭加，使之波动太大，不稳定，可能失去连续性。

$h_N(\vec{x})$ 的选取对 $\hat{p}_N(\vec{x})$ 的影响很大。

估计量 $\hat{p}_N(\vec{x})$ 是一随机变量，它依赖于随机的训练样本，所以估计量的性能只能用统计性质表示。

在满足下列条件下 $\hat{p}_N(\vec{x})$ 是渐近无偏估计、均方收敛、均方逼近($\vec{x}$)、且是渐近正态分布。

- (1) 概密 $p(x)$ 在 $x$ 处连续
- (2) 窗函数满足下列条件
  - ① $\varphi(\vec{u}) \ge 0$
  - ② $\int \varphi(\vec{u}) d\vec{u} = 1$
  - ③ $\sup_{\vec{u}} \varphi(\vec{u}) < \infty$
  - ④ $\lim_{\|\vec{u}\|\to\infty} \varphi(\vec{u}) \prod_{i=1}^{n} u_i = 0$

### (3) 窗宽限制
### (4) 对样本的要求

- ⑤ $\lim_{N\to\infty} V_N = 0$
- ⑥ $\lim_{N\to\infty} N V_N = \infty$
- ⑦ $\lim_{N\to\infty} k_N = \infty$
- ⑧ $\lim_{N\to\infty}\left(\frac{k_N}{N}\right)=0$

### (1) $\hat{p}_N(\vec{x})$是 $p(\vec{x})$ 的渐近无偏估计

证明：

∀$\vec{x}$, E[$\hat{p}_N(\vec{x})$]=$\frac{1}{N}\sum_{j=1}^{N}E\left[\frac{1}{V_N}\varphi\left(\frac{\vec{x}-\vec{x}_j}{h_N}\right)\right]$

(∵ $\vec{x}_j$ (j=1,2,$\cdots$,N)独立抽取，且分布相同)

= $\int \frac{1}{V_N}\varphi\left(\frac{\vec{x}-\vec{y}}{h_N}\right)p(\vec{y})d\vec{y}$

这里, $\delta_N(\vec{x})=\frac{1}{V_N}\varphi\left(\frac{\vec{x}}{h_N}\right)$

= $\int \delta_N(\vec{x}-\vec{y})p(\vec{y})d\vec{y}$

又∵ $\lim_{N\to\infty}V_N=0$, ∴ $\lim_{N\to\infty}\delta_N(\vec{x})=\delta(\vec{x})$

∴ $\lim_{N\to\infty}E[\hat{p}_N(\vec{x})]=\int\delta(\vec{x}-\vec{y})p(\vec{y})d\vec{y}=p(\vec{x})$

### (2) $\hat{p}_N(\vec{x})$ 均方收敛于 $p(\vec{x})$

∵ $\vec{x}_j$ (j=1,2,...,N) 独立抽取，且分布相同以及 lim$_{N\to\infty}$ N V_N = ∞

∴ Var[$\hat{p}_N(\vec{x})$] = Var[ $\frac{1}{N V_N} \sum_{j=1}^{N} \varphi(\frac{\vec{x} - \vec{x}_j}{h_N})$ ] = $\frac{1}{N V_N^2}$ Var[ $\varphi(\frac{\vec{x} - \vec{x}_j}{h_N})$ ]

再由式（1）求得的结果可得

Var[$\hat{p}_N(\vec{x})$] = $\frac{1}{N V_N^2} \int \{ \varphi(\frac{\vec{x} - \vec{y}}{h_N}) - V_N E[\hat{p}_N(\vec{x})] \}^2 p(\vec{y}) d\vec{y}$

= $\frac{1}{N V_N} \int \frac{1}{V_N} \varphi^2(\frac{\vec{x} - \vec{y}}{h_N}) p(\vec{y}) d\vec{y} - \frac{1}{N} E[\hat{p}_N(\vec{x})]^2$

由于 $\int \frac{1}{V_N} \varphi^2(\frac{\vec{x} - \vec{y}}{h_N}) p(\vec{y}) dy \le Sup(\varphi(\vec{x})) E[\hat{p}_N(\vec{x})]$

∴ lim$_{N\to\infty}$ Var[$\hat{p}_N(\vec{x})$] = 0

## P—窗法的特点

适用范围广，无论概密是规则的或不规则的、单峰的或多峰的。

但它要求样本分布较好且数量要大，显然这也是一个良好估计所必须的，但它的取样过程的操作增加了取样工作的复杂性。

窗函数选取得当有利于提高估计的精度和减少样本的数量。

图中，*p(x)*是均值为零、方差为1的一维正态分布，窗函数选择为正态窗函数：

```
φ(u) = 1/√(2π) exp[-1/2 u²]
```

h_N = h_1 / √N

*h₁*为可调节参量。于是：

```
p̂_N(x) = 1/N Σ_{j=1}^N 1/h_N φ((x - x_j)/h_N)
```

## 5.4 概密的窗函数估计法
### k_N-近邻估计法

在P—窗法中，把体积 V_N 作为 N 的函数导致 V_N

对估计结果影响很大。例如 V_N = V_1 / √N

当 V_1 选得太小将导致大部分区域是空的，会使 p̂_N (x̄) 不稳定；

当 V_1 选得太大，则 p̂_N (x̄) 较平坦，将丢失 p(x̄) 的一些重要空间变化。

k_N —近邻元估计法是克服这个问题的一个可能的方法。

基本思想：把含 x̄ 点的序列区域的体积 V₁,V₂,…,V_N,…

作为落入 R_N 中样本数 k_N 的函数，而不是直接作为实验样本数 N 的函数。我们可以预先确定 k_N 是 N 的某个函数，然后在 x̄ 点附近选择一“紧凑”区域，让它只含 k_N 个邻近样本。

如果 x̄ 点附近概密较大，则包含 k_N 个样本的区域体积自然就相对的小；

如果 x̄ 点附近概密较小，则区域体积就较大。显然，当区域为含有 k_N 个邻近样本而扩展到高密度区时，扩展过程必然会停止。

如果满足条件

- ① lim V_N = 0
  N→∞
- ② lim k_N = ∞
  N→∞
- ③ lim k_N / N = 0
  N→∞

则 $\hat{p}_N(\bar{x}) = \frac{k_N / N}{V_N}$ 收敛于真实的概率密度 p($\bar{x}$)。

在样本数目有限的条件下，k₁的选择也会影响估计的结果，但此方法避免了出现空的区域 R_N，消除了估计不稳定性；同时，R_N 的体积 V_N 适应于 k_N 的变化，而不是取决于 N，这也避免了出现 V_N 过大的情况，不会使估计过于平坦而严重失真。
