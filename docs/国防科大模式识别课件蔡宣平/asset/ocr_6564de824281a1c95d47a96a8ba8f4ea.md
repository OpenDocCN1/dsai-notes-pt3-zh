# 5.2 参数估计

# 最大似然估计(MLE)
(Maximum Likelihood Estimate)

$$p(\vec{x}_1,\vec{x}_2,\cdots,\vec{x}_N,\vec{\theta}) \triangleq p(X^{(N)},\vec{\theta})$$

上式中不同的 $\vec{\theta}$，$p(X^{(N)},\vec{\theta})$ 将不同。

由于 $\vec{\theta}$ 是概率的一个确定性的参数集，因此 $p(X^{(N)},\vec{\theta})$ 实际上就是条件概率 $p(X^{(N)}\mid\vec{\theta})$

如果各个 $\vec{x}_j(j=1,2,\cdots,N)$ 是独立抽取的，则进一步有：

$$p(X^{(N)}\mid\vec{\theta})=p(\vec{x}_1\mid\vec{\theta})p(\vec{x}_2\mid\vec{\theta})\cdots p(\vec{x}_N\mid\vec{\theta})=\prod_{j=1}^{N}p(\vec{x}_j\mid\vec{\theta})$$
