# 4.1.2 正态模式最小误判概率判决准则的具体形式

在 $c$ 类问题中，属于 $\omega_i$ 类的 $n$ 维模式 $\vec{x}$ 的多变量正态分布密度函数为：

$p(\vec{x}|\omega_i)=\frac{1}{(2\pi)^{n/2}|\Sigma_i|^{1/2}}\exp\left[-\frac{1}{2}(\vec{x}-\vec{\mu}_i)'\Sigma_i^{-1}(\vec{x}-\vec{\mu}_i)\right]$

式中，$\vec{\mu}_i=E_i[\vec{x}]$ 为均值矢量，

$\Sigma_i=E_i[(\vec{x}-\vec{\mu}_i)(\vec{x}-\vec{\mu}_i)']$ 为协方差矩阵
