# 三、匹配测度

# (4) Dice系数

$$m(\vec{x},\vec{y})=\frac{a}{2a+b+c}=\frac{\vec{x}'\vec{y}}{\vec{x}'\vec{x}+\vec{y}'\vec{y}}=\frac{(1-1)匹配个数}{两矢量中的总数}$$

# (5) Kulzinsky系数

$$m(\vec{x},\vec{y})=\frac{a}{b+c}=\frac{\vec{x}'\vec{y}}{\vec{x}'\vec{x}+\vec{y}'\vec{y}-2\vec{x}'\vec{y}}=\frac{(1-1)匹配个数}{(0-1)+(1-0)匹配个数}$$
