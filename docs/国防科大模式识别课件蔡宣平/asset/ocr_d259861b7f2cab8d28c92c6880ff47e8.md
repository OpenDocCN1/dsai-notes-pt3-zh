# 5.4 概密的窗函数估计法

# Parzen窗法

# 得到\vec{x}点处概密估计

```
\hat{p}_N(\vec{x}) = \frac{1}{N} \sum_{j=1}^{N} \frac{1}{V_N} \varphi\left[ \frac{\vec{x} - \vec{x}_j}{h_N} \right]
```

![](bbox=[0.04, 0.38, 0.4, 0.52])

上式实际是一个迭加函数，窗函数作迭加基函数，每个样本点处作为迭加节点，使用 $k_N$ 个以样本 $\vec{x}_j$ 为中心的窗函数迭加对 $\vec{x}$ 处的概密进行估计。显然，样本密集的区域上必然概密估计（迭加函数）值较大。这种方法称为 Parzen 窗估计法。
