# 为了将上述分类思想数学化，我们需定义点 $\vec{x}_j$ 处的位势函数 $K(\vec{x}, \vec{x}_j)$，它应满足：

+   (1) $K(\vec{x}, \vec{x}_j) = K(\vec{x}_j, \vec{x})$

+   (2) $K(\vec{x}, \vec{x}_j)$ 是连续光滑函数；

+   (3) $K(\vec{x}, \vec{x}_j)$ 是 $\vec{x}$ 与 $\vec{x}_j$ 间距离的单值单调下降函数。当且仅当 $\vec{x} = \vec{x}_j$ 时，$K(\vec{x}, \vec{x}_j)$ 达其最大值。当 $\vec{x}$ 与 $\vec{x}_j$ 之间的距离趋于无穷大时，$K(\vec{x}, \vec{x}_j)$ 趋于零。
