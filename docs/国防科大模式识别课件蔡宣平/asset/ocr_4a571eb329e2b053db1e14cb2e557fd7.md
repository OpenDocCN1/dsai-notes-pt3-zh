# 1、第一种情况（续）

判别规则为：

```
如果 \begin{cases} d_i(\vec{x}) > 0 \\ d_j(\vec{x}) \leq 0 \quad \forall j \neq i \end{cases} \quad \forall j \neq i \quad 则判 \vec{x} \in \omega_i
```

比如对图的三类问题，

+   d_1(\vec{x}) > 0
+   
+   d_2(\vec{x}) < 0
+   
+   d_3(\vec{x}) < 0

则该模式属于 ω1 类。
