P(L_{ij} < α | ω_i) = ∫_{-∞}^{α} 1/(√(2π) r_{ij}) exp[ - (L_{ij} - 1/2 r_{ij}^2)^2 / (2 r_{ij}^2) ] dL_{ij} = Φ( (α - r_{ij}^2 / 2) / r_{ij} )

P(L_{ij} > α | ω_j) = ∫_{α}^{∞} 1/(√(2π) r_{ij}) exp[ - (L_{ij} + 1/2 r_{ij}^2)^2 / (2 r_{ij}^2) ] dL_{ij} = 1 - Φ( (α + r_{ij}^2 / 2) / r_{ij} )

Φ(u) = ∫_{-∞}^{u} 1/√(2π) exp(- y^2 / 2) dy

# 于是，总的误判概率为：

P(e) = P(ω_i) P(L_{ij} < α | ω_i) + P(ω_j) P(L_{ij} > α | ω_j)

= P(ω_i) Φ[ (α - 1/2 r_{ij}^2) / r_{ij} ] + P(ω_j) { 1 - Φ[ (α + 1/2 r_{ij}^2) / r_{ij} ] }
