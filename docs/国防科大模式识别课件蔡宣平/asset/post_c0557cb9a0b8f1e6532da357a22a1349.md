## 二、相似测度

测度基础：以两矢量的方向是否相近作为考虑的基础, 矢量长度并不重要。设

x̄ = (x₁, x₂, ..., xₙ)′, ȳ = (y₁, y₂, ..., yₙ)′

+ 1. 角度相似系数(夹角余弦)

cos(x̄, ȳ) = (x̄′ȳ) / (‖x̄‖‖ȳ‖) = (x̄′ȳ) / [ (x̄′x̄)(ȳ′ȳ) ]^(1/2)      (2-2-11)

注意：坐标系的旋转和尺度的缩放是不变的, 但对一般的线性变换和坐标系的平移不具有不变性。

3. 指数相似系数

$e(\vec{x},\vec{y}) = \frac{1}{n}\sum_{i=1}^{n} \exp\left[-\frac{3}{4}\frac{(x_i - y_i)^2}{\sigma_i^2}\right]$  (2-2-13)

式中 $\sigma_i^2$ 为相应分量的协方差， $n$ 为矢量维数。
它不受量纲变化的影响。

## 二、匹配测度

当特征只有两个状态（0，1）时，常用匹配测度。

0表示无此特征 1表示有此特征。故称之为二值特征。

对于给定的x和y中的某两个相应分量xᵢ与yⱼ

若xᵢ=1, yⱼ=1 ，则称 xᵢ与yⱼ是 （1-1）匹配；

若xᵢ=1, yⱼ=0 ，则称 xᵢ与yⱼ是 （1-0）匹配；

若xᵢ=0, yⱼ=1 ，则称 xᵢ与yⱼ是 （0-1）匹配；

若xᵢ=0, yⱼ=0 ，则称 xᵢ与yⱼ是 （0-0）匹配。

## 三、匹配测度

对于二值n维特征向量可定义如下相似性测度

令 a = Σᵢ xᵢ yᵢ 为 x⃗ 与 y⃗ 的 (1-1) 匹配的特征数目

b = Σᵢ yᵢ (1 - xᵢ)    (0-1) 匹配的特征数目

c = Σᵢ xᵢ (1 - yᵢ)    (1-0) 匹配的特征数目

e = Σᵢ (1 - xᵢ)(1 - yᵢ)    (0-0) 匹配的特征数目
