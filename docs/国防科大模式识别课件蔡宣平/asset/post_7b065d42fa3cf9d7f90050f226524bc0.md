## 第四章 统计判决

客观现象或事物可以分为两类：一类是确定的，此类事物在一定条件下必然要发生或不发生；另一类是随机的，此类事物有很多可能的结果，在实验或实现前不能预知会出现哪种结果，但是其有统计规律，这种统计规律可用概率分布（密度）函数或数字特征来刻划。

- 前一章方法中，没有直接利用各类统计特性，将模式作为确定性的。
- 本章方法用于随机模式分类识别，通常称为贝叶斯判决。准则函数不同，所导出的判决规则就不同，分类结果也不同。

## “概率论” 有关概念复习

划分：设S为实验E的样本空间，B₁, B₂, ..., Bₙ为E的一组事件，若 Bᵢ∩Bⱼ=Φ，i≠j，i, j=1, 2, ..., n； B₁ ∪ B₂ ∪... ∪ Bₙ=S 则称，B₁, B₂, ..., Bₙ是样本空间S的一个划分。对每次实验，B₁, B₂, ..., Bₙ中必有一个且仅有一个发生。

全概率公式：设实验E的样本空间为S，A为E的事件，B₁, B₂, ..., Bₙ为S的一个划分，且 P(Bᵢ)>0 (i=1, 2, ..., n)，则 P(A)=P(A|B₁)P(B₁)+ P(A|B₂)P(B₂)+...+ P(A|Bₙ)P(Bₙ)

## “概率论” 有关概念复习

Bayes公式：设实验E的样本空间为S，A为E的事件，

B₁, B₂, ..., Bₙ为S的一个划分，且P(A)>0，P(Bᵢ)>0，

(i=1, 2, ..., n)，则：

$P(B_i \mid A) = \frac{P(A \mid B_i)P(B_i)}{\sum_{j=1}^{n} P(A \mid B_j)P(B_j)} = \frac{P(A \mid B_i)P(B_i)}{P(A)}$

$P(A)P(B_i \mid A) = P(B_i)P(A \mid B_i)$

### 条件概率

先验概率： P(ω_i) 表示类 ω_i 出现的先验概率，简称类 ω_i 的概率。

后验概率： P(ω_i|x) 表示 x 出现条件下类 ω_i 出现的概率，称其为类别的后验概率，对于模式识别来讲可理解为 x 来自类 ω_i 的概率。

类概率： p(x|ω_i) 表示在类 ω_i 条件下的概率密度，即类 ω_i 模式 x 的概率分布密度，简称为类概率。

## “概率论”有关概念复习

为表述简洁，我们将随机矢量及它的某个取值 **x** 都用同一个符号 **x** 表示，在以后各节中出现的是表示随机矢量还是它的一个实现根据内容是可以清楚知道的。

### 条件期望（某个特征）

$$E_i[g(\vec{x})]=\int_{X^n}g(\vec{x})p(\vec{x}|\omega_i)d\vec{x}$$

因不涉及 x 的维数，可将 $X^n$ 改写为特征空间 $\Omega$。

$$E_i[g(\vec{x})]=\int_{\Omega}g(\vec{x})p(\vec{x}|\omega_i)d\vec{x}$$

## Bayes法则—最大后验概率准则

对于两类ω₁, ω₂问题，直观地，可以根据后验概率做判别：

若 p(ω₁|x) > p(ω₂|x) 则 x ∈ ω₁

若 p(ω₁|x) < p(ω₂|x) 则 x ∈ ω₂

根据Bayes公式，后验概率 p(ω_i / x) 可由类ω_i的先验概率 P(ω_i)和条件概率密度 p(x / ω_i) 来表示，即

p(ω_i | x) = \frac{p(x | ω_i) P(ω_i)}{p(x)} = \frac{p(x | ω_i) P(ω_i)}{\sum_{i=1}^2 p(x | ω_i) P(ω_i)}

式中，p(x|ω_i)又称似然函数(likelihood function of class ω_i)，可由已知样本求得。

将P(ωi|x)代入判别式，判别规则可表示为

若 p(x⃗|ω1)P(ω1) > p(x⃗|ω2)P(ω2) 则 x⃗ ∈ ω1
若 p(x⃗|ω1)P(ω1) < p(x⃗|ω2)P(ω2) 则 x⃗ ∈ ω2

或改写为

l12 = p(x⃗|ω1)/p(x⃗|ω2) > P(ω2)/P(ω1) = θ12 则 x⃗ ∈ ω1
l12 = p(x⃗|ω1)/p(x⃗|ω2) < P(ω2)/P(ω1) = θ12 则 x⃗ ∈ ω2

l12称为似然比（likelihood ratio），θ12称为似然比的判决阈值。

原则：要确定x是属于ω1类还是ω2类，要看x是来自于ω1类的概率大还是来自ω2类的概率大。

## 例题1： 鱼类加工厂对鱼进行自动分类， ω₁:鲅鱼； ω₂:鲑鱼。模式特征x=x(长度)。

已知：（统计结果）

先验概率： P(ω₁)=1/3（鲅鱼出现的概率）

P(ω₂)=1-P(ω₁)=2/3 （鲑鱼出现的概率）

条件概率： p(x|ω₁) 见图示（鲅鱼的长度特征分布概率）

p(x|ω₂) 见图示（鲑鱼的长度特征分布概率）

求： 后验概率： P(ω|x=10)=?

（如果一条鱼x=10，是什么类别？）

## 解法1：

利用Bayes公式

$P(\omega_1 \mid x = 10) = \frac{p(x = 10 \mid \omega_1) P(\omega_1)}{p(x = 10)}$
$= \frac{p(x = 10 \mid \omega_1) P(\omega_1)}{p(x = 10 \mid \omega_1) P(\omega_1) + p(x = 10 \mid \omega_2) P(\omega_2)}$
$= \frac{0.05 \times 1/3}{0.05 \times 1/3 + 0.50 \times 2/3} = 0.048$

因为，$P(\omega_2 \mid x=10) = 1 - P(\omega_1 \mid x=10) = 1 - 0.048 = 0.952$
$P(\omega_1 \mid x=10) < P(\omega_2 \mid x=10)$

故判决：$(x=10) \in \omega_2$，即是鲑鱼。

## 解法2：

### 写成似然比形式

l₁₂(x=10) = p(x=10|ω₁) / p(x=10|ω₂) = 0.05 / 0.50 = 0.1

判决阈值 θ₁₂ = P(ω₂) / P(ω₁) = 2/3 / 1/3 = 2

∵ l₁₂(x=10) < θ₁₂ ， ∴ x ∈ ω₂ ， 即是鲑鱼。

## 4.1.1 最小误判概率准则判决

### 基本方法

根据类的概率和概密将模式的特征空间 Ω 分划成两个子空间 Ω₁ 和 Ω₂ ，即：

Ω₁ ∪ Ω₂ = Ω      Ω₁ ∩ Ω₂ = Φ

这里 Φ 是空集。

- 当 x⃗ ∈ Ω₁ 时，判 x⃗ ∈ ω₁ 类；
- 当 x⃗ ∈ Ω₂ 时，判 x⃗ ∈ ω₂ 类
