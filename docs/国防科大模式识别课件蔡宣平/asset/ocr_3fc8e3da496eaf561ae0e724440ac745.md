# （2）求解 Fisher 最佳鉴别失量

利用二次型关于矢量求导的公式可得：

$$\frac{\partial J_F}{\partial \vec{u}}=\frac{\partial}{\partial \vec{u}}\left[\frac{\vec{u}^{\prime}S_B\vec{u}}{\vec{u}^{\prime}S_W\vec{u}}\right]=\frac{2(\vec{u}^{\prime}S_W\vec{u})S_B\vec{u}-2(\vec{u}^{\prime}S_B\vec{u})S_W\vec{u}}{(\vec{u}^{\prime}S_W\vec{u})^2}=\vec{\phi}$$

令 $\lambda=\frac{\vec{u}^{\prime}S_B\vec{u}}{\vec{u}^{\prime}S_W\vec{u}}$

可得：$S_B\vec{u}=\lambda S_W\vec{u}$
