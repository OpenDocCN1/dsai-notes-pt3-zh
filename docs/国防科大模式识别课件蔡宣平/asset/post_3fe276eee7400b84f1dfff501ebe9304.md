
## 5·5 有限项正交函数级数逼近法——最小积分平方逼近法

对于 $c$ 类问题，设类概密和类概率分别为 $p(\vec{x}|\omega_i)$ 和 $P(\omega_i)$（$i=1,2,\cdots,c$），则混合概密为

$$p(\vec{x})=\sum_{i=1}^{c}P(\omega_i)p(\vec{x}|\omega_i)$$

设对每类的概密 $p(\vec{x}|\omega_i)$ 的估计 $\hat{p}(\vec{x}|\omega_i)$ 用正交函数有限项表示为

$$\hat{p}(\vec{x}|\omega_i)=\sum_{j=1}^{R}C_j^{(i)}\varphi_j(\vec{x})$$

## 5.5 有限项正交函数级数逼近法—最小积分平方逼近方法

∑_{j=1}^{R} C_j^{(i)} a_{jl} = b_l^{(i)}   (l = 1,2,⋯,R)

其中：
 a_{jl} = ∑_{s=1}^{N} φ_j(\vec{x}_s) φ_l(\vec{x}_s)   { l, j = 1,2,⋯,R
 i = 1,2,⋯,c }
 b_l^{(i)} = ∑_{s=1}^{N} φ_l(\vec{x}_s) u_i(\vec{x}_s)

u_i(\vec{x}_s) = { 1 , 当 \vec{x}_s ∈ ω_i
 0 , 当 \vec{x}_s ∉ ω_i }   (i = 1,2,⋯,c)

## 5.5 有限项正交函数数级数逼近法—最小积分平方逼近方法

```
\sum_{j=1}^{R} C_j^{(i)} a_{jl} = b_l^{(i)} \quad (l = 1,2,\cdots,R)
```

求得 $C_j^{(i)}$ $(i=1,2,\cdots,c ; j=1,2,\cdots,R)$ 后就能构造各类的概率逼近式：

```
\hat{p}(\bar{x}|\omega_i) = \sum_{j=1}^{R} C_j^{(i)} \varphi_j(\bar{x}) \quad (i=1,2,\cdots,c)
```

例：用逼近法求如下模式类别的 $p(\vec{x}|\omega_1)$ 和 $p(\vec{x}|\omega_2)$ 的估计。

解：用正交的二维Hermite多项式来构成正交函数集。

φ₁(x⃗)=φ₁(x₁,x₂)=H₀(x₁)H₀(x₂)=1

φ₂(x⃗)=φ₂(x₁,x₂)=H₁(x₁)H₀(x₂)=2x₁

φ₃(x⃗)=φ₃(x₁,x₂)=H₀(x₁)H₁(x₂)=2x₂

φ₄(x⃗)=φ₄(x₁,x₂)=H₁(x₁)H₁(x₂)=4x₁x₂

p̂(x⃗|ωᵢ)=∑_{j=1}^{4} C_{ij} φⱼ(x⃗)

i=1,2(类别号); j=1,2,3,4(正交函数项数)

C_{ij}=1/Nᵢ ∑_{k=1}^{Nᵢ} φⱼ(x⃗ₖ^{(i)})      N₁=7, N₂=6

## 最近邻方法

## 最近邻决策规则  1-NN

对于 c 类问题，设类 ωᵢ（i=1,2,…,c）有 Nᵢ 个样本 xⱼ⁽ⁱ⁾（j=1,2,…,Nᵢ）。分类的思想是：

对于一个待识别模式 x，分别计算它与 N=∑ᵢ₌₁ᶜNᵢ 个已知类别的样本 xⱼ⁽ⁱ⁾ 的距离，将它判为距离最近的那个样本所属的类。即：

$$d_i(x)=\min_{j=1,2,\ldots,N_i}\|x-x_j^{(i)}\|,\quad i=1,2,\ldots,c$$

如果 $d_m(x)=\min_{i=1,2,\ldots,c}d_i(x)$，则 $x\in\omega_m$。

## 最近邻方法

## 最近邻决策规则—k-NN

对于一个待识别模式 x, 分别计算它与 N = ∑_{i=1}^{c} N_i 个已知类别的样本 x_j^{(i)} 的距离, 取 k 个最近邻样本, 这 k 个样本中哪一类最多, 就判属哪一类。即：

d_i(x) = k_i          i = 1,2,⋯,c

显然      ∑_{i=1}^{c} k_i = k

如果      d_m(x) = max_{i=1,2,⋯,c} d_i(x)      则      x ∈ ω_m

## 剪辑最近邻方法

## 剪辑最近邻方法

对于两类问题，设将已知类别的样本集 X^(N) 分成参照集 X^(NR) 和测试集 X^(NT) 两部分，这两部分没有公共元素，它们的样本数各为 NR 和 NT，NR+NT=N。利用参照集 X^(NR) 的样本 y1, y2, …, yN 采用最近邻规则对已知类别的测试集 X^(NT) 中的每个样本 x1, x2, …, xN 进行分类，剪辑掉 X^(NT) 中被错误分类的样本。

若 y^0(x) ∈ X^(NR) 是 x ∈ X^(NT) 的最近邻元，剪辑掉不与 y^0(x) 同类的 x，余下的判决正确的样本组成剪辑样本集 X^(NTE)，这一操作称为剪辑。
