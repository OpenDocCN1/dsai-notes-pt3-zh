# 例：设有⼀个⼆维三类问题，三个判别函数为：

d₁₂(\vec{x}) = -x₁ - x₂ + 5    d₁₃(\vec{x}) = -x₁ + 3    d₂₃(\vec{x}) = -x₁ + x₂

求模式 \vec{x} = (4,3)′ 属于哪一类？

# 解：将模式 \vec{x} = (4,3)′ 代入 d_{ij}(\vec{x}) 有：

+   d₁₂(\vec{x}) = -2 ⇒ \vec{x} ∉ ω₁
+   d₂₃(\vec{x}) = -1 ⇒ \vec{x} ∉ ω₂
+   d₁₃(\vec{x}) = -1 ⇒ \vec{x} ∉ ω₁

上面三式等效为： d₂₁(\vec{x}) = 2    d₃₁(\vec{x}) = 1    d₃₂(\vec{x}) = 1

由于 d_{3j}(\vec{x}) > 0 (j = 1,2)，所以判 \vec{x} ∈ ω₃
