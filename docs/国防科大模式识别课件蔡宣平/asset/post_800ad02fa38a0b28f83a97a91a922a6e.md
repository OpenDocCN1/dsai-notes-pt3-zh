## 7.5.2 基于总的类内、类间离差矩阵、进行特征提取选择

- 基于总的类间离差矩阵 $S_B$ 的DKLT进行特征提取选择

对于 $c$ 类问题，由于 $S_B$ 的秩不大于 $c-1$，故 $S_B$ 最多有 $c-1$ 个非零特征值，而模式的维数 $n$ 通常要大于 $c$，因此依据类间离差矩阵 $S_B$ 进行特征选择是一个重要途径。具体的方法是：求出 $S_B$ 的非零特征值 $\lambda_i$ 和其相应的特征向量 $u_i$ $(i=1,2,\dots)$，按次序 $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_{c-1}$ 选取前 $d$ 个较大的特征值对应的特征向量构成变换矩阵，可实现特征的选取。

类间离差矩阵 $S_B$ 反映了各类中心到总体中心的平均平方距离，依据 $S_B$ 进行 DKLT 的目的是使各类的中心在新的坐标系某些轴上的投影相距较远，从而便于选择部分分量。

- • 基于总的类内离差矩阵 S_W 的DKLT进行特征提取选择

S_W → λ_i → ū_i (i = 1,2,⋯,n) λ_i = ū_i^T S_W ū_i
y_i = ū_i^T x̄ i = 1,2,⋯,d ; d ≤ n

构造准则函数 J(y_i) = \frac{\bar u_i^T S_B \bar u_i}{\bar u_i^T S_W \bar u_i} = \frac{\bar u_i^T S_B \bar u_i}{\lambda_i}

排序: J(y_1) ≥ J(y_2) ≥ ⋯ ≥ J(y_n), 取前面 d 个较大的 J(·) 值对应的 ū_i (i = 1,2,⋯,d)

适用于各类模式的类域在某些分量轴上的投影不重叠或较少重叠的情况。

- 依据 $S_W$、$S_B$ 作DKLT以降低特征维数的最优压缩方法

设 $\Lambda$ 和 $U$ 是对称正定阵 $S_W$ 的特征值对角阵和特征向量矩阵，作如下的白化变换

$\Lambda^{-\frac{1}{2}} U^{T} S_W U \Lambda^{-\frac{1}{2}} = I$

易知，存在正交阵 $\tilde{V}$ 可使

$\tilde{V}^{T} \Lambda^{-\frac{1}{2}} U^{T} S_B U \Lambda^{-\frac{1}{2}} \tilde{V} = \tilde{\Lambda}$

式中 $\tilde{\Lambda}$ 是白化变换后的总的类间离差矩阵的特征值对角阵。 $\tilde{S}_B = \Lambda^{-\frac{1}{2}} U^{T} S_B U \Lambda^{-\frac{1}{2}}$

由于 $S_B$ 的秩不大于 $c-1$，所以 $\tilde{S}_B$ 最多只有 $c-1$ 个非零特征值，设非零特征值共有 $d$ 个，用这 $d$ 个非零特征值所对应的特征向量 $\vec{v}_j (j=1,2,\dots,d)$ 作变换矩阵，所得的 $d$ 个分量含有原来 $n$ 维模式的全部信息。

## 7.5.2 基于类内、类间离差矩阵，进行特征提取选择

设

$V=(\vec{v}_1\ \vec{v}_2\ \cdots\ \vec{v}_d)$

则不损失信息而又达到最小维数的变换矩阵为：

$W^T=V^T\Lambda^{-1/2}U^T$

从而

$\vec{y}=W^T\vec{x}=V^T\Lambda^{-1/2}U^T\vec{x}$

当类数 $c$ 远比特征矢量维数 $n$ 小时，该方法的压缩性能是十分明显的。

## 7.7.1 次优搜索法

### （一）单独最优的特征选择

单独选优法的基本思路是：计算各特征单独使用时的判据值并以递减排序，选取前d个分类效果最好的特征。

一般地讲，即使各特征是统计独立的，这种方法选出的d个特征也不一定是最优的特征组合，只有可分性判据J是可分的时候，即

```
J(\vec{x}) = \sum_{i=1}^{n} J(x_i) 或 J(\vec{x}) = \prod_{i=0}^{n} J(x_i)
```

这种方法才能选出一组最优特征。
