
## 7.2.1 基于几何距离的可分性判据

在特征空间中，当类内模式较密集，而不同类的模式相距较远时，从直觉上我们知道分类就较容易，由各判据的构造可知，这种情况下所算得的判据值也较大。由判据的构造我们还可以初步了解运用这类判据的原则和方法。

## 7.2.2 基于类的概率密度函数的可分性判据

可用两类概密函数的重叠程度来度量可分性，构造基于类概密的可分性判据。此处的所谓重叠程度是指两个概密函数相似的程度。

由类概密构造的可分性判据 J_p 应满足：

- (1) J_p ≥ 0；
- (2) 当两类概密函数完全不重叠时， J_p = max；
- (3) 当两类概密函数完全重合时， J_p = 0；
- (4) 相对两个概密具有“对称性”。

### （一）Bhattacharyya 判据（J_B）

受相关概念与应用的启发，我们可以构造B-判据，它的计算式为

J_B = - ln ∫_Ω [p(x|ω₁) p(x|ω₂)]^{1/2} d x

式中Ω表示特征空间。在最小误判概率准则下，误判概率有

P₀(e) ≤ [P(ω₁) P(ω₂)]^{1/2} exp[- J_B]

证明：设 $P(e)$ 为误分概率，则最小误分概率为：

$P_0(e) = \min[P(e)] = \min\left[ P(\omega_1)\int_{\Omega_2} p(\vec{x}|\omega_1) d\vec{x} + P(\omega_2)\int_{\Omega_1} p(\vec{x}|\omega_2) d\vec{x} \right]$

$= \int_{\Omega} \min\left[ P(\omega_1) p(\vec{x}|\omega_1),\ P(\omega_2) p(\vec{x}|\omega_2) \right] d\vec{x}$

$\le \int_{\Omega} \left[ P(\omega_1) p(\vec{x}|\omega_1) P(\omega_2) p(\vec{x}|\omega_2) \right]^{1/2} d\vec{x}$

$= \left[ P(\omega_1) P(\omega_2) \right]^{1/2} \int_{\Omega} \left[ p(\vec{x}|\omega_1) p(\vec{x}|\omega_2) \right]^{1/2} d\vec{x}$

$= \left[ P(\omega_1) P(\omega_2) \right]^{1/2} \exp\left[ -J_B \right]$

### （二） Chernoff 判据（J_C）

我们可以构造比J_B 更一般的判据，称其为C-判据，

其定义式为

J_C = -ln ∫_Ω p(x⃗|ω₁)^s p(x⃗|ω₂)^{1-s} dx⃗

ΔJ_C(ω₁, ω₂; s)

ΔJ_C(s; x₁, x₂, …, xₙ) ΔJ_C(s)      0 < s < 1

J_C 具有如下性质：

- (1) 对一切 0 < s < 1， J_C ≥ 0；
- (2) 对一切 0 < s < 1， J_C = 0 ⇔ p(x̄|ω₁) = p(x̄|ω₂)；
- (3) 当参数 s 和 (1 − s) 互调时，有对称性，
      J_C(ω₁, ω₂; s) = J_C(ω₂, ω₁; 1 − s)
- (4) 当 x̄ 的各分量 x₁, x₂, …, xₙ 相互独立时，
      J_C(s; x₁, x₂, …, xₙ) = Σ_{i=1}^{n} J_C(s; x_i)

(5) 当x的各分量 x₁, x₂, …, xₙ 相互独立时，有

J_C(s; x₁, x₂, …, x_{k-1}) ≤ J_C(s; x₁, x₂, …, x_{k-1}, x_k)      (k ≤ n)

(6) 最小误判概率

P₀(e) ≤ P(ω₁)ˢ P(ω₂)¹⁻ˢ exp[−J_C(ω₁, ω₂; s)]   (0 < s < 1)

## Jc 性质（1）证明：

考虑函数 f(s) = s a + (1-s) b - a^s b^{1-s}    (a, b>0)

因为，当 0 ≤ s ≤ 1 时
f''(s) = -a^s b^{1-s} (ln a - ln b)^2 < 0

且 f(0)=f(1)=0，从而有 f(s)≥0。由该不等式有：

Jc(ω1, ω2, s) = -ln ∫_Ω p(→x | ω1)^s p(→x | ω2)^{1-s} d→x

≥ -ln ∫_Ω [s p(→x | ω1) + (1 - s) p(→x | ω2)] d→x = -ln(s + 1 - s) = 0

证毕。

## Jc 性质（2）证明：

只考虑连续的情况：

因为 f(0)=f(1)=0，当 0≤ s ≤1 时

f′(s) = a-b-a^s b^{1-s} (ln a - ln b)=0 ⇔ a=b

从而有 f(s)=0 ⇔ a=b，由此有：

Jc=0 ⇔ p(\vec{x} | ω₁) = p(\vec{x} | ω₂)

## Jc 性质（5）证明：

设 P(e) 为最小误分概率，则：

P₀(e) = min[P(e)] = min[ P(ω₁) ∫_{Ω₂} p(x⃗|ω₁) d x⃗ + P(ω₂) ∫_{Ω₁} p(x⃗|ω₂) d x⃗ ]
= ∫_{Ω} min[ P(ω₁) p(x⃗|ω₁), P(ω₂) p(x⃗|ω₂) ] d x⃗

利用不等式 min[a, b] ≤ a^λ b^{1-λ} (a ≥ 0, b ≥ 0, 0 ≤ λ ≤ 1)，由上式进一步可得：

P₀(e) ≤ P(ω₁)^s P(ω₂)^{1-s} ∫_{Ω} p(x⃗|ω₁)^s p(x⃗|ω₂)^{1-s} d x⃗
= P(ω₁)^s P(ω₂)^{1-s} exp[-J_C]

由 $J_B$ 和 $J_C$ 的定义知： $J_B = J_C(1/2)$

对两类都是正态分布情况：

$p(\vec{x}|\omega_1) \sim N(\vec{m}^{(1)}, C_1) \quad p(\vec{x}|\omega_2) \sim N(\vec{m}^{(2)}, C_2)$

$J_C = \frac{1}{2} s(1-s)(\vec{m}^{(1)} - \vec{m}^{(2)})^T [(1-s)C_1 + sC_2]^{-1} (\vec{m}^{(1)} - \vec{m}^{(2)}) + \frac{1}{2} \ln \frac{|(1-s)C_1 + sC_2|}{|C_1|^{1-s} \cdot |C_2|^{s}}$

$J_B = \frac{1}{8} (\vec{m}^{(1)} - \vec{m}^{(2)})^T \left[ \frac{C_1 + C_2}{2} \right]^{-1} (\vec{m}^{(1)} - \vec{m}^{(2)}) + \frac{1}{2} \ln \frac{\left| \frac{1}{2} (C_1 + C_2) \right|}{|C_1|^{1/2} \cdot |C_2|^{1/2}}$

$J_C = \frac{1}{2}s(1-s)(\vec{m}^{(1)} - \vec{m}^{(2)})^T\big[(1-s)C_1 + sC_2\big]^{-1}(\vec{m}^{(1)} - \vec{m}^{(2)}) + \frac{1}{2}\ln\frac{|(1-s)C_1 + sC_2|}{|C_1|^{1-s} \cdot |C_2|^{s}}$

$J_B = \frac{1}{8}(\vec{m}^{(1)} - \vec{m}^{(2)})^T\left[\frac{C_1 + C_2}{2}\right]^{-1}(\vec{m}^{(1)} - \vec{m}^{(2)}) + \frac{1}{2}\ln\frac{\left|\frac{1}{2}(C_1 + C_2)\right|}{|C_1|^{1/2} \cdot |C_2|^{1/2}}$

当 $C_1 = C_2 = C$ 时，

$\begin{cases} J_C = \frac{1}{2}s(1-s)(\vec{m}^{(1)} - \vec{m}^{(2)})^T C^{-1} (\vec{m}^{(1)} - \vec{m}^{(2)}) \\ J_B = \frac{1}{8}(\vec{m}^{(1)} - \vec{m}^{(2)})^T C^{-1} (\vec{m}^{(1)} - \vec{m}^{(2)}) \end{cases}$
