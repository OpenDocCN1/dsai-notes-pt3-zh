# 类内离差度 \(	ilde{S}_{W_i}^2\) 和总的类内离差度 \(	ilde{S}_W^2\) 为：

```
\(\tilde{S}_{W_i}^2 = \sum_j (y_j^{(i)} - \tilde{m}_i)^2 = \sum_j (\tilde{u}^T \tilde{x}_j - \tilde{u}^T \tilde{m}_i)^2 = \tilde{u}^T S_{W_i} \tilde{u}\)
```

```
\(\tilde{S}_W^2 = \tilde{S}_{W_1}^2 + \tilde{S}_{W_2}^2 = \tilde{u}^T (S_{W_1} + S_{W_2}) \tilde{u} = \tilde{u}^T S_W \tilde{u}\)
```

# 类间离差度为：

```
\(\tilde{S}_B^2 = (\tilde{m}_1 - \tilde{m}_2)^2 = (\tilde{u}^T \tilde{m}_1 - \tilde{u}^T \tilde{m}_2)(\tilde{u}^T \tilde{m}_1 - \tilde{u}^T \tilde{m}_2)^T = \tilde{u}^T S_B \tilde{u}\)
```
