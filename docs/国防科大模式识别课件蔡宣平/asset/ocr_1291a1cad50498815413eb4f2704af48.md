# 5.4 概率的窗函数估计法

# Parzen窗

按照上面的条件，除了选择方窗外，还可以选择其它的满足上述两个条件的函数作窗函数。下面列出几个一维窗函数的例子，n维的窗函数可用乘积的方法由一维函数构造。

+   (1) 方窗函数
+   
+   φ(u) = \left\{ \begin{array}{ll} 1 , |u| \leq 1/2 \\ 0 , 其它 \end{array} \right.

![](bbox=[0.52, 0.26, 0.95, 0.36])

+   (2) 正态窗函数
+   
+   φ(u) = \frac{1}{\sqrt{2\pi}} \exp\left[-\frac{1}{2} u^2\right]

![](bbox=[0.52, 0.36, 0.95, 0.46])

+   (3) 指数窗函数
+   
+   φ(u) = \exp[-|u|]

![](bbox=[0.52, 0.46, 0.95, 0.56])

+   (4) 三角窗函数
+   
+   φ(u) = \left\{ \begin{array}{ll} 1-|u| , |u| \leq 1 \\ 0 , |u|>1 \end{array} \right.

![](bbox=[0.52, 0.56, 0.95, 0.66])
