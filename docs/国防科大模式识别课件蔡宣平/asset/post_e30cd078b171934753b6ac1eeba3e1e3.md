## 最小最大损失准则的基本思想：

实际中，类先验概率 $P(ω_i)$ 往往不能精确知道或在分析过程中是变动的，从而导致判决域不是最佳的。所以应考虑如何解决在 $P(ω_i)$ 不确知或变动的情况下使平均损失变大的问题。应该立足最差的情况争取最好的结果。

对于两类问题，设一种分类识别决策将特征空间 Ω 分别为两个子空间 Ω₁ 和 Ω₂，记 λ_ij 为将实属 ω_i 类的模式判为 ω_j 的损失函数，各种判决的平均损失为

R = ∫_Ω R(α(\vec{x})|\vec{x}) p(\vec{x}) d\vec{x}
= ∫_{Ω₁} R(α₁(\vec{x})|\vec{x}) p(\vec{x}) d\vec{x} + ∫_{Ω₂} R(α₂(\vec{x})|\vec{x}) p(\vec{x}) d\vec{x}
= ∫_{Ω₁} Σ_{i=1}^2 λ_{i1} p(\vec{x}|ω_i) P(ω_i) d\vec{x} + ∫_{Ω₂} Σ_{i=1}^2 λ_{i2} p(\vec{x}|ω_i) P(ω_i) d\vec{x}
= λ_{11} P(ω₁) ∫_{Ω₁} p(\vec{x}|ω₁) d\vec{x} + λ_{21} P(ω₂) ∫_{Ω₁} p(\vec{x}|ω₂) d\vec{x}
+ λ_{12} P(ω₁) ∫_{Ω₂} p(\vec{x}|ω₁) d\vec{x} + λ_{22} P(ω₂) ∫_{Ω₂} p(\vec{x}|ω₂) d\vec{x}

利用 $P(ω_2)=1-P(ω_1)$ 和
$\int_{Ω_1} p(\vec{x}|ω_i) d\vec{x}=1-\int_{Ω_2} p(\vec{x}|ω_i) d\vec{x}$

则平均损失可写成

$R=λ_{22}+(λ_{21}-λ_{22})\int_{Ω_1} p(\vec{x}|ω_2) d\vec{x}$
$+P(ω_1)\left[(λ_{11}-λ_{22})+(λ_{12}-λ_{11})\int_{Ω_2} p(\vec{x}|ω_1) d\vec{x}+(λ_{22}-λ_{21})\int_{Ω_1} p(\vec{x}|ω_2) d\vec{x}\right]$

$\triangleq a+bP(ω_1)$

由于 $P(ω_1)$ 在 0 和 1 之间取值，所以平均损失值有

$a \le R \le a+b$

R = a + b P(ω₁)

+   由上式可见，当类概密、损失函数λ_ij、类域Ω_i 取定后，R是P(ω₁)的线性函数。
+   考虑P(ω₁)的各种可能取值情况，为此在区间(0, 1)中取若干个不同的P(ω₁)值，并分别按最小损失准则确定相应的最佳决策类域Ω₁、Ω₂，然后计算出其相应的最小平均损失R*，从而可得最小平均损失R*与先验概率P(ω₁)的关系曲线。

![](img/d893b90ad57f036ece52d376593dc2c5_455_0.png)

如果能求出某个 $P(ω_1) \triangleq P_B(ω_1)$，相对于 $P_B(ω_1)$ 的最佳判决类域 $Ω_1$ 和 $Ω_2$ 能使该式中的 $b=0$，即 $b = (λ_{11} - λ_{22}) + (λ_{12} - λ_{11}) \int_{Ω_2} p(\vec{x}|ω_1) d\vec{x} + (λ_{22} - λ_{21}) \int_{Ω_1} p(\vec{x}|ω_2) d\vec{x} = 0$

在此决策类域下，无论 $P(ω_1)$ 如何变化，因 $b=0$ 而使 $R$ 与 $P(ω_1)$ 无关，从而使得平均损失 $R$ 恒等于常数 $a$，即 $R = λ_{22} + (λ_{21} - λ_{22}) \int_{Ω_1} p(\vec{x}|ω_2) d\vec{x} \triangleq R^* = a$

求使 $b=0$ 的 $P(ω_1)$ 等价于在最小平均损失 $R^* \sim P(ω_1)$ 关系中求使 $dR^* / dP(ω_1) = 0$ 的 $P(ω_1)$，显然，此时的 $P(ω_1)$ 使 $R^*$ 取所有最小损失的最大值 $R_m^*$。所以 $R_m^*$ 是最大的最小损失。

R_j(\vec{x}) = \frac{\lambda_{2j} p(\vec{x}|\omega_2) + (\lambda_{1j} p(\vec{x}|\omega_1) - \lambda_{2j} p(\vec{x}|\omega_2)) P(\omega_1)}{(p(\vec{x}|\omega_2) + (p(\vec{x}|\omega_1) - p(\vec{x}|\omega_2)) P(\omega_1))}

R_j(\vec{x}) = \lambda_{1j} p(\vec{x}|\omega_1) P(\omega_1) + \lambda_{2j} p(\vec{x}|\omega_2) P(\omega_2) / (p(\vec{x}|\omega_1) P(\omega_1) + p(\vec{x}|\omega_2) P(\omega_2))

## 具体的设计过程是：

+   (1) 按最小损失准则找出对应于 (0,1) 中的各个不同值的 P(ω₁) 的最佳决策类域 Ω₁、Ω₂，
+   (2) 计算相应各个 P(ω₁) 及最佳决策类域的最小平均损失，得 R* ~ P(ω₁) 曲线，找出使 R* 取最大值的 P*(ω₁)，
+   (3) 运用 P*(ω₁)、1−P*(ω₁) 及 λ_{ij} 构造似然比阈值并运用最小损失准则下的决策规则对具体的模式分类识别。

## 最小最大损失判决规则 为：

如果 $\frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \geqslant \frac{(\lambda_{21}-\lambda_{22})(1-P^*(\omega_1))}{(\lambda_{12}-\lambda_{11})P^*(\omega_1)}$ 则判 $\vec{x} \in \begin{cases} \omega_1 \\ \omega_2 \end{cases}$

当采用 0-1 损失函数时，由 $b=0$ 可得

$\int_{\Omega_1} p(\vec{x}|\omega_2) d\vec{x} = \int_{\Omega_2} p(\vec{x}|\omega_1) d\vec{x}$

上式表明，最小最大损失判决所导出的最佳分界面应使两类错误概率相等，可知此时的平均损失

$R = \int_{\Omega_1} p(\vec{x}|\omega_2) d\vec{x}$

## 第四章 统计判决

## 4·4 N-P (Neyman—Pearson) 判决

![](img/d893b90ad57f036ece52d376593dc2c5_460_0.png)

在某些实际问题中，可能存在以下几种情况：

+   (1) 不知道各类的先验概率  P(ω_i)；
+   (2) 难以确定误判的代价  λ_ij；
+   (3) 某一种错误较另一种错误更为重要。

针对(1)，可以采用最小最大损失准则或令各类别概率相等的做法克服；

针对(2)，如果允许的话，可以避开使用损失函数而采用最小误判概率准则；

针对(3)，可以采用最小损失准则判决。针对上面的三个问题，更主要的是针对(3)，我们采用 N-P 准则。

所谓N-P准则，是严格限制较重要的一类错误概率令其等于某常数而使另一类误判概率最小。

对两类问题， $d(\vec{x})=0$ 将特征空间 $\Omega$ 分成两个子空间 $\Omega_1$ 和 $\Omega_2$，其中 $\Omega_1 \cup \Omega_2 = \Omega$， $\Omega_1 \cap \Omega_2 = \Phi$。
当一模式特征点 $\vec{x} \in \Omega_1$ 时，判决 $\vec{x} \in \omega_1$；当 $\vec{x} \in \Omega_2$ 时，判决 $\vec{x} \in \omega_2$。
