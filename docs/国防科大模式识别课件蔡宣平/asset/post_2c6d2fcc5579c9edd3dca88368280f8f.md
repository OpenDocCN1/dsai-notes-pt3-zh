
# 3.3 判别函数值的鉴别意义、权空间及解空间
### 3.3.2 权空间、解矢量与解空间
#### （3）解空间
$N$ 个训练模式将确定 $N$ 个界面，每个界面都把权空间分为两个半空间，$N$ 个正的半子空间的交空间是以权空间原点为顶点的凸多面锥。

满足上面各不等式的 $\vec{w}$ 必在该锥体中，即锥中每一点都是上面不等式组的解，解矢量不是唯一的，上述的凸多面锥包含了解的全体，称其为解区、解空间或解锥。

每一个训练模式都对解区提供一个约束，训练模式越多，解区的限制就越多，解区就越小，就越靠近解区的中心，解矢量 $\vec{w}^*$ 就越可靠，由它构造的判别函数错分的可能性就越小。

为使解矢量可靠, 使解区更小, 可以采取增加训练模式数以及引入余量b, 使 w'x ≥ b , 从而达到更好的效果。

即由 w x_j ≥ b >0 (j=1,2,…,N) 所确定的凸多面锥在 w x_j >0 (j=1,2,…,N) 所确定的多面锥的内部, 并且它的边界离开原解区边界的距离为 b / ||x_j|| 。

引入了余量可有效地避免量测的误差、引入的误差以及某些算法求得的解矢量收敛于解区的边界上，从而提高了解的可靠性。

### 3.4 Fisher线性判别
**思想：** 多维 ⇒ Fisher变换 ⇒ 利于分类的一维

# （1）求解Fish准则函数
用\vec{u}表示待求的\vec{w}_0。

设给定n维训练模式 \vec{x}_1, \vec{x}_2, …, \vec{x}_N，其中有N_1和 N_2=N−N_1 个模式分属 w_1类和 w_2类，分别记为 {\vec{x}_j^{(1)}} 和 {\vec{x}_j^{(2)}}，各类模式均值矢量为

\vec{m}_i = \frac{1}{N_i} \sum_{j} \vec{x}_j^{(i)} \quad (i=1,2)

# 各类别内离差阵 S_{W_i} 和总的类内离差阵 S_W 分别为：
S_{W_i} = \sum_{j} (\vec{x}_j^{(i)} - \vec{m}_i)(\vec{x}_j^{(i)} - \vec{m}_i)' \quad S_W = S_{W_1} + S_{W_2}

# 类内离差度 \(	ilde{S}_{W_i}^2\) 和总的类内离差度 \(	ilde{S}_W^2\) 为：
```
\(\tilde{S}_{W_i}^2 = \sum_j (y_j^{(i)} - \tilde{m}_i)^2 = \sum_j (\tilde{u}^T \tilde{x}_j - \tilde{u}^T \tilde{m}_i)^2 = \tilde{u}^T S_{W_i} \tilde{u}\)
```
```
\(\tilde{S}_W^2 = \tilde{S}_{W_1}^2 + \tilde{S}_{W_2}^2 = \tilde{u}^T (S_{W_1} + S_{W_2}) \tilde{u} = \tilde{u}^T S_W \tilde{u}\)
```
# 类间离差度为：
```
\(\tilde{S}_B^2 = (\tilde{m}_1 - \tilde{m}_2)^2 = (\tilde{u}^T \tilde{m}_1 - \tilde{u}^T \tilde{m}_2)(\tilde{u}^T \tilde{m}_1 - \tilde{u}^T \tilde{m}_2)^T = \tilde{u}^T S_B \tilde{u}\)
```

希望经投影后，类内离差度 \tilde{S}_W^2 越小越好，类间离差度 \tilde{S}_R^2 越大越好，根据这个目标作准则函数

J_F(\tilde{u}) = \frac{(\tilde{m}_1 - \tilde{m}_2)^2}{\tilde{S}_{W1}^2 + \tilde{S}_{W2}^2} = \frac{\tilde{u}' S_B \tilde{u}}{\tilde{u}' S_W \tilde{u}}

并使其最大,上式称为Fisher准则函数。

# （2）求解 Fisher 最佳鉴别失量
利用二次型关于矢量求导的公式可得：

$$\frac{\partial J_F}{\partial \vec{u}}=\frac{\partial}{\partial \vec{u}}\left[\frac{\vec{u}^{\prime}S_B\vec{u}}{\vec{u}^{\prime}S_W\vec{u}}\right]=\frac{2(\vec{u}^{\prime}S_W\vec{u})S_B\vec{u}-2(\vec{u}^{\prime}S_B\vec{u})S_W\vec{u}}{(\vec{u}^{\prime}S_W\vec{u})^2}=\vec{\phi}$$

令 $\lambda=\frac{\vec{u}^{\prime}S_B\vec{u}}{\vec{u}^{\prime}S_W\vec{u}}$

可得：$S_B\vec{u}=\lambda S_W\vec{u}$

当n较大时，S_W通常是非奇异的，于是有：
S_W^{-1} S_B \vec{u} = \lambda \vec{u}

上式表明，\vec{u} 是矩阵 S_W^{-1} S_B 相应于特征值λ的特征向量。对于两类问题，S_B 的秩为1，因此，S_W^{-1} S_B 只有一个非零特征值，其所对应的特征向量 \vec{u} 称为Fisher最佳鉴别向量，由上式可得：

\lambda \vec{u} = S_W^{-1} S_B \vec{u} = S_W^{-1} (\vec{m}_1 - \vec{m}_2)(\vec{m}_1 - \vec{m}_2)' \vec{u}

即
```
\(J_F = (\vec{m}_1 - \vec{m}_2)' S_W^{-1} (\vec{m}_1 - \vec{m}_2)\)
```
```
\(y = (\vec{m}_1 - \vec{m}_2)' S_W^{-1} \vec{x}\)
```
为Fisher变换函数

# (3) 求解Fisher判别函数
由于变换后的模式是一维的，因此判别界面实际上是各类模式所在轴上的一个点，所以可以根据训练模式确定一个阈值 y_t ，于是Fisher判别规则为：
```
ũ'x = y ≥ y_t ⇒ x̃ ∈ {ω1, ω2}
```
判别阈值可取两个类心在u方向上轴的投影连线的中点作为阈值，即：
```
y_t = \frac{\tilde{m}_1 + \tilde{m}_2}{2}
```

\(\tilde{m}_i=\frac{1}{N_i}\sum_j y_j^{(i)}=\frac{1}{N_i}\sum_j \vec{u}^{\prime}\vec{x}_j^{(i)}=\vec{u}^{\prime}\tilde{m}_i\)

# （8）计算 \(y_t\)。
\(y_t=\frac{\tilde{m}_1+\tilde{m}_2}{2}\)
