# W-H算法有两个性质

+   1. 当 $\vec{b} = (\frac{N}{N_1} \frac{N}{N_1} \cdots \frac{N}{N_1} \frac{N}{N_2} \cdots \frac{N}{N_2})'$ 时, MSE解 $\vec{w}^*$ 等价于 Fisher解。

+   2. 令 $\vec{b} = (1,1,\cdots,1)'$, 在样本数 $N \to \infty$ 时, MSE解以最小均方误差逼近贝叶斯判决函数:
+   
+   $d_B(\vec{x}) = P(\omega_1|\vec{x}) - P(\omega_2|\vec{x})$
