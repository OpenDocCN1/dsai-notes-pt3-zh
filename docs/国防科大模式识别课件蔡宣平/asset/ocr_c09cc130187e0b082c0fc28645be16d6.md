# 5.1 统计推断概述

# 基本概念

估计：所谓估计就是由样本 \vec{x}_j (j = 1,2,···,N) 按某种规则构造的一个统计量 \hat{\vec{\theta}}_N = \theta(\vec{x}_1, \vec{x}_2, ···, \vec{x}_N) 用以代替被估参数集 \vec{\theta}。估计量 \hat{\vec{\theta}}_N 作为随机样本的函数，显然也是随机量。

无偏估计：估计量 \hat{\theta}_N 的数学期望等于被估量 \vec{\theta} 的数学期望，即对任意的 N，有 E[\hat{\theta}_N] = E[\vec{\theta}]。估计无偏性的意义在于可以用多个估计的平均近似真值。
