# DKLT的性质

# (1) 变换后各特征分量正交或不相关

ȳ 的自相关阵和协方差阵为

R_ȳ = E[ȳ ȳᵀ] = E[(T' x)(T' x)'] = T' R_x T = ⎛ λ₁   λ₂   … ⎞
                                   ⎝       λₙ ⎠

C_y = E[(ȳ - ȳ̄)(ȳ - ȳ̄)'] = T' C_x T = ⎛ λ₁   λ₂   … ⎞
                                    ⎝       λₙ ⎠

+   ① 变换后的矢量的各分量是正交的，或不相关的（因为 C=R-E(x)E(x')，当 E(x)=0 时，不相关即是正交）；
+   ② λ_i=E(y_i²)，或 λ_i=E{[y_i -E(y_i)]²} （方差）
