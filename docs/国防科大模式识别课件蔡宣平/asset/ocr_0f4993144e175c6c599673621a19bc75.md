对于两类问题，设一种分类识别决策将特征空间 Ω 分别为两个子空间 Ω₁ 和 Ω₂，记 λ_ij 为将实属 ω_i 类的模式判为 ω_j 的损失函数，各种判决的平均损失为

R = ∫_Ω R(α(\vec{x})|\vec{x}) p(\vec{x}) d\vec{x}
= ∫_{Ω₁} R(α₁(\vec{x})|\vec{x}) p(\vec{x}) d\vec{x} + ∫_{Ω₂} R(α₂(\vec{x})|\vec{x}) p(\vec{x}) d\vec{x}
= ∫_{Ω₁} Σ_{i=1}^2 λ_{i1} p(\vec{x}|ω_i) P(ω_i) d\vec{x} + ∫_{Ω₂} Σ_{i=1}^2 λ_{i2} p(\vec{x}|ω_i) P(ω_i) d\vec{x}
= λ_{11} P(ω₁) ∫_{Ω₁} p(\vec{x}|ω₁) d\vec{x} + λ_{21} P(ω₂) ∫_{Ω₁} p(\vec{x}|ω₂) d\vec{x}
+ λ_{12} P(ω₁) ∫_{Ω₂} p(\vec{x}|ω₁) d\vec{x} + λ_{22} P(ω₂) ∫_{Ω₂} p(\vec{x}|ω₂) d\vec{x}
