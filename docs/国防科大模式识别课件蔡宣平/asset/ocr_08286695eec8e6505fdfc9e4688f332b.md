# 当ωᵢ和ωⱼ相邻时

dᵢ(x⃗) - dⱼ(x⃗) = ln P(ωᵢ) - ln P(ωⱼ) + (μ⃗ᵢ - μ⃗ⱼ)' Σ⁻¹ x⃗

    - 1/2 μ⃗ᵢ' Σ⁻¹ μ⃗ᵢ + 1/2 μ⃗ⱼ' Σ⁻¹ μ⃗ⱼ  Δ w⃗'ᵢⱼ (x⃗ - x⃗₀) = 0

# 式中：

w⃗ᵢⱼ = Σ⁻¹ (μ⃗ᵢ - μ⃗ⱼ)
x⃗₀ = 1/2 (μ⃗ᵢ + μ⃗ⱼ) - [ln[P(ωᵢ)/P(ωⱼ)]] / [(μ⃗ᵢ - μ⃗ⱼ)' Σ⁻¹ (μ⃗ᵢ - μ⃗ⱼ)] (μ⃗ᵢ - μ⃗ⱼ)

显然，该判别界面为一超平面。此决策超平面过点 x⃗₀，w⃗ᵢⱼ 是该超平面的法矢量。
