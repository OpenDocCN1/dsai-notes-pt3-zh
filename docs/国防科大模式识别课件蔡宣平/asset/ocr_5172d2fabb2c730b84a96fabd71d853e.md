可以将 $X^n$ 中非线性判别函数 $d(\vec{x})$ 的一般形式和 $\gamma^d$ 中相应的线性判别函数 $\widetilde{d}(\vec{y})$ 的关系表示如下：

$d(\vec{x}) = w_1 f_1(\vec{x}) + w_2 f_2(\vec{x}) + \cdots + w_d f_d(\vec{x}) + w_{d+1}$

$= w_1 y_1 + w_2 y_2 + \cdots + w_d y_d + w_{d+1} \equiv \vec{w}' \vec{y} = \widetilde{d}(\vec{y})$

式中 $\vec{w} = (w_1, w_2, \cdots, w_{d+1})'$ 

$\vec{y} = (y_1, y_2, \cdots, y_d, 1)' = (f_1(\vec{x}), f_2(\vec{x}), \cdots, f_d(\vec{x}), 1)'$

$y_i = f_i(\vec{x}) \,(i = 1,2,\cdots,d)$ 是 $\vec{x}$ 的单值实函数。
