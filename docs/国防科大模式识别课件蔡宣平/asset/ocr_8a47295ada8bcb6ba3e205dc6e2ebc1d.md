# 7.2.1 基于几何距离的可分性判据

# （一） 点与点的距离

$d(\vec{a},\vec{b})=\left[(\vec{a}-\vec{b})^{\mathrm{T}}(\vec{a}-\vec{b})\right]^{1/2}=\left[\sum_{k=1}^{n}(a_k-b_k)^2\right]^{1/2}$

# （二） 点到点集的距离

用均方欧氏距离表示

$\bar{d}^{2}\left(\vec{x},\{\vec{a}_{k}^{(i)}\}\right)=\frac{1}{N_i}\sum_{k=1}^{N_i}d^{2}\left(\vec{x},\vec{a}_{k}^{(i)}\right)$
