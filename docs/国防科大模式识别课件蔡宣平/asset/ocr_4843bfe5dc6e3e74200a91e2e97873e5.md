λ₁₁ p(\vec{x}|ω₁) P(ω₁) + λ₂₁ p(\vec{x}|ω₂) P(ω₂) ≤
λ₁₂ p(\vec{x}|ω₁) P(ω₁) + λ₂₂ p(\vec{x}|ω₂) P(ω₂)

经整理可得：

(λ₂₁ − λ₂₂) p(\vec{x}|ω₂) P(ω₂) ≤ (λ₁₂ − λ₁₁) p(\vec{x}|ω₁) P(ω₁)

# 两类问题的最小损失准则的似然比形式的判决规则为：

如果 \frac{p(\vec{x}|ω₁)}{p(\vec{x}|ω₂)} ≥ \frac{P(ω₂)(λ₂₁ − λ₂₂)}{P(ω₁)(λ₁₂ − λ₁₁)} 则判 \vec{x} ∈ { ω₁ \n ω₂ }
