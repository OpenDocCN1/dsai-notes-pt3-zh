# 7.2.2基于类的概率密度函数的可分性判据

J_D = I_{ij}(\vec{x}) + I_{ji}(\vec{x})
= \int_{\Omega} [p(\vec{x} | \omega_i) - p(\vec{x} | \omega_j)] \ln \frac{p(\vec{x} | \omega_i)}{p(\vec{x} | \omega_j)} d\vec{x}

\Delta J_D(\omega_i, \omega_j) \triangleq \Delta J_D(x_1, \cdots, x_n)

当两类都是正态分布时：

J_D = \frac{1}{2} Tr[C_i^{-1} C_j + C_j^{-1} C_i - 2I] + \frac{1}{2} (\vec{m}^{(i)} - \vec{m}^{(j)})^T (C_i^{-1} + C_j^{-1}) (\vec{m}^{(i)} - \vec{m}^{(j)})

当C_i=C_j=C时

J_D = (\vec{m}^{(i)} - \vec{m}^{(j)})^T C^{-1} (\vec{m}^{(i)} - \vec{m}^{(j)}) = 8 J_B
