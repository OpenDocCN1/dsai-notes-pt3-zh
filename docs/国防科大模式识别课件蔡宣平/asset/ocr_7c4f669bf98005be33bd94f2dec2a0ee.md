# 7.5.2 基于总的类内离差矩阵、类间离差矩阵、进行特征提取选择

+   • 基于总的类内离差矩阵 S_W 的DKLT进行特征提取选择

S_W → λ_i → ū_i (i = 1,2,⋯,n) λ_i = ū_i^T S_W ū_i
y_i = ū_i^T x̄ i = 1,2,⋯,d ; d ≤ n

构造准则函数 J(y_i) = \frac{ar u_i^T S_B ar u_i}{ar u_i^T S_W ar u_i} = \frac{ar u_i^T S_B ar u_i}{\lambda_i}

排序: J(y_1) ≥ J(y_2) ≥ ⋯ ≥ J(y_n), 取前面 d 个较大的 J(·) 值对应的 ū_i (i = 1,2,⋯,d)

适用于各类模式的类域在某些分量轴上的投影不重叠或较少重叠的情况。
