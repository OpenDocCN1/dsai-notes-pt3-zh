# （3）带拒绝的最小损失准则判决

R₁(x⃗) = [λ₁₁ p(x⃗|ω₁) P(ω₁) + λ₂₁ p(x⃗|ω₂) P(ω₂)]
= 2.5*0.7*(0.1,0.15,0.3,0.6)+2.0*0.3*(0.8,0.7,0.55,0.3)
=(0.655, 0.683, 0.855, 1.23)

R₂(x⃗) = [λ₁₂ p(x⃗|ω₁) P(ω₁) + λ₂₂ p(x⃗|ω₂) P(ω₂)]
=4.0*0.7*(0.1,0.15,0.3,0.6)+1.0*0.3*(0.8,0.7,0.55,0.3)
=(0.52, 0.63, 1.005, 1.77)

R₃(x⃗) = [λ₁₃ p(x⃗|ω₁) P(ω₁) + λ₂₃ p(x⃗|ω₂) P(ω₂)]
=1.5*0.7*(0.1,0.15,0.3,0.6)+1.5*0.3*(0.8,0.7,0.55,0.3)
=(0.465, 0.473, 0.563, 0.765)

因此第一、第二、第三、第四样本均拒判。
