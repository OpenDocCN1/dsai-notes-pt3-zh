# 利用贝叶斯分类器实现手写数字识别的例子

# 2. 实现步骤

(2) 计算 $P_j(\omega_i)$，再计算类条件概率 $P(X \mid \omega_i)$

$P_j(\omega_i) = \left(\sum_{\substack{k=0 \\ X \in \omega_i}}^{N_i} x_{kj} + 1\right) / (N_i + 2) \quad i = 0,1,\cdots,9 \quad j = 0,1,\cdots,24$

$P_j(\omega_i)$ 表示样品X属于 $\omega_i$ 类条件下，X的第j个分量为1的概率估计值。

$P(x_j = 1 \mid X \in \omega_i) P_j(\omega_i)$

$P(x_j = 0 \mid X \in \omega_i) = 1 - P_j(\omega_i)$
