
## 7.2.2基于类的概率密度函数的可分性判据

实际上 $J_C = -\ln \int_{\Omega} p(\vec{x}|\omega_1)^s \, p(\vec{x}|\omega_2)^{1-s} d\vec{x}$ 可以写成：

$J_C = -\ln\left[\int_{\Omega}\left(\frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)}\right)^s p(\vec{x}|\omega_2) d\vec{x}\right]$

这就启发我们运用两个概密的比或差来描述
两个概密重迭或相似的程度。

### （三）散度J_D（Divergence）

ω_i类对ω_j类的平均可分性信息为：

I_{ij}(\vec{x}) = E_i\left[\ln\frac{p(\vec{x}|\omega_i)}{p(\vec{x}|\omega_j)}\right] = \int_{\Omega} p(\vec{x}|\omega_i)\ln\frac{p(\vec{x}|\omega_i)}{p(\vec{x}|\omega_j)} d\vec{x}

ω_j对ω_i类的平均可分性信息为：

I_{ji}(\vec{x}) = E_j\left[\ln\frac{p(\vec{x}|\omega_j)}{p(\vec{x}|\omega_i)}\right] = \int_{\Omega} p(\vec{x}|\omega_j)\ln\frac{p(\vec{x}|\omega_j)}{p(\vec{x}|\omega_i)} d\vec{x}

### （三）散度JD (Divergence)

对于 ω_i 和 ω_j 两类总的平均可分性信息称为散度，其定义为两类平均可分性信息之和，即

J_D = I_{ij}(\vec{x}) + I_{ji}(\vec{x})
= \int_{\Omega} [p(\vec{x} | \omega_i) - p(\vec{x} | \omega_j)] \ln \frac{p(\vec{x} | \omega_i)}{p(\vec{x} | \omega_j)} d \vec{x}
\triangleq J_D(\omega_i, \omega_j) \triangleq J_D(x_1, \cdots, x_n)

J_D = I_{ij}(\vec{x}) + I_{ji}(\vec{x})
= \int_{\Omega} [p(\vec{x} | \omega_i) - p(\vec{x} | \omega_j)] \ln \frac{p(\vec{x} | \omega_i)}{p(\vec{x} | \omega_j)} d\vec{x}

\Delta J_D(\omega_i, \omega_j) \triangleq \Delta J_D(x_1, \cdots, x_n)

当两类都是正态分布时：

J_D = \frac{1}{2} Tr[C_i^{-1} C_j + C_j^{-1} C_i - 2I] + \frac{1}{2} (\vec{m}^{(i)} - \vec{m}^{(j)})^T (C_i^{-1} + C_j^{-1}) (\vec{m}^{(i)} - \vec{m}^{(j)})

当C_i=C_j=C时

J_D = (\vec{m}^{(i)} - \vec{m}^{(j)})^T C^{-1} (\vec{m}^{(i)} - \vec{m}^{(j)}) = 8 J_B

散度具有如下性质：

- (1) J_D ≥ 0;
- (2) 对称性: J_D(ω₁, ω₂)= J_D(ω₂, ω₁);
- (3) J_D = 0 ⇔ p(\vec{x}|ω₁) = p(\vec{x}|ω₂)
- (4) 当x 各分量x₁,x₂,...,xₙ相互独立时，（具有可加性）
- J_D(x₁,x₂,⋯,xₖ)=∑⋅⋅⋅J_D(xⱼ) 
- k ≤ n
- (5) 当x各分量x₁,x₂,...,xₙ相互独立时，（对特征数目单调不减）
- J_D(x₁,x₂,⋯,x_{k-1}) ≤ J_D(x₁,x₂,⋯,x_{k-1},x_k) 
- k ≤ n

一般情况下，散度与误分概率（或其上下界）之间的直接解析关系很难得到，但实验可以证明它们之间存在着单调关系。例如两类都是正态分布，且有相同的协方差阵时，$P_0(e)$ 是 $J_D$ 的单调减函数。

当两类先验概率相等且为具有相同协方差的正态分布时，则最小误分概率与 $J_D$ 的关系为：

$$P_0(e)=\int_{\frac{1}{2}\sqrt{J_D}}^{\infty}\frac{1}{\sqrt{2\pi}}\exp\left(-\frac{y^2}{2}\right)\,dy$$

### 对于J_C判据的最小误分概率的上界

P_0(e) ≤ P(ω₁)^s P(ω₂)^{1-s} exp[-J_c(ω₁,ω₂;s)]   0 < s < 1

为求最佳的s*, 使上界取最小值C_h (称为Chernoff界限)

s*应满足

```
d{P(ω₁)^s P(ω₂)^{1-s} exp[-J_c(ω₁,ω₂;s)]}/ds |_{s=s^*}=0
```

即 -d[J_c(s)]/ds |_{s=s^*} = ln P(ω₂)/P(ω₁) = θ

易证，这个最小上界的s*同时也给出了两种误判概率的最小上界：

```
P_{12}(e) ≤ exp[-J_c(s^*)+(1-s^*)θ] ≤ exp[-J_c(s)+(1-s)θ], 	\tilde{x} ∈ ω₁,but 	\tilde{x} ∉ Ω₂
P_{21}(e) ≤ exp[-J_c(s^*)-s^*θ] ≤ exp[-J_c(s)-sθ], 	\tilde{x} ∈ ω₂,but 	\tilde{x} ∉ Ω₁
```

令 $B_h = P(\omega_1)^{1/2} P(\omega_2)^{1/2} \exp(-J_B)$

$C_h = P(\omega_1)^s P(\omega_2)^{1-s} \exp[-J_C(\omega_1,\omega_2;s^*)]$

可证得: $\frac{1}{2}[1-(1-4B_h^2)^{1/2}] \leq P_0(e) \leq C_h \leq B_h$

虽然一般情况下$B_h>C_h$, 但$B_h$比较容易计算, 算得结果通常也比较接近$C_h$, 所以在分类器设计分析中 $B_h$、$J_B$也是常用的。

由$J_B$、$J_C$、$J_D$的定义式结构以及它们与误分概率的关系可以知道，所选取的特征向量应使所对应的$J_B$、$J_C$、$J_D$尽量大，这样可分性就较好。

对于c类问题，可采用平均B-判据、C-判据、D-判据：

$\bar{J}_B = \sum_{i=1}^{c} \sum_{j=i+1}^{c} P(\omega_i) P(\omega_j) J_B(\omega_i, \omega_j)$

$\bar{J}_C = \sum_{i=1}^{c} \sum_{j=i+1}^{c} P(\omega_i) P(\omega_j) J_C(\omega_i, \omega_j)$

$\bar{J}_D = \sum_{i=1}^{c} \sum_{j=i+1}^{c} P(\omega_i) P(\omega_j) J_D(\omega_i, \omega_j)$

## 大盖小问题

在特征空间中，若有某两类间的 $J_B$、$J_C$ 或 $J_D$ 很大，可使平均判据变大，这样就掩盖了某些类对的判据值较小的情况存在，从而可能降低总的分类正确率，即所谓的大盖小问题。为改善这种情况，可对每个类对的判据采用变换的方法，使对小的判据较敏感。例如，对 $J_D$，可采用变换

$$\widetilde{J}_D(\omega_i, \omega_j) = 1 - \exp\left[- J_D(\omega_i, \omega_j)/8\right]$$

$\widetilde{J}_D(\omega_i,\omega_j)=1-\exp[-J_D(\omega_i,\omega_j)/8]$

这样，当$\omega_i$和$\omega_j$两类模式相距很远时，$J_D(\omega_i,\omega_j)$变得很大，但$\widetilde{J}_D(\omega_i,\omega_j)$也只能接近于1。但对于散度$J_D(\omega_i,\omega_j)$小的情况，$\widetilde{J}_D(\omega_i,\omega_j)$又变得较敏感。于是，总的平均(变换)判据为

$\widetilde{J}_D = \sum_{i=1}^{c}\sum_{j=i+1}^{c} P(\omega_i)P(\omega_j)\widetilde{J}_D(\omega_i,\omega_j)$
