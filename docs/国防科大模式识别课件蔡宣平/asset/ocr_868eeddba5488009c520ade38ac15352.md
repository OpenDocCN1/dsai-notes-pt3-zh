# 7.5.1 离散K-L变换（DKLT）

由 $R_x \vec{t}_i = \lambda_i \vec{t}_i \quad i = m+1,...,n$ 表明：

$\lambda_i$ 是 $R_x$ 的特征值，而 $\vec{t}_i$ 是相应的特征向量。

利用上式有：

$\varepsilon^2(m) = \sum_{i=m+1}^{n} \vec{t}_i' R_x \vec{t}_i = \sum_{i=m+1}^{n} \vec{t}_i' \lambda_i \vec{t}_i = \sum_{i=m+1}^{n} \lambda_i$

在上述的估计式中，如果不是简单地舍弃后 (n-m) 项，而是用预选的常数 $b_i$ 代替 $y_i$, $i=m+1,...,n$, 此时的估计式为：

$\hat{\vec{x}} = \sum_{i=1}^{m} y_i \vec{t}_i + \sum_{i=m+1}^{n} b_i \vec{t}_i$
