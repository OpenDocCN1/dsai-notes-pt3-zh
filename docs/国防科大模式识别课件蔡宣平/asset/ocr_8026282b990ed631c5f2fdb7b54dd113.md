# 这是因为，对于任何其它取法，ω₁的新的判决类域

Ω₁' = (Ω₁* − Ω₁₁) ∪ Ω₁₂      Ω₁* 如前定义      Ω₁₁ ⊆ Ω₁*      Ω₁₂ ⊆ Ω₂*

于是 在 Ω₁₁ 上有    p(x⃗|ω₁) − λ p(x⃗|ω₂) > 0

在 Ω₁₂ 上有    p(x⃗|ω₁) − λ p(x⃗|ω₂) < 0

# 这时的 y 值为

y = (1 − λ ε₀) − ∫_{Ω₁*−Ω₁₁} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗ − ∫_{Ω₁₂} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗

= y* + ∫_{Ω₁₁} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗ − ∫_{Ω₁₂} (p(x⃗|ω₁) − λ p(x⃗|ω₂)) d x⃗

上式中第二项的积分为正值，第三项的积分为负值。

显然 y > y*
