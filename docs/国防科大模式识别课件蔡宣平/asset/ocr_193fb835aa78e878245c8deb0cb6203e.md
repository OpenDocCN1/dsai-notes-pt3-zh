# (3) 动态聚类法——改进的C均值法

+   1. 对给定的待分类模式集 \{ar{x}_1,ar{x}_2,\dots,ar{x}_N\} 进行初始划分产生c类；
+   2. 计算各聚类 \omega_j 所含模式数 n_j 、均值矢量 ar{\mu}_j 和协方差阵 \Sigma_j ；
+   3. 将各模式 ar{x}_i 按最小距离原则分到某一聚类中。这里采用最小误判概率准则下正态分布情况的判决规则，计算模式 ar{x} 到 \omega_j 的距离。
+   
+    d(ar{x},\omega_j)=\ln|\Sigma_j| + (ar{x}-ar{\mu}_j)'\Sigma_j^{-1}(ar{x}-ar{\mu}_j)-2\ln\frac{n_j}{N}
+   
+    如果 d(ar{x},\omega_k)=\min_j d(ar{x},\omega_j) 则 ar{x} \in \omega_k 
+   
+   4. 如果没有模式改变其类别，则停止算法；否则转至2。
