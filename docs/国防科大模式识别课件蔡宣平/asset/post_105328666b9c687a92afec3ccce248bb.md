## 5.1 统计推断概述

### 基本概念

设模式空间 Ω 是 n 维的。

母体（总体）：一个模式类称为一个总体或母体

母体的子样：一个模式类中某些模式(即母体中的一些元素)的集合称为这个母体的子样。母体的子样含有母体的某些信息，可以通过构造样本的函数来获得。

统计量：一般来说，每一个样本都包含着母体的某些信息，为了估计未知参数就要把有用的信息从样本中抽取出来。为此，要构造训练样本的某种函数，这种函数在统计学中称为统计量。

## 5.1 统计推断概述

### 基本概念

理论量（或理论分布）：$p(\vec{x}|\omega_i)$  $P(\omega_i)$  $P(\omega_i|\vec{x})$

数学期望、方差等

经验分布：由样本推断的分布称为经验分布。

参数空间：在统计学中，把未知参数θ的可能值的集合称为参数空间，记为Θ。

点估计、估计量：针对某未知参数θ构造一个统计量作为θ的估计$\hat{\theta}$，这种估计称为点估计。$\hat{\theta}$称为θ的估计量。

### 基本概念

区间估计：在一定置信度条件下估计某一未知参数 θ 的取值范围，称之为置信区间，这类估计成为区间估计。

## 5.1 统计推断概述

### 基本概念

估计：所谓估计就是由样本 \vec{x}_j (j = 1,2,···,N) 按某种规则构造的一个统计量 \hat{\vec{\theta}}_N = \theta(\vec{x}_1, \vec{x}_2, ···, \vec{x}_N) 用以代替被估参数集 \vec{\theta}。估计量 \hat{\vec{\theta}}_N 作为随机样本的函数，显然也是随机量。

无偏估计：估计量 \hat{\theta}_N 的数学期望等于被估量 \vec{\theta} 的数学期望，即对任意的 N，有 E[\hat{\theta}_N] = E[\vec{\theta}]。估计无偏性的意义在于可以用多个估计的平均近似真值。

## 5.1 统计推断概述

### 基本概念

**渐近无偏估计：** 即 $\lim_{N\to\infty}E\left[\hat{\theta}_N\right]=E[\vec{\theta}]$。当不能对所有有 $N$ 的都有 $E\left[\hat{\theta}_N\right]=E[\vec{\theta}]$ 时，希望估计量 $\hat{\theta}_N$ 是渐近无偏估计。

**最小方差无偏估计量：** 在无偏估计条件下，对任意的 $N$，$Var\left[\hat{\theta}_N^*\right]\leq Var\left[\hat{\theta}_N\right]$，则称 $\hat{\theta}_N^*$ 是最小方差无偏估计量。我们希望在无偏的基础上，估计量随机摆幅越小越好，即估计量的方差越小越好。
