## 4.2 最小损失准则判决

### 4.2.1 损失概念、损失函数与平均损失

设模式空间中存在c个类别： ω₁, ω₂, …, ω_c，

决策空间由a个决策： α₁, α₂, …, α_a，

决策α_j常指将模式x指判为某一类ω_j或者是拒判。

对一个实属ω_i类的模式采用了决策α_j所造成的损失记为：
λ(α_j/ω_i) ≜ λ_ij

于是就有{ω₁, ω₂, …, ω_c}×{α₁, α₂, …, α_a}
空间中的二元函数，称其为损失函数。

## 决策-损失表

| | ω₁ | ω₂ | … | ω_c |
|---|---|---|---|---|
| α₁ | λ(α₁/ω₁) | λ(α₁/ω₂) | … | λ(α₁/ω_c) |
| α₂ | λ(α₂/ω₁) | λ(α₂/ω₂) | … | λ(α₂/ω_c) |
| … |  |  |  | … |
| α_c | λ(α_c/ω₁) | λ(α_c/ω₂) | … | λ(α_c/ω_c) |
| α_{c+1} | λ(α_{c+1}/ω₁) | λ(α_{c+1}/ω₂) | … | λ(α_{c+1}/ω_c) |

决策α_j指将模式x指判为ω_j或者是拒判。

λ_ij = { = 0   i = j
          = 1   i ≠ j }

## 条件平均风险

令决策的数目 a 等于类数 c，如果决策 α_j 定义为判 x⃗ 属 于 ω_j 类，那么对于给定的模式 x⃗ 在采取决策 α_j 的条件下

## 损失的期望为

R_j(x⃗) = R(α_j|x⃗) = Σ_{i=1}^{c} λ_{ij} P(ω_i|x⃗) ≜ E_i[λ_{ij}|x⃗]    (j = 1,2,…,c)

条件期望损失 R_j(x⃗) 刻划了在模式为 x⃗、决策为 α_j 条件下的平均损失，故也称 R_j(x⃗) 为条件平均损失或条件平均风险（Risk）。由贝叶斯公式，上式可以写为

R_j(x⃗) = Σ_{i=1}^{c} λ_{ij} p(x⃗|ω_i) P(ω_i) / p(x⃗)
= Σ_{i=1}^{c} λ_{ij} p(x⃗|ω_i) P(ω_i) / Σ_{i=1}^{c} p(x⃗|ω_i) P(ω_i)

R_j(\vec{x}) = \sum_{i=1}^{c} \lambda_{ij} p(\vec{x}|\omega_i) P(\omega_i) / p(\vec{x}) = \sum_{i=1}^{c} \lambda_{ij} p(\vec{x}|\omega_i) P(\omega_i) / \sum_{i=1}^{c} p(\vec{x}|\omega_i) P(\omega_i)

求上式R_j(x)关于x的数学期望：

R = \int_{\Omega} R_j(\vec{x}) p(\vec{x}) d\vec{x} = \sum_{j=1}^{c} \int_{\Omega_j} R_j(\vec{x}) p(\vec{x}) d\vec{x}

= \sum_{j=1}^{c} \int_{\Omega_j} \sum_{i=1}^{c} \lambda_{ij} p(\vec{x}|\omega_i) P(\omega_i) d\vec{x}

= \sum_{i=1}^{c} \sum_{j=1}^{c} \int_{\Omega_j} \lambda(\alpha_j(\vec{x}) | \omega_i) p(\vec{x}|\omega_i) P(\omega_i) d\vec{x}

= \sum_{i=1}^{c} P(\omega_i) \int_{\Omega} \lambda(\alpha(\vec{x}) | \omega_i) p(\vec{x}|\omega_i) d\vec{x}

= \sum_{i=1}^{c} P(\omega_i) E_i[\lambda(\alpha(\vec{x}) | \omega_i)] = E[\lambda(\alpha(\vec{x}))]

### 4.2.2 最小损失准则判决

- 可以將最小條件平均損失判決規則表示為

如果 $R_j(\bar{x}) = \min_i [R_i(\bar{x})]$ 
則判 $\bar{x} \in \omega_j$

定理：使條件平均損失最小的判決也必然使總的平均損失最小。
所以最小條件平均損失準則也稱為最小平均損失準則或最小平均風險準則，簡稱為最小損失準則。

R_j(\vec{x}) = \sum_{i=1}^{c} \lambda_{ij} p(\vec{x}|\omega_i) P(\omega_i) / p(\vec{x})

对于两类问题，

R_1(\vec{x}) = [\lambda_{11} p(\vec{x}|\omega_1) P(\omega_1) + \lambda_{21} p(\vec{x}|\omega_2) P(\omega_2)] / p(\vec{x})

R_2(\vec{x}) = [\lambda_{12} p(\vec{x}|\omega_1) P(\omega_1) + \lambda_{22} p(\vec{x}|\omega_2) P(\omega_2)] / p(\vec{x})

如果 R_1(\vec{x}) \lessgtr R_2(\vec{x}) 则： \vec{x} \in \begin{cases} \omega_1 \\ \omega_2 \end{cases}

# 此时最小损失判决规则可以表为：

\lambda_{11} p(\vec{x}|\omega_1) P(\omega_1) + \lambda_{21} p(\vec{x}|\omega_2) P(\omega_2) \lessgtr \lambda_{12} p(\vec{x}|\omega_1) P(\omega_1) + \lambda_{22} p(\vec{x}|\omega_2) P(\omega_2)

λ₁₁ p(\vec{x}|ω₁) P(ω₁) + λ₂₁ p(\vec{x}|ω₂) P(ω₂) ≤
λ₁₂ p(\vec{x}|ω₁) P(ω₁) + λ₂₂ p(\vec{x}|ω₂) P(ω₂)

经整理可得：

(λ₂₁ − λ₂₂) p(\vec{x}|ω₂) P(ω₂) ≤ (λ₁₂ − λ₁₁) p(\vec{x}|ω₁) P(ω₁)

# 两类问题的最小损失准则的似然比形式的判决规则为：

如果 \frac{p(\vec{x}|ω₁)}{p(\vec{x}|ω₂)} ≥ \frac{P(ω₂)(λ₂₁ − λ₂₂)}{P(ω₁)(λ₁₂ − λ₁₁)} 则判 \vec{x} ∈ { ω₁ \n ω₂ }

若记似然比阈值 $\theta_{12} = \frac{P(\omega_2)}{P(\omega_1)} \frac{(\lambda_{21} - \lambda_{22})}{(\lambda_{12} - \lambda_{11})}$

# 则两类问题的判决规则为：

如果 $l_{12}(\vec{x}) \geqslant \theta_{12}$ 则判： $\vec{x} \in \begin{cases} \omega_1 \\ \omega_2 \end{cases}$

注意，若 $l_{12}(\vec{x}) = \theta_{12}$

我们规定任判或拒判。
