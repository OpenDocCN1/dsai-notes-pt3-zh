
# 求解最佳权矢量的方法——(1) 伪逆法

求 J(w→) 对 w→ 的梯度并令其为零，有：
∇J(w→)=2X'(Xw→−b→)=0

可得： X'Xw→ = X'b→

当 (X'X)^-1 存在时， w→ = (X'X)^-1 X'b→ ≜ X^+ b→

X^+ = (X'X)^-1 X' 称为 X 的伪逆 (有的书称为广义逆或 M—P 逆)， w→ = X^+ b→ 称为 w→ 的伪逆解。

X'X 是 (m+1)×(m+1) 矩阵，一般是非奇异的。当 (X'X)^-1 不存在时，可用广义逆法解 w→ = (X'X)^+ X'b→，这里 (X'X)^+ 为 X'X 的广义逆矩阵。

（X′X）⁻¹存在时，  w⃗ = X⁺ b⃗        X⁺ = (X′X)⁻¹X′
（X′X）⁻¹不存在， w⃗ = (X′X)⁺ X′b⃗

求矩阵的广义逆计算量较大，引入的误差也可能很大，在实际中多采用下面的梯度法。

# 求解最佳权矢量的方法——(2) 梯度法

由前述知，J(\vec{w}) 的梯度为 ∇J(\vec{w}) = 2X'(X\vec{w} - \vec{b})

梯度下降算法迭代公式为：

- ① \vec{w}(0)任取；
- ② \vec{w}(k+1) = \vec{w}(k) - \rho_k X'(X\vec{w}(k) - \vec{b})

可以证明，当\rho_k = \rho_1 / k，\rho_1为任意正的常数，则该算法使权矢量序列\{\vec{w}(k)\} 收敛于 \vec{w}^*；满足 ∇J(\vec{w}^*) = 0    \vec{w}^*也称为MSE解。

为了减少计算量和存储量，可以仿照单样本修正法：

由于： X'(X\vec{w} - \vec{b}) = \sum_{k=1}^{N} (\vec{w}'\vec{x}_k - b_k)\vec{x}_k

于是迭代式修改为：

- ① \vec{w}(0) 任取；
- ② \vec{w}(k+1) = \vec{w}(k) + \rho_k (b_k - \vec{w}(k)'\vec{x}_k)\vec{x}_k

此算法通常称为W—H(Widrow—Hoff)算法

# W-H算法有两个性质

- 1. 当 $\vec{b} = (\frac{N}{N_1} \frac{N}{N_1} \cdots \frac{N}{N_1} \frac{N}{N_2} \cdots \frac{N}{N_2})'$ 时, MSE解 $\vec{w}^*$ 等价于 Fisher解。
- 2. 令 $\vec{b} = (1,1,\cdots,1)'$, 在样本数 $N \to \infty$ 时, MSE解以最小均方误差逼近贝叶斯判决函数:
  
  $d_B(\vec{x}) = P(\omega_1|\vec{x}) - P(\omega_2|\vec{x})$

# 求解最佳权矢量的方法—— (3)H-K算法

前述的有关算法中，余量矢量 b⃗ 是取定的常矢量 而这将使所得的解 w⃗ 受 b⃗ 的影响。

H-K (Ho-Kashyap) 算法就是针对前面算法不足的一种改进。

H-K算法仍使用平方误差准则函数
J(X, w⃗, b⃗) = ||Xw⃗ - b⃗||² = Σ_{i=1}^{N} (w⃗' x_i - b_i)² ⇒ min

这种算法是将准则函数J(•)视为 w⃗ 和 b⃗ 的函数，在迭代过程中修正 w⃗ 的同时，也对矢量 b⃗ 进行调整。

# 求解最佳权矢量的方法——(3)H-K算法

H-K算法的迭代公式为：

$\vec{b}(k+1)=\vec{b}(k)-\rho\nabla_b J(\cdot)\equiv\vec{b}(k)+\vec{\beta}(k)$

其中 $\nabla_b J(\cdot)=-2(X\vec{w}-\vec{b})$      $\rho>0$

若 $X\vec{w}(k)-\vec{b}(k)\le 0$，则 $\vec{\beta}(k)=0$

若 $X\vec{w}(k)-\vec{b}(k)>0$ ，则

$\vec{\beta}(k)=-\rho\left(\frac{\partial J}{\partial \vec{b}}\right)_{\vec{b}=\vec{b}(k)}=2\rho\left[X\vec{w}(k)-\vec{b}(k)\right]$

记误差向量： $\vec{e}(k)=X\vec{w}(k)-\vec{b}(k)$

于是上述 $\vec{\beta}(k)$ 可统一写为： $\vec{\beta}(k)=\rho\left[\vec{e}(k)+|\vec{e}(k)|\right]$

由伪逆法可知： $\vec{w}=(X'X)^{-1}X'\vec{b}\equiv X^{+}\vec{b}$

于是 $\vec{w}$ 的迭代公式为：

$\vec{w}(k+1)=X^{+}\vec{b}(k+1)=X^{+}\vec{b}(k)+X^{+}\vec{\beta}(k)$

$=\vec{w}(k)+X^{+}\vec{\beta}(k)$

# H-K算法步骤

- Step1. 将训练样本符号规范化，得X
- 求伪逆  $X^{+} = (X'X)^{-1}X'$

- Step2. 置初值 $\vec{b}(1) > \vec{0}, k = 1, \rho = \frac{1}{2}$;

- Step3. 计算  $\vec{w}(k) = X^{+} \vec{b}(k)$
- $\vec{e}(k) = X \vec{w}(k) - \vec{b}(k)$

- Step4. IF ($\vec{e}(k)$ 的各分量停止变为正值)
- then End. (线性不可分，无解)
- else IF $\vec{e}(k) \Rightarrow \vec{0}$
- then 输出 $\vec{w}(k)$  End.

Step5. $\vec{w}(k+1)=\vec{w}(k)+\rho X^{+}[\vec{e}(k)+|\vec{e}(k)|]$

$=\vec{w}(k)+\rho X^{+}|\vec{e}(k)|$

$\vec{b}(k+1)=\vec{b}(k)+\rho(\vec{e}(k)+|\vec{e}(k)|);$

Step6. $k=k+1$; goto Step3;
