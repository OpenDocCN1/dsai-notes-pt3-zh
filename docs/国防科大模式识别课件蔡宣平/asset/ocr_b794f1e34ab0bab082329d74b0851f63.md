# 设有标准正交变换矩阵 $T$，（即 $T'T=I$）

$\vec{y}=T'\vec{x}=(\vec{t}_1\ \vec{t}_2\ \cdots\ \vec{t}_n)'\vec{x}=(y_1,y_2\cdots y_n)'$

$y_i=\vec{t}_i'\vec{x}\qquad(i=1,2\cdots,n)$

$\vec{x}=(T')^{-1}\vec{y}=T\vec{y}=\sum_{i=1}^{n}y_i\vec{t}_i$

（称为 $\vec{x}$ 的 K-L 展开式）

取前 $m$ 项为 $\vec{x}$ 的估计值  $\hat{\vec{x}}=\sum_{i=1}^{m}y_i\vec{t}_i\qquad 1\le m<n$

其均方误差为  $\varepsilon^2(m)=E\left[(\vec{x}-\hat{\vec{x}})'(\vec{x}-\hat{\vec{x}})\right]$

$=\sum_{i=m+1}^{n}E[y_i^2]=\sum_{i=m+1}^{n}E[y_i y_i']$
