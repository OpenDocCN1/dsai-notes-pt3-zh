# Bayes法则—最大后验概率准则

对于两类ω₁, ω₂问题，直观地，可以根据后验概率做判别：

若 p(ω₁|x) > p(ω₂|x) 则 x ∈ ω₁

若 p(ω₁|x) < p(ω₂|x) 则 x ∈ ω₂

根据Bayes公式，后验概率 p(ω_i / x) 可由类ω_i的先验概率 P(ω_i)和条件概率密度 p(x / ω_i) 来表示，即

p(ω_i | x) = \frac{p(x | ω_i) P(ω_i)}{p(x)} = \frac{p(x | ω_i) P(ω_i)}{\sum_{i=1}^2 p(x | ω_i) P(ω_i)}

式中，p(x|ω_i)又称似然函数(likelihood function of class ω_i)，可由已知样本求得。
