(3)令 j=j+1，输入 x⃗_j，计算积累位势函数

K_j(x⃗)=K_{j-1}(x⃗)+α_j K(x⃗,x⃗_j)

积累位势函数的调整规则为

α_j = { 0，若 x⃗_j ∈ ω_1 和 K_{j-1}(x⃗_j) > 0
0，若 x⃗_j ∈ ω_2 和 K_{j-1}(x⃗_j) < 0
1，若 x⃗_j ∈ ω_1 和 K_{j-1}(x⃗_j) ≤ 0
-1，若 x⃗_j ∈ ω_2 和 K_{j-1}(x⃗_j) ≥ 0 }
m = m + |α_j|

(4)如果 j < N，返至(3)。如果 j = N，检查是否有模式判错；若没 m = 0，则结束 d(x⃗)=K_j(x⃗)；若 m ≠ 0，令 j = 0，m = 0，返至(3)。
