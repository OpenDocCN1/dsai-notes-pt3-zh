# 2·3 类的定义与类间距离

ω_j 的类内离差阵定义为

```
S_W^{(j)} = \frac{1}{n_j} \sum_{i=1}^{n_j} (\vec{x}_i^{(j)} - \vec{m}_j)(\vec{x}_i^{(j)} - \vec{m}_j)' \quad (j = 1,2,\cdots,c) \quad (2-3-28)
```

式中 \vec{m}_j 为类 ω_j 的模式均值向量

```
\vec{m}_j = \frac{1}{n_j} \sum_{i=1}^{n_j} \vec{x}_i^{(j)} \quad (j = 1,2,\cdots,c) \quad (2-3-29)
```
