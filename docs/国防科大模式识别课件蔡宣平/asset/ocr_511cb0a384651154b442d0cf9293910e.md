# 例：已知如图（3-12-1）所示两类训练样本：

x⃗₁ = (0,0)', x⃗₂ (2,0)' ∈ ω₁; x⃗₃ = (1,1)', x⃗₄ = (1,-1)' ∈ ω₂

试用势函数法进行分类器训练。

解：选用第三类势函数，令 α=1，在二维情况下，

K(x⃗, x⃗ⱼ) = exp[-‖x⃗ - x⃗ⱼ‖²] = exp[-( (x₁ - xⱼ₁)² + (x₂ - xⱼ₂)² )]

K(x⃗) 为积累势函数

j = 0, K₀(x⃗) = 0

j = 1, x⃗₁ ∈ ω₁, K₁(x⃗) = K(x⃗, x⃗₁) = exp[-( (x₁ - 0)² + (x₂ - 0)² )] = exp[-(x₁² + x₂²)]

j = 2, x⃗₂ ∈ ω₁, K₁(x⃗₂) = exp[-(x₁² + x₂²)] = exp[-2²] = e⁻⁴ > 0

K₂(x⃗) = K₁(x⃗) = exp[-(x₁² + x₂²)]
