由于S_W^{-1}S_B的秩为c-1=1，因此S_W^{-1}S_B只有一个非零特征值，于是特征提取矩阵W是一个3x1矩阵，此即S_W^{-1}S_B的非零特征值对应的特征向量\vec{v}。

为求该特征值应解方程： S_W^{-1} S_B \vec{v} = \lambda \vec{v}

即 \frac{1}{4} S_W^{-1} (\vec{m}_1 - \vec{m}_2)(\vec{m}_1 - \vec{m}_2)^T \vec{v} = \lambda \vec{v}

由于\frac{1}{4}(\vec{m}_1 - \vec{m}_2)^T \vec{v}是标量，于是有：

\vec{v} = S_W^{-1}(\vec{m}_1 - \vec{m}_2) = \frac{1}{8}(2,10,-16)^T

这就是所要求的最佳特征提取矩阵。
