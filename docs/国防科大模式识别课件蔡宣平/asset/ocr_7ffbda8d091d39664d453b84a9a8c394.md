# 3. 没有不确定区的 ω_i/ω_j 两分法（第三种情况）

令方法2中的判别函数为：
$$d_{ij}(\vec{x}) = d_i(\vec{x}) - d_j(\vec{x}) = (\vec{w}_i - \vec{w}_j)'\vec{x}$$

则 $d_{ij}(\vec{x}) > 0$ 等价于 $d_i(\vec{x}) > d_j(\vec{x})$，于是对每一类 $\omega_i$ 均建立一个判别函数 $d_i(\vec{x})$，$C$ 类问题有 $C$ 个判别函数
$$d_i(\vec{x}) = \vec{w}_i'\vec{x} \quad i = 1,2,\cdots,c$$

故判决规则成为：
如果 $d_i(\vec{x}) > d_j(\vec{x}) \quad \forall j \neq i$ 则判 $\vec{x} \in \omega_i$

# 判决规则的另一种表达形式

如果 $d_i(\vec{x}) = \max_j \left[ d_j(\vec{x}) \right]$ 则判 $\vec{x} \in \omega_i$
