# 5.1 统计推断概述

# 基本概念

**渐近无偏估计：** 即 $\lim_{N\to\infty}E\left[\hat{\theta}_N\right]=E[\vec{\theta}]$。当不能对所有有 $N$ 的都有 $E\left[\hat{\theta}_N\right]=E[\vec{\theta}]$ 时，希望估计量 $\hat{\theta}_N$ 是渐近无偏估计。

**最小方差无偏估计量：** 在无偏估计条件下，对任意的 $N$，$Var\left[\hat{\theta}_N^*\right]\leq Var\left[\hat{\theta}_N\right]$，则称 $\hat{\theta}_N^*$ 是最小方差无偏估计量。我们希望在无偏的基础上，估计量随机摆幅越小越好，即估计量的方差越小越好。
