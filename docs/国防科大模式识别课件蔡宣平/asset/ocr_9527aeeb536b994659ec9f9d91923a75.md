# 7.2.2基于类的概率密度函数的可分性判据

令 $B_h = P(\omega_1)^{1/2} P(\omega_2)^{1/2} \exp(-J_B)$

$C_h = P(\omega_1)^s P(\omega_2)^{1-s} \exp[-J_C(\omega_1,\omega_2;s^*)]$

可证得: $\frac{1}{2}[1-(1-4B_h^2)^{1/2}] \leq P_0(e) \leq C_h \leq B_h$

虽然一般情况下$B_h>C_h$, 但$B_h$比较容易计算, 算得结果通常也比较接近$C_h$, 所以在分类器设计分析中 $B_h$、$J_B$也是常用的。
