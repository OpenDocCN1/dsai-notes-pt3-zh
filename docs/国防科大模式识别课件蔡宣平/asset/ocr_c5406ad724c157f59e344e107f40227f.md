# 加权类内距离准则 J_WW:

J_{WW}=\sum_{j=1}^{c} \frac{n_j}{N} \bar{d}_j^2

\bar{d}_j^2 = \frac{2}{n_j(n_j-1)} \sum_{\substack{\tilde{x}_i^{(j)} \in \omega_j \\ \tilde{x}_k^{(j)} \in \omega_j}} \|\tilde{x}_i^{(j)} - \tilde{x}_k^{(j)}\|^2

式中，\sum \|\tilde{x}_i^{(j)} - \tilde{x}_k^{(j)}\|^2表示 \omega_j类内任两个模式距离平方和，共有 \frac{n_j(n_j-1)}{2}个组合数，所以 \bar{d}_j^2表示类内两模式间的均方距离。N为待分类模式总数，\frac{n_j}{N}表示 \omega_j类先验概率的估计——频率。
