# 上述三种方法小结：

当 $c > 3$ 时，$\omega_i / \omega_j$ 法比 $\omega_i / \overline{\omega_i}$ 法需要更多的判别函数式，这是一个缺点。

但是 $\omega_i / \overline{\omega_i}$ 法是将 $\omega_i$ 类与其余的 $c-1$ 类区分开，而 $\omega_i / \omega_j$ 法是将 $\omega_i$ 类和 $\omega_j$ 类分开，显然 $\omega_i / \omega_j$ 法使模式更容易线性可分，这是它的优点。

方法(3)判别函数的数目和方法(1)相同，但没有不确定区，分析简单，是最常用的一种方法。
