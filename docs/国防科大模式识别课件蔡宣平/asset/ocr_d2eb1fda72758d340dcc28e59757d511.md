# 7.5.2 基于总的类内、类间离差矩阵、进行特征提取选择

+   基于总的类间离差矩阵 $S_B$ 的DKLT进行特征提取选择

对于 $c$ 类问题，由于 $S_B$ 的秩不大于 $c-1$，故 $S_B$ 最多有 $c-1$ 个非零特征值，而模式的维数 $n$ 通常要大于 $c$，因此依据类间离差矩阵 $S_B$ 进行特征选择是一个重要途径。具体的方法是：求出 $S_B$ 的非零特征值 $\lambda_i$ 和其相应的特征向量 $u_i$ $(i=1,2,\dots)$，按次序 $\lambda_1 \ge \lambda_2 \ge \dots \ge \lambda_{c-1}$ 选取前 $d$ 个较大的特征值对应的特征向量构成变换矩阵，可实现特征的选取。
