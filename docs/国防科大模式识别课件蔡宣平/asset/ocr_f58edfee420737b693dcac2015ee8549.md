# 5.4 概密的窗函数估计法

# Parzen窗法

$\delta_N(\vec{x}) = \frac{1}{V_N} \varphi\left(\frac{\vec{x}}{h_N}\right) \quad \hat{p}_N(\vec{x}) = \frac{1}{N} \sum_{j=1}^{N} \delta_N(\vec{x} - \vec{x}_j)$

当 $h_N$ 很小时，$\delta_N(\vec{x} - \vec{x}_j)$ 幅度很大，宽度很小，近似于以 $\vec{x}_j$ 为中心的 $\delta$—函数，此时 $\hat{p}_N(\vec{x})$ 是 $N$ 个以 $\vec{x}_j$ 为中心的尖脉冲在 $x$ 点处迭加，使之波动太大，不稳定，可能失去连续性。

$h_N(\vec{x})$ 的选取对 $\hat{p}_N(\vec{x})$ 的影响很大。
