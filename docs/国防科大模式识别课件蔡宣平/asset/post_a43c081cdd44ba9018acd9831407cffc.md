## 1.2 特征向量和特征空间

特征向量：

设一个研究对象的n个特征量测量值分别为 x₁, x₂, ..., xₙ, 我们将它们作为一个整体来考虑, 让它们构成一个n维特征向量x。

特征空间：

各种不同取值的特征向量的全体构成了n维特征空间。

注： 特征向量就是特征空间中的一个点。

## 1.3 随机矢量的描述

随机矢量：

在模式识别过程中，要对许多具体对象进行测量，以获得许多次观测值。每次观测值不一定相同，所以对许多对象而言，每个特征分量都是随机变量，即许多对象的特征向量在n维空间中呈随机性分布，称为随机矢量。

### (一)随机矢量的分布函数：

设 $\vec{X} = (X_1, X_2, \cdots, X_n)'$ 为随机矢量，

$\vec{x} = (x_1, x_2, \cdots, x_n)'$ 为确定性矢量。

随机矢量的联合概率分布函数定义为：

$F(x_1, x_2, \cdots; x_n) = P(X_1 \le x_1, X_2 \le x_2, \cdots; X_n \le x_n)$

$F(\vec{x}) = P(\vec{X} \le \vec{x})$

式中 $P(\cdot)$ 表示括号中事件同时发生的概率。

### （一）随机矢量的分布函数：

随机矢量 $\vec{X}$ 的联合概率密度函数定义为：

```
p(x₁, x₂, …, xₙ) \triangleq p(\vec{x}) 
= ∂ⁿF(x₁, x₂, …, xₙ)/∂x₁∂x₂⋯∂xₙ
```

### (一) 随机矢量的分布函数：

设集合由c类模式组成，第i类为 ω_i，

ω_i 类模式特征向量有其自己的分布函数和密度函数。

ω_i 类的模式特征向量的分布函数及密度函数分别定义为

F(\vec{x}|ω_i) = P(\vec{X} ≤ \vec{x}|ω_i)

p(\vec{x}|ω_i) = ∂ⁿF(x₁, x₂, …, xₙ | ω_i) / ∂x₁ ∂x₂ … ∂xₙ

### (二) 随机矢量的数字特征：

#### (1) 均值矢量(期望矢量)

n 维随机矢量 $\vec{X}$ 的数学期望 $\vec{\mu}$ 定义为：

$\vec{\mu} = E[\vec{X}] = \vec{\bar{X}} = \begin{pmatrix} E[X_1] \\ E[X_2] \\ \dots \\ E[X_n] \end{pmatrix} = \int_{X^n} \vec{x} p(\vec{x}) d\vec{x}$

### (二)随机矢量的数字特征：

其中， μ⃗ 的分量：

μ_i = E[X_i] = ∫_{-∞}^{+∞} x_i p(x_i) dx_i =

∫_{-∞}^{+∞} ... ∫ x_i p(x_1, x_2, ..., x_n) dx_1 dx_2 ... dx_n = X̄_i

式中，p(x_i)是 X⃗ 的第 i 个分量的边缘密度。随机矢量 X⃗ 的均值矢量 μ⃗ 的各分量是相应的各随机分量的均值。

### (二) 随机矢量的数字特征：

#### (2) 条件期望

在模式识别中，经常以类别 ω_i 作为条件，在这种情况下随机矢量 X⃗ 的条件期望矢量定义为

μ⃗_ω_i = E[ X⃗ | ω_i ] = ∫_{X^n} x⃗ p( x⃗ | ω_i ) d x⃗

### (二)随机矢量的数字特征：

#### (3) 协方差矩阵

随机矢量 X⃗ 的自协方差矩阵表征各分量围绕其均值的散布情况及各分量间的相关关系，其定义为：

```
Σ = E[(X⃗ − X̄)(X⃗ − X̄)′]
= ∫_{X^n} (x⃗ − μ⃗)(x⃗ − μ⃗)′ p(x⃗) d x⃗ = (σ²_{ij})_{n×n}
```

### (二) 随机矢量的数字特征：

#### (3) 协方差矩阵

式中σ²ᵢⱼ是X⃗的第i个分量与第j个分量的协方差，当 i=j 时，σ²ᵢⱼ便是Xᵢ的方差。

σ²ᵢⱼ = E[(Xᵢ - X̄ᵢ)(Xⱼ - X̄ⱼ)]
= ∫∫₋∞⁺∞ (xᵢ - μᵢ)(xⱼ - μⱼ) p(xᵢ, xⱼ) dxᵢ dxⱼ

### （二）随机矢量的数字特征：

#### （4）自相关矩阵

随机矢量 X 的自相关矩阵定义为

R = E[ X X' ]

由定义可知，X 的协方差矩阵和自相关矩阵间的关系是

Σ = R − X X' = R − μ μ'
