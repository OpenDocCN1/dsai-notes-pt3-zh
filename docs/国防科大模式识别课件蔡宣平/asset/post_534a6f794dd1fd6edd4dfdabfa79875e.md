### 最大似然估计(MLE)
(Maximum Likelihood Estimate)

这说明，样本总体的未知均值的最大似然估计就是训练样本的平均值。它的几何解释就是：若把N个样本看成是一群质点，则样本均值便是它们的质心。

### (2) 一维正态的情况，设 θ₁=μ,θ₂=σ² 则：

ln p(x_k | θ) = -1/2 ln(2π)θ₂ - 1/(2θ₂) (x_k - θ₁)²

∂ ln p(x_k | θ)/∂θ = [1/θ₂ (x_k - θ₁), -1/θ₂ + (x_k - θ₁)²/(2θ₂²)]

∑_{k=1}^N 1/θ̂₂ (x_k - θ̂₁) = 0

-∑_{k=1}^N 1/θ̂₂ + ∑_{k=1}^N (x_k - θ̂₁)²/θ̂₂² = 0

（3）对于一般的 多维正态密度 的情况，计算方法完全是类似的。最后的结果是：

$$\hat{\mu} = \frac{1}{N} \sum_{k=1}^{N} x_k$$

$$\hat{\Sigma} = \frac{1}{N} \sum_{k=1}^{N} (x_k - \hat{\mu})(x_k - \hat{\mu})^T$$

可以证明上式的均值是无偏估计，但协方差矩阵并不是无偏估计，无偏估计是：

$$\hat{\Sigma} = \frac{1}{N-1} \sum_{k=1}^{N} (x_k - \hat{\mu})(x_k - \hat{\mu})^T$$

## 5.2 参数估计

### 贝叶斯估计(BE)

引入损失函数： λ(θ⃗, θ̂) 即用 θ̂ 替代 θ⃗ 所造成的损失

在观测 X^(N) 条件下的期望损失为：

R(θ̂|X^(N)) = ∫_Θ λ(θ⃗, θ̂) p(θ⃗|X^(N)) dθ⃗

考虑到 X^(N) 的各种取值，我们应求 R(θ̂|X^(N)) 在 Ω^N = Ω × Ω × ⋯ × Ω 空间中的期望，即平均损失：

R = ∫_{Ω^N} R(θ̂|X^(N)) p(X^(N)) dX^(N)

= ∫_{Ω^N} ∫_{Θ} λ(θ⃗, θ̂) p(θ⃗|X^(N)) p(X^(N)) dθ⃗ dX^(N)

```
R = ∫_{Ω^N} R(\hat{θ}|X^{(N)}) p(X^{(N)}) dX^{(N)}
= ∫_{Ω^N} ∫_{Θ} λ(\vec{θ}, \hat{θ}) p(\vec{θ}|X^{(N)}) p(X^{(N)}) d\vec{θ} dX^{(N)}
```

贝叶斯估计的思想是：所求得的\vec{θ}的估计值\hat{θ}

应使估计损失的期望最小，这种使R或等价的使 R(\hat{θ}|X^{(N)})取最小值的\vec{θ}的估值\hat{θ}称为\vec{θ}的贝叶斯估计。

上式中，对于λ(\hat{θ},θ̂)不同的具体定义，可得到不同的最佳贝叶斯估计。比如，可以用平方误差作为代价，此时：

λ(\bar{θ}, \hat{θ}) = (\bar{θ} - \hat{θ})'(\bar{θ} - \hat{θ})

于是：

R = ∫_{Ω^N} [∫_Θ (\bar{θ} - \hat{θ})'(\bar{θ} - \hat{θ}) p(\bar{θ}|X^{(N)}) d\bar{θ}] p(X^{(N)}) dX^{(N)}

∂R(\hat{\vec{θ}}|X^{(N)}) / ∂\hat{\vec{θ}} = -2 ∫_Θ (\vec{θ} - \hat{\vec{θ}}) p(\vec{θ}|X^{(N)}) d\vec{θ} = \vec{φ}

从而可得：

\hat{\vec{θ}}(X^{(N)}) = ∫_Θ \vec{θ} p(\vec{θ}|X^{(N)}) d\vec{θ} = E[\vec{θ}|X^{(N)}]

上式表明，\vec{θ} 的最小方差贝叶斯估计是在观测 X^{(N)} 条件下的 \vec{θ} 的条件期望。

下面介绍估计θ 所涉及的其它公式或近似算式：

由于各样本是独立抽取的，故它们条件独立，即有

$p(X^{(N)}|\vec{\theta}) = p(\vec{x}_1,\vec{x}_2,\dots,\vec{x}_N|\vec{\theta}) = \prod_{j=1}^{N} p(\vec{x}_j|\vec{\theta})$

由贝叶斯定理知：

$p(\vec{\theta}|X^{(N)}) = p(X^{(N)}|\vec{\theta})p(\vec{\theta})/p(X^{(N)}) = \frac{p(X^{(N)}|\vec{\theta})p(\vec{\theta})}{\int_{\Theta} p(X^{(N)}|\vec{\theta})p(\vec{\theta})d\vec{\theta}}$

θ̅ 的后验概率 p(θ̅|X^(N)) 也可以作如下近似计算：

设 p(θ̅) 为正态分布 N(θ̅₀, C₀)，可取 θ̅₀ = θ̂，

C₀ 为估计的不确定性度量。由于 p(X^(N)) 只与 X^(N) 有关而与 θ̅ 无关，可取其为一个关于 X^(N) 的简单函数 α(X^(N))，由于观测是独立的，则上式可近似为：

p(θ̅|X^(N)) = p(θ̅|x₁, x₂, …, x_N) = α⁻¹(X^(N)) ∏_{j=1}^N p(x_j|θ̅) p(θ̅)

归纳起来贝叶斯估计的步骤是：

- 1. 确定未知参数集θ⃗的先验概率密度 p(θ⃗)
- 2. 由样本集 X^(N) 根据下式(已知模型)求 p(X^(N)|θ⃗)
  
  p(X^(N)|θ⃗) = p(x⃗₁, x⃗₂, …, x⃗_N|θ⃗) = ∏_{j=1}^{N} p(x⃗_j|θ⃗)
- 3. 根据下式计算 p(θ⃗|X^(N))
  
  p(θ⃗|X^(N)) = p(θ⃗|x⃗₁, x⃗₂, …, x⃗_N) = α^{-1}(X^(N)) ∏_{j=1}^{N} p(x⃗_j|θ⃗) p(θ⃗)
- 4. 根据下式计算 θ̂
  
  θ̂(X^(N)) = ∫_{Θ} θ⃗ p(θ⃗|X^(N)) dθ⃗ = E[θ⃗|X^(N)]

## 5.4 概率的窗函数估计法

由于下面只针对 ω_i 类的概率和样本进行讨论，为简洁，下面不再标记类别。记 ω_i 类的概率：

$p(\vec{x}|\omega_i) \triangleq p(\vec{x})$，是 $\vec{x}\in\omega_i$ 的总体概率

随机矢量 $\vec{x}$ 落入区域 $R$ 中的概率为 $P=\int_R p(\vec{x})d\vec{x}$

设 $N$ 个样本 $\vec{x}_1,\vec{x}_2,\ldots,\vec{x}_N$ 是从上述概率为 $p(\vec{x})$ 的总体中独立抽取的，$N$ 个样本中有 $k$ 个样本落入区域 $R$ 中的概率 $P_k$ 服从离散随机变量的二项分布

$P_k=C_N^kP^k(1-P)^{N-k}$

### 5.4 概密的窗函数估计法 概率密度的基本估计式

P_k = C_N^k P^k (1 - P)^{N - k}

在上面的二项分布中使 P_k 取最大的 k 值称为众数。

令 m 为众数，如果 (N + 1)P 不是整数，则：
 m = [(N + 1)P]    即 m 等于 (N + 1)P 的整数部分；

如果 (N + 1)P 是整数，则：
 m = (N + 1)P - 1 和 m = (N + 1)P

```
P_k = C_N^k P^k (1 - P)^{N - k}
```

众数定义表明有 m 个样本落入区域 R 的概率最大。由概率论知，k 的数学期望 E[k] = NP。若实际落入域 R 的样本有 k 个，就认为这时的 k ≈ m。

由于：(N + 1)P - 1 ≤ m ≤ (N + 1)P

所以： k ≈ NP ≈ N\hat{P}

这里 \hat{P} 是 P 的估计，当 N 较大 P 较小时上式的近似程度是足够的。
