
# 若各类的概率相等，由判别式

$$d_i(\vec{x})=\ln P(\omega_i)-\frac{1}{2}(\vec{x}-\vec{\mu}_i)'\Sigma^{-1}(\vec{x}-\vec{\mu}_i)$$

可简化为马氏距离的平方，即：

$$d_i(\vec{x})=(\vec{x}-\vec{\mu}_i)'\Sigma^{-1}(\vec{x}-\vec{\mu}_i)$$

因此 $\vec{x}$ 的类别就由 $\vec{x}$ 到各类的均值的马氏距离决定，应判 $\vec{x}$ 属于马氏距离最小的那一类。

$\bar{μ}_i$ 和 $\bar{μ}_j$ 连线的中点

$Σ_1 = Σ_2 = σ^2 I$

$I$ 为单位阵，

$σ^2$ 为分量的方差，显然有矢量 $\vec{w}_{ij}$ 和矢量 $(\bar{μ}_i - \bar{μ}_j)$ 方向相同，此时决策平面垂直于两类中心的连线

相邻两类的决策界面为：

$d_i(\vec{x}) - d_j(\vec{x}) = \vec{x}'(W_i - W_j)\vec{x} + (\vec{w}_i - \vec{w}_j)'\vec{x} + (w_{i0} - w_{j0}) = 0$

显然，上式表示的决策界面是二次曲面，随着$\Sigma_i$、$\mu_i$及 $P(\omega_i)$ 的不同而呈现为不同的二次曲面，它可能是超球面、超椭球面、超双曲面、超抛物面、超平面。

## 4.1.3 正态模式分类的误判概率

考虑两类问题，设两类模式为协方差阵相等的多变量正态分布，它们的密度函数分别为：

p(x⃗|ω_i) ∼ N(μ⃗_i, Σ)

p(x⃗|ω_j) ∼ N(μ⃗_j, Σ)

对数似然比 L_ij(x⃗) ≜ ln l_ij(x⃗) = ln p(x⃗|ω_i) − ln p(x⃗|ω_j)
= −1/2 (x⃗−μ⃗_i)′ Σ⁻¹ (x⃗−μ⃗_i) + 1/2 (x⃗−μ⃗_j)′ Σ⁻¹ (x⃗−μ⃗_j)
= x⃗′ Σ⁻¹ (μ⃗_i − μ⃗_j) − 1/2 (μ⃗_i + μ⃗_j)′ Σ⁻¹ (μ⃗_i − μ⃗_j)

L_{ij}(x) 是 x 的线性函数，而 x 的各分量是正态分布的，故 L_{ij} 是正态分布的随机变量。

E_i[L_{ij}] = \bar{\mu}_i \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j) - \frac{1}{2} (\bar{\mu}_i + \bar{\mu}_j)' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j) = \frac{1}{2} (\bar{\mu}_i - \bar{\mu}_j)' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j)

令 r_{ij}^2 = (\bar{\mu}_i - \bar{\mu}_j)' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j)

E_i[L_{ij}] \triangleq \bar L_{ij} = \frac{1}{2} r_{ij}^2 
L_{ij}(x) = x' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j) - \frac{1}{2} (\bar{\mu}_i + \bar{\mu}_j)' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j)

Var_i[L_{ij}] = E_i[(L_{ij} - \bar L_{ij})^2]
= E_i[((x - \bar{\mu}_i)' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j))^2]
= E_i[(\bar{\mu}_i - \bar{\mu}_j)' \Sigma^{-1} (x - \bar{\mu}_i)(x - \bar{\mu}_i)' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j)]
= (\bar{\mu}_i - \bar{\mu}_j)' \Sigma^{-1} (\bar{\mu}_i - \bar{\mu}_j)
= r_{ij}^2

E_i[L_{ij}] \triangleq \bar{L}_{ij} = \frac{1}{2} r_{ij}^2

Var_i[L_{ij}] = E_i[(L_{ij} - \bar{L}_{ij})^2] = r_{ij}^2

\alpha = \ln \theta_{ij} = \ln \frac{P(\omega_j)}{P(\omega_i)}

![](img/d893b90ad57f036ece52d376593dc2c5_421_0.png)

## 将属于 ω_i 类的模式误判为属于 ω_j 类的错误概率为

P(L_ij < α | ω_i) = ∫_{-∞}^{α} 1/(√(2π) r_ij) exp[ - (L_ij - ½ r_ij²)² / (2 r_ij²) ] dL_ij = Φ( (α - r_ij² / 2) / r_ij )

## 将属于 ω_j 类的模式误判为属于 ω_i 类的错误概率为

P(L_ij > α | ω_j) = ∫_{α}^{∞} 1/(√(2π) r_ij) exp[ - (L_ij + ½ r_ij²)² / (2 r_ij²) ] dL_ij = 1 - Φ( (α + r_ij² / 2) / r_ij )

式中 Φ(u) = ∫_{-∞}^{u} 1/√(2π) exp(- y² / 2) dy

P(L_{ij} < α | ω_i) = ∫_{-∞}^{α} 1/(√(2π) r_{ij}) exp[ - (L_{ij} - 1/2 r_{ij}^2)^2 / (2 r_{ij}^2) ] dL_{ij} = Φ( (α - r_{ij}^2 / 2) / r_{ij} )

P(L_{ij} > α | ω_j) = ∫_{α}^{∞} 1/(√(2π) r_{ij}) exp[ - (L_{ij} + 1/2 r_{ij}^2)^2 / (2 r_{ij}^2) ] dL_{ij} = 1 - Φ( (α + r_{ij}^2 / 2) / r_{ij} )

Φ(u) = ∫_{-∞}^{u} 1/√(2π) exp(- y^2 / 2) dy

## 于是，总的误判概率为：

P(e) = P(ω_i) P(L_{ij} < α | ω_i) + P(ω_j) P(L_{ij} > α | ω_j)

= P(ω_i) Φ[ (α - 1/2 r_{ij}^2) / r_{ij} ] + P(ω_j) { 1 - Φ[ (α + 1/2 r_{ij}^2) / r_{ij} ] }
