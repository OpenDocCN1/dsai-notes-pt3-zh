# 具体的设计过程是：

+   (1) 按最小损失准则找出对应于 (0,1) 中的各个不同值的 P(ω₁) 的最佳决策类域 Ω₁、Ω₂，

+   (2) 计算相应各个 P(ω₁) 及最佳决策类域的最小平均损失，得 R* ~ P(ω₁) 曲线，找出使 R* 取最大值的 P*(ω₁)，

+   (3) 运用 P*(ω₁)、1−P*(ω₁) 及 λ_{ij} 构造似然比阈值并运用最小损失准则下的决策规则对具体的模式分类识别。
