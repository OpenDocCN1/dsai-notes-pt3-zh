# 特取 $P(\omega_i)=P(\omega_j)=\frac12$，此时 $\alpha=0$

$P(e)=\frac12\Phi\left[-\frac12 r_{ij}\right]+\frac12\left\{1-\Phi\left[\frac12 r_{ij}\right]\right\}$

$=\Phi\left[-\frac{r_{ij}}{2}\right]=\int_{-\infty}^{-r_{ij}/2}\frac{1}{\sqrt{2\pi}}\exp\left[-\frac{y^2}{2}\right]dy$

$=\int_{r_{ij}/2}^{\infty}\frac{1}{\sqrt{2\pi}}\exp\left[-\frac{y^2}{2}\right]dy$

![](bbox=[0.75, 0.18, 0.98, 0.6])

上式表明了误判概率与两类的马氏距离的关系：

$P(e)$ 随 $r_{ij}^2$ 的增大而单调递减，只要两类马氏距离足够大，其误判概率可足够小。
