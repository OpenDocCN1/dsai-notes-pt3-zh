## 7.2.3 基于后验概率的可分性判据

在信息论中，熵(Entropy)表示不确定性，熵越大不确定性越大。可以借用熵的概念来描述各类的可分性。

对于c类问题，给定各类的后验概率 $p(\omega_i|\vec{x})$ 可以写成如下形式：

\{ \begin{array}{cccc} \omega_1 & \omega_2 & \cdots & \omega_c \\ p(\omega_1|\vec{x}) & p(\omega_2|\vec{x}) & \cdots & p(\omega_c|\vec{x}) \end{array} \} \triangleq \{ \begin{array}{cccc} \omega_1 & \omega_2 & \cdots & \omega_c \\ p_1 & p_2 & \cdots & p_c \end{array} \}

### 熵的定义：

$H(\vec{x}) \triangleq H(\vec{p}) = -\sum_{i=1}^{c} p_i \log p_i = -\sum_{i=1}^{c} p(\omega_i|\vec{x}) \log p(\omega_i|\vec{x})$

由洛必达法则知：当 $p_i = 0$ 时 $p_i \log p_i = 0$

熵的主要性质：

(1) H(p̄) ≥ 0，即 H(p̄) 是有下界的非负数。当且仅当某个 i 有 p_i = 1 而其余的 p_j = 0 (j ≠ i) 时等号成立，即确定场熵最小。

例如： p(ω_i | x̄) = 1    p(ω_j | x̄) = 0, ∀ j ≠ i

显然这时能实现完全正确的分类识别

熵的主要性质：

(2) $H(p_1,\cdots,p_c) \le \log c$ ，即 $H(\vec p)$ 有上界。当且仅当 $p_i = \frac{1}{c} (i=1,2,\cdots,c)$ 时等号成立，即等概率场熵最大。识别最困难。

(3) $H(\vec p)$ 是 $\vec p$ 的连续上凸函数。

设 $\Omega_s$ 在是某一降维的特征空间，如果 $H(\vec x)(\vec x \in \Omega_s)$ 较大，则说明 $p(\omega_i \mid \vec x), (i=1,2...,c)$ 较接近，这时分类正确率可能不高。

![](img/d893b90ad57f036ece52d376593dc2c5_647_0.png)

### 熵的主要性质：

(4) $H(p_1,p_2,\cdots,p_c)=H(p_1+p_2,p_3,\cdots,p_c)+(p_1+p_2)H\left(\frac{p_1}{p_1+p_2},\frac{p_2}{p_1+p_2}\right)$

其中 $p_1+p_2>0$

说明当类别较少时，分类识别的不确定性变小。

从特征选择角度看，我们应选择使熵最小的那些特征用于分类即选用具有最小不确定性的特征进行分类是有益的。

使熵最小的特征利于分类，取熵的期望：

J_H = E_x {-∑_i P(ω_i | x) log P(ω_i | x)} ⇒ min

广义熵（具有熵的性质，利于计算）定义为：

```
H^{(α)}(p_1,p_2,⋯,p_c)=(2^{1-α}−1)^{-1}(∑_{i=1}^c p_i^α −1)
```

式中α>0， α≠1。不同的α值可得不同的可分性度量。

当α→1时，由洛必达法则可得Shannon熵

```
H^{(1)}(p⃗ )=−∑_{i=1}^c p_i log p_i
```

当α=2时，可得平方熵

```
H^{(2)}(p⃗ )=2[1−∑_{i=1}^c p_i^2 ]
```

同理，我们亦可用点熵在整个特征空间的概率平均
$J_H^{(\alpha)} = E_{\bar{x}}[J^{\alpha}(p(\omega_1|\bar{x}), p(\omega_2|\bar{x}),\cdots, p(\omega_c|\bar{x}))]$
作为可分性判据。

使用 $J_H$ 判据进行特征提取与选择时，我们的目标是使
$J_H \Rightarrow \min$

### 7.3.1 基于离差矩阵判据的变换法

设 $s_w$ 和 $s_B$ 分别为原始特征空间中的类内和类间离差矩阵， $s_w^*$ 和 $s_B^*$ 分别为变换特征空间中的类内和类间离差矩阵，可知

```
$s_w^* = W^T s_w W$
$s_B^* = W^T s_B W$
```

根据 $J_1=\mathrm{Tr} [S_w^{-1}S_B] \to \max$ 或 $J_4=|S_w+S_B| / |S_B| = |S_T| / |S_B| \to \max$ 求变换矩阵 $W$。

（一）对于矩阵迹形式的判据

在变换域中 $J_1$ 为

```
$J_1^*(W) = Tr\left[\left(S_W^\ast\right)^{-1} S_B^\ast\right] = Tr\left[\left(W^T S_W W\right)^{-1}\left(W^T S_B W\right)\right]$
```

由线性代数可知，对矩阵作相似变换其迹不变，一个方阵的迹等于它的所有特征值之和。设 $W_e$ 为正交阵，用 $W_e$ 对对称阵 $S_W^{-1} S_B$ 作相似变换使其成为对角阵，

```
$W_e^{-1} S_W^{-1} S_B W_e = W_e^T S_W^{-1} S_B W_e = \begin{pmatrix} \lambda_1 & & 0 \\ & \lambda_2 & \\ & \ddots & \\ 0 & & \lambda_n \end{pmatrix} \triangleq diag(\lambda_1, \lambda_2, \cdots, \lambda_n)$
```

其中，$\lambda_i\ (i=1,2,\cdots,n)$ 为 $S_W^{-1} S_B$ 的特征值，$W_e$ 的列矢量 $w_i$ 为 $S_W^{-1} S_B$ 相应于 $\lambda_i$ 的特征向量。由上式可得

```
$J_1 = Tr\left[S_W^{-1} S_B\right] = Tr\left[W_e^T S_W^{-1} S_B W_e\right] = \sum_{i=1}^{n} \lambda_i$
```

假设 $W_e$ 的列矢量的排列已作适当调整，使 $S_W^{-1}S_B$ 的特征值 $\lambda_1 \ge \lambda_2 \ge ... \ge \lambda_n$ 。由此可得，在 $d$ 给定后，取前 $d$ 个较大的特征值所对应的特征向量 $w_i (i=1,2,...,d)$ 构造特征提取矩阵 $W$，即：

```
$W = (\vec{w}_1 \quad \vec{w}_2 \quad \dots \quad \vec{w}_d)$
```

作变换 $\vec{y}=W^T\vec{x}$，这时对于给定的 $d$ 所得到的

```
$J_1^*(W)=\sum_{i=1}^{d}\lambda_i$
```

达最大值。此方法对 $J_3 = Tr[S_B]/Tr[S_W]$ 也适用。
