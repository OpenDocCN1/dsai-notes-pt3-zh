# 解法1：

利用Bayes公式

$P(\omega_1 \mid x = 10) = \frac{p(x = 10 \mid \omega_1) P(\omega_1)}{p(x = 10)}$
$= \frac{p(x = 10 \mid \omega_1) P(\omega_1)}{p(x = 10 \mid \omega_1) P(\omega_1) + p(x = 10 \mid \omega_2) P(\omega_2)}$
$= \frac{0.05 \times 1/3}{0.05 \times 1/3 + 0.50 \times 2/3} = 0.048$

因为，$P(\omega_2 \mid x=10) = 1 - P(\omega_1 \mid x=10) = 1 - 0.048 = 0.952$
$P(\omega_1 \mid x=10) < P(\omega_2 \mid x=10)$

故判决：$(x=10) \in \omega_2$，即是鲑鱼。
