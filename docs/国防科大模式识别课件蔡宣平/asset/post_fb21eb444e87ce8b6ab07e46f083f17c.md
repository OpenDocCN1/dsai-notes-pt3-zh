
θ₁₂ = P(ω₂) (λ₂₁ − λ₂₂) / P(ω₁) (λ₁₂ − λ₁₁)

如果 l₁₂(x) ≥ θ₁₂ 则判： x⃗ ∈ { ω₁
ω₂ }

损失函数如何确定依赖于实际问题和经验，有时为了方便，对于一般的 C 类问题，令

λᵢⱼ = { 0 , i = j
1 , i ≠ j } （0-1损失函数）

此时： θ₁₂ = P(ω₂) / P(ω₁) 此即为最小误判概率准则的判决规则

## 4.2.2 最小损失准则判决

取0-1损失函数时，
最小损失准则等价于最小
误判概率准则，
此时的平均损失就是误判概率，
使平均损失最小即使误判概率最小。
这也表明，
最小误判概率准则是最小损失准则的特例。

例: 设信源信号为{0,1}，其通过一受加性噪声干扰的信道，噪声为正态分布，均值为零，方差为 σ²
信道输出为 X，试求出最优判决规则，以区分输入是0还是1。

解: 设信号0为ω₀类，信号1为ω₁类。因输入信号受正态分布 N(0,σ)的加性噪声干扰，所以输出信号的加性噪声干扰，所以输出信号为信源信号与噪声的添加，输出信号的概型由噪声确定，方差仍为 σ² 均值分别为0和1。

### 输入信号值为0和1而输出幅值为x的概率函数为：

p(x|ω₀) = 1/√(2πσ) exp[ - x² / (2σ²) ]

p(x|ω₁) = 1/√(2πσ) exp[ - (x-1)² / (2σ²) ]

### 似然比为：

l₀₁(x) = p(x|ω₀) / p(x|ω₁) = exp[ (1 - 2x) / (2σ²) ]

l₀₁(x) = p(x|ω₀) / p(x|ω₁) = exp[ (1 - 2x) / (2σ²) ]

### 运用最小损失准则，判决规则为：

l₀₁(x) = exp[ (1 - 2x) / (2σ²) ] ≤ (λ₁₀ - λ₁₁)/(λ₀₁ - λ₀₀) · P(ω₁)/P(ω₀) 时 x⃗ ∈ { ω₁ ω₂ } ≥

两边取对数： 当 x < 1/2 - σ² ln[ (λ₁₀ - λ₁₁)/(λ₀₁ - λ₀₀) · P(ω₁)/P(ω₀) ] 时

判 x ∈ ω₀ 即信号为 “0”。

若取 λ₀₁ = λ₁₀ = 1， λ₀₀ = λ₁₁ = 0， P(ω₀) = P(ω₁) = 1/2

则 x < 1/2 时，应判信号为“0”； x > 1/2 时应判信号为“1”。

这和我们通常的习惯处理方法是一致的。

### 例：

设正常细胞属于 ω₁ 类，异常细胞属于 ω₂ 类，它们的先验概率分别为 P(ω₁)=0.9，P(ω₂)=0.1

现有一個待识细胞，其观测矢量为 x⃗，从类概密曲线上查得 p(x⃗|ω₁)=0.2， p(x⃗|ω₂)=0.4 如果损失系数取为 λ₁₁=0， λ₁₂=1 λ₂₁=6 λ₂₂=0 试用最小误判概率准则和最小损失准则判断该细胞是正常的还是异常的。

### 解：

由贝叶斯定理可以分别算出 ω₁ 和 ω₂ 的后验概率。

P(ω₁|x⃗)= [p(x⃗|ω₁)P(ω₁)] / [∑_{i=1}^2 p(x⃗|ω_i)P(ω_i)] = [0.2×0.9]/[0.2×0.9+0.4×0.1] = 0.818

P(ω₁|x̄)=0.818      P(ω₂|x̄)=1−P(ω₁|x̄)=0.182

因 P(ω₁|x̄)=0.818 > P(ω₂|x̄)=0.182，所以按最小误判概率准则，应判 x̄ 归于正常细胞。

当依据损失进行判决时，需计算条件平均损失。

R(α₁|x̄)=∑ᵢ₌₁² λᵢ₁ P(ωᵢ|x̄)=λ₂₁ P(ω₂|x̄)=1.092

R(α₂|x̄)=∑ᵢ₌₁² λᵢ₂ P(ωᵢ|x̄)=λ₁₂ P(ω₁|x̄)=0.818

取损失最小的判决，由于 R(α₁|x̄) > R(α₂|x̄)，故 x̄ ∈ ω₂

之所以这两个判决结果相反，是因为 λ₂₁ 取得较大的缘故。

## 4.2.3 含拒绝判决的最小损失判决

拒绝判决可以作为最小损失判决中的一个可能判决，
α_{c+1} = “拒绝判决”。

令λ(α_{c+1}/ω_i)表示模式 \vec{x} 实属 ω_i 类但拒绝作出判决所造成的损失，于是

在模式 \vec{x} 条件下拒绝判决的平均损失为
R(α_{c+1}|\vec{x}) = \sum_{i=1}^{c} λ(α_{c+1}/ω_i) P(ω_i|\vec{x})

如果 $R(α_{c+1}|\vec{x}) < R(α_j|\vec{x})$    $j=1,2,\cdots,c$

则作出拒绝判决。

设 $λ(α_{c+1}(\vec{x})|ω_i)=λ_r,$  $(i=1,2,...,c)$

（即各类的拒判损失相同）

则 $R(α_{c+1}|\vec{x}) = \sum_{i=1}^{c} λ_r P(ω_i|\vec{x}) = λ_r \sum_{i=1}^{c} P(ω_i|\vec{x}) = λ_r$

又设 $λ(α_j(\vec{x})|ω_i)=λ_e,$  $(j≠i,\ i,\ j=1,2,...,c)$

（即各误判损失相同）

$λ(α_i(\vec{x})|ω_i)=λ_c,$  $(i=1,2,...,c)$

（即各正确判决损失相同）

且通常有 $λc<λr<λe$

R(α_j | \vec{x}) = \sum_{i=1}^{c} λ(α_j | ω_i) p(ω_i | \vec{x})

= \sum_{i=1}^{c} λ_e p(ω_i | \vec{x}) - (λ_e - λ_c) P(ω_j | \vec{x})

= λ_e - (λ_e - λ_c) P(ω_j | \vec{x})

如果 $R(\alpha_{c+1} | \vec{x}) < R(\alpha_j | \vec{x})$, $(j=1,2,...c)$, 则对 $\vec{x}$

做拒绝判决。

$\lambda_r < \lambda_e - (\lambda_e - \lambda_c) P(\omega_j | \vec{x})$

$P(\omega_j | \vec{x}) < \frac{\lambda_e - \lambda_r}{\lambda_e - \lambda_c} = 1 - \frac{\lambda_r - \lambda_c}{\lambda_e - \lambda_c}$

= 1 - t

这里 $t = \frac{\lambda_r - \lambda_c}{\lambda_e - \lambda_c}$ 称之为拒判门限。

因为 $\lambda_c < \lambda_r < \lambda_e$, 故 $0 \le t \le 1$。

## 4.2.3 含拒绝判决的最小损失判决

含拒绝决策的最小损失判决规则为：
如果 max_j [P(ω_j | x⃗)] < 1 − t，则对 x⃗ 拒判；
如果 max_i [P(ω_j | x⃗)] = P(ω_i | x⃗) ≥ 1 − t，则判 x⃗ ∈ ω_i。

当 t > 1 − 1/c 时, 1 − t < 1/c, 上式恒成立, 不存在拒判问题, 即存在拒判决策的条件应该是: t ≤ 1 − 1/c

对于两类问题，存在拒判决策的条件是：
0 ≤ t ≤ 1/2

## 4.2.3 含拒绝判决的最小损失判决

判决规则如下：

t = \frac{\lambda_r - \lambda_c}{\lambda_e - \lambda_c}

如果 \(\frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \ge \frac{P(\omega_2)(1-t)}{P(\omega_1)t}\) 则判 \(\vec{x} \in \omega_1\)

如果 \(\frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} \le \frac{P(\omega_2)t}{P(\omega_1)(1-t)}\) 则判 \(\vec{x} \in \omega_2\)

如果 \(\frac{P(\omega_2)t}{P(\omega_1)(1-t)} < \frac{p(\vec{x}|\omega_1)}{p(\vec{x}|\omega_2)} < \frac{P(\omega_2)(1-t)}{P(\omega_1)t}\) 则对 \(\vec{x}\) 拒判。
