# 7.2.1基于几何距离的可分性判据



类的均值矢量： $\tilde{m}^{(i)} = \frac{1}{N_i} \sum_{k=1}^{N_i} \tilde{x}_k^{(i)}$   i = 1,2,\cdots,c

各类模式的总体均值矢量 $\tilde{m} = \sum_{i=1}^c P_i \tilde{m}^{(i)}$

P_i为相应类的先验概率率，当用统计量代替先验概率时，总体均值矢量可表示为：

```
\tilde{m} = \sum_{i=1}^c P_i \tilde{m}^{(i)} = \sum_{i=1}^c \frac{N_i}{N} \tilde{m}^{(i)} = \frac{1}{N} \sum_{i=1}^c \sum_{k=1}^{N_i} \tilde{x}_k^{(i)} = \frac{1}{N} \sum_{l=1}^N \tilde{x}_l
```
