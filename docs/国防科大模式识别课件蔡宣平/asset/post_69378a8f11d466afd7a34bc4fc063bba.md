类内离差平方和
$s_t = \sum_{\vec{x}_i \in \omega_t} (\vec{x}_i - \vec{x}_t)'(\vec{x}_i - \vec{x}_t)$

$\omega_l = \omega_p \cup \omega_q \quad D_{pq}^2 = s_l - s_p - s_q$

$D_{pq}^2 = \frac{n_p n_q}{n_p + n_q} (\vec{x}_p - \vec{x}_q)'(\vec{x}_p - \vec{x}_q)$

$\vec{x}_t \vec{x}_p \vec{x}_q$ 分别为对应类的重心

递推公式为：
$D_{kl}^2 = \frac{n_k + n_p}{n_k + n_l} D_{kp}^2 + \frac{n_k + n_q}{n_k + n_l} D_{kq}^2 - \frac{n_k}{n_k + n_l} D_{pq}^2$

D_{kl}^2 = α_p D_{kp}^2 + α_q D_{kq}^2 + β D_{pq}^2 + γ |D_{kp}^2 - D_{kq}^2|

## 2.3 类的定义与类间距离
### 2.3.3 聚类的准则函数

判别分类结果好坏的一般标准：

**类内距离小，类间距离大。**

某些算法需要一个能对分类过程或分类结果的优劣进行评估的准则函数。如果聚类准则函数选择得好，聚类质量就会高。聚类准则往往是和类的定义有关的，是类的定义的某种体现。

## 2·3 类的定义与类间距离
### 2.3.3 聚类的准则函数

# 一、类间距离准则

设有待分类的模式集 $\{\vec{x}_1,\vec{x}_2,\ldots,\vec{x}_N\}$ 在某种相似性测度基础上被划分为 $c$ 类，$\{\vec{x}_i^{(j)};\ j=1,2,\ldots,c;\ i=1,2,\ldots,n_j\}$。类内距离准则函数 $J_W$ 定义为：（$\vec{m}_j$ 表示 $\omega_j$ 类的模式均值矢量。）

$$J_W=\sum_{j=1}^{c}\sum_{i=1}^{n_j}\left\|\vec{x}_i^{(j)}-\vec{m}_j\right\|^2 \tag{2-3-20}$$

## 2·3 类的定义与类间距离

$$J_W = \sum_{j=1}^{c} \sum_{i=1}^{n_j} \left\| \vec{x}_i^{(j)} - \vec{m}_j \right\|^2 \quad (2-3-20)$$

我们的目标是使 $J_W$ 取最小, 即 $J_W \Rightarrow \min$ , 这种方法也称为误差平方和准则。

显然, $J_W$ 是模式 $\vec{x}_i$ 和类心 $\vec{m}_j$ 的函数, 在样本集 $\{\vec{x}_i\}$ 给定条件下, $J_W$ 的值取决于类心的选取。

# 加权类内距离准则 J_WW:

J_{WW}=\sum_{j=1}^{c} \frac{n_j}{N} \bar{d}_j^2

\bar{d}_j^2 = \frac{2}{n_j(n_j-1)} \sum_{\substack{\tilde{x}_i^{(j)} \in \omega_j \\ \tilde{x}_k^{(j)} \in \omega_j}} \|\tilde{x}_i^{(j)} - \tilde{x}_k^{(j)}\|^2

式中，\sum \|\tilde{x}_i^{(j)} - \tilde{x}_k^{(j)}\|^2表示 \omega_j类内任两个模式距离平方和，共有 \frac{n_j(n_j-1)}{2}个组合数，所以 \bar{d}_j^2表示类内两模式间的均方距离。N为待分类模式总数，\frac{n_j}{N}表示 \omega_j类先验概率的估计——频率。

# 二、类间距离准则

J_B = Σ_{j=1}^{c} (m⃗_j - m⃗)'(m⃗_j - m⃗) ⇒ max    (2-3-24)

这里，m⃗_j 为 ω_j 类的模式平均矢量，m⃗ 为总的模式平均矢量。设 n_j 为 ω_j 类所含模式个数，

m⃗_j = (1/n_j) Σ_{x⃗_i ∈ ω_j} x⃗_i        m⃗ = (1/N) Σ_{i=1}^{N} x⃗_i

# 加权类间距离准则：

J_WB = Σ_{j=1}^{c} (n_j / N) (m⃗_j - m⃗)′ (m⃗_j - m⃗) ⇒ max    (2-3-25)

对于两类问题，类间距离有时取

J_B2 = (m⃗_1 - m⃗_2)′ (m⃗_1 - m⃗_2)    (2-3-26)

J_B2 和 J_WB 的关系是

J_WB = (n_1 / N) (n_2 / N) J_B2    (2-3-27)
