# 5.4 模糊的窗函数估计法 概率密度的基本估计式

则估计 \(\hat p_N(\vec x)=\frac{k_N/N}{V_N}\) 处处收敛于 \(p(\vec x)\)。

只要区域平稳地缩小，\(p(\vec x)\)在\(\vec x\)处连续，则：

\(\lim_{N\to\infty}V_N=0\)可使空间平均密度\(P/V\)收敛于真实的密度\(p(\vec x)\)

\(\lim_{N\to\infty}k_N=\infty\)仅对\(p(\vec x)\neq0\)的点才有意义，亦即当\(p(\vec x)\neq0\)时，使\(\hat p(\vec x)\neq0\)，可使频率在概率意义上收敛于概率\(P\)

\(\lim_{N\to\infty}\frac{k_N}{N}=0\)是\(\hat p_N(\vec x)=\frac{k_N/N}{V_N}\)收敛的必要条件，它描述了\n\(N\)的增长速度要大于\(k_N\)的增长速度，使\(k_N/N\)为无穷小，而\(k_N/N\)和\(V_N\)为同阶的无穷小，使\(\frac{k_N/N}{V_N}\)为非无穷大的有界数，避免了\(\hat p(\vec x)\to\infty\)。
