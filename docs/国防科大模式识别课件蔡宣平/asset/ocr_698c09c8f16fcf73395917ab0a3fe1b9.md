# 7.2.1 基于几何距离的可分性判据

# （五）类内离差矩阵

$$S_{\omega_i}=\frac{1}{N_i}\sum_{k=1}^{N_i}(\vec{x}_k^{(i)}-\vec{m}^{(i)})(\vec{x}_k^{(i)}-\vec{m}^{(i)})^{\mathrm{T}}$$

显然 $$\bar d^2(\omega_i)=\operatorname{Tr}[S_{\omega_i}]$$

# （六）两类之间的距离

$$\bar d^2(\omega_i,\omega_j)=\frac{1}{N_iN_j}\sum_{k=1}^{N_i}\sum_{l=1}^{N_j}d^2(\vec{x}_k^{(i)},\vec{x}_l^{(j)})$$

$$\bar d^2(\omega_i,\omega_j)=\frac{1}{N_iN_j}\sum_{k=1}^{N_i}\sum_{l=1}^{N_j}(\vec{x}_k^{(i)}-\vec{x}_l^{(j)})^{\mathrm{T}}(\vec{x}_k^{(i)}-\vec{x}_l^{(j)})$$
