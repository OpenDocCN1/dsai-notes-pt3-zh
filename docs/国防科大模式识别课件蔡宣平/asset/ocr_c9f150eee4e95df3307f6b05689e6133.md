# 7.5.1 离散K-L变换（DKLT）

x̂ = Σ_{i=1}^{m} y_i t⃗_i + Σ_{i=m+1}^{n} b_i t⃗_i 的均方误差为：

ε²(m) = E[(x⃗ - x̂)'(x⃗ - x̂)] = Σ_{i=m+1}^{n} E[(y_i - b_i)²]

# （1）最佳的b_i可通过 ∂ε²/∂b_i = 0 求得

∂/∂b_i {E[(y_i - b_i)²]} = 0        b_i = E[y_i] = t⃗_i' E[x⃗] = t⃗_i' x̄

ε²(m) = Σ_{i=m+1}^{n} E[(y_i - b_i)²] = Σ_{i=m+1}^{n} E[(t⃗_i' x⃗ - t⃗_i' x̄)²]

= Σ_{i=m+1}^{n} t⃗_i' E[(x⃗ - x̄)(x⃗ - x̄)'] t⃗_i = Σ_{i=m+1}^{n} t⃗_i' C_x̄ t⃗_i
