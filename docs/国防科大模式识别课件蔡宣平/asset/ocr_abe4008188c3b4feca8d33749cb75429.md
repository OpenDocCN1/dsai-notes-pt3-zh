将P(ωi|x)代入判别式，判别规则可表示为

若 p(x⃗|ω1)P(ω1) > p(x⃗|ω2)P(ω2) 则 x⃗ ∈ ω1
若 p(x⃗|ω1)P(ω1) < p(x⃗|ω2)P(ω2) 则 x⃗ ∈ ω2

或改写为

l12 = p(x⃗|ω1)/p(x⃗|ω2) > P(ω2)/P(ω1) = θ12 则 x⃗ ∈ ω1
l12 = p(x⃗|ω1)/p(x⃗|ω2) < P(ω2)/P(ω1) = θ12 则 x⃗ ∈ ω2

l12称为似然比（likelihood ratio），θ12称为似然比的判决阈值。

原则：要确定x是属于ω1类还是ω2类，要看x是来自于ω1类的概率大还是来自ω2类的概率大。
