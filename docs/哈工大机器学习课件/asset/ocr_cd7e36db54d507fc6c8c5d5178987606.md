# 最小描述长度准则（3）

+   - 使用编码理论的结论来解释等式6.16
+     - -log₂P(h)是在假设空间H的最优编码下h的描述长度。换言之，这是假设h使用其最优表示时的大小
+     - L_{C_H}(h) = -log₂ P(h)，C_H为假设空间H的最优编码
+     - -log₂P(D|h)是在给定假设h时，训练数据D的描述长度，L_{C_{D|h}}(D|h) = -log₂ P(D|h)，C_{D|h}是假定发送者和接收者都知道假设h时描述数据D的最优编码
+     - 因此式子6.16显示，h_MAP是使假设描述长度和给定假设下数据描述长度之和最小化的假设
+   - 最小描述长度准则：h_{MDL} = arg min_{h∈H} L_{C1}(h) + L_{C2}(D|h)
