# 局部加权线性回归（2）

+   - 三种重新定义误差准则E，以着重于拟合局部训练样例，记为E(x_q)
+     - 只对在k个近邻上的误差平方最小化
+       $E_1(x_q)=\frac{1}{2}\sum_{x \in \text{k个近邻}}(f(x)-\hat{f}(x))^2$
+     - 使整个训练样例集合D上的误差平方最小化，但对每个训练样例加权，权值为关于相距x_q距离的某个递减函数K
+       $E_2(x_q)=\frac{1}{2}\sum_{x \in D}(f(x)-\hat{f}(x))^2 K(d(x_q,x))$
+     - 综合1和2
+       $E_3(x_q)=\frac{1}{2}\sum_{x \in \text{k个近邻}}(f(x)-\hat{f}(x))^2 K(d(x_q,x))$
