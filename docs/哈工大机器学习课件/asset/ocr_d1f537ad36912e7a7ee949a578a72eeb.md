# 不可知学习和不一致假设

+   - 如果学习器不假定目标概念可在H中表示，而只简单地寻找具有最小训练错误率的假设，这样的学习器称为不可知学习器
+   - 式7.2基于的假定是学习器输出一零错误率假设，在更一般的情形下学习器考虑到了有非零训练错误率的假设时，仍能找到一个简单的边界
+   - 令S代表学习器可观察到的特定训练样例集合，\(errors(h)\)表示h的训练错误率，即S中被h误分类的训练样例所占比例
+   - 令\(h_{best}\)表示H中有最小训练错误率的假设，问题是：多少训练样例才足以保证其真实错误率\(error_D(h_{best})\)不会多于\(\epsilon+error_S(h_{best})\)？（上一节问题是这个问题的特例）
