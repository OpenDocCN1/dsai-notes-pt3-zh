# 举例：学习分类文本（3）

+   - 计算式 $v_{NB} = \arg\max_{v_j \in \{like, dislike\}} P(v_j) \prod_{i=1}^{19} P(a_i | v_j) = \arg\max_{v_j \in \{like, dislike\}} P(v_j) P(a_1 = \text{''this''} | v_j)...P(a_{19} = \text{''sentences''} | v_j)$
+   - 注意此处贝叶斯分类器隐含的独立性假设并不成立。通常，某个位置上出现某个单词的概率与前后位置上出现的单词是相关的
+   - 虽然此处独立性假设不精确，但别无选择，否则要计算的概率项极为庞大。
+   - 另外实践中，朴素贝叶斯学习器在许多文本分类问题中性能非常好
