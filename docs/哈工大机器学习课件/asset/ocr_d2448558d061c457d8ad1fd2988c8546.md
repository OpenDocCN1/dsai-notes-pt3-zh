# Q算法举例（3）

- 证明：

+   - 令 s' = δ(s,a)，则
+   |Q̂_{n+1}(s,a) - Q(s,a)| = |(r + γ max_{a'} Q̂_n(s',a')) - (r + γ max_{a'} Q(s',a'))|
+   = γ |max_{a'} Q̂_n(s',a') - max_{a'} Q(s',a')|
+   ≤ γ max_{a'} |Q̂_n(s',a') - Q(s',a')|
+   ≤ γ max_{s'',a'} |Q̂_n(s'',a') - Q(s'',a')|

+   - 令 Δ_n = max_{s,a} |Q̂_n(s,a) - Q(s,a)|，则
+   Δ_{n+1} ≤ γ Δ_n
+   lim_{n→∞} Δ_n = 0
