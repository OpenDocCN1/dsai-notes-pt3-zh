# 对基于解释的学习的说明（2）

+   - 基于解释的学习的特点
+     - 作为理论引导的样例泛化
+       - 使用给定的领域理论以从样例中合理泛化，区分出相关和不相关的样例属性，因此可以避免用于纯归纳推理中的样本复杂度界限
+     - 作为样例引导的理论重建
+       - Prolog-EBG算法被看作是一种重建领域理论到一种可操作形式的方式
+       - 重建领域理论是通过创建这样的规则
+         - 能从领域理论中演绎派生
+         - 在一个推理步内分类观察到的训练样例
+       - 学习到的规则可看作是领域理论的重组，它们能够在一个推理步内对目标概念的实例分类
