# 朴素贝叶斯分类器（4）

+   - 举例
+     - 表3-2提供了目标概念PlayTennis的14个训练样例，给新实例 <sunny, cool, high, strong>分类
+     - v_NB = arg max_{v_j ∈ {yes,no}} P(v_j) ∏_i P(a_i | v_j) = arg max_{v_j ∈ {yes,no}} P(v_j)P(sunny | v_j)P(cool | v_j)P(high | v_j)P(strong | v_j)
+     - 根据表3-2，可以计算出上式需要的概率值
+       - P(yes)=9/14=0.64
+       - P(no)=5/14=0.36
+       - P(strong|yes)=3/9=0.33
+       - P(strong|no)=3/5=0.60
+       - ...
+     - 求 v_NB
+       - P(yes)P(sunny|yes)P(cool|yes)P(high|yes)P(strong|yes)=0.0053
+       - P(no)P(sunny|no)P(cool|no)P(high|no)P(strong|no)=0.0206
+       - v_NB=no
