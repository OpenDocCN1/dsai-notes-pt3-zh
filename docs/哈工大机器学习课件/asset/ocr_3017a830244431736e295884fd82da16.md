# FOIL中的候选特化式的生成
（3）

+   - 生成进一步特化该规则的候选文字
+     - Female(z)
+     - Equal(z,x)
+     - Equal(x,z)
+     - Father(z,w)
+     - Father(w,z)
+     - 上面文字的否定

如果FOIL选择了Father(z,x)，然后又选择了Female(y)，将得到下面的规则，它只覆盖正例，因此终止了进一步搜索该规则的特化式的过程

```
GrandDaughter(x,y)←Father(y,z)∧Father(z,x)∧Female(y)
```

+   - FOIL移去被该规则覆盖的所有样例，如果还有未覆盖的正例，算法将开始搜索下一个规则
