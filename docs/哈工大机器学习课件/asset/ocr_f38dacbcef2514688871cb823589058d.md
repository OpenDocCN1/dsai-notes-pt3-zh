# 特定情况下的MAP假设（3）

+   - P(D)的推导
+     P(D) = Σ_{h_i ∈ H} P(D | h_i) P(h_i)
+     = Σ_{h_i ∈ V S_{H,D}} 1 × 1/|H| + Σ_{h_i ∉ V S_{H,D}} 0 × 1/|H|
+     = Σ_{h_i ∈ V S_{H,D}} 1 × 1/|H|
+     = |V S_{H,D}| / |H|
+   - 假设的概率演化情况如图6-1所示，初始时所有假设具有相同的概率，当训练数据逐步出现后，不一致假设的概率变为0，而整个概率的和为1，它们均匀分布到剩余的一致假设中
+   - 每个一致的假设都是MAP假设
