# 学习算法比较（3）

+   - 表5-5返回的 可被用作对公式5.14的一个估计，更合适的说法是把 看作下式的估计
+     $E_{S \subseteq D_b}[error_D(L_A(S)) - error_D(L_B(S))]$ 
+   - 估计式5.17的近似的N%置信区间可表示成 $\bar{\delta} \pm t_{N,k-1} s_{\bar{\delta}}$，其中 $t_{N,k-1}$是一常数，其意义类似于前面的$z_N$，第一个下标表示所需的置信度，第二个下标表示自由度，常记作$v$，它与生成随机变量的值时独立的随机事件数目相关。
+     而 代表 所服从的概率分布的标准差的估计，定义如下
+     $s_{\bar{\delta}} = \sqrt{\frac{1}{k(k-1)} \sum_{i=1}^{k} (\delta_i - \bar{\delta})^2}$ 
+   - 注意当自由度$v \to \infty$时，$t_{N,v}$的值趋向常数$z_N$。
