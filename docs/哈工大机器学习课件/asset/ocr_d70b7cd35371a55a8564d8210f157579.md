# Q学习

+   - 机器人在任意的环境中直接学习最优策略很难，因为没有形式为<s,a>的训练样例
+   - 训练数据是立即回报函数，容易学习一个定义在状态和动作上的数值评估函数，然后实现最优策略
+   - 很明显，可以将V*作为待学习的评估函数，由于状态s下的最优动作是使立即回报r(s,a)加上立即后继状态的V*值最大的动作a，即
+     π*(s) = arg maxₐ [r(s,a) + γ V*(δ(s,a))]
+     因此，如果具有回报函数和状态转移函数的完美知识，那么就可以计算出任意状态下的最优动作
+   - 但在实际问题中，无法知道回报函数和状态转移函数的完美知识
