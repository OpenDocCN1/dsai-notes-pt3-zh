# 群体进化和模式理论（4）

+   - 同时考虑交叉和变异，仅考虑单点交叉和可能造成的负面影响
+     $E[m(s,t+1)] \ge \frac{\hat{u}(s,t)}{\hat{f}(t)} m(s,t) \left(1 - p_c \frac{d(s)}{l-1}\right) (1 - p_m)^{o(s)}$
+     最左一项描述了选择步的影响，中间一项描述了单点交叉算子的影响，最后一项描述了代表模式s的任意个体在应用了变异算子后还代表s的概率
