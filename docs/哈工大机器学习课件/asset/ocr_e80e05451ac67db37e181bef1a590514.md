# 学习到的隐藏层表示

+   - 图中紧挨人脸图像下的4个矩形，每个矩形描绘了网络中4个输出单元中的一个权值，每个矩形中的4个小方形表示和这个输出单元关联的4个权值
+   - 隐藏单元的权值显示在输出单元的下边，每个隐藏单元接受所有30x32个像素输入。与这些输入关联的30x32个权值被显示在它们对应的像素的位置
+   - 针对每一个训练样例，梯度下降迭代100次后的网络权值显示在图的下部。  - 如果一个人的脸是转向他的右面，那么他的亮度高的皮肤会大致与这个隐藏单元中的较大正值对齐，同时他的亮度低的头发会大致与负权值对齐，这导致此单元输出一个较大的值，同样的图像会使第3个隐藏单元输出一个接近0的值。
