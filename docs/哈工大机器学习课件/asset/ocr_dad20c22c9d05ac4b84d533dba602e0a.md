# 学习规则集：小结（4）

+   - 规则的后修剪和后修剪的方法
+     - Learn-One-Rule也有可能形成过度拟合，解决的方法也可以是后修剪
+   - 性能函数的定义
+     - 相对频率：令n代表规则所匹配的样例数目，n_c代表其中它能正确分类的数目，则规则性能的相对频率估计为 n_c / n
+     - 精度的m-估计：令p为从整个数据集中随机抽取的样例与该规则赋予的分类相同的先验概率，令m为权，或称对此先验概率p进行加权的等效样例数目 (n_c + m p)/(n + m)
+     - 熵：令S为匹配规则前提的样例集合，熵衡量的是该样例集合中目标函数的均一性 Entropy(S)= - Σ p_i log2 p_i
