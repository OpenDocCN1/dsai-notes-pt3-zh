# 朴素贝叶斯分类器（3）

+   - 朴素贝叶斯分类器的定义： $v_{NB} = \arg\max_{v_j \in V} P(v_j) \prod_i P(a_i \mid v_j)$
+   - 从训练数据中估计不同 $P(a_i \mid v_j)$ 项的数量比要估计 $P(a_1, ..., a_n \mid v_j)$ 项所需的量小得多
+   - 只要条件独立性得到满足，朴素贝叶斯分类 $v_{NB}$ 等于 MAP 分类，否则是近似
+   - 朴素贝叶斯分类器与其他已介绍的学习方法的一个区别：没有明确地搜索可能假设空间的过程（假设的形成不需要搜索，只是简单地计算训练样例中不同数据组合的出现频率）
