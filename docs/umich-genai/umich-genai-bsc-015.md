# 生成式AI基础知识：15：生成式AI的幻觉现象

![](img/7b45d9aa9fc92f6432f3de4b8151581b_0.png)

## 📚 概述

在本节课中，我们将要学习生成式AI的一个重要概念与挑战：幻觉现象。我们将探讨其本质、产生原因、潜在风险以及它与人类认知的差异。

## 🤔 生成式AI的核心目标

从根本上说，生成式AI的理念是“创造事物”。它的目标是生成新颖且有趣的内容。

**核心公式**：`生成式AI = 生成(新颖 + 有趣的内容)`

然而，问题在于，如果你生成的内容是新颖且有趣的，你还需要知道，你所生成的这些新颖有趣的事物，并非虚假的。

## 🧠 人类与AI的认知差异

我们人类能够理解，当有人在讲故事时，那是一个故事，并非事实，而是虚构的。另一方面，当某人撰写学术文章并说“这是我的引用”时，那最好不是虚构的。那最好是对一篇实际存在的、被引用的学术著作的真实参考。

**关键区别**：人类能区分虚构与事实，而生成式AI（至少在目前）不知道如何做出这种区分。

## ⚠️ 幻觉：当前最受关注的局限

这或许是当前生成式AI系统最受讨论的局限性。对于生成式AI创造的这类“编造”事物，技术术语是“幻觉”。

**定义**：`幻觉 = AI生成的、看似合理但实际为虚构或错误的信息`

当前的生成式AI系统充满了幻觉，并且它们以非常有说服力的语言陈述。你无法从系统中获得任何暗示，表明它缺乏确定性，或者像人类那样通过面部表情、犹豫或支吾来暴露不确定或说假话的迹象。

这是一个当前存在的问题。我预计未来会找到技术解决方案，从而减少这种现象。但就目前而言，这是一个非常严重的问题，任何人在使用生成式AI系统时都必须考虑到。

## 🔍 更深层次的问题

回到我之前所说的关于人类本质的观点：人类倾向于认为用流利语言阐述的、论证充分的陈述比其他类型的陈述更可信。

更深层次的问题是，生成式AI系统能够非常流利地向我们呈现虚假信息。

换句话说，如果有人想故意使用生成式AI系统来误导我们，或让我们相信不真实的事情，他们拥有这样做的工具，因为这正是生成式AI系统所擅长的。

**核心风险**：`恶意使用 = 利用AI生成流利、可信的虚假信息`

这是一个比无意的幻觉问题更深层、更根本的问题。

## 📝 总结

![](img/7b45d9aa9fc92f6432f3de4b8151581b_2.png)

本节课中，我们一起学习了生成式AI的“幻觉”现象。我们了解到，生成式AI的核心是创造，但它目前无法像人类一样区分虚构与事实，从而导致其可能生成看似合理实则错误或虚构的内容。我们区分了无意的技术性“幻觉”与可能被恶意利用来制造虚假信息的更深层风险。认识到这一局限性，对于负责任地使用和评估生成式AI的输出至关重要。
