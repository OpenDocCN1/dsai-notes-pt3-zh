# 生成式 AI 示教：50：教育领域对AI的审慎态度与批判思维

![](img/68bf7300edb6408adebd03d5337c6d9e_1.png)

在本节课中，我们将探讨在教育领域，特别是医学教育中，应如何以审慎和批判性的思维看待以ChatGPT为代表的生成式AI技术。我们将分析历史经验教训，并强调基于证据的实践方法的重要性。

## 关于ChatGPT的认知

上一节我们介绍了生成式AI的潜力，本节中我们来看看如何理性地看待它。

我们必须认识到，这是一个重大的技术突破。这一点很重要。

我经常想起人工智能和机器学习领域其他重大突破的例子。其中一个例子是IBM Watson，它曾引起过巨大的炒作。IBM Watson至今仍然存在，但由于媒体报道，以及坦率地说，其市场营销和宣传方式，它经历了一些波折。

对于ChatGPT，我认为我们应该参考IBM Watson以及其他案例的经验。我们可以为之兴奋，并寻求在此基础上发展，但必须保持谨慎。

## 培养批判性思维：从怀疑到实践

以下是关于在教育中培养正确态度的关键点。

*   **倡导怀疑而非愤世嫉俗**：在我负责医学院循证医学课程时，我经常鼓励医学生保持怀疑态度，但不要愤世嫉俗。要远离愤世嫉俗，保持怀疑精神。
*   **怀疑精神的价值**：这种怀疑精神将使我们能够最有效地将这些工具部署到实践中。
*   **审慎的实施路径**：对于ChatGPT，它确实是一项伟大的、重大的突破。但我认为，我们必须确保在将此类工具引入医学教育和临床实践时，采取一种审慎、有度的方式。

本节课中我们一起学习了应以理性和批判性的眼光看待以ChatGPT为代表的AI技术。我们回顾了历史经验，强调了怀疑精神对于负责任地应用新技术的重要性，并指出在教育与实践领域采纳这些强大工具时，必须采取审慎和基于证据的路径。
