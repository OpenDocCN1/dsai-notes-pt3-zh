# 生成式AI示教：P43：提示工程实践 🧠

![](img/a5b917f6c71c81cec40010267f24c80a_0.png)

在本节课中，我们将探讨一个生成式AI领域的核心技能——提示工程。我们将了解它的定义、重要性，并分析它未来可能的发展方向。

## 什么是提示工程？ 🤔

上一节我们介绍了生成式AI的基本概念，本节中我们来看看如何与这些系统进行有效沟通。提示工程，或称提示创作，其核心在于：**如何生成特定的文本、音乐或图像描述字符串，并将其输入到生成式AI系统中，以引导系统产生符合预期的输出**。

这些系统具有独特的行为特性，其输出结果会随着输入内容的结构和方式而发生显著变化。因此，掌握如何构建有效的输入提示，是一项正在快速发展的专业技能。

## 提示工程的未来：专业技能还是通用能力？ 🔮

随着新技术的出现，劳动力市场总会产生新的机会。回顾互联网的崛起，我们可以发现一个有趣的类比。

以下是搜索引擎优化的发展历程：
*   **新生角色**：搜索引擎优化（SEO）在25年前并不存在。
*   **核心地位**：如今，它已成为任何面向网络业务的基础组成部分。

那么，提示工程将如何演变？这其中有两点值得思考：
1.  它是否会像搜索引擎优化一样，演变成一个独立的专业学科和特定技能？
2.  抑或它会像使用谷歌搜索引擎或进行网络搜索一样，成为我们每个人都熟练掌握的通用能力？

网络搜索在25年前并非大众技能，但今天已被广泛掌握。因此，提示工程未来的发展路径将非常引人注目：**它究竟会演变为一种需要专门学习的新职业，还是融入成为每个人的基础数字素养？** 观察它是否会成为未来组织中的一种新角色，将是一件非常有趣的事情。

## 总结 📝

![](img/a5b917f6c71c81cec40010267f24c80a_2.png)

本节课中我们一起学习了提示工程的基本概念。我们了解到，提示工程是通过精心设计输入文本来引导AI生成理想输出的关键过程。同时，我们探讨了它未来发展的两种可能路径：成为一门像SEO一样的专业学科，或者发展为像网络搜索一样的通用技能。理解这一点，有助于我们更好地为AI驱动的未来做好准备。
