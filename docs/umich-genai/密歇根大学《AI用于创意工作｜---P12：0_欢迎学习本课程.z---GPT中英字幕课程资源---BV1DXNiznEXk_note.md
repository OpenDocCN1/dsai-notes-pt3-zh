# AI用于创意工作：P12：负责任地使用AI

![](img/f43e3f82dd5b5b96ed36a6eccb7d694c_0.png)

## 概述

在本节课中，我们将探讨如何在创意工作中负责任地使用人工智能工具。我们将学习如何评估AI的适用性，理解其能力与局限，并规避相关的伦理与法律风险。

我们已经开始探索AI工具如何被用于提升工作场所的创造力，并且你也有机会思考整合AI可能如何影响你自己的创意工作流程。现在，让我们花点时间思考一下接下来的步骤。

## 采用AI前的关键考量

在采用最新、最强大的AI应用程序之前，批判性地思考在何种情况下适合整合AI至关重要。

我们如何在创意背景下学会负责任地使用AI？在工作场所使用AI是否存在一套最佳实践？AI是否总是应对我们所面临挑战的合适解决方案？

在本模块中，我们将转向在创意背景下使用AI的实际与伦理维度。

## 理解AI的能力与局限

理解AI的能力及其局限性非常重要。尤其是在涉及AI治理、数据安全和知识产权等关键问题时，评估和权衡在工作场所使用AI的风险尤为重要。

我们将首先讨论如何负责任地使用生成式AI，如何跟上围绕AI的法律环境，以及如何避免公司为错误任务采用AI工具时可能产生的声誉风险。

## 核心评估流程：CIF

接下来，我们将介绍整个课程的核心组成部分——一个你可以用来识别、评估、并最终证明或排除使用任何AI工具的过程。我们称这个必不可少的四步流程为 **CIF**。

以下是CIF流程的四个步骤：

1.  **明确需求**：具体定义你希望通过AI解决的问题或达成的目标。
2.  **识别工具**：寻找并筛选可能满足你需求的AI工具。
3.  **聚焦评估**：深入评估候选工具在准确性、偏见、数据安全等方面的表现。
4.  **建立信任**：在充分了解其局限性和风险后，决定是否信任并使用该工具。

通过将这一流程应用到你的工作中，通过学习如何筛选你的AI选项，你将能够开始负责任、合乎道德且高效地提升你的创意工作。
