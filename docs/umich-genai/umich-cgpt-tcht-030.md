# ChatGPT 示教：30：ChatGPT作为团队协作者 🤖

在本节课中，我们将探讨人工智能在医学领域中的不同角色，特别是如何从“工具”和“协作者”两个维度来理解其应用。我们将了解人工智能如何与医疗工作者互动，以及不同自主级别的人工智能系统在医疗决策中的作用。

我的名字是科尼利厄斯·詹姆斯，我是密歇根大学内科、儿科和学习健康科学系的助理教授。我领导一个名为“数据增强技术辅助医疗决策团队”的小组，简称Data MD。我们的工作是开发课程，旨在教授医学教育连续体中的学习者关于人工智能和机器学习的知识。

在个人与人工智能和机器学习的互动方式上，本质上会存在一个连续体。你经常会听到它被称为一种**工具**，在某些情况下这是合适的，而在其他情况下，它会是**一个团队成员**。

## 从工具到队友 🛠️➡️🤝

![](img/82e7687c820e3e3e0ee5d736e578d66b_1.png)

上一节我们提到了人工智能角色的连续性，本节中我们来看看“工具”与“队友”的具体区别。

如果你思考一下“工具”，它通常不会与你互动，或者在很多方面不会与你进行交互。因此，在某些情况下，人工智能与个人（例如临床医生）不会有太多的直接互动或接触。

![](img/82e7687c820e3e3e0ee5d736e578d66b_1.png)

而在其他情况下，人工智能可以与患者、医学生或临床医生进行双向交流。例如，聊天机器人就是一种工具，人们可以在手机上使用它，个人可以真正地与该技术进行来回对话。因此，在这方面，考虑到正在发生的双向交流，我认为它有可能成为一个“队友”。这与其它技术不同，那些技术通常只是向计算机输入一些东西，然后你会得到一个输出结果，但在很多情况下，并没有那么多的双向交流。

## 人工智能的自主性级别 🤖⚙️

理解了互动模式后，另一个关键维度是人工智能的自主性。我将补充说明，人工智能将具有不同级别的自主性。

在某些情况下，人工智能将不需要任何直接的人类输入或响应。而在其他时候，在人工智能做出响应、给出答复或能够根据其接收到的输入采取行动之前，人类将监督人工智能所做的一切。

你可以想象，一个工具通常不具有自主性，我们一般不会谈论一个工具有很高的自主权。而对于人工智能，你会遇到完全没有自主性、完全由人类指导和驱动的人工智能；也会有半自主的人工智能，它们会像团队一样协同工作来执行某些任务；还会有完全自主的人工智能，它不依赖临床医生的任何输入或参与来做出决策。
