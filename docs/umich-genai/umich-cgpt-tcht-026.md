# ChatGPT 示教：26：对AI的经济应对措施 💼

![](img/a34d134123e56dc45b713b8e3b64d090_0.png)

在本节课中，我们将探讨以ChatGPT为代表的生成式AI技术对经济活动可能产生的颠覆性影响，并分析其带来的替代效应与互补效应。

![](img/a34d134123e56dc45b713b8e3b64d090_0.png)

像ChatGPT这样的技术，对许多经济活动具有潜在的颠覆性。这一点对于当今许多其他AI技术也同样适用。每当出现一种新的能力，能够通过技术手段生产出过去难以实现、令人惊讶的事物时，它就会调整许多决定人们行为方式的既有平衡。ChatGPT的表现显然让许多人，包括普通大众和专家，都感到惊讶。

具体来说，对于像ChatGPT这样的语言生成技术，生成连贯、切题的文本在人类历史的大部分时间里，一直是一项成本高昂且困难的事情。如果通过AI自动化手段突然使其变得便宜和容易得多，它首先可能催生各种以前因成本效益不高而无法尝试的新应用，这非常令人兴奋。它还能推动许多以前受限于需要通过语言沟通结果而适用性有限的AI决策应用。我认为，这至今仍是许多AI应用的一个障碍。如果AI突然能够相当可信、流利地与人类沟通，它将开启许多我们前所未见的新应用。

那么，这将如何影响当前的经济参与者和整体经济呢？每当出现新的机遇和变化时，我们都需要考虑两种效应。

以下是两种主要的经济效应：

1.  **替代**：如果某项任务有新的、更便宜、更有效的方式来完成，旧的方式可能会被取代。这可能包括一些目前由人完成的工作，未来会更多地由AI来完成。
2.  **互补**：当一项技术能够放大人的效能或降低其做某事的成本时，人们可以通过结合AI来更好、更高效地完成任务。这可能会为这些人创造更多机会，使其更具生产力并生产出更好的产品。

我认为，像AI语言生成这样的技术，通常这两种因素都会同时起作用，既有替代效应，也有互补效应。这两种效应的相对强弱可能因具体情境而异，并可能随时间而变化。

为了说明AI如何既互补又可替代，我们可以参考国际象棋的例子。虽然国际象棋并非具有重大经济意义的活动，但这个例子很有启发性。大约25年前，一个AI程序击败了国际象棋世界冠军，这意味着在象棋领域，没有人能比计算机做得更好。此后一段时间，最优秀的棋手实际上是人与象棋程序合作的团队。这种组合可以击败任何单独的人或程序。这种情况持续了大约20年。然而，象棋程序变得越来越强大。现在，在人与象棋程序的团队中，人类几乎无法带来多少额外价值，几乎全是程序在主导。我们看到了这种模式：AI最终占据主导地位，人与AI在技能上的团队协作起初是互补的，但随着技术发展，最终不再互补。随着时间的推移，我们可能会在一系列其他AI技术中看到类似的模式。

本节课中，我们一起学习了生成式AI技术可能带来的经济影响，重点分析了替代与互补两种核心效应，并通过国际象棋的发展历程看到了这两种效应动态变化的可能性。理解这些效应有助于我们思考如何在AI时代调整个人与组织的策略。
