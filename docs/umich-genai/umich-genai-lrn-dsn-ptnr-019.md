# 生成式AI作为学习设计伙伴：3：生成式AI在学习中的优势与局限

![](img/5bd2d02cbb32ac6f7e70c127084fc59b_0.png)

在本节课中，我们将探讨生成式人工智能在学习环境中的应用，分析其优势与局限，并讨论如何将其定位为学习者的“智力伙伴”，以创造更有效的学习体验。

## 概述

在本系列课程中，我们主要讨论了学习设计师如何将生成式AI作为设计过程中的合作伙伴。然而，学习设计师的角色也包含为其他利益相关者提供关于学习活动与技术的咨询。因此，你可能会被问及生成式AI如何支持学习。本节我们将转换视角，探讨生成式AI如何与教育者和学习者一起应用于学习场景中。

当前，关于生成式AI在教育中的应用存在许多讨论，观点常趋于两极。一些人视其为解决教育诸多不足的“银弹”，另一些人则担忧它会导致作弊、浅层学习甚至取代教师。作为学习设计师，我们需要采取更审慎的态度，理解这些工具何时对学习有益，何时又需对其应用保持警惕。

## 生成式AI的优势与局限

为了展开讨论，我们首先需要了解生成式AI的优势与局限。

### 优势

生成式AI工具能够生成文本、图像和视频元素。具体能力包括：
*   撰写各类文章。
*   编写计算机代码。
*   对大量文本进行总结。
*   帮助发现不同信息集之间的关系与联系。
*   随着用新数据训练，能够持续学习新的信息和关系，从而强化模型，甚至开发专注于特定内容领域的更专业的AI模型。

### 局限

然而，生成式AI工具也存在一些弱点：
*   **可能产生错误**：有时是陈述不准确，有时则是编造信息并以看似权威的方式呈现。
*   **可能传递偏见与错误信息**：由于AI模型基于不同词语和短语之间的联系进行生成，如果训练数据包含偏见和错误信息，其底层模型就可能携带这些偏见和错误，并据此产生不准确的信息。
*   **引发伦理问题**：如果我们不经审查就直接采信生成式AI的输出，会带来伦理风险。

## 在学习场景中应用生成式AI

审视了这些优势与局限后，我们如何看待生成式AI在学习场景中的应用呢？

一个焦点问题是人们担心学习者会利用这些工具作弊，或将其生成的作品直接当作自己的成果。这被视为问题有两个原因：一是这被视为一种抄袭形式；二是生成式AI可能产生错误的作品。

我们可以将此担忧理解为：生成式AI可能无法支持学习，因为在上述例子中，它替学习者完成了所有重要的认知工作。因此，我们需要思考如何转变这一状况。

### 将生成式AI作为智力伙伴

![](img/5bd2d02cbb32ac6f7e70c127084fc59b_2.png)

![](img/5bd2d02cbb32ac6f7e70c127084fc59b_3.png)

我们需要创造这样的学习活动：学习者可以与生成式AI协作，但学习者仍需承担大部分的认知努力。换句话说，正如我们在系列课程中将生成式AI视为学习设计的“设计伙伴”一样，在思考如何支持学习时，我们现在也需要将生成式AI视为学生的“智力伙伴”。

我们应推动设计这样的学习活动：生成式AI生成的材料可供学习者使用，或以不同方式支持学习者正在进行的工作。目前，一些教育者已经开始探索以不同方式整合生成式AI的实例。

以下是一些应用示例：

*   **生成与评估**：与其布置学习者可能直接让AI代笔的论文写作任务，一些教育者让学生先用生成式AI生成一件作品（如文章、程序），然后学习活动要求学习者对该作品进行审查、批判和修正。
    *   **示例**：学习历史时，让生成式AI生成一篇关于某个历史事件的文章，然后让学习者评估该文章的历史准确性。
    *   **示例**：让生成式AI生成一个计算机程序、数学方程式或论文，然后让学生评估这些作品，并为AI“打分”，讨论其优缺点。
*   **作为反馈与修订工具**：一些教育者让学习者将论文初稿提交给生成式AI，以获得如何改进作品和写作的反馈。然后学习者根据反馈修订作品，并可能进行多轮修订循环。最后，学习者提交最终作品、之前的草稿以及AI的反馈，以便教育者了解他们的修订过程。
*   **比较与反思**：学习者先撰写自己的论文，然后让生成式AI就同一主题生成一篇论文。接着，学习者比较两篇论文，决定如何修改自己的论文，同时批判AI生成的论文。这有助于他们同时思考内容和自己的写作。
*   **生成反思性问题**：在阅读文本的学习活动中，可以指导学习者将阅读材料提交给生成式AI，并提示AI生成一些反思性问题或其他反思提示，供学习者思考和回答，从而帮助他们更深入地理解所读内容。

这些示例说明了一个关键点：当我们思考生成式AI如何支持学习时，需要将其视为学习者的智力伙伴。它不应为学习者完成重要的认知工作，而是可以被学习者和教育者以不同方式使用，通过新的活动和材料重塑学习情境，但始终牢记，学习者仍应负责完成重要的认知工作。

## 总结

本节课中，我们一起学习了生成式AI在学习中的优势与局限，并探讨了如何通过将其定位为“智力伙伴”来创造有效的学习活动。关键在于设计让学习者与AI协作但仍需付出主要认知努力的任务，例如评估AI生成内容、利用AI反馈进行修订或进行比较分析。
