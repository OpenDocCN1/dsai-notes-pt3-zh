# 总体数据质量（框架、度量、设计策略）：0：欢迎来到专项课程第三门课程

在本节课中，我们将介绍密歇根大学《总体数据质量》专项课程的第三门，也是最后一门课程。我们将概述本课程的核心目标、内容结构及其在整个专项课程中的定位。

欢迎来到“总体数据质量”专项课程的第三门，也是最后一门课程。本课程名为“最大化总体数据质量的设计策略”。特里特和我将简要介绍这第三门课程，以及它在整个专项课程大背景下的位置。

在第三门课程中，我们将重点关注研究人员和分析师在进行分析之前，可以用来最大化其收集或获取数据质量的方法与途径。我们将再次通过真实案例研究和实际示例，来阐述如何使用这类设计策略提升数据质量。

这里的核心在于，考虑如何在研究开始、收集或获取数据之前，就根据总体数据质量框架的所有维度来最大化数据质量。

![](img/c7a1f70d378cfd4163bc8a3540c19e0a_1.png)

许多提出的策略适用于改进数据收集或获取阶段的流程。

其他策略则旨在修复发生后出现的质量问题。在第二门课程中，我们学习了度量数据质量的技术。

![](img/c7a1f70d378cfd4163bc8a3540c19e0a_1.png)

现在，我们将讨论如果您的质量度量被认为不足，如何有意识地改进数据质量。

完成这第三门课程，乃至整个专项课程后，您将对分析前理解数据质量的重要性，以及用于度量和改进质量的有用工具与技术，拥有全面的认识。

这将确保您的分析能在质量尽可能高的数据集上进行。
