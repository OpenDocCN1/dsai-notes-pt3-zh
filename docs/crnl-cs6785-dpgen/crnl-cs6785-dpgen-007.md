# 7：标准化流









在本节课中，我们将要学习一种新型的生成模型——标准化流。我们将首先探讨为什么需要这种模型，然后回顾概率论和微积分中的变量变换公式，这是定义标准化流所需的数学工具。最后，我们将精确地定义什么是标准化流。








## 动机：结合自回归模型与隐变量模型的优势




上一节我们介绍了自回归模型和隐变量模型。本节中，我们来看看为什么需要标准化流。










自回归模型基于概率链式法则，并使用神经网络参数化条件概率。其优点是似然函数易于计算，便于使用最大似然进行训练。然而，它们也存在缺点：需要人为指定变量顺序、生成过程是顺序的（速度慢），并且没有隐变量，因此难以进行无监督表示学习。













为了弥补最后一个缺点，我们引入了隐变量模型，例如变分自编码器。这类模型引入了隐变量 `Z`，可以用于发现数据中隐藏的变化因素。其优点是能够进行无监督表示学习，并且采样速度快。主要缺点是计算精确的似然函数变得困难，因为需要处理复杂的积分，通常需要使用变分推断进行近似。






这就引出了一个问题：**是否存在一种结合了自回归模型和隐变量模型优点的模型？** 具体来说，我们能否拥有一个同时具备隐变量和可精确计算似然的模型？答案是肯定的，这就是标准化流。







## 核心数学工具：变量变换公式


为了定义标准化流，我们需要一个关键的数学工具：变量变换公式。接下来的内容将是对微积分的一些回顾，理解这部分内容对于掌握标准化流至关重要。




### 一维情况下的变量变换






我们的总体策略是：从一个简单的分布（如高斯分布或均匀分布）开始，然后通过一个可逆的变换，将其映射到一个复杂的分布。



让我们看一个简单的例子。假设我们有一个隐变量 `Z`，服从 `[0, 2]` 上的均匀分布，其概率密度为 `p(z) = 1/2`。现在我们通过一个线性变换 `x = 4z` 将其映射到新变量 `X`。那么 `X` 的密度 `p(x)` 是多少？






一个常见的错误是直接认为 `p(x=4) = p(z=1) = 1/2`。这是不正确的，因为它忽略了分布支撑集（定义域）体积的变化。`Z` 的支撑集长度为 2，而 `X` 的支撑集长度为 8。总概率质量（面积为1）必须保持不变，因此当支撑集扩大时，密度必须按比例缩小。




正确的变量变换公式如下：如果 `x = f(z)` 是一个可逆映射，其逆函数为 `h = f^{-1}`，那么 `X` 的密度为：
`p(x) = p_z(h(x)) * |h'(x)|`
其中 `|h'(x)|` 是逆函数在 `x` 处的导数的绝对值，用于调整体积变化。


在我们的例子中，`f(z) = 4z`，逆函数 `h(x) = x/4`，导数 `h'(x) = 1/4`。因此：
`p(x) = p_z(x/4) * (1/4) = (1/2) * (1/4) = 1/8`
这正是 `[0, 8]` 上均匀分布的密度。



### 扩展到多维空间



对于高维数据（如图像），我们需要将变量变换公式推广到多维情况。这需要引入**行列式**作为高维空间中体积的度量。





对于一个线性变换 `x = A z`，其中 `A` 是一个可逆矩阵，变换后的体积缩放因子是 `A` 的行列式的绝对值 `|det(A)|`。如果 `Z` 在单位超立方体上均匀分布，那么 `X` 在由 `A` 定义的平行多面体上均匀分布，其密度为 `1 / |det(A)|`。




对于非线性变换 `x = f(z)`，我们使用其局部线性近似——**雅可比矩阵** `J_f(z)`。雅可比矩阵是所有一阶偏导数的矩阵。局部体积的缩放因子由雅可比矩阵的行列式给出。




因此，多维空间中的变量变换公式为：
`p(x) = p_z(f^{-1}(x)) * |det(J_{f^{-1}}(x))|`
根据逆函数定理，这等价于：
`p(x) = p_z(f^{-1}(x)) * |det(J_f(z))|^{-1}`，其中 `z = f^{-1}(x)`。

**关键点**：要使该公式成立，`X` 和 `Z` 必须是连续变量且维度相同，并且映射 `f` 必须是可逆的。









## 定义标准化流模型




有了变量变换公式，我们现在可以定义标准化流模型。



标准化流是一种隐变量模型，其中观测变量 `X` 和隐变量 `Z` 通过一个确定性的、可逆的变换 `f_θ` 相关联：
`X = f_θ(Z)`
其中，先验分布 `p(Z)` 通常是一个简单的分布（如标准高斯分布）。由于 `f` 是可逆的，我们可以利用变量变换公式直接得到 `X` 的精确密度：
`p(x) = p_z(f^{-1}(x)) * |det(J_{f^{-1}}(x))|`

### 标准化流的优势与挑战




以下是标准化流的主要优势：
*   **精确的似然计算**：我们可以精确计算 `p(x)`，便于使用最大似然估计进行训练。
*   **高效的采样**：通过祖先采样即可生成样本：先从 `p(Z)` 采样 `z`，然后计算 `x = f(z)`。
*   **精确的隐变量推断**：对于任何观测 `x`，我们可以通过 `z = f^{-1}(x)` 精确地得到其对应的隐表示。



然而，构建标准化流也面临核心挑战：**如何设计变换函数 `f_θ`？** 它必须满足以下三个条件：
1.  **可逆**：必须有显式或易于计算的逆函数。
2.  **表达能力强**：足以将简单分布映射到复杂的真实数据分布。
3.  **雅可比行列式易于计算**：因为训练时需要计算 `log |det(J_f)|`。



### 构建策略：组合简单变换




一个有效的策略是通过组合多个简单的可逆变换来构建复杂的变换：
`f = f_K ◦ ... ◦ f_2 ◦ f_1`
这样，最终变换的雅可比行列式是各层雅可比行列式的乘积：
`J_f(z) = J_{f_K}(z_{K-1}) * ... * J_{f_2}(z_1) * J_{f_1}(z)`
其对数行列式为各层对数行列式之和：
`log |det(J_f(z))| = Σ_{k=1}^{K} log |det(J_{f_k}(z_{k-1}))|`
如果每一层 `f_k` 的雅可比行列式都易于计算，那么整个模型就易于处理。

### 一个简单示例：平面流







Rezende & Mohamed (2015) 提出了一种称为“平面流”的简单变换：
`f(z) = z + u * h(w^T z + b)`
其中 `u, w` 是向量，`b` 是标量，`h` 是一个光滑的非线性函数。这个变换可以解释为沿着由法向量 `w` 定义的超平面“折叠”或“拉伸”空间。通过组合多个这样的层，可以将简单分布（如均匀分布或高斯分布）转换为复杂的多模态分布。





计算其雅可比行列式可以利用矩阵行列式引理，使其相对高效。然而，这类早期模型通常表达能力有限，或主要用于增强其他模型（如VAE）的先验分布。








## 总结与展望







本节课中我们一起学习了标准化流模型。
*   **动机**：我们希望能结合自回归模型（精确似然）和隐变量模型（有隐变量、采样快）的优点。
*   **核心数学**：变量变换公式 `p(x) = p_z(f^{-1}(x)) * |det(J_{f^{-1}}(x))|` 是标准化流的基础，它要求 `f` 是可逆的，且 `X` 和 `Z` 维度相同。
*   **模型定义**：标准化流通过一个可逆变换 `f_θ` 将简单先验分布 `p(Z)` 映射到复杂数据分布 `p(X)`。
*   **优势**：精确似然计算、高效采样、精确隐变量推断。
*   **核心挑战**：设计同时满足可逆、表达能力强、雅可比行列式易算的变换 `f_θ`。
*   **构建策略**：通过组合多个简单的可逆变换（如平面流）来构建复杂变换。

当前的主要挑战在于高效计算雅可比行列式。一个关键的思路是：如果雅可比矩阵是**三角矩阵**，那么其行列式就是对角线元素的乘积，计算复杂度仅为 `O(n)`。在下一讲中，我们将看到如何基于这一思路设计出更强大、实用的标准化流模型（如RealNVP, Glow），并将其直接应用于图像等复杂数据。
