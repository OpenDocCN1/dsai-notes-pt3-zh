## `COUNTA` 函数的使用

上一节我们了解了本课程的背景，本节中我们来看看一个具体函数 `COUNTA` 的应用。`COUNTA` 应该被更频繁地使用。**`COUNTA` 函数用于统计一个范围内所有非空单元格的数量**。

当我们希望数据完全整合时，例如我们想统计有多少个条目。假设我们有一个团队列表，我们需要知道列表中有多少个团队，以便进行后续的信息处理。

在一个应用程序构建场景中，我们正在筹备一个活动，我们有一份受邀人员名单。现在我们需要知道要订购多少张桌子，因为每张桌子可以坐 8 个人。我们需要知道总共有多少人。

以下是使用 `COUNTA` 的步骤：

1.  使用公式 `=COUNTA(`。
2.  选中包含人名的列。
3.  公式将给出总人数。
4.  然后将结果除以 8，即可得到所需的桌子数量。

**示例公式**：
```excel
=COUNTA(A2:A100) / 8
```
