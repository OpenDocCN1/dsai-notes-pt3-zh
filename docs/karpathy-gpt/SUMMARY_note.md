## 📘 P1：神经网络与反向传播详解

上一节我们介绍了课程的整体结构，本节中我们将深入探讨神经网络和反向传播的核心原理。

在本节课中，我们将要学习神经网络的基本构成以及反向传播算法如何工作。反向传播是训练神经网络的关键，它通过计算损失函数相对于每个参数的梯度来更新网络权重。

以下是神经网络训练的核心步骤：

1.  **前向传播**：输入数据通过网络层，计算得到预测输出。
2.  **计算损失**：使用损失函数（如均方误差、交叉熵）比较预测输出与真实标签的差异。
3.  **反向传播**：从输出层开始，利用链式法则将损失梯度逐层反向传播至每一层。
4.  **参数更新**：使用优化器（如随机梯度下降）根据梯度更新网络参数。

反向传播的核心是链式法则，其公式可以表示为：
`∂L/∂W = (∂L/∂y) * (∂y/∂W)`
其中 `L` 是损失，`y` 是网络输出，`W` 是权重参数。

## 📙 P2：语言模型构建入门：Makemore

上一节我们掌握了神经网络的基础，本节中我们来看看如何将这些知识应用于构建一个简单的语言模型。

在本节课中，我们将要学习如何构建一个名为“Makemore”的字符级语言模型。该模型的目标是根据给定的字符序列，预测下一个最可能出现的字符。

以下是构建 Makemore 模型的主要流程：

1.  **数据准备**：将文本数据转换为模型可处理的数字序列（Tokenization）。
2.  **模型设计**：设计一个简单的统计模型或神经网络模型来学习字符间的概率分布。
3.  **训练**：使用准备好的数据训练模型，优化其预测能力。
4.  **生成**：使用训练好的模型，从一个起始字符开始，迭代生成新的文本序列。

一个基础的 N-gram 模型可以用条件概率表示：
`P(字符_n | 字符_{n-1}, 字符_{n-2}, ..., 字符_{n-k})`
其中 `k` 是上下文窗口的大小。

## 📗 P3：构建 Makemore 第二部分：多层感知机（MLP）

上一节我们构建了一个基础的统计语言模型，本节中我们将引入更强大的多层感知机模型。

在本节课中，我们将要学习如何使用多层感知机来改进我们的 Makemore 模型。MLP 通过引入隐藏层和非线性激活函数，能够学习更复杂的字符关系模式。

以下是 MLP 模型的关键组成部分：

1.  **输入层**：接收字符的独热编码或嵌入向量。
2.  **隐藏层**：包含一个或多个全连接层，并使用如 `tanh` 或 `ReLU` 的非线性激活函数。
3.  **输出层**：一个全连接层，输出维度等于词汇表大小，通常接一个 `Softmax` 函数以获得每个字符的概率分布。
4.  **前向传播公式**：对于一个单隐藏层 MLP，其前向传播可表示为：
    `h = tanh(X * W1 + b1)`
    `y_hat = softmax(h * W2 + b2)`
    其中 `X` 是输入，`W1`、`b1`、`W2`、`b2` 是可学习参数。

## 📕 P4：构建 Makemore 第三部分：激活值与梯度，BatchNorm

上一节我们介绍了 MLP 的结构，本节中我们来看看训练过程中的两个重要方面：激活值的管理和梯度问题。

在本节课中，我们将要学习激活函数的选择如何影响信号流动，以及梯度消失/爆炸问题。同时，我们将引入批归一化（BatchNorm）技术来稳定训练过程。

以下是本节的要点列表：

1.  **激活函数**：`ReLU`、`tanh`、`Sigmoid` 等函数将非线性引入网络，但可能导致梯度饱和。
2.  **梯度问题**：深层网络中，梯度在反向传播时可能变得极小（消失）或极大（爆炸），使训练困难。
3.  **批归一化（BatchNorm）**：该技术对每一层的输入进行归一化（减均值，除标准差），可以加速训练并提高稳定性。其操作可表示为：
    `BN(x) = γ * ((x - μ) / √(σ^2 + ε)) + β`
    其中 `μ` 和 `σ` 是批数据的均值和标准差，`γ` 和 `β` 是可学习的缩放和偏移参数。

## 📒 P5：构建 Makemore 第四部分：成为反向传播忍者

上一节我们讨论了训练中的稳定性问题，本节中我们将深入反向传播的细节，手动推导梯度以加深理解。

在本节课中，我们将要学习如何手动计算复杂神经网络中所有参数的梯度。通过“反向传播忍者”训练，我们可以更直观地理解框架（如 PyTorch）中 `autograd` 的工作原理。

以下是手动反向传播的核心练习：

1.  **展开计算图**：将模型的前向传播过程分解为一系列基本的原子操作（如加法、乘法、激活函数）。
2.  **应用链式法则**：从最终损失开始，为每个原子操作计算局部梯度，然后反向传递。
3.  **验证结果**：将手动计算的梯度与自动微分框架（如 `torch.autograd.grad`）计算的结果进行比较，确保一致。
4.  **代码示例**：对于表达式 `z = x * y`，其局部梯度为：
    `∂z/∂x = y`
    `∂z/∂y = x`

## 📓 P6：构建 Makemore 第五部分：构建一个 WaveNet

上一节我们精通了反向传播，本节中我们将探索一种更先进的网络架构——WaveNet，用于序列建模。

在本节课中，我们将要学习 WaveNet 架构，它使用扩张因果卷积来捕获长距离依赖关系，最初用于音频生成，但也适用于文本。

以下是 WaveNet 模型的关键特性：

1.  **因果卷积**：确保在时间步 `t` 的输出仅依赖于时间步 `t` 及之前的输入，防止信息“泄漏”未来。
2.  **扩张卷积**：通过间隔跳过输入值来增加感受野，使网络能够用较少的层捕获更长的上下文。扩张率按层指数增长（如 1, 2, 4, 8...）。
3.  **残差连接和门控激活**：使用残差块缓解梯度消失问题，门控激活单元（如 `tanh` 和 `Sigmoid` 的组合）帮助控制信息流。
4.  **Softmax 输出**：预测下一个字符的概率分布。

## 📖 P7：让我们从头开始构建 GPT：用代码实现

上一节我们了解了用于序列建模的 WaveNet，本节中我们将聚焦于当今最著名的语言模型架构——GPT，并从零开始编码实现。

在本节课中，我们将要学习 GPT 模型的核心组件：Transformer 的解码器部分。我们将用 PyTorch 逐步实现一个简化版的 GPT。

以下是构建 GPT 的主要步骤：

1.  **Transformer 块**：实现包含多头自注意力机制和前馈神经网络的核心模块。
2.  **自注意力**：这是 GPT 的核心，允许每个位置关注其之前的所有位置。其关键公式为：
    `Attention(Q, K, V) = softmax(Q * K^T / √d_k) * V`
    其中 `Q`（查询）、`K`（键）、`V`（值）由输入线性变换得到，`d_k` 是键向量的维度。
3.  **位置编码**：由于 Transformer 本身不含循环或卷积，需要注入序列中字符的位置信息。
4.  **堆叠解码器层**：将多个 Transformer 块堆叠起来，形成深度模型。
5.  **语言模型头**：在最后一层输出上接一个线性层，将隐藏状态映射到词汇表 logits。

## 📰 P8：GPT 的现状

上一节我们从零构建了 GPT，本节中我们将退一步，了解 GPT 模型在更广阔背景下的发展现状、训练流程和应用方式。

在本节课中，我们将要学习 GPT 系列模型的演进、其训练的两个主要阶段（预训练与微调）以及如何有效地使用这些大语言模型。

以下是关于 GPT 现状的核心内容：

1.  **模型演进**：从 GPT-1 到 GPT-3 及以后，模型规模（参数数量、训练数据）呈指数级增长，能力也随之涌现。
2.  **两阶段训练范式**：
    *   **预训练**：在大量无标签文本数据上训练，目标是下一个 Token 预测，使模型获得通用语言理解和生成能力。
    *   **微调/对齐**：使用指令数据、人类反馈强化学习等技术，使模型遵循指令、变得更有用、无害且真实。
3.  **提示工程**：通过精心设计输入提示（Prompt），可以引导模型完成特定任务，而无需更新其权重。
4.  **能力与局限**：讨论模型在推理、代码生成等方面的强大能力，同时指出其在事实性、逻辑一致性等方面的局限性。

## 🔤 P9：让我们构建 GPT 分词器

上一节我们探讨了 GPT 的宏观现状，本节中我们将深入一个基础但至关重要的组件——分词器，它负责将原始文本转换为模型能够处理的 Token ID。

在本节课中，我们将要学习字节对编码分词器的工作原理，并动手实现一个简化版本。分词质量直接影响模型的效果和效率。

以下是构建 BPE 分词器的关键步骤：

1.  **数据准备**：收集文本语料，初始时将每个字符或字节视为一个基础 Token。
2.  **迭代合并**：统计所有相邻 Token 对的出现频率，将最频繁出现的那个对合并为一个新的 Token。
3.  **构建词汇表**：重复合并过程，直到达到预定的词汇表大小。所有出现过的单个字符、字节以及合并出的新片段构成了词汇表。
4.  **编码与解码**：
    *   **编码**：将新文本按照学到的合并规则，贪婪地或最大匹配地切分成词汇表中的 Token，然后转换为 ID。
    *   **解码**：将 Token ID 序列转换回对应的字符串片段，并拼接成完整文本。

一个简单的合并规则可以表示为：
`将频率最高的相邻对 (A, B) 替换为新符号 AB`

## 📝 P10：让我们复现 GPT-2 (124M)

经过前面所有章节的学习，我们已经掌握了构建 GPT 所需的全部基础知识。在本节中，我们将进行终极实践：完整复现一个中等规模的 GPT-2 模型（124M 参数）。

在本节课中，我们将要学习整合之前学到的所有组件——分词器、Transformer 架构、训练循环等，在一个更大规模上训练一个真正的 GPT-2 模型。

以下是复现 GPT-2 (124M) 的主要任务：

1.  **架构实现**：严格遵循 GPT-2 论文中的模型规格（层数、头数、隐藏维度等）实现 Transformer 解码器。
2.  **数据加载**：准备一个大规模文本数据集（如 OpenWebText），并应用我们构建的分词器进行处理。
3.  **分布式训练**：由于模型较大，可能需要使用多 GPU 进行数据并行或模型并行训练。
4.  **超参数配置**：设置合适的学习率、批大小、优化器（通常使用 AdamW）和训练步数。
5.  **生成文本**：使用训练好的模型，通过采样（如 Top-k 或 Nucleus 采样）生成连贯的文本。
