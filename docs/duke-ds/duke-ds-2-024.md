# 课程24：对数与指数的关联性 📊

![](img/75056e839501ea9df0728040f04e17a6_0.png)

在本节课中，我们将要学习对数与指数之间的紧密联系。理解指数是理解对数的基础，因为这两个概念本质上是同一个关系的两种不同表达方式。我们将学习对数的两种形式、基本规则，并通过实例演示如何运用这些规则来简化和解决包含对数的问题。

## 概述

![](img/75056e839501ea9df0728040f04e17a6_2.png)

![](img/75056e839501ea9df0728040f04e17a6_4.png)

![](img/75056e839501ea9df0728040f04e17a6_6.png)

一旦你对指数有了基本的理解，理解对数就不会有太大的跨越。原因在于这两个概念紧密相关。对数本质上是在回答一个问题：“底数要自乘多少次方才能得到这个数？”

## 对数的两种形式

![](img/75056e839501ea9df0728040f04e17a6_14.png)

![](img/75056e839501ea9df0728040f04e17a6_16.png)

![](img/75056e839501ea9df0728040f04e17a6_18.png)

上一节我们介绍了对数的基本概念，本节中我们来看看如何用两种不同的数学形式来表达它。

![](img/75056e839501ea9df0728040f04e17a6_20.png)

![](img/75056e839501ea9df0728040f04e17a6_22.png)

![](img/75056e839501ea9df0728040f04e17a6_23.png)

![](img/75056e839501ea9df0728040f04e17a6_25.png)

对数的公式可以有两种不同的形式。

![](img/75056e839501ea9df0728040f04e17a6_27.png)

**指数形式**：一个底数 `B` 自乘 `X` 次方，等于结果 `N`。
`B^X = N`

![](img/75056e839501ea9df0728040f04e17a6_29.png)

![](img/75056e839501ea9df0728040f04e17a6_31.png)

![](img/75056e839501ea9df0728040f04e17a6_33.png)

**对数形式**：以 `B` 为底，`N` 的对数等于 `X`。
`log_B(N) = X`

![](img/75056e839501ea9df0728040f04e17a6_35.png)

![](img/75056e839501ea9df0728040f04e17a6_37.png)

这两种形式捕捉的是同一个核心思想，即三个数字之间的关系：一个**底数**、一个**指数**和一个**结果**。

![](img/75056e839501ea9df0728040f04e17a6_39.png)

![](img/75056e839501ea9df0728040f04e17a6_41.png)

![](img/75056e839501ea9df0728040f04e17a6_43.png)

![](img/75056e839501ea9df0728040f04e17a6_45.png)

例如：
*   指数形式：`2^3 = 8`
*   对数形式：`log_2(8) = 3`

![](img/75056e839501ea9df0728040f04e17a6_47.png)

同理，`2^4 = 16` 等价于 `log_2(16) = 4`。

![](img/75056e839501ea9df0728040f04e17a6_49.png)

## 对数的基本规则

![](img/75056e839501ea9df0728040f04e17a6_51.png)

![](img/75056e839501ea9df0728040f04e17a6_53.png)

![](img/75056e839501ea9df0728040f04e17a6_55.png)

正如指数有基本规则一样，对数也有几个基本规则，用于简化和解决包含对数的问题。

![](img/75056e839501ea9df0728040f04e17a6_57.png)

![](img/75056e839501ea9df0728040f04e17a6_59.png)

![](img/75056e839501ea9df0728040f04e17a6_61.png)

以下是三个主要的对数运算法则：

![](img/75056e839501ea9df0728040f04e17a6_63.png)

**1. 乘积法则**
对数的乘积法则表述如下：
`log_B(X * Y) = log_B(X) + log_B(Y)`

**2. 商法则**
对数的商法则表述如下：
`log_B(X / Y) = log_B(X) - log_B(Y)`

![](img/75056e839501ea9df0728040f04e17a6_65.png)

![](img/75056e839501ea9df0728040f04e17a6_67.png)

**3. 幂与根法则**
当一个数 `X` 被自乘 `N` 次方时，其对数规则如下：
`log_B(X^N) = N * log_B(X)`

![](img/75056e839501ea9df0728040f04e17a6_69.png)

![](img/75056e839501ea9df0728040f04e17a6_71.png)

![](img/75056e839501ea9df0728040f04e17a6_73.png)

![](img/75056e839501ea9df0728040f04e17a6_74.png)

这个规则无论 `N` 是正数、负数、整数还是分数都适用。

![](img/75056e839501ea9df0728040f04e17a6_76.png)

![](img/75056e839501ea9df0728040f04e17a6_77.png)

现在，我们通过一些具体的例子来看看如何应用这些规则。

![](img/75056e839501ea9df0728040f04e17a6_84.png)

![](img/75056e839501ea9df0728040f04e17a6_86.png)

**示例 1：乘积法则**
`log_B(35) = log_B(7) + log_B(5)`，因为 `7 * 5 = 35`。

![](img/75056e839501ea9df0728040f04e17a6_89.png)

![](img/75056e839501ea9df0728040f04e17a6_91.png)

![](img/75056e839501ea9df0728040f04e17a6_93.png)

**示例 2：商法则**
`log_2(16 / 4) = log_2(16) - log_2(4)`
我们知道 `2^4 = 16`，所以 `log_2(16) = 4`。
我们知道 `2^2 = 4`，所以 `log_2(4) = 2`。
因此，`log_2(16 / 4) = 4 - 2 = 2`。

![](img/75056e839501ea9df0728040f04e17a6_95.png)

![](img/75056e839501ea9df0728040f04e17a6_97.png)

**示例 3：幂与根法则**
`log_10(7^5) = 5 * log_10(7)`
`log_B(1000^(1/3)) = (1/3) * log_B(1000)` （这是1000的立方根）
`log_B(X^(-1)) = -1 * log_B(X)`

![](img/75056e839501ea9df0728040f04e17a6_99.png)

![](img/75056e839501ea9df0728040f04e17a6_101.png)

## 组合运用规则

![](img/75056e839501ea9df0728040f04e17a6_103.png)

![](img/75056e839501ea9df0728040f04e17a6_104.png)

![](img/75056e839501ea9df0728040f04e17a6_106.png)

![](img/75056e839501ea9df0728040f04e17a6_108.png)

在实际问题中，我们经常需要组合运用多个对数规则。让我们尝试一个例子。

![](img/75056e839501ea9df0728040f04e17a6_110.png)

![](img/75056e839501ea9df0728040f04e17a6_111.png)

![](img/75056e839501ea9df0728040f04e17a6_113.png)

![](img/75056e839501ea9df0728040f04e17a6_115.png)

假设我们需要简化 `log_B(X^2 * Y^(-3))`。
1.  首先应用**乘积法则**：`log_B(X^2) + log_B(Y^(-3))`
2.  然后对每一项应用**幂法则**：`2 * log_B(X) + (-3) * log_B(Y)`
3.  最终结果为：`2 * log_B(X) - 3 * log_B(Y)`

![](img/75056e839501ea9df0728040f04e17a6_117.png)

再比如简化 `log_B(X^2 / Y^(-1/2))`。
1.  首先应用**商法则**：`log_B(X^2) - log_B(Y^(-1/2))`
2.  然后对每一项应用**幂法则**：`2 * log_B(X) - ((-1/2) * log_B(Y))`
3.  简化符号：`2 * log_B(X) + (1/2) * log_B(Y)`

![](img/75056e839501ea9df0728040f04e17a6_119.png)

## 一个实用技巧与方程求解

![](img/75056e839501ea9df0728040f04e17a6_120.png)

![](img/75056e839501ea9df0728040f04e17a6_122.png)

![](img/75056e839501ea9df0728040f04e17a6_124.png)

在处理对数时，有一个实用的变换技巧：
`log(A) + log(B) = log(A * B)`
同时，它也等于 `log(A) - log(1/B)`。在某些问题中，这种变换非常有用。

![](img/75056e839501ea9df0728040f04e17a6_126.png)

![](img/75056e839501ea9df0728040f04e17a6_128.png)

![](img/75056e839501ea9df0728040f04e17a6_130.png)

![](img/75056e839501ea9df0728040f04e17a6_132.png)

对数一个更高级的用法是求解对数方程。我们可以将方程两边视为同一个底数的指数。

![](img/75056e839501ea9df0728040f04e17a6_134.png)

![](img/75056e839501ea9df0728040f04e17a6_136.png)

![](img/75056e839501ea9df0728040f04e17a6_138.png)

**示例：** 求解方程 `log_2( (39X) / (X-5) ) = 4`。
1.  将方程两边都作为2的指数：`2^{ log_2( (39X)/(X-5) ) } = 2^4`
2.  因为 `2^{log_2(A)} = A`，所以左边简化为：`(39X) / (X-5) = 16`
3.  解这个方程：
    *   两边乘以 `(X-5)`：`39X = 16(X - 5)`
    *   展开：`39X = 16X - 80`
    *   移项：`39X - 16X = -80`
    *   合并：`23X = -80`
    *   解得：`X = -80/23`

![](img/75056e839501ea9df0728040f04e17a6_140.png)

![](img/75056e839501ea9df0728040f04e17a6_142.png)

![](img/75056e839501ea9df0728040f04e17a6_144.png)

本节课中我们一起学习了对数与指数的核心关联。我们认识到对数是“求幂运算的逆运算”，并掌握了它的**指数形式** `B^X = N` 和**对数形式** `log_B(N) = X`。我们重点学习了三个基本运算法则：**乘积法则**、**商法则**和**幂与根法则**，并通过多个例子练习了如何应用及组合这些法则来简化表达式和求解方程。理解这些规则是掌握对数运算的关键。
