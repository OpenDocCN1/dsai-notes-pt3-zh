## 概述：瞬时变化率与切线

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_15.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_16.png)

假设我们有一个函数 `y = f(x)` 的图像，用绿色曲线表示。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_17.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_19.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_20.png)

现在，我们选取一个特定的点 `x = a`。我们想问的问题是：函数 `f(x)` 在 `x = a` 这一点变化得有多快？这是一个我们习以为常但实际上非常微妙的问题。就像说“此刻我在路上的速度是每小时55英里”，这并不意味着下一小时我会移动55英里，而是描述**此刻**的瞬时速度。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_22.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_23.png)

这个瞬时变化率在微积分中是一个关键概念。其几何图像是：在 `x = a` 处，我们可以画一条与函数图像相切的红色直线，这条线被称为**切线**。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_25.png)

## 从直线斜率到切线斜率

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_33.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_35.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_36.png)

在之前的课程中，我们学习了如何计算直线的斜率。切线也是一条直线，它的斜率恰好等于函数在该点的瞬时变化率。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_38.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_40.png)

即使函数图像本身是一条曲线，但在每一个点上，我们都可以画出一条与之相切的直线。这条切线的斜率，我们称之为函数在该点的**导数**，记作 `f'(a)`。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_42.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_44.png)

那么，如何计算 `f'(a)` 呢？计算直线斜率需要两个点，但我们目前只有一个点 `(a, f(a))`。这就是微积分变得“棘手”的地方，我们需要引入极限的概念。核心公式如下：

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_46.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_47.png)

`f'(a) = lim (h -> 0) [ (f(a+h) - f(a)) / h ]`

在接下来的内容中，我们将逐步拆解这个公式的含义。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_49.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_50.png)

## 一个简单的例子：直线函数

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_52.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_54.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_56.png)

为了理解这个概念，让我们从一个非常简单的例子开始。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_58.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_60.png)

假设我们有函数 `y = 3x`。我们可以将其想象为一个（不现实的）商业模型：`x` 代表商品售价，`y` 代表总收入。这个模型说，价格越高，收入无限增长，这显然不现实，但便于我们理解。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_62.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_63.png)

假设当前定价为 `$a`。我们想知道：如果我将价格提高一点，收入会增加多少？对于直线函数，这个问题很简单。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_65.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_66.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_68.png)

我们在图像上找到点 `(a, 3a)`。如果将价格提高 `$1`，新点坐标为 `(a+1, 3(a+1))`。计算这两点间线段的斜率：

**斜率 = (y值变化量) / (x值变化量) = [3(a+1) - 3a] / [(a+1) - a] = 3 / 1 = 3**

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_70.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_71.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_72.png)

关键在于，提高 `$1` 会使收入增加 `$3`。如果提高 `$2`，收入会增加 `$6`。这正是直线斜率的含义：**斜率代表了 `x` 每变化一个单位时，`y` 的恒定变化量**。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_74.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_75.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_77.png)

## 回到现实：曲线函数

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_84.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_86.png)

现在，让我们看一个更现实的模型。下图中的绿色曲线代表一个更符合实际的价格-收入关系函数 `y = f(x)`。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_88.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_89.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_91.png)

通常，提高价格会使收入增加（因为每件商品赚得更多）。但价格过高时，顾客会减少购买，导致总收入下降。这就是图中曲线先上升后下降的原因。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_93.png)

现在再次提出关键问题：在定价为 `$a` 时，如果我将价格提高一点，收入会增加还是减少？变化率是多少？

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_95.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_96.png)

与直线不同，**这个问题的答案取决于我们所在的价格点**。例如：
*   在点 `a` 处，提高价格可能会使收入显著增加。
*   在点 `b` 处，提高价格带来的收入增幅较小。
*   在点 `c` 处，提高价格反而会使收入下降。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_97.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_98.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_99.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_101.png)

因此，曲线上不同点处的切线斜率是不同的。在 `x = a` 处，切线的斜率（即导数 `f'(a)`）就精确地回答了“收入随价格变化的瞬时速率”这个问题。

## 如何计算切线的斜率？

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_116.png)

回顾一下，计算直线斜率需要两个点。对于切线，我们只有一个点 `(a, f(a))`。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_118.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_120.png)

为了得到第二个点，我们引入一个很小的变化量 `h`。在曲线上取另一个点，其坐标为 `(a+h, f(a+h))`。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_122.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_124.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_126.png)

现在，我们可以计算通过点 `(a, f(a))` 和 `(a+h, f(a+h))` 的**割线**的斜率：

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_128.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_130.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_132.png)

**割线斜率 = [f(a+h) - f(a)] / [(a+h) - a] = [f(a+h) - f(a)] / h**

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_134.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_136.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_138.png)

这个公式给出了两点间的平均变化率。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_140.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_141.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_142.png)

微积分的核心思想来了：如果我们让第二个点无限接近第一个点，即让 `h` 无限趋近于0，那么这条割线就会旋转并无限逼近我们想要的**切线**。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_144.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_145.png)

因此，切线的斜率（即导数）就是这个割线斜率在 `h` 趋近于0时的**极限**：

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_147.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_148.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_149.png)

`f'(a) = lim (h -> 0) [ (f(a+h) - f(a)) / h ]`

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_151.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_153.png)

## 总结

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_157.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_158.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_159.png)

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_160.png)

本节课我们一起学习了：
1.  **切线的几何意义**：曲线在某一点处的切线，是唯一在该点与曲线“刚好接触”的直线。
2.  **导数的概念**：函数在某一点的导数 `f'(a)`，就是该点处切线的斜率，它代表了函数在该点的**瞬时变化率**。
3.  **从割线到切线**：通过取曲线上两个点计算割线斜率，然后让两点无限靠近（`h -> 0`），其极限即为切线斜率。
4.  **核心计算公式**：导数定义为 `f'(a) = lim (h -> 0) [ (f(a+h) - f(a)) / h ]`。

![](img/42b8b1c4165b5581834f4bd95c1b3a5c_161.png)
