# 课程23：指数代数简化规则 📚

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_0.png)

在本节课中，我们将要学习指数运算的五个核心简化规则。掌握这些规则，你将能够理解和解决几乎所有基于整数指数的代数问题。我们会先简要介绍所有五个规则，然后通过一系列例子来演示如何应用这些规则简化指数表达式。

## 概述

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_2.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_4.png)

为了保持记号的清晰和进行代数运算，指数运算有五条简化规则。如果你能记住并练习这五条规则，你将能够理解和解决几乎所有基于整数指数的代数问题。

## 规则一：乘法规则 ✖️

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_18.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_20.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_22.png)

当对**相同底数**、**不同指数**的因子进行**乘积**运算时，我们**将指数相加**。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_24.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_26.png)

其公式如下：
```
x^n * x^m = x^(n+m)
```

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_28.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_30.png)

## 规则二：幂的幂规则 🔼

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_38.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_40.png)

当一个**已经包含指数的数**再被**提升到一个指数**时，我们取这两个指数的**乘积**作为新的幂。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_42.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_43.png)

其公式如下：
```
(x^n)^m = x^(n*m)
```

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_45.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_47.png)

## 规则三：积的幂规则 📦

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_51.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_52.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_54.png)

当我们有两个**不同的因子**，并且它们被提升到**同一个指数**时，我们将指数**分配**给乘积中的每一个元素。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_56.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_58.png)

其公式如下：
```
(x * y)^n = x^n * y^n
```

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_59.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_61.png)

为了更清晰地说明，让我们看一个例子：`(2 * 3)^3`。这等于 `(2*3) * (2*3) * (2*3)`。然后我们分别收集2和3，得到 `2^3 * 3^3`。

## 规则四：分数的幂规则 ➗

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_63.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_65.png)

这种情况是，我们有一个**分子**和一个**分母**，并将**整个分数**提升到一个指数。同样，我们将指数**分配**给分子和分母。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_67.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_69.png)

其公式如下：
```
(x / y)^n = x^n / y^n
```

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_71.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_73.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_75.png)

当将两个整数的比值提升到一个幂时，将指数分配给每个数。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_77.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_79.png)

## 规则五：除法与负指数规则 ➖

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_81.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_82.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_84.png)

这条规则运作如下：如果我们有 `x^n / x^m`，这等同于 `x^(n-m)`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_86.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_87.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_89.png)

你可能会注意到，这实际上结合了我们已有的规则。因为我们真正在做的是：`x^n * x^(-m)`，这等同于 `x^(n-m)`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_91.png)

## 应用示例

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_97.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_99.png)

上一节我们介绍了五条核心规则，本节中我们来看看如何应用这些规则解决具体问题。以下是几个简化指数表达式的例子，每个例子都说明了应使用哪条规则。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_101.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_103.png)

**示例 1：** `7^3 * 7^7`
*   **应用规则：** 乘法规则。
*   **解答：** 因为我们有共同的底数7，所以结果是 `7^(3+7)`，即 `7^10`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_105.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_107.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_108.png)

**示例 2：** `(4^3)^5`
*   **应用规则：** 幂的幂规则。
*   **解答：** 我们得到 `4^(3*5)`，即 `4^15`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_110.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_112.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_114.png)

**示例 3：** `(8 * 9)^7`
*   **应用规则：** 积的幂规则。
*   **解答：** 我们分配指数，得到 `8^7 * 9^7`。这是科学计数法可能有用的情况，因为结果是一个很大的数。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_116.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_118.png)

**示例 4：** `(2/7)^3`
*   **应用规则：** 分数的幂规则。
*   **解答：** 我们得到 `2^3 / 7^3`，即 `8/343`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_120.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_121.png)

**示例 5：** `10^5 / 10^3`
*   **应用规则：** 除法与负指数规则。
*   **解答：** 这等于 `10^5 * 10^(-3)`，即 `10^(5-3)`，也就是 `10^2`，等于 `100`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_123.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_124.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_138.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_140.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_142.png)

**示例 6：** `(x^3 * y^4 * z^5) / (x^3 * y^5 * z^2)`
处理这类问题的方法是**分离每个因子**。
*   我们有 `x^3 / x^3`。
*   我们有 `y^4 / y^5`。
*   我们有 `z^5 / z^2`。
*   **应用规则：** 使用除法与负指数规则。
*   **解答：** 这等于 `x^(3-3) * y^(4-5) * z^(5-2)`，即 `x^0 * y^(-1) * z^3`。由于 `x^0 = 1`，所以结果是 `y^(-1) * z^3`，或者写成 `z^3 / y`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_144.png)

**示例 7：** `[(x^2 * y^2) / (x^(-3) * y^2)]^(-1)`
我们首先分离每个因子，最后处理 `-1` 次方。
*   应用积的幂规则，分子是 `x^2 * y^2`，分母是 `x^(-3) * y^2`。
*   **解答：** 这等于 `[x^(2 - (-3)) * y^(2-2)]^(-1)`，即 `[x^5 * y^0]^(-1)`。由于 `y^0 = 1`，所以是 `(x^5)^(-1)`，最终等于 `x^(-5)` 或 `1 / x^5`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_146.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_148.png)

## 分数指数 📊

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_158.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_160.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_162.png)

我们想简要地再谈一个主题：如何处理指数本身是分数的情况。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_164.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_166.png)

答案是，你将其视为两个独立的操作：**上方的数字是标准指数，下方的数字是根号**。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_168.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_170.png)

在给出的例子中，我们有 `8^(2/3)`。这意味着：
1.  `8` 的平方，再开立方根；或者
2.  `8` 的立方根，再平方。
**顺序无关紧要。**

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_172.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_174.png)

让我们看看结果是什么：
*   `8` 的立方根是 `2`，因为 `2 * 2 * 2 = 2^3 = 8`。
*   然后将其平方：`2^2 = 4`。
同样，也可以先计算 `8^2 = 64`，再取立方根，`64` 的立方根也是 `4`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_176.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_178.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_180.png)

**另一个例子：** `125^(4/3)`
*   取 `125` 的立方根，等于 `5`。
*   将其提升到四次方：`5 * 5 * 5 * 5 = 625`。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_182.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_184.png)

因此，只要将有理数（分数）指数的每一部分视为独立操作，你就能轻松解决这类问题。

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_186.png)

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_188.png)

## 总结

![](img/cbb805f7d03c2a843ff2ef9c24231bfd_195.png)

本节课中我们一起学习了指数运算的五条核心简化规则：
1.  **乘法规则**：同底数相乘，指数相加。
2.  **幂的幂规则**：幂次再乘方，指数相乘。
3.  **积的幂规则**：乘积的幂等于各因子幂的乘积。
4.  **分数的幂规则**：分数的幂等于分子分母分别取幂。
5.  **除法与负指数规则**：同底数相除，指数相减。

我们还了解了如何处理分数指数，即将其分解为“取根”和“乘方”两个步骤。我建议你稍加练习，这些规则就会变得自然而然，通过解决问题和练习，它们将不再显得困难。
