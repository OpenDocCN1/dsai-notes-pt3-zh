上一节我们介绍了函数的基本概念，本节中我们来看看函数的单调性，即函数值随输入值变化的趋势。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_12.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_13.png)

我们主要关注从实数集到实数集的函数。今天的核心是理解**增函数**和**减函数**。需要明确的是，大多数函数并不属于这两类，但识别哪些函数属于哪一类非常重要。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_15.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_17.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_18.png)

观察左侧的三个函数图像：
*   **F(x)** 用红色表示。
*   **G(x)** 用蓝色表示。
*   **H(x)** 用黄色表示。

你会注意到，随着沿X轴向右移动，F(x)的图像始终在上升。G(x)的图像则始终在下降。而H(x)的图像先下降，后上升。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_20.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_21.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_22.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_23.png)

因此，我们说：
*   **F** 是一个**严格递增函数**。
*   **G** 是一个**严格递减函数**。
*   **H** 两者都不是。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_25.png)

数学家们不满足于直观的定义，他们喜欢用符号来精确描述。让我们看看这些符号定义如何对应我们已有的直观理解。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_31.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_32.png)

设 **F** 是一个从实数集到实数集的函数。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_34.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_36.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_38.png)

我们说 **F** 是**严格递增**的，如果满足以下条件：
对于任意两个输入值 **A** 和 **B**，只要 **A < B**，就必然有 **F(A) < F(B)**。

换句话说，输入值的顺序关系在输出值上得到保持。

以红色函数F为例，取点A和B（A < B）。观察它们在图像上的对应点F(A)和F(B)，可以看到F(A) < F(B)。无论A和B选在何处，这个关系都成立。因此，F是严格递增的。

我们说 **F** 是**严格递减**的，如果满足以下条件：
对于任意两个输入值 **A** 和 **B**，只要 **A < B**，就必然有 **F(A) > F(B)**。

输入值的顺序关系在输出值上发生了翻转。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_40.png)

以蓝色函数G为例，取点A和B（A < B）。观察G(A)和G(B)，可以看到G(A) > G(B)。因此，G是严格递减的。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_42.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_44.png)

另一方面，黄色函数H两者都不是。你可以自己验证：如果在下降部分取A和B（A < B），会发现H(A) > H(B)；如果在上升部分取A和B（A < B），会发现H(A) < H(B）。没有一致的关系。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_46.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_47.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_49.png)

我们已经看了一些图像例子，现在让我们通过公式来定义一些函数，并判断它们的单调性。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_54.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_56.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_58.png)

以下是三个函数：
*   **F(x) = 2^x**
*   **G(x) = 3^{-x}**
*   **H(x) = x^2**

![](img/dd038ffc376d358fe0302c8b60f5c4bb_60.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_61.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_63.png)

让我们判断哪些是严格递增、严格递减，或者两者都不是。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_65.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_67.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_69.png)

首先，绘制 **F(x) = 2^x** 的图像。这是一个指数函数，x在指数位置。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_71.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_72.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_74.png)

以下是部分函数值点：
*   x = 0 时，F(0) = 2^0 = 1 → 点 (0, 1)
*   x = 1 时，F(1) = 2^1 = 2 → 点 (1, 2)
*   x = 2 时，F(2) = 2^2 = 4 → 点 (2, 4)
*   x = -1 时，F(-1) = 2^{-1} = 1/2 → 点 (-1, 0.5)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_76.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_78.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_80.png)

连接这些点，图像从左下向右上快速增长。显然，**F(x) = 2^x 是严格递增的**。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_82.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_84.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_86.png)

其次，绘制 **G(x) = 3^{-x}** 的图像。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_88.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_90.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_92.png)

以下是部分函数值点：
*   x = 0 时，G(0) = 3^0 = 1 → 点 (0, 1)
*   x = 1 时，G(1) = 3^{-1} = 1/3 → 点 (1, 1/3)
*   x = -1 时，G(-1) = 3^{1} = 3 → 点 (-1, 3)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_94.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_96.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_98.png)

图像从左上下滑向右下。因此，**G(x) = 3^{-x} 是严格递减的**。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_100.png)

最后，绘制 **H(x) = x^2** 的图像。这是一个抛物线，经过点 (1,1), (-1,1), (0,0) 等。

图像在x<0时下降，在x>0时上升。因此，**H(x) = x^2 既不是严格递增，也不是严格递减**。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_102.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_103.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_104.png)

这里有一个重要的观察：虽然H在整个定义域上不是单调的，但它在部分区间上是。
*   **H 在区间 [0, +∞) 上是严格递增的**。
*   **H 在区间 (-∞, 0] 上是严格递减的**。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_106.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_108.png)

**例子1：儿童身高随年龄的变化**
*   **X轴**：出生后的年数。
*   **Y轴**：身高。
图像大致形状是：从出生开始快速增长，在青少年时期（约17岁）增速放缓并趋于稳定，成年后可能保持稳定或随年龄增长略有下降。所以，这个函数在很长一段时间内是递增的，然后变得平缓，最后可能略微下降。

图像大致形状是：从购买时的高价值开始，一旦驶离经销商便迅速贬值，随后贬值速度放缓，最终稳定在一个较低的价值附近。这主要是一个**递减函数**。

最后，我们介绍一个判断函数是否严格单调的简单视觉方法：**水平线检验法**。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_132.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_133.png)

观察红色（严格递增）和蓝色（非严格单调）的函数图像。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_135.png)

对于**严格递增（或严格递减）** 的函数，任何一条水平线（绿色）与函数图像**有且仅有一个交点**。这是因为函数值一旦达到某个水平，就永远不会再回到那个值（对于递增函数，它只会变得更大；对于递减函数，只会变得更小）。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_136.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_137.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_138.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_140.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_141.png)

对于**非严格单调**的函数（如蓝色抛物线），你可以找到一些水平线，它们与函数图像**有两个交点**。这意味着函数值在下降后又上升，回到了同一个输出值。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_143.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_145.png)

因此，水平线检验法可总结为：如果一个函数的图像与每一条水平线都恰好相交一次，那么这个函数是严格递增或严格递减的。

![](img/dd038ffc376d358fe0302c8b60f5c4bb_147.png)

![](img/dd038ffc376d358fe0302c8b60f5c4bb_148.png)

本节课中我们一起学习了：
1.  **严格递增函数**的定义：若 A < B，则 F(A) < F(B)。
2.  **严格递减函数**的定义：若 A < B，则 F(A) > F(B)。
3.  通过函数图像和公式（如 2^x, 3^{-x}, x^2）来判断函数的单调性。
4.  理解了函数可以在整个定义域上单调，也可以在特定区间上单调。
5.  探讨了单调性在现实世界（如身高增长、资产折旧）中的应用。
6.  学习了利用**水平线检验法**快速判断函数是否严格单调。
