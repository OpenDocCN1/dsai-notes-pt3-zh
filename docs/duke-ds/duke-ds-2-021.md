## 斜率符号的直观判断

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_34.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_36.png)

在开始计算之前，我们可以先直观判断一下这些点处切线斜率的正负。

*   在点 **A** 处，切线是向上倾斜的，因此斜率 **f'(a)** 应该是一个**正数**。
*   在点 **B** 处，切线比点 A 处更陡峭，因此斜率 **f'(b)** 不仅为正，而且应该**大于 f'(a)**。
*   在点 **C** 处，切线是向下倾斜的，因此斜率 **f'(c)** 应该是一个**负数**。

## 应用公式计算 f'(a)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_49.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_50.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_52.png)

现在，我们严格使用导数定义公式来计算函数 **f(x) = x²** 在任意点 **x = a** 处的导数。

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_54.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_55.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_57.png)

根据公式：
**f'(a) = lim (h→0) [f(a+h) - f(a)] / h**

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_59.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_61.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_63.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_65.png)

由于 **f(x) = x²**，所以：
*   **f(a) = a²**
*   **f(a+h) = (a+h)²**

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_67.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_69.png)

将以上代入公式：

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_70.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_72.png)

**f'(a) = lim (h→0) [(a+h)² - a²] / h**

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_74.png)

接下来是代数运算步骤：

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_75.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_76.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_77.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_78.png)

1.  展开 **(a+h)²**：
    **f'(a) = lim (h→0) [a² + 2ah + h² - a²] / h**
2.  消去 **a²** 和 **-a²**：
    **f'(a) = lim (h→0) [2ah + h²] / h**
3.  分子提取公因子 **h**：
    **f'(a) = lim (h→0) [h(2a + h)] / h**
4.  约去分子和分母的 **h**（注意 h ≠ 0）：
    **f'(a) = lim (h→0) (2a + h)**
5.  最后，求极限。当 **h** 无限趋近于 0 时，**(2a + h)** 就无限趋近于 **2a**。

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_80.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_81.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_83.png)

因此，我们得出结论：
**f'(a) = 2a**

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_85.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_87.png)

## 验证结果与理解导函数

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_95.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_97.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_99.png)

这个结果 **f'(a) = 2a** 非常有趣。让我们验证它是否符合之前的直观判断：

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_101.png)

*   如果 **a > 0**，则 **2a > 0**，这与点 A 和点 B 处斜率为正相符。
*   如果 **a < b**，则 **2a < 2b**，这与点 B 处斜率大于点 A 处斜率相符。
*   如果 **c < 0**，则 **2c < 0**，这与点 C 处斜率为负相符。
*   当 **a = 0** 时，**f'(0) = 0**，这意味着在原点 (0,0) 处的切线是水平的，这与图像完全吻合。

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_103.png)

更重要的是，由于 **a** 可以是任意值，我们实际上得到了一个**新的函数**。这个函数以 **x** 为输入，输出的是原函数 **f(x) = x²** 在 **x** 点处的切线斜率。

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_105.png)

我们称这个新函数为 **导函数**，记作 **f'(x)**。对于 **f(x) = x²**，其导函数为：
**f'(x) = 2x**

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_107.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_109.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_111.png)

### 如何理解导函数的图像

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_125.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_127.png)

以下是理解导函数图像 **y = 2x** 的关键点：

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_129.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_131.png)

*   对于任意 **x** 值，蓝色直线上对应的 **y** 值（即 **2x**），就是绿色曲线在 **x** 点处切线的斜率。
*   当 **x** 为正且增大时，**2x** 也增大，意味着曲线右侧的切线越来越陡。
*   当 **x** 为负且减小时，**2x** 也减小（变得更负），意味着曲线左侧的切线向下倾斜得越来越厉害。
*   在 **x=0** 处，**2x=0**，对应曲线在原点的水平切线。

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_133.png)

## 总结

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_143.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_144.png)

本节课我们一起学习了导函数的核心概念。

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_146.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_147.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_148.png)

1.  我们从一个具体的函数 **f(x) = x²** 出发，运用导数定义公式，一步步计算出了它在任意点 **a** 的导数：**f'(a) = 2a**。
2.  通过将 **a** 推广为变量 **x**，我们得到了**导函数** **f'(x) = 2x**。导函数本身也是一个函数，其功能是：输入 **x**，输出原函数在 **x** 点处的切线斜率。
3.  我们通过图像直观地验证了导函数值的含义，并理解了导函数图像（一条直线）如何反映了原函数图像（一条抛物线）上各点斜率的变化规律：从左侧的负斜率，平滑过渡到原点斜率为0，再到右侧的正斜率。

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_150.png)

![](img/970ecaa1beb2dca8b0b9b6e1e00ba591_152.png)

理解导函数是理解函数如何变化的关键一步。
