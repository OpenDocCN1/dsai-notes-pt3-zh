# 机器学习：第1讲：线性回归入门

在本节课中，我们将要学习机器学习中最基础且重要的模型之一：线性回归。我们将了解其核心思想、数学表示形式以及如何通过数据找到最优的模型参数。

## 概述

线性回归是一种用于建立输入变量（特征）与连续输出变量（目标）之间线性关系的监督学习方法。其目标是找到一条直线（或超平面），使得所有数据点到这条直线的距离之和最小。

上一节我们介绍了机器学习的基本概念，本节中我们来看看线性回归的具体实现。

## 核心概念与模型

线性回归模型试图用特征的线性组合来预测目标值。对于一个有 `d` 个特征的数据点，其预测值 `ŷ` 可以表示为：

**公式：** `ŷ = w₁*x₁ + w₂*x₂ + ... + w_d*x_d + b`

其中：
*   `ŷ` 是预测值。
*   `x₁, x₂, ..., x_d` 是输入特征。
*   `w₁, w₂, ..., w_d` 是模型需要学习的权重（系数）。
*   `b` 是偏置项（截距）。

为了简化，我们通常引入一个值为1的额外特征 `x₀`，并将 `b` 视为 `w₀`。这样，模型可以用向量形式简洁地表示为：

**公式：** `ŷ = wᵀ x`

这里 `w` 和 `x` 都是向量，`wᵀ x` 表示它们的点积。

## 损失函数与优化

为了找到最佳的参数 `w`，我们需要一个标准来衡量模型预测的好坏。这个标准就是损失函数。对于线性回归，最常用的损失函数是均方误差。

均方误差计算的是所有训练样本的预测值 `ŷ⁽ⁱ⁾` 与实际值 `y⁽ⁱ⁾` 之差的平方的平均值。

**公式：** `MSE(w) = (1/n) * Σ (y⁽ⁱ⁾ - ŷ⁽ⁱ⁾)²`，其中 `i` 从1到 `n`（样本数）。

我们的目标转化为一个优化问题：找到一组参数 `w*`，使得均方误差 `MSE(w)` 的值最小。

以下是寻找最小化损失函数的参数 `w` 的两种主要方法。

### 方法一：解析解（正规方程）

当特征数量不多且矩阵可逆时，我们可以直接通过数学公式计算出最优参数。

最优权重 `w*` 可以通过以下正规方程求得：

**公式：** `w* = (Xᵀ X)⁻¹ Xᵀ y`

其中 `X` 是包含所有样本特征的数据矩阵（每行一个样本，每列一个特征，包括 `x₀=1`），`y` 是所有样本真实值构成的向量。

### 方法二：数值解（梯度下降）

当数据量很大或特征维度很高时，计算正规方程的成本会非常高。此时，我们使用梯度下降法这种迭代优化算法。

梯度下降的核心思想是：初始化一组参数 `w`，然后反复沿着损失函数下降最快的方向（负梯度方向）更新 `w`，直到收敛。

参数更新规则如下：

**公式：** `w := w - α * ∇MSE(w)`

其中 `α` 是学习率，控制每次更新的步长；`∇MSE(w)` 是损失函数在当前 `w` 处的梯度。

以下是梯度下降算法的基本步骤：

1.  随机初始化权重向量 `w`。
2.  重复以下步骤直到满足停止条件（如达到最大迭代次数或损失变化很小）：
    *   计算损失函数关于 `w` 的梯度。
    *   按照更新规则 `w := w - α * ∇MSE(w)` 更新权重。
3.  返回最终学习到的权重 `w`。

## 总结

本节课中我们一起学习了线性回归模型。我们首先了解了其用线性组合进行预测的基本形式。接着，我们引入了均方误差作为衡量模型性能的损失函数。最后，我们探讨了两种寻找最优模型参数的方法：可以直接计算的**正规方程**，以及适用于大规模数据的迭代算法**梯度下降**。线性回归是理解更复杂模型的基石，其核心思想贯穿于整个机器学习领域。
