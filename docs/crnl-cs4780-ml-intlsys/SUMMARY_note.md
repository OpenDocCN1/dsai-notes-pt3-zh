## 如何使用本教程 🛠️

本教程结构清晰，建议你按顺序学习。每一讲都对应一个独立的Markdown文件，点击链接即可查看详细内容。在学习过程中，请注意理解每个算法的核心思想、数学公式或代码实现。

## 总结 📝

本节课中，我们一起浏览了康奈尔大学CS4780《智能系统的机器学习》课程的全部章节目录。从监督学习的基本设定开始，到k近邻、感知机、概率估计、逻辑回归、支持向量机、集成学习、神经网络，乃至Transformer等现代模型，本课程提供了一个全面而深入的机器学习知识体系。希望这份教程能帮助你系统地开启机器学习的学习之旅。
