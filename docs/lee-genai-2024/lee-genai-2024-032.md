## 概述：生成式AI的本质

![](img/b6e3160cba870c99e1c71d4cb751e370_7.png)

生成式人工智能的目标是让机器产生复杂而有结构的对象，例如文字、图像或声音信号。这些对象之所以“复杂”，是因为其可能的组合方式几乎是无穷无尽的，无法被一一列举。

### 文字的基本单位：Token

![](img/b6e3160cba870c99e1c71d4cb751e370_45.png)

文字是由 **Token** 构成的。Token 是语言模型开发者在训练前事先定义好的符号单位。例如，GPT-3.5/GPT-4 内部会将句子拆解成一串 Token。每个模型的 Token 集合称为 **Vocabulary**（词典）。

以 Llama 2 模型为例，其 Vocabulary 包含 **32,000** 个不同的 Token。语言模型每次“文字接龙”时，就是从这 32,000 个 Token 中选择一个输出。

![](img/b6e3160cba870c99e1c71d4cb751e370_47.png)

![](img/b6e3160cba870c99e1c71d4cb751e370_49.png)

```python
# 概念示例：语言模型从词汇表中选择一个Token
vocabulary = [“你”, “好”, “世”, “界”, ...] # 共32000个token
next_token = model.predict(vocabulary)
```

![](img/b6e3160cba870c99e1c71d4cb751e370_51.png)

### 图像的基本单位：像素

![](img/b6e3160cba870c99e1c71d4cb751e370_53.png)

图像是由 **像素** 构成的。每个像素（Pixel）具有一个颜色值。颜色的数量取决于 **每像素位数**。

*   **8 BPP**: 256 种颜色。
*   **16 BPP**: 65,536 种颜色。
*   **24 BPP**: 约 1670 万种颜色（常称为“全彩色”或“真彩色”）。

![](img/b6e3160cba870c99e1c71d4cb751e370_55.png)

因此，一张图片就是由大量带有颜色的像素排列组合而成的。

### 声音的基本单位：采样点

![](img/b6e3160cba870c99e1c71d4cb751e370_57.png)

![](img/b6e3160cba870c99e1c71d4cb751e370_59.png)

声音是由一系列 **采样点** 构成的。每秒钟包含的采样点数量称为 **采样率**。

*   **16K 采样率**: 每秒 16,000 个点。
*   **44K 采样率**: 每秒约 44,100 个点（CD音质）。

![](img/b6e3160cba870c99e1c71d4cb751e370_61.png)

每个采样点可以取的数值范围由 **采样解析度** 决定。解析度越高，每个点的数值可能性就越多。

## 生成式AI的统一任务

![](img/b6e3160cba870c99e1c71d4cb751e370_65.png)

了解了基本构成单位后，我们可以总结生成式AI的本质任务。

![](img/b6e3160cba870c99e1c71d4cb751e370_67.png)

生成式人工智能本质上要做的事情是：给定一个 **条件**，然后将基本单位按照正确的顺序组合起来。

![](img/b6e3160cba870c99e1c71d4cb751e370_69.png)

*   **对话AI**：读一个句子（条件），输出一串 Token（回答）。
*   **绘图AI**：读一段描述（条件），输出一堆像素组合成图片。
*   **语音AI**：读一段文本或主题（条件），输出一系列采样点组合成声音。

![](img/b6e3160cba870c99e1c71d4cb751e370_71.png)

因此，尽管应用不同，但生成式AI要解决的核心问题是相同的：**给定条件，如何生成并组合基本单位**。

![](img/b6e3160cba870c99e1c71d4cb751e370_73.png)

## 自回归生成：文字接龙的策略

我们已经知道对话AI是如何工作的了，它采用的是“文字接龙”的方式。这种方式有一个专有名词，叫做 **自回归生成**。

以下是自回归生成的工作原理：
1.  模型接收输入。
2.  模型产生第一个 Token。
3.  将已产生的 Token 作为新输入的一部分，再产生下一个 Token。
4.  重复此过程，直到生成完整的序列。

```python
# 概念示例：自回归生成过程
input_text = “今天的天气”
output_tokens = []
while not finished:
    next_token = model.predict(input_text + “”.join(output_tokens))
    output_tokens.append(next_token)
```

![](img/b6e3160cba870c99e1c71d4cb751e370_77.png)

这种策略在文字生成上取得了巨大成功。那么，它能否应用于图像和声音呢？

![](img/b6e3160cba870c99e1c71d4cb751e370_79.png)

## 自回归生成在图像与声音上的尝试与挑战

![](img/b6e3160cba870c99e1c71d4cb751e370_81.png)

本节我们来看看，将“文字接龙”的思路套用到图像和声音上是否可行。

理论上，图像可以用“像素接龙”的方式生成，声音也可以用“采样点接龙”的方式生成。历史上也有过这样的模型，例如 OpenAI 的“图像版GPT”和 Google 的 WaveNet 语音模型。

![](img/b6e3160cba870c99e1c71d4cb751e370_83.png)

然而，在实际应用中，图像和声音生成几乎不采用这种接龙方式。原因在于自回归生成有一个本质上的限制：**它必须按部就班、循序生成**。

这个限制会带来什么问题呢？我们来算一笔账：

![](img/b6e3160cba870c99e1c71d4cb751e370_85.png)

![](img/b6e3160cba870c99e1c71d4cb751e370_87.png)

*   **生成一张 1024x1024 的图片**：约有100万个像素。这意味着需要进行 **100万次** “像素接龙”。这相当于让模型写一部《红楼梦》那么长的内容，生成速度会极其缓慢。
*   **生成一分钟 22K 采样率的语音**：约有132万个采样点。这意味着需要进行 **132万次** “采样点接龙”。早期 WaveNet 生成一句话可能需要一个小时，完全无法实用。

因此，自回归生成虽然质量高，但**速度太慢**，不适合直接用于生成高分辨率图像或长段音频。

![](img/b6e3160cba870c99e1c71d4cb751e370_89.png)

---

## 非自回归生成：齐头并进的策略

既然自回归生成的主要问题是速度慢，我们能否换一个思路？能否不要按部就班，而是一次性同时生成所有基本单位呢？

![](img/b6e3160cba870c99e1c71d4cb751e370_91.png)

这就是 **非自回归生成** 的策略。模型在生成时，所有位置（如所有像素、所有采样点）的输出是**同时被计算出来**的。

![](img/b6e3160cba870c99e1c71d4cb751e370_93.png)

**优势**：在拥有强大并行计算能力的硬件上，非自回归生成可以**大幅加快生成速度**。虽然总计算量可能相似，但所需的实际时间会短得多。

**为什么图像生成主要用非自回归？** 正是因为速度优势。对于包含百万像素的图片，同时生成比逐个生成要快得多。

## 非自回归生成的挑战与解决方案

![](img/b6e3160cba870c99e1c71d4cb751e370_95.png)

上一节我们看到了非自回归生成的速度优势，但天下没有免费的午餐，它也有其本质问题。

![](img/b6e3160cba870c99e1c71d4cb751e370_97.png)

非自回归生成的核心问题是：**生成质量可能不佳**，容易产生模糊或矛盾的输出。这是因为生成任务需要模型进行“脑补”，而同样的条件可能对应多种合理的输出。

![](img/b6e3160cba870c99e1c71d4cb751e370_99.png)

**问题示例**：让模型画一只“奔跑的狗”。在同时生成不同位置的像素时，模型可能在某些位置“想”画一只向左的白狗，在另一些位置“想”画一只向右的黑狗。最终所有像素组合起来，就可能得到一张模糊或四不像的图片。这个问题被称为 **多模态性** 问题。

![](img/b6e3160cba870c99e1c71d4cb751e370_101.png)

这也是为什么文字生成不主要采用非自回归策略——它无法保证生成序列内部的一致性。

![](img/b6e3160cba870c99e1c71d4cb751e370_103.png)

那么，图像和声音生成是如何解决这个质量问题的呢？主要有以下几种思路：

![](img/b6e3160cba870c99e1c71d4cb751e370_105.png)

### 解决方案一：引入“潜变量”统一脑补内容

思路是：在生成前，先额外给定一个**随机生成的向量**（称为潜变量或噪声）。这个向量相当于提前“定好”了脑补的具体内容（如狗的朝向、品种、背景）。模型在生成每个像素时，不仅看文字条件，也看这个向量，从而确保整个生成过程朝着一致的方向进行。

你会发现，VAE、GAN、扩散模型等主流图像生成模型，都采用了这种“先生成一个随机向量，再输入给模型”的设计。

### 解决方案二：自回归与非自回归结合（两阶段生成）

![](img/b6e3160cba870c99e1c71d4cb751e370_107.png)

思路是：结合两者的优点，规避各自的缺点。
1.  **第一阶段（自回归）**：用自回归模型根据条件生成一个**精简的版本**（如草图、低分辨率图、压缩表示）。由于内容精简，生成速度快，且能保证整体结构的一致性。
2.  **第二阶段（非自回归）**：用非自回归模型根据精简版本，快速生成**精细的最终版本**。因为大框架已定，需要“脑补”的细节有限，从而避免了不一致问题。

![](img/b6e3160cba870c99e1c71d4cb751e370_109.png)

其中，第一阶段生成的“精简版本”可以是通过 **自编码器** 学习到的压缩表示。自编码器能训练一个编码器将图像压缩成人看不懂但信息密集的向量，并训练一个解码器将其还原。生成模型只需学习生成这种压缩向量，再由固定的解码器快速还原成高清图。

### 解决方案三：多步非自回归生成（迭代优化）

![](img/b6e3160cba870c99e1c71d4cb751e370_111.png)

![](img/b6e3160cba870c99e1c71d4cb751e370_113.png)

思路是：将生成过程拆解成多个步骤，每一步都是一个非自回归生成，但只生成比前一步“更好一点”的版本。
*   **版本差异可以是分辨率**：先生成 4x4 小图，再生成 8x8，最后生成 1024x1024。
*   **版本差异可以是噪声程度**：先生成全是噪声的图，下一步噪声少一点，最后生成干净图片。这就是 **扩散模型** 的核心思想。
*   **版本差异可以是局部修正**：先生成一版，自动检测并抹掉生成不好的区域，然后在抹掉的区域重新生成下一版。

这种方法可以看作是一种“宏观”的自回归（版本间按序生成），但每个版本内部是并行的非自回归生成，从而在速度和质量间取得平衡。

![](img/b6e3160cba870c99e1c71d4cb751e370_115.png)

![](img/b6e3160cba870c99e1c71d4cb751e370_117.png)

## 总结

![](img/b6e3160cba870c99e1c71d4cb751e370_119.png)

本节课中我们一起学习了生成式人工智能的两种核心生成策略：

*   **自回归生成**：特点是**按部就班**。优点是生成**质量高**、一致性；缺点是**速度慢**。这是文字生成的主流策略。
*   **非自回归生成**：特点是**齐头并进**。优点是生成**速度快**；缺点是存在**多模态性**问题，可能导致质量不佳。这是图像、语音生成为追求速度而采用的策略。

![](img/b6e3160cba870c99e1c71d4cb751e370_121.png)

由于两者各有所长，现代先进的生成模型（如 Stable Diffusion、Midjourney）通常会**将两者结合**，例如：
1.  在抽象的“潜空间”内进行多步自回归或非自回归生成，确定整体构思。
2.  通过训练好的非自回归解码器，一次性将构思快速解码为最终的高质量图像。

![](img/b6e3160cba870c99e1c71d4cb751e370_123.png)

通过这种结合，模型既能保持生成内容的结构一致性，又能实现高效的生成速度。
