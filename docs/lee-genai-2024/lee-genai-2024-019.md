# 19：第9讲：以大型语言模型打造的AI Agent 🧠🤖

![](img/dcf5b8ec28f83fad1f30017270bf332c_1.png)

在本节课中，我们将要学习如何利用大型语言模型来构建能够自主执行多步骤复杂任务的AI Agent。我们将探讨AI Agent的核心概念、运作原理以及未来的应用前景。

---

目前，多数人使用AI时，往往只要求其完成单一任务。例如，让GPT进行翻译，或让ChatGPT调用DALL·E生成一张图片。

![](img/dcf5b8ec28f83fad1f30017270bf332c_1.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_3.png)

然而，人类可以完成更复杂的任务，这些任务通常需要多个步骤才能完成。例如，组织一次朋友聚餐，可能需要先调查大家的时间，统计出最合适的时间，然后预订餐厅。如果首选餐厅没有位置，则需要寻找其他备选餐厅。

完成“举办朋友聚餐”这个任务需要多个步骤，并且步骤的先后顺序很重要。计划也可能需要根据实际情况进行调整。这种需要多步骤、能制定并调整计划的复杂任务，正是我们希望AI能够做到的。在这门课中，我们将这种能够执行此类任务的AI称为 **AI Agent**。

![](img/dcf5b8ec28f83fad1f30017270bf332c_3.png)

了解了AI Agent的应用场景后，我们来看看其背后的运作原理。

一个AI Agent的运作可以概括为以下核心循环：

1.  **输入**：Agent接收来自环境的**状态**（State），拥有**记忆**（Memory）和**终极目标**（Goal）。
2.  **规划**：基于以上三者，Agent制定一个**计划**（Plan），即短期的行动步骤。
3.  **行动**：Agent执行计划中的**行动**（Action），这可以是输出文字、生成图像或操控机械臂等。
4.  **反馈与更新**：行动会改变环境状态。Agent根据新的状态**更新记忆**，并可能**调整计划**。

这个循环可以表示为以下流程：
```
[状态] + [记忆] + [目标] -> [计划] -> [行动] -> (改变环境) -> [新状态] -> (更新记忆/计划) -> ...
```

![](img/dcf5b8ec28f83fad1f30017270bf332c_29.png)

今天的语言模型在制定和修改计划、利用记忆方面已具备一定能力，因此AI Agent的实现离我们并不遥远。

![](img/dcf5b8ec28f83fad1f30017270bf332c_31.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_29.png)

记忆是AI Agent的关键能力之一。当前的ChatGPT在单次对话外没有长期记忆。但OpenAI曾测试过具有记忆功能的版本，其思路可能是对历史对话进行摘要，并在新对话中检索相关关键信息，以实现一定程度的个性化。此外，也有如 **Memory GPT** 等研究致力于为语言模型添加记忆能力。

![](img/dcf5b8ec28f83fad1f30017270bf332c_31.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_33.png)

为了更具体地理解AI Agent，我们通过一个虚构例子来说明。

![](img/dcf5b8ec28f83fad1f30017270bf332c_35.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_37.png)

假设在动画《葬送的芙莉莲》中，用于在迷宫中救援考生的“逃脱用格雷姆”是一个AI Agent。

![](img/dcf5b8ec28f83fad1f30017270bf332c_39.png)

*   **目标**：自主行动，安全将考生带出迷宫。
*   **初始记忆**：空白。
*   **初始状态**：（通过图像描述技术获得）“眼前是遭遇复制体攻击而受重伤的考生艾黛尔”。

![](img/dcf5b8ec28f83fad1f30017270bf332c_41.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_43.png)

将以上信息输入给如GPT-4这样的大型语言模型，并指令“请产生行动计划”，模型可以生成合理的计划，例如：
1.  立即评估艾黛尔的伤势。
2.  提供急救。

![](img/dcf5b8ec28f83fad1f30017270bf332c_45.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_47.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_49.png)

接着，我们可以要求模型执行计划中的下一步行动（例如“评估伤势”）。最大的挑战在于如何将文字指令转化为在物理或虚拟世界中的具体动作。相关研究（如使用“慢思考”Agent规划、“快思考”Agent执行的框架）正在探索解决方案。

![](img/dcf5b8ec28f83fad1f30017270bf332c_47.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_51.png)

当环境变化时（例如“在评估伤势时遭遇复制体袭击”），AI Agent需要能调整计划。我们可以要求模型“根据新状态产生新的行动计划”。模型能够生成新的计划，例如将“优先保护艾黛尔”置于更重要的位置。

![](img/dcf5b8ec28f83fad1f30017270bf332c_53.png)

![](img/dcf5b8ec28f83fad1f30017270bf332c_57.png)

此外，AI Agent还能通过反思积累经验。我们可以要求模型“简短总结值得记下来的经验”。模型可能总结出“要对环境保持高度警觉”等经验。这些经验会被存入记忆。

---

本节课中我们一起学习了AI Agent的概念。我们了解到，AI Agent是能够为完成复杂目标而自主进行多步骤规划、执行、并能根据环境反馈调整计划和积累经验的智能体。尽管将语言模型的文字指令转化为具体行动仍是当前的主要挑战，但凭借现有大型语言模型的能力，具备这些功能的AI Agent很可能在不久的将来广泛出现在我们的生活之中。
