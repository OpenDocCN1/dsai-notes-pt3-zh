# 23：（延申）Transformer (上) 🧠

![](img/905f101c9ab35501dd62f6860b204dcf_1.png)

在本节课中，我们将要学习Transformer模型的上半部分，特别是其核心组件——Encoder的架构和工作原理。Transformer是当今生成式人工智能领域的基石模型，理解其设计对于后续学习至关重要。

## 概述：什么是Transformer？🤖

Transformer是一个**序列到序列模型**。序列到序列模型的缩写是Seq2Seq。

![](img/905f101c9ab35501dd62f6860b204dcf_3.png)

序列到序列模型是什么呢？我们之前在处理输入序列的案例时，输入是一个序列，输出则有几种可能。一种情况是输入和输出的长度相同，这是在作业二中做的。另一种情况是输出一个单独的东西，这是在作业四中做的。接下来作业五的案例是，我们不知道应该输出多长，由机器自己决定输出的长度。

## 序列到序列模型的应用场景 🌐

![](img/905f101c9ab35501dd62f6860b204dcf_5.png)

![](img/905f101c9ab35501dd62f6860b204dcf_7.png)

以下是序列到序列模型的一些典型应用场景。

![](img/905f101c9ab35501dd62f6860b204dcf_9.png)

### 语音识别 🎤

![](img/905f101c9ab35501dd62f6860b204dcf_11.png)

一个很好的应用就是语音识别。在做语音识别时，输入是声音信号，输出是语音识别的结果，即对应的文字。输入声音信号的长度是T，我们无法根据T确定输出文字的长度N。因此，输出的句子应包含几个字，由机器自己来决定。

### 机器翻译 🌍

![](img/905f101c9ab35501dd62f6860b204dcf_13.png)

另一个例子是机器翻译。让机器读一个语言的句子，输出另外一个语言的句子。输入句子的长度是N，输出句子的长度是N‘，N和N’之间的关系也要由机器自己来决定。

![](img/905f101c9ab35501dd62f6860b204dcf_15.png)

### 语音翻译 🔊

更复杂的问题是语音翻译。语音翻译是指对机器说一句话，它直接将听到的声音信号翻译成另一种语言的文字。例如，对它说“machine learning”，它输出“机器学习”。这对于许多没有文字的语言来说，是获取信息的重要途径。

### 聊天机器人 💬

![](img/905f101c9ab35501dd62f6860b204dcf_17.png)

在文字处理上，序列到序列模型也有广泛应用。例如，可以用它来训练一个聊天机器人。输入和输出都是文字序列。训练聊天机器人需要收集大量的人与人对话数据。

### 视为问答任务 ❓

![](img/905f101c9ab35501dd62f6860b204dcf_19.png)

事实上，很多自然语言处理任务都可以看作是问答任务。例如：
*   **翻译**：文章是英文句子，问题是“它的德文翻译是什么？”，答案是德文句子。
*   **摘要**：文章是一篇长文，问题是“这段文字的摘要是什么？”，答案是摘要。
*   **情感分析**：文章是一段评论，问题是“这个句子是正面还是负面的？”，答案是“正面”或“负面”。

这些问题都可以用序列到序列模型来解决：输入是“文章+问题”拼接成的长序列，输出就是答案序列。

![](img/905f101c9ab35501dd62f6860b204dcf_21.png)

### 其他硬解任务 🛠️

许多看似不相关的问题也可以用序列到序列模型“硬解”：
*   **文法剖析**：输入一个句子，输出一个代表语法树的序列。
*   **多标签分类**：输入一篇文章，输出属于的类别标签序列，由机器决定输出几个标签。
*   **目标检测**：输入一张图片，输出描述图中物体位置和类别的序列。

![](img/905f101c9ab35501dd62f6860b204dcf_23.png)

## Transformer的Encoder架构 ⚙️

上一节我们介绍了序列到序列模型的广泛应用，本节中我们来看看实现这一功能的核心架构——Transformer的Encoder。

一般的序列到序列模型会分成两块：**编码器**和**解码器**。输入序列由编码器处理，再把处理好的结果丢给解码器，由解码器决定输出什么样的序列。

![](img/905f101c9ab35501dd62f6860b204dcf_25.png)

Transformer的编码器接收一排向量，并输出另一排相同长度的向量。在Transformer中，编码器由多个相同的“块”堆叠而成。

### Encoder Block的详细结构

![](img/905f101c9ab35501dd62f6860b204dcf_27.png)

每个Encoder Block并不是神经网络的一层，它内部包含了好几个层级的操作。以下是其核心步骤：

![](img/905f101c9ab35501dd62f6860b204dcf_29.png)

1.  **自注意力层**：输入一排向量，通过自注意力机制，让每个向量都能考虑到整个序列的信息，输出新的一排向量。
    *   **公式**：`Output = SelfAttention(Input)`

2.  **残差连接与层归一化**：将自注意力层的输出与其输入相加，然后进行层归一化。
    *   **操作**：`X = LayerNorm( SelfAttention(Input) + Input )`

![](img/905f101c9ab35501dd62f6860b204dcf_31.png)

3.  **前馈神经网络**：将上一步的结果输入一个全连接的前馈神经网络。
    *   **操作**：`Y = FeedForward(X)`

4.  **再次残差连接与层归一化**：将前馈神经网络的输出与其输入X相加，再进行一次层归一化。这个结果就是整个Block的输出。
    *   **操作**：`Output = LayerNorm( FeedForward(X) + X )`

此外，在最开始的输入向量中，还需要加入**位置编码**，为模型提供序列中元素的顺序信息。

### 关于架构设计的讨论

![](img/905f101c9ab35501dd62f6860b204dcf_33.png)

你可能会问，为什么Transformer的Encoder要这样设计？是否可以不这样设计？答案是：不一定。原始论文的设计并非最优。

例如：
*   层归一化的位置可以调整，有研究表明将其放在每个Block的输入处可能效果更好。
*   为什么使用层归一化而不是批归一化？也有研究提出了可能更优的归一化方法。

![](img/905f101c9ab35501dd62f6860b204dcf_35.png)

这启发我们，对于模型架构，永远可以思考是否存在更好的设计方式。
