## 核心概念介绍 🧠

上一节我们概述了作业目标，本节中我们来了解一下背后的核心概念。

![](img/18d8a501dad48b1418d9f9f92a4eac44_7.png)

### 文本到图像模型

![](img/18d8a501dad48b1418d9f9f92a4eac44_9.png)

文本到图像模型是一种能够根据给定的文本描述生成对应图像的模型。例如，输入“一个留着胡子、穿着白色T恤的男人”，模型就能生成符合描述的图像。本次作业使用的模型是 **Stable Diffusion**。

![](img/18d8a501dad48b1418d9f9f92a4eac44_11.png)

### LoRA 微调原理

![](img/18d8a501dad48b1418d9f9f92a4eac44_13.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_15.png)

微调大型模型通常耗时耗力。LoRA的原理是在原始大模型中插入少量可训练的新层，通过只训练这些新增的小参数来改变模型行为，而不需要调整整个庞大的模型。这大大降低了计算成本和时间。

![](img/18d8a501dad48b1418d9f9f92a4eac44_17.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_18.png)

**核心思想**：冻结预训练模型的权重，只训练低秩分解的矩阵。

![](img/18d8a501dad48b1418d9f9f92a4eac44_19.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_21.png)

## 作业流程与评分 🛠️

了解了核心概念后，我们来看看本次作业的具体步骤和评分方式。

### 作业三步流程

![](img/18d8a501dad48b1418d9f9f92a4eac44_29.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_31.png)

整个作业流程可以简化为三个步骤：

![](img/18d8a501dad48b1418d9f9f92a4eac44_33.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_35.png)

1.  **训练模型**：使用提供的训练集对Stable Diffusion模型进行LoRA微调。
2.  **生成图像**：使用微调后的模型，根据给定的25个提示词生成图像。
3.  **自动评分**：代码会自动评估生成图像的质量并给出分数。

![](img/18d8a501dad48b1418d9f9f92a4eac44_37.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_39.png)

### 评分标准

![](img/18d8a501dad48b1418d9f9f92a4eac44_41.png)

评分将从以下三个维度进行：

1.  **人脸相似度**：使用 **Ghost FaceNet** 模型计算生成图像与训练集中人脸的平均距离。距离越小，分数越高。
    *   **公式示意**：`平均距离 = mean( distance(生成人脸_i, 训练集人脸_j) )`， 对所有 `i`, `j` 组合计算。
2.  **文本相关性**：使用 **CLIP Score** 评估生成图像与对应提示词的匹配程度。此分数需大于阈值（22分）才算有效提交，主要用于防止提交与提示词无关的现成图片。
3.  **有效人脸检测**：生成的图像必须包含清晰的人脸。允许最多5张图像不包含人脸，超过此数量则本次提交计为零分。

### 环境准备与数据下载

![](img/18d8a501dad48b1418d9f9f92a4eac44_59.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_61.png)

首先，需要连接Google Drive并下载所需数据包。

![](img/18d8a501dad48b1418d9f9f92a4eac44_63.png)

以下是初始化步骤：
1.  运行代码连接到你的Google Drive。
2.  指定一个文件夹名称（例如“brad”），用于存放作业相关文件。
3.  在Drive中会创建两个文件夹：以你命名命名的文件夹（如`brad`）和一个`dataset`文件夹。
    *   `dataset` 内含：100张训练图像、对应的文本描述、以及用于最终评分的25个提示词文件。
    *   你的文件夹（如`brad`）内已预下载了训练约1000步的模型检查点，方便你从该点继续训练。

![](img/18d8a501dad48b1418d9f9f92a4eac44_65.png)

### 参数设置

![](img/18d8a501dad48b1418d9f9f92a4eac44_67.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_69.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_71.png)

本次作业需要调整两个主要超参数：
*   **学习率**：影响模型学习速度。调得过大，生成的人脸会更像目标人物，但可能丢失模型原有的文本理解能力（例如，提示“白T恤”却生成黑西装）。
*   **训练步数**：决定训练时长。步数越多，训练时间越长。

![](img/18d8a501dad48b1418d9f9f92a4eac44_73.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_75.png)

参数设置代码如下（示例）：
```python
# 超参数设置示例
learning_rate = 1e-4
num_train_epochs = 1
train_batch_size = 4
gradient_accumulation_steps = 4
```

![](img/18d8a501dad48b1418d9f9f92a4eac44_77.png)

### 模型训练

![](img/18d8a501dad48b1418d9f9f92a4eac44_79.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_81.png)

如果你只想获得基础分数（8分），可以跳过训练步骤，直接使用预训练的1000步模型进行推理。

![](img/18d8a501dad48b1418d9f9f92a4eac44_83.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_85.png)

若想获得更高分数，则需要继续训练。代码预设了训练200步（约30分钟）。训练过程中，每间隔一定步数（由 `save_steps` 参数控制）会进行一次验证，生成样本图片并保存检查点，方便你观察训练进展。

![](img/18d8a501dad48b1418d9f9f92a4eac44_87.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_89.png)

训练结束后，系统会根据验证分数自动保存一个最佳检查点（`checkpoint-best`）和最后一个检查点（`checkpoint-last`）。

![](img/18d8a501dad48b1418d9f9f92a4eac44_91.png)

### 生成图像与提交

![](img/18d8a501dad48b1418d9f9f92a4eac44_93.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_95.png)

![](img/18d8a501dad48b1418d9f9f92a4eac44_97.png)

训练完成后，运行推理代码生成最终提交的25张图像。

![](img/18d8a501dad48b1418d9f9f92a4eac44_98.png)

以下是关键步骤：
1.  在推理代码部分，选择使用 `checkpoint-last` 还是 `checkpoint-best` 模型进行生成。
2.  运行代码，大约需要15分钟。生成的25张图像将保存在你的Google Drive文件夹下的 `inference` 子文件夹中。
3.  **重要**：推理完成后会显示一个分数，这是基于全部25张生成图像计算出的最终分数，请以此为准。
4.  最后，将这25张图像打包到一个以你**学号**命名的文件夹中，压缩后提交到课程作业系统。
