# 斯坦福 CS234 强化学习笔记：第1课 - 强化学习简介 🎯

在本节课中，我们将要学习强化学习的基本概念和框架。我们将了解什么是强化学习，它与其他机器学习范式的区别，以及其核心组成部分。

## 概述

强化学习是机器学习的一个分支，它关注智能体如何在一系列行动中学习，以最大化从环境中获得的累积奖励。与监督学习和无监督学习不同，强化学习通过试错和与环境的交互来学习。

上一节我们介绍了课程目标，本节中我们来看看强化学习的核心框架。

## 强化学习框架

强化学习问题通常由几个关键要素构成：智能体、环境、状态、行动和奖励。

以下是构成强化学习框架的核心要素列表：

*   **智能体**：做出决策的学习者或决策者。
*   **环境**：智能体与之交互的外部系统。
*   **状态**：环境在特定时刻的描述。
*   **行动**：智能体在给定状态下可以执行的操作。
*   **奖励**：环境在智能体执行一个行动后提供的即时反馈信号。

智能体在每个时间步 **t** 观察环境的状态 **S_t**，并据此选择一个行动 **A_t**。环境随后转移到新的状态 **S_{t+1}**，并向智能体提供一个数值奖励 **R_{t+1}**。这个过程不断重复。

## 目标与回报

智能体的目标不是最大化即时奖励，而是最大化长期累积奖励，即回报。

回报 **G_t** 是从时间步 **t** 开始未来奖励的总和。一个常用的计算方式是折扣回报：
`G_t = R_{t+1} + γ * R_{t+2} + γ^2 * R_{t+3} + ...`
其中，**γ** 是一个介于0和1之间的折扣因子，它决定了未来奖励的当前价值。

上一节我们定义了智能体的目标，本节中我们来看看智能体为了实现目标需要学习什么。

## 策略与价值函数

智能体通过学习策略来指导其行为。策略 **π** 是一个从状态到行动选择概率的映射。对于给定的状态 **s**，策略 **π(a|s)** 表示在状态 **s** 下选择行动 **a** 的概率。

为了评估策略的好坏，我们引入了价值函数。

*   **状态价值函数 V^π(s)**：表示从状态 **s** 开始，遵循策略 **π** 所能获得的期望回报。
    `V^π(s) = E_π[ G_t | S_t = s ]`
*   **行动价值函数 Q^π(s, a)**：表示在状态 **s** 下采取行动 **a**，然后遵循策略 **π** 所能获得的期望回报。
    `Q^π(s, a) = E_π[ G_t | S_t = s, A_t = a ]`

最优价值函数 **V*(s)** 和 **Q*(s, a)** 是所有可能策略中能获得的最大价值。找到最优策略是强化学习的终极目标。

## 总结

本节课中我们一起学习了强化学习的基础。我们介绍了强化学习的定义及其与其它机器学习范式的区别。我们详细阐述了强化学习的核心框架，包括智能体、环境、状态、行动和奖励。我们定义了智能体的目标是最大化长期回报，并引入了折扣因子的概念。最后，我们解释了策略和价值函数这两个关键概念，它们是智能体进行学习和决策的基础。理解这些基本要素是深入学习后续更复杂算法的重要前提。
