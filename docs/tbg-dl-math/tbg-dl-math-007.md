在本节课中，我们将学习几种在深度学习中频繁出现且非常有用的特殊矩阵和向量。它们通常拥有特定的名称和性质，理解它们有助于简化计算并加深对线性代数的理解。

上一节我们介绍了矩阵和向量的基本运算，本节中我们来看看几种具有特殊结构的矩阵和向量。

![](img/d596ad22e21a44c3cc401f127201beea_5.png)

### 对角矩阵

![](img/d596ad22e21a44c3cc401f127201beea_7.png)

首先，我们来看对角矩阵。对角矩阵是一种仅在主对角线上有非零元素，而其他位置均为零的矩阵。

![](img/d596ad22e21a44c3cc401f127201beea_9.png)

例如，矩阵 **D** 是一个对角矩阵，我们可以用 `diag(d)` 的记号来表示它，其中向量 **d** 的元素被放置在矩阵 **D** 的主对角线上。

![](img/d596ad22e21a44c3cc401f127201beea_11.png)

![](img/d596ad22e21a44c3cc401f127201beea_13.png)

**公式**：若 **D** = diag(**d**)，则 **D**<sub>ii</sub> = d<sub>i</sub>，且当 i ≠ j 时，**D**<sub>ij</sub> = 0。

与对角矩阵相乘非常简便。

如果我们用一个对角矩阵 **D** 乘以一个向量 **x**，由于 **D** 只有对角线元素非零，结果相当于用 **D** 的对角线元素分别缩放 **x** 的对应元素。

![](img/d596ad22e21a44c3cc401f127201beea_15.png)

![](img/d596ad22e21a44c3cc401f127201beea_16.png)

**公式**：**Dx** = **d** ⊙ **x**，其中 ⊙ 表示逐元素乘法（哈达玛积）。

求对角矩阵的逆也非常容易。我们不需要复杂的数值算法，只需将对角线上的每个元素分别取倒数，即可得到其逆矩阵。

**公式**：若 **D** = diag(d<sub>1</sub>, d<sub>2</sub>, ..., d<sub>n</sub>)，则 **D**<sup>-1</sup> = diag(1/d<sub>1</sub>, 1/d<sub>2</sub>, ..., 1/d<sub>n</sub>)。

![](img/d596ad22e21a44c3cc401f127201beea_18.png)

![](img/d596ad22e21a44c3cc401f127201beea_19.png)

### 对称矩阵

接下来介绍对称矩阵。对称矩阵是等于其自身转置的矩阵，即 **A** = **A**<sup>⊤</sup>。

![](img/d596ad22e21a44c3cc401f127201beea_21.png)

这意味着矩阵中所有位于主对角线上方的元素，都与主对角线下方对称位置上的元素相等。

**公式**：对于对称矩阵 **A**，有 **A**<sub>ij</sub> = **A**<sub>ji</sub>。

对称矩阵经常出现在涉及距离或相似度的场景中。例如，如果我们有五个城市，可以用一个5x5的矩阵来表示城市之间的距离。从城市A到城市B的距离等于从城市B到城市A的距离，因此这个距离矩阵就是一个对称矩阵。

### 单位向量与正交性

![](img/d596ad22e21a44c3cc401f127201beea_23.png)

现在，我们转向向量的特殊概念。单位向量是指其L2范数（欧几里得范数）等于1的向量。

![](img/d596ad22e21a44c3cc401f127201beea_25.png)

**公式**：向量 **x** 是单位向量，当且仅当 ||**x**||<sub>2</sub> = 1。

![](img/d596ad22e21a44c3cc401f127201beea_27.png)

如果两个向量 **x** 和 **y** 的内积等于0，则称它们相互正交。

**公式**：**x** 与 **y** 正交 ⇔ **x**<sup>⊤</sup>**y** = 0。

![](img/d596ad22e21a44c3cc401f127201beea_29.png)

![](img/d596ad22e21a44c3cc401f127201beea_30.png)

一组向量，如果其中每个向量都是单位向量，并且彼此两两正交，则称这组向量是标准正交的。“标准正交”这个词是“正交”和“标准化”（即长度为1）的组合。

![](img/d596ad22e21a44c3cc401f127201beea_32.png)

![](img/d596ad22e21a44c3cc401f127201beea_33.png)

### 正交矩阵

![](img/d596ad22e21a44c3cc401f127201beea_35.png)

最后，我们学习正交矩阵。正交矩阵是一个方阵，其所有行向量和所有列向量分别构成一组标准正交向量。

**公式**：方阵 **A** 是正交矩阵，当且仅当 **A**<sup>⊤</sup>**A** = **AA**<sup>⊤</sup> = **I**，其中 **I** 是单位矩阵。

![](img/d596ad22e21a44c3cc401f127201beea_37.png)

![](img/d596ad22e21a44c3cc401f127201beea_38.png)

这个性质意味着正交矩阵的逆矩阵就是其转置矩阵。

**公式**：对于正交矩阵 **A**，有 **A**<sup>-1</sup> = **A**<sup>⊤</sup>。

![](img/d596ad22e21a44c3cc401f127201beea_40.png)

![](img/d596ad22e21a44c3cc401f127201beea_41.png)

因此，计算正交矩阵的逆非常高效，只需要进行转置操作即可，即沿着主对角线翻转矩阵元素。

![](img/d596ad22e21a44c3cc401f127201beea_43.png)

本节课中我们一起学习了四种重要的特殊矩阵和向量：**对角矩阵**、**对称矩阵**、**单位向量与正交性**以及**正交矩阵**。理解它们的定义和性质，对于后续学习矩阵分解、优化算法等深度学习核心内容至关重要。
