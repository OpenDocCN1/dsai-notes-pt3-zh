## 概述

![](img/297bb4bd5723b471a8e7c3e764f7c752_3.png)

上一节我们介绍了光滑函数在非凸优化研究中的重要性。本节中，我们将深入探讨梯度下降法和随机梯度下降法在光滑非凸函数上的收敛性证明。核心思想是利用光滑性来量化每次迭代的进展。

## 梯度下降法证明

我们首先回顾并证明梯度下降法的定理。关键思路是研究每次迭代的进展，而光滑性正是我们的得力工具。

光滑性为我们提供了函数值变化的上界，这有助于分析进展。具体来说，对于任意两次迭代点 **w_t** 和 **w_t+1**，我们有：

![](img/297bb4bd5723b471a8e7c3e764f7c752_5.png)

```
f(w_{t+1}) ≤ f(w_t) + <∇f(w_t), w_{t+1} - w_t> + (L/2) * ||w_{t+1} - w_t||^2
```

![](img/297bb4bd5723b471a8e7c3e764f7c752_7.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_9.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_11.png)

将梯度下降的更新规则 **w_{t+1} = w_t - η ∇f(w_t)** 代入上式，并进行整理，我们可以得到进展量的表达式：

![](img/297bb4bd5723b471a8e7c3e764f7c752_13.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_14.png)

```
f(w_t) - f(w_{t+1}) ≥ (η - (Lη^2)/2) * ||∇f(w_t)||^2
```

![](img/297bb4bd5723b471a8e7c3e764f7c752_16.png)

以下是关于此进展公式的几个重要说明：

![](img/297bb4bd5723b471a8e7c3e764f7c752_18.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_20.png)

*   **进展与梯度大小相关**：进展量正比于梯度范数的平方 **||∇f(w_t)||^2**。这意味着梯度越大（即离解越远），进展越快；接近解时，进展会自动放缓。
*   **学习率的稳定边界**：只要学习率 **η** 严格小于 **2/L**，我们就能保证每次迭代都取得进展（函数值下降）。超过此边界，优化可能变得不稳定，甚至可能最大化函数。这在深度学习优化中被称为“不稳定边缘”现象。
*   **最优学习率**：若将进展量视为学习率 **η** 的函数，通过求导并令其为零，可以找到最大化进展的学习率，即 **η = 1/L**。这正是定理陈述中使用的步长。

![](img/297bb4bd5723b471a8e7c3e764f7c752_22.png)

接下来，我们完成证明的剩余部分。对不等式进行重新排列，并对时间步取平均。

![](img/297bb4bd5723b471a8e7c3e764f7c752_24.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_26.png)

重新排列要求学习率小于 **2/L**，否则不等式方向会改变。取平均后，我们注意到等式左边出现了伸缩和结构：

```
(1/T) * Σ_{t=1}^T ||∇f(w_t)||^2 ≤ [f(w_1) - f(w_{T+1})] / [T * (η - Lη^2/2)]
```

![](img/297bb4bd5723b471a8e7c3e764f7c752_28.png)

中间的项相互抵消，只剩下第一项和最后一项。由于 **f(w_{T+1})** 的函数值总是不小于最优值 **f(w^*)**，我们可以用后者替换并得到一个上界，这个上界就是初始次优性间隙 **Δ = f(w_1) - f(w^*)**。

由此，我们得到对所有满足 **η < 2/L** 的学习率都成立的一个界。通过优化这个关于 **η** 的界，我们发现当 **η = 1/L** 时取得最小值，从而证明了定理陈述中的结果。

![](img/297bb4bd5723b471a8e7c3e764f7c752_30.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_32.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_34.png)

## 随机梯度下降法证明

![](img/297bb4bd5723b471a8e7c3e764f7c752_36.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_38.png)

现在，让我们看看随机梯度下降法的证明。其思路与梯度下降法相似，但由于算法的随机性，处理起来更为复杂。

我们同样从光滑性定义出发，研究期望进展。SGD的随机性源于小批量样本或单个样本的选择，因此我们需要处理期望值，并对随机梯度估计器做出假设。

具体来说，我们假设可以访问一个随机梯度预言机，它提供真实梯度的无偏估计，并且估计的方差有界。为简化分析，我们还假设样本是独立的。

![](img/297bb4bd5723b471a8e7c3e764f7c752_40.png)

证明开始时，我们在给定当前解 **w_t** 的条件下取期望，以分离出由选择当前小批量 **Z_t** 带来的随机性影响。利用随机梯度的无偏性 **E[g_t | w_t] = ∇f(w_t)**，我们可以处理进展表达式中的各项。

![](img/297bb4bd5723b471a8e7c3e764f7c752_42.png)

经过类似梯度下降证明中的推导，并利用方差有界性假设，我们得到关于期望进展的不等式：

![](img/297bb4bd5723b471a8e7c3e764f7c752_44.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_46.png)

```
E[f(w_{t+1}) | w_t] ≤ f(w_t) - (η - Lη^2/2) * ||∇f(w_t)||^2 + (Lη^2/2) * σ^2
```

![](img/297bb4bd5723b471a8e7c3e764f7c752_48.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_50.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_51.png)

与梯度下降相比，这里多出了一个正项 ** (Lη^2/2) * σ^2 **。由于此项的存在，即使学习率 **η < 2/L**，我们也不能保证期望进展总是正向的。这意味着运行SGD时，下一次迭代的解可能比当前解更差，这解释了在优化深度学习模型损失时观察到的损失曲线波动现象。

![](img/297bb4bd5723b471a8e7c3e764f7c752_53.png)

证明的剩余部分与之前类似：对时间步取平均、重新排列、对所有随机决策取全期望，并利用样本独立性。最终我们得到一个上界：

![](img/297bb4bd5723b471a8e7c3e764f7c752_55.png)

```
(1/T) * Σ_{t=1}^T E[||∇f(w_t)||^2] ≤ [Δ / (T * (η - Lη^2/2))] + [Lησ^2 / (2 - Lη)]
```

![](img/297bb4bd5723b471a8e7c3e764f7c752_57.png)

该界对所有满足 **η < 2/L** 的学习率成立。最后一步是优化这个关于 **η** 的界。通过计算（此处从略），我们可以找到定理中所述的最优学习率 **η = min(1/L, Δ/(Lσ^2 T))^{1/2}**，并得到相应的收敛速率。

![](img/297bb4bd5723b471a8e7c3e764f7c752_59.png)

![](img/297bb4bd5723b471a8e7c3e764f7c752_61.png)

本节课中，我们一起学习了梯度下降法和随机梯度下降法在光滑非凸函数上的收敛性证明。我们利用光滑性量化了算法的进展，并分析了学习率的关键作用。对于梯度下降，我们得到了明确的进展保证和最优学习率 **1/L**。对于随机梯度下降，由于估计方差的存在，进展保证是期望意义上的，且最优学习率与初始间隙、光滑常数、方差和迭代次数有关。在下一讲中，我们将探讨一些增强SGD及其性能保证的方法。
