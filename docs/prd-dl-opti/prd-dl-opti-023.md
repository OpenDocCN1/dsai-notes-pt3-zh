## 从初始化到训练中的归一化

![](img/f76475ac8f693c5350d64736c67e8f10_6.png)

![](img/f76475ac8f693c5350d64736c67e8f10_7.png)

![](img/f76475ac8f693c5350d64736c67e8f10_9.png)

![](img/f76475ac8f693c5350d64736c67e8f10_11.png)

我们之前讨论了初始化，特别是He初始化。其核心思想是希望随机初始化的权重矩阵的每个坐标是均值为0的独立随机变量，并且其方差满足特定条件。

![](img/f76475ac8f693c5350d64736c67e8f10_13.png)

方差与权重矩阵的输入维度 `D_in` 和输出维度 `D_out` 相关，公式大致如下：

![](img/f76475ac8f693c5350d64736c67e8f10_15.png)

![](img/f76475ac8f693c5350d64736c67e8f10_16.png)

**方差 ∝ 2 / (D_in + D_out)**

这意味着，对于一个较小的层（即 `D_in` 和 `D_out` 较小），其权重值会相对较大；而对于一个较大的层，权重值则相对较小。因此，我们实际上是在所有层之间进行了一种归一化，以确保尽管各层的输入输出尺寸不同，但它们在初始化时的“强度”大致相同。

![](img/f76475ac8f693c5350d64736c67e8f10_18.png)

然而，这种归一化仅在初始化时进行。随着训练的进行，权重被不断更新，这种初始的归一化状态可能会丢失，各层的“强度”会发生变化。

![](img/f76475ac8f693c5350d64736c67e8f10_20.png)

因此，文献中提出了一些想法，旨在将我们在初始化时讨论的归一化思想扩展到整个训练过程中。我们将讨论其中的几种归一化思想。这些思想与后续课程中将要讨论的自适应训练方法在直觉上有一定联系，其核心目标都是确保不同参数能以大致相同的速率进行更新。

![](img/f76475ac8f693c5350d64736c67e8f10_22.png)

![](img/f76475ac8f693c5350d64736c67e8f10_23.png)

## 归一化的作用与原理

![](img/f76475ac8f693c5350d64736c67e8f10_25.png)

![](img/f76475ac8f693c5350d64736c67e8f10_26.png)

归一化思想虽然非常有效，但其原理并未被完全理解。不过，从优化角度进行的一些研究试图解释其有效性。多项研究表明，对激活值进行归一化可以导致更小的梯度。

![](img/f76475ac8f693c5350d64736c67e8f10_28.png)

![](img/f76475ac8f693c5350d64736c67e8f10_29.png)

回顾课程开始时讨论的理论，我们知道梯度下降法的收敛速度与利普希茨常数（或平滑常数）成比例。常数越大，函数对输入的敏感性越高，算法就需要使用更小的步长，收敛速度也就越慢。

![](img/f76475ac8f693c5350d64736c67e8f10_31.png)

![](img/f76475ac8f693c5350d64736c67e8f10_32.png)

归一化在某些场景下可以降低梯度，从而有效地降低了损失函数的利普希茨常数和平滑性。这意味着我们改善了损失函数的“地形”，因此能够收敛得更快。

在泛化能力和测试准确率方面，也有研究将损失函数地形的“尖锐度”与较差的泛化能力联系起来。因此，通过归一化降低损失的敏感性，我们不仅期望模型收敛更快，而且找到的解也可能具有更好的泛化能力。

![](img/f76475ac8f693c5350d64736c67e8f10_34.png)

![](img/f76475ac8f693c5350d64736c67e8f10_35.png)

## 主要的归一化方法

![](img/f76475ac8f693c5350d64736c67e8f10_36.png)

![](img/f76475ac8f693c5350d64736c67e8f10_38.png)

![](img/f76475ac8f693c5350d64736c67e8f10_40.png)

文献中提出了多种归一化方法。下图展示了四种，但我们将简要讨论其中两种：批归一化（Batch Normalization）和层归一化（Layer Normalization）。

![](img/f76475ac8f693c5350d64736c67e8f10_41.png)

![](img/f76475ac8f693c5350d64736c67e8f10_42.png)

想象你有一批样本或向量，具体来说是 `N` 个向量或矩阵。每个矩阵的尺寸是 `H × W`，我们称 `P = H × W`。这可以看作是将一个二维输入（如图像）向量化的结果。虽然图像可能有多个通道（如RGB图像的3个通道），但在接下来的讨论中，我们假设通道数 `C = 1` 以简化问题。

![](img/f76475ac8f693c5350d64736c67e8f10_44.png)

![](img/f76475ac8f693c5350d64736c67e8f10_46.png)

以下是两种方法的核心区别：
*   **批归一化**：沿着**批次（Batch）方向**进行归一化，即对同一批次中所有样本的同一特征维度进行统计。
*   **层归一化**：沿着**特征（Feature）方向**进行归一化，即对单个样本的所有特征维度进行统计。

![](img/f76475ac8f693c5350d64736c67e8f10_48.png)

接下来，让我们详细探讨这两种方法。

![](img/f76475ac8f693c5350d64736c67e8f10_50.png)

![](img/f76475ac8f693c5350d64736c67e8f10_52.png)

## 批归一化详解

我们考虑一个批次 `B`，其中包含 `B` 个向量 `U_1, ..., U_B`。这些是特定SGD迭代中，与数据点相关的激活向量。它们是 `P` 维向量。随机梯度本身就是这些激活向量的函数。

![](img/f76475ac8f693c5350d64736c67e8f10_54.png)

批归一化操作沿着批次维度进行归一化。其操作定义如下：

![](img/f76475ac8f693c5350d64736c67e8f10_56.png)

对于一个向量 `U`，我们按以下方式对其进行归一化：减去均值，除以标准差。为了防止除零错误并确保数值稳定性，我们通常会在分母加上一个很小的常数 `ε`。

![](img/f76475ac8f693c5350d64736c67e8f10_58.png)

![](img/f76475ac8f693c5350d64736c67e8f10_59.png)

除了减去均值和除以标准差，我们还有两个可学习的参数：缩放参数 `γ`（向量）和偏移参数 `β`（向量）。在更新神经网络参数的同时，我们也会从数据中学习更新 `α` 和 `β`。这里的 `⊙` 表示逐元素相乘（哈达玛积）。

![](img/f76475ac8f693c5350d64736c67e8f10_61.png)

公式中，`μ` 和 `σ` 分别是该批次中所有样本的均值和标准差。具体来说，`μ_i` 是批次中所有样本第 `i` 个特征的平均值，`σ^2` 是经验方差（样本方差）。

![](img/f76475ac8f693c5350d64736c67e8f10_63.png)

以下是批归一化在实践中需要注意的几个要点，这些要点主要基于经验观察：

*   **批次大小**：批次大小 `B` 需要适中。如果 `B` 太小，会因统计信息不足而丢失信息；如果 `B` 太大，则会带来巨大的计算开销。因此，我们通常需要找到一个适中的批次大小。
*   **噪声的益处**：在优化神经网络参数时，一定的噪声可能是有益的。它不仅有助于改进训练过程，有时还能提高模型的泛化性能。适中的批次大小会使归一化操作本身带有一定的噪声，这可能与使用批归一化的模型通常观察到的更好泛化性能有关。

![](img/f76475ac8f693c5350d64736c67e8f10_65.png)

## 批归一化的训练与推理

那么，在实践中如何将批归一化与其他操作结合使用呢？思路如下：

考虑一个多层感知机模型。我们有 `W * x + b`，对于每个 `x` 这会得到一个向量。假设我们有一个批次（例如64个数据点）的这些向量。我们将这个结果输入到批归一化层，得到一个向量，然后将其馈入非线性激活函数（如ReLU），之后可能还会输入到其他层（如Dropout，我们将在正则化课程中讨论）。

在推理阶段（即训练完成后使用模型时），操作略有不同。我们不再使用当前推理批次的统计量来计算均值和方差，而是使用整个训练数据的统计量。这样做的原因是：训练时我们需要噪声来帮助找到泛化性好的解，而推理时我们追求尽可能高的准确性。

![](img/f76475ac8f693c5350d64736c67e8f10_67.png)

显然，在整个大型训练集上计算均值和方差非常耗时。因此，实践中我们通常在训练期间估算整个训练数据的统计量。具体来说，我们可以基于训练过程中遇到的小批次，计算其均值和方差的移动平均值。当训练完成时，这些移动平均值可以被视为对整个数据统计量的良好估计。

![](img/f76475ac8f693c5350d64736c67e8f10_69.png)

![](img/f76475ac8f693c5350d64736c67e8f10_71.png)

![](img/f76475ac8f693c5350d64736c67e8f10_72.png)

## 层归一化详解

![](img/f76475ac8f693c5350d64736c67e8f10_74.png)

与批归一化不同，层归一化对每个向量（即每个样本的激活）单独进行归一化。这是一个确定性操作，不依赖于批次统计量，也不依赖于随机选择的特定批次。

![](img/f76475ac8f693c5350d64736c67e8f10_76.png)

![](img/f76475ac8f693c5350d64736c67e8f10_77.png)

![](img/f76475ac8f693c5350d64736c67e8f10_78.png)

其操作方式如下：

![](img/f76475ac8f693c5350d64736c67e8f10_80.png)

![](img/f76475ac8f693c5350d64736c67e8f10_82.png)

![](img/f76475ac8f693c5350d64736c67e8f10_83.png)

对于一个特定的激活向量 `U`，我们计算其所有坐标的均值 `μ`（这是一个标量，而不是批归一化中的向量），以及其经验方差 `σ^2`。然后进行归一化：将向量减去 `μ`（标量）乘以全1向量，再除以标准差（同样加上小常数 `ε` 以保证稳定性）。

![](img/f76475ac8f693c5350d64736c67e8f10_85.png)

![](img/f76475ac8f693c5350d64736c67e8f10_86.png)

![](img/f76475ac8f693c5350d64736c67e8f10_88.png)

层归一化最初是为了解决在循环神经网络中实现批归一化时遇到的一些问题而提出的。它也有一些优势：层归一化有助于稳定训练，因为它几乎是一个尺度不变的操作。这意味着，如果将输入 `U` 乘以一个缩放因子 `α`，那么均值和标准差也会被乘以 `α`，因此输出不会改变。这种尺度不变性被认为是其能稳定训练的一个非常有用的特性。

![](img/f76475ac8f693c5350d64736c67e8f10_90.png)

![](img/f76475ac8f693c5350d64736c67e8f10_92.png)

## 扩展到更高维数据

![](img/f76475ac8f693c5350d64736c67e8f10_94.png)

![](img/f76475ac8f693c5350d64736c67e8f10_95.png)

![](img/f76475ac8f693c5350d64736c67e8f10_96.png)

如前所述，我们介绍了针对向量的批归一化和层归一化。在实践中，我们处理的数据通常是矩阵和张量（例如具有多个通道的图像）。尽管如此，我们可以将这些思想推广到非向量的数据上。

![](img/f76475ac8f693c5350d64736c67e8f10_98.png)

![](img/f76475ac8f693c5350d64736c67e8f10_99.png)

![](img/f76475ac8f693c5350d64736c67e8f10_100.png)

核心思想不变：
*   **批归一化**：对一批矩阵，沿着批次方向进行归一化。
*   **层归一化**：对每个矩阵（或图像）单独进行归一化。
