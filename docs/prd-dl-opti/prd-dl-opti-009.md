## 概述
在本节课中，我们将学习如何从**主优化-最小化**的视角来理解梯度下降法。我们将看到，对于光滑函数，梯度下降可以被视为一种不断最小化函数上界的迭代过程。这一视角不仅帮助我们理解梯度下降的工作原理，还为我们设计更高级的优化算法（如处理约束、使用不同距离度量或随机梯度）提供了清晰的框架。

## 从不同视角理解梯度下降
上一节我们讨论了在非凸函数上研究梯度下降和随机梯度下降的性能，并指出在关注梯度范数作为收敛度量时，光滑性是一个必要的条件。本节中，我们来看看光滑性的另一个好处，它为我们理解梯度下降提供了一个新的视角。

![](img/7a1e10fb70685b449942d5ad94b55684_12.png)

![](img/7a1e10fb70685b449942d5ad94b55684_13.png)

![](img/7a1e10fb70685b449942d5ad94b55684_15.png)

目前，我们已经从两个角度讨论了梯度下降：
1.  **不动点计算视角**：寻找平稳点等价于寻找另一个函数的不动点。一个自然的算法是寻找不动点，这恰好就是梯度下降。
    `w_{t+1} = w_t - η ∇f(w_t)`
2.  **局部下降方向视角**：梯度下降意味着我们沿着局部下降方向前进，即在局部最小化函数，因此这是一个好的探索策略。

现在，得益于光滑性，我们有了第三个视角。这个视角非常优雅，能帮助我们思考如何开发更好、更通用的算法。

## 主优化-最小化算法框架
考虑迭代地最小化一个函数 `f`，这正是我们通常的做法（例如SGD和梯度下降）。我们希望确保解的质量不断提升。这意味着在最小化函数时，我们希望函数值在每一步都下降：
`f(w_{t+1}) < f(w_t)`
这被称为算法的**下降性质**。

![](img/7a1e10fb70685b449942d5ad94b55684_22.png)

理想情况下，我们希望更进一步，最大化每一步取得的进展。我们定义**进展函数**为从当前解 `w_t` 移动到下一个解 `w_t+1` 时函数值的减少量。我们希望找到下一个解，使得这个进展最大化。

![](img/7a1e10fb70685b449942d5ad94b55684_24.png)

为此，有一个非常巧妙的方法，称为**主优化-最小化**。当最小化损失函数时，我们迭代地**主优化**该函数，即找到一个函数的上界，然后转而最小化这个上界。我们持续进行一定次数的迭代，直到收敛。对于最大化问题（如利润、效用或奖励），则进行**次优化-最大化**，即找到函数的下界并最大化它。

![](img/7a1e10fb70685b449942d5ad94b55684_26.png)

![](img/7a1e10fb70685b449942d5ad94b55684_28.png)

我们将更详细地讨论这个流程，并探讨其与梯度下降的联系，以及如何利用它来开发更高级的算法。

![](img/7a1e10fb70685b449942d5ad94b55684_30.png)

![](img/7a1e10fb70685b449942d5ad94b55684_32.png)

## 主优化-最小化的性质与保证
我们希望最大化进展，并通过找到一个合适的上界来实现，这就是我所说的主优化步骤。

![](img/7a1e10fb70685b449942d5ad94b55684_34.png)

![](img/7a1e10fb70685b449942d5ad94b55684_35.png)

我们假设有一个函数上界 `U_t(w)`，它具有以下性质：
1.  **紧致性**：上界在当前解 `w_t` 处是紧的，即 `U_t(w_t) = f(w_t)`。
2.  **上界性**：它始终是函数值的上界，即对于所有 `w`，有 `U_t(w) ≥ f(w)`。
3.  **易优化性**：这个代理函数易于最小化。

我们希望，通过迭代地最小化这些代理函数，最终能收敛到原函数的最小值点。

![](img/7a1e10fb70685b449942d5ad94b55684_37.png)

![](img/7a1e10fb70685b449942d5ad94b55684_39.png)

那么，我们的主优化-最小化流程就是：每次找到当前代理函数 `U_t` 的最小值点，然后更新代理函数为 `U_{t+1}`，使得新的代理函数同样满足紧致性、上界性和易优化性这三个性质。

这看起来像一个非常数学化、宽泛的算法。事实上，你可能在其他课程中见过许多这类算法的例子，例如用于聚类问题的**K均值算法**，以及用于确定混合模型（如高斯混合模型）参数的著名**期望最大化算法**。

我们的目标是证明，**梯度下降也是主优化-最小化算法的一个例子**，前提是函数是光滑的。

![](img/7a1e10fb70685b449942d5ad94b55684_41.png)

首先，让我们讨论这些性质带来的保证。本质上，它们确保了我们的算法始终在取得进展，满足下降性质，因此应该收敛到一个好的解。

![](img/7a1e10fb70685b449942d5ad94b55684_43.png)

![](img/7a1e10fb70685b449942d5ad94b55684_45.png)

让我们更数学化地看看这一点。进展函数定义为从 `w_t` 移动到 `w_{t+1}` 时函数值的减少。利用代理函数是原函数上界这一事实，我们可以用 `U_t(w_{t+1})` 替换 `f(w_{t+1})`，从而得到进展的一个下界。我们希望对进展找到一个下界，以确保我们始终在取得进展，并且这个下界最好是非平凡的。

接下来，因为 `w_{t+1}` 是 `U_t` 的最小值点，所以 `U_t(w_{t+1}) ≤ U_t(w_t)`。最后，利用紧致性，`U_t(w_t) = f(w_t)`。因此，我们得到 `f(w_{t+1}) ≤ f(w_t)`。这意味着我们始终在取得进展，即算法具有下降性质。

如果我们进一步假设损失函数有下界（这是一个合理的假设，因为我们在最小化一个函数，如果它无下界，最小值就是负无穷），那么由于函数值持续下降，算法最终将会收敛。它会收敛或停止在一个平稳点。

但这并没有说明算法需要多少次迭代才能找到一个近似解。这属于**收敛速率分析**或**计算复杂性分析**的范畴，我们课程中目前讨论的容差就是一个例子。

![](img/7a1e10fb70685b449942d5ad94b55684_47.png)

## 梯度下降作为主优化-最小化的实例
现在，让我们讨论为什么梯度下降是主优化-最小化流程的一个例子。关键在于，**得益于光滑性，我们有一个天然的函数上界，而这个上界恰好是一个凸二次函数，因此易于最小化**。

![](img/7a1e10fb70685b449942d5ad94b55684_49.png)

具体来说，对于光滑函数，我们有一个凸二次上界，可以将其用作我们的代理函数：
`U_t(w) = f(w_t) + ∇f(w_t)^T (w - w_t) + (L/2) ||w - w_t||^2`
让我们验证它满足我们的性质：
*   **紧致性**：当 `w = w_t` 时，后两项为零，所以 `U_t(w_t) = f(w_t)`。
*   **上界性**：因为函数是L-光滑的，所以该不等式成立。
*   **易优化性**：这个上界是强凸的，因此非常容易优化。

![](img/7a1e10fb70685b449942d5ad94b55684_51.png)

![](img/7a1e10fb70685b449942d5ad94b55684_52.png)

![](img/7a1e10fb70685b449942d5ad94b55684_54.png)

回忆主优化-最小化流程，其思想是通过最小化代理函数来更新解。给定我们的代理函数是一个强凸二次函数，要找到其最小值点，只需对其求梯度并设为零。

对 `U_t(w)` 求梯度并设为零：
`∇U_t(w) = ∇f(w_t) + L (w - w_t) = 0`
经过整理，解 `w` 为：
`w = w_t - (1/L) ∇f(w_t)`
这正是我们之前见过的梯度下降，其学习率为 `1/L`。因此，这个结果表明，步长为 `1/L` 的梯度下降是主优化-最小化算法的一个实例。

![](img/7a1e10fb70685b449942d5ad94b55684_56.png)

更一般地，任何步长 `η ≤ 1/L` 的梯度下降方法，也都是主优化-最小化的实例，因为它同样会产生一个有效的函数上界（此时代理函数中的二次项系数为 `1/(2η) ≥ L/2`）。

![](img/7a1e10fb70685b449942d5ad94b55684_58.png)

![](img/7a1e10fb70685b449942d5ad94b55684_59.png)

![](img/7a1e10fb70685b449942d5ad94b55684_61.png)

## 基于新视角设计更通用的算法
这非常棒，因为它为设计更通用的算法提供了蓝图。

![](img/7a1e10fb70685b449942d5ad94b55684_63.png)

![](img/7a1e10fb70685b449942d5ad94b55684_65.png)

例如，我们在课程中一直避免讨论带有约束的优化问题场景，而这在深度学习中非常重要。我们不仅关心模型在训练和测试准确率上的表现，可能还关心其他标准，例如模型的鲁棒性、记忆化倾向等。

![](img/7a1e10fb70685b449942d5ad94b55684_67.png)

要处理约束，我们需要做的就是从主优化-最小化的视角重新思考梯度下降。我们有一个凸二次上界需要最小化，但现在我们在约束集上进行最小化。这个更新恰好对应于另一种方法——**投影梯度下降**。这意味着你仍然沿着下降方向前进，但如果得到的解不可行，则在取得进展后将其投影回约束集，以确保迭代解始终可行。这两种视角本质上是相同的。

![](img/7a1e10fb70685b449942d5ad94b55684_69.png)

除了处理约束，有时使用不同的距离度量也很有用。在上述上界中，我们使用了欧几里得范数的平方。有时将其替换为其他距离或散度是有益的，例如L1范数等。这样，你可以考虑以下算法：除了将欧几里得距离平方替换为捕获 `w` 和 `w_t` 相似性的抽象散度概念外，其他部分与之前方程相同。一个著名的例子是**镜像下降**，当待优化的参数 `w` 是一个概率向量时（例如强化学习中策略给出了选择动作的概率），这非常有用。通过将欧几里得范数替换为其他度量，你可以获得更快的性能，因为你利用了 `w` 属于概率单纯形的结构，而使用欧几里得范数则无法利用这种结构。

![](img/7a1e10fb70685b449942d5ad94b55684_71.png)

另一个扩展，同样由主优化-最小化视角推动，是将梯度替换为任意的更新向量 `g`。我们最小化相同的代理函数形式，只是将梯度 `∇f(w_t)` 替换为某个更新向量 `g`。这种方法的例子包括：将梯度替换为**随机梯度**，例如随机投影梯度下降，或随机版本的镜像下降等。

![](img/7a1e10fb70685b449942d5ad94b55684_73.png)

最后，这也提供了一种方法来利用其他结构并可能开发出更好的代理函数。我们这里讨论的结构是光滑性，它使我们能够找到这个漂亮的凸二次上界，并利用它来应用主优化-最小化。但如果函数具有其他结构（例如，我们知道其二阶导数或海森矩阵具有某些良好性质），我们或许能够利用这些结构来开发更好的代理函数，从而设计出更好的优化算法。

![](img/7a1e10fb70685b449942d5ad94b55684_75.png)

## 总结
本节课中，我们一起学习了从**主优化-最小化**的视角来理解梯度下降。我们看到，光滑性之所以重要，首先是因为它提供了一种在函数非凸时理解训练算法性能的方法；其次，它提供了一种不同的方式来思考梯度下降，并有可能借此设计出更高级的算法。在下一讲中，我们将专注于证明之前为SGD和梯度下降在非凸但光滑函数上所述的定理。
