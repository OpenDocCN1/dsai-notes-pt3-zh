# 斯坦福 CS520 知识图谱课程笔记 第1讲：知识图谱基础 🧠

在本节课中，我们将要学习知识图谱的基本概念、核心组成部分以及它的主要应用。知识图谱是一种用图模型来组织和表示知识的技术，它正成为人工智能和语义搜索领域的重要基石。

## 什么是知识图谱？

知识图谱是一种结构化的语义知识库，用于描述物理世界中的概念、实体及其相互关系。它以图的形式存储数据，节点代表实体或概念，边代表实体间的关系。

上一节我们介绍了知识图谱的抽象定义，本节中我们来看看它的核心数据模型。

## 核心数据模型：RDF三元组

知识图谱的基础数据模型是资源描述框架（RDF）三元组。一个三元组由**主体（Subject）、谓词（Predicate）、客体（Object）** 构成，可以表示为一条有向边。

其基本形式可以用以下公式表示：
`<主体， 谓词， 客体>`

例如，陈述“斯坦福大学位于加利福尼亚州”可以表示为：
`<斯坦福大学， 位于， 加利福尼亚州>`

在具体实现中，这通常用URI来标识，例如用代码描述为：
```
@prefix ex: <http://example.org/> .
ex:StanfordUniversity ex:locatedIn ex:California .
```

理解了基本的数据单元后，我们接下来看看如何用模式层来规范这些数据。

## 知识图谱的两层结构

一个完整的知识图谱通常包含**数据层**和**模式层**。

*   **数据层**：由大量的事实三元组构成，存储具体的数据。
*   **模式层**：在数据层之上，是知识图谱的概念模型和约束。它定义了类别（Class）、属性（Property）以及它们之间的层次关系（如父子类关系）。

模式层就像是数据库的 schema，它让数据更有组织性。以下是构建知识图谱的几个关键步骤。

## 知识图谱的构建流程

构建一个知识图谱主要涉及以下几个步骤：

1.  **知识抽取**：从结构化、半结构化和非结构化数据源中提取实体、关系和属性。
2.  **知识融合**：将来自不同数据源的知识进行整合，消除实体指称的歧义和冲突（例如，明确“苹果”是指公司还是水果）。
3.  **知识推理**：在已有知识的基础上，通过推理机推导出隐含的知识，丰富图谱内容。
4.  **知识存储**：将处理后的知识存入图数据库，以便高效查询和管理。

掌握了构建流程，我们来看看知识图谱在实际中能解决什么问题。

## 主要应用场景

知识图谱的应用十分广泛，以下是一些典型领域：

*   **搜索引擎**：增强搜索的语义理解，提供更精准的答案和知识卡片。
*   **智能问答**：直接回答用户提出的复杂问题，例如“谁创立了特斯拉汽车公司？”。
*   **推荐系统**：利用实体间的复杂关系进行更深层次的推荐。
*   **风险控制**：在金融领域，识别复杂的欺诈网络。
