# 斯坦福博弈论笔记 第1讲：博弈论基础 🎲

在本节课中，我们将要学习博弈论的基本概念和核心模型。博弈论是研究决策者之间策略互动的数学理论，广泛应用于经济学、政治学、计算机科学等领域。

## 什么是博弈论？🤔

博弈论分析的是两个或更多决策者（称为“参与者”）在策略情境中的互动。每个参与者的决策结果不仅取决于自己的选择，也取决于其他参与者的选择。

上一节我们介绍了博弈论的研究对象，本节中我们来看看构成一个博弈的基本要素。

## 博弈的基本要素 📝

一个标准的博弈模型包含以下四个核心部分：

以下是构成一个博弈的四个基本要素：

1.  **参与者**：做出决策的个体或实体。
2.  **策略**：每个参与者在博弈中可以选择的行动方案。
3.  **收益**：在博弈结束后，每个参与者根据所有参与者的策略选择所获得的结果。收益通常用数字（效用）表示。
4.  **信息**：参与者在做决策时所掌握的知识，特别是关于其他参与者特征和可能行动的知识。

## 核心模型：标准式博弈 📊

标准式博弈，也称为策略式博弈，是描述博弈的一种简洁方式。它特别适用于描述参与者同时做出决策的情况。

上一节我们了解了博弈的构成要素，本节中我们通过标准式博弈来具体看看这些要素如何组织在一起。

标准式博弈通过一个**收益矩阵**来呈现。以最简单的两人博弈为例，矩阵的行代表参与者A的策略，列代表参与者B的策略，矩阵中的每个单元格则对应一组策略组合下双方的收益。

例如，在一个经典的“囚徒困境”博弈中，假设两个囚徒（参与者1和2）都有“坦白”和“抵赖”两个策略。收益矩阵可以表示如下：

| 参与者1 \ 参与者2 | 坦白 | 抵赖 |
| :--- | :--- | :--- |
| **坦白** | (-5, -5) | (0, -10) |
| **抵赖** | (-10, 0) | (-1, -1) |

在收益括号 `(a, b)` 中，**a** 代表参与者1的收益，**b** 代表参与者2的收益。数字越小（或负得越多）代表刑期越长，结果越差。

## 核心概念：纳什均衡 ⚖️

纳什均衡是博弈论中预测博弈结果的一个核心概念。它描述的是这样一种策略组合：在给定其他参与者策略的情况下，没有任何一个参与者可以通过单方面改变自己的策略而获得更高的收益。

以下是纳什均衡的正式定义：

> 在一个有 *n* 个参与者的博弈中，策略组合 \( (s_1^*, s_2^*, ..., s_n^*) \) 是一个**纳什均衡**，当且仅当对于每一个参与者 *i*，其均衡策略 \( s_i^* \) 是对其他参与者均衡策略组合 \( s_{-i}^* \) 的**最优反应**。
> 用公式表示为：
> \( u_i(s_i^*, s_{-i}^*) \geq u_i(s_i, s_{-i}^*) \)， 对于参与者 *i* 的所有其他可能策略 \( s_i \) 都成立。

其中，\( u_i \) 是参与者 *i* 的收益函数，\( s_{-i}^* \) 表示除 *i* 之外所有其他参与者的均衡策略。

在之前的“囚徒困境”例子中，策略组合（坦白，坦白）就是一个纳什均衡。因为给定对方选择“坦白”，自己选择“坦白”的收益是-5，选择“抵赖”的收益是-10，所以“坦白”是最优反应。双方都如此推理，没有人愿意单方面偏离“坦白”这个选择。
