## 核心概念与学习路径 🧭

上一节我们列出了课程的全部内容，本节中我们来看看如何系统地学习这些知识。以下是建议的学习路径和核心模块。

### 第一部分：基础与核心均衡（P1-P11）

这部分课程建立了博弈论的基础。我们从课程介绍和博弈论简介开始，理解博弈论研究什么。然后，我们引入**利己主义的代理人**和**效用理论**，这是分析决策者行为的基石。一个代理人的效用可以形式化为一个函数：`U_i(a)`，表示在行动组合 `a` 下参与者 `i` 获得的满足感。

接着，我们学习如何**定义游戏**，通常包括参与者集合、策略集合和收益函数。课程通过多个**游戏例子**（如囚徒困境）让概念具体化。

核心内容是**纳什均衡**。纳什均衡是指这样一种策略组合：在该组合下，任何参与者单方面改变自己的策略都不会获得更高的收益。用数学公式表达，对于策略组合 `s* = (s*_1, ..., s*_n)`，满足对所有参与者 `i` 和其任何其他策略 `s_i`，都有：
`U_i(s*_i, s*_{-i}) >= U_i(s_i, s*_{-i})`
课程详细讲解了**最佳对策**、**战略推理**，并通过例子加深理解。此外，还介绍了**占优策略**和评价结果好坏的**帕累托最优**标准。

### 第二部分：混合策略与求解复杂性（P12-P18）

在纯策略纳什均衡可能不存在的情况下，我们引入了**混合策略**，即参与者以一定概率随机选择不同的纯策略。参与者 `i` 的混合策略是一个概率分布 `σ_i`。

计算混合策略纳什均衡比纯策略更复杂。课程探讨了**计算纳什均衡的复杂性**，指出即使在两人零和博弈中，求解也是困难的，并介绍了 **“Hardness Beyond 2x2 Games”** 的相关内容。之后，通过**混合策略纳什均衡示例**（如猜硬币游戏）和**数据职业体育**中的实际应用，展示了混合策略的分析方法。

### 第三部分：均衡精炼与拓展形式（P19-P34）

纳什均衡可能有多个，我们需要更精确的预测工具。这部分介绍了**严格支配策略和迭代去除**，这是一种简化博弈、寻找均衡的方法。**最大最小策略**则是从最坏情况出发的保守决策准则，旨在最大化自己的最小可能收益：`max_{s_i} min_{s_{-i}} U_i(s_i, s_{-i})`。

接着，课程转向用树状图表示的**拓展形式博弈**。我们学习了**完美信息拓展形式**（如象棋）及其形式化表述。对于此类博弈，**逆向归纳法**是求解**子博弈完美纳什均衡**的关键方法。课程以**最后通牒博弈**为例进行了分析。

然后，课程进入**不完美信息拓展形式**（如扑克），参与者无法观察到对手的全部行动或“类型”。这引出了**信息集**的概念，并区分了**混合策略**与**行为策略**。最后，讨论了如何将子博弈完美的概念拓展到不完美信息博弈中。

### 第四部分：长期互动与不完全信息（P35-P47）

当博弈重复进行时，参与者可以考虑长远利益，从而可能产生合作结果。这部分研究**重复博弈**，包括有限次、无限次和**折扣重复博弈**（未来收益打折）。**民间定理**表明，在无限重复博弈中，许多看似“合作”的结果都可以成为均衡。

**随机博弈**将重复博弈的状态空间一般化。课程还探讨了重复博弈中的**学习形式**。

当参与者拥有私人信息时，我们进入**贝叶斯博弈**的领域。课程给出了贝叶斯博弈的两个定义，并详细讲解了如何进行分析，包括计算**贝叶斯纳什均衡**，并通过样例演示了完整过程。

### 第五部分：合作博弈论（P48-P52）

最后，我们转向**合作博弈**，关注参与者可以形成联盟并分配总收益的情况。合作博弈定义为 `(N, v)`，其中 `N` 是参与者集合，`v` 是特征函数，为每个联盟 `S ⊆ N` 分配一个值 `v(S)`。

核心问题是如何公平地分配总收益 `v(N)`。课程介绍了两种主要解概念：
1.  **夏普里值 (Shapley Value)**：基于参与者对联盟的边际贡献的平均值来分配，公式为：
    `φ_i(v) = Σ_{S ⊆ N\{i\}} (|S|! (|N|-|S|-1)! / |N|!) * [v(S∪{i}) - v(S)]`
2.  **核心 (The Core)**：指所有不会被任何子联盟
