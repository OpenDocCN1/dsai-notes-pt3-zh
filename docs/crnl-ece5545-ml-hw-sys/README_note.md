# 康奈尔大学 ECE5545 机器学习硬件系统笔记：1：概述与基础概念

在本节课中，我们将要学习机器学习硬件系统的基本概念，理解为什么需要专门的硬件来加速机器学习计算，并初步认识相关的性能度量指标。

机器学习，特别是深度学习，对计算能力的需求呈指数级增长。传统的通用处理器（CPU）在处理大规模矩阵乘法和卷积运算时效率低下。因此，设计专用的硬件加速器变得至关重要。

## 为什么需要机器学习硬件？

上一节我们介绍了课程的基本目标，本节中我们来看看驱动专用硬件发展的核心原因。主要原因有以下几点：

*   **计算密集性**：深度学习模型涉及大量的浮点运算，例如矩阵乘法 `Y = W * X + B`。
*   **数据密集性**：模型训练需要反复访问海量的权重参数和输入数据。
*   **能效比**：在移动设备和数据中心，功耗是关键的约束条件。专用硬件（如ASIC）的能效通常远高于CPU。
*   **延迟要求**：自动驾驶、实时翻译等应用对推理速度有严格的要求。

## 关键性能指标

理解了需求之后，我们需要一套标准来衡量硬件系统的优劣。以下是评估机器学习硬件时最常用的几个性能指标：

*   **吞吐量**：单位时间内完成的运算量或处理的任务数。常用 **TOPS** 表示。
*   **延迟**：从输入数据到产生输出结果所需的时间。
*   **能效**：每焦耳能量所能完成的运算量。常用 **TOPS/W** 表示。
*   **面积效率**：单位芯片面积所能提供的计算能力。

## 基础计算模式：矩阵乘法

大多数深度学习计算的核心可以归结为矩阵乘法。我们以一个全连接层为例，其公式为：

**`Y = X · W^T + B`**

其中：
*   `X` 是输入激活矩阵，维度为 `[batch_size, input_dim]`。
*   `W` 是权重矩阵，维度为 `[output_dim, input_dim]`。
*   `B` 是偏置向量，维度为 `[output_dim]`。
*   `Y` 是输出矩阵，维度为 `[batch_size, output_dim]`。

在硬件设计中，高效地实现这个操作是首要目标。
