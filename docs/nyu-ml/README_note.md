# 机器学习课程笔记 01：线性回归 🧠

在本节课中，我们将要学习机器学习中最基础且重要的算法之一：线性回归。我们将从核心概念入手，逐步理解其工作原理、数学表达以及实现方式。

---

## 概述

线性回归是一种用于建立输入变量（特征）与连续输出变量（目标）之间线性关系的监督学习算法。它的目标是找到一条最佳拟合直线（或超平面），使得预测值与真实值之间的误差最小。

上一节我们介绍了机器学习的基本概念，本节中我们来看看线性回归的具体构成。

---

## 模型表示

线性回归模型试图通过一个线性方程来预测目标值。给定一个包含 *n* 个特征的数据集，模型形式如下：

**公式：**
`hθ(x) = θ₀ + θ₁x₁ + θ₂x₂ + ... + θₙxₙ`

其中：
*   `hθ(x)` 是假设函数，即模型的预测值。
*   `θ₀` 是偏置项（截距）。
*   `θ₁, θ₂, ..., θₙ` 是模型参数（权重），分别对应每个特征 `x₁, x₂, ..., xₙ`。

这个方程定义了特征与预测目标之间的线性关系。

---

## 成本函数

为了找到最优的参数 `θ`，我们需要一个衡量模型预测好坏的标准。这个标准就是成本函数（或损失函数）。对于线性回归，最常用的是均方误差函数。

**公式：**
`J(θ) = (1/(2m)) * Σ (hθ(x⁽ⁱ⁾) - y⁽ⁱ⁾)²`

其中：
*   `m` 是训练样本的数量。
*   `hθ(x⁽ⁱ⁾)` 是模型对第 `i` 个样本的预测值。
*   `y⁽ⁱ⁾` 是第 `i` 个样本的真实值。
*   `Σ` 表示对所有训练样本（`i` 从 1 到 `m`）求和。

成本函数 `J(θ)` 的值越小，说明模型的预测越准确。我们的目标就是最小化这个函数。

理解了如何衡量误差后，接下来我们需要找到最小化这个误差的方法。

---

## 梯度下降算法

梯度下降是一种用于寻找成本函数最小值的优化算法。它通过迭代更新参数 `θ` 来实现。

**算法步骤（重复直到收敛）：**

**公式：**
`θⱼ := θⱼ - α * (∂/∂θⱼ) J(θ)`

对所有参数 `j = 0, 1, ..., n` 同时进行更新。

其中：
*   `:=` 表示赋值。
*   `α` 是学习率，控制每次更新的步长。
*   `(∂/∂θⱼ) J(θ)` 是成本函数 `J(θ)` 对参数 `θⱼ` 的偏导数（梯度）。

对于线性回归的均方误差成本函数，其偏导数的具体计算如下。

以下是梯度下降中偏导数的推导结果：

**公式：**
`(∂/∂θⱼ) J(θ) = (1/m) * Σ (hθ(x⁽ⁱ⁾) - y⁽ⁱ⁾) * xⱼ⁽ⁱ⁾`

将上述偏导数代入更新公式，就得到了专用于线性回归的梯度下降更新规则。

---

## 实践示例

为了更直观地理解，我们来看一个简单的代码框架。假设我们使用 Python 和 NumPy 库。

**代码：线性回归梯度下降核心步骤**
```python
import numpy as np

# 假设 X 是特征矩阵（添加了 x0=1 的列），y 是目标向量，theta 是参数向量
def gradient_descent(X, y, theta, alpha, num_iters):
    m = len(y)
    for _ in range(num_iters):
        # 计算预测值
        predictions = X.dot(theta)
        # 计算误差
        errors = predictions - y
        # 计算梯度
        gradient = (1/m) * X.T.dot(errors)
        # 更新参数
        theta = theta - alpha * gradient
    return theta
```

这段代码展示了梯度下降在每一步中如何计算预测、误差和梯度，并据此更新参数。
