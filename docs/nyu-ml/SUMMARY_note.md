# 课程01：机器学习入门与课程概览 📚

在本节课中，我们将学习机器学习的基本概念，并了解纽约大学这门课程的整体结构与学习资源。课程内容涵盖从理论讲解到实践练习的多个环节，旨在帮助初学者建立对机器学习的系统性认识。

## 课程概述

本课程由一系列讲座和实验课组成，内容覆盖机器学习的基础知识、核心算法及其应用。课程资料以视频笔记的形式呈现，方便学习者按顺序或按需学习。

以下是本课程包含的所有章节列表，每个章节对应一次特定的讲座或实验课：

*   **P1：1月27日讲座** - 课程介绍与机器学习基础概念。

*   **P4：2月4日实验** - 对应P3讲座内容的实践练习。
*   **P5：2月10日讲座 (YouTube)** - 通过YouTube平台讲解的内容。
*   **P6：2月11日实验** - 对应P5讲座内容的实践练习。
*   **P7：2月17日讲座** - 继续学习新的机器学习模型或方法。
*   **P8：2月18日实验** - 对应P7讲座内容的实践练习。
*   **P9：2月24日讲座** - 学习进阶主题。
*   **P10：2月25日实验** - 对应P9讲座内容的实践练习。
*   **P11：3月2日讲座** - 探讨机器学习中的关键算法。
*   **P12：3月9日讲座** - 学习模型评估与选择。

## 学习建议

对于初学者，建议按照章节编号顺序进行学习，因为知识结构通常是递进的。理论讲座（Lec/Lecture）与实验课（Lab）相辅相成，建议在听完讲座后及时完成对应的实验，以巩固理论知识并提升实践能力。

核心的机器学习概念，例如**损失函数**、**梯度下降**或**神经网络的前向传播**，在教程中会使用**公式**或**代码块**进行明确描述。例如，均方误差损失函数的公式可能表示为：

**MSE = (1/n) * Σ(y_i - ŷ_i)^2**

一个简单的线性回归预测代码可能如下所示：
```python
def predict(x, w, b):
    return w * x + b
```
