上一节我们介绍了函数的基本结构，本节中我们来看看如何为函数参数设置默认值。

![](img/66d54415f3f25791d3fdaac49df10237_17.png)

一个函数可以有多个参数，其中部分参数可以预先设定默认值。在定义函数时，需要同时指定参数名称以及它们是否拥有默认值。

![](img/66d54415f3f25791d3fdaac49df10237_19.png)

![](img/66d54415f3f25791d3fdaac49df10237_20.png)

![](img/66d54415f3f25791d3fdaac49df10237_21.png)

以下是一个包含四个参数的函数示例：
```r
my_function <- function(a, b = 1, c = NULL, d = TRUE) {
  # 函数体
}
```
在这个例子中：
*   **`a`** 没有默认值，调用时必须提供。
*   **`b`** 的默认值是 `1`。
*   **`c`** 的默认值是 `NULL`。`NULL` 是一个常用值，通常表示“空”或“无内容”。
*   **`d`** 的默认值是 `TRUE`。

## 惰性求值 ⏳

![](img/66d54415f3f25791d3fdaac49df10237_31.png)

![](img/66d54415f3f25791d3fdaac49df10237_32.png)

R语言的一个关键特性是**惰性求值**。这意味着函数的参数只有在函数体内真正被用到时，才会被计算求值。

让我们通过一个简单的例子来理解这个概念：
```r
f <- function(a, b) {
  a^2
}
```
这个函数 `f` 接受两个参数 `a` 和 `b`，但函数体只使用了 `a`（计算其平方）。当我们调用 `f(2)` 时，会发生以下情况：
1.  数值 `2` 被位置匹配到参数 `a`。
2.  函数计算 `2^2`，得到结果 `4`。
3.  参数 `b` 在整个过程中**从未被使用**，因此R语言也**从未尝试去计算或检查它的值**，即使它没有默认值，也不会引发错误。

![](img/66d54415f3f25791d3fdaac49df10237_34.png)

![](img/66d54415f3f25791d3fdaac49df10237_35.png)

![](img/66d54415f3f25791d3fdaac49df10237_36.png)

![](img/66d54415f3f25791d3fdaac49df10237_37.png)

![](img/66d54415f3f25791d3fdaac49df10237_38.png)

![](img/66d54415f3f25791d3fdaac49df10237_39.png)

惰性求值的影响在错误处理中更为明显。请看另一个例子：
```r
f <- function(a, b) {
  print(a)
  print(b)
}
```
当我们调用 `f(45)` 时：
1.  数值 `45` 被匹配给 `a`。
2.  第一行 `print(a)` 成功执行，输出 `45`。
3.  执行到第二行 `print(b)` 时，R发现参数 `b` 没有被赋值且没有默认值，此时才会抛出错误：“argument ‘b’ is missing”。
这个例子说明，错误只会在真正需要评估那个缺失的参数时才发生。

## 特殊参数 `...`（点点点） 🔄

R函数中有一个特殊的参数 `...`（读作“点点点”），它用于传递**可变数量的参数**。这在两种主要场景下非常有用。

当你想要基于一个现有函数创建新函数，但又不想重复其冗长的参数列表时，可以使用 `...`。

![](img/66d54415f3f25791d3fdaac49df10237_57.png)

例如，你想创建一个自定义绘图函数 `myplot`，它改变基础 `plot` 函数中 `type` 参数的默认值，但保留其他所有参数选项：
```r
myplot <- function(x, y, type = "l", ...) {
  plot(x, y, type = type, ...)
}
```
在这个函数中：
*   `x`, `y` 和 `type` 被显式定义，且 `type` 的默认值被改为 `"l"`（折线图）。
*   `...` 参数“吸收”了调用 `myplot` 时传入的所有其他参数。
*   在函数体内，`...` 被原封不动地传递给原始的 `plot` 函数，从而保留了所有原始功能。

### 场景二：处理未知数量的参数

![](img/66d54415f3f25791d3fdaac49df10237_65.png)

当函数需要处理的参数数量在事先无法确定时，`...` 是必需的。`paste` 和 `cat` 函数就是典型的例子。

以下是 `paste` 函数的基本用法：
```r
# paste 函数用于连接字符串
paste("Hello", "World", sep = "-") # 输出: "Hello-World"
paste("A", "B", "C") # 输出: "A B C"
```
`paste` 可以接受任意数量的字符串进行连接，其第一个参数就是 `...`。

### 使用 `...` 的注意事项

![](img/66d54415f3f25791d3fdaac49df10237_76.png)

![](img/66d54415f3f25791d3fdaac49df10237_77.png)

![](img/66d54415f3f25791d3fdaac49df10237_78.png)

**位于 `...` 之后的参数必须显式地、完整地命名，不能使用位置匹配或部分匹配。**

![](img/66d54415f3f25791d3fdaac49df10237_80.png)

![](img/66d54415f3f25791d3fdaac49df10237_81.png)

![](img/66d54415f3f25791d3fdaac49df10237_82.png)

![](img/66d54415f3f25791d3fdaac49df10237_83.png)

![](img/66d54415f3f25791d3fdaac49df10237_84.png)

请看以下错误示例：
```r
# 意图：用冒号连接"A"和"B"
paste("A", "B", sep = ":") # 正确，输出 "A:B"

# 错误：试图对 `sep` 使用部分匹配 ‘se‘
paste("A", "B", se = ":") # 错误！输出 "A B :"
```
在错误的调用中，`se` 没有被识别为 `sep` 的部分匹配。因为 `sep` 参数位于 `...` 之后，R要求完全匹配。因此，`se = ":"` 被当作另一个要连接的字符串处理，最终得到了意料之外的结果 `"A B :"`。

本节课中我们一起学习了R语言函数的三个高级特性：
1.  **参数默认值**：允许为函数参数预设值，使函数调用更灵活。
2.  **惰性求值**：函数参数只在被需要时才计算，这影响了函数的执行流程和错误触发时机。
3.  **特殊参数 `...`**：用于处理可变数量参数，常见于扩展函数或参数数量未知的场景。使用时需注意，`...` 之后的参数必须完整命名。
