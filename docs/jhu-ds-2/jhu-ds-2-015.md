# 015：14_数据类型 数据框 📊

![](img/7b88c06ad485b826b9d53b8650c36929_0.png)

在本节课中，我们将要学习R语言中一个至关重要的数据类型——**数据框**。数据框是存储表格数据的主要形式，在统计分析和数据处理中应用极为广泛。

上一节我们介绍了列表，本节中我们来看看数据框。数据框本质上是一种特殊的列表，其中列表的**每一个元素长度必须相同**。你可以将数据框的每一列视为列表的一个元素。为了构成一个表格，每一列自然需要有相同的行数。

然而，与矩阵不同，数据框的**每一列可以是不同的数据类型**。例如，第一列可以是数值型，第二列可以是因子型，第三列可以是整型，第四列可以是逻辑型。这种灵活性使得数据框非常适合存储现实世界中复杂的混合类型数据。

数据框拥有一些特殊的属性。第一个特殊属性是**行名**。数据框的每一行都可以有一个名称，这常用于标注数据。例如，每一行可能代表研究中的一个受试者，行名就可以是其ID。但有时行名并不重要，系统会默认使用1、2、3等数字作为行名。

以下是创建数据框的几种常见方式：
*   最常用的方法是使用 `read.table()` 或 `read.csv()` 函数从外部文件读取数据。
*   你也可以使用 `data.frame()` 函数直接创建。

例如，我们可以用 `data.frame()` 创建一个简单的数据框：

```r
x <- data.frame(foo = 1:4, bar = c(T, T, F, F))
```

在这个例子中，我们创建了一个名为 `x` 的数据框。第一列名为 `foo`，是一个从1到4的整数序列；第二列名为 `bar`，是一个包含两个TRUE和两个FALSE的逻辑向量。

当我们打印这个数据框时，它会以整洁的表格形式显示两列数据。由于我们没有指定行名，系统默认使用1、2、3、4作为行名。使用 `nrow(x)` 可以查看行数（4行），`ncol(x)` 可以查看列数（2列）。

需要注意的是，虽然可以使用 `data.matrix()` 函数将数据框转换为矩阵，但如果数据框中包含多种数据类型，强制转换可能会导致所有元素被统一为同一种类型（通常是字符型），结果可能并非如你所愿。

本节课中我们一起学习了R语言的核心数据结构——**数据框**。我们了解到数据框是存储表格数据的利器，它允许各列拥有不同的数据类型，并通过 `data.frame()` 函数或读取外部文件来创建。理解数据框是掌握R语言进行数据分析的关键一步。
