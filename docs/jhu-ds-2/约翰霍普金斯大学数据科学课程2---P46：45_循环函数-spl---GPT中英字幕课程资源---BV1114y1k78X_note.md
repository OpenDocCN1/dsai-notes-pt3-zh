# 课程2：《R编程》｜P46：split函数详解 🧩

在本节课中，我们将要学习R语言中一个非常实用的函数：`split`。虽然它本身不属于循环函数家族（如`lapply`），但它常与这些函数结合使用，用于将数据对象按组拆分，以便后续进行分组计算。

## split函数的基本原理 ⚙️

![](img/7044923c9cfa237c4cff81d4f3576895_15.png)

`split`函数接收一个向量或对象`x`，以及一个因子变量`f`。这个因子变量用于标识分组水平。然后，`split`函数将对象`x`分割成因子`f`所标识的若干组。

例如，如果`f`有三个水平，标识了三个组，那么`split`函数就会将`x`分割成三个组。

![](img/7044923c9cfa237c4cff81d4f3576895_17.png)

![](img/7044923c9cfa237c4cff81d4f3576895_18.png)

![](img/7044923c9cfa237c4cff81d4f3576895_19.png)

![](img/7044923c9cfa237c4cff81d4f3576895_20.png)

![](img/7044923c9cfa237c4cff81d4f3576895_21.png)

一旦你将数据分组拆开，就可以使用`lapply`或`sapply`等函数，对每个独立的组应用特定的函数。

![](img/7044923c9cfa237c4cff81d4f3576895_22.png)

![](img/7044923c9cfa237c4cff81d4f3576895_23.png)

## split函数的优势：处理复杂对象 🗃️

`split`函数的一个优点是，它可以用来拆分更复杂类型的对象。

例如，这里我有一个数据框。我加载了`datasets`包，并查看其中的`airquality`数据框。这是该数据框的前六行，总共有大约一百多行。数据框中包含臭氧、太阳辐射、风速和温度的测量值，以及月份和该月内的日期。

![](img/7044923c9cfa237c4cff81d4f3576895_50.png)

![](img/7044923c9cfa237c4cff81d4f3576895_51.png)

![](img/7044923c9cfa237c4cff81d4f3576895_52.png)

我可能想做的一件事是，计算每个月内臭氧、太阳辐射、风速和温度的平均值。每个月大约有30多个观测值，我想计算每个月的平均值。

![](img/7044923c9cfa237c4cff81d4f3576895_53.png)

![](img/7044923c9cfa237c4cff81d4f3576895_54.png)

我该怎么做呢？我希望将数据框按月拆分成多个部分。一旦将数据框按月份拆分开，我就可以使用`apply`或`colMeans`来计算各列的均值。

以下是我所做的：我根据`month`变量（月份变量）拆分`airquality`数据框。严格来说，数据框中的`month`变量不是一个因子变量，但它可以转换为因子变量，因为它只取值5、6、7、8、9，因为测量只在一年中较温暖的月份进行。

在这里，我根据`month`变量拆分了`airquality`数据框。

![](img/7044923c9cfa237c4cff81d4f3576895_57.png)

## 使用sapply简化结果并处理缺失值 🧹

![](img/7044923c9cfa237c4cff81d4f3576895_68.png)

![](img/7044923c9cfa237c4cff81d4f3576895_69.png)

在修复缺失值问题之前，我也可以在这里调用`sapply`。`sapply`不会返回列表，而是会简化结果。因为返回列表的每个元素都是一个长度为3的向量，它们长度相同，所以`sapply`会将这些数字放入一个矩阵中，矩阵有3行（对应三个变量）和5列（对应五个月份）。

我需要做的是，在计算均值之前，将`na.rm`参数传递给`colMeans`函数，这将从每列中移除缺失值。

现在，当我对拆分后的列表调用`sapply`时，我可以得到五个月中每个变量的观测值的均值。

## 基于多个因子进行拆分 🔀

最后我想讨论的是基于多个水平进行拆分。在过去的几个例子中，我只有一个因子变量，并根据该单个因子的水平拆分对象（无论是向量还是数据框）。但你可能拥有多个因子。

例如，你可能有一个表示性别的变量（男/女），以及另一个表示种族的变量。你可能希望查看这些因子内部水平的组合。

这里我有`f1`，它是一个有两个水平的因子。我模拟了一个有10个观测值的正态随机变量。我有一个有两个水平的因子，每个水平重复五次。然后我有另一个有五个水平的因子，每个水平重复两次。这些是我的两个分组变量。

我想查看这两个因子的组合。我可以使用`interaction`函数将第一个因子的所有水平与第二个因子的所有水平组合起来。

因为第一个因子有2个水平，第二个因子有5个水平，当两者组合时，总共有10个不同的水平组合。

当我调用`interaction`函数时，我得到了另一个因子，它连接了两个因子的水平。你可以看到它打印出总共有10个水平。

![](img/7044923c9cfa237c4cff81d4f3576895_98.png)

![](img/7044923c9cfa237c4cff81d4f3576895_99.png)

现在，我可以根据这两个不同的水平拆分我的数值向量`x`。

![](img/7044923c9cfa237c4cff81d4f3576895_101.png)

使用`split`函数时，我不必使用`interaction`函数。我可以直接传入一个包含这两个因子的列表，它会自动为我调用`interaction`函数，创建那个10水平的交互因子。

我可以直接传递这两个因子的列表。你可以看到它返回一个列表，包含10个不同交互因子水平的水平，以及属于那些水平的数值向量元素。

当然，虽然两个因子之间有10个水平，但我们并没有观察到每一种组合，所以这里有一些空水平。你可以看到有些水平里面什么都没有（零个元素），而其他水平则有数值。

![](img/7044923c9cfa237c4cff81d4f3576895_103.png)

![](img/7044923c9cfa237c4cff81d4f3576895_104.png)

![](img/7044923c9cfa237c4cff81d4f3576895_105.png)

![](img/7044923c9cfa237c4cff81d4f3576895_107.png)

有时，不保留这些空水平会比较方便。`split`函数有一个参数叫`drop`。如果你指定`drop = TRUE`，它将删除由拆分创建的空水平。

![](img/7044923c9cfa237c4cff81d4f3576895_108.png)

![](img/7044923c9cfa237c4cff81d4f3576895_109.png)

![](img/7044923c9cfa237c4cff81d4f3576895_110.png)

![](img/7044923c9cfa237c4cff81d4f3576895_111.png)

![](img/7044923c9cfa237c4cff81d4f3576895_112.png)

当你组合多个不同的因子时，这非常方便。如果你只使用单个因子，那么这个参数作用不大，因为你使用了所有水平。但如果你有多个因子，通常你会有空水平，因为你没有观察到两个因子的每一种组合。

![](img/7044923c9cfa237c4cff81d4f3576895_113.png)

`drop = TRUE`会删除那些空水平，然后返回的列表将只包含有观测值的水平。

## 总结 📝

本节课中，我们一起学习了`split`函数。我们了解到：

![](img/7044923c9cfa237c4cff81d4f3576895_116.png)

![](img/7044923c9cfa237c4cff81d4f3576895_117.png)

1.  `split`函数用于根据一个或多个因子变量，将向量、数据框等对象拆分成组。
2.  它总是返回一个列表，列表的每个元素对应一个分组的数据子集。
3.  `split`常与`lapply`、`sapply`等循环函数结合使用，实现对每个分组进行独立计算。
4.  通过`drop = TRUE`参数，可以移除拆分后产生的空分组（当基于多个因子拆分时尤其有用）。
5.  `split`函数功能强大，不仅可以拆分向量，还可以拆分数据框等复杂数据结构，是进行分组数据分析的重要工具。
