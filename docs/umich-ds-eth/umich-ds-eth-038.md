# 38：案例分析：高通量生物学研究

![](img/c1aeb5909b9f5bb23d736c37cf4033ef_0.png)

在本节课中，我们将探讨高通量生物学研究这一现代生物技术，并分析其背后可能存在的统计陷阱与伦理考量。

## 🧬 传统生物学与高通量生物学

上一节我们讨论了数据科学的一般伦理问题，本节中我们来看看一个具体的生物信息学案例。

传统上，生物学家在实验台前工作，研究单个感兴趣的生物实体。如今，我们有了被称为高通量生物学的研究方法。其运作方式是，在一张基因芯片上，可以容纳数千个基因。所有这些基因可以同时被测量。

## 🔬 高通量实验的基本流程

以下是高通量生物学实验的一个典型步骤：

1.  采集少量某种类型的组织样本，例如健康组织。
2.  采集少量另一种类型的组织样本，例如病变组织。
3.  测量每个样本中每个基因的表达水平。

通过比较两种组织中基因的表达水平，你可以寻找那些在健康组织和病变组织之间表达水平存在显著差异的基因。这些基因可能与疾病过程有关，从而可以进行更深入的研究。

这类高通量生物学方法在为我们提供许多我们之前不了解的疾病过程的线索方面，已被证明极为有效。

## 📊 统计视角下的挑战

然而，从统计学的角度来看，有一些问题值得我们思考。当你想要比较来自两个群体的样本时，通常的做法是进行**P检验**。

假设你设定**P值**为0.05。这意味着，你所看到的两个群体间表达水平的差异，有95%的可能性不是偶然造成的，只有5%的概率是偶然造成的。这个结论对于任何一个单独的基因（就我们刚才讨论的P值而言）都是成立的。

![](img/c1aeb5909b9f5bb23d736c37cf4033ef_2.png)

但现在，我们对25，000个基因进行这种检验。

![](img/c1aeb5909b9f5bb23d736c37cf4033ef_4.png)

## ⚠️ 多重检验问题

以下是理解多重检验问题的关键逻辑：

*   如果对于任何一个单一基因，我们看到差异纯粹由于偶然的概率是5%。
*   那么，当你观察20个基因时，平均而言，其中**1个**基因的差异将纯粹由于偶然。
*   如果你观察20，000个基因，平均而言，其中**1，000个**基因的表达差异将纯粹由于偶然。

实际参与疾病过程的基因可能只有几十个。因此，我们可能只有几十个感兴趣的基因，其表达水平不同是由于真实的生物学差异。但同时，可能还有几百甚至上千个基因，其表达水平的差异纯粹是由于偶然。

![](img/c1aeb5909b9f5bb23d736c37cf4033ef_6.png)

换句话说，你得到了一些信息，但也掺杂了大量的噪声。如何将信息从噪声中分离出来，需要进行谨慎的下游分析，而不是简单地因为某些结果符合P值标准，就将其视为绝对真理。

## 📝 总结

本节课中，我们一起学习了高通量生物学的研究方法及其巨大的潜力。更重要的是，我们分析了其中存在的**多重检验问题**：当同时对海量基因进行统计检验时，会不可避免地产生大量假阳性结果。这提醒我们，在面对大规模数据分析结果时，必须保持批判性思维，理解其统计局限性，并依赖更严谨的分析方法来去伪存真，而不能仅仅依赖单一的显著性阈值（如P值）就做出结论。
