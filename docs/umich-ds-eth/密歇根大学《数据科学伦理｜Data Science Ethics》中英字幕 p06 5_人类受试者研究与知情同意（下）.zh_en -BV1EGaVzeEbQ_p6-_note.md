## 传统实验的数据收集流程

上一节我们介绍了知情同意的基本原则，本节中我们来看看传统人类受试者研究的具体操作流程。

在传统的人类受试者实验中，采用的是**前瞻性数据收集**方式。这意味着研究者首先设计实验，然后从该实验中收集数据。

以下是其标准流程：

1.  **IRB审查与批准**：任何涉及人类受试者的研究，无论是医学还是社会科学研究，都必须首先获得机构审查委员会的批准。
2.  **执行实验与收集数据**：在获得批准后，研究者才能开始进行实验并收集数据。

这个过程由美国联邦法律强制执行，适用于所有政府资助的实验。值得注意的是，此流程不仅适用于医学和社会科学实验，也适用于计算机科学实验。例如，如果要对一个新的网页程序用户界面进行用户研究，只要它是一项**研究**，就需要经过IRB审查。

## 商业实践中的例外情况

然而，法律中存在一个非常重要的例外条款。这一例外反映了社会价值观的共识：IRB审查仅针对**研究**活动，而不适用于**常规商业行为**。

这意味着什么？以网络公司为例，它们普遍进行一种称为 **A/B测试** 的实验。公司会将一部分网站访问者分组，向A组展示设计版本A，向B组展示设计版本B，然后观察并比较两组用户的行为数据。

```python
# 简化的A/B测试逻辑示意
if group == 'A':
    show_design_version_A()
elif group == 'B':
    show_design_version_B()

track_user_behavior(group)  # 追踪点击率、转化率等
compare_results('A', 'B')   # 比较哪个版本效果更好
```

信息技术行业的公司频繁进行此类测试。像谷歌这样的大公司，据说在任何时刻都同时进行着数百项A/B测试。这显然影响了用户，也无疑是一种实验（因为公司事先并不知道A组和B组哪个表现更好）。然而，这并不被视为“人类受试者研究”，因为公司的目的是在A和B这两个它认为都合理的选项中选择最优解，以最大化其商业目标（如点击率、收入）。公司通常不会展示一个预期效果很差的版本。

同样，公司利用心理学线索影响用户行为（例如促使购买或点击），或使用存在缺陷的算法，都被视为常规的商业实践和“尽力而为”的努力。只要这些行为属于日常运营范畴，就不会引发人类受试者研究相关的问题。

## 案例研究：Facebook情绪传染实验

与上述常规商业行为形成对比的，是2012年Facebook与康奈尔大学研究人员进行的一项实验。

在该实验中，研究团队操纵了部分Facebook用户的新闻推送内容：向一些用户展示更多积极正面的文章，而向另一些用户展示更多消极、令人失望或悲伤的文章。他们发现，看到更多积极内容的用户，自己在Facebook上发布的内容也更积极；反之亦然。这证明了“情绪传染”现象的存在。相关论文于2014年发表在《美国国家科学院院刊》上。

问题在于，参与实验的用户并不知道自己的信息流被为了研究目的而刻意操纵。虽然用户知道Facebook会定期调整推送算法，也明白自己看到的内容是Facebook认为“对他们好”的内容，但他们不知道，这些“好”内容可能因这项研究而被特意操控。

实验结果公开后，Facebook受到了广泛的舆论批评。这一事件的核心启示在于：**公司不应在研究中对用户故意撒谎**，即使其行为效果可能与一次普通的、效果不佳的商业操作相差无几。

## 社会共识的形成

另一个案例是婚恋网站OkCupid，它曾进行实验，向用户报告与算法实际计算不符的“匹配度”分数。其CEO克里斯蒂安·鲁德尔曾发文支持Facebook的做法，称“我们在人类身上做实验”。

从这些例子中我们学到，当新技术（如大规模的网络人类受试者实验）成为可能时，社会需要逐步摸索并形成关于“何为恰当行为”的共识。

显然，像克里斯蒂安·鲁德尔这样的人在当时认为自己的行为是恰当的。但时至今日，一个良好的社会共识已经形成：**公司不应进行这类研究**，即使法律可能允许。我们在伦理上已达成共识：公司在进行研究时对我们撒谎是不对的。

## 总结

本节课中我们一起学习了人类受试者研究在传统学术环境与商业实践中的不同适用标准。我们了解到，常规商业行为（如A/B测试）通常不受严格的研究伦理审查约束，但一旦以“研究”为目的并涉及对用户的欺骗性操纵，就会引发严重的伦理问题。通过Facebook和OkCupid的案例，我们看到社会伦理共识是如何随着技术实践的发展而逐步形成和演变的，其核心原则是维护用户的信任与知情权。
