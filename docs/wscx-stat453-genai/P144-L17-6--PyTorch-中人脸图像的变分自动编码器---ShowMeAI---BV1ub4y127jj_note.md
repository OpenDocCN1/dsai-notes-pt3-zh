## 🏗️ 模型架构

现在，让我们来看看针对人脸图像设计的变分自动编码器模型架构。其核心思想与 MNIST 示例相同，但规模更大、更复杂。

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_21.png)

主要区别如下：
*   **输入**：图像具有三个颜色通道（RGB）。
*   **潜在表示**：维度为 **200**，远高于 MNIST 示例的 2 维，以编码更复杂的人脸信息。
*   **网络结构**：更深、更宽，并引入了**批归一化**和 **Dropout** 层以提高性能和泛化能力。

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_23.png)

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_25.png)

模型同样由编码器和解码器两部分构成。编码器将输入图像映射为潜在空间中的均值（μ）和对数方差（log σ²），解码器则从潜在变量 **z** 重建图像。

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_27.png)

**核心采样公式**：
`z = μ + σ * ε`，其中 `ε ~ N(0, I)`

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_29.png)

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_31.png)

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_32.png)

损失函数依然是重构损失和 KL 散度的组合。

## 🔧 代码实现与训练

以下是模型实现和训练过程的关键步骤。

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_38.png)

首先，我们定义数据加载器，应用中心裁剪和归一化变换。

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_40.png)

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_42.png)

接着，我们定义变分自动编码器类。编码器部分由多个卷积层、批归一化层和 Dropout 层组成，最终输出 200 维的 μ 和 log σ²。解码器部分则通过转置卷积或上采样操作，将潜在变量 **z** 重建为原始图像尺寸。

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_44.png)

**训练循环代码框架**：
```python
for epoch in range(num_epochs):
    for batch_idx, (data, _) in enumerate(train_loader):
        # 前向传播，计算 mu, log_var, 重建图像
        recon_batch, mu, log_var = model(data)
        # 计算损失（重构损失 + KL散度）
        loss = loss_function(recon_batch, data, mu, log_var)
        # 反向传播与优化
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_46.png)

训练过程耗时较长（在 GPU 上约 1.5 小时）。损失曲线显示模型已基本收敛。

训练完成后，我们保存模型以供后续分析使用。

## 🧮 潜在空间分析

由于潜在空间是 200 维的，我们无法像二维那样直接可视化散点图。因此，我们采用直方图来分析潜在空间的分布。

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_56.png)

![](img/6ca75c4f6fe23dfeb48a60913c3d98b8_58.png)

我们加载训练好的模型，对 10000 张测试图像进行编码，得到它们的潜在表示。然后，我们绘制潜在空间前 25 个维度的值分布直方图。

分析显示，每个潜在维度的值大致服从均值为 0、方差为 1 的标准正态分布。这表明模型成功地将数据分布约束在了我们期望的先验分布上。
