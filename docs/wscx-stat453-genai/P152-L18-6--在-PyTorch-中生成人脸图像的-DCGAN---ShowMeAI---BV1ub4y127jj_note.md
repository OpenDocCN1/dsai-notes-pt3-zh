## 🏗️ DCGAN 模型架构

与之前基于 MNIST 的全连接 GAN 相比，核心区别在于我们使用了卷积层。让我们逐步了解生成器和判别器的结构。

### 生成器 (Generator)

生成器的目标是将一个 100 维的噪声向量 `z` 上采样为一张 64x64 的 RGB 图像。其结构主要由转置卷积层（Transposed Convolutional Layers）构成。

以下是生成器的关键层序列：
1.  输入：100 维噪声向量。
2.  通过多个转置卷积层进行上采样。
3.  每层后接批归一化（BatchNorm）和 LeakyReLU 激活函数。
4.  最后一层使用 `Tanh` 激活函数，将像素值范围约束在 **[-1, 1]**。

![](img/ee921d44bc17001fe894df15e01e9953_19.png)

![](img/ee921d44bc17001fe894df15e01e9953_21.png)

代码结构示意如下：
```python
self.main = nn.Sequential(
    # 将 100 维噪声上采样
    nn.ConvTranspose2d(100, 512, 4, 1, 0, bias=False),
    nn.BatchNorm2d(512),
    nn.ReLU(True),
    # ... 更多上采样层 ...
    # 输出 64x64x3 图像
    nn.ConvTranspose2d(64, 3, 4, 2, 1, bias=False),
    nn.Tanh()
)
```

![](img/ee921d44bc17001fe894df15e01e9953_23.png)

### 判别器 (Discriminator)

判别器是一个卷积神经网络，用于判断输入图像是真实的还是生成的。它不使用全连接层，而是通过卷积将特征图尺寸最终降至 1x1。

以下是判别器的设计思路：
1.  输入：64x64x3 图像。
2.  通过多个卷积层进行下采样（使用步幅为2的卷积代替池化层）。
3.  每层后接批归一化和 LeakyReLU。
4.  最后一层卷积将通道数变为 1，特征图尺寸变为 1x1。
5.  使用 `Flatten` 操作将其变为单个值，并通过 Sigmoid 函数输出为真实图像的概率。

其最后一层的转换可以表示为：
**输出 = Sigmoid( Conv( 特征图 ) )**
其中，卷积核大小设置为 4，恰好将 4x4 的特征图转换为 1x1。

![](img/ee921d44bc17001fe894df15e01e9953_29.png)

训练函数的主体结构与之前的 GAN 类似，但针对图像数据进行了适配。我们使用 Adam 优化器，并设置合适的学习率。

以下是训练循环的核心步骤：
1.  使用真实图像训练判别器，最大化其对真实图像的判断准确率。
2.  使用生成器产生的假图像训练判别器，最大化其识别假图像的能力。
3.  训练生成器，以生成能“欺骗”判别器的图像，即最小化判别器对假图像的判断准确率。

![](img/ee921d44bc17001fe894df15e01e9953_35.png)

一个值得讨论的细节是噪声向量的采样。在代码中，同一批噪声既用于为判别器生成假图像，又用于训练生成器。理论上，为这两步使用不同的、新鲜的噪声批次可能是一个值得尝试的技巧，或许能带来更稳定的训练，但这需要进一步的实验验证。

在实验过程中，当使用常规 ReLU 激活函数代替 LeakyReLU 时，训练出现了问题。

![](img/ee921d44bc17001fe894df15e01e9953_61.png)

![](img/ee921d44bc17001fe894df15e01e9953_63.png)

以下是失败案例的表现：
1.  损失曲线出现巨大尖峰。

2.  生成器发生**模式崩溃（Mode Collapse）**，所有生成的图像都高度相似，失去了多样性。
