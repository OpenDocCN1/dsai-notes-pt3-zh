## 🎨 StyleGAN：风格化生成对抗网络

上一节我们深入讨论了生成模型和GAN。本节中，我们来看看一个非常前沿且流行的GAN变体——StyleGAN。

StyleGAN在传统渐进式增长GAN的基础上进行了改进。传统GAN的生成器接收一个潜在向量 **Z**，并通过一系列上采样卷积层生成图像。然而，这种方式对生成内容的控制力较弱。

StyleGAN的核心思想是引入一个**映射网络**和一个**合成网络**。映射网络由全连接层组成，负责将潜在向量 **Z** 映射为一系列**风格向量**。合成网络则基于渐进式增长的架构，但在不同分辨率层上，会注入这些风格向量和额外的**噪声向量**。

以下是其核心流程的简化表示：

```python
# 伪代码示意
z = random_latent_vector()
# 映射网络
w = mapping_network(z)
# 合成网络
image = synthesis_network(w, noise_vectors)
```

通过这种方式，不同分辨率的风格向量可以分别控制图像的结构、中等细节和精细细节，实现了对生成图像的多分辨率风格控制。

## 🔄 自回归模型：另一种生成范式

除了GAN，自回归模型是另一种强大的生成模型范式。与GAN隐式学习数据分布不同，自回归模型显式地对数据分布进行建模，通常通过序列预测下一个数据点（如像素）的概率来实现。

以下是自回归模型的核心概念：

![](img/5e82fa7faa43312461dac4d2e5900323_3.png)

**公式**：对于一个图像，其联合概率可以分解为一系列条件概率的乘积：
`P(image) = P(pixel_1) * P(pixel_2 | pixel_1) * P(pixel_3 | pixel_1, pixel_2) * ...`

这种方法训练更稳定，但序列长度（图像像素数）会导致计算成本高昂。

---

### PixelRNN 与 PixelCNN

为了解决RNN序列过长的问题，研究者提出了PixelCNN。

PixelCNN使用带掩码的卷积层来确保每个像素的预测仅依赖于之前的像素。它通过以下方式工作：

1.  **掩码卷积**：在卷积核中，将“未来”像素和当前像素的权重置零。
2.  **门控块**：使用包含 `tanh` 和 `sigmoid` 激活函数的门控机制，以提升模型表现，类似于LSTM单元。

一个关键的改进是使用**垂直栈**和**水平栈**卷积来消除“盲点”，确保所有先前的上下文信息都能被利用。

自回归模型的优势在于训练稳定，且能应用于离散和连续数据。近年来，如VQ-VAE-2等模型已经能生成非常高质量和高分辨率的图像。

## 🎥 从图像到视频生成

![](img/5e82fa7faa43312461dac4d2e5900323_7.png)

将生成模型从图像扩展到视频面临巨大挑战，因为视频具有极高的维度且需要保持时间一致性。

### 无条件视频生成的挑战

无条件视频生成（从随机向量生成整个视频）主要有两种思路，但都存在严重问题：

1.  **单一潜在向量**：一个向量 **Z** 决定整个视频。这导致未来帧完全由过去帧决定，缺乏多样性，容易产生重复或静止的画面。
2.  **每帧独立潜在向量**：每一帧都有自己的随机向量 **Z_t**。这虽然引入了多样性，但难以在训练中建立帧与帧之间、以及潜在向量之间的相关性，容易导致画面闪烁和不连贯。

![](img/5e82fa7faa43312461dac4d2e5900323_9.png)

核心挑战在于**时间一致性**和**长期漂移**（模型逐渐偏离合理状态，收敛到平均帧）。

![](img/5e82fa7faa43312461dac4d2e5900323_11.png)

### 条件视频生成：更可行的路径

相比于无条件生成，条件视频生成将问题简化为“根据给定的条件序列（如语义分割图、姿态骨架）生成逼真视频”。这大大降低了难度。

一个代表性的工作是**Vid2Vid**（视频到视频合成）。它的关键思想包括：

*   **序列生成器**：基于过去L帧生成图像和条件来预测下一帧。
*   **双判别器**：
    *   图像判别器：判断单帧是否真实。
    *   时间判别器：判断帧序列的光流是否平滑、时间上是否一致。

其损失函数结合了这两部分：
`总损失 = L_图像判别器 + λ * L_时间判别器`

这种方法能生成高质量、时间连贯的视频。

### 实践案例：人脸与人体视频重演

![](img/5e82fa7faa43312461dac4d2e5900323_32.png)

条件生成的思想在具体应用中非常有效。

![](img/5e82fa7faa43312461dac4d2e5900323_34.png)

**视频肖像（Video Portraits）** 和 **Everybody Dance Now** 是两个典型案例。它们的流程相似：

1.  **分析**：对源视频（提供动作）和目标视频（提供外观）进行分析，提取控制信号（如3D人脸模型参数、2D人体姿态骨架）。
2.  **重定向**：将源视频的控制信号应用于目标人物的模型上。
3.  **合成**：训练一个图像到图像的转换网络（如Pix2Pix），将重定向后的控制信号（如渲染的3D人脸网格、姿态图）转换为目标人物逼真的视频帧。

这种方法的核心优势在于：
*   **锚定作用**：准确且时间一致的控制信号为生成提供了稳定的锚点，有效避免了漂移问题。
*   **小数据过拟合**：网络只需在单个人的少量视频数据上训练，就能取得很好效果，更像一个针对特定内容的优化器。
*   **可控性**：通过编辑控制信号（如改变姿态、表情），可以精确控制生成内容。

## 📝 总结

![](img/5e82fa7faa43312461dac4d2e5900323_40.png)

本节课中我们一起学习了：
1.  **StyleGAN** 通过分离风格与噪声，实现了对生成图像多层级、精细化的控制。
2.  **自回归模型**（如PixelRNN/PixelCNN）显式建模数据分布，提供了更稳定的训练替代方案。
3.  **视频生成** 的挑战主要在于时间一致性与计算复杂度。
4.  **条件视频生成** 通过利用强条件信号（如姿态、语义图），是当前生成高质量、连贯视频更有效的方法。人脸和人体视频重演是这一范式的成功应用。
