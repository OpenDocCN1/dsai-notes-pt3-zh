# 课程一：L1 - 深度学习计算机视觉介绍 👁️

## 概述

在本节课中，我们将要学习深度学习在计算机视觉领域的基础概念、核心任务以及其发展历程。我们将了解计算机视觉如何让机器“看懂”世界，并初步认识深度学习模型在其中扮演的关键角色。

## 什么是计算机视觉？

计算机视觉是人工智能的一个分支，它致力于让计算机能够从数字图像或视频中获取高层次的理解。其目标是模拟人类视觉系统的功能，实现对视觉信息的自动处理、分析和决策。

## 计算机视觉的核心任务

上一节我们介绍了计算机视觉的定义，本节中我们来看看它具体要解决哪些问题。以下是计算机视觉领域几个最核心的任务：

1.  **图像分类**：给定一张图像，判断它属于预定义类别中的哪一个。例如，识别图片中是猫还是狗。
2.  **目标检测**：不仅要识别图像中存在哪些物体，还要用边界框标出它们的位置。例如，在一张街景图中找出所有行人和车辆。
3.  **语义分割**：对图像中的每一个像素进行分类，将其划分到特定的物体类别中。这可以理解为更精细的“像素级”分类。
4.  **实例分割**：在语义分割的基础上，进一步区分同一类别的不同个体。例如，将图像中多只猫的像素分别标识出来。

## 深度学习在计算机视觉中的角色

传统计算机视觉方法严重依赖手工设计的特征（如SIFT、HOG）。而深度学习，特别是卷积神经网络（CNN），能够自动从海量数据中学习到层次化的特征表示。

一个典型的CNN层可以表示为以下公式，其中包含了卷积、非线性激活和池化操作：

`输出特征图 = 池化(激活函数(卷积(输入特征图, 卷积核) + 偏置))`

这种端到端的学习方式，使得模型性能得到了革命性的提升，成为当前计算机视觉领域的主流方法。

## 发展历程与关键模型

从早期的LeNet用于手写数字识别，到引发深度学习浪潮的AlexNet在ImageNet竞赛中夺冠，再到后续不断加深和优化的VGG、GoogLeNet、ResNet等模型，深度学习推动了计算机视觉能力的边界。

这些模型的演进体现了网络结构设计的思想，例如ResNet中引入的**残差连接**，其核心公式为：

`H(x) = F(x) + x`

这里，`x`是输入，`F(x)`是网络要学习的残差映射，`H(x)`是最终输出。这种设计有效缓解了深层网络中的梯度消失问题。

## 总结

本节课中我们一起学习了计算机视觉的基本概念及其核心任务，包括图像分类、目标检测和图像分割。我们探讨了深度学习如何通过卷积神经网络自动学习特征，取代了传统的手工特征工程，并简要回顾了推动该领域发展的关键模型。理解这些基础知识是进一步探索高级视觉任务的重要起点。
