## 卷积神经网络基础

上一节我们介绍了深度学习在视觉领域的应用背景，本节中我们来看看卷积神经网络的核心组件。

卷积操作是CNN的基石。它通过一个可学习的滤波器（或称卷积核）在输入图像上滑动，计算局部区域的点积和，从而提取局部特征。这一过程可以用以下公式表示：

**公式：**
`S(i, j) = (K * I)(i, j) = Σ_m Σ_n I(i+m, j+n) * K(m, n)`

其中，`I`是输入图像，`K`是卷积核，`S`是输出的特征图。

## CNN的核心层

一个典型的CNN由几种不同类型的层顺序堆叠而成。以下是其主要构成部分：

*   **卷积层**：执行上述卷积操作，自动学习图像的特征。
*   **激活层**：为网络引入非线性，使其能够学习更复杂的模式，常用ReLU函数：`f(x) = max(0, x)`。
*   **池化层**：对特征图进行下采样，减少数据量并增强特征的平移不变性，常用最大池化。
*   **全连接层**：在网络的末端，将学习到的特征映射到样本的标记空间，用于最终分类。

## 一个简单的CNN代码示例

理解了各层的作用后，我们可以用代码来构建一个简单的CNN模型。以下是使用PyTorch框架的示例：

```python
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    def __init__(self):
        super(SimpleCNN, self).__init__()
        # 定义第一个卷积块
        self.conv1 = nn.Conv2d(in_channels=3, out_channels=16, kernel_size=3, padding=1)
        self.pool = nn.MaxPool2d(kernel_size=2, stride=2)
        # 定义第二个卷积块
        self.conv2 = nn.Conv2d(16, 32, 3, padding=1)
        # 定义全连接层
        self.fc1 = nn.Linear(32 * 8 * 8, 128) # 假设经过两次池化后特征图尺寸为8x8
        self.fc2 = nn.Linear(128, 10) # 假设为10分类任务

    def forward(self, x):
        # 前向传播过程
        x = self.pool(F.relu(self.conv1(x)))
        x = self.pool(F.relu(self.conv2(x)))
        x = x.view(-1, 32 * 8 * 8) # 展平特征图
        x = F.relu(self.fc1(x))
        x = self.fc2(x)
        return x
```

## 训练流程概述

构建好模型后，下一步是训练它。神经网络的训练是一个迭代优化的过程，主要包含以下步骤：

1.  **前向传播**：输入数据通过网络，计算得到预测值。
2.  **计算损失**：使用损失函数（如交叉熵损失）比较预测值与真实标签的差异。
3.  **反向传播**：计算损失相对于每个网络参数的梯度。
4.  **参数更新**：使用优化器（如随机梯度下降SGD）根据梯度更新网络权重，以减小损失。

**引用：**
> 梯度下降是深度学习模型优化的核心方法，其更新规则为：`θ = θ - α * ∇J(θ)`，其中`θ`是参数，`α`是学习率，`J`是损失函数。
