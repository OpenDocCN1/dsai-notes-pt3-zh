# 应用机器学习：第24章：集成学习概述

![](img/c863d2efe5438c646afd02e75340feac_0.png)

在本节课中，我们将要学习集成学习的基本概念。我们将了解如何通过组合多个能力有限的“弱”分类器，来构建一个性能更强、更稳健的“强”分类器。

## 核心思想

上一节我们介绍了单一分类器的局限性，本节中我们来看看如何通过集成方法提升性能。

集成学习的核心思想是：**通过组合多个弱学习器来构建一个强学习器**。一个弱学习器指的是性能仅略好于随机猜测的简单模型。虽然单个弱学习器表现不佳，但当我们组合大量这样的模型，并让它们通过投票等方式共同决策时，整体性能会得到显著提升，并且通常比单个复杂的分类器更稳健。

## 关键优势

以下是集成学习带来的两个主要优势：

1.  **提升性能**：多个分类器的集体决策通常比单个最优分类器的决策更准确。
2.  **增强稳健性**：集成模型对数据中的噪声和过拟合问题不那么敏感，因为单个模型的错误会被其他模型纠正。

## 随机森林：一个经典示例

在众多集成学习方法中，随机森林是效果最好的之一。它正是基于我们刚才介绍的核心思想构建的。

随机森林的基学习器是**弱决策树**。这些决策树通常通过限制其深度或使用的特征数量来确保其“弱”的特性。然后，算法会构建成百上千棵这样的树，每棵树只使用数据的一个随机子集和特征的一个随机子集进行训练。最终，通过所有树的投票（对于分类任务）或平均（对于回归任务）来做出预测。

因此，在接下来的模块中，我们将首先介绍决策树分类器及其可视化方法。然后，我们将利用数据集中较少的特征来构建许多这样的弱分类器，并演示它们通过集成投票所达到的综合性能，将如何轻松超越任何单一的、复杂的分类器。

## 总结

![](img/c863d2efe5438c646afd02e75340feac_2.png)

本节课中我们一起学习了集成学习的概述。我们理解了通过组合多个弱分类器（如决策树）并采用多数投票机制，可以构建出性能更强、更稳健的模型。随机森林就是这一思想的成功实践。在后续课程中，我们将深入了解决策树，并具体实现集成学习的过程。
