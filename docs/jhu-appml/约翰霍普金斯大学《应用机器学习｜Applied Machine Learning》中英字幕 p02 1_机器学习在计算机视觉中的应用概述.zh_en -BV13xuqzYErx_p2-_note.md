## 什么是机器学习？

机器学习是一门艺术，它让计算机在没有明确编程的情况下解决计算问题。其核心思想是让计算机从数据中学习规律，而不是依赖硬编码的指令。

## 我们的第一个机器学习流程

上一节我们定义了机器学习，本节中我们来看看如何构建一个完整的机器学习流程。这个流程通常包括开发学习模型、在未见过的数据上测试模型，以及评估模型性能。

### 流程步骤概述

以下是构建和评估一个机器学习模型的主要步骤：

1.  **开发学习模型**：使用算法从训练数据中学习模式。
2.  **测试模型**：将训练好的模型应用于新的、未见过的数据点，以检验其泛化能力。
3.  **评估模型**：使用特定的指标来衡量模型的性能好坏。

## 实践案例：手写数字识别

我们将通过一个具体的计算问题来实践上述流程：识别信封上的手写数字，以帮助邮政工作人员自动分拣邮件。

### 解决方案概述

为了解决这个问题，我们的模型将使用**支持向量机**算法，对从信件正面获取的数字图像进行分类。

**核心算法**：支持向量机（SVM），一种用于分类和回归分析的监督学习模型。

## 模型性能评估

在模型训练和测试之后，我们需要知道它的表现如何。我们将提到一个最基本的性能衡量指标：**准确率**。

**核心指标公式**：`准确率 = (正确预测的样本数) / (总样本数)`
