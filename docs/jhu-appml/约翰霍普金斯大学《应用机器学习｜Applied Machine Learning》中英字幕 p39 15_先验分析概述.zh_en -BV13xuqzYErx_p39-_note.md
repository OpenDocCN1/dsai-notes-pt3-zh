# 应用机器学习：15：先验分析概述

![](img/46c1fcf6cce6bf277e2172c3d155dc15_0.png)

在本节课中，我们将学习一种名为“先验分析”的数据挖掘技术。这种技术常用于发现数据集中不同项目之间的关联关系，例如电商网站中的商品推荐。我们将了解其核心概念、数学定义，并简要介绍用于高效发现这些关联的算法。

你是否曾好奇，当在线商店告诉你“浏览此商品的顾客也考虑了以下商品”时，其背后的推荐引擎是如何工作的？计算特定商品在交易数据库中与其他商品一同出现的概率，是发现实体间共现关系与模式的关键方法之一。

## 关联规则学习

上一段我们提到了发现共现模式，本节中我们来看看实现这一目标的具体方法：关联规则学习。

关联规则学习就是从数据中提取“如果…那么…”规则的过程。例如，从烹饪食谱中发现制作蛋糕所需的必备食材，就是利用先验分析从在线资源中提取规则的一个好例子。

另一个例子是通过匹配用户在不同服务中的IP地址来进行客户画像分析。无论我们是否喜欢，在我们使用在线资源时，这类分析都在发生。

## 核心概念与算法

在定义了应用场景后，本节我们将为计算这些模式建立数学术语，并列出用于高效发现具有显著可能性的项目集的快速算法。

我们将引入三个核心指标来衡量关联规则的强度：

以下是用于评估关联规则的关键度量指标：

*   **支持度**：指项目集在所有交易中出现的频率。它表示规则的重要性。
    *   **公式**：`支持度(X) = 包含X的交易数 / 总交易数`
*   **置信度**：指当项目集X出现时，项目集Y也出现的条件概率。它表示规则的可靠性。
    *   **公式**：`置信度(X -> Y) = 支持度(X ∪ Y) / 支持度(X)`
*   **提升度**：指项目集X的出现对项目集Y出现概率的影响程度。它表示规则的有效性。
    *   **公式**：`提升度(X -> Y) = 置信度(X -> Y) / 支持度(Y)`

发现频繁项目集作为一个通用问题，是一个NP完全问题，这意味着随着数据量增大，计算会变得非常复杂。因此，我们需要高效的算法，例如Apriori算法，它利用“如果一个项目集不是频繁的，那么它的所有超集也不是频繁的”这一先验性质来大幅减少搜索空间。

## 实践与应用

在掌握了理论基础后，最后，我们将在实际交易数据库中应用这些度量指标，以发现有趣的关联关系。

通过计算支持度、置信度和提升度，我们可以筛选出既有代表性又可靠的关联规则。例如，我们可能发现规则 `{牛奶，面包} -> {黄油}` 具有很高的置信度和提升度，这便是一个有价值的洞察，可以用于商品摆放或捆绑销售。
