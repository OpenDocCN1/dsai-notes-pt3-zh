#  010：模型评估概述

![](img/960eb6d244554a95f400e3b56ceccd91_0.png)

在本节课中，我们将学习如何客观地评估机器学习模型的性能。客观评估至关重要，因为主观判断容易扭曲我们对模型能力的认知，并可能导致模型部署后失败。

## 模型评估的重要性

客观评估机器学习性能至关重要。这很容易扭曲我们对模型能力的看法，并在部署后遭遇失败。

## 课程内容概览

在本模块中，我们将研究如何从性能角度评估我们的学习模型。

首先，我们将列出机器学习中常用和流行的指标，并讨论它们在不同情况下的应用。

接下来，我们将讨论机器学习模型的泛化能力，并探讨为何泛化能力是学习模型最重要的属性。我们将介绍哪些分类器算法具有良好的泛化能力。

然后，我们将学习经典的评估方法：受试者工作特征曲线。我们将展示如何在学习流程中生成它。

最后，我们将讨论如何根据ROC曲线上的操作点，通过优化真正率与假正率来选择一个学习模型。

## 总结

![](img/960eb6d244554a95f400e3b56ceccd91_2.png)

本节课中，我们一起学习了模型评估的重要性、常用性能指标、模型泛化能力的概念、ROC曲线的生成与应用，以及如何根据ROC曲线选择最优模型。掌握这些知识是确保机器学习项目成功的关键。
