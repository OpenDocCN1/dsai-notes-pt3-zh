# Gibbs Sampling Example: P( S | +r)

+   - Step 1: Fix evidence
+     - R = +r

+   - Step 2: Initialize other variables
+     - Randomly

+   - Steps 3: Repeat
+     - Choose a non-evidence variable X
+     - Resample X from P( X | all other variables)
