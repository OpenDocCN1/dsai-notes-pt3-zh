# 3.4.5归结演绎推理的方法

谓词逻辑的归结演绎推理

将公式集{F, ¬G} = {(∀x)((∃y)(A(x,y) ∧ B(y))→(∃y)(C(y) ∧ D(x,y))), ¬(¬(∃x)C(x)→(∀x)(∀y)(A(x,y)→¬B(y)))}转化成子句集

# (7) 消去全称量词

F: (¬A(x,y) ∨ ¬B(y) ∨ C(f(x))) ∧ (¬A(x,y) ∨ ¬B(y) ∨ D(x,f(x)))

G: ¬C(x) ∧ A(m,n) ∧ B(n)

# (8) 消去合取词

F: ¬A(x,y) ∨ ¬B(y) ∨ C(f(x)), ¬A(x,y) ∨ ¬B(y) ∨ D(x,f(x))

G: ¬C(x), A(m,n), B(n)

# (9) 更换变量名称

子句集{¬A(x,y) ∨ ¬B(y) ∨ C(f(x)), ¬A(u,v) ∨ ¬B(v) ∨ D(u,f(u)) ¬C(z), A(m,n), B(n) }
