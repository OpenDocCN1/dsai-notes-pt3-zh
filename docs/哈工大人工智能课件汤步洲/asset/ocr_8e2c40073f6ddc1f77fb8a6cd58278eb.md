# D-separation and Markov Blanket

In a Bayesian network, the Markov blanket of a node X is the set consisting of

+   - Parents of X
+   - Children of X
+   - Parents of children of X

Example:

![](bbox=[0.04, 0.37, 0.46, 0.78])

The Markov blanket of I is {E, H, J, K, L}

Theorem: In a Bayesian network, a variable X is conditionally independent of all other variables given its Markov blanket.

Because the Markov blanket of X d-separates X from all other nodes.
