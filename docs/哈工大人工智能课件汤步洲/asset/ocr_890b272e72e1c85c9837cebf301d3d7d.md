# 实例框架

例如，有杨叶和柳青2个硕士生，
杨叶，女，计算机专业，参加了导师林海的网络智能研究方向的省部级项目；
柳青，22岁，计算机专业，导师是林海，论文被EI收录。



```
Frame <Master-1> //是一个
ISA: <Master> //是一个
Name: Yang, Ye
Sex: female
Major: Computer
Field: Web-Intelligence //方向Web智能
Advisor: Lin Hai //导师林海
Project: Provincial //项目省级
```



```
Frame <Master-2>
ISA: <Master>
Name: Liu, Qing
Age: 22
Major: Computer
Advisor: Lin Hai
Paper: EI //论文EI收录
```

其中用到了系统预定以槽名ISA，即Master-1和Master-2是2个具体的Master
