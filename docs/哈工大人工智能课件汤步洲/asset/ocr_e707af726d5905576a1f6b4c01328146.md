# Probability Distributions

+   - Unobserved random variables have distributions

| T | P |
| hot | 0.5 |
| cold | 0.5 |

| W | P |
| sun | 0.6 |
| rain | 0.1 |
| fog | 0.3 |
| meteor | 0.0 |

+   - A distribution is a TABLE of probabilities of values

P(W = rain) = 0.1

+   - Must have: ∀x P(X = x) ≥ 0 and ∑_x P(X = x) = 1

> Shorthand notation:
> 
> P(hot) = P(T = hot),
> P(cold) = P(T = cold),
> P(rain) = P(W = rain),
> ...
> 
> OK if all domain entries are unique
