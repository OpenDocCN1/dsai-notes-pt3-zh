# Normalization Trick

P(T, W)

| T | W | P |
|---|---|---|
| hot | sun | 0.4 |
| hot | rain | 0.1 |
| cold | sun | 0.2 |
| cold | rain | 0.3 |

P(W = s | T = c) = P(W = s, T = c) / P(T = c) = P(W = s, T = c) / [P(W = s, T = c) + P(W = r, T = c)] = 0.2 / (0.2 + 0.3) = 0.4

P(W = r | T = c) = P(W = r, T = c) / P(T = c) = P(W = r, T = c) / [P(W = s, T = c) + P(W = r, T = c)] = 0.3 / (0.2 + 0.3) = 0.6
