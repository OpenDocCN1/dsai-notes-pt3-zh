# 【产生式系统应用举例】

例1:设有以下两条规则

```
r1: IF 动物有羽毛 THEN 动物是鸟
r2: IF 动物是鸟 AND 动物善飞 THEN 动物是信天翁
其中， r1和r2是上述两条规则则在动物识别系统中的规则编号。
```

假设已知以下事实:

动物有羽毛，动物善飞

求满足以上事实的动物是何种动物。

解: 由于已知事实"动物有羽毛", 即 r1的前提条件满足, 因此 r1可用, 承认的 r1结论, 即推出新的事实"动物是鸟"。此时, r2的两个前提条件均满足, 即 r2的前提条件满足, 因此r2可用, 承认的r2结论, 即推出出新的事实"动物是信天翁"。
