# # 2. 4. 2 基本语义关系



指不同事件在发生时间方面的先后次序关系。
常用的时间关系有：
Before: 含义为"在前"
After: 含义为"在后"

![](bbox=[0.55, 0.1, 0.95, 0.35])



指不同事物在位置方面的关系.常用的有：
Located-on: 含义为"在...上面"
Located-under : 含义为"在...下面"
Located-at: 含义为"在..."
Located-inside : 含义为"在...内"
Located-outside : 含义为"在...外"
