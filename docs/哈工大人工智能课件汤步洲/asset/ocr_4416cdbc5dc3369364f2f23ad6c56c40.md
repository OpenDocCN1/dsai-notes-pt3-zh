+   - Result will be a selected joint of query and evidence
+   - E.g. for P(L | +r), we would end up with:

P(+r)
+ r | 0.1

P(T | +r)
+ r | +t | 0.8
+ r | -t | 0.2

P(L | T)
+ t | + l | 0.3
+ t | - l | 0.7
- t | + l | 0.1
- t | - l | 0.9
