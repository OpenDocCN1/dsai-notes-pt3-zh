# Rejection Sampling

+   - IN: evidence instantiation
+   - For i=1, 2, …, n
+     - Sample x_i from P(X_i | Parents(X_i))
+     - If x_i not consistent with evidence
+       - Reject: Return, and no sample is generated in this cycle
+   - Return (x_1, x_2, …, x_n)
