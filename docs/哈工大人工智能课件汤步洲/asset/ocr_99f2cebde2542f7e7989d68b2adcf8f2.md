# 3.4.2子句集及其应用

# 子句集的化简

在谓词逻辑中，任何一个谓词公式都可以通过应用等价关系及推理规则化成相应的子句集。

例如公式

```
(∀x)((∀y)P(x,y)→¬(∀y)(Q(x,y)→R(x,y)))
```

其化简步骤如下：

+   (1) 消去连接词“→”和“↔”

反复使用如下等价公式：

```
P→Q ⇔ ¬P ∨ Q
```

```
P↔Q ⇔ (P ∧ Q) ∨ (¬P ∧ ¬Q)
```

即可消去谓词公式中的连接词“→”和“↔”。

以上谓词公式经等价变化后为

```
(∀x)(¬(∀y)P(x,y) ∨ ¬(∀y)(¬Q(x,y) ∨ R(x,y)))
```
