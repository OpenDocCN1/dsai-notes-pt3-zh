# Factor Zoo Summary

+   - In general, when we write P(Y₁ ... Yₙ | X₁ ... Xₘ)
+     - It is a “factor,” a multi-dimensional array
+     - Its values are P(y₁ ... yₙ | x₁ ... xₘ)
+     - Any assigned (=lower-case) X or Y is a dimension missing (selected) from the array
