# Variable Elimination Ordering

+   - For the query $P(X_n\mid y_1,\cdots,y_n)$, work through the following two different orderings as done in previous slide: $Z, X_1, \cdots, X_{n-1}$ and $X_1, \cdots, X_{n-1}, Z$. What is the size of the maximum factor generated for each of the orderings?

![](bbox=[0.303, 0.316, 0.664, 0.735])

+   - Answer: $2^{n+1}$ versus $2^2$ (assuming binary)

+   - In general: the ordering can greatly affect efficiency.
