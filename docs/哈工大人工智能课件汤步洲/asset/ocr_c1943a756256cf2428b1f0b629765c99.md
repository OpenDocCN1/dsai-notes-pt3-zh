# 4.1.3 状态空间法

解：问题的状态可用4元组
(m, b, ON, H)
表示。其中：

+   - m 表示猴子的位置；
+   - b 表示箱子的位置；
+   - ON 表示猴子是否在箱子上，当猴子在箱子上时，y取1，否则y取0；
+   - H 表示猴子是否拿到香蕉，当拿到香蕉时z取1，否则z取0。

可能的状态

+   - S₀: (a, b, 0, 0) 初始状态
+   - S₁: (b, b, 0, 0)
+   - S₂: (c, c, 0, 0)
+   - S₃: (c, c, 1, 0)
+   - S₄: (c, c, 1, 1) 目标状态
