# Another Variable Elimination Example

**Query:** $P(X_3\mid Y_1=y_1, Y_2=y_2, Y_3=y_3)$

Start by inserting evidence, which gives the following initial factors:

$p(Z)p(X_1\mid Z)p(X_2\mid Z)p(X_3\mid Z)p(y_1\mid X_1)p(y_2\mid X_2)p(y_3\mid X_3)$

Eliminate $X_1$, this introduces the factor $f_1(Z,y_1)=\sum_{x_1}p(x_1\mid Z)p(y_1\mid x_1)$, and we are left with:

$p(Z)f_1(Z,y_1)p(X_2\mid Z)p(X_3\mid Z)p(y_2\mid X_2)p(y_3\mid X_3)$

Eliminate $X_2$, this introduces the factor $f_2(Z,y_2)=\sum_{x_2}p(x_2\mid Z)p(y_2\mid x_2)$, and we are left with:

$p(Z)f_1(Z,y_1)f_2(Z,y_2)p(X_3\mid Z)p(y_3\mid X_3)$

Eliminate $Z$, this introduces the factor $f_3(y_1,y_2,X_3)=\sum_z p(z)f_1(z,y_1)f_2(z,y_2)p(X_3\mid z)$, and we are left:

$p(y_3\mid X_3), f_3(y_1,y_2,X_3)$

No hidden variables left. Join the remaining factors to get:

$f_4(y_1,y_2,y_3,X_3)=P(y_3\mid X_3)f_3(y_1,y_2,X_3)$.

Normalizing over $X_3$ gives $P(X_3\mid y_1,y_2,y_3)$.

![](img/9a6adc64cdb7c98bcd042d4d38c7b00d_642_0.png)

Computational complexity critically depends on the largest factor being generated in this process. Size of factor = number of entries in table. In example above (assuming binary) all factors generated are of size 2 — as they all only have one variable ($Z$, $Z$, and $X_3$ respectively).

# Variable Elimination Ordering

- For the query $P(X_n\mid y_1,\cdots,y_n)$, work through the following two different orderings as done in previous slide: $Z, X_1, \cdots, X_{n-1}$ and $X_1, \cdots, X_{n-1}, Z$. What is the size of the maximum factor generated for each of the orderings?

![](img/9a6adc64cdb7c98bcd042d4d38c7b00d_643_0.png)

- Answer: $2^{n+1}$ versus $2^2$ (assuming binary)

- In general: the ordering can greatly affect efficiency.

# VE: Computational and Space Complexity

- The computational and space complexity of variable elimination is determined by the largest factor
- The elimination ordering can greatly affect the size of the largest factor.
  - E.g., previous slide’s example 2 vs. 2
- Does there always exist an ordering that only results in small factors?
  - No!
