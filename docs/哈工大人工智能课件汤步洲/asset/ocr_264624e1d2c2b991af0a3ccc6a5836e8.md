# Operation 2: Eliminate

+   - Second basic operation: marginalization
+   - Take a factor and sum out a variable
+     - Shrinks a factor to a smaller one
+     - A projection operation
+   - Example:

P(R, T)

| +r | +t | 0.08 |
| +r | -t | 0.02 |
| -r | +t | 0.09 |
| -r | -t | 0.81 |

sum R

P(T)

| +t | 0.17 |
| -t | 0.83 |
