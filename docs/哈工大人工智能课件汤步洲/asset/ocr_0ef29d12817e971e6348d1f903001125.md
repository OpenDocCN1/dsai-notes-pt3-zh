# Likelihood Weighting

+   - IN: evidence instantiation
+   - w = 1.0
+   - for i=1, 2, ..., n
+     - if X_i is an evidence variable
+       - X_i = observation x_i for X_i
+       - Set w = w * P(x_i | Parents(X_i))
+     - else
+       - Sample x_i from P(X_i | Parents(X_i))
+   - return (x_1, x_2, ..., x_n), w
