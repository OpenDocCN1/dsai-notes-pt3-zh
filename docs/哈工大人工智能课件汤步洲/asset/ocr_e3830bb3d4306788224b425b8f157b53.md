# 3. 4. 2 子句集及其应用

# 子句集的应用

# 证明

证明⇒ 已知F不可满足，假设F1是可满足的，则存在一个解释I，使F1在解释I下为真。 即对任意x1, ..., xr-1 在I的设定下有 (Qr+1 xr+1)⋯(Qn xn)M(x1,⋯,xr−1,f(x1,⋯,xr−1),xr+1⋯,xn) 为真。

亦即对任意的x1,⋯,xr−1 都有一个f(x1,⋯,xr−1)使 (Qr+1 xr+1)⋯(Qn xn)M(x1,⋯,xr−1,f(x1,⋯,xr−1),xr+1⋯,xn) 为真。 即在I下有 (∀x1)⋯(∀xr−1)(∃xr)(Qr+1 xr+1)⋯(Qn xn)M(x1,⋯,xr−1,xr,xr+1⋯,xn) 为真。

即F在I下为真。 但这与前提F是不可满足的相矛盾，即假设F1为可满足是错误的。从而可以得出“若F不可满足，则必有F1不可满足”。
