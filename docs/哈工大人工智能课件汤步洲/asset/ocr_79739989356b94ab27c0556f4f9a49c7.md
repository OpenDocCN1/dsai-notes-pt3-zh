# # 子句集合的语义

定义20： 称结构u* =< H, I_H >为对应于结构u =< U, I >的H-结构， 如果：

+   1. H为海伯伦域，I_H为海伯伦解释。
+   2. 对任意n，任意谓词P(n)以及任意项t1, t2, …, tn ∈ H， |⊢u P(n)(t1, …, tn) 当且仅当 P(n)(t1, …, tn) ∈ I_H。

定理3.2： 设结构u* =< H, I_H >为对应于结构u =< U, I >的H-结构， 对任意n，任意谓词P(n)以及任意项t1, t2, …, tn， |⊢u* P(n)t1 … tn 可以推出 |⊢u P(n)t1 … tn。
