# Conditional Probabilities

+   - A simple relation between joint and conditional probabilities
+     - In fact, this is taken as the *definition* of a conditional probability

```
P(a|b) = P(a, b) / P(b)
```

# P(T, W)

| T | W | P |
|---|---|---|
| hot | sun | 0.4 |
| hot | rain | 0.1 |
| cold | sun | 0.2 |
| cold | rain | 0.3 |

```
P(W = s | T = c) = P(W = s, T = c) / P(T = c) = 0.2 / 0.5 = 0.4
```
