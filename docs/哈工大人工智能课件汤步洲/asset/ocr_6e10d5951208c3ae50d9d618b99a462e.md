# # 特性继承的例

如前面的学生框架
若要查询Master-1 的Sex ，则可直接回答; 但要查询Master-2的Sex ，则需要沿ISA链和AKO链到Student框架取其默认佳male.

若要查询Master-2的Field, 需要沿ISA链到Master框架, 执行Field槽If-Needed
侧面的Ask-Field操作, 即 时产生一个值,假设产生的值是Data-Mining , 则表示Master-2的研究方向为数据挖掘。

如果要修改Master-2 的Major, 需要沿ISA链到Master框架, 执行 Major槽If-Added侧面的Check-Major操作, 对Field, Advisor进行修改, 以保持知识的一致性。
