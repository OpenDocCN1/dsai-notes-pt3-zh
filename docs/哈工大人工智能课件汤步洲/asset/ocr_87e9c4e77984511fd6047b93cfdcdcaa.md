+   - General case:
+     - Evidence variables: $E_1 \dots E_k = e_1 \dots e_k$
+     - Query* variable: $Q$
+     - Hidden variables: $H_1 \dots H_r$
+     $\left. \begin{array}{c} X_1, X_2, \dots X_n \\ \text{All variables} \end{array} \right\}$

+   - We want:
+     $P(Q|e_1 \dots e_k)$
+     * Works fine with multiple query variables, too
