# Inference with Bayes’ Rule

+   - Example: Diagnostic probability from causal probability:
+   
+     $$P(\text{cause}\mid\text{effect})=\frac{P(\text{effect}\mid\text{cause})P(\text{cause})}{P(\text{effect})}$$

+   - Example:
+     - M: meningitis, S: stiff neck

$$P(+m)=0.0001$$

$$P(+s\mid +m)=0.8$$

$$P(+s\mid -m)=0.01$$

![](bbox=[0.608, 0.5, 0.704, 0.613])

$$P(+m\mid +s)=\frac{P(+s\mid +m)P(+m)}{P(+s)}=\frac{P(+s\mid +m)P(+m)}{P(+s\mid +m)P(+m)+P(+s\mid -m)P(-m)}=\frac{0.8\times0.0001}{0.8\times0.0001+0.01\times0.999}$$

+   - Note: posterior probability of meningitis still very small
+   - Note: you should still get stiff necks checked out! Why?
