# MIT 6.S897 医疗机器学习 2019 中文笔记 📚

## 概述

在本课程中，我们将学习机器学习在医疗健康领域的应用。课程内容涵盖医疗数据的独特性、临床诊疗流程、多种医疗数据类型（如生理时间序列、病理图像、文本记录）的分析方法，以及因果推断、强化学习、疾病进展建模等高级主题。我们还将探讨将技术转化为临床实践所面临的挑战，包括监管、公平性、鲁棒性和可解释性等问题。

## 课程目录 📖

以下是本课程所有章节的列表，每个章节对应一个特定的主题。

*   **P1：医疗领域的独特性** - 探讨医疗数据和应用场景与其他领域（如互联网）的根本区别。
*   **P2：临床诊疗概述** - 介绍现代医疗体系中的标准诊疗流程和决策环节。
*   **P3：深入临床数据** - 详细解析电子健康记录、医学影像、基因组学等各类医疗数据的结构和特点。
*   **P4：风险分层（第一部分）** - 学习如何利用患者数据预测其未来发生特定不良健康事件的风险。
*   **P5：风险分层（第二部分）** - 继续深入风险分层模型，讨论评估指标和实际应用中的挑战。
*   **P6：生理时间序列** - 专注于处理和分析如心电图、脑电图、生命体征监测等产生的连续时序数据。
*   **P7：自然语言处理（NLP），第一部分** - 介绍如何应用NLP技术处理临床文本记录，如医生笔记、出院小结等。
*   **P8：自然语言处理（NLP），第二部分** - 深入NLP在医疗中的高级应用，如信息提取、关系挖掘和临床决策支持。
*   **P9：技术向临床转化** - 讨论机器学习模型从实验室研究到实际临床部署所经历的步骤和障碍。
*   **P10：机器学习在医疗中的应用** - 综述机器学习在诊断、治疗、预后和管理等方面的典型案例。
*   **P11：鉴别诊断** - 探索如何构建辅助医生进行鉴别诊断（从多种可能疾病中确定病因）的计算模型。
*   **P12：病理学中的机器学习** - 学习机器学习在病理切片图像分析中的应用，如癌症检测和分级。
*   **P13：乳腺X光检查中的机器学习** - 专注于机器学习在乳腺癌筛查影像（乳腺X光片）分析中的方法和挑战。
*   **P14：因果推断（第一部分）** - 介绍因果推理的基本概念，区分关联与因果，并讨论其在评估治疗效果中的重要性。
*   **P15：因果推断（第二部分）** - 深入探讨用于估计因果效应的统计和机器学习方法。
*   **P16：强化学习（第一部分）** - 介绍强化学习基础，并探讨其用于个性化治疗策略优化的潜力。
*   **P17：强化学习（第二部分）** - 继续讨论强化学习在医疗中的具体算法、安全考量及应用实例。
*   **P18：疾病进展建模（第一部分）** - 学习如何构建数学模型来模拟和预测慢性疾病的动态演变过程。
*   **P19：疾病进展建模（第二部分）** - 深入疾病进展模型的技术细节，如使用状态空间模型或深度学习。
*   **P20：精准医疗** - 探讨如何整合多组学数据、临床信息和环境因素，为患者提供个体化的预防和治疗方案。
*   **P21：自动化临床工作流** - 研究如何利用机器学习自动化部分临床任务，提升医疗效率和一致性。
*   **P22：机器学习的监管** - 了解医疗AI产品需要遵循的法规和审批流程，例如FDA的监管框架。
*   **P23：公平性** - 讨论机器学习模型在医疗应用中可能存在的偏见，以及确保不同群体间公平性的方法。
*   **P24：对数据集偏移的鲁棒性** - 探究当模型部署环境与训练数据分布不同时，如何保持其性能的稳定性。
*   **P25：可解释性** - 学习使复杂机器学习模型（如深度学习）的决策过程对医生和患者更透明、可理解的技术。

## 总结

本节课中，我们一起浏览了《MIT 6.S897 医疗机器学习 2019》课程的全貌。从理解医疗领域的核心独特性开始，我们逐步深入到各种数据类型的具体分析方法、高级建模技术，最终落脚于将AI模型安全、有效、公平地整合到现实临床环境中所必须考虑的实践性问题。这份目录为我们系统学习医疗AI奠定了清晰的路线图。
