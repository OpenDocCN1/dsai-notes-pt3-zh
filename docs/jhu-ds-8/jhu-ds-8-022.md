# 022：提升方法



在本节课中，我们将要学习**提升方法**。提升方法与随机森林一样，是你可以直接使用的、最准确的分类器之一。其核心思想是组合大量可能较弱的预测器，通过加权的方式利用它们的优势，从而构建一个强大的预测模型。



## 基本概念 🧩



上一节我们介绍了集成学习的思想。本节中我们来看看提升方法的具体思路。



提升方法的基本思想是选取K个分类器，这些分类器通常来自同一类别。例如，可以使用所有可能的分类树、所有可能的回归模型，或者所有可能的数据划分点。


然后，创建一个分类器，将这些分类函数加权组合起来。其核心公式可以表示为：


**`f(x) = Σ α_t * h_t(x)`**

其中，`α_t` 是权重，`h_t(x)` 是第t个分类器。这个加权分类器集合给出了对新数据点 `x` 的预测 `f(x)`。

## 算法目标与流程 ⚙️


目标是**最小化训练集上的误差**。这是一个迭代过程：

以下是算法的主要步骤：
1.  在每一步，选取一个分类器 `h_t`。
2.  根据该分类器产生的误差计算下一步的权重。
3.  增加被错误分类样本的权重，并选择下一个分类器 `h_{t+1}`，继续迭代。




最著名的提升算法是**AdaBoost**。你可以在维基百科或相关教程中找到更多细节。




## 一个简单示例 📊



为了理解提升方法如何工作，我们来看一个简单的二维分类例子。

假设我们试图用两个变量（变量1和变量2）来区分蓝色的“+”号和红色的“-”号。目标是构建一个能分离这两类点的分类器。





我们从一个非常简单的分类器开始：画一条垂直线。这条线将平面左侧分类为蓝色“+”，右侧分类为红色“-”。可以看到，右上角的三个点被错误分类了。


以下是初始分类步骤：
*   构建第一个分类器（垂直线）。
*   计算错误率（本例中约30%）。
*   增加被误分类点的权重（在图中用放大显示表示）。


然后，我们构建第二个分类器。考虑到被加权的点，第二条垂直线画在了更靠右的位置。这条线将右侧分类为红色“-”，左侧分类为蓝色“+”。这次，中间区域的三个点被错误分类，它们的权重随之增加。




接着，构建第三个分类器。为了正确分类前两轮被误判的点（那些被放大的“+”和“-”），我们这次画一条**水平线**。线以上的区域分类为蓝色“+”，以下分类为红色“-”。这个分类器又误判了另外三个点。


## 组合与加权 🤝


现在，我们将这三个简单的分类器加权组合起来。最终的分类器是它们的加权和：





**`最终分类器 = 0.42 * (第一个垂直线分类器) + 0.65 * (第二个垂直线分类器) + 0.92 * (水平线分类器)`**

当我们把这些分类规则加起来后，分类效果大大改善，成功分开了所有的蓝色“+”和红色“-”。每个基础分类器本身都很简单（只是一条分割线），但通过加权组合，最终得到了一个强大的分类器。

## 提升方法的实现与R语言应用 💻

提升方法可以与任何类型的弱分类器子集结合使用。一个非常大的类别是**梯度提升**。






R语言中有多个实现提升算法的包，主要取决于所使用的分类函数和组合规则。






以下是几个主要的R包：
*   **`gbm`包**：用于基于树的提升。
*   **`mboost`包**：用于基于模型的提升。
*   **`ada`包**：用于加性逻辑回归提升。
*   **`GAMBoost`包**：用于广义加性模型的提升。

其中大多数都可以通过`caret`包调用，你可以直接使用`caret`中的`train`函数来应用它们。



## 实战案例：预测工资 📈



让我们使用`Wage`数据集来演示如何应用提升算法。


首先，加载必要的库和数据，并创建训练集与测试集。



```r
library(ISLR) # 包含Wage数据
library(ggplot2)
library(caret)
data(Wage)
Wage <- subset(Wage, select = -c(logwage)) # 移除预测目标logwage
# 创建训练集与测试集（此处为示例，未显示完整分区代码）
```


然后，我们使用`gbm`方法（基于树的提升）来建模，将工资（`wage`）作为所有其他变量的函数。




```r
# 使用caret训练提升模型
model_fit <- train(wage ~ .,
                   data = training_set, # 假设training_set已定义
                   method = "gbm",
                   verbose = FALSE) # 避免过多输出
print(model_fit)
```


模型会显示使用了不同数量的树和不同的交互深度来构建提升的回归树模型。




最后，我们可以在测试集上评估预测结果。




```r
# 在测试集上进行预测
predictions <- predict(model_fit, newdata = testing_set)
# 绘制预测值与真实值的对比图（示例）
qplot(wage, predictions, data = testing_set)
```

虽然图中可能仍存在一定变异性，但我们得到了一个相对合理的预测。拟合提升算法（或任何提升算法）的基本思想，就是将这些弱分类器加权平均，从而获得更好的分类器。
