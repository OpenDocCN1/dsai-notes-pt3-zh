## 🔗 P4：L1.4 - 连接（Bindings）

在Python中，我们使用**变量**来存储数据。将一个值赋给一个变量的过程称为**连接**或**绑定**。

你可以把变量想象成一个贴有标签的盒子，标签是变量名，盒子里装的是数据（值）。使用赋值运算符 `=` 来建立连接。

```python
x = 10        # 将整数10绑定到变量名`x`
name = "Alice" # 将字符串"Alice"绑定到变量名`name`
is_valid = True # 将布尔值True绑定到变量名`is_valid`
```

变量名可以被后续代码引用，代表其绑定的值。例如 `print(x + 5)` 会输出 `15`。

## 🔀 P5：L2.1 - 分支与循环

程序并非总是直线执行。为了处理复杂的逻辑，我们需要控制程序的执行流程。本节介绍两种基本的流程控制结构：**分支**和**循环**。

*   **分支**：根据条件判断，决定执行哪一段代码。在Python中使用 `if`, `elif`, `else` 语句实现。
*   **循环**：重复执行一段代码，直到满足某个条件。在Python中主要使用 `while` 循环和 `for` 循环。

这两种结构是构建所有复杂程序逻辑的基石。

## ⚖️ P7：L2.3 - 程序中的「比较」逻辑

要实现分支判断，我们需要比较数据。Python提供了**比较运算符**，用于比较两个值，并返回一个布尔值（`True` 或 `False`）。

以下是常用的比较运算符：
*   等于：`==`
*   不等于：`!=`
*   大于：`>`

*   大于等于：`>=`

例如，`5 > 3` 的结果是 `True`，而 `"apple" == "orange"` 的结果是 `False`。这些比较结果是 `if` 语句进行条件判断的基础。

## 🛤️ P8：L2.4 - 分支

现在，让我们具体学习如何使用 `if` 语句来实现分支。`if` 语句检查一个条件，如果条件为真（`True`），则执行其下方的代码块；如果为假（`False`），则跳过。

`if` 语句可以搭配 `elif`（否则如果）和 `else`（否则）来构建多路分支。

```python
score = 85
if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("不及格")
# 输出：及格
```

代码块通过**缩进**（通常是4个空格）来定义。缩进相同的语句属于同一个代码块。

## 🔁 P9：L2.5 - while循环

`while` 循环会在条件为真时，反复执行其代码块。每次执行完循环体后，都会重新检查条件。

```python
count = 0
while count < 5:
    print(count)
    count = count + 1  # 重要：必须改变条件变量，否则可能陷入无限循环
# 输出：0, 1, 2, 3, 4
```

使用 `while` 循环时，务必确保循环条件最终会变为假，否则程序将陷入**无限循环**。

---

## 🔂 P10：L2.6 - for循环

`for` 循环是另一种循环结构，它更常用于遍历一个序列（如字符串、列表等）中的每个元素。

`for` 循环的语法是 `for 变量 in 序列:`，它会将序列中的每个元素依次赋值给变量，并执行循环体。

```python
for letter in "Python":
    print(letter)
# 输出：P, y, t, h, o, n (每个字母占一行)
```

与 `while` 循环相比，`for` 循环通常更简洁，尤其当你知道需要遍历多少次或遍历什么集合时。

## 🧩 P12：L3.2 - 字符串操作

除了基本操作，字符串还支持**切片**，用于获取子字符串。

切片语法为 `[start:stop:step]`。
*   `start`：起始索引（包含）。
*   `stop`：结束索引（不包含）。
*   `step`：步长（可选，默认为1）。

```python
s = "Hello, World!"
print(s[0:5])   # 输出 "Hello" (索引0到4)
print(s[7:])    # 输出 "World!" (从索引7到末尾)
print(s[:5])    # 输出 "Hello" (从开头到索引4)
print(s[::2])   # 输出 "Hlo ol!" (每隔一个字符)
```

切片非常强大，可以方便地提取、反转或按步长获取字符串的一部分。

## 🔄 P13：L3.3 - 字符串的for循环处理

`for` 循环是处理字符串中每个字符的利器。我们可以结合循环和字符串操作来实现复杂的文本处理逻辑。

例如，统计一个字符串中某个字母出现的次数：
```python
count = 0
target = 'a'
text = "banana"
for char in text:
    if char == target:
        count = count + 1
print(f"字母 '{target}' 出现了 {count} 次") # 输出：字母 'a' 出现了 3 次
```

通过循环，我们可以检查、修改或基于字符串中的每个字符进行计算。

## 🧱 P14：L4.1 - 分解、抽象与函数

随着程序变复杂，我们需要更好的方法来组织代码。**函数**是实现代码**分解**和**抽象**的核心工具。

*   **分解**：将一个大问题拆分成多个小问题，每个小问题由一个函数解决。
*   **抽象**：隐藏复杂的实现细节，只暴露一个简单的接口（函数名和参数）。使用者只需知道函数能做什么，无需知道它如何做。

函数是一段可重复使用的代码块，它接受输入（参数），执行特定任务，并可能返回输出（结果）。

---

## 📞 P15：L4.2 - 函数调用

要使用一个函数，你需要**调用**它。调用函数时，程序会跳转到函数定义处执行其中的代码，执行完毕后返回调用点。

使用函数名后跟括号 `()` 来调用函数。如果函数需要参数，将参数放在括号内。

```python
# 内置函数 print 的调用
print("Hello, Function!") # 输出：Hello, Function!

# 假设有一个计算平方的函数 square
def square(x):
    return x * x

result = square(5) # 调用 square 函数，传入参数 5
print(result)      # 输出：25
```

函数调用是程序执行的基本单元之一。

---

## 🎯 P16：L4.3 - 函数参数

函数通过**参数**接收外部传入的数据。参数在函数定义时声明，在函数调用时提供具体的值（称为**实参**）。

Python函数参数非常灵活：
*   **必需参数**：调用时必须提供，且顺序与定义一致。
*   **默认参数**：在定义时给参数一个默认值，调用时可省略。
*   **关键字参数**：调用时使用 `参数名=值` 的形式，可以不按顺序传递。

```python
def greet(name, greeting="Hello"): # name是必需参数，greeting是默认参数
    print(f"{greeting}, {name}!")

greet("Alice")               # 输出：Hello, Alice!
greet("Bob", "Hi")           # 输出：Hi, Bob!
greet(greeting="Hey", name="Charlie") # 使用关键字参数，输出：Hey, Charlie!
```

参数机制使得函数可以处理不同的输入，更加通用。

## 🔒 P18：L5.2 - 元组

元组用于存储不可变的数据集合。因为其不可变性，元组通常用于表示不应该被修改的数据，例如坐标点 `(x, y)`、RGB颜色 `(255, 0, 0)` 等。

定义和访问元组：
```python
point = (10, 20)

## 📋 P19：L5.3 - 简单列表

列表是Python中最通用、最强大的数据结构之一。它可以存储任意类型的元素，并且长度可以动态变化。

创建和访问列表：
```python
fruits = ['apple', 'banana', 'cherry']
numbers = [1, 2, 3, 4, 5]
mixed = [1, 'hello', 3.14, True]

print(fruits[0])   # 输出 'apple'

```

列表是可变的，这意味着我们可以修改列表中的元素。

## 🛠️ P20：L5.4 - 列表操作

列表支持丰富的操作来修改其内容。

以下是常见的列表修改操作：
*   **修改元素**：通过索引直接赋值。
    ```python
    fruits = ['apple', 'banana', 'cherry']
    fruits[1] = 'blueberry'
    print(fruits) # 输出 ['apple', 'blueberry', 'cherry']
    ```
*   **添加元素**：
    *   `append(item)`：在列表末尾添加一个元素。
    *   `insert(index, item)`：在指定索引位置插入一个元素。
*   **删除元素**：
    *   `del list[index]`：删除指定索引的元素。
    *   `pop(index)`：删除并返回指定索引的元素（默认为最后一个）。
    *   `remove(value)`：删除第一个匹配该值的元素。

这些方法使得列表可以灵活地作为动态数组使用。

## 👥 P21：L5.5 - 列表重命名与元素更改

理解变量名和列表对象的关系非常重要。变量名就像一个标签，可以贴在不同的对象上。

```python
a = [1, 2, 3]
b = a          # 这不是复制列表，而是将标签`b`也贴到`a`所指的同一个列表对象上
b[0] = 99
print(a)       # 输出 [99, 2, 3]，因为a和b指向同一个列表

# 创建真正的副本
c = a[:]       # 使用切片创建新副本
# 或
import copy
c = copy.copy(a) # 使用copy模块
c[0] = 100
print(a)       # 输出 [99, 2, 3]，a未受影响
print(c)       # 输出 [100, 2, 3]
```

对于包含其他可变对象（如嵌套列表）的列表，可能需要使用 `copy.deepcopy()` 进行深拷贝。

## ♻️ P22：L6 - 递归与字典

**递归**是一种强大的编程技术，函数通过调用自身来解决问题。递归通常用于解决可以自然分解为相似子问题的情况，例如计算阶乘、遍历树形结构。

**字典**是Python中另一种重要的内置数据结构，它存储**键-值对**。字典通过键来快速查找对应的值，效率很高。

```python
# 递归示例：计算阶乘 n!
def factorial(n):
    if n == 0:          # 基线条件，防止无限递归
        return 1
    else:
        return n * factorial(n-1) # 递归调用

# 字典示例
student = {'name': 'Alice', 'age': 20, 'major': 'CS'}
print(student['name']) # 输出 'Alice'
student['age'] = 21    # 修改值
student['grade'] = 'A' # 添加新的键值对
```

递归思维和字典的使用能极大提升你解决复杂问题的能力。

## 🐞 P23：L7.1 - 测试与调试、异常处理与断言

编写正确的代码充满挑战。**测试**和**调试**是发现并修复代码错误（bug）的关键过程。

为了辅助调试和确保代码健壮性，我们使用**异常处理**来捕获和处理运行时错误，使用**断言**在代码中设置检查点。

## ⚫️ ⚪️ P24：L7.2 - 黑盒与白盒测试

测试可以根据对代码内部的了解程度分为两类：

*   **黑盒测试**：测试者将程序视为一个“黑盒”，只关心输入和输出，不关心内部实现。测试基于功能规格说明。
*   **白盒测试**：测试者了解代码内部结构，根据代码逻辑设计测试用例，确保所有分支和路径都被执行到。

以下是设计测试用例时需要考虑的一些方面：
*   正常用例：典型的、预期的输入。
*   边界用例：输入范围的边界值（如最大值、最小值、空值）。
*   错误用例：故意输入非法或意外数据，测试程序的鲁棒性。

结合两种测试方法可以更全面地保障代码质量。

## ❌ P25：L7.3 - 错误处理

程序运行时可能发生各种错误，例如除以零、打开不存在的文件、列表索引越界等。在Python中，这些错误会引发**异常**。

如果不处理异常，程序会崩溃并打印错误信息（Traceback）。为了程序能更优雅地应对错误，我们需要进行错误处理。

最基本的方式是预先检查条件，避免错误发生：
```python
def safe_divide(x, y):
    if y == 0:
        print("错误：除数不能为零")
        return None
    else:
        return x / y
```

但对于不可预知或复杂的错误，更好的方式是使用异常处理机制。

## 🛡️ P26：L7.4 - 异常处理

Python使用 `try...except` 语句来捕获和处理异常。

```python
try:
