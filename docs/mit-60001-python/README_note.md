在本节课中，我们将要学习Python编程语言的基础知识，包括变量、数据类型、运算符、控制流以及函数。这些是构建任何Python程序的基石。

## 变量与数据类型

上一节我们介绍了课程概述，本节中我们来看看Python如何处理数据。在Python中，数据存储在变量中，每个变量都有其特定的数据类型。

变量是存储信息的容器。你可以将变量想象成一个贴有标签的盒子，标签是变量名，盒子里装的是数据。

Python有多种内置的数据类型，用于表示不同种类的数据。

以下是主要的数据类型：

*   **整数 (int)**： 表示没有小数部分的数字，例如 `5`、`-3`、`0`。
*   **浮点数 (float)**： 表示带有小数部分的数字，例如 `3.14`、`2.0`、`-0.5`。
*   **字符串 (str)**： 表示文本，由单引号或双引号包围，例如 `'hello'`、`"Python"`。
*   **布尔值 (bool)**： 表示逻辑值，只有 `True` 和 `False` 两个值。

## 运算符

了解了如何存储数据后，我们需要知道如何操作它们。运算符用于对变量和值执行操作。

Python支持多种运算符，用于数学计算、比较和逻辑判断。

以下是常见的运算符类别：

*   **算术运算符**： 用于基本的数学运算。
    *   `+` 加法
    *   `-` 减法
    *   `*` 乘法
    *   `/` 除法（结果为浮点数）
    *   `//` 整除（结果为整数）
    *   `%` 取模（求余数）
    *   `**` 幂运算
*   **比较运算符**： 用于比较两个值，返回布尔值。
    *   `==` 等于
    *   `!=` 不等于
    *   `>` 大于
    *   `<` 小于
    *   `>=` 大于等于
    *   `<=` 小于等于
*   **逻辑运算符**： 用于组合布尔条件。
    *   `and` 逻辑与（两者都为真则结果为真）
    *   `or` 逻辑或（至少一个为真则结果为真）
    *   `not` 逻辑非（取反）

## 控制流

掌握了数据和操作符，下一步是控制程序的执行顺序。控制流语句让程序能够根据条件做出决策或重复执行某些任务。

### 条件语句 (if/elif/else)

`if` 语句用于在条件为真时执行代码块。`elif` 和 `else` 提供了额外的分支。

其基本语法结构如下：
```python
if condition1:
    # 执行语句块1
elif condition2:
    # 执行语句块2
else:
    # 执行语句块3
```

### 循环语句

循环用于重复执行一段代码。

以下是两种主要的循环：

*   **`for` 循环**： 通常用于遍历一个序列（如列表、字符串）中的每个元素。
    ```python
    for item in sequence:
        # 对每个item执行操作
    ```
*   **`while` 循环**： 只要给定的条件为真，就会一直重复执行代码块。
    ```python
    while condition:
        # 条件为真时重复执行
    ```

## 函数

最后，我们将学习如何将代码组织成可重用的模块。函数是一段被命名的、可重复使用的代码块，用于执行特定任务。

定义函数使用 `def` 关键字。函数可以接收输入（参数）并返回输出（返回值）。

一个简单的函数定义如下：
```python
def function_name(parameters):
    """可选的文档字符串，描述函数功能。"""
    # 函数体
    return result  # 可选，用于返回一个值
```

**参数**是传递给函数的值，**返回值**是函数执行后返回的结果。使用函数可以避免代码重复，并使程序结构更清晰。

本节课中我们一起学习了Python编程的基础核心概念：变量与数据类型是信息的载体，运算符是操作信息的工具，控制流决定了程序的执行路径，而函数则将代码封装为可重用的模块。掌握这些内容是迈向有效Python编程的第一步。
