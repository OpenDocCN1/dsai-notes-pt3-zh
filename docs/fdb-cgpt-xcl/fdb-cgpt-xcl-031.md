# 031：什么是提示词？🤔

在本节课中，我们将深入探讨“提示词”这一核心概念。理解提示词的本质、维度和功能，是有效利用大型语言模型（如ChatGPT）进行交互和数据分析的基础。

---

## 概述

提示词是与大型语言模型交互的起点。它远不止是一个简单的问题，而是一个多维度、功能丰富的指令。本节将通过实际与ChatGPT的互动，解析提示词作为动词、形容词、名词的多重含义，并展示其如何跨越时间、唤起记忆、以及如何作为信息输入的渠道。

---

## 提示词的多重含义

我们首先询问ChatGPT“提示词”一词的含义，它给出了几个层面的解释，这有助于我们理解提示词的深度。

### 作为动词：唤起行动

提示词可以是一个动词，意为“促使或鼓励某人做某事”，即**唤起行动**。对于大型语言模型，提示词就是我们对它发出的行动指令，促使其开始为我们生成输出。

**核心公式**：`提示词 = 对模型的“行动调用”`

这个输出可以是各种形式，例如软件代码、诗歌、结构化数据等。关键在于，提示词是我们让模型开始工作的方式。

### 作为形容词：即时性

提示词也可以作为形容词，意为“及时或无延迟地完成”。这引出了关于时间的一个重要思考点。

虽然我们通常“即时”地向模型发出提示，但提示词的效果并不局限于当下。由于大型语言模型具备对话能力，一个提示词可以影响当前对话，也可以为未来的交互设定规则。我们将在后续课程中详细讨论这种“时间跨度”特性。

### 作为名词：提示与输入

作为名词，提示词有两个关键含义：

1.  **提示或提醒**：帮助某人记起他们应该做什么或说什么。在模型交互中，我们可以用提示词来提醒模型记住某些信息或它需要完成的任务，这可能涉及提供对话历史或其他上下文。
2.  **请求输入的消息**：出现在计算机或电子设备上、向用户索取输入的信息。这非常有用，因为通过恰当的结构，大型语言模型也可以反过来向我们提问、索取信息。因此，提示词可以是双向的：既是我们对模型的指令，也可以是模型对我们的提问。

## 通过实例理解提示词的维度

为了更直观地理解上述概念，我们通过一个与ChatGPT的互动示例来展示提示词的多个维度。

### 创建具有时间跨度的提示

首先，我们给出一个影响未来交互的提示：
`从今以后，每当我提问时，请建议一个更好的问题版本，并询问我是否愿意使用它。`

这个提示词附加了“从今以后”的时间条件，它不是一个即时生效的一次性指令，而是为后续所有交互设定了一个持续有效的规则。

### 即时提示与上下文影响

接着，我们提出一个即时问题：
`天空是什么颜色的？`

此时，之前设定的“时间跨度”提示开始生效。ChatGPT没有直接回答颜色，而是遵循规则，生成了一个更好的问题版本：“白天天空呈现蓝色的科学解释是什么？” 并询问我们是否要使用这个改进版。

这个互动展示了：
*   **时间维度**：之前的提示持续影响着当前的交互。
*   **模型对用户的提示**：模型在向我们索取确认（“你是否愿意使用这个版本？”），体现了提示词作为“索取输入”的功能。

### 信息的提供与模型的记忆

当我们对改进后的问题回答“是”时，ChatGPT给出了关于瑞利散射的科学解释。

此外，这个例子也揭示了**记忆**的概念。模型需要记住“从今以后”这个规则，并在后续对话中应用它。例如，当我们再问“世界上有多少个国家？”时，它依然会建议更好的问题版本。

然而，记忆也暴露了模型的**局限性**。当被问及2022年的数据时，ChatGPT会表示其知识截止于2021年9月。

这时，提示词又扮演了另一个角色：**提供新信息**。我们可以将模型训练后发生的事件或它未掌握的私有数据通过提示词提供给模型。例如，我们可以粘贴范德堡大学2022年官方发布的录取数据，然后提问，模型便能基于我们提供的新信息进行推理和回答。



**核心操作**：
```python
# 伪代码示例：通过提示词为模型提供新信息
user_prompt = """
以下是范德堡大学2022年官方发布的录取数据：[粘贴数据]。
基于以上信息，范德堡大学2022年的录取率是多少？
"""
response = chatgpt.generate(user_prompt)
```

## 总结

本节课我们一起学习了提示词的核心概念。我们了解到，提示词是一个多维度的工具：
*   它是**唤起模型行动的指令**。
*   它可以具有**时间属性**，既能即时生效，也能为未来对话设定规则。
*   它可以是**给模型的提醒**，帮助其利用上下文和记忆。
*   它可以是**模型向用户索取输入**的方式。
*   它还能作为**向模型提供新信息**的渠道，弥补其知识截止点的局限。

理解提示词的这些丰富内涵，是进行高效“提示工程”和实现复杂人机交互的第一步。在接下来的课程中，我们将学习如何构建更有效的提示词来解锁大型语言模型的强大分析能力。
