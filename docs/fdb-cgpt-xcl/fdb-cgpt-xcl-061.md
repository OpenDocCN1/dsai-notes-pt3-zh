# 提示工程：P61：尾部生成模式 🎯

在本节课中，我们将要学习一种称为“尾部生成模式”的提示工程技术。这种模式能有效帮助大型语言模型在长对话中记住核心任务和规则，从而维持对话的连贯性和准确性。

## 概述

当我们与大型语言模型进行长对话时，有时会遇到一个挑战：模型可能会忘记我们设定的“游戏规则”或正在执行的核心任务。为了解决这个问题，我们可以使用“尾部生成模式”。其核心思想是，在模型每次输出的**末尾**，都让它生成一段特定的“尾部”文本。这段文本的作用是提醒模型当前对话的上下文、规则或目标，从而帮助它在后续交互中保持正确的方向。

## 模式原理与应用

上一节我们介绍了多种提示模式，本节中我们来看看如何将尾部生成模式与其他模式结合使用。

尾部生成模式的核心是**在模型输出的结尾附加一段固定或特定格式的文本**。这段文本可以：
*   重新陈述任务规则。
*   请求下一步的输入。
*   总结当前对话状态。

一个典型的应用是将其与“替代方案模式”和“请求输入模式”结合。例如，当你要求模型为某个任务生成多个提示方案时，你可以在指令末尾添加：“当你完成后，请询问我下一个需要为其创建替代方案的任务。”

以下是该指令的关键部分解析：
1.  **`当你完成后`**： 指定了尾部生成的时间点。
2.  **`请询问我下一个...任务`**： 应用了“请求输入模式”，引导对话继续。
3.  **`创建替代方案`**： 重申了核心规则（即“替代方案模式”），提醒模型它的核心任务。

## 实战演示

让我们通过一个具体例子来看它是如何工作的。

假设我们给模型的初始指令是：
```
你是一个提示工程助手。我将给你一个任务，请你为该任务生成多个不同的提示方案。当你完成后，请询问我下一个需要为其创建替代提示方案的任务。
```

**第一轮交互**
*   **用户输入**： “写一个提示，让ChatGPT能自动从一系列邮件中检测问题，并以要点形式总结每个人对每个问题的看法。”
*   **模型输出**：
    1.  生成提示方案A...
    2.  生成提示方案B...
    3.  ...
    **尾部**： “请告诉我你是否还有其他任务需要我为其编写提示并创建替代方案。”

**第二轮交互**
*   **用户输入**： “写一个提示来评估不同的问题总结提示。”
*   **模型输出**：
    1.  生成评估提示方案A...
    2.  ...
    **尾部**： “请告诉我你是否还有其他任务需要我为其编写提示并创建替代方案。”

可以看到，每次模型输出后，其生成的尾部都重复了核心指令（“编写提示并创建替代方案”）并主动请求下一个输入。这就像一个内置的“记忆刷新”机制。

## 优势与适用场景

如果没有这个尾部，在多次来回对话后，模型可能会忘记它应该生成“多个”方案，或者忘记整个对话的初始目标。通过持续在输出末尾重新引入游戏规则，每次我们提交新输入时，模型都能获得它完成任务所需的上下文。

尾部生成方法在以下场景中非常有用：
*   **长程编程式对话**： 当你先设定一系列规则，然后进行大量交互时。
*   **需要维持特定上下文**： 任何需要模型不断记住某个关键信息（不一定是规则）的对话。

你可以自由设计尾部的内容，它可以是：
*   对下一步输入的请求。
*   对规则的重述。
*   对当前对话状态的简短总结。
本质上，它是我们附加在模型输出上的一个“小提示”或“小尾巴”，用来提醒模型：“我们一直在讨论什么，在开始下一个任务前，请记住这一点。”

## 总结

本节课中我们一起学习了**尾部生成模式**。这种模式通过**在大型语言模型的每次输出末尾附加一段特定文本**，来持续提醒模型对话的规则、任务或上下文。它能有效延长对话的“记忆”周期，确保在复杂的多轮交互中，模型不会偏离最初设定的目标。你可以将其视为一种简单而强大的对话状态维护工具。
