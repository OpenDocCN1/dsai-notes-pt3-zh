# 提示工程与ChatGPT：06：菜单操作模式 🍔

在本节课中，我们将学习一种名为“菜单操作模式”的提示工程技术。这种模式允许我们在与大型语言模型的对话中，定义并重复使用一系列预设的“动作”，就像在软件菜单中选择功能一样，从而提升交互效率和一致性。

当我们使用计算机软件时，一个非常有用的特性是程序通常有一个包含一系列可执行操作的菜单。例如，文字处理软件中的“文件”菜单允许你执行“新建文件”或“保存文件”的操作。另一个菜单可能允许你“查找和替换”文本。这种拥有菜单和可运行操作的概念非常实用。

有时，在进行提示工程时，尤其是在进行长对话时，在提示中开发类似的功能会很有帮助。其核心思想是，在对话开始时，就定义好一套可以运行的动作集合。这样，我们就不必在对话中反复输入冗长的提示，而是可以将某些对用户有帮助的操作固化下来。

## 菜单操作模式的工作原理

上一节我们介绍了菜单操作模式的基本概念，本节中我们来看看如何具体实现它。这种模式让我们能在提示中获得类似软件菜单的行为。我们将开发一个菜单，它是一系列可以运行的动作。每个动作本质上就是一个提示，是一组我们给大型语言模型的指令，用于在对话的特定时刻执行某项任务。

以下是其工作方式。我们描述需要输入什么内容来触发一个动作。

例如，我定义：**`每当输入“write <bullet_point> <paragraphs>”时`**。

让我稍后详细解释这一点，所以如果现在看起来不太明白，请不要担心。在这个定义中：
*   `write` 是一个关键词。
*   `<bullet_point>` 和 `<paragraphs>` 是占位符。

我实际上是在说：我将输入 `write`，然后输入一个代表要点的占位符，再输入一个代表段落数量的占位符。模型将为我指定的要点撰写内容，并按照我要求的段落数量生成文本。这样，我就创建了一个“撰写文本”的动作。

我还可以保留之前的动作。例如，我之前可能有一个“扩展大纲”的动作，其触发方式是：**`每当输入“<bullet_point>”时`**。这意味着，如果我仅输入一个像 `3.5.2` 这样的大纲编号，模型就知道要扩展该大纲点。

通过这种方式，我定义了一个菜单。现在我有两个动作：我可以扩展我的大纲，或者可以为大纲的某部分撰写文本。这为我的大纲扩展器赋予了更复杂的能力，我将其变成了一个可以交互的“程序”。

## 菜单操作模式的应用示例

以下是该模式的一个具体应用示例。假设我们正在处理一个关于写作的大纲。

首先，我运行“撰写文本”动作。我输入：**`write 3.5.3 2`**。
*   这表示：为大纲中编号为 `3.5.3` 的要点撰写内容，并写两段文字。
*   模型会找到大纲中的 `3.5.3` 要点（例如“尝试不同的语气和风格变化”），然后为其生成两段文本。

这样，我就创建并运行了一个定义好的动作。

接着，我可以运行“扩展大纲”动作。我输入：**`expand 3.5.2`**。
*   模型知道这是一个不同的动作，因此它会去扩展 `3.5.2` 这个要点，生成其子要点。

然后，我再次运行“撰写文本”动作。我输入：**`text 3.5.2.3 1`**。
*   这里我故意打错了关键词（用了 `text` 而非 `write`），但模型基于模式智能地推断出我可能想执行的是 `write` 动作。
*   于是，它找到要点 `3.5.2.3` 并为其撰写了一段文本。

这个例子展示了菜单操作模式的灵活性。我创建了一个复杂的交互程序，可以随时扩展大纲或为特定部分生成文本，而无需重复输入冗长的指令，只需使用定义好的简单格式即可。

## 菜单操作模式的优势与用途

以下是菜单操作模式的主要优势和应用场景：

*   **提升个人效率**：如果你反复使用提示执行相同任务，使用菜单操作模式定义一组常用动作会非常有帮助。你可以快速迭代，使用这些预设动作来处理输出内容，本质上是在对话中构建了自己的程序。
*   **促进团队协作与知识共享**：在一个组织内，多人可能执行相同的工作。他们可以共享这些定义好的动作来自动化不同任务。这有助于提高工作效率，并促进有用的提示在团队间分享。
*   **固化最佳实践**：你无需担心每次都能精确地措辞。一旦一个动作被编写并在菜单中生效，你就可以反复使用它。组织可以共享一套通用的菜单动作，将最佳提示措辞和操作流程固化下来，从而实现知识的共享和重用。
*   **集成到应用场景**：你还可以设想将这些动作嵌入到类似客服门户的“根提示”中。你可以为用户提供一些可运行的动作来查询账户信息。他们可以用自然语言提问，但通过描述“以下是一些您可以运行的操作”，可以获得更精准、更高效的服务。

本节课中，我们一起学习了菜单操作模式。这是一种非常强大的模式，它允许我们轻松地重用已有的提示和动作，与他人分享，并建立提示知识库，从而让我们成为更高效的提示工程师。🍔
