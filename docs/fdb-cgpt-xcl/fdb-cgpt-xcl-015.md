# 015：使用ChatGPT在Excel中创建VBA脚本

![](img/1dc2ae5989af20658bc1efb23a699ad7_0.png)

## 概述
在本节课中，我们将学习如何利用ChatGPT将宏大的想法转化为Excel中的实际应用。我们将重点探索使用ChatGPT生成VBA脚本，以实现比单个单元格公式或图表更复杂的功能。我们将从构思开始，逐步实现一个功能，并学习如何调试和修正ChatGPT生成的代码。

---

我们不应将想象力和目标局限于仅通过列和公式就能实现的功能。我们希望有能力去构思和实现更宏大的应用，而ChatGPT正是将我们的目标和想法转化为计算的伙伴。其中一种方式就是创建VBA脚本。VBA脚本可以实现比单个单元格公式或单一可视化图表复杂得多的功能。

当你开始思考VBA脚本时，我希望你将其视为几乎完整的应用程序，它们能为你完成真正有价值的工作，或自动化复杂的步骤。

上一节我们介绍了VBA脚本的潜力，本节中我们来看看这意味着什么，以及我们如何使用ChatGPT在VBA脚本中实现计算和应用。

我习惯从明确数据基础开始，这对我自己和ChatGPT都有帮助。以下是具体步骤：

*   **列出数据**：明确所有列及其标识符。这有助于回顾，ChatGPT有时会自动做这件事，但我认为这是一个好习惯。你可以选择跳过，但我建议保留。
*   **构思创意**：思考可以用这个电子表格做什么有趣的事情。我喜欢先进行头脑风暴，获取一些灵感。

我将以头脑风暴开始：“我能创建一个什么有趣的VBA脚本来处理这些数据？” 这是电影数据集，我们可以做很多有趣的事情，但我需要花时间探索各种可能性。

ChatGPT回复了一系列想法：
*   **基于类型的电影推荐生成器**：创建一个VBA脚本，允许用户选择一个类型，然后返回该类型的三部随机电影。这个想法很好，比如在周末与家人决定看什么电影时，能选择类型并获得建议会非常棒。
*   **随机电影之夜选择器**：这看起来也很有趣。
*   **电影知识问答游戏**：这个可能真的很有趣。

值得注意的是，在回复底部，ChatGPT甚至直接为我们原型化了其中一个想法，即“基于类型的电影推荐生成器”的VBA脚本。你会看到它生成了实现这个应用的基本代码。

当它生成代码时，也会解释代码的工作原理，这一点非常重要。

当你开始使用ChatGPT实现VBA脚本时，坦白说，你需要具备在Excel中使用VBA脚本的最低水平知识。如果你对此一无所知，你可以尝试按照它的指示去弄明白，如果你有一些编码或其他方面的经验会更有帮助。当然，你也可以从零开始，让它生成VBA脚本，然后按照指示在Excel中实现应用，但要知道，如果你理解代码，这个过程会容易得多。

这一点很重要，因为正如我们稍后将看到的，有时它需要你做一些额外的工作。如果你不知道如何修改代码，有时可能无法实现它的应用。

现在，它告诉我们如何将生成的脚本应用到Excel中：打开VBA编辑器，插入新模块，粘贴代码，然后运行脚本或从宏对话框运行。

让我们按照步骤操作。我按照它的指示，打开了Visual Basic编辑器，插入了一个新模块，复制并粘贴了它生成的VBA脚本（确保复制完整），然后转到宏，选择了“按类型推荐电影”的宏。

到目前为止一切顺利，非常令人兴奋。然而，我遇到了一个运行时错误。

你将看到，这是一个关键点：ChatGPT生成了VBA脚本，但它无法看到你眼前的Excel工作表。当然，如果你给它截图，它可以“看到”，我们稍后会讨论这一点。但它不一定知道具体发生了什么，而且在使用VBA脚本做更复杂的事情时，错误很可能会发生。

此外，我们按照它的指示操作，将其转化为工作表上的应用，我们也可能做了一些忘记告诉它的更改，比如调整了列名或工作表名，现在它引用的是错误的工作表或名称。在这个例子中，我给了它一个与Excel文件对应的CSV文件，但其中没有包含工作表名称。

这里存在各种细微差别，因为大多数时候，它犯错误是因为它无法看到你面前实际的Excel工作表。正因如此，它做出了不正确的假设。很多时候情况就是如此，或者它不知道你正在使用的Excel的确切版本或其他东西的确切版本，从而做出了错误的假设。

因此，我们需要做很多工作就是当错误发生时，向它解释情况，或者告诉它遗漏了哪些假设。在这个案例中，我们遇到了错误，但别担心。

我的做法是截取这个错误的屏幕截图，然后使用多模态提示将其放回提示中。我会展示：“当我运行它时发生了这个。” 我甚至不需要告诉它任何事。当然，你也可以复制粘贴错误信息，或者用文字描述错误。所有这些方式都有效。我只是喜欢截图并放进去，这对我来说通常更快。

当我这样做时，它回复说：“哦，好的。运行时错误‘9’：下标越界，通常意味着VBA试图访问一个不存在或拼写错误的工作表或范围。” 你经常会看到这种情况：你更改了工作表名、列名或移动了它们的位置，而它试图引用的却是错误的列或名称。

因此，很多工作就是来回沟通，确保你在Excel中所做的与ChatGPT所知道的相匹配。在这个案例中，它说脚本中使用了 `ThisWorkbook.Sheets("Sheet1")` 这一行，很可能那是错误的工作表名。

我看了看，立刻知道那不是工作表的名称，我需要修复它。但是，如果我事先查看了代码（我鼓励你无论是否理解代码，在运行前都先查看一下代码），就会发现这一点。

如果你不理解代码，却要用它来做决策（比如让它生成一些分析结果），那么情况就不同了。在这个案例中，它只是推荐电影。如果代码有错误或不完美，谁在乎呢？它只是在启发我，没什么大不了的。

但是，如果你用它来决定一些会产生影响的事情，比如影响一个人的治疗、抵押贷款、某人是否被解雇或加薪等，那么你绝对需要理解代码才能这样做。如果你无法理解VBA脚本，就不要依赖它来为你完成工作。

因此，何时直接使用它，何时不使用，取决于你和你的使用场景。如果是一个有趣、异想天开、易于检查的使用场景，比如为我自己的电影列表做个人推荐，即使它出错了而我却不理解脚本，也不是什么大问题。

如果这将决定一个人是否得到治疗、抵押贷款、某人是否被解雇或加薪等，那么你在使用它之前最好绝对理解脚本。在所有情况下，如果你要用它来做重要决策，你需要理解它，因为最终，是你而不是它对错误负责。如果它犯了错误，而你在不理解或没有进行尽职调查的情况下就采纳并应用了它，那就是你的过错。所以请确保，如果你要将它用于重要事情，你必须理解它。

现在，当它生成代码时，你应该阅读它。你应该寻找代码中的注释，比如它说“将Sheet1更改为你的工作表名称”，而我最初没有这样做，因为我粗心了，我只是直接执行了它。

所以我要去代码中寻找这些任务。在代码中，我看到了一个任务：我需要更改工作表名称。它告诉我要这样做，但我没仔细读。我现在去修复它。当我再次运行时，我得到了我的电影推荐。

它弹出一个对话框，我输入“drama”作为我想推荐的类型，现在它给了我一个推荐列表。我怀疑这个“Ds”是另一个bug，我可以去追踪它，但现在不打算这么做。但我想强调的是，它在代码中确实会犯错误。它非常非常好，但这就是为什么你拥有一些评估其正确性的技能或专业知识很重要，因为错误会发生。你不希望在不检查其代码的情况下，就让它做出重要决策，而它却犯了错误。

在这个案例中，有个有趣的电影“Mall3”，我从未听说过。我去维基百科查了一下，哦，确实有这部电影。这很有趣，也许我这周会去看看。

一旦它构思出想法，我们总是可以回去说：“嘿，那个想法，我现在要你实现它。” 当它扩展一个想法时，一个美妙之处在于它基本上构建了实现该想法的指令和要求，而不需要我们全部手动输入。

所以我要让它给我第二个想法“随机电影之夜选择器”的VBA代码。它给出了所有的VBA脚本，描述了如何实现以及该怎么做。我去使用了这个已经实现的“电影之夜选择器”，是的，它运行了，给了我一个随机电影推荐。

现在，我们可以让它构思想法，但当然我们也可以向它表达我们想要什么或我们的目标。我们可以说：“我想要一些能启发我选择电影的东西”，也许我们会生成那些想法。或者我可以更具体地说：“创建一个VBA脚本，接收一个电影标题，查找其信息，并显示其类型、发行年份和IMDB评分的摘要。” 这样我就不再是头脑风暴了，而是我知道我想要什么，我要你为我用VBA脚本实现它。将我想要的转化为计算，而计算将通过VBA脚本来实现。

它生成并解释了脚本，这里是脚本（我没有全部展示，你明白意思），它可以生成VBA脚本，并解释脚本及其使用方法。我去实现它，让它查找电影“E.T. the Extra-Terrestrial”，它给出了摘要。再次强调，有个小错误：IMDB评分实际上可能是IMDB ID列。所以它又引用了错误的列。这又是你将看到的最常见的错误之一：它对列标识符、工作表标识符和名称等的引用，与你眼前的Excel工作表略有不同。

在这种情况下，我可以跟进并说：“嘿，你知道IMDB评分实际上不是F列（或随便哪一列，我不记得了），是G列。” 我可以告诉它，它可以去调整。但你将始终要做的事情就是确保匹配，并且始终要检查、检查、再检查。

这是快速原型设计，帮助我创建应用。我知道如何查看、检查它，我可以与它聊天来改进和修复代码，或者因为我是计算机科学家，我具备相关技能，可以直接去编辑VBA脚本来实现我想要的功能。你需要弄清楚你打算怎么做。

如果你手动编辑了VBA脚本，你需要将其带回ChatGPT并说：“嘿，这是我手动更新的版本，现在让我们基于这个版本工作。” 如果你不这样做，就会遇到错误。所以，你始终需要在Excel和ChatGPT之间来回沟通，并且要保持列标识符、工作表名称、你当前正在处理的代码、公式、数据等内容的同步。它需要这些上下文才能准确地工作。

另一件事是，随着我们将想法转化为计算，随着我们用它来转化更大、更复杂的事物（如VBA脚本），出现细微错误的可能性会越来越大，因此我们检查、运行和测试事物变得非常重要。

人类也会犯错。随着复杂性的增加，某些软件的代码越复杂，我犯错的可能性就越大。我们在人类系统中如何处理这个问题？我们编写测试，我们检查，我们运行。同样，当你在构建东西时，你也必须去测试、检查并确保它是正确的，因为越复杂，第一次就做对的难度就越大。ChatGPT与人类并无不同，它也会犯错，并且随着复杂性的增加，它也无法免疫于错误。
