## 1. 数据类型概述

在本节课中，我们将学习Python中的数据类型，以及如何进行类型转换。

Python中的数据类型包括：

* **字符串（string）**：用引号表示，例如 `"hello"` 或 `"Python"`。
* **整数（integer）**：没有小数点的数字，例如 `10` 或 `20500`。
* **浮点数（float）**：有小数点的数字，例如 `3.78` 或 `0.049`。

## 2. 类型转换

类型转换是指将一个数据类型转换为另一个数据类型的过程。

### 2.1 类型转换函数

Python提供了`type()`函数，可以用来获取变量的数据类型。

```python
print(type("hello"))  # 输出：<class 'str'>
print(type(7.75))     # 输出：<class 'float'>
print(type(50))       # 输出：<class 'int'>
print(type("word"))   # 输出：<class 'str'>
print(type("10"))     # 输出：<class 'str'>
```

### 2.2 类型转换示例

以下是一些类型转换的示例：

```python
x = "10"
print(int(x))  # 将字符串转换为整数：10

y = 20
print(float(y))  # 将整数转换为浮点数：20.0

z = 5.9
print(int(z))  # 将浮点数转换为整数：5
```

### 2.3 隐式类型转换

隐式类型转换是指Python自动进行类型转换，例如：

```python
x = 8 / 4  # 自动将整数转换为浮点数：2.0
y = 0.0 + 9  # 自动将整数转换为浮点数：9.0
```

### 2.4 显式类型转换

显式类型转换是指手动进行类型转换，例如：

```python
x = int(5.9)  # 将浮点数转换为整数：5
y = str(3)    # 将整数转换为字符串："3"
z = float(2)  # 将整数转换为浮点数：2.0
```

## 3. 类型转换注意事项

在进行类型转换时，需要注意以下几点：

* **数据丢失**：在将浮点数转换为整数时，会丢失小数部分。
* **精度问题**：在将整数转换为浮点数时，可能会出现精度问题。
