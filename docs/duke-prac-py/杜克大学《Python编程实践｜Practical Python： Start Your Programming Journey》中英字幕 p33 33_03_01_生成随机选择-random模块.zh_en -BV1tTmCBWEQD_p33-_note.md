## 随机数与游戏设计

假设你正在玩一个视频游戏，游戏中控制的角色是Terry。Terry需要避开一只左右转动的猫，然后向前跳跃。你的任务是同时将Terry向左或向右移动，并希望避开猫。如果猫每次都向同一方向转动，游戏将不再有趣。例如，如果你已经知道猫会向右转，那么在第二次、第三次玩游戏时，你会知道猫会做什么。每次玩游戏，你只需将Terry向右移动，猫就会错过Terry。这不是很有趣。如果猫的移动是不可预测的，游戏将更有趣、更具挑战性。这意味着猫每次玩游戏时都会向随机方向移动。有时猫会错过，有时猫会抓到Terry。

## 抛硬币的例子

一个更简单的随机性例子是抛硬币并基于硬币哪一面朝上做出决定。假设我们有一个美国25美分硬币，一面是第一任美国总统乔治·华盛顿，另一面可以是许多不同的东西。在这种情况下，另一面是埃利斯岛和纽泽西。你正在决定今天是否去散步。所以你决定将硬币抛向空中。当它落地时，如果乔治·华盛顿的脸朝上，你就去散步。如果埃利斯岛的一面朝上，你今天就不去散步。看起来是正面。

## Python中的随机数

在Python中，没有抛硬币的功能。但是Python有生成指定范围内随机数的方法。随机生成1或2的数字本质上等同于抛硬币。如果随机生成1，那么就等同于25美分硬币乔治·华盛顿的一面朝上。我们可以去散步。但如果随机生成2，那么就等同于25美分硬币埃利斯岛的一面朝上。我们就不去散步。Python使用Python库random模块生成随机数。

## 导入模块

Python库通常被认为是一个借书的地方。你借阅别人写的书，阅读它，然后把它还回图书馆。Python库是一个借代码的地方，称为模块。模块就像一本书，但实际上是一个包含大量相关代码的文件。模块通常包含你可以用于程序的函数。

要访问库模块，你需要使用import语句。使用import单词，后跟模块的名称。import语句位于程序顶部。然后，在import语句下方，你可以使用该模块中的任何函数。

![](img/4985897f7b917ec2888d066aa2dd7bd3_3.png)

## 调用函数

要访问模块中的函数，你必须首先给出模块的名称，然后是点，然后是函数的名称，左括号，任何函数需要的值，我们称之为参数，最后是右括号。

## 内置函数

内置函数已经存在于Python中。我们可以直接使用该函数，而无需导入模块。由于我们没有导入模块，因此在函数前面没有模块名称。

使用函数的另一个名称是调用函数。这两个名称都意味着函数与附加的代码相关联，当执行该行代码时，将运行该代码。

调用函数的格式是函数的名称，后跟左括号，后跟0个或多个参数，然后是右括号。

## random模块

random模块的名称是random。要使用该模块，你需要导入它。我们将查看random模块中的两个函数，这些函数将帮助我们生成随机数。

第一个函数名为randint。它有两个参数：name No 1和number 2。此函数生成介于nu 1和nu 2之间的随机整数，包括nu 1和nu 2。请注意，nu 1和nu 2必须是整数。

另一个函数名为random。它生成介于0.0和1.0之间的随机浮点数，包括0.0，但不包括1.0。每次我们的代码调用该函数时，它都会生成一个不同的随机数。

## 示例代码

以下是使用random模块的示例代码：

```python
import random

# 生成1到3之间的随机整数
number = random.randint(1, 3)
print(number)

# 生成0到1之间的随机浮点数
random_number = random.random()
print(random_number)
```
