# Python编程实践：统计单词中的字符

![](img/36ee16c195b6a49468bd6b6116c9c3fb_0.png)

在本节课中，我们将学习如何使用Python编程来统计单词中某个字符出现的次数。

## 1. 问题背景

假设你想知道一本书中最常见的字母是什么。你需要遍历书中的每个单词，并计算每个字母出现的次数。如果你这样做，那么E可能是最常见的字母，因为它在许多单词中都存在。

## 2. 简化问题

让我们看看一个更简单的问题，我们可以用到目前为止所学的一切来解决它。让我们获取一个字符和一个单词，并计算该字符在单词中出现的次数。

### 2.1 示例

- 如果单词是underrepresented，字符是E，那么我们的程序将告诉我们单词中有五个E。
- 如果单词是butter，字符是T，那么我们的程序将告诉我们单词中有两个T。

## 3. 解决方案

为了计算一个字符在单词中出现的次数，我们需要查看单词中的每个字符。

### 3.1 循环和索引

- 我们需要一个循环来遍历单词中的字符。
- 我们需要一个索引变量来知道我们当前正在查看哪个字符。
- 我们从字符串的第一个字符开始，因此索引需要从0开始。

### 3.2 条件和计数

- 我们需要一个变量来跟踪当前字符出现的次数。
- 我们需要将单词中的每个字符与我们的字符进行比较。

### 3.3 代码示例

```python
word = input("请输入单词：")
character = input("请输入字符：")
index = 0
count = 0

while index < len(word):
    if word[index] == character:
        count += 1
    index += 1

print(f"字符'{character}'在单词'{word}'中出现了{count}次。")
```

## 4. 程序执行过程

以下是程序执行过程的示例：

1. 用户输入单词"boot"和字符"O"。
2. 程序初始化索引变量`index`为0，计数变量`count`为0。
3. 程序进入循环，检查索引0处的字符是否与目标字符匹配。
4. 如果匹配，计数变量`count`增加1。
5. 程序更新索引变量`index`，继续检查下一个字符。
6. 重复步骤3-5，直到索引变量`index`大于或等于单词长度。
7. 程序打印出目标字符在单词中出现的次数。
