## 概述

在本节课中，我们将学习如何使用复合布尔表达式。复合布尔表达式是由多个布尔表达式组合而成的，它们可以用来判断更复杂的条件。

## 复合布尔表达式

### 自然数的判断

假设我们要判断一个数是否是自然数。我们可以将自然数定义为任何正整数。因此，这个数必须是一个正数，并且它必须是一个整数，你才能得出这个数是自然数的结论。这两个条件都必须为真，这个数才能是自然数。

以下是一个表格，用于展示如何判断一个数是否是自然数：

| 数值 (nu) | 是否为正数 (is positive) | 是否为整数 (is int) | 是否为自然数 (is natural) |
|---|---|---|---|
| -3.5 | False | False | False |
| -6 | False | True | False |
| 2.4 | True | False | False |
| 8 | True | True | True |

### 代码示例

以下是一个Python代码示例，用于判断变量`num`是否是自然数：

```python
num = 10
is_positive = num > 0
is_int = type(num) == int
is_natural = is_positive and is_int
```

### 逻辑运算符

Python中有三个常用的逻辑运算符：

- `and`：表示“且”，只有当两个布尔表达式都为真时，结果才为真。
- `or`：表示“或”，只要其中一个布尔表达式为真，结果就为真。
- `not`：表示“非”，用于反转布尔表达式的值。

以下是一些逻辑运算符的示例：

- `A and B`：只有当A和B都为真时，结果才为真。
- `A or B`：只要A或B其中一个为真，结果就为真。
- `not A`：如果A为真，则结果为假；如果A为假，则结果为真。
