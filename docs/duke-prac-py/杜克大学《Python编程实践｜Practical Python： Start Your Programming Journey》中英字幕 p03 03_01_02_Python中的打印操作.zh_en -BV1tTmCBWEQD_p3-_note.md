## 打印操作

### 什么是打印？

打印是让我们看到Python在打印某些内容时正在做什么的一种方式。当我们打印某些内容时，我们将在Python控制台中看到这些内容。

以下是我们在进行任何操作之前Python控制台的外观截图。

这是我们在运行程序并告诉Python打印“hello world”之前的输出外观。

更具体地说，以下是终端中放大的输出。它显示了文本“hello world”，这正是代码告诉Python显示的内容。😊

### 为什么使用打印？

我们可以看到代码运行时的过程。打印对于确保代码正在执行您想要执行的操作非常有用。

如果代码正在为您执行某些任务，例如进行一些计算或玩游戏，打印是Python向您显示正在发生什么的方式。😊

### 如何进行打印？

我们使用`print`函数。我们将在稍后详细介绍函数。现在，重要的是代码首先说“print”，然后是一个左括号。没有空格。

接下来是您想要打印的内容，然后是一个右括号。

### 可以打印什么？

我们可以打印任何内容。让我们先谈谈打印文本，也称为Python中的字符串。字符串由单引号或双引号开头和结尾表示。

您使用哪种引号无关紧要，只要它们匹配即可。否则，Python找不到字符串的结尾。

例如，如果您想要打印经典的、历史悠久的传统“hello world”，这是计算机打印的第一个字符串之一。😊

整个代码行将是`print`，左括号后面没有空格，引号，我在这个例子中使用单引号。

单词“hello world”，另一个单引号，然后是右括号。

### 为什么有两种选项？

为什么我可以使用单引号或双引号？好吧，如果您有一个字符串中包含引号的字符串，比如“it's raining”或“she said hello”，您的代码可以使用另一种引号来包围整个字符串。

如果您想在字符串中使用两种引号，我们稍后会讨论。
