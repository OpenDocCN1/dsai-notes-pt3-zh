## 1. 引言

在本节课中，我们将学习如何在Python中存储数据。了解如何存储数据对于编写程序至关重要，因为程序需要数据来解决问题。

## 2. 数据存储的重要性

我们想要在计算机中存储数据，以便使用计算机解决问题。例如，如果你想要写一个关于三个朋友的故事，但你还没有确定他们的名字。他们的名字会在故事中反复出现。如果决定更改他们的名字，只在一个地方更改每个名字而不是在故事中的每个地方都更改，那岂不是很好？

## 3. 数据类型

Python支持不同类型的数据，这些被称为数据类型。了解你正在处理的数据类型很重要，因为它将决定你可以对该数据执行的所有操作。

### 3.1 字符串

一个数据类型是字符串。你已经学习了字符串及其打印方法。Python使用缩写`STR`表示字符串类型。

字符串由字母、数字和其他字符组成，两侧由单引号或双引号包围。

以下是一些示例：

- `Ho` 是一个由双引号包围的五字母字符串。
- `We to our course` 是一个由单引号包围的21个字母和空格组成的字符串。
- `Was't 2019 a great year?` 是一个包含单引号的字符串。记住，为了在单词“wasn't”中将单引号作为字符串的一部分，我们必须用双引号包围这个字符串。

### 3.2 浮点数

Python将十进制数字称为`float`类型。浮点数由数字0到9组成，一个十进制点或点，以及如果数字为负，则前面的负号。

以下是一些示例：

- `38.5`
- `-6.0`
- `3.14159265`

### 3.3 整数

Python表示的另一种数字类型是整数或整个数字。Python称它们为`int`类型。整数由数字0到9组成，如果数字为负，则前面的负号。

以下是一些示例：

- `89`
- `-5`
- `0`

## 4. 数据存储

所有数据都需要存储在计算机中，以便我们可以使用这些数据。数据存储在计算机内存中的地址位置。

计算机有很多内存位置可以存储数据，这些内存位置是编号的，我们称它们为编号地址位置。

以下是一些示例：

- 地址位置1578存储浮点数68.3。
- 地址位置2450存储字符串“Kia”（我的猫的名字）。
- 地址位置3626存储整数121。

## 5. 变量

变量是用于引用或引用存储在计算机某个内存位置中的值的名称。

Python有一些关于名称的规则。它必须由字母、下划线和数字组成，并且必须以字母开头。变量名称还应描述所存储的值。

以下是一些变量名称示例：

- `Temperature`
- `Bike_price`
- `Name_3`
- `Three_words`

变量名称不能以数字开头。

## 6. 赋值操作符

我们使用赋值操作符将值分配给变量。赋值操作符看起来像一个等号，但我们不会称它为等号，因为这会与数学中使用的等号混淆。赋值操作符用于将值分配给变量。

赋值格式为：首先放置变量名称，然后是赋值操作符，最后是值。

以下是一些示例：

```python
number = 89
number = 3
amount = item
```
