## 逆函数 🔄

函数 **F** 是一个规则，它为每个输入 **x** 分配一个输出 **y**。我们可以将其表示为：**F(x) = y**。

然而，在实际问题中，我们常常需要根据输出 **y** 和函数规则 **F** 来求解输入 **x**，或者根据输入 **x** 和输出 **y** 来求解函数 **F** 本身。求解 **x** 的过程就涉及到寻找函数的逆运算。

![](img/2cca68525264f905dec460c963c03ca8_1.png)

![](img/2cca68525264f905dec460c963c03ca8_3.png)

### 如何求逆函数

![](img/2cca68525264f905dec460c963c03ca8_5.png)

以下是通过一个例子来展示求逆函数的步骤。

给定函数 **F(x) = 2x + 1**，其逆函数的求解过程如下：

1.  将 **y** 表示为 **x** 的函数：**y = 2x + 1**。
2.  解出 **x**：**x = (y - 1) / 2**。
3.  按照惯例，将自变量和因变量互换，用 **x** 表示自变量，用 **y** 表示函数值。因此，逆函数为：**F⁻¹(x) = (x - 1) / 2**。

![](img/2cca68525264f905dec460c963c03ca8_7.png)

我们可以将这个过程总结为以下公式：

> **y = F(x) → 解出 x → 交换 x 和 y → 得到 F⁻¹(x)**

### 一一对应函数与水平线检验法

并非所有函数都有逆函数。只有当函数是“一一对应”时，其逆才是一个有效的函数。

一个函数是**一一对应**的，如果它永远不会取两次相同的值。即，如果 **x₁ ≠ x₂**，那么 **F(x₁) ≠ F(x₂)**。

![](img/2cca68525264f905dec460c963c03ca8_9.png)

我们可以使用**水平线检验法**来直观判断：
如果一个函数的图像被任何水平线穿过**最多一次**，那么它就是一一对应的。

![](img/2cca68525264f905dec460c963c03ca8_11.png)

例如，函数 **y = x²** 在整个定义域上不是一一对应的，因为水平线 **y=4** 会与图像相交于 **x=2** 和 **x=-2** 两点。但是，如果我们将其定义域限制在 **x ≥ 0**，那么它就变成一一对应的了。

![](img/2cca68525264f905dec460c963c03ca8_13.png)

### 逆函数的定义与图像

![](img/2cca68525264f905dec460c963c03ca8_15.png)

![](img/2cca68525264f905dec460c963c03ca8_17.png)

![](img/2cca68525264f905dec460c963c03ca8_19.png)

如果 **F** 是一个定义域为 **A**、值域为 **B** 的一一对应函数，那么它的逆函数 **F⁻¹** 的定义域为 **B**，值域为 **A**，并由以下等式定义：
**F⁻¹(y) = x ⇔ F(x) = y**

由于在求解过程中我们交换了 **x** 和 **y**，因此函数 **y = F(x)** 与其逆函数 **y = F⁻¹(x)** 的图像关于直线 **y = x** 对称。

![](img/2cca68525264f905dec460c963c03ca8_21.png)

## 指数函数 📈

上一节我们探讨了如何求函数的逆，本节我们将目光转向一类重要的函数：指数函数。

![](img/2cca68525264f905dec460c963c03ca8_23.png)

指数函数的形式为：**F(x) = aˣ**，其中底数 **a** 是一个大于0且不等于1的常数。

指数函数具有以下特性：
*   **定义域**：所有实数 **(-∞, ∞)**。
*   **值域**：所有正实数 **(0, ∞)**。
*   **单调性**：
    *   当 **a > 1** 时，函数单调递增（如 **y = 2ˣ, y = 10ˣ**）。
    *   当 **0 < a < 1** 时，函数单调递减（如 **y = (1/2)ˣ, y = (1/10)ˣ**）。

![](img/2cca68525264f905dec460c963c03ca8_25.png)

![](img/2cca68525264f905dec460c963c03ca8_27.png)

### 指数回归：一个应用实例

![](img/2cca68525264f905dec460c963c03ca8_29.png)

![](img/2cca68525264f905dec460c963c03ca8_31.png)

指数函数常用于对增长或衰减过程进行建模。例如，我们可以用它来拟合20世纪世界人口的数据。

以下是进行指数回归分析的步骤：

1.  **建立模型**：假设人口 **P** 与时间 **t** 的关系为 **P(t) = A * Bᵗ**。
2.  **线性化**：为了便于计算，我们对等式两边取对数：**ln(P) = ln(A) + t * ln(B)**。
3.  **变量替换**：令 **α = ln(A)**, **β = ln(B)**, **y = ln(P)**。原方程变为线性方程：**y = α + βt**。
4.  **求解**：利用最小二乘法，根据数据点 **(t, ln(P))** 拟合出最佳的 **α** 和 **β**。
5.  **还原参数**：计算 **A = eᵅ**, **B = eᵝ**，即可得到最终的人口增长指数模型。

![](img/2cca68525264f905dec460c963c03ca8_33.png)

![](img/2cca68525264f905dec460c963c03ca8_35.png)

通过这种方法，我们可以得到一个能很好拟合历史数据点的指数曲线，用于描述和分析人口增长趋势。

![](img/2cca68525264f905dec460c963c03ca8_37.png)

![](img/2cca68525264f905dec460c963c03ca8_39.png)

## 自然常数 e 🧮

在众多指数函数 **y = aˣ** 中，有一个底数 **a** 具有独特的数学性质，它就是自然常数 **e**。

![](img/2cca68525264f905dec460c963c03ca8_45.png)

**e** 被定义为满足以下条件的唯一实数：指数函数 **y = eˣ** 在点 **(0, 1)** 处的切线斜率恰好为 **1**。

![](img/2cca68525264f905dec460c963c03ca8_47.png)

![](img/2cca68525264f905dec460c963c03ca8_48.png)

**e** 是一个无理数，其近似值约为 **2.71828**。它可以通过一个极限公式来计算：
**e = lim (x→0) (1 + x)^(1/x)**

![](img/2cca68525264f905dec460c963c03ca8_50.png)

我们可以编写一个简单的程序来观察这个极限的收敛过程，验证随着 **x** 趋近于0，表达式的值确实趋近于 **e**。

因此，函数 **y = eˣ**（通常写作 **exp(x)**）在数学、科学和工程中具有基础性的重要地位。
