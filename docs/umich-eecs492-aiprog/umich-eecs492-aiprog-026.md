# 026：3.5 - 牛顿法求解非线性方程 📈

在本节课程中，我们将学习牛顿法，这是一种用于求解非线性方程 `F(x) = 0` 的数值方法。牛顿法通过迭代逼近方程的根，具有收敛速度快的特点，是科学计算和工程领域的重要工具。

![](img/3a8a2adc737fb2b25fc988de25aba561_1.png)

## 概述与目标

我们的目标是找到函数 `F(x)` 的一个零点 `P`，即满足 `F(P) = 0` 的点。我们假设 `F(x) = 0` 是一个非线性方程。

基本策略是：从一个初始近似点 `P0` 出发，寻找一个修正项 `H`，使得修正后的点 `P0 + H` 成为比 `P0` 更好的近似解。理想情况下，这个点就是精确解 `P`。

## 牛顿法的推导

![](img/3a8a2adc737fb2b25fc988de25aba561_3.png)

我们假设 `F` 的二阶导数存在且连续，因此可以在点 `P0` 处应用泰勒展开定理。

![](img/3a8a2adc737fb2b25fc988de25aba561_5.png)

![](img/3a8a2adc737fb2b25fc988de25aba561_6.png)

`F(P) = F(P0) + F'(P0) * (P - P0) + (1/2) * F''(ξ) * (P - P0)^2`

![](img/3a8a2adc737fb2b25fc988de25aba561_8.png)

![](img/3a8a2adc737fb2b25fc988de25aba561_9.png)

其中，`H = P - P0`。当 `|H|` 很小时，二阶项 `(1/2) * F''(ξ) * H^2` 也会很小。因此，我们可以合理地忽略这一项，得到近似等式：

![](img/3a8a2adc737fb2b25fc988de25aba561_11.png)

`0 ≈ F(P0) + F'(P0) * H`

将 `F(P0)` 移到等式另一边并除以 `F'(P0)`，我们得到修正项 `H` 的近似值：

![](img/3a8a2adc737fb2b25fc988de25aba561_13.png)

`H ≈ - F(P0) / F'(P0)`

![](img/3a8a2adc737fb2b25fc988de25aba561_15.png)

于是，我们可以用这个修正项来更新我们的近似解，得到一个新的、更好的近似点 `P1`：

`P1 = P0 - F(P0) / F'(P0)`

这个更新过程可以重复进行，这就是求解 `F(x) = 0` 的牛顿法。

## 迭代公式与几何解释

牛顿法的核心迭代公式如下：

![](img/3a8a2adc737fb2b25fc988de25aba561_17.png)

`P_{n+1} = P_n - F(P_n) / F'(P_n)`

从几何角度看，牛顿法有非常直观的解释。给定一个初始近似点 `P0`，我们在曲线 `y = F(x)` 上对应的点 `(P0, F(P0))` 处作切线。这条切线的方程是：

![](img/3a8a2adc737fb2b25fc988de25aba561_19.png)

`y = F(P0) + F'(P0) * (x - P0)`

![](img/3a8a2adc737fb2b25fc988de25aba561_21.png)

接下来，我们寻找这条切线与 x 轴的交点，即令 `y = 0`，解得：

![](img/3a8a2adc737fb2b25fc988de25aba561_23.png)

`x = P0 - F(P0) / F'(P0)`

这个 x 值就是我们的下一个近似点 `P1`。通过不断重复这个过程（在 `P1` 处作切线，求交点得到 `P2`，依此类推），我们得到的点列 `{P_n}` 将收敛到方程的根 `P`。

## 收敛性与注意事项

牛顿法并非总是收敛。其收敛性依赖于初始点 `P0` 的选择和函数 `F` 的性质。

![](img/3a8a2adc737fb2b25fc988de25aba561_25.png)

![](img/3a8a2adc737fb2b25fc988de25aba561_26.png)

一个经典的失败例子是求解 `arctan(x) = 0`。该方程的唯一解是 `x = 0`。如果初始点选为 `P0 = π/2`，牛顿迭代会发散，因为初始点离根太远，且函数的曲率导致切线交点跑到了更远的地方。

牛顿法有效的一个关键条件是导数 `F'(x)` 在根附近远离零。如果 `F'(x)` 为零，迭代公式中的分母为零，方法会失效。

理论上，如果函数 `F` 二阶连续可微，根 `P` 满足 `F'(P) ≠ 0`，并且初始点 `P0` 足够接近 `P`，那么牛顿法产生的序列将以**二次收敛**的速度逼近根 `P`。这意味着当前步的误差大致与上一步误差的平方成正比，收敛速度非常快。

![](img/3a8a2adc737fb2b25fc988de25aba561_28.png)

在某些对称性良好的问题中，甚至可能出现超二次收敛（如立方收敛）。

## 实践应用：计算平方根

![](img/3a8a2adc737fb2b25fc988de25aba561_30.png)

牛顿法的一个经典应用是计算一个正数 `Q` 的平方根，即求解 `x^2 = Q`。

我们可以将其转化为求函数 `F(x) = x^2 - Q` 的零点。此时，`F'(x) = 2x`。代入牛顿迭代公式：

`P_{n+1} = P_n - (P_n^2 - Q) / (2 * P_n)`

![](img/3a8a2adc737fb2b25fc988de25aba561_32.png)

简化后得到：

`P_{n+1} = (1/2) * (P_n + Q / P_n)`

![](img/3a8a2adc737fb2b25fc988de25aba561_34.png)

这个公式非常优美：新的近似值是旧近似值 `P_n` 和 `Q/P_n` 的算术平均。

![](img/3a8a2adc737fb2b25fc988de25aba561_36.png)

以下是该算法的简单实现流程：

![](img/3a8a2adc737fb2b25fc988de25aba561_37.png)

1.  给定待求平方根的正数 `Q`。
2.  初始化近似值 `x`（例如 `x = (Q + 1) / 2` 或 `x = Q`）。
3.  进入循环，重复执行更新：`x = (x + Q / x) / 2`。
4.  当连续两次迭代的结果变化小于某个容差，或达到最大迭代次数时停止。

![](img/3a8a2adc737fb2b25fc988de25aba561_39.png)

例如，计算 `Q = 2` 的平方根，迭代序列会迅速收敛到 `1.414213562...`，通常只需几次迭代就能达到机器精度。这个算法被高效地实现在现代计算机和计算器的 `sqrt()` 函数中。

![](img/3a8a2adc737fb2b25fc988de25aba561_41.png)

![](img/3a8a2adc737fb2b25fc988de25aba561_42.png)

## 总结

本节课我们一起学习了牛顿法求解非线性方程。我们首先了解了其基本思想：通过在当前近似点作切线，并用切线与x轴的交点作为新的近似点。我们推导了其核心迭代公式 `P_{n+1} = P_n - F(P_n) / F'(P_n)`，并从几何角度进行了解释。

![](img/3a8a2adc737fb2b25fc988de25aba561_44.png)

![](img/3a8a2adc737fb2b25fc988de25aba561_46.png)

我们讨论了牛顿法的收敛性，它要求初始点足够接近真根且导数在根处非零，在满足条件时具有快速的二次收敛速度。最后，我们通过计算平方根这个实际例子，展示了牛顿法的强大威力和简洁实现。牛顿法是数值分析中一个基础而重要的工具。
