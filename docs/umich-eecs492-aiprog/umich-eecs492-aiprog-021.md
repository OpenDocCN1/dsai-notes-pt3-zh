## 概述

在本节课中，我们将学习幂级数的基本概念，以及如何使用比率判别法来判断一个幂级数是否收敛。幂级数是表示和分析函数的有力工具，在工程和科学计算中应用广泛。

## 幂级数的定义

![](img/3888e6f12efa6f3bf81628a1cc02349b_4.png)

上一节我们介绍了解析函数的概念，本节中我们来看看如何用幂级数来表示它们。

解析函数是可以无限次微分的函数，因此它们是更平滑的函数。解析函数的单项式基由以下集合给出：**1, x, x², ...**。

幂级数定义如下：

*   关于 **x = 0** 的幂级数具有以下形式：
    `c₀ + c₁x + c₂x² + ... + cₙxⁿ + ...`
*   关于 **x = a** 的幂级数具有以下形式：
    `c₀ + c₁(x - a) + c₂(x - a)² + ... + cₙ(x - a)ⁿ + ...`

在这个表达式中，**a** 被称为级数的中心，而 **c₀, c₁, c₂, ...** 是系数。

## 一个重要的例子：几何级数

![](img/3888e6f12efa6f3bf81628a1cc02349b_6.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_8.png)

以下是幂级数的一个经典例子。

![](img/3888e6f12efa6f3bf81628a1cc02349b_9.png)

取所有系数 **cₙ = 1**，我们得到以下几何级数：
`∑ (n=0 到 ∞) xⁿ`

这个级数收敛于函数 **1/(1 - x)**，但仅在 **|x| < 1** 的区间内成立。你可以通过将 `(1 - x)` 乘以级数 `1 + x + x² + ...` 来验证，结果会得到 1。

![](img/3888e6f12efa6f3bf81628a1cc02349b_11.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_13.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_14.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_15.png)

对于函数 **y = 1/(1 - x)**，我们可以用多项式来逼近它。从常数项 1 开始，然后加上线性项 x，再加上二次项 x²，随着我们使用更高阶的多项式，它能更好地逼近原函数。然而，这种逼近仅在 **x** 介于 -1 和 1 之间时才有效。

## 收敛区间与比率判别法

从上面的例子可以得出两个关键点：
1.  函数可以用幂级数逼近。
2.  幂级数可能只在某个半径为 **R** 的区间内收敛。

![](img/3888e6f12efa6f3bf81628a1cc02349b_17.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_19.png)

因此，对于给定的幂级数，我们首先需要测试它是否收敛。如果级数不收敛，那么讨论它的值就没有意义。

比率判别法是判断级数收敛性的一种常用方法。

设 **∑ aₙ** 是一个级数，并假设以下极限存在：
`L = lim (n→∞) |aₙ₊₁ / aₙ|`

![](img/3888e6f12efa6f3bf81628a1cc02349b_21.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_23.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_25.png)

以下是比率判别法的结论：
*   如果 **L < 1**，则级数绝对收敛。
*   如果 **L > 1**，则级数发散。
*   如果 **L = 1**，则该测试无法得出结论（即无法判断）。

让我们通过例子来应用这个判别法。

## 应用比率判别法

以下是需要判断收敛区间的幂级数。

**例1：** `∑ (n=1 到 ∞) ((-1)ⁿ⁻¹ xⁿ) / n`

我们应用比率判别法。计算相邻项的比率绝对值：
`|aₙ₊₁ / aₙ| = | [xⁿ⁺¹/(n+1)] / [xⁿ/n] | = |x| * [n/(n+1)]`

当 **n → ∞** 时，`n/(n+1) → 1`。因此，极限 **L = |x|**。
*   当 **|x| < 1** 时，级数收敛。
*   当 **|x| > 1** 时，级数发散。
*   当 **|x| = 1**（即 **x = 1** 或 **x = -1**）时，测试无效，需要单独分析。
    *   当 **x = 1** 时，级数变为 `1 - 1/2 + 1/3 - 1/4 + ...`，这是一个收敛的交错级数。
    *   当 **x = -1** 时，级数变为 `-1 - 1/2 - 1/3 - 1/4 - ...`，这是一个发散级数（负的调和级数）。

因此，该幂级数的收敛区间为 **[-1, 1)**，即包含 -1 但不包含 1。

**例2：** `∑ (n=0 到 ∞) xⁿ / n!`

![](img/3888e6f12efa6f3bf81628a1cc02349b_27.png)

![](img/3888e6f12efa6f3bf81628a1cc02349b_29.png)

我们再次应用比率判别法：
`|aₙ₊₁ / aₙ| = | [xⁿ⁺¹/(n+1)!] / [xⁿ/n!] | = |x| / (n+1)`

当 **n → ∞** 时，`|x|/(n+1) → 0`。因为极限 **L = 0**（总是小于1），所以对于 **所有实数 x**，该级数都收敛。这个级数实际上就是函数 **eˣ** 的幂级数展开。

## 幂级数的微分与积分

![](img/3888e6f12efa6f3bf81628a1cc02349b_31.png)

幂级数表示法的一个巨大优势是，在其收敛区间内，我们可以方便地进行逐项微分和积分。

![](img/3888e6f12efa6f3bf81628a1cc02349b_33.png)

假设一个幂级数 `f(x) = ∑ cₙ (x - a)ⁿ` 的收敛半径为 **R**。那么在区间 `|x - a| < R` 内：
*   **导数**：`f'(x) = ∑ n * cₙ (x - a)ⁿ⁻¹`
*   **积分**：`∫ f(x) dx = C + ∑ [cₙ / (n+1)] (x - a)ⁿ⁺¹`

这种逐项操作的能力在许多应用中非常方便。

![](img/3888e6f12efa6f3bf81628a1cc02349b_35.png)

## 实例：指数函数的导数

![](img/3888e6f12efa6f3bf81628a1cc02349b_37.png)

让我们用幂级数来验证指数函数的一个基本性质。

已知 **eˣ = ∑ (n=0 到 ∞) xⁿ / n!**。
我们对其逐项求导：
`d/dx (eˣ) = 0 + 1 + (2x)/(2!) + (3x²)/(3!) + (4x³)/(4!) + ...`
简化后得到：`= 1 + x + x²/2! + x³/3! + ...`
这正是 **eˣ** 本身的级数。因此，我们通过幂级数证明了 `d/dx (eˣ) = eˣ`。

在实际工程应用中，我们经常将无穷级数截断为有限项多项式，以便进行计算或分析。这使得幂级数技术极其有用。
