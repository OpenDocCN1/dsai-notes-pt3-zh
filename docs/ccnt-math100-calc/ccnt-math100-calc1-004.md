## 🔢 数值方法研究极限

![](img/551905b9ef77636cd95bcda25c296289_9.png)

![](img/551905b9ef77636cd95bcda25c296289_10.png)

上一节我们通过图形观察了函数的行为，现在我们将从数值角度进行研究。我们知道 `x = 1` 是一个关键点。

![](img/551905b9ef77636cd95bcda25c296289_12.png)

以下是研究过程：我们创建一个数值表，列出越来越接近 `x = 1` 的值，并计算对应的 `f(x)` 值。由于函数 `f(x) = x + 1`，计算较为简单。

我们选取的 `x` 值如下：0.9， 0.99， 0.999， 这些数值从左侧越来越接近 1。

![](img/551905b9ef77636cd95bcda25c296289_14.png)

对应的 `f(x)` 值则为：1.9， 1.99， 1.999。可以观察到，`f(x)` 的值越来越接近 2。

![](img/551905b9ef77636cd95bcda25c296289_16.png)

因此，我们可以得出结论：当 `x` 从左侧无限接近 1 时，函数 `f(x)` 的极限是 2。我们用以下符号表示：

**公式：**
```
lim_{x→1⁻} f(x) = 2
```

![](img/551905b9ef77636cd95bcda25c296289_18.png)

![](img/551905b9ef77636cd95bcda25c296289_19.png)

这个符号读作“当 `x` 趋近于 1 时的左极限等于 2”。上标中的减号表示“从左侧接近”。

![](img/551905b9ef77636cd95bcda25c296289_20.png)

![](img/551905b9ef77636cd95bcda25c296289_22.png)

## ➡️ 从右侧研究极限

接下来，我们研究从右侧接近 `x = 1` 的情况。这意味着我们选取的 `x` 值都略大于 1。

我们选取的 `x` 值如下：1.1， 1.01， 1.001， 这些数值从右侧越来越接近 1。

对应的 `f(x)` 值则为：2.1， 2.01， 2.001。同样，`f(x)` 的值也越来越接近 2。

![](img/551905b9ef77636cd95bcda25c296289_24.png)

因此，我们得出结论：当 `x` 从右侧无限接近 1 时，函数 `f(x)` 的极限也是 2。我们用以下符号表示：

![](img/551905b9ef77636cd95bcda25c296289_25.png)

![](img/551905b9ef77636cd95bcda25c296289_26.png)

![](img/551905b9ef77636cd95bcda25c296289_27.png)

![](img/551905b9ef77636cd95bcda25c296289_28.png)

![](img/551905b9ef77636cd95bcda25c296289_29.png)

**公式：**
```
lim_{x→1⁺} f(x) = 2
```

![](img/551905b9ef77636cd95bcda25c296289_30.png)

![](img/551905b9ef77636cd95bcda25c296289_31.png)

![](img/551905b9ef77636cd95bcda25c296289_32.png)

这个符号读作“当 `x` 趋近于 1 时的右极限等于 2”。上标中的加号表示“从右侧接近”。

## ↔️ 双侧极限

当我们同时考虑从左、右两侧趋近时，如果左极限和右极限存在且相等，我们就可以定义该点的（双侧）极限。

![](img/551905b9ef77636cd95bcda25c296289_34.png)

对于函数 `f(x)`，由于左极限和右极限都等于 2，因此我们说：

![](img/551905b9ef77636cd95bcda25c296289_36.png)

![](img/551905b9ef77636cd95bcda25c296289_38.png)

![](img/551905b9ef77636cd95bcda25c296289_39.png)

**公式：**
```
lim_{x→1} f(x) = 2
```

这个符号读作“当 `x` 趋近于 1 时，`f(x)` 的极限等于 2”。它不指定方向，意味着从任何方向趋近，结果都相同。

![](img/551905b9ef77636cd95bcda25c296289_41.png)

![](img/551905b9ef77636cd95bcda25c296289_42.png)

## 📈 图形方法验证极限

![](img/551905b9ef77636cd95bcda25c296289_45.png)

现在，让我们从图形角度验证这个结论。观察函数 `f(x)` 的图像，当我们在 `x = 1` 附近无限放大时，无论从左侧还是右侧接近，函数图像的高度（即 `f(x)` 的值）都无限接近 `y = 2` 这条线。

即使我们考虑另一个函数 `g(x)`，它在 `x = 1` 处没有定义（图像上有一个“洞”），但当我们观察 `x = 1` 附近无限接近的点时，函数值依然趋近于 2。

![](img/551905b9ef77636cd95bcda25c296289_47.png)

**核心概念：极限描述的是函数在一点附近的行为，而不是在该点本身的值。** 即使函数在 `x = 1` 处没有定义（如 `g(x)`），或者有定义但值不同（如另一个函数 `h(x)` 在 `x=1` 处值为 3），其极限仍然可以是 2。

![](img/551905b9ef77636cd95bcda25c296289_48.png)

![](img/551905b9ef77636cd95bcda25c296289_49.png)

## 🧮 极限的直观定义

![](img/551905b9ef77636cd95bcda25c296289_52.png)

![](img/551905b9ef77636cd95bcda25c296289_53.png)

![](img/551905b9ef77636cd95bcda25c296289_54.png)

基于以上分析，我们可以给出极限的直观定义。

![](img/551905b9ef77636cd95bcda25c296289_56.png)

![](img/551905b9ef77636cd95bcda25c296289_57.png)

**定义：**
我们说当 `x` 趋近于 `a` 时，函数 `f(x)` 的极限是 `L`，记作：

![](img/551905b9ef77636cd95bcda25c296289_59.png)

**公式：**
```
lim_{x→a} f(x) = L
```

![](img/551905b9ef77636cd95bcda25c296289_61.png)

其含义是：我们可以通过让 `x` 足够接近（但不等于）`a`，来使 `f(x)` 的值任意接近我们想要的极限值 `L`。

![](img/551905b9ef77636cd95bcda25c296289_63.png)

换句话说，如果你希望 `f(x)` 与 `L` 的差距小于某个任意小的正数（例如 ε），你总能找到一个足够小的范围（例如 δ），使得所有在这个范围内（除了 `x = a` 点本身）的 `x` 所对应的 `f(x)` 值，都满足与 `L` 的差距小于 ε。

![](img/551905b9ef77636cd95bcda25c296289_65.png)

**注意：** 这是一个直观的定义。更严谨的数学定义（ε-δ 定义）会在更高级的课程中学习，它用精确的数学语言描述了“任意接近”和“足够接近”的概念。

## ✅ 课程总结

![](img/551905b9ef77636cd95bcda25c296289_71.png)

![](img/551905b9ef77636cd95bcda25c296289_72.png)

本节课中，我们一起学习了：

1.  **数值方法**：通过制作数值表，观察自变量 `x` 趋近某点时，函数值 `f(x)` 的变化趋势。
2.  **左极限与右极限**：学习了 `lim_{x→a⁻}` 和 `lim_{x→a⁺}` 符号的含义与区别。
3.  **双侧极限**：当左极限和右极限存在且相等时，可以定义该点的极限 `lim_{x→a}`。
4.  **极限的核心思想**：极限关注的是函数在一点**附近**的行为，而不是在该点**本身**的值。函数在该点是否有定义、值是多少，都不影响极限的存在与大小。
5.  **极限的直观定义**：初步理解了极限 `lim_{x→a} f(x) = L` 所描述的“无限接近”关系。

![](img/551905b9ef77636cd95bcda25c296289_74.png)

![](img/551905b9ef77636cd95bcda25c296289_75.png)

通过研究三个在 `x=1` 处行为不同（有定义、无定义、有不同定义）但极限相同的函数，我们深刻体会到极限概念的本质。
