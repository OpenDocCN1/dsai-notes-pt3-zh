# 第一部分 40：洛必达法则在指数型未定式中的应用 📘

![](img/b7e4833c8ab7ef5ec7b6feb164435263_1.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_2.png)

在本节课中，我们将学习如何应用洛必达法则求解一种特殊的未定式：**0⁰ 型**。我们将通过一个具体例子，详细演示处理这类涉及指数的未定式的标准步骤。



![](img/b7e4833c8ab7ef5ec7b6feb164435263_6.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_7.png)

## 🔍 问题引入：一个“奇怪”的未定式

![](img/b7e4833c8ab7ef5ec7b6feb164435263_9.png)

我们来看一个需要应用洛必达法则求解的“奇怪”未定式。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_11.png)

考虑以下极限：

![](img/b7e4833c8ab7ef5ec7b6feb164435263_13.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_14.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_15.png)

\[
\lim_{x \to 0^+} x^{\sqrt{x}}
\]



![](img/b7e4833c8ab7ef5ec7b6feb164435263_17.png)

## ❓ 为什么这是未定式？

![](img/b7e4833c8ab7ef5ec7b6feb164435263_18.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_20.png)

如果直接将 `x = 0` 代入表达式，我们会得到形式 `0⁰`。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_22.png)

这是一个**未定式**。我们无法直接确定它的值，因为不同的例子会得到不同的结果。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_23.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_24.png)

以下是两种看似合理的论点：
*   **论点一：结果应为 0**。因为 `0` 的任何非零次幂都是 `0`（例如 `0⁷ = 0`）。
*   **论点二：结果应为 1**。因为任何非零数的 `0` 次幂都是 `1`（例如 `1⁰ = 1`, `0.01⁰ = 1`）。

因此，`0⁰` 是一个特例，它既可能趋向 `0`，也可能趋向 `1`，具体取决于函数本身，我们需要通过计算来求解。



## 🛠️ 核心策略：利用对数转换

![](img/b7e4833c8ab7ef5ec7b6feb164435263_26.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_27.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_28.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_29.png)

我们不知道如何处理指数，但知道如何处理乘积。因此，解决这类指数型未定式的**核心技巧是使用自然对数**，因为对数可以将指数运算转换为乘法运算。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_30.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_31.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_33.png)

我们不直接计算原极限，而是先计算其自然对数的极限：

![](img/b7e4833c8ab7ef5ec7b6feb164435263_35.png)

\[
L = \lim_{x \to 0^+} \ln(x^{\sqrt{x}})
\]

![](img/b7e4833c8ab7ef5ec7b6feb164435263_36.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_37.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_39.png)

利用对数性质 `ln(aᵇ) = b * ln(a)`，我们可以将其改写为乘积形式：

\[
L = \lim_{x \to 0^+} [\sqrt{x} \cdot \ln(x)]
\]



![](img/b7e4833c8ab7ef5ec7b6feb164435263_41.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_42.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_43.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_44.png)

## 🔄 从未定式到未定式

![](img/b7e4833c8ab7ef5ec7b6feb164435263_46.png)

现在分析这个新极限。当 `x → 0⁺` 时：
*   `√x → 0`
*   `ln(x) → -∞`

因此，我们得到了 `0 * (-∞)` 型的未定式。我们只是将 `0⁰` 型未定式转换成了 `0 * ∞` 型，问题依然存在。



![](img/b7e4833c8ab7ef5ec7b6feb164435263_48.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_49.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_51.png)

## 📐 构造可应用洛必达法则的形式

洛必达法则适用于 `0/0` 或 `∞/∞` 型的**分式**。目前我们有一个乘积，但可以将其改写为分式。

将 `√x` 移到分母，使其指数变为负：

\[
L = \lim_{x \to 0^+} \frac{\ln(x)}{x^{-1/2}}
\]

![](img/b7e4833c8ab7ef5ec7b6feb164435263_53.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_54.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_55.png)

现在，当 `x → 0⁺` 时：
*   分子 `ln(x) → -∞`
*   分母 `x^{-1/2} → +∞`

![](img/b7e4833c8ab7ef5ec7b6feb164435263_57.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_58.png)

我们得到了 `(-∞) / (+∞)` 型的未定式。这是一个分式，因此可以应用洛必达法则。



![](img/b7e4833c8ab7ef5ec7b6feb164435263_60.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_62.png)

## ⚙️ 应用洛必达法则求解

![](img/b7e4833c8ab7ef5ec7b6feb164435263_64.png)

对分子和分母分别求导：
*   分子 `ln(x)` 的导数为 `1/x`。
*   分母 `x^{-1/2}` 的导数为 `(-1/2) * x^{-3/2}`。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_66.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_67.png)

应用洛必达法则：

\[
L = \lim_{x \to 0^+} \frac{1/x}{(-1/2) * x^{-3/2}}
\]

![](img/b7e4833c8ab7ef5ec7b6feb164435263_69.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_70.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_71.png)

化简这个复杂的表达式：

![](img/b7e4833c8ab7ef5ec7b6feb164435263_73.png)

\[
L = \lim_{x \to 0^+} \frac{1}{x} * \frac{-2}{1} * x^{3/2} = \lim_{x \to 0^+} (-2x^{1/2})
\]

现在，这是一个确定的形式。将 `x = 0` 代入：

![](img/b7e4833c8ab7ef5ec7b6feb164435263_75.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_76.png)

\[
L = -2 * 0^{1/2} = 0
\]

![](img/b7e4833c8ab7ef5ec7b6feb164435263_77.png)

所以，我们得到：

\[
\lim_{x \to 0^+} \ln(x^{\sqrt{x}}) = 0
\]



![](img/b7e4833c8ab7ef5ec7b6feb164435263_79.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_80.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_81.png)

## 🎯 得到最终答案

请注意，我们计算的是原函数自然对数的极限 `L = 0`，而不是原函数本身的极限。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_83.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_84.png)

为了得到原极限，我们需要“撤销”自然对数运算，即对结果取指数函数 `e^L`：

![](img/b7e4833c8ab7ef5ec7b6feb164435263_86.png)

\[
\lim_{x \to 0^+} x^{\sqrt{x}} = e^{L} = e^{0} = 1
\]

因此，最终答案是：

\[
\lim_{x \to 0^+} x^{\sqrt{x}} = 1
\]



## 📝 课程总结

![](img/b7e4833c8ab7ef5ec7b6feb164435263_88.png)

本节课我们一起学习了如何应用洛必达法则处理复杂的指数型未定式。

以下是处理各类未定式的策略总结：

*   **简单型**：如 `0/0` 或 `∞/∞`。可以直接应用洛必达法则：对分子分母分别求导，再求极限。

*   **中等型**：如 `∞ - ∞` 或 `0 * ∞`。这些不是直接的分式。需要通过代数技巧（如通分、将其中一个因子移至分母等）将其转化为 `0/0` 或 `∞/∞` 型，然后再应用洛必达法则。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_90.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_91.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_92.png)

*   **棘手型（指数型）**：如 `1^∞`, `∞⁰`, `0⁰`。这是最棘手的一类。
    处理这类问题的**标准流程**如下：
    1.  设原极限为 `y`。
    2.  取自然对数，得到 `ln(y)`，这将指数转换为乘积。
    3.  计算 `ln(y)` 的极限，过程中可能需要使用上述技巧将其转化为可分式，并应用洛必达法则。
    4.  得到 `ln(y) = L` 后，原极限 `y = eᴸ`。

![](img/b7e4833c8ab7ef5ec7b6feb164435263_93.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_94.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_95.png)

![](img/b7e4833c8ab7ef5ec7b6feb164435263_96.png)

通过掌握这些策略，你就能系统地应用洛必达法则求解各种类型的未定式极限了。
