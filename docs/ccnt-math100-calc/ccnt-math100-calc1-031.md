# 第一部分 31：使用隐函数微分法求反三角函数的导数 📚

在本节课中，我们将学习如何使用隐函数微分法来推导反三角函数的导数。我们将以反正切函数为例，详细讲解推导过程，并介绍如何将这一方法应用于其他反三角函数。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_4.png)

## 概述

我们再次讨论老朋友反正切函数。之前我们见过正切函数的图像，而反正切函数是通过交换 x 和 y 坐标，或者说在直线 y = x 上进行反射得到的，至少在定义域 (-π/2, π/2) 内是如此。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_6.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_7.png)

那么问题是，对于反正切函数以及其他反三角函数，它们的导数是什么？我们可以使用隐函数微分法来回答这些问题。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_9.png)

## 从定义出发

![](img/273c8af4b1dc3d53775567dd0b4b5df5_12.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_13.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_14.png)

首先，我们需要回顾一下定义。说 Y 是 x 的反正切函数，即 `Y = arctan(x)`，其等价含义是，我们可以反过来写：对 Y 取正切，得到 `tan(Y)`。由于正切和反正切是反函数，它们会相互抵消，最终得到内部的变量本身。因此，`Y = arctan(x)` 等价于 `tan(Y) = x`。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_16.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_17.png)

用公式表示这个关系：
```
Y = arctan(x)  ⇔  tan(Y) = x
```

## 应用隐函数微分法

![](img/273c8af4b1dc3d53775567dd0b4b5df5_19.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_20.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_21.png)

接下来，我们对等式 `tan(Y) = x` 的两边同时对 x 求导。注意，这里 Y 是 x 的函数，所以我们需要使用隐函数微分法。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_23.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_25.png)

左边 `tan(Y)` 是一个复合函数：外层是正切函数，内层是 `Y(x)`。因此，我们需要使用链式法则。

以下是求导步骤：
1.  对 `tan(Y)` 求导，得到 `sec²(Y)`。
2.  乘以内层函数 `Y` 的导数，即 `dY/dx`。
3.  右边 `x` 对 x 求导，结果为 1。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_27.png)

将这个过程写成等式：
```
d/dx [tan(Y)] = d/dx [x]
sec²(Y) * (dY/dx) = 1
```

## 解出导数 dY/dx

![](img/273c8af4b1dc3d53775567dd0b4b5df5_29.png)

![](img/273c8af4b1dc3d53775567dd0b4b5df5_30.png)

我们的目标是求出 `dY/dx`，即 `arctan(x)` 的导数。从上一步的等式 `sec²(Y) * (dY/dx) = 1` 出发，我们可以解出 `dY/dx`：
```
dY/dx = 1 / sec²(Y)
```
这个结果 `1 / sec²(Y)` 是正确的，但它仍然是用变量 Y 表示的。对于一个显函数的导数，我们通常希望它最终表示为 x 的函数。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_31.png)

## 利用三角恒等式转换为 x 的函数

![](img/273c8af4b1dc3d53775567dd0b4b5df5_33.png)

为了将 `1 / sec²(Y)` 用 x 表示，我们需要回忆几个重要的三角恒等式——毕达哥拉斯恒等式。

以下是三个基本的毕达哥拉斯恒等式：
*   `sin²θ + cos²θ = 1`
*   `tan²θ + 1 = sec²θ`
*   `1 + cot²θ = csc²θ`

通常只需记住第一个，因为后两个可以通过第一个推导出来。例如，将 `sin²θ + cos²θ = 1` 两边同时除以 `cos²θ`，即可得到 `tan²θ + 1 = sec²θ`。

![](img/273c8af4b1dc3d53775567dd0b4b5df5_35.png)

在我们的表达式中，`1 / sec²(Y)` 正好对应于 `1 / (tan²(Y) + 1)`。根据恒等式 `sec²(Y) = tan²(Y) + 1`，我们可以进行替换：
```
dY/dx = 1 / sec²(Y) = 1 / (tan²(Y) + 1)
```

## 代入原始关系完成推导

还记得我们最初的等价关系吗？`tan(Y) = x`。现在，我们可以将 `tan(Y)` 替换为 `x`：
```
dY/dx = 1 / (x² + 1)
```
最后，我们记得 `Y = arctan(x)`。因此，我们得到了反正切函数的导数公式：
```
d/dx [arctan(x)] = 1 / (x² + 1)
```
