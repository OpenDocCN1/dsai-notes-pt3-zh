## 🔍 显式函数与隐式函数

![](img/cbe46532801f8f8e83b2fa755bf49543_10.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_11.png)

到目前为止，微积分课程中我们主要关注的是**显式函数**。这类函数中，`y` 被直接表示为 `x` 的函数，例如 `y = f(x)`。我们通常的问题是：能否对这个函数求导？即求 `f'(x)`。

![](img/cbe46532801f8f8e83b2fa755bf49543_13.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_14.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_15.png)

但很多函数并非自然以显式形式给出，而是以**隐式**形式给出。以下是一个例子：

```
x² + y² = 1
```

![](img/cbe46532801f8f8e83b2fa755bf49543_17.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_18.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_19.png)

对于每一个 `x` 值，可能存在一个或多个 `y` 值，使得这对 `(x, y)` 满足该方程。因此，我们想探讨：给定一个隐函数（即一个包含 `x` 和 `y` 的方程），我们能否从中推导出显式函数？

![](img/cbe46532801f8f8e83b2fa755bf49543_21.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_22.png)

## ⭕ 从隐式方程到显式函数

例如，方程 `x² + y² = 1` 描述的是一个半径为 1 的圆。我们可以尝试将其解为 `y` 关于 `x` 的函数。

![](img/cbe46532801f8f8e83b2fa755bf49543_26.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_27.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_28.png)

首先，将 `y` 移到一边：
```
y² = 1 - x²
```

![](img/cbe46532801f8f8e83b2fa755bf49543_30.png)

然后，为了得到 `y` 的显式表达式，我们取平方根：
```
y = ±√(1 - x²)
```

然而，这里出现了问题：正负号意味着对于同一个 `x` 值，有两个可能的 `y` 值。这违反了函数的垂直线检验（一个 `x` 值只能对应一个 `y` 值）。从图形上看，画一条垂直线会与圆相交于两点。

![](img/cbe46532801f8f8e83b2fa755bf49543_32.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_34.png)

因此，我们无法找到一个单一的显式函数 `y = f(x)` 来描述整个圆。但我们可以将其分解为两个函数：
*   `y = +√(1 - x²)` 描述上半圆（黄色部分）。
*   `y = -√(1 - x²)` 描述下半圆（红色部分）。

所以，一个隐式方程可以对应多个显式函数。

![](img/cbe46532801f8f8e83b2fa755bf49543_36.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_37.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_38.png)

## 🧮 隐函数求导法

现在，我们的问题是：如何求 `y` 关于 `x` 的导数 `dy/dx`？

一种方法是，如果我们关心上半圆某点的导数，就使用 `y = +√(1 - x²)` 求导；如果关心下半圆，就使用 `y = -√(1 - x²)` 求导。但我们希望有一个更系统的方法。

![](img/cbe46532801f8f8e83b2fa755bf49543_40.png)

**核心思想**是：将 `y` 视为 `x` 的函数（即使我们不知道其具体表达式），然后对原方程两边同时关于 `x` 求导。

![](img/cbe46532801f8f8e83b2fa755bf49543_42.png)

让我们对 `x² + y² = 1` 应用这个方法。我们将 `y` 视为 `y(x)`。

![](img/cbe46532801f8f8e83b2fa755bf49543_43.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_44.png)

对等式两边关于 `x` 求导：
```
d/dx [x²] + d/dx [y²] = d/dx [1]
```

![](img/cbe46532801f8f8e83b2fa755bf49543_46.png)

以下是求导过程：
*   `d/dx [x²] = 2x`
*   `d/dx [1] = 0`
*   `d/dx [y²]` 需要用到链式法则。将 `y²` 视为外层函数（平方）和内层函数（`y`）的复合。因此，其导数为：`2y * dy/dx`。

![](img/cbe46532801f8f8e83b2fa755bf49543_48.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_49.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_50.png)

将以上结果组合起来：
```
2x + 2y * (dy/dx) = 0
```

现在，我们可以解出 `dy/dx`：
1.  将 `2x` 移到右边：`2y * (dy/dx) = -2x`
2.  两边同时除以 `2y`：`dy/dx = -x / y`

于是，我们得到了隐函数导数的通用公式：
```
dy/dx = -x / y
```

![](img/cbe46532801f8f8e83b2fa755bf49543_53.png)

## 📐 应用：求特定点的切线斜率

![](img/cbe46532801f8f8e83b2fa755bf49543_59.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_61.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_62.png)

现在，让我们应用这个公式来解决一个具体问题：求圆 `x² + y² = 1` 在点 `(-1/√2, 1/√2)` 处的切线斜率。

根据我们的公式，该点的斜率为：
```
dy/dx = -x / y
```

将坐标 `(x, y) = (-1/√2, 1/√2)` 代入：
```
dy/dx = -(-1/√2) / (1/√2) = (1/√2) / (1/√2) = 1
```

![](img/cbe46532801f8f8e83b2fa755bf49543_64.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_65.png)

因此，在该点处切线的斜率为 **1**。从图形上看，切线是一条斜率为 1 的直线。

![](img/cbe46532801f8f8e83b2fa755bf49543_66.png)

## ⚠️ 特殊情况：导数为无穷大

值得注意的是，当 `y = 0` 时（例如在点 `(-1, 0)` 或 `(1, 0)`），我们的公式 `dy/dx = -x / y` 会导致分母为零。

![](img/cbe46532801f8f8e83b2fa755bf49543_74.png)

![](img/cbe46532801f8f8e83b2fa755bf49543_75.png)

例如，在点 `(-1, 0)` 处：
```
dy/dx = -(-1) / 0 = 1/0
```

![](img/cbe46532801f8f8e83b2fa755bf49543_77.png)

这在数学上表示导数不存在（或为无穷大），对应于图形上一条**垂直的切线**。这与圆的几何性质相符：在圆的最左端和最右端，切线是垂直的。

---

## 📝 总结

本节课中我们一起学习了：
1.  **隐式函数**与显式函数的区别。
2.  一个隐式方程（如 `x² + y² = 1`）可能对应多个显式函数。
3.  **隐函数求导**的核心方法：将 `y` 视为 `x` 的函数，然后对等式两边同时关于 `x` 求导，并利用**链式法则**处理包含 `y` 的项。
4.  最终解出 `dy/dx` 的表达式，该表达式通常同时包含 `x` 和 `y`。
5.  利用求得的导数公式，可以计算曲线上任意给定点的切线斜率。
6.  当公式中分母为零时，意味着该点切线垂直。
