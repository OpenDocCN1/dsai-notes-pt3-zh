## 🔍 理解反余切函数

![](img/55010ec7a76cc6b2930b03878591286a_8.png)

![](img/55010ec7a76cc6b2930b03878591286a_9.png)

![](img/55010ec7a76cc6b2930b03878591286a_10.png)

上一节我们介绍了极限的基本概念，本节中我们来看看一个具体的例子：计算当 `x` 趋于无穷大时，`arctan(x)` 的极限。这里有两个可能带来困惑的点：一是 `x` 趋于无穷大，二是 `arctan(x)` 函数本身。

![](img/55010ec7a76cc6b2930b03878591286a_11.png)

![](img/55010ec7a76cc6b2930b03878591286a_12.png)

![](img/55010ec7a76cc6b2930b03878591286a_13.png)

首先，我们需要理解 `arctan(x)` 是什么。它是正切函数 `tan(x)` 的反函数。反函数意味着交换了 `x` 和 `y` 的角色。以下是正切函数 `tan(x)` 的图像：

![](img/55010ec7a76cc6b2930b03878591286a_15.png)

![](img/55010ec7a76cc6b2930b03878591286a_16.png)

![](img/55010ec7a76cc6b2930b03878591286a_8.png)

![](img/55010ec7a76cc6b2930b03878591286a_18.png)

正切函数是周期函数，在 `x = π/2` 和 `x = -π/2` 处有垂直渐近线。

![](img/55010ec7a76cc6b2930b03878591286a_19.png)

![](img/55010ec7a76cc6b2930b03878591286a_20.png)

![](img/55010ec7a76cc6b2930b03878591286a_21.png)

而 `arctan(x)` 的图像可以通过将 `tan(x)` 的图像关于直线 `y = x` 翻转得到：

![](img/55010ec7a76cc6b2930b03878591286a_23.png)

![](img/55010ec7a76cc6b2930b03878591286a_25.png)

![](img/55010ec7a76cc6b2930b03878591286a_25.png)

`arctan(x)` 有时也写作 `tan⁻¹(x)`。这里的 `-1` 表示反函数，而不是 `1/tan(x)`。为了避免混淆，我们通常写作 `arctan(x)`。

![](img/55010ec7a76cc6b2930b03878591286a_26.png)

反函数的一个重要性质是复合函数会得到恒等函数，即：
```
tan(arctan(x)) = x
arctan(tan(x)) = x
```
需要注意的是，这个性质只在正切函数的主值区间 `(-π/2, π/2)` 内成立。

![](img/55010ec7a76cc6b2930b03878591286a_28.png)

![](img/55010ec7a76cc6b2930b03878591286a_29.png)

## 📈 计算 `arctan(x)` 在无穷远处的极限

![](img/55010ec7a76cc6b2930b03878591286a_34.png)

现在，我们回到最初的问题：计算 `lim (x→∞) arctan(x)`。

![](img/55010ec7a76cc6b2930b03878591286a_36.png)

观察 `arctan(x)` 的图像，当 `x` 变得非常大（趋于正无穷）时，函数值会趋近于一个特定的值。从图像上看，曲线会逐渐变平，接近一条水平线。

为了确定这个值，我们可以回想 `tan(x)` 的图像。当 `x` 从左侧趋近于 `π/2` 时，`tan(x)` 的值趋于正无穷。因此，对于其反函数 `arctan(x)`，当 `x` 趋于正无穷时，其函数值就趋近于 `π/2`。

![](img/55010ec7a76cc6b2930b03878591286a_38.png)

所以，我们得出结论：
```
lim (x→∞) arctan(x) = π/2
```
我们称 `y = π/2` 是函数在 `x` 趋于正无穷时的一条**水平渐近线**。

![](img/55010ec7a76cc6b2930b03878591286a_39.png)

![](img/55010ec7a76cc6b2930b03878591286a_40.png)

![](img/55010ec7a76cc6b2930b03878591286a_42.png)

## 📉 计算 `arctan(x)` 在负无穷远处的极限

同理，我们可以计算当 `x` 趋于负无穷时的极限：`lim (x→-∞) arctan(x)`。

![](img/55010ec7a76cc6b2930b03878591286a_45.png)

![](img/55010ec7a76cc6b2930b03878591286a_46.png)

观察图像，当 `x` 趋于负无穷时，`arctan(x)` 的函数值趋近于 `-π/2`。这是因为在 `tan(x)` 的图像中，当 `x` 从右侧趋近于 `-π/2` 时，函数值趋于负无穷。

![](img/55010ec7a76cc6b2930b03878591286a_48.png)

![](img/55010ec7a76cc6b2930b03878591286a_49.png)

因此，我们得到：
```
lim (x→-∞) arctan(x) = -π/2
```
`y = -π/2` 是函数在 `x` 趋于负无穷时的另一条**水平渐近线**。

![](img/55010ec7a76cc6b2930b03878591286a_50.png)

`arctan(x)` 是一个非常有用的函数，在后续课程中我们会经常用到它。

## ⚡ 分析指数函数 `e^x` 的极限

![](img/55010ec7a76cc6b2930b03878591286a_59.png)

接下来，我们用同样的思路分析指数函数 `e^x` 在无穷远处的行为。以下是 `e^x` 的图像：

![](img/55010ec7a76cc6b2930b03878591286a_61.png)

![](img/55010ec7a76cc6b2930b03878591286a_72.png)

我们先看 `x` 趋于负无穷的情况。从图像可以看出，当 `x` 越来越小（趋于负无穷）时，`e^x` 的值越来越接近 0。

![](img/55010ec7a76cc6b2930b03878591286a_63.png)

![](img/55010ec7a76cc6b2930b03878591286a_64.png)

![](img/55010ec7a76cc6b2930b03878591286a_65.png)

![](img/55010ec7a76cc6b2930b03878591286a_66.png)

因此：
```
lim (x→-∞) e^x = 0
```
`y = 0` 是 `e^x` 在 `x` 趋于负无穷时的一条**水平渐近线**。

![](img/55010ec7a76cc6b2930b03878591286a_68.png)

![](img/55010ec7a76cc6b2930b03878591286a_70.png)

## 🚀 `e^x` 在正无穷处的行为

现在看 `x` 趋于正无穷的情况。当 `x` 变得非常大时，`e^x` 的值会变得巨大，并且持续增长，永远不会趋近于任何一个有限的数值。

它不会像 `arctan(x)` 那样“变平”并接近一个固定值。它会超过一百万、十亿、万亿，并且无限增长下去。

![](img/55010ec7a76cc6b2930b03878591286a_75.png)

![](img/55010ec7a76cc6b2930b03878591286a_76.png)

![](img/55010ec7a76cc6b2930b03878591286a_77.png)

![](img/55010ec7a76cc6b2930b03878591286a_78.png)

![](img/55010ec7a76cc6b2930b03878591286a_79.png)

因此，我们说：
```
lim (x→∞) e^x = ∞
```
这表示函数在 `x` 趋于正无穷时是**无界的**，会发散到无穷大。所以，在正无穷方向，`e^x` 没有水平渐近线。

![](img/55010ec7a76cc6b2930b03878591286a_81.png)

![](img/55010ec7a76cc6b2930b03878591286a_82.png)

对于 `e^x` 这类函数，其特点是：在一侧（负无穷）有水平渐近线，而在另一侧（正无穷）则发散至无穷。

![](img/55010ec7a76cc6b2930b03878591286a_84.png)

## 📝 本节课总结

![](img/55010ec7a76cc6b2930b03878591286a_87.png)

![](img/55010ec7a76cc6b2930b03878591286a_88.png)

本节课中我们一起学习了如何计算函数在自变量趋于无穷大时的极限。

![](img/55010ec7a76cc6b2930b03878591286a_89.png)

![](img/55010ec7a76cc6b2930b03878591286a_90.png)

我们通过两个核心例子进行了分析：
1.  **反余切函数 `arctan(x)`**：
    *   当 `x → ∞` 时，极限为 `π/2`。
    *   当 `x → -∞` 时，极限为 `-π/2`。
    *   函数在正负无穷远处均有**水平渐近线**。
2.  **指数函数 `e^x`**：
    *   当 `x → -∞` 时，极限为 `0`，存在水平渐近线 `y=0`。
    *   当 `x → ∞` 时，极限为 `∞`，函数无界发散，没有水平渐近线。

![](img/55010ec7a76cc6b2930b03878591286a_92.png)

![](img/55010ec7a76cc6b2930b03878591286a_93.png)

![](img/55010ec7a76cc6b2930b03878591286a_94.png)
