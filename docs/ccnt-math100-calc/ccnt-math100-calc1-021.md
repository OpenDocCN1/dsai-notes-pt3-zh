上一节我们定义了导数。本节的目标是开始系统地计算各种常见函数的导数。我们希望不只是计算单个函数的导数，而是能理解一类函数的求导方法。本节课将首先处理两个基础案例：常数函数和 `x²`。

![](img/9295de359ac14eb5578bc3205359f0f6_7.png)

在讲解过程中，我会交替使用两种导数符号：莱布尼茨记法 `d/dx` 和拉格朗日记法 `f'(x)`。对于通用函数 `f`，我常用 `f'(x)`；对于具体函数，则常用 `d/dx`。它们都表示求导运算。

## 📉 常数函数的导数

首先，我们考虑常数函数 `f(x) = C`，其中 `C` 是一个常数。它的图像是一条水平直线。

![](img/9295de359ac14eb5578bc3205359f0f6_14.png)

![](img/9295de359ac14eb5578bc3205359f0f6_15.png)

![](img/9295de359ac14eb5578bc3205359f0f6_16.png)

从几何角度看，导数是切线的斜率。对于这条水平线，其切线就是它本身。由于水平线没有“上升”，其斜率为零。

![](img/9295de359ac14eb5578bc3205359f0f6_17.png)

因此，我们可以得出结论：常数函数的导数为零。

![](img/9295de359ac14eb5578bc3205359f0f6_19.png)

![](img/9295de359ac14eb5578bc3205359f0f6_20.png)

![](img/9295de359ac14eb5578bc3205359f0f6_21.png)

用公式表示如下：

**公式：**
```
d/dx [C] = 0
或
若 f(x) = C，则 f'(x) = 0
```

## 🔄 过渡到幂函数

![](img/9295de359ac14eb5578bc3205359f0f6_29.png)

![](img/9295de359ac14eb5578bc3205359f0f6_30.png)

在理解了常数函数的导数后，我们接下来看看一个更复杂的函数：`f(x) = x²`。它的图像是一条抛物线。

对于常数函数，通过观察图像就能直观得到导数。但对于抛物线，其切线斜率的变化并不那么显而易见。因此，我们需要回到导数的**极限定义**，通过代数运算来严格推导其导数。

---

## 🧮 使用定义求 x² 的导数

![](img/9295de359ac14eb5578bc3205359f0f6_32.png)

![](img/9295de359ac14eb5578bc3205359f0f6_33.png)

![](img/9295de359ac14eb5578bc3205359f0f6_34.png)

我们的目标是计算 `d/dx [x²]`。我们将使用导数的正式极限定义：

![](img/9295de359ac14eb5578bc3205359f0f6_35.png)

![](img/9295de359ac14eb5578bc3205359f0f6_36.png)

![](img/9295de359ac14eb5578bc3205359f0f6_37.png)

![](img/9295de359ac14eb5578bc3205359f0f6_38.png)

![](img/9295de359ac14eb5578bc3205359f0f6_39.png)

**定义：**
```
f'(x) = lim (h -> 0) [ (f(x+h) - f(x)) / h ]
```

![](img/9295de359ac14eb5578bc3205359f0f6_40.png)

![](img/9295de359ac14eb5578bc3205359f0f6_41.png)

将 `f(x) = x²` 代入上述定义：

![](img/9295de359ac14eb5578bc3205359f0f6_43.png)

**推导步骤：**

1.  **写出极限表达式：**
    ```
    d/dx [x²] = lim (h -> 0) [ ((x+h)² - x²) / h ]
    ```

![](img/9295de359ac14eb5578bc3205359f0f6_45.png)

![](img/9295de359ac14eb5578bc3205359f0f6_46.png)

2.  **展开分子：**
    ```
    = lim (h -> 0) [ (x² + 2xh + h² - x²) / h ]
    ```

![](img/9295de359ac14eb5578bc3205359f0f6_47.png)

![](img/9295de359ac14eb5578bc3205359f0f6_49.png)

3.  **简化分子：**
    分子中的 `x²` 和 `-x²` 相互抵消。
    ```
    = lim (h -> 0) [ (2xh + h²) / h ]
    ```

4.  **约去公因子 h：**
    注意，我们是在极限过程中进行约分，因此不必担心 `h=0` 的情况。
    ```
    = lim (h -> 0) [ 2x + h ]
    ```

![](img/9295de359ac14eb5578bc3205359f0f6_51.png)

![](img/9295de359ac14eb5578bc3205359f0f6_52.png)

![](img/9295de359ac14eb5578bc3205359f0f6_53.png)

5.  **计算极限：**
    当 `h` 趋近于 0 时，`2x + h` 趋近于 `2x`。
    ```
    = 2x
    ```

![](img/9295de359ac14eb5578bc3205359f0f6_55.png)

![](img/9295de359ac14eb5578bc3205359f0f6_57.png)

至此，我们完成了证明。

**结论公式：**
```
d/dx [x²] = 2x
或
若 f(x) = x²，则 f'(x) = 2x
```

![](img/9295de359ac14eb5578bc3205359f0f6_59.png)

![](img/9295de359ac14eb5578bc3205359f0f6_60.png)

## 📝 本节总结

![](img/9295de359ac14eb5578bc3205359f0f6_63.png)

本节课中，我们一起学习了如何从定义出发求两类基本函数的导数：

![](img/9295de359ac14eb5578bc3205359f0f6_65.png)

![](img/9295de359ac14eb5578bc3205359f0f6_66.png)

1.  **常数函数 `f(x) = C`**：其导数为 **0**。这从图像（水平线斜率为零）和代数定义（差商恒为零）都很容易理解。
2.  **幂函数 `f(x) = x²`**：我们通过严格应用极限定义，经过展开、化简和求极限的步骤，证明了其导数为 **2x**。

![](img/9295de359ac14eb5578bc3205359f0f6_68.png)

这两个结果是构建更复杂函数求导规则的基础。在接下来的课程中，我们将以此为基础，探索更多函数的导数。
