# 微积分入门课程笔记 📝

在本节课中，我们将要学习微积分的一些核心概念，包括极限、导数以及它们的基本运算法则。这些内容是理解后续更复杂数学概念的基础。

## 极限的概念 🎯

上一节我们介绍了微积分的整体框架，本节中我们来看看其基石——极限。

极限描述了一个函数在输入值趋近于某个特定点时，其输出值的趋势。例如，当 `x` 无限接近 `a` 时，函数 `f(x)` 的值无限接近 `L`，则称 `L` 为 `f(x)` 在 `x` 趋近于 `a` 时的极限，记作：

**公式：** `lim (x→a) f(x) = L`

理解极限是学习导数和积分的第一步。

## 导数的定义与计算 📈

理解了极限之后，我们可以进入微积分的核心——导数。

导数衡量的是函数在某一点处的瞬时变化率。从几何上看，它代表了函数图像在该点切线的斜率。导数的定义基于极限：

**公式：** `f'(x) = lim (h→0) [f(x+h) - f(x)] / h`

这个公式计算的是当 `x` 的变化量 `h` 无限趋近于0时，函数平均变化率的极限值。

## 基本导数运算法则 ⚙️

知道了导数的定义，本节中我们来看看一些基本的运算法则，它们能帮助我们更高效地计算导数。

以下是几个最常用的导数运算法则：

*   **常数法则：** 常数的导数为0。
    **公式：** 若 `f(x) = c`，则 `f'(x) = 0`
*   **幂函数法则：** 对于幂函数 `x^n`，其导数为 `n*x^(n-1)`。
    **公式：** 若 `f(x) = x^n`，则 `f'(x) = n*x^(n-1)`
*   **乘法法则：** 两个函数乘积的导数。
    **公式：** `[f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)`
*   **除法法则：** 两个函数商的导数。
    **公式：** `[f(x)/g(x)]' = [f'(x)g(x) - f(x)g'(x)] / [g(x)]^2`

掌握这些法则，可以应对大多数基础函数的求导问题。

## 链式法则 🔗

在掌握了基本运算法则后，我们还需要一个工具来处理复合函数，这就是链式法则。

链式法则用于求复合函数 `f(g(x))` 的导数。其核心思想是“由外向内”逐层求导。

**公式：** 若 `y = f(u)` 且 `u = g(x)`，则 `dy/dx = (dy/du) * (du/dx)`

简单来说，复合函数的导数等于外层函数对中间变量的导数，乘以内层函数对自变量的导数。

---

本节课中我们一起学习了微积分的入门知识。我们首先理解了**极限**的概念，它是分析函数趋势的工具。接着，我们基于极限定义了**导数**，它描述了函数变化的瞬时速率。最后，我们学习了包括幂函数法则、乘法法则、除法法则以及**链式法则**在内的基本求导法则，这些是进行微分计算的核心工具。掌握这些内容，就为后续学习积分等更深入的主题打下了坚实的基础。
