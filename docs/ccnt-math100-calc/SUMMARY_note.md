### 🚀 P1：速度问题 I - 数值方法

本节课我们将从一个实际问题——速度问题——开始接触微积分。我们首先尝试用数值方法来估算瞬时速度。

上一节我们引入了速度问题，本节中我们来看看如何从图形角度理解它。

### 📈 P2：速度问题 II - 图形方法

通过绘制位置-时间图并观察割线的斜率，我们可以图形化地逼近瞬时速度。这为理解导数的几何意义奠定了基础。

在接触了具体问题后，我们需要正式引入微积分的核心语言——极限。

### 🔍 P3：三个函数的故事 - 极限导论 I

极限描述了函数在某个点附近的行为趋势，而不必等于该点的函数值。我们通过分析三个具有不同特性的函数来直观感受极限。

上一节我们初步认识了极限，本节将继续探讨极限更精确的定义和性质。

### 🧮 P4：三个函数的故事 - 极限导论 II

我们进一步明确极限的正式定义，并区分函数在一点有定义、极限存在以及连续之间的细微差别。

极限的行为并非总是有限的。

### ♾️ P5：什么是无穷极限？

当函数值随着自变量趋近某一点而无限增大或减小时，我们称其极限为无穷。其数学表达为：
\[
\lim_{x \to a} f(x) = \infty \quad \text{或} \quad -\infty
\]

计算复杂函数的极限需要借助一些基本法则。

### ⚖️ P6：极限法则 - 将复杂极限分解为简单极限

极限法则允许我们将极限运算分配到加法、减法、乘法、除法等运算中。例如：
\[
\lim_{x \to a} [f(x) + g(x)] = \lim_{x \to a} f(x) + \lim_{x \to a} g(x)
\]

掌握了基本法则后，我们可以开始计算一类常见函数的极限。

### 🧱 P7：计算有理函数极限的构建过程

对于有理函数（多项式之比），计算其在某点的极限通常涉及因式分解、约分等代数技巧，以消除导致分母为零的“不定式”。

并非所有函数都像多项式那样“规矩”。

### 📉 P8：振荡函数的极限与夹逼定理

对于像 `sin(1/x)` 这样振荡的函数，其极限可能不存在。夹逼定理是处理这类问题的重要工具：如果 `g(x) ≤ f(x) ≤ h(x)`，且 `g(x)` 和 `h(x)` 在 `x→a` 时有相同的极限 `L`，那么 `f(x)` 的极限也是 `L`。

计算极限时，熟练的代数技巧至关重要。

### 🛠️ P9：计算极限的四大代数技巧

以下是解决 `0/0` 型不定式最有效的四种代数方法：
1.  **因式分解**：分解分子分母并约去公因式。
2.  **有理化**：对含有根式的表达式进行分子或分母有理化。
3.  **找公分母**：用于处理复数分式相减的情况。
4.  **变量代换**：简化表达式形式。

学完极限，我们进入微积分的第一个核心概念——导数。

### 📐 P18：导数的定义 I

函数 `f(x)` 在点 `x=a` 处的导数，定义为当 `h` 趋近于0时，差商的极限：
\[
f'(a) = \lim_{h \to 0} \frac{f(a+h) - f(a)}{h}
\]
它表示函数在该点的瞬时变化率，几何上是切线的斜率。

让我们将定义应用到一个具体函数上。

### 🔢 P19：将导数定义应用于 1/x

我们严格使用定义来计算 `f(x) = 1/x` 的导数，过程涉及极限运算和代数化简。

再来看一个稍复杂的例子。

### ✏️ P20：导数定义示例 - f(x) = x + 1/(x+1)

对于这个函数，我们再次演练使用定义求导的过程，巩固对导数本质的理解。

从定义可以直接推导出一些简单函数的导数。

### 🔑 P21：从定义推导常函数和 x² 的导数

利用导数定义，我们证明：
*   常函数 `f(x) = c` 的导数为 `0`。
*   函数 `f(x) = x²` 的导数为 `2x`。

每次都使用定义求导非常繁琐，因此我们需要建立高效的求导法则。

### ⚡ P22：导数法则 - 幂法则、可加性与数乘

以下是三个基本的导数法则：
*   **幂法则**：若 `f(x) = x^n`，则 `f'(x) = n*x^(n-1)`。
*   **可加性**：`[f(x) + g(x)]' = f'(x) + g'(x)`。
*   **数乘**：`[c * f(x)]' = c * f'(x)`。

导数最直接的应用是求切线方程。

### 📏 P23：如何求切线方程

已知函数 `f(x)` 在点 `(a, f(a))` 的导数 `f'(a)`，则该点切线方程为：
\[
y - f(a) = f'(a)(x - a)
\]

指数函数 `e^x` 的导数具有独特的性质。

### 🌀 P24：e^x 的导数

函数 `f(x) = e^x` 的导数就是它本身：
\[
\frac{d}{dx} e^x = e^x
\]

接下来我们学习处理函数乘积与商的求导法则。

### ✖️➗ P25：乘积法则与商法则

*   **乘积法则**：`[f(x)g(x)]' = f'(x)g(x) + f(x)g'(x)`。
*   **商法则**：`[f(x)/g(x)]' = [f'(x)g(x) - f(x)g'(x)] / [g(x)]^2`。

三角函数在微积分中无处不在，其导数需要牢记。

### 📐 P26：三角函数的导数

以下是基本三角函数的导数公式：
*   `d/dx sin(x) = cos(x)`
*   `d/dx cos(x) = -sin(x)`
*   `d/dx tan(x) = sec^2(x)`

对于复合函数，我们需要链式法则。

### ⛓️ P27：链式法则 - 复合函数的导数

如果 `y = f(g(x))`，那么 `y` 关于 `x` 的导数为：
\[
\frac{dy}{dx} = f'(g(x)) \cdot g'(x)
\]

链式法则可以从图形上得到直观解释。

### 🖼️ P28：链式法则的图形解释

通过将复合函数分解为内外函数，并观察各自的变化率，可以图形化地理解链式法则中两个导数相乘的意义。

莱布尼茨记号让链式法则的书写更清晰。

### 🖋️ P29：使用莱布尼茨记号的链式法则

用 `dy/dx`, `dy/du`, `du/dx` 表示导数，链式法则写作：
\[
\frac{dy}{dx} = \frac{dy}{du} \cdot \frac{du}{dx}
\]
这种形式清晰地展示了“约分”的直观性。

当函数关系以隐式方程给出时，我们需要隐函数求导法。

### 🧩 P30：隐函数求导 - 当你只有一个方程时

对于方程 `F(x, y) = 0` 确定的函数 `y(x`，对方程两边同时关于 `x` 求导，并将 `y` 视为 `x` 的函数，然后解出 `dy/dx`。

隐函数求导可用来求反三角函数的导数。

### 🔄 P31：通过隐函数求导求反三角函数的导数

例如，设 `y = arcsin(x)`，则 `sin(y) = x`。两边对 `x` 求导：`cos(y) * dy/dx = 1`，解得 `dy/dx = 1/√(1-x²)`。

对于幂指函数等复杂形式，对数求导法非常有效。

### 📝 P33：对数求导法 - 示例 x^sin(x)

对于 `y = x^(sin x)`，先取自然对数：`ln y = sin x * ln x`，然后两边对 `x` 求导（使用隐函数求导），最后解出 `y'`。

导数可以用来解决相关的变化率问题。

### 🔗 P34：相关变化率导论

当两个或多个变量通过某个方程关联，且它们都随时间变化时，相关变化率问题要求我们通过求导找到这些变化率之间的关系。

导数也提供了函数的局部线性近似。

### 📍 P35：线性近似 - 用切线逼近函数

函数 `f(x)` 在点 `x=a` 附近的线性近似为：
\[
L(x) = f(a) + f'(a)(x - a)
\]
当 `x` 接近 `a` 时，`L(x) ≈ f(x)`。

微积分基本定理之一建立了导数与函数整体行为的关系。

### ⚖️ P36：中值定理实际上非常好

如果函数 `f(x)` 在闭区间 `[a, b]` 上连续，在开区间 `(a, b)` 内可导，则至少存在一点 `c ∈ (a, b)`，使得：
\[
f'(c) = \frac{f(b) - f(a)}{b - a}
\]
即，平均变化率等于某点的瞬时变化率。

导数可以帮助我们寻找函数的最大值和最小值。

### ⛰️ P37：相对与绝对极值 I

*   **临界点**：导数为零或不存在的点。
*   **相对极值**：函数在某个局部区间内的最高或最低点。
*   **绝对极值**：函数在整个定义域上的最高或最低点。

我们继续讨论寻找极值的方法。

### 🧭 P38：相对与绝对极值 II

寻找连续函数 `f(x)` 在闭区间 `[a, b]` 上的绝对极值：
1.  找出 `(a, b)` 内所有临界点。
2.  计算函数在所有临界点及端点 `a`, `b` 处的值。
3.  最大值和最小值就在这些函数值中。

洛必达法则是计算某些特定类型极限的强大工具。

### 🏔️ P39：用洛必达法则证明指数函数“压制”多项式

对于 `∞/∞` 型极限，洛必达法则表明：若 `lim f(x)/g(x)` 满足条件，则它等于 `lim f'(x)/g'(x)`。我们可以用此证明当 `x→∞` 时，`e^x` 的增长远快于任何多项式 `x^n`。

洛必达法则也能处理其他不定式。

### ⚡ P40：将洛必达法则应用于指数型不定式

对于 `0^0`, `∞^0`, `1^∞` 型不定式，通常先取对数将其转化为 `0/0` 或 `∞/∞` 型，再应用洛必达法则。

导数的一个经典应用是优化问题。

### 📏 P42：将铁丝折成最大矩形 - 优化示例

这是一个典型的优化问题：给定固定长度的铁丝，如何折叠（即如何选择长和宽）才能使围成的矩形面积最大？我们需要建立面积函数，求导找临界点，并判断其为最大值。

再看一个更复杂的优化例子。

### 📦 P43：优化示例 - 给定固定体积，最小化表面积

例如，设计一个圆柱形罐头，在体积固定的前提下，如何选择半径和高使得表面积最小？这需要建立表面积与半径（或高）的函数关系，并用导数求解。

最后，我们转向微积分的另一个核心——积分。

### 🔄 P45：什么是反导数？

如果 `F'(x) = f(x)`，则 `F(x)` 是 `f(x)` 的一个反导数。由于常数导数为零，所以反导数有无穷多个，彼此相差一个常数。

我们需要理解这个常数项的意义。

### ➕ P46：求解一般反导数中的常数

如果已知函数 `f(x)` 及其某个特定点 `(a, b)` 的值，我们可以通过解方程 `F(a) = b` 来确定反导数 `F(x)` 中的特定常数 `C`。

定积分起源于求曲线下面积的几何问题。

### 📊 P47：定积分 I - 用矩形逼近面积

为了计算曲线 `y=f(x)` 下从 `x=a` 到 `x=b` 的面积，我们可以用一系列矩形来逼近它。矩形的数量越多，逼近就越精确。

我们需要更精确的数学语言来描述这个过程。

### ∑ P48：定积分 II - 用求和符号定义

黎曼和是将区间 `[a, b]` 分割成 `n` 个子区间，在每个子区间上取一点 `x_i*`，求和：
\[
\sum_{i=1}^{n} f(x_i^*) \Delta x_i
\]
定积分定义为当最大子区间宽度趋于零时，黎曼和的极限：
\[
\int_a^b f(x) dx = \lim_{\|P\| \to 0} \sum_{i=1}^{n} f(x_i^*) \Delta x_i
\]

让我们用定义来计算一个简单积分。

### 🧮 P49：定积分 III - 根据定义计算

对于 `f(x) = x` 在 `[0, b]` 上的积分，我们可以选择特殊的分割和取点（如右端点），计算黎曼和的极限，最终得到结果 `b²/2`。

有时我们需要从给定的求和式反推对应的积分。

### ↩️ P50：“反向”黎曼和 - 根据求和求定积分

给定一个求和表达式，如果能将其识别为某个函数的黎曼和，我们就可以直接写出它对应的定积分。

微积分基本定理揭示了微分与积分之间的深刻联系。

### 🌉 P51：微积分基本定理 I - 几何思想 + 链式法则示例

FTC I 指出：如果 `f` 在 `[a, b]` 上连续，那么由积分上限定义的函数 `g(x) = ∫_a^x f(t) dt` 在 `[a, b]` 上可导，且 `g'(x) = f(x)`。这建立了积分与反导数之间的联系。

第二部分给出了计算定积分的实际方法。

### 💎 P52：微积分基本定理 II

FTC II 指出：如果 `F(x)` 是 `f(x)` 的任意一个反导数，那么
\[
\int_a^b f(x) dx = F(b) - F(a)
\]
这使得我们可以用反导数轻松计算定积分。

换元积分法是求反导数的重要技巧。

### 🔀 P53：换元积分导论 - 逆转链式法则

换元积分对应链式法则的逆过程。基本形式是：
\[
\int f(g(x)) g'(x) dx = \int f(u) du, \quad \text{其中 } u = g(x)
\]

有时需要调整常数因子以匹配换元形式。

### ⚙️ P54：调整换元积分中的常数

如果被积函数中 `g'(x)` 只差一个常数因子 `k`，我们可以通过乘以 `k/k` 来构造所需的微分 `du = g'(x)dx`。

定积分的换元需要同时改变积分上下限。

### ⚠️ P55：定积分的换元法 - 小心！

对定积分 `∫_a^b f(g(x)) g'(x) dx` 进行换元 `u = g(x)` 时，积分限也要相应变为 `g(a)` 和 `g(b)`：
\[
\int_{x=a}^{x=b} f(g(x)) g'(x) dx = \int_{u=g(a)}^{u=g(b)} f(u) du
\]

当换元后不能完全用 `u` 表示时，需要回代。

### ↩️ P56：回代 - 当 u-换元不能完全匹配时！

如果换元后，被积表达式中仍残留原变量 `x`，我们需要将 `u` 关于 `x` 的关系式代入，将其完全用 `u` 表示，或者进行回代，用 `x` 表示最终结果。

积分可以用来求连续函数的平均值。

### 📊 P57：连续函数在区间上的平均值

函数 `f(x)` 在区间 `[a, b]` 上的平均值为：
\[
f_{\text{avg}} = \frac{1}{b-a} \int_a^b f(x) dx
\]

### 🧩 P2：分部积分法导论 - 示例 ∫x sin x dx 和 ∫arctan(x) dx

分部积分法是乘积法则的逆运算，公式为：
\[
\int u dv = uv - \int v du
\]
关键在于恰当选择 `u` 和 `dv`。

让我们看两个更有挑战性的例子。

### 🧠 P3：两个棘手的分部积分示例

通过选择不同的 `u` 和 `dv`，有时需要多次应用分部积分，或者得到包含原积分的方程，然后解出该积分。

三角函数积分是常见的一类问题。

### 📐 P4：三角积分 - 通过勾股定理或半角公式处理 ∫sinⁿ(x)cosᵐ(x) dx

处理 `sin` 和 `cos` 幂次乘积的积分，策略取决于幂次的奇偶性。常用技巧包括利用恒等式 `sin²x + cos²x = 1` 或半角公式进行化简。

三角代换是处理含有根式 `√(a² - x²)`, `√(a² + x²)`, `√(x² - a²)` 的积分的强大工具。

### 🔄 P5：三角代换导论 - 示例：推导圆面积公式

例如，对于 `√(a² - x²)`，我们设 `x = a sinθ`，则 `√(a² - x²) = a cosθ`，从而将根式转化为三角函数。

如何选择正确的代换是关键。

###
