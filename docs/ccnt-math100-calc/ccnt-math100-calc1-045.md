## 🔄 从导数到原函数

![](img/1bcc34a7075fec2da43fdcf71e0d3862_7.png)

根据幂法则，我们知道函数 **x³** 的导数是 **3x²**。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_8.png)

![](img/1bcc34a7075fec2da43fdcf71e0d3862_9.png)

![](img/1bcc34a7075fec2da43fdcf71e0d3862_10.png)

**公式：**
```
d/dx (x³) = 3x²
```

![](img/1bcc34a7075fec2da43fdcf71e0d3862_12.png)

这个等式建立了 **x³** 和 **3x²** 之间的关系。现在，我们将这个关系反过来看，引入一个叫做“原函数”的概念。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_14.png)

我们说，**3x²** 的原函数是 **x³**。当我们称 **x³** 是一个原函数时，意思是：如果我们对 **x³** 求导，就会得到 **3x²**。

---

![](img/1bcc34a7075fec2da43fdcf71e0d3862_16.png)

## 📖 原函数的定义

以下是原函数的一般定义。我们通常用大写字母 **F** 来表示原函数。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_18.png)

**定义：**
如果函数 **F** 满足其导数等于函数 **f**，即 **F'(x) = f(x)**，那么 **F** 就是 **f** 的一个原函数。

换句话说，原函数的导数就是原来的函数。

---

## 🔍 原函数不唯一

任何函数求导后，原函数都是其导数的原函数。但关键在于，原函数并不只有一个。

例如，函数 **x³ + 7** 也是 **3x²** 的一个原函数。我们来验证一下：如果这是我们的原函数 **F**，对其求导，**3x²** 的导数不变，而常数 **7** 的导数是 **0**。因此，**x³ + 7** 的导数同样是 **3x²**。

实际上，无论加上什么常数——一百万、十亿、π 或 √2——只要加上任意常数 **C**，在求导时这个常数项都会消失。所以，**x³ + C** 这一整个无限函数族，都是 **3x²** 的原函数。

因此，我们有时会讨论**一般原函数**。如果 **F'(x) = f(x)**，那么 **f** 的一般原函数就是 **F(x) + C**，其中 **C** 是任意常数。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_20.png)

在语法上需要稍加注意：像 **x³ + 7** 这样的具体函数，我们称其为“一个”原函数，因为原函数有很多。而当我们写成 **F(x) + C** 这种形式时，指的是“一般原函数”。

## 🧮 幂函数的原函数

我们已经研究了 **3x²** 的原函数，现在让我们一般性地看看函数 **xⁿ** 的原函数。

**公式：**
函数 **xⁿ** 的一般原函数是：
```
∫ xⁿ dx = (xⁿ⁺¹)/(n+1) + C
```

![](img/1bcc34a7075fec2da43fdcf71e0d3862_26.png)

不要只听我说，让我们验证一下这是否成立。验证的条件就是：对这个表达式求导，看是否能得到 **xⁿ**。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_28.png)

![](img/1bcc34a7075fec2da43fdcf71e0d3862_29.png)

**验证过程：**
```
d/dx [ (xⁿ⁺¹)/(n+1) + C ]
= (1/(n+1)) * d/dx (xⁿ⁺¹) + 0  // 常数C的导数为0
= (1/(n+1)) * (n+1) * xⁿ        // 应用幂法则
= xⁿ
```
是的，这确实是一个原函数。

通常，在寻找这类原函数时，有点像“猜测并检验”。我们知道幂函数的导数会降低一次幂。所以反过来，对于 **xⁿ**，我需要尝试增加一次幂。我先尝试了 **xⁿ⁺¹**，但发现多了一个系数 **(n+1)**，于是再除以 **(n+1)**，最终得到了这个答案。

---

## 📐 三角函数的原函数

![](img/1bcc34a7075fec2da43fdcf71e0d3862_31.png)

让我们再用“猜测并检验”的方法试试。我断言，**sin(x)** 的一般原函数是 **-cos(x) + C**。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_32.png)

![](img/1bcc34a7075fec2da43fdcf71e0d3862_33.png)

![](img/1bcc34a7075fec2da43fdcf71e0d3862_34.png)

![](img/1bcc34a7075fec2da43fdcf71e0d3862_35.png)

同样，我们来验证一下。计算 **-cos(x)** 的导数。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_36.png)

**验证过程：**
```
d/dx [ -cos(x) ]
= - d/dx [cos(x)]  // 常数倍法则
= - (-sin(x))      // cos(x)的导数是 -sin(x)
= sin(x)
```
确实如此。**-cos(x)** 的导数是 **sin(x)**，这告诉我们 **sin(x)** 的原函数是 **-cos(x) + C**。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_38.png)

## ➕ 原函数的加法性质

![](img/1bcc34a7075fec2da43fdcf71e0d3862_40.png)

![](img/1bcc34a7075fec2da43fdcf71e0d3862_41.png)

最后，我们来看看原函数是否具有可加性。我们知道，和的导数等于导数的和。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_43.png)

**性质：**
如果 **F** 是 **f** 的一个原函数，**G** 是 **g** 的一个原函数，那么 **F + G** 就是 **f + g** 的一个原函数（在一般形式中还需加上常数 **C**）。

让我们验证这个性质。假设我们取底部 **F + G + C** 的导数。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_45.png)

**验证过程：**
```
d/dx [ F(x) + G(x) + C ]
= d/dx [F(x)] + d/dx [G(x)] + 0  // 和的导数法则，常数导数为0
= f(x) + g(x)
```
确实，我们得到了 **f(x) + g(x)**。因此，原函数和导数一样，也具有可加性。

![](img/1bcc34a7075fec2da43fdcf71e0d3862_46.png)

## 🎯 课程总结

在本节课中，我们一起学习了：

1.  **原函数的定义**：如果 **F'(x) = f(x)**，则 **F** 是 **f** 的一个原函数。
2.  **原函数不唯一**：任何原函数加上一个常数 **C** 后，仍然是原函数，这引出了“一般原函数” **F(x) + C** 的概念。
3.  **常见函数的原函数**：
    *   对于幂函数 **xⁿ**，其一般原函数为 **(xⁿ⁺¹)/(n+1) + C**。
    *   对于正弦函数 **sin(x)**，其一般原函数为 **-cos(x) + C**。
4.  **原函数的性质**：原函数具有可加性。如果 **F** 和 **G** 分别是 **f** 和 **g** 的原函数，那么 **F + G** 就是 **f + g** 的原函数。

在未来的课程中，我们将继续运用这种“逆向思维”，将链式法则、常数倍法则等求导规则反过来应用，以求出更多复杂函数的原函数。
