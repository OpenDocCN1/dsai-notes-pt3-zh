# 第一部分 9：L9 - 极限计算的四大代数技巧 📘

在本节课中，我们将学习四种在计算极限时非常有用的代数技巧。这些技巧能帮助我们处理那些直接代入会导致“0/0”未定式的极限问题。

---

## 🔍 概述

我们将通过四个具体的极限例子，逐一展示每种技巧的应用。这些技巧包括：**因式分解**、**展开表达式**、**通分**以及**有理化（使用共轭式）**。掌握这些方法，能让你在面对复杂极限时更加得心应手。

---

## 1️⃣ 技巧一：因式分解

上一节我们介绍了课程目标，本节中我们来看看第一种技巧——因式分解。它适用于分子和分母都是多项式，且代入极限点会产生“0/0”的情况。

考虑以下极限：
```math
\lim_{x \to -2} \frac{x^3 + 2x^2}{x^2 - x - 6}
```
如果直接将 `x = -2` 代入，分子和分母都为零，得到“0/0”的未定式，因此我们需要进行代数处理。

以下是解题步骤：
1.  观察分子和分母，发现都有公因子 `x`，可以将其提出。
2.  提出公因子后，分子变为 `x(x^2 + 2x)`，分母变为 `x(x - 3)`。此时可以约去 `x`。
3.  约分后，分母的二次式 `x^2 - x - 6` 仍可进一步因式分解为 `(x + 2)(x - 3)`。
4.  现在，分子是 `(x + 2)(x - 3)`，分母也是 `(x + 2)(x - 3)`。约去公因子 `(x + 2)`。
5.  最终得到极限 `lim (x - 3)`，此时可以直接代入 `x = -2`，得到结果 `-5`。

**核心要点**：在每一步变换前都必须保留极限符号 `lim`，直到最后一步确定表达式在极限点有定义后，才能代入数值计算。

---

## 2️⃣ 技巧二：展开表达式

接下来，我们看看与因式分解思路相反的技巧——展开表达式。当表达式包含括号，特别是平方项时，展开可能有助于简化。

考虑极限：
```math
\lim_{x \to 0} \frac{(x-2)^2 - 4}{x^2}
```
直接代入 `x = 0` 同样会得到“0/0”。

以下是解题步骤：
1.  首先展开分子中的 `(x-2)^2`，得到 `x^2 - 4x + 4`。
2.  原分子变为 `(x^2 - 4x + 4) - 4 = x^2 - 4x`。
3.  此时分子为 `x^2 - 4x`，分母为 `x^2`。分子分母仍有公因子 `x`，将其提出并约去。
4.  约分后得到极限 `lim (x - 4)`。
5.  现在可以安全地代入 `x = 0`，得到最终结果 `-4`。

**核心要点**：展开表达式可以消去常数项，暴露出隐藏的公因子，从而简化分式。

---

## 3️⃣ 技巧三：通分

当极限表达式中包含分数的加减运算时，通分是一个关键技巧。它可以将多个分式合并为一个，便于后续处理。

考虑极限：
```math
\lim_{x \to 0} \left( \frac{1}{x} - \frac{1}{x^2 + 2x} \right)
```
其中每一项单独在 `x=0` 处的极限都不存在，因此必须整体处理。

以下是解题步骤：
1.  首先找到公分母，即 `x(x^2 + 2x)`，但更简洁的形式是 `x^2(x+2)`。
2.  将两个分数通分：
    ```math
    \frac{1}{x} - \frac{1}{x^2+2x} = \frac{(x^2+2x) - x}{x(x^2+2x)} = \frac{x^2 + x}{x^3 + 2x^2}
    ```
3.  合并后，分子为 `x^2 + x`，分母为 `x^3 + 2x^2`。分子分母有公因子 `x`，约去后得到 `(x+1) / (x^2 + 2x)`。
4.  此时代入 `x=0` 仍为“0/0”，需要再次因式分解。分母可提公因子 `x`，得到 `x(x+2)`。
5.  约去分子分母的公因子 `x` 后，得到 `1/(x+2)`。
6.  现在可以代入 `x=0`，得到结果 `1/2`。

**核心公式**：对于分式 `A/B + C/D`，通分结果为 `(AD + BC) / (BD)`。

---

## 4️⃣ 技巧四：有理化（使用共轭式）

最后，我们学习处理含有根式的极限时最有效的技巧——有理化，即乘以共轭式。

考虑极限：
```math
\lim_{x \to 4} \frac{\sqrt{x} - 2}{x - 4}
```
直接代入 `x=4` 会得到“0/0”。

以下是解题步骤：
1.  分子是 `√x - 2`，其共轭式为 `√x + 2`。我们将分子和分母同时乘以这个共轭式。
2.  分子变为 `(√x - 2)(√x + 2) = (√x)^2 - 2^2 = x - 4`。这正是分母的表达式。
3.  此时，原极限变为：
    ```math
    \lim_{x \to 4} \frac{x - 4}{(x - 4)(\sqrt{x} + 2)}
    ```
4.  约去分子分母的公因子 `(x - 4)`，得到 `1/(√x + 2)`。
5.  现在可以代入 `x=4`，得到结果 `1/(2+2) = 1/4`。

**核心方法**：对于形如 `√A ± √B` 的表达式，乘以共轭式 `√A ∓ √B` 可以利用平方差公式 `(a-b)(a+b)=a²-b²` 消去根号。

---

## 📝 总结

本节课中，我们一起学习了计算极限的四大核心代数技巧：
1.  **因式分解**：用于处理多项式分式，通过约去公因子消除“0/0”。
2.  **展开表达式**：通过展开括号（如平方项）来简化表达式，暴露可约分的公因子。
3.  **通分**：将多个分式的加减运算合并为一个分式，便于统一处理。
4.  **有理化（共轭式）**：专门用于处理含有根式的极限，通过乘以共轭式消去根号。

这些技巧不仅是解决微积分中极限问题的利器，也是后续学习导数、积分等概念时频繁使用的基本功。记住，核心思路都是通过代数变换，将原表达式转化为在极限点处有定义的形式，从而能够直接代入求解。
