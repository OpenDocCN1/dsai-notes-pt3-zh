# 第一部分 53：换元积分法入门 - 链式法则的逆运算 📚

![](img/7d2e0462a4563d1cb344c9d952a0f97b_1.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_2.png)

在本节课中，我们将学习积分中的一个核心技巧：换元积分法。这个方法本质上是微分学中链式法则的逆运算，它能帮助我们求解更广泛类型的积分。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_3.png)

## 🔗 从微分规则到积分规则

![](img/7d2e0462a4563d1cb344c9d952a0f97b_5.png)

上一节我们回顾了基本的积分规则，例如幂函数和函数的积分。这些规则大多是从对应的微分规则推导而来的。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_6.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_7.png)

当我们最初定义导数时，首要任务之一就是证明尽可能多的微分规则。例如，我们证明了幂函数的导数公式，也证明了两函数之和的导数等于各自导数之和。

在积分学中，我们已经知道如何处理类似 `x^n` 的积分。我们也看到，像“和的导数等于导数之和”这样的规则在积分背景下依然成立，即**和的积分等于积分之和**。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_9.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_10.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_11.png)

然而，在微分学中还有一个非常重要的规则——链式法则，我们尚未在积分背景下处理它。

## 🔄 链式法则回顾

![](img/7d2e0462a4563d1cb344c9d952a0f97b_13.png)

链式法则描述了复合函数的导数。其公式如下：

![](img/7d2e0462a4563d1cb344c9d952a0f97b_14.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_15.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_16.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_17.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_18.png)

**公式：** `d/dx [F(g(x))] = f(g(x)) * g'(x)`

![](img/7d2e0462a4563d1cb344c9d952a0f97b_19.png)

这里，我们约定 `F` 是 `f` 的一个原函数，即 `F' = f`。因此，链式法则可以重写为：

**公式：** `d/dx [F(g(x))] = f(g(x)) * g'(x)`

![](img/7d2e0462a4563d1cb344c9d952a0f97b_21.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_22.png)

## 🧠 从链式法则推导换元法

![](img/7d2e0462a4563d1cb344c9d952a0f97b_23.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_24.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_25.png)

现在，我们有一个关于变量 `x` 的方程。左边是一个 `x` 的函数，右边是另一个 `x` 的函数。我们可以对等式两边关于 `x` 进行积分。

**公式：** `∫ d/dx [F(g(x))] dx = ∫ f(g(x)) * g'(x) dx`

对于左边，我们知道不定积分是求原函数。一个函数的导数的原函数就是该函数本身。因此，左边等于 `F(g(x)) + C`。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_27.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_28.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_29.png)

于是我们得到：

**公式：** `F(g(x)) + C = ∫ f(g(x)) * g'(x) dx`

这个方程有效地告诉我们，只要我们知道 `f` 的原函数 `F`，我们就能计算出形如 `∫ f(g(x)) * g'(x) dx` 的积分。这极大地拓宽了我们能够积分的函数类型。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_31.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_32.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_33.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_34.png)

## 📝 引入换元法（U-代换）

![](img/7d2e0462a4563d1cb344c9d952a0f97b_35.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_37.png)

上面推导出的方程通常被称为**换元法则**。为了简化符号，我们通常使用一种称为 **U-代换** 的技巧。

其核心思想是给内层函数 `g(x)` 起一个简单的名字 `u`。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_39.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_40.png)

**设定：** `u = g(x)`

那么，`F(g(x))` 就变成了 `F(u)`。由于 `F` 是 `f` 的原函数，我们可以将 `F(u) + C` 写成 `∫ f(u) du`。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_42.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_43.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_44.png)

通过比较 `∫ f(g(x)) * g'(x) dx` 和 `∫ f(u) du`，我们可以发现，`g'(x) dx` 这一项恰好对应于 `du`。

**总结：** 换元法则允许我们通过设 `u = g(x)`，将形如 `∫ f(g(x)) * g'(x) dx` 的积分重写为更简单的 `∫ f(u) du`。其答案就是 `F(u) + C`，最后再将 `u` 代回为 `g(x)`。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_46.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_47.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_48.png)

## 💡 应用示例

让我们通过一个具体例子来看它是如何工作的。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_50.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_51.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_52.png)

**例题：** 计算 `∫ 2x * sin(x²) dx`

我们的首要任务是将这个积分写成标准形式，识别出 `f`、`u` 和 `du`。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_54.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_55.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_56.png)

以下是识别步骤：

![](img/7d2e0462a4563d1cb344c9d952a0f97b_57.png)

1.  观察被积函数 `sin(x²)`，这是一个复合函数：外层是正弦函数 `sin(·)`，内层是 `x²`。
2.  内层函数 `x²` 的导数是 `2x`。
3.  注意到被积表达式中恰好有 `2x dx` 这一组合。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_59.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_61.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_62.png)

因此，我们可以进行如下设定：

**设定：**
*   `u = x²`
*   `du = 2x dx`
*   `f(u) = sin(u)`

![](img/7d2e0462a4563d1cb344c9d952a0f97b_64.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_65.png)

我们知道 `sin(u)` 的一个原函数是 `-cos(u)`。

![](img/7d2e0462a4563d1cb344c9d952a0f97b_67.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_68.png)

现在，将原积分进行代换：

![](img/7d2e0462a4563d1cb344c9d952a0f97b_69.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_71.png)

**计算：**
`∫ 2x * sin(x²) dx = ∫ sin(u) du = -cos(u) + C`

![](img/7d2e0462a4563d1cb344c9d952a0f97b_73.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_74.png)

最后，将 `u = x²` 代回，得到最终答案：

**答案：** `-cos(x²) + C`

![](img/7d2e0462a4563d1cb344c9d952a0f97b_76.png)

![](img/7d2e0462a4563d1cb344c9d952a0f97b_78.png)

## 🎯 课程总结

本节课中，我们一起学习了换元积分法。我们从回顾链式法则出发，通过对其两边积分，推导出了换元积分的基本公式。我们引入了 U-代换这一简化符号的技巧，并通过一个具体例子演示了如何识别合适的 `u` 和 `du`，从而将复杂的复合函数积分转化为简单的基本积分。掌握这个方法，是求解更高级积分问题的重要基础。
