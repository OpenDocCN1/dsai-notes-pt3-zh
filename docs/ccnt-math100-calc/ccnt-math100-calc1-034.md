## 1. 问题引入与建模

上一节我们介绍了相关变化率的基本思想。本节中，我们来看一个具体的例子。

![](img/7306518b583ccfe101f9e807e8e42842_8.png)

![](img/7306518b583ccfe101f9e807e8e42842_9.png)

想象有两辆汽车从同一点出发。汽车A向东行驶了0.4英里，汽车B向北行驶了0.3英里。

![](img/7306518b583ccfe101f9e807e8e42842_10.png)

我们可以用几何图形来表示这个场景，并思考两车之间的距离问题。下图清晰地展示了三者的位置关系：

![](img/7306518b583ccfe101f9e807e8e42842_12.png)

![](img/7306518b583ccfe101f9e807e8e42842_1.png)
![](img/7306518b583ccfe101f9e807e8e42842_2.png)
![](img/7306518b583ccfe101f9e807e8e42842_3.png)
![](img/7306518b583ccfe101f9e807e8e42842_4.png)
![](img/7306518b583ccfe101f9e807e8e42842_5.png)
![](img/7306518b583ccfe101f9e807e8e42842_6.png)

![](img/7306518b583ccfe101f9e807e8e42842_13.png)

![](img/7306518b583ccfe101f9e807e8e42842_14.png)

![](img/7306518b583ccfe101f9e807e8e42842_15.png)

![](img/7306518b583ccfe101f9e807e8e42842_16.png)

两车的行驶路径与它们之间的直线距离构成了一个直角三角形。根据勾股定理，我们可以建立变量之间的关系。

以下是描述这个关系的核心公式：

![](img/7306518b583ccfe101f9e807e8e42842_18.png)

![](img/7306518b583ccfe101f9e807e8e42842_19.png)

**`D² = x² + y²`**

![](img/7306518b583ccfe101f9e807e8e42842_21.png)

其中：
*   **`x`** 代表汽车A向东行驶的距离（0.4英里）。
*   **`y`** 代表汽车B向北行驶的距离（0.3英里）。
*   **`D`** 代表两车之间的直线距离。

![](img/7306518b583ccfe101f9e807e8e42842_22.png)

![](img/7306518b583ccfe101f9e807e8e42842_23.png)

![](img/7306518b583ccfe101f9e807e8e42842_24.png)

将已知的 `x` 和 `y` 值代入公式，可以计算出此刻的直线距离 `D` 为0.5英里。

## 2. 引入时间与变化率

![](img/7306518b583ccfe101f9e807e8e42842_26.png)

![](img/7306518b583ccfe101f9e807e8e42842_27.png)

![](img/7306518b583ccfe101f9e807e8e42842_28.png)

上一节我们建立了静态距离关系。本节中，我们引入时间变量，让问题“动起来”。

![](img/7306518b583ccfe101f9e807e8e42842_29.png)

![](img/7306518b583ccfe101f9e807e8e42842_30.png)

![](img/7306518b583ccfe101f9e807e8e42842_31.png)

![](img/7306518b583ccfe101f9e807e8e42842_32.png)

假设汽车A正以 **60英里/小时** 的速度继续向东行驶，汽车B正以 **50英里/小时** 的速度继续向北行驶。这意味着距离 `x` 和 `y` 都随时间 `t` 在变化，因此它们之间的直线距离 `D` 也随时间变化。

我们的目标不再是求某个固定时刻的距离，而是求在某个特定时刻（即 `x=0.4`, `y=0.3` 时），距离 `D` 的**瞬时变化率**，即导数 **`dD/dt`**。

![](img/7306518b583ccfe101f9e807e8e42842_34.png)

![](img/7306518b583ccfe101f9e807e8e42842_35.png)

为了找到变化率之间的关系，我们对之前建立的静态关系式 **`D² = x² + y²`** 两边同时关于时间 `t` 求导。

![](img/7306518b583ccfe101f9e807e8e42842_36.png)

![](img/7306518b583ccfe101f9e807e8e42842_37.png)

## 3. 对方程求导

![](img/7306518b583ccfe101f9e807e8e42842_39.png)

![](img/7306518b583ccfe101f9e807e8e42842_40.png)

上一节我们得到了包含时间变量的关系式。本节中，我们通过求导来揭示变化率之间的关系。

![](img/7306518b583ccfe101f9e807e8e42842_41.png)

![](img/7306518b583ccfe101f9e807e8e42842_42.png)

对等式 **`D(t)² = x(t)² + y(t)²`** 两边关于 `t` 求导。这里需要运用链式法则和幂法则。

以下是求导过程的核心步骤：

![](img/7306518b583ccfe101f9e807e8e42842_44.png)

![](img/7306518b583ccfe101f9e807e8e42842_45.png)

1.  左边：`d/dt [D²] = 2D * (dD/dt)`
2.  右边：`d/dt [x²] = 2x * (dx/dt)`
3.  右边：`d/dt [y²] = 2y * (dy/dt)`

![](img/7306518b583ccfe101f9e807e8e42842_46.png)

![](img/7306518b583ccfe101f9e807e8e42842_47.png)

![](img/7306518b583ccfe101f9e807e8e42842_48.png)

将以上结果组合，得到关联变化率的方程：

**`2D * (dD/dt) = 2x * (dx/dt) + 2y * (dy/dt)`**

![](img/7306518b583ccfe101f9e807e8e42842_50.png)

这个方程的美妙之处在于，它同时包含了原始变量（`D, x, y`）和它们的变化率（`dD/dt, dx/dt, dy/dt`）。

## 4. 求解目标变化率

![](img/7306518b583ccfe101f9e807e8e42842_55.png)

![](img/7306518b583ccfe101f9e807e8e42842_56.png)

上一节我们得到了一个通用的变化率关系式。本节中，我们整理公式并代入具体数值，求解目标变化率 `dD/dt`。

首先，将方程 **`2D * (dD/dt) = 2x * (dx/dt) + 2y * (dy/dt)`** 两边同时除以 `2D`，消去系数2，解出 `dD/dt`：

![](img/7306518b583ccfe101f9e807e8e42842_58.png)

**`dD/dt = [ x*(dx/dt) + y*(dy/dt) ] / D`**

![](img/7306518b583ccfe101f9e807e8e42842_59.png)

![](img/7306518b583ccfe101f9e807e8e42842_60.png)

现在，代入我们在特定时刻已知的所有数值：
*   `x = 0.4` 英里
*   `dx/dt = 60` 英里/小时 （汽车A的向东速度）
*   `y = 0.3` 英里
*   `dy/dt = 50` 英里/小时 （汽车B的向北速度）
*   `D = 0.5` 英里 （我们之前计算出的瞬时距离）

![](img/7306518b583ccfe101f9e807e8e42842_62.png)

代入公式计算：
**`dD/dt = [ (0.4 * 60) + (0.3 * 50) ] / 0.5 = [24 + 15] / 0.5 = 39 / 0.5 = 78`**

![](img/7306518b583ccfe101f9e807e8e42842_64.png)

因此，在所述时刻，两车之间的直线距离正以 **78英里/小时** 的速率增加。

## 5. 解决相关变化率问题的通用步骤

![](img/7306518b583ccfe101f9e807e8e42842_66.png)

通过上面的例子，我们可以总结出解决相关变化率问题的一般性步骤。无论具体场景如何，以下四步构成了核心框架：

![](img/7306518b583ccfe101f9e807e8e42842_67.png)

![](img/7306518b583ccfe101f9e807e8e42842_68.png)

以下是解决相关变化率问题的四个关键步骤：

![](img/7306518b583ccfe101f9e807e8e42842_70.png)

1.  **绘制示意图**：根据文字描述，画出问题情境的草图，并标出所有相关变量。
2.  **建立变量方程**：根据几何、物理或其他关系，找到一个联系所有相关变量（不包括时间t）的方程。
3.  **对时间求导**：将步骤2中的方程两边同时对时间 `t` 求导，应用链式法则等，得到一个包含原始变量及其变化率（导数）的新方程。
4.  **代入数值求解**：将问题中给出的特定时刻的变量值及其变化率数值，代入步骤3得到的方程，解出所要求的目标变化率。

![](img/7306518b583ccfe101f9e807e8e42842_72.png)

## 总结

![](img/7306518b583ccfe101f9e807e8e42842_76.png)

本节课中，我们一起学习了**相关变化率**的概念和解题方法。

我们从两辆汽车行驶的具体例子出发，首先利用勾股定理建立了静态距离关系 **`D² = x² + y²`**。接着，我们引入时间变量，通过对该等式两边关于时间求导，得到了关联变化率的方程 **`2D * dD/dt = 2x * dx/dt + 2y * dy/dt`**。最后，通过代入特定时刻的数值，我们计算出两车距离的变化率 **`dD/dt = 78` 英里/小时**。

![](img/7306518b583ccfe101f9e807e8e42842_78.png)

最重要的是，我们提炼出了解决此类问题的四步通用流程：**绘图 -> 建模 -> 求导 -> 代入求解**。掌握这个框架，你就能应对各种各样的相关变化率问题。
