## 核心服务的连接与集成

我认为，有趣的是看到我们如何能够实际连接Azure OpenAI服务。我们将已部署的模型与使用Azure AI搜索的检索增强生成模式结合起来。

这个连接的核心逻辑可以用以下伪代码表示：
```python
# 1. 用户输入查询
user_query = "用户的问题"
# 2. 使用Azure AI搜索检索相关上下文
retrieved_context = azure_ai_search.retrieve(user_query)
# 3. 将查询与上下文组合，发送给Azure OpenAI模型
enhanced_prompt = f"基于以下上下文：{retrieved_context}， 回答：{user_query}"
# 4. 获取并返回模型生成的答案
final_answer = azure_openai_model.generate(enhanced_prompt)
```
