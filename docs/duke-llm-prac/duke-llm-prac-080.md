## Azure平台与大型语言模型

我们将首先探索Microsoft Learn平台。这是一个理解API、查找文档和示例的优秀资源。同时，我们也会了解Azure平台内部与大型语言模型相关的一些差异。

理解这些差异和概念，并知道去哪里寻找更多答案，对我们后续的学习至关重要。这将在课程后续内容中得到体现。

## 核心服务与工具

以下是本课程中将涉及的核心Azure服务与工具简介。

*   **Azure OpenAI服务**：这是微软Azure平台上提供的托管服务，允许开发者访问和使用OpenAI开发的大型语言模型。
*   **Azure机器学习**：这是一个用于构建、训练和部署机器学习模型的云端环境。
*   **Azure机器学习工作室**：这是一个基于Web的交互式工作区，用于在Azure机器学习中进行低代码或无代码的模型开发和操作。

为了顺利进行本课程，你需要熟悉一些基础概念。以下是几个需要理解并感到舒适的关键点。

*   了解云计算和API的基本概念。
*   对机器学习有初步认识。
*   能够使用Microsoft Learn等平台查找技术文档。
