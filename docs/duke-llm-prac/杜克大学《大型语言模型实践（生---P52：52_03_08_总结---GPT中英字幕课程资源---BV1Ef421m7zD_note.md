# 大型语言模型实践：4：总结

![](img/7605698c7079c502b2bd43a9da7a8bb9_0.png)

在本节课中，我们将总结前面关于检索增强生成（RAG）模式的学习内容，回顾如何利用自有数据增强大型语言模型的能力。

## 课程概述

上一节我们介绍了如何将数据向量化并存入数据库。本节中，我们来看看整个RAG流程的总结与价值。

我们成功探索了如何将检索增强生成（RAG）与大型语言模型结合进行交互。

我们看到了如何管理数据。我特意选择了一个CSV（逗号分隔值）格式的文件，以便使用一种有趣的、在现有示例中不常见的数据格式。我们能够对该数据进行修剪、处理，并创建出特定的数据结构。

## 核心步骤回顾

以下是实现RAG模式的关键步骤：

1.  **数据准备**：对原始CSV格式数据进行清洗和格式化处理。
2.  **创建嵌入**：将处理后的文本数据转化为向量嵌入（Embeddings）。其核心是将文本 `T` 通过嵌入模型 `E` 映射为向量：`E(T) -> Vector`。
3.  **使用向量数据库**：将生成的向量存储到专门的向量数据库中，以便进行高效的相似性检索。
4.  **验证与检索**：利用向量数据库检索与用户查询最相关的信息，并将其作为上下文提供给大型语言模型，从而获得更精准的回复。

## 模式优势总结

本节课中我们一起学习了RAG模式的强大之处。这无疑是一个非常强大的模式，如果你选择实现类似的应用，它将允许你使用自己的数据，而无需重新训练整个大型语言模型。

因此，当你创建基于聊天的应用程序时，例如使用大型语言模型的客服系统，采用RAG模式可以获得质量高得多的响应。
