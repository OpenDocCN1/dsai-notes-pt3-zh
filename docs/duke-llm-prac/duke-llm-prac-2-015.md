## 核心概念与要点

以下是关于Celery，我们需要关注的一些要点：

*   **任务本质**：理解了**任务**作为异步执行单元的概念。
*   **错误处理**：探讨了当Celery任务中出现错误时会发生什么。有时这些错误信息并不明确。
*   **故障排查基础**：这部分知识非常有用，因为当系统出现故障时，你将具备基础知识和一个良好的起点来尝试修复问题，并最终使其运行得更好。
