## 🎯 核心概念回顾

上一节我们介绍了与大型语言模型交互的具体方法，本节中我们来总结其中的关键要点。

### 🤖 系统提示词的重要性

在这些课程中，我们演示了使用API的方式，这至关重要。你现在应该对如何通过系统提示词与大型语言模型进行实际交互有了清晰的认识。系统提示词非常重要，因为它能确保大型语言模型回复出我们所需的精确响应类型。

### 📊 数据格式处理

在本案例中，我们关注的是逗号分隔值（CSV）的处理。当大型语言模型在输出开头或结尾添加额外内容时，处理过程可能会有些棘手。因此，调整系统提示词以获得我们所需的确切输出，并持久化这些数据，是至关重要的步骤。

以下是数据处理流程的关键步骤：
*   **调整提示词**：修改系统提示词以精确控制模型输出格式。
*   **解析输出**：处理模型返回的文本，提取结构化的逗号分隔值。
*   **数据持久化**：将处理后的数据保存到磁盘。

### 🔄 构建自动化流程

这确保了我们能够整合一个完整的流程，以创建合成数据并将其持久化到磁盘，并以此为基础，在我们最初构建的代码框架上进行扩展。

## 📝 总结

本节课中我们一起学习了与大型语言模型API交互的核心实践。我们重点回顾了系统提示词在引导模型生成特定格式响应中的关键作用，探讨了处理模型输出（如CSV格式）时可能遇到的挑战及解决方案，并总结了如何构建一个从生成、处理到持久化合成数据的完整工作流程。这些基础代码和概念为后续更复杂的应用奠定了坚实的基础。
