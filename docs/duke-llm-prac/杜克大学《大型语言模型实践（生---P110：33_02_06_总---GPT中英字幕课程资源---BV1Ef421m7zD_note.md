# 大型语言模型实践：P110：总结与回顾

在本节课中，我们将回顾并总结使用Azure OpenAI服务的关键步骤与要点。我们将涵盖服务访问、模型部署以及使用Playground进行快速实验的核心内容。

## 访问Azure OpenAI服务

我们学习了如何使用Azure OpenAI服务。首先，需要了解如何实际获取对Azure OpenAI服务的访问权限。

需要注意的是，尽管目前访问权限受到一定限制，但随着服务日益普及，未来这些限制可能会放宽，相关情况也可能发生变化。

## 部署模型与使用Playground

上一节我们介绍了服务访问，本节中我们来看看模型部署。我们还学习了如何部署一个Azure OpenAI模型，并使用了Playground环境。

我认为Playground是一个极佳的入门工具，它能让你几乎不费力气地开始调整和探索已部署的Azure OpenAI模型。你看到部署几乎是瞬间完成的，这使得使用Playground变得非常简便且极具吸引力。

以下是使用Playground的优势：
*   可以轻松尝试不同的策略。
*   帮助你开始思考在部署和使用Azure OpenAI服务中的模型时，有哪些可能性。

## 课程总结

本节课中我们一起学习了Azure OpenAI服务的基本使用流程。我们了解了服务访问的现状与未来趋势，掌握了通过Azure平台部署LLM模型的方法，并重点体验了Playground这一强大且用户友好的工具，它能帮助我们快速进行模型测试与策略探索。
