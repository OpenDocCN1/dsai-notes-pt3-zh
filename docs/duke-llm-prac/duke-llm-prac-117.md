# 大型语言模型实践：1.1：引言与可扩展性概述

![](img/62db0de7c0fd53c375dea1e39b05a628_0.png)

在本节课中，我们将要学习大型语言模型（LLM）可扩展性的核心概念。理解这一点对于正确运用已部署的模型至关重要。

## 可扩展性的重要性

当你拥有一个已部署的实际模型时，例如Azure OpenAI服务中的OpenAI模型，正确把握其可扩展性就变得非常关键。

你的应用程序的关键差异化因素将在于你如何与这个已部署的模型进行交互。显然，直接使用默认的原始模型是不够的，我们有多种方法来扩展它。

## 本课程核心内容

接下来，我们将深入探讨如何通过特定框架来改进提示工程。我们将介绍一个名为Semantic Kernel的框架。

我们将了解Semantic Kernel究竟是什么，以及如何在Azure环境中与之交互。课程中会使用系统提示，并初步探索一些高级系统提示的用法。
