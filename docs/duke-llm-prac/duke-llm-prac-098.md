## 核心平台辨析

最后，清晰理解Azure提供的不同AI平台至关重要，这有助于我们选择合适的工具进行开发和部署。

![](img/004974ac402508f4d2b1547ef40b760c_1.png)

明确区分**Azure机器学习工作室**、**Azure机器学习**服务与**Azure OpenAI服务**之间的区别非常有用。

*   **Azure机器学习工作室**：是一个基于Web的交互式工作区，用于低代码或无代码的模型训练、部署和管理。
*   **Azure机器学习**：是一个更全面的企业级服务，提供用于端到端机器学习生命周期的SDK和基础设施。
*   **Azure OpenAI服务**：提供对OpenAI强大模型（如GPT系列）的托管访问，专注于生成式AI任务。

我认为现在这个概念已经清晰，这将使我们更容易探索这两个平台，并了解如何自然地开始部署模型并与它们交互。
