# 大型语言模型实践：2.3：生成式AI应用类型总结 🧠

![](img/4ee20b4b305c7546044094e2ad557f5e_0.png)

在本节课中，我们将总结生成式AI的常见应用类型，并深入探讨这些应用的具体形态。理解这些架构的差异和挑战，对于您未来构建自己的AI应用或做出技术选型将非常有帮助。

上一节我们介绍了多种生成式AI的应用架构，本节中我们来看看这些架构的核心要点与选择考量。

## 应用架构回顾

我们看到了多种不同的应用架构类型，其中多模态应用尤其值得关注。当您处理高度特定的模型时，这类应用特别有趣。您可能希望实现这类特定模型，因为它们更小、交互更快，并且所需资源更少。

例如，它们对GPU等计算资源的需求更低。这使得您的应用程序变得更加敏捷：部署更快、交互更容易、更轻量。因为它们不需要海量的资源来运行，也不需要庞大的存储空间来启动整个应用。

## 基于API架构的亮点与挑战

基于API的方法，即将请求卸载到远程模型，无疑也是一种有趣的方案。理解所有这些类型的模型应用（或基于大语言模型的应用）之间的差异与挑战，在您向前推进并尝试做出决策、选择发展方向时，将会非常有用。

以下是基于不同架构的核心特点对比：

*   **特定/轻量模型**：公式表示为 **模型大小小 & 资源需求低**。其优势在于**部署速度快**、**交互延迟低**且**成本较低**。
*   **多模态应用**：代码可描述为 `处理(文本， 图像， 音频)`。这类应用能处理多种输入类型，功能丰富，但集成复杂度较高。
*   **基于API的远程模型**：其工作流程为 **本地应用 -> API请求 -> 远程LLM -> 返回结果**。优点在于无需管理底层模型基础设施，但依赖于网络并可能产生持续的使用成本。

## 总结

本节课中，我们一起学习了生成式AI的不同应用架构类型及其特点。我们探讨了轻量级特定模型的速度与效率优势，多模态应用的强大功能，以及基于API方案的便利性与考量。理解这些选项的优劣，将帮助您根据自身需求——无论是追求快速部署、低成本运行还是处理复杂输入——来做出更明智的技术选择，从而成功构建您自己的AI应用程序。
