在本节课中，我们将要学习如何为实际应用构建解决方案，并探讨与开源大语言模型交互所需的编程语言和工具。我们将重点比较Python和Rust两种语言，分析它们各自的优势，并了解如何使用Rust来构建能够解决实际问题的应用。

当我们准备开始构建真实世界的应用程序时，这些解决方案最终需要部署到生产环境中。毫无疑问，我们必须审视一些编程语言，并利用现有的工具来与模型（在本课程中特指开源模型）进行交互。

因此，我们将探讨如何使用这些工具。我们之前在某些环节已经少量使用了Python，但接下来我们将更深入地研究Rust。

我们将看看Python和Rust之间的一些区别，分析你可能选择其中一种而非另一种的原因。同时，我们也会了解一些可以与Rust配合使用的解决方案，以便我们能够通过这些方案与模型交互，并最终整合出一个能够有效解决实际问题的应用。

上一节我们介绍了构建应用的基本背景，本节中我们来看看具体的技术选型。

以下是Python与Rust的主要对比考量点：

*   **Python**：以其简洁的语法和丰富的库生态而闻名，特别适合快速原型开发和数据科学任务。
*   **Rust**：则强调**内存安全**、**并发性能**和高执行效率，其核心优势在于能在编译时防止数据竞争等错误，适合构建高性能、高可靠性的系统。

本节课中我们一起学习了为生产环境构建LLM应用时对编程语言和工具的考量，比较了Python和Rust的适用场景，并引出了使用Rust与开源模型交互以构建解决方案的主题。
