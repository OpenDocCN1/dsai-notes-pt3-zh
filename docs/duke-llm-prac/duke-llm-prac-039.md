# 大型语言模型实践：1.2：总结与核心技巧 🧠

在本节课中，我们将回顾并总结之前探讨的大型语言模型（LLM）的局限性，并学习几种关键的提示词（Prompt）技巧，以帮助我们获得更优的模型响应。

上一节我们介绍了大型语言模型在处理复杂任务时可能遇到的上下文限制。本节中，我们来看看如何通过特定的提示策略来引导模型，从而克服这些挑战。

## 核心发现与挑战

我们观察到了模型在上下文长度上的限制。当我们要求模型完成的任务超出其处理能力时，它无法给出完整的答案。这本身是一个有价值的发现，因为它让我们直观地理解了模型的边界所在。

## 提升响应的关键技巧

为了获得更好的结果，我们探索并应用了以下几种提示词技巧：

以下是三种有效的策略：

1.  **思维链（Chain of Thought）引导**：通过指令 `请逐步思考` 或 `请分步骤进行`，引导模型将复杂问题分解为更小的、连续的推理步骤。
2.  **任务分解**：将庞大或复杂的请求拆分成多个较小的、定义清晰的任务，逐一提交给模型处理。
3.  **首尾强调法**：在提示词的开头**明确陈述核心指令**，在结尾处**再次重申关键要求或期望的输出格式**。这种方法在交互内容变得复杂时尤为有效。

通过结合使用这些技巧，尤其是“首尾强调法”，我们能够从大型语言模型中获得**显著更好**的响应质量，特别是在处理复杂任务时。
