## 📚 概述
在本节课中，我们将总结在浏览器中直接运行大型语言模型的关键要点，特别是使用 Transformers.js 的方法与前提条件。我们将回顾核心概念，并了解如何轻松地开始实践。

## 🧠 核心要点总结

我们看到了如何直接在浏览器中使用这些模型，特别是通过 **Transformers.js**。

但这里有一个关键要求，那就是使用 **ONNX** 格式。这些模型必须被转换并移植到 ONNX 格式上。我们还简要介绍了如何开始将一些现有模型转换为 ONNX 格式，以便在 ONNX 运行时上使用。

这正是 **Transformers.js** 能够在浏览器中使用模型的关键：它要求模型必须是 ONNX 格式。因为其底层技术依赖于浏览器中的 **ONNX 运行时**。

现在，需要特别注意模型的**大小**，这一点非常重要。请务必意识到模型大小对浏览器端运行的影响。
