## 🔗 核心内容：结合外部API的函数

我们将创建一个函数，它能够处理输入参数，并与外部服务进行交互。以下是实现这一目标的关键步骤：

1.  **定义函数接口**：首先，我们需要定义一个函数，它接收特定的参数。例如，一个查询天气的函数可能接收 `location` 和 `date` 作为参数。
    ```python
    def get_weather(location: str, date: str):
        # 函数逻辑
    ```

2.  **调用外部API**：在函数内部，我们将构造请求并调用一个外部服务（如天气API）。
    ```python
    import requests
    def get_weather(location: str, date: str):
        api_url = f"https://api.weather.com/v1/forecast?location={location}&date={date}"
        response = requests.get(api_url)
        return response.json()
    ```

3.  **处理与整合**：函数将处理API的返回结果，并将其格式化为大型语言模型能够理解或使用的形式。
