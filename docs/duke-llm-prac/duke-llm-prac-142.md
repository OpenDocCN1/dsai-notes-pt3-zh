## 概述

在本节课中，我们将学习如何使用检索增强生成技术。我们将重点介绍如何利用Azure AI搜索服务，结合Azure OpenAI，来实现让大型语言模型与我们自己的数据进行交互。

## 课程内容

上一节我们介绍了课程的整体目标，本节中我们来看看具体的实现路径。我们将通过Azure平台的不同服务来完成一个完整的检索增强生成流程。

以下是实现RAG模式需要完成的主要步骤：

1.  了解并创建所需的Azure服务。
2.  学习如何为文本数据创建嵌入向量。
3.  掌握如何将数据索引上传至搜索服务。
4.  验证生成的嵌入向量是否正确。
5.  最终，集成所有组件，使用Azure OpenAI实现检索增强生成模式。

我理解这里提到了许多尚未讲解的新概念和不同组件。但我会使用非常简单明了的示例进行说明。最有趣的是，我们将充分利用Azure云平台为我们完成的大量基础工作。

这样，我们就能获取一段文本，并生成大型语言模型与我们的私有数据交互所需的一切。本质上，我们正是要通过使用自己的数据，来扩展大型语言模型的功能。

## 总结

本节课我们一起学习了检索增强生成的基本概念和实现蓝图。我们了解到，借助Azure AI搜索和Azure OpenAI等服务，可以构建一个系统，使大型语言模型能够安全、有效地访问和处理我们的私有数据，从而扩展其应用能力。
