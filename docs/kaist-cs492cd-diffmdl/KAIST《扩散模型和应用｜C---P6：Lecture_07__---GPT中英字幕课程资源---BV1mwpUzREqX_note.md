# 扩散模型与应用：07：条件生成、潜在扩散与微调技术

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_0.png)

## 概述

在本节课中，我们将学习如何将扩散模型应用于更实际的场景。我们将探讨如何利用额外信息（如类别标签或文本描述）进行条件图像生成，以及如何高效地利用在大规模数据集上预训练的扩散模型，通过微调技术将其适配到特定任务上，例如个性化生成或特定类型的条件生成。

## 从分类器引导到无分类器引导

上一节我们介绍了扩散模型的基本原理。本节中，我们来看看如何利用额外信息来引导生成过程，从而提高生成质量或实现条件生成。

### 分类器引导

基本思想是，当我们拥有图像的额外信息（如类别标签）时，可以利用一个分类器网络来改进生成过程。具体来说，我们希望建模图像 `X_t` 和标签 `y` 的联合分布。

在扩散过程中，我们预测的噪声 `ε_θ` 与数据分布的梯度（即得分函数）相关。对于联合分布 `p(x_t, y)`，其得分函数可以分解为：

**公式：∇ log p(x_t, y) = ∇ log p(x_t) + ∇ log p(y | x_t)**

其中，`∇ log p(y | x_t)` 正是分类器网络所建模的条件概率的梯度。因此，我们可以通过以下方式修正预测的噪声：

**公式：ε_θ'(x_t, y) = ε_θ(x_t) - ω * σ_t * ∇ log p(y | x_t)**

这里，`ω` 是一个引导权重参数。通过引入一个预训练的分类器网络来计算 `p(y | x_t)`，我们可以在生成过程中“引导”模型产生更符合给定标签 `y` 的图像。

**优点**：可以提升生成图像的质量和与条件的对齐度。
**缺点**：需要额外训练一个分类器网络；当类别数量非常多时，分类器性能可能下降。

### 无分类器引导

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_2.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_4.png)

为了克服分类器引导的缺点，无分类器引导被提出。其核心思想是使用**同一个**噪声预测网络来处理有条件和无条件两种情况。

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_6.png)

具体做法是修改噪声预测网络 `ε_θ`，使其能接受条件 `y` 作为额外输入。同时，我们定义一个特殊的“空条件”（如 `∅`）来表示无条件生成。

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_8.png)

在采样时，我们同时计算有条件噪声 `ε_θ(x_t, y)` 和无条件噪声 `ε_θ(x_t, ∅)`，然后通过以下公式进行插值（实际上是外推）：

**公式：ε_θ'(x_t, y) = ε_θ(x_t, ∅) + ω * (ε_θ(x_t, y) - ε_θ(x_t, ∅))**

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_10.png)

其中 `ω` 是引导尺度。当 `ω > 1` 时，即为外推，它放大了条件的影响。

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_12.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_13.png)

**优点**：
*   实现简单，只需修改网络输入。
*   非常灵活，条件 `y` 可以是文本、图像等多种形式。
*   数学上等价于分类器引导，但无需单独的分类器。

**缺点**：每次采样需要运行两次前向传播（一次有条件，一次无条件）。

无分类器引导是现代文生图等扩散模型（如 Stable Diffusion）中最常用的技术之一。

## 潜在扩散模型

之前我们讨论的模型直接在像素空间操作。然而，要处理高分辨率图像和海量数据，计算成本极高。本节我们介绍一种更高效的范式：潜在扩散模型。

### 核心思想

潜在扩散模型的核心思想是**在低维潜在空间中进行扩散过程**，而非原始的高维像素空间。这通过一个预训练的自动编码器来实现。

**流程如下**：
1.  **编码**：使用编码器 `E` 将原始图像 `x` 压缩到一个低维潜在表示 `z = E(x)`。例如，将 512x512x3 的 RGB 图像压缩为 64x64x4 的潜在特征图。
2.  **潜在空间扩散**：在潜在空间 `z` 上训练扩散模型（即噪声预测网络）。
3.  **解码**：生成过程结束后，使用解码器 `D` 将潜在表示 `z` 重建回像素图像 `x' = D(z)`。

### 优势

*   **效率**：在低维空间进行扩散，大大降低了计算和内存开销，使得训练数十亿张高分辨率图像成为可能。
*   **质量**：专注于学习数据的语义特征，而非像素级细节，往往能生成质量更高、更连贯的图像。
*   **灵活性**：潜在空间为后续的图像编辑和控制提供了便利的接口。

在实现中，噪声预测网络通常采用 **U-Net** 架构，并集成了**交叉注意力**机制来融入文本等条件信息。文本描述先通过一个文本编码器（如 CLIP）转换为特征向量，然后通过交叉注意力层注入到 U-Net 的各个层中。

## 微调预训练扩散模型：ControlNet 与 LoRA

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_15.png)

我们拥有在数十亿图像上预训练的强大扩散模型（如 Stable Diffusion）。如何用相对少量的数据，将其快速适配到新的条件生成任务上？本节介绍两种高效的微调技术。

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_17.png)

### ControlNet：用于空间条件控制

ControlNet 旨在为预训练的扩散模型（尤其是 U-Net 的编码器部分）添加一个可训练的“副本”，以处理新的空间条件输入（如边缘图、深度图、姿态关键点等）。

**核心结构**：
1.  **锁定预训练模型**：保持原始 U-Net 的所有参数冻结。
2.  **创建可训练副本**：复制 U-Net 的编码器部分，作为可训练的条件编码分支。
3.  **零卷积连接**：使用一种特殊的“零卷积”层（权重初始化为零）将条件分支连接到原始 U-Net。这确保了在训练开始时，条件分支的输出为零，整个网络的行为与原始模型完全一致，保证了训练的稳定性。
4.  **渐进式融合**：随着训练进行，零卷积层的参数被更新，条件信息被逐渐融入到生成过程中。

**优点**：可以用少量（例如 10 万对）图像-条件对数据，高效地将模型微调为高质量的条件生成模型，同时保持原始模型的生成能力。

### LoRA：用于风格与对象个性化

LoRA 是一种参数高效的微调方法，适用于将模型个性化到特定风格或对象上。

**核心思想**：不直接微调原始模型庞大的权重矩阵，而是为网络中的一些线性层（如注意力模块中的 Q、K、V 投影层）注入低秩的适配器模块。

对于一个权重矩阵 `W ∈ R^(d×d)`，LoRA 将其更新表示为：
**公式：W' = W + ΔW = W + B * A**
其中，`A ∈ R^(r×d)`, `B ∈ R^(d×r)`，且秩 `r << d`。`A` 和 `B` 是可训练的参数，而 `W` 被冻结。

**优点**：
*   **参数高效**：只需训练极少量（通常 <1%）的参数。
*   **存储方便**：可以保存多个小的 LoRA 适配器文件，轻松切换不同风格。
*   **训练快速**：收敛速度快，适合小数据集上的个性化。

这使得用户可以用自己拍摄的少量照片（如 10-20 张），快速微调出一个能生成自己肖像或特定物品的个性化模型。

## 评估指标：FID 简介

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_35.png)

在比较生成模型质量时，我们常使用 **FID**。它衡量的是生成图像分布与真实图像分布之间的差异。

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_37.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_39.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_41.png)

FID 基于 **Fréchet 距离**（又称 Wasserstein-2 距离）计算。其基本思想是：将真实图像和生成图像都通过一个预训练的分类网络（如 Inception-v3）提取特征，然后假设这些特征服从多元高斯分布，并计算两个高斯分布之间的 Fréchet 距离。

**公式：FID = ||μ_r - μ_g||² + Tr(Σ_r + Σ_g - 2(Σ_r Σ_g)^(1/2))**
其中 `μ` 是均值向量，`Σ` 是协方差矩阵，下标 `r` 和 `g` 分别代表真实数据和生成数据。

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_43.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_45.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_46.png)

**注意**：FID 并非完美指标。它依赖于所选特征空间（Inception-v3）的表征能力，并且假设特征分布为高斯分布，这可能与实际情况不符。但它仍然是当前最常用的生成模型评估指标之一。

## 总结

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_48.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_50.png)

本节课我们一起学习了扩散模型走向实际应用的关键技术：
1.  **条件生成**：通过**分类器引导**和更通用的**无分类器引导**，利用文本、类别等条件信息控制生成内容。
2.  **高效架构**：**潜在扩散模型**通过在压缩的潜在空间进行扩散，大幅提升了处理高分辨率、大规模数据集的效率。
3.  **高效微调**：利用 **ControlNet** 可以将预训练模型快速适配到基于图像条件的生成任务（如草图转图像）；利用 **LoRA** 可以用极少的参数实现模型的风格或对象**个性化**。
4.  **评估指标**：了解了 **FID** 这一常用生成质量评估指标的基本原理与局限。

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_52.png)

![](img/aa8066cb5bb8cf333d3e4ec7575680e6_54.png)

这些技术构成了当前强大文生图、图生图等应用的核心基础，使我们能够灵活、高效地利用大规模预训练扩散模型解决多样化的生成问题。
