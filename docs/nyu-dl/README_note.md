# 深度学习基础 第1课：神经网络入门 🧠

在本节课中，我们将要学习神经网络的基本概念和工作原理。我们将从最简单的线性模型开始，逐步理解神经元如何通过权重和偏置进行计算，并最终组合成复杂的网络。

## 1. 什么是神经网络？

神经网络是一种模仿人脑神经元工作方式的计算模型。它由大量相互连接的“神经元”组成，能够通过学习数据中的模式来完成特定任务。

上一节我们介绍了神经网络的基本概念，本节中我们来看看构成神经网络的基本单元——神经元。

## 2. 神经元：网络的基本单元

一个神经元是神经网络中最小的计算单元。它接收多个输入信号，经过内部处理，产生一个输出信号。

以下是神经元工作的三个核心步骤：

1.  **加权求和**：神经元接收来自其他神经元或输入数据的信号。每个输入信号都有一个对应的**权重**，表示该输入的重要性。神经元将所有输入信号与其权重相乘后求和。
    *   公式表示为：`z = (w1 * x1) + (w2 * x2) + ... + (b)`，其中`w`是权重，`x`是输入，`b`是偏置项。

2.  **添加偏置**：在求和结果上加上一个**偏置**值。偏置允许神经元在输入全为零时也能产生输出，它决定了神经元激活的难易程度。

3.  **激活函数**：将加权求和并加上偏置的结果（称为“净输入”）通过一个**激活函数**。这个函数决定了神经元是否被“激活”以及激活的程度，为网络引入了非线性。

## 3. 从神经元到网络

单个神经元的能力有限。将许多神经元连接在一起，形成层状结构，就构成了神经网络。

上一节我们了解了单个神经元，本节中我们来看看如何将它们组织起来。

一个典型的神经网络包含三种类型的层：

*   **输入层**：接收原始数据（如图像像素、文本单词）。
*   **隐藏层**：位于输入和输出层之间，负责进行复杂的特征提取和转换。一个网络可以有多个隐藏层，“深度学习”中的“深度”即指隐藏层数量多。
*   **输出层**：产生网络的最终预测结果（如图像类别、翻译后的句子）。

信号从输入层开始，依次经过各隐藏层，最终到达输出层，这个过程称为**前向传播**。

## 4. 网络如何学习？

神经网络通过调整其内部参数（权重和偏置）来学习。这个过程的核心是一个称为**反向传播**的算法。

以下是学习过程的关键步骤：

1.  **初始化**：开始时，网络的所有权重和偏置被随机设置为很小的值。

2.  **前向传播与计算损失**：输入一批训练数据，通过网络进行前向传播，得到预测输出。然后，使用一个**损失函数**（如均方误差）来度量预测输出与真实答案之间的差距。

3.  **反向传播误差**：算法从输出层开始，反向计算损失函数相对于每个权重的梯度（即导数）。这回答了“每个权重需要对总误差负多少责任？”这个问题。

4.  **更新参数**：使用**优化算法**（如梯度下降）根据计算出的梯度来更新所有权重和偏置。更新的目标是减少损失函数的值。
    *   更新公式简化为：`新权重 = 旧权重 - 学习率 * 梯度`

5.  **重复迭代**：对训练数据重复步骤2到4多次（称为“轮次”），直到网络的预测性能不再显著提升或达到预设的迭代次数。

本节课中我们一起学习了神经网络的基础知识。我们了解了神经元作为基本计算单元如何通过加权求和、添加偏置和应用激活函数来工作。我们看到多个神经元可以连接成具有输入层、隐藏层和输出层的网络。最后，我们探讨了网络通过前向传播计算预测、通过损失函数衡量误差、并利用反向传播和梯度下降算法更新权重以进行学习的关键过程。理解这些概念是进入更复杂深度学习领域的坚实基础。
