# DeepLearningAI 2025 笔记：第一课 - 神经网络基础 🧠

在本节课中，我们将学习神经网络的基本构成单元——神经元，并理解其如何通过数学公式进行工作。我们将从最简单的模型开始，逐步构建理解。

## 概述

神经网络是模仿人脑工作方式的计算模型。它的基本单位是神经元。一个神经元接收输入信号，经过处理，产生一个输出信号。理解单个神经元是理解复杂神经网络的第一步。

## 神经元模型

上一节我们介绍了神经元的概念，本节中我们来看看它的数学模型。

一个神经元的工作流程可以概括为三步：
1.  接收多个输入。
2.  对输入进行加权求和并加上偏置。
3.  通过一个激活函数产生输出。

这个过程可以用一个公式来描述：

**`z = w1*x1 + w2*x2 + ... + wn*xn + b`**
**`a = σ(z)`**

其中：
*   `x1, x2, ..., xn` 是输入特征。
*   `w1, w2, ..., wn` 是对应每个输入的权重，代表了该输入的重要程度。
*   `b` 是偏置项，它是一个常数，用于调整神经元的输出。
*   `z` 是加权求和后的结果。
*   `σ` 代表激活函数，它将 `z` 映射到最终的输出 `a`。

## 激活函数

激活函数决定了神经元是否应该被“激活”，即是否输出信号以及输出信号的强度。没有激活函数的神经网络只是一个线性回归模型。

以下是几种常见的激活函数：

*   **Sigmoid 函数**：将输入压缩到 (0, 1) 之间。公式为 **`σ(z) = 1 / (1 + e^(-z))`**。常用于二分类问题的输出层。
*   **Tanh 函数**：将输入压缩到 (-1, 1) 之间。公式为 **`tanh(z) = (e^z - e^(-z)) / (e^z + e^(-z))`**。其均值接近0，有助于中心化数据。
*   **ReLU 函数（整流线性单元）**：目前最常用的激活函数。公式为 **`ReLU(z) = max(0, z)`**。它在正区间是线性的，计算速度快，能有效缓解梯度消失问题。

## 从神经元到网络

单个神经元的能力有限。将许多神经元连接起来，就形成了神经网络。神经网络通常由输入层、一个或多个隐藏层以及输出层组成。

*   **输入层**：接收原始数据。
*   **隐藏层**：位于输入和输出层之间，负责进行复杂的特征变换和提取。可以有多个隐藏层，层数越多，网络越“深”。
*   **输出层**：产生网络的最终预测结果。

每一层的神经元接收前一层所有神经元的输出作为输入，并计算自己的输出，传递给下一层。这种结构使得神经网络能够学习数据中复杂的非线性关系。

## 前向传播

前向传播是数据从输入层流向输出层的过程。我们通过一个简单的两层网络例子来说明。

假设网络有一个输入层（2个特征）、一个隐藏层（3个神经元）和一个输出层（1个神经元）。

以下是计算步骤：
1.  计算隐藏层的输入 `Z[1]` 和输出 `A[1]`：
    **`Z[1] = W[1] * X + b[1]`**
    **`A[1] = σ(Z[1])`**
    （这里 `W[1]` 是连接输入层和隐藏层的权重矩阵，`b[1]` 是隐藏层的偏置向量）
2.  计算输出层的输入 `Z[2]` 和最终输出 `A[2]`：
    **`Z[2] = W[2] * A[1] + b[2]`**
    **`A[2] = σ(Z[2])`**

这个过程就是前向传播，它让我们得到了一个基于当前权重和偏置的预测值。

## 总结

本节课中我们一起学习了神经网络的基础知识。我们从最基本的神经元模型及其数学公式开始，了解了激活函数的作用与常见类型。接着，我们看到了如何将神经元组织成具有输入层、隐藏层和输出层的网络结构。最后，我们通过前向传播的过程，理解了数据是如何在网络中流动并最终产生预测的。掌握这些概念是后续学习网络训练、反向传播和更复杂架构的坚实基础。
