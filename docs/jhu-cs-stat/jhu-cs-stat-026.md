## 案例背景

![](img/9cbb06f00f795e9c76afbc64267cf43d_6.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_8.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_9.png)

伯克利大学曾面临一起诉讼。一位数学教授在申请终身教职时被拒绝，她因此提起诉讼，指控伯克利大学存在性别歧视。她提供的证据并非关于教职评审，而是关于博士生的录取情况。她指出，在伯克利大学的全部22个系中，**每个系**录取的女性博士生比例都低于男性。

![](img/9cbb06f00f795e9c76afbc64267cf43d_11.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_13.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_14.png)

然而，伯克利大学反驳称，从**整个大学**的层面来看，博士生项目中录取的女性总数实际上**多于**男性。

![](img/9cbb06f00f795e9c76afbc64267cf43d_16.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_18.png)

这就引出了一个核心问题：**这可能吗？** 是否可能每个系录取的女性比例都更低，但全校加总后女性总数反而更多？

## 问题建模

![](img/9cbb06f00f795e9c76afbc64267cf43d_20.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_21.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_22.png)

为了分析这个问题，我们使用条件概率来建模。我们以两个系为例进行说明。

![](img/9cbb06f00f795e9c76afbc64267cf43d_24.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_26.png)

首先定义一些符号：
*   **A** 表示事件“被录取”。
*   **F_CS** 表示“女性申请计算机科学系”。
*   **F_EE** 表示“女性申请电气工程系”。
*   **M_CS** 表示“男性申请计算机科学系”。
*   **M_EE** 表示“男性申请电气工程系”。

原告（教授）的指控可以表述为以下两个条件概率不等式：
1.  **P(A | F_CS) < P(A | M_CS)**
2.  **P(A | F_EE) < P(A | M_EE)**

![](img/9cbb06f00f795e9c76afbc64267cf43d_28.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_29.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_30.png)

即，在**每个系内部**，女性申请者的录取概率都低于男性申请者。

![](img/9cbb06f00f795e9c76afbc64267cf43d_32.png)

而校方的反驳可以表述为：
*   **P(A | (F_CS ∪ F_EE)) > P(A | (M_CS ∪ M_EE))**

![](img/9cbb06f00f795e9c76afbc64267cf43d_34.png)

即，将两个系**合并看待**时，女性申请者的总体录取概率高于男性。

![](img/9cbb06f00f795e9c76afbc64267cf43d_35.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_36.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_37.png)

## 用具体数字验证可能性

现在，我们通过一组具体的数字来验证这种情况是否可能发生。

![](img/9cbb06f00f795e9c76afbc64267cf43d_39.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_40.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_41.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_42.png)

假设计算机科学系的录取情况如下：
*   女性申请者：1人申请，0人被录取。录取率 = **0/1 = 0%**
*   男性申请者：100人申请，50人被录取。录取率 = **50/100 = 50%**
*   显然，`0% < 50%`，满足第一个不等式。

![](img/9cbb06f00f795e9c76afbc64267cf43d_43.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_45.png)

假设电气工程系的录取情况如下：
*   女性申请者：100人申请，70人被录取。录取率 = **70/100 = 70%**
*   男性申请者：1人申请，1人被录取。录取率 = **1/1 = 100%**
*   显然，`70% < 100%`，满足第二个不等式。

![](img/9cbb06f00f795e9c76afbc64267cf43d_47.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_48.png)

现在，我们计算两个系合并后的总体录取率：
*   **总体女性**：申请总数 = 1 + 100 = 101，录取总数 = 0 + 70 = 70。总体录取率 = **70/101 ≈ 69.3%**
*   **总体男性**：申请总数 = 100 + 1 = 101，录取总数 = 50 + 1 = 51。总体录取率 = **51/101 ≈ 50.5%**
*   比较结果：`69.3% > 50.5%`

![](img/9cbb06f00f795e9c76afbc64267cf43d_50.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_51.png)

**结论**：尽管在每个系里，女性的录取率都低于男性，但从整体上看，女性的总体录取率却高于男性。这证明了所述情况在数学上是完全可能的。

这位数学教授最终赢得了诉讼，获得了终身教职。

这个案例引发了更深层次的思考：
*   教授赢得官司，是因为她发现了大学数据中存在的逻辑悖论，还是因为她“滥用”统计学来赢得官司？
*   即使整体结果“公平”，但每个系都存在的录取率差异，是否本身就意味着不公平？
*   不同性别申请者向不同院系递交申请的数量分布，如何影响我们对“公平”的判断？

## 本节总结

本节课我们一起学习了一个经典的统计悖论——**辛普森悖论**在现实生活中的体现（伯克利录取案）。我们了解到：
1.  **局部比较与整体比较可能得出相反结论**。这是条件概率中一个需要警惕的现象。
2.  **数据聚合方式会影响分析结果**。在查看统计数据时，必须清楚数据是如何被分组的。
3.  **相关关系不等于因果关系**。录取率的差异可能由多种复杂因素（如申请者的专业选择偏好、背景等）导致，不能直接简化为性别歧视。

![](img/9cbb06f00f795e9c76afbc64267cf43d_60.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_61.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_62.png)

![](img/9cbb06f00f795e9c76afbc64267cf43d_63.png)

这个悖论提醒我们，在进行统计推断时，必须仔细审视数据的结构和条件，避免得出片面或错误的结论。在后续课程或练习中，我们还会遇到更多类似的例子。
