上一节我们讨论了依赖事件，本节中我们来看看独立事件。

![](img/b8104f118f48d53e3f3f7c45561c8b38_26.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_27.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_28.png)

让我给你一个例子。假设事件A表示“随机抽取一张牌，它是Ace”。事件B表示“随机抽取一张牌，它是黑桃”。

![](img/b8104f118f48d53e3f3f7c45561c8b38_30.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_31.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_32.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_34.png)

那么，事件A和B同时发生的概率，即抽到黑桃A的概率，是1/52。因为一副牌有52张，黑桃A只有一张。

![](img/b8104f118f48d53e3f3f7c45561c8b38_36.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_37.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_39.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_40.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_42.png)

我们也可以分别计算事件A和事件B的概率。事件A（抽到Ace）的概率是4/52，即1/13。事件B（抽到黑桃）的概率是13/52，即1/4。

![](img/b8104f118f48d53e3f3f7c45561c8b38_44.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_46.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_47.png)

有趣的是，在这个例子中，事件A的概率乘以事件B的概率，其结果恰好等于事件A和B同时发生的概率：
`P(A) * P(B) = (1/13) * (1/4) = 1/52 = P(A ∩ B)`

![](img/b8104f118f48d53e3f3f7c45561c8b38_48.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_50.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_52.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_54.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_56.png)

这个发现引出了我们的核心规则：如果两个事件A和B满足 `P(A ∩ B) = P(A) * P(B)`，那么我们就称事件A和B是**独立的**。这是独立性的定义。

![](img/b8104f118f48d53e3f3f7c45561c8b38_58.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_59.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_60.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_62.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_63.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_65.png)

如果A和B独立，那么A与B的补集（即B不发生的事件）也是独立的。

现在，让我们重新审视一个之前提出的问题：`P(A|B)` 在什么情况下会等于 `P(B|A)`？

![](img/b8104f118f48d53e3f3f7c45561c8b38_72.png)

根据贝叶斯定理，我们知道：
`P(A|B) = P(A ∩ B) / P(B)`
`P(B|A) = P(A ∩ B) / P(A)`

![](img/b8104f118f48d53e3f3f7c45561c8b38_73.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_75.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_76.png)

要使这两个条件概率相等，即 `P(A ∩ B) / P(B) = P(A ∩ B) / P(A)`，需要满足以下条件之一：

![](img/b8104f118f48d53e3f3f7c45561c8b38_78.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_80.png)

以下是可能的选项：
1.  `P(A) = P(B)`
2.  `P(A) = 0` 或 `P(B) = 0`
3.  `P(A ∩ B) = 0`
4.  以上都不是

![](img/b8104f118f48d53e3f3f7c45561c8b38_82.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_84.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_86.png)

让我们来分析一下。如果 `P(A) = P(B)`，那么等式两边的分母相同，等式自然成立。如果 `P(A ∩ B) = 0`（即A和B是互斥事件），那么等式两边都等于0，等式也成立。而如果 `P(A) = 0` 或 `P(B) = 0`，会导致条件概率的定义出现问题（分母为零），因此不是有效情况。

![](img/b8104f118f48d53e3f3f7c45561c8b38_88.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_89.png)

所以，正确的答案是：当 `P(A) = P(B)` 或 `P(A ∩ B) = 0` 时，`P(A|B)` 等于 `P(B|A)`。

![](img/b8104f118f48d53e3f3f7c45561c8b38_90.png)

![](img/b8104f118f48d53e3f3f7c45561c8b38_91.png)

本节课中我们一起学习了独立事件的定义：如果两个事件A和B满足 `P(A ∩ B) = P(A) * P(B)`，则它们是独立的。我们还利用贝叶斯定理探讨了 `P(A|B) = P(B|A)` 成立的条件，即两个事件的概率相等，或者它们互斥（同时发生的概率为零）。理解独立性是进行更复杂概率分析和统计推断的重要基础。
