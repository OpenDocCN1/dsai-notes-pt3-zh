## 核心概念与公式

![](img/8bbebd9e66e2f208faf701455a000465_29.png)

当我们需要将 **n** 个**不可区分**的物品分配给 **r** 个**可区分**的接收者（如人、容器）时，分配方式的总数由以下组合公式给出：

![](img/8bbebd9e66e2f208faf701455a000465_31.png)

![](img/8bbebd9e66e2f208faf701455a000465_32.png)

![](img/8bbebd9e66e2f208faf701455a000465_33.png)

![](img/8bbebd9e66e2f208faf701455a000465_34.png)

![](img/8bbebd9e66e2f208faf701455a000465_35.png)

**公式：** `C(n + r - 1, r - 1)`

这个公式本质上是在求解一个线性方程：`x₁ + x₂ + ... + xᵣ = n`，其中每个 `xᵢ` 代表第 `i` 个接收者得到的物品数量，且 `xᵢ ≥ 0`。

## 示例一：分配鲜花 🌹🌼

让我们通过一个具体例子来理解这个公式。

![](img/8bbebd9e66e2f208faf701455a000465_50.png)

![](img/8bbebd9e66e2f208faf701455a000465_51.png)

![](img/8bbebd9e66e2f208faf701455a000465_52.png)

![](img/8bbebd9e66e2f208faf701455a000465_53.png)

假设我们有 **10朵玫瑰** 和 **15朵雏菊**，需要将它们分配给 **两个女孩**。两种花是各自不可区分的（所有玫瑰相同，所有雏菊相同），但女孩是可区分的。

![](img/8bbebd9e66e2f208faf701455a000465_55.png)

![](img/8bbebd9e66e2f208faf701455a000465_56.png)

![](img/8bbebd9e66e2f208faf701455a000465_58.png)

### 分配玫瑰
对于玫瑰，我们需要满足方程：`x₁ + x₂ = 10`，其中 `x₁, x₂ ≥ 0`。
*   **n** = 10 （玫瑰总数）
*   **r** = 2 （女孩数量）

![](img/8bbebd9e66e2f208faf701455a000465_60.png)

![](img/8bbebd9e66e2f208faf701455a000465_61.png)

![](img/8bbebd9e66e2f208faf701455a000465_62.png)

![](img/8bbebd9e66e2f208faf701455a000465_64.png)

代入公式：
`C(10 + 2 - 1, 2 - 1) = C(11, 1) = 11`
因此，分配10朵玫瑰给两个女孩有 **11种** 方式。

![](img/8bbebd9e66e2f208faf701455a000465_66.png)

![](img/8bbebd9e66e2f208faf701455a000465_68.png)

![](img/8bbebd9e66e2f208faf701455a000465_70.png)

### 分配雏菊
对于雏菊，我们需要满足方程：`x₁ + x₂ = 15`，其中 `x₁, x₂ ≥ 0`。
*   **n** = 15 （雏菊总数）
*   **r** = 2 （女孩数量）

![](img/8bbebd9e66e2f208faf701455a000465_72.png)

代入公式：
`C(15 + 2 - 1, 2 - 1) = C(16, 1) = 16`
因此，分配15朵雏菊给两个女孩有 **16种** 方式。

![](img/8bbebd9e66e2f208faf701455a000465_74.png)

![](img/8bbebd9e66e2f208faf701455a000465_75.png)

![](img/8bbebd9e66e2f208faf701455a000465_76.png)

![](img/8bbebd9e66e2f208faf701455a000465_77.png)

![](img/8bbebd9e66e2f208faf701455a000465_78.png)

![](img/8bbebd9e66e2f208faf701455a000465_79.png)

### 计算总分配方式
由于分配玫瑰和分配雏菊是两个独立的事件，根据乘法原理，总分配方式为：
`11 × 16 = 176`
所以，将10朵玫瑰和15朵雏菊分配给两个女孩，总共有 **176种** 不同的分配方式。

## 示例二：分配球到有条件的瓮中 ⚽⚽⚽

![](img/8bbebd9e66e2f208faf701455a000465_88.png)

![](img/8bbebd9e66e2f208faf701455a000465_89.png)

![](img/8bbebd9e66e2f208faf701455a000465_90.png)

现在，假设我们要将 **20个相同的球** 分配到 **3个不同的瓮** 中，但有以下条件：
*   瓮1至少要有 **1个** 球。
*   瓮2至少要有 **2个** 球。
*   瓮3至少要有 **3个** 球。

![](img/8bbebd9e66e2f208faf701455a000465_91.png)

![](img/8bbebd9e66e2f208faf701455a000465_92.png)

![](img/8bbebd9e66e2f208faf701455a000465_94.png)

![](img/8bbebd9e66e2f208faf701455a000465_96.png)

我们依然需要满足方程：`x₁ + x₂ + x₃ = 20`，但现在 `x₁ ≥ 1`, `x₂ ≥ 2`, `x₃ ≥ 3`。

![](img/8bbebd9e66e2f208faf701455a000465_97.png)

![](img/8bbebd9e66e2f208faf701455a000465_99.png)

![](img/8bbebd9e66e2f208faf701455a000465_100.png)

为了使用标准公式（要求 `xᵢ ≥ 0`），我们可以进行变量替换：
令 `u₁ = x₁ - 1`，则 `u₁ ≥ 0`
令 `u₂ = x₂ - 2`，则 `u₂ ≥ 0`
令 `u₃ = x₃ - 3`，则 `u₃ ≥ 0`

![](img/8bbebd9e66e2f208faf701455a000465_102.png)

![](img/8bbebd9e66e2f208faf701455a000465_103.png)

![](img/8bbebd9e66e2f208faf701455a000465_104.png)

将原方程用新变量表示：
`(u₁ + 1) + (u₂ + 2) + (u₃ + 3) = 20`
简化后得到：
`u₁ + u₂ + u₃ = 14`

![](img/8bbebd9e66e2f208faf701455a000465_105.png)

![](img/8bbebd9e66e2f208faf701455a000465_107.png)

现在，我们有了一个符合标准形式的新方程：`u₁ + u₂ + u₃ = 14`，其中 `u₁, u₂, u₃ ≥ 0`。
*   **n** = 14 （可自由分配的球数）
*   **r** = 3 （瓮的数量）

![](img/8bbebd9e66e2f208faf701455a000465_108.png)

![](img/8bbebd9e66e2f208faf701455a000465_109.png)

![](img/8bbebd9e66e2f208faf701455a000465_111.png)

![](img/8bbebd9e66e2f208faf701455a000465_112.png)

代入公式：
`C(14 + 3 - 1, 3 - 1) = C(16, 2)`

![](img/8bbebd9e66e2f208faf701455a000465_114.png)

![](img/8bbebd9e66e2f208faf701455a000465_116.png)

![](img/8bbebd9e66e2f208faf701455a000465_118.png)

计算组合数：
`C(16, 2) = (16 × 15) / (2 × 1) = 120`

![](img/8bbebd9e66e2f208faf701455a000465_120.png)

![](img/8bbebd9e66e2f208faf701455a000465_121.png)

![](img/8bbebd9e66e2f208faf701455a000465_122.png)

![](img/8bbebd9e66e2f208faf701455a000465_123.png)

因此，在满足每个瓮最低球数要求的前提下，将20个相同的球分配到3个不同的瓮中，总共有 **120种** 分配方式。

## 总结与重要性 📚

本节课中我们一起学习了不可区分物品的分配问题。

我们掌握了核心公式 **`C(n + r - 1, r - 1)`**，它用于计算将 `n` 个相同物品分配给 `r` 个不同接收者的方式数，前提是每个接收者得到的物品数可以为零。我们还学习了如何处理接收者有最低数量要求的情况，即通过变量替换将问题转化为标准形式。
