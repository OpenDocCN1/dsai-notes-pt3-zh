### 当 X = 1 时

![](img/c17152abea02ad6497904e5f59938a91_89.png)

![](img/c17152abea02ad6497904e5f59938a91_91.png)

**X = 1** 意味着第一次抛掷就得到了正面。
这个事件的概率就是单次抛掷出现正面的概率 **P**。
因此：
**P(X = 1) = P**

### 当 X = 2 时

![](img/c17152abea02ad6497904e5f59938a91_100.png)

![](img/c17152abea02ad6497904e5f59938a91_102.png)

![](img/c17152abea02ad6497904e5f59938a91_104.png)

![](img/c17152abea02ad6497904e5f59938a91_105.png)

![](img/c17152abea02ad6497904e5f59938a91_107.png)

**X = 2** 意味着第一次是反面，第二次是正面。
第一次出现反面的概率是 **1 - P**，第二次出现正面的概率是 **P**。由于每次抛掷独立，概率相乘。
因此：
**P(X = 2) = (1 - P) * P**

![](img/c17152abea02ad6497904e5f59938a91_109.png)

![](img/c17152abea02ad6497904e5f59938a91_110.png)

![](img/c17152abea02ad6497904e5f59938a91_112.png)

### 当 X = 3 时

![](img/c17152abea02ad6497904e5f59938a91_118.png)

![](img/c17152abea02ad6497904e5f59938a91_119.png)

![](img/c17152abea02ad6497904e5f59938a91_121.png)

**X = 3** 意味着前两次是反面，第三次是正面。
概率为两次反面和一次正面概率的乘积。
因此：
**P(X = 3) = (1 - P)² * P**

对于 **X = k**（其中 k 是 1, 2, 3, ..., n-1），要抛掷 k 次，意味着前 **k-1** 次都是反面，第 **k** 次是正面。
其概率公式为：
**P(X = k) = (1 - P)^(k-1) * P**

### 当 X = n 时的特殊情况

![](img/c17152abea02ad6497904e5f59938a91_161.png)

![](img/c17152abea02ad6497904e5f59938a91_163.png)

![](img/c17152abea02ad6497904e5f59938a91_165.png)

![](img/c17152abea02ad6497904e5f59938a91_167.png)

当 **X = n** 时，情况略有不同。它包含了两种可能的结果序列：
1.  前 **n-1** 次是反面，第 **n** 次**也是反面**（此时因达到最大抛掷次数 n 而停止）。
2.  前 **n-1** 次是反面，第 **n** 次**是正面**（此时因出现正面而停止）。

![](img/c17152abea02ad6497904e5f59938a91_168.png)

![](img/c17152abea02ad6497904e5f59938a91_169.png)

![](img/c17152abea02ad6497904e5f59938a91_171.png)

![](img/c17152abea02ad6497904e5f59938a91_172.png)

![](img/c17152abea02ad6497904e5f59938a91_173.png)

![](img/c17152abea02ad6497904e5f59938a91_174.png)

![](img/c17152abea02ad6497904e5f59938a91_176.png)

因此，我们需要计算这两种序列的概率之和。

![](img/c17152abea02ad6497904e5f59938a91_178.png)

![](img/c17152abea02ad6497904e5f59938a91_180.png)

![](img/c17152abea02ad6497904e5f59938a91_181.png)

![](img/c17152abea02ad6497904e5f59938a91_183.png)

![](img/c17152abea02ad6497904e5f59938a91_184.png)

以下是计算过程：
```
P(X = n) = P(前n-1次是反面，第n次是反面) + P(前n-1次是反面，第n次是正面)
         = (1 - P)^(n-1) * (1 - P)    +    (1 - P)^(n-1) * P
         = (1 - P)^(n-1) * [(1 - P) + P]
         = (1 - P)^(n-1) * 1
         = (1 - P)^(n-1)
```

![](img/c17152abea02ad6497904e5f59938a91_186.png)

![](img/c17152abea02ad6497904e5f59938a91_188.png)

![](img/c17152abea02ad6497904e5f59938a91_190.png)

所以，当随机变量取最大值 n 时，其概率公式为：
**P(X = n) = (1 - P)^(n-1)**

本节课中，我们一起学习了如何为一个“抛硬币直到出现正面或达到最大次数”的实验定义随机变量 **X**，并完整推导了它的概率分布。

![](img/c17152abea02ad6497904e5f59938a91_207.png)

![](img/c17152abea02ad6497904e5f59938a91_209.png)

![](img/c17152abea02ad6497904e5f59938a91_211.png)

![](img/c17152abea02ad6497904e5f59938a91_213.png)

我们得到了以下核心公式：
*   对于 **k = 1, 2, ..., n-1**： **P(X = k) = (1 - P)^(k-1) * P**
*   对于 **k = n**： **P(X = n) = (1 - P)^(n-1)**

![](img/c17152abea02ad6497904e5f59938a91_215.png)

这个分布涵盖了随机变量 **X** 所有可能的取值（从 1 到 n），并给出了每个值对应的概率，从而完整描述了该实验的统计特性。
