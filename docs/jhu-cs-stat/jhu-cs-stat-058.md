#  058：指示变量求和 📊

![](img/b1cc58305cf930137328b8a4d217a688_0.png)

![](img/b1cc58305cf930137328b8a4d217a688_2.png)

![](img/b1cc58305cf930137328b8a4d217a688_4.png)

在本节课中，我们将要学习一个关于期望值的重要定理。这个定理的核心思想是，通过将复杂问题分解为一系列简单的“是/否”指示变量，我们可以更轻松地计算事件发生次数的期望值。

![](img/b1cc58305cf930137328b8a4d217a688_6.png)

![](img/b1cc58305cf930137328b8a4d217a688_8.png)

## 定理陈述

![](img/b1cc58305cf930137328b8a4d217a688_10.png)

![](img/b1cc58305cf930137328b8a4d217a688_11.png)

给定一个概率空间 `(Ω, F, P)` 和一个事件集合 `A₁, A₂, ..., Aₙ`，这些事件都属于该概率空间。

![](img/b1cc58305cf930137328b8a4d217a688_13.png)

那么，这些事件中**预期发生的事件数量**等于每个事件发生概率的总和。

![](img/b1cc58305cf930137328b8a4d217a688_15.png)

![](img/b1cc58305cf930137328b8a4d217a688_16.png)

用公式表示如下：

![](img/b1cc58305cf930137328b8a4d217a688_18.png)

![](img/b1cc58305cf930137328b8a4d217a688_20.png)

![](img/b1cc58305cf930137328b8a4d217a688_22.png)

**E[T] = Σᵢ₌₁ⁿ P(Aᵢ)**

![](img/b1cc58305cf930137328b8a4d217a688_24.png)

![](img/b1cc58305cf930137328b8a4d217a688_26.png)

其中，`T` 表示实际发生的事件数量。

![](img/b1cc58305cf930137328b8a4d217a688_28.png)

![](img/b1cc58305cf930137328b8a4d217a688_30.png)

## 定理证明

![](img/b1cc58305cf930137328b8a4d217a688_32.png)

![](img/b1cc58305cf930137328b8a4d217a688_34.png)

上一节我们介绍了定理的内容，本节中我们来看看如何证明它。证明的关键在于引入**指示变量**。

![](img/b1cc58305cf930137328b8a4d217a688_36.png)

![](img/b1cc58305cf930137328b8a4d217a688_38.png)

首先，我们为每个事件 `Aᵢ` 定义一个指示变量 `Iᵢ`：

![](img/b1cc58305cf930137328b8a4d217a688_40.png)

![](img/b1cc58305cf930137328b8a4d217a688_42.png)

**Iᵢ(ω) = 1， 如果 ω ∈ Aᵢ；否则为 0。**

![](img/b1cc58305cf930137328b8a4d217a688_44.png)

这个指示变量的含义是：当事件 `Aᵢ` 发生时，`Iᵢ` 的值为 1；否则为 0。

![](img/b1cc58305cf930137328b8a4d217a688_46.png)

![](img/b1cc58305cf930137328b8a4d217a688_47.png)

接着，我们定义变量 `T` 为所有指示变量的和：

![](img/b1cc58305cf930137328b8a4d217a688_48.png)

![](img/b1cc58305cf930137328b8a4d217a688_50.png)

**T = I₁ + I₂ + ... + Iₙ**

![](img/b1cc58305cf930137328b8a4d217a688_52.png)

显然，`T` 的值就是实际发生的事件总数。

![](img/b1cc58305cf930137328b8a4d217a688_53.png)

![](img/b1cc58305cf930137328b8a4d217a688_54.png)

现在，我们计算 `T` 的期望值。根据期望值的线性性质，和的期望值等于期望值的和：

![](img/b1cc58305cf930137328b8a4d217a688_56.png)

![](img/b1cc58305cf930137328b8a4d217a688_58.png)

**E[T] = E[I₁ + I₂ + ... + Iₙ] = Σᵢ₌₁ⁿ E[Iᵢ]**

![](img/b1cc58305cf930137328b8a4d217a688_60.png)

![](img/b1cc58305cf930137328b8a4d217a688_62.png)

对于指示变量 `Iᵢ`，其期望值 `E[Iᵢ]` 恰好等于事件 `Aᵢ` 发生的概率 `P(Aᵢ)`。因为：

![](img/b1cc58305cf930137328b8a4d217a688_64.png)

![](img/b1cc58305cf930137328b8a4d217a688_66.png)

**E[Iᵢ] = 1 * P(Iᵢ = 1) + 0 * P(Iᵢ = 0) = P(Aᵢ)**

![](img/b1cc58305cf930137328b8a4d217a688_68.png)

![](img/b1cc58305cf930137328b8a4d217a688_70.png)

将上述结果代入，我们得到：

![](img/b1cc58305cf930137328b8a4d217a688_72.png)

![](img/b1cc58305cf930137328b8a4d217a688_74.png)

**E[T] = Σᵢ₌₁ⁿ P(Aᵢ)**

![](img/b1cc58305cf930137328b8a4d217a688_75.png)

![](img/b1cc58305cf930137328b8a4d217a688_77.png)

至此，定理得证。

![](img/b1cc58305cf930137328b8a4d217a688_79.png)

![](img/b1cc58305cf930137328b8a4d217a688_81.png)

## 应用示例

![](img/b1cc58305cf930137328b8a4d217a688_83.png)

![](img/b1cc58305cf930137328b8a4d217a688_85.png)

为了加深理解，我们来看一个具体的例子。

![](img/b1cc58305cf930137328b8a4d217a688_87.png)

假设我们抛掷 `n` 枚均匀的硬币。定义事件 `Aᵢ` 为“第 `i` 枚硬币结果是反面”。

![](img/b1cc58305cf930137328b8a4d217a688_89.png)

那么，变量 `T` 就表示出现反面的硬币总数。

![](img/b1cc58305cf930137328b8a4d217a688_91.png)

![](img/b1cc58305cf930137328b8a4d217a688_93.png)

根据我们刚刚证明的定理，出现反面次数的期望值为：

![](img/b1cc58305cf930137328b8a4d217a688_95.png)

![](img/b1cc58305cf930137328b8a4d217a688_97.png)

**E[T] = P(A₁) + P(A₂) + ... + P(Aₙ)**

![](img/b1cc58305cf930137328b8a4d217a688_99.png)

![](img/b1cc58305cf930137328b8a4d217a688_101.png)

由于每枚硬币是均匀的，出现反面的概率都是 `1/2`。因此：

![](img/b1cc58305cf930137328b8a4d217a688_103.png)

![](img/b1cc58305cf930137328b8a4d217a688_105.png)

**E[T] = 1/2 + 1/2 + ... + 1/2 = n/2**

![](img/b1cc58305cf930137328b8a4d217a688_107.png)

这个结果非常直观：抛掷 `n` 枚均匀硬币，预期会出现 `n/2` 次反面。

![](img/b1cc58305cf930137328b8a4d217a688_109.png)

![](img/b1cc58305cf930137328b8a4d217a688_111.png)

## 方法的威力与延伸

![](img/b1cc58305cf930137328b8a4d217a688_113.png)

![](img/b1cc58305cf930137328b8a4d217a688_115.png)

这个例子展示了指示变量求和法的简洁性。我们也可以从另一个角度计算 `E[T]`，即直接使用二项分布的定义：

![](img/b1cc58305cf930137328b8a4d217a688_117.png)

![](img/b1cc58305cf930137328b8a4d217a688_119.png)

**E[T] = Σᵢ₌₀ⁿ i * P(T = i) = Σᵢ₌₀ⁿ i * C(n, i) * (1/2)ⁿ**

![](img/b1cc58305cf930137328b8a4d217a688_121.png)

通过数学推导，这个复杂的求和式最终也会简化为 `n/2`。

![](img/b1cc58305cf930137328b8a4d217a688_123.png)

![](img/b1cc58305cf930137328b8a4d217a688_124.png)

更重要的是，通过将两种计算方法等同起来：

![](img/b1cc58305cf930137328b8a4d217a688_125.png)

**n/2 = Σᵢ₌₀ⁿ i * C(n, i) * (1/2)ⁿ**

![](img/b1cc58305cf930137328b8a4d217a688_127.png)

![](img/b1cc58305cf930137328b8a4d217a688_128.png)

![](img/b1cc58305cf930137328b8a4d217a688_130.png)

我们可以推导出一个组合恒等式：

**Σᵢ₌₀ⁿ i * C(n, i) = n * 2ⁿ⁻¹**

![](img/b1cc58305cf930137328b8a4d217a688_132.png)

这展示了概率论工具在证明纯数学恒等式方面的强大能力。

![](img/b1cc58305cf930137328b8a4d217a688_133.png)

![](img/b1cc58305cf930137328b8a4d217a688_134.png)

![](img/b1cc58305cf930137328b8a4d217a688_135.png)

## 核心要点总结

本节课中我们一起学习了指示变量求和定理及其应用。

![](img/b1cc58305cf930137328b8a4d217a688_137.png)

![](img/b1cc58305cf930137328b8a4d217a688_138.png)

以下是使用该方法的核心优势：

*   **化繁为简**：它将计算一个复杂随机变量（事件发生次数）的期望值，转化为计算一系列简单指示变量（单个事件是否发生）的期望值之和。
*   **无需独立性**：该定理成立**不需要**事件 `A₁, A₂, ..., Aₙ` 相互独立。无论事件之间是否存在依赖关系，期望值的线性性质都保证结论成立。
*   **强大的问题解决工具**：在概率和算法分析中，如果一个计数问题可以构造为一系列指示变量的和，那么优先使用这个方法通常会极大地简化计算过程。

![](img/b1cc58305cf930137328b8a4d217a688_140.png)

![](img/b1cc58305cf930137328b8a4d217a688_141.png)

![](img/b1cc58305cf930137328b8a4d217a688_142.png)

**核心建议**：当你面对一个需要计算某事件发生次数期望值的问题时，首先尝试将其分解为一系列“是/否”指示变量的和。这往往是通往解决方案最清晰、最有效的路径。
