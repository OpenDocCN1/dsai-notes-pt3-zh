## 一个直觉上的“证明”

一个常见的直觉是：每枚骰子出现玩家所选数字的概率是 **1/6**。投掷三枚骰子，那么获胜的概率似乎是：
```
P(获胜) = 1/6 + 1/6 + 1/6 = 1/2
```
这看起来玩家有50%的胜率。然而，这个结论正确吗？

## 错误分析与正确计算

![](img/ca0445189168202bcf2494fdffdf361d_57.png)

![](img/ca0445189168202bcf2494fdffdf361d_58.png)

![](img/ca0445189168202bcf2494fdffdf361d_60.png)

![](img/ca0445189168202bcf2494fdffdf361d_62.png)

直觉计算错误的原因在于，它假设了三个事件（第一枚骰子命中、第二枚骰子命中、第三枚骰子命中）是**互斥的**。但实际上，可能有两枚甚至三枚骰子同时命中玩家所选数字，这些重叠的情况被重复计算了。

![](img/ca0445189168202bcf2494fdffdf361d_64.png)

为了正确计算至少一枚骰子命中的概率，我们需要使用**容斥原理**。

![](img/ca0445189168202bcf2494fdffdf361d_66.png)

![](img/ca0445189168202bcf2494fdffdf361d_67.png)

设事件 **A_i** 为“第 i 枚骰子显示玩家所选数字”。那么获胜的概率是：
```
P(获胜) = P(A1 ∪ A2 ∪ A3)
```

![](img/ca0445189168202bcf2494fdffdf361d_69.png)

![](img/ca0445189168202bcf2494fdffdf361d_71.png)

根据容斥原理，这个概率的正确计算公式为：
```
P(A1 ∪ A2 ∪ A3) = P(A1) + P(A2) + P(A3)
                 - P(A1 ∩ A2) - P(A1 ∩ A3) - P(A2 ∩ A3)
                 + P(A1 ∩ A2 ∩ A3)
```

![](img/ca0445189168202bcf2494fdffdf361d_73.png)

![](img/ca0445189168202bcf2494fdffdf361d_74.png)

以下是各项概率的具体值：
*   `P(A1) = P(A2) = P(A3) = 1/6`
*   `P(A1 ∩ A2) = P(A1 ∩ A3) = P(A2 ∩ A3) = (1/6) * (1/6) = 1/36`
*   `P(A1 ∩ A2 ∩ A3) = (1/6) * (1/6) * (1/6) = 1/216`

![](img/ca0445189168202bcf2494fdffdf361d_76.png)

将数值代入公式：
```
P(获胜) = (1/6 + 1/6 + 1/6) - (1/36 + 1/36 + 1/36) + (1/216)
        = 1/2 - 3/36 + 1/216
        = 1/2 - 1/12 + 1/216
        ≈ 0.5 - 0.08333 + 0.00463
        ≈ 0.4213
```

![](img/ca0445189168202bcf2494fdffdf361d_78.png)

因此，玩家的真实获胜概率约为 **42.13%**，而不是50%。这证实了庄家（嘉年华）在游戏中占有优势。

## 一般性规则与注意事项

![](img/ca0445189168202bcf2494fdffdf361d_87.png)

![](img/ca0445189168202bcf2494fdffdf361d_89.png)

![](img/ca0445189168202bcf2494fdffdf361d_91.png)

从上面的计算中，我们可以总结出一个关于条件概率下并集计算的一般规则。对于事件A、B和条件C：
```
P(A ∪ B | C) = P(A | C) + P(B | C) - P(A ∩ B | C)
```

![](img/ca0445189168202bcf2494fdffdf361d_93.png)

![](img/ca0445189168202bcf2494fdffdf361d_95.png)

![](img/ca0445189168202bcf2494fdffdf361d_97.png)

![](img/ca0445189168202bcf2494fdffdf361d_99.png)

然而，必须注意这个公式的**方向性**。它不能随意反向推导或应用于其他结构。

![](img/ca0445189168202bcf2494fdffdf361d_101.png)

例如，考虑以下命题：如果事件C和D互斥（`C ∩ D = ∅`），那么 `P(A | C ∪ D)` 是否等于 `P(A | C) + P(A | D)`？

![](img/ca0445189168202bcf2494fdffdf361d_103.png)

![](img/ca0445189168202bcf2494fdffdf361d_105.png)

![](img/ca0445189168202bcf2494fdffdf361d_107.png)

答案是否定的。我们可以通过一个思想实验来反驳：假设在条件C下，A必然发生（`P(A|C)=1`）；在条件D下，A也必然发生（`P(A|D)=1`）。那么 `P(A|C) + P(A|D) = 2`，这显然不可能是一个概率值（概率值必须在0到1之间）。因此，这个等式不成立。

![](img/ca0445189168202bcf2494fdffdf361d_109.png)

本节课中我们一起学习了嘉年华骰子悖论。我们了解到，在计算多个事件“至少发生一个”的概率时，不能简单地将单个事件的概率相加，因为事件之间可能存在重叠。我们必须使用**容斥原理**来减去重叠部分被重复计算的概率。通过正确的计算，我们发现玩家的胜率实际上低于50%，这揭示了此类游戏庄家占优的本质。同时，我们也强调了概率公式的应用有其特定条件和方向，不能随意推广。
