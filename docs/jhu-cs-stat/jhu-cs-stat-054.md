在本节课中，我们将要学习两个描述随机变量中心趋势的重要概念：**期望值**和**中位数**。期望值，也称为均值或平均值，是概率加权后的平均结果。中位数则是将概率分布一分为二的那个值。理解这两个概念对于分析数据和进行统计推断至关重要。

## 期望值的定义 📖

![](img/375353f050db717ae79557374367add7_16.png)

![](img/375353f050db717ae79557374367add7_17.png)

![](img/375353f050db717ae79557374367add7_18.png)

上一节我们介绍了课程主题，本节中我们来看看期望值的精确定义。

![](img/375353f050db717ae79557374367add7_20.png)

![](img/375353f050db717ae79557374367add7_22.png)

![](img/375353f050db717ae79557374367add7_23.png)

期望值，也称为均值或平均值，是随机变量所有可能取值的加权平均，权重为每个值出现的概率。

![](img/375353f050db717ae79557374367add7_25.png)

![](img/375353f050db717ae79557374367add7_26.png)

对于一个随机变量 **R**，其期望值 **E[R]** 的数学定义如下：

![](img/375353f050db717ae79557374367add7_27.png)

![](img/375353f050db717ae79557374367add7_29.png)

**公式：**
`E[R] = Σ (r ∈ 样本空间) [ r * P(R = r) ]`

![](img/375353f050db717ae79557374367add7_31.png)

![](img/375353f050db717ae79557374367add7_33.png)

![](img/375353f050db717ae79557374367add7_35.png)

其中：
*   `E[R]` 表示随机变量 R 的期望值。
*   `Σ` 表示对所有可能结果求和。
*   `r` 是随机变量 R 的一个可能取值。
*   `P(R = r)` 是 R 取值 r 的概率。

![](img/375353f050db717ae79557374367add7_37.png)

![](img/375353f050db717ae79557374367add7_39.png)

![](img/375353f050db717ae79557374367add7_40.png)

这个公式的本质是计算一个**加权平均值**，每个观测值都按其发生的概率进行加权。

![](img/375353f050db717ae79557374367add7_42.png)

![](img/375353f050db717ae79557374367add7_44.png)

## 期望值示例：掷骰子 🎲

![](img/375353f050db717ae79557374367add7_45.png)

![](img/375353f050db717ae79557374367add7_46.png)

为了更直观地理解期望值，我们来看一个具体的例子：掷一个标准的六面骰子。

![](img/375353f050db717ae79557374367add7_48.png)

以下是计算掷骰子结果期望值的步骤：

![](img/375353f050db717ae79557374367add7_49.png)

![](img/375353f050db717ae79557374367add7_50.png)

![](img/375353f050db717ae79557374367add7_51.png)

![](img/375353f050db717ae79557374367add7_52.png)

1.  **列出所有可能结果及其概率**：骰子每一面（1到6）出现的概率都是 1/6。
2.  **应用期望值公式**：将每个结果乘以其概率，然后求和。

![](img/375353f050db717ae79557374367add7_54.png)

![](img/375353f050db717ae79557374367add7_56.png)

![](img/375353f050db717ae79557374367add7_58.png)

计算过程如下：
`E[掷骰子] = 1*(1/6) + 2*(1/6) + 3*(1/6) + 4*(1/6) + 5*(1/6) + 6*(1/6) = 3.5`

![](img/375353f050db717ae79557374367add7_60.png)

![](img/375353f050db717ae79557374367add7_62.png)

![](img/375353f050db717ae79557374367add7_64.png)

![](img/375353f050db717ae79557374367add7_66.png)

因此，掷一个公平六面骰子的期望值是 **3.5**。需要注意的是，3.5 本身并不是骰子上可能出现的点数。它的含义是：如果我们重复掷骰子很多次，将所有结果求平均值，这个平均值会随着试验次数的增加而越来越接近 3.5。所以，期望值描述的是长期平均行为。

![](img/375353f050db717ae79557374367add7_68.png)

![](img/375353f050db717ae79557374367add7_70.png)

![](img/375353f050db717ae79557374367add7_72.png)

![](img/375353f050db717ae79557374367add7_74.png)

## 中位数的定义 📐

![](img/375353f050db717ae79557374367add7_76.png)

![](img/375353f050db717ae79557374367add7_78.png)

![](img/375353f050db717ae79557374367add7_80.png)

了解了描述数据中心趋势的期望值（均值）后，我们来看看另一个重要的度量：中位数。

![](img/375353f050db717ae79557374367add7_82.png)

![](img/375353f050db717ae79557374367add7_84.png)

![](img/375353f050db717ae79557374367add7_86.png)

中位数是随机变量取值范围内的一个数 **x**，它满足以下两个条件：

![](img/375353f050db717ae79557374367add7_88.png)

![](img/375353f050db717ae79557374367add7_90.png)

![](img/375353f050db717ae79557374367add7_92.png)

![](img/375353f050db717ae79557374367add7_94.png)

1.  随机变量 **R** 的取值小于 **x** 的概率 **小于或等于** 1/2。
    **公式：** `P(R < x) ≤ 1/2`
2.  随机变量 **R** 的取值大于 **x** 的概率 **小于** 1/2。
    **公式：** `P(R > x) < 1/2`

![](img/375353f050db717ae79557374367add7_96.png)

![](img/375353f050db717ae79557374367add7_97.png)

简单来说，中位数是一个“中间点”，它使得取值比它小的概率不超过一半，同时取值比它大的概率严格小于一半。

![](img/375353f050db717ae79557374367add7_99.png)

![](img/375353f050db717ae79557374367add7_100.png)

![](img/375353f050db717ae79557374367add7_102.png)

## 中位数示例：再论掷骰子 🎯

![](img/375353f050db717ae79557374367add7_104.png)

![](img/375353f050db717ae79557374367add7_105.png)

现在，让我们根据上述定义，找出掷一个六面骰子结果的中位数。我们有以下候选答案：A) 3, B) 3.5, C) 4, D) 3 和 4。

![](img/375353f050db717ae79557374367add7_106.png)

![](img/375353f050db717ae79557374367add7_107.png)

![](img/375353f050db717ae79557374367add7_109.png)

以下是逐一验证的过程：

![](img/375353f050db717ae79557374367add7_111.png)

![](img/375353f050db717ae79557374367add7_112.png)

*   **验证 x = 3**：
    *   `P(R < 3) = P(掷出1或2) = 2/6 ≈ 0.333`，这小于 1/2，满足第一个条件。
    *   `P(R > 3) = P(掷出4,5,6) = 3/6 = 0.5`，这**等于**（而非小于）1/2，不满足第二个条件。因此 3 不是中位数。

![](img/375353f050db717ae79557374367add7_114.png)

![](img/375353f050db717ae79557374367add7_115.png)

![](img/375353f050db717ae79557374367add7_116.png)

*   **验证 x = 3.5**：
    *   `P(R < 3.5) = P(掷出1,2,3) = 3/6 = 0.5`，这等于 1/2，满足第一个条件。
    *   `P(R > 3.5) = P(掷出4,5,6) = 3/6 = 0.5`，这**等于**（而非小于）1/2，不满足第二个条件。因此 3.5 也不是中位数。

![](img/375353f050db717ae79557374367add7_118.png)

*   **验证 x = 4**：
    *   `P(R < 4) = P(掷出1,2,3) = 3/6 = 0.5`，这等于 1/2，满足第一个条件。
    *   `P(R > 4) = P(掷出5,6) = 2/6 ≈ 0.333`，这小于 1/2，满足第二个条件。

![](img/375353f050db717ae79557374367add7_120.png)

![](img/375353f050db717ae79557374367add7_121.png)

![](img/375353f050db717ae79557374367add7_122.png)

![](img/375353f050db717ae79557374367add7_124.png)

因此，根据给定的定义，掷六面骰子结果的中位数是 **4**。这个结果可能和直觉上“最中间的数”有所不同，但这正体现了精确定义的重要性。中位数关注的是累积概率分布上的中心点。

![](img/375353f050db717ae79557374367add7_125.png)

## 总结 📝

![](img/375353f050db717ae79557374367add7_127.png)

本节课中我们一起学习了两个核心的统计概念：
1.  **期望值 (E[R])**：它是随机变量所有可能值的概率加权平均，计算公式为 `Σ [r * P(R=r)]`。它代表了长期重复试验的平均结果。
2.  **中位数**：它是满足 `P(R < x) ≤ 1/2` 且 `P(R > x) < 1/2` 的值 **x**。它将概率分布分成两半，是另一个描述数据中心趋势的指标。

![](img/375353f050db717ae79557374367add7_128.png)

![](img/375353f050db717ae79557374367add7_129.png)

![](img/375353f050db717ae79557374367add7_130.png)

![](img/375353f050db717ae79557374367add7_131.png)

![](img/375353f050db717ae79557374367add7_132.png)

期望值和中位数都是描述随机变量“中心”或“典型值”的方式，但它们的计算方法和侧重点不同，适用于不同的场景和分析目的。
