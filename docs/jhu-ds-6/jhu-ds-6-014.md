```r
# 计算样本方差
var_x <- var(x)          # 例如：7.92
# 计算样本方差除以n
var_x_over_n <- var(x) / n # 例如：0.01
# 计算样本标准差
sd_x <- sd(x)            # 例如：2.81
# 计算标准误（标准差除以根号n）
se_x <- sd(x) / sqrt(n)  # 例如：0.09
```

数值 7.92 和 2.81 分别是样本方差和样本标准差。它们描述的是这个数据集中儿子身高的变异性。如果我们愿意假设这些儿子是来自某个有意义总体的随机样本，那么这些值就是对总体变异性的估计。

在这个例子中，我更喜欢使用 2.81 而不是 7.92，因为 7.92 的单位是英寸的平方，而 2.81 的单位是英寸。我更喜欢使用原始单位而非其平方单位。

### 📝 本节总结

本节涵盖了许多重要但略显复杂的主题。可以说，理解统计学与不理解统计学的根本区别在于 **理解变异性**。因此，这可能是最重要的一讲。

![](img/5efe3746ba069063ac38030731f15aba_52.png)

![](img/5efe3746ba069063ac38030731f15aba_53.png)

![](img/5efe3746ba069063ac38030731f15aba_54.png)

以下是我们的核心总结：

![](img/5efe3746ba069063ac38030731f15aba_56.png)

![](img/5efe3746ba069063ac38030731f15aba_57.png)

*   **样本方差** 是 **总体方差** 的估计量。
*   样本方差的分布以其估计的目标（总体方差）为中心。这是一个好性质，意味着它是 **无偏的**。
*   随着收集的数据增多，样本方差的分布会越来越集中于其估计的目标周围。这同样是一个好性质，意味着如果我们收集更多数据，就能得到更精确的估计。
*   关于 **样本均值** 的分布，我们了解很多。从上节课我们知道它的中心位置，而本节课我们还知道：
    *   样本均值的方差是 **总体方差除以 n**，公式为：`Var(样本均值) = σ² / n`
    *   其平方根，即 **σ 除以根号 n**，就是所谓的 **标准误**，公式为：`SE = σ / √n`
*   这些量代表了从该总体中抽取的样本平均值的变异程度。
*   事实证明，即使在实际数据中我们只能看到一个样本均值，我们也可以对随机样本的均值分布做出很多推断。这为我们提供了强大的分析工具，并构成了我们进行统计推断的许多方法的基础。

![](img/5efe3746ba069063ac38030731f15aba_59.png)

![](img/5efe3746ba069063ac38030731f15aba_60.png)

本节课中，我们一起学习了如何通过实际数据计算和解释方差、标准差和标准误，并总结了这些估计量的重要统计性质。理解这些概念是掌握统计推断的关键一步。
