# 022：t置信区间实例分析 📊




在本节课中，我们将学习如何使用R语言构建配对样本的t置信区间。我们将通过分析一个经典的睡眠药物数据集，来演示如何计算和解释配对数据的置信区间。



## 概述：睡眠药物数据集



在R语言中，输入 `data(sleep)` 可以加载睡眠数据集。该数据最初由戈塞特在其生物统计学论文中分析过。它记录了患者服用两种不同睡眠药物后，睡眠时间的增加量。


R语言默认将数据视为两个独立组，但在此分析中，我们将数据视为**配对数据**进行处理。





## 加载与查看数据



以下是加载和初步查看数据的步骤：



*   `data(sleep)` 用于加载数据集。
*   `head(sleep)` 用于打印数据框的前几行。


数据框包含以下变量：
*   `extra`：额外睡眠的小时数。
*   `group`：组别标识（1或2）。
*   `id`：受试者标识。观察值1到10对应受试者1到10，观察值11再次对应受试者1，依此类推。




## 数据可视化与配对分析的优势


通过绘制数据图（绘图代码可在R Markdown文件中找到），并用线条连接同一受试者的两次测量结果，可以清晰地看到配对分析的优势。




如果不考虑配对关系，我们比较的是**第一组的变异**与**第二组的变异**。如果考虑配对关系，我们比较的则是每个受试者自身的**差异**。由于同一个受试者内的观测值高度相关，这些差异的变异程度要低得多，从而使分析更加精确。



## 手动计算t置信区间



首先，我们提取数据：
*   `g1` 获取前10次测量（受试者1-10服用第一种药物）。
*   `g2` 获取后10次测量（相同的受试者1-10服用第二种药物）。


然后计算差异向量 `difference`，即 `g2 - g1`（顺序很重要）。差异的均值用 `mean` 函数计算，标准差用 `sd` 函数计算。设样本量 `n = 10`。


t置信区间的计算公式为：
**均值 ± t分位数(n-1自由度) × 标准误**
其中标准误 = 标准差 / √n。



在R中，可以这样计算：
```r
mean(difference) + c(-1, 1) * qt(0.975, n-1) * sd(difference) / sqrt(n)
```


## 使用内置函数计算




当然，我们不需要每次都手动计算。R提供了 `t.test` 函数。




可以使用以下两种方式：
1.  直接对差异向量进行检验：`t.test(difference)`
2.  使用公式语法并指定配对参数：
    ```r
    t.test(extra ~ group, data = sleep, paired = TRUE)
    ```


以上所有命令得出的结果基本一致。结果显示，两组睡眠时间的平均差异大约在 **0.70小时到2.46小时** 之间。



## 置信区间的解释

作为一个置信区间，其解释是：如果我们能在感兴趣的总体中重复独立抽样并进行此过程，那么大约有 **95%** 的区间会包含真实的总体平均差异。当然，这个结论的前提是，我们当前的样本能够代表我们感兴趣的总体。

本节课中，我们一起学习了如何为配对数据构建t置信区间。我们通过睡眠药物数据的实例，演示了从数据加载、可视化、手动计算到使用R内置函数 `t.test` 的完整流程。关键在于认识到配对数据能有效控制受试者自身的变异，从而得到更精确的估计。最终，我们得到的置信区间表明，第二种药物比第一种药物平均能多带来0.70至2.46小时的睡眠时间增长。
