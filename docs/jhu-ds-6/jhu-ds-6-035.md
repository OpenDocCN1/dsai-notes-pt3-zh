## t检验功效的计算原理



t检验功效的计算逻辑与我们之前讨论的正态分布情况非常相似。



我们拒绝原假设的条件是：我们的检验统计量（此时为 `(x̄ - μ₀) / 估计标准误`）大于某个t分布的分位数，而不是Z分位数，因为我们讨论的是t检验。



关键在于，当我们计算功效时，计算所依据的假设不再是 `μ = μ₀`，而是备择假设下的值 `μ = μₐ`。




事实证明，如果真实均值不是 `μ₀` 而是 `μₐ`（且 `μₐ ≠ μ₀`），那么统计量 `(x̄ - μ₀) / 标准误` 并不服从t分布。它服从一种称为**非中心t分布**的分布，这超出了本课程的讨论范围。


因此，计算功效需要能够评估非中心t分布，这正是 `power.t.test` 函数为我们所做的工作。





## 使用 `power.t.test` 函数


`power.t.test` 函数的一个优点是，它允许我们指定一些已知参数（如 `μ₀` 和 `α`）和一些未知参数（如 `μₐ`、`σ` 和样本量 `n`）。如果你省略其中一个参数但指定了其余参数，`power.t.test` 会为你解出被省略的那个参数。



以下是使用 `power.t.test` 的几个示例，用于计算功效、样本量或最小可检测差异。


### 示例1：计算功效





在第一个示例中，我们计算给定样本量、均值差和标准差时的统计功效。






```r
# 计算功效
# delta：均值差 (μₐ - μ₀)
# sd：标准差
# n：样本量
# type：检验类型（"one.sample" 单样本）
# alternative：单侧检验（"one.sided"）
# sig.level：显著性水平（默认0.05）
power.t.test(n = 16, delta = 2, sd = 4, type = "one.sample", alternative = "one.sided")$power
```
运行上述代码将返回功效值，例如 **0.6**（60%）。





需要理解的核心点是，功效实际上只取决于**效应量**，即均值差 `delta` 除以标准差 `sd`。因此，以下三个调用会产生相同的功效（60%）：


```r
power.t.test(n = 16, delta = 2, sd = 4, ...)$power      # 效应量 = 2/4 = 0.5
power.t.test(n = 16, delta = 0.5, sd = 1, ...)$power    # 效应量 = 0.5/1 = 0.5
power.t.test(n = 16, delta = 100, sd = 200, ...)$power  # 效应量 = 100/200 = 0.5
```



### 示例2：计算所需样本量


现在，我们尝试计算样本量。我们向 `power.t.test` 指定我们期望达到的功效值。


以下是计算达到80%功效所需样本量的方法：







```r
# 计算所需样本量
# 指定期望的功效（power = 0.8）
# 函数将返回所需的样本量 n
result <- power.t.test(delta = 0.5, sd = 1, power = 0.8,
                       type = "one.sample", alternative = "one.sided")
n_required <- result$n
print(n_required)
```
函数可能返回一个如 **25.5** 的值。在这类计算中，我们通常倾向于保守估计，因此会将结果向上取整到最近的整数。所以，我们需要 **26** 个样本量来以80%的功效检测出效应量为0.5的差异。






同样，只要效应量相同，无论 `delta` 和 `sd` 的具体值如何，计算出的样本量都是相同的：
```r
power.t.test(delta = 0.5, sd = 1, power = 0.8, ...)$n
power.t.test(delta = 2, sd = 4, power = 0.8, ...)$n    # 效应量 = 0.5
power.t.test(delta = 100, sd = 200, power = 0.8, ...)$n # 效应量 = 0.5
```


### 练习：计算最小可检测差异





作为练习，你可以尝试省略 `delta` 参数，但指定样本量 `n` 和期望功效 `power`，然后让 `power.t.test` 函数告诉你，在特定样本量下，要达到80%功效所需的最小可检测差异 `delta` 是多少。根据上面给出的代码，这个扩展练习应该不难完成。



## 实践建议




我几乎总是将 `power.t.test` 作为进行功效计算的第一个工具。

这样做的一个主要原因是，正如我在整个课程中可能解释过的，功效有许多可以调整的“旋钮和刻度”，很容易误以为自己拥有比实际更高的功效，或者认为自己需要更小的样本量。因此，当有疑问时，应尽量简化你的功效计算。




尽量将你要回答的问题简化为t检验或二项检验等，以尽可能简单的方式计算功效。这样得出的功效或样本量估计可能略微保守，但另一方面，你能很好地理解它。



之后，你可能想继续进行更复杂的功效计算，但作为第一步，你应该始终将t检验功效、正态分布计算或二项检验中的基本功效计算作为首要工作。
