# 069：大数定律与中心极限定理 📊

在本节课中，我们将要学习概率论中两个极其重要且基础的核心定理：**大数定律**和**中心极限定理**。它们是理解随机现象长期行为和统计推断的基石。

![](img/d01b0d52f1910412062799439fb639c8_3.png)

上一节我们介绍了概率论的基本概念，本节中我们来看看这两个关键的极限定理。

## 大数定律 📈

![](img/d01b0d52f1910412062799439fb639c8_5.png)

![](img/d01b0d52f1910412062799439fb639c8_6.png)

首先，我们介绍**大数定律**。它描述了当独立重复试验的次数趋于无穷时，样本均值会收敛到理论期望值。

![](img/d01b0d52f1910412062799439fb639c8_7.png)

![](img/d01b0d52f1910412062799439fb639c8_8.png)

### 强大数定律

考虑定义在同一概率空间 `(Ω, A, P)` 上，取值于实数域 `R` 的随机变量序列 `X_n`。我们假设它们是**独立同分布**的。

![](img/d01b0d52f1910412062799439fb639c8_10.png)

![](img/d01b0d52f1910412062799439fb639c8_11.png)

以下是IID（独立同分布）的具体含义：
*   **同分布**：所有随机变量 `X_1, X_2, X_3, ...` 都服从同一个概率分布 `P`。
*   **独立**：随机变量之间相互独立，即一个随机变量的结果不影响另一个的结果。

![](img/d01b0d52f1910412062799439fb639c8_13.png)

我们假设均值存在，即 `μ = E[X_1] < ∞`。同时，我们假设方差也存在，即 `Var(X_1) = σ^2 < ∞`。

![](img/d01b0d52f1910412062799439fb639c8_15.png)

在这些假设下，**强**大数定律指出，样本均值几乎必然收敛于总体均值 `μ`。用公式表示为：

![](img/d01b0d52f1910412062799439fb639c8_17.png)

![](img/d01b0d52f1910412062799439fb639c8_19.png)

**`(X_1 + X_2 + ... + X_n) / n → μ`  (当 `n → ∞` 时，几乎必然收敛)**

![](img/d01b0d52f1910412062799439fb639c8_21.png)

这意味着，随着样本量 `n` 的增大，我们通过实验得到的平均值会无限接近理论上的期望值。

![](img/d01b0d52f1910412062799439fb639c8_23.png)

![](img/d01b0d52f1910412062799439fb639c8_25.png)

## 中心极限定理 🎯

![](img/d01b0d52f1910412062799439fb639c8_27.png)

![](img/d01b0d52f1910412062799439fb639c8_28.png)

上一节我们介绍了大数定律，它描述了样本均值的收敛点。本节中我们来看看**中心极限定理**，它则描述了样本均值在收敛过程中的**分布形态**。

![](img/d01b0d52f1910412062799439fb639c8_30.png)

中心极限定理指出，无论原始随机变量 `X_i` 服从何种分布（只要满足一定条件），其样本均值的标准化形式，随着样本量 `n` 增大，其分布会趋近于一个**标准正态分布**。

用公式描述，对于独立同分布的随机变量序列 `X_i`，其均值为 `μ`，方差为 `σ^2`，则：

![](img/d01b0d52f1910412062799439fb639c8_32.png)

![](img/d01b0d52f1910412062799439fb639c8_33.png)

**`√n * ( (X̄_n - μ) / σ ) → N(0, 1)`  (依分布收敛)**

![](img/d01b0d52f1910412062799439fb639c8_35.png)

其中 `X̄_n = (X_1 + ... + X_n) / n` 是样本均值，`N(0,1)` 表示标准正态分布。

![](img/d01b0d52f1910412062799439fb639c8_37.png)

这个定理的威力在于其普适性。它解释了为什么在自然界和社会科学中，许多随机变量的和或平均值都近似服从正态分布。

## 总结

![](img/d01b0d52f1910412062799439fb639c8_40.png)

![](img/d01b0d52f1910412062799439fb639c8_41.png)

本节课中我们一起学习了概率论的两个核心极限定理。

![](img/d01b0d52f1910412062799439fb639c8_43.png)

![](img/d01b0d52f1910412062799439fb639c8_45.png)

*   **大数定律**告诉我们，在长期或大量重复下，随机事件的**频率**会稳定于其**概率**，样本均值会趋近于总体期望。这是统计估计的理论基础。
*   **中心极限定理**则揭示了，无论个体分布如何，大量独立随机变量之和的**标准化形式**会趋向于**正态分布**。这为参数估计、假设检验等统计推断方法提供了关键依据。

![](img/d01b0d52f1910412062799439fb639c8_47.png)

理解这两个定理，是掌握更高级机器学习算法和统计模型的重要前提。
