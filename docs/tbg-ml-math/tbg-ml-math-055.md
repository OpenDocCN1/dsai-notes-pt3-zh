## 离散测度 🎲

![](img/4756418928b9a9722f9816a6a6563e7a_6.png)

上一节我们介绍了概率测度的抽象定义，本节中我们来看看最简单的一种类型：离散测度。

![](img/4756418928b9a9722f9816a6a6563e7a_8.png)

![](img/4756418928b9a9722f9816a6a6563e7a_9.png)

对于离散测度，我们通常有一个有限的概率空间 Ω。这个空间是我们定义σ-代数和概率测度的基础，它是一个有限或可数的集合。

![](img/4756418928b9a9722f9816a6a6563e7a_11.png)

![](img/4756418928b9a9722f9816a6a6563e7a_13.png)

例如，Ω = {x₁, x₂, ...}。它要么是有限的，要么最多是可数的。

![](img/4756418928b9a9722f9816a6a6563e7a_15.png)

![](img/4756418928b9a9722f9816a6a6563e7a_16.png)

在这个集合上的σ-代数，我们通常考虑整个集合的幂集，即由该空间中所有元素可能构成的所有子集。

![](img/4756418928b9a9722f9816a6a6563e7a_17.png)

![](img/4756418928b9a9722f9816a6a6563e7a_19.png)

![](img/4756418928b9a9722f9816a6a6563e7a_21.png)

现在，我们可以通过为所有基本事件分配概率来定义一个概率测度。

![](img/4756418928b9a9722f9816a6a6563e7a_22.png)

我们定义一个概率测度 **P**，它从σ-代数映射到区间 [0,1]。其方法是为所谓的“基本事件”分配概率。

![](img/4756418928b9a9722f9816a6a6563e7a_24.png)

![](img/4756418928b9a9722f9816a6a6563e7a_25.png)

![](img/4756418928b9a9722f9816a6a6563e7a_26.png)

基本事件是什么意思呢？我想为随机实验的结果是某个特定 x 的概率赋值。例如，考虑一个骰子，我们有六个不同的面（1到6）。我们想说，掷出某个特定点数（比如1点）的概率是多少。

![](img/4756418928b9a9722f9816a6a6563e7a_28.png)

![](img/4756418928b9a9722f9816a6a6563e7a_29.png)

![](img/4756418928b9a9722f9816a6a6563e7a_31.png)

以下是定义离散概率测度的步骤：

![](img/4756418928b9a9722f9816a6a6563e7a_37.png)

1.  **确定样本空间**：样本空间 Ω 是一个有限或可数集合，包含所有可能的基本结果。例如，掷骰子：Ω = {1, 2, 3, 4, 5, 6}。
2.  **确定σ-代数**：通常取为 Ω 的幂集，即所有可能子集的集合。这确保了任何我们关心的事件（如“点数为偶数”）都在可测集合中。
3.  **分配基本概率**：为样本空间中的每一个基本结果 ωᵢ 分配一个概率 **pᵢ = P({ωᵢ})**。这些概率必须满足两个条件：
    *   每个概率都是非负的：**pᵢ ≥ 0**。
    *   所有基本概率之和为1：**∑ pᵢ = 1**。
4.  **计算任意事件的概率**：对于σ-代数中的任意事件 A（即Ω的任意子集），其概率定义为该事件包含的所有基本结果的概率之和：**P(A) = ∑_{ωᵢ ∈ A} pᵢ**。

本节课中我们一起学习了概率测度的一种基本类型——离散测度。我们了解到，它适用于结果可数的随机实验，通过为每个基本结果分配概率并求和来计算复杂事件的概率。这是构建概率直觉和进行许多理论推导的重要基础模型。
