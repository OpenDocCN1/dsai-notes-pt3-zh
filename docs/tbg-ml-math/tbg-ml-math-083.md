在本节课中，我们将学习概率论中的另一个重要极限定理——格利文科-坎泰利定理。该定理描述了经验累积分布函数如何一致收敛于真实的累积分布函数。我们将重点理解其证明思路，因为这种证明方法在统计学习理论中非常典型。

## 概述

在前面的课程中，我们已经学习了一些概率极限定理。例如，**大数定律**指出，独立同分布随机变量的经验平均值会收敛于其分布的期望值。**中心极限定理**则说明，适当归一化的独立随机变量之和在分布上会收敛于标准正态分布。

![](img/116143feeac2fc7ebf2b7d4980f55812_8.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_9.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_11.png)

本节中，我们将介绍**格利文科-坎泰利定理**。该定理关注的是累积分布函数。当我们从某个潜在分布中观测到大量随机变量时，可以基于这些观测构建一个经验累积分布函数。该定理的核心结论是，这个经验累积分布函数会一致收敛于真实的潜在累积分布函数。

![](img/116143feeac2fc7ebf2b7d4980f55812_13.png)

## 定理陈述与应用

![](img/116143feeac2fc7ebf2b7d4980f55812_14.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_15.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_17.png)

设我们有一个真实的潜在累积分布函数 **F(x)**。现在，我们从这个分布中观测到 n 个独立同分布的随机变量 **X₁, X₂, ..., Xₙ**。

![](img/116143feeac2fc7ebf2b7d4980f55812_19.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_20.png)

基于这些观测，我们可以构建一个**经验累积分布函数** **Fₙ(x)**，其定义为：
```
Fₙ(x) = (1/n) * Σ_{i=1}^{n} I(Xᵢ ≤ x)
```
其中 **I(·)** 是指示函数，当条件为真时取值为1，否则为0。

![](img/116143feeac2fc7ebf2b7d4980f55812_22.png)

格利文科-坎泰利定理指出，当样本量 n 趋于无穷大时，经验累积分布函数 **Fₙ(x)** 以概率1一致收敛于真实累积分布函数 **F(x)**。用公式表示为：
```
sup_{x ∈ ℝ} | Fₙ(x) - F(x) | → 0   (几乎必然收敛)
```

![](img/116143feeac2fc7ebf2b7d4980f55812_24.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_25.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_27.png)

该定理在统计学中有一些应用。例如，它可以作为**柯尔莫哥洛夫-斯米尔诺夫检验**的理论基础，用于检验样本是否来自某个特定分布。

![](img/116143feeac2fc7ebf2b7d4980f55812_29.png)

## 证明思路的重要性

![](img/116143feeac2fc7ebf2b7d4980f55812_31.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_32.png)

虽然定理本身有其应用价值，但本节课我们重点讨论它的证明。原因在于，这个证明所采用的方法是**统计学习理论**中的典型范式。

![](img/116143feeac2fc7ebf2b7d4980f55812_33.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_35.png)

在统计学习理论中，经常需要证明一类随机变量的上确界（supremum）收敛于某个值（通常是零）。这正是格利文科-坎泰利定理证明的核心：证明经验分布函数与真实分布函数之差的**上确界**收敛于零。

![](img/116143feeac2fc7ebf2b7d4980f55812_37.png)

需要说明的是，如果只关心定理本身，存在更简单的证明方法。但本节课我们将介绍一个在统计学习理论中更常用、更具启发性的证明思路。理解这个证明，对于深入学习统计学习理论至关重要。

![](img/116143feeac2fc7ebf2b7d4980f55812_38.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_39.png)

## 总结

![](img/116143feeac2fc7ebf2b7d4980f55812_43.png)

![](img/116143feeac2fc7ebf2b7d4980f55812_44.png)

本节课我们一起学习了格利文科-坎泰利定理。该定理保证了随着样本量的增加，经验累积分布函数会一致地逼近真实的累积分布函数。我们不仅了解了定理的陈述，更重要的是，探讨了其证明思路在统计学习理论中的典型性和重要性。这种处理上确界收敛性的方法，是理解更复杂学习理论的基础。
