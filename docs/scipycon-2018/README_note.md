# ScipyCon 2018 笔记：Python科学计算入门 🐍

在本教程中，我们将学习Python科学计算的核心概念与工具。我们将从基础的数据结构开始，逐步深入到数值计算和优化方法。

## 1. 核心数据结构：NumPy数组

上一节我们介绍了本课程的目标，本节中我们来看看科学计算的基础——NumPy数组。NumPy数组是存储和处理多维数据的核心对象。

以下是创建NumPy数组的几种基本方法：

*   **从Python列表创建**：`array = np.array([1, 2, 3, 4, 5])`
*   **创建全零数组**：`zeros = np.zeros((3, 4))`
*   **创建全一数组**：`ones = np.ones((2, 2))`
*   **创建单位矩阵**：`eye = np.eye(3)`
*   **生成等差数列**：`range_arr = np.arange(0, 10, 2)`

## 2. 数值计算与线性代数

了解了数据结构后，我们来看看如何使用它们进行数学运算。NumPy和SciPy提供了强大的数值计算功能。

以下是常用的线性代数操作：

*   **矩阵乘法**：`C = np.dot(A, B)` 或 `C = A @ B`
*   **计算行列式**：`det = np.linalg.det(M)`
*   **求解线性方程组**：`x = np.linalg.solve(A, b)`，其中 `A` 是系数矩阵，`b` 是常数向量。
*   **计算特征值和特征向量**：`eigenvalues, eigenvectors = np.linalg.eig(M)`

## 3. 数据拟合与优化

在科学计算中，我们经常需要根据数据找到最佳的模型参数。这涉及到拟合与优化问题。

以下是使用SciPy进行曲线拟合的基本步骤：

*   **定义模型函数**：例如，定义一个线性函数 `def linear_func(x, a, b): return a * x + b`。
*   **准备数据**：准备好自变量 `x_data` 和因变量 `y_data`。
*   **调用拟合函数**：使用 `scipy.optimize.curve_fit` 进行拟合：`params, covariance = curve_fit(linear_func, x_data, y_data)`。
*   **获取结果**：`params` 包含了最优参数 `a` 和 `b`。

## 4. 总结

本节课中我们一起学习了Python科学计算的基础。我们从NumPy数组的创建开始，掌握了数据处理的核心结构。接着，我们探索了基本的线性代数运算，如矩阵乘法和求解方程组。最后，我们介绍了如何使用SciPy进行简单的数据拟合，这是一个将理论模型与实际数据连接起来的关键步骤。这些工具构成了使用Python进行科学研究和工程分析的基石。
