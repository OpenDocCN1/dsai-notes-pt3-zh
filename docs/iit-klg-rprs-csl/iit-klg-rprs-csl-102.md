在本节课中，我们将学习自认知推理。这是默认推理的第四种方法，它结合了默认逻辑和限定逻辑的特点，通过引入一个信念算子，在语言内部处理“一致性假设”的问题。

上一节我们介绍了默认逻辑和限定逻辑。本节中，我们来看看自认知逻辑如何通过引入一个模态算子来形式化信念。

### 信念算子 B

自认知逻辑引入了一个模态算子 **B**。公式 **Bα** 表示“我们相信 α 为真”。例如，规则“鸟，且不相信它不会飞 ⇒ 它会飞”可以表示为：
`Bird(x) ∧ ¬B(¬Flies(x)) ⇒ Flies(x)`
其核心是：如果你不相信某物不能飞，那么你可以推断它能飞。

### 稳定扩张（Stable Expansion）

一个信念集合 **E**（也称为一个扩张）要被称为“稳定”的，必须满足以下三个性质：

以下是稳定扩张必须满足的三个关键性质：
1.  **逻辑后承封闭**：如果 **E** 能逻辑推出 α（**E ⊨ α**），那么 α 必须属于 **E**。
2.  **正内省**：如果 α 属于 **E**，那么 **Bα** 也必须属于 **E**。
3.  **负内省**：如果 α 不属于 **E**，那么 **¬Bα** 必须属于 **E**。

稳定扩张被定义为满足上述所有条件的最小信念集合。给定一个包含 **B** 算子的知识库 **KB**，一个公式 **φ** 属于稳定扩张 **E**，当且仅当：
`φ ∈ E 当且仅当 KB ∪ { Bα | α ∈ E } ∪ { ¬Bα | α ∉ E } ⊨ φ`
这个定义将知识库与由内省性质产生的假设（**Bα** 或 **¬Bα**）结合起来，用于推导信念。

### 计算稳定扩张的步骤

为了找到知识库的所有稳定扩张，我们可以遵循一个系统化的“猜测与验证”过程。目标是得到不包含 **B** 算子的客观语句集合。

以下是计算稳定扩张的具体步骤：
1.  **识别与猜测**：找出知识库中所有非客观语句（即包含 **B** 算子的语句）。为每个这样的语句 **Bα**，猜测其真值为 **True** 或 **False**。
2.  **简化知识库**：根据猜测，将每个 **Bα** 替换为 **True** 或 **False**，然后简化整个知识库（例如，`¬True` 变为 `False`，`False ⇒ P` 可被移除）。得到的结果称为客观知识库 **KB'**。
3.  **验证一致性**：
    *   如果 **Bα** 被替换为 **True**，则必须验证 **KB' ⊨ α** 成立。
    *   如果 **Bα** 被替换为 **False**，则必须验证 **KB' ⊭ α** 成立。
4.  **生成扩张**：如果所有验证都通过，那么该组猜测对应一个稳定扩张。此扩张的客观部分就是 **KB'** 的所有逻辑后承。

### 实例分析：Tweety 与 Chili

让我们通过一个具体例子来应用上述步骤。假设知识库 **KB** 包含：
1.  `Bird(tweety)`
2.  `Bird(chili)`
3.  `¬Flies(chili)`
4.  `Bird(tweety) ∧ ¬B(¬Flies(tweety)) ⇒ Flies(tweety)`
5.  `Bird(chili) ∧ ¬B(¬Flies(chili)) ⇒ Flies(chili)`

我们需要处理两个非客观语句：**B(¬Flies(tweety))** 和 **B(¬Flies(chili))**。共有四种真值组合。

**组合 1: B(¬Flies(tweety)) = True, B(¬Flies(chili)) = True**
*   替换并简化后，规则4和5的前提 `¬B(...)` 变为 `¬True = False`，导致两条规则整体为 `True`（可忽略）。
*   验证：需检查 **KB' ⊨ ¬Flies(tweety)** 和 **KB' ⊨ ¬Flies(chili)**。前者不成立（知识库未提及Tweety是否会飞），故验证失败。**这不是稳定扩张**。

**组合 2: B(¬Flies(tweety)) = True, B(¬Flies(chili)) = False**
*   简化后，规则4失效，规则5变为 `Bird(chili) ⇒ Flies(chili)`。
*   将新规则加入 **KB'** 后，会推出 `Flies(chili)`，但这与已知事实 `¬Flies(chili)` 矛盾。验证失败。**这不是稳定扩张**。

**组合 3: B(¬Flies(tweety)) = False, B(¬Flies(chili)) = True**
*   简化后，规则4变为 `Bird(tweety) ⇒ Flies(tweety)`，规则5失效。
*   **KB'** 包含 `Bird(tweety) ⇒ Flies(tweety)` 和 `¬Flies(chili)`。
*   验证：
    *   对于 `B(¬Flies(tweety)) = False`：需验证 **KB' ⊭ ¬Flies(tweety)**。确实推不出，通过。
    *   对于 `B(¬Flies(chili)) = True`：需验证 **KB' ⊨ ¬Flies(chili)**。事实已给出，通过。
*   **这是一个稳定扩张**。在此扩张中，我们相信 `Flies(tweety)` 和 `¬Flies(chili)`。

**组合 4: B(¬Flies(tweety)) = False, B(¬Flies(chili)) = False**
*   简化后，两条规则都生效：`Bird(tweety) ⇒ Flies(tweety)` 和 `Bird(chili) ⇒ Flies(chili)`。
*   **KB'** 会推出 `Flies(chili)`，与 `¬Flies(chili)` 矛盾。验证失败。**这不是稳定扩张**。

因此，该知识库只有一个稳定扩张，即组合3，其中 Tweety 会飞而 Chili 不会飞。

### 自认知推理的特性与总结

最后，我们通过几个简单的知识库来观察自认知推理的一些特性。

以下是几个值得思考的例子：
*   **KB = { ¬B(p) ⇒ p }**：此知识库没有稳定扩张。因为无论假设 `B(p)` 为真或为假，都会导致矛盾或不一致。
*   **KB = { ¬B(p) ⇒ q, ¬B(q) ⇒ p }**：此知识库恰好有两个稳定扩张。一个扩张相信 `p` 但不相信 `q`；另一个扩张相信 `q` 但不相信 `p`。
*   **KB = { B(p) ⇒ p }**：此知识库有两个稳定扩张。一个扩张中 `B(p)` 和 `p` 都为真；另一个扩张中 `B(p)` 和 `p` 都为假。虽然两者都稳定，但前者（相信p则p为真）在直观上更合理。

本节课中我们一起学习了自认知推理。它通过引入信念算子 **B** 和稳定扩张的概念，为处理默认信息提供了一种在语言内部进行一致性假设的严谨方法。其计算过程基于“猜测与验证”，虽然可能产生多个扩张，但能精确刻画基于信念的推理。接下来，我们将进入多智能体系统的知识推理，学习描述智能体之间知识关系的认知逻辑。
