## 回顾案例与检验统计量

![](img/22f1989e38beea36e4732494bcbf90fe_11.png)

上一节我们讨论了在大样本（n=100）下使用Z检验。现在，假设我们的样本量n变为16，而不是100。

![](img/22f1989e38beea36e4732494bcbf90fe_13.png)

![](img/22f1989e38beea36e4732494bcbf90fe_14.png)

我们的检验统计量保持不变，依然是样本均值减去假设的总体均值。这里我们检验的原假设是 **H₀: μ = 30**，备择假设是 **H₁: μ > 30**。

检验统计量的计算公式为：

![](img/22f1989e38beea36e4732494bcbf90fe_16.png)

![](img/22f1989e38beea36e4732494bcbf90fe_17.png)

![](img/22f1989e38beea36e4732494bcbf90fe_18.png)

![](img/22f1989e38beea36e4732494bcbf90fe_19.png)

**t = (x̄ - μ₀) / (s / √n)**

![](img/22f1989e38beea36e4732494bcbf90fe_21.png)

![](img/22f1989e38beea36e4732494bcbf90fe_22.png)

其中，x̄是样本均值，μ₀是假设的均值（此处为30），s是样本标准差（此处为10），n是样本量（此处为16）。

![](img/22f1989e38beea36e4732494bcbf90fe_24.png)

因此，我们的检验统计量衡量了样本均值距离假设均值有多少个估计标准误。在n=16的情况下，这个统计量服从自由度为15的t分布。

## 执行单侧t检验

![](img/22f1989e38beea36e4732494bcbf90fe_28.png)

![](img/22f1989e38beea36e4732494bcbf90fe_29.png)

![](img/22f1989e38beea36e4732494bcbf90fe_30.png)

在原假设成立的前提下，如果检验统计量的值大于t分布的第95百分位数，其概率为5%。我们需要计算这个临界值。

![](img/22f1989e38beea36e4732494bcbf90fe_32.png)

![](img/22f1989e38beea36e4732494bcbf90fe_33.png)

在R语言中，可以使用`qt`函数计算t分布的分位数。对于自由度为15的单侧检验（上侧5%），我们计算第95百分位数：

```r
qt(0.95, df = 15)
```

![](img/22f1989e38beea36e4732494bcbf90fe_35.png)

![](img/22f1989e38beea36e4732494bcbf90fe_36.png)

计算结果约为 **1.7531**。这意味着，如果我们的检验统计量大于1.7531，我们就在5%的显著性水平上拒绝原假设。

![](img/22f1989e38beea36e4732494bcbf90fe_38.png)

![](img/22f1989e38beea36e4732494bcbf90fe_39.png)

现在，假设我们观测到的样本均值x̄为32。代入公式计算检验统计量：

![](img/22f1989e38beea36e4732494bcbf90fe_41.png)

**t = (32 - 30) / (10 / √16) = 2 / 2.5 = 0.8**

![](img/22f1989e38beea36e4732494bcbf90fe_43.png)

![](img/22f1989e38beea36e4732494bcbf90fe_44.png)

计算得到的检验统计量 **0.8** 小于临界值 **1.7531**。因此，我们**无法拒绝**原假设。样本数据没有提供足够证据表明总体均值大于30。

## 理解双侧t检验

![](img/22f1989e38beea36e4732494bcbf90fe_49.png)

接下来，我们看看双侧检验。在某些科学背景下，无论备择假设的方向性是否明确，都可能要求进行双侧检验。双侧检验旨在探测总体均值是否显著地不同于（无论是大于还是小于）假设值。

在本例中，双侧检验的原假设仍是 **H₀: μ = 30**，但备择假设变为 **H₁: μ ≠ 30**。这意味着，如果检验统计量过大（正方向）或过小（负方向），我们都会拒绝原假设。

由于我们的检验统计量是正的（0.8），我们主要关注它是否过大。但与单侧检验不同，为了控制总体的第一类错误率为5%，我们需要将5%的拒绝概率平均分配到分布的两侧，即每侧2.5%。

因此，我们需要计算t分布的第97.5百分位数：

```r
qt(0.975, df = 15)
```

这个值将大于单侧检验的临界值1.7531。实际上，双侧检验的拒绝域更靠分布的两端，使得拒绝原假设变得更难。

因为我们的检验统计量0.8在单侧检验中尚且不显著，那么在要求更严格的双侧检验中，它**肯定也无法拒绝**原假设。这体现了一个一般规律：如果无法拒绝单侧检验，则必然无法拒绝相应的双侧检验。

## 使用R语言进行t检验

在实际分析中，我们通常不手动计算拒绝域，而是使用统计软件（如R语言）来完成。`t.test`函数可以方便地执行t检验并提供所有相关统计量。

![](img/22f1989e38beea36e4732494bcbf90fe_56.png)

![](img/22f1989e38beea36e4732494bcbf90fe_57.png)

![](img/22f1989e38beea36e4732494bcbf90fe_58.png)

我们以R内置数据集`father.son`为例，检验父亲与儿子身高的总体均值是否有差异。由于数据是配对的（每个儿子对应一个父亲），我们关注身高差值的均值是否为零。

![](img/22f1989e38beea36e4732494bcbf90fe_60.png)

![](img/22f1989e38beea36e4732494bcbf90fe_62.png)

以下是执行配对t检验的两种等效方法：

![](img/22f1989e38beea36e4732494bcbf90fe_64.png)

**方法一：直接计算差值向量后进行检验**
```r
差值 <- father.son$sheight - father.son$fheight
t.test(差值)
```

![](img/22f1989e38beea36e4732494bcbf90fe_66.png)

**方法二：使用两个向量并指定`paired = TRUE`参数**
```r
t.test(father.son$sheight, father.son$fheight, paired = TRUE)
```

![](img/22f1989e38beea36e4732494bcbf90fe_67.png)

![](img/22f1989e38beea36e4732494bcbf90fe_68.png)

函数输出会包含：
*   **t统计量**：本例中约为11.79，这是一个非常大的值。
*   **自由度**：本例中为1077（因为有1078对观测值）。
*   **p值**：与t统计量对应的概率值。
*   **置信区间**：均值差值的95%置信区间。

![](img/22f1989e38beea36e4732494bcbf90fe_70.png)

![](img/22f1989e38beea36e4732494bcbf90fe_71.png)

由于t统计量11.79极大，我们强烈拒绝“父子身高无差异”的原假设。同时，由于自由度很大（>1000），t分布已非常接近标准正态分布，此时t检验与Z检验的结果几乎没有区别。

## 置信区间的重要性

![](img/22f1989e38beea36e4732494bcbf90fe_80.png)

`t.test`函数会自动给出置信区间。除了查看检验是否显著（p值），**始终建议查看置信区间**。

![](img/22f1989e38beea36e4732494bcbf90fe_82.png)

置信区间以数据本身的单位，给出了总体参数可能取值的范围。这有助于我们判断结果是否具有**实际意义**。例如，即使检验在统计上显著（p值很小），如果置信区间非常接近零，其实际差异可能微不足道。反之，一个较宽的置信区间则提示估计存在较大不确定性。

![](img/22f1989e38beea36e4732494bcbf90fe_84.png)
