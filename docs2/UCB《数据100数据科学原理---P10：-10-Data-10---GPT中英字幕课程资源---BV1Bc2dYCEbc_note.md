## 什么是模型？🤔

模型是对一个系统或世界的理想化表示。著名统计学家乔治·博克斯曾说过：“所有的模型都是错误的，但有些是有用的。”这句话揭示了模型的本质：它们是对复杂现实的简化近似，虽然不完全准确，但足以帮助我们理解和预测。

例如，描述物体在地球重力作用下下落的模型使用重力加速度9.81 m/s²。这个模型忽略了空气阻力、局部重力变化等因素，但它足够精确，被广泛应用于日常计算和工程系统中。这说明了模型的价值：它们简化了我们对复杂系统的理解，使其变得可处理。

---

## 我们为何要建模？🎯

建模主要有三个目的，理解这些区别对于数据科学实践至关重要。

以下是三种主要的建模目标：

1.  **理解与解释复杂现象**：目标是理解变量之间的关系并能够解释它。例如，研究父母平均身高与子女平均身高的关系。这类模型需要**简单、可解释且足够精确**。
2.  **进行高精度预测**：目标是构建高度精确的模型来预测复杂现象，即使模型本身可能像个“黑箱”难以解释。例如，垃圾邮件过滤器或文档摘要生成器。这类模型（常涉及机器学习或深度学习）**优先考虑准确性**。
3.  **推断因果关系**：目标是确定一个变量是否会导致另一个变量的变化（例如，吸烟是否致癌）。这需要**因果推断**方法，这超出了Data 100的课程范围，将在更高级的课程中探讨。

![](img/4d72073087714099481f6b2065ebf7e4_2.png)

在数据科学中，我们经常需要在模型的**可解释性**和**准确性**之间取得平衡。一个完全不准确的模型没有用处，而一个完全无法解释的“黑箱”模型则难以在需要信任的领域（如医疗）中部署。

## 模型的类型 📈

在深入线性回归之前，我们先概览一下不同类型的模型。

上一节我们介绍了建模的目的，本节中我们来看看模型有哪些主要类别。

*   **确定性（物理/机械）模型**：这类模型描述了世界运作的基本规律，通常是确定性的，不涉及概率。例如，开普勒行星运动定律或牛顿运动定律。
*   **概率模型**：这类模型用于描述和预测随机过程。例如，脑电波信号随时间变化就是一个随机过程。通过概率建模，我们可以分析信号分布，用于预测癫痫发作或评估焦虑水平。

## Data 8回顾：线性回归与相关关系 📉

现在，让我们回到本节课的核心——线性回归。我们将从回顾Data 8中的知识开始。

上一节我们了解了模型的宏观分类，本节中我们聚焦于一种具体且基础的模型：简单线性回归。

在Data 8中，我们使用小说《小妇人》的数据，用章节中的句号数量来预测字符数量。散点图上的**回归线**是一条独特的直线，它**最小化了所有数据点的均方误差**。误差（或残差）是观测值 `y_i` 与预测值 `y_i_hat` 之间的垂直距离。

以下是Data 8中线性回归的核心公式：

*   **回归线方程**：`y_hat = a + b * x`
    *   其中 `b` 是斜率，`a` 是截距。
*   **斜率公式**：`b = r * (σ_y / σ_x)`
    *   `r` 是相关系数，`σ_y` 和 `σ_x` 分别是y和x的标准差。
*   **截距公式**：`a = y_bar - b * x_bar`
    *   `y_bar` 和 `x_bar` 分别是y和x的均值。
*   **残差**：`residual = y_i - y_i_hat`

---

## 相关关系详解 🔗

相关系数 `r` 是线性回归的核心概念之一，它衡量两个变量之间的线性关联强度。

以下是相关系数 `r` 的关键性质：

*   **定义**：`r` 是当x和y都转换为标准单位（均值为0，标准差为1）后，其乘积的平均值。公式为：
    `r = (1/n) * Σ [ (x_i - x_bar)/σ_x * (y_i - y_bar)/σ_y ]`
*   **取值范围**：`-1 ≤ r ≤ 1`。
*   **含义解读**：
    *   `r ≈ 1`：强正线性相关（x增加，y增加）。
    *   `r ≈ -1`：强负线性相关（x增加，y减少）。
    *   `r ≈ 0`：无线性相关。但请注意，这**不意味着没有关系**，可能存在非线性关系。
*   **重要区别**：相关关系不等于因果关系。回归分析只探讨关联，不证明因果。

## Data 100的建模流程 🏗️

在Data 100中，我们采用一个系统化的四步流程来进行建模。这个流程适用于我们将在课程中遇到的大多数模型。

上一节我们回顾了基础概念，本节中我们正式进入Data 100的标准化建模流程。

以下是建模的四个核心步骤：

1.  **选择模型**：根据任务和数据特点，选择一个数学模型。本节课我们选择**简单线性回归模型**。
2.  **定义损失函数**：选择一个函数来量化模型预测的“坏的程度”。我们希望最小化这个损失。
3.  **拟合模型**：使用优化方法（如求导）找到能使损失函数最小化的模型参数（`θ`）。
4.  **评估模型**：使用各种指标评估训练好的模型在数据上的性能。

---

### 步骤1：选择模型 - 简单线性回归

对于简单线性回归，我们假设预测值 `y_hat` 是输入 `x` 的线性函数。
`y_hat_i = θ_0 + θ_1 * x_i`
其中 `θ_0` 是截距参数，`θ_1` 是斜率参数。我们的目标是找到最优的参数值 `θ_0_hat` 和 `θ_1_hat`。

---

### 步骤2：定义损失函数

损失函数衡量单个预测的误差。对于回归问题，两种常见的损失函数是：

*   **L2损失（平方损失）**：`Loss(y, y_hat) = (y - y_hat)^2`
*   **L1损失（绝对损失）**：`Loss(y, y_hat) = |y - y_hat|`

**L2损失**会放大较大的误差，因此对异常值更敏感。**L1损失**对大小误差的惩罚成比例。

我们不能直接使用残差和（`Σ(y_i - y_i_hat)`）作为损失，因为正负残差会相互抵消，掩盖真实误差。

在简单线性回归中，我们通常使用L2损失，并计算所有数据点的平均损失，称为**成本函数**或**经验风险**：

*   **均方误差**：`MSE(θ) = (1/n) * Σ (y_i - y_i_hat)^2`
*   **平均绝对误差**：`MAE(θ) = (1/n) * Σ |y_i - y_i_hat|`

使用L2损失（即最小化MSE）的线性回归，特称为**最小二乘回归**。

---

### 步骤3：拟合模型 - 求解最优参数

我们的目标是找到参数 `θ_0` 和 `θ_1`，使得 `MSE(θ)` 最小化。这是一个优化问题，可以通过微积分解决。

我们分别对 `MSE` 函数关于 `θ_0` 和 `θ_1` 求**偏导数**，并令其等于0。这会得到两个**估计方程**：

1.  `(1/n) * Σ (y_i - θ_0 - θ_1*x_i) = 0` （残差均值为0）
2.  `(1/n) * Σ [ (y_i - θ_0 - θ_1*x_i) * x_i ] = 0` （残差与x的协方差为0）

解这个方程组，即可得到最优参数估计：

*   `θ_1_hat = r * (σ_y / σ_x)`
*   `θ_0_hat = y_bar - θ_1_hat * x_bar`

这与我们在Data 8中推导出的公式完全一致！通过严格的数学优化，我们验证了之前直观理解的结果。
