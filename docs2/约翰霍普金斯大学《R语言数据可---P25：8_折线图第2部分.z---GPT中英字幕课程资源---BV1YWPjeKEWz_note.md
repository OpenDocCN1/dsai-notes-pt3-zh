## 研究背景与数据

过去20到25年间，美国政治科学中的一个核心问题是：共和党与民主党是否变得越来越两极分化或极端化，即共和党是否变得更保守，民主党是否变得更自由。

政治学家们开发了一种基于投票记录来衡量美国国会议员保守与自由程度的方法。这种方法的具体名称不重要，它被称为DW-NOMINATE分数，并存在于Volden和Wiseman关于立法有效性的数据集中，对应的列名为 `DWnom1`。

在这个度量标准下，**分数越低表示国会议员越自由**，**分数越高表示国会议员越保守**。

因此，评估美国政党是否随时间变得极端化的一个潜在方法是：测量两党成员在不同时间点的平均意识形态。如果两者间的距离在增加，我们或许可以将其解读为政治两极分化的加剧。

现在，请跟随我一起通过数据可视化来评估这个问题。

## 数据准备与处理

以下是数据处理的步骤：

首先，我将Volden和Wiseman的立法有效性数据加载到R中。

```r
# 加载数据
data <- read.csv("your_data_file.csv")
```

为了便于解释，我将把 `dim` 变量从一个1/0指示变量重新编码，使其显示为“民主党”或“共和党”。

```r
# 重新编码政党变量
data$party <- ifelse(data$dim == 1, "Democrat", "Republican")
```

接下来，我将执行一个管道命令来排序和汇总数据，并将其保存到名为 `fig_data` 的对象中。

```r
# 汇总数据
fig_data <- data %>%
  group_by(congress, party) %>%
  summarise(mean_ideology = mean(DWnom1, na.rm = TRUE))
```

我从数据源开始，告诉R按“国会届次”和“政党”进行分组。分组后，我通过计算平均值来汇总基于这些分组的 `DWnom1` 意识形态分数，并为此目的忽略缺失数据。

如果你需要回过头花几分钟来理解这个R命令，请尽管去做，以确保你理解所有不同的步骤以及最终表格的真正样貌和含义。

完成数据整理后，我们查看 `fig_data` 对象，会发现它包含年份、意识形态分数和政党信息。我们得到了不同年份民主党和共和党的平均意识形态数据。

## 绘制折线图

数据准备就绪后，我们就可以将其输入到一个与之前股价示例类似的 `ggplot2` 命令中。

```r
# 绘制折线图
ggplot(data = fig_data, aes(x = congress, y = mean_ideology, group = party, color = party)) +
  geom_line() +
  scale_color_manual(values = c("Democrat" = "blue", "Republican" = "red"))
```

数据是我创建的汇总数据集。美学映射中，x轴是年份，y轴是平均意识形态分数。通过 `group` 参数绘制两条不同的线，并通过 `color` 参数依据政党列的值来为线条着色。

然后我们添加 `geom_line()` 函数，并可以使用 `scale_color_manual()` 手动控制颜色。

这完全是对之前视频内容的复习，只是底层数据不同。

## 结果解读

在此图中，你可以看到随着时间的推移，从一届国会到下一届国会，两党在一定程度上分道扬镳了。这表明两党之间的党派极化程度更高。

需要说明的是，一些政治学家可能会对我在此处解读数据的方式提出异议，但仅作为数据可视化教学的一个例子，这为你使用原始数据制作折线图提供了很好的练习。
