## 核心训练选项

![](img/8d59a5f602d892489b2bfc7aa92e9925_35.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_36.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_37.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_38.png)

`train` 函数的核心参数使我们能够定制训练过程。以下是几个关键选项：

*   **`preProcess`**：用于设置一系列数据预处理选项（将在后续课程中详细讨论）。
*   **`weights`**：可以为某些观测值设置权重。这在训练集类别不平衡（即某一类的样本远多于另一类）时特别有用。
*   **`metric`**：设置用于评估模型性能的指标。
    *   对于分类变量（因子），默认指标是**准确度（Accuracy）**，即模型试图最大化的正确分类比例。
    *   对于连续变量，默认指标是**均方根误差（RMSE）**，其公式为：**`RMSE = sqrt(mean((predicted - actual)^2))`**。

此外，我们可以通过 `trControl` 参数传递一个 `trainControl` 函数的调用来设置大量其他控制参数。

```r
# 使用trainControl设置训练控制
fitControl <- trainControl(method = "boot", number = 25)
modelFit2 <- train(type ~ ., data=training, method="glm", trControl = fitControl)
```

---

## 性能指标详解

`train` 函数内置了多种性能指标选项。

对于连续型结果变量：
*   **`RMSE`**：均方根误差。
*   **`Rsquared`**：R平方值，来自回归模型，衡量预测变量与线性预测之间的线性相关程度。**`R^2 = 1 - (SS_res / SS_tot)`**。这对于线性回归等模型很有用，但对于随机森林等非线性方法可能不那么适用。

对于分类型结果变量：
*   **`Accuracy`**：正确分类的比例，是默认的准确度衡量标准。
*   **`Kappa`**：一致性度量，是一个更复杂、更深入的指标，常用于Kaggle等数据科学竞赛中。

## 使用 `trainControl` 进行精细控制

![](img/8d59a5f602d892489b2bfc7aa92e9925_45.png)

`trainControl` 参数允许你更精确地定义模型训练方式。

![](img/8d59a5f602d892489b2bfc7aa92e9925_47.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_48.png)

以下是其主要选项：
*   **`method`**：指定重采样方法，如自助法（bootstrapping）或交叉验证（cross-validation）。
*   **`number`**：指定进行自助法或交叉验证的次数。
*   **`repeats`**：如果需要谨慎地进行重复交叉验证，可以指定整个重采样过程的重复次数。
*   **`p`**：指定训练集的大小比例。
*   **`returnResamp`**：可以设置为返回每次迭代构建模型时的实际预测值。
*   **`summaryFunction`**：可以使用默认摘要函数以外的其他函数。
*   **`seeds`**：为所有不同的重采样层设置随机种子。这在跨多个核心并行化计算时特别有用。虽然这里不深入讨论，但在处理大量样本和高维预测变量时，使用并行处理可以提高计算效率。

## 重采样方法

![](img/8d59a5f602d892489b2bfc7aa92e9925_52.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_53.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_54.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_55.png)

有多种重采样方法可供选择，并通过 `trainControl` 函数传递。

以下是可用的方法：
*   **`boot`**：标准自助法。
*   **`boot632`**：一种调整后的自助法，考虑了自助抽样中样本被重复抽取的事实，可以减少自助法带来的一些偏差。
*   **`cv`**：交叉验证，我们在之前的课程中讨论过。
*   **`repeatedcv`**：重复交叉验证，如果你想用不同的随机划分进行多次交叉验证。
*   **`LOOCV`**：留一法交叉验证。请记住，在使用交叉验证时，折数（folds）的多少存在偏差-方差权衡。

你还可以指定自助样本的数量、子采样的次数，或者在进行重复交叉验证时的重复次数。通常，默认设置效果很好。但是，如果你的样本量很大，或者模型需要在大量参数上进行精细调优，你可能需要增加交叉验证或自助样本的数量。

## 设置随机种子

![](img/8d59a5f602d892489b2bfc7aa92e9925_63.png)

训练这些模型的一个重要环节是设置随机种子。大多数程序依赖于数据的随机重采样。如果你重新运行代码，由于交叉验证时产生了随机抽取，可能会得到略有不同的答案。

![](img/8d59a5f602d892489b2bfc7aa92e9925_65.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_66.png)

设置随机种子可以确保每次生成相同的伪随机数序列，从而获得可重复的结果。这对于分享代码和确保他人能复现你的结果至关重要。

![](img/8d59a5f602d892489b2bfc7aa92e9925_67.png)

![](img/8d59a5f602d892489b2bfc7aa92e9925_69.png)

```r
# 设置全局随机种子以获得可重复结果
set.seed(12345)
modelFit2 <- train(type ~ ., data=training, method="glm")

![](img/8d59a5f602d892489b2bfc7aa92e9925_70.png)

# 重置种子并再次拟合，将得到完全相同的结果
set.seed(12345)
modelFit3 <- train(type ~ ., data=training, method="glm")
```

你可以设置整个过程的全局种子。如果进行并行计算，还可以通过 `trainControl` 函数的 `seeds` 参数为每个重采样设置种子。为每个样本设置种子对于并行拟合特别有用，但在非并行处理中通常不是必需的。
