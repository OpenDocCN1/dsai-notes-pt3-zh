## 数据准备与变量定义

![](img/5718815f1fb09af03fe9e7d8821f2ea7_8.png)

首先，我们使用R语言加载数据。为了简化后续操作，我们将儿子的身高数据定义为一个单独的向量 `x`。

```r
# 假设数据已加载，例如来自 'UsingR' 包中的 father.son 数据
# 定义 x 为儿子的身高向量
x <- father.son$sheight
```

接下来，我们定义观测值的数量 `n`，并设定进行 `B = 10000` 次自举重抽样。

![](img/5718815f1fb09af03fe9e7d8821f2ea7_10.png)

```r
n <- length(x)
B <- 10000
```

## 执行自举重抽样

![](img/5718815f1fb09af03fe9e7d8821f2ea7_16.png)

![](img/5718815f1fb09af03fe9e7d8821f2ea7_18.png)

上一节我们定义了数据和参数，本节中我们来看看如何执行核心的重抽样过程。

![](img/5718815f1fb09af03fe9e7d8821f2ea7_20.png)

自举法的核心思想是从原始数据中进行**有放回**的重复抽样，以模拟从**经验分布**中生成新样本。经验分布即为在每个观测数据点上赋予相同概率 `1/n` 的分布。

![](img/5718815f1fb09af03fe9e7d8821f2ea7_22.png)

以下是执行重抽样的代码：

![](img/5718815f1fb09af03fe9e7d8821f2ea7_24.png)

```r
# 生成 B 个重抽样数据集
# sample(x, size, replace=TRUE) 表示从 x 中有放回地抽取 size 个样本
resamples <- matrix(sample(x, n * B, replace = TRUE), B, n)
```

![](img/5718815f1fb09af03fe9e7d8821f2ea7_25.png)

![](img/5718815f1fb09af03fe9e7d8821f2ea7_27.png)

这段代码创建了一个矩阵 `resamples`。它的每一行都代表一个全新的、通过有放回抽样生成的数据集，其大小与原始数据集相同（`n` 个观测值）。

## 计算目标统计量

![](img/5718815f1fb09af03fe9e7d8821f2ea7_33.png)

在获得重抽样数据集后，我们需要对每个数据集计算我们感兴趣的统计量。在本例中，我们关注的是**中位数**。

![](img/5718815f1fb09af03fe9e7d8821f2ea7_35.png)

![](img/5718815f1fb09af03fe9e7d8821f2ea7_37.png)

以下是计算每个重抽样数据集中位数的代码：

```r
# 对 resamples 矩阵的每一行（即每个重抽样数据集）应用中位数函数
medians <- apply(resamples, 1, median)
```

![](img/5718815f1fb09af03fe9e7d8821f2ea7_39.png)

![](img/5718815f1fb09af03fe9e7d8821f2ea7_40.png)

现在，`medians` 向量包含了 `B=10000` 个基于重抽样数据计算出的中位数值。

## 分析与解释结果

![](img/5718815f1fb09af03fe9e7d8821f2ea7_47.png)

我们通过密度估计来可视化这10000个中位数的分布，并在图中用竖线标出原始数据的中位数。

```r
# 绘制自举中位数的密度估计图
plot(density(medians))
abline(v = median(x), col = "red", lwd = 2)
```

这张图估计了**中位数统计量的抽样分布**。由于我们不知道真实的总体分布，因此使用观测数据的经验分布作为其估计。

![](img/5718815f1fb09af03fe9e7d8821f2ea7_49.png)

![](img/5718815f1fb09af03fe9e7d8821f2ea7_50.png)

这个自举分布是进行统计推断的核心工具。例如：
*   我们可以计算这个分布的标准差，作为**中位数标准误**的估计。
*   我们可以计算这个分布的分位数，来构建**中位数的置信区间**。

## 总结

本节课中，我们一起学习了自举法的完整流程：
1.  **准备数据**：定义目标变量和重抽样次数。
2.  **重抽样**：使用 `sample(..., replace = TRUE)` 从原始数据中有放回地抽取大量新样本，模拟从经验分布中抽样。
3.  **计算统计量**：对每个重抽样数据集计算目标统计量（如中位数），得到一个统计量的自举分布。
4.  **分析推断**：利用这个自举分布来估计统计量的标准误、置信区间等性质。

![](img/5718815f1fb09af03fe9e7d8821f2ea7_55.png)

![](img/5718815f1fb09af03fe9e7d8821f2ea7_56.png)

![](img/5718815f1fb09af03fe9e7d8821f2ea7_57.png)

自举法是一种强大且实用的非参数方法，它不依赖于对总体分布的具体假设，仅通过重复利用现有数据来评估统计量的变异性。
