# 大型语言模型实践：P124：功能概述 🧠

![](img/41872ecdb1f5379b5e52780043b266c9_0.png)

在本节课中，我们将要学习大型语言模型中“功能”的概念及其工作原理。功能是增强LLM能力的关键机制，允许模型与外部数据源或API进行交互，从而提供更准确、更具体的回答。

---

## 用户输入与初始流程

我们首先从用户输入开始。用户输入是指用户向大型语言模型提出的任何问题或发出的任何指令，本质上就是一个提示词。

![](img/41872ecdb1f5379b5e52780043b266c9_2.png)

整个流程的第一步是收集这个提示词。随后，这个提示词会被发送到聊天应用程序进行处理。这个聊天应用程序可以是任何能够与LLM交互的框架或库，例如Semantic Kernel，也可以是简单的库。

**流程示意：**
`用户输入 -> 聊天应用 -> LLM`

---

![](img/41872ecdb1f5379b5e52780043b266c9_4.png)

## 传统流程的局限性

上一节我们介绍了基本的交互流程。接下来，我们通过一个具体例子来理解其局限性。假设用户提问：“波士顿一月的天气如何？”

按照传统流程，这个提示词会从聊天应用直接发送给LLM。LLM会基于其训练数据生成一个通用的、概率性的回答。然而，LLM本身并不具备获取实时天气数据的能力，因此其回答可能不够准确或具体。

![](img/41872ecdb1f5379b5e52780043b266c9_6.png)

![](img/41872ecdb1f5379b5e52780043b266c9_7.png)

**传统流程：**
`用户输入（天气问题） -> 聊天应用 -> LLM -> 聊天应用 -> 用户回答（基于训练数据的通用回答）`

![](img/41872ecdb1f5379b5e52780043b266c9_9.png)

---

## 引入功能作为中间步骤

为了解决上述局限性，我们引入“功能”作为中间步骤。功能充当了LLM与外部世界之间的中介。

当LLM收到提示词（如天气查询）后，它不会直接生成最终答案。相反，LLM会与聊天应用进行逻辑判断，识别出用户意图可能需要调用某个特定功能。例如，LLM会判断：“这个问题似乎与天气有关，调用天气API功能可能更合适。”

于是，流程变为：聊天应用将LLM识别出的关键信息（如地点“波士顿”、时间“一月”）发送给对应的功能（例如一个天气API）。该功能执行操作（调用API获取实时数据），并将结果返回给聊天应用。

**引入功能后的流程：**
`用户输入 -> 聊天应用 -> LLM -> 聊天应用 -> 功能（如天气API） -> 聊天应用 -> LLM -> 聊天应用 -> 用户回答`

## 功能的工作机制与价值

![](img/41872ecdb1f5379b5e52780043b266c9_17.png)

![](img/41872ecdb1f5379b5e52780043b266c9_18.png)

![](img/41872ecdb1f5379b5e52780043b266c9_19.png)

![](img/41872ecdb1f5379b5e52780043b266c9_20.png)

虽然这个流程看起来比传统方式复杂，但其核心价值在于为LLM赋予了“超能力”。LLM本质上是一个概率机器，擅长理解和生成语言，但缺乏获取实时、特定外部数据的能力。

功能机制通过以下方式增强了LLM：
1.  **提供落地信息**：为LLM的回答补充具体、准确的事实数据。
2.  **添加上下文**：引入外部知识，使回答更具相关性和实用性。
3.  **扩展能力边界**：使LLM能够完成原本无法独立完成的任务，如查询天气、检索数据库、执行计算等。

![](img/41872ecdb1f5379b5e52780043b266c9_22.png)

我们可以将这个过程想象为给LLM插上了一个“插件”，让它能够按需调用各种工具和服务。

![](img/41872ecdb1f5379b5e52780043b266c9_23.png)

![](img/41872ecdb1f5379b5e52780043b266c9_24.png)

## 核心概念总结

本节课中我们一起学习了LLM中功能的核心概念。关键要点如下：

![](img/41872ecdb1f5379b5e52780043b266c9_26.png)

![](img/41872ecdb1f5379b5e52780043b266c9_27.png)

![](img/41872ecdb1f5379b5e52780043b266c9_28.png)

*   **功能定义**：功能是LLM与外部系统（如API、数据库）交互的中间件。
*   **工作流程**：用户输入经LLM解析后，触发特定功能执行，功能返回的结果再经LLM整合，最终形成给用户的回答。
*   **核心价值**：功能为LLM提供了**落地性**和**扩展性**，使其回答基于实时、准确的外部数据，而不仅仅是训练数据中的概率模式。

![](img/41872ecdb1f5379b5e52780043b266c9_29.png)

![](img/41872ecdb1f5379b5e52780043b266c9_30.png)

![](img/41872ecdb1f5379b5e52780043b266c9_31.png)

通过引入功能，我们能够构建更强大、更实用的基于大型语言模型的应用程序。
