## 缺失值处理 🧩

![](img/03fe67411ac87e580b49b65632d45244_8.png)

![](img/03fe67411ac87e580b49b65632d45244_9.png)

![](img/03fe67411ac87e580b49b65632d45244_10.png)

![](img/03fe67411ac87e580b49b65632d45244_11.png)

上一节我们介绍了SVD和PCA的基本原理，本节中我们来看看一个实际应用中常见的问题：缺失值。无论是SVD还是PCA，一个共同的问题是它们无法直接处理含有缺失值的数据。真实数据通常包含缺失值，如果尝试在含有缺失值的数据上运行SVD，程序会报错。

![](img/03fe67411ac87e580b49b65632d45244_12.png)

![](img/03fe67411ac87e580b49b65632d45244_13.png)

![](img/03fe67411ac87e580b49b65632d45244_14.png)

因此，在运行SVD或PCA之前，我们需要对缺失值进行处理。一种常用的方法是使用来自Bioconductor项目的`impute`包来填补缺失的数据点。

![](img/03fe67411ac87e580b49b65632d45244_16.png)

![](img/03fe67411ac87e580b49b65632d45244_17.png)

![](img/03fe67411ac87e580b49b65632d45244_18.png)

![](img/03fe67411ac87e580b49b65632d45244_19.png)

以下是使用`impute.knn`函数进行填补的代码示例。该函数利用K近邻算法，例如当`k=5`时，它会找到与含有缺失值的行最接近的5行数据，然后用这5行数据的平均值来填补缺失值。

```r
# 假设dataMatrix是含有缺失值的数据矩阵
library(impute)
imputedData <- impute.knn(dataMatrix, k=5)
```

![](img/03fe67411ac87e580b49b65632d45244_21.png)

![](img/03fe67411ac87e580b49b65632d45244_22.png)

![](img/03fe67411ac87e580b49b65632d45244_23.png)

![](img/03fe67411ac87e580b49b65632d45244_24.png)

![](img/03fe67411ac87e580b49b65632d45244_25.png)

填补完成后，我们就可以在填补后的数据上运行SVD了。运行后不会再有错误，并且我们可以绘制出填补前后数据的第一个奇异向量进行比较。

![](img/03fe67411ac87e580b49b65632d45244_27.png)

下图左侧是原始数据矩阵的第一个奇异向量，右侧是填补缺失值后数据矩阵的第一个奇异向量。可以看到两者大致相似，虽然不完全相同，但填补过程对SVD的运行结果没有产生重大影响。

## SVD在图像压缩中的应用 🖼️

![](img/03fe67411ac87e580b49b65632d45244_32.png)

![](img/03fe67411ac87e580b49b65632d45244_33.png)

![](img/03fe67411ac87e580b49b65632d45244_34.png)

现在，让我们来看一个有趣的例子，展示如何利用SVD对图像进行压缩。图像本质上是一个矩阵，我们可以通过SVD得到它的一个低秩近似表示。

![](img/03fe67411ac87e580b49b65632d45244_38.png)

这里有一张人脸的相对低分辨率图片，可以看到鼻子、耳朵、眼睛和嘴巴等特征。

![](img/03fe67411ac87e580b49b65632d45244_40.png)

![](img/03fe67411ac87e580b49b65632d45244_41.png)

![](img/03fe67411ac87e580b49b65632d45244_42.png)

![](img/03fe67411ac87e580b49b65632d45244_43.png)

我们对这个人脸数据矩阵运行SVD，并查看方差解释率。第一个奇异向量解释了约40%的变异，第二个解释了约20%，第三个约15%。前5到10个奇异向量几乎捕获了数据集中的所有变异。

![](img/03fe67411ac87e580b49b65632d45244_44.png)

因此，我们可以通过矩阵乘法，使用比原始数据集更少的成分来重建人脸的近似图像。

以下是使用不同数量奇异向量进行重建的代码思路：

```r
# 假设svdResult是已完成的SVD分解结果
# U, D, V 分别为左奇异向量、奇异值矩阵、右奇异向量

# 使用第一个奇异向量重建
approx1 <- svdResult$u[, 1] %*% diag(svdResult$d[1]) %*% t(svdResult$v[, 1])

# 使用前五个奇异向量重建
k <- 5
approx5 <- svdResult$u[, 1:k] %*% diag(svdResult$d[1:k]) %*% t(svdResult$v[, 1:k])

# 使用前十个奇异向量重建
k <- 10
approx10 <- svdResult$u[, 1:k] %*% diag(svdResult$d[1:k]) %*% t(svdResult$v[, 1:k])
```

我们可以观察这些近似图像的效果：
*   **最左侧图像（A）**：仅使用第一个奇异向量。重建效果不佳，几乎看不出人脸。
*   **左二图像（B）**：使用前五个奇异向量。基本的关键特征已经出现，可以清楚地看到一张有眼睛、鼻子、嘴巴和耳朵的脸，虽然与原始图像不完全相同，但非常接近。
*   **左三图像（C）**：使用前十个奇异向量。图像更具细节，但与使用五个奇异向量的图像差异不大。
*   **最右侧图像（D）**：原始数据集。

![](img/03fe67411ac87e580b49b65632d45244_47.png)

![](img/03fe67411ac87e580b49b65632d45244_48.png)

![](img/03fe67411ac87e580b49b65632d45244_49.png)

![](img/03fe67411ac87e580b49b65632d45244_50.png)

这个例子表明，仅使用少数几个（如5到10个）奇异向量，就能获得一个合理的人脸近似图像，而无需存储所有原始数据。这体现了奇异值分解在**数据压缩**方面的应用。数据压缩和**统计摘要**是一枚硬币的两面，如果你想用更少的特征来总结一个数据集，奇异值分解同样有用。

## 注意事项与进一步资源 📚

![](img/03fe67411ac87e580b49b65632d45244_55.png)

![](img/03fe67411ac87e580b49b65632d45244_56.png)

在使用SVD和PCA时，有几点需要注意：

![](img/03fe67411ac87e580b49b65632d45244_59.png)

![](img/03fe67411ac87e580b49b65632d45244_60.png)

![](img/03fe67411ac87e580b49b65632d45244_61.png)

![](img/03fe67411ac87e580b49b65632d45244_62.png)

1.  **数据尺度问题**：数据的测量尺度很重要。如果不同变量具有完全不同的量纲（单位），那么量级大的变量会主导主成分分析或奇异向量的方向，这可能使得结果缺乏实际意义。因此，需要确保不同列或行的数据尺度大致可比。
2.  **模式混合**：正如我们在双模式例子中看到的，主成分和奇异向量可能会将真实的模式混合在一起。因此，你看到的模式可能不代表可分离的独立模式，而是混合模式。
3.  **计算强度**：对于非常大的矩阵，奇异值分解的计算量可能很大。虽然我们这里使用的是相对较小的矩阵，但计算能力在不断增强，并且存在一些高度优化的专用矩阵库来计算SVD，因此许多实际问题仍然可以处理。

以下是一些关于如何使用主成分分析和奇异值分解的进一步资源链接。此外，还有一些与此类似但在许多细节上有所不同的方法，例如**因子分析**、**独立成分分析**和**潜在语义分析**。这些方法都值得探索，其核心思想与PCA和SVD相同：**寻找能够解释数据中大部分变异的低维表示**。
