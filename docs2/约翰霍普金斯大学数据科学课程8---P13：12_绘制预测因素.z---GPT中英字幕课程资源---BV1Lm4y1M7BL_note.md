## 添加回归平滑曲线

我们还可以在图中添加回归平滑曲线，以更清晰地观察不同组别间的趋势差异。

以下代码按教育程度着色，并为每个教育组别添加线性平滑曲线：

```r
# 按教育程度着色，并添加线性平滑器
qplot(age, wage, colour = education, data = training) +
  geom_smooth(method = 'lm', formula = y ~ x)
```

`geom_smooth` 函数为每个教育类别拟合了一个线性模型。例如，紫色线代表拥有高等学历的人群，绿线代表上过一些大学的人群。通过这种方式，我们可以观察不同年龄组之间是否存在不同的关系。

## 使用密度图

最后，我们可以使用密度图来绘制连续预测变量的分布。密度图可以显示数据的集中区域，并且便于叠加多个分布进行比较。

以下代码绘制不同教育水平的工资密度图：

```r
# 绘制按教育程度分组的工资密度图
qplot(wage, colour = education, data = training, geom = "density")
```

![](img/f30c2143e7b005ab47d103f12c3991c6_103.png)

在密度图中，X轴是工资，Y轴可以理解为落在X轴该区间内的变量比例。例如，高中毕业生倾向于集中在工资范围较低的部分，而拥有高等学历的人群分布则略高一些。密度图有时能揭示箱线图无法显示的模式，特别是在比较多个组的分布时非常有用。

## 绘图注意事项与总结

![](img/f30c2143e7b005ab47d103f12c3991c6_112.png)

![](img/f30c2143e7b005ab47d103f12c3991c6_113.png)

在结束之前，有几个关键点需要牢记：
*   **仅在训练数据上绘图**：测试集不能用于探索性分析，这类似于在测试集上训练模型，会导致过拟合。
*   **绘图时寻找的模式**：
    *   **结果或预测变量中的不平衡**：如果某个预测变量在某个结果组中全是一种值，而在另一组中不是，那它是一个好的预测器。但如果一个结果组只有3个样本，而另一个有150个，则很难在这两个类别之间构建准确的分类器。
    *   **异常值或奇怪的数据群组**：这可能暗示缺失了某些变量。
    *   **偏态变量**：如果使用回归类模型，你可能需要转换它们使其更接近正态分布；但如果使用更多的机器学习方法，这可能不那么重要。

本节课中，我们一起学习了多种可视化预测因素的方法，包括使用 `caret::featurePlot` 进行快速概览、使用 `ggplot2` 进行定制化绘图、通过着色和添加平滑曲线揭示关系、将连续变量分箱、绘制并解读箱线图与密度图，以及使用表格进行分析。这些技能是理解数据、为后续模型选择与构建奠定基础的关键步骤。
