## 模拟简单线性模型 📈

首先，我们模拟一个简单的线性模型。该模型有一个连续型预测变量 `x`，一个服从正态分布的随机误差项 `epsilon`，并通过回归系数生成结果变量 `y`。

模型公式如下：
`y = β₀ + β₁ * x + ε`
其中，`ε ~ N(0, 2)`。我们假设截距 `β₀ = 0.5`，斜率 `β₁ = 2`。

以下是模拟步骤：

1.  设定随机种子以确保结果可重现。
2.  生成预测变量 `x`，假设其服从标准正态分布。
3.  生成误差项 `epsilon`，其服从均值为0、标准差为2的正态分布。
4.  根据模型公式计算 `y`。

```r
set.seed(20)
x <- rnorm(100)
epsilon <- rnorm(100, 0, 2)
y <- 0.5 + 2 * x + epsilon
summary(y)
plot(x, y)
```
运行摘要函数可以看到 `y` 的均值约为0.68，范围大约在-6到6之间。绘制散点图可以清晰地看到 `x` 和 `y` 之间存在我们设定的线性关系。

---

## 模拟带有二分类预测变量的线性模型 ⚖️

现在我们对上一个例子稍作变化。如果预测变量 `x` 不是连续的，而是一个二分类变量（例如代表性别或实验组/对照组），该如何模拟？

方法依然简单。我们可以使用二项分布生成二分类数据。假设 `x` 来自一次伯努利试验，取值为1的概率为0.5。

以下是具体步骤：

1.  设定随机种子。
2.  使用 `rbinom` 函数生成100个二分类随机变量作为 `x`。
3.  生成正态分布的误差项 `epsilon`。
4.  根据相同的线性模型公式计算 `y`。

```r
set.seed(20)
x <- rbinom(100, 1, 0.5)
epsilon <- rnorm(100, 0, 2)
y <- 0.5 + 2 * x + epsilon
summary(y)
plot(x, y)
```
此时 `y` 的均值约为1.4。由于 `x` 只有0和1两个值，散点图会呈现为两组垂直分布的点，但仍能清晰地看出从 `x=0` 到 `x=1`，`y` 的均值存在线性上升的趋势。

## 模拟泊松回归模型 🧮

最后，我们模拟一个更复杂的模型——广义线性模型，例如泊松回归。泊松回归常用于建模计数型数据。其误差分布不再是正态分布，而是泊松分布。

我们假设结果变量 `y` 服从泊松分布，其均值 `μ` 的对数与预测变量 `x` 呈线性关系。

模型公式如下：
`log(μ) = β₀ + β₁ * x`
`y ~ Poisson(μ)`
假设 `β₀ = 0.5`，`β₁ = 0.3`。

模拟步骤如下：

1.  设定随机种子。
2.  生成连续型预测变量 `x`（标准正态分布）。
3.  计算线性预测值 `log(μ)`。
4.  通过指数运算得到泊松分布的均值 `μ`。
5.  使用 `rpois` 函数，以 `μ` 为参数生成泊松随机变量作为 `y`。

```r
set.seed(20)
x <- rnorm(100)
log.mu <- 0.5 + 0.3 * x
y <- rpois(100, exp(log.mu))
summary(y)
plot(x, y)
```
`y` 的均值约为1.5，取值范围为0到6。从散点图可以看出，数据是离散的计数值，并且随着 `x` 的增加，`y` 的计数值整体呈上升趋势，符合泊松回归的特征。
