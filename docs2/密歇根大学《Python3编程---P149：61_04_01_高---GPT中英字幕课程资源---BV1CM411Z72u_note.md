## 可选参数

上一节我们介绍了课程目标，本节中我们来看看可选参数。可选参数允许我们为函数参数提供默认值。如果在调用函数时没有为该参数提供值，则将使用其默认值。

以下是定义和使用可选参数的步骤：

1.  在函数定义中，使用等号 `=` 为参数指定默认值。
2.  调用函数时，可以省略具有默认值的参数。
3.  如果提供了值，它将覆盖默认值。

例如，定义一个问候函数，其中 `greeting` 参数是可选的：

```python
def greet(name, greeting="Hello"):
    print(f"{greeting}, {name}!")

# 使用默认问候语
greet("Alice")  # 输出：Hello, Alice!

# 提供自定义问候语
greet("Bob", "Good morning")  # 输出：Good morning, Bob!
```

通过使用可选参数，我们可以减少常见情况下的代码冗余，使函数调用更简洁。

## 关键字参数

了解了可选参数后，我们来看看关键字参数。关键字参数允许我们在调用函数时通过参数名来指定值，而不是依赖于参数的位置顺序。这意味着我们可以以任意顺序传递参数。

以下是使用关键字参数的要点：

1.  在函数调用中，使用 `参数名=值` 的格式。
2.  可以混合使用位置参数和关键字参数，但位置参数必须在关键字参数之前。
3.  关键字参数提高了代码的可读性，尤其是在函数有很多参数时。

例如，定义一个描述个人的函数：

```python
def describe_person(name, age, city):
    print(f"{name} is {age} years old and lives in {city}.")

# 使用位置参数（传统方式）
describe_person("Charlie", 30, "New York")

# 使用关键字参数（顺序可变）
describe_person(age=25, city="London", name="Diana")

# 混合使用位置参数和关键字参数
describe_person("Eve", city="Paris", age=28)
```

使用关键字参数可以使函数调用的意图更加清晰，特别是在参数较多或可选参数很多的情况下。

## Lambda 函数

最后，我们来探讨 Lambda 函数。Lambda 函数是一种使用 `lambda` 关键字定义的匿名函数（即没有名字的函数）。它通常用于定义简单的、单行的函数，并且经常作为参数传递给其他高阶函数（如 `map()`、`filter()`、`sort()`）。

定义 Lambda 函数的基本语法是：

**`lambda arguments: expression`**

以下是 Lambda 函数的特点和用法：

1.  **简洁**：在一行内定义一个小型函数。
2.  **匿名**：通常不需要绑定到一个变量名。
3.  **返回表达式结果**：Lambda 函数会自动返回表达式的结果，不需要 `return` 语句。

例如，使用 Lambda 函数对一个数字列表进行平方运算：

```python
numbers = [1, 2, 3, 4, 5]

# 使用 lambda 函数和 map
squared = list(map(lambda x: x ** 2, numbers))
print(squared)  # 输出：[1, 4, 9, 16, 25]

# 使用 lambda 函数进行排序（按绝对值）
points = [-5, 2, -1, 10, -3]
points.sort(key=lambda x: abs(x))
print(points)  # 输出：[1, 2, -3, -5, 10] （注意：排序后是[-1, 2, -3, -5, 10]，但按绝对值排序后顺序是1,2,3,5,10对应的原值）
# 更正：按绝对值排序后，原列表变为 [-1, 2, -3, -5, 10]
```

Lambda 函数让代码在需要小型、一次性使用的函数时更加紧凑和直接。
