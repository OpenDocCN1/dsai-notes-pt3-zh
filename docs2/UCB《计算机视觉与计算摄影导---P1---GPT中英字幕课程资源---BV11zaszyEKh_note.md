# 课程1：三维重建与神经渲染入门 🎥

在本节课中，我们将学习计算机视觉中三维重建的核心流程，从传统的运动恢复结构到前沿的神经辐射场技术。我们将了解如何从一组二维图像中恢复出三维场景，并探讨不同方法的原理与联系。

## 从稀疏到稠密：运动恢复结构

上一节我们介绍了图像拼接和单应性变换。本节中，我们来看看如何从多张图像中恢复出三维结构。

运动恢复结构的目标是，给定多张从不同视角拍摄的图像，同时求解出所有相机的姿态（位置和朝向）以及场景中特征点的三维坐标。

**核心优化公式**如下：
我们通过最小化重投影误差来求解。对于每个三维点 `X_j` 和每个相机 `i`，我们比较该点在图像 `i` 中观测到的二维坐标 `x_{ij}` 与通过相机参数（旋转 `R_i`、平移 `t_i`、内参 `K_i`）将 `X_j` 投影到图像平面上的预测坐标 `proj(K_i, R_i, t_i, X_j)` 之间的差异。

```python
# 重投影误差的简化表示
error = sum_over_all_points_and_cameras( || observed_2D_point - projected_3D_point ||^2 )
```

我们需要优化的参数是所有相机的 `R_i`, `t_i` 和所有三维点 `X_j`。这是一个大规模的非线性优化问题，因为投影过程涉及除法运算（从齐次坐标转换到二维坐标）。

以下是解决此问题的标准增量式流程：

1.  **选择初始图像对**：选择两张具有足够多匹配特征点（便于计算）和足够大基线（便于恢复深度）的图像。
2.  **初始化重建**：使用这两张图像，通过双目立体视觉或基础矩阵分解的方法，初步估计出相机姿态和一组稀疏三维点。
3.  **增量添加视图**：重复以下步骤，直到所有图像都被处理：
    *   选择一张能看到当前已重建三维点最多的新图像。
    *   根据已有的三维点，估计新相机的姿态。
    *   利用新相机和已有相机，对新的特征点进行三角测量，得到其三维坐标。
    *   运行**集束调整**优化所有参数（所有相机姿态和所有三维点），使整体重投影误差最小。
4.  **输出**：得到所有相机的精确姿态和场景的稀疏三维点云。

**集束调整**是解决这个非线性优化问题的工具。可以把它想象成训练一个巨大的神经网络：参数众多，存在复杂的非线性相互作用，但通过梯度下降等方法，最终能找到一组一致的解。良好的初始化（如从两视图重建开始）对于收敛至关重要。

一个相关的概念是**视觉SLAM**，它主要应用于机器人领域，强调在线、实时地处理传感器数据，并在机器人移动过程中持续更新地图和自身定位。

## 多视图立体视觉：获取稠密三维模型

通过运动恢复结构，我们得到了相机姿态和稀疏点云。但我们的目标通常是获得带有颜色信息的、稠密的三维模型，就像谷歌街景那样。这就是多视图立体视觉要解决的问题。

多视图立体视觉的输入是已标定（已知内外参数）的多张图像，输出是稠密的三维模型（如网格或点云）。

其基本思想是双目立体视觉的扩展。在双目立体视觉中，我们有两个已标定的相机，通过寻找匹配点并计算视差来得到深度。多视图立体视觉则利用更多视图，使得匹配更鲁棒，并能填补遮挡区域的空白。

以下是其核心算法步骤：

1.  **选择参考视图**：从所有已标定图像中选一张作为参考。
2.  **对参考视图的每个像素**：
    *   从相机中心出发，经过该像素，形成一条三维射线。
    *   沿着这条射线，在可能的深度范围内采样一系列假设的深度值 `Z_k`。
    *   对于每个假设的深度 `Z_k`，计算对应的三维点 `P_k`。
    *   将 `P_k` 投影到**所有其他**可见的相机视图中。
    *   在参考图像中，以该像素为中心取一个图像块。在所有其他视图的对应投影位置，也取同样大小的图像块。
    *   计算参考图像块与其他所有视图图像块之间的差异（如L2距离）之和，作为该深度假设的“不一致性”代价。
3.  **确定深度**：选择代价最小的那个深度 `Z_k`，作为该像素的深度估计。
4.  **生成稠密深度图**：对参考图像的每一个像素都执行上述操作，最终得到一张稠密的深度图。结合相机参数，即可将每个像素反投影为三维点，形成稠密点云。

由于我们拥有多个视图，匹配信号更强，更容易排除错误的深度假设。这体现了“更多数据让问题变得更简单”的原则。

为了获得物体完整的三维模型（而不仅仅是单侧视图），我们可以从多个角度拍摄，分别进行稠密重建，然后将多个局部网格融合。另一种方法是**体素雕刻**：我们从一个包含整个物体的初始大体积（由许多小立方体，即体素构成）开始。对于每个相机视图中的每条光线，我们检查光线穿过的体素。如果某个体素在所有视图中都不满足颜色一致性，则认为它是空的空间并将其“雕刻”掉。最终剩下的体素就构成了物体的三维模型。

## 神经辐射场：隐式的三维场景表示

多视图立体视觉需要显式地建立像素间的对应关系。近年来，一种称为**神经渲染**的新方法取得了巨大成功，其代表工作是**神经辐射场**。它不需要显式对应关系，而是通过“分析-合成”的方式，利用重建损失隐式地学习一致性。

神经辐射场的输入同样是已标定的一系列图像，但其输出不是一个显式的网格或点云，而是一个连续的5D函数。这个函数表示为一个神经网络：

*   **输入**：一个三维空间位置 `(x, y, z)` 和一个观察方向 `(θ, φ)`。
*   **输出**：在该位置、从该方向看过去的颜色 `(r, g, b)` 和体密度 `σ`。

体密度 `σ` 可以理解为该位置存在物质的“可能性”或“不透明度”。这是一个**连续的体素化表示**，你可以想象空间充满了无数微小的、具有不同颜色和透明度的立方体。

这个表示与计算机图形学中的**全光函数**概念紧密相连。全光函数描述了在任意时间、任意空间位置、朝任意方向、任意波长的光强度，它完整地定义了所有可见的外观。神经辐射场可以看作是对全光函数在静态场景、RGB颜色空间下的一个5D近似建模。

神经辐射场的优化过程如下：

1.  我们有一个已训练好的神经网络，它定义了上述的5D函数。
2.  对于训练集中的每一张图像，我们知道相机姿态。我们可以从相机中心向每个像素发射一条光线。
3.  沿着每条光线，采样一系列三维点。
4.  将每个采样点的坐标和光线方向输入神经网络，得到该点的颜色和密度。
5.  利用**体渲染**公式，将这些采样点的颜色和密度沿着光线积分，合成出该像素的最终预测颜色。
6.  计算预测颜色与真实图像颜色的差异（如L2损失）。
7.  通过反向传播优化神经网络的所有参数，使得从所有训练视角渲染出来的图像都与真实图像尽可能一致。

一旦神经网络训练完成，我们就可以从任意新的视角，通过体渲染来生成该视角下的图像，从而实现逼真的新视图合成。神经辐射场成功地将场景的几何与外观（包括复杂的光照、反射）统一在一个连续的隐式表示中。

目前已有许多工具（如`COLMAP`用于运动恢复结构，`nerfstudio`用于神经辐射场）使得这些技术更容易被使用。

## 展望：端到端的深度学习革命

无论是传统的运动恢复结构、多视图立体视觉，还是神经辐射场，它们通常都遵循一个“从零开始”的流程：针对一个新场景，收集数据，然后进行优化重建。模型本身没有利用过去见过的海量场景的先验知识。

一个激动人心的新方向是**端到端的深度学习方法**。例如，`DUSt3R` 等工作表明，我们可以用海量的图像对及其对应的三维数据来训练一个庞大的Transformer模型。这个模型直接学习从一对（或多张）图像预测出在统一坐标系下的密集三维点云。在这个过程中，相机标定、特征匹配、三角测量等传统步骤所蕴含的约束，被模型通过数据驱动的方式隐式地学会了。这预示着三维重建领域可能正迎来一场类似图像识别领域由深度学习引发的革命。

## 总结

本节课中我们一起学习了三维重建的核心技术路线：
1.  **运动恢复结构**：从多视图图像中同时恢复稀疏三维点云和相机姿态，核心是优化重投影误差。
2.  **多视图立体视觉**：在已知相机姿态的基础上，通过多视图匹配获取稠密的三维模型。
3.  **神经辐射场**：用连续的神经隐式函数表示场景，通过体渲染和优化实现高质量的新视图合成，无需显式几何。
4.  **未来趋势**：利用大规模数据预训练的端到端模型，正在改变传统三维重建的范式。

从显式几何重建到隐式神经表示，再到数据驱动的端到端学习，三维计算机视觉正在不断融合新思想，变得更强大、更智能。
