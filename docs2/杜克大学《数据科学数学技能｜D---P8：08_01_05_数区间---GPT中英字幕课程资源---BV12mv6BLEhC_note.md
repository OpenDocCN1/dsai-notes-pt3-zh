# 📊 课程08：数区间与区间表示法

在本节课中，我们将学习实数线上的区间概念，以及如何用不同的符号表示这些区间。区间是数据科学中描述数值范围的基础工具。

---

## 实数线与无限集合

![](img/402bbeb601e796bce45fe229b5ec88c2_1.png)

我们之前讨论过有限集合，但实数线本身是一个无限集合，它包含无穷多个元素。实数线有许多子集，这些子集同样也是无限大的。

![](img/402bbeb601e796bce45fe229b5ec88c2_3.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_4.png)

让我们直接开始。请看这个符号：**[2, 3.1]**。这是一个无限集合，但它有有限的边界。接下来我们将描述这个集合的含义。

![](img/402bbeb601e796bce45fe229b5ec88c2_6.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_8.png)

这个区间等于满足以下两个条件的所有实数 **x** 的集合：
1.  **x ≥ 2**
2.  **x ≤ 3.1**

![](img/402bbeb601e796bce45fe229b5ec88c2_9.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_11.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_13.png)

换句话说，在实数线上画出这个区间：这里是2，这里是3.1。**x** 被限制在这两个边界之间，并且可以等于边界值。

![](img/402bbeb601e796bce45fe229b5ec88c2_15.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_17.png)

**x** 可以是任何满足 **2 ≤ x ≤ 3.1** 的数。

![](img/402bbeb601e796bce45fe229b5ec88c2_19.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_21.png)

以下是该区间内的一些例子：
*   **2.3** 在区间内，因为 2 ≤ 2.3 ≤ 3.1。
*   **3** 在区间内。
*   **3.1** 也在区间内。

![](img/402bbeb601e796bce45fe229b5ec88c2_23.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_25.png)

但是，**1** 不在区间 **[2, 3.1]** 内，因为 1 不小于或等于 2（尽管它确实小于或等于 3.1）。

![](img/402bbeb601e796bce45fe229b5ec88c2_27.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_29.png)

这就是一个**闭区间**。

![](img/402bbeb601e796bce45fe229b5ec88c2_31.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_32.png)

## 开区间

![](img/402bbeb601e796bce45fe229b5ec88c2_36.png)

上一节我们介绍了包含端点的闭区间。现在，让我们看看另一种形式。

![](img/402bbeb601e796bce45fe229b5ec88c2_38.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_40.png)

假设我给你 **(5, 8)**，这里我用圆括号代替了方括号。这代表一个无限集合，即所有满足 **x > 5** 且 **x < 8** 的实数 **x** 的集合。

![](img/402bbeb601e796bce45fe229b5ec88c2_42.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_44.png)

我们这样表示：在数轴上，在5和8的位置画一个空心的小圆圈，然后取它们之间的所有点。

![](img/402bbeb601e796bce45fe229b5ec88c2_46.png)

这意味着你必须在5和8之间，但不能等于这两个端点。

![](img/402bbeb601e796bce45fe229b5ec88c2_48.png)

例如：
*   **5.5** 在开区间 (5, 8) 内。
*   **5.0001** 也在开区间 (5, 8) 内。
*   但是，**5** 不在开区间 (5, 8) 内，因为5不小于5（尽管它小于8）。

![](img/402bbeb601e796bce45fe229b5ec88c2_50.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_52.png)

你可能会想，闭区间 **[5, 8]** 和开区间 **(5, 8)** 有什么区别？它们恰好相差两个数：**5** 和 **8** 在闭区间内，但不在开区间内。

## 半开区间

![](img/402bbeb601e796bce45fe229b5ec88c2_58.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_60.png)

我们已经了解了闭区间和开区间。现在，我们来看介于两者之间的两种形式，称为**半开区间**。

![](img/402bbeb601e796bce45fe229b5ec88c2_62.png)

例如：**(-7.1, 15]**。你可能已经猜到了，左边是开区间符号，意味着使用严格不等式；右边是闭区间符号，意味着使用“小于或等于”。这是一个无限集合，包含所有满足 **-7.1 < x ≤ 15** 的实数 **x**。

![](img/402bbeb601e796bce45fe229b5ec88c2_63.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_65.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_67.png)

我们这样画：在 -7.1 处画一个空心点，在15处画一个实心点，然后取中间的所有部分。

![](img/402bbeb601e796bce45fe229b5ec88c2_69.png)

再看另一个例子：**[20, 20.3)**。这表示所有满足 **20 ≤ x < 20.3** 的实数 **x** 的集合。

![](img/402bbeb601e796bce45fe229b5ec88c2_71.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_73.png)

在数轴上画出来：在20处画一个实心点，在20.3处画一个空心点。

![](img/402bbeb601e796bce45fe229b5ec88c2_75.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_76.png)

这里有一个有趣的观点：从感觉上看，20到20.3这个区间在实数线上相比 -7.1 到 15 来说非常小。然而，它内部仍然包含无穷多个数。这就是实数线奇妙的地方，背后有深奥的数学原理。

## 无穷区间

![](img/402bbeb601e796bce45fe229b5ec88c2_82.png)

我们已经见过闭区间（如 [2, 3.1]）、开区间（如 (5, 8)）和两种半开区间（如 (-7.1, 15] 和 [20, 20.3)）。有时，第一种半开区间被称为“左开”，第二种被称为“右开”，但这并不太重要。

![](img/402bbeb601e796bce45fe229b5ec88c2_84.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_86.png)

现在，让我们看一种更特殊的形式。假设我们写 **[2, ∞)**。这里的圆括号表示无穷大不是一个可以“达到”的端点。这代表所有满足 **x ≥ 2** 的实数 **x** 的集合。你不需要写“小于无穷大”，因为每个数都小于无穷大。

![](img/402bbeb601e796bce45fe229b5ec88c2_88.png)

我们常在数轴上这样表示：标出0和2，然后从2开始向右画一条射线，表示一直延伸下去。这被称为**射线**。

![](img/402bbeb601e796bce45fe229b5ec88c2_90.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_91.png)

你也可以有 **(-∞, 7.1)** 这样的形式，它表示所有满足 **x < 7.1** 的实数 **x** 的集合。你应该明白这个意思了。

![](img/402bbeb601e796bce45fe229b5ec88c2_93.png)

## 与不等式代数的联系

![](img/402bbeb601e796bce45fe229b5ec88c2_99.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_101.png)

最后，让我们将区间与之前的不等式代数视频联系起来。

![](img/402bbeb601e796bce45fe229b5ec88c2_103.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_105.png)

我们已经熟悉这样的想法：如果有人要求你解方程 **x + 5 = 10**，你通过代数运算解得 **x = 5**。所以，**x = 5** 就是答案，一个数字就是答案。

![](img/402bbeb601e796bce45fe229b5ec88c2_107.png)

另一方面，假设有人给你以下问题：如果 **1 ≤ x + 5 < 10** 成立，告诉我关于 **x** 的所有信息。

![](img/402bbeb601e796bce45fe229b5ec88c2_109.png)

注意，这里答案不是一个单一的数字。例如，如果 **x = 4**，那么 4 + 5 = 9，9 小于10且大于等于1。但 **x = 3.9** 也成立。事实上，答案是一个区间。

![](img/402bbeb601e796bce45fe229b5ec88c2_111.png)

让我们对这个不等式做一点代数运算：从所有部分减去5。
*   从左边减去5：**1 - 5 = -4**
*   从中间减去5：**x + 5 - 5 = x**
*   从右边减去5：**10 - 5 = 5**

![](img/402bbeb601e796bce45fe229b5ec88c2_113.png)

于是我们得到：**-4 ≤ x < 5**

换句话说，第一个谜题的答案是，**x** 可以是这个范围内的任何值。只要 **x** 在左闭右开的半开区间 **[-4, 5)** 内，就满足原不等式。

## 总结

本节课中，我们一起学习了：
1.  **闭区间**（如 **[a, b]**）：包含两个端点，表示 **a ≤ x ≤ b**。
2.  **开区间**（如 **(a, b)**）：不包含两个端点，表示 **a < x < b**。
3.  **半开区间**（如 **(a, b]** 或 **[a, b)**）：只包含一个端点。
4.  **无穷区间**（如 **[a, ∞)** 或 **(-∞, b)**）：表示一端没有界限的区间。
5.  如何将解不等式得到的结果用区间表示，这是描述数值范围的有力工具。

![](img/402bbeb601e796bce45fe229b5ec88c2_115.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_116.png)

![](img/402bbeb601e796bce45fe229b5ec88c2_117.png)

理解这些不同的区间表示法，对于描述数据范围、定义函数域以及解决各种数学问题都至关重要。
