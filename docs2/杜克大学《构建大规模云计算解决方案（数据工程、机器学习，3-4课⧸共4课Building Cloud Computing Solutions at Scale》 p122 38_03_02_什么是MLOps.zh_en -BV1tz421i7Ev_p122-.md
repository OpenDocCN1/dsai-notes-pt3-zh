What is MLOs， It's a combination of the DevOs methodologies and machine learning。

 Why is DevOs such an important methodology， It is about operationalizing code in the old days a lot of times you would have a developer on a laptop pushing changes maybe in the middle of night causing chaos and eventually the standardization of best practices became Devops where you would have a build server that would test the code and automatically pushing into production So the same thing now is applying to machine learning。

 if you look at a lot of the machine learning that's done maybe it's a scientist or an academic and they're doing some kind of analytics in a laboratory somewhere and that style of development is really not a good fit for production and what machine learning operations does is take that Wild West mentality that that was common in the old days of development as well and merges it in with DevOs so really it's the operationalization。

Best practices of software development combined with machine learning that way when you deploy a model into production。

 you don't have to guess whether it's going to be successful。

 you can look at the impact that that model is going to have on the customer maybe look at the impact on the revenue that your company is generating and finally。

 you can also monitor things like data drift， for example。

 and look at whether the model needs to be retrained because the underlying data has shifted so much。

 so MLOs is here to stay and it's a best practice that will get into a little bit more in this following videos。
