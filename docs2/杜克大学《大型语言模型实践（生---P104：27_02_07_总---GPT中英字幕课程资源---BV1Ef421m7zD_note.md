## 部署流程回顾

上一节我们介绍了Azure机器学习工作室的具体操作，本节中我们来总结核心的部署步骤。

以下是部署模型到Azure的主要步骤序列：

1.  **创建资源**：在Azure机器学习工作室中初始化所需的工作区与计算资源。
2.  **选择模型**：从模型库或上传的模型文件中选定需要部署的特定模型。
3.  **部署模型**：将选定的模型部署到指定的计算目标（如Azure容器实例或Azure Kubernetes服务）。
4.  **使用HTTP API**：模型部署成功后，获取评分终结点（Scoring Endpoint）并通过发送HTTP POST请求来调用模型。一个简单的Python请求示例如下：
    ```python
    import requests
    import json

    url = ‘你的模型终结点URL’
    headers = {‘Content-Type’: ‘application/json’}
    data = {“input_data”: “你的输入数据”}

    response = requests.post(url, headers=headers, data=json.dumps(data))
    print(response.json())
    ```

## 部署挑战与应对策略

整个部署流程的实现，依赖于你是否拥有实际部署这些模型所需的配额。云环境，特别是Azure平台，变化迅速。对GPU资源的需求巨大，有时配额和资源可用性会成为棘手问题。

不过，我们探讨了一些可以缓解此问题的策略，这些策略能在你尝试部署模型时提供一定的灵活性。以下是关键应对措施：

*   **提前规划与申请**：在项目开始前，评估所需GPU类型与数量，并通过Azure支持渠道提前申请增加配额。
*   **选择替代SKU**：如果首选GPU虚拟机系列（如`NCas_T4_v3`）配额不足，可以尝试功能类似的其他系列（如`NC_A100`系列，若有配额）。
*   **利用不同区域**：Azure各数据中心的资源可用性不同。尝试在多个区域创建资源，可能在某些区域有可用配额。
*   **考虑低优先级虚拟机**：对于非紧急或可中断的工作负载，使用低优先级（Spot）虚拟机可以显著降低成本并可能提高资源获取成功率。

本节课中我们一起学习了在Azure上部署机器学习模型的完整流程，并重点讨论了因GPU高需求导致的配额与可用性挑战及其应对策略。理解这些步骤和潜在问题，将帮助您更顺利地在云平台上进行模型部署与集成。
