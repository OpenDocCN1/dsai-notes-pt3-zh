## 小于与大于

![](img/192154badd7dd6e6b8f30e4d78e57df8_13.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_15.png)

首先，让我们在实数轴上理解“小于”的含义。

![](img/192154badd7dd6e6b8f30e4d78e57df8_17.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_19.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_21.png)

假设这是实数轴，这里是零点，这里是数字2，这里是数字3.1。

![](img/192154badd7dd6e6b8f30e4d78e57df8_23.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_25.png)

考虑这个陈述：**2 < 3.1**。

![](img/192154badd7dd6e6b8f30e4d78e57df8_27.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_29.png)

这个指向左边的“<”符号，读作“小于”。

![](img/192154badd7dd6e6b8f30e4d78e57df8_30.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_32.png)

这个陈述“2小于3.1”意味着：在实数轴R上，数字2位于数字3.1的**左侧**。这确实是正确的，2在3.1的左边。

![](img/192154badd7dd6e6b8f30e4d78e57df8_34.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_36.png)

再比如，-11.78也小于3.1。事实上，-11.78同样位于3.1的左侧。

![](img/192154badd7dd6e6b8f30e4d78e57df8_37.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_39.png)

因此，一般来说，当我写 **a < b** 时，我的意思是：在实数轴上，无论a在哪里，b都必须在其右侧，即a在b的左边。

![](img/192154badd7dd6e6b8f30e4d78e57df8_40.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_42.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_44.png)

一个常见的误解是认为“a小于b”意味着a在数值上“更小”。当a和b都是正数时，这似乎说得通（比如2比3.1“小”）。但当a是负数时，这种说法就不准确了。例如，我不会说-11.78在通常意义上比3.1“小”，它只是在其左边。

![](img/192154badd7dd6e6b8f30e4d78e57df8_46.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_48.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_50.png)

当我们写 **3.1 > 2** 时，意思是：在实数轴上，3.1位于2的**右侧**。这是正确的。

![](img/192154badd7dd6e6b8f30e4d78e57df8_52.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_53.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_55.png)

事实上，**a < b** 为真，**当且仅当** **b > a** 也为真。这个“当且仅当”是一个有趣的数学符号，表示两者等价。

## “远小于”的概念

![](img/192154badd7dd6e6b8f30e4d78e57df8_57.png)

接下来是这个有趣的符号：**x << y**。

你几乎不会在正规的数学教科书中看到它，因为它不是一个严格的数学概念。但在数据科学中，你会经常看到它。它的真正含义是：**x 远小于 y**。

![](img/192154badd7dd6e6b8f30e4d78e57df8_59.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_60.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_61.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_62.png)

例如，“1远小于1百万”可能是一个合理的说法。我说“可能”，是因为没有真正的方法来判断这是真还是假。而像“2 < 3.1”这样的陈述，你可以判断真假。“远小于”更多是一种主观判断，但我们通常对其含义有共识。例如，1百万相对于1来说，通常被认为是“远大于”。

![](img/192154badd7dd6e6b8f30e4d78e57df8_64.png)

## 小于等于与大于等于

![](img/192154badd7dd6e6b8f30e4d78e57df8_66.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_68.png)

上一节我们介绍了“小于”和“大于”，本节我们来看看包含等号的情况。

这个陈述：**a ≤ b**。读作：a **小于或等于** b。

![](img/192154badd7dd6e6b8f30e4d78e57df8_70.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_72.png)

从书写上看，你先写小于号“<”，然后在下面加一条横线。从某种意义上说，你应该画两条线来表示“小于或等于”，但通常你看到的都是在小于号下加一条线。它的意思是：**a 小于 b，或者 a 等于 b**。这实际上就是一个简写。

![](img/192154badd7dd6e6b8f30e4d78e57df8_74.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_75.png)

在实数轴上，如果这里是b，那么 **a ≤ b** 意味着：要么a在b的左边（a < b），要么a正好在b的位置上（a = b）。

![](img/192154badd7dd6e6b8f30e4d78e57df8_77.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_79.png)

那么，我们如何判断一个像“a ≤ b”这样的具体陈述是否为真呢？让我们看几个例子。

![](img/192154badd7dd6e6b8f30e4d78e57df8_81.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_82.png)

假设有人说：**2 ≤ 3.1**。
我们相信他吗？这个人实际上是在说以下两个断言中至少有一个为真：
1.  2 < 3.1
2.  2 = 3.1
第一个断言为真，第二个为假。但合在一起，这个“或”关系的陈述为真。这是“或”的好处：只需满足一个条件即可。

![](img/192154badd7dd6e6b8f30e4d78e57df8_84.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_86.png)

另一方面，如果有人声称：**2 ≤ 2**。
这意味着：
1.  2 < 2
2.  2 = 2
第一个为假，第二个为真。合在一起，陈述为真。

![](img/192154badd7dd6e6b8f30e4d78e57df8_88.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_90.png)

再看一个我们会失败的例子：有人说 **2 ≤ 0.8**。
这意味着：
1.  2 < 0.8
2.  2 = 0.8
第一个为假，第二个也为假。因此，整个陈述为假。

![](img/192154badd7dd6e6b8f30e4d78e57df8_92.png)

![](img/192154badd7dd6e6b8f30e4d78e57df8_94.png)

本节课中，我们一起学习了不等式的基本概念。

![](img/192154badd7dd6e6b8f30e4d78e57df8_102.png)

我们学习了“小于”（<）、“大于”（>）、“小于等于”（≤）和“大于等于”（≥）这些严格数学概念的含义，它们都与数字在实数轴上的相对位置有关。

我们还了解了“远小于”（<<）的含义，这虽然不是一个严格的数学概念，但却是人们（尤其是在数据科学中）经常使用的直观表述。
