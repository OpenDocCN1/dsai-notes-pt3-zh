# 大型语言模型实践（高级数据工程、AWS、Databricks和本地LLM）：P91：使用CodeWhisperer CLI 🛠️

![](img/99165e09ee3b388b58e225e966f52a26_0.png)

在本节课中，我们将学习如何使用AWS CodeWhisperer的命令行界面（CLI）工具。我们将探索它如何帮助理解AWS命令、生成代码片段以及辅助完成日常开发任务。

## 概述

AWS CodeWhisperer CLI是一个强大的工具，它允许开发者使用自然语言与命令行交互，并智能地生成AWS服务相关的命令。本节将演示其核心功能，包括命令自动补全、自然语言翻译为Shell命令，以及作为AWS API的探索工具。

## 启动与基础使用

首先，我们需要在已安装AWS CodeWhisperer CLI的终端中启动它。

在终端中输入以下命令来启动工具：
```bash
code whisper ai start
```

启动后，我们可以使用自然语言向它提问。例如，输入“List files”，工具会将其翻译为Shell命令 `ls -l`。这对于不熟悉Shell命令的用户尤其方便。

启动后，界面会提供一个菜单，允许我们执行命令、编辑命令、重新生成答案、提出新问题或取消操作。

现在，让我们执行生成的 `ls -l` 命令。

## AWS命令自动补全

上一节我们体验了基础的自然语言翻译功能。本节中我们来看看CodeWhisperer CLI一个强大的特性：针对AWS命令的智能自动补全。

由于此工具由AWS开发，它对AWS命令有出色的自动补全支持。例如，输入 `aws s3` 后，工具会自动列出所有可用的S3相关命令。

这非常有用，因为查阅官方文档通常很耗时。我们可以利用这种探索式的方法快速了解可执行的操作。

继续输入命令，例如 `aws s3 ls`，即可查看所有的S3存储桶。

这个功能不仅限于S3服务。输入 `aws ec2` 等前缀同样有效。这是一种极佳的方式来理解AWS各服务的API，无论你使用的是Ruby、Python还是其他语言。我认为这是该工具最有价值的初始用途之一。

## 生成工作流命令

除了自动补全，CodeWhisperer CLI还能帮助我们构思新的工作流程。

以下是它作为工作流生成器的一个例子。假设我们想将本地文件复制到S3存储桶。

我们可以输入一个自然语言请求，例如：“copy files from downloads to a S3 bucket in my account”。

工具会生成一个接近我们需求的命令。虽然可能不完全精确，但它提供了一个极佳的起点。如果需要，我们可以将生成的命令复制到编辑器中进一步调整。

这个功能也是一个AWS命令的“灵感生成器”。例如，你可能之前不知道可以使用递归复制命令。

## 与复杂AWS服务交互

我们已看到工具处理基础命令和生成工作流的能力。接下来，我们探索它如何协助与更复杂的AWS服务进行交互，例如DynamoDB。

从命令行操作DynamoDB可能较为复杂。CodeWhisperer CLI可以简化这个过程。

例如，输入：“list all dynamo DB tables”。工具会生成对应的AWS CLI命令 `aws dynamodb list-tables`。

执行该命令，我们可以看到当前账户下的DynamoDB表，例如一个名为“music”的表。

如果我们想向这个表添加一个项目，可以继续提问。例如：“Add the term Classical to my Dynamo DB table Music”。

工具生成的命令可能不是完全准确或完美的，但它提供了一种文档式的起点。此时，我们可以将这些命令分步复制到更专业的编程环境中去执行和调试。

## 总结

本节课中我们一起学习了AWS CodeWhisperer CLI的核心用途。总而言之，该工具的优点是：
*   **出色的自动补全**：帮助你洞察AWS命令的工作方式。
*   **生成一次性命令**：协助处理常规的批处理或Shell任务。
*   **提供灵感和起点**：作为探索AWS API和生成命令原型的有效工具。
