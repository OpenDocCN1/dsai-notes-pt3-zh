首先，让我们回顾一下等式的代数运算。我们这样做是为了求解未知数 `X`。

以下是等式运算的两个基本规则：

![](img/15fbcf457a32fbcda9738cb8879376fa_30.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_31.png)

1.  **等式两边加上或减去同一个数**：如果 `A = B`，那么 `A + C = B + C`。
2.  **等式两边乘以或除以同一个非零数**：如果 `A = B` 且 `C ≠ 0`，那么 `C × A = C × B`。

![](img/15fbcf457a32fbcda9738cb8879376fa_33.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_35.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_36.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_38.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_40.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_42.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_43.png)

这些规则使我们能够解方程。例如，对于方程 `x + 3 = 10`，我们可以在两边减去 `3` 来求解 `x`：
```
x + 3 - 3 = 10 - 3
x = 7
```

现在，让我们转向不等式。对于不等式，加减法规则与等式类似。

![](img/15fbcf457a32fbcda9738cb8879376fa_61.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_63.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_65.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_67.png)

**不等式两边加上或减去同一个数**：如果 `A < B`，那么对于任意数 `C`，都有 `A + C < B + C`。

![](img/15fbcf457a32fbcda9738cb8879376fa_69.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_70.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_71.png)

这个规则允许我们像处理等式一样处理不等式。例如，对于不等式 `x + 3 < 10`，我们可以在两边减去 `3`：
```
x + 3 - 3 < 10 - 3
x < 7
```
这意味着 `x` 可以是任何小于 `7` 的数。

![](img/15fbcf457a32fbcda9738cb8879376fa_73.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_75.png)

然而，当涉及到乘法时，不等式有一个非常重要的注意事项。

以下是乘法规则：

![](img/15fbcf457a32fbcda9738cb8879376fa_83.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_85.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_87.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_89.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_91.png)

*   如果 `A < B`，且 `C > 0`（正数），那么 `A × C < B × C`。
*   如果 `A < B`，且 `C < 0`（负数），那么 `A × C > B × C`。**此时必须翻转不等号的方向。**

![](img/15fbcf457a32fbcda9738cb8879376fa_93.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_94.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_96.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_98.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_100.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_102.png)

![](img/15fbcf457a32fbcda9738cb8879376fa_103.png)

让我们看一个例子。假设我们有不等式 `-2x < 10`。为了求解 `x`，我们需要在两边乘以 `-1/2`。因为乘的是负数，我们必须翻转不等号：
```
(-1/2) × (-2x) > (-1/2) × 10
x > -5
```
这意味着 `x` 可以是任何大于 `-5` 的数。

本节课中我们一起学习了不等式的代数运算。关键要点是：对不等式进行加减运算时，规则与等式相同；但当不等式两边乘以或除以一个**负数**时，**必须记得翻转不等号的方向**。这是处理不等式时唯一但非常重要的区别。
