## 概述：什么是探索性数据分析？

探索性数据分析是一种态度和一种灵活的状态，旨在发现数据中“不存在”的东西以及我们“认为存在”的东西。它没有一个固定的公式，但却是数据科学的核心部分。你可以将其想象为“拆箱”新数据：拿到数据后，你开始检查它，发现有趣的特征，识别问题，并思考如何修复或补充它。

在数据科学生命周期中，我们经常从获取一些混乱的数据开始，然后进入探索性数据分析阶段。这个阶段涉及转换数据、理解数据的好坏，并可能连接回获取更多数据的步骤。

以下是进行探索性数据分析时需要思考的五个关键方面，我们将在今天详细讨论：

*   **结构**：数据的形状和组织方式。
*   **粒度**：单行数据代表什么。
*   **范围**：数据是否反映了我试图研究的内容。
*   **时间性**：数据在时间上是如何定位的。
*   **可信度**：数据中是否存在缺陷或错误。

## 第一部分：理解数据结构 📐

上一节我们概述了EDA的五个方面，本节中我们来看看第一个方面：**结构**。在数据科学中，我们通常努力将数据转换为更“矩形”的格式，例如表格或矩阵，以便使用Pandas或SQL等工具进行处理。

### 矩形数据的两种形式

以下是两种常见的矩形数据形式：

1.  **表格**：例如Pandas的DataFrame、电子表格。它们的特点是列有名称，每列应包含相同类型的数据。我们使用Pandas或SQL来操作它们。
    *   公式：`DataFrame = 行(记录) × 列(变量)`

2.  **矩阵**：在建模时，我们经常需要将包含字符串和各种类型数据的表格，转换为可以构建模型的大型数值矩阵。
    *   代码：`model_matrix = df[['feature1', 'feature2']].values`

### 常见文件格式：CSV

CSV文件是一种非常常见的数据交换格式。它使用逗号分隔字段，使用换行符分隔记录。通常第一行是列标题。

**示例CSV结构：**
```
列名1,列名2,列名3
值A1,值B1,值C1
值A2,值B2,值C2
```

### 演示2：处理数据粒度与类型问题

检查数据，我们发现第一行是一个“总计”行。这是数据中常见的“汇总”粒度，与各州的数据粒度不同。我们需要理解并处理它。

更严重的问题是，数据看起来是字符串类型，而不是数字。这是因为数字中包含了千位分隔符逗号，在CSV文件中造成了混淆。

```python
print(tb_df.dtypes) # 查看列的数据类型
# 可能显示为 `object` (字符串)
```

我们需要在读取数据时告诉Pandas，这些逗号是千位分隔符。

```python
tb_df = pd.read_csv(
    'data/cdc_tb.csv',
    header=1,
    thousands=',', # 指定千位分隔符
)
tb_df = tb_df.rename(columns=column_rename_map)
print(tb_df.dtypes) # 现在应该显示为 `int64` 或 `float64`
```

现在我们可以正确地计算总和了。

### 演示3：获取外部数据与数据合并

要计算发病率（每10万人的病例数），我们不仅需要病例数，还需要各州的人口数据。公式如下：

**发病率 = (病例数 / 人口数) × 100,000**

这意味着我们需要获取人口数据。我们从美国人口普查网站下载了相关数据。加载和清理人口数据的过程与结核病数据类似：需要跳过说明行、处理列名、转换数据类型等。

```python
# 加载并清理2010年代人口数据（示例）
pop_df_2010s = pd.read_csv('data/census_2010s.csv', header=3, thousands=',')
# ... 进行一系列重命名、删除无关列、转换类型、删除缺失值等操作 ...
pop_df_2010s.head()
```

现在，我们有两个数据表：`tb_df`（结核病数据）和`pop_df_2010s`（人口数据）。为了计算发病率，我们需要将它们合并。

这引出了数据处理中的一个核心概念：**表连接**。我们通过**主键**和**外键**来关联不同表中的行。

*   **主键**：表中能唯一确定其他列值的一列或一组列。
*   **外键**：一个表中的一列或一组列，它引用了另一个表的主键。

在我们的例子中：
*   `tb_df` 表中的 `US jurisdiction` 列（州名）可以视为主键。
*   `pop_df_2010s` 表中的 `Geographic Area` 列（地理区域）也是主键。
*   我们需要通过这两个键将表连接起来。

在Pandas中，我们使用`merge`函数进行连接。

```python
# 将结核病数据与2019年人口数据合并
merged_df = pd.merge(
    left=tb_df,
    right=pop_df_2010s[['Geographic Area', '2019']], # 只选择需要的列
    left_on='US jurisdiction',
    right_on='Geographic Area',
    how='inner' # 内连接，只保留两边都匹配的行
)
# 合并后，可以删除重复的‘Geographic Area’列
merged_df = merged_df.drop(columns=['Geographic Area'])
merged_df.head()
```

我们使用`how=‘inner’`（内连接），这意味着只保留两个表中键值匹配的行。如果某个州在一个人口数据表中没有记录，它将被排除。有时你可能想保留所有结核病数据，即使没有对应人口数据，这时可以使用`how=‘left’`（左连接）。

现在，我们可以计算2019年的发病率了：

```python
merged_df['recomputed_incidence_2019'] = (
    merged_df['cases_2019'] / merged_df['2019'] * 100000
)
merged_df[['US jurisdiction', 'incidence_2019', 'recomputed_incidence_2019']].head()
```

计算出的结果可能与原始文章中的数字略有差异，这可能是因为使用了略微不同的人口估计值。这个过程展示了EDA中验证和复现计算的重要性。

## 第三部分：其他数据格式与变量类型 📄

### 其他文件格式

除了CSV，你还会遇到其他格式：

*   **TSV**：制表符分隔值文件，用制表符`\t`代替逗号。
*   **JSON**：JavaScript对象表示法，在Web开发中非常普遍。它类似于Python的字典，可以表示嵌套的、非矩形的数据。Pandas的`read_json`可以处理一些JSON，但复杂的嵌套结构可能需要手动提取和转换。

```python

    covid_json = json.load(f)
# covid_json 是一个Python字典，可以从中提取数据并构建DataFrame
```

### 理解变量类型

在表格中，每一列代表一个**变量**。理解变量的类型至关重要，它影响我们如何分析和可视化数据。

变量类型有两个层面：
1.  **存储类型**：数据在计算机中是如何存储的（如`int`, `float`, `object`）。通过`df.dtypes`查看。
2.  **概念类型**：我们如何从语义上解释这个变量。这是我们更关心的。

概念类型主要分为两大类：

*   **定量变量**：表示数值。
    *   **连续型**：可以在给定范围内取任何值（如温度、价格）。
    *   **离散型**：只能取特定的整数值（如兄弟姐妹数量、受教育年数）。
*   **定性变量**：表示类别。
    *   **名义型**：类别没有顺序（如州名、头发颜色、种族）。
    *   **有序型**：类别有顺序，但差值无意义（如衬衫尺码S/M/L、满意度评级1-5星）。

**思考练习：** 以下变量属于哪种概念类型？
*   CO2浓度 (ppm)：定量连续
*   兄弟姐妹数量：定量离散
*   GPA成绩：定量连续
*   收入等级（低/中/高）：定性有序
*   邮政编码：定性名义（尽管是数字，但不进行数学运算）
*   Yelp星级评分：通常视为**定性有序**。虽然我们常用平均值（如4.7星），但星级之间的心理差距可能并不相等，因此严格来说，计算平均值是将它当作定量离散变量来处理，这是一种简化。
