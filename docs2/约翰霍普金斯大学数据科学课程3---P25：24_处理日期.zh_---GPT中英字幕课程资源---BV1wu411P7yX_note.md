# 课程3：获取和清理数据｜P25：处理日期 📅

在本节课中，我们将要学习如何在R语言中处理日期数据。日期数据有时会有些棘手，因为它们具有各种特性，例如在一周或一个月结束后重新开始计数。我们将从基础函数开始，逐步介绍如何创建、转换、格式化日期，并利用`lubridate`包简化操作。

## 概述

日期数据是数据分析中的常见类型，但因其格式多样且包含时间信息，处理起来可能比较复杂。本节将介绍R中处理日期的核心函数和技巧。

## 1. 基础日期函数

![](img/146b57bbe7db2f3b722417d4e5c3a004_8.png)

首先，我们从最简单的`date()`函数开始。这个函数返回当前的系统日期和时间。

```r
current_time <- date()
```

该变量的类别实际上是字符型。`date()`函数返回一个给出日期和时间的字符。

![](img/146b57bbe7db2f3b722417d4e5c3a004_10.png)

```r
class(current_time)
```

![](img/146b57bbe7db2f3b722417d4e5c3a004_11.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_12.png)

## 2. `Sys.Date()`函数

![](img/146b57bbe7db2f3b722417d4e5c3a004_14.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_15.png)

然而，情况并非总是如此简单。例如，使用`Sys.Date()`函数会得到一个看起来像日期的对象，但不包含时间。

```r
today <- Sys.Date()
class(today)
```

这个变量的类别是`Date`。`Date`类变量具有一些不同的属性，使其在分析日期数据时更方便，但在某些方面比处理纯文本文件更复杂。

## 3. 格式化日期

![](img/146b57bbe7db2f3b722417d4e5c3a004_17.png)

我们可能想做的第一件事是将日期重新格式化为不同的样式。这时可以使用`format()`函数。

![](img/146b57bbe7db2f3b722417d4e5c3a004_18.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_19.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_20.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_21.png)

以下是使用`format()`函数的一个例子，我们将日期格式化为“星期缩写 月份缩写 日期”的形式。

![](img/146b57bbe7db2f3b722417d4e5c3a004_22.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_23.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_24.png)

```r
formatted_date <- format(today, "%a %b %d")
```

![](img/146b57bbe7db2f3b722417d4e5c3a004_25.png)

你可以使用不同的字符组合来获得所需的格式。例如：
*   `%d`：日期（数字）
*   `%a`：星期缩写
*   `%A`：星期全称
*   `%m`：月份（数字，01-12）
*   `%b`：月份缩写
*   `%B`：月份全称
*   `%Y`：四位年份

利用这些，你可以将日期转换成任何视觉上清晰美观的格式。

![](img/146b57bbe7db2f3b722417d4e5c3a004_27.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_28.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_29.png)

## 4. 将字符转换为日期

你也可以将字符向量转换为日期。以下是一个包含多个日期的字符向量。

```r
date_strings <- c("January 10, 2012", "December 9, 2011", "March 25, 2013")
```

我们可以使用`as.Date()`函数将它们转换为日期，需要指定日期的格式。

![](img/146b57bbe7db2f3b722417d4e5c3a004_31.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_32.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_33.png)

```r
converted_dates <- as.Date(date_strings, format = "%B %d, %Y")
```

![](img/146b57bbe7db2f3b722417d4e5c3a004_34.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_35.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_36.png)

这样做的好处是，转换后的日期对象可以进行计算和操作。例如，可以计算两个日期之间的差值。

![](img/146b57bbe7db2f3b722417d4e5c3a004_37.png)

```r
time_diff <- converted_dates[1] - converted_dates[2]
```

这个差值是一个`difftime`对象，表示天数差。你可以轻松地将其转换为数值变量，从而量化日期之间的间隔。

## 5. 提取日期信息

![](img/146b57bbe7db2f3b722417d4e5c3a004_39.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_40.png)

你可以从日期对象中提取各种信息，例如星期几、月份，或将其转换为儒略日。

![](img/146b57bbe7db2f3b722417d4e5c3a004_41.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_42.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_43.png)

以下是相关函数：
*   `weekdays()`：获取星期几
*   `months()`：获取月份
*   `julian()`：转换为儒略日（即自某个原点日期以来的天数）

![](img/146b57bbe7db2f3b722417d4e5c3a004_44.png)

```r
weekday <- weekdays(today)
month <- months(today)
julian_day <- julian(today)
```

默认情况下，儒略日的原点是1970年1月1日。`julian()`函数的结果就是自该原点日期以来的天数。

## 6. 使用`lubridate`包

![](img/146b57bbe7db2f3b722417d4e5c3a004_46.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_47.png)

`lubridate`包非常实用，它使处理日期变得比使用`as.Date()`等基础函数更简单。

![](img/146b57bbe7db2f3b722417d4e5c3a004_48.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_49.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_50.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_51.png)

加载`lubridate`库后，你可以轻松地将数字或字符转换为日期，而无需预先指定复杂的格式。

![](img/146b57bbe7db2f3b722417d4e5c3a004_52.png)

```r
library(lubridate)
```

`lubridate`提供了一系列以日期组成部分命名的函数，如`ymd()`、`mdy()`、`dmy()`等，它们能智能解析常见格式的日期字符串。

![](img/146b57bbe7db2f3b722417d4e5c3a004_54.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_55.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_56.png)

```r
date1 <- ymd("20140108")      # 年-月-日
date2 <- mdy("08/04/2013")    # 月-日-年
date3 <- dmy("03-04-2013")    # 日-月-年
```

![](img/146b57bbe7db2f3b722417d4e5c3a004_58.png)

它的优势在于，你无需在将字符转换为日期前进行复杂的格式化。

## 7. 处理日期时间

![](img/146b57bbe7db2f3b722417d4e5c3a004_60.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_61.png)

`lubridate`同样可以处理包含时间的日期时间数据。函数名通过添加`_hms`、`_hm`等后缀来指定时间部分。

![](img/146b57bbe7db2f3b722417d4e5c3a004_62.png)

```r
datetime1 <- ymd_hms("2011-08-03 10:15:25")
```

![](img/146b57bbe7db2f3b722417d4e5c3a004_64.png)

如果时间部分的顺序不同，可以使用对应的函数，例如`ymd_hms`（时-分-秒）或`ymd_smh`（秒-分-时）。

```r
# 假设时间是“秒-分-时”的顺序
datetime2 <- ymd_smh("2011-08-03 25:15:10")
```

![](img/146b57bbe7db2f3b722417d4e5c3a004_66.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_67.png)

## 8. 设置时区

![](img/146b57bbe7db2f3b722417d4e5c3a004_70.png)

你还可以在创建日期时间对象时设置时区。

![](img/146b57bbe7db2f3b722417d4e5c3a004_71.png)

datetime_tz <- ymd_hms("2011-08-03 10:15:25", tz = "Pacific/Auckland")

## 9. 函数语法差异

![](img/146b57bbe7db2f3b722417d4e5c3a004_73.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_74.png)

需要注意的是，某些函数在基础R和`lubridate`包中的语法略有不同。

![](img/146b57bbe7db2f3b722417d4e5c3a004_75.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_76.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_77.png)

![](img/146b57bbe7db2f3b722417d4e5c3a004_78.png)

例如，在基础R中，我们使用`weekdays()`来获取星期几。而在`lubridate`中，对应的函数是`wday()`。

```r
# 基础R
weekdays(today)

# lubridate
day_of_week_num <- wday(today)
day_of_week_name <- wday(today, label = TRUE) # 设置label=TRUE得到缩写名称
```
`wday(today)`默认返回一个数字（例如3代表星期二）。设置`label = TRUE`会返回因子的水平值，即星期几的缩写或全称。
