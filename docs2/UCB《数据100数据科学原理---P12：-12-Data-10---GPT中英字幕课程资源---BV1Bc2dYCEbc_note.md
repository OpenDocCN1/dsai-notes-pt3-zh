# 课程12：多元线性回归与普通最小二乘法 📊

![](img/3bc08febc7648ea8e0631d43334e1199_1.png)

在本节课中，我们将学习多元线性回归模型，也称为普通最小二乘法。我们将探讨如何将多个特征结合起来进行线性预测，并从几何角度理解模型的工作原理。最后，我们将通过一个NBA球员数据的实例，演示如何应用这些概念。

---

## 模型概述

多元线性回归模型用于根据多个输入特征预测一个输出值。其核心思想是，预测值是各个特征的加权和，再加上一个偏置项。

模型的预测公式如下：

**公式：**
`y_hat = θ₀ + θ₁ * x₁ + θ₂ * x₂ + ... + θₚ * xₚ`

其中：
*   `y_hat` 是预测值。
*   `θ₀` 是偏置项。
*   `θ₁` 到 `θₚ` 是与 `p` 个特征 `x₁` 到 `xₚ` 对应的权重参数。

这个模型被称为“线性”的，是因为它对于参数 `θ` 是线性的组合，每个参数都被一个特征值缩放。

---

## 矩阵表示法

为了更高效地处理多个数据点，我们将模型表示为矩阵运算。

首先，我们为每个数据点添加一个值为1的“偏置”特征，这样可以将 `θ₀` 也纳入参数向量。对于一个有 `n` 个观测值和 `p` 个特征的数据集，我们构建一个**设计矩阵** `X`。

**设计矩阵 `X` 的维度：** `n` 行 × (`p` + 1) 列。其中一列全为1（对应偏置项），其余列对应原始特征。

**参数向量 `θ` 的维度：** (`p` + 1) 行 × 1 列。

**预测向量 `y_hat` 的维度：** `n` 行 × 1 列。

整个模型的预测可以简洁地写为：

**公式：**
`y_hat = X * θ`

---

## 损失函数：均方误差

我们使用均方误差作为损失函数，来衡量预测值与真实值之间的差距。

均方误差可以表示为残差向量 `e = y - y_hat` 的 L2 范数平方的平均值。

**公式：**
`MSE(θ) = (1/n) * || y - Xθ ||²₂`

其中，`|| · ||₂` 表示向量的 L2 范数（即欧几里得长度）。最小化 MSE 等价于最小化预测向量 `y_hat` 与真实向量 `y` 之间的距离。

---

## 几何视角与最优解

上一节我们定义了模型和损失函数，本节中我们来看看如何找到最优的参数 `θ`。

从几何角度看，所有可能的预测 `y_hat = Xθ` 构成了设计矩阵 `X` 的列空间（一个子空间）。我们的目标是在这个子空间中找到离真实值向量 `y` 最近的点。

这个最近的点就是 `y` 在列空间上的**正交投影**。在最优解处，残差向量 `e = y - y_hat` 必须与列空间中的每一个向量（即 `X` 的每一列）都垂直（正交）。

这个正交条件引出了**正规方程**：

**公式：**
`Xᵀ * X * θ_hat = Xᵀ * y`

其中 `θ_hat` 是我们要求的最优参数。

假设矩阵 `Xᵀ * X` 是可逆的，我们可以解出 `θ_hat`：

**核心解公式：**
`θ_hat = (Xᵀ * X)⁻¹ * Xᵀ * y`

这个公式给出了普通最小二乘法的直接解析解。

## 实例演示：预测NBA球员得分

现在，让我们将理论应用于实践。我们将使用2018-19赛季的NBA数据集，根据球员的场均两分球命中数、助攻数和三分球出手数来预测其场均得分。

以下是构建和评估模型的步骤：

1.  **准备数据**：从数据集中提取三个特征列和目标列（得分）。
2.  **构建设计矩阵**：添加一列全为1的偏置项，形成设计矩阵 `X`。
3.  **计算最优参数**：使用公式 `θ_hat = (Xᵀ * X)⁻¹ * Xᵀ * y` 计算。
4.  **进行预测**：计算 `y_hat = X * θ_hat`。
5.  **评估模型**：计算均方误差和多重 R² 分数。

**代码示例（概念）：**
```python
import numpy as np
# 假设 X_features 是原始特征矩阵 (n x p)，y 是目标向量
# 1. 添加偏置项
X = np.hstack([np.ones((X_features.shape[0], 1)), X_features])
# 2. 计算 OLS 最优参数
theta_hat = np.linalg.inv(X.T @ X) @ X.T @ y
# 3. 预测
y_pred = X @ theta_hat
# 4. 计算均方误差
mse = np.mean((y - y_pred) ** 2)
```

通过比较使用不同特征组合时的多重 R² 分数，我们可以评估每个特征对解释数据方差的重要性。

## 模型性质总结

本节课中我们一起学习了多元线性回归与普通最小二乘法。最后，我们来总结一下该模型的一些重要性质：

*   **残差性质**：在最优解下，残差向量与设计矩阵 `X` 的每一列正交。这意味着 `Xᵀ * e = 0`。
*   **残差和为零**：如果模型包含偏置项 `θ₀`，则所有残差之和为0。这解释了为什么我们使用残差的平方而不是直接求和作为损失。
*   **解的唯一性**：当 `X` 的列是线性无关（即 `X` 是列满秩）时，`Xᵀ * X` 可逆，此时普通最小二乘解 `θ_hat` 是唯一的。如果特征之间存在线性依赖，则会有多个解。
