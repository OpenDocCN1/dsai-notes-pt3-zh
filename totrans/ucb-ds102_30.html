Motivation and Introduction¶

What is a Concentration Inequality?¶

Concentration inequalities provide a way to quantify how likely a random variable is to be in the tail of its distribution (that is, the parts of the distribution on the far ends, away from the mean). We often will write these inequalities involving the distance between a random variable XXX and its mean E[X]E[X]E[X]. For example, consider the following inequality:

P(∣X−E[X]∣≥t)≤ϵP(|X-E[X]|\geq t) \leq \epsilonP(∣X−E[X]∣≥t)≤ϵ
(1)

This looks at the distance between random variable XXX and its mean E[x]E[x]E[x], and says that the probability of that distance being large (specifically, larger than some threshold ttt) is small (specifically, smaller than some value δ\deltaδ).

Such inequalities are useful in understanding the behavior of arbitrary random variables, as well as algorithms that use random variables. For example, consider a sample of i.i.d. random variables X1,…,XnX_1, \ldots, X_nX1​,…,Xn​, and their sample mean:

Y=1n∑iXiY = \frac{1}{n} \sum_i X_iY=n1​i∑​Xi​
(2)

If we’re using YYY to estimate the mean of XiX_iXi​, then we can already guarantee that the average value of YYY will be the correct answer: E[Y]=E[(1/n)∑iXi]=E[Xi]E[Y] = E\left[(1/n) \sum_i X_i\right] = E[X_i]E[Y]=E[(1/n)∑i​Xi​]=E[Xi​]. But this statement doesn’t tell us anything about our chance of being far off from the correct answer. Is it possible that YYY could be very far away from E[Xi]E[X_i]E[Xi​]? How likely is such a thing to happen?

Concentration inequalities provide the answers to such questions: if we can guarantee that

P(∣Y−E[Xi]∣≥t)≤ϵ,P(|Y - E[X_i]| \geq t) \leq \epsilon,P(∣Y−E[Xi​]∣≥t)≤ϵ,
(3)

then we can have more confidence in our result. Suppose that the above statement holds for t=1t=1t=1 and ϵ=0.01\epsilon=0.01ϵ=0.01. Then we can clearly state “YYY is very likely to be within 1 of the true mean E[Xi]E[X_i]E[Xi​]: the probability that it’s further away is less than 1%1\%1%.”

If the XiX_iXi​ are drawn from a well-known distribution such as the Gaussian, binomial, Poisson, etc., then we can compute such probabilities exactly, and we have no need for a concentration inequality. These inequalities are useful when we have less information about a random variable, and we want to make strong statements that hold regardless of the specific distribution.

Example: One-sided Upper Tail Bound¶

We’ll start by looking at the upper tail bound for a random variable XXX with unknown density fff and corresponding CDF FFF. Specifically, we want to find a probabilistic upper bound α\alphaα such that most of the time, XXX takes on values less than α\alphaα. Formally, we can write this one of two ways:

P(X≥α)≤ϵP(X<α)≥1−ϵ\begin{align*} P(X \geq \alpha) &\leq \epsilon \\ P(X < \alpha) &\geq 1-\epsilon \end{align*}P(X≥α)P(X<α)​≤ϵ≥1−ϵ​
(4)

For small values of ϵ\epsilonϵ, we can interpret this statement as saying that we are confident that XXX will be below α\alphaα. For this reason, we’ll use the following terminology:

  • α\alphaα is our upper confidence bound,

  • ϵ\epsilonϵ is our failure probability, and

  • 1−ϵ1-\epsilon1−ϵ is our confidence level.

In general, we can express the bound as α(ϵ)\alpha(\epsilon)α(ϵ) to show the dependence explicitly: we specify some desired level of confidence (or failure probability), and find a bound that holds for that level. In practice, we want these bounds to be as small as possible: we can always choose a trivial bound at ∞\infty∞, but this isn’t useful to us. So, we want α(ϵ)\alpha(\epsilon)α(ϵ) to grow relatively slowly as a function of ϵ\epsilonϵ.

Suppose we choose ϵ=0.05\epsilon = 0.05ϵ=0.05, and we want a value of α(0.05)\alpha(0.05)α(0.05) that satisfies the inequality above. If fff and FFF were known, we could easily compute such a value by solving for α\alphaα (for this example, we’ll assume XXX is continuous so that P(X<α)=P(X≤α)P(X < \alpha) = P(X \leq \alpha)P(X<α)=P(X≤α)):

P(X≤α)≥1−ϵF(α)≥1−ϵα≥F−1(1−ϵ)\begin{align*} P(X \leq \alpha) &\geq 1-\epsilon \\ F(\alpha) &\geq 1 - \epsilon \\ \alpha &\geq F^{-1}(1-\epsilon) \end{align*}P(X≤α)F(α)α​≥1−ϵ≥1−ϵ≥F−1(1−ϵ)​
(5)

In other words, if we knew the CDF FFF (and therefore the inverse CDF F−1F^{-1}F−1), we could calculate α(0.05)=F−1(0.95)\alpha(0.05) = F^{-1}(0.95)α(0.05)=F−1(0.95).

What if we don’t know the CDF? If we don’t know anything at all about the random variable XXX, then we’re stuck: we can’t really make any statement about α\alphaα that would apply to any arbitrary random variable. But, we’ll see that if we make just a few assumptions, or just know a few things about XXX, then we can make some interesting statements.

Example: Sample Mean¶

One of the most common applications of concentration inequalities is to sample means. We’ll return to the example of a sequence of i.i.d. random variables X1,…,XnX_1, \ldots, X_nX1​,…,Xn​ with mean μ\muμ, and their sample mean Y=(1/n)∑XiY = (1/n)\sum X_iY=(1/n)∑Xi​.

Markov’s Inequality¶

We’ll start by assuming that XXX is nonnegative, and that we know its mean E[X]E[X]E[X]. Note that these are fairly weak assumptions: if we know that E[X]=10E[X] = 10E[X]=10 and that XXX is nonnegative, there are an enormous number of possible densities for XXX! Markov’s inequality holds for all of them, and it tells us:

Markov’s inequality: For a nonnegative random variable XXX and bound α>0\alpha > 0α>0, we have

P(X≥α)≤E[X]α.P(X \geq \alpha) \leq \frac{E[X]}{\alpha}.P(X≥α)≤αE[X]​.
(6)

Understanding properties of Markov’s inequality¶

Let’s use Markov’s inequality to derive a general upper confidence bound that will hold for any nonnegative random variable. If we want P(X≥α)≤ϵP(X \geq \alpha) \leq \epsilonP(X≥α)≤ϵ for a given value of ϵ\epsilonϵ (i.e., a desired confidence level / failure probability), then we have ϵ=E[X]/α\epsilon = E[X]/\alphaϵ=E[X]/α, or equivalently α=E[X]/ϵ\alpha = E[X]/\epsilonα=E[X]/ϵ. We can make some important observations about this bound:

  • As ϵ\epsilonϵ decreases, α\alphaα increases. Convince yourself that this makes sense: if we want our bound α\alphaα to have a very small probability of failing (i.e., to have a very small probability that the random variable takes on a value above the bound), then we must make the bound very large.

  • How fast does our bound increase as ϵ\epsilonϵ gets small? As we noted above, a good bound will increase relatively slowly. Unfortunately, Markov’s inequality provides a relatively poor bound: the bound increases as O(ϵ−1)O(\epsilon^{-1})O(ϵ−1), which for most random variables is not a very tight bound.

Example: Sample Mean with Markov’s Inequality¶

Given X1,…,XnX_1, \ldots, X_nX1​,…,Xn​ and their sample mean YYY, how well does Markov’s inequality answer the question of whether YYY can be far from the true mean μ\muμ?

P(Y−μ≥α)=P(Y≥μ+α)≤μμ+αP(Y - \mu \geq \alpha) = P(Y \geq \mu + \alpha) \leq \frac{\mu}{\mu+\alpha}P(Y−μ≥α)=P(Y≥μ+α)≤μ+αμ​
(7)

This is a remarkably poor bound! In particular, note that it doesn’t even improve as the number of samples nnn grows larger. If we were to ask for an upper confidence bound α(ϵ,n)\alpha(\epsilon, n)α(ϵ,n) at a given level of confidence ϵ\epsilonϵ for a given number of samples nnn, we would see that this bound also has no dependence on nnn: in other words, it remains the same regardless of how many samples we collect. This is contrary to our intuition about sample means: in general, we expect that the more independent samples we collect, the better our result should be. This is something we’ll look for in future inequalities.

Chebyshev’s inequality and higher moments¶

What if we use more information? Specifically, suppose we use both the mean and the variance. To do so, let’s consider a random variable XXX, for which we want to bound tail probabilities, and then the random variable Z=(X−E[X])2Z = (X-E[X])^2Z=(X−E[X])2. We can see that ZZZ is always nonnegative, and by the definition of variance, E[Z]=var(X)E[Z] = \mathrm{var}(X)E[Z]=var(X). So, if we apply Markov’s inequality to ZZZ, we arrive at Chebyshev’s inequality:

Chebyshev’s inequality: Consider a random variable XXX with known (finite) mean and variance. For any t>0t > 0t>0,

P(∣X−E[X]∣≥t)≤var(X)t2\mathbb{P}(\vert X - E[X] \vert \ge t) \le \frac{\mathrm{var}(X)}{t^2}P(∣X−E[X]∣≥t)≤t2var(X)​
(8)

Proof:

P(∣X−E[X]∣≥t)=P((X−E[X])2≥t2)=P(Z≥t2)≤E[Z]t2=var(X)t2■\begin{align*} P(\vert X - E[X] \vert \geq t) &= P((X - E[X])^2 \geq t^2) \\ &= P(Z \geq t^2) \\ &\leq \frac{E[Z]}{t^2} \\ &= \frac{\mathrm{var}(X)}{t^2} \blacksquare \end{align*}P(∣X−E[X]∣≥t)​=P((X−E[X])2≥t2)=P(Z≥t2)≤t2E[Z]​=t2var(X)​■​
(9)

Understanding properties of Chebyshev’s inequality¶

This tells us that the X is unlikely to be far away from its mean: the probability that the distance ∣X−E[X]∣|X-E[X]|∣X−E[X]∣ is large (specifically, larger than ttt), decreases proportional to var(X)(X)(X) and inversely proportional to t2t^2t2.

Let’s use Chebyshev’s inequality to derive a general upper confidence bound that will hold for any random variable with known mean and variance. If we want P(X≥α)≤ϵP(X \geq \alpha) \leq \epsilonP(X≥α)≤ϵ for a given value of ϵ\epsilonϵ, we need to do some algebra first before we can apply Chebyshev’s inequality.

P(X≥α)=P(X−E[X]≥α−E[X])≤P(∣X−E[X]∣≥α−E[X])≤var(X)(α−E[X])2,\begin{align*} P(X \geq \alpha) &= P(X - E[X] \geq \alpha - E[X]) \\ &\leq P(|X - E[X]| \geq \alpha - E[X]) \\ &\leq \frac{\mathrm{var}(X)}{(\alpha - E[X])^2}, \end{align*}P(X≥α)​=P(X−E[X]≥α−E[X])≤P(∣X−E[X]∣≥α−E[X])≤(α−E[X])2var(X)​,​
(10)

So, we have ϵ=var(X)(α−E[X])2\epsilon = \frac{\mathrm{var}(X)}{(\alpha - E[X])^2}ϵ=(α−E[X])2var(X)​. While we could use the quadratic formula to obtain an expression for α(ϵ)\alpha(\epsilon)α(ϵ), the most important observations here are:

  • The bound α(ϵ)\alpha(\epsilon)α(ϵ) is directly proportional to the variance of XXX

  • How fast does our bound increase as ϵ\epsilonϵ gets small? The bound α(ϵ)\alpha(\epsilon)α(ϵ) is proportional to ϵ−1/2\epsilon^{-1/2}ϵ−1/2 (i.e., it increases as O(ϵ−1/2)O(\epsilon^{-1/2})O(ϵ−1/2), which is a significant improvement over what we saw with Markov’s inequality. The question remains: can we do better?

Higher moment bounds¶

Chebyshev’s inequality uses the first and second moments (E[X]E[X]E[X] and E[X2]E[X^2]E[X2]). For any nonnegative random variable XXX and for any natural number kkk, we can apply Markov’s inequality to XkX^kXk, obtaining higher moment bounds:

P(X≥α)≤E[Xk]αk\mathbb{P}(X \geq \alpha) \leq \frac{E[X^k]}{\alpha^k}P(X≥α)≤αkE[Xk]​
(13)

Some important observations:

  • If we use this to find an upper confidence bound α(ϵ)\alpha(\epsilon)α(ϵ) as above, we can derive that the bound increases as O(ϵ−1/k)O(\epsilon^{-1/k})O(ϵ−1/k), which for large values of kkk can be very small.

  • Using such bounds requires additional information about the random variable XXX: in fact, if we knew exactly all the moments E[Xk]E[X^k]E[Xk] for k=1,2,…k = 1, 2, \ldotsk=1,2,…, then we would most likely also know the CDF.

Chernoff Bound¶

Since eλXe^{\lambda X}eλX is a nonnegative random variable, we can again use Markov’s inequality to find a bound:

P(X≥α)=P(E[eλX]≥eλα) ≤ E[eλX]eλα = MX(λ)eλαP(X \geq \alpha) = P(E[e^{\lambda X}] \geq e^{\lambda \alpha}) ~ \leq ~ \frac{E[e^{\lambda X}]}{e^{\lambda \alpha}} ~ = ~ \frac{M_X(\lambda)}{e^{\lambda \alpha}}P(X≥α)=P(E[eλX]≥eλα) ≤ eλαE[eλX]​ = eλαMX​(λ)​
(17)

This is a family of bounds, one for each positive λ\lambdaλ. To get the best possible one (i.e., the smallest), we should minimize over all nonnegative λ\lambdaλ:

P(X≥α) ≤ min⁡λ≥0MX(λ)eλαP(X \geq \alpha) ~ \leq ~ \min_{\lambda \ge 0} \frac{M_X(\lambda)}{e^{\lambda \alpha}}P(X≥α) ≤ λ≥0min​eλαMX​(λ)​
(18)

Some important observations:

  • This requires significantly more information about the distribution than the earlier two bounds we saw. Specifically, if we know all the moments of a distribution, in most cases we effectively know the distribution. But, as we’ll see shortly, it can still be useful if we can bound the MGF for an entire class of distributions: in that case, we can replace MX(λ)M_X(\lambda)MX​(λ) with an upper bound on it.

  • How fast does our bound increase as ϵ\epsilonϵ gets small? Solving for an upper confidence bound α(ϵ)\alpha(\epsilon)α(ϵ), we see that ϵ=MX(λ)eλα\epsilon = \frac{M_X(\lambda)}{e^{\lambda \alpha}}ϵ=eλαMX​(λ)​. So, if we can find a class of random variables where the MGF is known (or bounded, as in the previous observation), then we can place much tighter bounds on those random variables.

Bounding the probability for a given threshold¶

We now apply each of the bounds we’ve learned about to a Gaussian random variable with known mean μ\muμ and variance σ2\sigma^2σ2, X∼N(μ,σ2)X \sim \mathcal{N}(\mu, \sigma^2)X∼N(μ,σ2). For this example, we can also compute exact bounds and compare them.

We cannot use Markov’s inequality, since this random variable can take on negative values.

Because X−μX - \muX−μ is symmetric about zero, the Chebyshev bound for a single tail is:

P(X−μ≥t)=12P(∣X−μ∣≥t)≤σ22t2P(X - \mu \geq t) = \frac{1}{2}P(|X - \mu| \geq t) \leq \frac{\sigma^2}{2t^2}P(X−μ≥t)=21​P(∣X−μ∣≥t)≤2t2σ2​

min⁡λ≥0exp⁡(σ2λ22−λt)=exp⁡(min⁡λ≥0{σ2λ22−λt}).\min_{\lambda \geq 0} \exp \left( \frac{\sigma^2 \lambda^2}{2} - \lambda t \right) = \exp \left(\min_{\lambda \geq 0} \left\{\frac{\sigma^2 \lambda^2}{2} - \lambda t \right\} \right).λ≥0min​exp(2σ2λ2​−λt)=exp(λ≥0min​{2σ2λ2​−λt}).
(22)

The quantity in the exponent is a quadratic function f(λ)f(\lambda)f(λ), and can be minimized using the quadratic formula to get λ∗=tσ2\lambda^* = \frac{t}{\sigma^2}λ∗=σ2t​, and f(λ∗)=−t22σ2f(\lambda^*) = \frac{-t^2}{2\sigma^2}f(λ∗)=2σ2−t2​.

Putting everything together, we get

P(X−μ>t) ≤ exp⁡(−t22σ2)P(X-\mu > t) ~\leq ~\exp\left(-\frac{t^2}{2\sigma^2}\right)P(X−μ>t) ≤ exp(−2σ2t2​)
(23)

Bounding the threshold for a given probability¶

Suppose that instead of being given a threshold and asked for the probability of exceeding it, we instead want the opposite: we want to know, given a desired probability, a bound or threshold such that the probability of exceeding that bound is small. This is the upper confidence bound we described earlier. To simplify our calculations, and without loss of generality, we’ll assume that μ=0\mu = 0μ=0. If we go about computing this for the normal distribution, we find that:

  • As we saw before, the exact probability is F−1(1−ϵ)F^{-1}(1-\epsilon)F−1(1−ϵ).

It’s a bit silly to compute Chernoff and Chebyshev tail bounds this way for normal random variables, because we already know the true probabilities. Still, this helps us understand how good those bounds are, and we’ll see in the next section that we can apply these same bounds even in cases where we don’t know the MGF exactly.

Hoeffding’s Inequality¶

So far, we’ve seen that using the MGF of a random variable can give us excellent tail bounds. But, if we know the MGF exactly, then we also know the distribution of the random variable, and in that case we might as well use the CDF to find tail bounds. As we saw in the previous example, even the Chernoff bound was not as good as using the actual CDF.

In that case, what’s the point of the Chernoff bound? In many cases, we may not know the MGF, but we can bound it: in other words, we can find some function of λ\lambdaλ, h(λ)h(\lambda)h(λ), such that MX(λ)≤λ  ∀λM_X(\lambda) \leq \lambda ~ ~ \forall \lambdaMX​(λ)≤λ  ∀λ.

One such example is that of bounded random variables: that is, random variables that only take on values between some lower bound aaa and some upper bound bbb.

Hoeffding’s Lemma¶

Hoeffding’s lemma gives us an upper bound on the MGF for any bounded random variable. Specifically, given a random variable XXX with mean E[X]E[X]E[X] that is bounded between aaa and bbb, we have that

MX(λ)=E[eλX]≤exp⁡{λE[X]+λ2(b−a)28}M_X(\lambda) = E[e^{\lambda X}] \leq \exp\left\{\lambda E[X] + \frac{\lambda^2(b-a)^2}{8}\right\}MX​(λ)=E[eλX]≤exp{λE[X]+8λ2(b−a)2​}
(24)

Hoeffding’s Inequality¶

We could use Hoeffding’s lemma on any bounded random variable, in combination with Chernoff’s bound, to bound tail probabilities. For the rest of this section, we’ll focus on the specific case of sample means, which is what Hoeffding’s inequality is all about.

Let X1,X2,…,XnX_1 ,X_2, \ldots, X_nX1​,X2​,…,Xn​ be independent (but not necessarily identically distributed) random variables bounded between aaa and bbb. Then Hoeffding’s inequality states that:

P(1n∑i=1n(Xi−E[Xi])≥t)≤exp⁡(−2nt2(b−a)2)P(1n∑i=1n(Xi−E[Xi])≤−t)≤exp⁡(−2nt2(b−a)2).P\left(\frac{1}{n}\sum_{i=1}^n (X_i - \mathbb{E}[X_i]) \geq t\right) \leq \exp\left(-\frac{2nt^2}{(b-a)^2}\right) \\ P\left(\frac{1}{n}\sum_{i=1}^n (X_i - \mathbb{E}[X_i]) \leq -t\right) \leq \exp\left(-\frac{2nt^2}{(b-a)^2}\right).P(n1​i=1∑n​(Xi​−E[Xi​])≥t)≤exp(−(b−a)22nt2​)P(n1​i=1∑n​(Xi​−E[Xi​])≤−t)≤exp(−(b−a)22nt2​).
(25)

We also have the two-sided version:

P(∣1n∑i=1n(Xi−E[Xi])∣≥t)≤2exp⁡(−2nt2(b−a)2).P\left(\left|\frac{1}{n}\sum_{i=1}^n (X_i - \mathbb{E}[X_i])\right| \geq t\right) \leq 2\exp\left(-\frac{2nt^2}{(b-a)^2}\right).P(∣∣​n1​i=1∑n​(Xi​−E[Xi​])∣∣​≥t)≤2exp(−(b−a)22nt2​).
(26)

In the case where the XiX_iXi​ are identically distributed with mean μ\muμ, we can rewrite the first version as:

P([1n∑i=1nXi]−μ≥t)≤exp⁡(−2nt2(b−a)2)\mathbb{P}\left(\left[\frac{1}{n}\sum_{i=1}^n X_i\right] - \mu \geq t\right) \leq \exp\left(-\frac{2nt^2}{(b-a)^2}\right) \\P([n1​i=1∑n​Xi​]−μ≥t)≤exp(−(b−a)22nt2​)
(27)

This is a remarkable result! Recall that the Central Limit Theorem tells us that a similar result holds asymptotically: that is, for large values of nnn, the sample mean converges to a normal distribution, and therefore, the probability of obtaining a value far from the mean decreases as e−t2e^{-t^2}e−t2. But this statement holds for any value of nnn: whether nnn is small or big, or the distribution of the XiX_iXi​ is “nice” or not, this is true for the sample mean of any bounded random variables.

We can also know it without knowing anything else about the distribution of the random variables XiX_iXi​, other than some bounds on them.

Just as before, we can make some observations:

  • How fast does our bound increase as ϵ\epsilonϵ gets small? Solving for an upper confidence bound α(ϵ)\alpha(\epsilon)α(ϵ), we see that ϵ=MX(λ)eλα\epsilon = \frac{M_X(\lambda)}{e^{\lambda \alpha}}ϵ=eλαMX​(λ)​. Solving for α\alphaα (see below for an example), we can see that it grows as log⁡(ϵ−1)\log(\epsilon^{-1})log(ϵ−1): this is much, much slower than our previous two results! So, if we can find a class of random variables where the MGF is known (or bounded, as in the previous observation), then we can place much tighter bounds on those random variables.

Concentration Inequalities and Confidence intervals¶

We’ve seen many times that if we have an estimator θ^\hat{\theta}θ^, we can construct a confidence interval for that estimator by using the distribution of θ^\hat{\theta}θ^. Up until now, we’ve relied on either the bootstrap, computing the distribution exactly, or using the Central Limit Theorem to approximate it.

But, all of the methods we just discussed are applicable to any random variable! So, we could use any of them to construct a confidence interval for an estimator θ^\hat{\theta}θ^, especially if that estimator is a sample mean (but often even if it isn’t). While the other approaches are perfectly valid, there are often cases where we might prefer a confidence interval from concentration inequalities instead:

  • Why concentration inequalities over computing the distribution exactly? As we’ve already discussed, in many cases, we many not know the distribution of our random variables exactly, and computing the distribution exactly may not be feasible.

  • Why concentration inequalities over bootstrap? Using the bootstrap requires us to observe data and use that data to generate bootstrap resamples. In some cases, if we want to show a theoretical confidence interval before observing any data, it’s useful to use concentration inequalities.

  • Why concentration inequalities over the Central Limit Theorem? As we’ve already discussed, the Central Limit Theorem only applies for large values of nnn, while the results we’ve derived here are applicable for any value of nnn, and for any shape of distribution.
